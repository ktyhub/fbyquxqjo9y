hoppscotch 2026.8.0

这个项目是干啥的：一个开源版的 Postman，在浏览器或桌面端就能发请求、调接口、做 API 测试，还能团队共享，给前后端开发者和测试人员用。

变更架构图

亮点

  • REST-GQL 统一工作区 — REST 与 GraphQL 请求现在可以共存在同一个工作区（#6545），混合协议 API 项目不必再按请求类型拆分。经常同时用两种协议的团队值得升级。
  • 数据驱动的集合运行 — 集合运行现在可以使用 CSV 或 JSON 数据集（#6513），无需手动改请求即可参数化并重复测试场景。需要多样输入的 API 测试流程值得升级；只跑基础静态集合的用户可跳过。
  • 可靠性与安全修复 — 保存文档时请求标签页描述不再丢失（#6592），连接超时、桌面实例恢复认证、Set-Cookie 回退和仅主机 cookie 处理也都得到纠正（#6584、#6587、#6586、#6585）。本版本还应用了依赖链安全补丁（#6604），注重安全的用户以及依赖 cookie 或桌面认证的用户应更新。
  • 升级指引 — changelog 未列出破坏性变更或必需的迁移步骤。多数用户应为了安全补丁和错误修复而升级；既不需要新工作区/数据集功能、也不受这些修复影响的用户，才有把握跳过。

此版本将 REST 和 GraphQL 请求整合到一个工作区中，添加了使用 CSV 或 JSON 数据文件运行的数据驱动收集，并修复了保存时请求文档丢失的问题，以及安全补丁和错误修复。
