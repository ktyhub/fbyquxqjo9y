小版本 发布时间2026年8月31日 来源charmbracelet/crush 英文原文

#粉碎v0.92.0

紧凑退出横幅 + 模式

此版本包括一些修复和用户体验改进。

紧凑退出横幅

如果您愿意，现在可以将退出横幅配置得更紧凑。 .crushrc：

option ui exit-banner compact
option ui exit-banner none
option ui exit-banner default  # default

crush.json：

{
  "options": {
    "tui": {
      "exit_banner": "compact"
    }
  }
}

默认值： 紧凑：

代理修复

我们对 Fantasy 进行了相当多的修复，以使其更加稳定，并修复了一些推理提供程序的一些问题。

小 Bash 配置修复

@devYRPoli 对 Bash 配置进行了修复。添加模型时，--price-cache-create 和 --price-cache-hit 被交换，但此问题现已解决。 魅力团队
