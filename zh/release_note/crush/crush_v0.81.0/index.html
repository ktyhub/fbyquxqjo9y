crush v0.81.0

小版本 发布时间2026年6月29日 来源charmbracelet/crush 英文原文

#粉碎v0.81.0

给你一些用户体验的东西

我们通过添加一些不错的添加和改进以良好的方式开始这一周。

聊天滚动条

就是这样，聊天刚刚有了滚动条！这应该会让您在长时间的导航过程中更加轻松。现在，您可以在滚动时准确地看到自己所在的位置。 可以通过以下设置调整行为：options.tui.scrollbar。

  • default（2秒后隐藏）
  • always
  • never
{
  "options": {
    "tui": {
      "scrollbar": "default" // default, always, never
    }
  }
}

https://github.com/user-attachments/assets/c0c0f888-78d4-4457-ae32-eb1a2dd5f575

牧民支持

您是否一直想使用 herdr.dev 来满足您的所有代理管理需求？好吧，现在更好了！ @taciturnaxolotl 合并了对代理状态信号的支持，因此现在 herdr 可以了解 CRUSH 的状态，并在它被阻止或完成时向您发送通知！

降低CPU使用率

当流式传输思维轨迹并为您显示它们时，Crush 可能会使用过多的 CPU。 @taciturnaxolotl 进行了优化，现已修复！

修复启动时可能出现的死锁

如果您的配置中碰巧有一个不再存在的型号 ID（已从提供程序中删除），Crush 可能会在启动时锁定并且根本无法启动。此错误已得到解决。

图像和你的会话

这是另一个修复程序，可防止当您切换到非视觉模型但会话已有图像时会话中断。我们将跳过图像，以便您的会话继续进行。 就这样！ 魅力
