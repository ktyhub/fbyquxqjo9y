crush v0.80.0

小版本 发布时间2026年6月25日 来源charmbracelet/crush 英文原文

#粉碎v0.80.0

老周四补丁

大家好！现在是补丁时间，也是一些奖励功能的时间。我们走吧！

修复损坏的工具调用

有时，模型会选择使用无效参数（无效的 JSON）进行工具调用，会话刚刚中断，甚至新的提示也不再出现。我们现在正在验证该问题并将其作为错误报告给模型，以便模型可以自行纠正。当然，我们还修复了 Crush 中的相关错误，因此会话将不再中断。

本地模型：自动检测上下文窗口

谁喜欢本地型号？现在，Crush 现在将自动检测模型上下文窗口，并为 llamacpp、omlx、lmstudio、litellm 和 ollama 添加端点。在此之前，它错误地将窗口大小设置为零。

配置：更难、更快、更强

好吧，也许并不难。但 Crush 中的配置绝对更快更强。 我们对其进行了重构，因此对于有许多提供者、模型等的大而长的配置来说，它的性能更高、更安全。这也意味着模型选择器对话框的加载速度也会更快！我们还添加了一些保护措施，以防止多个 Crush 实例同时尝试更新配置时出现竞争情况。
