#粉碎v0.88.1

是时候进行错误修复了

此版本主要关注稳定性和生活质量，并针对 MCP、服务器-client 和零碎内容进行了一系列修复。这是里面的内容：

  • UX: 在命令中输入 clear 将匹配 Summarize；谢谢，@joestump！
  • LSP： @piakdev 修复了 LSP 可能出现恐慌的情况
  • MCP： 加载缓慢的 MCP 可能会阻止消息发送：我们减少了默认超时
  • 服务器-Client： MCP OAuth 在服务器-client 模式下不起作用；现在确实如此
  • **服务器-Client：**同一工作区中的 Client 可能会互相杀死：不再是了
  • Server-Client： 当服务器通过 TCP 运行时，击键不再影响服务器并减慢一切速度
  • Hyper： 添加了各种小改进以获得更好的用户体验 感谢您使用 Crush。周末愉快！ 魅力💌
