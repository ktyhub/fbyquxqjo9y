#粉碎v0.85.0

如果您有疑问，我们有答案

此版本为我们带来了一个问题工具（终于！）以及一堆错误修复和细节。我们走吧！

提问工具

那么！ Crush 现在附带了一流的问题工具，当法学硕士想要拷问你时非常有用。问题工具有多种形式，如单选、多选、自由格式文本和是/否。问题也可以组合在一起构建一个表格。

你说什么？ “有鼠标支持吗？”为什么，是的。

这是什么巫术？只有@taciturnaxolotl 知道。他在 [Hyper](https://hyper.charm.land) 上仅使用开源模型单独完成了整个功能。 ## 快点等待吧 你是否曾经把法学硕士投入到工作中，却忘记了它，回来后想知道它已经运转了多久？ @andrinoff确实做到了。不再好奇了。

Perf：滚动条优化以加快渲染速度 * Perf：记忆标记渲染器以加快渲染速度 * Perf：如果转弯在开始前取消，则短路 `jq` 内置操作 * 耶！ OpenAI 合并了我们上游的 PR，所以我们放弃了分叉 系好安全带，我们还有更多人来。 呵呵， 魅力💘 ## Changelog ### 新！ *
