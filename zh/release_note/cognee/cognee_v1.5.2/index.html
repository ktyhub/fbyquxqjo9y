cognee v1.5.2

修订 发布时间2026年8月22日 来源topoteretes/cognee 英文原文

发布日期： 2026-08-22 更改： v1.5.2 → 主要

总结

此补丁版本的重点是使 Cognee 更加可靠并提高日常查询的搜索相关性。它包括有针对性的错误修复、更清晰的错误消息、摄取和搜索性能改进以及更安全的 API 行为的内部强化。

变更架构图

亮点

  • 改进了简短且不明确的查询的搜索相关性，因此答案更有用。
  • 为大量上传和批量导入提供更快、更可靠的数据摄取。
  • 更清晰的错误消息和日志使调试和集成更容易。
  • 多个错误修复和内部强化，以减少同步失败和崩溃。

重大变更

  • v1.5.2 中没有重大变化。升级对所有用户来说都是安全的，但我们建议在部署到生产环境之前在暂存阶段测试摄取和搜索工作流程。

新功能

  • v1.5.2中没有添加主要的新功能模块。此版本侧重于面向用户的改进：搜索现在可以更好地解释简短查询（因此，当您使用简短短语搜索时，您将获得更相关的结果），并且摄取路径经过强化，可以更可靠地完成大型导入。

改进

  • 搜索相关性：调整搜索排名逻辑可以改善简短或模糊查询的结果，这意味着您将看到更直接相关的文档和更少的嘈杂匹配。
  • 摄取可靠性：上传和批量导入过程对于中断和暂时性错误更加稳健，从而减少了部分数据集导入或失败的数据集导入的可能性。
  • 开发人员体验：API 和 SDK 返回的错误消息已得到澄清，包括可操作的提示（出了什么问题以及常见的后续步骤），从而可以更快地诊断集成问题。
  • 日志记录和可观察性：内部日志为数据集同步和查询生命周期事件提供更清晰的标记，因此支持和调试更容易。

性能

  • 减少了常见场景中搜索查询的延迟（短/短语查询的显着改进），因此交互式搜索可以更快地返回答案。
  • 改进了大文件摄取期间的内存处理，以避免以前可能导致超时或重试的峰值。

安全

  • 加强了公共 API 端点的输入验证和错误处理，以减少格式错误的请求导致不一致状态的可能性。这提高了集成第三方数据源时的整体稳健性。

错误修复

  • 修复了可能导致数据集同步在间歇性网络中断后停止的情况。
  • 解决了高并发摄取作业期间罕见的崩溃问题。
  • 更正了误导性的 API 错误消息，该消息使一些暂时性故障看起来是永久性的。
  • 修复了小/短查询有时返回相关性较低的结果的问题。

技术变更

  • 对数据集同步和摄取代码进行内部重构，以简化重试行为并提高可维护性。
  • 依赖性更新和轻微的 SDK 改进，以在网络故障期间实现更稳健的 client 行为。
  • 改进了围绕搜索排名和数据集同步的单元和集成测试。
