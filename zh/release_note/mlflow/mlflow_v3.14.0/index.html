mlflow v3.14.0

小版本 发布时间2026年6月17日 来源mlflow/mlflow 英文原文

mlflow v3.14.0

变更流程图

亮点

  • GenAI/agent 工作流是主线 — v3.14.0 以 agent 工具为核心：mlflow agent setup 一条命令完成接入（追踪 + 面向 Claude Code、Codex 和 OpenCode 的 MLflow 技能），背后是由 MlflowWalSpanExporter 和 WAL 守护进程支撑的持久、低延迟 Claude Code 追踪，即使网络抖动或崩溃也不丢 trace，还不拖慢 agent。新增内容还有：能把结构化标注写回 trace 的审查队列、改版的评估数据集 UI、通过 @mlflow.test 标记做的 pytest 回归测试（EvaluationResult.passed/.reason），以及接通 AI Gateway 与 Prompt Registry 的 LLM Playground。构建或评估 GenAI 应用的团队获益最大；纯传统机器学习的用户收获有限。
  • 破坏性——三种 flavor 的模型序列化默认值变了 — mlflow.sklearn 的 serialization_format 默认值从 cloudpickle 改为 skops（#23987），mlflow.pytorch.log_model/save_model 默认改为 "pt2"（#23988），mlflow.lightgbm 的 log_model/save_model 默认改为 "skops"（#23986）。迁移：如果你依赖旧默认值来保证产物兼容或可复现，请在升级前于 log/save 调用里显式钉住 serialization_format（如 cloudpickle）——否则新记录的模型序列化方式不同，旧环境可能无法加载。
  • 评估/追踪成为可用的自托管平台 — 新增基于规则的 scorer（RegexMatch、PIIDetection、ResponseLength）、Google ADK judge（Hallucination、Safety、ResponseEvaluation）、MLFLOW_GENAI_JUDGE_DEFAULT_MODEL、OSS 原生标签 schema（实体 + SQL 存储 + REST）、用于 trace 摄取/API 的 x-mlflow-run-id 与 run_id 支持、用于 UC trace 的 MLFLOW_TRACE_LOCATION（Claude Code/Codex），以及 OSS auth provider 中的 MLFLOW_WORKSPACE。配合 POST /mlflow/genai/evaluate/invoke 处理器，这些减少了对 Databricks 托管专属特性的依赖。
  • 值得拥有的安全与可靠性加固 — 拒绝项目 zip 解压中的路径穿越（#23713），为 /ajax-api/3.0/mlflow/get-trace-artifact 注册 auth 校验器（#23317），配置为通配来源时禁用带凭据的 CORS（#23178），并修复了全新数据库上的 mlflow db upgrade（#23752）以及 CLOSE_WAIT socket 上 _stop_listen_for_spark_activity 的挂起（#23839）。自托管/运维部署单凭这些就应升级。
  • 结论 — GenAI/agent 团队（agent 接入、WAL 追踪、审查队列、@mlflow.test 回归闸门、playground）以及需要这些安全修复的人值得升级；如果你只做传统模型记录、且想避开序列化默认值变化，可以安全跳过——那种情况下先按兵不动，等你在 mlflow.sklearn、mlflow.pytorch 和 mlflow.lightgbm 调用里显式钉住 serialization_format 再说。

MLflow 3.14.0 包括几项主要功能和改进

主要新功能

  • 🚀 用 mlflow agent setup 一条命令接入 agent：安装 MLflow、设置追踪，并把 MLflow 技能交给你喜欢的编码 agent（Claude Code、OpenAI Codex 或 OpenCode）来检测你的应用，全部通过一条命令完成。
  • ⚡ 为 Claude Code 提供持久、低延迟的追踪：放心地在整个团队推广 Claude Code 追踪：预写日志（write-ahead-log）避免它拖慢 agent、压垮追踪服务器，或在网络抖动/崩溃时丢失 trace。
  • 📝 trace 审查队列：把 trace 指派给审查者（或 agent），在 UI 中收集结构化反馈和真实值标注，直接写回 trace，可立即用于评估。
  • 🗂️ 改版的评估数据集 UI：直接在 UI 中浏览、检查、编辑和批量管理评估数据集记录，并可点击跳转到源 trace。
  • 🧪 用于回归测试的 Pytest 集成：用带 @mlflow.test 标记的普通 pytest 函数编写 GenAI 回归测试，在 CI 中设闸门，并在 UI 里查看测试历史和逐断言的 judge 结果。
  • 🎛️ LLM Playground：在浏览器里针对你的 AI Gateway 端点和 Prompt Registry 版本迭代提示词，支持设置、工具、结构化输出和模板变量。

破坏性变更

  • [模型] 将 mlflow.sklearn 的 serialization_format 默认值从 cloudpickle 改为 skops（#23987、@copilot-swe-agent）
  • [模型] 将 mlflow.pytorch.log_model 和 mlflow.pytorch.save_model 的 serialization_format 默认值改为 "pt2"（#23988、@copilot-swe-agent）
  • [模型] 将 mlflow.lightgbm 的 log_model/save_model 中 serialization_format 默认值改为 "skops"（#23986、@copilot-swe-agent）
