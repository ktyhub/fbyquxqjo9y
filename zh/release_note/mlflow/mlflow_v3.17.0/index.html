mlflow v3.17.0

这个项目是干啥的：一个机器学习全流程管理平台，能跟踪实验、管模型、支持AI智能体工作流，给做模型训练和上线的团队用。

变更架构图

亮点

  • 破坏性的数据库升级 — 这不是滚动式的小版本升级：SQL 后端的服务器必须停止所有写入方、做一次可恢复的备份、运行 mlflow db upgrade <database-url>，然后在 v3.17.0 上重启每个副本。即使每日汇总仍关闭，schema 变更也是强制的；不支持混合版本运行。
  • 共享服务器的访问控制与隐私 — 细粒度 RBAC 现在支持对包含的产物（如 run、trace 和模型版本）使用通配授权和显式 DENY。MLflow Assistant 的对话限定于已登录用户，且账号切换时活动会话会重置——对共享或多用户服务器很重要。
  • TypeSafe/Jev 评估、Gateway 与追踪 — 内置 scorer 和自定义 judge 现在在这些界面都支持类型化的布尔或分类反馈。自定义 base_url 和 typesafe_api_base 端点、@mlflow/typesafe 追踪/autologging，以及 System One/OpenRouter judge 支持，拓宽了 provider 集成。对 TypeSafe/Jev 用户是很有说服力的升级，对其他人的影响较小。
  • Trace 分析与评估溯源 — 可选的 SQL 每日汇总降低了大型 trace 数据集的分析开销，同时保留原始查询回退。聚合的已记录模型评估指标现在与其托管的源数据集关联，提升了结果的可追溯性。
  • 可靠性、安全与升级结论 — 大量修复改进了 Gateway 工具调用流式传输、Unicode trace 搜索、UTF-8 工件处理和分页。共享或对外暴露的部署尤其应为这些修复而升级：工件主机限制、protobuf 字段混淆、实验授权、scorer 模块匹配，以及嵌套模型版本 GraphQL 权限修复（GHSA-mr9f-g8qf-4w4j、GHSA-3g8m-hm3x-gh2r、GHSA-26p8-2jq9-3vq9、GHSA-f253-vggg-rwh8）。GenAI 密集型团队和共享 SQL 后端部署收益很大；其他团队若能承受强制的数据库维护、且不受这些安全修复影响，可以延后。

MLflow 3.17.0 包括几项主要功能和改进。

主要新功能

  • 跨评估、Gateway 和追踪的 Jev 决策：在内置 scorer 和自定义 judge 中使用 TypeSafe 模型，提供类型化的布尔或分类反馈。（#26100、@B-Step62）
  • 共享资源的细粒度权限：用通配授权和显式 DENY 控制对包含的资源类型（包括 run、trace 和版本）的访问。（#26157、@rrrkharse）
  • 大型 trace 数据集的更快分析：通过可选的每日汇总降低 SQL 分析查询开销，并保留原始查询回退。（#25991、@HumairAK）
  • 更清晰的评估结果：把聚合的已记录模型评估指标与其产生自的托管数据集关联起来。（#25927、@joshuawong-db）
  • 面向共享服务器的 Assistant 改进：把保存的对话限定于已登录用户，账号切换时重置活动会话。（#26009、@kriscon-db）

数据库升级： SQL 后端的服务器需要一次协调的 schema 升级，须停止所有写入方并做好可恢复备份，即使每日汇总仍关闭也一样。在所有副本重启到新 MLflow 版本前，先运行 mlflow db upgrade <database-url>。不支持混合版本的滚动升级。请遵循数据库升级说明。

MLflow 3.17.0 包括几个主要功能和改进。

主要新功能

  • 跨评估、网关和跟踪的 Jev 决策：在内置评分器和自定义法官中使用 TypeSafe 模型，并提供类型化布尔或分类反馈。 （＃26100，@B-Step62）
  • 共享资源的细粒度权限：通过通配符授予和显式拒绝控制对包含的资源类型（包括运行、跟踪和版本）的访问。 （＃26157，@rrrkharse）
  • 大型跟踪数据集的更快分析：通过选择每日摘要和原始查询回退来减少 SQL 分析查询开销。 （＃25991，@HumairAK）
  • 更清晰的评估结果：将聚合记录模型评估指标与生成这些指标的托管数据集关联起来。 （＃25927，@joshuawong-db）
  • 共享服务器的辅助改进：将保存的对话范围保持在登录用户范围内，并在帐户更改时重置活动会话。 （＃26009，@kriscon-db）

数据库升级： SQL 支持的服务器需要协调架构升级，所有编写器都停止，并需要可恢复的备份，即使每日汇总仍处于禁用状态。在新的 MLflow 版本上重新启动所有副本之前运行 mlflow db upgrade <database-url>。不支持混合版本滚动升级。按照数据库升级说明。
