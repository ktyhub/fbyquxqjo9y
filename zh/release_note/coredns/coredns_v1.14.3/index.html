coredns v1.14.3

此版本引入了 Windows 服务支持以及完整的 TSIG 验证 跨 DoH、DoH3、QUIC 和 gRPC 传输，并改进了 TSIG 传播和 DoH 请求验证。它还为指标端点添加了可选的 TLS。性能 通过缓存预取、QUIC 优化和新的 转发插件中的 max_age 选项。其他更新包括增强的 SVCB/HTTPS 支持、改进的区域传输行为以及各种 DNSSEC、PROXY 协议和 并发修复。该版本是用 Go 1.26.2 构建的，其中包括安全性 修复了 CVE-2026-32282、CVE-2026-32289、CVE-2026-33810、CVE-2026-27144、 CVE-2026-27143、CVE-2026-32288、CVE-2026-32283 和 CVE-2026-27140，还包括 修复了 CVE-2026-32936、CVE-2026-33190、CVE-2026-33489、CVE-2026-32934 和 CVE-2026-35579。
