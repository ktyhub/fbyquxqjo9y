coredns v1.15.0

此版本改进了 DNS 缓存、转发和传输可靠性， 修复过时缓存处理、上游连接、崩溃/竞争修复， 以及许多插件的增强。 转发现在支持 DNS-over-QUIC 上游。其他新功能包括 可选的 JSON 查询日志记录、经过身份验证的 RFC 2136 动态 DNS 更新、SIIT 支持、 expr-lang 模板和 PROXY 协议 v2 元数据。 该版本使用 Go 1.27.3 构建，涵盖 CVE-2026-56865、CVE-2026-56864、 CVE-2026-33818、CVE-2026-97032、CVE-2026-78659、CVE-2026-97031 和 CVE-2026-111943，以及 其他安全修复。
