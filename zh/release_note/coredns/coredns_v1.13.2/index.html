coredns v1.13.2

此版本增加了对 DoH3 的初步支持，并包括多个核心性能和稳定性 修复，包括减少分配、解决 uniq 中的数据竞争以及更安全的 QUIC 侦听器 初始化。插件更新提高了转发器的可靠性，扩展了 GeoIP 架构支持， 并修复 secondary、nomad 和 kubernetes 中的问题。缓存和文件插件也接收 有针对性的性能调整。 弃用：GeoIP 插件当前因缺少纬度/经度而返回 0，即使 0,0 是真实位置。在下一个版本中，这种行为将会改变：缺少坐标 将返回一个空字符串。这避免了将“缺失”与真实坐标混为一谈。 依赖 0 作为标记值的用户应在此更改生效之前更新其逻辑。 请参阅 PR #7732 以供参考。
