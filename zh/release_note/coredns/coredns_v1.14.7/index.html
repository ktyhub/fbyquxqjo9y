coredns v1.14.7

此版本增强了 DNS 缓存、转发和传输可靠性， 改进的过时缓存行为、更安全的上游处理和更紧密的连接 和过载控制。它还为 ACME 管理的 TLS 添加了新功能， 拓扑感知 Kubernetes 服务、HTTP/2 转发、DNS-over-QUIC 和 辅助区域管理，同时提供正确性和性能修复 跨文件服务、重写、ACL、主机、传输和 Kubernetes 处理。 该版本是使用 Go 1.26.6 构建的，包含对 CVE-2026-56865 的修复， CVE-2026-56864 和 CVE-2026-33818。
