特点

  • claude: 在 VS Code 中支持 Claude Code (#2752) (13a310a)

  • kompress: 加载 v2 检查点的 merged.pt 而不是未合并的 PEFT safetensors (#2716) (46da91b)
  • kompress: 拒绝运行时失败的工件，并在启动时预取模型文件 (#2740) (224578e)
  • 学习： 过滤环境用户角色脚手架 (#2275) (3eb0122)
  • 学习： 在事件循环之外运行项目发现 (#2731) (a70e5ff)
  • 标准化 WebSocket 升级上的 /p/ 前缀，以便响应 WS 路由不会被 403 拒绝 (#2379) (789a4f3)
  • 提供者： 为每个模型提供一个分词器 (#2761) (cd92ed5)
  • 提供者： 阻止较短的模型系列遮蔽较长的模型系列 (#2762) (0cb72f4)
  • 提供商： 停止将现代内容块定价为零 (#2760) (06add9e)
  • 代理/成本： 标记估计基础预算记录并添加执行策略 (#2713) (#2725) (01df245)
  • 代理/调试： 协调 /debug/warmup 中的 Kompress 预热状态 (#2711) (3a27c4d)
  • proxy/openai: 对聊天完成运行工具描述压缩 (#2741) (f9db5b5)
  • 代理： 通过专用 /v1/live 传输路由 Codex Live 语音 (#2709) (232fb49)
  • **代理：**跳过 Codex client 的 OpenAI tool_search 延迟 (#2729) (56b3e4c)
  • **代理：**停止在 Anthropic 工具数组中切换 headroom_retrieve (#2672) (08fce29) *删除rtk和lean-ctx CLI上下文工具(#2677)(e0ce4b1)
  • 路由器： 停止将图像的 Base64 有效负载计算为后缀标记 (#2778) (f03cc6d)
  • 节省： 表面请求增长 tok_saved 夹吞 (#2708) (184146b)
