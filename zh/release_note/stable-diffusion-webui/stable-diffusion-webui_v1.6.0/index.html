stable-diffusion-webui v1.6.0

小版本 发布时间2023年8月31日 来源AUTOMATIC1111/stable-diffusion-webui 英文原文

stable-diffusion-webui v1.6.0

特点：

  • 精炼机支持 #12371
  • 为随机数生成器源设置添加 NV 选项，允许在 CPU/AMD/Mac 上生成与 NVidia 显卡上相同的图片
  • 添加样式编辑器对话框
  • 修复：添加一个选项以在第二遍中使用不同的检查点（#12181）
  • 在内存中保留多个加载模型的选项 (#12227)
  • 新采样器：重新启动、DPM++ 2M SDE 指数、DPM++ 2M SDE Heun、DPM++ 2M SDE Heun Karras、DPM++ 2M SDE Heun 指数、DPM++ 3M SDE、DPM++ 3M SDE Karras、DPM++ 3M SDE 指数 (#12300、 #12519、#12542)
  • 重新设计 DDIM、PLMS、UniPC 以使用与 k 扩散采样器中相同的 CFG 降噪器：
    • 使它们全部与 img2img 一起工作
    • 使快速合成成为可能（AND）
    • 使它们可用于 SDXL
  • 始终在 UI 中显示额外的网络选项卡 (#11808)
  • 创建模型时使用更少的 RAM (#11958, #12599)
  • SDXL 的文本反转推理支持
  • 额外网络 UI：显示 SD 检查点的元数据
  • 检查点合并：添加元数据支持
  • 提示编辑和注意：添加对数字后空格的支持 ([ red : green : 0.5 ]) (种子破坏更改) (#12177)
  • VAE：允许为每个检查点选择自己的 VAE（在用户元数据编辑器中）
  • VAE：将选定的 VAE 添加到信息文本中
  • 主 UI 中的选项：为 txt2img 和 img2img 添加自己的单独设置，从粘贴的信息文本中正确读取值，添加列数设置（#12551）
  • 向 txt2img 和 img2img 选项卡添加调整大小句柄，允许更改赋予生成参数和生成的图像库的水平空间量（#12687、#12723）
  • 更改批处理 cond/uncond 的默认行为 - 现在默认情况下启用它，并通过 UI 设置禁用（Optimizatios -> Batch cond/uncond） - 如果您使用 lowvram/medvram 并遇到 OOM 异常，则需要启用它
  • 显示队列中的当前位置并使其按照到达顺序处理请求（#12707）
  • 添加 --medvram-sdxl 标志，仅对 SDXL 型号启用 --medvram
  • 提示编辑时间线具有单独的第一次通过和雇用修复通过（种子破坏更改）的范围（[#12457]（https://github.com/AUTOMATIC1111/stable-diffusion-webui/pull/12457））

次要：

  • img2img 批次：RAM 节省、VRAM 节省、img2img 批次中的 .tif、.tiff (#12120、#12514、#12515)
  • 后处理/额外功能：节省 RAM (#12479)
  • XYZ：在轴标签中，从模型文件名中删除路径名
  • XYZ：支持雇用采样器（[#12298]（https://github.com/AUTOMATIC1111/stable-diffusion-webui/pull/12298））
  • XYZ：新选项：使用文本输入而不是下拉菜单（#12491）
  • 添加gradio版本警告
  • 对 VAE 检查点列表进行排序 (#12297)
  • 在修复中使用透明白色蒙版，以及选择颜色的选项 (#12326)
  • 将一些设置移动到自己的部分：img2img、VAE
  • 添加复选框以显示/隐藏额外网络的目录
  • 为所有 VAE 编码/解码操作添加 TAESD（或更多）选项（#12311）
  • 渐变主题缓存，新的渐变主题，以及用户可以输入自己的值的说明（#12346、#12355）
  • 采样器修复/调整：s_tmax、s_churn、s_noise、s_tmax (#12354、#12356、#12357、#12358、 #12375、#12521)
  • 使用 Linux 安装的正确说明更新 README.md (#12352)
  • 不保存不完整图像的选项，默认开启 (#12338)
  • 默认启用 cond 缓存
  • git 自动修复已损坏的存储库 (#12230)
  • 允许通过鼠标中键在新浏览器选项卡中打开图像（#12379）
  • 在“本地”运行时自动在浏览器中打开 webui (#12254)
  • 将常用的采样器放在顶部，使 DPM++ 2M Karras 成为默认选择
  • 缩放和平移：自动扩展宽图像的选项，改进的集成（#12413、#12727）
  • 在内存中缓存 Lora 网络的选项
  • 返工雇用修复 UI 以使用手风琴
  • 面部恢复和平铺移至设置 - 如果您希望恢复它们，请使用“主 UI 中的选项”设置
  • 更改快速设置项目以具有可变宽度
  • Lora：添加 Norm 模块，添加对偏差的支持 (#12503)
  • Lora：在 UI 中输出警告，而不是因不适合 Loras 而失败；切换到控制台中的错误输出日志记录
  • 支持搜索和显示所有额外网络项目的哈希值 (#12510)
  • 为 img2img 操作添加额外的噪声参数 (#12564)
  • 支持带有偏见的 Lora (#12584)
  • 使中断更快 (#12634) *可配置的画廊高度（#12648）
  • 使结果列粘性（#12645）
  • 更多哈希文件名模式 (#12639)
  • 使图像查看器实际上适合整个页面 (#12635)
  • 使进度条独立于实时预览显示工作，从而使其更新得更频繁
  • 禁止medvram的完整实时预览方法并添加一个设置来撤消禁止
  • 可以本地化工具提示和占位符
  • 添加选项以与 sgm 存储库的采样实现保持一致（#12818）
  • 恢复面和平铺生成参数已移至主 UI 之外的设置
    • 如果您想将它们放回主 UI，请使用 UI 页面上的 Options in main UI 设置。
