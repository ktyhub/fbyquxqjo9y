stable-diffusion-webui v1.1.0

小版本 发布时间2023年5月1日 来源AUTOMATIC1111/stable-diffusion-webui 英文原文

stable-diffusion-webui v1.1.0

特点：

  • 切换到手电筒 2.0.0（AMD GPU 除外）
  • 自定义代码脚本的视觉改进
  • 添加文件名模式：[clip_skip]、[hasprompt<>]、[batch_number]、[ Generation_number]
  • 添加对在 img2img 中保存初始化图像的支持，并在信息文本中记录它们的哈希值以实现可重复性
  • ctrl+up/down调整权重时自动选择当前单词
  • 添加 X/Y/Z 图的下拉菜单
  • 设置：稳定扩散/随机数生成器源：可以使给定手动种子生成的图像在不同 GPU 上保持一致
  • 支持Gradio的主题API
  • Linux上默认使用TCMalloc；可能修复内存泄漏 *（优化）选项以消除低西格玛值的负面条件#9177
  • 在.safetensors 文件中嵌入模型合并元数据
  • 扩展设置备份/恢复功能#9169
  • 在 img2img 中添加“调整大小”和“调整大小”选项卡
  • 在文本反转图像预处理中添加“保持原始大小”选项
  • 通过模拟摇杆滚动图像查看器
  • 按钮用于恢复会话丢失/选项卡重新加载的进度

次要：

  • 渐变升至 3.28.1
  • 在额外选项卡中，将额外选项“缩放至”更改为滑块
  • 为工具按钮添加标签以使其可以隐藏
  • 添加对 ScuNET 的平铺推理支持
  • 添加对扩展安装的分支支持
  • 更改 linux 安装脚本以安装到当前目录而不是 /home/username
  • 按名称对文本反转嵌入进行排序（不区分大小写）
  • 允许 styles.csv 符号链接或安装在 docker 中
  • 删除“不为图像添加水印”选项
  • 使选定的选项卡可通过 UI 配置进行配置
  • 额外的网络 UI 现在固定高度且可滚动
  • 添加disable_tls_verify arg以与自签名证书一起使用

扩展：

  • 添加重新加载回调
  • 添加is_hr_pass字段进行处理

错误修复：

  • 修复“附加/批处理”选项卡上损坏的批处理图像处理
  • 在额外网络下拉列表中添加“无”选项
  • 修复 CLIP 询问器的 FileExistsError
  • 修复 /sdapi/v1/txt2img 端点在 Linux 上不起作用 #9319
  • 修复缓慢任务期间实时预览和进度条消失的问题
  • 修复全屏图像视图在某些情况下无法正常工作的问题
  • 防止alwayson_scripts args参数在插入script_arg列表时调整其大小
  • 修复二阶采样器的提示时间表
  • 修复图像遮罩/复合以获得奇怪的分辨率#9628
  • 使用 AND 时使用正确的图像进行预览（请参阅#9491）
  • img2img 批次中的一张损坏的图像不会停止所有处理
  • 修复训练/预处理中的图像方向错误
  • 修复 Ngrok 每次重新加载时重新创建隧道的问题
  • 修复 —realesrgan-models-path 和 —ldsr-models-path 不起作用
  • 修复 —skip-install 不起作用
  • Outpainting Mk2 & Poorman 应使用 SAMPLE 文件格式保存图像，而不是 GRID 文件格式
  • 如果制作图片时某些 Loras 加载失败，请不要让所有 Loras 失败
