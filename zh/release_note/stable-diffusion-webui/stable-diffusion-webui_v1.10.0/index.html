stable-diffusion-webui v1.10.0

稳定扩散-webui v1.10.0

特点：

*大量性能改进（见下面的性能部分）

  • 稳定扩散 3 支持（#16030、#16164、#16212）
    • 推荐的欧拉采样器；目前不支持 DDIM 和其他时间戳采样器
    • T5文本模型默认关闭，需要在设置中启用
  • 新的调度程序：
    • 调整你的脚步 (#15751)
    • KL 最优 (#15608)
    • 正常 (#16149)
    • DDIM (#16149)
    • 简单 (#16142)
    • 测试版（#16235）
  • 新采样器：DDIM CFG++ (#16035)

次要：

  • 选择在早期步骤中跳过 CFG (#15607)
  • 添加 —models-dir 选项 (#15742)
  • 允许移动用户使用两根手指按下打开上下文菜单 (#15682)
  • 信息文本：添加 Lora 名称作为捆绑文本反转的 TI 哈希值 (#15679)
  • 下载后检查模型的哈希值以防止下载损坏 (#15602)
  • 更多扩展标签过滤选项 (#15627)
  • 保存 AVIF 时，使用 JPEG 的质量设置 (#15610)
  • 添加文件名模式：[basename] (#15978)
  • 添加选项以启用 SDXL 上 clip L 的 clip 跳过 (#15992)
  • 在生成过程中防止屏幕休眠的选项（#16001）
  • 在图像查看器中切换 LivePriview 按钮 (#16065)
  • 删除重新加载和快速滚动时的 ui 闪烁 (#16153)
  • 禁用保存按钮 log.csv 的选项（#16242）

扩展和 API：

  • 添加 process_before_every_sampling 钩子 (#15984)
  • 在无效采样器错误时返回 HTTP 400 而不是 404 (#16140)

性能：

  • [性能 1/6] use_checkpoint = False (#15803)
  • [性能 2/6] 用 torch 本机操作替换 einops.rearrange (#15804)
  • [性能 4/6] 预计算 is_sdxl_inpaint 标志 (#15806)
  • [性能 5/6] 防止不必要的额外网络偏差备份 (#15816)
  • [性能 6/6] 添加 — precision half 选项以避免推理过程中的强制转换 (#15820)
  • [性能] LDM 优化补丁 (#15824)
  • [性能] 在 CPU 上保留 sigmas (#15823)
  • 在完成所有步骤后，仅检查unet中的nans一次
  • 添加了运行 torch profiler 来生成图像的选项

错误修复：

  • 修复没有全面信息文本的网格（#15958）
  • 壮举：lora 部分更新先于完整更新 (#15943)
  • 修复文件扩展名有多余“.”的错误在某些情况下（#15893）
  • 修复损坏的模型初始加载循环 (#15600)
  • 允许 API 中的旧采样器名称（#15656）
  • 更多旧采样器调度程序兼容性（#15681）
  • 修复 Hypertile xyz (#15831)
  • XYZ CSV 跳过初始空间 (#15832)
  • 修复 mps 和 xpu 上的软修复，torch_utils.float64 (#15815)
  • 修复不在主分支上时的扩展更新 (#15797) *更新pickle安全文件名
  • 使用 webui-assets css 的相对路径 (#15757)
  • 创建虚拟环境时，升级webui.bat/webui.sh中的pip (#15750)
  • 修复属性错误 (#15738)
  • 在 launch_utils 中使用 script_path 作为 webui 根目录 (#15705)
  • 修复额外批处理模式 P 透明度 (#15664)
  • 在 css 中使用渐变主题颜色 (#15680)
  • 修复提示输入中拖动文本的问题 (#15657)
  • 为 .mjs 文件添加正确的 mimetype (#15654)
  • QOL Items - 更干净地处理 SD 模型、Loras 和嵌入的元数据问题 (#15632)
  • 将 wsl-open 替换为 wslpath 和 explorer.exe (#15968)
  • 修复 SDXL 修复 (#15976)
  • 多尺寸网格（#15988）

  • 停止生成额外内容 (#16085)

  • [bug] 不要破坏非作业操作的进度条（添加wrap_gradio_call_no_job）（[#16202]（https://github.com/AUTOMATIC1111/stable-diffusion-webui/pull/16202））
  • 修复 OSError: 无法将模式 P 写入 JPEG (#16194)
