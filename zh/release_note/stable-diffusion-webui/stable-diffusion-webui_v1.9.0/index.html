stable-diffusion-webui v1.9.0

稳定扩散-webui v1.9.0

1.9.0

特点：

  • 根据模型时间步长而不是采样步数进行精炼器切换 (#14978)
  • 添加一个选项以使用旧式目录视图而不是树视图；额外网络排序/搜索控件的风格更改
  • 添加用于重新排序回调的 UI，支持在扩展元数据中指定回调顺序 (#15205)
  • SDXL-Lightning 型号的 Sgm 统一调度程序 (#15325)
  • 主 UI 中的调度程序选择（#15333、#15361、#15394）

次要：

*“打开图像目录”按钮现在打开实际目录（#14947）

  • 支持 LyCORIS BOFT 网络推理（#14871、#14973）
  • 默认情况下将额外的网卡描述设为纯文本，并可以选择重新启用 HTML
  • 调整额外网络的句柄大小 (#15041)
  • cmd 参数：--unix-filenames-sanitization 和 --filenames-max-length (#15031)
  • 在 HTML 表中显示额外的网络参数，而不是原始 JSON (#15131)
  • 添加对 LoRA/LoHa/LoKr 的 DoRA（权重分解）支持（#15160、#15283）
  • 添加“—no-prompt-history”cmd 参数以禁用上一代提示历史记录（#15189）
  • 更新替换预览上的预览 (#15201)
  • 仅获取扩展程序的活动 git 分支的更新 (#15233)
  • 将高档后处理 UI 放入手风琴中 (#15223)
  • 支持拖放 URL 来读取信息文本 (#15262)
  • 使用diskcache库进行缓存(#15287, #15299)
  • 允许 PNG-RGBA 用于“附加”选项卡 (#15334)
  • 支持嵌入 safetensors 元数据中的封面图像 (#15319)
  • 使用 NN 高档时更快的中断 (#15380)
  • Extras upscaler：限制输出图像最大边长的输入字段（#15293、#15415、#15417、#15425)
  • 在“附加”选项卡中添加隐藏后处理选项的选项

扩展和 API：

  • ResizeHandleRow - 允许覆盖列比例参数（#15004）
  • 提前调用 script_callbacks.ui_settings_callback ；修复 extra-options-section 内置扩展在使用不存在的设置时杀死 ui
  • 可以在 webui 上下文之外使用 Zoom.js (#15286, #15288)
  • 允许在metadata.ini 中使用不同的扩展名称（#15290）
  • 在重新加载 UI 时使重新加载 UI 脚本成为可选，默认情况下关闭
  • 将 request: gr.Request 放在 img2img 函数的开头，类似于 txt2img
  • open_folder 作为 util (#15442)
  • 可以将扩展的脚本文件导入为 import scripts.<filename> (#15423)

性能：

  • 针对额外网络 HTML 页面的性能优化
  • 优化额外网络过滤
  • 额外网络排序优化

错误修复：

  • 防止退出按钮在尚未生成时导致中断
  • [bug] 避免在修复中进行双倍放大 (#14966)
  • 可能修复了在某些情况下对于额外网络不出现重新加载按钮的问题。
  • 修复：运行分割超大图像时 split_threshold 参数不起作用 (#15006)
  • 修复垂直布局的调整大小手柄可见性（移动）（#15010）
  • register_tmp_file 也用于 mtime (#15012)
  • 在精炼机切换期间保护 alphas_cumprod (#14979)
  • 修复 API 图像加载中的 EXIF 方向 (#15062)
  • 只有在提示中实际使用时才覆盖强调 (#15141)
  • 修复 params.txt 中缺失的强调信息文本（#15142）
  • 修复 extract_style_text_from_prompt #15132 (#15135)
  • 修复 AnimateDiff 的软修复 (#15148) *编辑注意：取消选择周围的空白（[#15178]（https://github.com/AUTOMATIC1111/stable-diffusion-webui/pull/15178））
  • 杂务：修复字体未加载的问题 (#15183)
  • 按路径排序时在额外网络中使用自然排序
  • 修复 torch.nn.MultiheadAttention 引起的内置 lora 系统错误 (#15190)
  • 避免 get_learned_conditioning 中的 None 错误（#15191）
  • 写入元数据后向 MassFileLister 添加条目 (#15199)
  • 修复使用雇用提示时的样式问题（#15269、#15276）
  • 从员工修复提示中删除评论（#15263）
  • 使 imageviewer 事件监听器与浏览器一致 (#15261)
  • 修复 OFT 尝试获取 MultiheadAttention 权重时出现的 AttributeError (#15260)
  • 添加缺失的 .mean() (#15239)
  • 修复“恢复进度”按钮（#15221）
  • 修复 InputAccordion [custom_script_source] 的 ui-config (#15231)
  • 手柄 0 轮 deltaY (#15268)
  • 阻止 Firefox 的替代菜单 (#15267)
  • 修复：修复语法错误 (#15179)
  • 恢复输出路径 (#15307)
  • 转义 btn_copy_path 文件名 (#15316)
  • 当文件名包含撇号时修复额外的网络按钮 (#15331)
  • lora 随机提示生成器中的转义括号 (#15343)
  • 修复：Python 版本检查 PyTorch 安装兼容性 (#15390)
  • 修复 call_queue.py 中的拼写错误 (#15386)
  • 修复: 当找到已经加载的模型时，删除按数组索引加载的模型 (#15382)
  • 修复了 sd 模型内存管理的小错误 (#15350)
  • 修复 CodeFormer 重量 (#15414) *修复：删除ordered_callbacks_map中的脚本回调（[#15428]（https://github.com/AUTOMATIC1111/stable-diffusion-webui/pull/15428））
  • 修复有限的文件写入（谢谢，Sylwia）
  • 修复额外单图像 API 未进行升级失败的问题 (#15465)
  • 错误处理paste_field callables (#15470)

硬件：

  • 添加训练支持并更改 Ascend NPU 的 lspci (#14981)
  • 更新至 ROCm5.7 和 PyTorch (#14820)

  • Ascend NPU wiki 页面 (#15228)
