stable-diffusion-webui v1.5.0

小版本 发布时间2023年7月25日 来源AUTOMATIC1111/stable-diffusion-webui 英文原文

stable-diffusion-webui v1.5.0

特点：

  • SD XL 支持
    • 需要 --no-half-vae。有关更多详细信息，请参阅#11757。
  • 自定义网络的用户元数据系统
  • 扩展 Lora 元数据编辑器：设置激活文本、默认权重、查看标签、训练信息
  • Lora 扩展重新设计以包括其他类型的网络（所有这些网络之前都是由 LyCORIS 扩展处理的）
  • 扩展显示 github 星星
  • img2img 批处理模式可以从 png 信息中读取额外的内容
  • img2img 批量处理子目录
  • 移动提示元素的热键：alt+左/右
  • 重新设计拍摄时间/VRAM 显示
  • 将文本反转哈希添加到信息文本中
  • 优化：缓存git扩展repo信息
  • 将生成按钮移动到移动 clients 的生成图片旁边
  • 在 Lora 额外网络接口中隐藏不兼容稳定扩散版本网络的卡
  • 如果已经安装了所有软件包，则跳过使用 pip 安装软件包 - 启动速度加快约 2 秒

次要：

  • 用于选中/取消选中“已安装”选项卡中所有扩展的复选框
  • 将 gradio 用户添加到信息文本和文件名模式中
  • 允许使用 gif 进行额外的网络预览
  • 添加更改网格颜色的选项
  • 对额外网络中的项目使用自然排序
  • Mac：使用 torch 2 中的empty_cache()来清除VRAM
  • 添加了对安装 Navi3 (AMD) 正确库的自动支持
  • 添加选项 SWIN_torch_compile 以加速 SwinIR 升级
  • 默认情况下禁止在启动时将 TI 嵌入信息打印到控制台
  • 加速额外网络列表
  • 添加了 [none] 文件名标记。 *删除了拇指额外的网络视图模式（使用设置选项卡更改宽度/高度/比例以获得拇指）
  • 将always_discard_next_to_last_sigma选项添加到XYZ图
  • 如果生成的图片有 NaN，则自动切换到 32 位浮点 VAE，无需 --no-half-vae 命令行标志。

扩展和 API：

  • api 端点：/sdapi/v1/server-kill、/sdapi/v1/server-restart、/sdapi/v1/server-stop
  • 允许脚本有自定义元类
  • 添加模型存在状态检查 /sdapi/v1/options
  • 将 —add-stop-route 重命名为 —api-server-stop
  • 添加before_hr脚本回调
  • 添加回调after_extra_networks_activate
  • 默认情况下在 API 的控制台中禁用丰富的异常输出，使用 WEBUI_RICH_EXCEPTIONS env var 来启用
  • 当没有找到thumb文件时返回http 404
  • 允许用环境变量替换扩展索引

错误修复：

  • 修复检索扩展索引时的捕获错误 #11290
  • 修复从网络驱动器读取时 .safetensors 文件加载速度非常慢的问题
  • API缓存清理
  • 修复写入文件 CLIP 询问器批处理模式时的 UnicodeEncodeError
  • 修复 PyTorch 已弃用的“has_mps”警告
  • 修复额外网络保存图像作为预览丢失生成信息的问题
  • 修复尝试使用 I;16 模式调整图像大小时抛出异常的问题
  • 修复#11534：画布缩放和平移扩展劫持快捷键
  • 修复了可从任何目录运行的启动脚本
  • 不要将“种子调整大小：-1x-1”添加到 API 图像元数据
  • 使用 ctrl+up/down 正确删除末尾括号
  • 在较新的 gradio 版本上修复 —subpath
  • 修复：调整大小时检查填充大小不为零（修复#11425）
  • 使用提交和模糊快速设置文本框
  • 使用 images.save_image() 保存 img2img 批次
  • 防止为禁用的扩展运行 preload.py
  • 修复：以前，模型名称与目录名称一起添加到信息文本和 [model_name] 文件名模式中；现在不包括目录名称
