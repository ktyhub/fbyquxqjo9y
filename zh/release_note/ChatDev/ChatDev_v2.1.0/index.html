ChatDev v2.1.0

小版本 发布时间2026年1月22日 来源OpenBMB/ChatDev 英文原文

ChatDev v2.1.0

这个项目是干啥的：是一个让多个AI扮演产品经理、程序员、测试等角色，像开会一样协作把软件写出来的工具，给想快速做应用原型的人用。

变更架构图

亮点

  • 批量执行与 Laboratory 界面 — v2.1.0 新增了一等公民式的批量运行能力，可在一次执行中驱动大量任务，同时提供一个“Laboratory”（实验室）界面用于比较配置和管理实验结果。如果你之前为大规模实验手写编排循环，这就是升级的理由——但要留出时间对照新界面校验配置结构，再信任批量输出。
  • 旧版 Chat 接口支持 — 本次发布加入了兼容模式，恢复早期的 OpenAI API 语义，因此固定在工具调用之前请求/响应结构的集成可以升级而不必重写聊天层。把它当作迁移的桥梁而非终点：它目前可用，但刻意沿用旧行为，因此应规划脱离它的路径。
  • 函数调用稳定性 — 修复了复杂和多轮流程中的多处失败：API 调用丢失、冗余/重复的返回值，以及 JSON/JSONL 解析错误（相关工作跨 PR #501、#513、#515）。如果你为不稳定的结构化输出加过防御性 workaround，现在是移除它们、并针对新行为重跑解析测试的时候了。
  • 配置、图像生成与分支链接修复 — 修正了动态配置解析、并行图像生成错误以及旧版分支链接的 bug，并刷新了 GameDev_v1.yaml 等示例配置以匹配当前功能。请重新运行依赖这些示例或并行图像生成的流水线——结果现在可能反映文档所述意图，而非之前的怪异行为。
  • 运维文档与防护提示 — 扩展了上下文窗口指引，针对文件输出任务增加了明确的 --reload 警告，并改进了 README 中关于前后端断连的排障说明。在调试截断或静默断连之前值得一读；尤其 --reload 提示可避免输出被覆盖。

无破坏性变更报告。

此版本的亮点

1.批量执行支持和实验室界面的引入 添加了新的批量运行功能，可实现高效的批量级任务执行，并显着提高大规模实验的可扩展性。除了此功能之外，还引入了实验室界面，为运行批量实验、比较配置以及管理面向研究的工作流程中的实验结果提供更直观的环境。 2.界面升级：支持旧版聊天界面并增强功能调用稳定性 添加了对旧聊天界面的支持，以保持与早期 OpenAI API 语义的一致性。除此之外，还修复了多个函数调用问题（例如 API 调用失败、冗余返回值和 JSON/JSONL 解析错误），增强了复杂多轮聊天场景中的稳定性。 3.其他工程和文档改进 其他更新侧重于整体系统稳定性和可用性，包括：

  • 修复动态配置问题、并行映像生成错误和遗留分支链接问题；
  • 更新示例配置（例如，GameDev_v1.yaml）以与当前功能保持一致；
  • 关于上下文窗口使用的扩展文档以及文件输出任务中 --reload 的明确警告；
  • 改进了自述文件中常见前后端断开问题的故障排除指南。
