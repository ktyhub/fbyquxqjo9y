ChatDev v1.1.5

修订 发布时间2024年8月28日 来源OpenBMB/ChatDev 英文原文

ChatDev v1.1.5

这个项目是干啥的：是一个让多个AI扮演产品经理、程序员、测试等角色，像开会一样协作把软件写出来的工具，给想快速做应用原型的人用。

变更架构图

亮点

  • GPT-4o 与 GPT-4o mini 支持 — PR #404 是本次的重头戏，也是升级的主要理由：把更便宜、更快的 4o-mini 加入模型阵容，对 ChatDev 的多智能体链意义重大，因为角色之间的每次交接都是一次计费的 LLM 调用。采用者应更新模型配置和 API key 权限，指向 gpt-4o / gpt-4o-mini，并重新校准任何针对 GPT-3.5 时代行为调优的提示词或回归基线——输出不会逐字节一致。
  • CommandDash 加入 — PR #415 和 #418（均来自首次贡献者）新增了一个“CommandDash”组件；注意它实际上被落地了两次，因此请将其视作刚合并的代码，在基于它构建之前先做冒烟测试。发布说明没有描述它的接口范围，请阅读这两个 diff 来判断它是否适合你的自动化工作流，而不要假设它有稳定的 API。
  • OpenAI 关键字参数兼容性修复 — PR #419 修复了一起“意外的 keyword arg refusal”崩溃。如果你通过代理、网关或响应中带 refusal 字段的 OpenAI 兼容端点运行 ChatDev（新 SDK 和 Azure 式部署中很常见），这曾是一次硬失败，因此该修复为自定义后端扫清了一道实际障碍，或许能让你去掉端点方面的 workaround。
  • 测试错误摘要修复 — PR #416 修正了测试失败的汇总方式。单看这一项很小，但如果你把 ChatDev 生成的代码接入 CI，它就相关了：失败输出的格式可能变化，请检查任何解析它的日志抓取或分流脚本。
  • 新增语言文档 — 韩语（#405）、俄语（#411）和乌尔都语（#417）的 README 已落地。这不是运行时变更，但体现了采用面的扩大，也是你维护本地化分支时方便的模板。

无破坏性变更。
