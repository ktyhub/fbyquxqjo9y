ChatDev v1.0.1

修订 发布时间2023年9月20日 来源OpenBMB/ChatDev 英文原文

ChatDev v1.0.1

变更流程图

亮点

  • 修复多轮对话 token 溢出 — 聊天超过五轮时，token 可能超出模型限制，导致长时间运行的智能体任务中途失败或静默截断上下文。对在 ChatDev 上构建长对话的开发者来说，这是本次发布影响最大的可靠性修复：深度多轮工作流现在能够完成，而不必在第六轮卡死。
  • Replay Demo 中恢复 SelfImprove 阶段 — 重放查看器此前会跳过 SelfImprove 阶段，因此审查一次运行的人看到的是不完整的轨迹。这对调试和审计生成的软件很重要：迭代精炼循环现在端到端可见，从而能诊断设计为何以某种方式收敛。
  • 修复 Windows 测试阶段错误 — Windows 上测试阶段的平台相关失败（由 TashaSkyUp 贡献）已解决。Windows 用户现在可以走完完整的生成—测试流水线，而不必在验证环节撞墙——如果你的 CI 或本地开发机跑的是 Windows，值得留意。
  • 新增贡献页面与演示体验升级 — 贡献页面正式化了对社区贡献的认可，Log Demo 增加了复制按钮，ChatChainVisualizer 加入了颜色编码。对演示或分享日志的人来说，这些是实用的改进：输出更容易提取，彩色阶段链让执行流程一目了然。
  • 社区信号显示采用已超出核心团队 — 首个社区贡献的软件（来自 GeekyWizKid 的 roguelike 游戏）、Munsif Raza 的另外两项贡献，以及新增的日语和韩语 README，表明扩展路径确实有效、文档也在走向国际化。对采用者而言，这证明社区贡献的软件和非英语上手引导是真实且受支持的途径。
  • 需要提前规划的未解问题 — 安全执行（Safe Execution）、面向其他开源/本地 LLM 的端点，以及向 OpenAI 服务器发送消息的问题，明确仍未解决。如果你的用例依赖沙箱执行或非 OpenAI 后端，请认为 v1.0.1 不适合这些路径，并相应设计 workaround。

本次发布无破坏性变更。

我们非常感谢社区的贡献！我们缺少审核和测试人员，已经修复了一些问题并添加了一些功能，之后我们将尽快解决问题并跟上更新的步伐。

社区贡献

  • 其他语言的自述文件：我们感谢 Eltociear 添加日语自述文件。 我们感谢 Wonhyeong Seo 添加韩文自述文件。
  • GeekyWizKid 贡献了第一个社区软件！这是一款类似胭脂的游戏。
  • Tasha Upchurch 帮助我们修复了 Windows 测试阶段的错误。
  • Munsif Raza 也贡献了两个软件。
  • 我们感谢所有社区贡献者。

错误修复和新功能

  • Bug修复：进行多轮聊天（超过5轮）时，代币可能会超出限制。
  • 错误修复：重播演示无法显示自我改进阶段。
  • 新功能：添加贡献页面。
  • 新功能：为 Log Demo 添加复制按钮并为 ChatChainVisualizer 添加颜色

问题依然存在

我们知道社区中还有很多迫切的需求是我们一直在关注并将努力解决的，包括：

  • 安全执行
  • 其他开源或本地法学硕士的端点
  • 向 OpenAI 服务器发送消息时出现各种问题
