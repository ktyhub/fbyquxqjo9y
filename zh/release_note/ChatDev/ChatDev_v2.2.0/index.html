ChatDev v2.2.0

小版本 发布时间2026年3月23日 来源OpenBMB/ChatDev 英文原文

ChatDev v2.2.0

变更流程图

亮点

  • OpenClaw 编排 — 后端工作流现在可以调用 OpenClaw 智能体团队并动态协调它们（#584），让开发者能把 ChatDev 工作流与外部智能体技术栈组合起来。在把生产工作流交给它之前，请先验证 OpenClaw 的连接性与权限。
  • 官方 Python SDK — 现在可以通过编程方式访问 ChatDev 工作流和智能体能力（#586），无需界面交互即可实现脚本化运行和服务端自动化。在自动化流水线中请固定 SDK 版本，以保持工作流行为可复现。
  • 基于文件系统的 Agent Skills — 智能体节点现在可以使用存储在磁盘上的技能（#559），使可复用的智能体行为更容易与工作流配置一起做版本管理。跨容器或开发机共享技能时，请检查文件路径与权限。
  • 新的工作流与聊天能力 — general_problem_solving_team 为开放式问题解决工作流提供了可复用的起点（#558），而持久化的全屏聊天改善了长时间会话的检查体验（#577、#583）。自定义界面集成在 #576 和 #580 的修复之后应重新测试导航和滚动。
  • 搭建与运行时可靠性 — 可选的基于 Docker 的本地开发（#536）、改进的 Windows Makefile/同步兼容性（#530），以及修正 .env.example 中的 Gemini 端点（#552），降低了上手门槛。WebSocket 与前端卡顿修复（#525、#553）针对不稳定的会话；使用非默认嵌入模型的团队应验证硬编码维度修复（#582）。
  • 破坏性变更 — 本次发布未宣布任何破坏性变更。

主要更新：

OpenClaw 集成

ChatDev 现在在其后端工作流程中提供对 OpenClaw 的全面支持，从而实现代理团队的无缝调用和工作流程的动态编排。

ChatDev Python SDK

官方 ChatDev Python SDK 已发布，允许开发人员以编程方式访问 ChatDev 工作流程并利用代理功能。
