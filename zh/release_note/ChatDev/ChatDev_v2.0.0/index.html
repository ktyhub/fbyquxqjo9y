ChatDev v2.0.0

大版本 发布时间2026年1月7日 来源OpenBMB/ChatDev 英文原文

ChatDev v2.0.0

变更流程图

亮点

  • 通用编排能力 — v2.0 用与任务无关的多智能体平台，取代了原先聚焦软件开发的“虚拟公司”模式，因此采用它属于架构层面的变更，而非常规升级。
  • DevAll 带来零代码工作流 — 用户无需编写代码即可构建、配置并执行定制化的多智能体系统，降低了软件工程之外自动化任务的门槛。
  • main 现在指向 v2.0 — 拉取 main 的自动化流程拿到的将是 DevAll，而非旧版实现。想要可复现构建，请固定 v2.0.0 或明确的分支。
  • 旧版 v1.0 仍然可用 — 现有用户可以继续留在 chatdev1.0，同时评估 DevAll。本次发布没有提供详细的 API 或配置迁移指南，因此切换前应先对现有集成做兼容性测试。
  • 破坏性变更 — 未列出明确的 API 或配置破坏性变更。

ChatDev 2.0 发布

ChatDev 已经从一个以软件开发为中心的多代理框架发展成为一个通用的多代理编排平台。此版本标志着一个清晰的架构转变：从特定于领域的虚拟软件公司范例到用于跨不同任务编排智能代理的零代码系统。 **ChatDev 2.0 推出了 DevAll，这是一个用于“开发一切”的零代码多代理平台。**它使用户能够构建、配置和执行定制的多代理系统，而无需编写代码，从而显着扩展了 ChatDev 的范围，超越了软件工程。

迁移注意事项

ChatDev 2.0 是 ChatDev 1.0 的概念概括，main 分支现已切换到 2.0 (DevAll)。我们鼓励寻求灵活多代理编排的用户迁移到此版本。 ChatDev 1.0 的现有用户可以继续通过其分支 chatdev1.0 访问旧版实现。
