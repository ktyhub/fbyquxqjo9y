ChatDev v1.1.2

修订 发布时间2023年12月21日 来源OpenBMB/ChatDev 英文原文

ChatDev v1.1.2

变更流程图

亮点

  • OpenAI SDK 升级与 GPT-4 Turbo — v1.1.2 迁移到当前的 OpenAI API，并新增 GPT_4_TURBO 模型选项（#277、#262）。旧 API 路径仍保留，因此现有配置不会直接报错，但维护者明确建议拉取最新代码并升级 openai 包——请规划这次依赖升级并重新核对模型标识符，尤其因为上报的成本现在由所选模型派生（#132），换成 turbo 会改变计费。
  • 破坏性变更：online_log 更名为 visualizer — 演示模块被重命名（#303），因此任何引用 online_log 的导入、脚本或路径都必须更新；现在通过 python3 visualizer/app.py 启动。注意命名不一致：更新日志写的是 visualizer，而 PR #303 写的是 chat_visualizer——接线前请确认带标签代码树里的实际目录名。
  • 增量开发（Incremental Development） — 新增了一个工作流，用于继续或扩展现有代码库，而不是从头重新生成（#246），由 #249 添加的配置项控制。你需要加上该配置项，否则该模式不会启用；假设每次都是全新（greenfield）运行的脚本可能也需要调整。
  • Docker 支持 — 本次发布加入了容器化的搭建路径（#203，文档在 wiki 中），消除了本地 Python/依赖的麻烦，并让运行可复现；请检查容器内如何处理 API key 及任何 GPU 需求。
  • 可靠性与日志修复 — ModelBackend 现在会重试遇到速率限制/超时的 GPT-4 调用（#140），减少长时间生成任务的不稳定；log_arguments 的字符串转义也做了重构（#250）——如果有下游在解析这些日志，值得一看。
  • SRDD 数据集 — 本次发布附带了一个新的需求/设计文档数据集，可作为需求分析工作的基准或微调语料。

重要变化

  • ChatDev 现在更新了 OpenAI API 并添加了对 GPT4-turbo 的支持。虽然我们保留了对旧版 API 的支持，但我们强烈建议提取最新代码并更新 openai 版本。
  • online_log 模块现已重命名为可视化工具。请执行“python3 visualizer/app.py”来启动可视化演示。

新功能

  • Docker 支持 (https://github.com/OpenBMB/ChatDev/blob/main/wiki.md#docker-start)
  • 增量开发支持
  • 我们发布了SRDD数据集（https://github.com/OpenBMB/ChatDev/tree/main/SRDD）
