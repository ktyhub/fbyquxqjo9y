AstrBot v4.26.7

修订 发布时间2026年7月18日 来源AstrBotDevs/AstrBot 英文原文

变更架构图

亮点

  • 交互式的 ChatUI 回复 — 内联 GenUI 支持（#8712）让聊天回复可以渲染交互式生成界面，而不再只依赖文本。修正过的后续处理（#9309）对与这些 UI 元素进行多轮交互也很重要。
  • Agent 可观测性与上下文控制 — 统计现在在每次 LLM 调用后流式输出（#9260），让开发者能增量看到 Agent 的执行情况。配置好的上下文上限存在时优先采用（#9263），让有效的提示词预算更可预测。
  • 扩展的检索配置 — TEI rerank provider（#9274）为检索流水线增加了一个后端选项，可配置的 embedding 维度发送模式（#9245）有助于匹配不同 provider 的契约。切换 provider 前请确认所选维度和模式。
  • 异步的配置持久化 — 快照保存现在异步且带版本感知（#9300），避免事件循环停顿，并防止较旧的保存覆盖较新的状态。此前假定保存立即完成的集成需要适配异步行为。
  • 更少的插件集成失败 — handler 绑定现在是幂等的，避免重复的 self 参数（#9316）。插件 schema 可以带 UTF-8 BOM 标记（#9223），仓库 URL 也不再被误当成插件名（#9314）。
  • 运行时与失败路径加固 — 修好了 Python 3.14 上 python-ripgrep 的崩溃（#9244），知识库部分上传失败会得到补偿（#9007、#9246），Dashboard API 错误有兜底处理器（#9271）。补偿改善了恢复能力，但不要把它当作每篇文档都已索引的保证。

  • 将核心日志翻译成英文。 (#9318)

  • 更正了版本化技能名称的技能下载存档文件名。 (#9270)
  • 为仪表板 API 错误添加了一个包罗万象的异常处理程序。 (#9271)
  • 补偿了部分知识库上传失败的问题。 （＃9007，＃9246）

  • 恢复了不安全 HTTP 来源上的代码块复制。 (#9267)
  • 正确处理 ChatUI 后续消息。 (#9309)

  • 防止在每次工具调用之前出现目的解释。
  • 当建议面板打开时隐藏命令工具提示。 (#9312)
  • 停止将插件存储库 URL 作为插件名称进行匹配。 (#9314)
  • 插件架构中接受 UTF-8 BOM 标记。 (#9223)
