AstrBot v4.13.0

AstrBot v4.13.0

这个项目是干啥的：是一个能接入QQ、微信、LINE等平台的聊天机器人框架，让想做AI助手的人把大模型、知识库和工具调用串起来，直接放进群里用。

变更架构图

亮点

  • Skills 与工具上下文处理 — 头号变化：现在可以导入并使用 Anthropic Skills（PR #4715，文档见 docs.astrbot.app/use/skills.html）；同时新增「Skill-like」Tool Schema，分两阶段调用工具（PR #4681），让庞大的工具集不再吞噬上下文。对工具密集型 Agent、或已经感受到上下文/token 压力的场景最关键——这是升级到 v4.13.0 的主要理由。
  • 供应商密钥与插件配置 — API 密钥现在可以从环境变量解析（#4696），不必再把机密硬编码在供应商配置里。插件配置新增 file 类型以支持文件上传（#4539），从而解锁需要接收上传文件的插件；如果你集中管理密钥，或开发/使用这类插件，就值得升级。
  • 稳定性修复 — 两个实打实的 bug 修复：Gemini API 可能陷入无限工具调用循环（#4686）；WebUI 的 GitHub 代理选择器失效，且卸载插件后会报错（#4724）。如果你用 Gemini 或插件管理器，单凭这两项就值得升级。
  • WebUI 体验改善 — WebUI 的 API 访问日志默认不再打印到终端，减少控制台噪音（#4661，可在 Dashboard 配置日志开关）；「更新所有插件」现在有确认弹窗，防止误点（#4658）。属于小改动、低风险。
  • 升级结论 — 未提及破坏性变更或迁移步骤，因此从 v4.12.4 升上来是安全的功能/小版本更新。想要 Skills / Skill-like 工具、环境变量密钥，或需要 Gemini/WebUI 修复的就升级；如果这些都与你无关、想保持现状，可以跳过。

发生了什么变化

新功能

  • 支持 Anthropic Skills 导入和使用。参见 Skills；
  • 支持新的 Tool Schema 模式：Skill-like。通过两阶段调用来减少 Tool 过多的情况下，占用过多上下文的问题。
  • 支持通过环境变量配置提供商 API Key。(#4696)
  • 支持插件的上传文件功能配置项类型 file (#4539)

修复

  • Gemini API 部分情况下工具无限循环调用 (#4686)
  • 修复 WebUI GitHub 代理选择器问题及卸载插件后出现的错误 (#4724)

优化

  • 默认不在终端显示 WebUI API 访问日志 (#4661)
  • 增加插件管理页面“更新所有插件”按钮的确认对话框，防止误点击 (#4658)

更新日志

新功能

  • 人择技能支持：添加了对导入和使用人择技能的支持。有关详细信息，请参阅技能文档。
  • 类似技能的工具架构：引入了新的“类似技能”的工具架构。这使用两阶段调用过程来减少管理大量工具时的上下文膨胀。
  • 环境变量 API 密钥：支持通过环境变量配置提供程序 API 密钥 (GitHub #4696)。
  • 文件上传配置：为插件文件上传功能添加了文件配置类型（GitHub #4539）。

错误修复

  • Gemini 工具循环：修复了 Gemini API 可能进入无限工具调用循环的问题 (GitHub #4686)。
  • WebUI 稳定性：解决了 GitHub 代理选择器的问题以及卸载插件后出现的错误 (GitHub #4724)。

优化

  • 控制台日志：WebUI API 访问日志现在默认隐藏在终端中 (GitHub #4661)。
  • 意外 Click 保护：在管理界面中添加了“更新所有插件”按钮的确认对话框（GitHub #4658）。
