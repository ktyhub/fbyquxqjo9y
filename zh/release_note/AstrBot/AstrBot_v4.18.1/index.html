AstrBot v4.18.1

修订 发布时间2026年2月22日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.18.1

变更流程图

亮点

  • SubAgent 后台执行 — 设置 background: true 后，子 Agent 可以不阻塞主对话地运行，并在完成时通知你。这是为长时或非紧急任务提供的可选项；无需迁移。
  • 配置 schema 中的密码渲染 — string 和 text 字段可以用 password: true 或 render_type: "password" 在 WebUI 中渲染为密码输入框。对需要暴露机密的插件作者很有用，不过它只改变展示方式，不涉及存储安全。
  • 插件市场修复 — #5309 修复新市场中插件卡片空白的问题，并让已安装插件卡片尺寸一致。如果插件卡片缺失或排版参差，值得升级。
  • SubAgent 页面布局 — #5306 防止过长的介绍文字挤压 SubAgentPage 右侧的控件。
  • 升级建议 — 需要后台子 Agent 工作流、或受上述问题 UI 影响的用户值得安装；两者都不涉及的用户可以放心跳过这个补丁。变更日志未列出破坏性变更或迁移步骤。

发生了什么变化

修复

  • fix: 修复插件市场出现插件显示为空白的 bug；纠正已安装插件卡片的排版，统一大小 (#5309)

新增

  • SubAgent 支持后台执行模式配置：当 background: true 时，子代理将在后台运行，主对话无需等待子代理完成即可继续进行。当子代理完成后，会收到通知。适用于长时间运行或用户不需要立即结果的任务。(#5081)
  • 配置 Schema 新增密码渲染支持：string 与 text 类型可通过 password: true（或 render_type: "password"）在 WebUI 中按密码输入方式显示。

更改内容 (EN)

修复

  • 修复：修复了插件市场会显示插件空白卡的问题；更正了已安装插件卡的布局以保持尺寸一致（#5309）

新功能

  • 添加了对子代理的后台执行模式支持：当设置 background: true 时，子代理将在后台运行，允许主对话继续进行，而无需等待子代理完成。当子代理完成时，您将收到通知。这适用于长时间运行的任务或当用户不需要立即结果时。 (#5081)
  • 在配置模式中添加了密码呈现支持：string 和 text 字段可以使用 password: true（或 render_type: "password"）在 WebUI 中呈现为密码输入。

发生了什么变化

  • fix(SubAgentPage): 当中间的介绍文本非常长时，Flex 布局会自动挤压右侧的控制按钮区域 by @SXP-Simon in https://github.com/AstrBotDevs/AstrBot/pull/5306
  • fix: 修复新版本插件市场出现插件显示为空白的 bug；纠正已安装插件卡片的排版，统一大小 by @SXP-Simon in https://github.com/AstrBotDevs/AstrBot/pull/5309 *功能：支持生成子代理作为后台任务，不会阻止https://github.com/AstrBotDevs/AstrBot/pull/5081中的@advent259141的主代理工作流程 完整 Changelog：https://github.com/AstrBotDevs/AstrBot/compare/v4.18.0…v4.18.1
