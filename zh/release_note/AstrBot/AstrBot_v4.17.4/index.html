AstrBot v4.17.4

修订 发布时间2026年2月17日 来源AstrBotDevs/AstrBot 英文原文

变更架构图

亮点

  • NVIDIA provider 集成 — 新增 NVIDIA provider 模板，简化 AstrBot 连接 NVIDIA 模型服务的配置，降低采用者的手动设置成本（#5157）。
  • 可搜索的配置界面 — 配置组件现在支持搜索，更快定位设置项；WebUI 也新增了可搜索的配置入口（#5168）。
  • 未保存改动保护 — 配置页面现在会在有未保存修改时给出提醒，避免离开页面时意外丢失配置。
  • 更可操作的执行工具报错 — Python 和 shell 工具给出更清晰的权限拒绝提示，便于诊断本地执行失败。
  • 自适应的管理与编辑界面 — provider 来源菜单、移动端布局和人设编辑得到改进（#5162），CronJob 操作列按钮重叠问题也已修复（#5163）。
  • 本地化与应用内指引 — 欢迎页新增带本地化标题的公告，侧边栏导航增加 FAQ 链接。

发生了什么变化

新增

  • 新增 NVIDIA Provider 模板，便于快速接入 NVIDIA 模型服务 (#5157)。
  • 支持在 WebUI 搜索配置

修复

  • 修复 CronJob 页面操作列按钮重叠问题，提升任务管理可用性 (#5163)。

优化

  • 优化 Python / Shell 本地执行工具的权限拒绝提示信息引导，提升排障可读性。
  • Provider 来源面板样式升级，新增菜单交互并完善移动端适配。
  • PersonaForm 组件增强响应式布局与样式细节，改进不同屏幕下的编辑体验 (#5162)。
  • 配置页面新增未保存变更提示，减少误操作导致的配置丢失。
  • 配置相关组件新增搜索能力并同步更新界面交互，提升配置项定位效率 (#5168)。

更改内容 (EN)

新功能

  • 添加了 NVIDIA 提供程序模板，以便更快地与 NVIDIA 模型服务集成 (#5157)。
  • 在欢迎页面添加了公告部分，并支持本地化公告标题。
  • 在垂直侧边栏添加了常见问题解答链接，并更新了本地化导航。

修复

  • 修复了 CronJob 页面操作列中重叠的操作按钮，以提高任务管理可用性 (#5163)。
  • 改进了 Python 和 shell 工具中本地执行的权限拒绝消息，以便更清晰地进行故障排除。

改进

  • 增强了提供商来源面板，提供了精致的菜单样式和更好的移动支持。
  • 改进了 PersonaForm，具有响应式布局和样式更新，可在不同屏幕尺寸上提供更好的编辑体验 (#5162)。
  • 在配置页面添加未保存更改通知，以减少意外配置丢失。
  • 向配置组件添加了搜索功能，并更新了相关 UI 交互，以加快设置发现速度 (#5168)。
