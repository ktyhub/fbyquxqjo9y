AstrBot v4.27.0

这个项目是干啥的：是一个能接入QQ、微信、LINE等平台的聊天机器人框架，让想做AI助手的人把大模型、知识库和工具调用串起来，直接放进群里用。

变更架构图

亮点

  • 持久的群组上下文 — AstrBot 现在会持久化群消息历史（保留时长可配置），并提供一个 LLM 工具用于搜索和检索当前群的消息，让助手能回忆此前的对话，而不必无限期保留历史。（#9465）
  • 受管的 shell 执行 — 本地工具现在可以运行交互式会话，支持增量输出、写入 stdin、中断、终止和超时。会话按发送者隔离，会话管理员保留管理权限；Windows 改用 PowerShell，因此依赖 shell 的提示词和脚本应检查跨平台行为。（#9470、#9471、#9479、#9501）
  • 更好的知识检索 — embedding 现在包含文档上下文并保留标题路径；确定性的归一化稠密/稀疏分数融合以及来源文档多样化提升了相关性和稳定性。vLLM rerank 失败现在会报出来，而不是静默降低结果质量。（#9454、#9455、#9457）
  • 更广的安装来源、更安全的更新 — 插件可以从通用 HTTP(S)、SSH 和 SCP 风格的 Git 仓库安装和更新。Core、dashboard 和插件更新现在共用统一更新器，带包和元数据校验；请按这套新架构复核自定义的仓库和更新工作流。（#9493）
  • 扩展与能力管理 — 统一的扩展/人设接口新增了路由式插件工作区和共享能力选择器，并让 MCP 服务器、工具和 Skill 的来源更清晰。内置的 skill-creator、documents、pdf、spreadsheets Skills 开箱即用地提供可复用的 Skill 编写和办公文档工作流。（#9499）
  • 安全与迁移说明 — API key 现在对管理员聊天和配置访问强制要求子范围，并对敏感设置和项目路径加强了授权；请审计现有 token，只授予所需范围。废弃的 API 现在会发出运行时警告，to_openai_to_calls_model 改名为 to_openai_tool_calls_model，并保留兼容别名。（#9468、#9469、#9503）

无破坏性变更。

[4.27.0] - 2026-08-02

根据《阿斯佩拉广告阿斯特拉》。

添加

  • 添加了持久组消息历史记录，具有可配置的保留、规范化存储以及用于从当前组搜索和检索消息的 LLM 工具。 (#9465)
  • 添加了具有增量输出、stdin 写入、中断、终止、超时和生命周期清理功能的托管本地 shell 会话； Windows 会话现在使用 PowerShell，并且面向行的程序支持显式行写入。 （＃9470，＃9471，＃9501）
  • 添加了统一的扩展和角色管理体验，包括共享功能选择器、路由插件工作区以及更清晰的 MCP 服务器、工具以及技能来源和状态。 (#9499)
  • 添加了内置 skill-creator、documents、pdf 和 spreadsheets 技能，用于创建可重复使用的技能以及处理 Office 文档、PDF 和电子表格。
  • 添加了通用 HTTP(S)、SSH 和 SCP 样式 Git 存储库中托管插件的安装和更新。 (#9493)
  • 转换后的 ChatUI 将超过 10,000 个字符粘贴到文本附件中。 (#9496)
  • 添加了用于管理员聊天访问和管理员配置更改的敏感 API 关键子范围，以及生成的范围到端点的参考文档。 (#9503)

已更改

  • 通过标准化密集/稀疏相对分数融合和源文档多样化提高了知识库检索质量。 (#9455)
  • 通过文档上下文和保留的标题路径丰富知识库嵌入。 (#9457)
  • 集中式核心、仪表板和插件更新流程，支持更安全的更新程序架构，并具有包和元数据验证。 (#9493)
  • 正式化了现有已弃用的 API，并带有运行时警告，并更正了 OpenAI 工具调用转换方法名称，同时保留了向后兼容的别名。 （＃9468，＃9469）
  • 完善了技能卡、角色管理、扩展工作区和项目聊天编辑器布局。
  • 使用紧凑的基于时间戳的瞬态文件名和更清晰的工作空间相对路径指导来减少工具路径令牌的使用。 (#9505)
  • 为已完成的本地 shell 命令返回简洁的纯文本结果，同时保留活动命令的托管会话元数据。 (#9507)

已修复

  • 推迟了 BM25 依赖项导入，以便 AstrBot 可以在与已安装的 NumPy 版本不兼容的 CPU 上启动并使用 FTS5 检索。 (#9435)
  • 使知识库排名融合具有确定性，并显示 vLLM 重新排名响应失败。 (#9454)
  • 保留ChatUI流媒体响应尾部并防止QQ官方流媒体缓冲区丢失主角。 （＃9439，＃9444）
  • 使用系统时区本地化未来任务时间戳。 (#9462)
  • 由发送者隔离托管的本地 shell 会话，同时允许对话管理员管理其对话中的会话。 (#9479)
  • 强化管理员身份、敏感配置和项目工作空间路径的 API 关键授权边界。 (#9503)
  • 在未生成助理响应时保留终端工具调用、结果和 trusted 令牌使用情况。 (#9500)
  • 防止扩展的 ChatUI 编辑器、回复和附件与最新消息重叠。 (#9496)
  • 从移动插件配置对话框中删除了双滚动条。 (#9491)
  • 存储清理后重新创建了工具图像缓存目录，以便仍然可以保存新图像。 (#9490)
  • 保持出站 TTS 和 QQ 官方音频可用，直到全局临时文件清理，以便异步下载不会失败。 (#9506)
