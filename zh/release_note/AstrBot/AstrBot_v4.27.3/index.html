AstrBot v4.27.3

修订 发布时间2026年8月12日 来源AstrBotDevs/AstrBot 英文原文

变更架构图

亮点

  • 桌面端免密访问 — 桌面应用现在无需登录即可直接打开 WebUI，首次使用和日常访问更省心；这是一次实质性的安全行为变化，需要在工作站或远程访问策略中加以考虑（#9585）。

  • 更可靠的知识库检索 — 文档搜索不再截断结果，也不再把加载失败误判为「确实没有答案」；名称解析现在可以回退到 UUID。这让用户侧的 RAG 行为更可预期，也更容易排查（#9577、#9578、#9618、#9636）。

  • 减少主线程阻塞 — SharedPreferences 和配置偏好访问改为异步、非阻塞路径，减少相关流程中肉眼可见的卡顿和死锁风险。依赖同步读取设置的插件作者应检查自己的集成假设（#9582、#9584、#9649）。

  • 调度与 Agent 生命周期改进 — 定时任务现在继承配置的时区，设置项会显示 AstrBot 的实际生效时间，停止的运行会被立即取消。Agent 结束时也会先记录结束时间再上报统计，提高时间统计精度并减少无谓的后台工作（#9579、#9581、#9597、#9602）。

  • 更稳健的平台集成 — QQ 官方支持大文件分块上传，并且现在会把媒体上传失败暴露出来，而不是静默继续；Windows 本地 Shell 新增 PowerShell 7 支持。错误处理与重试逻辑需要把这些新暴露的失败情况考虑进去（#9622、#9644、#9646）。

  • 更好的管理与兼容性诊断 — 一键重置可恢复插件配置默认值；Dashboard 插件的 Skill 状态保持同步；MCP 工具名会针对 LLM API 做净化；显式配置的陈旧 WebUI 发行版会触发警告。这些改动简化了故障恢复、减少跨系统状态漂移，并让兼容问题更早暴露（#9534、#9518、#9596、#9599）。
