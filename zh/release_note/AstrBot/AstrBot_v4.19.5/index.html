AstrBot v4.19.5

修订 发布时间2026年3月10日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.19.5

变更流程图

亮点

  • 飞书流式卡片 — 适配器现在支持 CardKit 流式输出，机器人的长回复可以逐步呈现，而不必等完整消息生成完。这改善了流式工作流的感知响应时间（#5777）。
  • MCP 启动与可靠性 — MCP 服务器现在在后台加载，不再阻塞启动；同时修复了导致用户无法查看服务器列表的 UI 错误（#5993）。启动就绪可能早于 MCP 完全初始化，因此依赖它的工作流应留出短暂预热时间。此外，stdio 缺少命令时的错误文案也在此前改动后恢复（#5992）。
  • TTS 校验与 Azure 凭据 — 供应商测试现在会校验输出文件大小并检测 MiniMax 空音频，能抓出此前可能误判为成功的无效响应（#5999）。Azure TTS 也接受 84 字符的订阅密钥，消除了凭据长度带来的兼容障碍（#5813）。
  • WebUI 导航与插件管理 — 新增过滤和排序，让庞大的已安装插件列表更易管理（#5923）。从聊天页切到欢迎页时现在能正确保留页面切换配置，避免导航过程中意外重置配置（#5792）。
  • 文档位置变更 — 文档从 AstrBotDevs/AstrBot-docs 迁入主仓库（#5960）。请更新仍指向旧文档仓库的书签、仓库链接和自动化脚本。
  • 破坏性变更 — 无。

发生了什么变化

新增

  • Lark 适配器支持 CardKit 流式输出（飞书）(#5777)。
  • WebUI 已安装插件列表新增筛选与排序功能 (#5923)。

优化

  • 启动时后台加载 MCP Server，不阻塞加载流程 (#5993)。

修复

  • 部分情况下 MCP 页报错 500 导致查看不了 MCP 服务器 (#5993)。
  • 修复 TTS Provider 测试：增加文件大小校验，并补充 MiniMax 空音频检测 (#5999)。
  • 修复前端切换到 Chat 后又回到 Welcome 时，页面切换配置未正确持久化的问题 (#5792)。
  • 修复 Azure TTS 不支持 84 位订阅密钥的问题 (#5813)。

文档

  • 文档仓库迁移：将 AstrBotDevs/AstrBot-docs 内容迁移至 AstrBotDevs/AstrBot (#5960)。

更改内容 (EN)

新功能

  • 新增对Lark/飞书适配器的CardKit流式输出支持（#5777）。
  • 在 WebUI 中添加了对已安装插件的过滤和排序（#5923）。

改进

  • MCP 服务器现在在启动期间在后台加载，而不会阻止加载过程 (#5993)。

错误修复

  • 在 TTS 提供程序测试和 MiniMax 空音频检测中添加了文件大小验证 (#5999)。
  • 修复了从聊天切换回欢迎时前端状态持续存在的问题 (#5792)。
  • 修复了 Azure TTS 对 84 字符订阅密钥的支持 (#5813)。
  • 恢复了上次修复后的 MCP stdio 丢失命令错误措辞更改 (#5992)。

文档

  • 将文档内容从 AstrBotDevs/AstrBot-docs 迁移到 AstrBotDevs/AstrBot (#5960)。
