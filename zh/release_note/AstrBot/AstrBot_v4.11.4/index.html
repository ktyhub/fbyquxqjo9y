AstrBot v4.11.4

发生了什么变化

修复

  • 从 Anthropic API 的二进制数据中检测图像 MIME 类型（#4426）
  • 更正代理记录器警告中的重复单词（#4390）
  • 通过模式清理 llm 上下文 (#4367)
  • 修复删除后列表配置保存为 [""] 而不是 [] (#4401)

改进

  • 添加了最终用户许可协议。
  • 增强回复功能以支持选定的文本引用（#4387）
  • 确保知识库的原子创建，并在失败时进行适当的清理（#4406）
  • 在配置中添加对插件列表的空检查以修复空列表问题（#4392）
  • 为非视觉模型添加图像占位符以修复私人聊天中无响应的问题 (#4411)
  • 将版本号标签附加到警告和错误级别日志（[#4388]（https://github.com/AstrBotDevs/AstrBot/issues/4388））
  • 优化插件自述文件 Markdown 渲染并删除冗余代码 (#4415)
  • 清理加载时无效的平台 ID (#4432)
  • 法学硕士健康模式（#4431）

详细信息

  • 壮举/chatui 引用 @Soulter 在 https://github.com/AstrBotDevs/AstrBot/pull/4387 中的文字 *修复：确保知识库的原子创建，并在https://github.com/AstrBotDevs/AstrBot/pull/4406中@Li-shi-ling失败时进行适当的清理 *修复（webui）：修复https://github.com/AstrBotDevs/AstrBot/pull/4366中@letr007工具表中所有行的意外扩展
  • 修复：当 @stevessr 在 https://github.com/AstrBotDevs/AstrBot/pull/4380 中的 session_id 包含“：”时
  • 修复：在配置中添加对插件列表的空检查，以修复https://github.com/AstrBotDevs/AstrBot/pull/4392中@advent259141的空列表问题
  • 修复（核心）：更正 https://github.com/AstrBotDevs/AstrBot/pull/4390 中@letr007 代理记录器警告中的重复单词
  • 修复：为非视觉模型添加图像占位符，以修复 https://github.com/AstrBotDevs/AstrBot/pull/4411 中 @advent259141 的私人聊天无响应问题
  • feat(context)：通过 @Futureppo 在 https://github.com/AstrBotDevs/AstrBot/pull/4367 中通过方式清理 llm 上下文
  • 修复 (#4297): 修复 https://github.com/AstrBotDevs/AstrBot/pull/4401 中 @NayukiChiba 删除后列表配置保存为 [""] 而不是 []
  • feat(log): 将版本号标签附加到 https://github.com/AstrBotDevs/AstrBot/pull/4388 中的 @ocetars 的 WARN 和 ERROR 级别日志
  • 修复：通过 https://github.com/AstrBotDevs/AstrBot/pull/4426 中的 @KBVsent 从 Anthropic API 的二进制数据中检测图像 MIME 类型
  • 修复(webui): 优化markdown渲染并删除https://github.com/AstrBotDevs/AstrBot/pull/4415中@clown145的冗余代码
  • 壮举（安全）：法学硕士健康模式，@Soulter 在 https://github.com/AstrBotDevs/AstrBot/pull/4431
  • 清理加载时无效的平台 ID，并通过 @Soulter 在 https://github.com/AstrBotDevs/AstrBot/pull/4432 中添加 UI 验证
