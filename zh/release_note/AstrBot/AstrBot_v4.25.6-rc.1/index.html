AstrBot v4.25.6-rc.1

预发布 发布时间2026年6月21日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.25.6-rc.1

变更流程图

亮点

  • 更安全的更新应用 — WebUI 现在把 dashboard 和核心 ZIP 暂存到每次更新独立的临时目录，用 ZipFile.testzip() 校验压缩包完整性，并只在两次下载都成功后才应用文件。这避免了核心下载失败导致的半更新；但解压或依赖安装失败仍缺乏完整回滚。
  • 异步更新 API — POST /api/update/do 现在立即返回 {"id": ..., "status": "running"}，而不是等待完成。自定义客户端必须轮询 /api/update/progress 获取成功或失败，使用新的 verify 和 apply 阶段，并避免对活跃的 progress_id 重复提交。
  • 托管核心包并提供回退 — 发布构建会产出带版本号的核心归档，更新器优先使用托管 registry，下载失败或不是合法 ZIP 时回退到 GitHub 的 zipball。设置 ASTRBOT_CORE_PACKAGE_BASE_URL 可使用镜像，留空则禁用托管下载。
  • Dashboard 解压加固 — 现在会检查 Dashboard 归档条目是否落在解压根目录内，拒绝可能写到数据目录之外的绝对路径和 ../ 穿越。自定义 Dashboard 归档必须去掉不安全的成员路径后重新打包。
