AstrBot v4.12.1

修订 发布时间2026年1月15日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.12.1

变更流程图

亮点

  • 这是真正的热修复，不是重新打标签 — v4.12.1 明确标注为「hotfix of v4.12.0」，完整变更日志覆盖 v4.11.4...v4.12.1，因此这个标签同时包含了 v4.12.0 的功能更新和热修复。它不是只改元数据的空版本，而是有实打实的代码变更。

  • 会话隔离失效——最该升级的理由 — PR #4490（“fix: unique session not working” / 修复会话隔离功能失效的问题）修复了本就不生效的「会话隔离 / unique session」功能。如果你依赖按会话隔离，且还在 v4.11.4 或 v4.12.0，请升级：这是影响正确性和隐私的修复，不是外观问题。

  • 用 Anthropic 且遇到图片 400 的用户请升级 — PR #4444 修复了发送 OpenAI 风格 image_url 载荷导致 Anthropic 返回 “400 invalid tag” 错误的问题。只有把图片输入路由到 Anthropic 模型时才相关；否则这个修复对你没有影响。

  • 新能力：沙箱代码解释器 + ChatUI 项目/批量管理 — PR #4449 新增 AstrBot Agent 沙箱环境（改进的代码解释器，文档见 https://docs.astrbot.app/use/astrbot-agent-sandbox.html）；PR #4477 新增 ChatUI 项目管理；PR #4194 新增会话/自定义规则的批量操作（@Luna-channel 的首次贡献）。这些是 v4.12.0 的亮点功能，想要的话就值得升级。

  • 其他修复与升级建议 — PR #4485 在 Telegram/Discord 命令注册时排除已禁用命令；PR #4486 修复 ChatUI 标题显示；PR #4487 保证 ChatUI 消息流顺序正确；另外还有工具调用提示词调优和 Context 文档规范化（#4436）。变更日志未提及破坏性变更或迁移步骤；已在 v4.12.0 且没遇到隔离问题的用户，主要需要的就是 #4490，其余可按是否需要沙箱/ChatUI 功能自行判断。

v4.12.0 的修补程序 fix: 修复会话隔离功能失效的问题。

优化

  • 标准化 Context 类文档格式 (#4436)
