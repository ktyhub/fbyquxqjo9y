AstrBot v4.26.2

修订 发布时间2026年6月27日 来源AstrBotDevs/AstrBot 英文原文

变更架构图

亮点

  • 现在要求 Python 3.12 — 升级前请先更新部署镜像和 CI 环境；不再支持更旧的 Python 版本（#9022）。
  • 更可靠的供应商请求处理 — Anthropic 现在会清理孤立的 tool_result 块；OpenAI 兼容供应商会丢弃那些 tool_call_id 在上下文截断后已不存在的工具消息，减少 HTTP 400 错误（#8952、#8350）。
  • 推理模型兼容性 — 只包含 reasoning_content 的助手消息会补上占位内容，以满足严格 API 的要求；DeepSeek V4 代理名称改用子串匹配来注入推理内容（#8483、#9015）。
  • 媒体保真与流式清理 — 转换时保留图片格式和 JPEG 质量；流式输出中的空白会被规范化，发送前会去掉尾部缓冲（#9019、#9031、#9029）。
  • 插件生命周期与 UI 修复 — 插件启用状态与工具启用状态分离；卸载插件时会清除其 KV 数据；更新通知尊重市场版本；安装来源会被记录，用于更新检查（#9048、#8291、#9033、#9037）。
  • 集成与运行时修复 — DashboardRequest 兼容性修复了一些 IM webhook 错误；支持 MiMo STT 和推理输出；Windows shell 超时会终止整个进程树；避免 send_message_to_user 重复回复（#9021、#9023、#8938、#8822、#9051）。

无破坏性变更。
