AstrBot v4.23.6

修订 发布时间2026年4月27日 来源AstrBotDevs/AstrBot 英文原文

变更架构图

亮点

  • Token 遥测新增命令，TPM 语义也变了 — 新增 /stats 命令（#7831），按会话展示用量，拆分为总量、缓存输入、其他输入和输出 token，让开发者无需给 provider 层埋点就能调试成本和缓存命中行为。注意 #7827 的行为变化：统计页的 TPM 现在只统计输出 token，因此按旧数字校准的仪表盘、预算或告警读数会偏低——在把趋势当作真实流量下降之前，请先重新校准阈值。
  • 推理模型的兼容性得到加固 — 一组针对推理型 provider 的修复：DeepSeek v4 现在接受空字符串 reasoning_content，并在 assistant 消息上保留 reasoning 字段（#7823、#7830）；OpenRouter 错误的 reasoning_key 属性被修正（#7821）；空 assistant 消息在流式和非流式路径中被一致过滤（#7758），严格 provider 不再拒绝重放的会话历史。净效果：会话中途切换模型时，400 错误更少，推理元数据也更少被静默丢弃。
  • Firecrawl 成为一等检索工具 — #7764 新增基于 Firecrawl 的网页搜索和页面提取，并带结果处理、会话管理和载荷校验。对 Agent 开发者来说，这意味着开箱即用就有经过校验、有状态的抓取路径，而不必自己拼装提取和请求净化。
  • 你会明显感受到的消息平台行为变化 — 微信客服文本消息现在在 15 秒窗口内去重（#7788），所以（有意或无意）依赖快速重复事件的机器人会收到更少的投递。MiniMax TTS 默认从 MP3 改为 WAV，以消除 QQ 官方频道的 RIFF 错误（#7797）——如果依赖 MP3，请显式设置输出格式。电脑沙箱的图片下载现在以图片而非通用文件形式送达（#7785）。
  • 值得为这些安全与传输修复升级 — #7751 堵住了文件上传中的路径穿越向量，并剥离文件名中的内嵌 NUL 字节；如果 Dashboard 对公网开放，这是最该打补丁的理由。#7778 让 Windows HTTPS 请求走 certifi SSL 上下文以修复校验失败，#7747 为不安全上下文和对话框添加了 execCommand 剪贴板回退，#7807 通过共享的尺寸检查辅助函数缩放过大图片，避免下游失败。

发生了什么变化

新增

  • 新增 /stats 命令，可查看当前会话的 Token 使用统计，并按总量、输入（缓存）、输入（其他）与输出拆分展示。（#7831）
  • 新增 Firecrawl Web 搜索与网页提取工具，支持搜索结果处理、网页内容提取、会话管理、请求校验与相关测试。（#7764）
  • 微信客服文本消息新增 15 秒内去重，减少重复消息处理。（#7788）

优化

  • 优化 Provider 配置界面性能与响应式显示，改善相关组件的字体和布局体验。（#7772）
  • 优化统计页 TPM 计算逻辑，TPM 现在仅统计输出 Token，并更新相关文案。（#7827）
  • 优化 OpenAI 兼容 Provider 的空 assistant 消息过滤逻辑，流式与非流式路径统一处理空字符串和空列表内容，避免严格 Provider 拒绝历史消息。（#7758）

修复

  • 修复 DeepSeek v4 与 reasoning content 相关处理，支持空字符串 reasoning 内容，并在 assistant 消息中保留 reasoning 字段。（#7823, #7830）
  • 修复 OpenRouter reasoning 字段属性名不正确的问题。（#7821）
  • 修复超大图片未压缩可能导致后续处理异常的问题，并复用图片最大尺寸检查工具。（#7807）
  • 修复 MiniMax TTS 默认输出 MP3 导致 QQ 官方平台语音转换出现 RIFF 错误的问题，默认输出格式改为 WAV。（#7797）
  • 修复 Computer 沙盒图片下载未按图片发送的问题。（#7785）
  • 修复 Windows 环境下部分 HTTPS 请求证书校验失败的问题，使用 certifi SSL context 提升兼容性。（#7778）
  • 修复非安全上下文或部分对话框中复制功能不可用的问题，抽取共享剪贴板工具并增加 fallback。（#7747）
  • 修复文件上传可能存在路径穿越的问题，并清理上传文件名中的 NUL 字节。（#7751）

更改内容 (EN)

新功能

  • 添加了 /stats 命令以显示当前对话的令牌使用情况，包括令牌总数、输入缓存令牌、输入其他令牌和输出令牌。 (#7831)
  • 添加了 Firecrawl Web 搜索和 Web 提取工具，具有结果处理、内容提取、会话管理、有效负载验证和测试功能。 (#7764)
  • 新增微信客服短信15秒去重，减少重复消息处理。 (#7788)

改进

  • 改进了提供程序配置 UI 性能和响应式布局，包括字体和组件样式更新。 (#7772)
  • 更新了统计页面 TPM 计算，以便 TPM 仅计算输出令牌以及匹配的标签更新。 (#7827)
  • 通过跨流式和非流式路径共享逻辑并处理空字符串或空列表内容，改进了 OpenAI 兼容提供商的空助理消息过滤。 (#7758)

错误修复

  • 通过支持空字符串推理内容并保留助理消息中的推理字段，修复了 DeepSeek v4 和推理内容处理。 （[#7823]（https://github.com/AstrBotDevs/AstrBot/pull/7823），[#7830]（https://github.com/AstrBotDevs/AstrBot/pull/7830））
  • 修复了用于 OpenRouter 的推理字段属性。 (#7821)
  • 通过缩小大图像并共享图像最大尺寸检查助手来修复超大图像处理。 (#7807)
  • 通过将默认输出格式从 MP3 更改为 WAV，修复了 QQ 官方语音转换的 MiniMax TTS 输出。 (#7797)
  • 修复了计算机沙箱图像下载，以便它们作为图像发送。 (#7785)
  • 使用 certifi SSL 上下文修复了 Windows 上的 HTTPS 证书验证问题。 (#7778)
  • 通过提取具有回退行为的共享 clipboard 实用程序，修复了不安全上下文和对话框中的复制操作。 (#7747)
  • 修复了文件上传中的路径遍历风险，并从上传文件名中删除了嵌入的 NUL 字节。 (#7751)
