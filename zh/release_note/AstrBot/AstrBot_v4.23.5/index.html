AstrBot v4.23.5

修订 发布时间2026年4月23日 来源AstrBotDevs/AstrBot 英文原文

变更架构图

亮点

  • 备份导入器的安全修复 — PR #7681 修补了路径穿越漏洞（CWE-22），此前精心构造的备份文件可以写到目标目录之外。凡是从不可信或共享来源导入备份的用户都应尽快升级；如果你只导入自己本地创建的备份，风险较低，但这个修复仍值得拿。

  • ChatUI 大改：编辑、重新生成、检查点与工具调用时间线 — PR #7673 新增消息内联编辑、从选定消息重新生成、话题/分支面板（选中 AI 回复文本即可打开）和对话检查点；PR #7742 把推理阶段的工具调用重构为侧边时间线；#7627 为非流式 Agent Loop 增加中间消息缓冲。如果你常用 WebUI 聊天页，这是头号升级理由——交互模型明显更好，不过并未提及破坏性变更或迁移步骤。

  • 供应商与兼容性修复 — #7685 修复国内/自定义 OpenAI 与 Anthropic 兼容供应商因 TLS 证书链、代理或模型列表能力差异导致的配置失败；#7692 让 MiniMax Token Plan Provider 在配置的模型不在硬编码列表时改为警告而非硬阻断；#7691 恢复 /provider 内置命令。如果你用的是非标准或国内托管供应商，这次升级能解除阻塞。

  • 值得了解的正确性与可靠性修复 — #7715 修复输出包含推理内容时丢失正常回复的问题（影响会输出推理的模型）；#7718 为 QQ 官方 API 增加 DNS/连接重试；#6077 规范化 MCP schema 中无效的 required 标记；#7706 删除陈旧的 documents_fts 表以解除知识库 FTS 迁移阻塞；#7633 让 RegexFilter 同时接受 str 和 re.Pattern。未声明破坏性变更或手动迁移步骤，但删除 documents_fts 表和放宽 RegexFilter 签名属于行为变化，插件作者应留意。

  • 值得升级吗？ 对大多数用户来说是的：这是一个功能丰富的补丁版本（v4.23.2 → v4.23.5），包含真正的安全修复、供应商配置修复和有分量的 ChatUI 改进——而且无需迁移步骤。只有在你不用 WebUI 聊天页、不导入备份、只用主流守规矩的供应商、且不受推理内容/知识库修复影响时，才可以跳过。

发生了什么变化

新增

  • WebUI ChatUI 新增消息重新编辑、从重新生成 AI 回复、分支询问面板（划选 AI 回复内容即可看到）与会话 checkpoint 支持。（#7673）
  • WebUI ChatUI 适配思考时的工具调用的模式，并自动将该 Loop 过程合并到独立的侧边栏面板中，以时间线呈现，大幅提升用户体验。(#7742)
  • WebUI ChatUI 附件处理新增预览与 Dedup 校验，改善上传前的附件识别与展示体验，修复用户消息气泡无法正常显示图片的问题。（commit）
  • 知识库文档上传新增 EPUB 支持，并补充 EPUB 解析、文件读取与相关测试。（#7594）
  • 非流式 Agent Loop 新增中间工具调用消息过程折叠发送功能。（#7627）
  • 重新内置 /provider 命令，支持通过命令管理与查看 Provider 相关信息。（#7691）
  • 插件页新增“有新版本时置顶显示”能力，并支持保存该偏好设置。（#7665）

优化

  • 优化 FileReadTool 描述，明确图片、PDF 与 DOCX 支持，并增强工具结果的模态能力检查。（#7506）
  • 统一多处文档链接，修正 CLI、配置、Dashboard 与知识库页面中的文档入口。（#7709）

修复

  • 修复部分国内或自定义 OpenAI/Anthropic 兼容模型提供商因 TLS 证书链、代理或模型列表能力差异导致配置不可用的问题。（#7685）
  • 修复模型回复包含 reasoning content 时可能漏发普通回复的问题。（#7715）
  • 修复 QQ 官方 API 在 DNS 或连接瞬时异常下缺少重试导致请求失败的问题。（#7718）
  • 修复 RegexFilter 不能同时接受 str 与 re.Pattern 的问题。（#7633）
  • 修复备份导入器存在路径穿越风险的问题。（#7681）
  • 修复旧版 documents_fts 表残留时可能影响知识库 FTS 迁移的问题。（#7706）
  • 修复 MiniMax Token Plan Provider 在已配置模型不在硬编码列表中时直接阻塞的问题，改为警告提示。（#7692）
  • 修复 MCP schema 中无效 required 字段未被规范化导致工具 schema 异常的问题。（#6077）
  • 修复视频附件传给 LLM 时的处理问题，并补充相关测试。（#7679）

更改内容 (EN)

新功能

  • 添加了内联消息编辑、从选定消息重新生成、线程面板以及 WebUI 聊天页面的对话检查点支持。 (#7673)
  • 在WebUI中添加了聊天附件预览和文件签名检查，以提高上传前的附件识别和显示。 (提交)
  • 为非流代理循环添加了缓冲中间消息，允许在非流场景中显示工具调用等流程消息。 (#7627)
  • 重新引入 /provider 作为用于查看和管理提供者相关信息的内置命令。 (#7691)
  • 添加了一个选项，可将已安装的具有可用更新的插件固定到插件页面的顶部，并具有持久的首选项存储。 (#7665)
  • 增加了对知识库文档上传的 EPUB 支持，包括 EPUB 解析、文件读取支持和测试。 (#7594)

改进

  • 更新了 FileReadTool 描述以提及图像、PDF 和 DOCX 支持，并改进了工具结果的模态检查。 (#7506)
  • CLI 输出、配置、仪表板和知识库页面的统一文档链接。 (#7709)

错误修复

  • 修复了当模型输出包含推理内容时缺少正常回复的问题。 (#7715)
  • QQ官方API流程中添加了针对瞬时DNS和连接错误的重试。 (#7718)
  • 修复了 RegexFilter，使其接受 str 和 re.Pattern。 (#7633)
  • 修复了备份导入器中的路径遍历漏洞。 (#7681)
  • 删除存在的旧 documents_fts 表，以避免知识库 FTS 迁移问题。 (#7706)
  • 修复了由于 TLS 证书链、代理处理或模型列表功能差异导致的某些国内或自定义 OpenAI/Anthropic 兼容模型提供程序的配置失败。 (#7685)
  • 更改了 MiniMax 令牌计划提供商的行为，以在配置的模型不在硬编码模型列表中时发出警告而不是阻止。 (#7692)
  • 对 MCP 模式中的无效 required 标志进行标准化，以避免工具模式错误。 (#6077)
  • 修复了 LLM 请求的视频附件处理并添加了相关测试。 (#7679)
