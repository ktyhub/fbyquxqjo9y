AstrBot v4.18.2

修订 发布时间2026年2月24日 来源AstrBotDevs/AstrBot 英文原文

变更架构图

亮点

  • Agent 控制与可观测性 — /stop 可以终止活跃的 Agent 会话，同时尽量保留已产出的内容；工具调用结果现在也能在执行过程中显示。这让长时间运行的 Agent 更容易中断和诊断（#5380、#5388）。
  • 更丰富的子 Agent 交接 — 子 Agent 现在接受图片 URL 和本地路径，交接期间也可使用 computer-use 工具。这支持多模态以及浏览器/桌面工作流，而不仅是纯文本委派（#5348、#5399）。
  • 插件生命周期管理 — 新增 load/unload 钩子，让插件协调初始化和清理；加载失败的插件支持热重载，加快开发和恢复。保留目录的处理也得到纠正（#5331、#5334、#5369）。
  • 沙箱权限收紧 — 文件传输工具现在强制要求管理员权限。以非特权身份运行的集成必须使用授权账号，或调整其权限模型（#5402）。
  • 集成与配置修复 — embedding 维度现在会传到 provider API，请确认配置的维度与模型和现有向量索引一致（#5411）。OneBot/aiocqhttp 的关闭和文件路径处理更稳健（#5412、#5391），Dashboard 发布跳转支持可配置的 base URL（#5330），带 UTF-8 BOM 的配置文件也能正确解析（#5376）。
  • 兼容性 — 未宣布破坏性变更。

发生了什么变化

新增

  • 新增 Agent 会话停止能力，并优化 stop 请求处理流程，支持 /stop 指令终止 Agent 运行并尽量不丢失已运行输出的结果。 (#5380)。
  • 新增 SubAgent 交接场景下的 computer-use 工具支持 (#5399)。
  • 新增 Agent 执行过程中展示工具调用结果的能力，提升执行过程可观测性 (#5388)。
  • 新增插件加载/卸载 Hook，扩展插件生命周期能力 (#5331)。
  • 新增插件加载失败后的热重载能力，提升插件开发与恢复效率 (#5334)。
  • 新增 SubAgent 图片 URL/本地路径输入支持 (#5348)。
  • 新增 Dashboard 发布跳转基础 URL 可配置项 (#5330)。

  • 修复 File 组件处理逻辑并增强 OneBot 驱动层路径兼容性 (#5391)。
  • 修复 sandbox 文件传输工具缺少管理员权限校验的问题 (#5402)。
  • 修复 pipeline 与 from ... import * 引发的循环依赖问题 (#5353)。
  • 修复配置文件存在 UTF-8 BOM 时的解析问题 (#5376)。
  • 修复 ChatUI 复制回滚路径缺失与错误提示不清晰的问题 (#5352)。
  • 修复保留插件目录处理逻辑，避免插件目录行为异常 (#5369)。
  • 修复 ChatUI 文件消息段无法持久化的问题 (#5386)。
