AstrBot v4.12.4

修订 发布时间2026年1月24日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.12.4

变更流程图

亮点

  • 人格文件夹，便于高级管理 — 通过人格文件夹新增层级化的人格组织方式（#4443，另有一项数据库支持的「persona folder management」改动）。如果你管理大量人格，这是亮点功能；原有的扁平人格配置不受影响，升级无需迁移。
  • ChatUI 新增拖拽上传与 Live Chat Mode — 现在可以把文件拖进 ChatUI 上传（#4583）；ChatUI 还新增了「Live Chat Mode」（#4534）。ChatUI 用户能获得实实在在的流程改进；如果你只通过 qq、钉钉等非 ChatUI 适配器使用 AstrBot，这些都与您无关。
  • 供应商与适配器可靠性修复 — 供应商选择强化了错误处理/日志，避免 Provider 不是 Provider 类型 错误（#4654）；嵌入维度保证以整数返回（#4547）；模型名过长不再遮住供应商选择按钮（#4631）；aiocqhttp 适配器处理 Markdown 时不再抛 KeyError/UnboundLocalError（#4656）。遇到过这些问题的用户值得升级，尤其是自定义供应商、基于嵌入的方案，以及 QQ（aiocqhttp）部署。
  • 平台相关的流式与引用修复 — 修复了钉钉流式响应（#4590）；更新 web_search_tavily，让信息引用不再泄漏到非 ChatUI 平台（#4633）。只有使用钉钉、或在多个适配器上跑 Tavily 搜索时才相关；否则影响很小。
  • 破坏性变更：已弃用的 tool 命令被移除 — 已弃用的 tool 命令现已删除，仍在调用它的脚本、文档或操作习惯都会失效，必须改用替代方式——如果你依赖它，升级前务必留意。本版本还带来 Genie TTS 支持和 T2I 模板编辑器预览（#4574）。总体来看这是一个扎实的增量补丁（不是重新打标签或只改元数据）：人格/嵌入/ChatUI 用户，以及遇到上述已修复错误的人应升级；不用 tool 命令、也不涉及受影响平台的用户可以视情况跳过。

发生了什么变化

新功能

  • 为 ChatUI 添加文件拖拽上传功能 (#4583)
  • 实现人格文件夹以进行高级人格管理 (#4443)
  • 添加人格文件夹管理以支持层级组织 (db)
  • 支持 Genie TTS

修复

  • 增强提供商选择错误处理和日志记录，避免出现 Provider 不是 Provider 类型 的错误 (#4654)
  • aiocqhttp 适配器中的 Markdown KeyError 或 UnboundLocalError 问题 (#4656)
  • 确保 providers 中的 embedding 维度作为整数返回 (#4547)
  • 钉钉流式响应问题 (#4590)
  • 提供商选择按钮被长模型名称遮挡的问题 (#4631)
  • 更新 web_search_tavily 处理，避免在非 ChatUI 平台出现信息引用 (#4633)

性能优化

  • T2I 模板编辑器预览 (#4574)

杂项

  • 移除已弃用的 tool 命令
