dubbo 2.7.2

修订 发布时间2019年5月31日 来源apache/dubbo 英文原文

dubbo dubbo-2.7.2

新功能

  • nacos配置中心/元数据中心支持。 #3846
  • Etcd 支持作为配置中心和元数据中心 #3653
  • 元数据报告中支持Redis集群。 [#3817]（https://github.com/apache/dubbo/issues/3817）
  • 为 Dubbo 事件添加新模块。 #4096
  • 支持多种注册表，包括一些有效的注册表，例如zk、redis #3599
  • 支持 nacos 元数据 #4025
  • Dubbo 支持 Google Protobuf 通用参考 #3829
  • 将serialization-native-hessian-for-apache-dubbo合并到incubator-dubbo #3961
  • 将 rpc-native-thrift-for-apache-dubbo 合并到 incubator-dubbo #3960
  • 添加socks5代理支持#3624
  • 与 SOFARegistry 集成 #3874
  • 为 GenericService 引入 CompletableFuture $invokeAsync，现在，对于泛型调用，您可以使用：
    $invoke 用于具有正常返回类型的同步方法调用。 $invokeAsync 用于使用 CompletableFuture 签名的异步方法调用。 #3163

增强

  • DefaultFuture 中 TimeoutTask 的性能调整。 #4129
  • 添加脚本来检查依赖项许可证。 #3840
  • 更改 DynamicConfiguration 定义以更好地适应 Apollo 的命名空间存储模型。#3266
  • 使用同等的显式类来替换匿名类 #4027
  • 将 Constants.java 分成一些子常量类 #3137
  • 需要增强 DecodeableRpcResult 错误消息 #3994
  • 提供更有意义的二进制版本。 #2491
  • 删除无用的 module-dubbo-test-integration #3573
  • 完整的consul注册表查找方法并添加集成测试#3890
  • 指标服务 #3702
  • 将 nacos-client 更新为 1.0.0 #3804
  • 流畅的样式生成器 API 支持 #3431
  • 更新自述文件以删除孵化器前缀 #4159
  • 更新 erlang 链接 #4100
  • 优化数组代码风格 #4031
  • 优化一些代码风格 #4006
  • 删除无用的 module-dubbo-test-integration #3989
  • 优化常量命名风格 #3970
  • 使用 Maven CI 友好版本：修订版。 #3851
  • 删除解析错误日志 #3862
  • ConfigCenterConfig 的完整 xsd 定义。 #3854
  • 在 RpcContext 中添加 RemoteApplicationName 字段 #3816

错误修复

  • @Reference 无法匹配本地@Service bean。 #4071
  • 删除一些非法许可证：jcip-annotations、jsr173_api。 #3790
  • QoS 端口不能被外部化属性禁用。 #3958
  • 修复消费者会生成错误的 stackTrace。 #4137
  • nacos 注册表服务名称可能会发生冲突。 #4111
  • 当网络重新连接时，client 会丢失监听器。 #4115
  • 修复重新创建引用代理时注册网址永远增加的问题。 #4109
  • dubbo 2.7.1 中，zookeeper client 的 watcher 处理器抛出 Nullpoint 异常。 #3866
  • 一旦订阅抛出异常，ReferenceConfig 初始化不会更改为 false #4068
  • dubbo 注册表扩展与 dubbo 2.6.x 兼容。 #3882
  • 注释模式无法在2.7.0中设置服务参数。 #3778
  • 与 Zipkin 兼容。 #3728
  • 在注册任何侦听器之前进行本地导出。 #3669
  • 无法识别 dubbo-admin 中的 2.6.x 兼容规则。 #4059
  • 在 Dubbo 2.7.0 中，提供者无法配置为异步 #3650
  • dubbox 兼容性 #3991
  • dubbo-2.7.1 提供者重复注册 #3785
  • 领事注册表：NullPointerException #3923
  • 当本地ip和公网ip同时存在时，无法发布本地ip地址 #3802
  • 回滚 3520 所做的更改。#3935
  • dubbo-registry-nacos 模块未捆绑到 Apache Dubbo 2.7.1 #3797
  • 从 CopyOnWriteArrayList 切换到常规列表，以避免潜在的 UnsupportedOperationException #3242
  • avro 协议和 protocoluff 协议之间的序列化 ContentTypeId 冲突 #3926
  • 延迟导出功能不起作用。 #3952
  • org.apache.dubbo.rpc.support.MockInvoker#getInterface 不应返回 null #3713
  • dubbo TagRouter 不能与 dubbo:parameter 一起使用 #3875
  • 使协议成为可变列表（具体的 ArrayList）#3841
  • javadoc lint 问题 #3646
  • etcd3 租约应正确回收 #3684
  • 当参数没有空构造函数并且某些字段是原始字段时，telnet 无法工作 #4007
  • 在设置 RouterChain 的“routers”字段之前对添加的路由器列表进行排序 #3969
  • 修复 injvm 和本地呼叫 #3638
  • org.apache.dubbo.common.extension.AdaptiveClassCodeGenerator#generateReturnAndInovation 中的拼写错误 #3933
  • 元数据报告不支持带有密码的 redis #3826
