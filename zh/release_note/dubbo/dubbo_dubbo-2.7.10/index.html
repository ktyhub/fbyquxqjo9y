dubbo 2.7.10

修订 发布时间2021年4月2日 来源apache/dubbo 英文原文

dubbo dubbo-2.7.10

通知

1.脚本路由器

默认情况下不会激活 ScriptRouter。如果用户仍想使用它，请在 selfs spi 文件中添加 scriptRouterFactory。 见dubbo-cluster/src/test/resources/META-INF/dubbo/internal/org.apache.dubbo.rpc.cluster.RouterFactory

2. 通用调用

默认情况下不会激活本机 Java 反序列化。如果用户仍想使用它，请在环境中将dubbo.security.serialize.generic.native-java-enable设置为true。

3. 序列化块列表

dubbo-common/src/main/resources/security/serialize.blockedlist 中引入了嵌入式序列化块列表。
如果用户想添加允许列表，请参阅dubbo.security.serialize.allowedClassList。
