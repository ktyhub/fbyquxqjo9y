特点

  • [解决方案] 如何将 Apache Dubbo 与 Nacos 认证集成 #5956
  • [Dubbo-5130]完成lfu缓存提案#5734
  • [功能] 为了支持应用程序选择首选网络接口 #5795
  • [Dubbo-Performance] 复用 Hessian2Output 和 Hessian2Input 实例来减少记忆…#5889

  • 支持RPC调用链上的超时传递和倒计时。第6008章
  • 添加新的负载均衡策略#6064

增强

  • 当 RPC 调用失败时调用 onThrowable (#5828)
  • 将 fastjson 升级为 1.2.68 #5941
  • 将 hessian-lite 更新为 3.2.7 #5964
  • [feature] 当线程池耗尽时发布 ThreadPoolExhaustedEvent #5958
  • [Dubbo-5855] FINALIZE 时 ReferenceConfig(null) 不会被销毁 #5863
  • 将指定的 url 注册到提供程序模型，无论提供程序是否配置为延迟发布#5757
  • [增强] 如果 Dubbo Config 的 id 属性为空，则将其 name 属性作为 Spring Bean #6063
  • [增强] 为 Apache License #6060 添加构建工具模块
  • [增强] 重构 XML 配置中 dubbo config BeanDefinitions 的解析器 #6039
  • [重构] 将“parameters”属性提取到新的抽象 Dubbo 配置类 #6043
  • [重构] 重命名ServiceAnnotationBeanPostProcessor的类名 #6070
  • [增强] 添加 ExtensionLoader 的覆盖规则 #6068
  • [增强] 解决配置类中 XML BeanDefinition 的占位符 #6079
  • 未找到服务/方法时忽略反序列化#5733
  • DynamicConfiguration：如果未实现，则返回默认值。第6086章
  • [Dubbo-Optimization] 修改同步监听对象为final #6081
  • 支持使用@Method或@DubboReference时的合并 #6092
  • 将“dubbo-build-tools”模块设为不可部署模块。第6115章

错误修复

  • zipkin 跟踪过滤器导致死锁 #5955
  • 修正所选调用者的数量#5875
  • 修复多注册表订阅负载均衡策略无法正常工作的问题。第5686章
  • [Dubbo-5871][Dubbo-5885][Dubbo-5899] 修复自 2.7.6 #5902 以来 nacos 注册表不起作用的错误
  • 修复默认配置无法按预期工作的问题。第5952章
  • 修复潜在的 ConcurrentModificationException #6031
  • 恢复与jdk相关的computeIfAbsent错误#6032
  • 修复tomcat9支持。第5711章 第6066章
  • 修复阿里巴巴 RpcContext setAttachment(String,String) #6052
  • 使用jdk11时添加javax支持 #154
  • 在请求包中使用正确的服务名称 #6138

  • 与注册“默认”的较低版本兼容。键#5950
