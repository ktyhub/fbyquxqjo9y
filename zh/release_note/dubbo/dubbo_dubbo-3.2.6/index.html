dubbo 3.2.6

修订 发布时间2023年9月4日 来源apache/dubbo 英文原文

dubbo dubbo-3.2.6

发生了什么变化

功能

  • gson 的通用调用支持 https://github.com/apache/dubbo/pull/12832 中 @finefuture 的 null args
  • 支持检查https://github.com/apache/dubbo/pull/12952中的qos服务器是否由@AlbumenJ启动
  • 通过https://github.com/apache/dubbo/pull/12892中的@robin977为服务接口添加metrics初始化指标(#12850)
  • 支持https://github.com/apache/dubbo/pull/12998中@AlbumenJ忽略刷新配置

错误修复

  • 通过 @icodening 修复 https://github.com/apache/dubbo/pull/12805 中的内存泄漏
  • https://github.com/apache/dubbo/pull/12835中添加rest方法注解支持@suncairong163判断
  • 删除 https://github.com/apache/dubbo/pull/12837 中@suncairong163 的休息第一场比赛休息时间
  • @suncairong163 在 https://github.com/apache/dubbo/pull/12854 中支持 Resteasy 响应上下文结果
  • 通过 @suncairong163 在 https://github.com/apache/dubbo/pull/12842 中修复剩余线程内存泄漏
  • 修复回调模式 rpc 上下文丢失。作者：@wuwen5 在 https://github.com/apache/dubbo/pull/12866
  • 修复 https://github.com/apache/dubbo/pull/12911 中 @AlbumenJ 的 Spring Listener 顺序
  • 支持在 Spring 关闭时继续运行，并使用 @AlbumenJ 在 https://github.com/apache/dubbo/pull/12912 中的属性
  • 修复 https://github.com/apache/dubbo/pull/12913 中 @AlbumenJ 的 DubboMergingDigest 并发问题
  • 通过 @icodening 在 https://github.com/apache/dubbo/pull/12918 中修复三重 npe
  • 通过 @suncairong163 修复 https://github.com/apache/dubbo/pull/12890 中的 http 方法路径匹配器
  • 修复 https://github.com/apache/dubbo/pull/12926 中 @suncairong163 的 chunkoutputstream chunksize 异常
  • 修复 https://github.com/apache/dubbo/pull/12938 中 @AlbumenJ 的 injvm 参数错误
  • 修复 https://github.com/apache/dubbo/pull/12949 中@AlbumenJ 的 shouldReconnect 检查
  • 修复 https://github.com/apache/dubbo/pull/12951 中 @AlbumenJ 的静态目录指标标签
  • 修复了 @ray-lsr 在 https://github.com/apache/dubbo/pull/12962 中的 serialize.allowlist 不包含 SingletonMap 的问题
  • 如果作用域模型是 https://github.com/apache/dubbo/pull/12985 中 @AlbumenJ 的 LifeCycleManagedExternally，则忽略启动
  • 如果 @AlbumenJ 在 https://github.com/apache/dubbo/pull/12993 中 qos 启动失败，则清理资源
  • 修复https://github.com/apache/dubbo/pull/13000中@suncairong163的Rest序列化异常
