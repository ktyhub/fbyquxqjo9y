dubbo 3.3.0-beta.1

预发布 发布时间2023年10月7日 来源apache/dubbo 英文原文

我们非常高兴地宣布 3.3.x 分支的第一个测试版发布，该版本有一些非常令人兴奋的功能可供展示。

强烈建议继续使用 3.2.x 进行生产使用，并且仅在第一个稳定版本可用后才升级到 3.3.x（无 beta 后缀）。

新功能

  • 新增Triple协议，完全兼容gRPC，同时支持cURL和浏览器直接访问。
  • Rest风格的编程（Spring MVC和JAX-RS）和通信（application/ZZPH100​​ZZ）支持，使Dubbo应用程序更容易充当标准的Web服务器。
  • 使用 Spring Boot（Zookeeper、Nacos、Sentinel 等）进行开发时，有一堆启动器可轻松进行依赖管理。
  • GraalVM 原生镜像支持 Dubbo AOT。
  • 完全支持 JDK 21 和项目 Loom 线程模型。
  • 指标和跟踪改进。
