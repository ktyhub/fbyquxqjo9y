agentscope v0.0.2

修订 发布时间2024年3月29日 来源agentscope-ai/agentscope 英文原文

发生了什么变化

  • 添加ReActAgent代理
  • 新增web_digest服务
  • 添加更多示例
    • 自主对话并提及
    • 自组织对话
    • 与LangChain库的基本对话
    • 与ReAct代理对话
    • 与 RAG 特工对话
    • 五子棋
    • 分布式辩论
    • 分布式并行搜索
  • 添加更多模型包装
    • DashScope：聊天、图像合成、文本嵌入
    • 双子座：聊天、嵌入
    • Ollama：聊天、嵌入、生成
  • 在模型包装器（聊天和生成）中添加格式化功能以替换 PromptEngine
  • 添加AgentScope Studio
  • 相应更新文档
