agentscope v0.1.0

发生了什么变化

型号 APIs

1.支持智普AI API(https://github.com/modelscope/agentscope/pull/181) 2.支持小蚁API(https://github.com/modelscope/agentscope/pull/343) 3. AgentScope支持流模式（https://github.com/modelscope/agentscope/pull/347） 4.支持LiteLLM（https://github.com/modelscope/agentscope/pull/204） 5. 根据模型名称（https://github.com/modelscope/agentscope/pull/381）格式化输入消息

服务

新增以下服务功能

  1. TripAdvisor 搜索 2.Dblp搜索 3.维基百科搜索
  2. 网页浏览器控制 5、OpenAI和DashScope多模态服务功能

其他

1.在AgentScope中实现MoA方法（https://github.com/modelscope/agentscope/pull/327） 2.新增提示工程模块（https://github.com/modelscope/agentscope/pull/242） 3.改进RAG模块（https://github.com/modelscope/agentscope/pull/184）
