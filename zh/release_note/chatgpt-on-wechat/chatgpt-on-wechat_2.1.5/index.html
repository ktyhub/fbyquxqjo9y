chatgpt-on-wechat 2.1.5

这个项目是干啥的：一个把大模型接进微信的聊天机器人项目，能让 AI 在微信里自动回复、进群互动，还支持插件和访客页，适合想在微信里玩 AI 的人。

变更架构图

亮点

  • 提示词注入与凭证加固 — 这是最值得紧急升级的理由：#2968 切断了一条攻击链——注入的内容原本可以改写 MCP 配置，进而转向任意命令执行和密钥窃取；edit 工具也不再绕过保护去读写 ~/.cow/.env。如果你在不信任的仓库上跑代理，或把密钥放在那个 env 文件里，请把它当安全补丁而非功能版本来对待。

  • 文件/搜索/编辑工具行为变化 — 工作流层面变化最大的一项。search_files（#2982）新增基于 ripgrep 的内容搜索和工作空间内文件名搜索，read 现在总是输出行号，引用和后续编辑因此更稳定。edit 变得更严格：模糊匹配不再悄悄重新缩进、重复文本不会命中错误的位置、增加显式的全部替换，并在文件被代理外部修改时给出提示。注意那些依赖宽松模糊编辑、或依赖 read 不带行号输出的自动化；前台 bash 超时也调高了，且 bash 现在支持后台命令，长时间运行的服务/日志跟踪不再阻塞会话。

  • 上下文压缩与命令清理 — /compact 现在按需做摘要，而不用等自动裁剪，能在长会话里省下 token；/clear 成为清空当前会话的唯一方式，/context clear 仅作为别名保留；默认上下文窗口也调大了，裁剪开始得更晚。净效果是单个会话能干更多活、成本更低，已有的 /context clear 肌肉记忆或脚本仍然可用。

  • 工作空间预览与文件引用 — 聊天页现在内联渲染生成的 HTML、文档和图片，并带可点击的文件路径卡片；你可以把工作空间文件拖进来，或输入 @ 把文件/目录引用进上下文。这让上下文收集从复制粘贴变成直接落地，Web 和桌面端都一样；Web 输入框还能用自定义模板把简短提示词扩写成完整指令（#2989）。

  • 桌面客户端：Apple Silicon、飞书、内置 ripgrep — arm64 安装包此前一直带的是 x64 后端，修正后在 M 系列 Mac 上主进程和浏览器工具都有明显提速，收益最大。飞书作为频道回归，SDK 精简到约 1 MB 并在首次启用时拉取（#2988）；Windows 现在内置 ripgrep，搜索开箱即用；某个版本的更新弹窗只会自动弹出一次。

  • 可靠性修复与升级路径 — 多项修复消除了原本看起来像真失败的代理无谓重试：grep/find 退出码判断错误、浏览器脚本被误报为语法错误、相对图片路径无法解析。另外，config.json 里的 tools.bash.timeout 和 tools.bash.safety_mode 终于生效（#2986），全局记忆工作空间路径的 bug 也修好了（#2992）。源码部署用 cow update（或拉取后重启）升级；桌面用户通过客户端内更新器或下载页获取。

本版本无破坏性变更。

🗂 工作区和文件预览

聊天页面获得工作区的可视化视图：可以就地预览代理生成的文档、网页和图像。 Web 控制台和桌面 client 都支持它。

  • 工作区浏览：从面板中浏览工作区目录下的文件，并可搜索并下载到本地。
  • 文件预览：HTML 页面、文档和图像直接在侧面板中打开，回复中的文件路径呈现为 clickable 卡片。
  • 文件引用：将工作区文件拖到对话中，或在输入框中使用 @ 引用文件和目录并将其拉入上下文中。

🔧 核心工具改进

系统化的文件搜索、读取、写入、编辑和shell工具，增强Agent的文件处理和编码能力。

  • 新文件搜索工具：search_files 按内容或文件名搜索工作区，默认情况下由 ripgrep 支持 - 在大型目录上速度明显更快。谢谢@Maaayhan (#2982)
  • 行号读取输出：read 输出现在始终带有行号，从而更容易定位和引用特定行。
  • 更准确的编辑：edit 不再重写模糊匹配上的周围缩进，并且当文本重复时不再出现错误；添加了全部替换；现在会标记在代理外部修改的文件。
  • 写入时语法检查：write / edit 在写入之前验证结构化文件的格式，并解析源文件以将语法错误报告回代理。
  • 后台命令：bash 可以在后台运行命令，用于长时间运行的工作，例如启动服务或跟踪日志；提高了前台命令的默认超时时间。
  • 取消立即生效：clicking停止或运行/cancel会终止当前正在运行的命令。

文档：文件搜索

🧠 上下文管理

  • 上下文压缩：新的 /compact 命令根据需要汇总和压缩对话上下文，有效减少令牌使用。
  • 统一命令：/clear 现在统一清除当前会话的上下文，并保留 /context clear 作为别名。
  • 更大的默认窗口：提高了默认上下文限制，因此长对话稍后开始修剪。

文档：上下文管理

🖥 台式机 Client

  • Mac 上的本机：修复了带有 x64 后端的 macOS arm64 安装程序，大大加快了 Apple Silicon 机器上的主进程和浏览器工具。
  • 添加飞书通道：修复了client中缺少的飞书通道。飞书 SDK 现在是首次启用通道时按需下载的精简依赖项（约 1 MB）。感谢@EvanProgramming (#2988)
  • 更新提示：给定版本的更新对话框仅自动打开一次。
  • 捆绑搜索后端：Windows client 附带 ripgrep，因此文件搜索可以开箱即用。

下载：【CowAgent桌面版】(https://cowagent.ai/download/)

文档：桌面 Client

✨ One-Click 提示优化

Web输入框现在可以将您输入的内容扩展为更完整、更明确的指令，并且优化规则支持自定义模板。谢谢@sufan721 (#2989)

🔒 安全强化

  • MCP 和文件写入强化：修复了可通过提示注入利用的攻击链 - 恶意内容可能导致代理重写 MCP 配置，并从那里运行任意命令并窃取密钥。谢谢@Correctover (#2968)
  • 凭证文件保护：修复了 edit 工具绕过凭证保护来读取和写入 ~/.cow/.env。

🛠 改进和修复

  • 遵循 bash 配置：修复了 config.json 中的 tools.bash.timeout 和 tools.bash.safety_mode 被忽略的问题。感谢@EvanProgramming (#2986)
  • 内存工作空间路径：修复了全局内存配置中错误解析的工作空间路径。谢谢@Maaayhan (#2992)
  • 对话历史保护：修复内存索引自我修复，可以清除对话历史记录。
  • 会话删除：修复了仍在进行中的回复，将已删除的会话写回到列表中。
  • 浏览器启动：修复了浏览器已运行时启动重复实例的问题。
  • 准确的工具结果：修复了多个工具的误导性故障 - grep / find 的退出代码判断错误，浏览器脚本错误地报告为语法错误，相对图像路径无法解析 - 减少无意义的重试。

📦 如何升级

  • 源部署：运行 cow update 进行一 click 升级，或拉取最新代码并重新启动。参见【升级指南】(https://docs.cowagent.ai/guide/upgrade)。
  • 桌面 client：检查更新并使用 client 内的一个 click 进行更新，或从 下载页面 获取最新版本。
