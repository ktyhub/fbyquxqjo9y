chatgpt-on-wechat 2.1.1

这个项目是干啥的：一个把大模型接进微信的聊天机器人项目，能让 AI 在微信里自动回复、进群互动，还支持插件和访客页，适合想在微信里玩 AI 的人。

变更架构图

亮点

  • 自我进化默认开启 — 新安装会得到一个代理：对话一旦空闲，它就在后台复盘，修复表现异常的技能、沉淀可复用的新技能、跟进未完成的任务，并把发现写入记忆和知识库。只有在确实发生改动时才会出声；每次复盘前都会快照备份并支持完整撤销，内置技能受保护，所有读写都限定在工作空间内。关键落地细节：已有安装仍保持旧行为，直到你通过 Web Console → Settings → Agent Config 主动开启，所以上线时要明确决定是否打开。

  • Web Console 聊天真正可编辑、可并行 — #2865 在用户消息和机器人消息上都加入编辑/删除/重新生成，代码块带语言标记和一键复制，多个会话同时运行且切回时实时流会自动续上。文件可以拖到聊天视图的任意位置，删除当前会话会回退到相邻会话。如果你的工作流假设只有单条流，值得测一测：现在两个会话独立运行并且是”续上”而非”重来”。

  • MCP 在 Windows 上打通并支持并发 — #2859 修复了 stdio 传输在 Windows 上失败的问题，并把服务端超时通过 mcp.json 暴露为可配置，这对那些工具被悄悄超时的场景很关键。sse 和 streamable-http 传输现在能跨会话并发处理调用，多工具链不再被串行化。Windows 上还在用旧配置的用户，升级后应重新检查 mcp.json 的超时值。

  • 模型阵容调整，但无需迁移 — #2855 把 MiniMax-M3 提升为默认，同时保留 M2.7 系列作为可选；需要输出一致性的话请显式固定 M2.7。Qwen3.7-plus 新增多模态对话，#2857 让 Web Console 可以选择并持久化 ASR（语音识别）模型，一行安装脚本精简了菜单并加入 Xiaomi MiMo。注意那些从未指定模型的提示词，行为可能发生变化。

  • 运行时与部署加固 — 修复了 Python 3.13 的安装/依赖问题；流式回复现在真的可以中断（一个长期存在的取消 bug）；cow status 会报告当前项目路径；频道排序跟随 UI 语言，并改进了 auto 回退。安全方面，#2863 把凭证文件屏蔽范围收窄到仅 ~/.cow/.env，其他目录不受影响；当 wechatmp_token 为空时，微信公众号现在会拒绝 webhook 请求——如果你依赖无需认证的公众号 webhook，升级前请先设置 token。源码部署可执行 cow update（或拉取后重启）。

  • 破坏性变更 — 2.1.1 中未正式声明。

🧬 自我进化

CowAgent 引入自我进化，让代理超越完成单一任务，并通过与您的日常协作不断改进：

  • 空闲后自动审核：一旦对话空闲，座席会在后台对其进行审核，以修复技能在使用中暴露的问题，创建可重用的新技能，跟进未完成的任务，并将重要信息记录到内存和知识库中
  • 默认情况下保持沉默，按需通知：仅在实际进行更改时才报告更改的内容，否则保持沉默
  • 安全且可逆：每条评论都会事先备份，并且可以随时撤消。内置技能受到保护，所有读取和写入都保留在工作空间内

新安装时默认启用。现有用户可以在 Web 控制台中的设置 → 代理配置下使用单个 click 将其打开。

文档：自我进化

💬 Web 控制台升级

Web 控制台聊天体验得到了多项增强：

  • 消息管理：编辑、删除和重新生成用户和机器人消息；代码块现在包括语言标签和一个 click 复制按钮
  • 并行会话：同时运行多个会话而不会产生干扰，当您切换回会话时，直播会自动恢复
  • 改进：将文件拖放到聊天视图中的任意位置；删除活动会话后自动切换到同级会话

感谢@core-power (#2865)

🧩 跨平台 MCP 增强

  • Windows 兼容性修复：修复了 Windows 上 stdio 通信失败的问题，并通过 mcp.json 配置服务器超时
  • 并发调用：sse 和 streamable-http 传输现在支持跨会话并发调用，以实现更快的多工具响应

谢谢@xliu123321 (#2859)

文档：MCP 工具

🤖 新模型和改进

  • MiniMax-M3：添加并设置为默认型号，M2.7 系列保留为选项。感谢@octo-patch (#2855)
  • Qwen3.7-plus：添加了对多模式对话的支持
  • 可选择的 ASR 模型：Web 控制台现在可以选择并保留 ASR（语音识别）模型。谢谢@nightwhite (#2857)
  • 简化的安装菜单：一行安装脚本简化了型号菜单并添加了小米 MiMo 选项

文档：型号概述

🛠 改进和修复

  • Python 3.13 支持：修复了 Python 3.13 上的安装和依赖兼容性
  • 国际化：频道列表现在按界面语言排序；完善auto模式下自动语言回退
  • 更可靠的取消：修复了流式回复无法中断的情况
  • CLI：cow status 现在显示当前项目路径
  • 强化部署安全性：凭证文件块缩小到 ~/.cow/.env，因此其他目录不再受到影响（感谢 @orbisai0security #2863）；当 wechatmp_token 为空时，微信公众号现在会拒绝 webhook 请求
  • 群组任务板插件：添加了群组任务板插件源。感谢@Wyh-max-star (#2853)

📦 升级

源代码部署可以运行 cow update 进行一 click 升级，或者提取最新代码并手动重新启动。详情请参见【升级指南】(https://docs.cowagent.ai/guide/upgrade)。
