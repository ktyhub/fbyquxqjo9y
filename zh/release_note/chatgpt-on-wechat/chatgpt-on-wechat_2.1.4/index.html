chatgpt-on-wechat 2.1.4

这个项目是干啥的：一个把大模型接进微信的聊天机器人项目，能让 AI 在微信里自动回复、进群互动，还支持插件和访客页，适合想在微信里玩 AI 的人。

变更架构图

亮点

  • 远程 MCP 服务器的 OAuth 支持 — 需要登录的第三方 MCP 服务器现在可以通过标准 OAuth 流程认证，你不再需要手工生成和轮换 token。这去掉了接入托管 MCP 工具时最脆弱的一环；正式依赖前请先确认 MCP 文档里支持的授权类型和 token 刷新行为。

  • 通过 /steer 和调度器实时控制任务 — #2977 新增 /steer，可以在任务还在运行时注入新指令，让你中途改方向而不必杀掉重启。它和后台静默任务（#2954）、按需手动运行（#2958）、跨频道 /tasks 命令（#2965）配套，另有一个修复解决控制台编辑时悄悄丢掉 mode type 等隐藏字段的问题（#2959）。最后这项对在 2.1.3 里编辑过定时任务的人很重要——请重新检查配置，那些字段可能已经丢了。

  • 飞书：撤回取消工作，引用进入上下文 — 需要留意的行为变化：撤回飞书消息现在会取消其关联的正在运行或排队中的任务（#2978），一次快速的”撤回”可能终止你本想保留的作业。好处是引用文本会并入代理上下文（#2966），Markdown 回复和定时推送渲染成卡片（#2962），/tasks 变成带启用/禁用控件的交互卡片（#2961），流式卡片新增可折叠的思考/工具调用面板（#2963），远程图片链接也能在卡片内渲染（#2967）。

  • 一等公民的备份与恢复 — cow backup / cow restore（#2957）用一条命令导出并重新导入配置、知识库、记忆及相关本地数据。把它作为升级前和迁移机器的标准手段，而不是手工复制数据目录——它同时给出更干净的回滚路径。

  • 新模型后端 — 新增 kimi-k3 以及 gpt-5.6-luna、gpt-5.6-terra、gpt-5.6-sol。无需改动配置结构，但如果你按名称固定模型，请更新这些引用，并在切换前确认新档位的可可用性和成本。

  • 桌面客户端加固 — 内置浏览器能力，并优先使用已安装的系统 Chrome/Edge 以加快启动；Windows 安装包已代码签名（减少 SmartScreen 警告），并支持旧版 Windows 7/8。一项密码登录修复解决了设置密码后窗口加载失败的问题——如果你要把客户端铺到混合或较老的机器上，这点相关。

本版本无破坏性变更。

🖥 台式机 Client

继上一版本推出桌面版client之后，本版本进一步提升了浏览器能力、系统兼容性以及整体体验：

  • 浏览器工具支持：client捆绑了浏览器功能，更倾向于复用系统已安装的Chrome/Edge，优化了浏览器启动和访问性能。
  • UI 优化：改进聊天视图、消息气泡、工具调用步骤和频道页面的视觉效果和交互。
  • Windows 代码签名：Windows 安装程序现在已进行代码签名，减少了安装过程中的安全警告。
  • Windows 7/8 支持：增加了对 Windows 7/8 等旧系统的 client 支持，覆盖更多环境。
  • 知识库链接修复：修复了桌面知识库中无法导航的文档内链接。
  • 密码登录：桌面client支持设置登录密码，并修复设置密码后窗口无法加载的问题。

下载：【CowAgent桌面版】(https://cowagent.ai/download/)

文档：桌面 Client

🔌MCP OAuth 授权

远程 MCP 服务器现在支持 OAuth 授权。当连接到需要登录的第三方 MCP 服务器时，可以通过标准 OAuth 流程完成身份验证 - 不再需要手动配置和维护令牌。

文档：MCP 工具

⏰ 计划任务

  • 静默模式：创建静默运行的计划任务，这些任务在后台执行，无需推送消息 - 非常适合数据组织或定期归档等不受干扰的场景。 (#2954)
  • 手动运行：从控制台手动触发现有任务立即运行，无需等待下一个调度。 (#2958)
  • 编辑时保留配置：修复了在 Web 控制台中编辑任务可能会删除模式类型等隐藏字段的问题。 (#2959)
  • 跨渠道任务命令：新增/tasks管理命令，跨渠道兼容。 (#2965)

谢谢@AaronZ345

文档：计划任务

💬 飞书频道改进

飞书频道在消息展示和交互方面进行了一系列增强，以提供更好的体验。

  • 流式卡片完善：流式卡片添加可折叠面板，显示思维过程、工具调用和执行时间。 (#2963)
  • Markdown 格式：对于非流式回复和计划推送，包含 Markdown 的消息将呈现为卡片，以便更清晰地显示。 (#2962)
  • 调度程序卡：/tasks 命令以卡的形式呈现，能够直接从卡启用或禁用任务。 (#2961)
  • 引用的消息上下文：当用户引用消息时，引用的内容会自动添加到发送给 Agent 的上下文中。 (#2966)
  • 远程图像渲染：现在可以在飞书卡内渲染远程图像链接。 (#2967)
  • 取消消息撤回：撤回飞书消息会自动取消其相应的正在运行或排队的任务。 (#2978)

谢谢@AaronZ345

文档：飞书

💾 数据备份与恢复

添加了 cow backup 和 cow restore 命令，可通过一条命令导出和恢复本地数据（配置、知识库、内存等），使迁移和备份变得轻松。谢谢@AaronZ345 (#2957)

文件：数据备份

🤖 新型号

  • 添加了对 kimi-k3 的支持
  • 添加了对 gpt-5.6-luna、gpt-5.6-terra 和 gpt-5.6-sol 的支持

文件：型号

🛠 改进和修复

  • 主动任务转向：添加了 /steer 命令以在任务执行期间注入新指令，动态引导或重定向正在运行的任务。谢谢@AaronZ345 (#2977)
  • 文件编辑：修复了编辑文件时模糊匹配可能定位错误的问题。感谢@weijun-xia (#2945)

📦 如何升级

  • 源部署：运行 cow update 进行单 click 升级，或拉取最新代码并重新启动。参见【升级指南】(https://docs.cowagent.ai/guide/upgrade)。
  • 桌面 client：检查更新并使用 client 内的一个 click 进行更新，或从 下载页面 获取最新版本。
