openclaw v2026.9.37

这个项目是干啥的：一个AI助手工具，更新失败能自动恢复、私人检查保持私密，升级更稳更安全，给想要安心用AI的日常用户用。

这是仅网关的 extended-stable 版本，由维护者明确决定从退役的维护线发布。此版本是 2026 年 9 月底发布的 OpenClaw，此外还有重要的安全更新、可靠性和性能修复以及新模型支持等功能。本次发布时 OpenClaw 的最新版本是 2026.11.2

2026.9.37

变更架构图

亮点

  • 私人检查保持私密： 配对节点照片和屏幕截图不再自动附加到回复中，并且在准备回复附件时会尊重明确的媒体读取拒绝。 （＃174814，＃184964）谢谢@eleqtrizit。
  • **响应式回复和页面：**长的零宽度 Telegram 表格单元和格式错误的插件 SVG 转换不再停止网关或浏览器页面。 （#183217、#182674）感谢@LeizhenZhang、@obviyus 和@SebTardif 作者：@steipete。感谢@LeizhenZhang、@obviyus 和@SebTardif。
  • **链接帐户在重置后仍保留：**会话通过 /new、/reset 以及空闲或每日展期保留其个人链接模型帐户。修复#179432。 (#179433) 感谢@masatohoshino 由@steipete 创作。谢谢@masatohoshino。
  • 更安全的更新恢复： 中断的快照写入保留以前的回滚点，并且配置文件支持的更新和 Doctor 维护不再超越其自己的维护所有权。 （#189946、#177792、#187104）感谢@kaguranananana、@GrahamMcBain 和@RomneyDa，作者为@steipete。感谢@kaguranananana、@GrahamMcBain 和@RomneyDa。
  • 连接恢复干净： 通道帐户可以在手动停止超时后恢复，并且 ClickClack 在静默网络掉线后重新连接。修复#184852。 （#177444、#184853）感谢@masatohoshino、@YangManBOBO 和@obviyus。
  • Windows 状态访问可跨路径别名工作： 等效的 Windows 路径保留相同的状态所有权，而不是错误地报告脱机维护。修复#176163。 (#176174) 感谢@tjarrau-dev 由@steipete 创作。谢谢@tjarrau-dev。

变化

  • 更快的插件准入： 在同一准入捕获中重用本机引用验证，而不是重复遍历同伴目录，同时重新验证替换捕获和恢复副本。修复#162047。 (#162254) 感谢@WG-Mojo，作者为@steipete。谢谢@WG-Mojo。

修复

  • 私人诊断： 省略详细诊断中抑制的回复文本和后台命令内容，同时保留状态元数据。谢谢@steipete。
  • 媒体边界： 默认情况下保持配对节点检查照片和屏幕截图的私密性，并尊重回复附件的明确读取拒绝，而不会阻止授权的托管输出。 （＃174814，＃184964）谢谢@eleqtrizit。
  • 限制性组策略： Doctor 保留显式空的组允许列表、继承的设置和禁用的组策略，而不是填充后备发件人。修复#173826。 (#174787) 感谢@lockhartheavyindustries，作者为@steipete。谢谢@lockhartheavyindustries。
  • 发现输出： untrusted 网关发现字段中的转义终端控制字符。 (#183355) 谢谢@Alix-007。
  • 状态和写入结果： 识别已提交的 SQLite 写入，其工作结果无法序列​​化，避免不安全的重播，并跨等效路径拼写保留 Windows 所有权。修复#176163。 （#177321、#176174）感谢@tjarrau-dev，作者为@steipete。谢谢@tjarrau-dev。
  • **会话帐户：**通过显式重置和自动滚动保留链接的模型帐户选择及其来源。修复#179432。 (#179433) 感谢@masatohoshino 由@steipete 创作。谢谢@masatohoshino。
  • **频道恢复：**在超时手动停止后恢复频道帐户，并在静默网络掉线后恢复ClickClack消息接收。修复#184852。 （#177444、#184853）感谢@masatohoshino、@YangManBOBO 和@obviyus。
  • **本地工具连接：**替换意外关闭的 MCP 环回侦听器并保留其关闭的清理工作，而不是让以后的工具调用永久断开连接。修复#139340。 (#183352) 感谢@SC-10749 和@eli-pavlov 由@steipete 创作。感谢@eli-pavlov 和@SC-10749。
  • 电报和控制 UI： 限制了长零宽度表格单元格和格式错误的 SVG 转换字符串的处理，而不更改有效的表格或图标渲染。 （#183217、#182674）感谢@LeizhenZhang、@obviyus 和@SebTardif 作者：@steipete。感谢@LeizhenZhang、@obviyus 和@SebTardif。
  • 命令结果和临时文件： 当分离后代清理不确定时保留已完成命令的退出结果，保留可见的清理警告，并在写入失败时删除临时 MCP 配置目录。修复#179555。 （#185636、#179603）感谢@xiaopan-xydt 和@Yolo521-bot 由@steipete 创作。感谢@Yolo521-bot 和@xiaopan-xydt。
  • 网关凭据： 在配置单独的远程令牌时保持本地密码 SecretRefs 处于活动状态，并在指纹选项为空或仅包含空格时保留已保存的节点 TLS pin。 （#128175、#125646）感谢@TheAngryPit、@CassieMei、@obviyus、@RomneyDa 和@wanyongstar。
  • 更新和重新启动可靠性： 在写入中断后保留回滚快照，在重新打开请求者策略之前释放已完成的维护，在 Doctor 维护期间确认前置停止收据，并准备在重新启动信号围栏之外重新启动配置。 （#189946、#177792、#187104、#172777）感谢@kaguranananana、@GrahamMcBain 和@RomneyDa，作者为@steipete。感谢@RomneyDa、@kaguranananana 和@GrahamMcBain。
  • 内存作业和导入： 禁用已停止或失败的梦想作业，并刷新导入的 ChatGPT 记录示例，而不会覆盖真实的 Notes 部分。修复#180655、#193161。 （#180694、#193173）感谢 @Yun-0000、@lisandromachado、@KhanCold 和 @obviyus 由 @steipete 创作。感谢@lisandromachado、@KhanCold、@Yun-0000 和@obviyus。
  • 发布工件验证： 限定候选人的确切插件工件，通过认可的验证者进行路由验证，并接受省略步骤详细信息的成功准入作业，同时保留运行、尝试、工件和权限检查。 （＃164464，＃173437，＃188597）谢谢@RomneyDa。 ###完整贡献记录 此审核记录涵盖完整的 v2026.9.36..2f7023b27b95ab6e3734e588d7eef40fd66b84fd 历史记录：28 个范围内 PR + 0 个保留的仅种子 PR = 28 个唯一 PR。生成清单还提供直接提交作为编辑输入；上面分组的注释优先考虑用户影响。 已发送基线排除：v2026.9.36（1 PR：#158414）。
