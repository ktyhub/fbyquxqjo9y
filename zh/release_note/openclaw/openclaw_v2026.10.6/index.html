openclaw v2026.10.6

2026.10.6

变更流程图

亮点

  • 需要修补的节点运行时： OpenClaw 现在需要第 24 行上的节点 24.22.1+ 或第 26 行上的 26.12.1+，这会拒绝使用 2026 年 10 月 Node.js 安全版本中解决的受损证书密钥签名的 TLS 链。 Docker 映像附带节点 24.22.1，安装程序选择修补的运行时，而 openclaw update 在安装到旧节点上之前会拒绝恢复指导，而不是破坏正在运行的安装。源代码现在已引脚 pnpm 12.15.0。 (#179992) 谢谢@joshavant。
  • 更安全的更新和恢复： 包交换现在拒绝不安全的服务状态，Windows 和 macOS 包管理器更新从特定于平台的故障中恢复，并且冻结的 Gateway 启动所有者可以干净地退休。 （#171101、#170940、#171936、#171678）感谢@RomneyDa、@homeworld520、@Yolo521-bot、@stop-time、@AntaresGG 和@TommyLei666。
  • 数据保留迁移和备份： 医生和迁移路径现在拒绝格式错误或有损的工作区导入，保留格式错误的 Notes 字节，拒绝不安全的非 UTF-8 wiki 重写，保留深度嵌套的 SQLite 备份，并在恢复检查失败时保留暂存证据。 （#172293、#172953、#172742、#174573、#168583、#170867、#172028）感谢@wangmiao0668000666、@RomneyDa、@Leon-SK668、@ericcurtin、@Yolo521-bot、@obviyus 和@altaywtf。
  • 重新启动后的可靠传递： 排队轮流、监视子结果、死信传递和流式回复现在可以在恢复后继续存在，而不会消失、重复或产生错误的缺失答案通知。 （#170384、#169489、#169932、#173798）感谢@RomneyDa、@huyengiang101086-spec 和@Yolo521-bot。
  • 提供者和模型弹性： GPT-5.6 工具轮换、OpenRouter DeepSeek 工具调用、LM Studio 溢出恢复、并行 OpenAI 推理设置以及模型重试/回退预算现在表现一致。 （#176709、#175058、#169189、#169322、#164808）感谢@RomneyDa、@Linux2010、@ZhimingQ、@xpeng5278-web 和@anyech。
  • Windows 和移动稳定性： 全新的 Windows 状态存储、代理支持的环境和存储的 Anthropic 凭据不再阻止启动，而 iOS Talk 和聊天连接可从首次回复和超时故障中恢复。 （#176174、#176194、#174571、#168416、#169912）感谢@RomneyDa、@tjarrau-dev、@skyzhao1223、@easyteacher、@scalesmart、@masatohoshino、@Takhoffman 和@Solvely-Colin。
  • **代理和工具调用恢复：**未完成的工具现在明显超时，引导工具结果后上下文溢出压缩，格式错误的调用在早期拒绝后继续，大补丁块避免参数限制崩溃，并且停止生成的任务保持停止状态。 （#172983、#172019、#170615、#174477、#169453）感谢@RomneyDa、@budzation、@mirasrael、@r3n3x、@freeqaz-openai 和@obviyus。
  • 渠道传送正确性： WhatsApp 重试和贴纸、Telegram 相册和双栈回复、Slack 中继恢复和 Discord 语音通话回复不再丢失或重复消息。 （#142434、#164210、#163926、#171564、#173407、#172380）感谢 @ashawwal、@RomneyDa、@andrewwbuilds、@abacha、@Dat1GUI、@brainmonger、@obviyus 和 @vincentkoc。
  • **工作线程和工作树恢复：**主机在重新启动后回收工作线程容量，部分克隆工作树修复丢失的对象，并且子结果和执行唤醒证据在网关重新启动后仍然存在。 （＃168863，＃168864，＃169489，＃169645）谢谢@RomneyDa。

变化

  • 此补丁版本仅包含重点可靠性修复；它没有引入新的面向用户的功能。

修复

  • **状态和系统代理恢复：**恢复对受影响升级所持有的代理的访问，在架构更改后恢复持有的系统代理数据库，并在取证快照失败时保留实时配置。 （#175007、#176783、#171217）感谢@RomneyDa、@PennyVibe 和@Yolo521-bot。
  • Windows 状态和更新： 规范化跨路径别名的架构所有权，在检查 IPC 之前序列化代理支持的环境，在更新工作期间隐藏 SQLite 帮助程序窗口，并识别每个区域设置中的本机计划任务权限失败。 （#176174、#176194、#174969、#178624）感谢@RomneyDa、@tjarrau-dev、@skyzhao1223、@easyteacher 和@throwingbones。
  • macOS 配套执行： 遵守配套套接字上的长命令和批准截止日期，对迟到或丢失的回复进行分类，而无需重播提交的命令，并保留本机权限详细信息。 (#172117) 感谢@holgergruenhagen、@RomneyDa、@ylcn91 和@Colton-Harris。
  • 医生和托管插件： 修复空的退役插件元数据，清除已解决的迁移警告，并将应用程序管理的插件聚合到已安装的核心版本。 （#173851、#177096、#174257）感谢@RomneyDa、@fengfan201314-eng、@ScientificProgrammer、@yinx65588-boop、@jj5638521 和@kazuyuki-eguchi。
  • 更新诊断： 保留 FRV 阻止程序，解释包日志身份和运行时保留故障，并避免共享恢复清单上的清理停顿。 （#171186、#170385、#169280、#174249）感谢@vincentkoc、@RomneyDa、@astapenkoav、@council10-kera 和@shoaibulhaque。
  • SQLite 正确性： 在警告处理程序抛出时保留事务结果，在共享工作线程拒绝后解决对等点关闭问题，并防止退休的缓存生成获取工作线程所有权。 （#157151、#173813、#172798）感谢@vincentkoc 和@RomneyDa。
  • 回复恢复： 保留附带问题和立即后备排序，避免流传输后重复或丢失答案，并防止重新启动已停止的已生成任务。 （#174869、#169305、#173798、#169453）感谢@RomneyDa 和@freeqaz-openai。
  • Codex 和本机会话： 在取消或清理失败后释放停滞的启动等待和完成的子代理，在运行时重新启动时保留对话，在回复重置时保留工作区绑定，并在会话准备就绪之前解决恢复的子绑定写入。 （#168347、#173547、#166368、#160549、#177564）感谢@RomneyDa、@Kimiyu-186、@alkor2000、@jhgaylor、@vincentkoc、@jjjhenriksen 和@obviyus。
  • **网关生命周期：**保留重新启动托管，避免停止时租用死锁，重新启动后恢复工作线程容量，并在重新加载时保留抑制通道配置。 （＃172852，＃171308，＃168863）谢谢@RomneyDa。
  • CLI 和进程诊断： 在网关命令退出时保留 JSON 输出，报告资源处置和 PTY EOF 故障，并显示失败的诊断写入而不会崩溃。 （#176795、#173566、#176362、#174622）感谢@vincentkoc 和@RomneyDa。
  • 预定的后续行动： 由授权操作员安排的同一对话后续行动在运行时会保留该操作员的当前权限，并且一次性延续可以调用 next_check 稍后再检查。 (#176422)
  • 媒体和 TTS： 超时缓慢的托管语音合成并报告播放缓存、探测和配额失败，而不是默默地丢弃清理错误。 （＃175614，＃175634，＃174668）谢谢@RomneyDa。 ###完整贡献记录 此审核记录涵盖完整的 v2026.10.5..bba7238a1be3a0d4e92c371988f94e81011a06b2 历史记录：293 个范围内 PR + 0 个保留的仅种子 PR = 293 个唯一 PR。生成清单还提供直接提交作为编辑输入；上面分组的注释优先考虑用户影响。
