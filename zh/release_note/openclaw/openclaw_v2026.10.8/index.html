openclaw v2026.10.8

这个项目是干啥的：一个AI助手工具，更新失败能自动恢复、私人检查保持私密，升级更稳更安全，给想要安心用AI的日常用户用。

2026.10.8

变更架构图

亮点

  • 完成并恢复的更新： 普通的更新后 Doctor 故障会重新启动网关而不是使其停止，孤立的维护工作人员不再阻止每个 CLI 命令和网关启动，并且更新不再在 ACL 文件系统、Windows pnpm 可选依赖项链接、pnpm 10 全局安装、调试控制台日志记录或丢失的旧版 OAuth 目录上中止。 （#180668、#181695、#181141、#181596、#181456、#182850、#180174）感谢@hannesrudolph、@SMF12138、@rayluo88、@PonySlayer28 和@VN77-77VN。
  • 网关服务安装在每个桌面上： macOS 恢复已加载的启动注册（其 plist 已被删除），Linux 在 Ubuntu 默认 umask 下安装，创建一个私有状态目录而不是被拒绝，并且 macOS 更新程序在 Doctor 运行之前等待服务网关释放其数据库。 （#180390、#179538、#182055）感谢@avnishkirnalli 和@XiaoPengYouCode。
  • 对话继续接受消息： 被杀死的运行释放其重新启动恢复围栏，中断的和刚刚接受的子会话在网关重新启动后恢复，当回复运行时无法发布时，入站消息将永远停止重试，并且控制 UI 忘记发送重试会传递回复而不是创作错误。 （#181992、#178888、#181871、#181300、#182219）感谢@najef1979-code、@handcraftrc-pixel、@sukhdeepjohar 和@teddashh。
  • **启动和数据库弹性：**启动工作不再继承封闭的 SQLite 读取器范围，因此模型、聊天元数据和频道回复保持可用；重试代理数据库启动期间的瞬时锁争用；模型目录在技能运行期间保持可用。 （#182615、#182446、#182385）
  • 安全强化： 执行白名单模式需要批准 test -v 操作数扩展，通用节点调用拒绝浏览器代理命令，沙箱生成的子项无法运行主机 CLI 后端，秘密出口代理拒绝 distrusted eMudhra 链，Fish Audio 和 Gradium 错误不再暴露 API 密钥，深度嵌套的 Tlon 内容不再拖延通道。 （#180880、#179880、#178742、#179249、#178877、#177536）感谢@eleqtrizit 和@joshavant。
  • Windows exec 和插件： 代理 exec 在安装了 Store PowerShell 的情况下在 S4U 计划任务下工作，本机插件在具有 Endpoint DLP 的计算机上加载，并且 Doctor 恢复另一个文件系统上的悬空依赖项连接和插件。 （#182898、#179949、#179549、#179445）修复#182652 感谢@RomneyDa、@tre1d、@coaiMax、@paulcam206、@JIRBOY 和@ceckert。
  • 提供程序和模型连续性： Codex 轮流使用较旧的运行时插件来保持预算，而不是默默地回退，Codex 本机子推理在启动后起作用，OpenAI OAuth 适用于过时的目录，人性化 PDF 分析适用于设置令牌 OAuth，超时的 MCP 会话关闭在下一回合不再失败，并且 CLI 历史记录所有者更改停止而不是在另一个提供程序上静默重播。 （#182995、#176311、#181356、#178420、#182189、#180075）修复#181619 感谢@RomneyDa、@kip-claw、@enki、@sasan1200、@sunlit-deng、@khensthoth、@aniketkrs、@goslingmanagment、@wr-web 和@teddash。

变化

  • 全新 OpenAI 设置： 首次运行模型元数据不再将模型选择器限制为一个模型。 (#175945) 感谢@matthematics1137 和@jb-dev1。

修复

  • 频道帐户： 默认 Slack、Google Chat、X、Nextcloud Talk 和 Zalo 帐户在添加命名帐户后继续启动并保守秘密。 （#176267、#180450、#182608）感谢@555aaditya、@progerjkd 和@masatohoshino。
  • Slack： 在禁用套接字模式通道之前重试隔离的 invalid_auth，并且静默中继网络会断开重新连接。 （＃181056，＃182368）感谢@mushuiyu886和@marns。
  • Matrix、Twitch、Zalo、iMessage 和飞书传送： 普通 Matrix 消息不再被视为文本命令，Twitch 发送标准化频道目标，处理带有 URL 的 Zalo DM，消息桥死亡后 iMessage 恢复，飞书快速操作卡再次发送。 （#179506、#178480、#178938、#180900、#79832）感谢@xiaopan-xydt、@doomy、@HeZ2z、@Takhoffman、@zzrs-xyr、@namchamvinhcuu 和@xiabee。
  • **代理运行和提供程序：**当后台命令完成时，心跳循环停止，临时 Codex 探针工作程序不再累积，Codex 本机轮次在主机工作期间保持活动状态，Claude CLI 轮次在流输出达到限制时不再停滞 15 分钟，提供程序流错误立即浮出水面，并且会话准入竞争不再触发模型回退。 （#179060、#167390、#181839、#159931、#117397、#179347）修复#178937、#181805 和#178000 感谢@maxdjohnson、@sunlit-deng、@Terwox、@AINCHORS、@robertmsale 和@davidcittadini。
  • 语音和会议： Discord 实时语音咨询初始化其运行时间，语音呼叫使用配置的代理模型，长会议对讲回复保留其音频。 （#179462、#181451、#178254）感谢@shoaibulhaque、@yagizkus、@potoior、@BeyonceBot 和@sukhdeepjohar。
  • 远程访问和历史记录： Tailscale Serve 和 Funnel 在 tailscaled 重新启动后恢复，并且 cron 历史记录在提供程序更改后保持可读。 （#180081、#181311）感谢@enki、@saariuslystoned 和@xtimor。
  • 医生修复： 标题修复后保留的成绩单进行验证，并且修复保留了 Codex 主机压缩模型。 （#179089、#179914）感谢@mr savingsblogspot-rgb 和@LiuwqGit。
  • **插件和节点：**旧插件防抖回调继续工作，计算机使用接受来自旧 Mac 节点的输入结果，当 OKF 概念消失时，Memory Wiki 会保留用户注释。 （#118011、#137755、#179657）
  • 秘密和挂钩： 1Password 秘密提供程序接受可组写的 OpenClaw 文件，并且并发会话内存捕获不再相互覆盖。 （#181127、#181081）感谢@jalehman、@jason-allen-oneal 和@yetval。
  • Doctor 恢复消息： 当 Doctor 无法恢复已停止的网关时，它会打印故障以及如何启动网关。 (#181941)
  • Codex 原生子项和回复： 已完成或无法交付的子项完成不再重播或楔入父项，回复在本机子项完成、被打断或完成后续操作后解锁，最终答案在短暂重试后仍然存在，没有镜像提示完成的已解决回合，本机工具声明保持稳定，排队聊天在插件重新加载后恢复，在终端发布之前提交转向提交，Codex 接受托管环回代理默认值。 （＃173018，＃175246，＃177577，＃179099，＃179050，＃183286，＃181779，＃183077，＃182104，＃184062，＃183232）谢谢@quqi1599，@Stronggenics，@linancn，@wtfichigo， @mmartoccia、@Marvinthebored、@sukhdeepjohar、@jjjhenriksen、@aatreya、@ermaxinc 和 @RomneyDa。
  • Claude CLI 会话： 不相关的本机任务不再保留最终答案，父级回复在嵌套后台代理后完成，停止的第一回合保持对话，房间事件不再重置会话，操作员可以保留本机代理和工作流程工具，恢复的会话查看对话更新，并且 Claude CLI 模型通过保存的订阅保持可用。 （＃170322，＃182267，＃181966，＃182273，＃183765，＃183059，＃179203）谢谢@cassthebandit，@VACInc，@goslingmanagment，@holgergruenhagen，@xiaopan-xydt，@Marvinthebored，@scarabone，@atomsmasher81， @josh-cornelius 和 @teddashh。
  • **子代理和代理轮次：**模型回退在本地运行时故障后停止，恢复的子结果在会话重用后交付，私有完成收据在重新启动后协调，父级继续等待活动收集器，批处理工具调用在 sessions_yield 之前解决，延迟的 sessions_send 回复不再被削减为 4,096 个字符，轮次在工具结果恢复后完成，恢复在转录重建期间发送的消息，并释放已完成的尝试回调。 （＃180042，＃184069，＃184041，＃172959，＃184021，＃178271，＃175685，＃182666，＃164843，＃183884）谢谢@sunlit-deng，@danielsiemers，@johan-eilertsen，@jailbirt，@rjdotdev， @wr-web、@seriouslysean、@MSNexploder 和 @PollyBot13。
  • 网关稳定性和流式传输： 长 HTML 和 JSX 答案、精心制作的 Teams HTML 以及看起来像工具调用的回复不再阻碍网关；推理标签在流式传输之前被保留；静音转弯不再发送丰富的有效负载；通道重新启动后仍会退出运行取消；强制插件停用后网关关闭；插件服务计划的寿命超出了创建它们的范围；冷工具库存不再增加内存。 （#175472、#183438、#183252、#182454、#129244、#182433、#181270、#182207、#178596）感谢@JasonBuildAI、@LeizhenZhang、@zax0rz、@JOY、@0xtc23、@bguliano， @obviyus 和@wuqxuan。
  • 更新、安装和 Doctor： Windows 管理的更新不再将自己锁定在 TEMP 别名上，Windows 安装程序通过 iex 运行，更新在通道中断期间完成并保留接受的策略引脚，停止的数据库备份允许读者，Doctor 在 SIGHUP 后恢复网关，保留有效的重新播种配置和继承的登录，修复不受支持的节点运行时，删除日志丢失后恢复代理，恢复插件主机链接，处理非常大的保留历史记录，并使用更少的内存大型舰队。 （#183622、#183145、#179471、#180505、#180827、#182901、#183703、#179726、#181618、#181804、#181140、#180414、#180792、#181465）谢谢@ryandle、@duyufansh2008、@waynegault、@csabatatrai、@samueltardieu、@4140leal-cw、@rybing7、@RomneyDa、@LiuwqGit、@sukhdeepjohar 和 @teddashh。
  • **会话和存储：**相对会话存储根据状态目录解析，会话通过符号链接状态路径存档，过时的重新启动恢复源不再楔入会话，cron 清理保留活动子会话，存档的 Discord 斜杠命令会话恢复到位，后台插件工作保留其 SQLite 读取器，会话删除重用热存档工作人员。 （#182444、#181554、#180853、#179057、#168596、#179031、#171156、#175091、#183410）感谢@erickj92、@Cloud-Ocean、@Oldrich333 和@PollyBot13。
