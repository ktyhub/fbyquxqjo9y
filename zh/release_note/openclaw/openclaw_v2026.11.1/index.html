openclaw v2026.11.1

这个项目是干啥的：一个AI助手工具，更新失败能自动恢复、私人检查保持私密，升级更稳更安全，给想要安心用AI的日常用户用。

2026.11.1

变更架构图

亮点

  • 更安全的 Mac 设置：失败的配置保存不再覆盖机密，并且关闭 Tailscale 暴露可保持网关身份验证完好无损。 （#187734、#187664）修复#187600、#187597 感谢@anmol0b。
  • 更可靠的渠道回复：在请求处理程序或更早的轮次完成后，Telegram、Discord 和 webhook 对话会继续到达代理。 （#179200、#179385、#179704、#189457）修复#178554 感谢@steipete、@LiuwqGit、@jalehman 和@vincentkoc。
  • 对话可以承受更多的干扰：超大转弯保留有用的历史记录，并且停止第一个 Claude CLI 转弯不再从头开始下一条消息。 （#191146、#181966、#186380）修复#191133、#181945 感谢@Yun-0000、@obviyus、@mirasrael 和@holgergruenhagen。
  • 更新恢复在更新程序崩溃或取消后恢复正常，在验证失败后恢复 Windows 网关，并避免在大状态检查期间重复进行完整数据库复制。 （＃177932，＃186787，＃189647，＃182632，＃187921）修复＃177684，＃184893，＃189620谢谢@duyufansh2008，@RomneyDa，@fuller-stack-dev，@TheAngryPit，@sukhdeepjohar，@steipete，@syxscott，和@stephen3303。
  • 子代理通过模型和会话更改保持跟进，而父会话即使使用自定义会话存储也会收到子批准。 （#186238、#183501、#189827）修复#179289、#189823 感谢@steipete、@Marvinthebored、@RomneyDa 和@ekinnee。
  • 具有兼容网关的 Android End Talk 停止监听而不取消接受的代理工作，因此其答案仍然可以在聊天中到达；明确取消仍然可用。 （＃172276，＃188798）谢谢@RomneyDa。
  • 提供商恢复遵循提供商指定的速率限制计时，Gemini Flash 文本模型默认在官方 API-key 端点上使用交互，而自定义代理保留其现有的默认设置。 （#180280、#189395）感谢 Ayaan Zaidi、@evomach、@sukhdeepjohar、@RomneyDa。

变化

  • Claude CLI：保存的订阅帐户可以使配置的模型无需单独的本机登录即可使用，操作员可以通过 plugins.entries.anthropic.config.managedNativeTools 选择本机代理和工作流程编排；默认值保持关闭状态，受限运行保留其现有的工具限制。 （＃179203，＃183765）谢谢@RomneyDa。
  • Anthropic：API键设置可以记录可选的Anthropic工作区ID；现有的工作区标题将被保留，并且工作区范围的键不需要额外的设置。 (#186976) 感谢 Ayaan Zaidi、@evomach、@sukhdeepjohar、@RomneyDa。
  • Google：交互请求尊重托管代理和 TLS 设置，在速率限制后进行流式传输之前轮换符合条件的 API 密钥，保留本机视频输入，并一致地转发核心采样；当需要显式 Gemini 缓存句柄时，选择 google-generative-ai。 （＃189395，＃190695）谢谢@RomneyDa。
  • 基岩地幔：发现的编号 OpenAI GPT 模型自动选择响应路线，而 GPT-OSS 保留聊天完成，Claude 保留人类消息。感谢@MertBasar0、@anmol0b、@shakkernerd、@kybrcore、@sukhdeepjohar、@potoior、@RomneyDa。
  • 控制 UI：模型选择器显示配置的活动上下文预算，而不仅仅是模型最大值，并且短会话链接保留其预期的导航目标。 （＃180870，＃183148）谢谢@RomneyDa。
  • Google Chat：远程 HTTP(S) 附件作为可见链接与标题一起传送；服务帐户身份验证仍然不支持本地文件和本机上传。谢谢@RomneyDa。
  • 更新诊断：详细的准备情况将就绪核心与通道中断分开，允许修复的更新程序完成命名通道警告，而不会隐藏 HTTP 503 或削弱正常的服务启动检查。谢谢@duyufansh2008，@RomneyDa。

修复

  • 网络和工具安全：ClickClack 和 ClawHub 拒绝重定向到不相关的私有服务，Discord CDN 下载不再继承浏览器私有网络访问权限，并且 FIFO 本机钩子凭据被拒绝而不挂起代理。 （#190944、#190939、#191458、#191423）感谢@pgondhi987、@SebTardif 和@Leon-SK668。
  • 医生同意和访问政策：非交互式检查不再在没有修复同意的情况下下载插件，并且明确空的组允许列表保持为空而不是重新填充。 （#191523、#174787）修复#191420、#173826 感谢@brandonulrich、@steipete 和@lockhartheavyindustries。
  • 恢复数据：格式错误的 UTF-8 旧版导入将被拒绝，而不是替换原始内容；失败的技能恢复回滚会保留原始副本，并且当工作区检查失败时清理会拒绝破坏性工作。 （#180861、#173954、#174195、#176362）修复#180782、#180795 感谢@RomneyDa、@duyufansh2008、@steipete 和@wangmiao0668000666。
  • 日志修订：格式错误的自定义条目不再禁用有效规则或内置秘密保护；报告无效策略，同时安全编辑仍处于活动状态。 (#173471) 感谢@skyzhao1223 和@RomneyDa。
  • 秘密出口：拒绝依赖于托管代理和导出的子进程 CA 捆绑包中的 distrusted emSign ECC G3 根的链；更新后重启网关，并单独更新具有独立trust存储的clients。 (#179249) 谢谢@RomneyDa。
  • macOS 连接：配置的凭据优先于过时的应用程序环境，键入的环境秘密引用正确解析，并且远程设置遵循控制 UI 基本路径。 （#191468、#185141、#128175）修复#164596 感谢@RomneyDa、@anmol0b 和@goldmar。
  • Mac 工具和消息传递：iMessage 在应用程序更新后仍然可用，无需重新授予自动化权限，Peekaboo 窗口检查接受有效的快照引用，node exec 会保留配置命令的结果，而不会超时。 （#186107、#172116、#190729）修复#178719 感谢@aniketkrs、@RomneyDa、@anmol0b、@SharkeyDev、@holgergruenhagen、@LiuwqGit 和@etzelm。
  • Mac 语音和嵌入页面：避免重复的语音发送和错误发送的反馈，并显示可恢复的加载错误，而不是空白或陈旧的 Mac 选项卡。 （#186271、#185432）感谢@anmol0b、@etzelm 和@RomneyDa。
  • 原生语音和捕获：iOS 和 macOS Talk 可以容忍有限缓冲内的缓慢音频确认，长会议回复不会仅仅因为生成速度超过播放速度而被切断，超大 Mac 录音会因大小指导而失败，而不是断开节点连接。感谢@MertBasar0、@anmol0b、@shakkernerd、@kybrcore、@sukhdeepjohar、@potoior 和@RomneyDa。
  • Android和桌面兼容性：Android Chat在切换网关后等待角色允许的代理列表，独立更新的Mac节点可以返回可选的光标坐标，而不会出现计算机使用合同错误。感谢@MertBasar0、@anmol0b、@shakkernerd、@kybrcore、@sukhdeepjohar、@potoior、@RomneyDa。
  • 通道恢复：Slack 检测失效的中继连接，而不将普通的静默视为故障，Tlon 重新连接停滞的流，以便可以重播未确认的事件，托管的 Tailscale 暴露在守护程序重新启动后恢复，同时本地身份验证的访问保持可用。谢谢@RomneyDa。
  • 渠道投放：飞书将工具调用前后的文字保留在同一个流媒体卡中； Synology 仅根据收件人匹配的消息 ID 确认送达； Twitch 目标和 Zalo 不受支持的事件文本遵循其频道处理，而不是默默地丢失可用内容。谢谢@RomneyDa。
  • 通道凭据和通知：隐式 Slack 默认帐户与命名帐户一起保留完整的顶级凭据，通道秘密消费者尊重帐户激活，Nostr 报告失败的配对通知而不撤消批准。谢谢@RomneyDa。
  • iMessage 存储：恢复光标键不再包含 PostgreSQL 不兼容的 NUL 分隔符，允许通道以 PostgreSQL 支持的状态启动。 (#184919) 修复#184862 感谢@duyufansh2008、@RomneyDa 和@etzelm。
  • 会话和代理权限：删除一个代理不再破坏其他代理的工具权限，并且本地会话功能更改会阻止不适当的提供程序回退，而不是尝试每种模型。 （#174918、#179312）修复#179290 感谢@steipete、@chelsealong、@obviyus 和@Marvinthebored。
  • 提示缓存：会话工具定义在各个回合中保持稳定，包括完成、心跳和非所有者请求，避免不必要的提示缓存丢失。 （＃175309，＃176167）谢谢@obviyus。
  • 对话恢复：压缩在重复摘要中保留主动的人类请求；队列溢出摘要保留每个可见的发送者和对话上下文； exec 完成指导不会溢出。 （#180214、#187833、#190698、#182188、#184216）感谢@RomneyDa 和@aniketkrs。
  • Codex 连续性：会话范围的限制保留兼容的本机线程，临时限制保留普通会话绑定，并且具有记录历史记录的丢失线程报告错误，而不是默默地重新开始。感谢@skyzhao1223 和@RomneyDa。
  • Codex回复：瞬时重试可以总结原始请求和已完成的工具，而无需重新运行它们；终端切换允许已提交的转向有有限的机会来确认消费，并且不会自动重放不确定的输入。 （＃183077，＃184062，＃181839，＃167390）谢谢@RomneyDa。
  • 共享凭证和模型可用性：并发 MCP 调用者可以重复使用新的 OAuth 令牌，而无需不必要的独占锁定，速率限制冷却时间遵循提供者计时，而不是累积本地回退时间，新的模型发布将取代被取代的刷新结果。 （＃179997，＃180280，＃179144）谢谢@RomneyDa。
  • Claude CLI 和计划的工作：取消的 cron 运行停止回复挂钩，中断的长时间运行的作业不再阻止调度程序启动，超大或无效的 CLI 流立即取消其子进程，托管完成保留策略过滤的工具目录。 （#181245、#191422、#159931、#172026）感谢@steipete 和@fuller-stack-dev。
  • 会话历史和内存：长记录解码立即释放数据库读取快照，有界历史页面保留其请求的锚点和相邻消息，内存索引等待存档记录实现。 （#164442、#172970、#177937、#182091、#190182、#189284、#188450、#188483、#190690）修复#171467 感谢@RomneyDa 和@etzelm。
  • 子代理和重新启动恢复：活的后代保持其过期的父母可用于通信，接受的产量在移交之前解决同级工具结果，并且过时的中断输入不再无限期地阻止新的人类消息。 （＃179057，＃184021，＃180853，＃181871，＃178888，＃184041，＃184069，＃172959）谢谢@RomneyDa。
  • 代理切换：等待会话发送恢复存储的长回复，而不是仅返回短生命周期预览，并且 ACP 创建的会话保留请求的工作目录以供以后提示。 （＃178271，＃176852）谢谢@RomneyDa。
  • 控制 UI 恢复：静静地死去的网关连接重新连接，而无需重放不确定的发送，消耗的斜线引导消息离开队列，例行重启通知保持简洁。 （＃179101，＃178642，＃180024，＃172843）谢谢@RomneyDa。
  • GitHub 工作流程：活动会话可以打开重新连接流程，失败的后续推送保留现有 PR，并且读取器在丢弃响应正文时不再挂起。 （#180200、#187835、#191721）修复#187832 感谢@RomneyDa、@anmol0b、@obviyus 和@nocodet888-arch。
  • 插件生命周期：启动避免重新复制托管二进制文件，在安装根更改后修复拥有的陈旧主机链接，并使插件后台读取器保持活动状态以进行承认的回调和清理；内部插件重新加载继续保留在当前会话中，而不是使用旧的外部收件人。 （#187865、#181140、#182207、#179031、#181270、#179549、#190982）感谢@Satoshi-Kusumoto、@RomneyDa、@jasonftl 和@obviyus。
  • 网关启动和关闭：在过时声明清理和 sidecar 启动期间重试临时数据库锁定，并在干净关闭后退出，而不是等待 systemd 杀死具有泄漏句柄的进程。 （#187724、#186920、#191251）修复#187723、#186875、#191119 感谢@masatohoshino、@obviyus、@steipete、@yousan、@bianyuxia-commits 和@davesanvil。
  • 更新启动和迁移：使用保留的工作索引进行恢复，避免从 2026.10.7–2026.10.9 自动迁移恢复时崩溃，保留恢复错误，并拒绝在暂存之前需要不可用的较新节点的 Git 目标。 （#189023、#189713、#191495、#181715）感谢@RomneyDa 和@steipete。
  • 更新修复：释放废弃的取消保管并解决待处理的包步骤，无需修复循环；验证失败后恢复挂起的 Windows Gateway 任务，同时保留原始失败详细信息。 （#177932、#186787、#189647）修复#177684、#184893、#189620 感谢@RomneyDa、@fuller-stack-dev、@TheAngryPit、@sukhdeepjohar、@steipete、@syxscott 和@stephen3303。
  • 更新捕获和服务切换：列出恢复捕获时忽略 Finder 元数据，从 / 启动时恢复 CLI 节点运行时，并将不可用的自动更新服务切换分类为已跳过而不是未记录的故障。 （#186663、#178112、#188405）修复#186650、#177739、#188302 感谢@duyufansh2008、@RomneyDa、@steipete、@woshicby、@downingkeys 和@ARSA31。
  • 医生迁移：绑定长 Matrix 存档文件名，仅在迁移指南更改时保留配置升级，运行明确请求的无头修复，在跳过所需工作时返回失败而不是成功，并通过可操作的验证保留无效的心跳安静时间。 （#187443、#190665、#187192、#186305）修复#187390、#190658、#187122 感谢@RomneyDa、@skyzhao1223、@steipete、@dakoller、@saariuslystoned 和@JordanNewell。
  • 配置和存储恢复：解释当旧的二进制文件遇到新的配置时如何恢复；相对会话存储根据活动状态目录进行解析，Doctor 将遗留的错位存储与备份合并，同时保留冲突的对话并拒绝不安全的退出。 （#187639、#182444、#181554、#180414、#179089）修复#152791 感谢@RomneyDa、@duyufansh2008、@steipete 和@kip-claw。
  • 服务和备份可靠性：修复的更新程序将持久数据库更改与只读 WAL 簿记区分开来，等待服务 Mac 子级释放状态，保留没有元数据的有效替换配置，并在支持的节点修复期间保持不相关服务覆盖完好无损。谢谢@RomneyDa。
  • 诊断和提供程序工具：超时消息将未知工具结果与安全重试区分开来，Anthropic PDF 请求使用所选帐户的正确身份验证，Gemini/Vertex 流在终端标记处停止，而不是消耗后面的帧。 （#180247、#182429、#184434、#178420、#117397）谢谢 Ayaan Zaidi、@evomach、@sukhdeepjohar、@RomneyDa、@MertBasar0、@anmol0b、@shakkernerd、@kybrcore、@potoior。 ###完整贡献记录 此审核记录涵盖完整的 v2026.10.10..63e490a32182f338dba0267cea5a161f40f288dd 历史记录：78 个范围内 PR + 0 个保留的仅种子 PR = 78 个唯一 PR。生成清单还提供直接提交作为编辑输入；上面分组的注释优先考虑用户影响。
