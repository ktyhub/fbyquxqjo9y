openclaw v2026.11.3

这个项目是干啥的：一个AI助手工具，更新失败能自动恢复、私人检查保持私密，升级更稳更安全，给想要安心用AI的日常用户用。

2026.11.3

变更架构图

亮点

  • 私人任务结果： 将私人子代理完成情况排除在流式聊天回复之外。 (#188490) 感谢@fuller-stack-dev。
  • 可靠的子任务移交： 允许家长在取消子任务后将其移交给替换工作，而不会留下已取消子任务的完成收据来阻止移交。 （#178893；相关#178565）感谢@brianmcguire 和@letsc4。
  • 可见的工具故障： 报告未答复的工具故障，而不是默默地结束用户指定的转向成功。 （#182458；相关#99645）由@steipete创作。谢谢@rdleclerc。
  • 有界身份验证： 在运行截止日期停止停滞的提供者身份验证，并通过身份验证工作传播取消。 (#189144) 谢谢@amittell。
  • 沙盒图像访问： 即使在完全访问模式下，也将所需的沙盒图像预览保留在允许的文件夹内，同时保留明确的管理员图像配额。 (#176203) 谢谢@shakkernerd。
  • 验证工作区连接： 在提供空指纹时保留保存的节点证书引脚，并在发送凭据或数据之前验证工作区传输证书。 （#125646，#190002）感谢@wanyongstar 和@avelev99。
  • 更快、响应更快的网关： 减少启动模块文件加载开销，并避免中止命令检测遇到长标点符号运行时出现停顿。 （#192217、#184433）感谢@karkarl、@RomneyDa、@LeizhenZhang 和@obviyus。

变化

没有新的配置选项或功能。

修复

  • 凭证隔离： 将重用和缓存的插件结果保留在其连接凭证范围内，并将其他插件的传输挂钩保留在提供者的来源上。 （＃178444，＃177974，＃189423）由@steipete创作。谢谢@obviyus。
  • 搜索和内存凭证： 使用其范围端点保留 Firecrawl 搜索和抓取密钥，并将凭证嵌入其目的地。 （#190706、#184966）感谢@zhangguiping-xydt 和@eleqtrizit。
  • 凭证编辑： 从配置读取中编辑内联环境凭证，并从 Exa 错误中反映搜索凭证。 （＃190618，＃178745）由@steipete创作。谢谢@yetval。
  • 子进程环境： 防止托管信号守护进程和捆绑语言服务器继承不相关的网关机密。 （#179198，#179415）感谢@VACInc。
  • 身份验证错误： 显示凭据读取失败，而不是将其视为丢失凭据，并拒绝明确选择的属于不兼容提供程序的身份验证配置文件。 （＃173970，＃181597）由@steipete创作。谢谢@vincentkoc。
  • 频道安全： 将传入的 Twitch IRC 内容排除在解析器错误日志之外，并在多个 Tlon 审批待决时要求显式请求 ID。 （＃174552，＃186243）由@steipete创作。谢谢@mmaps。
  • 计划作业： 在不退出网关的情况下处理排队的 cron 存储故障，并在作业重复出现时清除一次性清理。 （＃175678，＃168985）由@steipete创作。感谢@yxshee、@wangmiao0668000666 和@obviyus。
  • 更新： 让配置文件支持的更新识别自己的维护锁，并在分类帐写入延迟时保留取消。 （#177792，#187998）感谢@GrahamMcBain 和@vincentkoc。
  • 更新恢复： 当初始包存在检查超时时安全恢复，在替换之前需要新的有效目录标识并保留回滚到原始包。 (#181906) 作者：@steipete。
  • 人为使用上限： 识别用尽的复数使用限制错误，而无需花费瞬时速率限制重试预算。 （#176186；相关#176179）感谢@sunlit-deng 和@blue-dot-1。
  • 终端会话： 将软转发/重置到网关，而不是硬重置会话。 (#172431) 感谢@yetval 和@obviyus。
  • Git 恢复： 在 Git 修复期间保留不确定的命令失败，而不是将未经确认的操作视为成功。 (#176006) 作者：@steipete。
  • 内存提供程序选择： 接受大小写混合的 none 和 auto 提供程序值。 (#186310) 作者：@steipete。谢谢@sagealice2002-dotcom。 ###完整贡献记录 此审核记录涵盖完整的 v2026.11.2..abf11ef015b9d4cdf5b2e6e2a6a84b87c7b8c920 历史记录：34 个范围内 PR + 0 个保留的仅种子 PR = 34 个唯一 PR。生成清单还提供直接提交作为编辑输入；上面分组的注释优先考虑用户影响。
