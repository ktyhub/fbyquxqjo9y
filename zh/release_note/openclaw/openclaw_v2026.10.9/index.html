openclaw v2026.10.9

这个项目是干啥的：一个AI助手工具，更新失败能自动恢复、私人检查保持私密，升级更稳更安全，给想要安心用AI的日常用户用。

2026.10.9

变更架构图

亮点

  • 修补易受攻击的运行时依赖项：fast-uri 4.2.3 在 MCP 架构验证中拒绝格式错误的 URI 方案和主机，在 A2UI 和 Discord 嵌入式应用程序 SDK 中早期拒绝过大的 Zod 集合，IMAP 发件人解析使用 Nodemailer 10.1.4，因此欺骗的发件人无法通过发件人令牌门，Microsoft Teams 使用修补的 MSAL 节点 7.1.1。 (#187294) 谢谢@RomneyDa。
  • 将 tools.fs.workspaceOnly 应用于网关构建的工具，因此委托更改仍然需要批准，并且媒体工具保留在工作区中。 (#185094) 感谢@eleqtrizit、@RomneyDa 和@shakkernerd。
  • 将实时凭证排除在 MCP CLI 检查之外，并在日志中屏蔽 Google OAuth client 机密。 （#180321、#180308、#183193）感谢@brandon-julio-t、@wr-web、@LeizhenZhang 和@RomneyDa。
  • 确保失败的更新回滚安全：Git 源回滚保留操作员编辑，而不是重置签出，npm 回滚重试短暂的 Windows 拒绝并报告恢复可启动安装的确切操作，而不是搁置软件包根目录。 （#185201、#184887、#185160、#184889）感谢@wr-web、@syxscott、@LiuwqGit、@shakkernerd 和@RomneyDa。
  • 在 SQLite 标记器更改后恢复完整的代理数据库和过时的全文索引，包括更新快照。 （#176234、#176220、#176833、#181206）感谢@ndakota79 和@RomneyDa。
  • 重新安装后修复发布完成的更新，同时保留原始启动器和密封恢复助手。 （#186557、#186527）感谢@ericcaiwx-star、@sennyhoney 和@RomneyDa。
  • 迁移大型转录档案而不超出 Node.js 字符串限制。 （＃170853，＃170847）感谢@iamonlv426和@RomneyDa。
  • 一旦空间可用，允许代理在磁盘已满后恢复，而无需重新启动。 (#176902) 谢谢@RomneyDa。

变化

此维护版本重点关注安全依赖性补丁、恢复、数据保存和可靠性修复。

修复

  • 从会话自己的工作区而不是代理的默认工作区解析 Codex 引导消息中的本地媒体。 (#181528) 谢谢@RomneyDa。
  • 报告来自缓冲命令（例如本地 CLI 语音提供程序）的不确定进程清理，而不是将其呈现为普通命令失败。 （#184270、#184237）感谢@shakkernerd 和@RomneyDa。
  • 在请求恢复之前通过发布批准及其提交的配对事实来保持重新批准的节点连接处于活动状态。谢谢@RomneyDa。
  • 当无法验证服务激活时恢复停止的网关；在 Windows 分类中保留未受影响的恢复行为。 （#172784、#181577、#181698）感谢@SMF12138 和@RomneyDa。
  • 避免在未安装服务的情况下在被动 macOS 停止期间卸载网关服务。 (#181257) 感谢@shakkernerd、@LiuwqGit、@eleqtrizit、@syxscott 和@RomneyDa。
  • 从文件系统根启动时恢复 CLI 节点运行时，包括启动作业。 （#178112、#177739）感谢@downingkeys 和@RomneyDa。
  • 在请求的工作目录而不是默认工作区中启动新的 ACP 会话。 （#176852、#123557）感谢@yinx65588-boop、@crappier 和@RomneyDa。
  • 防止因请求失败而导致重叠模型刷新。 (#179144) 谢谢@RomneyDa。
  • 遵循 openclaw gateway probe --ssh 中的显式 SSH 端口 22，而不是别名的配置端口。 (#171092) 感谢@zhangguiping-xydt、@obviyus 和@RomneyDa。
  • 当内联 YAML 元数据值具有尾随注释时，保留技能元数据，例如图标和主页。 (#171224) 感谢@zhangguiping-xydt、@Takhoffman 和@RomneyDa。
  • 在 openclaw infer video generate 文本和 JSON 输出中显示提供商忽略的选项。 (#171172) 感谢@ly85206559、@obviyus 和@RomneyDa。 ###完整贡献记录 此审核记录涵盖完整的 v2026.10.8..c213740c8338a05ac1a6db036e0d11060e70bf5d 历史记录：48 个范围内 PR + 0 个保留的仅种子 PR = 48 个唯一 PR。生成清单还提供直接提交作为编辑输入；上面分组的注释优先考虑用户影响。 已发送的基线排除：v2026.10.8（3 个 PR：#180390、#180668、#181596）。
