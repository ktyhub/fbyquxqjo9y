openclaw v2026.11.7

这个项目是干啥的：一个AI助手工具，更新失败能自动恢复、私人检查保持私密，升级更稳更安全，给想要安心用AI的日常用户用。

2026.11.7

变更架构图

亮点

  • 对话恢复： 在网关重新启动时恢复中断的回复和子结果，而不会丢失挂起的工作。 (#198905、#201544、#200924、#200967) 作者：@steipete。感谢@RomneyDa、@galiniliev 和@vincentkoc。
  • 可靠的自动化： 让自动化的所有者对话修复故障，并将恢复或故意跳过的运行与真正的故障区分开来。 （#161007、#201638、#152165、#194276）相关#194261 感谢@RomneyDa、@vyctorbrzezowski、@vincentkoc、@obviyus、@pash-openai、@wr-web 和@slatem。
  • 更平滑的更新： 通过架构更改、繁忙的数据库和保留的恢复状态来完成 Git 和软件包更新，而不是在新版本开始之前或之后停止。 （#201600、#201463、#201545、#201330）由@steipete 创作。感谢@RomneyDa、@vincentkoc 和@fuller-stack-dev。
  • 响应式网关： 在缓慢的文件系统操作、大型恢复包和页面提取期间保持聊天、准备情况检查和不相关会话的响应。 （#191236、#201248、#200623、#200925）由 @steipete 创作。感谢@RomneyDa 和@vincentkoc。
  • 浏览器配对： 将另一个浏览器与网关主机上批准的短代码配对，在等待批准时提供更清晰的说明。 （#191513、#200905）感谢@vincentkoc、@RomneyDa、@daniel-lxs、@jalehman 和@etzelm。
  • 当前 ChatGPT 目录： 发现新可用的订阅模型，无需等待另一个 OpenClaw 版本，并保持登录发现独立于 npm。 （#201130、#201493）相关#201480 感谢@RomneyDa、@obviyus 和@daniel-lxs。

变化

  • 知识搜索： 使用取代的措辞查找当前记录并匹配规范等效的 Unicode 关键字拼写。 （#193742、#195092）相关#193054、#195031 感谢@RomneyDa、@daniel-lxs、@Linux2010、@jalehman 和@saariuslystoned。
  • 谈话转录： 使用保存的 Deepgram、ElevenLabs 或 Mistral API 密钥进行实时转录。 (#199858) 相关#199684 感谢@daniel-lxs。
  • 会话控制 — 破坏 SDK 更改： 将会话键控的 setActiveEmbeddedRun(…) 注册移动到主机提供的 runAttempt 回调中，并保留其确切的清理功能；未经许可的注册现在报告 SESSION_CONTROLLER_ADMISSION_REQUIRED。 (#175837) 作者：@steipete。谢谢@RomneyDa 和@jalehman。
  • 网关方法 — 破坏 SDK 更改： 使用 openclaw/plugin-sdk/gateway-method-runtime 中的dispatchGatewayMethod 替换可变的 chatAbortControllers 和 chatQueuedTurns 访问，在插件清单中声明contracts.gatewayMethodDispatch: [“authenticated-request”]；现有的呼叫者权限仍然适用。 (#175837) 作者：@steipete。感谢@RomneyDa、@vincentkoc、@johan-eilertsen 和@jalehman。
  • 开始观察 - 破坏 SDK 更改： 将 AgentTurnStartOwner.observe() 消费者从 expiresAtMs 更新为 startDeadlineAtMs；这是执行开始截止时间，而不是执行超时，并且没有兼容性别名。请参阅 docs/plugins/sdk-migration.md 了解迁移指南。 (#175837) 作者：@steipete。谢谢@jalehman。

修复

  • 回复和命令边界： 禁止执行普通散文中的斜线命令，并在重试回复丢失的工具操作之前发出警告。 （#200458、#201523）感谢@Patrick-Erichsen 和@VACInc。
  • 停止和转向： 应答停止后发送的消息，通过长时间运行的工具保留转向，并让用户在代码模式 shell 命令运行时进行转向。 （#195612、#199878、#200998）相关#194303 由@steipete 创作。感谢@RomneyDa、@amittell、@obviyus 和@VACInc。
  • 子代理结果： 将结果附加到其请求的轮次，并防止一个孩子的交付失败而丢弃兄弟结果。 （＃200873，＃201563，＃195275）由@steipete创作。感谢@RomneyDa、@VACInc 和@jalehman。
  • 计划的工作： 通过帐户、共享和组更改保留自动化所有权，并在现有对话中保留计划的全局工作。 （#201008、#201434、#188173）感谢@RomneyDa、@obviyus、@vincentkoc、@jalehman 和@shakkernerd。
  • Claude CLI： 在进度消息后保留最终答案，在完成回合中包含长子结果，并使用自定义 Claude 配置目录显示工具历史记录。 （#200470、#200226、#198337）相关#199633 由@steipete 创作。感谢@RomneyDa、@gouyu-hou、@chaeyn、@obviyus、@etzelm、@VACInc、@mulderp82、@xiaoguomeiyitian 和 @Szqub。
  • Codex： 在同一本地编写器上保留恢复的对话，区分 API 配额和订阅耗尽，并在流式回复中保留换行符。 （#201474、#192165、#201102）感谢@RomneyDa、@jalehman、@vincentkoc、@TheRealUnknownSoldier、@VACInc 和@freeqaz。
  • 模型和凭证恢复： 通过正在运行的网关保持共享 OAuth 刷新，使用 Bedrock Mantle 的环境 AWS 凭证，并报告列出的模型拒绝请求的原因。 （#198214、#190988、#200073）相关#163006 感谢@RomneyDa、@obviyus 和@netcrazed。
  • 压缩： 在配额错误后使用配置的回退，避免错误的压缩后停顿中止，并在沙盒会话中保留选定的技能。 （#194813、#194722、#198029）相关#194803、#194715 作者：@steipete。感谢@RomneyDa、@VACInc、@saariuslystoned、@vyctorbrzezowski、@jason-allen-oneal 和@obviyus。
  • Telegram： 完成大型媒体上传，在替换传送失败时保留回调控制，并在附件无法下载时回复消息。 （#151923、#193948、#200682）相关#193947 感谢@RomneyDa、@amittell、@obviyus 和@AmelioMansour。
  • Discord 和 Slack： 中断后重新连接所有 Discord 帐户，保留替换活动任务的独立请求，并将顶级 Slack 完成情况保持在顶级。 （#201415、#201518、#187065）相关#162189 感谢@RomneyDa、@obviyus、@mattreyes0824、@vincentkoc 和@wr-web。
  • Matrix 和飞书： 保留图像标题和回复位置，在 Element X 中显示 Matrix 民意调查和投票，并在同一张流媒体卡中完成长飞书回复。 （#188018、#191700、#161777）相关#188038、#191678、#139443 感谢@seriouslysean、@thatsrue、@obviyus、@chelsealong、@geekforlife、@ArthurNie 和@Simon2256928。
  • 语音通话： 避免原始 JSON 和截断的长答案​​，忽略回声的呼叫者文字记录，并在背景噪音阻止终结时应答。 （#151367、#191537、#191498）感谢@Weiming-Hu、@weiming、@obviyus 和@mnowrot。
  • 移动和 macOS： 在响应运行时启动新的 Android 聊天，接受本机 Talk 设置，并让 macOS 应用程序应答其第一个聊天，而不会出现错误的低内存拒绝。 （#191372、#191194、#200373）相关#191339、#200340 感谢@RomneyDa、@gouyu-hou、@saariuslystoned、@vyctorbrzezowski、@obviyus 和@jalehman。
