openclaw v2026.9.36

这个项目是干啥的：一个AI助手工具，更新失败能自动恢复、私人检查保持私密，升级更稳更安全，给想要安心用AI的日常用户用。

这是仅网关的 extended-stable 版本，相当于我们当前的 LTS。此版本是 2026 年 9 月底发布的 OpenClaw，此外还有重要的安全更新、可靠性和性能修复以及新模型支持等功能。本次发布时 OpenClaw 的最新版本是 2026.10.9

2026.9.36

变更架构图

亮点

  • 失败的更新保持可恢复： 失败的 npm 回滚不再导致已安装的软件包丢失，更新检查保留 Doctor 恢复指导，停止重新复制私有排练数据库，并且不再重新打开候选迁移状态。修复#184889。 （#185160、#186177）感谢@syxscott、@LiuwqGit 和@RomneyDa。
  • 工作空间限制到达网关构建的工具： 对于 tools.fs.workspaceOnly，通过网关环回和技能调度构建的 openclaw 代表现在需要按预期获得批准，并且媒体工具保留在工作空间内。 (#185094) 感谢@eleqtrizit 和@RomneyDa。
  • Microsoft Teams 许可名单仍然受到限制： 无法解析的名称键控 teams 或 groupAllowFrom 条目现在不会授予任何内容，而不是向每个团队或组开放机器人。 (#184989) 感谢@eleqtrizit、@RomneyDa 和@shakkernerd。
  • Untrusted 输入受到限制： 格式错误的媒体元数据、入站邮件地址、TOML、URI、自定义 A2UI 架构中的超大集合和 Discord 的嵌入式 SDK，以及响应控制的 Microsoft 身份验证路由不再导致无限制的工作或更改身份。 （#187288、#187282、#187283、#187305、#187289、#187287）感谢@RomneyDa 和@cyyynthia。
  • **回复保留其文本：**表情符号和其他星体字符不再从出站回复中删除后的比较散文。 (#187415) 谢谢@RomneyDa。

变化

  • 证书 trust 和 Docker 图像： 应用了 eMudhra trust 修复，Docker 发布图像携带源/版本绑定证据以及更可靠的架构构建。 (#186639) 谢谢@RomneyDa。

修复

  • 凭据和内容边界： 为网关构建的 OpenClaw 工具派生文件系统策略，关闭未解决的 Microsoft Teams 允许列表，并将修补的 MSAL 范围限制为受影响的 Teams 和 Azure Identity 使用者。 （#185094、#184989、#187287）感谢@eleqtrizit、@RomneyDa 和@shakkernerd。
  • Untrusted 解析： 绑定 Matrix 媒体元数据和 IMAP 邮件解析、TOML 密钥解析器、URI 解析以及自定义 A2UI 架构中的超大 Zod 集合和 Discord 的嵌入式 SDK。 （#187288、#187282、#187283、#187305、#187289）感谢@RomneyDa 和@cyyynthia。
  • 回复传递： 在出站消毒剂中保留星体字符后的比较散文。 (#187415) 谢谢@RomneyDa。
  • xAI： 允许旧模型使用 off，无需可配置的推理工作，而不是将其视为无效的思维水平而拒绝。 (#187425) 谢谢@RomneyDa。
  • 更新、安装和 Doctor： 在拒绝回滚重命名后恢复已安装的软件包根，保留 Doctor 恢复指南和迁移回滚限制，保留缓冲命令结果中的清理不确定性，将更新兼容性清单保留在已发布的软件包中，并停止在每次清理扫描时重试损坏的工作树元数据。修复#184889、#184237。 （#185160、#186177、#184270、#187424、#187475）感谢@syxscott、@shakkernerd、@LiuwqGit 和@RomneyDa。
  • 节点上传： 打开分阶段上传快照后重新检查取消，以便取消的上传不再显示 AbortError。 (#162567) 谢谢@RomneyDa。
  • **依赖项：**更新此线上的 ClawHub undici 引脚、Vercel 工具链包和 Vitest 队列。 （＃187261，＃187258，＃187275）谢谢@RomneyDa。 ###完整贡献记录 此审核记录涵盖完整的 v2026.9.35..d04a9bec6c286f60f106d6f61354bad4e8b9a057 历史记录：28 个范围内 PR + 0 个保留的仅种子 PR = 28 个唯一 PR。生成清单还提供直接提交作为编辑输入；上面分组的注释优先考虑用户影响。
