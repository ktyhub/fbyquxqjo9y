openclaw v2026.9.35

这个项目是干啥的：一个AI助手工具，更新失败能自动恢复、私人检查保持私密，升级更稳更安全，给想要安心用AI的日常用户用。

这是仅网关的 extended-stable 版本，相当于我们当前的 LTS。此版本是 2026 年 9 月底发布的 OpenClaw，此外还有重要的安全更新、可靠性和性能修复以及新模型支持等功能。本次发布时 OpenClaw 的最新版本是 2026.10.7

2026.9.35

变更架构图

亮点

  • 服务管理器下的内存更稳定： 即使网关服务通过进程范围的 --max-old-space-size，工作线程堆上限现在也适用，空闲的 Codex 应用程序服务器 client 在 30 秒后退出，并且存档工作线程在会话删除之间重用，因此长时间运行的网关停止累积内存。修复#179515、#169797、#165663。 （#166581、#171490、#168387、#171156、#175091）感谢@valkyriweb 和@RomneyDa。
  • 更新更频繁地完成： 更新时 Doctor 现在会在迁移后删除剩余的未知配置密钥，接受丢失的旧版 OAuth 目录，保留缺少 meta 的有效配置，解决已为候选者提供服务的已完成包发布，并且不再在非常大的会话历史记录中溢出。修复#174618、#183479。 （#175404、#180174、#183703、#180414）
  • **网关保持响应：**精心制作的 Microsoft Teams HTML、形状类似于工具调用的回复以及长流式 HTML 或 JSX 答案不再使网关事件循环一次停顿几秒钟。 （#183438、#183252、#174833、#175472、#180765）感谢@LeizhenZhang 和@JasonBuildAI。
  • **回复到达用户：**消息工具在工具搜索下保持直接可见，模型回退在未执行的工具调用和压缩后起作用，超时的 MCP 会话不再中断下一个回合，并且达到输出限制的 Claude CLI 回合会快速失败，而不是停滞 15 分钟。修复#176045。 （#179450、#183282、#182189、#159931）感谢@hehuang139、@pstarkgit、@aniketkrs 和@Terwox。
  • Codex 本地子代理正确解决： 在本地子代理完成、被打断或完成后续操作后，父代理不再被阻止；无法交付的完工项目不会复活；并且完成的孙子在网关重新启动后不再重播。 （#173018、#175246、#179050、#179099、#177577、#181839）感谢@quqi1599、@wtfichigo、@linancn 和@sunlit-deng。
  • 默认情况下更安全： test -v 执行操作数现在需要在白名单模式下获得批准，浏览器代理命令通过通用节点调用被拒绝，生成的视频下载使用 SSRF 防护，以及 openclaw mcp list/show 加上日志编辑凭据。 （#180880、#179880、#182425、#180321、#183193）感谢@eleqtrizit、@brandon-julio-t 和@LeizhenZhang。
  • SQLite 3.54 数据安全性： 医生和更新快照现在修复 SQLite 标记器更改留下的陈旧全文索引，而不是隔离代理数据库。修复#176220。 （＃176234，＃181206）

变化

  • Kimi K3.1 Pro： moonshot/kimi-k3.1-pro、kimi/k3.1-pro 及其高速变体获得 K3 的思维、努力和视频控制； K3.1 在本地拒绝 off，而不是返回提供者 400。（#181923）感谢 @obviyus。
  • 已知问题文档： 记录了 --preserve-symlinks 插件捕获解决方法、2026.8.35 更新程序的架构警告以及发布日志设备编号更改后的恢复。相关#175591、#170031。 (#184143) 谢谢@RomneyDa。

修复

  • **凭证和内容边界：**需要批准 test/[ -v 操作数，拒绝通用节点调用上的浏览器代理命令，保护生成的视频下载，编辑 MCP 检查输出和 Google OAuth client 机密，不轮流评论被禁用的回复，并使私人媒体不轮流沉默。 （#180880、#179880、#182425、#180321、#183193、#178518、#129244）感谢@eleqtrizit、@brandon-julio-t、@LeizhenZhang 和@obviyus。
  • **回复传递和回退：**保持消息工具在工具搜索下可见，允许在未执行的工具调用和压缩后进行模型回退，立即回退到耗尽的 Anthropic 使用上限，在空 length 停止后恢复未完成的工具工作，并将拒绝的 Claude CLI 草稿保留在最终回复中。修复#176045、#176179。 （#169091、#179450、#183282、#176186、#153728、#168764）感谢@hehuang139、@pstarkgit、@sunlit-deng、@zhangguiping-xydt 和@ruel225。
  • 网关响应能力： Microsoft Teams HTML 的绑定正则表达式和标签扫描、工具调用型回复和长流式标记。 （#183438、#183252、#174833、#175472、#180765）感谢@LeizhenZhang 和@JasonBuildAI。
  • Claude CLI 会话： 检查孤立工具调用时忽略请求回显，将拒绝的恢复检查点分类为过期会话，立即结束输出限制停顿，并停止通过重置 CLI 聊天进行公告唤醒。 （#172026、#159931、#181308、#176218）感谢@Terwox、@mushuiyu886 和@elavb43。
  • **代理运行时：**释放已完成的尝试回调，取消子任务后完成父级切换，限制大型子代理完成批次，在并发会话重置期间保留内存捕获，在 macOS 工作区大小写不同时加载技能，并停止来自实用程序模型（包括自定义 GLM 标题模型）的仅思考回复。 （#183884、#178893、#172068、#181081、#181236、#169920、#172580）感谢@brianmcguire 和@jason-allen-oneal。
  • **Codex：**淘汰闲置的无主应用程序服务器 clients，在完成轮次上保持本机工具声明稳定，在主机工作期间保持本机活动，并解决本机子代理完成、中断、后续操作并重新启动重播。修复#165663。 （#168387、#183286、#181839、#173018、#175246、#179050、#179099、#177577）感谢@sunlit-deng、@quqi1599、@wtfichigo 和@linancn。
  • **通道：**从隔离的 invalid_auth 恢复 Slack 套接字模式，从静默网络丢弃恢复 Slack 中继连接，仅使用命令源标记 Matrix 控制命令，保持 Telegram 偏移检查点在 Bun 上工作，保持回调的实时语音传输运行时，并在取消退出运行后保持通道帐户重新启动。修复#179398。 （#181056、#182368、#179506、#178909、#179462、#182433）感谢@mushuiyu886、@xiaopan-xydt、@brianmcguire 和@shoaibulhaque。
  • MCP 和 GitHub 工具： 让并发代理在没有独占租约的情况下读取新的共享 MCP OAuth 凭证，并接受连接后附加配置文件的操作员发布的 GitHub PR。 （#179997、#169400）感谢@maliv2 和@Gigaxel。
  • 网关、状态和就绪性： 回答 trusted 代理就绪性探测，无需转发标头，绑定通道身份准入等待，因此停滞的准入无法固定 WAL 检查点，使排队的启动工作远离临时 SQLite 读取器范围，避免写入器在初始主机准入期间停顿，在恢复过时的 Linux 锁的同时保留活动状态锁所有者，并在库存报废后完成工作程序关闭。相关#143524。 （#182823、#172244、#182615、#171549、#175118、#168862）感谢@ericcaiwx-star、@xialonglee 和@xiaopan-xydt。
  • 更新、安装和 Doctor： 在更新期间删除无主的配置密钥，接受丢失的旧 OAuth 目录，保留缺少 meta 的有效配置，在准入期间路由调试从 JSON 标准输出注销，绑定激活后 Doctor 步骤并更新基线检查，从 / 启动时恢复节点运行时，接受具有额外执行位的未更改的 dist 文件，容忍 Windows 交换中缺少可选包，启动隐藏在 Windows 上的 SQLite 帮助程序，创建状态目录 0700 无论 umask 是什么，允许组可写插件秘密解析器，在停止备份期间允许 SQLite 读取器，导入文件名与标头不同的记录，在有效负载之前读取 cron 历史记录身份，避免非常大的会话历史记录上的堆栈溢出，解决已为候选者提供服务的已完成包发布，并在网关节点不满足目标的 engines.node 时拒绝暂存之前的注册表更新，而不是在切换后崩溃循环。修复#174618、#183479、#183149。 (#180769、#175404、#180174、#183703、#182850、#173862、#181906、#178112、#181141、#181596、#174969、#179538、#181127、#180827、 ＃178146，＃174530，＃180414）谢谢@jalehman和@wangmiao0668000666。
  • **插件：**替换悬空依赖连接，而不是拒绝插件迁移，跨文件系统复制本机捕获，并容忍本机同伴准入中仅 ctime 的统计漂移。 （＃179549，＃179445，＃179949）谢谢@coaiMax。
  • SQLite 全文索引： 在 Doctor 中的 SQLite 3.54 标记器更改后修复过时的 FTS 索引并更新快照，而不是隔离代理数据。修复#176220。 （＃176234，＃181206）
  • 发布验证兼容性： 携带当前完整发布验证所需的发布回顾第 5 批工具（准入引脚、紧凑重用计划、插件 SDK 修订版渲染）。 (#181920) 谢谢@RomneyDa。 ###完整贡献记录 2026.9.35 维护审计涵盖了所有 3,595 个 main 提交 beaee570a5d4 (2026-10-21) 至 f227543e4815，加上未解决的 P0/P1 问题和 运营商请求的 PR。来自 77 个编号的 PR 和 3 个特定于分支的 78 个修复 进行或调整了修复；其余的被归类为不受影响， 已经涵盖，或有理由排除。 完整的公关清单、改编、排除和更正 2026.9.34审核保存在 2026.9.35 扩展稳定向后移植审核。 上面分组的注释仍然是用户影响摘要。
