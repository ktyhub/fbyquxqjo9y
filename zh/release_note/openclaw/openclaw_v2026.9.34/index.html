openclaw v2026.9.34

这是仅网关的 extended-stable 版本，相当于我们当前的 LTS。此版本是 2026 年 9 月底发布的 OpenClaw，此外还有重要的安全更新、可靠性和性能修复以及新模型支持等功能。本次发布时 OpenClaw 的最新版本是 2026.10.6

2026.9.34

变更流程图

亮点

  • 更安全的代理文件编辑： apply_patch 现在会在改变工作区之前验证有序信封，因此后来的无效块无法删除先前操作更改的文件。 (#160409) 感谢@masatohoshino、@obviyus 和@RomneyDa。
  • 更可靠的托管升级： 应用程序拥有的更新现在将官方插件与核心融合在一起，并保留修复诊断。修复#174120。 (#174257) 感谢@kazuyuki-eguchi 和@RomneyDa。
  • 内存 Wiki 数据安全： OKF 概念重新导入现在保留人类撰写的注释。修复#175700。 (#175707) 感谢@YangManBOBO 和@RomneyDa。
  • 可靠的模型启动和选择： 网关启动现在可以在模型刷新所有权替换后继续存在，并且目录准备就绪遵循有效主模型的配置帐户密码。修复#178502。 （#173366、#178522）感谢@ericcaiwx-star、@eduardonunesfreire-rgb 和@RomneyDa。
  • 网关和集成稳定性： 日志轮换不再在已删除的 /tmp 上旋转，Buzz 中继关闭在身份验证期间不再退出网关，并且 OpenRouter 加入接受有效凭据。修复#147269。 （#160433、#170591、#173292）感谢@masatohoshino、@jarvis-modern-mail、@chandraveshchaudhari、@RomneyDa 和@WadeOwenWatts。
  • 恢复插件挂钩： before_tool_call 挂钩现在在 openclaw agent exec 下运行。修复#158824。 (#159333) 感谢@joseairosa 和@RomneyDa。

变化

  • **托管更新融合：**官方插件在升级过程中与应用程序管理的核心版本协调一致，并保留修复路径的诊断信息。修复#174120。 (#174257) 感谢@kazuyuki-eguchi 和@RomneyDa。

修复

  • 代理补丁原子性： 预检在突变之前订购了 apply_patch 信封，因此后来的无效块无法破坏早期的文件。 (#160409) 感谢@masatohoshino、@obviyus 和@RomneyDa。
  • 内存 Wiki 注释保存： 再次导入 OKF 概念时保留人工编写的注释。修复#175700。 (#175707) 感谢@YangManBOBO 和@RomneyDa。
  • 模型生命周期和身份验证选择： 通过模型刷新替换保持启动活动，并在目录准备期间遵循配置的主帐户密码。修复#178502。 （#173366、#178522）感谢@ericcaiwx-star、@eduardonunesfreire-rgb 和@RomneyDa。
  • 网关日志记录和 Buzz 稳定性： 避免删除日志目标 CPU 旋转并防止 NIP-42 继电器关闭退出网关。修复#147269。 （#160433、#170591）感谢@masatohoshino、@jarvis-modern-mail、@RomneyDa 和@WadeOwenWatts。
  • OpenRouter 入门： 在路由验证期间接受有效的 API 密钥。 (#173292) 感谢@chandraveshchaudhari 和@RomneyDa。
  • 代理插件挂钩： 恢复 openclaw agent exec 的 before_tool_call 执行。修复#158824。 (#159333) 感谢@joseairosa 和@RomneyDa。
  • 跨版本更新程序兼容性： 在扩展稳定替换期间保留 2026.10.1 launchd 观察和更新程序运行时导出，并保守地拒绝此旧版本系列上的不可变安装突变。 (#160663) 谢谢@RomneyDa。
  • 已修补的节点运行时底线： 需要在安装、更新、Docker 映像和 macOS 应用程序运行时检查中使用 Node >=24.22.1 <25 || >=26.12.1，因此升级会通过明确的下一步来拒绝易受攻击的运行时。 (#181073) 谢谢@RomneyDa。
  • 依赖项建议： 补丁 zod (GHSA-mrhx-c7xc-m3w5)、body-parser 以及此发行版上的其他生产建议。 (#181341) 谢谢@RomneyDa。
  • 会话持久性： 跳过空成绩单存档实现并在成绩单协调期间隔离第一次创建。 (#170122) 谢谢@RomneyDa。
  • Claude CLI 会话连续性： 子代理完成不再重置 Claude CLI 会话并丢失先前的上下文。 (#178955) 感谢@Marvinthebored 和@RomneyDa。
  • **更新恢复：**安全完成中断的更新恢复，并保留入院中断原因以供医生跟进。 （＃181503，＃181870）谢谢@RomneyDa。
  • 备份、Linux 和 macOS 修复： 进行此版本系列所需的备份和平台服务修复，包括旧版 macOS 网关状态路径。 (#181466) 谢谢@RomneyDa。
  • 发布验证兼容性： 协调当前完整发布验证工具链所需的分支本机更新准入、声明表面、安全基线和测试装置。 (#180988) 谢谢@RomneyDa。 ###完整贡献记录 扩展的维护审计涵盖了来自数据库的所有 743 个选定源行。 v2026.9.33 之后的 2026.10 稳定版和测试版发布线：596 个唯一编号 PR 和 105 个未编号的发布伙伴。最终源行配置 其中 142 个已应用，82 个分支适应，128 个已涵盖，391 个明确 排除。 完整的重复数据删除 PR 库存、混合源行序列、未编号 同伴和排除原因保存在 2026.9.34 扩展稳定向后移植审核。 上面分组的注释仍然是用户影响摘要而不是重复 数百行审计。
