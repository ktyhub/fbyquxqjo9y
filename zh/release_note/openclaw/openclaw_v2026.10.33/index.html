openclaw v2026.10.33

这是仅网关的 extended-stable 版本，相当于我们当前的 LTS。此版本是 2026 年 10 月下旬发布的 OpenClaw，此外还有重要的安全更新、可靠性和性能修复以及新模型支持等功能。本次发布时 OpenClaw 的最新版本是 2026.11.5

2026.10.33

此扩展稳定版本带来了自 2026.9.37 以来累积的网关和核心插件改进，以及已批准的 2026.11.4 产品基准上的选定维护修复。发行版涵盖核心 npm 包、匹配的官方 npm 插件和 Gateway Docker 镜像；不包括本机应用程序版本。

变更流程图

亮点

  • 长对话和大型会话存储使用有界导出和恢复工作，减少聊天、内存导出、Doctor 修复和网关启动期间的内存不足故障。 （＃194066，＃196158，＃195459，＃196480，＃176737，＃181289）由@steipete创作。感谢@RomneyDa、@vincentkoc、@ericcaiwx-star、@obviyus、@garrytan 和@oxen-horse。
  • 当执行程序死亡时，中断的更新会恢复，而不是让网关陷入脱机状态，而版本偏差检查会保护已安装服务仍在使用的状态。 （＃181695，＃186971，＃187819）由@steipete创作。感谢@RomneyDa、@PonySlayer28、@tomdailey55、@jalehman、@fuller-stack-dev 和@vincentkoc。
  • 回复可以在更多的重启和重新连接路径中保留下来，保留原始提示，恢复 Telegram 响应，并避免丢失 WhatsApp 回复或跳过 Signal 消息。 （#187157、#195400、#168778、#187667）感谢@shakkernerd、@jason-allen-oneal、@mcaxtr、@HermanZeng 和@obviyus。
  • 共享会话隐私性更强：侧聊天对其查看者保持私密性，内部模型提示不显示在显示的输出中，压缩会编辑引用摘要中的凭据。 （＃185390，＃173460，＃197349）由@steipete创作。感谢@Satoshi-Kusumoto、@RomneyDa、@zhangguiping-xydt、@Patrick-Erichsen 和@obviyus。
  • 自动化可以对轮询条件和 MCP 事件做出反应，运行可重复的脚本，并使用明确允许的 MCP 服务器。 （＃101195，＃165399，＃160996，＃160995）由@steipete创作。谢谢@obviyus。
  • 已安装的技能可以按需搜索和阅读，帮助座席找到相关说明，而无需将每个已安装的技能都放入提示中。 （＃158089，＃158090，＃158091，＃160538）由@steipete创作。感谢@RomneyDa 和@vincentkoc。
  • 会话可以导入现有的 Claude Code 或 Codex 转录本，并在本地和云环境之间移动，并具有存储库配方和更清晰的云启动进度。 （＃161955，＃171690，＃170862，＃170895）由@steipete创作。感谢@joshavant 和@RomneyDa。

其他维护修复

  • 提供程序连续性：在同一提供程序 API 和端点上的凭证或模型更改中保留服务器压缩检查点，避免不必要的历史记录重播。 （＃200063，＃200208）谢谢@obviyus。
  • macOS 安装：在 shell 安装期间保留控制终端，以便新手可以安装插件，而不会中止分离的 Node 子进程。 (#200247) 谢谢@miguelbranco80。
  • 更新恢复：记录成功的网关启动写入，以便下次运行 Doctor，而不接受启动之前的更改。 (#200260) 谢谢@RomneyDa。
  • 现有设备文件夹：使用隐式 OpenClaw 运行时识别模型，而无需将该默认值转换为显式会话覆盖。 (#190065) 谢谢@obviyus。
  • 插件兼容性：保留签名的 2026.11.4 源基线作为此版本的兼容性标识，而不更改其显示的版本或降低插件 API 要求。 (#200302) 谢谢@RomneyDa。
