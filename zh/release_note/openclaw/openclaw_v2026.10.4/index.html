openclaw v2026.10.4

这个项目是干啥的：一个AI助手工具，更新失败能自动恢复、私人检查保持私密，升级更稳更安全，给想要安心用AI的日常用户用。

2026.10.4

变更架构图

亮点

  • 网关在计算机睡眠或系统时钟跳变后继续运行，而不是自行重新启动，因为其所有权心跳看起来已过时。 (#170790) 感谢@AnvinaLI、@sgh6688、@waynegault 和@RomneyDa。
  • 网关关闭和重新启动不再挂在停滞的转录工作人员或正在进行的会话生命周期事件上。 （＃170493，＃170555）谢谢@Oldrich333。
  • Tlon 组 DM 不再将其他参与者视为所有者，从而关闭了所有者冒充路径。 (#165801) 谢谢@eleqtrizit。
  • 当站点等待密钥时，无头浏览器页面不断响应 clicks。 (#170857) 谢谢@trukhinyuri。
  • 手动 /compact 在压缩之前解决活动运行，而不是中止它并丢弃挂起的请求。 (#166163) 感谢@holny 和@alxph-dev。

变化

  • 2026.10.3 的稳定性补丁，没有新功能或配置更改。谢谢@RomneyDa。

修复

  • 网关：在长回复标记流中保持响应，并且引用工具调用 XML 的长回复不再重新解析每个标记上的 Markdown。 （＃166782，＃171573）谢谢@boeingchoco。
  • 网关：阻塞的持久上下文引擎轮次记录一次，而不是每次运行时记录。 (#167595) 谢谢@jalehman。
  • 控制 UI：延迟的应用程序心跳不再强制重新连接。 (#171253)
  • 网关：在睡眠和挂钟更改后恢复状态所有权，并允许来自经过验证的外部 macOS 终端的 openclaw gateway restart。 （#170790、#170354）感谢@AnvinaLI、@sgh6688、@waynegault 和@RomneyDa。
  • 网关：绑定的transcript-worker关闭等待，并在关闭期间等待会话生命周期发布。 （＃170493，＃170555）谢谢@Oldrich333。
  • 网关：使用网关启动启用的独立插件文件，并在托管服务设置进程范围堆标志时强制执行工作线程堆限制。 （#171330、#166581）感谢@holgergruenhagen、@valkyriweb、@xydigitLybnnnn、@goslingmanagment、@waynegault 和@obviyus。
  • 代理：启动的插件不再因作者声明错误而失败，并且 Claude CLI 会话不再跨消息路由分叉历史记录。 （＃170077，＃167241）谢谢@cmatrx0。
  • 代理：手动压缩解决活动运行而不是中止它。 (#166163) 感谢@holny 和@alxph-dev。
  • OpenAI：api.openai.com 上的推理模型工具轮流完成路线不再因 400 失败。（#166182）感谢 @obviyus 和 @AsTutoAI。
  • 更新：代理数据库在快照捕获期间不再标记为已更改，成功摘要停止将已解决的插件数据/设置升级重复为待处理，并且元数据库存在进度输出背压下保持运行。 （#170351、#170413、#168493）感谢@DonnieFi、@RomneyDa 和@vincentkoc。
  • 更新：缓慢的主机准入不再占用数据库编写器并中断网关工作，通过临时 Doctor 维护不断报告进度，快照故障获得准确的标题和恢复建议，Linux 更新可以清理受保护的 systemd 用户管理器下废弃的运行时目录。 （#171493、#171454、#171457、#171488、#170783、#166335）感谢@RomneyDa、@DonnieFi 和@vincentkoc。
  • 更新：候选验证不再在实时安装时放大私有 SQLite 快照，较旧的驱动程序停止读取候选迁移状态并清除陈旧的重启判决，并且可选的 cron 检查或快照清理失败不再停止更新。 （#167451、#170130、#170754）感谢@angeliti999 和@RomneyDa。
  • 更新：openclaw update repair 在较慢的主机上运行工具之前不再超时；嵌套权限检查重用当前状态快照，而不是再次复制数据库。 (#166847)
  • Doctor：更新不再拒绝未引用的退役 OAuth sidecar，并且离线状态修复适用于应用程序拥有的网关。 （#165420，#170768）感谢@obviyus 和@RomneyDa。
  • Tailscale：中断的启动会停止其服务进程，当 tailnet 拒绝服务时，本地访问保持可用，并且 Doctor 检查配置的 Tailscale 启动先决条件。 （#167514、#171509、#166947）感谢@pandysp 和@RomneyDa。
  • macOS：应用程序恢复保持兼容的较新网关而不是降级它们，并且修复接受已经在进行中的经过验证的 LaunchAgent 引导程序。 （＃170766，＃170740）谢谢@RomneyDa。
  • 会话：等效的 POSIX 路径别名（例如 /tmp 和 /private/tmp）不再重新启动通道。 (#166462) 谢谢@ericcaiwx-star。
  • MCP：当授权服务器注册不带端口的环回重定向 URI 时，OAuth 登录完成。 (#170876) 感谢@9fw2pq8sgb-art。
  • 浏览器：无头页面在站点等待密钥时接受 clicks。 (#170857) 谢谢@trukhinyuri。
  • 控制用户界面：更新的聊天通过服务文档恢复。 (#168941)
  • Tlon：切勿将群组 DM 作者视为所有者。 (#165801) 谢谢@eleqtrizit。
  • Telegram：轮询工作人员在源代码和包构建中解析。 (#154286) 感谢@xydt-juyaohui 和@markfietje。
  • 不和谐：语音更改后座席咨询继续工作。 (#171029) 感谢@ericcaiwx-star 和@brainmonger。
  • 飞书：配置热重载不再孤立会话绑定。 (#169226) 感谢@ruel225、@junniar 和@obviyus。
  • IRC：当服务器中继长的非 ASCII 回复时，它们不再丢失。 (#159730) 谢谢@rodricksz4h5。
  • 发布：插件 npm 发布可以容忍重复的工件分页条目，Linux 在使用托管运行者凭据自动请求后构建触发器，并且棘轮检查读取大型 Git 基线。 （#171044、#167087、#167237、#164743）感谢@RomneyDa 和@shakkernerd。 ###完整贡献记录 此审核记录涵盖完整的 v2026.10.3..d58dd3ceef67f10eab31d93387d2c90866b3ec93 历史记录：61 个范围内 PR + 0 个保留的仅种子 PR = 61 个唯一 PR。生成清单还提供直接提交作为编辑输入；上面分组的注释优先考虑用户影响。
