claude-code v2.1.325

修订 发布时间2026年11月13日 来源anthropics/claude-code 英文原文

发生了什么变化

  • 修复了如何解码 zstd 压缩响应的安全问题
  • 在 VS Code 和类似的集成终端中添加了有关重新运行笔记本单元的旋转提示，一旦 Claude 阅读或编辑了 Jupyter 笔记本就会显示
  • 在组织的策略阻止请求时显示的错误下添加了一行，说明如何继续：运行 /rewind 并更改消息，或运行 /clear
  • 当沙盒 git checkout、git stash 或自动存储拉取无法更新受保护文件（例如 .claude 中的文件）时，为 Claude 添加了注释
  • 修复了 /security-review 和技能的内联 git 命令因裸存储库、--separate-git-dir 签出和 Android repo 签出的工作树中的错误而停止的问题
  • 修复了当模型设置为 opusplan 或 haiku 时，其自己的模型被移至计划模式模型的子代理
  • 修复了不同模型上的子代理，根据主会话的模型调整文件读取和 MCP 结果
  • 修复了许多第三方网关和 Foundry 上的会话每次都会因上下文长度错误而停止而不是压缩的问题
  • 修正了克劳德代码停止而没有干净退出后，有时会从恢复的会话中丢失最近的回合
  • 修复了删除工作目录后在启动目录中运行的 shell 命令；该命令现在失败并显示一条消息，可以重新发出
  • 修复了当 plansDirectory 文件夹无法接受时已批准的计划编辑丢失的问题：该计划现在保存在默认计划文件夹中，并有一条警告说明位置和原因
  • 修复了在新安装时将已保存的 sonnet[1m] 模型设置重写为 API 拒绝的模型 ID 的问题
  • 修复了当计划任务在提示后回复时焦点视图会隐藏对提示的回复
  • 修复了全屏关闭时后台子代理视图中有时会丢失提示的问题
  • 修复了列表中的长选项和权限提示在换行时被部分覆盖，以及首次运行屏幕在狭窄终端上丢失行的问题
  • 修复了有关权限规则的启动警告以及滚动到视图之外时记录的“N MCP 服务器需要身份验证”通知
  • 修复了欢迎标题显示控制字符或在代理名称或工作文件夹包含控制字符或换行符时跨行分割的问题
  • 修复了克劳德尝试仅您可以运行的命令时显示的红色错误：一条暗线现在表示它仅在您在提示符下键入时运行
  • 修复了 /stats 显示的总活跃天数过高的问题
  • 修复了当没有符合分析资格的会话时 /insights 表示报告已准备就绪，并将两个值写入其 HTML 报告而无需 escaping 的问题
  • 修复了当托管设置、--settings 或项目的 .claude/settings.json 或 .claude/settings.local.json 保持原样时，/voice 说语音模式已更改的问题；现在它说出了它的持有者是什么
  • 修复了在 Windows 和 Linux 上显示 Cmd+Esc 快速启动的 IDE 欢迎对话框
  • 修复了 Slack 应用程序提示，显示您的组织的策略何时拒绝云会话
  • 修复了当没有终端可以读取密钥时 claude purge 静静地挂起，并且当标准输入通过管道传输时，其项目选择器和 -i 提示忽略键盘
  • 修复了 claude plugin eval --output-dir '' 将报告写入当前文件夹的问题；现在退出并出现错误
  • 修复了终端上的 claude -p 文本输出，传递除文本样式之外的控制序列；管道和文件未更改
  • 修复了配置目录中堆积的剩余 .oauth_refresh.lock.owner.tmp.* 文件
  • 修复了 /fast 在无密钥控制台登录下显示“快速模式已被您的组织禁用”的问题，其中 Claude Code 未询问服务器
  • 修复了 /model 表示当 Claude Code 无法检查时您的组织限制模型，例如没有网络的情况
  • 修复了当您在浏览器步骤之后按下 Esc 时，/login 中的“使用您的控制台帐户登录”替换您现有的登录信息
  • 修复了浏览器在某些情况下登录失败或被取消时显示登录成功页面的问题
  • 修复了 claude auth status 和其他短命令在控制台配置文件上留下锁，这导致下一个会话挂起大约一分钟
  • 修复了使用启动后台服务的 shell 中的 API 密钥或令牌（并计费）在 claude.ai 登录时启动的后台会话
  • 修复了更多会话在后台转移到另一个登录的情况；这些举措现在被拒绝，并有一条消息说明什么是有效的
  • 修复了拒绝移动到后台后退出对话框中的第二个 Enter 停止后台工作的问题
  • 修复了当 allowedProviders 托管设置不允许时 Amazon Bedrock 将对话发送到 Bedrock 时的令牌计数
  • 修复了在没有 HOME 环境变量的情况下启动 Claude Code 时 AWS credential_process 帮助程序和 Google Cloud 默认凭证失败的问题
  • 修复了子代理的计划获得批准后，会话有时会返回到较早的权限模式的问题
  • 修复了代理 SDK applyFlagSettings() 呼叫中的一个无效值，以静默方式丢弃先前呼叫中的所有设置；现在，执行此操作的调用会被拒绝并出现错误
  • 修复了当完成的拉取请求仅需要您自己的审查或合并时显示为等待输入的会话
  • 修复了在没有警告的情况下忽略无法识别的 teammateMode 设置值的问题：claude -p、启动警告和 claude doctor 现在将其列为跳过条目（仍未应用）
  • 修复了 --worktree 在新主目录中首次运行时从 CLAUDE_CODE_PLUGIN_SEED_DIR 中的插件跳过 WorktreeCreate 挂钩的问题
  • 修复了简短模式会话，例如调度，在回合已经回复后再次发送回复
  • 修正了克劳德说当插件在不同的 URL 列出工作的 Atlassian、Asana 或 Sentry 连接器时在云会话中失败的问题
  • 修复了 Claude Desktop 和 SDK 会话，在文件夹移动或预热启动后，将文件夹自己的 MCP 服务器（.mcp.json，本地）列为主机添加或根本不列出，并且不连接 WebSocket 服务器
  • 修复了在插件重新加载并在连接时将其删除后，/mcp 仍然列出插件的 MCP 服务器的问题
  • 修复了 MCP 服务器保持“需要身份验证”状态，并且在令牌刷新仅被拒绝片刻后，其 mcp_tool 挂钩被跳过
  • 修复了在工具调用期间替换服务器连接后，MCP 引出请求被取消而无需在无头模式下询问的问题
  • 修复了工具调用重新连接 MCP 服务器后，来自 SDK 主机的 MCP 工具调用回答“未连接”的问题
  • 修复了 MCP 任务在使用 Esc 关闭其问题或再次询问后卡住的问题：页脚现在显示需要您的输入，并且在 /tasks 中输入再次显示问题
  • 修复了后台 MCP 任务，当稍后的调用重新连接时，对同一服务器的另一次调用失去连接后停止更新
  • 修复了后台 MCP 任务在您仍在输入的消息上打开的问题；现在它会等待，直到您发送或清除草稿，并且旋转器和转动计时器继续运行
  • 修复了 worktree.sparsePaths 以及稀疏插件和市场克隆，在较旧的 git 版本上遗漏了存储库的根文件，例如 2.34
  • 修复了多个存储库无法使用在会话中添加的存储库的自托管运行器会话
  • 修正了克劳德在阅读你自己的工件或其数据之前请求许可的问题
  • 修复了 Artifact 工具的拒绝和询问权限规则和挂钩不适用于某些云会话的问题
  • 修复了代码模式脚本忽略使用 EnterWorktree 输入的工作树，将 ~ 路径写入项目，并让 /mcp 在登录过期后显示 MCP 服务器已连接的问题
  • 修复了在代码模式下克劳德无法在权限对话框或计划批准中输入“是”的问题
  • 修复了当您恢复在代码模式脚本期间结束的会话时克劳德自行开始工作的问题；它现在等待您的下一个提示
  • 修复了工具调用运行时发送的消息丢失的 OpenTelemetry user_prompt 事件。赛事有delivery.mode: "mid_turn"，跑步回合有prompt.id
  • 修复了当排队消息在 VS Code 中合并到一轮中或当一条消息具有图像时，OpenTelemetry user_prompt 事件会遗漏早期消息的文本
  • 修复了斜线命令的 allowed-tools 授予应用于在其回合期间或之后唤醒的后台特工的问题
  • 修复了 /feedback 和 /bug 仅在登录帐户或组织录制时上传其他会话
  • 修复了 cd 之后不再覆盖项目的相对拒绝和请求许可规则（例如 Read(./.env)）；它们现在也适用于添加的目录
  • 修复了以 mcp__plugin_*_ 开头的拒绝和请求权限规则缺少插件的 MCP 服务器或以另一个字母大小写拼写的工具
  • 修复了在自托管运行程序和 claude remote-control 会话中，拒绝规则不适用于 Claude Code 重新启动后到达的权限批准的问题
  • 修复了当 Claude Code 在存储库的某些子文件夹中启动时，提交的 .claude/settings.local.json 可能被视为用户自己的 .claude/settings.local.json 的情况
  • 修复了一些不适用于某些 Bash 命令的拒绝和询问规则
  • 修复了 Bash 权限检查中的一个漏洞，其中某些复合命令可以在不询问的情况下运行；这些现在请求许可
  • 修复了 Bash 允许规则可以运行与其命名的程序不同的程序的情况
  • 修复了云会话中连接器工具的批准提示在插件仍在加载时自动应答的问题
  • 修复了一些子代理更改组织外部人员可以看到的工件或将文件上传到其中的情况，而无需先询问何时设置允许规则或先前批准上传
  • 修复了当为 Artifact 选择“不再询问”时，某些工件发布会跳过组织外部人员可以看到的页面的确认
  • 修复了自动模式，仅判断组织外部人员可以看到的工件的第一个更改；现在它的“是”仅涵盖了这一变化
  • 修复了代理和技能上的托管 strictPluginOnlyCustomization 锁定在已运行的会话中未生效的问题
  • 修复了沙盒命令在某些情况下能够写入本机更新程序的下载文件夹的问题
  • 修复了 Bash 沙箱未完全保护工作树的设置和挂钩的情况
  • 修复了 Bash 沙箱未完全保护链接工作树的共享 git 文件夹的情况
  • 修复了 /teleport 在一些不寻常的 git 状态下的存储选择：它现在停止并说明要做什么
  • Windows：修复了当 PATH 条目位于您的帐户无法打开的文件夹下时，可能会持续大约一秒钟的启动停顿
  • 修复了 Windows 上的 /resume 拒绝或隐藏其文件夹使用不同驱动器盘符大小写或斜杠记录的会话的问题
  • 修复了 Windows 上的会话中 /resume 在使用不同的驱动器盘符大小写记录会话时会丢弃项目保存的 trust
  • Linux：修复了当工作目录位于 denyRead 内的 allowRead 文件夹下方（例如在符号链接主目录下）时，沙盒 Bash 命令因 bwrap: Can't create file 失败的问题
  • 修复了 Claude Desktop 的第三方部署在令牌续订完成之前一直处于“停止”状态（一旦包含此版本）
  • 改进的子代理在输出令牌限制处切断：现在再次要求他们提供完整的答案，更简短，而不是只返回其结尾
  • 改进了无密钥控制台登录或其他人性配置文件登录的启动：无需等待凭据锁定即可读取仍然有效的令牌
  • 改进了帐户电子邮件检查：现在，它还会在命令运行、文件写入、Web 获取和 MCP 调用的脚本中拒绝将您的电子邮件作为 client 的身份
  • 改进了私人插件市场的 HTTPS authentication failed 消息：它现在表示 git 的终端提示和 Askpass 程序已禁用，并且它也出现在较新的 git 版本中
  • 改进了添加市场确认、插件推荐提示和插件安装警告，表明插件可以在您的计算机上运行代码，并可以访问您的文件和 shell
  • 改进了 claude --desktop 登录错误，以命名 API 密钥、提供商或设置，从而阻止 Claude 帐户登录工作
  • 改进了 macOS 和 Windows 上的 /voice“未检测到音频”消息：它现在显示在哪里选择麦克风
  • 改进的 MCP 任务：当任务正在等待您的答复时，克劳德现在会被告知，并可以将您指向 /tasks
  • 改进了 claude remote-control：现在，当它自行停止时，它会以状态 4 退出（单会话运行仍然退出 0）；当它无法注册时，它会以状态 69 退出，因此服务管理器可以再次启动它
  • 改进了后台会话无法使用其会话的 API 密钥或令牌时显示的消息：它们不再建议将密钥添加到设置中
  • 改进了捆绑数据可视化技能对静态图像和具有自然顺序的部分（例如年龄范围）的部分到整体建议
  • 更改了沙盒 Bash 命令以默认遵循正常权限流程；设置 sandbox.autoAllowBashIfSandboxed: true 继续运行它们而不提示
  • 更改了打开沙箱的托管设置：要在没有提示的情况下保持命令运行，请在排名最高的托管源中设置 sandbox.autoAllowBashIfSandboxed: true
  • 更改了只读 git 命令，以首先在不是项目或您 trusted 的存储库中询问；将其命名为 --add-dir，而不是 additionalDirectories 设置，以便在没有提示的情况下运行它们
  • 更改了计划任务和 /loop 在运行声明 allowed-tools 或挂钩的技能之前询问；将 Skill(name) 添加到 permissions.allow 以无人值守运行
  • 更改了桌面、IDE 和 SDK 主机中的“始终允许”：仅在保存时才提供一条规则，该规则将再次允许该命令，因此依赖于该命令的计划任务现在可以等待您
  • 更改了沙箱，以拒绝对添加目录中的 .claude 设置、技能、代理、命令和挂钩进行沙箱写入，就像在启动文件夹中一样
  • 更改了工作树隔离：隔离的工作树会话或代理现在被拒绝 git bisect run、git maintenance register|start 和 scalar 的设置命令，并被告知哪些内容仍然有效
  • 更改了插件 MCP 包（.mcpb、.dxt）以在插件目录下解压，而不是在插件文件夹中解压 .mcpb-cache，因此加载只读插件文件夹；通过 URL 获取的内容会再次下载一次
  • 更改了远程市场的插件，这些插件在 prependPlugins 或 appendPlugins 中声明、启用和列出托管设置，以计为组织的插件； pluginDigests 已弃用并被忽略
  • 更改了插件加载以跳过，并更改了 claude plugin validate 以报告插件文件夹中的一些不安全路径和链接
  • 更改了嵌套技能加载：--plugin-dir 插件中的 .claude/skills 文件夹不再从在其上方启动的会话加载；在插件文件夹中启动 Claude Code
  • 更改了 EnterWorktree 以拒绝通过项目内部符号链接的 WorktreeCreate 挂钩路径；让钩子打印真实路径
  • 更改了 tmux 和 iTerm2 队友，以及使用 ← 打开的代理视图中的新会话，以在会话文件夹中启动，而不是在 shell 上次运行的位置 cd
  • 更改了终端中的提示建议，以在由后台或计划任务启动的连续 8 轮后刷新频率降低，节省使用量，直到您按下某个键或返回终端
  • 将后台 MCP 任务问题上的 Esc 更改为“稍后回答”：没有任何内容发送到服务器，问题保留在 /tasks 中
  • 更改了 CLAUDE_CODE_MAX_CONTEXT_TOKENS，以设置以 claude- 开头的无法识别的模型 ID 的上下文窗口，例如网关的 claude-sonnet-latest
  • 更改了 /login 以请求更改您的隐私设置的权限
  • 更改了 /cost、$.session.usage()、--max-budget-usd 以及成本和代币指标以计算 mod 的 $.model.complete 和 $.model.classify 调用
  • 更改了 Claude Code 沙箱为其自身使用而启动的程序（例如其网桥），使其在其环境中无需 Claude Code 的登录令牌和 API 密钥即可运行
  • 更改了 ripgrep、本地 git 命令和沙箱运行时自己的帮助程序，使其在其环境中无需 mTLS client 密钥的密码即可运行
  • 远程控制：将/resume和/teleport更改为当连接的会话有共享链接或无法检查时首先断开连接；运行/remote-control再次连接
  • 更改了 Web 上的 Claude 代码、云计划任务和 Cowork 云会话以启动，尽管 sandbox.failIfUnavailable：托管容器没有命令沙箱
  • 更改了通过云或自托管会话连接对设置、权限规则、挂钩或状态的请求，以减少返回或被拒绝；会话中适用的内容没有改变
  • 将没有缓存帐户数据的 claude -p 更改为在首次请求之前等待该数据，因此干净环境中的首次运行可以在几秒钟后开始
  • 更改了克劳德的说明，将您想要的文件保留在临时暂存文件夹中，该文件夹可以被清除
  • 更改了市场 ref 以接受分支或标签上任何提交的完整 ID；此版本之前的 clients 无法克隆此类 pin，因此以这种方式固定的市场将停止加载
  • 当 ALL_PROXY 是唯一的代理集时，更改了插件市场和插件下载以使用 CONNECT 隧道；拒绝 CONNECT 的代理现在让他们失败
  • 更改了-p和SDK在安装到容器中的工作树或子模块中运行，以仅在文件夹被trusted后应用.claude/settings.local.json允许规则
  • 更改了自托管运行器以拒绝会话文件夹或存储库路径是符号链接的会话，而不是 checkout 挂钩的结帐
  • 删除了云会话和远程控制下的支出限制和共享预算错误中的“要求管理员提高”
