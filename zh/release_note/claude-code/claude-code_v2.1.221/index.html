claude-code v2.1.221

修订 发布时间2026年8月4日 来源anthropics/claude-code 英文原文

claude-code v2.1.221

发生了什么变化

  • [VSCode] 添加了焦点视图：聊天菜单切换，将工具活动隐藏在可扩展的每回合摘要后面，并带有实时运行工具指示器，使用 Ctrl+Alt+F 或“Claude Code：切换焦点视图”命令进行切换
  • 为 Linux 和 WSL 上的沙箱凭证文件添加了 mode: "mask" — 沙箱命令读取哨兵副本（整个文件，或只是 extract 正则表达式捕获的跨度），而沙箱代理替换出口上的实际值；在 macOS 上文件屏蔽回退到 deny
  • 当 Claude Desktop 的托管市场同步拒绝市场或插件名称时，向 claude plugin validate 添加警告
  • 在 claude-api 技能中添加了 prompt-audit 子命令，用于审核为旧模型编写的模式的提示和工具描述
  • 修复了 Bash 工具权限检查绕过，其中 zsh 可以执行 [[ ]] 正则表达式条件中的隐藏命令；受影响的命令现在提示权限
  • 修复了 Windows 上 PowerShell 权限检查错误处理包含引号字符的路径；此类路径现在提示批准
  • 修正了思考切换对从思考开始的会话的其余部分没有影响的问题；禁用 MCP 服务器中间连接不再以静默方式恢复
  • 修复了 --mcp-config 中的 MCP 服务器在第一次进入打印模式 (-p) 之前未连接的问题，这使得模型以文字文本形式发出工具调用
  • 修复了按 Esc 键撤回提示并重新提交时@提到的文件被默默删除的问题
  • 修复了为以内置对象属性（例如 constructor）命名的 SDK MCP 工具准备 API 请求时发生的崩溃
  • 修复了当思考被禁用时，网络搜索失败并出现 400 错误 xhigh/max
  • 修复了沙盒大型上传通过沙盒代理因 TLS 错误而失败的问题
  • 修复了团队和企业支出限制消息错误地指责组织的每月限制而不是您的个人支出限制
  • 修复了在设置杂散 HOME 环境变量的 Windows 计算机上的桌面管理会话中使用 AWS SSO 命名配置文件进行的 Bedrock 身份验证失败的问题
  • 修复了 CLAUDE_CODE_RESUME_INTERRUPTED_TURN=0 不禁用断转自动恢复的问题；错误的价值观现在受到尊重
  • 修复了一个罕见的睡眠唤醒竞赛，其中两个 Claude Code 进程都可以同时刷新相同的 MCP 连接器或 WIF OAuth 令牌，从而强制重新进行身份验证
  • 修复了从 Claude Code Desktop 或 claude.ai 重命名会话而不更新 CLI 的会话名称的问题；每个重命名表面的会话名称现在都已清理
  • 修复了以仅终端内置插件（例如 /help、/feedback）命名的插件和组织交付的技能在非交互式会话中不可调用的问题
  • 修复了重新加载插件而不是清除后“插件已更改”通知挥之不去的问题
  • 修复了 Vim 模式：复制寄存器现在可以在对话框、历史搜索和记录视图中保留下来，而不是默默地清空
  • 修复了 Vim 模式：撤消回到空提示，现在在返回代理视图之前启用“再次按 ←”确认
  • 改进了 Google Vertex AI 上的工具搜索：为 Claude 4.5-generation 和更新型号重新启用
  • 改进的自动模式：并行工具调用的权限检查现在具有缓存效率，并且在检查挂起时切换模式会可靠提示，而不是应用过时的结果
  • 通过在决策中重用缓存的对话前缀，降低了自动模式权限检查的提示缓存成本
  • 改进了统计面板，可在令牌总数中计算缓存令牌，并按输入、输出、缓存读取和缓存写入进行细分
  • 改进了当存储库与其基础没有共享历史记录时的 /ultrareview 错误消息：现在会预先拒绝没有分支的结账，并建议创建分支，并且拒绝提示不再在已完成的克隆上建议 git fetch --unshallow
  • 改进了 Windows 启动：现在通过本机 kernel32 调用读取进程创建时间，而不是生成 PowerShell，因此控制 powershell.exe 的端点安全工具不再提示
  • 更改了后台会话以提交和推送以保留工作，仅在任务需要时才打开草稿 PR，遵循 CLAUDE.md git 说明，并始终以报告工作所在位置结束
  • 更改了 /plugin install 以刷新过时的市场目录并在报告未找到插件之前重试
  • 更改了从 /plugin 安装的插件，以在安全时立即激活，而不是始终需要 /reload-plugins
  • 更改插件以接受 "." 作为 skills 路径，根级 SKILL.md 验证错误现在建议使用插件根
  • 更改了 /status 以显示会话类型：interactive，或后台作业 attached 或 unattended
  • 更改了表情符号自动完成以接受常见的替代短代码，例如 :thumbsup:、:thumbsdown: 和 :love:
  • 更改了与 /fork 分叉的会话，以创建自己的新工作树，而不是在原始会话的结帐中工作
  • 更改了 Chrome 中的 Claude，以便在不再需要时关闭它打开的浏览器选项卡
  • 更改了快速模式，以便在使用积分在会话中用完时报告流，而不是默默地失败
  • 更改了监视器：退出时不产生任何输出的手表现在会这样说，而不是报告“流结束”
  • 更改了网关 model 字段验证：非字符串值将被拒绝并返回 400，而不是被转发
  • 删除了批准提示中重复的“自动模式分类器调用排队时权限模式已更改”通知
