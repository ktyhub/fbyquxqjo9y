claude-code v2.1.239

claude-code v2.1.239

这个项目是干啥的：Anthropic 官方的命令行 AI 编程助手，在终端里让 Claude 直接帮你读写代码、改项目、跑命令。给习惯用命令行的开发者用。

变更架构图

亮点

  • Bedrock 代理的关键成本修复 — 如果你的代理会剥掉响应 Content-Type，Bedrock 流可能静默回退到非流式并重新运行每一回合，导致计费的 API 调用翻倍。代理后的 Bedrock 用户应升级；HTTPS_PROXY 后 awsAuthRefresh + SSO 启动挂起的问题也已修复。
  • 开发者工具迁移：Python SDK 1.x — /claude-api upgrade 可将 Python 项目从 anthropic 0.x 迁移到 1.x，包括把 httpx.Timeout 替换为 anthropic.Timeout。这是可选的迁移命令，不是自动的破坏性变更，但 SDK 1.x 的超时设置无法沿用旧写法。
  • 云/插件身份与可靠性 — 从 claude.ai 同步的插件现在显示为 name@synced，可用 claude plugin enable/disable <name>@synced 控制，且不能覆盖同名的本地安装插件。云会话在 worker 重启后保留 plan 模式，并能从瞬时 5xx 错误中恢复远程 MCP 服务器，包括通过 SDK setMcpServers() 重连。
  • 值得升级的可靠性与安全修复 — 此版本修复了路径中含 _、- 或 . 的跨目录会话混淆、目录被删时的崩溃和 hook 问题、导致标题同步失控的回归、超出预定 15 分钟仍保留的 WebFetch 内容泄露，以及密码字段文本泄露到 Ctrl+Y 或提示历史。使用 /resume、Remote Control、沙箱 worktree 或掩码输入的用户应优先升级。
  • 全屏、终端与平台打磨 — 长 MCP 表单现在可滚动且 Accept/Decline 始终可见；斜杠命令面板不再遮挡最近消息；仅聚焦的点击不再触发权限提示。JetBrains 的 Edit/Write 停顿、Alpine/musl 媒体插件、Windows 跨会话消息以及若干编辑/键位 bug 也已修复。这些特定工作流值得升级；否则 Bedrock 计费修复和会话安全修复是主要理由。

发生了什么变化

  • 成本估算（/cost、状态行、--max-budget-usd）现在包括 1.1× 仅限美国的数据驻留工作空间的推理溢价
  • 在 Bedrock、Vertex、Foundry 和其他先前排除的设置上添加了一次性全屏渲染器功能；新安装现在以全屏模式开始
  • 添加了 /claude-api upgrade 以将 Python 项目从 anthropic 0.x 迁移到 1.x，并更新了 1.x 的技能 Python 参考（超时使用 anthropic.Timeout，而不是 httpx.Timeout）
  • 云会话：从 claude.ai 同步的插件现在显示为 name@synced，可与 claude plugin enable/disable <name>@synced 配合使用，并且永远不会覆盖您安装的同名插件
  • Alpine/musl 构建：本机图像粘贴、clipboard 和音频捕获插件现在加载（musl 构建的二进制文件，而不是运行时拒绝的 glibc 二进制文件）
  • 当您的每月支出限额已用完时显示的使用限制消息现在还会显示您的会话或每周限额何时重置
  • 修复了代理后面的基岩流，该代理会剥离响应内容类型标头，通过重新运行每轮非流式传输，默默地将计费的 API 调用增加一倍
  • 修复了当使用带有 SSO 配置文件和 awsAuthRefresh 的 Bedrock 时，Claude 代码在启动时挂在 HTTPS 代理后面的问题 — 凭证预检查现在支持 HTTPS_PROXY
  • 修复了从不再存在的目录启动 Claude Code 时的原始故障转储；它现在打印一条清晰的消息
  • 修复了连接 Claude Code 插件时 JetBrains IDE 终端中的编辑和写入调用暂停约 5 秒的问题
  • 修正了一场比赛，在提示排队的情况下按 Esc 可能会让下一个回合提前结束，从而在克劳德仍在工作时让会话空闲，并让稍后重新提交重复操作
  • 修复了 WebFetch 在整个会话期间（而不是预期的 15 分钟）在内存中保留过期页面内容的问题
  • 修复了闲置工作人员重新启动后云会话（网络、桌面和移动应用程序上的克劳德代码）恢复计划模式的问题
  • 修复了 MCP 引出表单比全屏模式下 clipped 终端更高的问题：表单现在适合窗口，通过滚动可访问隐藏字段，并且 Accept/Decline 始终可见
  • 修复了在云会话中或通过 SDK setMcpServers() 进行会话中重新连接时发生短暂 5xx 后，远程 MCP 服务器保持失败的问题
  • 修复了重命名后写入超过 ~64 KB 的对话后，自定义会话标题从 /resume 中消失的问题
  • 修复了 claude -c/resume 从不同目录中拾取会话的问题，该目录的路径仅因 _、- 或 . 等字符而不同
  • 修复了 /resume 和代理视图，当仅触及其文件或仅重新打开它时，显示最近更改的会话（并重新排序）
  • 修复了所有项目模式下的 /resume 告诉您将 cd 放入已删除的目录（例如已删除的工作树）；此类会话现在在当前目录中恢复
  • 修复了全屏模式下 dark-ansi 主题渲染扩展工具导致文本颜色与背景颜色相同的问题
  • 修复了每次启动时重新出现的全屏渲染器提示，而该提示永远无法得到答复；现在在三次启动后显示停止
  • 修复了当目标位于 gitignored 目录中时以 **/ 开头的 .worktreeinclude 模式默默地不匹配任何内容
  • 修复了 .md 文件以 UTF-8 BOM 开头的代理、技能和命令被默默忽略的问题
  • 修复了 /insights 在某些型号的响应中回显文字 <message> 标签的问题
  • 修复了市场 metadata.pluginRoot 无效的问题：裸插件源名称现在按照文档描述在其下解析
  • 修复了基于浏览器的终端中的鼠标移动，当鼠标报告到达时，将 "35;150;7M" 等文本插入提示中
  • 修复了被忽略的工作/超代码状态徽章颜色的自定义主题覆盖
  • 修复了 OpenTelemetry 跟踪碎片：由 PreToolUse 挂钩推迟的工具执行现在在原始回合的跟踪中恢复，而不是开始新的跟踪
  • 修复了代理视图中的 vim 模式：Escape 现在切换到正常模式并保留文本而不是清除提示
  • 修复了 selection:copy 键绑定静默删除已使用 Shift+箭头键扩展的文本选择
  • 修复了通过 voice.enabled 设置启用语音听写后仍然出现 /voice 启动提示的问题
  • 修复了 shell 模式 (!) Tab 补全从 ./script 路径中删除 ./ 的问题，这导致 shell 无法运行命令
  • 修复了当您 clicked 终端窗口仅将其重新聚焦时全屏模式回答权限提示或按下按钮的问题
  • 修复了全屏模式下的斜线命令面板（例如 /config、/model），涵盖最新消息；对话现在固定在面板上方
  • 修复了 /workflows 详细信息对话框在克劳德仍在响应时打开时溢出终端并在屏幕外丢失标题的问题
  • 修复了 Linux 沙箱导致不存在的 .git/config.worktree 无法读取的问题，这会破坏设置了 extensions.worktreeConfig 的存储库中的每个沙箱 git 命令
  • 修复了删除会话工作目录后挂钩因“posix_spawn ENOENT”而失败的问题；他们现在从项目根目录或主目录运行
  • 修复了当模式命名规则目录或符号链接而不是其目标时，claudeMdExcludes 不排除符号链接的 .claude/rules 文件
  • 修复了当两个 Claude Code 进程共享一个后台作业状态时同步到远程控制的失控会话标题（2.1.232 回归）；标题更新现在已进行重复数据删除且速率受到限制
  • 修复了标题以 / 开头的会话无法被 SendMessage 寻址并在 ListAgents 中显示为“（无标题）”的问题
  • 修复了当光标位于其中时 Ctrl+W、Ctrl+U、Ctrl+K、Option+Backspace、Option+D 和 vim df/dt 留下损坏的 [Pasted text #N] 占位符
  • 修复了屏蔽（密码式）输入，例如登录代码字段，允许使用 Ctrl+Y 将其文本粘贴回其他位置，或者在使用双 Esc 清除时保存到提示历史记录
  • 修复了 Ctrl+Backspace 在搜索框中删除一个字符而不是一个单词的问题
  • 修复了在显示拒绝之前重新发送的被组织策略检查拒绝的请求
  • 改进了压缩后显示的提醒，以便技能的原始参数不会作为新请求重新运行
  • 工具使用行上的长文件路径现在在中间截断以保留在一行上
  • 当长 SessionStart 或 Setup 钩子运行时，远程会话不断发送保持活动状态，因此容器不会在钩子中闲置
  • /goal：现在减少对长时间运行的后台工作重复签入（30 分钟，然后 1 小时，然后每 2 小时一次），而不是每 30 分钟重复一次
  • /goal：从 claude --resume 选择器恢复会话现在可以恢复其活动目标
  • ListAgents 现在告诉会话它自己的名称（对等方用来向其发送消息的名称），而 SendMessage 则以您自己的名字表示，而不是“没有名为……的代理”
  • ListAgents 和 /list-agents 现在列出您的实时队友（以前仅出现子代理和其他会话，因此可联系的队友看起来缺席）
  • keybindingFlavor: "readline" 现在也与 Bash 匹配单词键：Alt+F 和 Ctrl/Option+→ 停在单词末尾，Alt+D 删除它（Ctrl+Y 将其粘贴回来），标点符号分隔单词
  • 持久重试模式 (CLAUDE_CODE_RETRY_WATCHDOG) 现在会在组织支出限制和信用不足错误时立即失败，而不是无限期地等待重置
  • Chrome 中的 Claude：/clear 现在会关闭会话的 Chrome 选项卡组，并且当 Claude Code 退出时，/resume 上的空组也会关闭
  • 远程会话：从移动设备上传的图像现在包含其保存的文件路径，因此克劳德可以将它们复制到它创建的文件中
  • 网络上的克劳德代码：从 Bash 和其他工具到非 API anthropic.com 主机（例如 www、docs）的请求现在通过会话的网络代理，因此您的环境允许的域适用
  • 远程控制：当您的帐户未启用远程控制时，更清晰的消息和 claude doctor 措辞
  • Windows：现在可以使用跨会话消息传递，因此计算机上的 Claude Code 会话可以使用 SendMessage 相互发送消息，并使用 ListAgents 相互查找，就像在 macOS 和 Linux 上一样
  • [VSCode] 使用限制横幅中的“查看使用情况”现在与警告文本内联，而不是浮动在横幅中间
