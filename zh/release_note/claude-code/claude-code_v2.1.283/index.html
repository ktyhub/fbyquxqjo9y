claude-code v2.1.283

修订 发布时间2026年9月25日 来源anthropics/claude-code 英文原文

发生了什么变化

  • 将 x-claude-code-prompt-id 添加到网关提示标头，以便 LLM 网关可以对服务于一个用户提示的请求进行分组；选择加入 CLAUDE_CODE_GATEWAY_HINT_HEADERS=1
  • 添加了 availableModelsMatch 托管设置：对于 "exact"，availableModels 条目仅允许其命名的型号版本，因此新版本在列出之前会被阻止
  • 添加了 deniedModels 托管设置来阻止特定型号，即使 availableModels 允许它们
  • 当 OTEL_LOG_TOOL_CONTENT=1 时，向 tool.output OpenTelemetry 跨度事件添加了 MCP 工具、WebFetch 和 WebSearch 输出
  • 添加了 /doctor prompt-audit（也称为 /checkup prompt-audit）来审核您的 CLAUDE.md 文件、技能、代理和命令，以提示为旧模型编写的模式
  • 添加了 click-to-expand，用于全屏模式下其他会话的截断消息
  • 将path添加到流中的--plugin-dir加载失败条目-json system/init plugin_errors，命名未加载的目录
  • 在 Claude 应用程序网关配置中添加了一个选择加入 load_test_mode 块：请求已构建并签名，但不发送到上游，并且 clients 获得预设回复，因此可以对部署进行负载测试
  • 向 Amazon Bedrock 的 Mantle 端点的 Claude 应用程序网关添加了 mantle 上游提供商
  • 修复了 SDK 会话在回合提前结束时丢失延迟的工具调用或完成的工具结果、工作人员重新启动后保留的批准提示以及非流回退的 result.usage
  • 修复了一旦长时间运行的工具调用移至后台就会丢弃 MCP 进度通知的问题；后台任务现在显示最新进度
  • 修复了当会话结束但仍在启动时 stdio MCP 服务器仍保持运行的问题
  • 修复了来自无状态远程 MCP 服务器（例如重新部署中的代理）的简短 HTTP 404，导致该服务器在会话的其余部分无法使用，同时仍显示为已连接
  • 修复了没有有效 URL 的服务器的 MCP 登录失败并出现不透明 SDK 错误的问题； /mcp 不再为此类服务器提供身份验证
  • 修复了禁用遥测时每周寓言限制不会出现在 /usage 和 VS Code 使用表中的问题
  • 修复了当 id 带有日期或 -v1:0 后缀时，在普通 id 被拒绝的情况下，/model 接受 Sonnet 4.6 或 Sonnet 5 with [1m]
  • 修复了当 ANTHROPIC_DEFAULT_HAIKU_MODEL 固定不同型号时 /model 选择器显示硬编码俳句版本和价格的问题
  • 修复了在模型回退期间启动的动态工作流程，在回退模型上运行每个代理，而不是重试配置的模型
  • 修复了当俳句是会话的主要模型时 DISABLE_PROMPT_CACHING_HAIKU 没有效果的问题
  • 修复了 claude plugin validate 说 Claude Code 接受无法安装的插件或市场名称的问题； marketplace.json 中的此类名称现在无法验证
  • 修复了 claude plugin validate 传递 outputStyles、themes、monitors 或 lspServers 路径丢失或指向插件目录之外的插件
  • 修复了 claude plugin details 显示 0 个 MCP 服务器的插件，这些插件在 plugin.json 中声明其服务器
  • 修正了 claude plugin marketplace remove 没有说明它在市场上卸载了哪些已安装的插件；现在列出了它们
  • 修复了 claude plugin uninstall 删除了两个已安装插件中的另一个，其 id 仅在情况下不同，其选项和秘密，当指定的插件在该范围内没有 enabledPlugins 条目时
  • 修复了当缓存文件丢失时声明没有版本在其源的最新提交（而不是安装的版本）中静默恢复的插件
  • 修复了用户安装的插件和市场在移动主目录或配置目录后无法加载“缓存缺失”的问题，例如在绑定安装的开发容器中
  • 修复了 installed_plugins.json 在无效插件 ID 下保存记录时显示无插件的问题；这样的文件再次加载
  • 修复了 installed_plugins.json 被重写、丢失记录、当它保存此版本无法读取的记录时； claude plugin 命令现在命名记录并说明如何恢复
  • 修复了屏幕阅读器模式下的权限对话框读取引用的命令和路径的问题，就好像它们是对话框自己的文本一样
  • 修复了 /context 不计算 MCP 服务器指令的问题：它们现在显示为自己的行并计入总数
  • 修复了 Warp 终端中的降价链接呈现为纯文本而不是 clickable 超链接
  • 修复了当用户或本地配置文件无法写入时（例如在沙箱内）claude mcp add、add-json 和 remove 报告成功的问题
  • 修复了云会话中回复的第一句话有时出现较晚而不是像克劳德写的那样流式传输的问题
  • 修正了克劳德的内置键绑定指南说和弦在 1 秒而不是 3 秒后超时，并将 cmd 称为 meta 的别名，这可能会产生大多数终端从不发送的 cmd+ 快捷方式
  • 修复了 keybindings.json 默默接受拼写错误的修饰符，例如 ctl+k；它现在在调试日志中发出警告并建议修复
  • 修复了 footer:openSelected 在 keybindings.json 中反弹或解除绑定后页脚提示仍然显示“进入查看”的问题
  • 修复了快速一起输入的按键（提前输入、按键重复、通过 ssh 或 tmux 突发）有时会针对陈旧状态进行处理的问题
  • 修复了当 CA 证书作为 GIT_CONFIG_COUNT 环境对传递到 git 时工作树签出失败的证书验证（例如在 Git LFS 下载上）
  • 修复了沙盒 git 要求凭证助手存储沙盒代理的登录信息，该登录打印出“无法存储”
  • 修复了当一个嵌套值无效时完全忽略托管 sandbox 设置的问题；无效值现在无法关闭，并且块的其余部分仍然适用
  • 修复了当 Claude Code 在 git 存储库的子目录中启动时，Claude 对自己的自动记忆注释的编辑被阻止为敏感文件写入的问题
  • 修复了当使用 DISABLE_TELEMETRY 或 DO_NOT_TRACK 关闭遥测功能时远程控制在付费计划中不可用的问题
  • 修复了 /remote-control 菜单在狭窄终端中剪切其 QR 码提示中字的问题
  • 修复了 vim 模式 . 删除 Shift+Enter 换行符，将光标留在带重音字母的内部，并在最后一行的 3J 或可视模式 J 之后重复旧的更改
  • 修复了 vim 模式光标放置：在正常模式下调用超过 10,000 个字符的提示不再使光标超出末尾，并且 V 和 p 现在落在第一个非空白处
  • 修复了 vim 模式 J 连接行的间距与 Vim 不同（例如 ) 之前或制表符之后的空格），以及最后一行上的 3J 或可视模式 J 不会像 Vim 那样移动光标
  • Windows：修复了允许 cmd /c rd、rmdir、del 或 erase 删除驱动器根目录、主文件夹和 Remove-Item 拒绝的其他文件夹的 PowerShell 工具
  • 改进了 /mcp 工具列表：它一次显示更多工具，使用翻页键和鼠标滚动，并使用警告图标标记您的组织阻止的工具
  • 改进了 MCP 工具结果：MCP 工具返回的图像现在也保存到文件中，因此 Bash、Read 和其他工具可以打开它们
  • 改进的 /tasks：行显示状态图标、名称和全部事实、标题和关键提示保留在屏幕上并包含许多任务，并且列表获得分页键、鼠标滚轮和 clicks
  • 改进了 /help、/hooks、/copy、/chrome、/memory、/ide、/release-notes、/rewind、/diff、/remote-env、/plugin 和其他带有翻页键、鼠标滚轮和 clicks 的选择器中的列表
  • 改进了搜索框旁边的列表，例如 /skills 和 /artifacts，在搜索框有按键时将其指针绘制成暗色，因此只有一个指针突出显示
  • 改进了压缩旋转器：它的计时器现在在压缩开始时启动，并在摘要的令牌流式传输时对其进行计数，从而替换了百分比栏
  • 改进了登录 MCP 服务器后显示的浏览器页面：居中布局、深色模式和新艺术作品
  • 改进了当技能属于加载失败的插件时技能工具的回复，因此克劳德告诉你插件无法加载，而不是调用技能已卸载
  • 改进了 Claude Code 配置上的 prompt-audit：过时的路径、过时的命令和矛盾的指令文件现在引导报告，并思考 Claude Code 文档保留的关键字
  • 改进了从根本无法读取的 installed_plugins.json 的恢复：在重建之前，其内容保存在其旁边的文件中，并且 claude plugin list 命名该文件
  • 改进的工件数据库读取：返回整页的有序查询现在表示它是一页以及如何读取其余部分
  • 改进了首次回复延迟：在会话首次回复结束时运行的模式编译步骤现在在回复流式传输时运行
  • 通过重用预连接的 API 连接来改进首次请求延迟
  • 改进的启动：claude -p 和 Claude Code Remote 不再加载交互式 UI，自动模式分类器的规则和 Artifact 工具在首次使用时加载，而不是在启动时加载
  • 改进了 claude.ai 帐户的启动，这些帐户的 Artifact 工具功能尚不清楚，如首次运行时：提示不再等待 1.5 秒来检查它们；如果需要，第一条消息会等待
  • 更改了第三方提供商的交互式会话或在未配置权限模式时将遥测关闭以自动模式启动； permissions.defaultMode 仍然覆盖它
  • 更改了 /ultrareview 启动对话框，表示查看本地分支可能会将未提交的更改上传到跟踪文件
  • 更改了 /model 选择器的 Opus 行和默认模型的名称，以删除“（1M 上下文）”，其中 Opus 已经具有 1M 上下文窗口；窗口没有变化
  • 更改了终端中的提示建议，使其在连续 20 个未使用后出现的频率降低；使用一个可以让他们回来
  • 更改了 --system-prompt 和 --append-system-prompt 以同时接受其文本和 -file 表格；文件的文本首先出现
  • 更改了 Skill(anthropic-skills:<name>) 拒绝规则，以便在 Claude Desktop 将其作为插件提供时也阻止该技能，并且 Skill(skill:<name>) 拒绝匹配该技能的别名和显示名称
  • 更改了 /rewind 和 /diff 列表，使其与其他列表 (select:*) 执行相同的键绑定操作； messageSelector:*/diff:*重新绑定仍然有效
  • 更改了 /workflows 运行列表，使其自身大小与其他列表一样：终端内联的一半，并且当提示显示在下面时，它将其标题保留在屏幕上
  • 将 claude plugin eval 更改为安装 git 时需要 git 2.31 或更高版本；在较旧的 git 上运行被拒绝，并显示一条命名版本的消息
  • 更改了神器监视：自动武装的手表（不是您要求的）现在在 3.5 小时后结束且没有任何活动；再次发布或观看工件会重新武装它
  • 自托管运行器：更改了生命周期挂钩的 git 以跳过存储库的 Git LFS pre-push 挂钩，忽略可写系统 core.hooksPath，并且不签署没有 --configure-git 的提交
  • 自托管运行器：在 Anthropic 管理的 git 下更改了 GIT_SSL_CAINFO 和 GIT_SSL_NO_VERIFY：运行器自己的 git 始终验证 Anthropic 的 git 路线，警告线说明适用于何处
  • 恢复了 claude-ai 名称的 2.1.282 保留：技能、命令、工作流程和 MCP 服务器的技能和提示再次加载，Skill(claude-ai:*) 规则是普通前缀规则
  • [VSCode] 修复了自动切换失败后会话继续以自动或旁路模式运行时权限模式指示器显示默认的问题；现在会重试开关直至其落地
  • [VSCode] 修复了从网络传送的会话丢失克劳德工作时发送的消息的问题
  • [VSCode] 修复了当旧版本保存了一个空的本地副本时，Web 会话在会话列表中保持隐藏状态，并在其位置打开一个空的聊天窗口
  • [VSCode] 修复了重新打开的会话在克劳德在回合中收到消息时分割回合的问题，例如自动继续
  • [VSCode] 修复了重新加载的会话显示回退的回合，或仅显示压缩之前的行
  • [VSCode] 修复了页脚的代理药丸在狭窄的面板中将其图标绘制偏离中心，状态点靠在边缘的问题
  • [VSCode] 修复了聊天输入在将以换行符结尾的行粘贴到长提示中后显示其文本略低于光标和选择的问题
  • [云会话] 改进了将存储库添加到正在运行的云会话：您的 GitHub 帐户可以读取但不能推送到的私有存储库现在可以附加以供读取
  • [云会话]修复了云会话偶尔会重做已完成的步骤，例如从服务器端重启恢复后发布重复的评论或推送
  • [云会话] 将新的例程安排更改为默认为整点后几分钟，并注意精确设置在整点的例程可能会晚几分钟开始
  • [Claude 标签] 添加了“Claude 可以搜索的频道”管理设置，该设置将 Claude 的 Slack 搜索限制为其已添加到的公共频道，按组织、工作区或频道设置
  • [Claude Tag] 在连接 Claude 帐户后显示的页面上添加了返回 Slack 按钮，使您返回到您开始的线程
  • [Claude Tag] 修复了当频道通过附加规则获取其访问捆绑包时，频道的配置页面没有列出连接器或插件的问题；现在显示附加规则的捆绑包
  • [Claude Tag] 修复了 GitHub 应用程序安装中的访问捆绑存储库搜索缺失的存储库，该安装仅限于大量选定的存储库
  • [克劳德标签] 修复了克劳德偶尔在回复中被新消息打断时两次发布相同回复的问题
  • [Claude Tag] 修复了在 Slack 通道 ID 更改的旧私人通道中停止运行的通道例程，例如在 Slack Connect 共享之后
  • [Claude Tag] 修复了设置为“仅限频道”的频道中的对话，当非来宾会员加入且 Slack 确认其会员资格缓慢时所有对话都会结束的问题
  • [代码审查] 修复了当 GitHub 未能返回拉取请求时“@claude review”请求变得静默的问题：请求重试一次，并且注释会解释是否仍然失败
  • [代码审查] 修复了在时限内停止且未验证任何内容的审查的计费问题：现在显示为不完整，不收费，并且重试一次
