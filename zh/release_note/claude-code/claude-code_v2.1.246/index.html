claude-code v2.1.246

修订 发布时间2026年8月25日 来源anthropics/claude-code 英文原文

claude-code v2.1.246

变更流程图

亮点

  • 权限与凭据安全 — 启动警告现在标出子命令前带通配符的 Bash 允许规则（如 Bash(git * main)），因为它们也会匹配插入到前面的选项；带悬空 && 或 || 的格式错误命令始终需要批准，标记为 requiresUserInteraction 的 MCP 工具不再提供”是，以后不再询问”。遥测/指标请求不再把第三方网关的 API 密钥发送给 Anthropic——凭据只发送到其自身主机（ANTHROPIC_BASE_URL）。预期会比以前多几次提示；新的 /permissions Auto 选项卡可用于检查/编辑驱动这一变化的分类器规则。
  • Headless、SDK 与后台会话可靠性 — 非交互会话（-p、SDK、云）现在会自动继续被服务器错误、连接断开或停滞截断的响应，而非以错误结束；修复还包括 45 秒后台会话打开失败（启动目录被删、机器休眠、主机慢）、与并发 npm 重装时的 EACCES 竞态、claude agents 重复/启动中条目、代理写入工具块导致的恢复 400，以及自托管 runner 对格式错误的工作轮询响应重试。如果你自动化 Claude，这是升级的最强理由。
  • MCP 与插件生态 — MCP 修复涵盖：headless/远程会话中被中断的调用被误报为”已完成，无输出”、空 schema（{}）的参数以 JSON 字符串而非真实类型发送、--strict-mcp-config 对永不加载的 .mcp.json 服务器提示。插件修复涵盖：重复的 SHA 命名缓存目录、叠加的 /plugin:plugin:skill、裸名称下 claude plugin update 失败、plugin.json 中的 UTF-8 BOM、/reload-plugins 对 skills/*/SKILL.md 报告 0 个 skill、hook 错误中的字面量 ${CLAUDE_PLUGIN_ROOT}，以及损坏的 known_marketplaces.json 导致 claude plugin install 静默失败。注意遥测字段变更：plugin_id_hash 现在反映真实 marketplace，管理员安装的插件 enabled_via 为 admin-install；/code-review 现在也能在 Bedrock、Vertex AI、Foundry 和 Claude apps 网关上自启动，即使禁用遥测/非必要流量。
  • 全屏/记录性能与 UI 打磨 — 超长单行 diff（如 base64）导致的严重记录变慢通过加标记截断解决，每条消息的行不再保留全记录工具查找的完整副本，阻止全屏和 Ctrl+O 视图的内存增长。还修复：缩放后记录空白、卡住/中途跳转到底部、+/N) 列表和 setext 标题禁用 markdown、/stats 热力图在 UTC 以东偏移一小时、/rename 覆盖主题 promptBorder、忽略自定义 diff 颜色（diffAdded/diffRemoved）、keybindings.json 中未知操作让某个键失效。回合结束现在显示完成耗时（如 ✻ Sautéed for 23s · done 6:05 PM）。
  • 升级结论——无破坏性变更，无需迁移 — 这是实质性维护版本，不是重新打标签或仅元数据提升；无需改动配置。用 headless/SDK 或云会话、MCP、插件或大/全屏会话的用户都值得升级。只有以上都不使用且未遇到 UI/性能问题时才能放心跳过。值得知晓的行为：/goal 将空闲检查限制为每个目标三次（你下一条消息再给三次），触及 maxTurns 的子 agent 现在返回标记为部分输出并附 SendMessage 继续提示，/cd 立即应用新目录的设置、hook、.mcp.json 服务器、skill 和 agent，而非等到 --resume。

发生了什么变化

  • 添加了针对 Bash 允许规则在子命令之前使用通配符（例如 Bash(git * main)）的启动警告，因为它们还匹配在子命令之前插入的选项
  • 在 /permissions 中添加了自动模式选项卡，用于查看和编辑自动模式分类器规则
  • 将回合的完成时间添加到回合结束持续时间线中，例如✻ Sautéed for 23s · done 6:05 PM
  • 修复了调整终端大小并跳到底部直到下一次按键后显示空白记录的全屏模式
  • 修复了当 diff 包含很长的单行（例如，base64 字符串）时，转录严重减慢的问题；这些行现在用标记截断呈现
  • 修复了定位到较早消息时不稳定的全屏滚动，包括跳到底部卡在脚本中间
  • 修复了当 Claude Code 的起始目录被删除、机器已休眠或主机启动进程缓慢时，后台会话在 45 秒后无法打开的问题
  • 修复了当另一个 Claude Code 进程当时重新安装 npm 包时后台会话无法打开并显示“无法启动后台服务… EACCES”的问题
  • 修复了当前 500 个字符不包含 Markdown 时整条消息以及 +/N) 列表和 setext 标题禁用 Markdown 渲染的问题
  • 修复了被无头/远程会话中传入消息中断的 MCP 工具调用，该调用被报告给模型为“已完成但无输出”，而不是显式中断错误
  • 修复了当参数架构为空 ({}) 时 MCP 工具参数作为 JSON 字符串发送，而不是其真实类型
  • 修正了一个命令在运行中中断，显示为“Ran 1 shell 命令”，没有任何迹象表明它被切断
  • 修复了在动态工作流程中按 ← 或运行 /background 重新启动其已完成的子代理的问题；现在它首先询问并说明将重新启动多少个子代理
  • 修复了在 claude agents 中打开一个刚刚启动的会话，而其工作进程仍在启动（在 Windows 上常见）的问题，并以“重生正在进行时停止”来停止它
  • 修复了 claude agents 两次列出后台命名会话的问题；现在再次将同一对话置于后台对新行进行编号（例如 my-session (2)）
  • 修复了后台保留扫描，当旧的后台会话记录指向您自己创建的 .claude/worktrees/ 下的 git 工作树时，会删除它们
  • 修复了自动模式工具调用在非常大的会话中被拒绝为“暂时不可用”的问题，方法是根据提示大小调整安全检查截止时间
  • 修复了插件缓存为同一插件创建重复的 SHA 命名目录的问题
  • 修复了其 frontmatter name 已经包含 <plugin>: 前缀的插件技能，显示它在斜杠菜单中加倍（例如 /plugin:plugin:skill）
  • 修复了 claude plugin update 在给定其裸名称的情况下安装的插件失败的问题（只有完全限定的名称有效）
  • 修复了使用 UTF-8 字节顺序标记 (BOM) 保存 plugin.json 时插件安装失败的问题
  • 修复了 /reload-plugins 为在 skills/*/SKILL.md 下定义技能的插件报告 0 技能的问题
  • 修复了显示文字 ${CLAUDE_PLUGIN_ROOT} 而不是解析的插件路径的挂钩错误消息
  • 修复了 /rename 将主题的提示边框颜色（包括自定义主题的 promptBorder）替换为默认青色的问题；边框现在会保持主题的颜色，除非您选择带有 /color 的颜色
  • 修复了差异和 /theme 预览中忽略的自定义主题差异颜色（diffAdded/diffRemoved 及其变暗变体）
  • 修复了 keybindings.json 与未知操作名称的绑定，默默地使该键失效；现在已跳过它，因此默认绑定继续工作，并在 --debug 下记录警告
  • 修复了 /stats 活动热图，显示 UTC 以东时区每天的活动相差一个单元格（星期日的计数低于星期一）
  • 修复了已分叉或后台会话中的 /fork 以空对话启动新会话
  • 修复了以 /-- 开头的提示（例如精益文档注释）被作为未知斜杠命令拒绝而不是发送给克劳德
  • 修复了在键入的文本停止匹配真实路径后 @ 文件选择器保持打开状态的问题
  • 修复了导航到代理视图并返回后状态行的成本和持续时间重置为零的问题
  • 修复了当您 clicked 终端窗口仅将其重新聚焦时，全屏模式将键盘焦点移动到指针下方的控件上的问题
  • 修复了当完成令牌或工作目录包含空字节时路径完成失败的问题
  • Windows/macOS：修复了无头会话未清理不干净退出的会话留下的 ~/.claude/sessions 中陈旧条目的问题
  • 修复了当第三方 Anthropic 兼容端点 (ANTHROPIC_BASE_URL) 传输没有 id 的 tool_use 块时，UI 在第一次工具调用时因渲染错误而停止的问题
  • 修复了写入工具报告“内存不足”或在覆盖非常大的现有文件后长时间冻结的问题，即使该文件已被写入
  • 修复了 claude plugin install <name> 在 ~/.claude/plugins/known_marketplaces.json 为空或损坏时静默退出（或挂在终端中）而不是报告错误的问题
  • 修复了当保存的历史记录包含 Anthropic API 不接受的工具块时，恢复的会话每回合都会失败并显示 400（通常由第三方 API 代理编写）
  • 修复了某些具有服务器管理设置的团队/企业用户的 curl -fsSL https://claude.ai/install.sh | bash 失败并显示“不支持原始模式”的问题
  • 修复了在 VS Code 扩展中以计划模式结束的会话，以及在未设置权限模式时使用权限提示工具在 claude -p --continue/--resume 中恢复计划模式之外的会话
  • 修复了沙箱“沙箱外的网络请求”权限提示正在等待时 Notification 钩子未触发的问题
  • 修复了 Bash 权限检查，始终要求使用悬空的 && 或 || 运算符批准格式错误的命令
  • 修复了 --strict-mcp-config 会话提示批准它们永远不会加载的 .mcp.json 服务器，这导致后台会话在启动时等待
  • 修复了向 Anthropic 发出的遥测和指标请求，该请求携带为第三方网关 (ANTHROPIC_BASE_URL) 配置的 API 密钥；凭证现在仅发送到其自己的主机
  • 修复了当 apiKeyHelper 返回短暂的 JWT 时空闲后第一个提示上可见的 API 错误：现在在发送之前刷新过期的缓存令牌，并且 401/403 身份验证错误会安静地重试
  • 修复了全屏和 Ctrl+O 记录视图中内存随着会话长度而增长的问题：每个渲染的消息行不再保留记录范围工具查找的完整副本
  • 修复了从一个存储库（例如从多个工作树）同时启动的 /ultrareview 运行和云会话，有时会从另一次启动的未提交更改开始
  • 修复了后台云会话显示的任务进度计数（例如 3/5），例如 /autofix-pr 偶尔会丢失任务
  • 修复了远程控制会话在出现第二个提示之前将其占位符名称保留在 claude.ai 和 Claude 应用程序中的问题；自动生成的标题现在出现在第一个提示之后
  • 修复了标记为 requiresUserInteraction 的 MCP 工具在权限提示中仍提供“是，不再询问”的问题；该选项写入了允许规则，然后该工具忽略了
  • 修复了自托管运行器在工作轮询响应格式错误（例如拦截代理的 HTML 页面）时结束其实时会话或退出的问题；它现在重试投票
  • 改进了/cd：新目录的项目设置、挂钩、.mcp.json服务器（在通常的批准提示后面）、技能和代理现在在移动后立即生效，而不是在--resume上生效
  • 通过重放快照函数而无需每个函数使用 base64 子 shell，改进了 bash shell 上的 Bash 工具延迟
  • 改进的子代理结果：在 maxTurns 限制处停止的子代理现在返回标记为部分的输出，并提示通过 SendMessage 继续它，而不是显示为已完成
  • 改进了非交互式会话（-p、SDK、云会话），可自动继续因服务器错误、连接丢失或停顿而中途中断的响应，而不是以错误结束
  • 改进了对工作负载身份联合会话、apiKeyHelper 启动时运行时发送的事件以及登录令牌在空闲时过期后发送的事件的使用遥测对组织的归因
  • 更改了 /code-review，以便 Claude 还可以在禁用遥测或非必要流量时通过 Claude 应用程序网关在 Bedrock、Vertex AI 和 Foundry 上自行启动它
  • /goal：更改了空闲会话，以针对每个目标的长时间运行的后台工作启动最多三个签入；您的下一条消息允许再发送三个
  • 更改了 claude install 和 claude update 以将待处理的托管设置同意提示推迟到下一个交互式会话，而不是在命令中提示
  • 更改了从 claude.ai 同步的插件的 OpenTelemetry 插件事件：plugin_id_hash 现在反映了插件的真实市场，而 enabled_via 是管理员安装的插件的 admin-install
  • 修复了命令沙箱的文件系统配置不尊重 --setting-sources
