claude-code v2.1.269

这个项目是干啥的：Anthropic 官方的命令行 AI 编程助手，在终端里让 Claude 直接帮你读写代码、改项目、跑命令。给习惯用命令行的开发者用。

变更架构图

亮点

  • 插件工具与自动化 — claude plugin eval 现在生成带评分、可复现的插件评估，并输出 JSON 和 HTML 报告。/output-style [name] 现在也能跨 Remote Control、云和 headless 会话工作，/ultrareview --post 直接发布发现结果，而不再启动另一个云会话。
  • 权限行为变更——审计你的规则 — 以 ! 开头的拒绝/询问规则现在只在声明它们的作用域来源内生效，裸 ! 否定会被忽略。Bash tee 写入现在遵守 Edit() 拒绝规则和工作目录检查，因此 Bash(tee:*) 不再允许写入允许目录之外的目标。
  • 会话可靠性与成本 — 修复减少中断或截断回合后的提示缓存未命中，在 headless 重试/模型切换之间保留回复，防止超大提示在自动压缩期间卡住，并使 /goal 带解释地重试或暂停。后台 agent 也不再让远程/headless 会话误报”waiting for your input”。
  • 编辑器、终端与平台更新 — VSCode 新增 agent 地图、实时子 agent 进度和 Hooks/Permission rules 对话框。大量终端修复涵盖 SSH 与协议兼容性、启动转义码噪声、光标渲染和调整大小。云同步 skill 重命名为 anthropic-skills:<name>；无歧义时裸名称仍可用。
  • 升级判断 — 这是实质性维护版本，不是重新打标签。插件作者、权限敏感团队、云/headless 用户以及 VSCode 或受影响终端的用户应升级；没有这些工作流的用户可以安全推迟。

发生了什么变化

  • 添加了 claude plugin eval：针对 Claude Code 运行插件的评估套件并获得评分、可重现的结果（JSON + HTML 报告）；见claude plugin eval --help
  • 添加了 /output-style [name] 来列出和切换输出样式，包括通过远程控制、云和其他无头会话
  • 添加了当 Bash 工具处理文件编辑时 Bash 命令更改为 Bash 工具结果的文件差异（设置 bashEditDiffEnabled）
  • 添加了 OTEL_METRICS_INCLUDE_REPOSITORY 以使用 vcs.* 存储库属性标记 OpenTelemetry 指标和事件；提交事件获取 vcs.ref.head.* 和 OTEL_LOG_TOOL_DETAILS
  • 添加了 CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS 以延长 LLM 网关 /v1/models 发现超时（默认 3 秒）
  • 添加了一个旋转提示，建议使用 /focus 进行视图，其中仅包含提示、一行工作摘要和响应
  • 添加了 CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS (1–256) 以提高工作流工具对于推理绑定扇出的每次运行并发代理限制
  • 修复了响应在输出令牌限制处被切断并自动恢复后，提示缓存在回合中部分失效的问题
  • 修复了中断克劳德思考后恢复会话可能会改变先前上下文重新发送方式的情况，从而损害提示缓存重用
  • 修复了 F1/F2/F4 在 kitty 协议终端中不起作用以及 st 中的删除、Alt+箭头在 rxvt-unicode 中充当转义符以及 Shift+标点符号在 WezTerm 中键入未移动的键（2.1.247 中的回归）
  • 修复了后台代理仍在运行时报告“正在等待您的输入”的远程和无头会话（设置 CLAUDE_CODE_BG_TASKS_REPORT_RUNNING=0 以恢复旧行为）
  • 修复了终端对功能查询 (^[[?1;2c) 的回复在某些终端启动时显示为杂散文本的问题
  • 修复了调整终端大小后，记录顶部或底部的行在全屏显示为空白的问题
  • 修复了从 ! 开始应用超出编写它的设置源的拒绝或请求权限规则；这样的规则现在仅适用于其自己的源代码，并且忽略纯粹的 ! 否定
  • 修复了压缩后 Claude 被告知的 git status：它现在是当前状态，而不是会话开始时的状态
  • 修复了远程会话恢复时同步插件 MCP 服务器无法连接的问题
  • 修复了当模型切换或在回合中重试请求时恢复的无头会话丢失回合回复的问题
  • 修复了后台任务磁盘记录中的终端转义码、换行符和超大文本到达任务列表以及恢复工作时的任务通知
  • 修复了 CMYK JPEG 图像无法附加并显示“无法解码”的问题；它们现在可以像其他 JPEG 一样进行转换和调整大小
  • 修复了托管设置批准对话框未命名没有方案的 gRPC 遥测端点集的收集器
  • 修复了插件 headersHelper 同意提示，显示可能被误读为不同主机的 URL 路径
  • 修复了显示 [redacted URL] 代替文件夹名称以 @ 开头的相对 Windows 路径的插件错误
  • 修复了启用终端本机光标时权限规则、自动模式规则、添加目录、会话重命名和反馈审核文本字段中缺少光标的问题
  • 修复了 /fork 收据上重复的 click，每个间隔不到一秒，在等待当前工具完成时不会立即将会话置于后台
  • 修复了拒绝 shutdown 参数（例如 rust-analyzer）的插件 LSP 服务器在会话结束时继续运行；即使 shutdown 失败，现在也会发送 exit
