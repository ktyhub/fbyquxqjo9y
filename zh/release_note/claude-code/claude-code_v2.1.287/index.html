claude-code v2.1.287

修订 发布时间2026年10月1日 来源anthropics/claude-code 英文原文

发生了什么变化

  • 添加了克劳德模组：插件现在可以修改更深层次的行为
  • 添加了“你应该知道”，一个内置模组，其中有一个侧面代理监视你的背后并标记你或克劳德可能错过的事情。使用 /plugin enable cc-plugin-you-should-know@builtin 将其打开（对于启用遥测功能的第一方会话）
  • 在代理视图中添加了匹配会话名称和任务的 n:<text> 过滤器；现在，过滤器会显示折叠部分中的匹配项，然后按 Enter 键打开第一个匹配项
  • 将 prompt_text 添加到 OpenTelemetry user_prompt 事件，这是 prompt 的副本，用于嵌套点键的后端；在您放置或遮盖 prompt 的地方放置或遮盖它（anthropics/claude-code#70763）
  • 在 2025 年 11 月 25 日协议上添加了 MCP 服务器的 URL 提示，例如登录。如果服务器在此更新后不再连接，请将“bareElicitationCapability”：true 添加到其 MCP 配置条目
  • Windows：添加了拒绝 Bash 工具时启动警告也会关闭 PowerShell 工具，因此 Claude 没有 shell 工具
  • 自托管运行器：为在未安装 GitHub CLI 的 macOS 和 Linux 计算机上使用 Anthropic 管理的 git 的会话添加了内置 gh api（仅限 REST）
  • 修复了快速模式在没有用户帐户的代理拥有的远程会话中保持关闭的问题，即使组织允许
  • 修复了当重新连接请求未得到响应时远程控制在几分钟内无法接收消息的问题；现在它会在 30 秒后放弃并重试
  • 修复了配置为 asyncRewake 的钩子，当钩子的脚本文件丢失时，会一遍又一遍地用“发现问题”通知唤醒克劳德；现在报告一次损坏的钩子
  • 修复了当模型的响应流因没有数据到达而停止时工具心跳无法到达 SDK 主机的问题
  • 修复了基岩和顶点启动模型检查忽略强制执行的 availableModels 列表的问题，这可能会将 /model 折叠到一个 Opus 行
  • 修复了 Chrome 浏览器选择器中的 Claude 在无法访问 Chrome 时显示 JSON 解析错误的问题
  • 修复了在 claude.ai 登录保存当前版本 ID 时在 /model 中选择《寓言》的问题，因此您保存的默认值现在遵循最新的《寓言》，就像 Opus 和 Sonnet 一样
  • 修复了 Opus 5.5 和 Sonnet 5.5（/model、opusplan）之间的切换，重写了早期的 MCP 工具公告，这可能会放弃早期的扩展思维
  • 修复了亚马逊基岩护栏块在响应中到达时，当回复开始思考时，以 API 错误结束回合，而不是护栏消息的问题
  • 修复了危险的 rm（例如 / 或主目录上的一个）在同一命令还将输出重定向到 ~ 或通配符路径时失去其始终询问保护的问题
  • 修复了 claude -p 和 SDK 会话在运行回复时切换模型后对每条后续消息重复模型回退的问题
  • 修复了恢复会话或压缩后第二次附加文件夹的 CLAUDE.md
  • 修复了代理退出并删除会话启动所在的工作树后无法从 claude agents 重新打开的后台会话
  • 修复了 /advisor 配对检查：Sonnet 5.5 现在可以为 Opus 4.7 和 4.8 提供建议，并且 API 拒绝的顾问会预先标记，而不是默默地丢弃
  • 修复了 Bash 权限提示，显示内部解析器名称，例如“Contains simple_expansion”，而不是简单的解释
  • 修复了在长时间对话中按住滚动键时，缓慢或繁忙的计算机上的全屏会话退出并显示“无法恢复的界面错误后克劳德代码退出”的原因
  • 修复了名为 __proto__ 的 MCP 工具悄悄降低组织每个工具权限上限的问题
  • 修复了 Claude 被告知将大型 MCP 结果分页保存为 JSON 并带有读取偏移量和限制的问题，该结果无法分割一长行
  • 修复了压缩后在工具结果内传递的提交归因提醒
  • 修复了屏幕阅读器模式，使光标远离搜索框（例如 /resume 和 /permissions）和登录代码字段中键入的文本
  • 修复了屏幕阅读器模式拒绝在 /rewind 的摘要选项上输入任何内容的情况下回车的问题，其添加的上下文是可选的
  • 修复了屏幕阅读器模式，在批准提示中显示“Tab 进行修改”提示，其中 Tab 不执行任何操作
  • 修复了屏幕阅读器模式列出在 /permissions 和 /mcp 中不执行任何操作的箭头键，并在空菜单中或搜索框有这些键时显示“使用数字选择”的问题
  • 修复了屏幕阅读器模式忽略文件编辑批准提示和其他差异中已更改的行
  • 修复了屏幕阅读器模式，在每个旋转框架上再次将 claude --teleport 进度屏幕和 MCP 表单字段在检查时发送到屏幕阅读器
  • 修复了 CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS 未从会话标题和提示挂钩请求中删除结构化输出格式，而基岩支持的网关会拒绝该格式
  • 修复了屏幕阅读器模式，当前一个屏幕比终端窗口高时，会遗漏第二个批准提示的顶行、更改的 /config 行或拒绝计划行
  • 修复了 --include-partial-messages 迟到或不发送简短回复的 message_stop 的问题，因此应用程序可以将回复显示为仍在进行中
  • 修复了 claude agents 有时不显示后台会话正在等待的权限提示
  • 修复了当上传停止在无法读取的已提交 .gitattributes（例如保存为 UTF-16 的 .gitattributes）上时，/ultrareview 提供有关 .git/info/attributes 的建议
  • 修复了 claude remote-control 无法在 HTTP 代理后面注册并出现误导性的“检查您的组织权限”错误的问题 (anthropics/claude-code#97352)
  • 修复了 Linux 上的沙盒 Bash 命令继承了 Claude Code 可执行文件上的开放句柄
  • 修正了运行工具点和三个旋转器在“减少运动”设置打开的情况下仍在移动，并且/倒带的确认屏幕在您键入注释时更新其“前”时间
  • 修复了 claude agents 中屏幕阅读器模式下每秒变化的时间；它们现在最多每 10 秒改变一次
  • 修复了已撤销的 claude.ai 登录名显示通用 API Error: 401 而不是“OAuth 令牌已撤销”的问题；在 -p 模式下，错误现在以“无法验证”开头
  • 修复了 /ultrareview 上传拒绝的问题，建议您将存储库的设置文件命名的变量复制到您自己的用户设置中
  • 修复了 --output-format stream-json 和 SDK 无法通过键入 /<skill> 作为提示来流式传输 context: fork 技能运行的回合，就像它们对技能工具的叉子所做的那样
  • 修复了 /feedback 和 /bug：预先填写的 GitHub 问题不再包含您最近的错误消息，确认屏幕现在将它们列为报告的一部分
  • 修复了当存储库通过普通 http 提供服务时，claude plugin marketplace add --sparse 和 git-subdir 插件安装失败并出现“不允许传输‘http’”的问题
  • 修复了云会话在压缩会话时重新启动时有时会丢失早期会话的问题
  • 修复了与启动 --plugin-url 下载重叠的插件重新加载，损坏了会话的插件存档的缓存副本
  • 修复了打开 Claude Desktop 时 /desktop 引用部分输出超时或打印过多输出的问题；现在错误列出了原因
  • 修复了 MCP 连接器工具调用偶尔运行两次，或者当其服务器更改其支持的 MCP 协议版本时，连接器的调用在重新启动之前失败的问题
  • 修复了未在新云会话中运行的同步插件的 SessionStart 挂钩

  • 修复了克劳德从云端发送的文件和远程控制会话在 30 秒超时后上传完成时失败的问题；现在等待 35 秒
  • 修复了在云和 SDK 会话中添加的存储库未加载其技能和插件，以及在 Claude 更改目录后较晚加载 CLAUDE.md 的问题
  • 修复了单边超过 8,000 像素的 PNG、JPEG 和 WebP 图像无法从远程会话发送的问题；克劳德现在发送缩小版副本

  • 改进的/config：循环显示<>并使用←/→双向步进的设置，窄终端将每个值堆叠在其标签下，以及PgUp/PgDn对列表进行分页

  • 改进了克劳德在因临时原因无法发送文件时所说的内容：现在提到您可以在几分钟内再次请求该文件
