claude-code v2.1.214

修订 发布时间2026年7月18日 来源anthropics/claude-code 英文原文

claude-code v2.1.214

发生了什么变化

  • 修复了单段 dir/** 允许 Edit(src/**) 自动批准写入树中任意位置的嵌套 dir/ 目录的规则，而不仅仅是 <cwd>/dir
  • 修复了影响 Windows PowerShell 5.1 会话中运行的命令的权限检查绕过
  • 修复了 Bash 权限检查在 bash 解析方式与权限分析器不同的文件描述符重定向表单上失败关闭的问题
  • 修复了 Bash 权限检查错误判断很长命令的问题 — 超过 10,000 个字符的命令现在始终提示而不是自动运行
  • 修复了 Bash 权限检查，将 [[ ]] 比较中的 zsh 变量下标和修饰符视为惰性文本 - 这些命令现在提示批准
  • 修复了 Bash 权限检查，不再自动批准某些可能运行不安全选项、命令替换或反斜杠路径的 help 和 man 命令
  • 修复了远程会话上可能在本地确认对话框之前进行的权限提示
  • 添加了 EndConversation 工具：Claude 可以结束与高度滥用用户或越狱尝试的会话，就像自 2025 年以来在 claude.ai 上一样 - 请参阅 https://www.anthropic.com/research/end-subset-conversations
  • 为之前处于静默状态的长时间运行的工具调用添加了定期进度心跳
  • 向内存文件 frontmatter 添加了 ISO modified 时间戳
  • 向 OpenTelemetry 日志事件添加了 message.uuid、client_request_id 和 tool_source 属性，以实现消息级关联和工具来源
  • 添加了 CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH 以配置 OpenTelemetry 内容属性的 60 KB 截断限制
  • 为 subagentStatusLine 有效负载添加了推理工作，因此自定义代理行可以呈现模型和工作量
  • 添加了针对 docker 命令（包括 Podman docker shim）的权限提示，该命令携带守护进程重定向标志（--url、--connection、--identity 和 Podman 的远程模式），而这些标志以前在没有权限的情况下运行
  • 修复了当 GrowthBook 功能评估为 null 时发生的崩溃，以及格式错误的标志有效负载可能会擦除缓存的功能标志的错误
  • 修复了当 pkill -f 模式意外匹配 CLI 自己的进程时 Bash 工具终止 Claude 会话的问题 (Linux)
  • 修复了当 --settings 指向设备文件或多 GB 文件时内存无限增长的问题；过大（>2 MiB）的设置文件现在在启动时失败并出现明显错误
  • 修复了 Windows 上企业代理后面的流转失败并出现“套接字已关闭”的问题
  • 修复了慢读 SDK/管道消费者在退出时流 json 输出截断的问题；出口消耗现在随排队字节而不是固定的 2 秒上限进行缩放
  • 修复了计划任务拒绝将其自己配置的提示作为 untrusted 输入的问题 - 触发的提示现在作为会话分配的任务进行传递
  • 修复了子进程等待标准输入时 PowerShell 工具命令挂起直至超时的问题 (Windows)
  • 修复了 PowerShell 工具下的 Python 脚本在从标准输入 (Windows) 读取非 UTF-8 数据时因 UnicodeDecodeError 崩溃的问题
  • 修复了通过 PowerShell 工具运行的 Python 脚本在非 ASCII 输出上崩溃并出现 UnicodeEncodeError 的问题，以及包含原始 ANSI 转义序列的 PowerShell 7 错误消息 (Windows)
  • 修复了 PowerShell 工具在返回有效的否定答案时将 where.exe、fc.exe 和 diff.exe 报告为错误的问题 (Windows)
  • 修复了 Windows PowerShell 5.1 上的 PowerShell 工具下的 > 和 >> 写入其他工具无法读取为 UTF-8 的 UTF-16LE 文件
  • 修复了一个移位的后台守护进程在关闭时删除其后继者的控制套接字，这使得下一个 client 杀死健康的替换守护进程
  • 修复了使用 ← 或 /background 停放的后台会话，并保持空闲状态，使后台守护进程和工作进程无限期地保持活动状态
  • 修复了后台服务空闲后无法通过 claude rm 或代理视图删除已完成的后台会话的问题
  • 修复了从非 git 文件夹调度的后台会话无法从代理视图中删除的问题
  • 修复了当会话存储中存在不可读的文件夹时重新打开已停止的后台会话无法恢复其保存的对话的问题
  • 修复了未明确启用远程控制的会话中远程控制“会话就绪”推送通知的触发问题
  • 修复了 /install-github-app 和 /mcp 设置菜单在代理视图会话中被阻止的问题 - 它们现在仅在没有连接终端的后台会话中被拒绝
  • 修复了通过 --settings CLI 标志启用的插件未加载（自 v2.1.181 以来的回归）
  • 修复了 OAuth 令牌轮换后长时间运行的会话中功能标志变得过时的问题
  • 修复了 /ultrareview 拒绝在没有合并基础的存储库中运行的问题 - 它现在可以审查所有跟踪的文件
  • 修复了当 shell 配置路径是目录时 claude update 和 claude doctor 静默挂起以及 /status 系统诊断部分变为空白的问题
  • 修复了保存内存文件时内存 frontmatter 值在内联 # 处被静默截断的问题
  • 修复了发出多个累积 message_delta 帧的流上的会话成本和令牌遥测重复计算问题
  • 修复了顾问思考时出现的虚假“检查网络”警告
  • 修复了退出代码 2 的挂钩在挂钩的标准输出 JSON 架构验证失败时不会按照记录阻塞的问题
  • 修复了在回合的异步上下文之外发出的 OTel 日志事件，缺少交互跨度的跟踪上下文
  • 修复了提示/资源刷新期间清除服务器的斜线命令和资源期间的 MCP 瞬时错误
  • 改进了主目录中的 claude rc 工作区-trust 错误，表示 trust 从未保存并建议从项目目录运行
  • 更改了单段 dir/** 挂钩 if: 条件以仅匹配 <cwd>/dir；写入 **/dir/** 进行任何深度匹配。 deny/ask 权限规则保持其任意深度匹配。
  • 使用 -m/--magic-file 或 -f/--files-from 更改了 file 命令以需要权限，而不是自动允许为只读
  • 将保持活动连接池更改为在失效连接错误后禁用，因此重试打开新套接字
  • 更改了 SessionStart 挂钩，以在会话作为分叉而不是 "resume" 开始时报告源 "fork"
