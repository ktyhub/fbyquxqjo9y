claude-code v2.1.268

修订 发布时间2026年9月10日 来源anthropics/claude-code 英文原文

发生了什么变化

  • 添加到 Claude 应用程序网关：在 gateway.yaml 中设置 pricing: 时，登录的 Claude 代码 clients 通过托管设置接收相同的费率，因此 /cost 和遥测与支出表匹配
  • 添加了 access_control.allow_cidrs 为空时网关的启动警告，以及第一次从公共地址到达请求时的一次性警告
  • 添加了 gatewayInternalNetworks 托管设置，让管理员允许 /login 访问其组织自己的公共 IPv4 块上的 Claude 应用程序网关
  • 添加了 claude self-hosted-runner --remove-session-state（默认关闭）：会话结束时删除 <base-dir>/_sessions/ 下每个会话的每会话目录
  • 将 configDirectory 添加到 claude auth status --json 的输出
  • 将--json添加到claude plugin install、uninstall、update、enable和disable，并将errorDetails/noteDetails添加到claude plugin list --json的每一行
  • 为已发布的工件添加了浏览器选项卡图标，由克劳德选择以匹配每个页面
  • 修复了自 2.1.265 以来第三方 Anthropic 兼容端点 (ANTHROPIC_BASE_URL) 上的 HTTP 400 失败的每个回合：Artifact 工具的输入架构中的正则表达式被这些端点拒绝
  • 修复了 WebFetch 无限期挂在服务器上的问题，该服务器使响应保持打开状态而未完成；现在，提取会在 300 秒后失败。设置 CLAUDE_CODE_WEBFETCH_DEADLINE_MS 覆盖截止时间（0 将其关闭）
  • 修复了重生的进程内队友从您未曾见过的文件夹中的同名代理文件中拾取工具或系统提示的问题
  • 修复了持续的高 CPU 使用率：长时间运行的空闲会话中的繁忙循环不再固定 CPU 核心，并且会话回顾期间的 rapid 终端焦点报告不再保持 CPU 高
  • 修复了 Claude 有时在 MCP 工具调用后回复“您的消息为空”的问题
  • 修复了当路径由其真实位置给出时，符号链接目录（macOS 上的 /etc、/tmp、/var；Linux 上的 /bin）上的拒绝和询问权限规则不适用，并且 Bash 命令忽略在符号链接路径拼写上写入的拒绝规则
  • 修复了当权限检查器无法分析的 env -C、eval 或类似命令位于同一行时读取或编辑拒绝规则不适用的情况
  • 修复了显示来自 git 源 URL 的令牌或密码的插件和市场错误
  • 修复了 /mcp 和 /plugin 服务器详细信息、claude mcp list/get 和 MCP 登录错误，显示从 MCP 配置中的 ${VAR} 占位符解析的机密
  • 修复了使用 excludeDynamicSections 的 SDK 会话中的提示缓存和扩展思维中断：第一条消息不再重新呈现每个请求
  • 修复了当缓存的模型访问拒绝过时时，授权用户在重新启动后或在“桌面代码”选项卡中被告知模型受到限制的问题
  • 修复了当另一个克劳德代码进程刷新过时的模型访问条目时，正在运行的会话会默默地切换到组织的默认模型
  • 修复了《Fable》模型上的长上下文 429，显示使用积分同意提示，而不是 Pro 和 Team 计划上的 1M 上下文消息
  • 通过配置文件修复了工作负载身份联合（如 claude-code-action 配置的那样）：共享配置文件的进程可能会在 401 … jti reused 的运行中失败
  • 修复了当本地回调端口范围无法绑定时，MCP 服务器 OAuth 登录失败并显示“没有用于 OAuth 重定向的可用端口”的问题
  • 修复了 /compact 生成的对话摘要和包含 $ 序列的自动压缩文本
  • 修复了恢复以 /compact 结束的对话：其恢复的文件注释现在以相同的顺序加载在每个简历上
  • 修复了 SDK 提示建议、附带问题和 /rename 在压缩之前发送对话的问题
  • 修复了使用向上箭头调用上一个提示并进行编辑后不出现的 @ 文件和 / 命令建议
  • 修复了 claude agents：以自然的速度再次按 ← 返回代理列表不再被忽略，直到您暂停一秒以上
  • 修复了当工作树无法删除时 claude agents 会话删除卡住的问题：消息列出了原因和下一步，对于 git worktree ctrl+x 仍然会再次删除目录
  • 修复了代理面板中的后台代理和工作流程行在其文本包含换行符时扩展为多行的问题
  • 修复了当组织管理设置设置 MCP 允许列表时，Slack 会话中的 Claude 丢失其 Slack 工具的问题
  • 修正了 Chrome 中的 Claude 在导航 URL 有方案但主机无法解析时要求允许主机“https”的问题
  • 修复了当前任务标签较长时旋转器会换行的问题；标签和“下一步：”任务行现在保留在一个终端行内
  • 修复了启用终端本机光标时 /bug 和 /feedback 描述字段不显示光标的问题
  • 修复了 claude remote-control 提供的远程控制会话在 ListAgents 中显示生成的名称而不是会话标题的问题
  • 修复了 claude plugin validate 拒绝插件加载器接受的目录名称以两个点开头的插件路径
  • 修复了插件静默跳过无法检查的默认监视器文件或根 SKILL.md
  • 修复了 WebFetch 对 localhost 和其他无点主机名的错误，以解释 URL 被拒绝的原因并建议使用curl
  • 修复了 PermissionRequest 挂钩在 --print 模式下不触发的问题
  • 修复了在无头 (-p) 运行时不打印的策略助手警告
  • 修复了 /resume 在其父级名称而不是其自己的 ⑂ 分叉名称下列出 /fork 后台会话的问题
  • 修复了 /remote-control 和其他 claude.ai 门控命令，以在注销时建议 /login，而不是显示 Claude for Enterprise 迁移消息
  • 修复了 CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS 不扩展没有每个钩子 timeout 的 SessionEnd 钩子（在 1.5 秒后它们仍然被取消）
  • 修复了 /autofix-pr 和其他云会话命令在没有连接 GitHub 帐户时重试或安装 Claude GitHub 应用程序的问题；他们现在指向 /web-setup 或网络连接页面
  • 修复了 /teleport 和 /remote-env 等云会话命令，以解释组织策略何时关闭它们，而不是回答“未知命令”
  • 修复了 Bash 沙盒指令过度限制的问题：当文件系统隔离关闭时，没有未强制执行的路径列表，并且严格模式不再声明命令永远不能在未沙盒的情况下运行
  • 改进的全屏模式：添加或删除提示行（Shift+Enter）现在可以像键入字符一样快速地重新绘制，而不是重新渲染可见的文字记录
  • 改进了 --continue / --resume：对话立即出现，而不是等待 SessionStart 挂钩，并且第一条消息不再重新读取整个记录
  • 通过不再重新绘制隐藏的每工具批次提醒的记录，提高了工具密集转弯时的响应能力
  • 改进了使用 .claude/workflows/ 脚本的项目的启动时间：列出它们不再解析每个脚本
  • 改进的自动模式拒绝：克劳德现在收到的消息命名了阻止该操作的规则，并要求克劳德尝试更安全的方法并完成不相关的工作，然后再停下来询问您
  • 改进了 Chrome 中的 Claude：长页面读取现在保持内联，而不是保存到文件中并读回
  • 改进了 MEMORY.md 截断警告，以说明剪切了多少行以及剪切开始的位置
  • 改进了工件的终端权限提示：它现在以询问的问题开头
  • 改进了提示页脚：编辑器或 /diff 选择现在显示在提示输入内，全屏模式在页眉而不是页脚中显示远程控制状态
  • 改进了“1M上下文需要使用积分”消息，表明在会话中打开的使用积分在重新启动克劳德代码后生效
  • 改进/plugin：安装、启用或禁用插件现在在关闭菜单时生效；之后不再需要/reload-plugins
  • 更改了 Bedrock、Vertex 和 Foundry 上的系统提示，以附件形式提供环境、模型和设置详细信息，匹配第一方会话
  • 更改了 Bedrock、Vertex 和 Foundry 会话，以在对话中保持工具列表字节稳定（后期连接工具加载延迟而不是重写），匹配第一方会话
  • 更改了任务跟踪工具（TaskCreate/Get/Update/List、TodoWrite），使其仅在 Claude 3.x、Opus 4.0–4.7、Sonnet 4.0–4.6、Haiku 4.5 上提供；在别处设置 CLAUDE_CODE_ENABLE_TODO_TOOLS=1
  • 将终端中的工件数据编辑权限提示更改为显示文档计数以及谁可以打开工件的卡片
  • 更改了本地 Cowork 会话设置为跳过所有批准：Artifact 工具现在拒绝会话文件夹之外或符号链接后面的本地文件，而不是在不询问的情况下读取它
  • 更改了普通 WebFetch 拒绝和询问规则，使其不再适用于 Artifact 工具读取和更新；使用 Artifact 规则（或 WebFetch(domain:claude.ai)）来阻止或控制它们
  • 更改了“N MCP 服务器需要身份验证”启动通知，以宣布每个服务器一次，而不是每次启动时都宣布
  • [VSCode] 修复了在设置文件中设置 CLAUDE_CONFIG_DIR 或 environmentVariables 设置时的会话列表、设置切换和聊天选项卡
  • [VSCode] 修复了模型药丸、模型选择器和命令菜单在登录、注销或帐户切换后在打开的选项卡中空白几秒钟的问题
  • [VSCode] 修复了当项目或本地设置覆盖 ~/.claude/settings.json 中命名的模型时，自动从新选项卡或刚刚重新加载的对话中的模式选择器中消失的问题
  • [VSCode] 修复了配置 SessionStart 挂钩后，在窗口重新加载后会话名称恢复为最后一个提示的问题
  • [VSCode] 修复了当窗口中的另一个选项卡已经启动时，页脚的模型丸和远程控制丸等待新选项卡的克劳德进程启动的问题
  • [VSCode] 修复了当会话选项卡的启动在其配置读取后超过半秒到达时，第二个 Claude 进程在其完全启动过程中运行的问题
  • [VSCode] 修复了从会话列表中恢复会话时忽略 claudeCode.preferredLocation: "sidebar"（它始终打开面板）的问题，并且以编程方式打开将该设置重置为“面板”
  • [VSCode] 修复了 Windows 问题：未安装 WSL 的计算机上不再出现 WSL 安装提示，并且安装 WSL 后现在可以正确返回 Windows 文件的 IDE 诊断信息
  • [VSCode] 修复了自定义样式生成器在通过设置设置 CLAUDE_CONFIG_DIR 时将用户级别样式保存在 CLI 不读取的文件夹中的问题
  • [VSCode] 添加了向左和向右箭头键，以更改键盘和屏幕阅读器用户保存始终允许权限规则的位置
  • [VSCode] 为键盘和屏幕阅读器用户添加了“Claude Code：聚焦最后一条消息”命令，将键盘焦点移动到对话中的最新消息
  • [VSCode] 更改了管理插件对话框以应用安装、启用、禁用和卸载以打开会话而无需重新启动
  • [VSCode] 更改了一些工件权限提示以省略“不再询问”选项，以匹配终端
  • [网络上的克劳德代码] 修复了运行时间超过大约六个小时的云会话，无提示地丢失保存到持久会话文件夹的文件；保存现在最多可以持续一天
  • [网络上的克劳德代码] 修复了在管理员限制模型工作量的组织中，当例程恢复会话或会话在没有设定工作量的情况下开始时出现“无效工作量级别”错误
  • [网络上的克劳德代码] 改进了对话中的例程创建：当新例程没有连接器时，克劳德现在会这样说以及如何添加它们，而不仅仅是确认它
  • [Claude Tag] 修复了管理设置页面挂在加载框架上或在瞬时加载失败后变为空白的问题；无法加载的部分现在显示“重试”按钮
  • [Claude 标签] 在 Slack 管理设置中添加了从 Slack 频道的配置页面返回组织 Claude 的链接
  • [Claude Tag] 修复了 Slack Enterprise Grid 通道在 Slack 管理员将其移至另一个工作区后丢失其 Claude 设置（存储库、环境、访问）的问题
  • [Claude Tag] 改进了 Claude 解释阻止操作的方式：现在它会说明是否是权限检查、自己决定首先确认或缺少访问权限阻止了该操作
  • [Claude Tag] 提高回复速度：Claude 现在同时运行多个只读查找（搜索 Slack、阅读帖子、查找人员），而不是一个接一个地运行
  • [Claude Tag] 改进了比较的格式：句子长度比较现在以列表形式出现，而不是横向滚动的宽表格，并且长表格单元格换行
  • [Claude Tag] 修复了具有自己会话的线程中的 @Claude !restart 有时也会发布矛盾的“此线程由通道会话处理”通知
  • [Claude Tag] 改进了当您的 Claude 帐户位于与 Slack 工作区不同的组织中时显示的消息：它现在解释了如何将工作区连接到您的组织
  • [Claude Tag] 修复了 URL 包含在尖括号中的 Markdown 链接，在 Slack 中显示为文字括号文本，而不是 clickable 链接
  • [Claude Tag] 修复了工作区访客在访客可能使用 Claude 的频道中的顶级@提及，有时会收到“您的 Slack 帐户未连接”回复而不是答案
  • [Claude Tag] 修复了频道中长时间运行的会话被新会话所取代的问题；计划的刷新现在会等待，直到通道及其线程安静为止
  • [Claude Tag] 修复了通道设置卡 clicked 多次告诉提议会话更改在应用后被拒绝；结果现在发送一次
  • [克劳德标签]更改了公共频道的记忆：每个频道现在保留自己的笔记，克劳德不再回忆它在其他公共频道中保存的笔记；工作区笔记保持共享
  • [代码审查]在后续审查中仍在开放的调查结果列表下添加了一条注释：解决发现的线程，而不仅仅是回复它，阻止以后的评论将其计为开放
  • [代码审查]修复了当其中一名代理验证结果中途失败时，审查有时会以不完整结束的问题；审查现已更换该代理人并做出裁决
  • [代码审查] 修复了推送触发的审查，该审查在拉取请求转换为草稿后仍在运行的审查后面排队
  • [代码审查]修复了当 PR 编辑仅与 CLAUDE.md 列出的文件共享名称的根文件（例如 README.md）时忽略目录的 CLAUDE.md 约定的审查
