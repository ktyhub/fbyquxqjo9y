claude-code v2.1.232

修订 发布时间2026年8月13日 来源anthropics/claude-code 英文原文

变更流程图

亮点

  • 子 agent 与响应速度 — 子 agent fork 默认启用：subagent_type: "fork" 继承完整对话和提示缓存，而非队友的交互式生成现在在后台运行。委派保留上下文而不阻塞前台工作；可通过 /tasks 查看完成情况。全屏流式渲染也避免每次更新都重新规范化整个对话，提升长会话响应速度。
  • 跨会话协调 — 输入 @ 可以按名称寻址另一个活跃的 Claude 会话，SendMessage 现在能解析唯一裸名称而无需请求引用；重名的活跃会话会获得 name-word-word 变体。新增 /config 控制入站接受/保持/拒绝行为。这对多会话工作流有用；单会话用户可以跳过。
  • 配置变更与破坏性校验 — additionalMarketplaces 和 allowedMarketplaces 现在是 extraKnownMarketplaces 和 strictKnownMarketplaces 的别名。但网关 desktop: 覆盖层在启动时会进行 schema 校验，未知/无效键、空的 managed.policies[].match.groups 或 admin.admin_groups、格式错误的 email_domain 值现在会导致启动失败。迁移：将项目级 sandbox.ripgrep 覆盖移到用户、托管设置或 --settings；管理员应在升级前校验配置。
  • 安全与信任加固 — 此版本堵住 Windows PowerShell 和 Git Bash 权限绕过、Linux 沙箱受保护路径绕过以及共享 /tmp 套接字目录被接管的风险；还新增 GitLab token 脱敏，并使 glab 凭据存储获得与 gh 相当的保护。迁移：嵌套 git 仓库不再继承父级信任，因此每个仓库都需要单独确认。强烈建议 Windows、共享主机、GitLab、沙箱和嵌套仓库工作流升级。
  • Remote Control 与后端可靠性 — Remote Control 现在会重新挂载恢复的 Desktop/IDE 会话、还原桥接历史、隔离云桥记录与凭据、网络闪断后重连约 30 分钟，并清楚报告接管、终止或删除；已删除的 claude.ai/app 会话会启动替代会话，修复了 v2.1.227 回归。MCP 探测挂起、mTLS 证书轮换、格式错误的 AWS/Vertex 区域以及 Bedrock/Vertex/网关流空闲失败也已修复。使用这些路径的用户强烈建议升级；不需要安全修复的稳定纯本地用户可以推迟。

发生了什么变化

  • 现在默认启用子代理分叉：subagent_type: "fork" 子代理继承完整的对话和提示缓存，并且默认情况下在后台运行的交互式会话中生成非队友代理
  • 在提示中输入 @ 以提及另一个 Claude 会话的名称；然后 Claude 使用 SendMessage 直接到达该会话
  • SendMessage 现在提供与一次实时会话完全匹配的裸名，而不是首先要求与裁判确认
  • 一台计算机上的交互式会话现在保留唯一的名称：启动会话或将会话重命名为另一个实时会话已使用的名称，为其提供 name-word-word 变体并告诉您
  • 添加了“对话到期”和“来自其他会话的消息”的 /config 行（跨会话入站接受/保留/拒绝）
  • 添加了 GitLab 代币系列（glrt-、gloas-、glptt-、glagent-、glimt-、glsoat-、glcbt-、glft-、glffct-）的秘密编辑以及可路由 glpat-/gldt- 代币的完整编辑； glab CLI 配置存储获得与 gh 相同的沙箱和凭证路径保护
  • 添加了对插件市场的 GitLab 支持：裸 gitlab.com 存储库 URL（包括嵌套子组）现在像 github.com URL 一样克隆，并且克隆身份验证失败提示命名您的实际 git 主机
  • 设置：additionalMarketplaces 和 allowedMarketplaces 现在被接受为 extraKnownMarketplaces 和 strictKnownMarketplaces 的更友好的别名
  • 企业策略：当 CLI 将其分类为 git 克隆时，裸存储库 URL 的 url 类型 blockedMarketplaces 条目会持续阻止该 URL
  • 网关：desktop: 覆盖现在接受每个已发布的桌面设置（是 11 个手动列出的键），并在启动时根据桌面自己的架构进行验证；未知或无效的密钥无法启动
  • 网关：空的 managed.policies[].match.groups/admin.admin_groups 条目和格式错误的 email_domain 值（空或包含 @、空格或逗号）现在在启动时失败，而不是默默地匹配任何人或授予管理员访问权限
  • 《神鬼寓言 5》再次作为 /advisor 的顾问提供给具有《神鬼寓言》访问权限的组织，并通过 /model fable 设置使用积分同意
  • 修复了 PowerShell 权限绕过问题，其中变量写入参数可能会静默覆盖 $PSDefaultParameterValues 并重定向后续命令的文件访问
  • 修复了 Windows 权限绕过问题，其中 Git Bash 遵循 Cygwin 风格的符号链接，路径验证将其视为常规文件；现在通过它们写入需要许可批准
  • 修复了从父目录继承 trust 的嵌套 git 存储库；每个存储库现在都需要自己的 trust 确认
  • 修复了当服务器无法应答或向协议版本探测发送格式错误的答复时，MCP 连接在整个 30 秒连接超时期间挂起的问题
  • 修复了由云会话内的桥托管的远程控制会话继承该会话的记录或凭据
  • 修复了每次恢复本地会话时从 Claude Desktop 或 IDE 启动的远程控制会话显示为新的 claude.ai 会话的问题；他们现在重新连接到现有的
  • 修复了空闲时新连接的 clients 无法访问远程控制会话的问题
  • 修复了会话工作程序重新启动时远程控制桥会话不会恢复对话历史记录的问题
  • 远程控制：恢复已从 claude.ai 删除会话的对话，或者应用程序现在开始替换，而不是失败并显示有关您登录的消息（在 v2.1.227 中回归）
  • 修复了当托管设置加载失败时，云网关 /login 在“按 Enter 继续”后静默退出或留下无响应终端的问题；原因现已显示
  • 修复了当语音服务拒绝连接时本机版本上的语音模式卡在“正在监听…”的情况；现在立即显示拒绝
  • 修复了需要重新启动的 mTLS client 证书轮换；克劳德代码现在会在连接错误时自动重新加载轮换的证书和密钥
  • 修复了用于构建请求 URL 的格式错误的 AWS 或 Vertex 区域值；他们现在回退到默认区域
  • 修复了导致请求失败而不是在 Bedrock、Vertex 和网关部署上恢复的流空闲超时错误
  • 修复了包含截断文本的内容大小覆盖导致一列太宽，以及开始截断文本折叠为省略号的问题
  • 修复了长 shell 命令或代理描述预览在表情符号中间被切断的杂乱字符
  • 修复了由于并发写入 known_marketplaces.json 可能导致默默注销插件市场的启动竞赛
  • 修复了在重新启动后幸存的工作正在运行时 /update 和 /tui 拒绝重新启动的问题
  • 修复了建议 SDK 和远程会话中不可用斜线命令的使用限制指南
  • 修复了交互式 --advisor fable 启动的同意消息，该消息告诉您在刚刚退出的交互式会话中运行 /model fable
  • 改进的全屏流媒体：长时间会话保持响应，因为整个对话不再在每次更新时重新标准化
  • 改进了托管设置批准对话框：显示端点 URL，对仅遥测更改使用更清晰的措辞，跳过例行 OpenTelemetry 选项，并需要批准服务器管理的沙箱二进制覆盖（sandbox.bwrapPath、sandbox.socatPath、sandbox.ripgrep）
  • /feedback 和 /bug 现在在克劳德响应时被调用时立即打开，而不是等待回合结束
  • /plugin install plugin@marketplace 现在首先刷新市场，因此新发布的插件无需手动市场更新即可安装
  • /code-review 在高、xhigh 和最大努力下现在像其他级别一样在后台代理中运行
  • 粘贴和 clipboard 图像的读取不会阻塞事件循环
  • 远程控制现在在网络故障后保持重新连接约 30 分钟，并且在一个小时内出现几个故障后不再断开
  • 远程控制：恢复对话不再默默地将远程控制从仍然拥有远程控制的同一台机器上的另一个克劳德代码中夺走；在那里运行 /remote-control 来移动它
  • 更新的代理面板：完成的子代理立即隐藏，并带有 /tasks 页脚提示，并且“↓ N more”溢出指示器向左移动以提高可见性
  • 远程控制：终端现在会显示会话是否被另一台设备接管、从另一应用程序结束或删除，并停止建议重新连接以撤消会话
  • Bash 输入重定向 (< file) 现在像所有平台上的参数拼写一样进行权限检查
  • 缩短了恢复已完成的后台代理时显示的消息
  • Cowork 会话不再内联外部 @-从用户范围内存文件导入
  • 强化了共享 /tmp 上自动生成的跨会话消息套接字目录：现在拒绝而不是使用预先植入的符号链接或其他用户的目录
  • 强化了 Linux 文件系统沙箱，防止受保护路径绕过
  • 将 sandbox.ripgrep 更改为仅从用户、托管和 --settings 设置中启用；项目设置无法再覆盖沙箱的 ripgrep 二进制文件
  • 删除了建议您创建自定义子代理的启动提示，以及 /powerup 游览中的匹配轻推
