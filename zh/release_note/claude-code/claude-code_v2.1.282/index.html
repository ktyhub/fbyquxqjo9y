claude-code v2.1.282

修订 发布时间2026年9月24日 来源anthropics/claude-code 英文原文

变更架构图

亮点

  • 会话可靠性 — 修复了恢复/续聊损坏、扩展思考丢失、无法解密的网页搜索历史、无效的 redacted_thinking 块以及压缩回退问题。恢复大会会话的速度也更快。凡是遇到续聊坏掉的人都应升级。
  • 安全与设置 — 托管限制现在能在嵌套值无效时依然生效，忽略项目/本地设置中开启遥测的变量，并正确执行沙箱与权限规则。迁移： 项目级遥测覆盖（如 CLAUDE_CODE_ENABLE_TELEMETRY 和 OTEL_LOG_*）不再生效；请把它们移到托管设置。
  • 技能命名空间变更 — 破坏性变更： anthropic-skills 和 claude-ai 文件夹、命令、工作流及允许规则不再覆盖插件或同名 MCP 服务器。重命名受影响的 MCP 服务器以恢复列出的技能/提示。
  • 模型与自动模式行为 — 在直连 Anthropic API 且关闭遥测的情况下，自动模式现在默认使用服务端分类器；设置 CLAUDE_CODE_AUTO_MODE_SERVER=0 可退出。若干 Fable 与安全开关失效问题也已修复。
  • UI 与终端修复 — 新增 maxProseWidth，改进 VS Code 流式输出与滚动条，并修复粘贴、全屏、历史记录以及大量 vim 模式错误。终端/Vim 用户值得升级；不受这些领域影响的用户可以跳过，除非会话修复对你重要。

发生了什么变化

  • 添加了 maxProseWidth 设置，该设置限制宽终端中克劳德散文的宽度，而表格和代码块保持全宽度
  • 添加了启动通知以及 /status 和 claude doctor 条目，列出了项目设置文件中被忽略或关闭遥测的遥测变量
  • 添加了 allowClaudeInChromeWithManagedMcp 托管设置，让 claude --chrome 与专属 managed-mcp.json 一起运行； Chrome 被阻止时显示的错误现在将其命名
  • 将 store.readiness_grace_seconds 添加到 Claude 应用程序网关，以便 /readyz 可以在短暂的 Postgres 中断（例如数据库故障转移）中保持准备状态
  • 全屏模式下/feedback草稿列表添加滚动条；当鼠标悬停在列表上时它会出现
  • 修复了历史记录包含 API 无法解密的 Web 搜索结果的对话中每个请求失败并出现 400 错误的问题（例如，通过第三方网关应答的回合）
  • 修复了更多继续或恢复会话（--continue、--resume）以更改的形式重新发送早期消息的情况，这可能使 API 放弃克劳德早期的推理
  • 修正了当克劳德工作时使用 /model、/rename、/artifacts 或另一个立即斜杠命令时，早期的扩展思维被丢弃的问题
  • 修复了当使用 --tools 列表重新启动时，继续或恢复的对话会丢失早期的扩展思维，该列表遗漏了对话中先前提供的内置工具
  • 修复了每次回合都会失败并出现“redacted_thinking 块中无效的 data”API 错误的问题；克劳德·科德现在会放弃对话的思维障碍并重试一次
  • 修复了汇总请求被拒绝时压缩失败的问题；它现在重试后备模型
  • 修复了在思考关闭且努力高于高的会话中进行安全相关模型切换后失败的转弯（“思考关闭时无法使用努力‘xhigh’”）
  • 修复了 SDK 托管会话（例如 Claude Desktop）中未答复的《神鬼寓言》使用积分提示切换模型的问题；回合现在结束，远程控制 clients 现在看到模型切换通知
  • 修复了带有完整《神鬼寓言》模型 ID 的 /model 在计划需要尚未打开的使用积分时停止在 API 错误，而不是打开使用积分提示的问题
  • 修复了在刷新过程中关闭或终止其他进程后，请求失败长达一分钟并出现“另一个克劳德代码进程正在刷新它”登录错误的问题
  • 修复了当另一个 Claude Code 窗口刷新登录（常见于多个 VS Code 窗口）时启动的会话，而不重试其组织策略获取的问题
  • 修复了在启动时通过通过 .. 或 /.vol 样式内核路径到达 macOS /Network 的存储库符号链接读取的 CLAUDE.md 和规则，或者列出了指向 macOS /home 的规则链接
  • 修复了 Bash 权限规则，其中设置文件中的中间模式 :* 被跳过，而 --allowedTools 则遵守它们；他们现在可以从各个来源工作，并有关于他们如何匹配的启动警告
  • 修复了在远程会话的工作人员重新启动时运行两次的恢复权限提示下批准的命令
  • 修复了托管设置忽略布尔锁定键（例如 disableClaudeAiConnectors 或 allowManagedPermissionRulesOnly）的错误输入值的问题；现在锁已应用，并且启动程序命名了密钥
  • 修复了当一个嵌套值无效时，托管的 permissions、autoMode、worktree 和 attribution 设置被完全忽略的问题；该块的其余部分现在仍然适用
  • 修复了存储库、用户和 --add-dir 技能、命令和技能目录插件清单，通过托管 allowManagedPermissionRulesOnly 下的 allowed-tools 预先批准自己的工具
  • 修复了 Amazon Bedrock 和 Bedrock Mantle 上不显示请求 ID 的安全防护阻止消息；阻止消息现在还显示消息 ID
  • Vertex AI：修复了无法为 Claude Code 尚未识别的模型（例如新发布的模型）提供网络搜索的问题
  • 修复了 Bash 和 PowerShell 将完整磁盘配额隐藏在“退出代码 1”后面并将大型输出文件保留在临时文件中的问题
  • 修复了当同一调用中的其他参数也无效时，工具输入验证错误仅命名未知、缺失或输入错误的参数；现在也列出了这些
  • 修复了在会话中重置终端的括号粘贴模式后逐行提交粘贴的多行文本的问题
  • 修复了在带有 SessionStart 挂钩的项目中启动时提示的示例文本闪烁和消失的问题
  • 修复了以全屏模式启动时第一帧之前闪烁的空白屏幕
  • 修复了屏幕变短但仍比终端高后非全屏渲染器中乱码、错位的行，例如在 shell 命令流输出时删除提示行
  • 修复了当重绘行的 CJK 字符或表情符号换行到下一行时，差异最后一列中留下的陈旧字符
  • 修复了当提示包含选项卡时，光标在从历史记录中调用的提示结束之前着陆的问题
  • 修复了在将其作为换行符发送的终端上显示 ctrl+enter 的立即发送提示（1.25 之前的 Windows 终端）；现在显示 ctrl+x ctrl+s
  • 修复了 claude remote-control --debug 因“未知参数：—debug”而失败的问题，尽管远程控制自身的资格错误表明要使用 --debug 运行
  • 修复了 /install-github-app 说“已取消”，然后仍然推送分支并保存 API 密钥的问题；现在离开将停止剩余步骤并报告已完成的操作
  • 修复了在保存过程中取消后，Bedrock、Vertex 和其他第三方提供商仍然保存报告文件的 /feedback、/bug 和 /share
  • 修复了插件卸载报告成功并在其设置文件仍然启用或无法读取时删除插件的已保存选项的问题；它现在停止并命名该文件
  • 修复了插件卸载在删除后无法读取已安装插件列表时删除插件保存的选项和秘密的问题；它们现在被保留，卸载也是如此
  • 修复了在 /skills 中的 / 之后立即键入的按键会移动技能列表而不是到达搜索框
  • 修复了打字时终端光标从 /skills 搜索框跳转到技能列表的问题，这可能会隐藏插入符号并将 IME 输入放在错误的位置
  • 修复了带有滚动条的列表，例如 /skills 和 /mcp，在全屏模式之外会缩小两列，滚动条永远不会出现
  • 修复了代理面板页脚用长反弹键包裹在两行上的问题，并且其“Esc 折叠”提示忽略了反弹折叠键
  • 修复了当 keybindings.json 中取消绑定停止所有代理快捷方式时，/tasks 对话框页脚中的双 · 分隔符
  • 修复了当 Claude 为版本指定的标签长度​​超过 60 个字符时工件发布失败的问题；标签现已缩短
  • 修复了屏幕阅读器模式、引用列表和超长列表，直接或在引用内删除打开列表项的代码块顶部的空白行
  • 修复了 PDF 页面读取错误消息：带有重音或非拉丁字符的路径现在可读，并且名为“密码”或“无效”的文件夹不再使错误名称成为错误原因
  • 修复了 vim 模式 >> 缩进空行、r 的计数长于行更改文本、2J 加入一行太多以及最后一行的计数（2dd、2>>）移动或删除它

  • 修复了 vim 模式下光标超出从历史记录中调用的提示末尾或在正常模式下从队列中拉回的问题，因此 x 不执行任何操作
  • 缩短了恢复大型会话的时间，包括从未压缩过的会话
  • 改进了当会话因无法读取其转录文件 (EBADF) 而无法恢复时在 Windows 上显示的错误：它现在列出了可能的原因以及要尝试的操作
  • 改进了克劳德桌面未知型号错误，建议切换到不同型号

  • 改进的 /artifacts：标题排列在一列中，细节被整个删除而不是在单词中间剪切，并且列表支持 PgUp/PgDn、Home/End、鼠标滚轮和 clicks
  • 更新了 claude-api 技能：输出前拒绝计费现在链接到拒绝如何计费文档、中流拒绝按正常费率计费以及输出前拒绝计入速率限制

  • 更改了项目和本地设置以忽略打开导出、设置其端点或捕获内容的 OpenTelemetry 变量，例如 CLAUDE_CODE_ENABLE_TELEMETRY 和 OTEL_LOG_*

  • 更改了 anthropic-skills 或 claude-ai 命名空间中的技能文件夹、命令文件和工作流程命令，不再加载；如此命名的插件仍然会加载，但会产生与同步技能相关的名称
  • 更改了以 anthropic-skills 或 claude-ai 名称配置的 MCP 服务器，以不列出技能或提示（他们的工具仍然有效）；重命名 MCP 配置中的服务器以再次列出它们
  • 将 /effort 中的 ultracode 视觉效果和提示输入更改为简单样式（无波纹、边框华丽或关键字闪烁），并删除了动态工作流程旋转提示
