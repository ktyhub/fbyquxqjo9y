claude-code v2.1.212

claude-code v2.1.212

这个项目是干啥的：Anthropic 官方的命令行 AI 编程助手，在终端里让 Claude 直接帮你读写代码、改项目、跑命令。给习惯用命令行的开发者用。

变更架构图

亮点

  • /fork 语义变更（破坏性） — /fork 现在会把你的对话复制到新的后台会话，并在 claude agents 中有自己的一行，而不是在会话内启动子 agent；旧行为移至 /subtask。任何依赖 /fork 快速创建会话内子任务的用户必须改用 /subtask。相关改动：agent 视图中的 /resume 现在打开过往会话选择器（包括从列表中删除的会话），并将所选会话作为后台会话恢复，未命名 fork 会以你的提示词命名。
  • 新的失控循环防护 — 会话级 WebSearch 上限（默认 200，CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION）和子 agent 生成上限（默认 200，CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION，由 /clear 重置）用于阻止 agent 循环；超过 2 分钟的 MCP 调用会自动转入后台（CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS，可调或禁用）。重度 agentic 用户应在升级前调整这些设置，否则长会话可能意外停止；轻度用户不受影响。
  • 权限与沙箱修复——应为此升级 — Plan 模式不再静默运行修改文件的 Bash（touch、rm）而不提示或不触发 SDK canUseTool 回调；worktree 创建不再跟随仓库提交的 .claude/worktrees 符号链接（可能写文件到仓库外）；print/SDK 模式下的 SIGTERM 现在会中止回合、杀死进程树并以 143 退出，而不是留下孤儿进程。使用共享或不可信仓库的团队应优先升级此版本。
  • 企业与 SDK 行为变化 — forceLoginMethod 现在对 VS Code 扩展、SDK、setup-token 和 install-github-app 登录也强制生效，而不只是终端；Task 工具的 mode 参数已弃用并被忽略，子 agent 继承父级权限模式；托管会话忽略仓库配置的 mTLS 证书、CA 包和 OAuth 作用域并给出警告；set_model 控制请求现在在 headless/SDK 会话的回合中途生效；continue:false 的 hook 停止不再被丢弃。管理员和 SDK 集成者应在部署前审计配置。
  • 可靠性提升；谁可跳过 — Web 搜索/获取现在会以有界退避重试 529 和限流请求，且不再把字面量 “API Error” 文本作为结果返回；图片密集型对话避免误报 “Request too large”；提示缓存可在 Bedrock/Vertex/自定义 base URL 后工作；OpenTelemetry 修复涵盖 411/400 分块编码拒绝以及设置 TRACEPARENT 时缺失 trace_id/span_id。适合 agent 重度、SDK 和可观测性用户升级；随意交互用户可以放心等待。这是实质性版本，不是空操作、重新打标签或仅元数据变更。

发生了什么变化

  • /fork 现在将您的对话复制到新的后台会话中（在 claude agents 中它自己的行），同时您继续工作；它过去启动的会话中子代理现在是 /subtask
  • 新增 claude auto-mode reset 恢复默认自动模式配置，并有确认提示（通过 --yes 跳过）
  • 添加了对 WebSearch 工具调用的会话范围限制（默认 200，可通过 CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION 调整）以阻止失控的搜索循环
  • 添加了子代理生成的每会话上限（默认 200，用 CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION 覆盖）以阻止失控的委托循环； /clear 重置预算
  • 运行时间超过 2 分钟的 MCP 工具调用现在会自动移至后台，以便会话保持可用；使用 CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS 配置阈值或禁用
  • 在代理视图中键入 /resume 现在会打开过去会话的选择器（包括从列表中删除的会话）并恢复您的选择作为后台会话
  • 修复了计划模式自动运行文件修改 Bash 命令（例如 touch、rm），没有权限提示或 SDK canUseTool 回调
  • 修复了在 .claude/worktrees 处存储库提交的符号链接之后创建工作树的问题，这可能会在存储库外部创建文件
  • 修复了当工具失败或完成中流时 continue:false 挂钩的停止被删除，以及挂钩基础设施错误被错误报告为用户拒绝的问题
  • 修复了在 print/SDK 模式下运行 Bash 工具期间孤立命令的进程树期间的 SIGTERM； CLI 现在中止转弯，杀死树，并退出 143
  • 修复了当组策略阻止 PowerShell 5.1 时，/background 和 claude --bg 在 Windows 上失败并显示“EUNKNOWN：未知错误，uv_spawn”；守护进程现在更喜欢 PowerShell 7
  • 修复了当路径自动完成弹出窗口打开时 shell 模式 (!) 不执行包含文件路径的命令
  • 修复了当表情符号中长拒绝原因被截断时，自动模式拒绝通知会呈现损坏的字符
  • 修复了 Ctrl+J 不会在具有扩展键报告的终端上的代理视图调度输入中插入换行符的问题，并在 ? 帮助叠加层中显示换行符快捷方式
  • 修复了 /ultrareview 拒绝 PR 引用（例如 #123、PR 123）和粘贴 PR URL 的问题；错误提示现在命名您实际输入的命令
  • 修复了 /ultrareview <branch> 在远程存在时不从原点获取分支的问题；现在它会建议拼写错误时最接近的分支名称
  • 修复了 /ultrareview 在 /clear 之后的新对话中跳过账单确认的问题
  • 修复了 Claude Desktop 上 /ultrareview 的“不是 git 存储库”错误，现在建议使用项目的存储库文件夹而不是终端命令
  • 修复了当存储库设置配置 mTLS 证书、额外 CA 捆绑包或 OAuth 范围时托管（主机管理）会话在启动时失败的问题；现在将忽略这些传输设置并显示警告
  • 修复了在恢复会话之前编辑已使用偏移/限制读取的文件时出现的虚假“文件尚未读取”错误
  • 修复了在打印/SDK 模式下恢复与 --continue/--resume 的会话后，ExitWorktree 失败并显示“无活动 EnterWorktree 会话”的问题
  • 修复了在运行中加入会话的远程控制 clients 的工作流程代理网格保持为空的问题
  • 修复了流模式控制请求在其处理程序完成之前被标记为完成的问题，这可能会在会话重新启动时丢失请求
  • 修复了使用 /fork 创建的后台会话在状态写入失败后失去实时父保护的问题
  • 修复了从代理视图重新打开停止的后台会话失败的问题 - 现在它可以恢复会话，或者显示为什么不能恢复并让您强制重新启动
  • 修复了代理团队：当团队初始化在会话中重新运行时，停止的队友可能会向领导者发送重复的空闲通知
  • 修复了当文件路径较长时计划批准对话框页脚将“ctrl+g 在 <编辑器> 中编辑”分开的问题
  • 修复了在全屏模式下组合宽度+高度终端调整大小后欢迎横幅保持其旧面板宽度的问题
  • 修复了差异预览在狭窄布局中丢失行号和 +/- 标记的问题
  • 修复了@-提及在读取部分文件后不附加任何内容、针对错误市场的插件卸载以及退出代码 143 上的错误“命令超时”
  • 修复了 Azure Monitor 和其他不接受分块传输编码的端点以 411/400 拒绝 OpenTelemetry HTTP 导出的问题
  • 修复了当 TRACEPARENT 设置为 SDK/无头模式时 OTLP 事件日志记录丢失 trace_id/span_id
  • 修复了与许多图像的对话因“请求太大”错误而错误失败的问题，并改进了错误消息以解释实际原因
  • 修复了当 API 过载时 Web 搜索和 Web 获取返回“API 错误”文本作为搜索结果或页面内容的问题
  • 通过重试 529 错误和具有有限退避的速率限制请求，提高了 Web 搜索和 Web 获取的可靠性
  • 改进的提示缓存：对话中系统块现在在 LLM 网关和自定义基本 URL（Bedrock、Vertex、1P）后面工作
  • 改进的后台代理附加：冷附加现在在会话启动时立即显示格式化的记录，而不是空白等待
  • 减少代理间消息传递中的令牌使用：SendMessage 正文不再复制到重播历史记录和工具结果中
  • 更改了 /fork，以便在会话没有标题时在提示后命名副本，以便在代理视图中可以识别该行
  • 更改了裸 /btw 以重新打开最近一次交流中的附带问题面板，以便您可以浏览之前的答案
  • 当后台代理完成但不需要您输入任何内容时，将 ← 页脚提示更改为脉冲 N done 片刻
  • 弃用了任务工具的 mode 参数（现已忽略）；子代理默认继承父会话的权限模式
  • 更改了 Enterprise forceLoginMethod，以强制 VS Code 扩展、SDK、setup-token 和 install-github-app 登录，而不仅仅是终端
  • 更改了会话记录以记录每条助理消息的推理努力水平
  • 更改了无头/SDK 会话以在回合中应用 set_model 控制请求；下一个模型往返使用新模型而不是等待下一个转弯
  • 更改了代理视图/claude agents --json：等待沙箱、MCP 输入或托管设置提示的会话现在显示为“需要输入”而不是“正在工作”
  • 将身份验证状态面板标题从“云身份验证”更新为“身份验证”
  • 更正了早期的 release note (2.1.200)：通过 3.6 系列的 tmux 缺乏同步输出；自动检测支持的较新 tmux
