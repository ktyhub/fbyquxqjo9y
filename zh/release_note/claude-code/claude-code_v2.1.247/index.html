claude-code v2.1.247

修订 发布时间2026年8月26日 来源anthropics/claude-code 英文原文

变更架构图

亮点

  • 反馈、成本工具与组织定制 — SendFeedback 可以起草会话反馈报告，供在 /feedback 发送前审阅（用 feedbackDrafts 禁用）。/claude-api cost-optimize 分析 API 支出，并指导对缓存、token 卫生、批处理、努力程度和模型选择进行有依据的改动。/claude-api 新增 Admin API 覆盖，spinnerTipsOverride 支持通过 {id, text, cooldownSessions, priority}、tipsFile 和 label 定义组织提示。
  • 更有韧性的子 agent 与后台/云会话 — 子 agent 首次调用模型返回 404 时现在使用会话的回退模型链并返回详细诊断。过大的 hook/后台输出不再溢出对话，不可写的输出文件不再导致内存无限增长。云会话会报告容器重启期间丢失的工作，死亡的后台主机会快速失败，而不是永远显示 opening…。依赖子 agent、hook 或云/后台会话的用户应升级。
  • 终端与配置安全 — Bash 清理不再删除由 dotfile 管理的 ~/.claude/settings.json 符号链接，/terminal-setup 会合并而非覆盖 Zed 的 keymap.json，/install-github-app 通过 SSH 时会准确报告复制/打开失败。修复还包括拆分鼠标报告、非拉丁 Ctrl 快捷键以及陈旧的历史/菜单导航。终端重度用户——尤其是 nix/home-manager、stow 和 Zed 用户——有具体升级理由。
  • 默认行为变更 — 1M 上下文下的 Sonnet 5 现在在约 967K token 处自动压缩，而非约 934K。跨会话消息折叠为单行预览，用 Ctrl+O 展开正文。指向网络/自动挂载路径或包含不安全控制/不可见字符的终端 markdown 链接渲染为纯文本。这些变更未记录迁移步骤，但长上下文和跨会话用户应调整预期。
  • 企业加固与启动风险 — 包含控制/不可见字符的 marketplace 名称被拒绝，渲染的 marketplace 文本做了转义安全处理，即使禁用遥测也会报告失败的 MCP 连接，且在强制网关/自定义 OAuth 配置下分析从启动起保持关闭。可能带来破坏：组织登录强制现在在托管设置无法读取时立即退出，即使存在 Windows 主机/用户注册表设置。管理员应在部署前验证设置可达；否则不受这些领域影响的稳定本地工作流可以跳过。

发生了什么变化

  • 添加了SendFeedback工具：当会话中出现问题时，克劳德可以起草反馈报告供您查看并从/feedback发送（通过feedbackDrafts设置关闭）
  • 添加了 {id, text, cooldownSessions, priority} 条目、tipsFile 和 label 到 spinnerTipsOverride，因此组织可以将自己的提示与内置提示一起轮换
  • 添加了有关 Bash 权限提示指向自动模式的提示，并带有一键“是，并切换到自动模式”选项
  • 添加了 /claude-api cost-optimize，以分析现有项目的 Claude API 支出，并通过成本杠杆（缓存、代币卫生、批次、工作量、模型选择）一次测量一个变化进行工作
  • 更新了 /claude-api 技能，包括管理员 API 覆盖范围（组织成员、邀请、工作区、API 密钥、速率限制报告、工作负载身份联合、CMEK）
  • 修复了快速箭头键+输入序列作用于您在历史搜索中导航到的上一行、/config、/mcp、/skills、后台任务和/model
  • 修复了子代理在首次调用模型 404 上死亡的问题：它们现在使用会话的后备模型链，并且返回给父级的错误包括错误类型、状态、请求 ID 和模型
  • 修复了打印兆字节错误输出的挂钩或后台代理，能够溢出对话并将会话楔入“提示太长”
  • 修复了 Ctrl 键盘快捷键在 kitty 协议终端中的非拉丁语（例如西里尔语）键盘布局下不触发的问题
  • 修复了当鼠标报告到达时将 <35;150;7M 等文本插入到提示中的问题，在转义前缀之后立即拆分读取
  • 修复了 Bash 沙箱的命令后清理，当它被重新指向沙箱的可写区域之外时，会删除点文件管理的 ~/.claude/settings.json 符号链接（nix/home-manager，stow）
  • 修复了 /terminal-setup 覆盖整个 Zed keymap.json 而不是合并到其键绑定中的问题
  • 修复了 /rename 无法更新会话注册表时默默确认的问题；现在它说其他会话可能仍显示旧名称
  • 修复了以 --agent 开始的会话中的 /compact 和“从此处总结”，在默认系统提示下而不是对话自己的提示下进行总结
  • 修复了终端主机进程死亡后，claude agents 中永远显示“正在打开…”的后台会话；该行现在会在几秒钟内失败并显示原因，然后按 Enter 重新启动它
  • 修复了当钩子或后台任务的输出文件无法写入时内存无限增长的问题；该文件现在记录了输出丢失的位置
  • 修复了 SSH 上的 /install-github-app：复制快捷方式现在显示如何复制登录 URL，而不是始终声明成功，并且当没有浏览器可以打开时，该 URL 会立即出现
  • 修复了从前台继承的 shell 命令，记录内部错误或在后台会话中完成时显示误导性的 [exited with code -1] 行
  • 修复了无版本市场插件的实时缓存目录被删除并在第二范围安装上重新创建的问题，这可能会中断使用它的正在运行的会话
  • 修复了以 /remote-control 启动的远程控制会话不向连接的 clients 报告工作树差异的问题
  • 修复了在 Claude 代码启动之前报告 running 的自托管运行器会话，这可能会触发来自 Claude 桌面应用程序的过早“Claude 正在等待您的输入”通知
  • 修复了当托管设置配置 Claude 应用程序网关登录且 Anthropic 端点无法访问时，首次运行设置会退出并显示“无法连接到 Anthropic 服务”的问题
  • 修复了当您在发送消息后立即切换模式时，云会话（网络、桌面和移动应用程序上的克劳德代码）有时会显示先前的权限模式
  • 修复了当会话的容器在轮次之间重新启动而后台代理、shell 或监视器仍在运行时，云会话会变得静默的问题 — 恢复的会话现在会报告丢失的工作
  • 改进的插件市场强化：包含控制或不可见字符的名称将被拒绝，/plugin 和 claude plugin 输出中市场提供的文本是转义安全的
  • 改进了 Bedrock、Vertex 和 Foundry 会话（以及任何禁用遥测功能的会话）：现在，当配置的 MCP 服务器无法连接时，克劳德会被告知，而不是断定其工具不存在
  • 将 Sonnet 5 的默认自动压缩窗口更改为完整的 1M 上下文，因此 1M 窗口上的会话现在自动压缩为约 967K 令牌，而不是约 934K
  • 将跨会话对等消息默认折叠为单行 Message from @<sender>: <first line> 预览； Ctrl+O 展开全身
  • 更改了渲染 Markdown 中的终端超链接：指向网络或自动安装程序路径、包含控制字符或带有不可见字符的引导的链接目标现在呈现为纯文本
  • 更改了提示页脚 PR 徽章，以在最后一次检查不到一分钟时跳过终端重新聚焦时的 GitHub 重新检查
  • 更改了分析以阻止启动，不仅是在登录后，当托管设置强制网关登录或配置自定义 OAuth 部署时
  • 更改了 Claude 应用程序网关登录请求以识别 Claude 代码（surface=claude_code 设备授权参数和 claude-code/<version> 用户代理）
  • 将组织登录强制更改为在无法读取管理员的托管设置时在启动时退出，即使存在主机提供的或每用户的 Windows 注册表设置
