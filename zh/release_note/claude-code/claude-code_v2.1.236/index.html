claude-code v2.1.236

修订 发布时间2026年8月19日 来源anthropics/claude-code 英文原文

发生了什么变化

  • 添加了 ANTHROPIC_DEFAULT_MODEL 环境变量：设置新会话启动的模型，而 /model 选择仍然覆盖它并在重新启动后持续存在（与 ANTHROPIC_MODEL 不同）
  • 将 notify_when_idle 添加到跨会话 SendMessage：要求该计算机上的另一个 Claude Code 会话在下次空闲时发送一个通知 - 选择加入、一次性、无轮询（macOS 和 Linux）
  • 沙箱：在 macOS 上，通配符读取拒绝规则（例如 **/.env）现在在允许的读取区域内优先，覆盖匹配的目录内容，并且无法通过重命名被拒绝的文件来绕过
  • 修复了在删除会话切换到的目录后 clipboard 复制、后台管理、后台会话和本地 MCP 日志中断的问题（自 2.1.229 起）
  • 修复了单次启动失败后全屏渲染器永久失败的问题：它现在回退到经典渲染器，而不是在每次后续启动时退出
  • 修复了 /model 选择器呈现比终端高的问题：它现在仅显示适合窗口的模型，其余模型可通过滚动到达
  • 修复了当格式错误的结束标记将消息文本留在摘要字段内时 SendMessage 呼叫被拒绝的问题
  • 修复了子进程无法启动时未处理的承诺拒绝，例如禁用 Windows 互操作的 WSL 上的 powershell.exe（2.1.234 中的回归）
  • 修复了全屏模式有时在终端调整大小后的下一次更新之前不显示新发送的消息的问题
  • 修复了在全屏模式下清除多行提示后可能保留在提示上方的空白带，以及在全屏模式下调整终端大小后无法重新绘制窗格的问题
  • 修复了托管设置批准提示有时在启动时不会出现，但仍然捕获第一个按键作为批准
  • 修复了 tmux 中跳转的终端选项卡标题（iTerm tmux 集成）：现在仅在文本更改时写入标题，而不是每 960 毫秒动画一次
  • 修复了云环境列表返回为空或格式错误时出现的不清楚错误
  • 修复了《神鬼寓言 5》首次使用积分提示在使用远程控制时 60 秒后自动选择后备模型且无应答的问题
  • 修复了当 ~/.claude.json 中缓存的访客通行证奖励格式错误时，旋转器提示永远不会出现，并且重复出现后台错误的问题
  • 修复了 SDK/VS Code 会话中的技能热重载，在删除会话的工作目录后，每次技能更改都会引发错误 (2.1.229+)
  • 修复了在空闲、退出或启动超时时释放的自托管运行器会话偶尔会在会话后挂钩完成之前在另一个运行器上恢复的问题
  • 修复了 Clawd 吉祥物的眼睛和脚在 iTerm2 中以某些字体大小渲染不均匀的问题
  • 修复了偶尔失控的会话回顾：回顾文本（自动和 /recap）现在上限为 400 个字符，在单词边界处剪切
  • 改进的启动性能：会话计数器现在写入后台
  • 改进的自动模式：当自动模式处于活动状态时，Monitor 允许规则现在被搁置，因此监视器命令的审查方式与 Bash 命令相同
  • 改进了 Bedrock、Vertex AI 和 Foundry 上的自动模式，以及禁用遥测时：分类器现在使用与 Claude API 上相同的默认值，包括严重性评分分类
  • 改进的自动模式：git 状态检查不再被存储库的 status.showUntrackedFiles=no 设置欺骗以报告干净的树
  • 更改了 /model 选择器以仅突出显示最新型号的名称，因此突出显示标记新版本而不是列表的任意子集
  • /goal：目标位于长时间运行的后台工作后面的空闲会话现在会在 30 分钟（然后是 1 小时、2 小时）后自动签入，而不是等待您返回
  • /usage 现在显示团队和企业成员的使用积分支出行，并在支出之前显示 0% 的上限行
  • 打印/SDK 模式下的 SIGTERM 在退出前不再记录中断的转弯或合成工具拒绝；正在运行的命令仍然终止，进程仍然退出，代码为 143
  • 在斜杠命令拼写错误或此会话中不可用的命令上按 Enter 键现在会报告它，而不是运行最接近的模糊匹配；前缀和别名仍然运行
  • 当 CLI 退出或其终端关闭时，远程控制现在会在几秒钟内将会话标记为离线
  • 一旦 rapid 突发超出会话收件箱接受的内容，SendMessage 现在会拒绝向该会话发送更多消息，而不是在它们被丢弃时报告它们已发送
  • 将提示边框上的会话标题芯片与页脚的右边缘对齐
  • 右对齐的页脚项目（目标指示器、会话状态、后台代理状态）和截断的通知现在与提示区域的其余部分共享一致的右边距
  • [VSCode] 添加了对文字记录的屏幕阅读器支持：回复、权限请求、错误和状态更改的实时公告，以及每回合标题导航
