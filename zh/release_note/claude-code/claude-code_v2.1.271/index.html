claude-code v2.1.271

修订 发布时间2026年9月14日 来源anthropics/claude-code 英文原文

claude-code v2.1.271

发生了什么变化

  • 在 Claude Code 远程会话（云和自托管运行器）中添加了快速模式：主机的快速模式设置或在会话中键入的 /fast 适用于您的组织允许的情况
  • 在全屏模式下向 /config 面板添加了鼠标支持：滚轮滚动设置列表，设置值上的 click 会更改它，并且指针下方的行会突出显示
  • 添加了 claude self-hosted-runner --drain-marker-file <path>：当该文件存在于 SIGTERM 消耗时，运行程序将其退出作为主机消耗向服务器报告（仅限遥测）
  • 在带有沙箱的自动模式下将每个命令 allowed_domains 添加到 Bash、PowerShell 和 Monitor：使用它来审查命令所需的主机并单独为其打开；其他主机被拒绝
  • 将 omitClaudeMd 添加到代理 frontmatter 和 --agents JSON，让自定义和插件子代理在没有用户、项目和本地 CLAUDE.md 文件的情况下运行；托管策略文件仍然加载
  • 将 --accept-command <sha256> 添加到 claude plugin install 和 claude plugin update 以准确接受先前 --json 运行显示的命令，而不是 -y
  • 在 modelPricing 托管设置和 Claude 应用程序网关 pricing 块中添加了对高于 1、最多 10 的 multiplier 的支持，以实现标记的内部退款率
  • 添加了一个旋转提示，将 Bedrock、Vertex AI、Foundry 和 LLM 网关用户指向 Claude 桌面应用程序； claude.ai 桌面应用程序提示现在建议 /desktop，它可以下载该应用程序
  • 修复了在切换帐户、组织或 API 密钥后重用缓存的组织策略，以及在凭证在会话中更改时进行每小时检查之前策略不会刷新的问题
  • 修复了当组织策略在启动后完成加载或在会话中更改时，工具和命令列表不会更新的问题
  • 修复了无法读取或解析的企业 managed-mcp.json 被忽略的问题：它现在保持独占 MCP 控制（用户、项目和插件服务器不加载）并在启动时发出警告
  • 修复了通过 ANTHROPIC_UNIX_SOCKET 设置的第三方本地代理获取并拒绝组织策略的问题；它们再次像其他自定义网关一样对待，包括远程控制
  • 修复了在会话工作线程重新启动后应用工作流或代理批准时，云会话拒绝每个子代理工具调用（“updatedInput …失败的架构验证”）
  • 修复了当组织禁用快速模式时 /fast off 回答“快速模式不可用”而不是关闭快速模式的问题
  • 修复了在 API 拒绝快速模式后，CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK 每轮重新发送快速请求开始的会话；拒绝现已成立并说明其原因
  • 修复了 CLAUDE_CODE_RETRY_WATCHDOG 下的快速模式无法开启使用积分限制，或以快速速度重试过载，而不是回落到标准速度的问题
  • 修复了 Bash 权限检查在遵循检查器无法识别的选项时缺少 fmt、column 和类似命令读取的文件的问题
  • 修复了当通配符位于命令模式或选项值中时（例如 grep -v dir/* file），Bash 权限检查会跳过通配符扩展的文件
  • 修复了 Bash 权限检查，以便 shell 变量声明标志不能歪曲正在运行的命令
  • 修复了具有两个目录更改、子 shell 或 cd+git 链的 Bash 命令，在旁路和自动模式下跳过 permissions.blockReadsOutsideWorkingDirectories 下的提示
  • 修复了沙盒命令无法启动后，旧的 .git/config.lock 会在会话的剩余时间内破坏 git checkout -b、git push -u 和 git config (Linux)
  • 修复了在系统文件事件服务饱和的 macOS 计算机上在会话之外进行的设置文件更改未被注意到的问题；观察者现在退回到轮询
  • 修复了恢复的 claude -p 会话，其工具全部来自 MCP 服务器，失败并显示“至少一个工具必须具有 defer_loading=false”
  • 修复了当 LLM 网关将非流式回复返回为 text/plain 时，转向失败并显示“API 返回空或格式错误的响应”的问题
  • 修复了当 MCP 服务器在紧密循环中发送 list_changed 通知时持续较高的 CPU 使用率和重复的工具列表请求
  • 修复了 MCP OAuth 错误处理 client 注册的问题：拒绝同意会强制创建新注册，重复使用另一个重定向 URI 的注册，并发写入可能会删除有效注册或保留不匹配的注册
  • 修复了当克劳德通过裸名称而不是完整的 mcp__server__tool 名称选择 MCP 工具时工具搜索不返回匹配项的问题
  • 修复了 Ctrl+O 取消挂起的 MCP 服务器重新连接以及在转录视图打开时从远程控制发送的 /mcp 失败的问题
  • 修复了当 ToolSearch 不可用时 Chrome 中的 Claude 提示告诉模型通过 ToolSearch 加载工具
  • 修复了接收会话的权限模式策略所持有的跨会话消息，不留下任何痕迹：无头发件人现在会收到送达通知，并且 SendMessage 结果不再暗示它已被读取
  • 修复了克劳德启动后台命令的第二个副本（例如监视任务或开发服务器）的问题，该命令在压缩对话后仍在运行
  • 修复了 /model 在切换回实际运行对话的模型时丢失对话缓存的警告
  • 修复了 /reload-skills 报告的技能计数与 /cd 之后的斜杠菜单不一致的问题
  • 修复了 /resume 和 /continue 在短终端上仅以全屏模式显示 1-2 个会话的问题
  • 修复了 /resume 和 /teleport 保留先前对话的文件读取跟踪，以便克劳德可以编辑恢复的对话从未读取过的文件
  • 修复了当恢复会话的模型系列与配置的默认模型不同时，--resume 会删除 1M 上下文窗口 ([1m])
  • 修复了 /artifacts 附加的工件在 --resume 之后从会话中消失的问题
  • 修复了后台会话（claude --bg、claude agents）不观看他们为在其他地方重新发布而发布的工件
  • 修复了自定义代理、斜线命令和输出样式超出第一个不从报告 inode 0 的虚拟驱动器加载的问题，例如作为 Windows 驱动器安装的加密保管库
  • 修复了当主机配置目录超过 64 MiB 时，自托管运行器会话会默默丢失所有主机配置（设置、技能、插件、MCP 服务器）；添加了 --host-config-snapshot disk|memory
  • 修复了从 claude.ai 同步的技能在注销后无限期保留在磁盘上的问题； cleanupPeriodDays 内未刷新的副本现在会在下次启动时移至可回收垃圾箱
  • 修复了微调器提示建议的命令不适用于您的帐户类型或在您的会话中禁用的命令
  • 修复了 /add-dir 路径输入：左右箭头键现在移动光标，Enter 仅添加键入的路径，而不是还添加突出显示的完成
  • 修复了主提示之外的文本字段，将前导 ! 移动到您键入内容的末尾（!foo 显示为 foo!）
  • 修复了当钩子匹配器以继承的对象属性（例如 __proto__ 或 constructor）命名时，交互式 /hooks 菜单崩溃的问题
  • 修复了全屏渲染故障，其中文本周围的框失去背景后仍保持陈旧的背景颜色
  • 修复了 rxvt-unicode 中 st 中的删除键和 Alt+箭头键在附加后台会话中不起作用的问题
  • 修复了当 Claude Code 退出、暂停或启动后立即打开编辑器时，终端对功能查询 (^[[?1;2c) 的回复出现在 shell 提示符或编辑器中
  • 改进的终端渲染性能：大差异和长转录本渲染速度更快，慢速帧更少
  • 通过在每次启动时跳过内置模型数据的冗余验证，略微改进了启动时间
  • 改进的挂钩反馈：当 SessionStart、UserPromptSubmit、PreToolUse 或 SessionEnd 挂钩运行时，微调器会显示经过的时间，并且 Esc 会取消等待 SessionStart 挂钩的提示
  • 改进了长时间思考期间的旋转器状态：现在在 45 秒后显示“深入思考”，并在从输出令牌限制中恢复时显示“重新思考”
  • 改进了动态工作流程，在达到使用限制时暂停，并在重置时自动继续，而不是删除受影响的代理
  • 改进了远程控制，以便在不稳定网络上安装失败时在 claude.ai 上留下更少的空会话
  • 改进了无法访问浏览器时云会话中 Chrome 中的 Claude 消息：它现在表示计算机可能在建议安装之前处于睡眠状态
  • 改进了 claude mcp serve：正在运行的工具调用现在每 30 秒发送一次进度更新，因此 clients 显示它仍在运行，并且空闲超时不会中止不打印任何内容的长命令
  • 改进了 Foundry 和 Claude Platform on AWS 会话：在会话中完成连接的 alwaysLoad MCP 服务器可在下一轮使用，无需工具搜索往返
  • 改进了作为工件发布的 Markdown 文件：它们现在呈现为样式文档页面（标题标题、文档排版、语法突出显示的代码）
  • 改进了 Artifact 工具发布错误：没有文件的发布现在会提示先将页面写入文件，并且在丢失图标之前报告不受支持的文件类型
  • 改进了当页面声明其合约版本缺少的功能时 Artifact 工具的错误：它现在列出了每个受支持的功能，并在较新的合约版本具有该功能时进行注释
  • 改进的工件观看：一个会话现在可以同时观看最多 10 个已发布的工件，以便在其他地方重新发布，而以前为 5 个
  • 改进了 PDF @-提及，当 pdfinfo 无法计算页数时，显示“页数未知”，而不是根据文件大小猜测页数
  • 改进了 /mobile，以显示 claude.ai/mobile 的单个 QR 码，从而为您的手机打开正确的应用程序商店
  • 更改了自动模式，以便技能或斜线命令的内联 ! shell 命令遵循默认模式权限规则而不是分类器；没有规则决定的命令作为经过审查的工具调用运行
  • 更改了自动模式，以便子代理通过安全分类器审查的专用回传呼叫向其呼叫者报告，而不是事后审查其最后一条消息
  • 将监视器手表更改为始终有截止时间（最多 30 分钟；单提示 -p 运行中为 10 分钟）并通知 Claude 重新布防，替换无超时 persistent 选项
  • 将提示中的 IDE 选择指示器更改为与文本一起包裹的 [⧉ …] 药丸，而不是挤压多行提示；使用 Backspace 将其删除以保留所选内容
  • 将 Pro 计划中的默认动态工作流程规模更改为小型，并将中等规模指导原则从 15 个座席减少到 10 个座席
  • 更改了 Claude 应用程序网关、Bedrock、Vertex AI 和 Foundry 会话，以便它们不再刷新会话不使用的剩余 claude.ai 登录信息
  • 更新了捆绑的 claude-api 技能，以在流式自定义工具上启用 eager_input_streaming，并开始与 user.define_outcome 一起使用可交付的托管代理
  • [VSCode] 添加了“附加打开文件”设置，关闭该设置后，将阻止将打开的文件添加到消息中；选定的文本仍被附加
  • [VSCode] 修复了报告保存失败的钩子和权限规则对话框，以及在仅插件策略锁定下钩子对话框变为空白或在保存错误中显示颜色代码的问题
  • [VSCode] 修复了 Hooks 对话框保存：替换时没有重复的钩子，在其他 capitals 中重新输入的标头名称保持其秘密，并且在保存返回之前将忽略 settings.local.json
  • [VSCode] 修复了当工作区位于 Windows 映射网络驱动器或 SUBST 驱动器上时仅显示当前会话的会话历史记录
  • [VSCode] 修复了会话列表的活动过滤器在过滤器菜单中也选中“打开”时隐藏打开的空闲会话的问题
  • [VSCode] 修复了会话列表刷新时新聊天切换回上一个聊天的问题
  • [VSCode] 修复了打开的选项卡和侧栏保留旧配置文件夹，直到在 environmentVariables 设置中更改 CLAUDE_CONFIG_DIR 后重新加载窗口的问题
  • [VSCode] 修复了当扩展程序运行后台命令（例如 git、ripgrep 和登录状态检查）时控制台窗口在 Windows 上闪烁的问题
  • [VSCode] 修复了提示缓存时钟的悬停文本仅在延迟后出现，以及自动压缩图标在弹出窗口旁边显示浏览器自己的工具提示
  • [VSCode] 改进了 Hooks 对话框：由于设置文件本身而导致保存被拒绝，现在会打开一个弹出窗口，其中包含“打开设置文件”按钮以及“复制错误”背后的原因

  • [网络上的 Claude Code] 将 claude.ai/code 上的“例程”页面更改为新布局，其中包含“您的”和“模板”选项卡以及显示运行状态的两列例程卡，并删除了其日历视图

  • [网络上的 Claude Code] 改进了云环境管理页面：它显示了 Claude Tag 和 Claude Code 的默认环境，以及用于更改它的链接，并标记了推荐的创建类型

  • [Claude Tag] 修复了一个线程，该线程要求 Claude 观看拉取请求，而在 Claude 在该线程中重新启动后，该线程不再听到有关 CI 失败、评论和评论的信息
