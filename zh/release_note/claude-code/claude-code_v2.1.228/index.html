claude-code v2.1.228

claude-code v2.1.228

这个项目是干啥的：Anthropic 官方的命令行 AI 编程助手，在终端里让 Claude 直接帮你读写代码、改项目、跑命令。给习惯用命令行的开发者用。

变更架构图

亮点

  • 可靠性与数据安全修复 — 解决交互式渲染冻结、Windows git 检测、/tui 回退 /model 变更、跨会话收件箱缺失、自托管 runner 启动和会话结束失败，以及可能删除项目记忆或符号链接插件缓存内容的清理 bug。使用自托管 runner 或依赖这些工作流的任何人应优先应用此补丁。
  • claude.ai 同步 skill 的安全加固 — 同步的 skill 不再遮蔽本地命令或 MCP 提示；其描述经过清理和标注，正文无法在本地执行 ! 命令或展开 @ 文件。从 claude.ai 同步 skill 的用户应升级，以降低命令遮蔽和本地执行风险。
  • 隔离与凭据修复 — marketplace 条目现在作为整体条目合并，而不是跨设置层级继承自定义头；Remote Control /resume 不再把恢复会话的标题或历史泄露到连接的会话中。Vertex AI 凭据失败现在会在数秒内浮出，而不是重试数分钟后才报错，提升了可靠性和排障速度。
  • 写入工具行为按模型变化 — 较新的模型可以在当前会话中未读取文件的情况下覆盖已存在文件，与 Edit 工具的规则一致；较旧模型仍需先读取。依赖”写前必读”强制执行的自动化应考虑这一按模型而变化的行为，不过未说明需要手动迁移。
  • 较小的 UX 改进 — 跨会话消息内联显示发送者和正文，Remote Control 消息标明发送者的会话名称，压缩显示重试倒计时和停滞提示，终端标题字形减少抖动。这些是有用的体验改进，但本身不构成升级理由；不受这些修复或加固工作流影响的用户可以合理跳过此补丁。

发生了什么变化

  • 修复了在出现罕见的内部布局错误后，交互会话可能会完全停止重绘，而进程仍在运行的情况
  • 修复了从 git 安装的父文件夹启动 Claude Code 时在 Windows 上找不到 git / Git Bash 的问题
  • 修复了自上次响应以来 /model 发生更改时 /tui 将会话恢复到早期模型的问题
  • 修复了安装或升级后的第一个会话中有时会在没有收件箱的情况下启动跨会话消息传递的问题
  • 修复了连接时远程控制 /resume 将恢复的对话的标题或历史记录泄漏到连接的会话中的问题
  • 修复了当会话未推送到的存储库的 checkout 挂钩失败时，每个新跑步者上的 claude self-hosted-runner 会话都会失败；该存储库现在已被跳过并带有警告
  • 修复了自托管跑步者在后台任务完成和后续回合开始之间的间隙结束会话的问题
  • 修复了会话清理删除项目内存文件夹内的内容的问题
  • 修复了当插件的唯一版本是符号链接开发结帐时后台插件缓存清理会删除插件缓存的问题
  • 修复了设置合并问题，其中在较高优先级设置层中重新定义的市场条目可能会继承另一层的自定义标头；市场条目现在合并为整个条目
  • 修复了延迟工具提醒在技能调用后偶尔会两次发送到模型的问题
  • 从 claude.ai 同步的强化技能：它们不再隐藏本地命令或 MCP 提示，它们的描述经过清理和标记，并且在您的计算机上，它们的主体不会运行 ! 命令或展开 @ 文件
  • 改进的跨会话消息：发件人和正文现在显示内联而不是折叠行，并且发送到其他计算机上的远程控制会话的消息将您的远程控制会话名称显示为发件人
  • 改进了 Vertex AI 凭证处理：过期或丢失的 Google Cloud 凭证现在会在几秒钟内失败，而不是在几分钟内重试
  • 改进的压缩进度：重试倒计时和停顿提示现在在压缩过程中出现，而不仅仅是进度条
  • 更新了终端标题 busy-spinner 字形，以减少某些终端上的选项卡栏抖动
  • 更改了写入工具，以便较新的模型可以覆盖他们在本次会话中未读取的现有文件，这符合编辑工具的规则；旧型号仍然需要先阅读
  • 删除了关于 Pro、Max 和 Team 计划的首次使用通知中自动模式会话成本略高的过时注释
