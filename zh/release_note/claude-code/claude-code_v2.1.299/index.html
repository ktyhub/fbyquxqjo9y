claude-code v2.1.299

修订 发布时间2026年10月14日 来源anthropics/claude-code 英文原文

变更流程图

亮点

  • 空闲压缩登陆终端 — 超过 200K 令牌的对话闲置约 54 分钟后，现在会在一小时的提示缓存过期前完成压缩，下一条消息不必重新处理整段历史；可用 CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS 调整下限，或在 settings.json 中用 "idleCompaction": false 关闭（两者都要求 v2.1.290+）。对会把大会话晾在一边的人来说，这是直接的令牌/成本与延迟收益，也是本次升级的首要理由；除非想退出该功能，否则无需任何操作。

  • 安全与沙箱加固 — 修复了以下漏洞：沙箱内的 shell 可以写入 --plugin-dir 目录，而 Claude Code 之后会在沙箱外重载并执行它；为第三方 ANTHROPIC_BASE_URL 配置的 API 密钥会被附加到发往 Anthropic 的功能开关/启动/快速模式/画像/反馈以及服务器托管设置请求上（多处泄露）；凭证会部分泄露到代理队友的任务描述中。如果你使用托管设置、自定义网关或依赖沙箱，应把它当作安全更新；否则这些修复是无感的。

  • mod/插件 API 扩展，有两个迁移注意点 — 新增接口：$.prompt.media、$.session.identity()、session.append 上的 queue 门控、传给 skill.prompt 的技能 frontmatter/来源/插件名/文件路径，以及 Text/Box 样式（size、weight、mono、tabular、间距 xs–xl）。近似破坏性变更：bold 被弃用，改用 weight；claude plugin eval 现在把 API 拒绝的运行判为 0 分并以退出码 1 结束（此前可能通过）——在 CI 中使用 plugin eval 的团队应重新核对预期。mod 作者应升级；不安装任何 mod 的用户可跳过此项。

  • 云端、Remote Control、Cowork 与无头可靠性 — 修复了两个 2.1.296 引入的回归：恢复后已批准的工具调用会执行两次，以及在钩子仍在运行时停止某条消息会导致 Edit/Retry 失败。另外还修复了 Remote Control 提示丢失、事件上传缓慢时云端视图冻结、同步/重载后账号插件过期，以及后台任务期间 ScheduleWakeup 不触发的问题。如果你被 2.1.296 的回归坑到，升级就是解药；纯本地终端用户几乎感受不到。

  • MCP、配置与平台修复，以及新的退出开关 — 名为 constructor/prototype/toString 的 MCP 服务器现在可以连接并遵守权限/策略检查（此前要么连不上，要么错误地弹提示）；被阻止的服务器不再被 claude mcp list/get 启动；HTTP MCP 挂起时间从 30 秒缩短；单个字符串形式的 enabledMcpjsonServers/disabledMcpjsonServers 不再导致设置文件被整体忽略；WSL2 下 /mnt/c 的沙箱 bwrap 失败和空 .mcp.json 的误报无效也已修复。新增开关：CLAUDE_CODE_DISABLE_FILE_MENTIONS（只传递 @ 文件路径而非内容）和 CLAUDE_CODE_ATTRIBUTION_HEADER=0（隐藏署名块）。提供的变更日志在最后一条 Fixed 处被截断，因此本段仅反映可见部分。

发生了什么变化

  • 添加了 CLAUDE_CODE_DISABLE_FILE_MENTIONS 环境变量：Claude 获取 @ 文件提及的路径以使用其文件工具读取，而不是文件的内容
  • 在终端中添加了空闲压缩：闲置约 54 分钟的 200K+ 令牌对话将在其一小时提示缓存过期之前进行压缩，因此您的下一条消息不会重新处理全部内容
  • 添加了 CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS 以更改空闲压缩的 200K 代币最小值；设置中的 "idleCompaction": false。json 将其关闭。两者都需要 v2.1.290 或更高版本
  • 添加了 $.prompt.media，因此通过托管设置安装的 mod 的 prompt.submit 挂钩可以读取附加到提示的图像或文档的字节
  • 为通过托管设置安装的模组添加了 $.session.identity()：会话如何登录，以及托管时的组织和电子邮件 forceLoginOrgUUID 列出了该组织
  • 将 size、weight、mono 和 tabular 添加到 mod 的 Text 中，并将命名间距步骤（xs 到 xl）添加到其 Box 中； bold 已弃用，取而代之的是 weight
  • 将 --shutdown-drain-sec 添加到 claude self-hosted-runner orchestrator：在 SIGTERM 上，它会停止轮询，并在飞行中进行轮询并运行生成钩子，直到完成所需的秒数
  • 将技能的前言、来源、插件名称和文件路径添加到 mod 的 skill.prompt 挂钩接收的内容中
  • 在代理视图中添加了 /effort 和 /fast 以设置新会话开始的内容；裸露的 /model、/effort 或 /fast 现在会打开一个选择器
  • 在代理视图查看面板中添加了一条“安全模式”行，用于以 --safe-mode 启动的后台会话
  • 添加了一次性注释，因为计划模式不会在大多数编辑或命令之前询问，因为可以使用绕过权限
  • 向 claude plugin eval 添加了 --disallow-tools 和 disallowed_tools 案例字段，以保持特定的内置工具（例如 Agent）不参与评估运行
  • 添加了对在 Claude Desktop 的“代码”选项卡中关闭归因块的支持：在 Claude 应用程序网关的 code 策略的 env 中设置 CLAUDE_CODE_ATTRIBUTION_HEADER=0
  • 在克劳德应用程序网关后面的克劳德代码会话中的归因块中添加了一个字段；使用 CLAUDE_CODE_ATTRIBUTION_HEADER=0 移除块
  • 在 session.append mod 挂钩中添加了 queue 门，因此 mod 可以使成绩单的队列记录与发送时的提示不同
  • 在 /plugin 和 claude plugin validate 中添加了注释，命名了在组织管理 Claude Code 时跳过的 mod 挂钩
  • 添加了针对最大努力、工作流程、始终在线上下文和大型工具结果的 /usage 警告
  • 修复了拒绝云会话的错误，当使用 apiKeyHelper 的密钥时，该错误可能会指向错误的组织
  • 修复了自定义 ANTHROPIC_BASE_URL 后面的网关特定模型名称上的会话，以“提示太长·自动压缩失败”结尾，接近 200K 令牌，而不是发送请求
  • 修复了一个 mod，该 mod 在每个回合结束时提交提示，保持无头运行经过 --max-turns、--max-budget-usd、中断或主机对话结束
  • 修复了云会话有时会在工具组的单行标签后显示模型的后续文本的问题
  • 修复了当配置目录的路径中没有 .claude 时，写入和编辑工具在会话的 mods 文件夹中创建 mod 而无需在接受编辑模式下询问的问题
  • 修复了远程关闭后在开放会话中继续运行的已安装模组；他们现在在转弯之间卸载
  • 修复了 Cowork 和 claude.ai 云会话中的编辑和重试在 UserPromptSubmit 或 mod prompt.submit 挂钩仍在运行时消息停止时失败的问题（2.1.296 中的回归）
  • 修复了代理队友在没有描述的情况下启动时在为其显示的任务描述中保留部分凭证的问题
  • 修复了当大量事件无法通过慢速连接完成上传时，claude.ai 的远程控制或云会话冻结视图
  • 修复了沙箱 shell 命令能够写入 --plugin-dir 文件夹的问题，该文件夹的代码 Claude Code 会重新加载并在沙箱外运行
  • 修复了大量调试日志记录（--debug、--debug-file）下的内存增长，以及当调试日志位于停止接受写入的磁盘或网络安装上时退出时挂起的问题
  • 修复了当调试输出进入 stderr 并且父进程停止读取它时内存无限增长的问题
  • 修复了不运行 rm 的 shell -c 脚本上的 rm 提示。在脚本运行时构建的 rm Claude Code 无法读取，不再提示，除非 CLAUDE_CODE_STRICT_INLINE_SHELL_RM_PROMPT=1
  • 修复了在全屏模式下展开的文字记录行中双 clicking 单词折叠行而不是选择单词的问题
  • 修复了 claude mcp list、claude doctor 和 /status 将空 .mcp.json 报告为无效的问题
  • 修复了 /btw 在全屏向上滚动时被询问时将成绩单跳到底部的问题
  • 修复了当沙箱可以写入 Windows 驱动器时，沙箱命令在使用 bwrap: Can't mkdir /mnt/c/Program Files/ClaudeCode 的 WSL2 上失败的问题
  • 修复了代理 SDK、IDE 和 claude remote-control 会话中运行后台任务时未触发的计划唤醒 (ScheduleWakeup)
  • 修复了 mod 的 prompt.submit 重写被默默删除的问题，发送键入的提示，对于某些带有粘贴图像或无法读取的图像的提示
  • 修复了当同一批次中的另一个排队提示未能传递时远程控制提示丢失的问题
