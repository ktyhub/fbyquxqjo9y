claude-code v2.1.275

修订 发布时间2026年9月17日 来源anthropics/claude-code 英文原文

发生了什么变化

  • 将登录帐户添加到 Claude apps 网关登录中：当网关命名它时，您在保存凭据之前确认它，并且 /status 显示它
  • 添加了立即发送键（ctrl+enter，或ctrl+x ctrl+s），可以中断当前回合并立即发送所有排队的消息；已发送和排队的消息显示为灰色，直到模型收到它们
  • 当配置的 otelHeadersHelper 失败时添加了启动警告，因此会注意到无提示导出任何遥测数据的会话
  • 添加了将 claude.ai 帐户上启用的技能和插件同步到使用该帐户登录的终端会话的功能；使用 syncClaudeAiSkills: false 或 syncClaudeAiPlugins: false 选择退出
  • 添加了 /plugin install <plugin> --marketplace <source>，它可以在安装插件之前添加市场
  • 修复了恢复的内存文件的年龄注释在压缩或恢复后的请求之间发生变化，这会导致提示缓存丢失
  • 修复了 --forward-subagent-text 流-json 和 SDK 输出，丢弃由 context: fork 技能生成的子代理的消息，以及由子代理或其他分叉技能调用的分叉技能的消息
  • 修复了使用自定义 fileSuggestion 命令或键入 @./@./ 时隐藏在 MCP 资源下方的@提及文件建议
  • 修复了全屏模式，将后台任务完成通知放置在长回合的折叠工具行下方，而不是它们到达的位置；现在每个通知都会关闭打开的行
  • 修复了当获取失败且市场以其存储库命名时 claude plugin marketplace update 删除 GitHub 市场的本地副本的问题
  • 修复了插件和市场消息、日志和 claude plugin marketplace list 显示存储在 git、ssh 或市场 URL 中的密码或令牌
  • 修复了恢复的云会话在排队消息取代后在记录中留下未回答的问题
  • 修复了 vim 模式下将光标置于重复点“!”之后的一个字符的问题或者快速输入“i!”将非空提示符切换到 shell 模式
  • 修复了向上滚动经过大文件差异时全屏模式冻结或空白几秒钟的问题
  • 修复了偶尔出现在响应中的零散 </ccmemory> 风格的结束标签
  • 修复了插件消息、日志和 VS Code 插件对话框显示某些 git 地址的错误服务器
  • 修复了网络网关后面的用户每次都会出现的终端 API Error: 400，当 beta 请求标头被拒绝时，该终端会重写 API 错误响应
  • 修复了 Linux 上的沙盒 Bash 命令在 shell 为 zsh 时报告失败命令的退出代码 0
  • 修复了在内存压力下无法解码大文件的一部分时读取工具挂起而不是报告错误的问题
  • 修复了 --resume、恢复选择器预览、恢复后台代理和记录视图在保存的历史记录包含格式错误的任务提醒或 @ 文件附件条目的会话上失败的问题
  • 修复了恢复对话记录中包含格式错误的消息条目时发生的崩溃，以及此类对话在向上滚动时收到新消息时发生的全屏崩溃
  • 修复了当保存的记录包含格式错误的消息内容块时会话无法恢复或启动的问题
  • 修复了 Grep、Glob 和 @-file 建议在超过 20MB 输出上限的搜索中挂起或耗尽内存，以及系统 ripgrep 在大量警告后报告“不匹配”而不是错误
  • 修复了当会话的文件历史记录备份无法完全复制时，分叉或后台会话中的 /rewind 会恢复零填充或截断的文件
  • 修复了当快速输入或在斜线命令下拉菜单打开时按住按键时，全屏会话有时会退出并显示“无法恢复的界面错误后克劳德代码退出”的问题
  • 修复了当通过标准输入输入的命令在文件描述符已用完的计算机上运行时后台会话崩溃并重新启动工作程序的问题
  • 修复了当 ~/.claude.json 持有格式错误的 mcpNeedsAuthNoticed 值时启动时发生的崩溃
  • 修复了 --resume 和 --continue 在对话启动的内置工具已被服务器端标志关闭时放弃对话的早期想法
  • 修复了在全屏 claude --resume 会话选择器中用鼠标选择的文本永远不会到达 clipboard
  • 修复了从 --plugin-dir 或 --plugin-url 存档加载插件时，插件重新加载预览替换正在运行的会话提取的插件文件的问题
  • 修复了 --drain-wait-sec 的自托管跑步者丢失在 SIGTERM 耗尽期间完成的回合的最终结果的问题；跑步者现在短暂等待转弯报告
  • 修复了 SubagentStop 钩子，为每个代理类型为空的停止子代理触发特定的 matcher
  • 修复了沙盒 Bash 命令无法写入名为 hooks/ 或 config/ 的项目目录的问题
  • 修复了在另一台计算机上恢复会话或其暂存器被清除后，工件更新失败并显示“找不到文件”的问题：页面的最后发布版本已恢复
  • 修复了 /update-config 写入 Write(path) 权限规则（文件权限检查不匹配）的问题，而不是 Edit(path) 规则
  • 修复了捆绑的 claude-api 技能的实时源表中的四个死文档 URL（定价、计算机使用、技能、CLI）
  • 改进了包含 __SYSTEM_PROMPT_DYNAMIC_BOUNDARY__ 行的 --system-prompt 的提示缓存：其上方的文本现在已全局缓存，因为 SDK 的数组形式已经是
  • 改进了 Claude Desktop 无法打开时的 /desktop 错误：它现在会说明原因以及下一步要做什么
  • 改进了 Artifact 工具的发布和读取结果：他们现在会说明谁可以打开该页面以及所有者的共享菜单提供什么
  • 改进的工件发布结果：它们命名发送的选项卡图标，当页面包含 NUL 字节时发出警告，并在过时的发布后重试新页面的片状获取以进行合并
  • 改进了粘贴和附加图像：它们现在保存在 Claude 可以在没有权限提示的情况下将它们作为文件打开的位置，包括在桌面和 VS Code 中
  • 改进了工件工具的指导，因此当您获得对共享工件的编辑访问权限时，克劳德会就地更新共享工件，而不是发布单独的副本
  • 改进的计划使用读取：一台计算机上的编辑器窗口和非交互式会话现在共享最后一分钟进行的读取，而不是分别调用使用端点
  • 改进了 ListPlugins 工具描述，以便 Claude 知道它列出了您 claude.ai 帐户上启用的插件，而不是使用 /plugin 本地安装的插件
  • 提高了终端缓慢或暂停时的响应能力：当终端赶上时，输出不再进一步落后
  • 改进了同步帐户技能文件夹中文件的写入和编辑结果：他们现在说更改未保存到您的帐户以及如何保存它
  • 更新了 Claude 应用程序网关登录的 /logout，以结束通告令牌撤销的网关上的会话
  • 更改了托管会话，以在容器重新启动后保持未答复的权限提示，而不是再次询问
  • 更改了 Artifact 工具，要求在第一次发布时使用单字选项卡图标，而不是表情符号图标
  • 在自动模式下更改了 Chrome 中的 Claude，以跳过扩展程序对分类器批准的调用的每个站点检查，就像旁路模式一样，修复了重定向后的 browser_batch“权限被拒绝”
  • 更改了从 npm 源安装的插件，以使用 npm pack --ignore-scripts 获取并验证完整性，因此包的安装脚本不再运行
  • 更改了“计划”和“立即运行”例行运行，以将数据保存到并重新发布该工件的页面，您无需询问即可编辑该工件；公共工件，先发布再删除还问
