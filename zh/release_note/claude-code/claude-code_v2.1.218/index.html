claude-code v2.1.218

修订 发布时间2026年7月22日 来源anthropics/claude-code 英文原文

claude-code v2.1.218

发生了什么变化

  • 将 /code-review 更改为作为后台子代理运行，因此审阅工作不再填满您的对话，并将堆叠的斜线命令保留为审阅目标
  • 在 --ax-screen-reader 模式下添加了针对单词和行删除（Option+Delete、Ctrl+W、Cmd+Backspace、Ctrl+U、Ctrl+K）的已删除文本的屏幕阅读器公告
  • 修复了带有 \u 前缀段（如 C:\Users\unicorn）的 Windows 路径在工具输入中被损坏为 CJK 字符，从而导致这些文件无法访问的问题
  • 修复了左箭头键丢弃对话且无法撤消的问题：编辑后立即按下，现在要求确认，代理视图中的 Esc 返回到其后台对话
  • 当服务器无法连接时，向 claude mcp list 和 /mcp 添加了 HTTP 状态和错误文本，并对带有隐藏前导或尾随空格的 MCP 配置值发出警告
  • 修复了多行粘贴折叠成一行，并用 j 代替终端中的换行符，将粘贴的换行符编码为 Ctrl+J
  • 修复了 /context 在从消息选择器压缩后报告陈旧的预压缩令牌使用情况的问题
  • 修复了 /ultrareview 在诸如“查看我的身份验证更改”之类的描述性参数上失败的问题 - 他们现在对您当前的分支进行审查，并将文本用作结果注释
  • 修复了 /code-review ultra 在非交互式会话中静默运行本地审核的问题 - 现在启动云审核
  • 固定网关支出计量，以按配置模型的费率对 Bedrock 应用程序推理配置文件 ARN 和其他配置映射的上游模型 ID 进行定价
  • 修复了长 IDE 选择在表情符号中间被截断时的 mojibake，以及工具执行器错误可能会被静默删除的情况
  • 修复了一个引擎拆卸竞赛，该竞赛可能会启动并放弃幻象转弯，并在关闭后持续拒绝输入
  • 修复了工具调用中断后的虚假“[请求被用户中断]”消息，以及当工具在响应中中止时记录中留下未配对的 tool_use 块
  • 修复了 VoiceOver 读取“新行”的问题，而不是在 --ax-screen-reader 模式下回显输入末尾的键入空格
  • 修复了插件和设置面板不将终端光标移动到焦点行的问题，以便屏幕阅读器和放大器可以遵循箭头键导航
  • 修复了删除或移动深层嵌套的监视目录树以及渲染深层嵌套的 UI 树时发生的崩溃（超出最大调用堆栈）
  • 修复了创建或链接 PR 后会话立即退出时偶尔会丢失拉取请求事件的问题
  • 修复了 Bedrock 设置向导在分区 AWS 区域和仅代理网络上无法对假设角色配置文件进行配置文件验证的问题
  • 通过使用单调时钟对轮流进行定时调整，修复了系统时钟调整后罕见的负值或不正确的轮流持续时间测量
  • 修复了“N MCP 服务器需要身份验证”启动通知过度计数 claude.ai 中未连接的 claude.ai 连接器
  • 修复了当历史记录写入争用或失败时提示历史记录条目被删除或重复的问题
  • 修复了一个重试循环，该循环会在上下文溢出错误后以大量思考预算重新发送相同的注定失败的请求； Ctrl+B 背景现在应用与其他路径相同的背景外壳上限
  • 修复了从 untrusted 文件夹运行的代理 frontmatter 挂钩：挂钩现在要求代理文件自己的文件夹已接受工作区 trust
  • 修复了在无头和 SDK 会话中压缩后分叉会话沿袭丢失的问题
  • 修复了当其历史记录包含格式错误的增量附件时，恢复的会话每次都会失败或恢复时崩溃的问题
  • 改进了 /ultrareview 错误反馈，以便 Claude 可以更正无效参数，而不是原样重试
  • 改进的自动模式：危险-rm、后台-& 和可疑-Windows 路径检查不再打开权限对话框；自动模式分类器对它们进行裁决
  • 改进了 IDE 交互的沙箱命令限制
  • 改进了 trust 对话框，以命名授权所涵盖的存储库根目录
  • 将 /deep-research 更改为仅在手动调用时启动；克劳德不再单独推出它
  • 更改了自动计划模式，不再提示输入静态分析器无法证明只读的 Bash 命令；自动模式分类器会判断它们
  • 添加了由于通过 /config model=<x> 或远程控制切换模型而导致快速模式更改时的通知
  • 更改了服务器管理的设置，因此良性功能和成本切换不再触发设置批准提示
  • 更改了代理降价文件以拒绝包含 : 的代理名称，该名称是为插件命名空间保留的
  • 更改了context: fork的技能默认在后台运行；使用 background: false 选择退出每项技能
  • 添加了 yes/no/on/off/1/0（不区分大小写）作为技能和插件 frontmatter 布尔值的可接受值，以及 true/false
  • 修复了远程会话在工作人员被替换后继续发送心跳的问题，这使得长期存在的桌面和 IDE 进程每隔几秒就永远重试被拒绝的请求
