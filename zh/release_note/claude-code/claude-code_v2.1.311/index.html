claude-code v2.1.311

修订 发布时间2026年10月26日 来源anthropics/claude-code 英文原文

变更流程图

亮点

  • 长会话卡死与重试失败 — 修复了由过长的 CLAUDE.md 列表项、MCP 读取或技能下载期间的延迟中断，以及大型 Write/Edit 操作导致的启动/文件操作冻结。标准上下文会话超过 200K 令牌后现在会压缩并继续，而不是失败；标记为不可重试的 API 响应不再让回合停摆——在 CLAUDE_CODE_RETRY_WATCHDOG 下也不会无限期卡住。长时间运行或无值守用户应升级。
  • 子代理与后台会话可靠性 — 子代理现在可以使用延迟连接的服务器上的 MCP 工具，SubagentStop 在完成时只运行一次，隔离 worktree 在后台子代理使用期间保持可用。恢复的代理团队会话保留其任务列表，符合条件的后台会话在崩溃后会重启。对多代理和后台工作流来说这是有意义的升级。
  • 压缩与转录正确性 — 自动压缩不再留下过期的 CLAUDE.md 或 MEMORY.md，缺失的摘要通常会在替换前重新请求。claude -p 和 SDK 的转录顺序与已撤销消息处理也已修复。行为变更： 设置中的 DISABLE_COMPACT 和 mod 的 $.env.set 现在只能关闭压缩，不能重新启用；请移除冲突的重新启用覆盖。
  • 配置与输出兼容性 — 模型名称和 ID 去掉了无效的 [1m] 后缀，但仍接受该写法，因此现有引用应继续可用。--output-format json 和 stream-json 现在把 DEL、C1 和 Unicode 格式字符转义为 \uXXXX；解析后的值不变，但原始输出解析器应做测试。Bedrock、Mantle、Vertex 和 Foundry 现在会获取签名模型目录；若不想要这个网络依赖，使用 CLAUDE_CODE_MODEL_CATALOG=off。
  • IDE/云端改进与升级结论 — VS Code 现在为自定义技能和斜杠命令保留打开文件/选择上下文，在关闭遥测时不拉取功能开关即遵守设置，并新增语法着色。云端例行任务、远程服务器认证显示和 Claude Tag 技能分析也有改进。ultrathink 现在通过 Anthropic API 在 Opus 5.5、Sonnet 5.5、Haiku 5.5 和 Fable 5.1 上以 xhigh effort 运行。IDE、云端、Slack 及受影响的 CLI 用户应升级；不受这些修复影响的短终端工作流可以跳过。

发生了什么变化

  • 将 --hold-idle-file 和 --max-hold-min 添加到 self-hosted-runner，以在主机报告进程保持运行时保持空闲会话
