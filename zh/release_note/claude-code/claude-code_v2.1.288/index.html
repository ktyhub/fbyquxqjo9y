claude-code v2.1.288

修订 发布时间2026年10月2日 来源anthropics/claude-code 英文原文

变更流程图

亮点

  • 断点续聊与上下文恢复 — 最大一组修复让 --resume 变得可靠：从 2.1.286 或更早版本启动的会话不再丢失模型早期的思考内容，压缩后恢复的文件/上下文不再被丢弃，每轮的最后一条响应重新被保存，被并发重写截断的转录文本也能处理。用 Ctrl+C 清空的提示词现在会留下可恢复的草稿，按 Up 可还原（包括粘贴的文本和图片）；响应中途的 API 超时不再导致整轮失败——非交互会话和子代理会从部分响应继续，仅有思考内容的回复会重试。如果你依赖长时间或反复恢复的会话，这项价值很高。

  • 行为与配置变更（少量迁移） — claude project purge 改名为 claude purge；旧名仍可用但会打印提示。后台命令时间限制现在只适用于无值守会话（-p、Agent SDK、CI、云），终端、桌面应用和 VS Code 会话不再受限。/autocompact 现在按模型分别存储自动压缩窗口；客户端自动模式分类器会忽略指向 Sonnet 5.5/Opus 5.5 的 ANTHROPIC_DEFAULT_SONNET_MODEL 固定值，改用 Sonnet 5；MCP URL 提示会等你说”我已处理完，继续”再往下走。新增开关：/code-review 的 --max-findings <n>|all（持续生效直到 --max-findings default）、供 mod 使用的 $.ui.selection()，以及面向拒绝结构化输出的网关的 CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS。脚本和 dotfiles 需注意 purge 改名和重新划定的时间限制范围。

  • 安全与权限加固 — 补上了几个真实的缺口：bash -c/sh -c 中的危险 rm（例如针对 / 或主目录）即使在 bypassPermissions 模式或 shell 允许规则下也会提示；shell 按算术求值的 BASHPID 赋值现在会提示；当凭证无法保存时 /login 不再误报成功（并支持重试）；npm 自动更新器只装到占位 claude 存根时不再宣称成功。PreToolUse/PermissionRequest 钩子在匹配失败或输入无法序列化时会阻止调用，而不是被静默跳过。重视安全的用户值得升级。

  • 插件、mod 与 MCP — 可扩展性方面改动很多：插件 LSP 服务器现在会在 initializationOptions/settings 中替换 ${user_config.*}/${CLAUDE_PLUGIN_ROOT} 值；插件的 tool.call 钩子不再破坏 worktree 子代理中的 Bash/文件搜索；git-subdir 安装在 git < 2.39（如 Ubuntu 22.04 的 2.34）上可用；没有 GitHub SSH 密钥时 claude plugin install 会回退到 HTTPS 并给出提示；后台会话在插件重载/禁用后仍能存活。MCP 方面，服务器需要更多 OAuth scope 时会在调用中途弹出重新认证提示；超过 16 MB 或无法解析的结果不再重复执行工具调用；用户配置的 memory 服务器工具会在 Claude Desktop 的 Code 标签页暴露给子代理。

  • 值得升级吗？ — 这是一个覆盖面广的稳定性/维护版本，不是功能旗舰：没有重磅新能力，但有几十项跨断点续聊/压缩、插件/mod、MCP、权限、屏幕阅读器模式、VS Code 和 Claude Tag 的正确性修复（包括 idle_prompt 钩子、Remote Control 凭证恢复和 claude_code.tool.blocked_on_user 遥测修复）。如果你用 --resume/长会话、插件、MCP 服务器、屏幕阅读器模式，或跑无值守/CI/云端任务，建议升级——其中几项修复针对数据丢失和误报成功的问题；重试看门狗现在超时三次后也会放弃，不再重试数小时。只有在配置很窄、环境稳定且上述情况都不适用时才可以跳过；除 purge 改名和重新划定的后台时间限制外，没有需要行动的破坏性变更。

发生了什么变化

  • 为 mods 添加了 $.ui.selection()：返回您最后在全屏模式下选择的文本，并且当选择位于一个转录本行内时，返回该行
  • 向图像没有 GitHub CLI 的云会话添加内置 gh api，并修复了内置从文件名、jq 过滤器或 GitHub 发送控制字符到终端的错误
  • 添加了对使用 Ctrl+C 清除的提示的恢复：在空提示上按向上键可恢复草稿，包括粘贴的文本和图像
  • 当 MCP 服务器在工具调用期间请求更多 OAuth 范围时添加了重新验证提示
  • 将 --max-findings <n>|all 添加到 /code-review 以报告比通常限制更多或更少的发现；该选择将重复使用，直到您通过 --max-findings default
  • 添加了 Ctrl+F 按名称查找会话和 Alt+↑/↓ 在代理视图中的组之间跳转；两者和重命名都可以在键绑定中反弹。json
  • 添加了批准计划时新权限模式的屏幕阅读器模式公告，包括使用 Shift+Tab
  • 修复了中间响应 API 超时导致回合失败的问题：非交互式会话和子代理现在从部分响应继续，并且仅重试仅思考响应
  • 修复了当最后一个回复报告零令牌使用时，长对话失败并显示“提示太长”而不是自动压缩的问题
  • 修复了 --resume 有时会丢弃压缩刚刚恢复的文件和其他上下文
  • 修复了恢复的会话有时不保存回合的最后一个响应，因此下一个 --resume 显示未应答的提示
  • 修复了当同一会话在加载期间重写文件时，简历偶尔会加载的记录被缩短的问题
  • 修复了恢复在 2.1.286 或更早开始的对话，从而放弃模型的早期想法
  • 修复了 Mantle 上或拒绝结构化输出的网关后面的会话标题、记忆调用和提示挂钩失败的问题；添加了 CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS 以关闭结构化输出
  • 修复了当被阻止的工具不是 Bash 时自动模式拒绝将 Claude 指向 Bash 权限规则的问题
  • 修复了基岩和地幔上的自动模式在请求旧模型（例如 WebFetch 摘要或 sonnet 子代理）后在会话的其余部分切换到本地分类器
  • 修复了在服务器拒绝后在新选择的模型上重新启动的云会话，并回复该模型
  • 修复了在未批准 URL 的 WebFetch 权限提示五分钟内无人应答后，Cowork 云会话仍标记为等待输入的问题
  • 修复了加入在另一台设备上启动的 Cowork 云会话的手机上未出现提示建议的问题
  • 修复了在克劳德代码重新启动之前绘制的视图上按下时，mod 的按钮有时会运行不同按钮的操作
  • 修复了当一个 Code 元素包含无法解析的差异时，插件的窗格不显示任何内容的问题；它现在绘制为纯代码
  • 修复了插件 LSP 服务器接收 initializationOptions 和 settings 中的文字 ${user_config.*} 和 ${CLAUDE_PLUGIN_ROOT} 占位符，而不是替换值或清单默认值
  • 修复了插件的 tool.call 挂钩导致 Bash 失败并且文件搜索读取工作树中运行的子代理中的错误文件夹
  • 修复了 git-subdir 插件在较旧的 git 上安装失败或缓存不完整插件的问题（2.39 之前，例如 Ubuntu 22.04 的 2.34）
  • 修复了加载 --plugin-dir 的插件在 /plugin 中不显示“配置选项”的问题
  • 修复了当插件重新加载或禁用而其计时器或读取之一仍在运行时后台会话结束的问题
  • 修复了带有不带引号的分隔符 (python3 <<EOF) 的沙盒heredocs，当正文仅包含纯文本和简单的 $VAR 引用时，要求沙盒自动允许下的每次运行都获得批准
  • 修复了 Bash 工具权限检查，以在 BASHPID 赋值之前进行提示，shell 会将其值评估为算术值，而不是默默地允许它
  • 修复了当插件或模组在提示上方显示行时打开后台任务对话框时，全屏会话因“不可恢复的界面错误”而退出的问题
  • 修正了克劳德向另一个会话报告一条消息在该会话持有该消息时已传递的问题：通知现在表示该消息未传递并命名该会话，并且在 SDK 会话中，克劳德现在可以在回合中了解到它
  • 修复了 OpenTelemetry claude_code.tool.blocked_on_user 跨越 -p 和 SDK 会话中报告 unknown 源或决策以及 PreToolUse 挂钩批准的问题
  • 修复了在 -p 或中断回合中未得到答复的权限请求，不发出 tool_decision 事件
  • 修复了 Cowork 云会话中的编辑和重试拒绝 /compact 之前发送的消息的问题，即使其历史记录仍然保存
  • 修复了无人值守会话 (CLAUDE_CODE_RETRY_WATCHDOG) 在很长的响应流失败后重试数小时的问题； Claude Code 现在再次直播，并在三次超时后放弃
  • 修复了当凭据无法保存到安全存储时 /login 报告“登录成功”的问题；它现在显示失败，并在新登录未生效时提供重试（anthropics/claude-code#73861）
  • 修复了基岩凭证查找期间的停止，有时会将会话移至后备模型而不是结束请求
  • 修复了当笔记本电脑从睡眠状态唤醒而另一个 Claude Code 进程正在登录时，第二个 gcpAuthRefresh/awsAuthRefresh 浏览器登录打开的问题
  • 修复了代理团队：按名称生成的插件定义代理现在使用自己的提示、工具、disallowedTools 和工作量运行，而不是默认值
  • 修复了当 timeout 或 systemd 等主管发送 SIGCONT 时，无头 (-p / SDK) 会话偶尔会忽略 SIGTERM
  • 修复了重新启动的云会话恢复组织强制模型列表拒绝的模型

  • 修复了在没有 GitHub SSH 密钥的 macOS 和 Linux 计算机上 GitHub 源插件的 claude plugin install 失败的问题：克隆现在回退到 HTTPS 并打印通知

  • 修正了克劳德在使用团队和企业计划或具有托管设置的机器上的 Artifact 工具启动幻灯片或设计时遗漏了组织的设计系统的问题
