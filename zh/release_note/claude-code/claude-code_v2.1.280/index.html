claude-code v2.1.280

修订 发布时间2026年9月22日 来源anthropics/claude-code 英文原文

变更流程图

亮点

  • 新默认模型与计划默认值——预算和努力设置需要检查 — Claude Opus 5.5 (claude-opus-5-5) 作为新的默认 Opus 模型加入：1M 上下文，$4/$20 每 Mtok，缓存读取 $0.20/Mtok。Pro 和 Team Standard 计划的默认模型也从 Sonnet 改为 Opus（与 Max/Team Premium/Enterprise 一致），因此成本敏感的用户应检查用量。近似破坏性变更：/effort 改为按模型保存之前保存的努力程度不再适用于 Opus 5.5 等新模型（它们以默认级别开始，直到你选择）；Opus 4.7、Opus 4.8 和 Fable 5 不再通过 -p、Agent SDK 或项目/托管/--settings 的 effortLevel 携带其发布默认努力程度——如果依赖它，请重新选择级别。
  • 权限/auto 模式加固（安全，含迁移注意事项） — 通过符号链接路径的写入现在按实际落点判断，而非其在树内的写法：提示会显示真实目标，acceptEdits、允许规则和 auto 模式不再批准逃出树的写入——此前自动批准的写入现在会提示或被拒绝。当安全检查拒绝审查（拒绝一次并附说明）或未给出答案（退避，连续十次后停止）时，auto 模式不再旋转重试。破坏性： PermissionRequest hook 不再运行 agent 类型 hook——它们的回答永远无法允许/拒绝请求——现在会报错并指引你使用 command 或 http hook。
  • 新旋钮与遥测 — CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH 允许将会话中所有 MCP 服务器的 MCP 工具描述和服务器指令的 2048 字符上限调高（需选择启用；默认不变）。hook_execution_complete OpenTelemetry 事件现在携带 hook 输出大小和保存为文件的超大输出数量——有助于诊断 hook 负载膨胀。
  • 大量崩溃/挂起和后台任务修复——遇到就值得升级 — 修复了每回合都因 “role ‘system’ must precede an ‘assistant’ message” 失败的对话、代理/网关后带有 “Input tag ‘advisor_20260301’” 的 API 400（现在去掉该标签重试）、从格式错误的保存记录或系统消息恢复/compact 时崩溃、“unrecoverable interface error” 的一个原因（损坏的缓存消息列表会重建），以及设置文件在读取中被替换为命名管道时的挂起。后台工作可靠得多：headless/SDK 会话中发给正在结束的子 agent 的消息不再丢失，报告在读取前经历压缩也能保留，LSP 对后台子 agent 可用，良性的非零退出（如 grep 无匹配）不再标记为失败，claude --bg 可用于含 NUL 的环境变量，按两次 Ctrl+C 现在会在子 agent 运行时退出。
  • TUI/VS Code 打磨与小行为变更 — 对话框在双按 Ctrl+C/Ctrl+D 时不再退出应用，误按 n/y 不再关闭/确认（在 keybindings.json 中重绑 confirm:yes/confirm:no 可恢复），文本字段不再因键位而丢字符，修复语音听写/Windows 重绘/波斯-阿拉伯零宽连接符，且 ctrl+l/cmd+k 再次是重绘而非清屏（回滚 2.1.260）。VS Code 新增 /status、/sandbox、/chrome、/export、/plan 和斜杠命令对话框中的 skill，标记超过 800 字符/2 个换行符的粘贴文本，“Open in New Tab” 现在在当前编辑器组旁边打开。模仿保留名称的插件 marketplace 被拒绝/停止，私有仓库 marketplace 自动更新现在遵循 git 凭据助手。不是重新打标签或仅元数据变更——这是实质性版本；安全与稳定性修复使其成为推荐升级，只有依赖 agent 类型 PermissionRequest hook 或旧努力默认值的用户需要规划迁移。

发生了什么变化

  • 添加了 Claude Opus 5.5 (claude-opus-5-5)，现在是默认 Opus 模型 — 1M 上下文，每个 Mtok 4 美元/20 美元，带有 $0.20/Mtok 缓存读取
  • 在全屏模式下为更多列表添加了鼠标支持：滚轮滚动 /skills 列表，/plugin 中的技能状态选项可以为 clicked
  • 添加了 CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH 以更改会话中每个 MCP 服务器的 MCP 工具描述和服务器指令的 2,048 个字符上限
  • 添加了挂钩输出大小以及保存到 hook_execution_complete OpenTelemetry 事件文件中的超大输出的数量
  • 修复了通过符号链接路径进行的写入，该路径由其树内拼写进行判断：写入着陆的提示名称和 acceptEdits，允许规则和自动模式不再批准外部着陆
  • 修复了当安全检查 declined 进行审查时，自动模式会一遍又一遍地重试某个操作的问题；该操作现在被拒绝一次，并指出重试无济于事
  • 修复了当安全检查没有给出答案时自动模式会一遍又一遍地拒绝操作而不会暂停的问题；重试现在停止，连续十次后轮流停止并显示一条消息
  • 修复了当模型发送 path、file_text、file_content 或杂散 description 而不是 file_path 和 content 时写入调用验证失败的问题
  • 修复了在大多数对话框中按两次 Ctrl+C 或 Ctrl+D 的问题（/model、/effort、/config、/status、/usage、/plugin、/sandbox、/permissions、/artifacts、/mobile、/login、/upgrade、 /usage-credits、/install-github-app、/setup-bedrock、/setup-vertex) 退出 Claude Code 而不是关闭对话框
  • 修复了一个 click，它仅将终端窗口带到前面，同时触发指针下的项目 - 在搜索选择器、选项卡栏、代理/工作流程行、斜杠命令链接和建议下拉列表中
  • 修复了一个零散的 n 关闭对话框和一个零散的 y 确认对话框；输入Esc接受并取消（将y/n绑定到keybindings.json中的confirm:yes/confirm:no即可恢复）
  • 修复了对话框中的文本字段丢失键入的字母、数字或空格到该键上的键绑定的问题
  • 修复了在 Enter 上删除不可见字符后，Windows 终端上的提示行保持混乱的问题；屏幕现已重新绘制，因此您可以查看将发送的确切文本
  • 修复了隐形字符清理，删除了波斯语和阿拉伯语文本用于将后缀附加到拉丁单词或数字的零宽度非连接符，例如“PDF”的复数形式
  • 修复了按 Ctrl+C 时语音听写不会停止的问题（提示被清除，但麦克风继续录音），在处理笔录时 Esc 不会取消，并在笔录视图和 vim NORMAL 模式下按住空格键开始听写
  • 修复了 Claude 工作时从主机应用程序（Claude Desktop、VS Code、SDK）进行的模型切换，导致下一个提示出现提示缓存缺失
  • 修复了恢复的分叉子代理重建其工具列表，而不是重新发送他们第一次使用的工具列表，这会破坏该代理的提示缓存
  • 修复了在详细模式之外扩展时显示内部来源前导码的子代理返还消息
  • 修复了 installed_plugins.json 在从 GitHub 存储库或跟踪分支或标签的 git URL 更新插件后保留安装时提交的问题
  • 修复了当该文件夹中的 manifest.json 列出其名称时，~/.claude/skills/ 中的技能被移动到 ~/.claude/skills/.trash/ 的问题
  • 修复了会话反馈调查显示浅色和 ANSI 主题上没有悬停突出显示的问题
  • 修复了 /workflows 在打开唯一运行之前短暂显示单行列表的问题
  • 修复了全屏模式下鼠标滚轮不滚动带有隐藏选项（例如 /model 和 /permissions）的选择列表的问题
  • 修复了您关闭的技能显示与 /plugin 和 /skills 中无法加载的插件相同的红色 ✘ 的问题；关闭现在显示暗淡 ◯
  • 修复了多选选项描述在选项编号下而不是在标签下缩进的问题
  • 修复了 /plugin、/skills 和 /mcp 中的搜索框在全屏模式下丢失右边框的问题
  • 修复了 /mcp 在服务器列表中显示 △ 但在同一服务器的详细视图中显示 ⚠ 的问题；列表、详细视图和 /plugin 现在全部显示 ⚠
  • 修复了 Home 和 End 在 /config 设置列表和选择列表（例如 /model、/memory 和权限提示）中不执行任何操作的问题
  • 修复了 /skills 菜单中的 PgUp/PgDn 绕过第一个或最后一个技能而不是停在那里的问题
  • 修复了 Tab 静默更改 /config 列表中所选设置的值的问题；现在它什么也不做
  • 修复了对话每次失败并出现“角色‘系统’必须在‘助理’消息之前”API 错误的问题

  • 修复了会话每次失败以及 /compact 当其保存的历史记录包含有关无法加载 MCP 工具的格式错误的通知时的问题

  • 修复了长时间运行的全屏会话退出时出现“无法恢复的界面错误后克劳德代码退出”的一个原因：现在重建了损坏的缓存消息列表

  • 修复了当子代理完成轮流时发送到后台子代理的消息在无头和 SDK 会话中默默丢失的问题
  • 修复了在读取报告之前压缩启动子代理的对话时已完成的子代理报告丢失的问题

  • 修复了当传递给会话的环境变量包含 NUL 字符时后台会话 (claude --bg) 无法运行 git、hooks、插件和其他帮助程序的问题
  • 修复了后台子代理运行时 Ctrl+C 需要按三到四次才能退出的问题；现在按两下退出
  • 修复了当发送的提示返回到输入时，IDE 选择被删除的问题，例如按 Esc 对其进行编辑、倒回至它，或者在启动挂钩运行时按 Esc
  • 修复了使用 Ctrl+S 隐藏的 ! shell 模式提示在恢复时会以普通提示的形式返回，并且 / 在隐藏后立即列出文件路径

  • 更改了 /effort 成为每个型号之前保存的工作量级别，不再适用于新发布的型号，例如 Opus 5.5；它们从默认值开始，直到您选择一个级别
