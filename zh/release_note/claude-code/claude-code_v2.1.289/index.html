claude-code v2.1.289

这个项目是干啥的：Anthropic 官方的命令行 AI 编程助手，在终端里让 Claude 直接帮你读写代码、改项目、跑命令。给习惯用命令行的开发者用。

变更架构图

亮点

  • 托管设备上权限规则收紧 — 关闭了多个 deny/ask 绕过：Bash 规则现在能捕获隐藏在展开后的环境变量前缀后面的命令（例如 TZ="$HOME" rm -rf build），以及沙箱自动允许下的裸变量赋值；复合 shell 命令嵌套片段上的 deny/ask 规则现在优先于用户安装 mod 的批准；通过符号链接被 @ 提及、被修改或 IDE 选中的文件也会应用 Read 拒绝规则。用户安装的插件不再能改写组织托管的 MCP 服务器登录工具的描述。如果你依赖组织策略或 MCP，旧行为只是”名义上可执行”——应升级；无需配置迁移。

  • 终端与阅读器崩溃/冻结修复 — 修复了以下冻结：包含大量未闭合 <script> 标签的短代码块，或深层嵌套 ${ 替换导致的终端卡死；插件绘制未知边框样式的 Box，或无高度区域持续增大导致的启动/退出崩溃。异步屏幕处理器抛错和 ui.render 行错误不再以”不可恢复的界面错误”结束受监管/后台会话：引擎会自己画一行；绘制过程中失败的 Client 现在只影响自己并抛出 ui.fault，不再拖垮周围 UI。发布的产物页面不再因同样的 <script> 模式冻结/崩溃阅读器的浏览器标签页。标签页、杂散转义/C1 控制字符、CRLF 文本，以及 [-]/关闭标记下右对齐内容的渲染也得到修正。

  • 插件与 mod 生命周期修复 — plugin list、plugin eval 和 plugin update 不再显示从本地文件夹市场安装的插件的过期副本，符号链接的 --plugin-dir 现在支持热重载。已安装的 mod 在升级后的第一个会话中就会加载；claude plugin validate 不再跳过同时含有市场清单的文件夹中的插件，也不再跳过 Anthropic 市场自身的插件/--json 的 plugin.json。代码窗格打开大文件更快（按最终宽度只布局一次）；使用 localhost、路径中含 @、主机名大写或 file: 路径的链接恢复渲染；失败消息现在会点名 mod 并给出真实原因。

  • 新增代理 API（增量、非破坏性） — 新增面向队友的 agent.spawn，一个代理 id 在插件钩子事件间共享，以及 $.agent.list() 中的 idle/waiting 状态。只有当你编写编排队友的插件/mod 时才相关；其他情况无需操作。

  • 谁该升级 / 谁可跳过 — 这里没有破坏性变更、迁移步骤或仅改标签/元数据的信号——这是一个实打实的错误修复补丁加上上面的 API。VS Code 用户：2.1.288 中对 claude auth status 的一项改动可能导致登出更频繁，现已回滚。如果你在托管机器/MCP 上，使用插件/mod，或遇到过上述任何冻结，建议升级；如果你在 2.1.288、不用这些功能且没出现过症状，可以放心跳过。

发生了什么变化

  • 修复了复合 shell 命令嵌套部分的拒绝或询问规则，该规则不支持受管计算机上用户安装的 mod 的批准
  • 修复了具有许多未封闭的 <script> 标签或深度嵌套的 ${ 替换的短代码块上的终端冻结问题
  • 修复了 Read 拒绝规则不适用于通过符号链接在 IDE 中提及、更改或选择的文件
  • [VSCode] 将 2.1.288 更改恢复为 claude auth status，这可能会使注销更加频繁
  • 通过将突出显示的视图以其最终宽度放置一次，改进了在插件代码窗格中打开大文件的速度
  • 修复了 plugin list、plugin eval 和 plugin update 显示从本地文件夹市场安装的插件的过时副本，以及符号链接 --plugin-dir 的热重载
  • 修复了升级后第一个会话中未加载已安装模组的问题
  • 修复了当后台任务对话框全屏打开时，提示上方的插件行显示过时的行
  • 修复了当链接使用本地主机地址、路径中的 @、大写主机或 file: 路径时插件窗格不显示任何内容的问题
  • 修复了用户安装的插件能够重写组织管理的 MCP 服务器登录工具的描述
  • 修复了当插件绘制具有终端不知道的边框样式的框时启动时冻结或强制退出的问题
  • 修复了当插件的屏幕处理程序异步抛出时监督和后台会话结束的问题
  • 修复了当没有高度的插件区域持续增长时以界面错误结束的会话
  • 修复了当沙箱自动允许命令时，Bash 拒绝和询问规则缺少带有扩展值（例如 TZ="$HOME" rm -rf build）的环境变量前缀后面的命令
  • 修复了当命令之前出现裸变量赋值时在沙箱自动允许下跳过 Bash 拒绝或询问规则的问题
  • 修复了当文件夹还包含市场清单时 claude plugin validate 跳过插件的问题
  • 为队友添加了 agent.spawn、跨插件挂钩事件的一个代理 ID，以及 $.agent.list() 中的空闲和等待状态
  • 修复了当 mod 的 ui.render 钩子写入的值在绘制时发生行抛出时以“不可恢复的接口错误”结束的会话；引擎现在绘制自己的行
  • 修复了带有制表符、杂散转义符和 C1 控件的文本，或者带有制表符和 CRLF 行结尾的短文本，在其下方的行上绘制
  • 修复了 mod 窗格中的右对齐内容或关闭标记或 [-] 下的带状图，现在还从终端边缘保留一列
  • 修复了 mod 的 Client 在绘制时失败，并删除了 mod 在其周围绘制的所有内容；现在它单独失败并引发 ui.fault
  • 修复了 claude plugin validate 使 Anthropic 市场自己的插件失败并在 --json 中列出干净的 plugin.json
  • 修复了模组的乐队无法短暂绘制并告诉其下方的卡牌靠边的问题
  • 修复了失败的插件组件，当失败不携带任何消息时，显示 Error 或没有任何内容作为其原因
  • 改进了 mod 作者在其条带或窗格无法绘制时看到的线条：它命名了 mod 并表示未绘制任何内容
  • 修复了已发布的工件页面在带有许多未封闭的 <script> 标签的短代码块上冻结或崩溃读者浏览器选项卡的问题
  • 修复了 mod 的 Client 区域在绘制时终端抛出后在整个会话中保持失败的问题
