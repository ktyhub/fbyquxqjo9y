claude-code v2.1.292

修订 发布时间2026年10月6日 来源anthropics/claude-code 英文原文

变更流程图

亮点

  • 安全与权限加固——建议升级 — 修复了 UNC 路径审批绕过、沙箱读拒绝与凭证注入生命周期错误、macOS/Windows 链接互换导致的文件读取逃逸、/ultrareview 上传泄露、过期的 allowed-tools 授权，以及可能禁用内置策略的托管设置缓存篡改。如果你使用自动模式、沙箱、钩子、托管策略或网络共享，这一点尤其重要。
  • 新的插件与 mod 能力 — claude plugin install --marketplace <source> 可以在安装前按同样的策略检查添加缺失的市场。Agent 工具新增 effort 参数；mod 新增 prompt.autocomplete、$.model.complete 提示缓存，以及 agent.spawn 中的工作流代理元数据。大量钩子重启、权限和拒绝报告修复也让插件行为明显更可靠。
  • 兼容性与迁移变更 — 本地 stdio MCP 连接现在默认协商协议 2026-07-28；若服务器不兼容，可设置 MCP_PROTOCOL_NEGOTIATION=legacy。超过 256 字符的代理名会被拒绝，过长的技能/插件文件 name 值会被忽略。claude plugin validate 现在会拒绝某些重复声明或重新赋值的 $.state 模式；钩子 expect 断言失败和存根答案被拒绝时，claude plugin test 现在会判为失败，而不是静默通过。
  • 更可靠的无头、MCP 与后台工作流 — claude -p 和 Agent SDK 会话的首轮不再等待 HTTP/SSE MCP 的 resources/list；一次性运行也会等待后台命令和定时唤醒。修复针对丢失的定时任务、重启后的 /loop 唤醒、与恢复相关的任务创建，以及云端会话通知丢失。如果你依赖自动化、MCP 服务器或云端/后台会话，值得升级。
  • 行为变更与面向用户的修复 — 定时和 Run 现在以私有方式发布常规产物而无需审批，但请求连接器或其他访问权限的产物仍会提示；严格沙箱现在自动允许带环境变量前缀的解释器命令，如 FOO=bar python3 app.py。长响应渲染、提示/输入法/vim 输入、iTerm2 回滚、PDF 与大型 @ 文件处理、Remote Control、Slack 和 Code Review 也有改进。多数用户应为了安全与可靠性修复而升级；未涉及这些工作流的用户可以合理推迟其余的打磨性改动。

发生了什么变化

  • 将 --marketplace <source> 添加到 claude plugin install：如果需要，在与 claude plugin marketplace add 相同的策略检查下添加市场，然后从中安装插件
  • 在代理工具中添加了 effort 参数，以便克劳德按照您要求的工作量运行子代理
  • 添加了 CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS 环境变量，以便在重试过载 (529) 请求时为退避设置更长的基本延迟
  • 添加了 prompt.autocomplete，mod 挂钩的一个事件，用于将自己的行添加到提示框的自动完成列表中
  • 为 mods 添加了对 $.model.complete 的提示缓存：prompt 和 system 获取文本块，块上的 cache: true 缓存该请求
  • 将工作流代理添加到 agent.spawn mod 挂钩，及其运行和索引，以便 mod 可以拒绝它们
  • 修复了当自动模式不可用时 permissionMode: auto 进入自动模式的子代理定义（被设置、断路器或不支持它的型号禁用）
  • 修复了沙盒命令能够读取 ~/.claude/seed-admin 下 /ultrareview 上传的暂存文件副本的问题
  • 修复了一个托管沙箱读取拒绝路径（及其旁边的用户路径），该路径在会话中出现或重新指向，不会将项目拨款放入其中或结束从其覆盖的文件中的凭据注入
  • 修复了在 macOS 和 Windows 上读取的笔记本或 PDF 能够通过在读取过程中交换的链接返回已批准范围之外的文件的问题
  • 修复了服务器管理设置的磁盘缓存被篡改的问题，在设置获取失败时能够关闭或取消内置策略插件
  • 修复了 8.3 短名称上的 rm -rf 或主文件夹的其他替代 Windows 拼写或驱动器不被视为删除它
  • 安全性：修复了 PreToolUse 挂钩批准和自动模式，绕过从网络 (UNC) 路径读取文件的权限提示
  • 修正了当你在该回合中途离开自动模式或计划模式时，技能或斜线命令的 allowed-tools 规则会在稍后的回合中返回
  • 修复了当设置 HTTPS_PROXY 时，Claude Code 自己的 API 请求（登录、策略、反馈、工件）会忽略 NO_PROXY
  • 修复了名称超过 128 个字符的 MCP 工具导致每次请求失败的问题；该工具现在已被排除，并且 MCP 错误将其命名
  • 修复了在首次运行时加载组织的托管设置之前运行的 claude plugin 命令，例如 marketplace add 和 install
  • 修复了一次性 claude -p 和代理 SDK 在最终结果后 5 秒运行停止后台命令，以及一次性 claude -p 运行丢弃计划的唤醒；两者现在都在等待
  • 修复了从 claude --resume 会话选择器或使用 /resume 恢复会话时计划模式无法恢复的问题
  • 修复了在 /resume、/branch 或 /clear 之后创建的保存的计划任务永远不会触发的问题，以及保存的任务在两次写入任务文件（间隔毫秒）后忽略稍后创建和删除的问题
  • 修复了后台会话的 /loop 在会话进程重新启动时（例如崩溃后）静默停止，因为其挂起的唤醒丢失了
  • 修复了当无法读取给定的文件或文件夹时 Grep 和 Glob 报告不匹配的问题；克劳德现在重试一次或者告诉你
  • 修复了当 PDF 的 pages 是“6,9,15”等列表时，读取工具仅返回第一个条目，没有错误的问题；它现在返回一个错误，表示单独读取每个页面或范围
  • 修复了@提到的超过 256KB 的文本文件被默默忽略的问题：克劳德现在被告知文件的大小并分部分读取它
  • 修复了当代理在已停止主对话的限制上失败时，每个后台代理重复使用一次的使用限制警报
  • 修复了远程控制查看者在桌面应用程序或 IDE 托管的会话中看到后台子代理的空子代理窗格的问题
  • 修复了跨会话传递通知，显示两个会话与一个收件人具有相似的名称，并且当终端会话让消息失效时，到期通知会指责桌面应用程序
  • 修正了在桌面应用程序中立即发送，当另一条消息已排队时，结束子代理正在等待的轮次
  • 修复了 /bug、/share 和 /feedback <text> 在发送报告时按 Ctrl+O 或 Ctrl+Z 后重新开始，并在发送后关闭为取消的问题
  • 修复了当您立即按 Enter 时 /remote-env 替换您保存的默认环境的问题：列表现在以您的默认值打开，并且当没有默认值生效时，没有行有复选标记
  • 修正了当多个粘贴在一个提示中重叠时，一些粘贴的文本作为键入的文本到达克劳德的问题
  • 修复了 vim 模式下光标超出行尾、j/k 在较短的行上丢失列以及 f/t/F/T/;/, 跳转到或删除提示符另一行上的匹配项的问题
  • 修复了 /add-dir 路径框，让 Shift+Enter 或粘贴添加换行符，并将快速键入的“tab”、“up”或“down”视为这些键
  • 修复了选择提示页脚行时快速打字、输入法文本和分解重音符号被删除以及 ! 使该行保持选定状态的问题
  • 修复了全屏模式在检测到 iTerm2 时在每个窗口大小调整和 Ctrl+L 上发送全屏清除，这可能是 iTerm2 的回滚中充满陈旧页面的原因
  • 修复了 @-words 的虚假“无法检查”注释，当设置读取拒绝规则并且工作目录位于符号链接下时，该注释不会命名任何文件
  • 修复了“指令文件未加载”行在 /cd 或权限更改后过时或丢失的问题，并在未加载嵌套行时添加了转录行
  • 修复了重复 /name 的压缩摘要，让克劳德调用为用户保留的技能
  • 修复了 Write、Edit、NotebookEdit 和 LSP 行以及单个 Read、Grep 和 Glob 行，隐藏了 mod 拒绝调用的原因：该行现在显示原因
  • 修复了一个云会话，显示当其工作人员在回合结束时停止时，回合从未结束
  • 修复了带有大文本的云会话，有时会在获得批准后再次请求许可
  • 修复了当克劳德阅读消息时重试或编辑消息时，计划任务和其他排队通知在云会话中丢失的问题
  • 修复了云会话在会话容器重新启动时忘记在 client 中选择的思考设置的问题
