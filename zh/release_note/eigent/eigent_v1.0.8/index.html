eigent v1.0.8

修订 发布时间2026年11月17日 来源eigent-ai/eigent 英文原文

Eigent v1.0.8 带来了一种在应用程序中移动的新方式——带有主页和设置的栏杆、列出每个空间及其会话的主页以及跨所有内容的搜索——并使新的对话时间线成为默认值，并将代理的工作以可读的任务日志形式告知。 此更新还修复了测试中发现的和社区报告的一长串错误，从删除空间和选择文件夹到停止任务的工具调用。

变更架构图

亮点

  • 带有主页和设置的栏杆 — 左侧的细长柱可容纳主页、固定的空间、设置和帐户。固定一个空格以使其远离 click。
  • 主页列出了每个空间及其会话 — 直接从主页打开、启动、固定、重命名、结束或删除会话。右键 click 某个会话的菜单，一目了然地查看哪些会话有您未读过的新闻。
  • 搜索所有内容 — 按 ⌘K 或顶部栏中的搜索按钮可在任何空间中查找空间、会话、任务、文件、自动化和调度。
  • 后退和前进 — 从顶部栏在主页、空间、会话和设置之间前后移动。
  • 新的对话时间线是默认的 - 代理的工作读取为任务日志，批准和问题位于对话中并命名它们所针对的文件或命令，并且当模型发生更改时会显示分隔符。选择您看到的细节数量。
  • 新作曲家 - 一个“+”按钮添加文件、技能和连接器，只需一次搜索即可跨越所有三个。连接器会在您的消息中显示他们的徽标和名称，简短的欢迎会帮助您开始您的第一次会话。
  • 每个空间都有一个表情符号 — 为空间提供一个表情符号，而不是其第一个字母。表情符号选择器可以离线工作。

空间和文件

  • 空间可以使用主文件夹之外的文件夹。系统文件夹仍然被拒绝，并且空间中设置为整个主文件夹的任务会被预先拒绝，并附有有关如何继续的注释。
  • 仍然有会话的空间可以被删除。
  • 空间侧边栏打开后显示空间菜单：重命名、固定、删除和保存点，其设置只需一click即可。
  • 可以下载太大而无法预览的文件。
  • 文件预览仅提供给打开它们的 Eigent 窗口。
  • 无法从系统或凭据文件夹导入插件。
  • 失败的文件写入不再阻塞工作区的其余部分。
  • 在 Git 支持的空间中同时启动的两个会话都启动。

任务和代理

  • 带有格式错误的参数的工具调用在运行之前被捕获，因此任务可以继续进行。
  • 即使调用包含它们不使用的参数，浏览器和搜索工具也会运行。
  • 记忆不再将来自自动化的消息视为您自己的话。
  • 当 Pro 试用版的每日积分用完时，Eigent 会这么说，并且“刷新”不再挂起。
  • 中断的任务不再不断重新加载其状态。

接口

  • 需要一段时间才能打开的会话在整个会话中显示加载发光；很快就出现了。
  • 重新打开会话会显示其结束时的消息和任务日志，而无需回放工作。
  • 模型名称显示时不带提供商前缀，例如 gemini-4-carbon。
  • 空间的全名会在合适的时候显示在其页面标题中。
  • 当菜单打开时，打开菜单的按钮保持突出显示。
  • 空间和会话打开速度更快，您选择的最新空间始终获胜，并且陈旧的会话状态会被清除。
  • 主页、空间页面和应用程序外壳的布局、对齐和动态优化。 完整 changelog: v1.0.7 → v1.0.8
