eigent v1.0.5

这个项目是干啥的：一个能替你干活的桌面 AI 助手，能并排开多个会话、调用各种技能和工具，给想让 AI 自动办事的人用。

Eigent v1.0.5 改进了会话恢复、任务队列以及用于检查正在进行的工作的工具。它还添加了元模型 API 支持，使空间资源更易于配置，并引入了并行会话执行的有限、可选择的预览。

变更架构图

亮点

  • 更可靠的会话恢复 — 在连接中断或应用程序重新启动后，更一致地恢复任务状态、对话历史记录、经过的时间和完成的输出。使用可接受的模型配置恢复会话，并在使用限制后更可靠地处理模型切换。
  • 更清晰的任务队列 — 使用拖放或键盘控件对排队的任务重新排序，选择接下来启动的任务，并在启动另一个任务之前显式停止当前任务。更清晰的等待、停止和启动状态使队列更容易遵循。
  • 后台进程和更好的预览 — 检查正在运行的进程，打开其终端输出或本地服务器预览，并从会话侧面板停止它们。改进PDF渲染、预览失败恢复和本地浏览器加载； HTML 预览现在支持最大 10 MiB 的文件。
  • 更轻松的空间配置 — 从空间设置中浏览配置的技能、连接器、MCP 服务器和模型。将已发布和设置的 Space 的默认模型应用到新会话，同时保留手动会话选择和现有会话模型。
  • 扩展模型支持 — 将元模型 API 和 Muse Spark 添加到自定义模型设置。使用保存的凭据改进模型发现、API-key 错误、推理工作处理、OpenAI/Azure 工具请求、Anthropic 兼容工具调用以及 OpenAI Workforce 初始化。

可靠性和可用性改进

  • 显示更清晰的信用、访问、连接和提供商错误，并减少重复提醒。
  • 更一致地保存已完成的任务结果、文件摘要和历史持续时间；停止失败的历史任务的计时器。
  • 防止长时间运行的触发器执行仅仅因为服务器端时间阈值已过而被标记为失败。
  • 改进工作区写入协调、进程关闭、提供程序重试、取消和增量内存处理。
  • 即使本地后端暂时不可用，也能完成空间删除。
  • 改进技能文件浏览，减少连接器加载闪烁，并保持设置标题可见。
  • 单独的网络代理保存、重置和重新启动操作，并防止在保存挂起时进行编辑。
  • 将赞成和反对反馈连接到消息级事件。
  • 正确处理包含空格、Unicode 或换行符的 Git 文件名。
  • 将 Git 与 Windows x64 版本捆绑在一起，以防止未安装 Git 时后端启动失败。
  • 以原子方式保存凭据环境文件并在支持的系统上强制执行仅限所有者的权限。

并行会话执行预览

此版本包括针对支持的本地单代理文件工作流程的默认关闭、选择加入预览。在显式配置的部署中，符合条件的新会话可以在隔离的工作区中同时运行，结果会自动集成回其空间中。每个会话中的任务仍然按顺序运行。 预览需要部署设置、支持的自定义或本地模型、现有文件权限以及每个新会话的显式选择加入。它不包括现有会话、附件、MCP、通用终端/浏览器工具、劳动力或云执行。请参阅预览设置和范围。

升级注意事项

现有会话保留其当前执行路径；升级不会自动启用并行执行。如果某些较旧的中断任务保存的模型功能不再与当前配置匹配，则可能需要新任务。
