eigent v1.0.7

这个项目是干啥的：一个能替你干活的桌面 AI 助手，能并排开多个会话、调用各种技能和工具，给想让 AI 自动办事的人用。

Eigent v1.0.7 允许您同时处理多个会话，并排或在它们自己的窗口中，添加会话菜单和消息操作，并使自动化在您的本地时间可靠地启动一次。

此更新还修复了测试中发现的和社区报告的一长串错误，从更新后的批准和退出到登录。

变更架构图

亮点

  • 并排会话 — 在空间中最多显示三个彼此相邻的会话，或在其自己的窗口或浏览器选项卡中打开会话。后台工作（例如计划的自动化）仅从一个窗口启动，因此没有任何操作会运行两次。
  • 会话菜单 — Click 会话标题以固定、重命名、结束或删除它，或将会话转变为技能或自动化。
  • 消息操作 — 复制消息、编辑并重新发送消息，或展开长消息。分隔符显示模型何时在任务之间发生变化。
  • 空间概述 — 在工作区编辑器旁边的面板中查看空间的概述。
  • 重新设计的调度页面 — 远程控制页面具有新的布局。
  • BytePlus ModelArk 子代理 — 从重新设计的设置 → 子代理页面添加 BytePlus ModelArk 托管代理作为远程子代理提供商。
  • 用完积分，而不是没有选项 — 当您的 Eigent 积分用完时，请直接根据通知升级您的计划或切换到您自己的 API 密钥。

自动化

  • 现在运行立即启动自动化，并运行从未收到的应用程序并恢复。
  • 列出了整个空间的自动化，其时间表保持在您当地时间。
  • 当您随后打开其会话时，自动化仅运行一次。

批准、问题和任务

  • 批准和问题出现在消息框上方，并命名它们所针对的文件或命令。
  • 重新加载后仍在等待的问题可以得到解答，并且客服人员的问题和您的答案会保留在聊天中。
  • 内存更改要求确认并显示其详细信息。
  • 后续消息在队列中等待，直到解决失败的任务。
  • 恢复任务保留其浏览器工具。
  • 中断的任务显示他们完成的操作和他们写入的文件。
  • 代理知道每项任务的当前日期和时间。
  • 被拒绝的会话在重新加载后继续显示错误。
  • 一旦您按下“发送”，就会打开一个新会话。

退出、更新和模型

  • 当任务正在启动、运行或等待您时，Eigent 在退出前进行询问，并清理每个任务的终端环境。
  • 更新后，您保持登录状态，Eigent 会重新打开您的最后一个空间。
  • 在会话中选择模型只会更改该空间的模型，而不是新空间的默认模型。

接口

  • 更宽的聊天栏、对齐的消息插入和编辑器控件，以及在回复流时保持锚定的查询。
  • 滚动到浮动聊天控件的底部，预览旁边有一个会话摘要列。
  • PDF 预览显示文件名并适合页面。
  • 日期使用应用程序语言，图标共享一种线宽，滚动条在各处看起来都相同，并且工具提示在对话框打开时关闭。
