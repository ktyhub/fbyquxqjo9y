小版本 发布时间2026年11月16日 来源github/github-mcp-server 英文原文

github-mcp-server v2.2.0

这个项目是干啥的：一个让 AI 助手能操作 GitHub 的 MCP 服务器，能搜代码、管仓库和 issue，给想把 AI 接入 GitHub 工作流的人用。

变更架构图

亮点

  • 基于 Skills 的指引 — #3685 用经过过滤的 MCP skills 取代服务端指令（server instructions）。支持 skill 发现的客户端可以获得更有针对性的指引；依赖服务端指令的客户端应验证兼容性。没有记录必需的迁移。
  • 密钥扫描隐私 — #3838 为密钥扫描告警工具加入可选的密钥隐藏功能。当结果可能到达不可信客户端或日志时，值得启用；不使用该选项时行为不变。
  • Agent 自动化 — #3719 新增公开的 agent automation 工具，为构建或运行 agent 的用户扩展了编程式工作流选项。
  • 可靠性修复 — #3665 返回非 nil 的空 completion 结果，避免 null 与 empty 的处理失败；#3772 防止校验错误容量溢出，降低极端输入的风险。
  • 升级结论 — 使用 MCP skills、密钥扫描、agent automation，或遇到这些边界情况的用户应升级。否则可以跳过本版本。更新日志没有列出明确的破坏性变更或强制迁移步骤。
