github-mcp-server v2.1.0

小版本 发布时间2026年11月3日 来源github/github-mcp-server 英文原文

github-mcp-server v2.1.0

变更流程图

亮点

  • 实验性 artifact 工具 — PR #3554 新增两个实验性 MCP 工具，用于附件的创建/读取/更新/删除。这是本版本的重头功能，但”实验性”意味着该接口是可选启用且可能变化——只有在你需要 artifact CRUD 且能容忍不稳定时才值得升级。

  • 改变输出/输入的行为修复 — PR #3468 修复了 PR 列表输出中报告的合并状态（对读取 PR 状态的人是正确性修复），PR #3650 现在拒绝大于等于 2^63 的整数参数。后者是真实的行为变化：此前在极值处漏过的输入现在会被拒绝，所以传入超大整数的调用方应检查边界。

  • GitHub Models 分诊退役 — PR #3629 用 agentic workflows 取代退役的 GitHub Models triage。如果你依赖旧的分诊行为，请当作迁移处理：你的工作流需要迁移到对应的 agentic 实现，而不是期待旧路径继续存在。

  • 依赖刷新 — Go 依赖 golang.org/x/net 0.59.0→0.61.0、github.com/go-chi/chi/v5 5.3.2→5.4.0、github/codeql-action/start-proxy 4.38.2→4.39.0，以及 /ui 更新（@primer/octicons-react、@types/node、vite-plugin-singlefile）。主要是维护/安全卫生；除非你想要 x/net 的修复，否则不构成独立的升级理由。

  • 升级结论 — 这是一次真正的次版本发布，不是重打标签或纯元数据空操作。需要 artifact、依赖正确的 PR 合并状态，或必须从 GitHub Models triage 迁移的用户应升级。如果你满足于 v2.0.3 且不需要 artifact 或这些 bug 修复，可以放心跳过——光靠依赖升级不足以支撑迁移。除分诊替换外，没有发布明确的破坏性变更说明或迁移步骤；唯一的文档改动是修正 host-integration.md 中的 MCP SDKs 链接（PR #3598）。
