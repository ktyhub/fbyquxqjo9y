trl v1.16.0

特点

🛠️ TRL 现在在 AWS Trainium 上进行训练

v1.15 的融合 LM 头使 Neuron 变得易于处理；剩余的差距在这里被弥补。有一个[指南](https://huggingface.co/docs/trl/neuron)与之配套。 神经元对每个输入形状重新编译一次，因此未填充的运行在每个新序列长度上都会停止大约一分钟。 `pad_to_multiple_of` 现在在 Neuron 上默认为 `"auto"`: 128，在其他地方默认为 `None`，因此 GPU 上没有任何变化。 Trainium2、Qwen3-0.6B SFT，20 步：**130 秒，默认为 260 秒，无**。 * 添加 @qgallouedec 在 https://github.com/huggingface/trl/pull/7729 上进行 AWS Trainium 培训的指南 * @qgallouedec 在 https://github.com/huggingface/trl/pull/7724 中将 `pad_to_multiple_of` 默认为 `"auto"` * 在 https://github.com/huggingface/trl/pull/7669 中 @qgallouedec 在没有 Triton 的设备上运行融合的 LM 头和蒸馏内核 * 在 `trl env` 中报告 Neuron 设备并在 https://github.com/huggingface/trl/pull/7672 中通过 @qgallouedec 进行遥测 * 支持https://github.com/huggingface/trl/pull/7670中@qgallouedec激活卸载中的任何加速器 ### 🌳 AsyncGRPO 的树注意力 AsyncGRPO 现在将每个微批次行打包为**前缀树**，而不是平面序列。多回合和多代推出重复了很多前缀：在共享提示上，这些令牌过去每行转发一次。树包装将它们转发一次。 ```text rollout 0: [ prompt ] [ completion A ] prompt ──┬── completion A ── later turn rollout 1: [ prompt ] [ completion B ] => └── completion B rollout 2: [ prompt ] [ completion A ] [ … ] ``` 没有分叉的链会折叠成段，每个段的查询都会参与在单个 FA3 varlen 调用中沿着其根到段路径收集的 K/V。无掩码张量：除了注意力之外的每一层每个唯一标记运行一次，并且只有 K/V 沿着共享前缀重复。 Qwen3-1.7B，每次推出 32K 代币，向前
