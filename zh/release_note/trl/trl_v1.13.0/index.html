trl v1.13.0

特点

训练超过 1M 代币

一个新的[长上下文指南](https://huggingface.co/docs/trl/long_context_training) 加上一个可运行的示例，该示例在单个 8×H100 节点上每步训练一个书本长度的序列。 测量：**Qwen3-8B，1,048,576 个令牌，380 秒/步，每个 GPU 56.2 GB**（bf16、`per_device_train_batch_size=1`、`loss_type="chunked_nll"`）。端到端运行并保存。该指南按照您敲击杠杆的顺序记录了杠杆（`chunked_nll`、梯度检查点 `offload`、YaRN RoPE）和约束（仅全神贯注，无打包）。需要 `transformers >= 5.16` 来设置检查点 `offload`。 * 记录
