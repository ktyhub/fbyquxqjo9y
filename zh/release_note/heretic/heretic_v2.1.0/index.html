heretic v2.1.0

小版本 发布时间2026年11月8日 来源p-e-w/heretic 英文原文

heretic v2.1.0

变更流程图

亮点

  • 新评分器与配置灵活性 — 新增响应长度评分器（PR #562）和自定义配置文件路径支持（PR #557），因此你可以按长度给输出打分，也能在不改动默认配置的前提下运行非默认配置。对跑评分/基准测试工作流的人最重要。
  • 导出与重置的可靠性 — 模型重置错误不再中断正在进行的导出（PR #565），插件设置现在也能正确导出（PR #570，@Vinay-Umrethe 补充了测试）。如果你依赖导出或插件，这些修复消除了真实的故障场景，是扎实的升级理由。
  • 内存与性能 — 所有模型张量现在都常驻内存（PR #564），获取模块 I/O 时会禁用 KV 缓存（PR #566），基准评分器中的批大小缓存也终于真正生效（PR #567）。对内存受限或性能敏感的运行有意义；日常轻度使用基本不受影响。
  • 破坏性变更 / 迁移 — 未提及。版本号提升到 2.1.0.dev0（PR #558）属于例行维护，PR #572 是文档准备，因此这是一个正常的兼容性小版本，无需迁移步骤。
  • 谁该升级 — 如果你使用导出、插件设置、评分/基准测试或自定义配置，建议升级。在 2.0 上用得很好且没有这些需求的用户可以跳过，不会错过任何功能。

变化

  • 杂务：https://github.com/p-e-w/heretic/pull/558 中 @p-e-w 的 2.1.0.dev0 碰撞版本 *功能：允许通过@dreamfast在https://github.com/p-e-w/heretic/pull/557中指定自定义配置文件路径
  • 壮举：通过 @p-e-w 在 https://github.com/p-e-w/heretic/pull/562 中添加响应长度记分器
  • 修复：通过 @p-e-w 在 https://github.com/p-e-w/heretic/pull/564 中强制所有模型张量驻留内存
  • 修复：防止模型重置期间出现错误，从而中断 https://github.com/p-e-w/heretic/pull/565 中 @p-e-w 的导出
  • perf: 在https://github.com/p-e-w/heretic/pull/566中通过@p-e-w获取模块I/O时禁用KV缓存
  • 修复：使基准评分器中的批量大小缓存实际上通过 https://github.com/p-e-w/heretic/pull/567 中的@p-e-w 起作用
  • 修复：在 https://github.com/p-e-w/heretic/pull/570 中通过 @p-e-w 正确导出插件设置（由 @Vinay-Umrethe 贡献的其他测试）
  • 文档：为 @p-e-w 在 https://github.com/p-e-w/heretic/pull/572 中发布 2.1 做准备
