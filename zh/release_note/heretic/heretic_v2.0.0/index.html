heretic v2.0.0

变更流程图

亮点

  • 破坏性变更 / 必须迁移 — Heretic 1.x 的配置文件与 2.0 不兼容。升级前请按照迁移指南更新配置。研究功能也已被移除，官方建议改用 Lophius。
  • 可扩展的插件与评估 — 通用插件系统、modifier 插件、插件级 reproducible 元数据、benchmark 评分器和 Generic BERT Classifier 评分器，让自定义评估与修改流程成为可能。数据集现在可以指定特定的配置/子集，上传标签和模型描述符也可配置。
  • 更广的模型与平台支持 — 新增对 Hyper-Connections（包括展平残差流）以及聊天模板拒绝 system 角色的模型的支持。Windows 上的评估不再触发 UnicodeEncodeError；新增接受更多 Qwen2.5 和 Windows 测试哈希，CI 也覆盖 Python 3.14 和 3.15。
  • 正确性与可复现性修复 — 修正了试验总数统计，lora_A 不再在试验之间串扰，复现/恢复时也会还原已保存的插件设置。校验现在会拒绝无效的评分器实例名和空白的拒答关键词；响应前缀检测、输出转义以及保存/上传报告也都有改进。
  • 性能、自动化与升级结论 — ARA 现在通过低秩更新而非稠密权重来计算闭包输出，W_org 只在需要的地方使用，MLP 消融可通过 0 的 max_weight 下限关闭。无头运行和端到端测试让自动化跑批更实用。对自动化场景、插件用户和受影响的模型来说，这是一次实质性升级——但现有 1.x 用户应为配置迁移预留时间，只做研究的用户应转向 Lophius，而不是升级。

重大变更

Heretic 2.0 是一个破坏向后兼容性的主要版本：

  • 为 Heretic 1.x 制作的配置文件与 Heretic 2.0 不兼容！请参阅迁移指南，了解需要更改哪些内容才能使旧配置正常工作。
  • 研究功能已被删除。预期的替代品是Lophius。
