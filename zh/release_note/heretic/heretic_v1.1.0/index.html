heretic v1.1.0

变更流程图

亮点

  • 硬件与平台支持 — 新增基础的 MPS（Apple Silicon）支持（PR #5）、多 GPU 支持（PR #17、PR #32）以及 notebook（Colab/Kaggle）兼容性（PR #42），因此你现在可以在 Mac 上、跨多 GPU、在托管 notebook 中运行，而不再被绑定在单张 CUDA GPU 上。
  • 模型覆盖面 — 新增 IBM Granite MoE（PR #14）、带 Triton 张量的 MXFP4 量化模型（PR #28），以及对需要 trust_remote_code 的模型的支持（PR #31），并修复了某些默认使用 float32 dtype 模型的加载问题（PR #44）——拓宽了你实际能加载并做遗忘的模型范围。
  • 正确性与健壮性 — 实现了 @accemlcc 建议的”重要 padding 修复”，改进了拒答检测（PR #45）和本地数据集加载（PR #33），修复了 Hugging Face 用户资料字段缺失时的错误（PR #20），并降低了内存占用（PR #15）。如果你在意输出质量，单凭 padding 修复就值得升级。
  • 新能力 — 新增研究特性、支持提前停止优化过程，以及支持思考型模型，让你对长时间运行有更多控制，并能使用推理风格模型。
  • 破坏性变更 / 谁该升级 — 文档未记录破坏性变更或迁移步骤。Apple Silicon、多 GPU 或 notebook 用户，以及需要新模型格式或 padding 修复的人值得升级；如果你在用得好好的单 GPU CUDA 环境且没有这些需求，可以放心跳过。
