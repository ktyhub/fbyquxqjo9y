incubator-seata v2.0.0

大版本 发布时间2023年11月24日 来源apache/seata 英文原文

西塔2.0.0发布 Seata 是一个易于使用、高性能、开源的分布式事务解决方案。 版本更新如下： ###特点：

  • [#5165]优化TCC结构，支持API接入。添加集成层模块（seata-integration-tx-api）用于事务流程定义和代理增强。
  • [#5352] 为 tcc 业务操作上下文添加 jackson json 解析器和 gson json 解析器
  • [#5377] 使 AbstractHttpExecutor.class 支持 http put

  • [#5600]功能：支持根据XID追踪交易链接
  • [#5357] 功能：控制台集成 saga-statemachine-designer
  • [#5717] 与 1.4.2 及以下版本中的 file.conf 和registry.conf 配置兼容
  • [#5842] 将元信息添加到 docker 图像
