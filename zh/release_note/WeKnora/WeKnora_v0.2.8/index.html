WeKnora v0.2.8

修订 发布时间2025年12月31日 来源Tencent/WeKnora 英文原文

变更流程图

亮点

  • 数据分析代理与结构化数据工具 — 新增内置 Data Analyst 代理，配套的 DataSchema 工具可直接从 CSV/Excel 文件获取 schema，并支持按代理限制文件类型。这让 WeKnora 超越纯文本 RAG：你可以把电子表格路由给专用代理，并用文件类型白名单作为治理手段，确保代理不会收到无法解析的输入。预期需要在代理清单中注册新代理，并确认摄取流水线暴露了所需的 schema 元数据。
  • Thinking 模式成为一等配置 — 推理模型的“思考”模式现在可配置，Summary 配置新增 Thinking 字段。运行推理模型的团队可以通过配置显示或抑制思考输出，而不必依赖客户端绕过方案。升级时请留意配置 schema：任何反序列化 Summary 配置的代码都应容忍新字段。
  • 流式与会话 API 面变化 — KnowledgeQAStream 新增参数，并支持流式响应类型与工具调用，同时 SSE 流初始化经过重构。此外，会话创建请求被简化，knowledgeRefs 改为 References 类型。这些是最容易坑到集成方的变化——如果你消费流式端点或解析响应对象，请针对新结构重新测试 SSE 客户端与序列化代码。自动标题生成也可关闭，适合高并发或标题需确定性的工作流。
  • 文件上传与存储加固 — 可配置上传大小限制、MinIO bucket/权限列举以及全文合并视图，同时修复 Nginx 413（Payload Too Large）处理和 Asynq Redis DB 配置。对自托管者而言，大文档摄取终于可以预期地工作，但请把 Nginx client_max_body_size 与应用层新限制对齐，否则只是把失败点后移。MinIO 权限列举也让审计最小权限服务账号更容易。
  • 升级前需检查的迁移与数据完整性修复 — tag_id 迁移现在会检查 embeddings 表是否存在，批量标签更新会刷新索引字段，重复创建标签的问题也已修复——对于标签密集型部署，这显著降低了糟糕迁移损坏或卡住索引的风险。另需注意：通过排除 ChatTemplateKwargs 改进了 OpenAI API 兼容性，并行搜索中缺失的 WebSearchStateService 也已恢复，如果你依赖这些路径请验证。
  • 可运维性与打包 — 新增 WEKNORA_VERSION 环境变量支持、Docker APK 镜像源配置和更简洁的包安装，简化了版本固定和受限网络构建。模型锁定被移除，用户可自由切换模型；“agent not ready”提示也统一了——这些改动虽小，但会影响编写部署脚本或构建模型切换 UI 的人。

[0.2.8] - 2025-12-31

🚀 新功能

  • 新：数据分析师代理和工具
    • 添加了内置数据分析师代理
    • 添加了 DataSchema 工具，用于从 CSV/Excel 文件检索架构
    • 支持代理文件类型限制
  • 新：思维模式支持
    • 添加了对思考模式的配置支持
    • 在摘要配置中添加了思考字段
  • 新：增强的文件和存储管理
    • 支持列出MinIO存储桶和权限
    • 可配置的文件上传大小限制
    • 全文合并查看模式
  • 新：对话增强
    • 添加了禁用自动标题生成的选项
    • 增强的 KnowledgeQAStream 参数
    • 支持流响应类型和工具调用
  • 新：系统和配置
    • 添加了 WEKNORA_VERSION 环境变量支持
    • Docker 中的 APK 镜像配置支持
    • 增强的分块分隔符选项
    • FAQ两级优先级标签过滤
    • 批量更新标签时更新索引字段

⚡ 改进

  • 改进：代理和模型处理
    • 统一代理未就绪消息逻辑
    • 优化内置代理配置同步
    • 删除了模型锁定逻辑以允许自由切换
    • 增强的模型选择和错误处理
  • 改进：重构
    • 简化的会话创建请求结构
    • 将 KnowledgeRefs 转换为 References 类型
    • 重构了 SSE 流设置
    • 重构了Bucket策略解析逻辑
    • 简化 Docker 软件包安装

🐛 错误修复

  • 已修复：本地化占位符显示问题
  • 已修复：重复标签创建和流响应解析
  • 已修复：并行搜索中缺少 WebSearchStateService
  • 已修复：设置弹出窗口关闭时模型列表刷新
  • 已修复：Asynq Redis 数据库配置
  • 固定：菜单删除逻辑和计数更新
  • 已修复：OpenAI API 兼容性（不包括 ChatTemplateKwargs）
  • 修复：处理 Nginx 413（有效负载太大）请求
  • 修复：在 tag_id 迁移中添加了嵌入表的存在检查 完整 Changelog：https://github.com/Tencent/WeKnora/compare/v0.2.7…v0.2.8
