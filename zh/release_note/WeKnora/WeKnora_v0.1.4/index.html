WeKnora v0.1.4

修订 发布时间2025年9月17日 来源Tencent/WeKnora 英文原文

WeKnora v0.1.4

这个项目是干啥的：一个能基于你自己的文档资料回答问题的知识库系统，支持多个知识库和翻译，给想搭智能客服的公司用。

变更架构图

亮点

  • 多知识库工作流 — 知识库切换与管理现已贯穿 UI，并支持可配置的多数据源搜索引擎设置（PR #319、#321）。这让检索可以跨多个语料库进行，而不是把知识库选择当作单一全局设置；采用该工作流时请复查搜索引擎配置。
  • 租户管理 — 新增专门的租户信息页和改进的用户/租户管理工具（#312），为多租户部署提供更清晰的管理界面。如果你的部署暴露了该页面，请检查角色与访问假设。
  • 安全加固 — 修复思考组件的 XSS 漏洞（#308），纠正 CSP 错误（#311），并加强前端输入净化。如果渲染的模型输出或生成内容会暴露给用户，请尽快升级。
  • LLM 与下载正确性 — App LLM 模型校验逻辑发生变化（#322），文件下载现在保留正确内容（#310）。升级后请验证自定义模型配置，特别是那些依赖宽松校验的配置。
  • 设置与认证 UI — 设置页、初始化流程、菜单和登录导航均经过重构，包括修复直接跳转到登录页的问题。预期 UI 交互会发生变化；必要时更新截图、上手指南和端到端测试选择器。
  • 移除测试数据功能 — 测试数据功能及其相关 API 被移除，初始化组件得到简化。任何调用这些 API 的内部脚本或集成都必须在升级前更新。

🚀 主要特点

  • 新：多知识库操作支持
    • 增加了全面的多知识库管理功能
    • 实现多数据源搜索引擎配置和优化逻辑
    • 增强了 UI 中的知识库切换和管理
  • 新：增强租户信息管理
    • 添加了专门的租户信息页面
    • 改进的用户和租户管理功能

🎨 UI/UX 改进

  • 重新设计：设置页面具有改进的布局和功能
  • 增强：具有多知识库支持的菜单组件
  • 改进：初始化配置页面结构
  • 优化：登录页面和身份验证流程

🔒 安全修复

  • 修复：思维组件中的 XSS 攻击漏洞
  • 已修复：内容安全策略 (CSP) 错误
  • 增强：前端安全措施和输入清理

🐛 错误修复

  • 固定：应用程序LLM模型检查逻辑

  • 改进：文档内容组件显示

🧹 代码清理
