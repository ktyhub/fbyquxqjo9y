WeKnora v0.6.0

小版本 发布时间2026年5月21日 来源Tencent/WeKnora 英文原文

WeKnora v0.6.0

这个项目是干啥的：一个能基于你自己的文档资料回答问题的知识库系统，支持多个知识库和翻译，给想搭智能客服的公司用。

变更架构图

亮点

  • 多租户 RBAC 现端到端强制执行 — PR #1367 新增 schema、强制执行、成员管理、所有权转移和审计日志（跟踪 #1303）；#1385 将租户 RBAC 和每用户租户上限暴露为环境变量开关，#1406 把跨租户超管 Admin 同步到 UI 门控。这是本版本最大的架构转变：从单一共享工作区迁移的团队必须预置角色/成员并重新审计 API 调用，因为强制执行由配置驱动，此前开放的跨租户操作现在可能被拒绝。#1421 中链接了中文 RBAC 指南。
  • 检索改为知识库级并扇出到多个向量库 — #1310 引入知识库级检索引擎解析的工厂，#1386 将查询扇出到绑定到某知识库的每个向量库，#1372 在创建/复制/删除时校验这些绑定。实际影响：一个知识库现在可以跨多个后端，结果集可能包含此前从未命中的内容，错误绑定的存储会在写入时而非查询时静默失败。当一个 KB 绑定多个存储时，请关注排序与去重行为。
  • docreader gRPC 被收紧——破坏性部署变更 — #1308 不再将 docreader gRPC 端口发布到主机，#1359/#1361 新增带强化 TLS/token 上线的认证，#1363 将 grpcio 最低版本提高到 1.78.0 以匹配重新生成的 proto。如果你此前通过主机发布端口访问 docreader，该路径已消失——请改用网络内发现并配置 TLS/token 凭据。Python 客户端必须升级到 grpcio ≥1.78.0，否则会出现生成版本不匹配的错误。
  • CLI 在一个版本内从 v0.3 跳到 v0.6 — #1315、#1342、#1354、#1368 新增扩展的管理接口与 session 子树、强化的输出契约并与主流对齐、agent CRUD 及带审计驱动清理的分块子树，以及文档等待/状态/多 ID 删除。输出契约在 v0.4 和 v0.6 被刻意强化，因此任何解析 CLI stdout 的脚本都应重新验证——字段结构和命名被有意规范化了。
  • 凭据获得一等 API 与加密，新后端上线 — #1364 将凭据迁移到 /credentials 子资源，支持静态加密和测试连接 UX；#990 对敏感字段脱敏并防止编辑时丢失凭据。新集成：智谱 AI embedding（#1365/#1366）、华为云 OBS 存储（#1377），以及带受控开关的可配置 Doris 兼容模式（#1395）。使用旧的内联凭据字段的客户端需要迁移到该子资源。
  • 升级卫生：Go 1.26、迁移修复与更清晰的 API 错误契约 — #1407 将 go.mod 升级到 Go 1.26.0；#1334 在迁移 000041 中先创建 pg_trgm 再建 trigram 索引（修复全新数据库上升级失败）；#1335 让迁移错误带上排障链接。#1336/#1339 将 ErrSessionNotFound 和 ErrKnowledgeBaseNotFound 跨 handler 映射为 404，消费者终于可以依赖 404 语义——请更新依赖旧 200/500 行为的代码。#1384 将 DISABLE_REGISTRATION 与 auth.registration_mode 统一，升级时请核对配置键。
