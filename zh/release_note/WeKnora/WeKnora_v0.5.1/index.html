WeKnora v0.5.1

修订 发布时间2026年4月30日 来源Tencent/WeKnora 英文原文

变更架构图

亮点

  • 代理与 IM 执行 — 代理模型调用现在有专门的超时，同时移除了会中止多轮推理的流水线级超时（#1059、#1070）。IM 会话按代理隔离，并在删除后恢复（#1069）；回复中的私有存储链接被重写为 HTTP URL 以便 IM 投递（#1068）。长时推理现在可以完成，而不会让单次 LLM 调用无界运行。
  • 文档摄取与长文件处理 — Wiki Lite 摄取新增加锁、失败操作重排队和一致的同步重试（#1064），独立图片上传不再被错误过滤（#1076）。DOCX 解析不再有默认 100 页上限（#1071），因此长文档可以完整摄取——但可能需要更多处理时间和内存。
  • 检索与分析正确性 — 重排序优先级在 Execute 与 rerankResults 之间对齐（#1067），减少依赖路径的结果顺序差异；宽查询回退现在能拿到知识库文档列表（#1072）。数据分析 SQL 新增校验与类型处理（#1053），让格式错误或类型敏感的查询更早暴露；升级后请重新检查自定义的排序假设。
  • 安全与加密失败处理 — 加密后的 API Key 值（enc:v1:...）不再暴露给 UI，并可在 API Info 页面重置（#1087、#1089）。无法解密的加密数据库字段现在显式失败，而非静默处理（#1100）；部署前请验证加密密钥与现有密文。
  • 多租户与集成运维 — 租户扫描同时接受旧版和当前 payload 格式（#1060），客户端可切换租户（#1085），用户菜单下提供租户级 IM 渠道总览（#1102）。新增微信小程序插件（#1055）增加了另一个 IM 入口；多租户集成应验证其 payload 与渠道路由。
  • 破坏性变更 — 未声明。
