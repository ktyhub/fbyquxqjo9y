WeKnora v0.4.0

小版本 发布时间2026年4月15日 来源Tencent/WeKnora 英文原文

发生了什么变化

  • 修复：允许 https://github.com/Tencent/WeKnora/pull/911 中的 @voidkey 通过环境变量配置 MINIO_ENDPOINT
  • 修复：解决 https://github.com/Tencent/WeKnora/pull/914 中 @tsukiga-kirei 的流媒体工具调用中的工具名称重复问题
  • feat(agent): 支持 https://github.com/Tencent/WeKnora/pull/916 中 @tsukiga-kirei 定制的 LLM 调用超时
  • https://github.com/Tencent/WeKnora/pull/923 中 @voidkey 的壮举/连接器概念
  • 壮举：通过 @ochanism 在 https://github.com/Tencent/WeKnora/pull/922 中添加 VectorStore 实体、存储库和迁移
  • 壮举：通过 @the-waste-land 在 https://github.com/Tencent/WeKnora/pull/925 中添加对远程模型的 Azure OpenAI 支持
  • 壮举：@DaWesen 在 https://github.com/Tencent/WeKnora/pull/926 中添加视频多模式功能
  • 修复/ Dockerfile 由 @DaWesen 在 https://github.com/Tencent/WeKnora/pull/931 中构建错误
  • 壮举（网络搜索）：在 https://github.com/Tencent/WeKnora/pull/930 中添加 ollama 网络搜索提供商支持 #907 by @jhao0413
  • fix: 修正视频相关迁移文件版本号冲突，从 000032 改为 000033 by @DaWesen in https://github.com/Tencent/WeKnora/pull/937
  • 壮举：https://github.com/Tencent/WeKnora/pull/938 中 @lyingbug 的 Wails 桌面应用程序、精简版自动设置和 UI 增强功能
  • 壮举：通过 https://github.com/Tencent/WeKnora/pull/939 中的 @lyingbug 添加具有重试机制和特定于平台的关闭信号处理的服务器侦听功能，以提高鲁棒性
  • https://github.com/Tencent/WeKnora/pull/941 中@lyingbug 的壮举/桌面应用程序
  • 修复：将 neo4j 驱动程序从 v6 降级到 v5，以修复 https://github.com/Tencent/WeKnora/pull/942 中 @lyingbug 的 Go 1.24 Windows 内部编译器错误
  • 修复：恢复到 neo4j v6 并解决 Go 1.24 Windows 编译器错误，@lyingbug 在 https://github.com/Tencent/WeKnora/pull/943 中使用 -p=1
  • feat(web-search): 添加 baiduweb 搜索提供程序支持 #907 by @jhao0413 in https://github.com/Tencent/WeKnora/pull/944
  • feat(im)：在 https://github.com/Tencent/WeKnora/pull/946 中添加微信与二维码登录的集成以及 @lyingbug 的长轮询支持
  • 修复(im): 在 https://github.com/Tencent/WeKnora/pull/947 中通过 @voidkey 发送到 IM 之前去除 和 引用标签
  • 壮举：将 WeKnoraCloud 提供商与聊天/嵌入/重新排名模型集成，并由 @begoniezhao 在 https://github.com/Tencent/WeKnora/pull/927 中签名的文档阅读器
  • 重构：通过在 https://github.com/Tencent/WeKnora/pull/954 中用 @begoniezhao 的 AES utils 替换 CryptoService 来简化加密
  • feat(im)：通过 https://github.com/Tencent/WeKnora/pull/955 中的 @voidkey 支持私有 WeCom 部署的自定义端点
  • 壮举：在 https://github.com/Tencent/WeKnora/pull/933 中添加带有类型和连接测试的 VectorStore 服务层
  • 功能：@peterchan2020 在 https://github.com/Tencent/WeKnora/pull/949 中添加阿里云存储配置 *修复（嵌入）：删除https://github.com/Tencent/WeKnora/pull/960中@begoniezhao BatchEmbed中硬编码的TruncatePromptTokens
  • 重构：https://github.com/Tencent/WeKnora/pull/956中@peterchan2020将OSS服务从AWS S3 SDK迁移到阿里云OSS SDK v2
  • 壮举：在 https://github.com/Tencent/WeKnora/pull/934 中添加 @ochanism 的 VectorStore CRUD API 端点和文档
  • 壮举：attachment_support by @MaoMengww in https://github.com/Tencent/WeKnora/pull/935
  • feat(weknoracloud)：通过@lyingbug在https://github.com/Tencent/WeKnora/pull/961中实现凭证管理和状态检查
  • feat(prompt_templates)：在https://github.com/Tencent/WeKnora/pull/962中添加文档分析提示并通过@lyingbug增强重写模板描述
  • 通过 @lyingbug 在 https://github.com/Tencent/WeKnora/pull/966 中删除视频解析器
  • 壮举（发布）：更新至版本 0.4.0，包含 https://github.com/Tencent/WeKnora/pull/967 中 @lyingbug 的新功能、改进和错误修复
  • feat(weknoracloud)：通过@lyingbug在https://github.com/Tencent/WeKnora/pull/974中实现WeKnoraCloud VLM集成
  • feat(router): 通过 @lyingbug 在 https://github.com/Tencent/WeKnora/pull/976 中实现 Lite 版本的自动设置失败处理
