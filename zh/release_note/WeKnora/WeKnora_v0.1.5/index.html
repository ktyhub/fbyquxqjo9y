WeKnora v0.1.5

修订 发布时间2025年10月20日 来源Tencent/WeKnora 英文原文

变更流程图

亮点

  • 多知识库与多数据源检索 — v0.1.5 让多知识库操作成为一等能力（#321），并新增可配置的多数据源检索（#319），菜单组件现在负责知识库切换与上传前校验。这是本次最核心的能力变化：此前假设单一知识库的集成应重新审视查询与摄取路径。MCP server 还新增基于文件的知识创建（#361），对自动化摄取流水线很有用。
  • 租户信息与 API Key 生命周期 — 新增租户信息页展示存储配额与使用率（#312），后端现在通过 types.Tenant 和 tenantService.UpdateTenant 自动生成并轮换租户 API Key。UI 中对 Key 做了掩码并提供复制入口。注意：任何依赖从设置页读取明文 Key 的自动化或内部文档都需要更新。
  • 更严格的初始化与 VLM 校验 — 初始化向导现在强制更严格的表单校验，校验 VLM/OpenAI 兼容端点 URL，并预览/校验多模态上传（InitializationContent.vue）；App LLM 模型检查也做了修订（#322）。升级提示：首次运行时曾被容忍的端点或模型配置现在可能被拒绝——上线前请验证 VLM URL。
  • 前端安全加固 — 修复“思考”渲染路径中的 XSS（#308）和 CSP 错误（#311），并加固输入校验与敏感值掩码。编辑提示：如果你把自定义 HTML/Markdown 喂给模型输出或推理视图，现在会被转义或清理——请针对该构建测试富内容流程。
  • 需要关注的 API 行为变化 — 新增 URL 重复错误类型并引入 409 Conflict 处理（#339），handler.GetSystemInfoResponse 和 types.Tenant JSON 字段的内部结构也有变化。解析系统信息或租户数据的客户端应重新验证，调用方需处理重复创建 URL 时的 409。PostgreSQL 镜像也升级到 v0.18.9-pg17（#365），重新部署时请计划数据库兼容性与备份检查。
  • 构建与部署 — Docker 脚本现在识别 amd64/arm64，并通过 get_version.sh 和 build_images.sh 注入 VERSION / COMMIT / BUILD_TIME / GO_VERSION，配合对 LDFLAGS 友好的 Makefile（#326、#330、#332、#335）。这带来可复现、可追溯的多架构镜像，值得在 CI 中采用。另外，一个 [WIP] 的知识抽取与图数据库功能已落地（#343）——请视其为实验性功能，不要在生产中依赖。

概述

  • 本次合并包含若干功能增强、UI/UX 改进、安全修复与错误修复，覆盖后端服务、前端界面、镜像构建和部署脚本等模块。
  • 主要目标：多知识库支持、租户/账户增强、初始化流程优化、前端安全与体验改进，以及 DevOps 脚本和 Docker 镜像构建的健壮性提升。 亮点
  • Multi-knowledgebase 支持与多数据源检索优化（前端与后端协同改进）。
  • 租户信息页与 API Key 管理功能增强（包括 API Key 生成与复制交互）。
  • 初始化向导（Initialization）结构优化并加入更完善的验证与多模态（VLM）配置校验。
  • 前端安全改进：修复 XSS、隐藏 UI 中的 API Key 等敏感信息。
  • Docker / CI：改进镜像构建脚本与跨平台检测，增强构建信息注入（VERSION / COMMIT / BUILD_TIME / GO_VERSION）。 功能与增强
  • 新增多知识库（Multi-knowledgebases）操作支持与管理（UI 与后端逻辑）。
  • 增强租户信息管理，新增租户页面与更友好的存储配额、使用率展示（参见 TenantInfo.vue）。
  • 初始化向导改进：更严格的表单验证、VLM/OpenAI 兼容 URL 校验及多模态文件上传预览与校验（参见 InitializationContent.vue）。
  • 后端：API Key 自动生成与更新逻辑（见 types.Tenant 与 tenantService.UpdateTenant）。 用户界面/用户体验
  • 重构设置页与初始化页面布局，优化按钮状态、加载与提示信息，上传/预览体验改进。
  • 菜单组件增强：多知识库切换与上传前校验逻辑（参见 menu.vue）。
  • 隐藏/保护敏感信息（例如 API Key）并增加复制交互提示（参见 TenantInfo.vue）。 安全修复
  • 修复前端潜在 XSS 漏洞并增强输入校验与内容安全策略。
  • UI 隐藏 API Key 并改进复制行为提示，提升信息泄露防护。 错误修复
  • 修复 OCR/AVX 支持相关问题与图像解析并发错误。
  • 修复前端路由/登录跳转问题与文件下载内容错误。
  • 修复 docreader 服务健康检查与模型预取问题。 DevOps / 构建
  • 改进镜像构建脚本，增强平台/架构检测（amd64 / arm64），并在构建时注入版本信息（见 get_version.sh 与 build_images.sh）。
  • Makefile 与构建流程完善，便于 CI 注入 LDFLAGS（参见 Makefile）。
  • 脚本与迁移工具（migrate）使用和文档完善（参见 migrate.sh）。 文档
  • 更新 README 与多语言文档（EN/CN/JA）与 release/CHANGELOG（详见 CHANGELOG.md 与 README.md）。
  • 补充 MCP server 使用说明与安装（见 mcp-server/INSTALL.md）。 开发者/内部 API 变更（可参考）
  • 新增/变更后端系统信息响应结构：handler.GetSystemInfoResponse。
  • 租户数据结构与 JSON 存储字段：types.Tenant。
