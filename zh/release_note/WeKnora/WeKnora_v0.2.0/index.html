WeKnora v0.2.0

WeKnora v0.2.0

变更流程图

亮点

  • Agentic ReACT 模式 — v0.2.0 把 WeKnora 从一次性 RAG 推进到推理-行动循环：代理跨多个知识库检索，调用用户配置的 MCP 和网页搜索工具，并在产出总结报告前反复反思迭代。这是本次的核心能力——你现在可以构建多步、使用工具的工作流——但也意味着更多 token、更高延迟和非确定性的工具路径。请为可观测性做好规划；会话流程页现在暴露工具调用执行过程以帮助排查。
  • MCP 工具扩展性 — 代理可通过三种传输方式扩展——Stdio、HTTP Streamable 和 SSE——并内置 uvx 和 npx 启动器。传输选择是这里真正的部署决策：Stdio 让工具与服务同机本地运行，而 HTTP/SSE 访问远程服务，因此请根据网络和运维模式选择，不要把它们当成可互换的。
  • 集中式模型管理与租户共享 — 模型配置被整合，模型选择现在位于各知识库的设置中，并且模型可跨租户共享。共享模型对租户用户可消费但不可编辑或查看细节——有利于治理，但意味着无法对共享模型做按租户定制。
  • 类型化知识库（FAQ + 文档） — 知识库现在带有显式类型，在文档知识库之外新增 FAQ 专属操作（批量导入/删除、在线录入与测试），以及文件夹/URL 导入和标签管理。请把它当作一次迁移步骤：现有知识库需要在重新设计的设置页中指定类型并选择模型，因此升级后请重新验证检索行为。
  • 异步任务与自动数据库迁移 — 工作现在通过 MQ 支撑的队列执行，在重启间保证任务完整性，升级时自动进行 schema/数据迁移。运维上这是最重要的升级提示：请先备份，但迁移预期是全自动的。docker-compose.dev.yml 快速开发模式和事件发布/订阅机制完善了平台能力。
  • 破坏性变更 — 本版本未明确说明。

WeKnora v0.2.0 Release Notes

发布日期：2025-12-05 这是一个重大功能更新，引入了 ReACT Agent 模式、模型管理系统、FAQ 知识库等。

🚀 主要特点

ReACT 代理模式

  • 新的 ReACT Agent 模式，带有用于知识库检索的内置工具
  • 支持用户配置的MCP工具和网络搜索工具来访问外部服务
  • 多次迭代和反思，提供全面的总结报告
  • 跨知识库检索支持，允许选择多个知识库

模型管理系统

  • 集中模型配置管理
  • 知识库设置页面添加模型选择
  • 跨多个租户的内置模型共享功能
  • 租户可以使用共享模型，但无法编辑或查看模型详细信息

多类型知识库支持

  • 支持创建常见问题解答和文档知识库类型
  • 文件夹导入功能
  • URL导入功能
  • 标签管理系统
  • 在线知识录入能力

常见问题知识库

  • 新增FAQ型知识库
  • 批量导入和批量删除功能
  • 在线常见问题解答条目
  • 在线常见问题解答测试能力

对话策略配置

  • 支持配置Agent模式和普通模式模式
  • 可配置的检索阈值
  • 在线提示配置
  • 精确控制多轮对话行为和检索执行方式

网页搜索集成

  • 支持可扩展的网络搜索引擎
  • 内置DuckDuckGo搜索引擎

MCP 工具集成

  • 支持通过MCP扩展Agent功能
  • 内置 uvx 和 npx MCP 启动器工具
  • 支持三种传输方法：Stdio、HTTP Streamable 和 SSE

🎨 UI/UX 改进

  • 重新设计：具有代理模式/正常模式切换的对话界面
  • 重新设计：登录页面用户界面
  • 增强：按时间顺序分组的会话列表
  • 新：快速操作区域具有统一的 UI 视觉效果
  • 改进：知识库列表卡显示类型、知识计数和构建状态
  • 新：常见问题解答和文档列表页面中的面包屑导航
  • 重新设计：知识库设置页面，具有类型、模型、分块方法和高级设置的单独配置
  • 新：权限配置的全局设置页面
  • 增强：对话流程页面带有工具调用执行过程显示

⚡ 基础设施升级

  • 新：基于 MQ 的异步任务管理确保服务重启后任务的完整性
  • 新：自动数据库迁移支持版本升级期间的架构和数据迁移
  • 新：使用 docker-compose.dev.yml 的快速开发模式，可快速启动开发环境
  • 改进：日志结构优化
  • 新：事件订阅和发布机制 完整 Changelog：CHANGELOG.md
