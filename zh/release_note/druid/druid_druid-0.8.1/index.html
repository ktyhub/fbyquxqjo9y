druid 0.8.1

修订 发布时间2015年9月16日 来源apache/druid 英文原文

从 0.8.0 更新

不应该有更新问题，并且可以遵循标准更新程序进行滚动更新

新功能

  • #1259 实验性 查询时查找 (QTL) - – 能够在查询时执行有限的连接。 简单的示例用例是国家/地区代码到国家/地区名称。
  • #1374 实验性 Hadoop 批量重新索引和 Delta 摄取。 重新索引允许您使用新架构来摄取现有的 Druid 段，删除某些列、更改粒度等。“Delta”摄取允许将数据附加到数据源中的现有间隔。有关详细信息，请参阅新的 dataSource inputSpec 和 multi inputSpec。

改进

  • #1465 从 HDFS 读取 Hadoop 配置文件
  • #1472 支持使用组合器进行 Hadoop 摄取
  • #1506 在摄取期间更好地支持空输入行
  • #1518 添加了对 Azure 深层存储的更多支持
  • #1550 添加配置选项以打印所有 HTTP 请求到日志
  • #1563 #1602 改进了 Broker 上的合并性能
  • #1567 #1568 改进了段活动的错误日志记录
  • #1596 改进了协调器控制台，现在是一个单独的 Maven 依赖项，而不是巨大的代码转储
  • #1601 减少段扫描期间的锁争用
  • #1603 改进了词典 TopN 的性能
  • #1643 解释为什么 SegmentDescriptorInfo 不存在的有用原因 改进了索引服务、摄取和协调器端点的测试覆盖率

错误修复

  • #1406 修复 groupBy 在超过最大中间行数时中断的问题
  • #1441 修复关闭输出流时被抑制的刷新错误
  • #1469 修复 druid.metadata.* 属性不一致的属性名称
  • #1484 JobHelper.ensurePaths 将正确设置配置中的属性
  • #1499 使用重命名的聚合器修复 groupBy 缓存
  • #1503 修复 ZK 中泄漏的索引服务状态节点
  • #1534 修复近似直方图的缓存
  • #1616 修复本地索引任务中的依赖错误
  • #1627 修复实时任务在关闭时卡住的问题，即使状态显示为成功
  • #1634 允许 IrcFirehoseFactory 彻底关闭
  • #1640 版本 tarball + 脚本中的软件包扩展用于运行德鲁伊服务器
  • #1653 修复路由器查询指标中发出的成功标志
  • #1659 在终止段上，不要在 HDFS 上留下版本、间隔和数据源目录
  • #1681 修复重叠段不适用于摄取段 Firehose

文档

  • 新的 Firehoses 文档、评估 Druid 以及大量修复。
  • 改进了使用 CDH 的文档
  • 添加了 PostgreSQL 元数据存储的说明
  • 有关如何使用 ApproximateHistograms 的更多文档 完整的更改列表可以在此处找到
