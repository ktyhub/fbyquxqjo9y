druid 0.7.1.1

修订 发布时间2015年4月9日 来源apache/druid 英文原文

druid druid-0.7.1.1

新功能

  • 按星期几、一天中的小时等对结果进行分组 我们添加了对时间提取函数的支持，您可以根据 DateTimeFormatter 支持的任何内容对结果进行分组。有关更多详细信息，请参阅 http://druid.io/docs/latest/DimensionSpecs.html#time-format-extraction-function 。
  • 审核规则和动态配置更改 Druid 现在支持记住规则或配置更改的原因以及更改者。请注意，您必须自己提供作者和评论字段。默认情况下将记录发出配置更改的 IP。有关更多详细信息，请参阅 http://druid.io/docs/latest/Coordinator.html 上的标题“X-Druid-Author”和“X-Druid-Comment”
  • 为元数据存储的密码提供程序提供支持 这使得人们能够编写一个模块扩展来实现获取元数据存储密码的逻辑。
  • 在 Druid 节点上启用 servlet 过滤器 这使得人们能够为 Druid 请求编写身份验证过滤器。

改进

  • 代理上的查询并行化以实现长间隔查询 我们添加了将长间隔查询分解为多个可以并行运行的较短间隔查询的功能。这应该会提高更昂贵的 groupBy 的性能。有关更多详细信息，请参阅 http://druid.io/docs/latest/Querying.html#query-context 上的“chunkPeriod”
  • 更好的模式探索 代理现在可以返回按时间间隔细分的数据源的维度和指标。
  • 提高代码覆盖率 我们添加了许多单元测试来提高代码覆盖率，并将在未来使用 Coveralls 跟踪覆盖率。
  • 额外的摄取指标 添加了失败的持久性和失败的切换的附加指标。
  • 用于批量摄取的可配置输入格式 (#1177)

错误修复

  • 修复了有时代理和协调器会错过段公告，导致空指针异常的错误。 (#1161)
  • 修复了聚合器和后聚合器命名相同时 groupBy 查询会失败的错误 (#1044)
  • 修复了在选择查询中不包含 pagingSpec 会生成模糊 NPE 的错误 (#1165)。感谢油炸硬件！ -“bySegment”groupBy 查询现在应该可以工作（#1180）
  • 在用于 Hadoop 索引的减速器中荣誉 ignoreInvalidRows
  • 通过 https 从 Maven Central 下载依赖项
  • 更新了 MySQL 连接器以修复最新 MySQL 版本的问题
  • 修复联合数据源上的 timeBoundary 查询 (#1243)
  • 修复 DruidSecondaryModule 的 Guice 注入 (#1245)
  • 修复 log4j 版本依赖性 (#1239)
  • 修复分区号 0 不存在时的 NPE (#1190)
  • 修复任意粒度规范 (#1214) 并忽略索引任务间隔无效的行 (#1264)
  • 修复 AsyncQueryForwardingServletTest 中的线程饥饿问题 (#1233)
  • 更多有用的 ZooKeeper 日志消息
  • 各种新的单元测试
  • 将 MapDB 更新为 1.0.7 以修复错误
  • 修复在 hadoop 上开发时重新上传独立快照 jar 的问题 (#1261)

文档

  • 重新设计了 Druid 文档流程并修复了许多错误。
  • 感谢@infynxx 修复了我们许多损坏的链接！
  • 感谢@mrijke 对指标和发射器配置进行了许多修复。
  • 感谢 @b-slim、@bobrik 和 @andrewserff 提供文档和示例修复

其他

  • 感谢@housejester 改进了启动脚本。
