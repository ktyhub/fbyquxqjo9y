druid 0.15.1-incubating

修订 发布时间2019年8月16日 来源apache/druid 英文原文

druid druid-0.15.1-incubating

Apache Druid 0.15.1-incubating 是一个错误修复版本，其中包括对基于 Apache Zookeeper 的段加载、“druid-datasketches”扩展等的重要修复。

错误修复

协调员

#8137 协调器在尝试加载段时抛出异常（由 #8140 修复）

中层经理

#7886 Middlemanager 由于任务文件损坏而启动失败（已由 #7917 修复） #8085 修复分叉任务运行器任务关闭，使其更加优雅

查询

#7777 timestamp_ceil 函数错误或具有误导性（已由 #7823 修复） #7820 subtotalsSpec 和过滤不返回结果（由 #7827 修复） #8013 修复 ExpressionVirtualColumn 功能；修复 groupBy 对 StorageAdapter#getColumnCapability 的不当使用。

API

#6786 apache-druid-0.13.0-incubating 路由器 /druid/router/v1/brokers （由 #8026 修复） #8044 SupervisorManager：向批量端点添加授权检查。

指标发射器

#8204 HttpPostEmitter 在使用 emitAndReturnBatch 时抛出类转换异常（由 #8205 修复）

扩展
数据草图

#7666 草图-核心-0.13.4 #8055 包装 ByteBuffer 时强制使用本机顺序

Kinesis 索引服务

#7830 Kinesis：修复 getPartitionIds，应该检查 isHasMoreShards。

移动平均查询

#7999 Druid 移动平均查询导致循环引用错误（由 #8192 修复）

文档修复

#8002 改进扩展页面中的 pull-deps 参考。 #8003 添加对物化视图扩展的缺失引用。 #8079 修复文档格式 #8087 修复教程文档中对 bin/supervise 的引用

从 0.15.0-incubating 及更早版本更新

由于问题 #8137，当从_具体_0.15.0-incubating 更新到 0.15.1-incubating 时，建议在历史服务器之前更新协调器，以防止升级期间段不可用（这通常是相反的）。从 0.15.0-incubating 之前的任何版本升级都不会出现这些问题，并且可以正常完成。

已知问题

构建 Docker 图像当前已损坏，将在下一个版本中修复，请参阅 #8054（已由 #8237 修复）以了解更多详细信息。
