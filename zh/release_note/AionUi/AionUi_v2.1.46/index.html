AionUi v2.1.46

修订 发布时间2026年8月3日 来源iOfficeAI/AionUi 英文原文

亮点

反重力支持

  • Google 的反重力 (agy CLI) 现在是完全支持的内置代理。以前它可以被选择，但什么也不做——没有聊天界面出现，并且第一条消息从未发送。现在，它像任何其他代理一样通过 ACP 聊天界面运行。

消息锚轨

  • 长对话会沿着聊天区域的左边缘获得一条消息锚轨：每条用户消息打勾，悬停以预览该回合，click 直接跳转到该回合。导轨顶部的放大镜为对话搜索提供了第二个更明显的入口点。

资源管理器在文件夹中显示

  • 右键 click 资源管理器中的任何文件可在系统文件管理器中显示它（仅限桌面）。

启动和更新可靠性

  • 缓慢的后端启动不再被错误地报告为损坏的安装。以前，即使后端处于活动状态并正在侦听，运行状况检查超时也可能会弹出阻塞的“重新安装/检查防病毒”对话框 - 对于重新安装无法修复的问题的误导性建议。
  • 在操作系统文件监视配额耗尽的系统上（在 ARM Linux 上常见），后端现在可以正常降级而不是无法启动，并且 UI 不再归咎于不完整的安装。
  • 已经自我修复的安装完整性故障会在发出警报之前得到协调，因此您不会收到有关不再存在的问题的警告。
  • 手动“检查更新”现在将 CDN 通道清单视为权威，因此当 GitHub API 无法访问时检查仍然有效。

修复和改进

  • 从资源管理器打开文件会恢复预览面板中的多选项卡行为，而不是替换当前选项卡。
  • CLI 特工的第一回合不再错误地使用 aionrs 提供者模型。

引擎更新（AionCore v0.1.56 → v0.1.57）

  • 反重力（agy CLI）作为直接 CLI 代理添加 - 上面支持的后端一半。
  • 后台工作现在可见。 工作流程、后台 Bash 命令和后台任务子代理用于使 Claude 对话完全静音 - 17 分钟的工作流程在整个飞行过程中没有显示任何内容。他们现在会实时传输进度卡，结果会不按顺序交付，而不是触发无提示的回合。
  • 当代理仍在构建其回合时到达的取消现在将被应用而不是被删除。
  • 现在，会收获脱离其进程组的工具子进程，并且会重试激活捆绑的 Node 运行时的瞬时故障，而不是显示为硬错误。
  • Windows 路径输出不再泄漏逐字 \\?\ 前缀。
  • 数据库迁移预修复现在涵盖 030 之前的任何起点，扩大了针对启动阻止升级的保护。

发生了什么变化

  • 修复（预览版）：在#3821中通过@tcp404从资源管理器打开文件时恢复多选项卡
  • feat(explorer)：在#3820中添加@tcp404在文件夹中显示的上下文菜单（仅限Electron）
  • 修复（对话）：使反重力对话可以在 UI 中使用，由 @kaizhou-lab 在 #3812 中实现
  • 壮举（对话）：通过 @IceyLiu 在 #3824 中添加带有搜索入口点的消息锚轨
  • 杂务（预览）：通过@tcp404在＃3822中切断死出口链和目录选择模式
  • 修复（guid）：阻止 CLI 代理第一次使用 @kaizhou-lab 在 #3827 中的 aionrs 提供者模型
  • 修复（运行时）：在 #3828 中@piorpua 发出警报之前协调自愈安装完整性故障
  • feat(update): 通过@kaizhou-lab 在 #3830 进行手动更新检查 CDN 权威
  • 修复（启动）：停止将后端启动缓慢错误地报告为 @piorpua 在 #3831 中的安装损坏
