JeecgBoot v3.7.3springboot3sas

JeecgBoot v3.7.3springboot3sas

这个项目是干啥的：是一个基于Spring Boot的低代码后台开发平台，让企业开发者用生成器和现成模块快速搭出管理系统，少写重复的增删改查。

变更架构图

亮点

  • Spring Boot 3 与 JDK 17 基线 — 该分支把平台迁移到 Spring Boot 3 和 JDK 17，并提供配套的 JDK 17 Docker 镜像（#5563、#7317）。采用前请按这条基线验证运行时、构建和部署配置。
  • 移除 Shiro，改用 Spring Authorization Server — 认证机制重构以支持第三方登录和 Spring Authorization Server（#5819、#6243、#6646）。自定义认证、租户处理和权限校验都需要重测；这是本版本影响最深远的架构变更。
  • 令牌工具更新与客户端兼容性 — 新增令牌校验、客户端辅助工具、强制登出和手动生成令牌（#5965、#6014）。更短的 token 改善与主分支前端的兼容（#6899），但假设旧 token 格式的客户端可能需要验证。
  • 安全与授权修复 — 去掉了授权拒绝异常的堆栈信息，并缓存权限加载以减少重复查询（#5995）。Redis 认证序列化处理在回退后又再次调整（#7327、#7329、#7332）；上线时请清理受影响缓存并验证会话恢复。
  • 依赖与代码生成修复 — Fastjson 升到 2.0.43，Tomcat 换成 Undertow（#5716），Druid 1.2.22 兼容性修复支撑升级后的技术栈（#6081、#6091、#6092）。请审查容器专属配置和 JSON 库的假设，别当成直接替换的补丁。
  • 运维与 Online 表单可靠性 — 修复覆盖 WAR 启动失败、WebSocket 连接、Online 数据库同步与表单加载、仪表盘 401 响应，以及 Redis key 扫描（#6182、#6194、#6199、#6878、#7564、#7950）。其中 #8007 对 CVE-2023-6378 的修复是优先采用本版本的具体理由。本版本未声明破坏性变更。
