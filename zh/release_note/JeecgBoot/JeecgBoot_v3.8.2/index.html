JeecgBoot v3.8.2

修订 发布时间2025年8月9日 来源jeecgboot/JeecgBoot 英文原文

JeecgBoot v3.8.2

这个项目是干啥的：是一个基于Spring Boot的低代码后台开发平台，让企业开发者用生成器和现成模块快速搭出管理系统，少写重复的增删改查。

变更架构图

亮点

  • AI 辅助 Online 开发 — Online 3.8.2-GA 新增 AI 建表、Mock 测试数据和 AI 报表生成。上线前请审查生成的表结构、SQL、权限和租户边界。
  • 报表管控与 SQL Server 可靠性 — Online 报表现在支持权限控制和租户隔离，高级查询支持多选筛选。分页修复确保 SQL Server 的 OFFSET … ROWS FETCH NEXT 查询带上排序，避免未排序报表报错。
  • 代码生成更完整 — 生成器支持自定义按钮和 JS 增强，生成的菜单 SQL 也带上组件名。请核对重新生成的路由和组件映射；ERP 主从表刷新与关联记录创建的修复（#8163、#8575、#8532）也减少了数据完整性方面的意外。
  • 必须迁移 XXL-JOB — starter/executor 版本不一致导致定时任务跑不完的问题修好了（#8621），但 XXL-JOB 2.4.0+ 移除了旧的分片参数获取方式。升级前请审查自定义任务并更新分片处理逻辑。
  • 依赖与数据库变更 — MyBatis-Plus 升到 3.5.12，JSqlParser 到 4.9，JimuReport 到 2.1.1，JimuBI 到 2.1.0。本版本还改了数据库结构：先备份，再执行随附的迁移/初始化脚本，并对 Oracle、SQL Server、PostgreSQL 上的自定义 SQL 做回归测试。
  • 安全与部署修复 — 修改密码的水平越权漏洞已修复（#8567），Swagger 接口与实际接口不匹配的问题也修了（#8665）。上线前请两项都验证；新增的单体与微服务 Docker Compose 脚本以及 pgvector 服务让全新部署更简单。

升级日志

本次升级重点增强了在线功能，新增AI智能建表、AI测试数据和AI报表自动生成能力，大幅提升数据处理效率；同时全面强化代码生成器，支持自定义按钮和JS增强代码生成。此外，新增APP版本管理、权限自定义首页公告和全新通知系统等实用功能。请注意，本次升级涉及数据库结构调整，请务必提前做好数据备份和测试验证，确保平稳升级。
