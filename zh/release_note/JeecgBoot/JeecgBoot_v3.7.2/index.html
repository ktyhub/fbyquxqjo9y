JeecgBoot v3.7.2

JeecgBoot v3.7.2

变更流程图

亮点

  • 免费大屏设计器 — 集成 JimuBI，提供免费的仪表盘与数据可视化设计器，同时将 JimuReport 升级到最新版；带 token 感知和租户隔离的仪表盘访问问题也已修复（#7444）。对通过带鉴权链接对外分享仪表盘的部署更有价值。

  • Redis 兼容性与可扩展性 — 用 SCAN 替换阻塞式 KEYS 查询（#31），并避免 JeecgRedisCacheWriter 使用 KEYS（#6907），解决集群或托管 Redis 禁用该命令的问题（#6918）。这是生产环境值得升级的运维类修复；发行说明还提到 Redis 订阅/启动与 SAS 序列化修复。

  • 在线 ERP 数据丢失与报表修复 — 修复在线 ERP 表单编辑主记录时可能删除全部子表数据的严重问题（#7190），以及子表显示/查询、在线报表字段排序、中文字段名和 UNION 支持等问题。显著提升低代码表单与报表流程的安全性和可用性。

  • qiankun 微前端支持 — JeecgBoot 现在可以作为 qiankun 子应用运行，并修复了相关集成问题（#6947、#7285）。把它嵌入 Vue 3 微前端壳的团队，应验证对应的 qiankun 集成与生命周期配置。

  • SAS / Spring Boot 3 可靠性 — 修复可能导致用户意外退出的 token 刷新行为（#7305）、@IgnoreAuth 处理（#7459）、XXL-JOB 分页报错和在线表单日期格式问题。SAS 用户升级后应回归测试鉴权流程和对时区敏感的表单渲染。

  • 前端与表单组件修正 — 修复 FormProps 传递（#7150）、分组表头行编辑（#7384）、BasicTable 选择/树形行为、港澳地区联动，以及循环行后 XLSX 模板公式问题。自定义表格、生成的 ERP 表单和导出功能最值得针对性测试。
