JeecgBoot v3.8.0

小版本 发布时间2025年4月18日 来源jeecgboot/JeecgBoot 英文原文

JeecgBoot v3.8.0

变更流程图

亮点

  • 低代码与 AIGC 融合 — v3.8.0 把 AI 应用、模型管理、知识库和工作流编排带进 JeecgBoot 的 Java + Vue3 平台。核心优势在于集成：AI 流程可以调用已有业务 API 和逻辑，而不是作为一套独立的大模型应用栈运行。

  • 工作流变成可复用 API — 画布式 AI 设计器支持自定义开发节点和实时执行检查。开发者可以把智能体行为打包成可供业务应用调用的服务；请把对外暴露的工作流当作生产 API 对待，集成前审查鉴权、校验和失败处理。

  • RAG 文档处理能力增强 — 知识库支持 PDF、PPT 等常见文档格式，以及包含图片的完整 Markdown 仓库；聊天回复中也保留 Markdown 格式和图片，减少文档密集型应用的预处理工作。生产使用前请在复杂源文档上验证转换保真度。

  • 云端与本地模型共用一套管理层 — 支持的集成横跨 OpenAI、Claude、Gemini、DeepSeek、Qwen、智谱，以及 Ollama 等本地运行时，并提供向量数据库连接。这使混合云/本地部署成为可能，但团队应逐一验证各提供商的能力是否对等，不要假设每个模型都支持相同功能。

  • 聊天助手可嵌入现有系统 — 通过 iframe 集成，第三方应用无需重建聊天界面即可加入基于知识库的对话式辅助。嵌入时请在目标环境中测试会话处理和跨域行为。

  • 破坏性变更 — 发行说明中未公布。

AIGC应用平台介绍

JeecgBoot 平台的AIGC功能模块，是一套类似Dify的AIGC应用开发平台+知识库问答子系统，是一款基于LLM大语言模型AI应用平台和RAG的知识库问答系统。其洞察的界面结合了AI流程编排、RAG管道、知识库管理、模型管理、活动监控、实时运行可观察等，让您可以快速原型到生产，拥有AI服务能力。

AI赋能低代码：目前提供了AI应用、AI模型管理、AI流程编排、AI对话助手，AI建表、AI写文章、AI知识库问答、AI领域建议等功能；支持各种AI模型ChatGPT、DeepSeek、Ollama、智普、千问等。

Dify VS JEECG AI

JEECG AI与Dify相比，在多个方面表现出显着的优势，特别是在文档处理、格式和图片保持方面。以下是一些具体的优点：

  • Markdown文档库导入： JEECG AI允许用户直接导入整个Markdown文档库，这不仅保留markdown格式，还支持图片的导入，确保文档内容的完整和可视化效果。
  • 对话回复格式美观： 在对话过程中，JEECG AI能够保持内容回复的原格式，也不丢失图片，使得输出的文章更加美观，不会出现格式错乱的情况，还支持图片的渲染。
  • PDF文档导入与格式转换： JEECG AI在处理PDF文档时，能够更好地保留原始格式和图片，保证转换后的内容与原始文档保持一致。这哥们的功能在很多AI产品中表现不佳，而JEECG AI在这方面做出了显着的优化

功能特点

  • AI流程：提供强大的AI流程设计器引擎，支持编排AI工作流程，满足复杂业务场景，支持上部构建和实时运行查看AI流程运行情况。
  • AI流程即服务：通过AI流程编排你需要的智能体，结合AI+自定义开发节点实现功能性API，让你瞬间拥有各种智能体API。
  • AI助手对话功能：集成ChatGPT、Deepseek、智普、体内大模型等AI模型，提供智能对话和生成式AI功能，深度与知识库结合提供更精准的知识。
  • RAG功能：内容从文档文档到检索的所有内容，支持从PDF、PPT等常见文档格式中提取文本，支持检索增强生成（RAG），将未数据训练与AI模型集成，提升交互能力。
  • AI知识库：通过导入文档或已有问答进行训练，让AI模型能够根据文档以饮酒对话方式回答问题。
  • 模型管理：支持对接各类大模型，包括本土大模型（Deepseek/ Llama 3 / Qwen 2 等）、国内公共大模型（通义千问 / 腾讯混元 / 字节豆包 / 百度千帆 / 智谱 AI / Kimi 等）和国外公共大模型（OpenAI / Claude / Gemini 等）；
  • 无缝嵌入：Iframe一键嵌入，支持将AI聊天助手快速嵌入到第三方系统，让系统快速拥有智能问答能力，提高用户满意度。
