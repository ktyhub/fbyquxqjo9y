anything-llm v1.2.2

anything-llm v1.2.2

变更流程图

亮点

  • 通过插件实现自定义代理技能 — 头条功能（PR #2202）：你现在可以编写任意 NodeJS 技能来扩展 @agent 调用——“凡是 NodeJS 能做的，这里都能做”。这把代理从固定工具集变成扩展平台，因此预计你会构建并分发自己的技能，并应把插件接口当作一个新的集成面，随其演进而锁定版本并测试。
  • @agent 与技能通过开发者 API — PR #2161、#2158、#2171：代理运行——现在包括自定义技能和 RAG 代理插件——可以从 dev API 调用触发，并新增 session-ID 支持。这让技能可以被编程驱动，而不再仅限 UI；把多轮工作流接入自有应用时，请留意 session-ID 语义。
  • 浏览器扩展与真正的网页摄取 — PR #2066、#2224、#2163、#2199：Chrome 扩展可以把网页内容发送并嵌入工作区，包括来自密码保护、VPN 或其他非公开页面的内容，并新增 searchapi 支持的浏览。embed 移至子模块，并修复了 embed 域名的 onblur 处理。这拓宽了可摄取内容，不再局限于公开页面，但也意味着扩展范围的凭据现在可以喂给你的工作区。
  • 模型与提供商刷新 — Azure 的 gpt-4o（PR #2182）、新的 Voyage AI embedding 模型（PR #2193）、Gemini exp 模型（PR #2268）、更新的 OpenAI 模型列表与定价（PR #2269）、Ollama 顺序 embedding（PR #2230）以及 Milvus 修复（PR #2183）。如果你锁定了模型 ID 或 embedding 模型名称，请复核——切换 embedding 模型仍意味着要对现有工作区重新 embedding。
  • API 契约与提示词匹配行为 — Swagger 输出现在符合 OpenAPI 3（PR #2219），因此请重新生成并测试任何生成的客户端或消费 spec 的工具。另外，提示词现在精确匹配而非部分匹配（PR #2245），并伴随斜杠命令预设 UI 修复（PR #2260）和文档模态框的 Esc 关闭（PR #2222）；请检查依赖部分提示词匹配的自动化。

本版本无破坏性变更。

🥳 大变化

  • 自定义代理技能： 创建完全自定义代理技能以扩展 @agent 调用的功能。如果它可以在 NodeJS 中完成 - 你可以在这里完成。
  • AnythingLLM 浏览器扩展： 将信息从网络直接发送并嵌入到 AnythingLLM 或直接嵌入到您的工作区以供以后使用！这甚至可以让您从受密码保护、VPN 保护或其他非公开网页中抓取数据
  • 您现在可以通过开发者API使用@agent来运行技能。 （很好）
