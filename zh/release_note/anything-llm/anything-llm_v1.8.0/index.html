anything-llm v1.8.0

小版本 发布时间2025年4月18日 来源Mintplex-Labs/anything-llm 英文原文

anything-llm v1.8.0

变更流程图

亮点

  • 全面兼容 MCP，支持零停机热重载 — PR #3547 让 AnythingLLM 成为一等 MCP 客户端，代理可以通过 Model Context Protocol 使用外部工具。运维上最关键的细节是：MCP 配置可以即时更新并重新加载，无需重启，省去了增删工具服务器时的重启代价。Docker 镜像现在内置 npx 和 uv，因此通过 npm 和 Python 分发的 MCP 服务器开箱即用，不再需要定制镜像——请对照扩展后的配置接口复核你现有的服务器定义，并留意 #3569 中的 MCP UI 链接修复。

  • SQL 代理连接串解析器被替换 — #3560 更换了 SQL 代理使用的 connectionString 解析器。这是本版本低调但高风险的一处改动：如果你用 SQL 代理处理非标准连接串（特殊字符、自定义驱动或非常规 URI scheme），上线前务必验证解析和连通性，因为解析器替换可能引入变更日志未提及的静默回归。

  • Gemini 提供商重构到 OpenAI 兼容接口 — #3616 让 Gemini 走 OpenAI 接口 API，并伴随 #3609 的模型列表同步。好处是流式输出和工具调用行为与其他提供商更一致；需要注意的是，提供商层面的重构可能微妙改变函数调用语义，因此请重新测试任何依赖精确工具调用或固定行为的 Gemini 代理。

  • 代理崩溃循环保护 — #3617 关闭了代理自动重试。现在崩溃的代理运行会直接停止，而不是无限重试——用偶发故障恢复的机会换取对失控循环的保护。如果你之前依赖重试来扛过间歇性错误，这些错误现在会表现为运行中止。

  • UI 全面刷新与小幅行为修复 — 新的聊天首页（#3555）加上重新设计的引导流程与青色 CTA 样式（#3533、#3627）改变了默认外观；工作区设置的保存按钮移到了页面顶部（#3613）。低调但实用的改动：用户名现在接受句点（#3592），OpenRouter 引用处理得到修正（#3620），仓库 URL 会做 .git 规范化（#3655），嵌入组件同步支持 “thought” 模型（#3596）——如果你之前有本地绕行方案，请检查这些。

  • 提供商与语言覆盖扩展 — Azure AI 选项和模型映射通过新配置得到更新（#3660），新增日语（#3651）和俄语（#3658）翻译，并通过 Buildx 升级修复了 GHA 缓存弃用导致的 CI 构建基础设施问题（#3653）。这些大多是增量改动，但如果你使用 Azure 模型或曾被弃用的缓存 action 卡住，值得关注。

本版本未记录破坏性变更。
