anything-llm v1.8.2

修订 发布时间2025年6月10日 来源Mintplex-Labs/anything-llm 英文原文

anything-llm v1.8.2

这个项目是干啥的：一个能把你的文档喂给大模型、再像聊天一样提问的私有知识库工具，还能连接各种 AI 插件，适合想搭个人或团队知识库的人。

变更架构图

亮点

  • 聊天中途换模型 + 提示词历史 — 现在无需离开对话即可切换模型或提供商，通过 Cmd/Ctrl+Shift+L 打开切换提示框（#3969）；新增聊天提示词历史菜单（#3770）和本地存储的系统提示词版本，可跳回之前的提示词。这让提示词调校成为会话内可逆的工作流：在同一工作区跨提供商 A/B 测试提示词而不丢上下文。注意切换后的模型映射过时/回退行为（#3971），因为缓存的模型能力现在会被刷新。

  • AWS Bedrock 重构 — 该提供商针对多模态输入重写并修正了 token 限制（#3714），同时新增 IAM 角色认证（#2632）。Bedrock 用户应重新检查分块与上下文大小：修正后的 token 限制会改变文档切分方式和可容纳的上下文量，IAM 角色引入了可替代静态密钥的新凭据路径。

  • 向量存储与连接器扩展 — pgvector 现已成为受支持的向量数据库后端（#3788），并新增 Obsidian（#3798）、GitLab wiki 抓取（#3271）连接器和 Dell Pro AI Studio 提供商（#3829），另有 Drupal 连接器修复（#3878、#3893）。这拓宽了自托管的存储选择——pgvector 对已在用 PostgreSQL 的团队尤其值得关注——并增加了若干企业数据源。

  • Agent flows 获得 API 对齐与可组合性 — API 调用块现在支持 PUT/PATCH（#3937），新增 JSON 解析器块（#3863），flows 支持直接输出（#3873），并可从 community hub 导入 flows（#3867）。apiChatHandler 现在包含 agent 聊天（#3905），LLM Instruction 块移除了 inputVariable 必填要求（#3954）——编写更简单，但要重新测试那些假定该字段必填的既有 flows。

  • 更智能的上下文与可靠性修复 — 自动上下文窗口检测（#3817）现在能优雅处理无效的探测响应（#3896），另有 MCP 环境继承修复（#3909）、内容 embedding 时禁用消息发送（#3832）、从文件选择器过滤畸形后处理文档（#3853），以及重新设计的嵌入聊天组件（#3899）。这些减少了配置猜测和 embedding 相关竞态；如果你定制过嵌入组件，新版设计可能需要复核 CSS。

  • 破坏性变更 — 本版本无。

现在，您可以通过 cmd/Ctrl + Shift + L 在聊天过程中轻松交换模型或提供商，以显示工具提示菜单，从而无需更改屏幕即可轻松交换模型

现在，当您编辑任何工作区的系统提示时，我们会在本地存储此信息，以便您可以轻松引用或恢复到可能更适合给定模型或工作区的先前提示。
