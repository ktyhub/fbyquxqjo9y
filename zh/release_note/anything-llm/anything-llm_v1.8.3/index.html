anything-llm v1.8.3

修订 发布时间2025年7月9日 来源Mintplex-Labs/anything-llm 英文原文

变更架构图

亮点

  • 内置浏览器工具，支持带认证的爬取 — 这是 1.8.3（桌面版）的头条能力：代理现在可以爬取私有、需要认证或受其他门禁限制的页面，而不只是公开网页内容。这让 RAG 摄取和代理网页爬取流程能够作用于内部 wiki、已登录门户和付费墙来源——这些此前对 collector 是不可见的。在向终端用户开放前，请针对你的受限来源测试一下——发布说明中的文档链接界定了范围，而这一点实实在在地扩展了代理可触达的范围。

  • Community Hub 发布可复用配置 — 系统提示词（#3976）、代理 flows（#4001）和斜杠命令（#4019）现在都可发布到 AnythingLLM Community Hub。这把此前本地的、复制粘贴的配置变成可分享的制品，如果你要跨团队或跨部署标准化一套提示词/flow 配置，这很重要——你可以分发和复用，而不必在每个实例上手工重建。

  • 认证加固与提示词变量可见性变化 — 新增一个 flag，可在带凭据认证运行时禁用登录 UI 及其端点（#3984），适合锁定单用户或嵌入式部署。另外，静态定义的提示词变量现在任何授权用户都可读取（#4086）：方便，但如果你的模型此前假定这些变量是所有者作用域的，请重新审视该假设——访问边界放宽了。

  • 嵌入组件与流式行为 — 嵌入聊天组件现在真正遵守提示词、模型和 temperature 覆盖（#4036）；如果你之前在嵌入集成中固定了这些却疑惑为何被忽略，问题已修复——升级后请复查组件配置。通用 OpenAI 提供商新增一个由环境变量控制的禁用流式选项（#4079），查询模式聊天获得可发现性提示（#4076）。如果你依赖先前的覆盖语义，请留意组件行为。

  • 向量排序、tokenizer 与 collector 修复（有下游影响） — Milvus、Zilliz 和 Pinecone 的相关性分数上报得到修正（#4106），因此排序以及你依据旧（错误）分数调优的任何相关性阈值都可能变化——升级后请重新验证阈值。另修复了：tokenizer 竞态条件（#4091）、LMStudio 的零值 embeddings（#4084）、因 Google API 变更而失效的 YouTube 转录爬取（#4005），以及 Amazon Bedrock 的本地凭据文件支持（#3986）。

本版本无破坏性变更。

AnythingLLM 1.8.3 已上线！
