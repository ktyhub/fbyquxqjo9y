anything-llm v1.11.0

小版本 发布时间2026年2月18日 来源Mintplex-Labs/anything-llm 英文原文

变更流程图

亮点

  • 桌面悬浮面板（头条功能） — AnythingLLM Desktop 新增一个免费、操作系统级、应用感知的面板，单次按键即可打开，能把当前打开的应用程序内容吸收进你现有的聊天/文档/RAG/代理工作流。它仅限桌面版，被定位为推荐的日常使用模式；桌面用户仅凭此点就应升级，而纯 Web/Docker 部署则无法受益。

  • 破坏性变更与迁移 — PR #4958 把系统偏好迁移到基于字段的端点并移除了旧端点，因此任何调用旧端点的脚本/客户端都必须更新；PR #4922 把 AzureOpenAI 工具调用从 function 切换为 tool；PR #4828 统一了用户名约束（并借 #4914 清理了”用户名已存在”错误），可能影响已有用户名；PR #4909/#4908 重构了 Ollama 上下文窗口设置。如果你对接这些 API 或依赖自定义用户名，升级前请先测试。

  • 扩展的模型与提供商支持 — 新增 SambaNova（#4943）和 PrivateModeAI（#4937）集成、LMStudio LLM/embedder 的 API-token 支持（#4948）、Generic OpenAI LLM 的自定义 header（#4999）、LocalAI 与 Gemini gemini-embedding-001 的可配置 embedder 输出维度（#4980）、UAE 区域 Bedrock 模型（#4964），以及 Ollama SDK 从 0.5.10 升级到 0.6.3（#4977）。如果你使用其中任何后端，值得升级；否则无关。

  • UI 打磨与 bug 修复 — 新登录页（#4862）、聊天历史滚动到顶/底快捷键（#4870）、Web 推送通知（#4942）、思考块开关状态持久化（#4916）、流式聊天中引用 UI 闪烁的修复（#4897）、多处侧边栏修复（#4881、#4965、#4970）、代理工作区设置不再无限加载（#4956），以及编辑既有 SQL 代理连接的能力（#4848）。这些是日常用户的体验改善，但本身不构成升级理由。

  • 升级结论 — 这是一个内容充实的功能版本，不是空操作、重新打标签或仅元数据变更。桌面用户和需要新提供商/API 的人应升级；依赖被移除的系统偏好端点或 AzureOpenAI function 式工具调用的团队必须先迁移。对当前提供商满意的纯服务端用户可以安全跳过。
