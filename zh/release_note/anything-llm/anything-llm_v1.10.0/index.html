anything-llm v1.10.0

小版本 发布时间2026年1月22日 来源Mintplex-Labs/anything-llm 英文原文

变更架构图

亮点

  • 设备端桌面助手 — AnythingLLM Desktop 现在定位为 Granola/Otter/Fireflies 的本地、无上限替代品：它使用 NVIDIA Parakeet 加 AnythingLLM 自有编排，完全在设备端录制并总结会议，而且——对采用者至关重要——它能调用你现有的代理工具和 MCP 服务器，而非产出孤立的笔记。新增自定义总结模板、转录聊天、说话人识别，以及”已加入会议”桌面通知（在 Zoom/Slack/Discord/Teams 上跨应用开始录制）。重要性在于：转录与总结都留在你的环境内，没有速率限制或用量上限，消除了让许多团队不敢采用托管会议机器人的数据驻留障碍。
  • 第一方 Android 客户端 — 移动应用现已在 Google Play 上线，可与云/自托管实例以及桌面实例同步。这表明移动端是受支持的界面而非社区封装；在向外出用户推广前，请确认你自托管实例的 API 可达性与认证配置。
  • Azure OpenAI 迁移到统一的 v1 API — PR #4744 把 Azure OpenAI 迁移到 v1 API，提供完整代理支持和推理模型流式输出。对使用 Azure 的团队这是一个真正的迁移点：升级后请重新核验部署/模型名称和流式配置，因为集成路径发生了变化，而不只是新增功能。
  • 代理提供商与连接器获得实质修复 — Cohere 成为代理提供商（#4703），AWS Bedrock 代理新增流式支持（#4850），另有 Docker 的 AWS 凭据修复（#4842）。摄取方面，拖入聊天的 XLSX 文件终于通过合并工作表而对模型”可见”（#4847），YouTube 爬取在 upstream 未公开的 API 变更后得到修复（#4820），paperless-ngx 分页得到修正（#4757），Ollama embedding 请求现在可携带 auth token（#4766）。请留意这些连接器行为的变化，而不要假定只是纯粹的 bug 修复。
  • 需冒烟测试的底层迁移 — 一波显著的依赖与内部调整：bcrypt → bcryptjs（#4767），并从 collector 移除 bcrypt（#4747），Multer 2.0.0（#4768），Express 4.21.2（#4760），MCP SDK 1.24.3（#4773），Docker 基础镜像升级到 Ubuntu 24（#4754），以及 VectorDB 类迁移（#4787）。还有多个 ESM import 补丁（#4819、#4867）和懒加载 LanceDB（#4764）。自定义插件、脚本和基于 Docker 的部署应针对这些变更做回归测试。
  • 可靠性与引导流程打磨 — 全局 Error Boundary（#4765）防止整页白屏崩溃，过期用户权限与会话修复（#4751、#4770）加固了认证状态，聊天输入新增校验（#4811）。移除了引导流程中的”创建工作区”页面（#4823），新用户直接进入以本地语言显示工作区的主界面，同时工作区文件选择器为性能做了重构（#4740）。这些是较低风险的改动，但改善了首次使用体验并减少支持工单。

突出显示的更改

AnythingLLM 桌面助手上线了！

现在，AnythingLLM Desktop 可以直接替代 Granola、Otter、Fireflies 等付费工具。

  • 完全在您的设备上运行，无需加入即可录制会议或汇总任意文件
  • 由 NVIDIA Parakeet + AnythingLLM 的设备上编排提供支持
  • 可以调用任何代理工具、MCP 或您已与 AnythingLLM 一起使用的任何其他工具！
  • 自定义摘要模板、聊天记录，甚至说话人识别。
  • “已加入会议”桌面通知，用于使用 click 开始新的录制。适用于任何会议软件（Zoom、Slack、Discord、Teams 等）
  • 无速率限制、使用上限或限制 https://github.com/user-attachments/assets/355ad2fc-cca1-4e9d-8f08-4a1a08dac48d

AnythingLLM Mobile 已在 Google Play 上上线

Android AnythingLLM 移动应用程序 现已在 Google Play 上上线。这与 AnythingLLM 的云/自托管和桌面版本同步。 https://github.com/user-attachments/assets/e4232dfa-e42e-4d15-af9e-d58f2f0245f9

其他值得注意的变化

  • 删除了“创建工作区”页面 -> 现在直接返回主页，使用用户母语的新工作区
  • 重构工作区文件选择器以提高性能
  • 将 Azure OpenAI 迁移到统一的 v1 api，并提供完整的代理支持
  • 修复了 paperless-ngx 中的分页错误
  • 修复了未记录的 YouTube API 更改并破坏 YT 抓取工具的问题
  • 作为代理提供商实施了 Cohere
  • 依赖的颠簸
  • 修复了拖放到聊天中的 XSLX 文件对模型“不可见”的错误
  • MCP 修复了非 Windows 计算机上的路径
  • Docker 图像凹凸和补丁以获得健康的 Scout 分数 (B)
  • 在 UI 中添加了错误边界以防止白页崩溃
