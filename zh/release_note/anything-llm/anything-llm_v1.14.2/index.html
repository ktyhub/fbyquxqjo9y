anything-llm v1.14.2

修订 发布时间2026年6月22日 来源Mintplex-Labs/anything-llm 英文原文

anything-llm v1.14.2

这个项目是干啥的：一个能把你的文档喂给大模型、再像聊天一样提问的私有知识库工具，还能连接各种 AI 插件，适合想搭个人或团队知识库的人。

变更架构图

亮点

  • AWS Bedrock 提供商替换是破坏性变更（PR #5848） — AWS SDK 提供商被彻底移除（19 个文件中删除约 3100 行），转而通过 OpenAI 兼容客户端驱动 AWS 原生 chat-completions 端点。PR 明确指出这对依赖短时/IAM 式凭据而非长期 API key 的 Bedrock 用户是破坏性的——升级前请重新配置密钥或更换提供商。战略动因是移除最后一个”古怪”的 SDK 以解锁 Langchain 的移除，因此预计 1.15.0/2.0.0 线上会有更多提供商变动。
  • 原生 Chat 与 Agent 模式修复 Anthropic Opus 4.7/4.8（PR #5882） — 这些模型会拒绝 temperature、top_p 和 top_k 并返回 400 "temperature is deprecated for this model"。现在通过 noTemperatureModels 列表和 temperatureParam 辅助函数，在流式（Chat）和非流式（Agent/Query）路径上都剥离 temperature。先前的修复（#5822）只覆盖 Bedrock 提供商，因此原生 Anthropic 用户仍会遇到 400——这次才真正解除阻塞。
  • 两个新网页搜索后端：Brave（PR #5872）与 fastCRW（PR #5824） — 代理网页检索在现有集合之外又多了两个提供商选择。两者都是增量改动，无需迁移，但在将其设为默认前，请根据当前提供商评估其 API key 要求、定价和结果质量——搜索在代理工作流中是按查询计费的成本中心。
  • Groq 新增为语音转文字提供商（PR #5853） — 解决了长期存在的请求（#2239），新增 Groq 作为 STT 后端，在现有提供商之外为你提供低延迟的 Whisper 级语音输入选项。纯增量：现有 STT 配置不受影响。
  • 带认证的 Ollama embeddings 不再报告”离线”（PR #5863） — isAlive() 此前发起未认证的存活请求，因此受 Bearer token 保护的 Ollama 实例返回 401/403 并被标记为死亡，尽管 embeddings 实际可用。健康检查现在发送配置好的 authToken；未认证配置不受影响。如果你的 embedding 提供商在认证后显示为不可用，这就是修复。
  • 聊天 UX 与 RAG 正确性打磨（PR #5861、#5849、#5871） — 编辑提示词控件现在出现在用户提示词上，空工作区和代理聊天中恢复附加文件上下文及引用——后者最重要，因为缺失引用会让检索到的答案无法验证。批量删除线程现在只在悬停时显示，减少共享工作区中的误删。
