anything-llm v1.7.5

修订 发布时间2025年3月4日 来源Mintplex-Labs/anything-llm 英文原文

anything-llm v1.7.5

这个项目是干啥的：一个能把你的文档喂给大模型、再像聊天一样提问的私有知识库工具，还能连接各种 AI 插件，适合想搭个人或团队知识库的人。

变更架构图

亮点

  • Anthropic 提供商现代化 — 该提供商现在调用 Anthropic 的 /models 端点（#3376），并加入 Claude 3.7（#3337）。这很重要，因为旧的 Anthropic 端点正在退役，在较老版本上模型发现可能悄悄失效。如果你依赖 Anthropic，值得专门为此升级。
  • 文档 collector 加固 + 多语言 OCR — collector 在被 CDN 拦截时不再崩溃（#3373），aibitat runner 修复了空值检查（#3283），上传时非英文字符乱码的问题已修复（#3301），OCR 模块新增多语言支持（#3325）。对摄取爬取内容或非英文文档的人来说，这是主要的稳定性提升。
  • 开发者 API 扩展，含一处行为变化 — 新增按文件夹名检索文档（#3258）、上传到指定文件夹（#3276）和额外的 embed 端点（#3264）。注意开发者 API 中聊天排序默认值被”规范化”了（#3270）——依赖先前默认排序的客户端应重新验证，尽管未记录明确的迁移步骤或硬性破坏性变更。
  • 单用户 API key 删除 bug 修复 — 在单用户模式下删除一个 API key 此前会删除所有 key（#3358）。这是一次真正的防数据丢失修复；单用户部署仅凭此点就应升级。
  • 升级结论 + i18n/UI 打磨 — 其余为增量改动：阿拉伯语翻译（#3357）、聊天/数据上传窗口更广的语言支持（#3010）、自定义消息中的 markdown（#3267）、可配置消息布局（#3244）、用户简介字段（#3346）、新的思考/代理动画（#3302）、PPIO 提供商（#3211）、Ollama 客户端 auth token（#3005），以及 Windows 开发环境变量支持（#3354）。如果你使用 Anthropic、collector、非英文内容或受影响的 API/bug 路径，建议升级；如果都不相关且当前环境稳定，可安全跳过。

显着变化

  • Anthropic 提供者现在使用他们的 /models 端点（最终）
  • 修复了收集器上的错误以防止线程崩溃
  • 收集器支持多语言 OCR
  • 更多本地化和语言支持
