anything-llm v1.15.0

小版本 发布时间2026年6月25日 来源Mintplex-Labs/anything-llm 英文原文

anything-llm v1.15.0

这个项目是干啥的：一个能把你的文档喂给大模型、再像聊天一样提问的私有知识库工具，还能连接各种 AI 插件，适合想搭个人或团队知识库的人。

变更架构图

亮点

  • Magic Features 扩展到全系统（Desktop） — 1.15.0 引入 Echo（设备端听写，带屏幕感知）、Beacon（在任何应用中对选中文本操作，可完整使用你的代理技能、MCP 和工具）和 Tab（设备端、上下文感知的自动补全，定位为 Grammarly 替代品）。全部完全本地运行且免费，但有每日限额；Pro 只是取消这些限额，纯增量——没有移除或门禁任何现有功能，因此采用本版本不会改变你当前的工作流。
  • Intelligent Tool Selection 默认开启 — PR #5893 将 ToolReranker 翻转为默认启用。这是需要注意的行为变化：代理现在会对工具进行重排/选择子集，而不是一视同仁地呈现所有工具，因此依赖所有工具都可用的工作流可能需要调整提示词或工具描述以避免回归。
  • 聊天历史上限解除 — PR #5906 移除了存储聊天历史的上限。无需迁移，但如果你之前受截断/保留策略约束，现在要预期历史无限增长并相应规划存储。
  • Windows update-embeddings 修复 — PR #5907 解决了 Windows 路径上 Prisma “filename is missing” 的失败。如果你在 Windows 部署中遇到过，升级即可修复；除升级外无需配置变更。
  • GenericOpenAI embedder 前缀 — PR #5589 为 query/passage 前缀新增环境变量。如果你使用期望索引与查询时前缀不同的非对称 embedding 模型，这很重要——设置错误会悄悄降低检索质量。

本版本无破坏性变更。

AnythingLLM 现已成为跨操作系统的 AI 代理

借助桌面版 AnythingLLM 1.15.0，我们一直努力思考”把你的代理带到你身边”意味着什么。它仍然是本地的，但走出应用或浏览器的围墙。本版本带来了我们在这方向上首批 3 项功能——希望你喜欢。

AnythingLLM 现在是跨操作系统的 AI 代理

借助 AnythingLLM 1.15.0 桌面版，我们一直在努力研究将您的代理带到您身边的意义。仍然是本地的东西，但在应用程序或浏览器的范围之外。此版本包含我们关于此工作的前 3 个功能 - 我们希望您喜欢它们。

魔法功能介绍

神奇功能将人工智能带入您的整个计算机——而不仅仅是 AnythingLLM 内部。听写、文本操作和自动完成功能可在任何应用程序中完全在设备上使用。 所有魔法功能均可免费使用 - 无需注册。 Pro 取消了每日限制。

任何LLM Pro

AnythingLLM 没有任何变化。 Pro 纯粹是附加的 - 现有功能不会受到影响，也不会锁定任何内容。 每个专业版功能都将始终有免费的每日套餐，无需注册。 您可以此处 详细了解 AnythingLLM Pro 是什么。
