anything-llm v1.2.3

修订 发布时间2024年10月3日 来源Mintplex-Labs/anything-llm 英文原文

anything-llm v1.2.3

这个项目是干啥的：一个能把你的文档喂给大模型、再像聊天一样提问的私有知识库工具，还能连接各种 AI 插件，适合想搭个人或团队知识库的人。

变更架构图

亮点

  • 开发者 API 扩展可发送和调用的内容 — API 调用方现在可以调用 @agent 自定义技能（#2280）并附加文件/图片（#2373），而 workspaceThread 终于把 userId 当作真正可选（#2276）。这是向后兼容的放宽，现有集成继续工作；如果你此前一直绕开必填的 userId 或无法通过 API 传递附件，本版本移除了这些限制。
  • 大幅扩展的提供商与文件格式覆盖 — 新增通过 Tavily 的网页搜索代理支持（#2395）、新 LLM 提供商 DeepSeek（#2377）和带 Llama 3.2 模型的 Fireworks AI（#2300、#2384）、启用 Mistral Multimodal（#2343）、Perplexity 模型升级（#2275），以及 voyage-3 / voyage-3-lite embeddings（#2394）。文档方面获得 XLSX 支持（#2403）、从网页或本地复制/粘贴图片、文件和文本（#2326）、对 Dockerfile 和 Jenkinsfile 等无扩展名文件的异常处理（#2410）、文件类型过滤（#2378），以及 3GB body-parser 限制（#2390）——如果你摄取大型或异常文档并遇到过上传失败，这些与你相关。
  • Confluence 与 GitLab 连接器获得实质修复 — Confluence 现在接受更多 URL 格式（#2118）、自定义域名（#2328），并新增部署类型下拉框（#2376）；GitLab 现在可在自托管实例上工作（#2316）、加载所有分支（#2325）并能获取 issue（#2335）。被这些连接器卡住的企业和自托管团队有最强的升级理由。
  • 聊天、代理与嵌入聊天 UX 打磨 — 工作区代理可自动选择（#2357），流式读取更自然（#2336），嵌入聊天获得历史导出（#2329）和更详细的错误消息（#2306），另有滚动条显示/隐藏设置（#2187）、全选/取消全选上下文菜单（#2337）、改进的移除文档 UX（#2359）、完成超时修复（#2374）以及若干 UI 补丁（#2282、#2284、#2386）。大多是面向终端用户的体验改进，本身不构成升级理由。
  • 升级建议——无破坏性变更，选择性升级 — 变更日志未列出破坏性变更或迁移步骤；userId 变为可选以及新增的 plugin.json JSONSchema（#2344）都是增量改动。对开发者 API 消费者、使用 Confluence/GitLab 或新支持提供商/格式的团队，以及遇到文件上传上限的人值得升级。如果你在 v1.2.2 上且不触及这些集成，这个以功能和修复为主的补丁可以安全跳过。
