cline cli-v3.0.72

发布 发布时间2026年10月16日 来源cline/cline 英文原文

cline cli-v3.0.72

这个项目是干啥的：VS Code 里的 AI 编程插件，能自动帮你写代码、改文件、跑命令，还能接云端的 AI 任务。给在编辑器里写代码的开发者用。

变更架构图

亮点

  • 插件执行移到 worker（破坏性） — 插件不再跑在 hub 里，而是跑在 worker 中；如果当前构建跑不了插件，Cline 现在会在 cline config tools、cline hub plugins 和会话启动警告里明确告知，而不是默默在进程内处理。迁移：CLINE_PLUGIN_MODE=in_process 不再支持——改用 worker（默认）或 sandbox。任何钉住了该环境变量的人都必须更新，否则插件加载会失败。

  • 流式与请求可靠性 — 中途被 provider 错误打断的响应，现在会先重试最多 3 次再判定本轮失败，偶发的网络/provider 抖动不再轻易吞掉一轮对话。失败的模型请求还会记录 provider 的 request id，让支持工单更容易追踪。

  • Hub CLI 增强脚本能力与发现控制 — cline hub ensure 和 cline hub start 新增 --json（输出 hub URL 和 auth token）、--allow-port-fallback、--no-connectors 和 --login-shell-path；cline hub 接受 --discovery-path 来使用独立的发现记录——对自动化和非标准部署很有用。另外，cline hub 命令不再计入 CLI 激活统计，hub 的日常维护不会虚增你的激活指标。

  • 模型目录刷新改变大量默认值（行为变化） — 未选择模型时，Cline provider 现在用 Gemini 4 Argon。目录新增 Boundless 和 Standard Compute；SambaNova 改由目录提供，默认 MiniMax M3；Cline 推荐列表加入 Gemini 4 Argon、移除 Grok 4.7；免费列表用 Nemotron 3.5 Super VL 替换 Step 5 Preview；OpenCode Go 去掉 MiniMax M2.7。默认模型发生变化的有 Cortecs、CrossModel、Eden AI、Google Gemini、GitHub Copilot、Google Vertex AI、LLM Gateway、Ofox、OpenCode Go、Prime Inference（Gemini 4 Argon），Fireworks AI、Nebius Token Factory、Requesty（Muse Spark Open），CoreWeave、DigitalOcean、NanoGPT、Nvidia（Nemotron 3.5 Super VL），以及 Aixy 和 Neon（Claude Haiku 5.5）——如果你依赖隐式默认值，先确认你 provider 的默认模型。

  • 升级结论 — 插件用户（隔离性加上必须做的环境变量迁移）、遇到中途 provider 错误的人，以及想要新 provider 或脚本 flag 的人，都值得升级。钉住明确模型、不用插件、也不关心新 provider 或统计变化的用户可以放心跳过。这是真正的功能发布，不是空操作或重打标签。

  • 插件现在在工作线程中运行，而不是直接在集线器内运行。如果此版本无法运行插件，Cline 会在 cline config tools、cline hub plugins 和会话启动警告中如此说明，而不是在集线器内悄悄运行它们。不再支持 CLINE_PLUGIN_MODE=in_process；使用 worker（默认）或 sandbox

  • 当提供商错误中断响应时，Cline 在失败之前会重试最多 3 次

  • 失败的模型请求现在会记录提供者的请求 ID，这使得支持票证更容易追踪

  • cline hub ensure 和 cline hub start 获得 --json（打印中心 URL 和身份验证令牌）、--allow-port-fallback、--no-connectors 和 --login-shell-path。 cline hub 接受 --discovery-path 使用专用发现记录

  • 在使用统计中，cline hub 命令不再算作 CLI 激活

  • 由于没有选择任何型号，Cline 提供商现在使用 Gemini 4 Argon，这是 Cline 推荐列表中的新第一个型号

  • 更新了模型目录。添加了 Boundless 和 Standard Compute 提供程序，SambaNova 现在来自目录，默认使用 MiniMax M3。 Cline推荐列表添加了Gemini 4 Argon并删除了Grok 4.7，Cline免费列表用Nemotron 3.5 Super VL取代了Step 5 Preview。 OpenCode Go 不再列出 MiniMax M2.7。 Cortecs、CrossModel、Eden AI、Google Gemini、GitHub Copilot、Google Vertex AI、LLM Gateway、Ofox、OpenCode Go 和 Prime Inference (Gemini 4 Argon)、Fireworks AI、Nebius Token Factory 和 Requesty (Muse Spark Open)、CoreWeave、DigitalOcean、NanoGPT 和 Nvidia (Nemotron 3.5 Super VL)、Aixy 的默认模型发生更改和 Neon (Claude Haiku 5.5)、Agnes AI、Ambient、IteraCompute、Poe、Scaleway 和 SenseNova 完整 Changelog：https://github.com/cline/cline/compare/cli-v3.0.71…cli-v3.0.72
