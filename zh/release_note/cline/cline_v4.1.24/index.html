cline v4.1.24

修订 发布时间2026年10月13日 来源cline/cline 英文原文

变更流程图

亮点

  • Provider 默认值变化 — 升级前请复核 — 未选择模型时，Cline 和 OpenRouter 现在用 Claude Sonnet 5.5；302.AI、GitHub Copilot、Google Vertex AI、OpenCode Go、Requesty 等默认值也变了，多数变成 Claude Haiku 5.5 或 Muse Wonder 1.0。依赖隐式默认值的人，升级前先钉住当前模型以保持行为。OpenCode Go 现在用 https://opencode.ai/inference/go/v1，v0 只提供 v0-1.5-md。
  • 模型目录与 provider 设置 — 新增 Claude Haiku 5.5、AI/ML API、LowRouter 和 Prime Inference provider，Cline 免费列表加入 Step 5 Preview。选择 ai& 现在会显示它专属的 API key 和模型控件，而不是通用的 OpenAI 兼容 base URL 和自定义 header 表单。
  • 推理控制跨 provider 修复 — 在 GPT-6 Astra、GPT-6.1 Sol、Claude Fable 5 或 Claude Opus 5.5 上关闭推理不再返回 HTTP 400，且跨 provider 一致生效。仅有级别的 Gemini 模型也不再因 thinking budget 错误拒绝请求，推理设置切换更安全。
  • 更少崩溃、更少误导性错误、更少过早压缩 — MCP 服务器或钩子提前退出不再让扩展宿主崩溃；已退役模型 404 显示真实错误而不是登录提示；生产日志保留错误细节。图片不再虚增 token 估算，目录数据缺失时自动压缩回退到所选模型的上下文窗口。
  • 配置与编辑修复 — 符号链接的规则文件能加载，.claude/skills 技能会被发现，编辑器不再收到 null 替换文本，删除斜杠命令保留周围空格，旧设置不再创建空的 SAP AI Core provider。升级判断：用到这些工作流或受影响的 provider 就升；否则这是维护版本，除非想要目录刷新，否则可跳过。

已更改

  • 由于未选择任何型号，Cline 和 OpenRouter 提供商现在使用 Claude Sonnet 5.5。对于Cline，这是Cline推荐列表中的第一个型号。
  • 选择 ai& 显示其自己的 API 密钥和模型选择器，而不是具有基本 URL 和自定义标头的通用 OpenAI 兼容表单。
  • 更新了模型目录。添加了 Claude Haiku 5.5 和 AI/ML API、LowRouter 和 Prime Inference 提供商。 Cline 空闲列表添加了第 5 步预览。 v0 提供商现在仅提供其默认模型 v0-1.5-md，而 OpenCode Go 使用其新的 https://opencode.ai/inference/go/v1 端点。 302.AI、Cortecs、CrossModel、DevPass、DigitalOcean、Eden AI、GitHub Copilot、Google Vertex AI、LLM Gateway、Meta、Moark、NanoGPT、NEAR AI Cloud、Neuralwatt、Novita AI、Ofox、OpenCode Go、Requesty、Vivgrid 和其他一些（现在大多数是 Claude Haiku 5.5 或 Muse Wonder）的默认模型发生更改1.0）。如果您使用这些提供程序之一而不固定模型，则预计会出现不同的默认值。

已修复

  • 在 GPT-6 Astra、GPT-6.1 Sol、Claude Fable 5 或 Claude Opus 5.5 上关闭推理不再失败并出现 400 错误，现在适用于每个提供商。仅级别的双子座模型不再因思维预算错误而拒绝请求。
  • 在读取其所有输入之前退出的 MCP 服务器或挂钩不再在大约 3 秒后使扩展主机崩溃。
  • 来自过时或已退役模型 ID 的 404 不再显示为登录问题。 Cline 显示真正的错误而不是注销的卡。
  • Cline 输出日志中的错误保留其详细信息。生产版本过去常常删除它们，因此像“Cline OAuth登录失败：”这样的行没有显示任何原因。
  • 从输入中删除斜杠命令会保留其周围文本的间距。
  • 屏幕截图和其他图像不再夸大令牌估计，这使得自动压缩在对话接近极限之前就运行了。
  • 当目录条目没有上下文窗口时，自动压缩会使用所选模型的上下文窗口。
  • 现在加载符号链接的规则文件，并且现在发现 .claude/skills 中的技能。
  • 编辑器工具不再接收 null 来代替某些模型中要替换的文本。
  • 从旧版本迁移的设置不再添加空的 SAP AI Core 提供程序。 完整 Changelog：https://github.com/cline/cline/compare/v4.1.23…v4.1.24
