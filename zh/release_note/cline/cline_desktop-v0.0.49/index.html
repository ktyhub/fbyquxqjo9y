cline desktop-v0.0.49

发布 发布时间2026年10月26日 来源cline/cline 英文原文

变更架构图

亮点

  • 会话审查与代码上下文工具 — 新增 Changes 按钮（每轮/整个会话的行数统计 + diff 面板）、项目文件面板（文件树、只读多标签查看器、git 状态字母、agent 改过的文件可切 File/Diff，本地和 SSH 都可用）、用 Ctrl+反引号切换的底部终端面板，PR 状态从输入框栏移到头部按钮并带合并/检查详情与操作。对在应用内审查 agent 修改的人来说，这是升级的主要理由。无需迁移，但注意 PR 入口位置变了。

  • 本地模型与可配置快捷键 — 新的 Local Models 设置页管理 Ollama 和 LM Studio，带配置引导和显示已加载模型显存占用的输入框 chip；快捷键现在可在 Settings/应用/Help 菜单里编辑，Quit 可以要求长按（macOS 默认 1 秒），防止误退出。斜杠命令和 @file 提及现在渲染成 chip。跑本地模型或经常误退出的人值得升级。

  • Hub 可靠性与大会话修复 — Hub 启动失败现在显示 Retry/导出诊断界面，而不是每个操作都报 “desktop backend endpoint not ready”，General 设置里也有 Restart Hub 按钮；约 8 MB 以上的会话又能恢复了（之前 transcript 被发给 Hub 两次，超过消息大小限制）；打开另一个应用里正在跑的任务会附着到它，而不是启动一个停不掉的副本；任务中途关掉应用留下的孤儿请求会明确失败而不是挂住。遇到这些情况就该升级。

  • 模型/provider 变化——部分行为破坏性 — 目录刷新：新增 Liquid Inference 和 Munito AI；移除 CrofAI、iFlow 和 Llama；ClinePass 默认 Kimi K3.1 Pro；另 56 个 provider 默认值变化（多数变为 Kimi K3.1 Pro、MiniMax M3.1 Flash、DeepSeek V4.1 Flash 1017）。gemini provider 不再发送原生 Google Search（免费层 key 在 Gemini 3+ 上每轮 429，2.x 上丢掉所有 Cline 工具）；Kimi K3 在 Extra High/Max 下拿到 max 推理而不是被拒的 xhigh；自动压缩不再在上下文未知的模型上运行、也不再每隔几次工具调用就重复触发；请求重试从 5 次降到 3 次。用了被移除 provider 或受影响默认值的用户，升级后应重新检查模型选择——默认行为会变，但没有明确的迁移步骤。

  • 平台与工具修复——谁可以跳过 — 只流式输出推理就断线的连接现在会重试；ask_question 选完选项后继续执行、拒绝空回答、只附文件的回答也算；空列表的 run_commands 现在报错，PowerShell 下会给出引号转义和递归删除前确认的提示；定时任务状态/错误报告改进；无托盘的 Linux 桌面（Fedora/Debian 原生 GNOME）现在关窗即退出；SSH ProxyJump 别名可连接；未跟踪文件多时的几千个 git 进程问题已修；侧边栏排序会记住；仅供模型的内部消息和裸 user_input 包装不再泄漏到 transcript。这是实质性发布，不是重打标签或只改元数据——为工作流工具和可靠性修复值得升级，但依赖被移除 provider（CrofAI、iFlow、Llama）或已变默认值的用户可以跳过或计划重新配置。

  • 会话标题中的新 更改 按钮显示会话的行数，并打开一个窗格，列出上一轮或整个会话中更改的文件，以及每个文件的差异。当一个回合结束时，其下方的摘要会列出其更改的文件； click它以在该回合打开窗格

  • 项目文件面板（会话标题中的文件夹按钮）在对话旁边显示文件树，其中包含只读选项卡式查看器、git 状态字母以及会话更改的文件上的标记。代理编辑的文件有文件/差异切换。适用于本地和 SSH 环境

  • 集成的 终端面板 在窗口底部打开（使用 Ctrl+反引号进行切换）

  • 拉取请求状态从编辑器上方的栏移至标题按钮。它的菜单显示 PR 标题、合并状态和检查（首先检查失败），并允许您在 GitHub 上打开 PR、创建 PR、复制分支名称或刷新

  • 新的本地模型设置页面管理 Ollama 和 LM Studio 模型：设置指南、模型详细信息和存储，以及显示加载模型使用了多少内存的作曲家芯片

  • 按键绑定可在“设置”中配置（也可从应用程序和“帮助”菜单访问）。退出可能需要按住快捷键，macOS 上默认为 1 秒，因此更难意外退出

  • 斜线命令和 @file 提及在编辑器和发送的消息中显示为碎片

  • 如果集线器无法启动，应用程序现在会显示一个带有重试和导出诊断的启动屏幕，而不是因“桌面后端端点未就绪”而导致每个操作失败

  • 常规设置显示集线器的状态并具有重新启动集线器按钮

  • 打开已在另一个 Cline 应用程序中运行的任务现在会附加到该运行，而不是启动第二个无法停止的任务。等待中途关闭任务的应用程序的请求现在会失败，并显示一条明确的消息，而不是挂起

  • 具有非常大的记录（超过约 8 MB）的会话可以再次恢复。之前，记录被发送到集线器两次，超出了其消息大小限制

  • 文件和差异查看器中的长行会换行，并且滚动时行始终跨越整个宽度

  • 新的云聊天在您本地的 Cline 或 ClinePass 型号上启动。如果 Cloud 不提供该型号，ClinePass 订阅者将获得 ClinePass 型号，其他人将获得 Claude Sonnet 5.5

  • 粘贴的 Cline API 密钥现在取代了旧的浏览器登录，而不是被忽略。提供商设置字段在窄侧面板中正确堆叠

  • 侧边栏中的会话/项目排序选择在重新启动时会被记住

  • 在没有托盘的 Linux 桌面上（Fedora 或 Debian 上的普通 GNOME），关闭窗口会退出应用程序，而不是让它继续运行而无法退出

  • 仅适用于模型的内部消息不再显示在脚本中，并且实时会话标题不再显示原始 user_input 包装器

  • 计划状态保持最新状态，失败的运行显示完整错误

  • 检查更改不再在具有许多未跟踪文件的工作区中产生数千个 git 进程

  • ProxyJump 别名后面的 SSH 环境现在可以连接

  • 更新 toast 的重新启动按钮位于消息文本下方

  • 在模型仅传输推理后连接断开的回合现在会重试，而不是结束运行

  • 模型请求最多重试 3 次，而不是 5 次

  • Kimi K3 现在获得 Extra High 和 Max 的 max 推理，而不是它拒绝的 xhigh 设置

  • Gemini API 密钥（gemini 提供商）不再发送本机 Google 搜索。免费层密钥在 Gemini 3+ 上每轮都会失败，出现 429 配额错误，在 Gemini 2.x 上每个 Cline 工具都被丢弃

  • 自动压缩不再针对上下文限制未知的模型运行，并且在第一次压缩后每隔几次工具调用就不再运行

  • ask_question：选择一个选项后模型继续运行，空答案将被拒绝，只有附件的答案才算数

  • 具有空命令列表的 run_commands 现在返回错误而不是静默成功。在 PowerShell 上，该工具告诉模型 quote escaping 如何工作并首先确认递归删除

  • 更新了模型目录。添加 Liquid Inference 和 Munito AI 提供商，并删除 CrofAI、iFlow 和 Llama。 Cline 免费列表添加了 Reflection Beam、Nemotron 3.5 Lightning 和 Laguna S 2.1，并删除了 Mimo V2.6 Flash 和 Muse Spark 1.3 Contributor。 ClinePass 现在默认为 Kimi K3.1 Pro，并添加 MiniMax M3.1 Flash 和 DeepSeek V4.1 Flash 1017。其他 56 个提供商的默认型号发生变化，主要为 Kimi K3.1 Pro、MiniMax M3.1 Flash 或 DeepSeek V4.1 Flash 1017 完整 Changelog：https://github.com/cline/cline/compare/desktop-v0.0.48…desktop-v0.0.49
