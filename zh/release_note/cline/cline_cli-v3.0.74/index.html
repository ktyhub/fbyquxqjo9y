cline cli-v3.0.74

cline cli-v3.0.74

这个项目是干啥的：VS Code 里的 AI 编程插件，能自动帮你写代码、改文件、跑命令，还能接云端的 AI 任务。给在编辑器里写代码的开发者用。

变更架构图

亮点

  • 长任务可靠性 — 单凭这条就值得升。 打开一个已在其他 Cline 应用里运行的任务，现在会挂接到那个运行，而不是再起一个停不掉的；应用任务中途关闭导致的孤儿请求会带明确报错失败，不再挂死。cline hub status 和 cline doctor 不再因 Hub 卡死而永久挂起——健康检查 3 秒超时并报告为未运行。只流式输出推理就断线（例如 “The socket connection was closed unexpectedly”）的回合现在会重试。注意取舍：模型请求最多重试 3 次而不是 5 次，瞬时故障会更早暴露。

  • 工具行为变化 — 如果你脚本化 ask_question/run_commands 请复核。 准破坏性：run_commands 传空命令列表现在返回错误而不是静默成功，依赖旧空操作行为的调用方得处理。ask_question 在你选完选项后模型会继续跑，拒绝空回答，并且只带附件的回答也算数——期望选完就结束回合的流程会不一样。PowerShell 下工具会教引号转义并在递归删除前要求确认。插件斜杠命令在当前会话执行，skills 工具标签不再显示 null 参数。

  • 模型目录与默认值变动 — 最大的静默变更风险。 目录刷新新增 Liquid Inference 和 Munito AI，移除 CrofAI、iFlow 和 Llama；Cline 免费列表加入 Reflection Beam、Nemotron 3.5 Lightning 和 Laguna S 2.1，移除 Mimo V2.6 Flash 和 Muse Spark 1.3 Contributor。ClinePass 现在默认 Kimi K3.1 Pro，另有 56 个 provider 默认值变化（多数变为 Kimi K3.1 Pro、MiniMax M3.1 Flash 或 DeepSeek V4.1 Flash 1017）。依赖旧默认值或被移除 provider 的人，升级前先显式钉住模型。另外，gemini API key 不再发送原生 Google Search——免费层 key 在 Gemini 3+ 上每轮 429、在 Gemini 2.x 上丢掉所有 Cline 工具——Kimi K3 在 Extra High/Max 下现在拿到 max 推理级别，而不是被拒的 xhigh。

  • 自动压缩更保守。 上下文上限未知的模型完全不跑自动压缩，首次压缩后也不再每隔几次工具调用重复触发。对文档不全的模型更稳，但如果你靠激进的重压缩维持长会话，上下文会增长而不再自动裁剪。

  • 打包与 ACP 打磨 — 低风险、无需迁移。 编译后的 CLI 二进制现在从二进制内嵌资源加载插件并提供 dashboard，ACP 的 provider/account 选项也移到了正确的配置分类下。总之：为任务/Hub 挂死修复和推理断线重试而升；只有钉在被移除 provider 或旧默认模型上、或依赖 Gemini 原生 Google Search / 旧的空 run_commands 行为时，才需要跳过或谨慎分阶段升级。

  • 打开已在另一个 Cline 应用程序中运行的任务现在会附加到该运行，而不是启动第二个无法停止的任务。如果应用程序在任务中关闭，等待它的请求现在会失败，并显示一条明确的消息，而不是挂起

  • cline hub status 和 cline doctor 不再挂在已冻结的集线器上。现在，其运行状况检查会在 3 秒后超时，并且集线器被报告为未运行

  • 在模型仅传输推理后连接断开的回合（例如，“套接字连接意外关闭”）现在会重试，而不是结束运行

  • 模型请求最多重试 3 次，而不是 5 次

  • Kimi K3 现在获得 Extra High 和 Max 的 max 推理，而不是它拒绝的 xhigh 设置

  • Gemini API 密钥（gemini 提供商）不再发送本机 Google 搜索。免费层密钥在 Gemini 3+ 上每轮都会失败，出现 429 配额错误，在 Gemini 2.x 上每个 Cline 工具都被丢弃

  • 自动压缩不再针对上下文限制未知的模型运行，并且在第一次压缩后每隔几次工具调用就不再运行

  • ask_question：选择一个选项后模型继续运行，空答案将被拒绝，只有附件的答案才算数

  • 具有空命令列表的 run_commands 现在返回错误而不是静默成功。在 PowerShell 上，该工具告诉模型 quote escaping 如何工作并首先确认递归删除

  • 插件斜杠命令在活动会话中运行

  • 编译的 CLI 二进制文件加载插件并通过二进制文件中嵌入的资源为仪表板提供服务

  • ACP：提供商和帐户选项现在显示在正确的配置类别下

  • 技能工具调用标签不再显示 null 参数

  • 更新了模型目录。添加 Liquid Inference 和 Munito AI 提供商，并删除 CrofAI、iFlow 和 Llama。 Cline 免费列表添加了 Reflection Beam、Nemotron 3.5 Lightning 和 Laguna S 2.1，并删除了 Mimo V2.6 Flash 和 Muse Spark 1.3 Contributor。 ClinePass 现在默认为 Kimi K3.1 Pro 并添加 MiniMax M3.1 Flash 和 DeepSeek V4.1 Flash 1017。其他 56 个提供商的默认型号发生变化，主要为 Kimi K3.1 Pro、MiniMax M3.1 Flash 或 DeepSeek V4.1 Flash 1017 完整 Changelog：https://github.com/cline/cline/compare/cli-v3.0.73…cli-v3.0.74
