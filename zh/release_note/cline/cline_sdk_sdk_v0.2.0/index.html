cline v0.2.0

小版本 发布时间2026年10月26日 来源cline/cline 英文原文

变更流程图

亮点

  • 会话与运行生命周期（破坏性） — 启动一个已有运行在跑的会话，现在会重新附着到那个活跃运行，而不是替换它的运行时；如果启动时还带了 prompt 而运行正在进行，则会被拒绝。hub 会记录每个为会话注册了能力的客户端（包括中途加入已运行任务的客户端），把请求路由给第一个仍连接的客户端；一个都不剩时快速失败并给出可操作的提示，而不是永远挂住。桌面端云编排已移入 hub，session.list 新增 activeCloudCommands，云命令运行期间 hub 不再被换掉。依赖”启动即接管”进行中运行的集成必须改流程。

  • 模型 provider 与目录（部分破坏性） — gemini provider 不再发送原生 Google Search：Gemini 3+ 免费层 key 每轮都 429，Gemini 2.x 会丢掉所有 Cline 工具，这些用户因此失去原生搜索（Vertex 保留）。AI SDK 升到 ai 7.0.136 / @ai-sdk/provider-utils 5.0.58，max 推理级别现在直达 provider，不再被改写成 xhigh（Kimi K3 把 Extra High/Max 映射为 max）。目录从 7,041 缩到 6,457 个模型，移除 CrofAI、iFlow 和 Llama，新增 Liquid Inference、Munito AI 和 Munito AI (EU)，并改变了 56 个 provider 的默认值——钉住模型 ID 或依赖被移除 provider/默认值的用户应重新检查。

  • 重试与遥测 — 模型请求在首次尝试后最多重试 3 次（从 5 次降下来，对指望 5 次的调用方是收窄了预算）。只流式输出了推理就断线的轮次会重试，并丢弃那部分推理；含文本、媒体或工具调用的轮次仍绝不重试。失败尝试记入 Langfuse trace，取消的请求不再被报成 Langfuse 错误，新的 RunHealthObserver 停滞信号出现在 agent.run-finished / agent.run-failed 上。

  • 压缩、性能与 SSH — 模型输入上限未知时不再运行自动压缩（手动和溢出恢复压缩仍可用），压缩后的体积估算改用实际发送的消息（工具结果按截断后算），修掉了约 7 倍的高估——之前每隔几次工具调用就重跑压缩。checkpoint diff 改用单个 git cat-file --batch 进程读文件，而不是每个文件最多两次 git show，避免在未跟踪文件多的仓库里拉起几千个 git 进程。SSH 远端现在可在 ProxyJump 别名后工作，预算提高到连接 30 秒（原 10 秒）、每条命令 60 秒、隧道就绪 40 秒，ssh 中途退出时报告真实错误而不是 EPIPE，且 LocalForward 不再冲突。

  • 工具、插件与打包 — run_commands 现在拒绝空 commands 列表并在 schema 里声明 minItems: 1；ask_question 把裸选项包装成问题让模型继续往下走（空回答被拒，只附文件的回答算已回答）；PowerShell 描述覆盖反引号转义、字面路径加单引号和优先用 cmdlet。插件命令运行在活跃会话的 runtime 和 hub 中，发现目录出现时 watch 会恢复，编译好的二进制直接从二进制加载内嵌的插件/dashboard 资源并打包所有声明的 SDK runtime 导出，CLINE_PLUGIN_RUNTIME_DIR 会解析成绝对路径；@cline/ui 随 SDK 包一起发布（新增 Kbd 和 token chips）。这是真正的功能发布，不是重打标签或只改元数据：会话/云编排、Gemini/压缩/SSH 工作流或插件用户值得升级；只有这些路径都与你无关且钉住的模型 ID 不受影响时才可跳过。

  • 启动已经在运行的会话现在会重新附加到实时会话，而不是替换其运行时。之前，原始运行仍在继续，但无法到达，并且其记录写入落在陈旧的快照上。运行过程中包含提示的启动会被拒绝

  • 集线器记录每个注册会话功能的 client，包括加入已在运行的任务的 client，并将每个请求发送到第一个仍连接的任务。如果没有剩下，请求会很快失败，并显示一条用户可以采取行动的消息，而不是永远等待

  • 在模型仅传输推理后连接断开的回合现在会重试，并且部分推理将被丢弃。文本、媒体或工具调用的转弯仍然不会重试

  • 模型请求在第一次尝试后最多重试 3 次（从 5 次减少）。失败的尝试记录在 Langfuse 跟踪中，取消的请求不再报告为 Langfuse 错误

  • AI SDK 更新为 ai 7.0.136 / @ai-sdk/provider-utils 5.0.58。 max 推理现在到达了提供商：网关不再将其转换为 xhigh，Kimi K3 获得 max 以获得 Extra High 和 Max。尽管有新的 anthropic.* 自定义流部件，空人择转弯仍会重试

  • gemini 提供商不再发送本机 Google 搜索。在 Gemini 3+ 上，免费层密钥每次都会失败，并出现 429 配额错误，而在 Gemini 2.x 上，它会丢弃所有 Cline 工具。 Vertex 保留本机搜索

  • 当模型的输入限制未知时，自动压缩不再运行。手动和溢出恢复压缩仍然有效

  • 第一次压缩后，大小估计现在使用实际发送的消息，工具结果被截断。之前，它高估了大约 7 倍，并且每隔几次工具调用就会再次运行压缩

  • 检查点差异使用单个 git cat-file --batch 进程读取文件内容，而不是每个文件最多两个 git show 进程。具有许多未跟踪文件的工作空间用于生成数千个 git 进程

  • SSH 远程在 ProxyJump 别名后面工作。连接预算从 10 秒变为 30 秒，每个命令限制为 60 秒，隧道准备时间为 40 秒。当 ssh 上传中途退出时，会报告其真正的错误而不是 EPIPE，并且别名上的 LocalForward 不再与隧道冲突

  • ask_question 答案是有框架的，因此模型会继续追求简单的选择。空答案将被拒绝，只有附件的答案算作已回答

  • run_commands 因工具错误而拒绝空的 commands 列表，并且其架构现在通告 minItems: 1

  • 在 PowerShell 上，run_commands 描述解释了反引号 escaping、单引号文字路径、优先使用 cmdlet 而不是 cmd /c，以及首先确认递归删除

  • 插件命令在活动会话运行时和集线器中运行。当发现目录出现时插件手表再次开始工作

  • 编译的二进制文件直接从二进制文件加载嵌入的插件和仪表板资源，并且每个声明的 SDK 运行时导出都被打包

  • 配置的 CLINE_PLUGIN_RUNTIME_DIR 解析为绝对路径

  • 当 OpenRouter 没有与 Cline 推荐型号匹配时，其功能将从 Vercel 目录中填充

  • 桌面云会话编排移至中心。 session.list 报告 activeCloudCommands，并且云命令仍在运行时不会更换集线器

  • 核心添加了对话摘要和云延续支持

  • 运行失速遥测：agent.run-finished 和 agent.run-failed 携带来自新 RunHealthObserver 的失速信号

  • @cline/ui 现在在共享版本上随 SDK 软件包一起提供。它为 AgentComposer 中的斜线命令和文件提及添加了 Kbd 组件和令牌芯片

  • 更新了模型目录（7,041 → 6,457 个模型）。添加了 Liquid Inference、Munito AI 和 Munito AI (EU) 提供商，并删除了 CrofAI、iFlow 和 Llama。 Cline 免费列表添加了 Reflection Beam、Nemotron 3.5 Lightning 和 Laguna S 2.1，并删除了 Mimo V2.6 Flash 和 Muse Spark 1.3 Contributor。 ClinePass 增加了 Kimi K3.1 Pro（现在是默认设置）、MiniMax M3.1 Flash 和 DeepSeek V4.1 Flash 1017，并删除了 Mimo V2.5 和 V2.5 Pro。其他 56 个提供商的默认型号发生变化，主要为 Kimi K3.1 Pro、MiniMax M3.1 Flash 或 DeepSeek V4.1 Flash 1017 完整 Changelog：https://github.com/cline/cline/compare/sdk/sdk/v0.0.95…sdk/sdk/v0.2.0
