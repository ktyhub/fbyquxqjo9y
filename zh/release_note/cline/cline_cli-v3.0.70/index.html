cline cli-v3.0.70

发布 发布时间2026年10月8日 来源cline/cline 英文原文

变更架构图

亮点

  • 推理关闭的模型兼容性 — 提交信息生成和关闭推理的任务，在 GPT-6 Astra、GPT-6.1 Sol、Claude Fable 5 或 Claude Opus 5.5 上不再报 400。如果把其中某个模型钉住并关了推理，这个版本实际上是解锁这些工作流的必需版本；其他人这里没有收益。

  • 破坏性：CLI 命令与 flag 变化 — cline dashboard 改为 cline hub dashboard，旧命令仅作为隐藏别名保留；裸跑 cline hub 会打印子命令。原来接受但无效的选项现在报 “unknown option”：cline history --page，以及 cline schedule create/update 的 --autonomous、--no-autonomous、--idle-timeout、--poll-interval、--delivery-channel。裸 --retries 不带数字会被拒绝而不是崩溃。升级前从脚本里去掉这些，不过之前用它们保存的定时任务仍能加载。

  • MCP 与钩子可靠性 — MCP 服务器或钩子在读完所有输入前退出时，Cline 不再约 3 秒后退出；cline mcp add 现在会在设置向导里保留 --header 值——向导每次提示要一个 header，并像 --yes 一样校验每个（之前接受预填答案会保存一个没有 Authorization 等 header 的远程服务器）。迁移的 VS Code 设置也不再注入空的 SAP AI Core provider。依赖 MCP 服务器、钩子或带认证的远程服务器的人值得升。

  • 定时任务投递校验 — cline schedule create、update 和 import 现在会拒绝根本发不出去的投递，例如只有 --delivery-adapter 没有 --delivery-thread，或未知连接器，报错会点名要修的 flag 或 --metadata-json 路径。以前这种定时任务能保存，结果却被静默丢弃，所以升级后应审计现有自动化。

  • 模型目录刷新 — 新增 Claude Haiku 5.5，并改变 Google Vertex AI（Claude Sonnet 5.5 → Claude Haiku 5.5）、Cortecs、DevPass（LLM Gateway）、Eden AI、GitHub Copilot、LLM Gateway、NanoGPT、OpenCode Go、Requesty 和 Vivgrid 的默认模型，多数变为 Claude Haiku 5.5。复查这些 provider 上配置的默认值；不受影响的 provider 用户可以把这条和感知 CLINE_LOG_PATH 的 cline doctor log、修正过的 --help 默认值一起当常规更新。

  • 提交消息生成和带有推理关闭的任务不再因 GPT-6 Astra、GPT-6.1 Sol、Claude Fable 5 或 Claude Opus 5.5 上的 400 错误而失败

  • MCP 服务器或挂钩在读取其所有输入之前退出后，Cline 不再退出约 3 秒

  • 从 VS Code 扩展迁移的设置不再添加空的 SAP AI Core 提供程序

  • 当打开设置向导时，cline mcp add 会保留您的 --header 值。之前，接受预先填写的答案保存了没有标头的远程服务器（例如，Authorization）。该向导现在要求每个提示提供一个标头，并以与 --yes 相同的方式验证每个标头

  • cline dashboard 现在是 cline hub dashboard。旧命令仍然可以作为隐藏别名使用

  • 裸露的 cline hub 打印其子命令

  • 当设置该变量时，cline doctor log 打开由 CLINE_LOG_PATH 设置的文件

  • cline --help 已更正：--retries 显示其实际默认值 3（表示为 6），而 --thinking 解释说它回落到 /model 中选取的级别

  • 没有计数的裸 --retries 现在会因错误而被拒绝，而不是崩溃

  • 已接受但从未执行任何操作的选项被删除，现在失败并显示“未知选项”：cline history --page、cline schedule create/update --autonomous、--no-autonomous、--idle-timeout、--poll-interval 和 --delivery-channel。从脚本中删除它们。仍会加载随其保存的现有计划

  • cline schedule create、update 和 import 拒绝无法过帐的交货，例如没有 --delivery-thread 的 --delivery-adapter 或不是已知连接器的适配器。之前，计划已保存，但其结果从未默默发布。错误名称要修复的标志或 --metadata-json 路径

  • 更新了模型目录。添加克劳德俳句 5.5。 Google Vertex AI（Claude Sonnet 5.5 → Claude Haiku 5.5）、Cortecs、DevPass（LLM Gateway）、Eden AI、GitHub Copilot、LLM Gateway、NanoGPT、OpenCode Go、Requesty 和 Vivgrid（现在大多数是 Claude Haiku 5.5）的默认模型发生变化 完整 Changelog：https://github.com/cline/cline/compare/cli-v3.0.69…cli-v3.0.70
