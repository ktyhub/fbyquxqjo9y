cline desktop-v0.0.48

cline desktop-v0.0.48

这个项目是干啥的：VS Code 里的 AI 编程插件，能自动帮你写代码、改文件、跑命令，还能接云端的 AI 任务。给在编辑器里写代码的开发者用。

变更架构图

亮点

  • GPT-6 兼容性修复 — 发往 gpt-6-sol、gpt-6.1-sol 等模型的请求现在用 max_completion_tokens 替换被拒的 max_tokens，可在 OpenAI 和 Azure OpenAI 兼容端点上正常工作。用这些模型的人应升级。

  • 默认模型与 provider 目录变化 — Claude Sonnet 5.5 回归 Cline 默认和首选推荐。目录新增 CommandCode 和 Reflection，并改变 302.AI（Gemini 4 Argon）、Eden AI、Prime Inference（Muse Spark Open）、CoreWeave（Reflection Beam 1.0）、NanoGPT、Pioneer（Nemotron 3.5 Super VL）、Scaleway（DeepSeek V4.1 Flash）的默认值。这些 provider 的用户升级后应复查所选模型，因为默认自动变化会改变成本和行为。

  • 升级建议 — 这是有意义的兼容性与选模更新，不是纯元数据发布。用 GPT-6 模型或任何默认值变化的 provider 就升级；不受这些模型影响的用户可放心跳过。

  • GPT-6 模型（例如 gpt-6-sol 和 gpt-6.1-sol）适用于 OpenAI 和 Azure OpenAI 兼容端点。之前，每个请求都被拒绝，因为 Cline 发送的是 max_tokens 而不是 max_completion_tokens

  • Cline提供商的默认型号再次是Claude Sonnet 5.5，它又回到了Cline推荐列表的顶部

  • 更新了模型目录。添加 CommandCode 和 Reflection 提供程序。 302.AI (Gemini 4 Argon)、Eden AI 和 Prime Inference (Muse Spark Open)、CoreWeave (Reflection Beam 1.0)、NanoGPT、Pioneer (Nemotron 3.5 Super VL) 和 Scaleway (DeepSeek V4.1 Flash) 的默认模型发生变化 完整 Changelog：https://github.com/cline/cline/compare/desktop-v0.0.47…desktop-v0.0.48
