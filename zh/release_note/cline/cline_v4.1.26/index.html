cline v4.1.26

这个项目是干啥的：VS Code 里的 AI 编程插件，能自动帮你写代码、改文件、跑命令，还能接云端的 AI 任务。给在编辑器里写代码的开发者用。

变更架构图

亮点

  • 云任务成为一等公民，并有专属模型 — 设置 > API 配置里新增 Local | Cloud 开关（开启云会话时出现），用于选择新云任务运行的模型，与本地模型分开保存；点击云会话的模型标签即可在那里打开。启动/恢复沙箱现在会显示进度卡片（仓库、分支、启动沙箱 → 克隆仓库 → 启动 agent），agent 启动后卡片会收起；云会话会隐藏 Plan/Act 开关和自动批准栏，而不是把它们显示为禁用状态。
  • 破坏性 — 模型目录重排改变默认值并移除 provider — 新增 CommandCode、Reflection、Liquid Inference 和 Munito AI；移除 CrofAI、iFlow 和 Llama（升级前先从这些迁走）。如果你没钉住模型，默认值会变：大多数 provider 现在默认是 Kimi K3.1 Pro、MiniMax M3.1 Flash 或 DeepSeek V4.1 Flash 1017，ClinePass 默认 Kimi K3.1 Pro，未选择模型的 Cline provider 回退到 Claude Sonnet 5.5。
  • 修复 — 打断了整轮对话的 API 兼容问题 — GPT-6 模型（gpt-6-sol、gpt-6.1-sol）现在能在 OpenAI 和 Azure OpenAI 兼容端点上正常工作，SAP AI Core 也不再以 “Unsupported parameter: ‘max_tokens’” 拒绝请求——两者都改成发送 max_completion_tokens。gemini provider 不再发送原生 Google Search：免费层 key 在 Gemini 3+ 上每轮都因 429 配额错误失败，在 Gemini 2.x 上则会静默丢掉所有 Cline 工具。Kimi K3 在 Extra High/Max 下现在拿到 max 推理级别，而不是被拒绝的 xhigh；请求重试次数从 5 降到 3。
  • 修复 — 提示丢失、回答被吞和失控的压缩 — 任务启动时切换 Plan/Act 不再吞掉你的第一条提示或残留另一模式的工具；ask_question 在你选完选项后会继续执行，并拒绝空回答；旧问题抢走你下一条消息的竞态已消除；run_commands 传空列表现在会报错而不是静默成功（PowerShell 会解释引号转义并要求确认递归删除）。只流式输出推理就断线的请求会重试，自动压缩不再在上下文上限未知时运行，也不会每隔几次工具调用就重复触发；禁用的规则保持禁用；启动命令不再把聊天焦点抢到终端。
  • 值得升级吗？ — 只要你用 gemini provider（尤其是免费层/Gemini 2.x）、OpenAI/Azure 上的 GPT-6、SAP AI Core、云会话，或被丢提示/问题 bug 坑过，就该升级——这些是修复坏掉的工作流，不只是打磨。只有当你钉住模型、不用云任务、也不依赖被移除的 provider 时才能跳过；没钉模型的用户以及仍在用 CrofAI/iFlow/Llama 的人必须处理这个版本，不能跳过。这不是空操作，而是有真实行为变化的实质性发布。

添加

  • 云任务：设置 > API 配置有一个本地 |云会话开启时云切换。云选择运行新云任务的 Cline 模型，与本地模型分开保存。 Clicking 云会话的作曲家中的模型标签可将其打开。
  • 启动或恢复云沙箱会显示进度卡，其中包含存储库、分支和步骤（启动沙箱、克隆存储库、启动代理）。一旦代理启动，它就会崩溃。

已更改

  • 云会话隐藏计划/行动切换和自动批准栏，而不是显示它们已禁用。
  • 由于没有选择型号，Cline 提供商再次使用 Claude Sonnet 5.5，它又回到了 Cline 推荐列表的顶部。
  • 模型请求最多重试 3 次，而不是 5 次。
  • Kimi K3 现在获得针对 Extra High 和 Max 的 max 推理，而不是它拒绝的 xhigh 设置。
  • 更新了模型目录。添加了 CommandCode、Reflection、Liquid Inference 和 Munito AI 提供程序，并删除了 CrofAI、iFlow 和 Llama。 Cline 免费列表添加了 Reflection Beam、Nemotron 3.5 Lightning 和 Laguna S 2.1，并删除了 Mimo V2.6 Flash 和 Muse Spark 1.3 Contributor。 ClinePass 现在默认为 Kimi K3.1 Pro 并添加了 MiniMax M3.1 Flash 和 DeepSeek V4.1 Flash 1017。大多数其他提供商的默认模型发生变化，主要为 Kimi K3.1 Pro、MiniMax M3.1 Flash 或 DeepSeek V4.1 Flash 1017。如果您使用未固定模型的提供商，则默认值会有所不同。

已修复

  • GPT-6 模型（例如 gpt-6-sol 和 gpt-6.1-sol）适用于 OpenAI 和 Azure OpenAI 兼容端点，并且 SAP AI Core 不再拒绝带有“不支持的参数：‘max_tokens’”的请求。现在两者都得到 max_completion_tokens。
  • Gemini API 密钥（gemini 提供商）不再发送本机 Google 搜索。在 Gemini 3+ 上，免费层密钥每次都会失败，并出现 429 配额错误，而在 Gemini 2.x 上，每个 Cline 工具都会被丢弃。
  • 任务开始时切换计划/行动不再删除您的第一个提示，并且会话不再继续使用其他模式的工具运行。
  • 禁用的规则保持禁用状态。
  • 启动命令不再将键盘焦点移动到终端，因此您在聊天中输入的文本不再出现在 shell 中。
  • 当 Cline 提问时取消一项任务或打开另一项任务不再会让您的下一条消息被视为旧问题的答案。
  • 在模型仅传输推理后连接断开的回合现在会重试，而不是结束任务。
  • 自动压缩不再对上下文限制未知的模型运行，并且在第一次压缩后每隔几次工具调用就不再运行。
  • ask_question：选择一个选项后模型继续运行，空答案将被拒绝。
  • 具有空命令列表的 run_commands 现在返回错误而不是静默成功。在 PowerShell 上，该工具告诉模型 quote escaping 如何工作并首先确认递归删除。
  • 任务标题徽章换行而不是隐藏关闭按钮，GitHub 连接检查不再闪烁加载指示器，并且本地/云切换的填充已修复。 完整 Changelog：https://github.com/cline/cline/compare/v4.1.25…v4.1.26
