rea rea-agents-6.3.0

6.3.0 (2026-10-09)

⚠ 重大变更

  • 捕获： 没有当前生产者会计或交易身份的历史捕获，以及缺少可访问性或存储维度的网络差异将被拒绝。保留原始捕获并与当前制作人一起重新捕获；更新比较消费者以包含每个维度，而不是综合缺失的观察结果。请参阅流程捕获指南和浏览器场景合约。 (3283a45)
  • 浏览器： JSON 形状路径现在包含类型化属性和数组元素段。 WebMCP input_schema_shape 被 input_schema 和 input_schema_sha256 替换，保留声明的示例和默认值。
  • 进程： 文件系统摘要遗漏条目现在需要 system_code；预算和更改文件省略使用 null，不可用文件省略保留操作系统错误代码。
  • 合同： 提供商分析输出必须明确提供之前使用默认值修复的元数据；不支持的可为 null 的方面必须报告为 null。
  • javascript： 语义图事实现在存储证据上下文 ID 和位置。图形和语义跟踪结果需要内联evidence_contexts表。
  • 合同： 源映射 URL 现在位于由clarified_url_sha256 选择的目标观察中，并且医生技能身份不再发出installed_catalog_digest。请改用记录的观察连接和identity.skill.state。
  • javascript: 从 JavaScript 应用程序分析结果和架构中删除永不递增的 truncated_scopes 统计信息。
  • native: Objective-C 属性标记现在仅包含名称和值。属性报告可为空的原子性和只读事实；类标志、ivar 计数和方法要求标志在未观察到时可为 null。
