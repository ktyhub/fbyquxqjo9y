rea rea-agents-4.0.0

4.0.0 (2026-10-05)

⚠ 重大变更

  • 托管比较元数据添加了精确签名匹配及其计数，并且 name_matching 现在报告精确签名回退。
  • 设置： 无范围设置仅刷新 REA 拥有的现有注册。使用 —all-Detected 配置每个检测到的 client。设置 JSON 包含一个紧凑的医生摘要；使用 rea doctor 进行全面诊断。取消和成功的试运行现在成功退出。
  • 删除受控重放、节点表征、有限重放机、托管运行时规划和冗余字符串跟踪工具。淘汰进程重播、填充程序、反应场景、自定义检查点以及活动浏览器重播和原始范围输入。
  • 工具： 删除了权限配置和策略命令、批准字段、文件系统范围输入以及固定的确认选项。进程捕获继承主机环境并接受命令名称；调用者必须刷新工具架构并迁移已删除的字段。
