rea rea-agents-6.2.0

6.2.0 (2026-10-09)

⚠ 重大变更

升级前请阅读 6.1 到 6.2 迁移指南。 REA 的 always-bump-minor 政策包括重大变更； 6.2 不是向后兼容的承诺。保留原始保存的文件并重新生成丢失的观察结果，而不是伪造身份或事实。

  • MCP / 证据 / 快照 / 工件： 成功结果是直接的规范证据；读取 normalized_result 而不是旧的 result/evidence 包装器。证据需要可为空的 analysis_profile，会话提供程序别名被删除，快照需要完整的配置文件绑定查询记录，并且工件角色/权限属于事件。重新创建不兼容的保存数据；添加字段而不重新计算其语义标识是无效的。 (63bf914)
  • 进程捕获： 旧版 v3 转换已删除。需要显式可执行标识和 event_journal；保留旧的捕获并在需要当前比较时重新捕获，而不是发明启动标识或事件顺序。 (2a77469)
  • 清理和评估： 一次性分析报告清理失败，同时保留完整的观察或初步诊断。处理 cleanup_incomplete 并保留观察/资源。配置的代理评估装置需要有证据支持的正确性，而不仅仅是路由或答案措辞。 （[#1211]（https://github.com/morluto/rea/pull/1211），[27a9cea]（https://github.com/morluto/rea/commit/27a9ceade7232c1c9a24dc7d454ae060948183a1））
  • JavaScript: 返回字段投影需要显式存在；出口形态的变化涉及双方的存在和房地产库存覆盖范围。语义对象操作保留完整的 property_path 段。重新生成旧的分析并区分未知值和未知存在。 (475a0f8)
  • 功能对比： 去掉不可到达的truncated维度状态和summary.truncated计数器；更新枚举并显示消费者，同时保留明确的 unknown 事实。 (5510b27)
  • 历史来源： 不可读/未知的符号链接目标需要 target: null；外部目标保留观察到的绝对目标。重新导入包含显示占位符（例如 <outside-root>）的图形并处理可为 null 的目标。 (b7b4333)
