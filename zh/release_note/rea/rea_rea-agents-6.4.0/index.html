rea rea-agents-6.4.0

6.4.0 (2026-10-11)

变更流程图

亮点

  • Android：通过 ADB 添加了设备检查、拆分 APK 获取、日志、屏幕截图、文件传输和显式应用程序生命周期操作，以及使用 Apktool 进行清单和本地化字符串解码。 （[#1552]（https://github.com/morluto/rea/pull/1552），[#1556]（https://github.com/morluto/rea/pull/1556））谢谢@3QL。
  • JEB：通过调用者启动的本地 JEB MCP 服务器浏览项目单元并反编译所选项目。 (#1536) 谢谢@3QL。
  • 大型分析：无需加载每个有效负载即可发现保留的证据，并通过摘要和选定视图检查 JavaScript 图表、二进制布局和功能档案。 （[#1682]（https://github.com/morluto/rea/pull/1682），[#1568]（https://github.com/morluto/rea/pull/1568），[#1570]（https://github.com/morluto/rea/pull/1570），[#1345]（https://github.com/morluto/rea/pull/1345），[#1507]（https://github.com/morluto/rea/pull/1507），[#1247]（https://github.com/morluto/rea/issues/1247））谢谢@jhuang-tw， @kaoru0822-kitauji，@N0zoM1z0。
  • JavaScript：在拥有的进程中隔离源分析，并具有可配置的堆和超时限制；当分析资源耗尽时，保留完整的事实和明确的未知数。 （[#1651]（https://github.com/morluto/rea/pull/1651），[#1563]（https://github.com/morluto/rea/issues/1563），[#1565]（https://github.com/morluto/rea/issues/1565））感谢@N0zoM1z0，@peter-research。
  • Ghidra：在自动分析之前配置导入语言/编译器规范和种子函数、代码和标签。 (#1667) 谢谢@sqmagellan。
  • RPC 发现：识别 JavaScript 应用程序和 Web 包中支持的 tRPC 调用、HTTP 链接 URL 和命名 GraphQL 操作。 (#1670) 谢谢@pompiliodonatoapp。

变化

  • 添加了对 Windows PE DLL 和有界 MIPS ELF 分析的 Ghidra 支持，包括带有不完整节表的雕刻 MIPS 输入。 Windows P0 保持只读状态。 （[#1303]（https://github.com/morluto/rea/pull/1303），[#1362]（https://github.com/morluto/rea/pull/1362），[#1629]（https://github.com/morluto/rea/pull/1629），[#1290]（https://github.com/morluto/rea/issues/1290），[#718]（https://github.com/morluto/rea/issues/718），[#1619]（https://github.com/morluto/rea/issues/1619））谢谢@bqw371，@jaelliot， @kvalls，@N0zoM1z0。
  • 为具有突变权限的 Ghidra 会话启用 set_address_name 和 set_addresses_names，包括命名空间感知数据标签和每个地址批处理结果。 （[#1635]（https://github.com/morluto/rea/pull/1635），[#1634]（https://github.com/morluto/rea/issues/1634））谢谢@giri256。
  • 恢复了额外的签名 AArch64 相对跳转表模式。 (#1592) 谢谢@RishTheFish21。
  • 为支持的 x64 PE32+/.NET 8 RTR 9.1 输入添加了 PE 资源检查和只读 NativeAOT 元数据解析。 NativeAOT 解析器的 Windows 主机 Ghidra 工作流程在真实的 Windows 主机上仍未得到验证。 （[#1482]（https://github.com/morluto/rea/pull/1482），[76d8f68]（https://github.com/morluto/rea/commit/76d8f68cb918dfb43869f2b649a0b6c0c1cf266d），[#1254]（https://github.com/morluto/rea/issues/1254））谢谢@N0zoM1z0，@thangldw。
  • 添加了 Pi、Hermes 和 Qwen 代码设置，包括 Hermes 活动配置文件支持。 （[#1376]（https://github.com/morluto/rea/pull/1376），[#1403]（https://github.com/morluto/rea/pull/1403），[#1415]（https://github.com/morluto/rea/pull/1415），[#1409]（https://github.com/morluto/rea/issues/1409））谢谢@rasatpetabit，@yiliang114，@zaydiscold。
  • 为尺寸上限的 MCP client 添加了 REA_MCP_INPUT_SCHEMA_PROFILE=compact，例如 Kimi/Moonshot，同时保留规范的运行时验证。 （[#1514]（https://github.com/morluto/rea/pull/1514），[#1580]（https://github.com/morluto/rea/pull/1580），[#1484]（https://github.com/morluto/rea/issues/1484），[#1581]（https://github.com/morluto/rea/issues/1581））谢谢@haythemsellami，@N0zoM1z0。
  • 添加了实时进程捕获进度和可选的 finalization_ms 以在超时升级之前捕获关闭输出；取消仍然是立即的。 (#1483、#1583、#1252、#1253、modelcontextprotocol/typescript-sdk#2997)谢谢@N0zoM1z0，@nikolay-dementiev，@sathariels。
  • 改进了 Codex 的加入和从观察到的 client、PATH 和提供商阻止程序的恢复。 (#1613) 谢谢@N0zoM1z0。
  • 减少重定向的 JSON 和终端输出大小，并推迟大量导入，直到命令需要为止。 （[#1413]（https://github.com/morluto/rea/pull/1413），[#1450]（https://github.com/morluto/rea/pull/1450），[#1439]（https://github.com/morluto/rea/pull/1439），[21dbcf7]（https://github.com/morluto/rea/commit/21dbcf7a1458219989ad291e44ce7d017378b727））谢谢@kaoru0822-kitauji。

修复

  • 电子分析：遵循重命名和默认导入的 API 和可选调用，忽略覆盖的身份和媒体预加载属性，并解析打包的 app.asar 页面和解包的同伴。 （[#1391]（https://github.com/morluto/rea/pull/1391），[#1393]（https://github.com/morluto/rea/pull/1393），[#1400]（https://github.com/morluto/rea/pull/1400），[#1664]（https://github.com/morluto/rea/pull/1664），[#1673]（https://github.com/morluto/rea/pull/1673））谢谢@kaoru0822-kitauji，@marnixpluim，@N0zoM1z0， @suninrain086。

  • JavaScript 包：解析精确的导出子路径，保留尾部斜杠目录请求和精确的 CommonJS 键，并尊重隐藏的 require 绑定。 (#1424、#1615、5485483、8b2f851、f998fcb、1e51c73、 #1365) 谢谢@akshitkhokhani、@AWUQAQ、@immanuwell、@rudycelekli。
  • 大型 JavaScript 输入：处理超大内联源映射、深度返回和重新分配循环；在大型分析过程中避免参数扩展限制和产量。 (#1386、#1368、#1390、#1539、#1525、#1542、 #1545、#1557、#1380、#1401、#1538、#1462) 谢谢@cold-atom， @KadirJeager、@kaoru0822-kitauji、@marnixpluim、@N0zoM1z0、@rudycelekli。
  • JavaScript 接收器：扩展转义方法一次，索引返回对象目标，并避免重播早期写入或重复保留的图形分配。 （[#1517]（https://github.com/morluto/rea/pull/1517），[#1537]（https://github.com/morluto/rea/pull/1537），[#1444]（https://github.com/morluto/rea/pull/1444），[#1601]（https://github.com/morluto/rea/pull/1601），[#1495]（https://github.com/morluto/rea/issues/1495））谢谢@CassieFox23，@geekwolf， @kaoru0822-kitauji，@N0zoM1z0，@zeynelacikgoez。

  • 浏览器场景：种子存储在正确的分区中，标准化环回附加身份，保留声明的秘密编辑，并需要在 Windows Electron 信号之前验证沿袭。 (#1604、#1590、#1588、8b4c3de、#1497、#1591、 #1589) 谢谢@Adolanium、@akushonkamen、@dakjdakd。

⚠ 重大变更

  • WebSocket 结果：使用 network.websocket_connections 而不是 network.websocket_events。连接包括request_id、url和events；当尺寸未知时允许 payload_bytes: null。不再保留旧别名。 (db4e360)
  • 直接资源 API：将调用者拥有的 ArtifactResourceScope 传递到库存/提取、JavaScript 分析、参考导入和 Web 导出；通过清理/关闭保留它。对于 readJavaScriptArtifactFiles，范围是参数三，中止信号是参数四。保留每个根清单源的单一清理所有者。使用 OwnedFileHandle 所有者，注入 ASAR fd/read 句柄而不是 createReadStream、VCS Result 值和 WebScriptExportError 的选项对象。用于范围操作的 CLI/MCP 输入未更改。 (ffe0574、53e7fad、684199b、be75ed5、be6272f、e0e49e9、 95a77b6)
  • 保存的参考图：排除需要匹配 pattern 并区分 project-ignored 和 default-ignored。重新导入缺少该出处的图表。 (6585293)
  • 终端捕获：使用 columns × (rows + scrollback) 将初始和调整大小的缓冲区保持在 1,000,000 个单元内；过大的场景在启动前会被拒绝。 (f9ea9a9)
  • 可选代理验证报告：接受架构版本 4、可为空的 expectedFirstTool 和 targetClarificationPassed。 CLI/MCP 生产合同没有变化。 (#1613)
  • 捕获比较：使用自定义规范化模式时，重新捕获具有匹配 literal-replacements-v1 语义的双方。遗留的未版本化模式捕获仍然可读，但无法与新模式捕获进行比较；没有模式的捕获不受影响。 （[#1456]（https://github.com/morluto/rea/pull/1456），[2b6f14f]（https://github.com/morluto/rea/commit/2b6f14f528297cf12c776c960af0859f5cfbefbf））谢谢@Madhavan006，@N0zoM1z0。
  • 工件图边缘：从 occurrence_id 选择的事件中读取子工件 ID 和路径，而不是边缘字段 child_artifact_id/logical_path。早期的库存证据不再与新的承诺相对应。 (#1493) 谢谢@kaoru0822-kitauji。
  • 语义图模式：节点和关系不再包含 identifier_strategy，并且关系 ID 不再对它进行散列。早期证据不再针对此模式进行验证。 (#1474) 谢谢@kaoru0822-kitauji。
  • 语义标识：从父图中选择ID；从 event_name 读取确切的事件名称，从 endpoint 读取端点，从 properties.value 读取文字值。新的分析使用基于摘要的 ID 来表示长/保留事件和端点名称以及 value-sha256 文字角色键，并带有较短的标签；字符串文字标签现在显示为 string literal。以前存储的图表保留其原始 ID 并保持有效的工作流程输入。 （[#1427]（https://github.com/morluto/rea/pull/1427），[#1423]（https://github.com/morluto/rea/pull/1423），[#1407]（https://github.com/morluto/rea/pull/1407））谢谢@N0zoM1z0。
