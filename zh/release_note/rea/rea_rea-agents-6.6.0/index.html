rea rea-agents-6.6.0

6.6.0 (2026-10-18)

变更流程图

亮点

  • 添加 Kuna 作为调用者提供的静态分析提供者。
  • 查询选定的 JavaScript 事实和多个 APK 语言环境表，无需重复底层分析。
  • 将 Ghidra 分析扩展到 Windows ARM PE 目标和显式原始 m68k 图像。
  • 保留已完成的证据、取消原因以及跨提供商的可重试清理和 CLI 最终确定。

变化

  • Kuna 分析： 使用调用者安装的 Kuna 进行过程列表、伪代码、汇编、调用关系、精确地址外部参照和缓存字符串搜索。项目导出保留源跨度和摘要；重复请求重用已完成的工作。记录的真实提供商覆盖范围在 Linux 上使用 Kuna 1.833；不支持 Windows、PE 和通用 Mach-O。请参阅提供者指南。 （[#3832]（https://github.com/morluto/rea/pull/3832）、[#3854]（https://github.com/morluto/rea/pull/3854）、[#4071]（https://github.com/morluto/rea/pull/4071）、[#4095]（https://github.com/morluto/rea/pull/4095））。感谢@gensokyo-dev、@kaoru0822-kitauji、@N0zoM1z0。
  • **保留JavaScript事实：**通过inspect_analysis_view查询确切的应用程序路径、选定的属性和过滤的模块引用，具有分页和完整的行证据。这些视图重用已完成的分析并保留源选择和未知覆盖范围。 (#4265、morluto/rea#4190、#4097、morluto/rea#4092)。谢谢@kaoru0822-kitauji，@N0zoM1z0。
  • APK 区域设置表： 使用可重复的 CLI --locales 或 MCP locales 在一次解码中请求多个资源区域设置。每个表报告其状态和覆盖范围；现有的单一区域设置字段仍然可用。 （[#4804]（https://github.com/morluto/rea/pull/4804），[morluto/rea#4777]（https://github.com/morluto/rea/issues/4777））。感谢@abhay-2108、@N0zoM1z0。
  • Windows ARM 二进制文件： Ghidra 承认 Windows x64 主机通道上的 ARMNT/Thumb-2 和 ARM64 PE 应用程序和 DLL。记录Ghidra 12.1.4验证使用WindowsResourceReference禁用并提高启动预算；默认分析器完成后，ARM64EC/ARM64X 和 Windows-on-Arm 主机仍未验证或不受支持。请参阅确切范围。 （[#3965]（https://github.com/morluto/rea/pull/3965），[morluto/rea#2186]（https://github.com/morluto/rea/issues/2186））。感谢@N0zoM1z0、@WestLabsAI。
  • 原始 m68k 图像： 使用 Ghidra 的固定 68000 配置文件和调用者提供的对齐条目分析显式选择的大端 m68k 原始二进制文件。在 macOS arm64 上使用 Ghidra 12.1.4 进行真实的 CLI/MCP 验证； Linux 未经验证，Windows P0 不承认 m68k。请参阅映射要求。 （[#4018]（https://github.com/morluto/rea/pull/4018））。谢谢@icedac。
  • JADX 截止日期： 设置 REA_JADX_OPERATION_TIMEOUT_MS 以同时延长 APK 加载和上游操作截止日期。医生报告有效值并提出明确的选择。 （[#4466]（https://github.com/morluto/rea/pull/4466），[morluto/rea#3918]（https://github.com/morluto/rea/issues/3918））。谢谢@jaychou813，@SandstromPL。
  • 电子窗口选项： 解决稳定的局部常数 BrowserWindow 选项，同时保留源出处。相关的写入和转义使结果未知。 （[#4400]（https://github.com/morluto/rea/pull/4400），[morluto/rea#4366]（https://github.com/morluto/rea/issues/4366））。谢谢@kaoru0822-kitauji，@N0zoM1z0。
  • 语言版本： 添加希腊语网站版本和马拉雅拉姆语文档，以及整个网站的韩语排版和翻译更正。 (#3520、#4792、#3821、morluto/rea#3820、#3799、morluto/rea#3798、 #4344、#3856、#4166)。感谢@gensokyo-dev、@hi2242、@kalayciburak、@kaoru0822-kitauji、@kraken-503、@kukinghan、@N0zoM1z0、@yeseong0412。

  • Client 配置： 保留选定的启动器、目标文件、调用者超时选择和未解决的配置证据。安装/卸载恢复与确切发布的文件保持绑定，保留当前经过验证的备份，并转移失败的清理所有权以进行重试。 (d0253c9、7e4eed9、2fb5e20、8235210、d818c3d、19329e4、 dadf909、333e0ab、c15c206)。谢谢@Adolanium。

  • 更新： 通过经过验证的更新程序和绑定的保留包管理器诊断路由 --update。 （[4f7b5fb]（ZZPH100​​ZZ），[01cdbbd]（https://github.com/morluto/rea/commit/01cdbbdc556262c47d04a5b3391dd9c17946d3fc））。
  • MCP 合约： 公布自包含工具输入，同时保留跨模式配置文件的元组、数组、布尔值和嵌套 JSON 约束。模式引用处理不再重写文字元数据；目录标识包括输出模式配置文件。 (5e30969、10aa74d、204b9f3、b3389a5、a2e3016、 ba98130、c5fb86d)。谢谢@akushonkamen、@HarsH-1877、@kaoru0822-kitauji、@xingzihai。
