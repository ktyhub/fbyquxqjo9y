career-ops v1.35.0

小版本 发布时间2026年10月1日 来源career-ops-hq/career-ops 英文原文

career-ops career-ops-v1.35.0

这个项目是干啥的：一个帮人找工作和管理求职流程的工具，收集多个渠道的职位、跟踪投递和面试邀请，适合正在求职、想集中管理机会的人。

此版本拓宽了职业机会的范围：九个新的工作来源，从美国学区的申请系统到墨西哥的 OCC Mundial。它承载着 86 人的作品，其中 50 人是首次贡献。

变更架构图

亮点

  • 九个新工作来源。 AppliTrack、NEOGOV、Red Rover 和 SchoolSpring，由美国 K-12 学区和社区学院使用，作者：@raymondwilliamskc (#4360)。 @cRolandoJr (#4460) 的 HiringRoom，@VictorMeneses77 (#3748) 的 OCC Mundial，@Schlaflied (#4055、#3739、#3919) 的 Eploy、PeopleSoft Candidate Gateway 和 PrevueAPS。 BambooHR 已受支持，现在是完整扫描 (scan:full) 的一部分，作者：@ilyakanevskiy (#4365)。
  • 您逐一审查的主要职业简介。 node career-profile.mjs import --review 读取您的简历，并让您批准、编辑或跳过每个事实；仅保存批准的事实，validate 检查结果。也可用作 /career-ops master-profile。作者：@Kilaa13 (#4456)。
  • 简历详细信息。 @Zoubeir23 (#3763) 在你的名字下提供一个可选的专业头衔，@lesiashu (#4049) 为每个经验条目提供一个可选的单行 context，以及一个阻止 generate-pdf 按时间顺序打印工作经历的警卫，由 @abp002 提供，他拾取了 @kmichels’ #2343 (#4489)。
  • 您的数据根，在更多脚本中。 如果您的数据位于代码签出之外 (CAREER_OPS_ROOT)，简历和求职信 PDF 现在可以通过 @shaurya20335 (#4486) 和 @marcosfemonteiro (#4314) 找到它，@abankar1 (#3988) 的 set-status、hired-share、reply-watch 也可以找到它， @alejandra-dahl (#4571, #4570) 的 paste-reply 和 batch-tailor，@SulimanAbdulrazzaq (#4287) 的 fix-slugs 和 validate-portals。
  • 安装和更新。 npm install 在没有 apt-get 的 Linux 发行版上不再失败，例如 Fedora，作者：@Zoubeir23 (#4233)。 npx @santifer/career-ops init 在 Windows 上的 npm install 不再失败，作者：@samintisar (#4572)。 node update-system.mjs status 打印您的版本并提交，作者：@Shaamak (#3897)。

更新中

您的代理会在您下一次会话开始时提供此更新。如果没有，请在您的 Career-ops 文件夹中运行一次：

node update-system.mjs apply --confirm

在 1.33 或更早版本上，提示可能会显示您的系统文件不同：请选择“是”。从 1.33 或更早版本开始，第一个更新将安装当前的 main 而不是此版本。您的简历、个人资料、跟踪器和报告不会受到影响，也无需执行其他操作。 如果您在 1.34.0 发布后从 1.33 或更早版本进行更新，则您的安装可能会在运行 main 的更高版本快照时报告 1.34.0。此更新将其向前推进至 1.35.0 版本。 新安装：npx @santifer/career-ops init。
