career-ops v1.40.0

小版本 发布时间2026年11月10日 来源career-ops-hq/career-ops 英文原文

career-ops career-ops-v1.40.0

这个项目是干啥的：一个帮人找工作和管理求职流程的工具，收集多个渠道的职位、跟踪投递和面试邀请，适合正在求职、想集中管理机会的人。

此版本旨在说明职业运营人员未阅读或未保留的内容。仅部分读取的板会被记录为 partial 而不是 reachable，PDF 渲染器丢弃的模板标签会收到警告，并且动词与您编写的项目符号偏离的简历项目符号会被阻止。

变更架构图

亮点

  • 部分阅读的董事会是这么说的。 职业操作员只能部分阅读的董事会现在记录为 partial，而不是 reachable (#6636)，并且因临时错误而失败的董事会在扫描后可以再尝试一次 (#6675)，均由@kellymmcgrath 完成。在引导浏览器重试之前，活性检查首先读取站点的 robots.txt（#6551 by @benbalter）。
  • 你的简历，坚持你自己的事实。 生成的项目符号的动词偏离其源项目符号被阻止（#6630 by @kellymmcgrath），结构化事实绑定到它们来自的记录（#6016 by @luochen211），并且具有未解析的 {{token}} 的构建失败而不是打印它（#6408 by @sogav21）。 cv-templates.mjs lint cv <name> --render 警告渲染器默默丢弃的内容，例如脚本和远程字体（#5943 by @rubicon）。
  • 随身携带您的跟踪器。 import-tracker.mjs 导入另一个跟踪器的 CSV 导出 (#6170)，扫描会保留发布的结束日期并将其显示在管道中 (#6597)，均由 @mbrow190 完成。
  • 一次一个要求。 职业行动会在你的第一份报告之后要求一次 GitHub 星星，稍后再要求一次宣言，从来没有在同一次运行中要求过。分布在扫描、医生和更新中的请求现在集中在一个地方 (#6700)。
  • 还有十二个地方值得一看。 HiBob、HireHive 和 ALDI Nord（#6502、#6503、#6529 by @ilyakanevskiy）、每个 Workable 租户通过 Workable 的公共 XML feed（#6793 by @ilyakanevskiy）、Polymer 和 Trakstar Hire（#6128、#6131 by @mbrow190）、Tes （#6731 by @AdilAzhariOmsan）、TurboHire（#6712 by @okeken）、任何雇主的工作站点地图（#6631 by @kellymmcgrath）、Remote 自己的 ATS（#6392 by @artemtrofymenko）、ADP 招聘管理（#6678 by @dgitman）和 SEEK NZ（#6488 by @prateek942）。

更新中

在您的 Career-ops 文件夹中运行 node update-system.mjs apply --confirm。如果您之前对更新提示说“不”，则这是相同的命令。
