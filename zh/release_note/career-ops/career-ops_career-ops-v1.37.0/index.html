career-ops v1.37.0

小版本 发布时间2026年10月16日 来源career-ops-hq/career-ops 英文原文

career-ops career-ops-v1.37.0

此版本旨在了解什么仍然值得您花时间：您正在跟踪的帖子会为您检查，并且每个报告都会打开其结论。仪表板工作（面试准备、求职信草稿、行比较）在 web-v0.15.0 中提供。

变更流程图

亮点

  • 它仍然处于打开状态吗？ check-liveness.mjs --tracker 检查打开的跟踪器行后面的过帐，并且当您添加 --apply 时，--discard-expired 将已评估的过帐移动到已丢弃（否则这是一次试运行），作者：@mbrow190 (#5177，#5241)。当您发现扫描遗漏的手工帖子时，coverage-check 会由 @IaroslavMazur (#4849) 解释原因。
  • 以通话为主导的报告。 现在每个报告都会以 Verdict 块打开，作者为 @rubicon (#3960)。 Block G 获得 Signal 18，招聘人员身份验证，作者为 @stdOWL (#5080)，事实门读取德国计数声明，作者为 @duathron (#5074)。信号 8 到 17 现在仅在触发时才加载，因此评估会读取较短的提示，由 @mbrow190 (#5229) 编写。
  • 更多地方可以用您的语言查看。 Google 提供商仅读取第一个结果页面（robots.txt 允许），以及选择加入 Ashby 嵌入源，作者：@kellymmcgrath（#4078、#4298）。东南亚的 Kalibrr 和亚洲技术，作者：@rafifshaf-fun (#4420)。 Platsbanken，瑞典国家就业委员会，作者：@gdut4140 (#5069)。 preferred_languages 保留您所申请的语言的帖子版本，作者：@ilyakanevskiy（#5285，#4789、#5044、#5260、#5264）。
  • 您的设置。 可以通过 @mbrow190 (#5164) 关闭后续操作。一个选择加入的本地 LaTeX 安装程序，以便 LaTeX 路径可以开箱即用地进行编译，作者：@CaptainCo0L (#5133)。 Nix 开发 shell 可在 @asinglesprinkle (#5073) 的新 NixOS 克隆上运行。

安全

  • 提供者： 现在，在直接路径上也拒绝字面上的私有 IP 主机（例如 http://127.0.0.1/），而不仅仅是在代理（GHSA-jh4g-g3vm-m943）后面。由 @gtyree 报道，他还停止了在此版本中堆积数千个空闲连接的全面 ATS 扫描 (#4841)。

更新中

您的代理会在您下一次会话开始时提供此更新。如果没有，请在您的 Career-ops 文件夹中运行一次：

node update-system.mjs apply --confirm

您的简历、个人资料、跟踪器和报告不会受到影响。
