career-ops v1.38.0

小版本 发布时间2026年10月23日 来源career-ops-hq/career-ops 英文原文

career-ops career-ops-v1.38.0

这个项目是干啥的：一个帮人找工作和管理求职流程的工具，收集多个渠道的职位、跟踪投递和面试邀请，适合正在求职、想集中管理机会的人。

此版本的目的是不丢失您输入的内容。您的简历、PDF、portals.yml、跟踪器行和保存的答案现在可以在中断的写入、奇怪的格式和更新中幸存下来，并且它在一周内来自 48 个人，而在同一天内，职业运营 Discord 的会员数量超过了 5,000 名。

变更架构图

亮点

  • 确保文件安全的更新。 更新程序拥有的内容列表现在位于其自己的清单中，无需导入即可读取，并且 1.37.0 上的安装通过桥接列表进行更新。在从 1.37.0 和旧安装发布之前进行了测试：应用和回滚使我们检查的用户文件字节相同。 （#5563 作者：@vliggio）
  • 写入不能半发生。 cv.md、portals.yml 和生成的 PDF 被原子替换，每个核心锁现在使用一种协议。 （#5552、#5389，作者：@vliggio）
  • 批量，更多在你手中。 --company 限制运行到你指定的公司，--thin-action 决定当无法获取 JD 文本时会发生什么，工作人员应用你的交易破坏者并记录完成的 SKIP。 （#5526，#5547，@zhangruyi1993，#5493，@mbrow190）
  • 更多地方可供参考。 拉丁美洲的 Computrabajo 和 Magneto365 (#2650 by @configurowebmax)、Atlassian (#5497 by @kellymmcgrath)、Dover (#5565 by @IaroslavMazur)、Zoho Recruit 职业网站 (#5345 by @ilyakanevskiy) 以及 scan:full 中的白标 SuccessFactors 网站（#5740，@Schlaflied）。
  • 跟进，更少记住。 在写简历之前进行重复检查 (#5735)、带回家的截止日期 (#5736)、从 .ics 文件中读取面试邀请 (#5744)，全部由 @Schlaflied 完成，以及电子表格的 tracker.mjs query --csv (#5624 by @mbrow190)。

安全

  • 当输入的文本包含换行符时，网络应用程序的辅助应用可以提交申请表：换行符现在已从该文本中删除，并且后备无需按键即可插入它，因此它不再提交表单（GHSA-rm8h-2825-ww26，由 @vliggio 报告，#5770）。

更新中

在您的 Career-ops 文件夹中运行 node update-system.mjs apply --confirm。如果您之前对更新提示说“不”，则这是相同的命令。
