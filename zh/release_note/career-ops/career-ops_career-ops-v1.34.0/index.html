career-ops v1.34.0

小版本 发布时间2026年9月24日 来源career-ops-hq/career-ops 英文原文

career-ops career-ops-v1.34.0

这个项目是干啥的：一个帮人找工作和管理求职流程的工具，收集多个渠道的职位、跟踪投递和面试邀请，适合正在求职、想集中管理机会的人。

这是自从我开始全职从事职业运营以来的第一个版本。现在，仅当新版本实际发布时才会显示更新提示。到目前为止，几乎任何登陆 main 的变化都可能触发它，通常是每天。此版本还包含 63 人的作品，其中 43 人是首次贡献。

变更架构图

亮点

  • 仅针对新版本提示更新。 update-system.mjs 安装最新发布的版本而不是 main，check 仅在存在更新版本时询问，并且说“不”持续到下一个版本而不是永远。 --channel main 仍可跟踪 main。基于 @obielin 在 #3845 中的发布决议。
  • 更少的实时报价标记为已关闭。 Liveness 现在通过 Greenhouse gh_jid、SmartRecruiters、Arbeitsagentur 和 We Work Remotely 通过其公共 API 检查公司页面 (#4444)，并且在 iframe 中加载其 ATS 的职业页面不再被视为死帖子 (#4439)，均由 @luochen211 完成。
  • 更清晰的扫描。 @vaishaldsouza 的聚合器转发的域级检测（#4263），@Zoubeir23 的选择性加入严格位置过滤器在空位置上无法关闭（#4033），可以覆盖整个域的黑名单行（#4169），以及当门户返回零作业而没有单个成功响应时的警告（#4441），均由 @luochen211 完成。
  • 新来源。 @lasithadilshan (#4173) 提供的 Python.org 工作提供者，@ConnorCloze (#4100) 提供的通才世界董事会提供者以及 @duathron (#4001) 提供的明确的 Personio 租户 pin，所有三个都是第一个贡献。

更新中

您的代理会在您下一次会话开始时提供此更新。如果您之前收到过更新提示，请运行一次以获取它：

node update-system.mjs apply --confirm

新安装：npx @santifer/career-ops init。
