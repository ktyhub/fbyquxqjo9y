Vibe-Trading v0.1.8

这个项目是干啥的：一个用AI智能体来炒股票、做交易的框架，让AI按策略自动分析和下单，给想试试自动炒股的投资者用。

🧬 v0.1.8 — Alpha Zoo v1 + 研究工作流程优化

v0.1.8 是 Vibe-Trading 的主要内容版本。标题是 Alpha Zoo：跨四个捆绑库（qlib158、alpha101、gtja191 和 academic）的 452 个预构建定量 alpha，用单行 CLI 来测试宇宙中的任何动物园，通过两个新工具进行代理集成，具有 SSE 流式处理进度的四个新 REST 路线，以及 /alpha-zoo 上的浏览​​/详细信息/测试 Web UI。该版本还实现了长期运行的 MCP client 集成、Web UI 中的 Trust 层运行卡、在 vibetrading.wiki 上发布的公共 wiki、假设注册表 MVP 以及由社区 PR 驱动的实质性安全 + 强化通行证。 此版本可在 PyPI、ClawHub 和 GitHub 版本上使用。

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

变更架构图

亮点

🧬 Alpha Zoo — 4 个动物园中 452 个预建的 Quant Alpha

带有元数据的横截面公式化 alpha，在操作员层禁止前瞻，经过注册验证，并且可从 CLI、代理、REST API 和 Web UI 访问：

  • qlib158 — 154 个阿尔法。 Microsoft Qlib 的 Alpha158 功能处理程序的 Apache-2.0 端口，上游提交 SHA 固定在每个改编模块的标头中，并捆绑上游 NOTICE。
  • alpha101 — 101 个阿尔法。 Kakushadze (2015)“101 Formulaic Alphas”(arXiv:1601.00991) 的实现，根据论文附录编写。 19 个行业中立的 alpha 标记为 requires_sector=True，并在没有扇区标签的宇宙中干净地跳过。
  • gtja191 — 191 个阿尔法。国泰君安证券2014年*《191短期交易Alpha因素》*研究报告实施。每个 alpha 记录的操作员映射决策（SMA / WMA / REGBETA / HIGHDAY 解释）。
  • 学术 — 6 个因素。 Fama-French 5 + Carhart 势头，作为诚实的 基于价格的代理 发货（规范的 FF 系列需要账面市值/盈利能力/投资增长基本面，我们不捆绑）。昵称带有 [PRICE PROXY] 前缀； Kenneth French 的数据库可供需要规范月度回报的用户参考。 每个 alpha 都带有一个由 py​​dantic extra="forbid" 模式验证的 __alpha_meta__ 字典（公式 LaTeX、主题、universe、columns_required、warmup、decay Horizo​​n、notes）。

🖥️ 一线 CLI

vibe-trading alpha list --zoo gtja191 --theme momentum --limit 10
vibe-trading alpha show gtja191_171
vibe-trading alpha bench --zoo gtja191 --universe csi300 --period 2018-2025 --top 20
vibe-trading alpha compare --all
vibe-trading alpha export-manifest --out wiki/alpha-library/manifest.json

bench 驱动带有实时 alpha-id + ETA 横幅的丰富进度条，在失败时返回正确的退出代码，并消除 scipy ConstantInputWarning 噪音。所有五个子命令均支持 TTY 提示和 --json 脚本编写模式。

🌐 /alpha-zoo 的 Web UI + 4 个 SSE 的 REST 路线

React Web UI 中的三个视图：浏览（4 个动物园卡、过滤栏、分页表）、详细信息（公式、元数据、源代码）、基准（表单 → SSE 流式处理进度 → 活跃/反转/死亡统计卡 + 按 IR 排名前 5 位 + 最反转表 + 按主题条形图）。 Auto-Vite 路线位于 /alpha-zoo，布局中的导航条目。

GET  /alpha/list?zoo=&theme=&universe=&limit=
GET  /alpha/{alpha_id}
POST /alpha/bench               (body: {zoo, universe, period, top}) → 202 + job_id
GET  /alpha/bench/{job_id}/stream   (SSE: progress / result / done / error)

后台工作台作业通过 asyncio.to_thread 运行，具有 2 个并发作业信号量（饱和时为 429）、具有 1 小时 TTL 的内存状态、防止代理关闭空闲流的 15 秒心跳注释帧以及经过清理的错误消息，以便意外异常不会泄漏服务器端路径。

🤖 代理集成

两种新的自动发现工具（AlphaZooTool、AlphaBenchTool）加上多因素技能中的面板式 ZooSignalEngine.from_zoo(...) 工厂，可将一个或多个阿尔法组成与现有回测引擎兼容的长短信号。保留传统的每符号 example_signal_engine.py 是为了向后兼容。

🛡️安全地板

每次 PR 和 vibe-trading alpha bench 运行时都会触发质量门：

  • AST 纯度门 (test_alpha_purity.py) — 扫描每个 zoo/**/*.py 模块，仅允许 pandas、numpy、scipy.*、src.factors.base、__future__、typing、math、dataclasses 导入；禁止 os / sys / subprocess / socket / urllib / requests / httpx / pathlib / Path / open / eval / exec / compile / __import__ plus breakpoint / input / globals / locals / vars / __class__ / __subclasses__ / __mro__ / __globals__ / __builtins__，加上 dunder 字符串 getattr 访问（包括 BinOp 连接的 dunder）。
  • 前瞻哨兵测试 (test_lookahead.py) — 300 行合成面板；通过探针的损坏行；断言探针处的因子在 1e-9 内保持不变。
  • pytest-socket 集成 — 因素测试套件在网络禁用的情况下运行。
  • CI grep Gates (tools/ci_grep_gates.sh) — 拒绝没有 safe_load 的 yaml.load(、已发货工件中的商标名称字符串以及 wiki/**/*.{json,csv,html} 中的任何按股票代码的数据泄漏。

📡 MCP client 集成（stdio v1）

代理现在可以通过 ~/.vibe-trading/agent.json 从外部 MCP 服务器加载工具，通过 ALLOW_SESSION_MCP_SERVERS=1 在每个会话中选择加入。仅在 v1 中使用 Stdio 传输； HTTP/SSE 延迟。工具名称冲突获得确定性哈希后缀；远程工具故障会标准化为错误有效负载，而不是冒泡。非常感谢 @shadowinlife (#83) 的端到端实施和安全意识默认设置。

🪪 Trust Web UI 中的图层运行卡

运行详细信息页面现在呈现 run_card.json 以及指标和工件，完成了之前完成的 trust 层工作的 UI 部分。

🧠 假设注册表（后端 MVP）

create_hypothesis / update_hypothesis / link_backtest / search_hypotheses 为研究假设提供持久的生命周期、运行卡的链接和失效注释。接下来进行 UI 集成。

🌐 公共维基 vibetrading.wiki

wiki 提供了自己的 Alpha 库渲染器 (wiki/scripts/build_alpha_library.py)，它读取清单 JSON 并发出 452 个每 alpha 页面 + 4 个每动物园概述页面，每个页面都有 script-src 'none' CSP。该研究实验室获得了第一篇长篇文章：“191 个 GTJA alpha 中的哪一个在 2026 年仍然有效？” — 汇总 IC、主题生存率，以及在 CSI 300（2018-2025）的样本外数据中生存了八年的顶级 alpha，并提出了生存偏差警告。

注意事项/已知限制

  • **btc-usdt宇宙是单一资产。**横截面IC需要≥2个仪器，因此alpha101_btc通过构造返回活着/反转/死亡= 0/0/0。计划为 0.2 策划一个 crypto-majors 多符号篮子。
  • SP500 全域使用今天的成分股名单作为时间点指数成员资格的代理，引入了生存偏差。记录在 bench_summary.json["meta"] 和 wiki 博客警告部分。时间点成分源是 0.2 后续成分。
  • **MCP 服务器尚未公开 alpha_zoo / alpha_bench 工具。计划对 0.1.9 进行 MCP 总结。
  • 19 个行业中立的 alpha101 alpha (#48, 56, 58, 59, 63, 67, 69, 70, 76, 79, 80, 82, 87, 89, 90, 91, 93, 97, 100) 需要扇区标签。 Tushare 提供了这个； yfinance 没有，所以 SP500 benches 跳过这 19 个。 Cross-zoo SP500 后续会插一个扇区数据源。
  • docs/ 被忽略，仅用于内部规划。 不要将 docs/ 的内容推送到公共分支机构。
