Vibe-Trading v0.1.6

🚀 v0.1.6 — 关键包装修复 + 社区驱动的功能

如果您通过 pip install 或 uv tool install 安装 vibe-trading-ai==0.1.5，vibe-trading --swarm-presets 返回 No presets available 并且 run_swarm 无法使用。此版本修复了该问题 - 请升级。

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

亮点

🐛 Swarm 预设打包修复 (#55)

预设的 YAML 是通过 pyproject.toml 中的 [tool.setuptools.data-files] 声明的，这会将它们放置在 <install-prefix>/.data/data/config/swarm/ 下，而不是加载程序所看到的 <site-packages>/config/swarm/ 下。可编辑安装（pip install -e .）恰好可以工作，因为源代码树路径解析正确，因此该错误仅在已发布的轮子中出现 - 每个 pip install vibe-trading-ai==0.1.5 在此代码路径上都被破坏。 分辨率：29 个预设的 YAML 移至 agent/src/swarm/presets/，因此它们与普通 package-data 一样发货。装载机现在通过 Path(__file__).parent / "presets" 解析 - 在可编辑安装和内置轮子下相同。由 6 次测试打包回归套件固定，因此不会再次默默回归。 @qxj 报告的错误 - 屏幕截图使其成为 5 分钟的根本原因查找。

📊 基准比较面板

回测输出现在提供基准比较面板（股票/基准回报/超额回报/信息比率），并为 SPY、沪深 300 和其他主要指数提供 yfinance 支持的分辨率。由 @MB-Ndhlovu (#48) 贡献。

🛡️ /upload 流媒体 + 大小限制

/upload 端点以 1 MB 块的形式传输请求正文，并通过部分文件清理中止经过 MAX_UPLOAD_SIZE。现在，50 MB 上限实际上是在恶意/超大 clients 下强制执行的。通过 4 项回归测试固定。由@genoshide (#53) 贡献。

📈 富途数据加载器（港股+A股）

第六个数据源——Futu OpenAPI港股和A股股票集成，具有券商级实时报价。由@hamza-mobeen (#47) 贡献。

🔧 vnpy CtaTemplate 导出技巧

第 72 项技能 — vnpy-export 为 vnpy 回测框架生成可立即运行的 CtaTemplate 策略代码。由@hamza-mobeen (#46) 贡献。

0.1.6维修

  • 加载程序：AKShare 加载程序通过强化注册表回退正确地将 ETF (510300.SH) 和外汇 (USDCNH) 路由到正确的端点
  • 工作空间：相对 run_dir 标准化为活动运行目录 - 修复工具调用中的空/相对路径（#43，@Mothilal-M）
  • 安全性：safe_path 中强制执行路径遏制 + 日记/影子帐户工具的沙箱
  • 构建：MANIFEST.in 在 sdist 中运送 .env.example / 测试 / Docker 文件
  • 前端：路由级延迟加载将初始包缩小为 688 KB → 262 KB
  • 文档：自述文件使用示例（#45，@hamza-mobeen）
  • 技能清单：同步到 22 个 MCP 工具/72 个技能/6 个数据源/29 个群体预设
