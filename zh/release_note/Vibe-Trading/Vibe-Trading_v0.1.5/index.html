Vibe-Trading v0.1.5

亮点

研究代理之上的两个新英雄循环 - 从经纪人日志中提取你自己的策略，然后回测你“应该如何”交易的影子。

👥 影子账户（新）

上传经纪商日志 → LLM 提取您的规则 → 跨市场运行规则手册 → 8 部分的 HTML/PDF 报告准确显示您在表格上留下多少盈亏以进行纪律细分（违反规则、提前退出、错过入场、反事实交易）。 4 个新工具（extract_shadow_strategy、run_shadow_backtest、render_shadow_report、scan_shadow_signals）+ 1 项技能。

📊 贸易期刊分析器（新）

analyze_trade_journal 摄取同花顺 / 东方财富 / 富途 / 通用 CSV 导出 → 完整交易概况（持仓天数、胜率、盈亏比、回撤）+ 4 项行为诊断（处置效应、过度交易、追势、锚定）。

📄 通用文件阅读器（新）

read_document 在一个统一的信封内发送 PDF、Word、Excel、PowerPoint、图像 (OCR) 和 40 多种文本格式。 read_url 来自 Jina 的网络版。

🧠 特工安全带 v2

  • 持久跨会话内存（~/.vibe-trading/memory/）
  • SQLite FTS5 会话搜索
  • 自我进化技能——完整的CRUD（保存/修补/删除/技能文件）
  • 5层上下文压缩
  • 读/写工具批处理
  • 107 项新测试

0.1.5 维护

  • 安全：python-multipart >= 0.0.18（CVSS 7.5 CVE 地板）
  • MCP：公开了 5 个新工具（贸易日志 + 影子帐户系列），修复了 pattern_recognition → pattern 注册表名称不匹配（返回 404）
  • Docker 奇偶校验：requirements.txt 添加了 9 个运行时依赖项（openpyxl、python-docx、python-pptx、pypdfium2、Pillow、ddgs、jinja2、matplotlib、weasyprint） - Docker 图像默默地缺少这些
  • CLI：横幅版本升至 0.1.5（卡在 0.1.0）
  • 前端：侧边栏+包。json 版本已升级至 0.1.5
  • 测试：test_skills.py 不再泄漏到 ~/.vibe-trading/skills/user/ 中
  • 技能清单：同步到 22 个 MCP 工具/71 个技能/29 个群体预设

安装/升级

pip install -U vibe-trading-ai==0.1.5

Docker：

docker compose pull && docker compose up -d

  • 暴露了 22 个 MCP 工具

  • 7个回测引擎+期权组合
  • 13 个 LLM 提供商，5 个具有自动回退功能的数据源
  • 29 个群体预设
