Vibe-Trading v0.1.11

这个项目是干啥的：一个用AI智能体来炒股票、做交易的框架，让AI按策略自动分析和下单，给想试试自动炒股的投资者用。

🇮🇳 v0.1.11 — 印度股票、基本面因素、IM 渠道 + 自 0.1.10 以来的汇总

v0.1.11 是三周工作的汇总。头条新闻：印度股票 (NSE/BSE) 成为一流的回测市场，PIT 安全的基本因子层使 Alpha Zoo 达到 5 个家族的 460 个 alpha，IM 通道运行时通过 16 个消息适配器提供研究，以及预定的研究端到端运行。他们周围提供可选的QVeris高级数据轨道、完成的**api_server模块化**、带有CI门的集中式环境配置、Trading 212只读连接器（11个经纪商）、周转感知投资组合优化器（5个优化器）、analyze_image视觉工具以及贡献者修复的长尾。 此版本可在 PyPI、ClawHub 和 GitHub 版本上使用。

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

亮点

🇮🇳 印度股票（NSE/BSE）是一流市场

专用的 IndiaEquityEngine（#305，感谢 @muku314115）对实际交易的市场进行建模：T+1 交割、无隔夜空头（选择加入日内）、可配置的 电路波段、1 股手数以及配置驱动的 STT / 印花税 / 交易所 / SEBI / GST 成本堆栈。 .NS/.BO 符号通过 yahoo → yfinance → india_broker → local 路由，其中​​ india_broker 是一个选择加入的 只读 Shoonya/Dhan bar 桥，并且 255 个 alpha101/qlib158 因子选择进入新的 equity_in 宇宙。回测引擎：7 → 8；市场数据来源：19 个免费 + QVeris = 20。

💎 基本因素层，第一阶段 — PIT 安全 SEC 基本原理

SEC 公司事实现在以与价格数据相同的方式流入密集的每日 fund:* 因子面板中 — 提交日期锚定（您只能看到当天公开的内容）、首次提交的重述政策、真实季度 (start, end) 框架选择和 第四季度合成，因此 YTD/年度框架不会污染 TTM，以及滚动 TTM 聚合。顶部：新 fundamental 动物园系列中的 get_fundamentals 工具和 4 个质量/价值因素。凭借周期早期的 4 个典型学术 alpha（#277，感谢 @Robin1987China — Jegadeesh 逆转、George-Hwang 52 周高点、Amihud 流动性不足、Harvey-Siddique 共同偏度），Alpha Zoo 在 5 个家庭中增长了 452 → 460。

💬 IM 通道运行时 — 通过 16 个适配器进行研究交付

相同的代理会话运行时现在附加到 16 个内置消息适配器 - WebSocket、Telegram、Slack、Discord、Matrix、WhatsApp、Signal、QQ/NapCat、WeChat/WeCom、飞书、钉钉、电子邮件、MS Teams、MoChat - 通过安装提示进行依赖门控，可通过 AgentConfig.channels 配置，并可通过 REST (/channels/*)、CLI 进行控制(vibe-trading channels ...) 和 Web 设置，在所有 5 个 UI 区域设置中。此版本还修复了第一张图像的剪纸问题：入站媒体现在位于 ~/.vibe-trading/uploads/<channel>/ 下，位于代理允许的文件根目录内（#465，感谢 @fei-moss），并且 NapCat 私人消息触发配对代码（#463）。

⏰ 预定研究，端到端

默认关闭的后台执行器 (VIBE_TRADING_ENABLE_SCHEDULER) 通过会话运行时触发到期的间隔/cron 作业（#278，感谢 @mvanhorn），在崩溃安全原子作业存储、身份验证门控 /scheduled-runs 路由（#452 中的测试，感谢 @Robin1987China）、报告库和回测后归因之上。结合研究自动驾驶仪第 3 阶段闭环（#267，感谢 @Robin1987China）——scaffold_signal_engine → link_autopilot_backtest——假设→信号引擎→回测→时间表现在可以在中间无需人工干预的情况下运行。

💰 可选的 QVeris 高级数据轨道

19 个免费来源保持默认状态。 仅显式付费模式（设置 → QVeris 或 vibe-trading data mode paid）可解锁 3 个密钥门控工具（qveris_search / qveris_inspect / qveris_execute）背后的 63 多个提供商，并具有默认预览和会话预算门控。 QVeris 永远不会进入自动回退：无密钥、无成本、无意外。

🧰 平台和安全

  • api_server 模块化完成 — 1,103 → 371 行（#424 结束#331，感谢@shadowinlife）经过一个路由切片循环后。
  • 集中式环境配置 - 一个 Pydantic EnvConfig 模式 + 一个 AST CI 门，拒绝配置层之外的原始 os.getenv （#440，感谢 @shadowinlife）。
  • Trading 212 只读连接器（#321，感谢 @mvanhorn）— 11 个经纪商。无运行时纸张/活体鉴别器 → place_order/cancel_order 硬拒绝每个订单，包括纸张。加上一个选择加入的 PreTradeAdvisoryInterface，可以记录咨询审查而无需绕过授权门。
  • 安全：环回 CSRF 保护 (#293)、CGNAT/mesh 范围的 SSRF 防护强化 (#389)、Pillow/langchain CVE 地板凹凸 (#390)、收紧的开发默认值。
  • 周转感知优化器（#466，感谢@Robin1987China）——第五个优化器：均值方差实用程序，对权重变化进行 L1 惩罚，因此只有当改进超过流失时，投资组合才会进行交易。
  • analyze_image 视觉工具（#464，感谢@fei-moss）——语义图表/屏幕截图读取会话模型（需要具有视觉功能的模型）。工具：72 个自由模式/75 个 QVeris。
  • 清单计数守卫（#461，感谢 @asahikiko）- 打包的 SKILL.md 功能计数现在根据 CI 中的源进行断言。

🙌 贡献者周期

自 0.1.10 以来，合并了 60 个贡献者撰写的 PR（总共 73 个）。完整的个人积分位于自述文件贡献者部分和 CHANGELOG — 亮点：@shadowinlife（12 个 PR，包括 api_server 顶点）、@Robin1987China（自动驾驶仪 P3、学术阿尔法、影子账户条件、周转优化器）、@muku314115（印度股权）、@mvanhorn （调度程序、Trading 212）、@fei-moss（视觉工具 + IM 修复）、@sambazhu（价值投资工具包）等等。 0.1.11 的数字： 8 个回测引擎 · 460 个 alpha / 5 个系列 · 86 个技能 · 30 个群体预设 · 20 个数据源 · 72 个免费工具（75 个付费） · 54 个 MCP 工具 · 11 个代理连接器 · 16 个 IM 适配器 · 5 个优化器。
