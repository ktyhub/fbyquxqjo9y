Vibe-Trading v0.1.7

🛡️ v0.1.7 — 安全边界强化 + 研究工作流程完善

v0.1.7 是 Vibe-Trading 的一个以安全为中心的维护版本。它增强了默认的 API、文件、URL、生成代码、shell 工具、Docker、CLI/Web 和 MCP/ClawHub 边界，同时为普通 CLI 和 Web UI 用户保留低摩擦的本地主机工作流程。 此版本可在 PyPI、ClawHub 和 GitHub 版本上使用。

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

变更流程图

亮点

🛡️ 安全边界强化

此版本的主要目标是默认情况下使 Vibe-Trading 更安全，而无需将本地研究工作流程转变为配置工作。

  • API 身份验证和读取保护：默认情况下，非本地 API 使用现在更加严格，并且敏感的运行/会话/群读取路径受到一致的保护。
  • 上传和本地文件边界：上传处理和本地文件读取工具现在使用更严格的路径/类型边界，回归测试涵盖了以前有风险的路径。
  • 文档和 URL 读取器：本地文档读取和出站 URL 读取现在强制执行更严格的安全检查。
  • 支持 Shell 的工具：Shell 执行工具通过入口点/显式选择加入进行控制，减少 Web/API/Docker/MCP 部署中的意外暴露。
  • 生成的策略加载：生成的回测和影子帐户策略代码在执行/导入之前进行验证。
  • Docker 基线：运行时映像现在以非 root vibe 用户身份运行，并且 Docker Compose 默认设置为 localhost-first。
  • 耐用性：强化由跨身份验证、上传、路径安全、文档读取、网页读取、工具注册表、回测加载和影子帐户代码生成的回归测试支持。 感谢 lemi9090 (S2W) 在发布之前提供协调的安全报告和修复覆盖率的快速验证。

⚙️ 网页用户界面设置

新的设置界面使提供程序/模型、基本 URL、推理工作和数据源凭证状态可通过 Web UI 进行管理，并由本地/身份验证保护设置 API 和数据驱动的提供程序元数据提供支持。 (#57)

🔥 相关热图

新的相关性仪表板/API 计算滚动收益相关性并呈现 ECharts 热图以进行投资组合和交易品种分析。后续修复使前端代理和 PR 审查拦截器保持一致。 （＃64，＃66）

🔐 OpenAI Codex OAuth 提供商

Vibe-Trading 现在通过 ChatGPT OAuth 登录 (vibe-trading provider login openai-codex) 支持 OpenAI Codex 提供商，并具有设置元数据和提供商适配器测试。 (#65)

🧭 A股ST前过滤技巧

新的 ashare-pre-st-filter 技能用于 A 股 ST/*ST 风险筛查，并具有后续相关性过滤功能，因此证券账户列表提及不会增加 E2 处罚计数。 (#63)

🖥️ 互动 CLI UX

交互模式现在有一个实时底部状态栏，用于显示提供程序/模型、会话持续时间、上次运行延迟和累积工具调用统计信息，以及通过 prompt_toolkit 提示历史导航和光标编辑。 (#69)

🧩 群体预设检查

vibe-trading --swarm-inspect <preset> 和相关管道使您可以在运行多代理工作流程之前更轻松地检查群体预设。 （＃73）

📈 股息分析技巧

添加了针对收入股票、派息可持续性、股息增长、股东收益率、除息机制和收益陷阱检查的 dividend-analysis 捆绑技能。

🧰 本地开发工作流程

通过 scripts/dev up|open|logs|stop 添加了单命令本地开发工作流程，以及 Codespaces 支持和前端/后端开发人体工程学。这样做的目的是使干净的本地测试和演示变得更加容易。
