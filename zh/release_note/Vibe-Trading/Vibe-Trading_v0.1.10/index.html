Vibe-Trading v0.1.10

修订 发布时间2026年6月19日 来源HKUDS/Vibe-Trading 英文原文

Vibe-Trading v0.1.10

这个项目是干啥的：一个用AI智能体来炒股票、做交易的框架，让AI按策略自动分析和下单，给想试试自动炒股的投资者用。

🌍 v0.1.10 — 自 0.1.9 以来的全局数据层 + 汇总

v0.1.10 是一个汇总版本。标题是全球数据层：市场数据注册从 10 个来源增长到 18 个来源，并获得 18 个只读数据工具，这些工具可以超越 OHLCV 进入基本面和流量，所有这些都通过 MCP 公开。它围绕着它提供了自 0.1.9 以来积累的所有内容 - 10 个代理 SDK 连接器、Alpha Zoo alpha compare 全堆栈、提供商可靠性检修、研究自动驾驶仪第 1 阶段、选择加入本地数据缓存以及社区驱动的安全强化浪潮。 此版本可在 PyPI、ClawHub 和 GitHub 版本上使用。

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

🌍 全局数据层 — 18 个来源 + 18 个只读数据工具

加载程序注册表从 10 个增长到 18 个市场数据源：

  • 免费，无密钥 — tushare、okx、yfinance、akshare、baostock、tencent、mootdx、ccxt、futu、local 以及四个新的直接 API 添加：Eastmoney、Sina、Stooq 和直接 HTTP 雅虎 client。
  • 可选的密钥门控美国提供商 — Finnhub、Alpha Vantage、Tiingo、FMP；缺失的键会在后备链中被跳过，永远不会使其崩溃。 后备链根据 IP 禁止风险（轻量级、可容忍节流的公共端点引导；密钥控制的 REST 路径）在共享节流 HTTP 门 (backtest/loaders/_http.py) 后面重新排序，具有每个主机的速率桶、抖动和会话重用。最上面有18种只读数据工具——资金流向、龙虎板、北向（沪港通）流向、保证金交易、大宗交易、股东人数、禁售期满、行业会员、研究报告、新闻、SEC备案文件（EDGAR + XBRL）、财务报表、期权链、机构持股、全市场筛选、交易品种搜索、FRED宏和iwencai自然语言A股搜索——覆盖A股/美股/ HK，全部通过 MCP 曝光。三个共享的 clients (eastmoney / yahoo / sec_edgar) 支持加载程序和工具，以及一个综合的 data-routing 索引以及每个源的 eastmoney / sec-edgar 技能文档层。

💱 10 个经纪商 SDK 连接器 — 阅读+纸质，强制门控实时

交易是连接器优先：选择一个配置文件，纸质/实时是连接器的一个属性。此次发布使名册达到10家经纪商——IBKR（本地只读TWS/网关）·Robinhood（Agentic MCP，OAuth）·Tiger·Longbridge·Alpaca·OKX·Binance·Futu·Dhan·Shoonya（印度NSE/BSE + F&O）。 Direct-SDK 连接器共享 broker_sdk 传输，每个连接器都执行读取 + 纸质帐户订单下达；实时布局通过单个故障关闭有界自治门（sdk_order_gate.py：授权+终止开关+审核）。 没有运行时纸质/实时鉴别器（Longbridge、Dhan、Shoonya）的经纪商在结构上上限为 纸质 + 只读 - 他们的 place_order / cancel_order 在第一行硬拒绝任何非纸质配置。下订单工具远离 MCP（仅限代理 + CLI）。

📊 CLI / REST / Web / 代理工具的 Alpha 比较

vibe-trading alpha compare 在您的宇宙中按 IC / IR 对任何一组 Alpha Zoo 因素进行排名，在 CLI 后面共享一个 compare_runner.compare_alphas 核心、具有 SSE 流式传输进度的 POST /alpha/compare REST 路线、Alpha Zoo Web UI 比较视图和只读 alpha_compare 代理工具。 run_bench(only=…) 子集过滤器仅对比较因素而不是整个动物园进行测试。

🔌 提供商可靠性检修

提供者能力层控制每个提供者的推理捕获/重放、Gemini 思想签名、Kimi 用户代理和 OpenRouter 推理主体。 vibe-trading provider doctor 打印经过编辑的诊断快照。流式传输失败现在会引发一个明确的、经过编辑的 ProviderStreamError（携带 status_code + .retryable），并在 4xx 上重试一次瞬态和快速失败；节流的 reasoning_delta SSE 在 Web UI 中驱动“推理…”活动指示器。另外：可选的本机 DeepSeek 适配器 (VIBE_TRADING_DEEPSEEK_ADAPTER)、只读工具硬超时 (VIBE_TRADING_TOOL_TIMEOUT_SECONDS) 和每个提供商的温度处理（Kimi-k2 强制为 1.0，MiniMax 钳位 > 0）。

🔬 研究自动驾驶仪第一阶段

run_research_autopilot 将 hypothesis_id 转变为研究目标（论文作为客观、与回测相关的验收标准、下一步提示），而 generate_backtest_config 根据假设的宇宙和数据源自动编写回测 config.json - 因此代理直接从想法 → signal_engine.py → 运行。

🗃️ 选择加入本地数据缓存 + local 加载器

VIBE_TRADING_DATA_CACHE=1 将 已结算 条缓存到 ~/.vibe-trading/cache（用户主目录，从不 存储库）；过时防护永远不会缓存今天结束的范围，并且缓存的帧与实时获取的字节相同。新的 local 加载程序通过 ~/.vibe-trading/data-bridge/config.yaml 直接从您自己的 CSV / Parquet / DuckDB 文件读取 OHLCV，并提供正常的后备链支持。

🛡️ 安全与强化浪潮

社区驱动的强化过程：API 设置写入身份验证 (#245)、代理 shell 工具选择加入 (#243)、环回主机重新绑定拒绝 (#242)、显式本地关闭身份验证 (#241) 以及任务提案 ID (#256)、持久内存类型 (#257) 和 MCP 群运行 ID (#258) 的标识符包含。加上响应式中流停止 + 返回运行会话时的 SSE 重新连接 (#229)、多引擎 web_search 回退 (#231) 以及通过 OpenAI 兼容工具调用的 Gemini thoughtSignature 往返 (#176、#184)。

🪪 版本报告现已一致

--version、REST API (/docs + /api)、MCP 服务器握手和 Web UI 页脚均源自同一个来源 — REST API 已漂移到错误的硬编码 5.0.0。打包现在还在轮子中提供了技能示例脚本，并且 Docker 映像安装了 weasyprint 的本机库，以便呈现 PDF 报告。
