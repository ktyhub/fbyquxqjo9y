Vibe-Trading v0.1.12

这个项目是干啥的：一个用AI智能体来炒股票、做交易的框架，让AI按策略自动分析和下单，给想试试自动炒股的投资者用。

🌀 v0.1.12 — 关联机制时间线、三个新提供商、MetaTrader 5 + 可靠性浪潮

v0.1.12 汇总了自 0.1.11 (2026-07-10) 以来近两周的工作 — 头条新闻：相关机制时间表，它回答*“市场何时融合成一个集团，我们现在处于这种状态吗？”*，三个新的 LLM 提供商加上基于目录的端点解析，使每个提供商只需一个密钥即可工作，MetaTrader 5 (Exness) 经纪商连接器（12 个经纪商）， 策略开发经理技能，币安 USD-M 永续债券具有历史资金，以及广泛的可靠性浪潮 - 严格的 JSON/有限强化、会话/日志稳健性、80×矢量化和本机 zai 流修复。 此版本可在 PyPI、ClawHub 和 GitHub 版本上使用。

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

🌀 相关机制时间线

新的附加 GET /correlation/regime 端点和“相关性”选项卡上的选择加入**“制度时间线”条带（＃756，关闭＃719，感谢@ebujinovch）。它重用了已获取的相同价格数据 /correlation：滚动成对相关性减少为每条边缘密度标量（|ρ| 清除阈值的资产对的比例），该系列被因果平滑**（尾随窗口 - 永远不会读取未来），并且双阈值迟滞状态机标记连续的 FUSED 事件，并带有抑制颤动的死区。它共享 /correlation 的授权 + 速率限制预算，将窗口降低，因此短时间线不能返回空，并且明确描述性风险背景，而不是交易信号。由 correlation-regime 技能支持（#557）。

🔌 三个新的 LLM 提供商 + 强大的端点解析

SiliconFlow（CN + Global，#565，感谢 @UNHNQ）、iFlytek Spark（#537，感谢 @FenjuFu）和 原生 Anthropic Messages API（#695，感谢 @jelech；pip install "vibe-trading-ai[anthropic]"）以及 MiniMax 区域端点（#731，感谢 @octo-patch）的原生适配器。在下面，提供者凭据通过一个集中路径解析（#563，感谢@shadowinlife），并且修复了两个长期存在的粗糙边缘（#758）：当没有设置 *_BASE_URL 时，后端现在回退到每个提供者的规范目录端点（已使用相同的默认 Web 设置），而不是默默地默认为 api.openai.com - 因此提供者仅使用一个密钥 - 并且流式传输 零块的端点回退到非流式调用而不是错误，当基本 URL 配置错误时，会显示 HTML 错误页面提示。

📈 MetaTrader 5 (Exness) 连接器 + mt5 数据源 — 12 家经纪商

一流的 MetaTrader 5 经纪商连接器（#481，感谢 @StaniellG） — 完整的读取表面以及针对本地运行终端的下单，具有 双向身份防护（纸质资料 ⇔ 演示 trade_mode，登录固定，竞赛被拒绝）以及演示和实时连接器级别的 max_order_volume / max_order_notional_usd 上限。实时委托门获得了 forex/cfd 工具词汇和手数大小挂钩，因此美元上限与手数大小的订单绑定（0.1 手数 EURUSD ≈ 10,800 美元，绝不是 0.1 × 报价）。 mt5 装载机引领外汇后备链（经纪商精确符号，带有 Exness 后缀发现，1m–1D 条形图）。代理连接器：11 → 12；市场数据来源 → 23。

🧬 战略发展经理

sdm_register / sdm_status / sdm_decay_scan 将学术论文和经纪人研究转化为注册因素和策略（#457，关闭#455，感谢@shadowinlife），并由持久 SQLite 工件存储（UNIQUE(name, universe)）和驱动 active → monitoring → decayed → disabled 生命周期的自动化IC/Sharpe 衰减监控支持。附带适用于 read_document 的可插入 OCR（默认情况下为本地 RapidOCR；云 Qwen-VL 仅是显式选择加入，从不自动选择）。

₿ 币安 USD-M 永续合约

显式 BTC-USDT-PERP 路由具有执行/标记价格分离（当两者时间戳不同步时失败关闭）和历史资金结算（#470/#716，感谢@honginp）。维护括号与实时验证的提取分离，并作为经过验证的内容哈希工件提供（#757），因此普通的 -PERP 回测保持零凭证 - 每个 Perp 提取都需要 Binance API 密钥的回归消失了。

👁️ 可插入 OCR + LLM 视觉提取

read_document 获得了可插拔的 OCR 引擎架构，具有可选的 LLM 视觉提取 和可配置的文本密度阈值（#548，感谢 @shadowinlife） - 默认情况下是本地的，云引擎仅选择加入，从不自动选择。

🧰 平台和安全

  • 所有五个投资组合优化器的前瞻偏差修复（#487，感谢 @YZY0108） - 在柱线开盘时执行的权重不再包括该柱线的接近收盘收益。加上每个优化器实现的投资组合周转率指标（#478，感谢@Robin1987China）。
  • 安全强化 - 2026 年 7 月 10 日外部审计的所有 10 个结果已关闭 (#476)：AST 强化回测沙箱、短期 SSE 身份验证票、强化 Compose、/correlation 身份验证 + 速率限制、安全标头、哈希锁定依赖项和 SHA 固定操作。
  • 80×信号对齐矢量化（#698，感谢@shadowinlife）和群MCP工具发现缓存（#704）在宽面板和多工作线程运行上减少挂钟。
  • 选择 Alpaca 的 TAP 模式（#377，感谢 @0xZKnw）、IBKR 线程本地连接池 + 快照报价（#636，感谢 @MikeCer）、Robinhood account_number 接线（#726，感谢 @nareshkps）、Requesty 网关提供商（#474，感谢 @Thibaultjaigu）和 用户群预设发现（#570，感谢@darkknight4563）。
  • 两个新的学术因素 - Frazzini-Pedersen betting-against-beta (#480，感谢 @YogeshModi24) 和 academic_corr_rewire (#705，感谢 @ebujinovch)：Alpha Zoo 460 → 462 跨越 5 个家庭。

🛠️ 可靠性和正确性浪潮

  • 严格-JSON /有限数强化跨越回测+工具堆栈（感谢@santhreal）——当净值跨越零（#765）或年化爆炸路径（#739/#740）时，风险比率保持有限；标量指标 (#766)、因子 IC 标准 (#767) 和模式趋势斜率 (#764) 发出严格的 RFC-8259 JSON（null，从不 NaN/Infinity）； Black-Scholes 助手将非阳性点/罢工视为内在的（#744）。
  • 会话/日志稳健性 - 一个损坏的 session.json (#762) 或模式错误的 messages.jsonl 行 (#763) 不再中止列表/阅读； Excel 浮点字符串化 A 股代码 (#770)、unicode-dash PDF 页面范围 (#769)、export KEY= dotenv 行 (#768) 和 yahoo 1m 条形图 (#761) 均能正确解析。
  • 广泛的可靠性 - 在第一次 AgentLoop 迭代之前取消（#641，关闭 #638），修复前端 insertBefore 流 DOM 竞赛（#717，感谢 @Marnie0415），复合引擎回退未知符号（#734），对 Codex 流 HTTP 失败进行分类以进行正确的重试（#663），以及 #584（感谢 @xkam7ar）关闭批次包装/网络/调度程序/群/CLI 问题。
