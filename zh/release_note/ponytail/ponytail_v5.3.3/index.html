ponytail v5.3.3

这个人清理了乐队。在团队、企业和托管计算机上，第一个提示上的警告消失了，并且区域再次显示您的模型和会话名称。在 VS Code 中，它保留在一行上，其他插件的命令不再打印在马尾辫的名称下，并且嘈杂的“重复？”提示消失了。

发生了什么变化

  • 修复（band）：在https://github.com/DietrichGebert/ponytail/pull/1161中@timofeevAV /clear和/resume之后再次显示级别
  • 修复（地图）：提高 git ls-files 缓冲区，以便大型存储库通过 @HyperionBurn 在 https://github.com/DietrichGebert/ponytail/pull/1156 中跟踪文件
  • ci：在https://github.com/DietrichGebert/ponytail/pull/1154中@ml-lubich在测试工作流程中运行代理基准测试自测试
  • 文档：通过 https://github.com/DietrichGebert/ponytail/pull/1135 中的 @Boulea7 阐明游标模式状态范围
  • 修复（codex）：小作曲家图标，而不是 https://github.com/DietrichGebert/ponytail/pull/1164 中 @DietrichGebert 的 554 KB 徽标
  • 修复（钩子）：15 s 钩子超时，因此 Windows 上缓慢的节点启动会在 https://github.com/DietrichGebert/ponytail/pull/1165 中保持 @DietrichGebert 的输出
  • 修复（hooks）：给代码库映射 3 秒，以便缓慢的 Windows 启动将其保留在 https://github.com/DietrichGebert/ponytail/pull/1166 中的@DietrichGebert
  • 修复（工作台）：在 https://github.com/DietrichGebert/ponytail/pull/1116 中 @devohmycode 清理工作目录之前等待被杀死的待办事项服务器 *修复（band）：在https://github.com/DietrichGebert/ponytail/pull/1242中找到@trinehart-attentive没有经典钩子的转录本
  • 修复（band）：仅监视/clear，/resume和/branch，因此其他插件的输出不会在https://github.com/DietrichGebert/ponytail/pull/1291中被@ph3on1x标记为马尾辫
  • 修复（band）：仅在https://github.com/DietrichGebert/ponytail/pull/1302中的@lelmarir在终端中将行大小调整为bodyColumns
  • 修复（带）：删除重复项？提示，仅计算项目文件，通过 @DietrichGebert 在 https://github.com/DietrichGebert/ponytail/pull/1305 中查看更严格的详细信息
  • 杂务：通过 @DietrichGebert 在 https://github.com/DietrichGebert/ponytail/pull/1307 中发布 v5.3.3
