ponytail v4.13.0

此版本主要是关于马尾辫保持在您设定的水平。 Codex 上的切换级别现在提供了新级别的规则，每个项目都保留自己的模式，关闭实际上意味着关闭，并且状态线徽章在插件更新后仍然存在。 Kimi Code 作为新主机加入，自述文件现在还提供西班牙语、韩语、简体中文和日语版本，并且取消了 ZCode 支持。
