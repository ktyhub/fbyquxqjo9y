gson gson-parent-2.9.0

这个项目是干啥的：谷歌出的 Java JSON 处理库，能在 Java 对象和 JSON 字符串之间轻松互转，给需要在项目里读写 JSON 的程序员用。

变更架构图

亮点

  • 破坏性变更：最低要求 Java 7 — Gson 现在要求 Java 7，不再是 Java 6。请相应升级构建和运行时工具链；必须留在 Java 6 的项目只能停留在更早版本。
  • 新 API 与反序列化支持 — 新增 GsonBuilder.disableJdkUnsafe()、FieldNamingPolicy.UPPER_CASE_WITH_UNDERSCORES、EnumMap 反序列化和 LazilyParsedNumber 默认适配器。这些可以替代自定义的绕行方案，让你对对象创建和字段命名有更多控制。
  • 正确性与线程安全修复 — 修复了 JsonReader.hasNext() 在输入结束时错误返回 true、构造函数不可访问的 Collection/Map 类型序列化失败、TreeTypeAdapter 的线程安全问题，以及 Gson.newJsonWriter 忽略 lenient 和 HTML-safe 设置。还修复了 upperCaseFirstLetter 把非字母字符也转成大写的问题。
  • 默认适配器更严格 — 默认适配器现在执行更严格的解析，异常信息也有所改进。以前能接受的输入现在可能失败，所以升级前请运行反序列化测试并检查自定义适配器。
  • 构建改动与升级判断 — 移除了 Gradle 构建支持，影响的是构建 Gson 本身的贡献者或下游项目，而不是普通的 Maven 产物使用者。修正后的 Multi-Release JAR 打包对模块化应用有益。Java 7+ 用户如果需要新 API 或修复就应该升级；其他人可以在回归测试后把它当作可选的维护版本。

支持的最低 Java 版本从 6 更改为 7。

  • 将目标 Java 版本更改为 7 (#2043)
  • 将 module-info.class 放入 Multi-Release JAR 文件夹中 (#2013)
  • 改进无法构造抽象类时的错误消息 (#1814)
  • 支持EnumMap反序列化(#2071)
  • 添加 LazilyParsedNumber 默认适配器 (#2060)
  • 修复 JsonReader.hasNext() 在文档末尾返回 true (#2061)
  • 删除 Gradle 构建支持。构建脚本已过时且不再积极维护 (#2063)
  • 添加 GsonBuilder.disableJdkUnsafe() (#1904)
  • 在 FieldNamingPolicy 中添加 UPPER_CASE_WITH_UNDERSCORES (#2024)
  • 修复使用不可访问的构造函数序列化 Collection 或 Map 失败的问题 (#1902)
  • 改进 TreeTypeAdapter 线程安全性 (#1976)
  • 修复 Gson.newJsonWriter 忽略宽松和 HTML 安全设置 (#1989)
  • 删除未使用的 LinkedHashTreeMap (#1992)
  • 使默认适配器更加严格；改进异常消息 (#2000)
  • 修复 FieldNamingPolicy.upperCaseFirstLetter 大写非字母 (#2004)
