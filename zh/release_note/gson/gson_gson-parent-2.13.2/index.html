变更流程图

亮点

  • JPMS 打包修复 — 改进了模块声明的打包方式，使 Eclipse 和 VS Code 用户能正确以 com.google.gson 引用 Gson 模块（issue #2679）。这是升级的主要理由。
  • 内部清理 — 移除了内部类 GsonPreconditions（#2879）。使用受支持的公开 API 不需要迁移，但依赖 Gson 内部实现的代码可能受影响。
  • 构建与依赖维护 — 改用 central-publishing-maven-plugin（#2900）；本版主要是依赖更新。变更日志没有指出面向用户的运行时行为变化。
  • 升级建议 — 用 JPMS 且在 Eclipse 或 VS Code 里遇到过模块名解析问题的应升级。其他用户一般可以跳过；没有记录公开 API 破坏性变更或必须执行的迁移步骤。

此版本中的主要更改只是更新的依赖项。

发生了什么变化

  • 改进了 Gson jar\ 中 JPMS 模块声明的打包 这修复了 Eclipse 和 VS Code 用户无法引用 Gson 模块名称 com.google.gson 的问题。参见问题 https://github.com/google/gson/issues/2679.
  • 通过@Marcono1234在https://github.com/google/gson/pull/2879中删除内部类`GsonPreconditions`
  • 在 https://github.com/google/gson/pull/2900 中切换到使用 @eamonnmcmanus 的central-publishing-maven-plugin

新贡献者

  • @MukjepScarlet 在 https://github.com/google/gson/pull/2852 中做出了第一个贡献
  • @ChrisCraik 在 https://github.com/google/gson/pull/2856 中做出了第一个贡献
