gson gson-parent-2.12.0

变更流程图

亮点

  • 移除 Java 7 支持（破坏性） — 头号变化：2.12.0 彻底不再支持 Java 7。还在 Java 7 上的必须留在更早的 Gson 版本；这是唯一真正阻塞升级的迁移项，其他人不需要改代码。
  • JsonReader 嵌套深度限制（PR #2588） — 给 JsonReader 加了深度上限，防止深层嵌套或恶意 JSON 导致递归失控/栈溢出。解析不可信输入的值得升级；否则影响很小。
  • 类型适配器行为修复（PR #2789、#2731） — 重新允许为 JsonElement 注册自定义适配器（恢复了一条此前坏掉的定制路径）；引入 NullSafeTypeAdapter，使 TypeAdapter.nullSafe() 不再把自己套进层层嵌套的 null-safe 适配器里。注册过 JsonElement 适配器或依赖 nullSafe() 语义的要留意。
  • 泛型类型解析正确性（PR #2758、#2759、#2706） — 在 GsonTypes.getMapKeyAndValueTypes 中支持 Properties 子类；在 ParameterizedTypeImpl 中强制 rawType 必须是 Class；修复了 owner 发生变化时解析 ParameterizedType 未克隆 typeArguments 数组的问题。都是较窄的边界修复，但和大量反射泛型操作的代码相关。
  • 静态分析与打包——升级结论（PR #2693、#2711、#2712、#2735、#2727、#2734、#2704） — 新增 @CheckReturnValue 注解（配合 Error Prone 使用），以及 OSGi/bnd 清理（bnd.bnd 移入 bnd-maven-plugin 配置、去掉了对 gson.annotations 的自导入）和内部枚举/优化重构。想要解析加固和适配器修复，或用的是没有 Java 7 包袱的现代 JDK，就升级；如果锁定在 Java 7，或只通过 OSGi 消费 Gson 且不需要这些行为修复，放心跳过。

发生了什么变化

最大的变化是我们不再支持Java 7。仍然需要在Java 7上运行的人将需要使用早期版本的Gson。

其他变化：

  • 允许@Marcono1234在https://github.com/google/gson/pull/2789中再次注册`JsonElement`的适配器
  • 通过 @Marcono1234 在 https://github.com/google/gson/pull/2588 中添加 JsonReader 的嵌套限制
  • 将 @CheckReturnValue 添加到我们的套餐中。通过 @cpovirk 在 https://github.com/google/gson/pull/2693
  • 添加 NullSafeTypeAdapter 以防止 TypeAdapter.nullSafe() 返回嵌套的空安全类型适配器 (#2729) by @lyubomyr-shaydariv in https://github.com/google/gson/pull/2731
  • 支持 https://github.com/google/gson/pull/2758 中 @panic08 的 GsonTypes.getMapKeyAndValueTypes 中的属性子类
  • 通过 https://github.com/google/gson/pull/2759 中的 @panic08 强制 rawType 成为 ParameterizedTypeImpl 中的类
  • 通过 @Marcono1234 在 https://github.com/google/gson/pull/2704 中删除枚举适配器的 AccessController 使用
  • 修复了 https://github.com/google/gson/pull/2706 中 @TBlueF 解析具有更改所有者的 ParameterizedType 时 typeArguments 数组不被克隆的问题
  • 删除https://github.com/google/gson/pull/2711中@HannesWell对所需OSGi执行环境的重复声明
  • 通过https://github.com/google/gson/pull/2712中的@HannesWell将bnd.bnd文件配置移动到bnd-maven-plugin的’bnd’元素中
  • 通过https://github.com/google/gson/pull/2727中的@Marcono1234将枚举和`JsonElement`适配器类移动到单独的类文件
  • EnumTypeAdapter 构造函数由 @esaulpaugh 在 https://github.com/google/gson/pull/2734 中优化
  • OSGi / bnd：删除https://github.com/google/gson/pull/2735中@chrisrueger的gson.annotations的自导入
