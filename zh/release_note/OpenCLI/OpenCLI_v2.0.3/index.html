OpenCLI v2.0.3

修订 发布时间2026年11月7日 来源jackwener/OpenCLI 英文原文

OpenCLI v2.0.3

包括 Chrome 扩展 1.0.27。更新环回连接、本机键盘输入和浏览器窗口恢复修复的扩展。

特点

  • 添加拼多多搜索和 Twitter 列表成员命令。
  • 在 Twitter 搜索结果中包含回复和转发，并在身份验证失败时建议站点登录命令。

修复

  • 就守护进程、CLI 和扩展之间可到达的环回地址达成一致；避免用较旧的 CLI 替换较新的守护程序。
  • 将浏览器 clicks 瞄准已解析的元素，检测同级遮挡，发送完整的本机键盘事件，并在重新启动后恢复拥有的空闲窗口。
  • 当文件选择器未打开时，回退到 DataTransfer 上传；安全地替换 Windows 上过时的插件主机连接。
  • 在管道中保留 JavaScript 管道和带引号的表达式，在 URL 片段之前附加查询参数，并转义 CSV/Markdown 标头。
  • 隔离并发下载临时文件，保留文章代码块，并遵守 yt-dlp 失败退出状态。
  • 改善 LinkedIn 体验、活动和职位解析；等待微信验证和文章渲染；修复携程火车导航。
  • 改进 Twitter 身份、Facebook 搜索、Reddit 阻止页面处理、JD 登录检测、Gemini 对话提取、Grok 会话/文本提取和 YouTube 登录检测。
  • 更新小红书搜索和创作者注释提取，并将卸载的交互计数报告为错误而不是零。
  • 将 undici 更新为 7.30.1 以获取已发布的安全公告。
