OpenCLI v2.0.0

大版本 发布时间2026年10月17日 来源jackwener/OpenCLI 英文原文

OpenCLI v2.0.0

主要版本专注于代理体验：更小的 CLI 表面、可预测的 JSON 结果、原生 Chrome API 以及证据驱动的适配器开发。包括 Chrome 扩展 1.0.25。

重大变更和迁移

  • 浏览器会话是显式选项：使用 opencli browser <command> ... --session research 而不是位置会话名称。
  • CLI结果默认为{ "ok": true, "data": ... }；失败使用 { "ok": false, "error": { "code", "message", "hint", ... } } 和非零退出状态。更新消费者阅读data；跟随模式发出 JSON 线。明确的人类可读格式和原始导出仍然可用。
  • 使用 opencli adapter init、adapter test 和 adapter check 进行适配器创作和验证。它们取代了以前的浏览器初始化/验证和适配器验证入口点。
  • 使用 opencli browser network --static 捕获请求以及 AST 派生的端点证据，使用 opencli browser state --diagnostics 进行页面诊断。单独的发现/分析工作流程已被删除。
  • Electron 桌面自动化、其应用程序注册表和公共启动器导出、站点地图知识和外部 CLI Hub 直通被删除。仍然支持与 Chrome 的直接 CDP 连接。
  • 现有的 JS 适配器注册和执行合约（cli({...})、func(args)、func(page, args)）仍然受支持。适配器 defaultFormat 不再覆盖 CLI 的 JSON 默认值。

特点

  • 通过 opencli browser chrome describe 和 chrome call 原生 Chrome API 发现和调用，包括选项卡/窗口管理以及选项卡组创建和编辑，无需附加页面会话。受管理的会话资源受到保护。
  • 使用 opencli list [query] --site --limit --offset 进行紧凑、分页的命令发现；简化了捆绑代理技能和适配器创作。
  • 基于 AST 的静态端点发现与捕获的网络证据集成，并在请求时保留不完整的网络捕获。
  • 每个站点插槽池提供并发适配器运行独占选项卡和运行级别节奏；可选的自有选项卡清理和可配置的浏览器空闲超时。
  • Proton API 收件箱和经过验证的浏览器身份验证；小红书评论/评论删除和YouTube评论命令；更丰富的 Twitter、YouTube 和 Bilibili 元数据。

修复

  • 从直接 CDP 页面选择中排除 Chrome 155 浏览器工具栏目标，以便空白选项卡仍然可用。
  • 更可靠的 ChatGPT 文件/图像上传和作曲家定位；当前的 Gemini、Grok 和 DeepSeek 作曲家流程。
  • 小红书验证码/搜索/评论处理、淘宝购物车确认和阻塞页面检测、DBLP 浏览器支持的 XML 读取以及 YouTube 频道句柄解析。
  • 插件路径包含和主机包链接、浏览器上传文件选择器激活、身份验证恢复提示以及结构化错误/退出代码处理。
  • 更新了 Vitest 以解决 GHSA-82fw-gwwq-j7x9。 完整 changelog: https://github.com/jackwener/OpenCLI/compare/v1.8.8…v2.0.0
