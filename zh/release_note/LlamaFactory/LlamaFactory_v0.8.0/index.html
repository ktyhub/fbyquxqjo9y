LlamaFactory v0.8.0

这个项目是干啥的：是一个给大模型做微调的统一工具，让开发者不用深究训练细节，用配置甚至网页界面就能把开源模型调成自己要的样子。

变更架构图

亮点

  • LlamaBoard 中的分布式训练 — Web UI 现在支持单机分布式训练、从保存的 checkpoint/配置恢复（包括全量微调和冻结微调的 checkpoint），以及吞吐监控（#4053、#4066）。开发者不用切到 CLI 就能管理和诊断多卡任务。
  • 更多对齐目标 — KTO（#3785）支持从二元的”理想/不理想”反馈优化，不需要成对的偏好样本；SimPO 增加了无参考模型的偏好目标。团队可以在现有训练流水线里把两者当作 DPO/PPO 的替代方案评估。
  • 多模态推理 — API 模式现在接受图片输入，新支持的视觉语言模型（如 PaliGemma）可用于服务。CLI 推理也加入 system message 控制（#3812），多模态 RLHF 和 LoRA targeting 的修复（#3835）减少了微调失败。
  • 数据集互操作与打包 — 偏好数据集现在接受 ShareGPT 格式（#3799），dataset_info.json 支持 num_samples（#3829），SFT 提供贪心背包打包（#4009）。用 num_samples 做可控的子集运行，启用打包前验证打包序列长度和 loss mask。大文件也已从仓库移除，所以要检查引用了仓内副本的工作流。
  • 服务与初始化控制 — 把 max_lora_rank 透传给 vLLM（#3794），让更高 rank 的适配器不受后端默认值限制。新增 train_from_scratch 参数可随机初始化而非加载预训练权重；只把它留给预训练式运行，因为它从根本上改变了训练起点。
  • 破坏性变更 — 未宣布。
