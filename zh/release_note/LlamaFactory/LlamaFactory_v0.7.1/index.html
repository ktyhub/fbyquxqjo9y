LlamaFactory v0.7.1

LlamaFactory v0.7.1

这个项目是干啥的：是一个给大模型做微调的统一工具，让开发者不用深究训练细节，用配置甚至网页界面就能把开源模型调成自己要的样子。

变更架构图

亮点

  • 强制安装与新 CLI 入口 — #3596 把安装变成前置条件：不能再直接从源码检出运行训练/推理。一切都要走 llamafactory-cli，入口点是 src/llamafactory/cli.py。如果你的自动化按文件路径调用脚本，升级前改指向 CLI，否则任务会直接失败。
  • 文件与参数的破坏性重命名 — 同一轮重构把 train_bash.py→train.py、train_web.py→webui.py、api_demo.py→api.py，更危险的是把参数 num_layer_trainable→freeze_trainable_layers、name_module_trainable→freeze_trainable_modules。保存的配置、shell 脚本和任务定义里的旧名字都要更新；否则冻结设置可能被静默忽略而不是报错，所以要仔细审计。
  • 脚本移除与新子命令 — cli_demo.py、evaluate.py、export_model.py、web_demo.py 被删除；改用 llamafactory-cli chat/eval/export/webchat。示例也从 shell 脚本切到 YAML 配置，可读性更好，但现有 eval/export 流水线和从示例派生出来的脚本必须迁移，不能只是重跑。
  • 行为变化：移除数据集 SHA1 校验 — #3596 去掉了加载数据集时的哈希校验。启动会更快，但损坏或被篡改的缓存数据集不再被自动发现——如果你依赖这个完整性保证，值得自己加校验。
  • 新能力 — 支持在 Ascend NPU 910 设备上训练/推理（提供 Docker 镜像）；vLLM 引擎新增 stop 参数（#3527），让生成能在停止序列处正确终止；freeze_extra_modules 可在冻结调优时微调 token embedding，这对新增 token 或词表很重要。README 还加了 Llama3 快速上手。
  • 新模型覆盖与值得注意的修复 — 新增 Yi-1.5（6B/9B/34B）和 DeepSeek-V2（236B）的 base/chat 版本，以及 Yi-VL-Chat（#3748，视觉）和 Llama3-Chinese-Chat；注意 236B 模型对硬件要求很高。底层还要留意 DPO/ORPO 慢操作修复和多模态全量微调修复（#3651），这两项都可能改变偏好调优或 multimodal 全量微调的结果。

核心重构

  • 新增 CLI 用法，现在推荐用 llamafactory-cli 启动训练和推理，入口位于 cli.py
  • 文件重命名：train_bash.py -> train.py、train_web.py -> webui.py、api_demo.py -> api.py
  • 删除文件：cli_demo.py、evaluate.py、export_model.py、web_demo.py，改用 llamafactory-cli chat/eval/export/webchat
  • 示例改用 YAML 配置 而非 shell 脚本，更清爽
  • 加载数据集时移除 sha1 哈希校验
  • 参数重命名：num_layer_trainable -> freeze_trainable_layers、name_module_trainable -> freeze_trainable_modules

上述改动由 @hiyouga 在 #3596 中完成。

提醒：现在安装是使用 LLaMA Factory 的强制要求

新功能

  • 由 @zhou-wjjw 和 @statelesshz 支持在 Ascend NPU 910 设备上训练与推理（也提供 docker 镜像）
  • 由 @zhaonx 在 #3527 中支持 vLLM 引擎的 stop 参数
