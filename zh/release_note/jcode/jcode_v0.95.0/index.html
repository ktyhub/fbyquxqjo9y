jcode v0.95.0

jcode v0.95.0

变更流程图

亮点

  • OpenCode Go 模型，包括 grok-4.7 和 gpt-6-luna，现在通过响应 API 进行路由
  • 挂钩公开回合结束令牌的使用情况，并且turn_start/turn_end现在会触发一次性jcode运行回合
  • /agents 支持每会话工作模型覆盖

改进

  • 当启用display.resume_project_scope时，/resume可以打开范围到当前项目
  • Swarm 获得了一个停滞的工人看门狗，并且无头运行——套接字会话可以加入 Swarms
  • macOS 菜单栏助手使用稳定的签名身份，将流媒体图标绘制为绿色，并且可以通过 [menubar]enabled = false 关闭
  • 内嵌图像适合其保留框，信息小部件拥抱其内容
  • 命令风险评估现在检查 $(…)、反引号和此处文档中的命令
  • SDK 启动的私有实例不再在会话中自动更新，并给出更短、更准确的连接错误

修复

  • Ctrl/Alt/Cmd 快捷键适用于韩语 2-Set 输入源
  • 当 jcode 在信号上退出时，终端键盘协议和 TUI 模式将恢复
  • 速率限制和提供商重新连接自动恢复受到限制，而不是无限期地重试
  • OpenAI 流从停顿中恢复得更快，并且 OAuth 令牌刷新不再挂起
  • 作为 DSML/调用标记文本发出的工具调用被恢复而不是丢失
  • 通过 OpenRouter 进行 Kimi 推理不再丢失非累积快照中的文本
  • 恢复会话可以修复陈旧的凭证路径，以便 Swarm 工作人员继承有效的凭证路径
  • 记录中保存的计算机使用屏幕截图的大小受到限制
  • 浏览器工具在 macOS 上重复使用持久会话，无需打开重复的窗口
  • 当 jcode 以覆盖的 HOME 启动时，仅运行一个菜单栏帮助程序
  • Swarm 成员归属和重启通知正确 完整 changelog：https://github.com/1jehuang/jcode/compare/v0.94.0…v0.95.0

平台可用性

  • Linux x86_64：可用
  • Linux aarch64：可用
  • macOS Apple Silicon：可用
  • macOS 英特尔：可用
  • Windows x86_64：可用
  • Windows ARM64：可用
  • FreeBSD x86_64：可用
