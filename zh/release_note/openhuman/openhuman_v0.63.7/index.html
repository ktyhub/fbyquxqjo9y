openhuman v0.63.7

流程、内存和语音启动

该版本包含了深度工作流程构建升级、更精简的内核化核心以及内存、推理和语音方面的巨大可靠性胜利，再加上一系列 UI 改进，让一切感觉更加敏捷和坚固。 🎉

变更流程图

亮点

流程和工作流程 Copilot，已升级 🧩

工作流创作和 Copilot 获得了重大的可用性和可靠性通过：更清晰的步骤标签、“保存并启用”路径、批准后安全的实时测试运行、停止按钮、更好的运行轨道行为、改进的编译/运行时正确性以及整个画布的视觉刷新。还有更强大的存储行为（损坏行处理、事务更新插入）、更好的本地化覆盖范围以及更严格的运行/批准边界，因此您批准的就是运行的。

(#5088、#5089、#5090、#5097、#5099、#5111、#5112、 #5114、#5115、#5120、#5128、#5135、#5148、 #5150、#5153、#5176、#5205、#5212、#5223、 #5227、#5228、#5248、#5264、#5265、#5285、 #5286、#5287、#5289、#5290、#5292、#5293、 #5294、#5296、#5297、#5302、#5303、#5304、 #5366) — 谢谢@graycyrus 和@senamakel！

可扩展的内存和代理配置文件🧠

内存向前迈出了一大步：TinyCortex 整合和工具内存切换继续进行，标识符标准化更加可靠，新的警告有助于防止嵌入预算耗尽时“无声”内存停止。流还获得了更多有意的内存行为（流命名空间+摘要、专用内存节点支持和只读内存助手），而配置文件获得了“爱马仕风格”的家庭，可以整齐地组织每个配置文件的工作空间、内存、技能和 cron 属性。

(#5043、#5101、#5118、#5140、#5175、#5176、 #5205、#5220、#5227、#5237、#5244、#5246、 #5275、#5280、#5282、#5368、#5398、#5402、 #5427) — 谢谢@senamakel、@graycyrus、@YellowSnnowmann、@CodeGhost21 和@mysma-9403！

语音、吉祥物和实时体验🎙️

语音捕获和 TTS 可靠性得到改进（包括更好的样本格式处理、Piper 二进制修复和更清晰的提供程序行为），并且现在默认显示实时语音模式。还有一个重大的新集成：带有核心 RPC、实时会话和本地中继处理程序的 ElevenLabs 语音代理 - 与 UX 改进（如逐句流式传输）相结合，以减少感知延迟。

(#4537、#5216、#5367、#5404、#5407、#5428、 #5441) — 谢谢@mysma-9403 和@YellowSnnowmann！

聊天、对话和日常 UI 润色 💬

聊天和对话用户体验变得更加流畅和坚固：长 URL 现在可以正确换行，修复了渲染循环，模板拒绝更加清晰，并且线程目标页脚不再意外自动滚动。 “人性”体验也在不断发展：吉祥物现在可以实时停靠在聊天中，支持上传的自定义头像，并避免与口型同步相关的 UI 锁定，而且您可以用三个单词命名一个线程。

(#5030、#5210、#5274、#5309、#5369、#5412、 #5419、#5420) — 谢谢@jgentes、@graycyrus 和@YellowSnnowmann！

推理、嵌入、搜索和成本正确性 ⚡

推理和嵌入行为更可预测、更安全：更好的模型路由（包括支持视觉的模型）、更多可操作的错误（和经过编辑的秘密）、改进的本地模型可靠性以及更清晰地处理 BYOK 密钥和预算。搜索通过 Exa 支持（托管 + BYOK）进行扩展，并且归因得到改进，因此使用情况可以正确链接到解析的提供商。

(#4885、#5103、#5117、#5206、#5207、#5215、 #5218、#5219、#5222、#5253、#5254、#5262、 #5363、#5371) — 谢谢@M3gA-Mind、@YellowSnnowmann 和@samrusani！

核心内核化、功能门和性能 🧱

核心继续变得更精简、更模块化：大依赖修剪、内核化工作、DomainGroup 重新调整以及显式编译时功能背后的更多功能。通过批处理、共享配置弧、委派检查点/恢复以及跨代理和技能运行的运行时进程池，性能和编排也得到了改进。

(#5029、#5040、#5052、#5061、#5062、#5068、 #5078、#5079、#5129、#5178、#5202、#5233、 #5240、#5314、#5328、#5332、#5364、#5365、 #5396、#5405) — 谢谢@senamakel、@YellowSnnowmann、@oxoxDev 和@mysma-9403！

代理、批准和编排安全🤖

代理和批准消除了更尖锐的边缘：在清理过程中保留了替换路由，路径清理更安全，可以选择加入“自动批准全部”设置，并且自定义注册表代理现在可以使用其真正的工具运行。编排可靠性也在多个方面得到了改善，包括 cron 正确性、消除无效的托管引导轮询，以及使委派/代理行为大声失败而不是默默地丢弃结果。

(#4786、#4998、#5039、#5042、#5094、#5121、 #5123、#5211、#5306) — 谢谢@graycyrus、@samrusani、@mysma-9403、@oxoxDev、@sanil-23 和@M3gA-Mind！

桌面打包、配置/身份验证弹性和构建健康🛠️

启动和登录流程更具弹性：可以修复和解释不可读的配置，临时存储读取不会重置配置文件，并且会话到期仍然可以分类。桌面打包得到了有针对性的修复（AppImage 路径、用户放松、D-Bus 会话总线），Tauri 窗口行为针对混合 DPI 多显示器设置进行了改进，CI/测试覆盖率/稳定性得到了有意义的升级。

(#4716、#4772、#5081、#5083、#5171、#5181、 #5189、#5190、#5221、#5241、#5252、#5255、 #5267、#5276、#5277、#5311、#5336、#5337、 #5340、#5341) — 谢谢@YellowSnnowmann、@senamakel、@M3gA-Mind、@samrusani、@myi1 和 @senamakel！

Medulla、SDK 路由和面向后端的管道🌐

OpenHuman 越来越多地被定位为 Medulla 核心，具有为托管编排器服务的新外观/RPC 表面和工作流平面。后端 client 现在通过供应的tiny humans SDK 进行路由，管理的后端流量被切断，并且多个 Medulla/MCP 目录和 URL 解析修复有助于保持端到端的一致性。

(#5105、#5229、#5232、#5233、#5234、#5238、 #5245、#5260、#5266、#5361) — 谢谢@senamakel 和@graycyrus！

小地方和特工世界的改进🗺️

Tiny Place 和代理世界的功能不断成熟，包括目录搜索+分页、账本过滤器（带有可复制的 tx-ids）、更好的处理传输线路，以及将 Tiny Place World 作为具有中继接缝的本地 sim 的更清晰的框架/文档。现在，某些身份/源媒体行为在适当的情况下明确仅限于网络。

(#4998、#5192、#5193、#5271、#5278、#5295) — 谢谢@CodeGhost21 和 @M3gA-Mind！

开发工具、工作台线束和文档 📚

通过新的基准测试和分析环境、日志优先的选项卡式 TUI 以及更广泛的 CI 验证，开发人员体验得到了改善。文档还得到了有意义的更新：CITATION 元数据、安装修复 (macOS Homebrew cask)、为 Windows 桌面设置提供指导以及更新了 Exa 的搜索文档。

(#5060、#5107、#5131、#5142、#5145、#5152、 #5177、#5215) — 谢谢@YellowSnnowmann、@senamakel、@mwakidenis、@NgoQuocViet2001 和@M3gA-Mind！

UI 基础、清理和生活质量 ✨

这里有很多深思熟虑的清理和 UI 基础工作：可重用的 React 基础、删除未使用/孤立的模块和文件，以及多次精简核心并适当重新定位桌面功能。您还会看到一些小而令人愉快的细节，例如可忽略的应用内 GitHub 明星 CTA 和更安全的主题/渐变拆卸行为。 (#5095、#5102、#5110、#5113、#5124、#5125、 #5130、#5141、#5143、#5185、#5186、#5188、 #5206、#5273、#5279、#5310、#5343) — 谢谢@graycyrus、@senamakel、@sanil-23、 @M3gA-Mind 和@YellowSnnowmann！
