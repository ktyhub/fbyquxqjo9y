openhuman v0.63.0

openhuman v0.63.0

这个项目是干啥的：一个开源桌面AI助手，自动把邮箱、Notion等上百种服务数据拉到本地攒成长期记忆，还会调度智能体，给注重隐私、想让AI懂自己的个人用户用。

可靠性和控制升级

此版本包含更强大的工作流程、更流畅的聊天和 Agent World 体验，以及大量的底层强化，以保持一切快速可靠。 🎉

变更架构图

亮点

您可以使用的工作流程 trust 🧩

工作流程副驾驶和画布获得了重大的可靠性通过：建议一致地呈现（即使对于较大的图形），每个副驾驶现在都以真正的终端结果结束（不再有无声的尾随），接受现在自动保存，并且运行 UI 保持准确和实时更新。通过修复更新实时装备、更好的断路、批准状态可见性以及对 Composio 工具调用更强的层/批准执行，安全性和正确性也得到了改善。 (#4881、#4886、#4887、#4888、#4889、#4890、#4891、 #4893、#4904、#4911、#4932、#4933、#4941、 #4942、#4943、#4945、#4955、#4956、#4999、 #5000、#5007、#5011、#5012、#5013) — 谢谢@graycyrus 和@senamakel！

聊天感觉更快捷且更可控💬

聊天通过停止按钮加上 ESC 中断和重新编辑，以及更强大的保护来防止“水合”快照擦除新的流或工具时间线，从而在用户体验上取得了巨大的胜利。编排也变得更加透明：异步子代理故障和“等待用户”结果现在可以在聊天中正确显示，并且委托现在默认为异步，具有持久、可恢复的会话和持久的工作流建议。 (#4898、#4903、#4908、#5074) — 谢谢@M3gA-Mind、@graycyrus 和@senamakel！

记忆和成绩单升级🧠

内存摄取和回忆变得更加清晰和安全：OpenHuman 可以摄取 Codex 和 Claude 编码会话，Composio 同步不再按键更新插入类似秘密的标题，并且回忆避免提取淹没真实事实的同一会话“回显”文档。最重要的是，文字记录现在更加强大：冷启动简历恢复完全保真的上下文和思维，并且文字记录系统正在转向仅附加的派生视图，以原始会话日志作为事实来源。 (#4863、#4953、#4991、#5077、#5086) — 谢谢@senamakel、@M3gA-Mind 和@graycyrus！

特工世界（Tiny Place）感觉充满活力🌍

Tiny Place 现在更具交互性和完整性：DM 和 feed 实时更新，分类帐和 feed 对前 50 项以外的项目进行分页，目录条目最终会打开丰富的个人资料视图。个人资料还可以通过编辑您自己的个人资料（姓名/个人简介/头像）和任意句柄的公共查看器路线来升级。 (#4951、#4952、#4988、#4989、#4990、#4994、 #4996、#4997) — 谢谢@M3gA-Mind！

性能、优化和“它就是有效”修复 ⚡

从可访问性和 UI 优化到启动和运行时性能，此版本减少了整个应用程序的摩擦：改进了深色主题对比度，在应用程序不可见时暂停网格渐变渲染，以及启动轮询得到整合和更安静。现在，首次运行设置覆盖仅在实际配置时出现，应用程序内更正了渠道设置指南，定价/结账重定向行为正常，并且设置“清除应用程序数据”重置现在可以正确定位登录用户。 (#4897、#4902、#4905、#4910、#4939、#4954、 #5035、#5036、#5066、#5075、#5085) — 谢谢@M3gA-Mind、@YellowSnnowmann 和@senamakel！

构建灵活性、CI 强化和新表面🛠️

现在，核心更加模块化，并且更容易通过编译时功能门（媒体、web3、流程、技能、MCP、meet）和新的功能门控终端聊天 UI (openhuman tui) 以精简版本交付。桌面运输和 CI 也变得更加严格和安全：语音和 tokenjuice-treesitter 被正确转发到桌面构建中，CI 现在控制功能转发漂移，macOS clippy 拦截器得到解决，“关门”烟道得到修复并运行测试，学习初创订户与通道解耦并覆盖更稳定的测试。还有一个核心重构，将网络聊天管道移出 channels/。 (#4840、#4855、#4912、#4913、#4914、#4915、 #4916、#4917、#4934、#5004、#5020、#5023、 #5025、#5070、#5082、#5084) — 谢谢@oxoxDev、@CodeGhost21、@senamakel 和@M3gA-Mind！

集成、推理和工具改进🔌

集成和本地 AI 变得更加可靠：与 OpenAI 兼容的本地运行时现在可以正确探测 /v1/models，自定义嵌入端点验证错误更加清晰且可操作，并且流式重试现在支持 Retry-After。 Composio 工具的执行更加智能、安全，每个操作工具都在其完整合约上进行门控（减少参数猜测），并且不可同步的工具包不再自动注册为内存源。还有一个新的 generate_document 工具，可以发出真正的 .docx，以及用于下游托管/计费的最后一轮使用总数的公共访问器。 (#4899、#4909、#4940、#4993、#4995、#5064、 #5067) — 谢谢@M3gA-Mind 和@senamakel！

帐户、分享和导航乐趣🔗

现在，您可以为 X 和 LinkedIn 生成一键“看看我的代理做了什么”共享卡，X/Twitter“继续使用 Google”弹出窗口保留在应用程序中，奖励最终可以通过云门控侧边栏条目发现，并且 Codex 身份验证按钮已正确本地化。另外：主动的“代理任务洞察”固定装置和生命周期重置得到加强，以保持用户界面的一致性。 (#4892、#4944、#4949、#4992、#5010、#5015、 #5065) — 谢谢@YellowSnnowmann、@graycyrus 和@M3gA-Mind！

安全和及时的纪律改变🧯

桌面自动化安全控制出现了混乱：引入了紧急停止功能，后来根据产品方向完全删除了该功能。同时，本地 LLM 提供商的代理行为得到了改进，具有提供者感知的上下文/委托护栏、更强大的结构化输出实施、针对小型模型更具弹性的工具调用解析，并且 AGENTS.md 指令现在加载到系统提示符中，并进行后续安全强化，以防止符号链接/路径逃逸，并在 AGENTS.md 存在时编辑调试日志。 (#4600、#4900、#4935、#4938、#5073、#5087、 #5096) — 谢谢@CodeGhost21、@M3gA-Mind、@sanil-23、@yh928 和@senamakel！

其他亮点🔗

一些更有针对性的贡献使这个版本更加完善，其中有针对性的修复和改进值得一提。 (#4872、#4877、#4906、#5008) — 谢谢@senamakel、@graycyrus 和@M3gA-Mind！
