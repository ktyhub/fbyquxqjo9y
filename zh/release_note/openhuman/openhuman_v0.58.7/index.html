openhuman v0.58.7

修订 发布时间2026年6月30日 来源tinyhumansai/openhuman 英文原文

v0.58.0–v0.58.7 具有更清晰的会议体验、更快+更可靠的连接（技能/MCP）以及跨座席、内存和提供商的一波稳定性升级。 🚀

亮点

会议，端到端的打磨🎥

会议进行了全面重新设计，包括平台选择器、清晰的历史主从布局和更智能的默认设置，以及一系列质量修复，使会议感觉更“活跃”且不易出错。您将看到更好的 UI 反馈（包括“正在离开…”状态）、会议结束时自动刷新最近通话以及改进的后端容量消息处理。 现在，可以为活动会议机器人正确转发唤醒短语，会议显示名称可以从您连接的帐户自动填充，并且自动摘要策略得到遵守 - 为“询问”流程提供了新的手动摘要 RPC。
(#4308、#4348、#4347、#4221、#4231、#4297、#4353) — 谢谢@graycyrus 和@YOMXXX！

连接：MCP 和感觉快速（并保持快速）的技能🔌

MCP 取得了重大飞跃：MCP 服务器页面现已“完整”，包含精心策划的目录、生命周期改进和 E2E 覆盖范围。在幕后，MCP 工具调用在回复帧到达后立即返回（巨大的延迟胜利），stdio 服务器使用用户的真实 shell PATH 生成（hello npx/uvx），并且模式迁移现在是并发安全的。 身份验证和安装用户体验也得到了全面改进：更清晰的 MCP 401 解释（具有更安全的消息传递）、更好的“已安装/正在安装”卡状态以及激活持久性、注册表缓存 + 分页和延迟检测等技能改进。
(#4300、#4220、#4295、#4219、#4321、#4224、 #4288、#4120、#4182、#4188、#4238) — 谢谢@YellowSnnowmann、@M3gA-Mind、@oxoxDev 和@YOMXXX！

聊天体验：附件、视觉效果和更流畅的长回合💬

Chat 现在拥有一流的图像、视频和文档附件按钮，并支持拖放和粘贴。代码块在 Markdown 表面上获得了语法突出显示，并且作曲家/页脚布局现在动态保留空间，因此排队的后续内容（和其他扩展页脚内容）不再与对话重叠。 在可靠性方面，由于心跳进度信号，长推理回合在过去的 2 分钟静默超时后仍保持活力。
(#4292、#4335、#4334、#4282) — 谢谢@oxoxDev 和@graycyrus！

代理和工具运行时：更少的循环，更清晰的停止🧠

代理编排现在更难脱轨：相同的工具调用循环被检测到并停止，卡住的子代理可以显式地“不完整”地返回，并且会话工具调用现在尊重超时而不是永远挂起。当暂停以供用户澄清时，MCP 设置代理不再陷入重新生成循环，并且目标完成指令得到加强以改进自动完成行为。 内置的研究人员代理也通过有界的工具表面和每转输出的上限进行了收紧。 (#4230、#4262、#4303、#4310、#4313、#4314) — 谢谢@sanil-23， @YOMXXX、@oxoxDev、@salarkhannn 和 @senamakel！

内存和智能：更好的连续性和更安全的跨主机行为🗂️

内存得到了有意义的耐用性升级：仅摘要的 wiki 历史现在通过 git 进行跟踪，跨线程搜索通过在克隆重击之前进行排名而更快，并且即使在库指南打开时，Trees UI 也具有更清晰的反馈和稳定的工具栏布局。 对于多设备设置，跨主机库路径现在明确显示为属于特定主机操作系统，因此前端不会尝试在 Linux 上打开 macOS 路径（反之亦然）。重新登录后，大脑记忆图会可靠地重新加载，并且情报页面会在大脑卡内正确滚动。
(#4168、#4311、#4331、#4342、#4330、#4223、 #4332) — 谢谢@senamakel、@mysma-9403、@graycyrus、@oxoxDev 和@M3gA-Mind！

提供者、推理和可观察性强化 🧰

此版本包含一系列广泛的修复，可将嘈杂的“错误”转变为正确分类的预期状态，减少重试风暴，并提高跨提供商和本地环境的弹性。亮点包括：更安全的模型目录解析、更好的嵌入验证（包括自动检测维度和 Gemini 模型 ID 标准化）、改进的配额/限制状态处理以及更强大的 OpenAI 兼容解析。 后端路由也更安全：后端 API 调用不会意外路由到 BYO 云推理主机。对于通道，当深度链接往返失败时，OAuth“正在连接”状态现在可以干净地恢复。对于 cron 作业，缺少 API 键会提前停止（具有更好的用户可见错误显示）。
(#4157、#4160、#4184、#4186、#4185、#4207、 #4209、#4210、#4161、#4189、#4187、#4208、 #4286、#4306、#4166、#4169) — 谢谢@oxoxDev 和@M3gA-Mind！

Tiny Place：身份+交易修复，Linux 渲染更流畅🪙

Tiny Place 进行了一轮强有力的修复：正确的定价等级、USDC SPL 铸币厂接受句柄注册、用于赏金创建的更长 RPC 超时，以及通过应用内确认模式进行破坏性操作的更精致的用户体验。交易也更可用——从正确的结算 RPC 中读取余额，在尝试购买后正确重新启用“购买”，并且用户可以在多个身份之间切换其主要句柄。 在 Linux 上，世界渲染器现在通过 SwiftShader 获取工作的 WebGL 上下文（无需恢复到旧的“禁用 GPU”钝工具）。
(#4215、#4211、#4212、#4214、#4218、#4217、 #4216、#4213) — 谢谢@M3gA-Mind！

语音、人类、设备和桌面可靠性🎙️

macOS 上的语音更加强大：进程内 Whisper STT 可以在不依赖外部二进制文件的情况下工作，并且安装/测试 UI 的行为更加可预测。人性化 UI 还得到了实用的修复：麦克风设备选择器保留在视口内，而不是 clipping 离开屏幕。 桌面可靠性改进包括针对恶劣环境的 CEF GPU 禁用启动覆盖、Debian 安装首选 .deb 软件包（具有适当的运行时依赖）以及现在使用正确的 Socket.IO ACK 流进行设备配对。
(#3915、#4343、#4309、#4263、#4355) — 谢谢@YellowSnnowmann、@graycyrus、@Sam 和@YOMXXX！

新的创意工具、吉祥物和模型路由 ✨

这是一个全新的媒体生成领域，其中包含图像/视频代理和 GMI 媒体工具，可将输出下载到稳定的本地路径中。吉祥物现在可以从 GitHub 支持的清单加载，从而更容易随着时间的推移扩展和发展人类体验。在路由方面，新的 burst-v1 层已注册并用于适当的低上下文工作人员，包括 SuperContext scout 和其他工具驱动代理。 通过记录已处理通道事件的提供者/模型元数据，还提高了通道回复的可审核性。
(#4244、#4312、#4260、#4315、#3682) — 谢谢@senamakel、@senamakel-droid 和@ron-liu！

整个堆栈中较小（但强大）的修复🛠️

一系列尖锐的修复涉及代币会计、学习、安全、人员、工件和 CI 人体工程学。 TokenJuice 避免了 UTF-8 字符边界恐慌，并正确地将压缩节省归因于每轮模型；由于子代理代币的存在，使用量不再超过 100%；学习稳定性使用正确的方面半衰期；聊天文件在冷启动时从工件分类帐中吸收；并且人员存储在核心启动时正确播种。 安全强化还收紧了多个 untrusted 输入接收器，并且通过提高 RUST_MIN_STACK 以避免 llvm-cov 堆栈溢出来稳定 CI 覆盖运行。
(#4170、#4229、#4327、#4328、#4232、#4345、 #4158、#4346) — 谢谢@mysma-9403、@rainbowpuffpuff、@oxoxDev、@Sam、@obchain 和 @graycyrus！

文档更新📚

Docs 进行了实质性的 GitBook/README 修改和一系列正确性后续措施，以收紧术语、范围和 RPC 命名。
(#4225、#4243) — 谢谢@senamakel！

其他亮点🔗

一些更有针对性的贡献使这个版本更加完善，其中有针对性的修复和改进值得一提。 (#4140、#4163、#4183、#4287、#4293、#4296、 #4318) — 谢谢@senamakel-droid、@oxoxDev、@M3gA-Mind、@YellowSnnowmann 和@YOMXXX！
