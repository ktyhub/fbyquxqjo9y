claude-mem v15.7.0

小版本 发布时间2026年10月30日 来源thedotmack/claude-mem 英文原文

claude-mem v15.7.0

变更流程图

亮点

  • My Work 刷新不再泄漏到你的 Codex 账户 — (#5190，修复 #5189) 被拒绝的答案（最常见是超过 1,200 字的审查）现在终止于产生它的 agent 的那次刷新，下一次计划运行用既有失败退避重试同一 agent；只有真正不可用的 agent（未登录、崩溃）才交接。这很重要，因为旧的交接会在 owner 的 ChatGPT 账户上触发隐藏的 codex exec --ephemeral 运行，即使设置了 CLAUDE_MEM_PROVIDER=claude——报告中 4 天内约 230 次。如果你安装了 Codex，单凭这一点就值得升级；真正死掉的 agent 的交接仍保留，因此不会有东西坏掉。

  • 记录器默认模型变化，自动迁移 — (#5195) 默认值从固定的 Haiku 4.5 ID 改为 Claude Code 的 haiku 别名，后者始终解析为最新的 Haiku。带有出厂固定 ID 的已保存设置会在升级时迁移；你自己输入的模型保持不变，仓库的 CLAUDE.md 现在也写明”绝不把带日期的模型 ID 固定为默认值”。多数用户无需手工操作，但如果你想要最新 Haiku 且此前显式保存了固定 ID，可能需要清除该设置。

  • 安全态势显著加固 — (#5148、#5149、#5162/#5161、#5160、#5152、#5151、#5150、#5174、#5173、#5171) 可执行文件发现不再搜索当前目录；安装程序 URL 改为 https，Bun 从 owner 控制的目录运行；worker 拒绝跨源浏览器对会话端点和 POST /api/memory/ingest 的写入；Postgres API key 以加盐 scrypt 哈希存储，每个 sslmode 都被遵循；原子写入使用独占创建的随机临时文件名；脱敏扩展到 GitLab/Hugging Face/npm 令牌、URL 凭证中的密码，以及本地脱敏开启时的入站同步文本。任何暴露 worker 或处理密钥的人都应升级；这是本版升级的最强理由。

  • 感知图片的观察已就位但默认不启用 — (#4341) 第一阶段新增有界的媒体契约和一个惰性的 Sharp 0.35.5 转换器，带大小、像素和截止时间限制，但 CLAUDE_MEM_MEDIA_CAPTURE_ENABLED 和 CLAUDE_MEM_MEDIA_INFERENCE_ENABLED 均默认为 false。除非你选择启用，否则这不是行为变更，可以忽略；只要知道有这个能力，以便日后开启。

  • 可靠性与整理改进，附带一处保留注意 — (#5133 缓解 #5124、#5157、#5139、#5186，外加修复 #5126/#5177/#5191/#5179/#5166/#5154) My Work 的后台重建现在会合并，使打开的页面不再每次数据库提交都重建；Work View 等待数据库启动，处理状态在流中断后重新对账；hook stdin 分帧、EPIPE 处理、CLAUDE_MEM_DATA_DIR 中的 ~ 展开，以及 provider 状态解析 bug 也得到修复。注意：早于 CLAUDE_MEM_LOG_RETENTION_DAYS（默认 30；设 0 表示永久保留）的每日 worker 日志现在会被清理，始终保留今明两天的文件——若依赖更早日志，请在升级前设置该变量。否则对没有 Codex 或外部暴露的单 agent 用户，这是安全、非紧急的升级。

我的工作：刷新保留在您的代理上，并且有一个反馈按钮（#5190）

当 My Work 的自动刷新从 Claude Code 得到 claude-mem 拒绝的答复（通常是超过 1,200 个字符的审核）时，整个刷新将转移到下一个登录的代理。在安装了 Codex 的计算机上，这意味着隐藏的 codex exec —ephemeral 在所有者的 ChatGPT 帐户上运行，即使使用 CLAUDE_MEM_PROVIDER=claude （#5189：四天内运行约 230 次）。

  • 被拒绝的答案现在会结束对给出答案的代理的刷新。下一次计划的运行将再次尝试相同的代理，并使用现有的故障退避。根本无法运行（未登录、崩溃）的代理仍会将运行交给下一个代理。
  • “我的工作”标题中“星号”旁边的“反馈”按钮。它会打开一个简短的“我的工作反馈”问题表单。

记笔记者总是使用最新的俳句 (#5195)

笔记记录者的默认模型现在是 Claude Code 的俳句别名，它始终解析为最新的俳句，而不是固定的俳句 4.5 ID。仍带有附带的固定 ID 的已保存设置会在升级时移至别名。您自己输入的模型将被保留。该存储库的 CLAUDE.md 现在将其声明为策略：永远不要将过时的模型 ID 作为默认值。

我的工作和工人

  • “我的工作”的活动驱动后台重建被合并，因此打开的“我的工作”页面不再在每次数据库提交时重建（#5133，缓解#5124）。
  • 工作视图在构建之前等待数据库完成启动 (#5157)。
  • 观看者的处理状态在流间隙后协调（#5139）。
  • 早于 CLAUDE_MEM_LOG_RETENTION_DAYS（默认 30，0 永久保留）的日常工作日志将被删除。今天和昨天的文件始终保留（#5186）。

项目

  • 父 Git 存储库内的命名环境可以声明显式继承，因此不相关的父内存不再泄漏到其上下文中 (#5022)。
  • Oh My Pi 在模型上下文中保留瞬态项目内存 (#5183)。
  • Claude Duet：捕获和回忆（#5188）。

媒体（默认关闭）

  • 图像感知观察的第一阶段：有界媒体合约和具有大小、像素和截止日期限制的惰性 Sharp 0.35.5 转换器。 CLAUDE_MEM_MEDIA_CAPTURE_ENABLED 和 CLAUDE_MEM_MEDIA_INFERENCE_ENABLED 均默认为 false (#4341)。

安全

  • 可执行发现永远不会在当前目录中查找（#5148）。
  • 安装程序 URL 为 https，Bun 从所有者控制的目录运行 (#5149)。
  • 工作线程拒绝跨源浏览器写入会话端点和 POST /api/memory/ingest (#5162、#5161)。
  • Postgres API 密钥存储为加盐 scrypt 哈希值 (#5160)，并且每个 Postgres sslmode 都受到尊重 (#5152)。
  • 原子写入使用独占创建随机临时名称（#5151）。
  • 私人标签在大写之前被剥离，赫尔墨斯的最后一个回合被门控（#5150）。
  • 密文现在涵盖 GitLab、Hugging Face 和 npm 令牌 (#5174)、URL 凭据中的密码 (#5173) 以及本地密文开启时的入站同步文本 (#5171)。

修复

  • Hook stdin 在完成时被构建，无需等待 EOF (#5126)。
  • 关闭会话的 EPIPE 不再记录为致命的 (#5177)。
  • 解释了 Windows Codex 沙箱拒绝 (#5140)。
  • OpenAI 兼容的提供程序从带有文本代码的 200 错误信封中读取 HTTP 状态 (#5191)。
  • SessionStart 在没有 TeamBrain 的情况下将内存使用块计入其预算 (#5181)。
  • CLAUDE_MEM_DATA_DIR 中的前导 ~ 被扩展（#5179）。
  • 日志尾部仅读取完整行（#5166）。
  • 过滤后的 Chroma 后备范围缩小到 SQLite 行 ID (#5154)。 完整 changelog: https://github.com/thedotmack/claude-mem/compare/v15.6.0…v15.7.0
