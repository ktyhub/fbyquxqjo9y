claude-mem v15.5.0

小版本 发布时间2026年10月29日 来源thedotmack/claude-mem 英文原文

claude-mem v15.5.0

变更流程图

亮点

  • 安全与脱敏加固 — 本版堵上多个真实的密钥泄漏缺口：裸 token、secret、api_key 键下的值（#5130）、Authorization 头对象中的 bearer 令牌（#5129）、结构化载荷中成对的 MYSQL_PWD/dbPassword（#5111），以及 Slack 应用级（xapp-）和刷新（xoxe-）令牌（#5119）现在都会被脱敏。POST /api/logs/clear 也增加了对外部 localhost 来源的防护（#5123），阻断跨域日志删除。如果捕获数据中包含凭证，单凭这一点就值得升级。

  • 观察者批处理（可选启用） — #5117 在可选开关后新增兼容 OpenAI 的请求批处理，默认行为不变，但高量用户可以合并调用，降低 API 成本/延迟。除非你想启用，否则无需操作。

  • My Work / Work 视图变更 — UI 迁移到 Aceternity 组件（#5136），摘要 provider 选择现在显式化（#5104），升级后请检查配置的 provider。可靠性通过刷新失败退避/有限重试（#5108）、在更正中保留被拒绝的答案（#5113）、渲染分组标题和审查摘要（#5114），以及控制部分预算以让构建不超限（#5128）得到提升。注意 #5107 为 My Work viewer 打开和页面切换新增了 PostHog 遥测——如果你在意出站分析，这与你相关。

  • Antigravity / MCP 与平台修复 — MCP 调用现在以真实工具名和稳定 id 记录（#5170），Antigravity 项目上下文能正确解析（#5105），这会改变这些调用的存储标识符。其他修复：Windows 8.3 短路径查找用 %I 而非 %~I（#5099）、Linux 端口回收从 /proc 读取 owner/cmdline/name（#5101）、清理陈旧 last-install-error.json（#5102）、无备份时 backup-setup 不再中止（#5103）、Codex 通过解析出的可执行文件启动（#5112），以及 Pi 会话开始上下文获得 hook 的 API 预算（#5118）。

  • 升级指引 — 未指出破坏性变更或迁移步骤，且这不是空操作/重新打标签：这是一次实质性的特性与修复发布。如果你依赖脱敏/安全、观察者成本节省、Antigravity/MCP 正确性或 My Work/Work 视图修复，请升级；如果不使用这些界面且认可当前的脱敏覆盖和遥测行为，可安全跳过。测试改动仅限于对已提交插件包做语法检查（#5137），对运行无影响。

特点

  • 我的工作/我的焦点： 我的工作和我的焦点中的 Aceternity 组件 (#5136)
  • 观察者： 选择兼容 OpenAI 的批处理 (#5117)
  • **工作视图：**摘要提供者选择现在是明确的（#5104）
  • 遥测： 统计 PostHog 中“我的工作”查看器的打开情况和页面切换情况 (#5107)

修复

工作视图/我的工作

  • 通过部分预算将构建故事控制在上限范围内 (#5128)
  • 停止洪水代理刷新失败并永远重试 (#5108)
  • 在刷新更正中保留被拒绝的答案（#5113）
  • 渲染记录的组标题和评论摘要（#5114）

编辑

  • 编辑裸 token、secret 和 api_key 键下的值 (#5130)
  • 编辑授权标头对象的不记名令牌 (#5129)
  • 在结构化有效负载中配对 MYSQL_PWD 和 dbPassword 密钥 (#5111)
  • 编辑 Slack 应用程序级别 (xapp-) 和刷新 (xoxe-) 令牌 (#5119)

反重力/MCP

  • 使用真实工具名称和稳定 ID 记录 agy MCP 调用 (#5170)
  • 解决反重力项目背景（#5105）
  • 在 Windows 8.3 短路径查找中使用 %I，而不是 %~I (#5099)

工作人员、安装人员和代理

  • 保护 POST /api/logs/clear 免受外国本地主机来源的影响 (#5123)
  • 端口回收从 Linux 上的 /proc 读取端口所有者、命令行和名称 (#5101)
  • 安装或修复完成后清除 last-install-error.json (#5102)
  • 当安装的 claude-mem 没有备份时 backup-setup 停止 (#5103)
  • 通过解析的可执行文件启动 Codex (#5112)
  • Pi：为会话启动上下文请求提供钩子的 API 预算 (#5118)

测试

  • 语法检查提交的插件包，而不是构建的插件包 (#5137) 完整 changelog: https://github.com/thedotmack/claude-mem/compare/v15.4.0…v15.5.0
