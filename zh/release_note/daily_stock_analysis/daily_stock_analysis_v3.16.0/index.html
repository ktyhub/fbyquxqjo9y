daily_stock_analysis v3.16.0

小版本 发布时间2026年5月10日 来源ZhuLinsen/daily_stock_analysis 英文原文

变更架构图

亮点

  • Web 大盘复盘 — Web 首页新增触发入口、任务轮询与完成后报告直出，并提示首次启动时的配置缺口；API、CLI 和 Bot 共用 build_market_review_runtime，减少配置装配差异，同时补充 litellm_model / llm_model_list 与 legacy key 回退说明。
  • 通知路由与诊断 — 支持按 report、alert、system_error 将通知收窄到指定渠道，Web 设置页可一键测试渠道；修正 Model disabled、provider blocked 等错误分类，避免将渠道配置或策略问题误报为网络异常。
  • 分析稳定性与市场修复 — 个股操作建议结合支撑/压力、量能、筹码和主力资金流校准，减少买入/卖出信号剧烈切换，并补强 Agent 决策兜底；同时修复港股历史数据源路由，以及北交所 BJ 前缀与 .BJ 后缀代码校验不一致的问题。
  • 部署与依赖 — Docker 镜像支持非 root 用户运行，提升容器安全性；LiteLLM 依赖约束放宽至后续安全 1.x 修复版本。使用非 root 镜像的部署需确认挂载目录对容器用户可写；更新后应重新构建镜像。
  • 升级判断 — 值得 Web 大盘复盘、通知路由、港股/北交所用户及 Docker 部署用户升级；不依赖这些功能的 CLI/API 用户升级收益较小。未声明显式 Breaking changes 或必须执行的迁移步骤，其余变化主要是设置帮助、文档和催化线索展示稳定性改进。

发布亮点

  • feat: Web 首页新增“大盘复盘”触发入口、任务轮询与完成后报告直出；首次启动配置状态可提示缺口并引导到系统设置。
  • feat: 新增通知路由策略，支持按 report、alert、system_error 将通知收窄到指定渠道；Web 设置页支持通知渠道一键测试。
  • feat: 系统设置页新增配置项帮助入口与多语言帮助文案基础设施，首批覆盖自选股、LLM 主模型、LLM 渠道、飞书 Webhook 与 WebUI 监听地址。
  • improve: 大盘复盘 API、CLI、Bot 共用 build_market_review_runtime 装配路径，补齐 litellm_model / llm_model_list 与 legacy key 回退说明。
  • improve: 个股报告操作建议结合支撑/压力、量能、筹码与主力资金流校准，减少买入/卖出剧烈切换，并补强 Agent 决策兜底。
  • improve: Docker 镜像支持非 root 用户运行，LiteLLM 依赖约束放宽到后续安全 1.x 修复版本。
  • fix: 修正 LLM 渠道测试中 Model disabled、provider blocked 等错误分类，避免被误报为网络异常。
  • fix: 港股日线跳过不支持港股的内置历史数据源；北交所 BJ 前缀与 .BJ 后缀代码校验保持一致。
  • fix: Web 大盘复盘按钮可观测性、Windows fallback 锁进程探测和催化线索展示更稳健。
  • docs: 新增文档中心与配置帮助维护说明，清理 README、完整指南与配置指南中的临时 PR/文档同步说明。
