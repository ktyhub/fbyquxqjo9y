daily_stock_analysis v3.18.0

小版本 发布时间2026年5月21日 来源ZhuLinsen/daily_stock_analysis 英文原文

daily_stock_analysis v3.18.0

变更流程图

亮点

  • 告警中心进入 P6 — #1323/#1334/#1337/#1345/#1379 补齐此前不完整的告警中心：后台评估、Web 规则管理、持久化冷却、通知尝试记录、MA/RSI/MACD/KDJ/CCI 指标规则，以及自选股/持仓/账户联动规则。如果之前因为告警不全而没升，这个版本值得上。
  • 策略选择与更丰富的报告 — #1331/#1332 增加 Web 端策略挑选，以及题材动量、事件驱动、成长质量和预期重估策略；#1369 在静态通知报告中呈现港股/美股基本面、财务摘要、股东回报和相关板块。这改变了分析实际产出，升级后要重新检查报告模板和通知格式。
  • 美股数据与模型兼容性更稳 — Finnhub 和 AlphaVantage 适配器扩展美股日线故障转移链（#1313/#1351，含 pct_chg 排序修复）；LiteLLM 增加严格温度处理、请求内自愈重试和 MiMo/LiteLLM 兜底定价注册（#1317/#1350）。依赖美股行情或非标准模型的值得升；主要消除的是新模型参数不匹配和未知模型计费失败。
  • 指标与新闻语义变化 — 无显式破坏性变更或迁移步骤 — RSI 改用 Wilder EMA/SMMA（#1358）；新闻分层为 direct_company_news / sector_related_news / macro_market_news，并收紧港股数字代码和美股 ticker 匹配（#1359）。文档未声明 API 破坏或必做迁移，但重算的 RSI 和调整的新闻顺序可能改变告警触发与报告排序，按旧 RSI 值调过的规则要回归测试。
  • 桌面打包与正确性修复 — #1320/#1321/#1387 修复更新器产物命名、把内置策略打进 macOS 后端包、安装后不再复用过期 WebUI 缓存；#1385/#1388/#1349/#1364/#1361/#1368 修复已完成记忆队列缺 query_id/created_at、持仓实时估值、告警历史去重、资金流/筹码分布降级和 DatabaseManager 冷启动竞态。桌面端及告警/持仓用户建议升；只用核心日线分析、无告警/策略/美股数据的稳定无头部署可安全跳过。

发布亮点

  • feat: 告警中心从 P2 推进到 P6，补齐后台评估、Web 告警中心、真实通知结果、持久化冷却、MA/RSI/MACD/KDJ/CCI 技术指标规则，以及自选股、持仓标的和持仓账户联动规则。
  • feat: 个股分析支持策略选择，新增热点题材、事件驱动、成长质量和预期重估策略；报告侧补充 HK/US 基本面、财务摘要、股东回报和关联板块展示。
  • feat: 新增 Finnhub / AlphaVantage 美股数据源适配器，扩展美股日线 failover 链，提升美股行情获取韧性。
  • improve: LiteLLM 生成参数增加严格 temperature 模型适配、一次请求内自愈重试和 fallback pricing 注册，降低新模型参数兼容与未知模型计费失败风险。
  • improve: 个股新闻检索新增相关度评分和 direct_company_news / sector_related_news / macro_market_news 分层，优先展示命中股票代码或公司主体的新闻。
  • improve: 大盘复盘展示、RSI 计算口径、每日分析 workflow 排序、通知报告表格和 yfinance 分红/币种口径继续收敛，减少误读和跨市场数据偏差。
  • fix: 修复桌面端发布打包与更新链路问题，包括 strategies 目录缺失、安装包/更新元数据命名不一致，以及新版安装后 WebUI 旧缓存复用。
  • fix: 修复分析状态接口 completed 内存队列缺少 query_id / created_at、AlphaVantage 涨跌幅计算、美股日线路由和持仓快照实时估值等问题。
  • fix: 修复告警触发历史重复、DatabaseManager 冷启动并发初始化竞态、资金流/筹码分布缺失提示重复或过强，以及相关降级路径。
  • docs: 新增小白客户端安装与配置指南，扩展 Web 设置页帮助信息，并补充 LiteLLM、fallback pricing、新闻相关度和筹码/资金流降级的兼容边界说明。

  • 在#1331和#1332中添加@ZhuLinsen的网络股票分析策略选择和新的主题动量、事件驱动、增长质量和预期重估策略
  • 添加香港/美国基本面，并在静态通知报告中公开财务摘要、股东回报和相关董事会，由@zhangtianle 在 #1369 中提供
  • 添加 Finnhub 和 AlphaVantage 美国市场数据适配器，修复 AlphaVantage pct_chg 排序，并通过 #1313 和 #1351 中的 @DragonL641 和 @wqlC 扩展后备链路由美国每日数据
  • 改进了 LiteLLM 参数兼容性、请求本地恢复以及 MiMo / LiteLLM 后备定价注册（@ZhuLinsen 在 #1317 和 #1350 中）
  • 通过直接公司、行业相关和宏观市场层面提高股票新闻相关性排名，包括@ZhuLinsen 在 #1359 中更严格的香港数字代码和美国股票代码匹配

  • 通过标准化更新程序工件、添加无缓存 WebUI 启动行为以及在 macOS 后端包中捆绑内置策略来修复桌面打包和更新可靠性（@ZhuLinsen 在 #1320、#1321 和 #1387 中）
  • 修复@ZhuLinsen 在 #1385 和 #1388 中分析状态已完成的内存路径和 Web 报告相关的板布局
  • 通过 @sjh9714、@massif-01 和 @ZhuLinsen 在 #1349、#1364、#1361 和 #1368 中修复投资组合实时快照估值、警报触发历史重复数据删除、DatabaseManager 冷启动初始化以及资金流/筹码分布退化行为
