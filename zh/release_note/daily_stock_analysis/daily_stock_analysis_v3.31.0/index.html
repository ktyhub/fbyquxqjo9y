daily_stock_analysis v3.31.0

小版本 发布时间2026年8月23日 来源ZhuLinsen/daily_stock_analysis 英文原文

daily_stock_analysis v3.31.0

变更流程图

亮点

  • Agent 执行控制 — 新增分类级和逐工具超时策略（首个命中生效）、不可重试的超时结果、协作式取消、有界并行、缓存同步和运行时热加载。慢/挂死的工具现在失败更可预测，不会重试风暴；自定义工具配置应对照新的超时行为复核。
  • 股票身份与数据韧性 — 跨市场名称候选、确定性的 StockDaily.canonical_id 双写，以及已注册 A 股指数的兜底路由，减少歧义股票匹配，并在数据源失败时改善行情连续性。
  • 新闻/搜索行为（需要操作） — 报告现在披露缺失的新闻证据，Anspire 默认改为全球区域搜索，公共 SearXNG 实例需显式 opt-in。此前依赖自动发现公共 SearXNG 的用户需显式启用/配置；未列出其他破坏性 API 迁移。
  • 调度、告警与诊断 — 重启后恢复持久化的定时任务、暴露无报告的分析失败、识别钉钉 Webhook，并修正大盘复盘摘要和生成器诊断。这显著改善无人值守运行、通知投递和排障准确性。
  • 安全与升级建议 — 桌面更新器依赖升级到 builder-util-runtime 9.7.0，修复 CVE-2026-54673 在 HTTP 重定向中泄漏 credential header 的风险。桌面用户以及依赖定时分析、Agent 工具或新闻兜底的用户应升级；不受影响的可延后。这是实质版本，不是重发 tag 或只改元数据。

v3.31.0

发布亮点

  • 壮举：代理工具调用新增按类别和单工具配置的超时契约，并补齐防重试、协作取消、队列调度、线程安全与热重载一致性。
  • feat: 股票名称解析、StockDaily.canonical_id双写和A股指数多数据源回退路由共同完善股票身份与行情降级关联。
  • 改进：新闻搜索为空时在报告中如实披露证据边界；Anspire 默认覆盖全球区域，公共 SearXNG 实例改为显式启用。
  • 修复：修复服务重启后的定时任务恢复、分析无报告时的失败反馈、钉钉通知识别，以及大盘复盘历史摘要和实际生成耳机诊断。
  • security:桌面端升级builder-util-runtime至9.7.0，修复CVE-2026-54673涉及的HTTP税务头信息泄露风险。
  • 文档：增加 xAI Grok 的 LiteLLM 配置示例、Grok Bot 集成说明与可复用异步分析技能，并更新 AIHubMix 中国大陆直连入口。

发生了什么变化

  • 添加了类别级别和每个工具的代理超时策略，包括首胜解决方案、不可重试的超时结果、协作取消、有限并行执行、缓存同步和运行时重新加载支持，作者：@lmx-2077。
  • 通过跨市场候选名称、确定性 canonical_id 持久性以及注册 A 股指数的专用多源后备路线扩展股票身份处理，作者：@Gach-Coder 和 @elvisw。
  • 通过 @Mach-Chan 和 @yddcy，在报告和本地化界面中明确缺失的新闻证据，将 Anspire 切换为全球区域搜索，并将不可靠的公共 SearXNG 发现更改为选择加入。
  • 恢复服务重启后的持久时间表，明确无报告分析故障，将钉钉Webhooks识别为通知渠道，并更正市场评论摘要和发电机诊断，作者：@ZhuLinsen和@mameikagou。
  • 将桌面更新程序依赖项路径升级至 builder-util-runtime 9.7.0，以解决 CVE-2026-54673（作者：@anupamme）。
  • 添加了 xAI Grok LiteLLM 示例、Grok Bot 集成指南和异步安全技能合约，并更新了用于中国大陆连接的 AIHubMix 推荐链接（作者：@tseliangmin-star 和 @ZhuLinsen）。
  • 稳定了 yfinance 股息 TTM 和单一股票报告文件名固定装置，使后端 CI 不再依赖于挂钟，作者：@xxiaoxiong 和 @ZhuLinsen。
