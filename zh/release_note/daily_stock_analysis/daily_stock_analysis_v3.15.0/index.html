daily_stock_analysis v3.15.0

小版本 发布时间2026年5月5日 来源ZhuLinsen/daily_stock_analysis 英文原文

变更架构图

亮点

  • LLM 提供方扩展 — v3.15.0 新增 ANSPIRE_API_KEYS 网关（OpenAI 兼容），并在渠道编辑器补充 MiniMax、火山方舟（Volcengine）、OpenAI、Claude 的预设/模板，编辑器里展示能力标签和官方来源链接。多提供方或想经 Anspire 路由的用户省去手工试错；单一可用提供方的用户只是增量能力、无变化。MiniMax 预设也修正为官方 URL。
  • 决策与告警升级 — 大盘复盘新增红黄绿红绿灯结论便于一眼判断；EventMonitor 新增 price_change_percent 阈值条件用于涨跌幅告警。依赖每日复盘或涨跌通知的值得升；否则是新的可选能力，不改变既有行为。
  • 通知与诊断管道 — 自定义 Webhook 可通过 CUSTOM_WEBHOOK_BODY_TEMPLATE 发送 JSON body，适配 AstrBot/NapCat 类机器人；Bot /status 把 LLM 模型、Agent 模型、渠道模式和通知状态汇总到一个视图；Web LLM 诊断增加更细的错误分类和显式的 JSON/tools/vision/stream 冒烟触发。主要对接第三方机器人或排查提供方问题的用户有价值。
  • 正确性修复（安静但重要） — Agent 弱兜底现在保留本地趋势分析，不再让默认 50 分覆盖仪表盘；持仓快照缺价不再污染市值和未实现盈亏；LLM 运行时清理限定为托管提供方，cohere/*/google/*/xai/* 直连路径刻意保留 legacy。这些修的是真实数据质量 bug 和一处有意的行为收窄——用这些直连提供方的要注意最后一条，尽管没有声明破坏性变更或迁移步骤。
  • 升级结论 — 相对 v3.14.2 是实打实的功能+修复版本，不是重发 tag 或只改元数据；changelog 未声明破坏性变更或必做迁移（文档更新 #1180 是补充）。多提供方用户、Anspire/AstrBot/NapCat 集成方，以及踩到评分或快照 bug 的用户应升级；单一稳定提供方可放心跳过。

发布亮点

  • feat: 新增 ANSPIRE_API_KEYS 接入 Anspire OpenAI-compatible 网关，渠道编辑器补充服务商预设与模板（MiniMax、火山方舟、OpenAI、Claude 等）。
  • feat: 大盘复盘新增红绿灯结论（green/yellow/red）；EventMonitor 支持 price_change_percent 涨跌幅阈值告警。
  • feat: 自定义 Webhook 支持 CUSTOM_WEBHOOK_BODY_TEMPLATE JSON body 模板，适配 AstrBot、NapCat。
  • feat: Web LLM 检测补充细分错误分类，支持显式触发 JSON/tools/vision/stream smoke。
  • improve: LLM 渠道编辑器展示 provider 能力标签、官方来源；补齐 GitHub Actions 显式映射。
  • improve: Bot /status 统一展示 LLM、Agent 模型、渠道模式与通知渠道状态。
  • fix: Agent weak 兜底优先保留本地趋势分析，避免首页评分被默认值 50 覆盖。
  • fix: LLM runtime 清理仅对托管 provider 生效；cohere/*/google/*/xai/* 直连路径按 legacy 保留。
  • fix: 持仓快照缺价时不再污染市值与未实现盈亏；MiniMax 预设更新为官方 URL。
  • docs: 完善 LLM provider 配置文档，补充 Actions 变量对照和错误排障（#1180）。

发生了什么变化

  • 壮举：为 Anspire OpenAI 兼容网关添加 ANSPIRE_API_KEYS；添加提供商预设和模板（MiniMax、Volcengine、OpenAI、Claude 等）。
  • 壮举：市场回顾添加了红绿灯摘要（绿色/黄色/红色）； EventMonitor 支持 price_change_percent 阈值警报。
  • 壮举：自定义 Webhook 支持 AstrBot、NapCat 等的 CUSTOM_WEBHOOK_BODY_TEMPLATE JSON 主体模板。
  • 壮举：Web LLM 诊断添加了详细的错误分类和明确的 JSON/tools/vision/stream Smoke 触发器。
  • 改进：LLM渠道编辑器显示提供商能力标签和官方来源；填写 GitHub Actions env 映射。
  • 改进：Bot /status统一显示LLM模型、Agent模型、通道模式和通知通道状态。
  • 修复：代理弱回退保留本地趋势分析结果，防止默认分数 50 覆盖仪表板。
  • 修复：LLM运行时清理仅适用于托管提供商； cohere/*/google/*/xai/* 直接路径保留为旧版。
  • 修复：投资组合快照不再因缺失价格而污染市场价值； MiniMax 预设已更新至官方 URL。
  • 文档：使用 Actions 变量参考和错误故障排除改进 LLM 提供商配置文档 (#1180)。 完整 Changelog：https://github.com/ZhuLinsen/daily_stock_analysis/compare/v3.14.2…v3.15.0
