daily_stock_analysis v3.25.0

小版本 发布时间2026年7月3日 来源ZhuLinsen/daily_stock_analysis 英文原文

变更流程图

亮点

  • 本地生成后端 — 新增 claude_code_cli 和 opencode_cli 作为仅生成的本地 CLI 后端，并带后端状态诊断、预览/冒烟测试 API 和 Web 状态面板。一直被托管生成绑定的用户有了本地路径——但注意这些后端只负责生成，不能替代完整后端能力。
  • 台湾市场覆盖 — 台湾报告现在完整整合三大法人数据：报告渲染、LLM 提示词上下文、新台币币种标注和收盘集合竞价识别，背后有抓取熔断器、日期守卫和缓存击穿保护。台湾用户报告质量明显提升，数据抓取也更稳。
  • 通知与语言 — 新增钉钉群机器人通知（长消息分片）、韩文报告输出（覆盖提示词、报告、通知文案和 Web 文案），以及 AI 建议决策风格重评估预览。用钉钉或需要韩文报告的团队该升；否则这部分可跳过。
  • Agent 流式 API — 对调用方可能是破坏性变更 — /chat/stream 统一了进度事件，引入阶段开始/完成生命周期、流水线超时和预算跳过语义。如果你基于这个端点写客户端，要做好改事件处理的准备：这是本次最可能需要迁移的地方，尽管发布说明没给出显式迁移步骤。
  • 可靠性与升级建议 — 大范围加固：AlphaSift 调用方超时、东方财富直连限流/抖动、策略目录元数据与防御性策略，并修复桌面 WebUI 主机/端口绑定、macOS Homebrew CLI PATH 诊断、Discord 长报告分片、yfinance 分红解析、A 股回测代码规范化、市场阶段检测和大盘复盘格式。未标注显式破坏性变更或迁移。台湾/CLI/钉钉/韩文用户以及踩到上述稳定性问题的建议升级；若 v3.24.1 已稳定且新能力都用不上，可安全跳过。

v3.25.0

发布亮点

  • feat: 新增 claude_code_cli 和 opencode_cli generation-only 本地 CLI backend，并补齐生成后端状态诊断、预览、冒烟测试 API 和 Web 状态面板。
  • feat: 台股报告完整接入三大法人资料，覆盖报告渲染、LLM prompt、TWD 币别标示、收盘集合竞价识别和 fetcher 韧性加固。
  • feat: 新增钉钉群机器人通知、韩语报告输出和 AI 建议决策风格重评估预览。
  • feat: Agent /chat/stream 标准化 progress event，新增阶段开始/完成、pipeline timeout 和预算跳过语义。
  • improve: AlphaSift 接入 caller-side timeout、东财直连限速/抖动、策略目录元数据和防守策略，降低外部数据源卡住时触发 Web 等待超时的概率。
  • fix: 修复桌面端 WebUI host/port 绑定、macOS Homebrew CLI PATH 诊断、Discord 长报告分片、yfinance 分红解析、A 股回测代码归一化、市场阶段识别和大盘复盘格式化等稳定性问题。

发生了什么变化

  • 添加了 Claude Code 和 OpenCode 本地生成后端、后端状态诊断、预览/冒烟测试 APIs 以及 @massif-01 和 @ZhuLinsen 的 Web 状态面板。
  • 通过 @WenyuChiou 和 @ZhuLinsen 扩展了台湾股票报告，包括机构流程渲染、LLM 提示上下文、TWD 货币标签、收盘竞价检测、获取器断路器、日期防护和缓存踩踏保护。
  • 添加了@Shlok1729 对长消息分块的钉钉通知支持。
  • 通过 @devpark435 添加了跨提示、报告、通知标签和 Web 报告副本的韩语报告语言支持。
  • @sh1water 针对阶段生命周期、管道超时和预算跳过语义的标准化代理 /chat/stream 进度事件。
  • 由 @ZhuLinsen、@WenyuChiou 和 @massif-01 提供的强化桌面启动、AlphaSift 超时处理、Discord 长报告交付、yfinance 股息解析、回测 A 股代码规范化、市场评论格式化、股票栏徽章和调度程序立即运行行为。
