open-design v0.25.0

小版本 发布时间2026年10月15日 来源nexu-io/open-design 英文原文

open-design open-design-v0.25.0

🌟 代号：OpenDesign Motion

Claude Motion 的开源替代方案 🎞️ 53 PRs · 16 contributors · 21 days — 用代码将想法转化为视频。 从五个捆绑的动作示例开始，创建可编辑的动画，并将您的作品导出为 MP4。此版本还使跨设备的编辑、预览和持续工作更加顺畅。

🔥 亮点

  • 🎞️ 介绍 OpenDesign Motion。 在家庭或社区上打开 Motion Design，从五个捆绑示例中进行选择，并使用 @ 选择器中的动作技能。索要视频以获得可编辑的源文件和 MP4；交互式动画仍然是可运行的 HTML。当您离开活动预览时，声音会停止。 (#8619)
  • 🧭 从设计计划转向制定计划。 设计任务可以从普通的书面计划继续，而不会因缺少内部响应标记而失败。仅对计划的请求仍然是计划，当模型提供后续建议时，已完成的工作可以再次提供后续建议。 （＃8356，＃8770）谢谢@itscheems。
  • 🔄 您决定何时另一台设备的更改取代本地工作。 在应用云更新之前查看它。选择“现在不”和 24 小时提醒选项会静音该设备上该项目的提醒；当您准备好时，更新仍然可用。 (#8683) 谢谢@PerishCode。
  • 🖼️ 新文件出现，预览保留在原来的位置。 已完成的任务会刷新文件列表，以便可以打开新创建的图像和其他文件。手动预览选择仍然受到尊重，恢复项目会保留已保存的设计文件选择。 （#8744，#8745）
  • 💳 信用不足警告可确保您的汇票安全。 已因资金不足而持有的家庭汇款在继续之前等待确认的可用余额或计划津贴。失败的检查会让你留在家里；关闭对话框会保留草稿。当可用的编码计划配额可用时，零钱包余额仍然允许工作。 （＃8688，＃8775）
  • 🤖 当模型更改或对话增加时继续工作。 如果 AMR 模型被删除，应用程序可以使用目录默认值并告诉您哪个模型被替换。长时间对话限制重复的图像和 PDF 附件，以减少请求大小失败；需要时可以再次阅读较旧的附件。 （#8602，#8767）谢谢@Siri-Ray。
  • 🔑 登录并开始使用 OpenDesign Hosted。 欢迎流程在登录后打开 Hosted，而本地 AI 和 API 密钥仍然可用。登录控件显示进度、取消以及在需要时重新打开浏览器页面的方法。 (#8567)
  • 🔎 有用的诊断，减少重复上传。 对同一 API 故障的重复实例进行分组，AMR 故障证据包括受影响的运行记录。 Windows 日志轮换保留了用户的同意边界。 （#8461、#8488、#8487）谢谢@Siri-Ray。

📥 下载： 开放设计0.25.0。

✨ 已添加

🎨 动作和模板

  • 从五个动作示例开始： Motion Future、产品促销、Showreel、UI Morph 和视觉课程。他们捆绑的脚本、字体、音频和预览支持示例中的编辑。视频导出检查生成的 MP4 是否可以播放；导出失败会使可编辑源保持可用。 (#8619)
  • Aster Atelier 建筑工作室模板。 从可编辑的本地示例启动一个网站，其中包含章节导航、服务和常见问题解答部分以及联系表单演示。包含英文和中文示例提示；该演示不会发送真正的联系请求。 (#8314)

🔁 已更改

###💬日常工作

  • 发送立即清除作曲家。如果发送无法继续，则其文本、附件、上下文和引用将返回，除非您已经开始新的草稿。 (#8380) 谢谢@Siri-Ray。
  • 导出、登录、更新、存储、信用和停止任务消息以简单语言解释了所有 19 个受支持区域设置中发生的情况。导出错误不再显示原始技术故障文本。 (#8620) 谢谢@lefarcen。
  • 将鼠标悬停在缩短的模型名称上，可在“设置”和作曲家模型选择器中完整阅读它。被计划锁定的型号保留其升级说明。 (#8409) 谢谢@PratikRai0101。

🐛 已修复

💬 对话和设计任务

  • 当较旧的对话历史记录完成加载时，Live Thinking 文本仍然可见。 (#8167)
  • 迟到的存储卡保留在生成它们的对话中，包括在切换对话或重新加载之后。 （#8065）
  • 回答澄清会在下一个任务开始时保留先前完成的任务的状态、持续时间和折叠的步骤。 (#8401) 谢谢@Siri-Ray。
  • 继续旧的设计对话保留原始请求、附件和相关历史记录。纯文本答案可以正常完成，未完成的任务仍然可以继续。 (#8356)
  • 自动设计生产后可以再次出现后续建议。选择一个建议会填充作曲家供您发送。 (#8770) 谢谢@itscheems。

🗂️ 项目、文件和预览

  • 空项目列表完成加载；读取失败会显示错误并重试，而不是永远旋转或假装没有项目。切换工作区会停止对前一个列表的后台状态请求。 （＃8443，＃8442）谢谢@Siri-Ray。
  • 一批上传中具有相同名称的文件按提交顺序接收后缀，使每个返回的文件名与其内容相匹配。现有文件将被保留。 (#8742)
  • 任务完成后会发现新生成的文件，并且当服务器尚未保存较新的选择时，保存的本地选项卡选择在恢复后仍然有效。 （#8744，#8745）
  • 通过在短窗口中滚动，仍然可以访问主页的标题和完整的作曲家。 (#8649) 谢谢@itscheems。
  • 切换到从右到左的语言后，缩短的工作区名称可以正确显示隐藏的文本。 (#8692) 谢谢@Siri-Ray。
  • 缓存的应用内广告活动可以在临时离线期间继续存在，并在其授权仍然有效时重新启动。撤回或过期的营销活动不会从旧缓存中重新出现。 (#8676)

🧠 模特和当地经纪人

  • 同时登录凭据刷新可以通过现有的安全重试路径恢复，而不是立即使任务失败。 (#8160) 谢谢@Marinski。
  • 反重力可以在 Windows 上启动长提示任务，并在聊天中显示流式回复和工具步骤。 (#8594) 谢谢@lefarcen。
  • Windows 上已完成的 AMR 答案不再仅仅因为应用程序关闭已完成的代理进程而被标记为失败。 (#8514) 谢谢@Siri-Ray。
  • 早于 Windows 10 1809 的 Windows 版本导致的 AMR 故障说明 Windows 需要更新，而不是提供无效的重试。 (#8629) 谢谢@Siri-Ray。
  • OpenCode技能可以读取自己的支持文件，而无需不必要的权限提示。 (#8178) 谢谢@aron-intframe。
  • 保存应用程序设置后，Pi 保留其配置的替代设置目录。 (#8119) 谢谢@L4XB。
  • 捆绑的 Vela CLI 已更新为 0.1.6，为与许多图像或 PDF 的对话启用历史记录附件限制。 (#8767) 谢谢@Siri-Ray。

🖥️ 桌面可靠性

  • 长 macOS 临时目录路径不再阻止本地应用程序服务启动。 (#8002) 谢谢@abhi-zit77。
  • 当操作系统耗尽网络缓冲区时，桌面应用程序将停止重复的内部请求重试，而不是延长挂起时间。 (#8283) 谢谢@chenlei-github。
