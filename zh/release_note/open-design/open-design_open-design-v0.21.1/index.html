open-design v0.21.1

修订 发布时间2026年8月31日 来源nexu-io/open-design 英文原文

open-design open-design-v0.21.1

Nix 发行说明（2026 年 8 月 31 日添加）： 存储库拥有的 flake 已通过 PR #7644 提交 49cc51058fd76ec825fcd6a9f684f8d3a138fca3 中的 main 上退役。如果您仍然需要最后一个存储库传送的薄片，请固定到标记 open-design-v0.21.1（提交 fbd4d48ebe21b20f4a2faaad0ad5e53aaeb1dc4b）或较早的标记，而不是针对 main 进行更新。

🌟 代号：社区优先：无需登录

🔓 开放设计一直扎根于社区。现在我们回到 该承诺：无需帐户。 直接选择本地 CLI 或 BYOK 回家并开始创作。开放设计云仍然可以在您需要时随时使用 它。

🔥 亮点

  • 🔓 无需登录即可开始。 开放式设计不再需要云 帐户，然后才能开始创建。 (#7381) 谢谢@Siri-Ray。
  • 🧰 使用您自己的家庭工具。 选择现有的本地 CLI 或连接 通过 BYOK 您的首选模型提供商。 (#7381) 谢谢@Siri-Ray。
  • 🧪 引入开放设计实验室。 在设置中启用开放设计框架 尝试新一代策略并创造更精美的结果。更多 实验正在进行中。 （＃7445，＃7514）谢谢@lefarcen。

✨ 已添加

创作与实验

  • 🧪 设计框架现在只需一个开关即可。 开放设计实验室在 设置，您可以在其中选择最新一代策略，而无需 安装另一个版本或到达终端。开关解释了什么 它涵盖并在重新启动时保存并告诉您何时另一个策略拥有该 选择。 (#7445)
  • 🖼️ 真实的主题获得真实的图像。 当原型命名一个人时， 产品、艺术品、事件或地点，开放设计现在搜索并使用 实际的所指对象，而不是发明一个相似的对象。图像保持自然 比例和全画幅而不是被迫变成剩菜 占位符作物。 (#7436)
  • 📱 OD Next 了解移动界面的骨架。 日历、统计数据、 设置行、顶部栏、底部导航、图像和确认对话框 现在收到专门构建的结构，因此生成的手机原型如下 显然，无需将每个模式展平到同一个通用行中。 (#7327)

团队协作

  • 🧭 大型团队工作空间可以为后台追赶设置上限。 选择加入累积预算可以防止背景物质化在没有 离开前台时绑定的项目会立即打开且不受影响。 (#7403) 谢谢@lefarcen。

⚡ 性能和可靠性

  • ⚡ 团队项目从温暖的路径开始。 重复的项目列表和深层链接 读取重用短暂的、工作区安全的缓存；共享、取消共享和工作区 更改立即使其失效。 (#7398) 谢谢@lefarcen。
  • 🚀 首页开始时对屏幕的竞争较少。 重复的目录 读取会折叠起来，隐藏的自动化区域会等待您实际操作 在获取数据之前打开它。 （＃7408，＃7413）谢谢@lefarcen。
  • 🧹 现在停止运行意味着整个运行已经停止。 取消、超时、 失败、重试和应用程序关闭之前清理完整的代理进程树 宣布尝试结束，防止被遗弃的儿童继续 来消耗资源。 (#7432) 谢谢@Siri-Ray。

🐛 已修复

代理、模型和设置

  • ☁️ 云注销不再关闭本地工作的大门。 本地代理和 在注销或云不可用时，BYOK 保持可选状态，并且 注销会保留提供者密钥、基本 URL、模型选择和媒体 默认值存储在此安装中。 （＃7381，＃7437）谢谢@Siri-Ray。
  • 🧭 运行错误现在指向实际可以提供帮助的操作。 不兼容的代理握手要求您更改代理版本而不是 重试；会员并发限制显示其重置指南；和一个 AMR 模型拒绝在一秒钟之前停止，误导性的提示失败可以取代 真正的原因。 （#7303、#7429、#7458）谢谢@lefarcen、@Siri-Ray。
  • 🚦 **真正的上游限制不再隐藏在“空输出”之下。**配额， 速率限制和可用性信号优先于一般的无结果 分类，因此重试行为遵循实际发生的故障。 (#7248) 谢谢@mturac。
  • 💬 您可以看到的澄清表格是您可以回答的澄清表格。 策略任务不再成为渲染问题形式后面的终端，并且 拒绝带有内部状态错误的响应。 (#7509)
  • 🔌 缺少的本地引擎现在会明显失败，而不是返回应用程序 shell 就像数据一样。 登录、代理发现和其他 API 调用表面 当守护进程源不是时，可识别的、可重试的连接失败 配置。 (#7399) 谢谢@lorenzozanee。

Studio、预览和导出

  • 🧩 编写 HTML 的 HTML 不再将其自己的预览分开。 打印 窗口、电子邮件模板、srcdoc 有效负载和存储在脚本或中的标记 属性按照编写的方式继续运行。预览、甲板、PDF 和工件导出 现在在真实文档边界插入开放设计的桥梁而不是 将标签形状的文本误认为是结构。 （＃7421，＃7422）谢谢@lefarcen。
  • 📊 可编辑 PPTX 导出不再在不可见背景下成功。 重试空的 Chromium 捕获；如果正确的分层捕获仍然无法 生产出来后，出口会因为明显的失败而停止，而不是给你一个 透明幻灯片。 (#7337) 谢谢@mrcfps。
  • 🎛️ 小型编辑控件保持在其车道内。 聊天调整大小手柄没有 较长时间窃取悬停、click 或从滚动边缘拖动；斜杠命令 菜单使每一行都可读；并切换到图像立即选择它 而不会使创建选项卡变暗。 （＃7324，＃7368，＃7375）谢谢@Siri-Ray， @lefarcen。

团队、导航和界面

  • 💳 团队平衡遵循您正在查看的团队工作区。 设置和 家庭就活跃的工作空间平衡达成一致，不再退回到 当团队数据不可用时，成员的个人钱包。 (#7384)
  • 🎞️ 私人项目使用它们所属的团队平衡。 Vela 图像和 视频生成现在保留了项目的工作区计费范围，而无需 更改其私人共享状态。 (#7504) 谢谢@alchemistklk。
  • ↩️ 创建设计系统会让您回到起点。 是否 您从对话、选择器、图书馆、主页或侧边栏、返回进入 恢复原始上下文，而不是将您带到通用页面。 (#7367) 谢谢@lefarcen。
  • 🌐 插件和恢复副本使用应用程序的语言。 技能卡 描述遵循选定的区域设置，并带有可预测的英语后备， 缺少的捆绑场景以相同的语言解释了如何重新安装 恢复它。 （＃7369，＃7325）谢谢@lefarcen，@Siri-Ray。
  • 📣 Go Plan 日落通知到达了正确的人手中 语言。 有针对性的消息变体打开专用通知及其副本， 操作和布局遵循所选的开放设计区域设置，而不是下降 回到硬编码的中文。 （＃7430，＃7453，＃7477）谢谢@nettee。
  • 🔗 云授权返回到已安装的应用程序，而不是流浪的 Electron window. 开发运行不再接管系统范围的 opendesign:// 链接处理程序，而打包版本保持正常登录和邀请 切换。注销的用户也不会再看到需要 帐户。 (#7479) 谢谢@lefarcen。
  • ⬆️ 更新操作保持在您期望的位置。 已注销的桌面用户 现在可以在登录时的同一右上角集群中看到可立即安装的更新 用户无需使用家庭编辑器和模型选择器。 (#7482) 谢谢@Siri-Ray。
