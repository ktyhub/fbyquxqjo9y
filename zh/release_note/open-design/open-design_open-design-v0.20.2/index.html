open-design v0.20.2

修订 发布时间2026年8月21日 来源nexu-io/open-design 英文原文

open-design open-design-v0.20.2

⚡ 生产导出现在在一分钟内完成：当字体或图像 你的工作永远不会回来，开放设计不再保留整个管道 十分钟 — 它会停止等待并提供图像或 PDF。 HTML 您已经打开的预览会保持其状态，并且首次运行设置仅允许您 真正连接后继续。除此之外，定价、权利 Go Plan 附带的徽章和升级路径经过了仔细的校准 通过，那么您的计划是什么，您可以从哪里开始，以及 click 将前往何处 带大家老老实实地读一读。

⚡ 性能和可靠性

  • 📤 卡住的导出现在需要不到一分钟而不是十分钟。 当字体或 您作品中的图像永远不会加载，开放设计不再等待它，并且 无论如何，完成图像或 PDF。正常加载的工作仍会导出 全面的品质，真正的失败现在会说出其原因，以便您可以采取行动。 (#7182) 谢谢@lefarcen。
  • 🖥️ 返回打开的 HTML 预览，它仍然在您离开的位置。 不再切换项目、切换文件选项卡和切换预览/代码 触发空白闪光或完全重新加载 - 滚动位置、实时文档和 您的编辑会保留下来，并且文本更改会在您保存时显示。 (#7156) 谢谢@lefarcen。
  • ✅ 生成文件的运行不再被报告为不生成任何内容。 当浏览器没有及时完成文件同步时，Open Design trusts什么 守护进程已确认已交付。真正没有产生什么结果的运行 显示原始错误。 (#5750) 谢谢@ferrarifankid04。
  • 🧩 项目预览中的交互式脚本不会受到 URL 重写的影响。 内联 脚本原封不动地交付，而 CSS 和其他资产保持不变 工作区范围内，因此脚本驱动的交互式预览实际上运行。 (#6938) 谢谢@mturac。

🐛 已修复

首次运行设置

  • 🚦 “继续”现在意味着您实际上已准备好继续。 选择本地人 首次运行设置期间，CLI 使按钮保持惰性，直到检测到 CLI。 使用BYOK，填写密钥、基本URL和模型运行真实连接测试 在 click 上 — 失败或速率限制会让您停留在可操作的页面上 错误，只有测试通过后安装才完成。 (#7164) 谢谢@alchemistklk。

定价、计划和升级

  • 🌐 您输入定价所用的语言就是您停留时使用的语言。 应用程序移交的区域设置现在在页面绘制之前应用，而不是 首先闪烁错误的。仍然没有明确区域设置的直接访问 按照您的浏览器和保存的首选项进行操作。 (#7197) 谢谢@Siri-Ray。
  • ↩️ 结帐后您将返回到原来的 Cloud Console。 定价 测试、功能验证和本地环境的切换又回到了 他们自己的切入点，而不是登陆生产环境。无效目标 显示局部错误并禁用结帐而不是默默地掉落 回来。 (#7219) 谢谢@nettee。
  • ⬆️ 您当前的计划以及您可以从该计划开始的地方，一目了然。 您当前使用的计划被标记为“当前计划”，低于该计划的任何计划都不再有效 clickable，更高级别保留其升级条目。节省金额、型号 顺序、状态栏、推荐口音和每月/每年切换 全部符合批准的设计。 （＃7191，＃7222）谢谢@Siri-Ray。
  • ♾️ “无限制”仅出现在您的计划实际包含的型号上。 去吧， 另外，Pro 和 Max 徽章根据自己的权利而定；团队工作空间 不再继承个人计划的徽章，并且 BYOK 不再声明 平台端无限制使用。余额恰好为零的订户止损 看到他们无法采取行动的余额筹码，而透支、免费计划和团队 仍然存在需要注意的平衡。 （#7190、#7202、#7196） 谢谢@lefarcen，@Siri-Ray。
  • 低平衡对话框的操作按钮恢复一致的视觉效果 层次结构。 (#7138)

界面和导航

  • ⬇️ 更新按钮不再拥挤帐户胶囊。 一旦有新版本 下载完成后，绿色更新按钮将作为其自己的控件出现 头像/余额胶囊的右侧，所以是帐户菜单和更新 行动停留在自己的地方。 (#7237) 谢谢@Siri-Ray。
  • 🔔 消息中心又是普通列表了 已读和未读消息分享 没有过滤选项卡的一个视图；未读的项目带有一个紧凑的点，打开一个 仍然标记为已读该消息。 (#7231) 谢谢@Siri-Ray。
  • 🔗 社区链接位于导航栏的底部。 社交链接已移动 走出账户菜单进入首页导航页脚——中文 界面显示飞书群，其他语言显示Discord，还有X和邮箱 保持不变。 (#7232) 谢谢@alchemistklk。

🌐 网站

  • 主页的第一个屏幕和胶囊标题得到了一轮收紧：a 更清晰的品牌主张、更轻的功能芯片、更克制的 CTA 以及 在 click 上加载的视频演示。已clicked的访客停止下载 再次提示。 （＃7178，＃7186）谢谢@joeylee12629-star。
  • 中国访问者可以获得飞书社区入口，而其他语言访问者则保留 Discord 和事件回顾页面已本地化。 （＃7120，＃7119）
  • 产品菜单现在包含 Codex 插件条目和 DeepSeek Harness 指南切换到每个平台的单行安装程序，更直接 入门流程。 (#7139) 谢谢@joeylee12629-star。

🙏 感谢所有运送 0.20.2 的人
