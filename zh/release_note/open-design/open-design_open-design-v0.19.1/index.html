open-design v0.19.1

修订 发布时间2026年8月14日 来源nexu-io/open-design 英文原文

open-design open-design-v0.19.1

🌟 代号：使用 DeepSeek Harness 进行设计

🧰 59 个 PR · 24 个贡献者 · 4 天 — DeepSeek Harness 现在作为 Open Design 内的代理。 Open Design 找到您的官方 dsh，指导设置 开放设计连接配置文件，列出了线束模型和 推理选项，并在稍后的回合中恢复相同的 Harness 会话。 0.19.1 还开始了为期两周的无限 DeepSeek V4 Pro 和 Flash 付费计划， 让家庭和团队项目在负载下保持响应。

🔥 亮点

  • 🧰 将您的官方 DeepSeek Harness 安装引入开放设计中。 Open Design 发现 dsh，读取其模型和推理选择，并给出 针对缺少凭据、配置文件设置或未经测试的具体指南 线束版本。设置和od agent setup deepseek-harness可以安装或 仅修复开放设计连接配置文件；开放式设计不会取代 或升级线束本身。运行流式思维、文本、工具调用、结果、 并用作结构化事件，然后稍后恢复相同的 Harness 会话 轮流。取消和进程清理还涵盖 Windows .cmd 安装。 (#6874)
  • 🎁 付费计划可免费使用两周的 DeepSeek V4 Pro 和 Flash。 8月13日20:00至8月27日20:00（亚洲/上海），两种型号 在工作台上携带无限徽章，并选择活动行动 V4 专业版。拒绝上一 Flash 营销活动的用户仍会看到此营销活动 一次。当滚动模型窗口填满时，“打开设计”会显示重试时间 并确认该请求未被收取费用。 (#6861)
  • 🏠 主页让您更快地进入项目。 刷新后的主页添加了 更清晰的创建型行和更直接的工作区控制。本地项目 不再等待云工作区身份才能启动，同时 云项目会进行余额检查。提交后，开放设计将移动 直接进入新项目的准备状态并干净地回滚，如果 创建失败。 （#6692、#6741、#6756）
  • 🔐 过期的云会话会让您返回登录状态。 无效 凭证被清除，现有的登录流程接管，并且暂时 工作空间权限失败重试而不重复请求。无头 操作员还获得 od amr status 和 od amr logout 用于检查和 从 CLI 重置云验证。 (#6786)
  • ⚡ 团队工作区将后台工作限制在范围内。 共享资源 拉取是批量的，同步扇出是有上限的，工作空间权限读取是 安全缓存，大型项目扫描、归档和推送队列都有牢固的 限制。工作区和计费刷新现在在事件爆发和 在中断期间退缩，而不是增加上游请求。 （#6711、#6752、#6782、#6788、#6871）

✨ 已添加

  • 设计系统目录现在包括 Cloudflare Kumo UI，可供使用 作为生成界面的视觉基础。 (#6769)
  • od mcp install claude-desktop可以为Claude桌面配置开放设计 在 macOS 和 Windows 上。 （#6489）
  • 公共定价页面现在描述托管图像生成以及文本 模型。 (#6395)
  • 从登陆页面和社区链接更容易发现启动周 在您离开开放设计之前就已经被贴上了标签。 （#6680，#6684）

🔁 已更改

  • 生成完成后，新的图像和视频输出将在预览中打开。 当代理命名现有工件时，写入会更新该文件 放置而不是创建编号的副本。 （＃6688，＃6719）
  • 消息中心行展开和折叠到位。还保存注释 将评论面板保留为您选择的状态，而不是强制打开它。 （＃6851，＃6862）
  • 主页搜索包括个人项目以及从社区创建的项目 模板保留模板的原始项目类型。 （＃6838，＃6847）
  • MCP 斜杠命令解释它们的作用，以及新创建的自定义技能加载 他们的文件无需刷新。 （＃6597，＃6735）
  • 活动和升级提示仅限于它们适用的 AMR 路径， 而不是出现在不相关的本地工作流程中。 （＃6760，＃6841）

🐛 已修复

🏠 工作空间和项目

  • 邀请已经属于工作区的人现在可以明确说明原因 邀请失败，恢复链接会打开实际的“设置”部分 包含所请求的控件。 （＃6830，＃6831）
  • od project list 和 MCP 资源读取改为尊重登录工作区 回到个人或空虚的范围。 （＃6736，＃6773）
  • 重新确定个人设计系统使其与项目保持联系， 之后即可到达。 (#6776)
  • 删除的项目在删除后立即离开工作区项目下拉列表 成功并在重新加载后保持消失。 (#6886)

🧠 运行和代理

  • 重复按 Enter 键和 clicks 不再将重复的聊天请求排入队列， 旧的守护进程重启恢复卡在稍后成功运行后消失。 （＃6748，＃6749）
  • 恢复的工具错误无法再将已经成功的运行恢复为 失败的一个。表格答案不会在简历中重复，且消息已过时 写入无法覆盖守护程序的规范运行事件。 （＃6305，＃6418， 第6764章）
  • 缺少 Vela 安装报告为不可用，Azure 别名身份验证 重试兼容令牌参数，CodeBuddy 模型发现句柄 CLI 的当前帮助输出。 （#6617、#6718、#6738）
  • 共享管道原子体在每个活动阶段插入一次，而不是 在提示中重复。 (#6245)

🖥️ 桌面和交付

  • 社交共享图标在打包应用程序、便携式 Windows 安装中呈现 将 NSIS 日志写入运行时路径，较慢的 macOS 冷启动就足够了 sidecar 报告健康状况的时间。 （#6559、#6750、#6762）
  • Docker 浏览器对等体可以进行身份验证，并且打包的运行时会启动 修复了已知容器漏洞的依赖层。 （＃6715，＃6733）
  • 韩语浏览器辅助 UI 和法语后备副本再次完成。 （＃6212，＃6612）
