open-design v0.21.0

小版本 发布时间2026年8月25日 来源nexu-io/open-design 英文原文

open-design open-design-v0.21.0

🌟 代号：可靠，自始至终

🛡️ 42 个 PR · 13 个贡献者 · 4 天 — 从代理连接到上线 HTML 预览和应用程序重新启动，开放设计 0.21.0 完成整个创作 体验更可靠，并且在出现问题时更容易恢复。 🚀

🔥 亮点

  • 🖼️ HTML 预览保持可见、实时且正确连接。 多文件 工件保留其脚本、样式、图像、模块和相关请求； 切换项目、文件或代码/预览不再通过 导航竞赛可能会将完整的文档涂成白色 框架。演示模式也获得了可靠的出路，clicking 预览会像其他地方的 clicking 一样关闭其视口菜单。 （＃7336， #7358）谢谢@lefarcen。
  • 🧰 工作代理不再消失在损坏的垫片后面。 OpenDesign 当 PATH 上的早期可执行文件过时时继续搜索，留下真正的 无法启动时的诊断和修复操作，并支持 DeepSeek Harness 发布线用户实际收到。一站式安装程序 完成而不是陷入依赖解析中。 （＃7153，＃7339） 谢谢@lefarcen。
  • 🌙 Kimi 再次在 0.37 及更新版本上工作。 这些版本停止接受 OpenDesign 附加到每个会话的 stdio MCP 传输，几乎变成了 每次都会遇到不透明的握手错误。 OpenDesign 现在仅发送 传输每个 Kimi 构建接受的内容，因此消息会生成流式回复 再次，而不是在工作开始之前失败。 (#7313) 谢谢@lefarcen。
  • 🚪 重新启动应用程序可以从陈旧的本地引擎中恢复。 Web Sidecar 崩溃留下的可以保留应用程序的套接字并让以后的每次启动 在启动时退出。 OpenDesign 现在安全地收回了那个过时的所有者，并且它的 守护进程和 Web 进程随桌面应用程序一起关闭，而不是困扰 下次发射。 (#7279) 谢谢@mrcfps。
  • 🤖 编码计划模型访问遵循您实际签署的帐户 进入。 模型选择器和无限制使用徽章现在读取经过身份验证的 权利列表而不是依赖于硬编码的层快照。深寻V4 Flash Vision Exp 还加入了付费个人计划的无限阵容， 当较旧的 client 未拾取时，具有更清晰的激活指导 尚未享有权利。 （＃7289，＃7250）谢谢@Siri-Ray。
  • 🧠 AI Optimize 运行一次，即使 click 发生两次。 两个条目 点可以在内部启动相同的隐藏设计系统细化 毫秒，充电两次并竞相重写相同的文件。 client 现在在重复项离开之前停止它，并且守护进程强制执行相同的操作 跨选项卡和外部 clients 的单运行边界。 （＃7271）谢谢 @lefarcen。
  • 💳 现在，定价行为在结账之前会说出真相。 当前 间隔、挂起的更改、取消状态、不可用的移动和团队 计费全部出现在做出决定的地方。 Go 显然已经卖完了，它很旧 应用内广告活动消失了，剩下的 DeepSeek 广告活动提供付费和 未付费用户可以选择一致的途径，而不是竞争性的促销活动。 （＃7228， ＃7239，＃7240，＃7352，＃7361）谢谢@Siri-Ray。
  • 🌐 当您离开选项卡时，网站克隆会留下提示。 本地化的“克隆此站点”脚手架不再跟随您进入 Slide Deck， 图像、文档、超帧、视频或音频。添加您自己的 URL，草稿为 仍然是你的；保持指南不变，下一个创作模式开始 干净。 (#7344) 谢谢@lefarcen。
  • 🔌 只要工作需要，长时间运行的 MCP 会话就可以保持活动状态。 熟悉的 30 分钟空闲行为仍然是默认设置，而 OD_MCP_STDIO_IDLE_EXIT_MS 可以选择更长的边界 — 最长 24 小时 — 或者 禁用 clients 的空闲退出，故意在之间保持会话安静 来电。 (#7288) 谢谢@huytdps13400。

✨ 已添加

🧠 代理、运行时和自动化

  • OD_MCP_STDIO_IDLE_EXIT_MS 配置 stdio MCP 空闲寿命； 0 保持 该进程一直处于活动状态，直到 client 断开连接。 (#7288) 谢谢@huytdps13400。

🔑 模型、计划和媒体

  • 编码计划模型可用性和无限徽章现在跟随实时， 经过验证的权利列表。 (#7289) 谢谢@Siri-Ray。
  • DeepSeek V4 Flash Vision Exp 在 Go、Plus、Pro 和 Max 上不受限制，并且 定价页面介绍了如何刷新旧版 clients 上的延迟权利。 (#7250)

🔁 已更改

  • 公开定价页面遵循登录订阅的时间间隔，并且 状态，禁用移动结帐将拒绝，恢复帐户条目 计费上下文很重要，并且使计划/模型细节更容易扩展和 比较。 （#7228、#7239、#7240）谢谢@Siri-Ray。
  • Go 对现有订阅者仍然可见，但新订阅者已标记为已售完 购买； client 不再显示其旧的活动徽章或欢迎模式。 （＃7352，＃7361）谢谢@Siri-Ray。
  • 现在每个社区条目都会导致Discord，包括中文桌面， 以前将社区分裂的站点和文档界面 飞书与不和。 (#7295) 谢谢@joeylee12629-star。
  • 帐户头像的第一个 click 现在将其菜单固定为打开状态；第二个 click， 退出、外部按下或导航会明确关闭它。 （＃7330）谢谢 @Siri-Ray。
  • 空的技能源会从过滤器中消失，并在以下情况下自动返回： 它们包含一些可供浏览的内容。 (#7298) 谢谢@nettee。

🐛 已修复

🎨 Studio，预览和导出

  • 多文件 Electron 预览解析相关脚本、样式、图像、 模块、导入和请求；活动预览在项目、文件中保持温暖 和代码/预览切换，而不是导航到白框。 (#7336) 谢谢@lefarcen。
  • 当预览本身为 clicked、演示模式时，视口菜单关闭 有一个退出控件，在焦点进入幻灯片后仍然有效，并且版本 当在新窗口中打开预览时，历史会清楚地说明。 （＃7358）谢谢 @lefarcen。
  • 无头和容器部署不再提供 PPTX 导出路径 他们的守护进程无法渲染；桌面保留导出，并且连接失败 停止伪装成缺乏能力。 (#7224) 谢谢@jiulongche。
  • 网站克隆起始文本在未触及时将作曲家返回为空， 当用户添加 URL 时保留，并在支持的创建中进行本地化 表面。 (#7344) 谢谢@lefarcen。

🧠 代理、运行时和对话

  • DeepSeek Harness 检测会绕过损坏的 PATH 垫片，保留无法使用的代理 通过诊断和修复操作可见，并接受当前 0.1.1-rc.x线。 （＃7153，＃7339）谢谢@lefarcen。
  • Kimi 0.37+ 会话省略了那些构建拒绝的 stdio MCP 传输，恢复 正常 ACP 启动和流式回复。 (#7313) 谢谢@lefarcen。
  • 反重力收到真实的用户提示，而不是字面的 -。 (#7205) 谢谢@mturac。
  • 本机简历和成绩单回放现在共享一个跨代理安全决策： 仅当存储的会话仍与可见对话匹配时才恢复； 否则清除陈旧的句柄并使用完整的转录本重新播种一次。 (#5269) 谢谢@alucero270。
  • ACP 使用、会话信息和命令元数据不再泄漏到可见区域 作为原始状态文本的对话。 （＃7309）谢谢@helsome。
  • ACP 阶段超时保持真正的静默持续时间并指定看门狗 结束了运行，使昂贵的摊位可以诊断，而不是看起来像 用户打断了它。 (#7310) 谢谢@lefarcen。
  • 设计系统 AI Optimize 允许对每个对话进行一次主动优化，因此 双 click，另一个选项卡或外部 client 无法创建重复项 针对相同文件计费运行。 (#7271) 谢谢@lefarcen。

🖥️ 桌面、导航和界面优化

  • 打包的 clients 在启动和清理期间回收无响应的 Web Sidecar 当桌面所有者退出时启动它们的守护进程和 Web 子进程。 （＃7279）谢谢 @mrcfps。
  • 前台故障不再引发冗余系统通知，而 结果已显示在屏幕上；后台通知和启用完成 声音保持其现有的行为。 (#7329) 谢谢@Siri-Ray。
  • 头像为clicked后，帐户菜单保持打开状态，本地CLI选择 在入职期间保持一致，空的技能源过滤器不会出现 的方式。 （#7330、#7338、#7298）感谢@Siri-Ray、@lefarcen、@nettee。
  • DeepSeek 活动使用官方提供商标志，具有可访问性、 当图像无法加载时可读的后备。 (#7326) 谢谢@Siri-Ray。

💳 计划和活动

  • 定价行为遵循发送前的真实订阅状态和间隔 任何人都可以结账；待处理、取消、不可用和降级状态是 明确的。 (#7239) 谢谢@Siri-Ray。
  • 模型订购、计划文案、推荐颜色和活动颜色现在保留 定价和主页之间保持一致。 (#7228) 谢谢@Siri-Ray。
  • Go 不再提供库存关闭后结帐服务，并且本地 client 停止与有效的 DeepSeek 优惠一起显示其已退役的活动。 （＃7352，＃7361）谢谢@Siri-Ray。

🙏 感谢所有运送 0.21.0 的人
