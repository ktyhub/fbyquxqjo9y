open-design v0.27.0

小版本 发布时间2026年11月4日 来源nexu-io/open-design 英文原文

open-design open-design-v0.27.0

🌟 代号：CoRouter for Teams

座位不限。共享积分。 一项订阅可让您的团队共享模型积分。免费邀请同事到您的工作空间，无需额外的座位费。使用相同的共享积分在开放设计中创建或通过 API 调用模型。工作区所有者管理订阅、升级和充值。

🔥 亮点

  • 🤝 邀请同事，共享工作区。 从入职或主页发送电子邮件邀请，让团队成员加入您的工作区，并就共享项目进行协作。邀请会显示哪些电子邮件成功，哪些需要再次尝试，因此您可以重试失败的条目，而无需再次发送成功的邀请。 (#9120)
  • 💳 一个工作区，共享积分。 查看工作区的共享设计计划和计量津贴，并在订阅更改时刷新计划和模型可用性。当平衡或并发阻止任务启动时，您的草稿仍然可用；解决限制后，您可以控制何时再次发送。 （＃9120，＃9138）
  • 🔐 选择团队可以看到的内容。 设置项目对您自己或团队成员的可见性，包括在默认的个人工作区中。将工作区可见性与发布工作链接以供审阅分开。 （＃9120，＃9193）
  • 🎞️ 从参考视频开始您的动作片段。 附加视频或粘贴支持的视频链接并要求重新播放。 Agent 可以检查其时间、场景和配乐，构建可编辑的动作，并导出 MP4。要求更改特定元素以进行重点修订；结果还需要您的审核。 (#9105)
  • 🎨 还有十三种行动方式。 新的动效模板涵盖产品发布、门票促销、解说、动态排版等。标题、描述、入门提示和输入标签遵循所有 19 种受支持的 client 语言，并改进了预览字体加载和大小调整。 (#9131)
  • 🧠 规划和阅读作为一项任务。 自动规划和生产共享一个可扩展的流程和运行的总运行时间。步骤保持有序，而最终答案和可交付成果仍然很容易在流程之外找到。 （＃8735，＃9196）
  • 💬 保留已有的反馈。 失败的评论刷新可通过重试操作使现有评论保持可见。阅读状态遵循实际显示的注释，并且保存的位置标记与所选注释保持对齐。 (#9027) 谢谢@alchemistklk。
  • 🗂️ 最近的项目跟随您的工作。 主页和项目列表按您最新接受的消息或手动重试排序。打开项目、重命名项目或接收代理回复不再将其推到您刚刚开始的工作之前。 (#8802) 谢谢@alchemistklk。

📥 下载： 在 GitHub 版本 上查找桌面安装程序。

✨ 已添加

🤝 团队协作

  • 工作区邀请包括注册和加入流程、角色描述、传送状态以及失败收件人的重试。 (#9120)
  • 可从主页和项目获取共享工作空间津贴和计划信息；订阅更改会刷新可用模型目录。 (#9120)
  • 项目可见性控制可在个人工作区和团队工作区中使用。 （＃9120，＃9193）

🎞️ 动作创作

  • 参考视频检查和并排比较可帮助特工根据测量的场景时间进行工作并审查生成的影片。默认情况下，如果存在参考音频，则重复使用参考音频；不可用的链接要求上传。 (#9105)
  • 13 个捆绑的 Motion 模板添加了更多起点，包括 SuperX Audience Growth、TixFox Ticket Promo、Windows Studio Launch 和 DistilBookExplainer。 (#9131)

🔁 已更改

  • 自动计划和生产使用一个任务演示，具有一致的时间安排和按时间顺序排列的流程细节。 （＃8735，＃9196）
  • 项目指示器、转向标题和通知使用一致的运行、停止、失败和需要回复状态。问题表格会等待您的回答，而不是十分钟后自动提交。 (#8860) 谢谢@Siri-Ray。
  • 最近的项目排序遵循已接受的人工提交；执行开始时，排队的消息保留其原始提交时间。 (#8802) 谢谢@alchemistklk。
  • 共享发布当前保存在磁盘上的文件。仅打开编辑或注释工具不再阻止共享并出现保存状态警告；复制链接不会发布更改，刷新共享内容仍然是显式操作。 （＃9025，＃9202）谢谢@alchemistklk。

🐛 已修复

💬 对话和代理

  • OD Next 已流式传输的文本在运行失败或停止后仍然存在，包括重新打开对话后。 (#8903) 谢谢@Siri-Ray。
  • 大量历史对话可以在数据不断到达的同时完成加载；切换对话或取消会释放旧连接。 (#8771) 谢谢@alchemistklk。
  • 排队的消息在发送开始后立即离开其队列卡。如果余额检查阻止了它，则完整的草稿将返回到队列中。 (#8381) 谢谢@Siri-Ray。
  • OpenCode 支持的运行可以读取经过验证的任务指令以及它们在系统临时目录中创建的文件，从而避免运行在没有有用答复的情况下结束。 （＃9060，＃9077）谢谢@HaiYangBG1，@Siri-Ray。
  • 工作区图像快照、缩略图、视频封面和下载链接保留正确的项目上下文，包括刷新或重新打开后。 (#9151)

🤝 分享、评论和工作区访问

  • 链接共享和工作区可见性独立控制加载和重试，因此其中一个问题不会清除另一个问题。 (#9025) 谢谢@alchemistklk。
  • 评论阅读跟踪不再跳过其他文件中未见的评论或迟到的评论；延迟回复不能替代不同项目的评论列表。 (#9027) 谢谢@alchemistklk。
  • 评论位置标记在支持的预览模式中保持一致，当目标被删除时有明显的回退。 (#9027) 谢谢@alchemistklk。
  • 最大工作区并发通知始终要求所有者、管理员和成员等待另一项任务完成。 (#9138)
  • 家庭邀请函和注册副本遵循所选语言，邀请函字幕在小窗口和从右到左的语言中正确换行。 （＃9207，＃9208）谢谢@qd1993102。

🖥️ 窗口和对话框行为

  • 活动对话框在调整大小或缩放时保持内容和按钮可访问。背景页面保留其滚动位置，键盘焦点保留在最上面的对话框中。 （＃9149，＃9179）
