open-design v0.24.0

小版本 发布时间2026年9月22日 来源nexu-io/open-design 英文原文

open-design open-design-v0.24.0

🌟 代号：每次运行，保持完整

🧭 26 PRs · 13 contributors · 1 天 — **跑步应该在真实的情况下生存
世界，不仅仅是幸福之路。**重新加载、后续问题、预览更改
首次发布曾经是工作可能失去其地位的时刻；现在
项目保留它。 🚀

🔥 亮点

  • 🧵 当工作不断进展时，对话仍能保持主线。 规划
    答案、实时任务延续、阻塞任务决策和恢复输出
    即使在重新加载或后续操作之后，也要继续执行产生它们的任务。
    分叉聊天会干净地开始，而不是继承另一个对话的工作。
    仅计划回复现在以您收到的答案结束，而不是红色失败
    跑。 （＃8322，＃8195，＃8008，＃8007，＃8172，＃8029，＃8158）谢谢@itscheems，
    @lefarcen。
  • 🖼️ 您当前的预览保持您选择的预览。 真实页面不再
    变成空白快照，读取陈旧文件无法窃取聊天预览
    当你正在检查其他东西时。 （＃7125，＃8067）谢谢@huynextlevel。
  • 🃏 丰富的答案以答案的形式出现，而不是标记。 开放设计解码卡片
    在思维流中并安全地掉落一张畸形的卡片而不是溢出
    将原始数据放入对话中。 （＃8258，＃8264）谢谢@lefarcen。
  • 🪟 首次在应用程序中安装全新的 Windows。 打包的应用程序
    不再将其初始有效负载状态误认为切换失败，因此网络
    接口可以在首次启动时连接到其本地引擎。 （＃7520）谢谢
    @lorenzozanee。
  • 🔑 Novita AI 已在 BYOK 选择器中准备就绪。 选择 Novita AI，带上您的
    键，并从当前的 DeepSeek、MiniMax、Qwen、GLM、Kimi 和 GPT-OSS 中进行选择
    模型无需手动构建提供者设置。 (#6327) 谢谢@jax-novita。

✨ 已添加

🔑 BYOK、模型和媒体

  • Novita AI 加入了 BYOK 提供商预设及其模型目录和 API-key
    管理链接。 (#6327) 谢谢@jax-novita。

🔁 已更改

🧠 代理、运行时和沙箱

  • 当您更改配置文件时，工作区订阅会彻底重置，从而保持
    您面前的项目和帐户状态与您的工作空间同步
    实际选择的。 (#8020) 谢谢@AmyShang-alt。
  • 当两者都安装时，本地代理检测优先选择直接 Copilot CLI
    通过 VS Code 的引导副本。 (#7974) 谢谢@tony-box。
  • od automation create和od automation update可以再次接受
    逗号分隔的技能上下文在命令运行之前不会失败。
    (#7612) 谢谢@johnkattenhorn。
  • od media generate --help 现在无需尝试启动生成即可显示帮助。
    (#8066)

🎨 工作室、编辑和画布

  • 清单支持的 Markdown 工件现在算作实际运行输出，并且较晚
    封面渲染达到清晰的最终状态而不是留下误导性
    结果落后。 （＃7586，＃8061）谢谢@arccat-114。

🐛 已修复

🧠 代理、运行时和对话

  • 恢复的对话保留正确的任务判决、输出和计划
    重新加载和继续的意图。 （#8195、#8008、#8007、#8172）
  • 分叉对话不再将其源运行工件带入
    新的聊天。 (#8029) 谢谢@lefarcen。
  • 持续的对话不假装地瓦解了未回答的问题 得到了答复。 (#8158)
  • 计划阶段的拒绝仍然给你一个有用的答复保持正常
    完成状态而不是显示运行失败的卡片；真正的生产故障
    仍然表现为失败。 (#8322) 谢谢@itscheems。

🎨 Studio，预览和导出

  • 预览快照保留真实页面内容，延迟文件读取无法
    替换您正在使用的预览。 （＃7125，＃8067）谢谢
    @huynextlevel。
  • 有效的思维流卡呈现为卡片；无效的可以安全地留在外面
    的谈话。 （＃8258，＃8264）谢谢@lefarcen。

🌍 本地化

  • 整个设计系统流程、库和内存的法文副本都是完整的。
    （＃7906，＃7756）谢谢@davezfr。

🖥️ 桌面

  • 全新 Windows 安装完成本地桌面切换并可以加载
    应用程序正常。 (#7520) 谢谢@lorenzozanee。

🙏 感谢所有运送 0.24.0 的人
