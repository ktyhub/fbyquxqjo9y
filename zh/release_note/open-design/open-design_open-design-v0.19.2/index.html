open-design v0.19.2

修订 发布时间2026年8月14日 来源nexu-io/open-design 英文原文

open-design open-design-v0.19.2

🌟 代号：DeepSeek Harness，一个命令即可

🧰 28 个 PR · 9 个贡献者 · 2 天 — 0.19.2 缩短了从 安装 DeepSeek Harness 即可完成工作。 一个命令即可设置 兼容的 Harness 工具链，带有空格的 Windows 路径不再破坏 打开设计连接，长流保持响应。这个补丁还增加了 离线安全 HTML 导出和结构化设计系统 3.0 运行时。

🔥 亮点

  • 🧰 使用一个命令安装 DeepSeek Harness。 新的引导脚本 涵盖 macOS、Linux、Windows PowerShell 和 Windows CMD。他们重复使用兼容的 本地工具或安装独立的用户范围的 Node.js 24 工具链 固定线束释放，然后打开 dsh web 进行 API 密钥设置。立即打开设计 通过 shell 安全的配置文件路径安装其连接组件，包括 Windows 应用程序和包含空格的 DSH_HOME 路径。 （#6900，#6905）
  • 📦 导出 HTML，在移动后继续工作。 立即下载 HTML 捆绑项目本地图像、样式、字体、模块、工作人员和嵌套 将文档合并为一个离线安全文件。丢失或过大的依赖项返回 一个明显的错误而不是损坏的导出。可以通过以下方式获得相同的输出 od export --format html。 (#6855)
  • ⚡ 长时间的代理运行保持响应。 思考和文本仍然流入 聊天时，Open Design 在幕后批处理持久性和 React 更新。 终端转换刷新最后缓冲的输出。 od export 也可以 仅使用项目 ID，因此代理不再需要工作区或成员标志 对于已保存工作区绑定的项目。 (#6915)
  • 🎨 **结构化设计系统现在推动生成和验证。**设计 系统 3.0 包为代理提供意图图、精确的组件实现、 令牌和规则。代理可以在生成之前解析组件，仅加载 其声明的文件，然后验证重用、所需状态、令牌使用和 后退行为。可以通过以下方式获得相同的工作流程 od tools design-systems。 （#6805）

✨ 已添加

  • DeepSeek Harness 设计指南现在拥有 13 个经过验证的配套集合 设计插件，按愿景、生成 UI、工作流程和预览使用进行分组 案例，具有本地化的详细信息页面和源支持的安装命令。 （#6864，#6897）
  • 打包应用程序现在搜索标准 nix-darwin、NixOS、系统和用户配置文件 发现本地安装的代理 CLI 时的目录。 (#6885)

🔁 已更改

  • 主页创建行将最常见的项目类型放在第一位，然后 DeepSeek Pro 和 Flash 营销活动文案在整个产品中保持一致， 本地化登陆页面截至 8 月 27 日。（#6852、#6863、#6876、#6892）
  • 登陆页面生产部署现在会在发布后清除活动主机 保持 HTML 的短边 TTL，减少访问者花在陈旧信息上的时间 发布后的页面。 (#6552)

🐛 已修复

🧠 DeepSeek Harness 和代理

  • 取消线束运行现在一旦取消就会解决，终止配置文件 处理，保留提供者错误详细信息，并记录正确的提供者和 诊断中的模型。取消的回合不再显示为“正在工作”、“已完成”或“正在运行” 失败了。 （#6880）
  • 缺少 DeepSeek 凭据现在会生成 dsh web、设置的步骤 → 型号，并用 DEEPSEEK_API_KEY 代替 [object Object]。 （#6890）
  • 长结构化事件流在有用的输出后不再让聊天变得忙碌 出现，项目导出避免了重复的工作空间上下文失败。 (#6915)

🖼️ 预览和工作区 UI

  • 当 Chromium 中止 about:srcdoc 时生成的演示文稿会恢复 导航、强力预览在反向代理和评论桥后面工作 在报告准备就绪之前等待提交的预览 URL。 （＃5592，＃6797， 第6882章）
  • 移动评论预览在关闭时不再闪烁，甲板预览会填满 查看器没有信箱，移动到团队对话框覆盖了作曲家 在它下面。 （#6785、#6829、#6854）
  • 展开的消息中心行再次显示其配置的 HTTP(S) 操作。 不安全的操作 URL 仍处于隐藏状态。 (#6894)

🖥️ 桌面和交付

  • Sidecars接受配置的内部主机允许列表，该列表保持打包 在批准的内部主机后面工作的部署。 （#6802）
  • 团队定价副本现在与登陆页面上每席位 5 美元的目录相匹配 表面。 (#6834)

🙏 感谢所有运送 0.19.2 的人
