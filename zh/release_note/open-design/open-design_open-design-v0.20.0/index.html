open-design v0.20.0

小版本 发布时间2026年8月19日 来源nexu-io/open-design 英文原文

open-design open-design-v0.20.0

🌟 代号：设计稳定

🧭 51 个 PR · 13 个贡献者 · 5 天 — 从 Prototype 开始，导航每个 同步预览和注释的幻灯片，并导出可编辑的 PowerPoint 文件 字体和换行符完好无损。我们还修复了一个可能导致 生成的工件打开到空白屏幕。 0.19 填充了菜单中的内容 你可以做； 0.20.0 是让他们每个人都坚持下去的版本——从一开始 click 回到您移交的文件的主页。

🔥 亮点

  • 🧪 家庭从大多数人真正开始的地方开始：原型。 一个新鲜的 作曲家在 Prototype 上打开，创作列表现已稳定， 产品拥有的集 - 原型、幻灯片、图像、文档、HyperFrames、 网站克隆、视频、音频、实时工件、WebGL — 而不是列表 随安装的插件而变化。落地/营销， 仪表板、移动应用程序、线框、应用程序、开发人员工具、品牌/设计和 各种语言的文档/报告始终位于原型下，并且 社区过滤器也以原型为主导。 （#6914、#6975、#6906、#6980）谢谢@Siri-Ray。
  • 🎞️ 可编辑的 PowerPoint 保留您批准的设计。 导入 Google 字体现在进入文件，编写的换行符保留在您放置的位置 而不是在 PowerPoint 或 WPS 中重排，以及分层幻灯片背景 度过这次旅行。源模式导出在开发运行时再次起作用， 包含 $ 样式替换序列的标题则逐字导出 而不是失去角色。 （#6840、#6845、#6921、#6947）感谢@Siri-Ray、@dcrtorres、@cactusrabbit。
  • 🖼️ 甲板缩略图带您前往它显示的幻灯片。 缩略图，主要 舞台、页码计数器、演讲者备注和上一个/下一个控件现在会移动 作为一个整体——跨越旧版和当前的套牌——而不是侧边栏 当舞台停留在第一张幻灯片时继续前进。缩略图布局保持真实 幻灯片比例，并重新混合来自社区的套牌，为您提供工作 立即预览。 （#6950、#7095、#6996）谢谢@lefarcen。
  • 🩹 生成的工件停止打开到空白屏幕。 切换文件， 切换代码/预览或在项目之间移动可能会留下永久的错误 当 Chromium 中止保留的预览导航时，白色画布。立即预览 在这些交换机上保持安装和可重复使用，当发生故障时自行恢复 导航被删除，并加载他们的字体而不是退回到裸露的 页。 （#7128、#7055、#7007）谢谢@lefarcen、@Siri-Ray。
  • 🎬 HyperFrames 从应用程序渲染视频，而不是从您的 npm 缓存。 视频 作品现在通过开放设计搭建支架并使用 HyperFrames 进行渲染 运行时与守护进程一起固定和打包，因此是一个陈旧的本机工件 用户的 npm 缓存不能再破坏生成和 Windows 打包构建 正确运送。 （＃7030，＃7132）谢谢@Siri-Ray。
  • 🌐 网站克隆使用您已有的浏览器。 克隆用于 花费几分钟将 Playwright 安装到每个生成的项目中，但经常失败 直截了当。现在，它通过驱动器驱动已安装的 Chrome、Edge 或 Chromium 隔离的临时配置文件，使您的项目保持不变，并且工作原理相同 从 UI 或从没有打开 client 窗口的 od。 （＃7000，＃7066）谢谢@lefarcen。
  • 🧑‍🤝‍🧑 工作区故障不再影响您的项目。 文件已存在 当云目录在您的计算机上保持可编辑、可运行和可共享 暂时无法访问，新邀请的队友可以打开共享项目 在传输每个字节之前，公共文件共享在守护程序重新启动后仍然存在， 您最后进入的工作区就是您返回的工作区。 （＃7027，＃6989， ＃7002，＃7067）谢谢@lefarcen，@Siri-Ray。
  • ⚡ 刷新长时间运行，无需再次支付整个历史记录。 多分钟 会议仍然会现场直播思考和文本，但现在已写下文字记录 在持久的仅附加批次中：重新加载保持响应，活动运行重建 干净地完成对话，不再累积不断增长的重写 成本。 (#6952) 谢谢@lefarcen。
  • 🧹 在任何地方运行 Open Design 的防倾斜检查。 工件 linter 应用程序内的警卫工作现在是 od lint。将其指向文件或管道标准输入， 选择一个故障阈值，并获得可读或 JSON 结果，而无需启动 模型——这样无头代理和 CI 可以在任何事情发生之前捕获弱默认值 出口。 (#6959) 感谢@DojoGenesis。
  • 🛑 失败的运行看起来不再像已完成的运行。 重复的 OpenCode shell 错误 — 包括过去常常漏掉的 PowerShell 故障 已完成的工具 - 现在到达环路防护，因此开放设计可以警告、停止和 保留真正的失败，而不是以看似绿色的结果结束。克劳德奔跑 超出上下文窗口的内容被如此命名，而不是报告为 一般执行失败。 （＃6933，＃7044）谢谢@YUHAO-corn，@Siri-Ray。
  • 🖼️ 被拒绝的图像表示它被拒绝了。 当内容安全政策发生变化时 按下图像请求后，回复现在会这样说并指向提示或 您实际上可以更改参考图像 - 而不是让您等待 对于永远无法恢复的中断。 (#6993) 谢谢@alchemistklk。
  • 🌍 切换 AMR 环境会移动整个应用程序。 平衡、工作区 上下文、升级链接和设置目的地现在遵循您的配置文件 挑选 - 生产、测试或功能测试 - 无需重新启动，并且未映射 目的地失败关闭而不是悄悄打开错误的环境。 (#6991) 谢谢@AmyShang-alt。
  • 👤 最近的项目看起来像您的工作空间，而不是匿名列表。 您自己的项目 项目带有您的登录名和头像，而不是通用的“我”，以及 行的溢出菜单在屏幕底部附近向上翻转，因此每个操作 - 删除包含 — 保持可达。 （＃6857，＃6971）谢谢@lefarcen，@Siri-Ray。
  • 🛡️ BYOK 媒体下载在您的机器周围划出更牢固的界限。 图像和 外部提供商返回的视频 URL 无法再引导守护进程返回 进入本地主机，包括通过 DNS 技巧。特意配置的本地 提供商网关继续工作； untrusted 资产响应不再相同 特权。 (#6072) 感谢@CVE-Hunter-Leo。
