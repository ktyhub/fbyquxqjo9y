oh-my-pi v18.22.1

oh-my-pi v18.22.1

@oh-my-pi/pi-agent-core

添加

  • 扩展的自定义 api 上的模型可以通过声明 remoteCompaction: { api: "anthropic-messages", enabled: true } 来采用 Anthropic 按需压缩通道；请求像任何回合一样通过自己的流（#19580 by @ryanskidmore）

已修复

  • 修复了提供者错误处理，因此失败的工具调用不再作为拒绝解释反馈给模型。
  • 修复了自定义智普编码计划提供商的一次性重试和标题生成问题，以便遵守北京时间的配额重置。
  • 修复了 OpenAI 远程压缩（V1 和 V2）删除 models.yml 和扩展注册模型的配置标头，因此标头身份验证的网关返回 401 (#19579 by @ryanskidmore)

@oh-my-pi/pi-ai

添加

  • 通过 buildAnthropicSearchHeaders 中的 extraBetas 选项添加了对请求特定的 Anthropic beta 标头的支持。
  • 将 omitDemotedReasoning 添加到 StreamOptions，允许 Anthropic 请求省略其他模型的推理，否则这些推理将作为文本重播； refused requests report the omitted block count in demotedReasoningBlocks.
  • 使用情况报告现在可以包括 API-key 或 OAuth 凭据使用的凭据 ID，并且 AuthStorage.sessions.sticky 为服务会话的凭据提供只读查找。
  • 将 riskAcknowledgement 添加到 OAuthPrompt，允许主机显示登录警告接受文本，即使他们在显示授权 URL 之前取消 cline 输入。
  • remoteCompaction: { api: "anthropic-messages", enabled: true } 在已知部署之外的网关 baseUrl 处选择 Anthropic 模型进行按需压缩； enabled 单独排除了此类网关，并且远离配置的端点的重新路由仍然必须到达已知的部署。 isBuiltinApi() tells a built-in request adapter from an extension’s custom api (#19580 by @ryanskidmore)

已更改

  • OpenAI Codex 请求现在自动跟踪最新的兼容 @openai/codex client 版本，并具有可选的 PI_AI_CODEX_CLIENT_VERSION 覆盖，因此可以使用新提供的 Codex 模型而无需更新 omp。
  • Updated OpenAI Codex request formatting and ChatGPT token-refresh reporting to match Codex CLI 0.169.
  • 将 Claude Code 和 Gemini CLI client 版本标识符分别更新为 2.1.326 和 0.68.0。

已修复

  • Fixed OpenAI Decisions usage accounting for gateways that report prompt_tokens and completion_tokens instead of input_tokens and output_tokens.
  • 改进了包含非常长的不间断行的围栏思维内容的流性能。
  • 修复了人为请求重放具有不支持的线程元数据的签名服务器压缩块的问题，避免在重试之前拒绝请求。
  • 通过报告经过的时间、上传状态和请求大小，改进了对在响应之前断开的人为连接的诊断。
  • 修正了人择对话失去早期非克劳德回合或通过压缩保留的回合的推理。
  • 修复了使用zhipu编码计划端点的自定义提供商的凭证轮换和重试时间，以便遵守北京时间的配额重置。
  • 修复了克劳德寓言和神话的使用限制错误，以便轮换尽可能选择具有可用配额的同级帐户。
  • 无效的反重力 CLI 工具参数现在将验证错误和预期模式返回到模型，而不是结束回合。
  • Abandoned Antigravity CLI login directories without credentials are automatically cleaned up after 24 hours.
  • 提高了慢速连接上托管反重力 CLI 下载的可靠性，并提供了更有用的进度和超时错误。
  • 修复了具有混合类型联合模式的反重力 CLI 主机工具发布不正确的问题，允许子代理提交结果。
  • 修复了 partial_answer 阶段中的 Codex 助理消息在存储和重播时丢失其阶段的问题。

@oh-my-pi/浏览器中继

已修复

  • 修复了浏览器中继可能无法识别其清空并隐藏在选项卡中的框架的页面和标题的问题。

@oh-my-pi/pi-目录

已修复

  • 修复了 Factory Droid 的 Muse Spark 1.3 支持，以便图像输入正常工作并且模型无需停用功能标志即可使用。
  • 修复了 GitLab Duo Claude 模型，以便在后续转弯和压实过程中正确处理早期推理上下文。
  • 修复了过时的命令代码模型元数据，包括图像输入支持、推理控制、令牌定价和部署上下文限制。
  • 修复了使用zhipu编码计划端点的自定义提供程序的重试重置时区处理，包括带有尾部斜杠的基本URL。

@oh-my-pi/pi-coding-agent

重大变化

  • The JavaScript eval commit helper now validates its arguments strictly: unknown option names and non-object options throw a TypeError that lists the supported options.更新传递额外选项的脚本。现在提交未更改的草稿存储库会报告它未更改，而不是建议 take()。

添加

  • 添加了默认启用的 providers.webKeyless 设置，以控制网络搜索和 URL 读取是否可以使用无密钥服务。禁用它以将这些操作限制为已配置的提供程序；单独的 omp q --model web/<engine> 请求仍然可以显式运行无钥匙引擎。
  • 通过 live.endpoint 和 live.apiKey 添加了可配置的实时语音端点和 API 按键。 Live voice can now connect to any OpenAI Realtime WebRTC-compatible server without Codex or ChatGPT sign-in, including offline use, and live.voice accepts arbitrary voice names.
  • Computer el.setValue() now accepts finite safe integer and decimal numbers and writes them as text, while continuing to reject unsupported values such as booleans, objects, NaN, and Infinity.
  • On macOS, browser results now report relevant native windows—such as pickers, print or save sheets, sign-in prompts, passkey dialogs, and permission bubbles—with their computer.window() identifiers.
  • Browser select() now accepts label-, value-, and zero-based index-based choices, including mixed choices for multi-select controls, across Chromium, Tern, and cmux tabs.

已更改

  • 无钥匙并行搜索不再发送会话或模型标识符；仅发送搜索查询。
  • computer 工具的 macOS 接管消息现在描述实际的键盘切换状态，并解释后台窗口移动和仅悬停控件的行为。
  • Chromium tab.observe() 和 tab.ariaSnapshot() 现在会短暂等待先前操作触发的页面更新，从而产生更可靠的操作后结果。
  • 当另一个代理控制桌面时，InputBusy 现在会识别该代理及其 omp 进程。
  • 子代理现在默认使用自己的浏览器上下文，而不是在用户的 Chrome、Tern 或 cmux 会话中打开选项卡；仍然可以明确请求中继或 Tern 访问。
  • 现在，浏览器任务指导会在第一次浏览器调用后自动提供，并在第一次调用前提供安全指导，并在压缩或倒带后恢复。
  • 命名菜单读取现在包括嵌套命令及其完整命令路径。
  • eval commit 帮助程序现在除了 .git/hooks/ 中的钩子之外还运行配置的 Git 钩子，匹配 git commit 行为。配置的挂钩可能会导致提交花费更长的时间或被拒绝。
  • 服务就绪模式现在可以正确匹配行边界，并且 shell 文件时间命令遵循配置的 TZ 时区。
  • 大型 write 和 edit 调用在其参数流时保持响应。
  • 选择性提交现在可以更准确地处理初始化的子模块指针和稀疏检出，并显式报告不匹配的路径。
  • Git 提交操作现在提供更清晰的状态和挂钩反馈，包括未更改的存储库、挂钩输出、挂钩修改的提交主题以及具有正在进行的操作或未解决的冲突的存储库。
  • 当最近的会话在收到第一条消息之前在其他地方创建时，/continue 现在会恢复当前目录的最新会话。
  • /copy 现在复制 out:// 回复中显示的内容并保留其代码块。
  • 在目标模式下启用的工具在离开该模式后仍然可用。
  • 状态行使用情况现在反映了为多凭证提供者实际选择的凭证。
  • 使用Zhipu Coding Plan端点的自定义提供商现在在正确的北京时间配额重置处重试。
  • ^model 引用后跟句子标点符号现在解析为模型代理引用。
  • /restart 现在通过原始启动器重新启动，因此恢复的会话将使用升级的安装。
  • RPC 主机在配额错误后可靠地接收完成事件，并且 OSC 7501 终端在较新的运行期间不再播放过时的成功通知。

已修复

  • 修复了配置的 Exa 和 Firecrawl 凭证在凭证解析失败时默默回退到无密钥端点的问题；现在报告凭据错误。
  • 修复了评估单元绕过 yield 完成委托任务的问题；请改用直接工具。
  • 修复了 /commit 和 eval 提交在合并和其他 Git 操作期间创建不正确的单父提交；现在，当操作正在进行或冲突仍然存在时，提交会被拒绝。
  • 修复了 apply_patch 工具文档错误地将其描述为 shell 命令并不允许绝对路径。
  • 修复了 shell rg 内置忽略包含斜杠的 --glob 模式。
  • 修复了当选定路径或全局匹配未更改文件时 eval commit only(...) 失败的问题。
  • 修复了浏览器调用在中断页面评估后变得永久繁忙的问题，并修复了过时的 JavaScript confirm 或 prompt 对话框导致后续调用失败的问题。
  • 修复了 macOS Chrome 和 Electron computer.setValue() 无法从空选项列表中选择选项的问题。
  • 修复了当另一个扩展（例如密码管理器）持有该选项卡时浏览器中继选项卡被关闭的问题；该选项卡现在仍然可以重新连接。
  • 修复了当用户继续键入时 macOS 计算机接管无法报告用户干预的问题。
  • 通过识别涉及的框架、扩展和页面，改进了隐藏扩展框架的浏览器中继错误。
  • 修复了 site: 查询和安全拒绝搜索的人类网络搜索，包括更清晰的拒绝和提供者错误报告以及适当的重试行为。
  • 没有输出模式的子代理不再接收不必要的 yield 工具，并且没有数据的 yield 不再错误地使用最后一条消息作为其结果。
  • 修复了 macOS 弹出窗口和菜单交互，可能导致菜单打开或按下错误的控件。
  • 修正了克劳德在模型切换或压缩后从早期非克劳德模型转向中丢失推理的问题，并防止拒绝文本污染以后的请求。
  • 修复了选择性提交跳过更新的子模块指针并错误地将稀疏签出路径报告为删除的问题。
  • 修复了当后台 Git 进程保持输出管道打开时 Git 状态扫描挂起的问题。
  • 修复了 macOS 上首次启动 WebKit 启动时引擎仍在初始化时回落到 Chromium 的问题。
  • 修复了拒绝从提交错误中忽略的预提交挂钩输出。
  • 修复了 Mach-O 二进制文件中 Objective-C 消息结果和 arm64 保留寄存器数据的 Ghidra 分析，包括缓存的框架。
  • 修复了模式对话框后面的浏览器交互错误地报告成功的问题；覆盖的字段和禁用的元素现在被拒绝，并检测覆盖的拖动端点。
  • 修复了需要自担风险确认的提供商的 RPC 登录问题；现在会向主持人提交确认信息，并且只有在获得批准后才能继续登录。
  • 在 Linux 上，node_modules 和 .git/objects 中的语言服务器文件监视不再消耗过多的 inotify 监视。

@oh-my-pi/pi-mnemopi

已修复

  • 修复了当超大输入在表情符号或其他 Unicode 字符中间使用 cli 时嵌入请求失败的问题。

@oh-my-pi/pi-natives

添加

  • 添加了 DesktopFocusReturn.keyboard，它报告 macOS 接管后用户键盘发生的情况：交回、按选择保留、保留、仅带到前面或不发送。
  • 添加了 desktopWindowRoster() 以枚举所有屏幕上的 macOS 窗口，包括弹出窗口、选择器和系统提示，及其所有者、图层以及对 listWindows 的可见性。
  • 添加了稀疏签出感知的 Git 树操作，以便选择性提交保留稀疏锥体之外的文件和折叠的稀疏目录条目。

已更改

  • macOS 滚动现在与 Windows 和 Linux 匹配：正 dy 向下滚动，正 dx 向右滚动。
  • 当该信息可用时，InputBusy 现在可以识别持有输入或焦点控制的代理和 OMP 进程。
  • Wayland 文本输入现在支持在提供 libei 文本支持的合成器上通过活动键盘布局无法使用的字符，包括重音字符、CJK 文本和表情符号。
  • 改进了大型 GTK、Qt 和其他应用程序的 Linux 可访问性性能和可扩展性，包括更快的元素查找和非常大的表和列表的有界树读取。
  • 树列表现在公开 gitlink 模式，因此选择性提交可以区分子模块指针和普通文件。

已修复

  • 修复了计算机接管和后台输入后 macOS 和 Windows 焦点恢复的问题，包括目标应用程序自行前进的情况；原始应用程序现在再次激活，并准确报告焦点结果。
  • 修复了当目标使用不同的键盘布局或大写锁定、粘滞键或其他布局处于活动状态时 Windows 和 X11 上的键盘输入。
  • 修复了 X11 输入被传递到另一个应用程序的菜单、屏幕锁定或其他键盘抓取的问题；输入现在等待瞬态抓取结束或失败而不发送密钥。
  • 修复了 Linux 文本输入在代理输入期间影响用户活动字段的问题。支持的 GTK 和 Qt 文本字段现在尽可能使用基于安全辅助功能的输入，而不受支持的字段则继续使用现有的键盘路径。
  • 修复了 Linux 与组合框的交互，以便安全地拒绝不支持的弹出打开操作，同时可以在不接管键盘的情况下进行支持的 GTK 3 和 Chromium 选择。
  • 修复了 SwiftUI 切换的 macOS 辅助功能标签，包括将其相邻标签与 find({ title }) 匹配。
  • 修复了刷新表（包括活动监视器）中的 macOS 元素引用，因此行操作遵循未更改的行，安全地拒绝更改的行，并在无法匹配行时提供有用的前后详细信息。
  • 修复了当目标被隐藏、不可用、被纸张覆盖或无法 clickable 时，macOS click 和按下被报告为成功的问题。
  • 修复了 macOS Chromium <select> 交互，包括选项匹配、菜单清理以及可用选项不完整时的安全处理。
  • 修复了 macOS setValue 的数字控件（例如滑块和步进器），包括报告控件钳位或舍入的值；不受支持但可步进的控件现在解释如何使用其增量和减量操作。
  • 修复了当用户主动键入或按住输入控件时 macOS 接管和发送按键的后台输入；此类操作现在等待安全空闲点，或者在不发送输入的情况下失败。
  • 修复了 macOS 菜单和弹出按钮交互，导致菜单打开或在后台输入完成后将按键发送到用户的应用程序。
  • 修复了当用户的应用程序短暂按下键盘时 macOS 后台操作错误停止的问题，并改进了拖放或远程控制交互后的目标选择。
  • 修复了已发布 Linux 版本中的 Wayland 屏幕截图和依赖于屏幕截图的 click、拖动和滚动。 capabilities() 现在会在捕获不可用时报告，并在缺少 PipeWire 时显示解释性错误。
  • 修复了 Windows 本机 IPC 崩溃，该崩溃可能导致守护进程服务的工具在另一个会话关闭其连接后挂起。
  • 修复了因忽略拒绝 pre-commit 或 commit-msg 挂钩输出而导致的 commitCreate() 错误；现在与 git commit 一致地包含挂钩输出。
  • 修复了锚定在第一个属性或文档注释上的 Rust 块编辑，以便它们覆盖整个项目，而不是被视为单行编辑。

已删除

  • 删除了过时的 wayland-pipewire 货物功能和 OMP_NATIVE_FEATURES 配置变量。

@oh-my-pi/omp-stats

已修复

  • 修复了“增益”选项卡低估了使用 snapcompact 上下文压缩的会话的节省，包括升级后回填最近的压缩历史记录。

@oh-my-pi/pi-tui

添加

  • 任务工具和代理中心行现在对主代理和子代理使用不同的、主题感知的颜色；主题可以选择自定义六种子代理颜色。
  • 添加了表格列和行的自动换行，保留硬换行符，以便长时间的表格内容保持可读。

已更改

  • 改进了终端 UI 响应能力并减少了 CPU 使用率，同时传输长响应、监控事件循环以及启用 macOS 拼写检查的情况下打字。
  • 状态帐户身份现在可以包含可选的凭据 ID，允许将使用情况归因于 API 密钥帐户，并允许在凭据更改时刷新缓存的使用情况。

已修复

  • Ask 表单中的图像现在可以在 Kitty 协议终端（包括 Kitty、Ghostty 和 herdr）中正确呈现。
  • 修正了模型提及后的标点符号，以便它们成为可编辑的芯片而不消耗标点符号。
  • 修复了 /copy 以复制中间结果://回复中的可见散文，包括通过命令发送的回复，而不是工具的内部结果文本。

  • 修复（提交）：在 https://github.com/can1357/oh-my-pi/pull/19474 中的 @alphastorm 正在进行合并或变基时拒绝提交草稿 *修复（编辑）：将apply_patch描述为工具输入，而不是https://github.com/can1357/oh-my-pi/pull/19468中@alphastorm的shell命令
  • 修复（内置）：在 https://github.com/can1357/oh-my-pi/pull/19476 中通过 @alphastorm 匹配相对于工作目录的 rg 锚定 glob
  • 修复（eval）：通过 @alphastorm 在 https://github.com/can1357/oh-my-pi/pull/19470 中的 eval 工具桥拒绝收益
