oh-my-pi v19.1.1

oh-my-pi v19.1.1

@oh-my-pi/pi-agent-core

已修复

  • 通过检测准备好的上下文何时超出目标模型的上下文窗口，防止过大的切换到达提供者。
  • 保留提供者错误状态、错误标识符、重试分类以及失败或取消的辅助轮次的取消标记。
  • 修复了在执行完成之前丢弃或中止时推测工具调用挂起的问题。

@oh-my-pi/pi-ai

添加

  • 添加了 AssistantMessage.requestId，由 Anthropic 的 request-id 响应标头填充，因此失败或拒绝的请求保留 Anthropic 支持所需的标识符。
  • 将 GET /v1/pi/models 添加到 omp auth-gateway，为 pi-native clients 提供网关的模型目录（限制、思维水平、定价）。

已更改

  • Devin 帐户选择现在优先考虑具有剩余每日或每周配额的登录，然后是由按需余额资助的帐户，同时跳过没有可用容量的帐户。 Devin 登录还跟踪电子邮件、用户 ID 和组织，以便在 omp usage 和 auth.accountPolicies 中区分不同的组织；必须重新验证现有登录名才能填充此信息。
  • 提供商的计费失败现在被视为使用限制，允许重试轮换帐户并继续通过模型后备链。
  • 由扩展注册的提供程序使用报告现在在 omp 进程中持续存在，从而避免了不必要的重复使用端点检查。
  • 在提供程序操作期间停滞的请求现在被归类为超时，允许自动回退到另一个模型。
  • 仅当为请求启用扰动时才加载提示扰动数据，从而减少空闲内存使用量。

已修复

  • 修复了拆分工具调用处理，以便配置了 splitToolCalls 的型号以正确的消息顺序接收每个工具调用及其相应结果。
  • 修复了 apple/on-device 完成原因处理，以便请求不再发出虚假的 stderr 警告并正确报告已识别的停止或长度完成。
  • 通过报告模型、提供程序和收到的消息计数而不是不透明的提供程序错误，改进了对空 Anthropic 请求的本地验证。
  • 修复了 OpenAI 和 Codex 请求在包含不受支持的未转义字符模式的 MCP 工具架构上失败的问题。
  • 以未计费的加密推理项结束的 OpenRouter 响应请求现在会显示底层提供程序故障，而不是静默完成。
  • 修复了使用 Portkey 或身份验证网关时跨工具调用保留 Gemini 思想签名的问题。
  • 修复了思维循环防护错误地重试包含长 Markdown 表或类似形状的 JSON 记录的最终答案。
  • 修复了严格的工具模式转换，因此接受任意字段的对象属性不会错误地限制为空对象。
  • 修复了 antigravity-cli 型号无法接收 read 等工具返回的图像的问题。
  • 修复了因中断快照流和禁用进程剩余部分的使用情况报告而导致的暂时性代理错误。
  • 修复了同一帐户的并发反重力 CLI 会话在凭证暂存期间失败的问题。
  • 修复了 OpenAI Codex WebSocket 延续，以便为后续请求保留粘性转向路由信息。
  • 改进了从损坏的 agent.db 中的恢复，以便在可能的情况下恢复可读的提供程序凭据，并且禁用的凭据保持禁用状态。

@oh-my-pi/浏览器中继

已修复

  • 侧面板的连接设置现在显示浏览器拒绝本机主机时的具体原因（例如，因为本机消息传递被企业策略阻止），而不是错误地建议主机可能丢失。

@oh-my-pi/pi-目录

添加

  • Z.AI (zai) 现在会发现可用于您的 GLM 编码计划密钥的模型，因此新发布的 GLM 模型会出现，无需等待目录更新。
  • 在 @oh-my-pi/pi-catalog/models 中添加了 getUpstreamPin() 和 routedModelsAreEqual()，以区分路由到不同上游提供商的聚合器模型。
  • 添加了 @oh-my-pi/pi-catalog/discovery/pi-native 和 piNativeModelManagerOptions()，用于从身份验证网关的 GET /v1/pi/models 读取提供商的模型名册。

已修复

  • 修复了 Llama 3.x 模型在通过基于 vLLM 的主机（包括通过 OpenRouter 的 CoreWeave）提供服务时调用多个工具后轮流失败的问题。
  • 对于共享同一电子邮件地址的组织，Devin 的使用现在是分开的。
  • 更新了 Devin 图像代币会计，以匹配 Devin 发布的跨受支持的 Gemini 图像模型的每张图像 1,089 个代币收费。
  • 更正了 GPT-5.6 Sol、Terra 和 Luna 快速通道的 Devin 定价和上下文限制，包括超过 272K 输入令牌的长上下文速率以及禁用扩展上下文时的标准 272K 限制。
  • 更正了 GPT-5.6 Sol、Terra 和 Luna 模型的游标定价，因此超过 272K 输入代币的输出使用记录的 1.5× 汇率。
  • 关闭 GPT-6.1 Terra 的思考现在使用受支持的 none 推理工作。
  • 修复了 GPT-6.2 和更高版本的 OpenAI Responses 模型在会话修剪和后续工具调用后丢失推理上下文的问题。
  • 修正了 Bedrock Kimi K3.1 Pro Highspeed 推理选项和工作量处理。
  • GitHub Copilot 现在仅列出帐户可用的模型，包括重新启动后的模型。
  • 在捆绑之前发现的 Codex 模型现在使用其格式化的显示名称，例如 GPT-6.2 Sol。

@oh-my-pi/pi-coding-agent

重大变化

  • 本机 shell Rust API 现在将索引变量存储为 IndexedArray 而不是 Vec；使用 items.into() 构造 VarValue::Indexed 值。

添加

  • 添加了选择加入的 tree 状态段，它显示会话在倒带后或在分支上在会话树中的位置；在 Tern 中，当 clicked 时，该段打开 /tree。
  • 通过身份验证网关 (transport: pi-native) 路由的提供程序现在列出网关的模型，因此可以选择网关在运行时发现的模型（例如新的 Codex 模型），而无需在 models.yml 中声明它们，并且隐藏网关无法路由的模型。
  • 添加了 computer.takeover 作为 computer.backgroundFallback 的替代品，并具有 fallback、foreground 和 always 模式，用于控制计算机工具何时接管前台窗口。默认情况下会保留现有的后备行为。
  • 添加了内置的便携式 column shell，其中包含与 util-linux 兼容的选项，包括表格式、命名列、对齐、隐藏、排序、JSON 输出、树显示和宽度控件。
  • 通过 pi.registerTodoBackend() 和 todo.backend 设置添加了扩展待办事项后端。注册的后端可以将会话的完整待办事项列表镜像到外部存储，并且可以从 /settings → 工具 → 待办事项中进行选择和配置。
  • /wt 现在运行新工作树的 post-checkout 挂钩，在 TUI 中显示进度，并加载挂钩创建的技能和命令。失败的挂钩会使工作树保持完整并显示警告。

已更改

  • 空停止恢复现在使用所选模型、提供程序和停止元数据记录每次重试，从而使重复的空模型响应在会话日志中可见。
  • 快速模型选择器在后台刷新过时的提供商目录，因此长时间运行的会话可以发现新的可用模型。
  • 在 Linux 上，语言服务器文件监视现在适应 inotify 监视限制，因此大型工作区不太可能干扰其他文件监视程序和系统服务。
  • eval 工具现在在其提示和超时参数中记录其默认的 30 秒单元截止时间。

已修复

  • 改进了 Magic Edit，使其可以搜索和读取当前草稿，重试失败的替换而不丢失成功的编辑，在写入之前验证语法，并支持以文本形式发出工具调用的模型。
  • 修复了当 bash 被扩展替换时的 shell 工具命令处理，包括支持带有远程或沙盒 shell 的纯工具命令行。
  • 修复了浏览器滚动验证和文档，以便无效的对象形式解释正确的像素增量签名和等效调用。
  • 修复了 ask 对单选按钮使用不同名称的字段集的处理，防止预选选项与用户的选择一起提交。
  • 修复了标题生成，当模型明确使用 <title/> 或 none 来 decli 时停止，同时继续处理下一个错误或不可用回复的候选者。
  • 修复了自动和推测压缩，因此超大或不可重试的切换请求将转移到下一个可用的压缩方法，而不是重复发送到提供者。
  • eval 单元中的 wait() 现在接受显示的子代理 ID，包括 agent://id 表单，同时仍然拒绝属于其他会话的句柄。
  • 修复了启动和会话模型配置，以便思维级别、模型提供者排序、启用模型白名单、路由选择和固定上游路由在模型交换机、cycling、恢复、计划模式和元数据刷新之间保持一致。
  • 修复了当中断的响应被丢弃时排队的后续消息丢失的问题，以及修复了可能导致会话无法继续的 TTSR 中断的问题。
  • 修复了 OpenAI Responses 会话重写之前发送的工具结果的问题，这可能会导致稍后的推理项目被拒绝。
  • 修复了写入格式和符号链接相关的文件编辑问题，包括不正确的写入失败、丢失快照、重复的 local:// 路径以及预览和日志中不正确的符号链接文件名。
  • 修复了当下载的文件被短暂锁定时，Windows 浏览器下载有时会保留临时 GUID 文件名的问题。
  • 修复了 RPC 关闭导致 MCP 子进程在会话结束后继续运行的问题。
  • 修复了顾问和 Spotlight 输出，以便准确表示截断或重复的工具结果，而不会丢失原始内容。
  • 修复了选择默认模型后仍然存在的首次运行启动警告。
  • 修复了上下文翻转处理，以便并发簿记不再默默地删除显式翻转，并且跳过翻转会产生警告。
  • /omfg 现在在成功保存规则后关闭其面板并显示保存的路径；错误使面板保持打开状态。
  • 修复了使用 glob、大括号或命名用户主目录扩展的主要 cd 命令的 shell 处理。
  • Claude 格式的插件代理现在可以正确地将 Claude 工具名称（例如 WebFetch、WebSearch、TodoWrite、AskUserQuestion、MultiEdit 和 Agent）映射到其 OMP 等效名称。
  • 启动扩展通知现在保持可见，而不是被以后的通知或 MCP 启动状态覆盖。
  • 修复了 CLI 解析，因此 --plan 在启动、重新启动、fork 或子命令路由期间不再消耗以下 CLI 标志作为其值。
  • 修复了/usage使用数据库临时锁定时的问题；存储的历史记录仍然可见，并且如果无法刷新，则标记为未同步。
  • 模型发现现在将纯语音和纯转录模型分类为 TTS 和 STT 模型，而不是聊天模型。
  • 被父代理阻止的子代理现在会记录它们被父代理阻止。
  • 修复了 RPC 和 ACP 会话的 SDK 和扩展导入、示例以及特定于会话的扩展发现。
  • 修复了 X 和 YouTube URL 读取，以尊重 SDK 会话设置，即使全局设置尚未初始化。
  • 恢复的会话现在可以正确报告结果未知的后台作业，并且 omp --restore 不再在空闲压缩或中断后重播已完成的回合。
  • 选择性提交现在保留草稿内容和二进制、非文本、超大和 Git LFS 文件的 Git 清理过滤结果，并避免覆盖自草稿创建以来更改的文件。
  • 修复了启用推测执行和 beforeToolCall 挂钩时 read 挂在图像和其他非文本文件上的问题。
  • 提供者错误日志现在包括排除人为拒绝故障所需的请求 ID。
  • 从协作提示开始的会话现在会收到自动标题。
  • 修复了 /tan 分叉在其分配保持阻塞时过早结束空闲等待的问题。

@oh-my-pi/pi-natives

已修复

  • 修复了 grep()、glob()、fuzzyFind()、astGrep()、astEdit() 和递归 shell 搜索命令偶尔挂在具有多个 CPU 的计算机上的问题。
  • 修复了本机搜索、文件匹配、模糊搜索、AST 和编辑操作中可能导致崩溃或释放后使用错误的取消和超时竞争。
  • 修复了 grep() 的匹配限制，报告不完整的结果，而不是在目录遍历失败时拒绝。
  • 修复了从 Bun 缓存安装或独立二进制文件从另一个版本提取本机插件时 @oh-my-pi/pi-natives 无法加载的问题。
  • 修复了 Linux Wayland 对 GTK 对话框、控制值以及选定行、列表项和选项卡的可访问性和自动化支持。
  • 修复了命令退出后 Linux PTY 输出偶尔会包含额外的空行的问题。
  • 修复了在 kitty 键盘协议下 NumLock 关闭时键盘导航键被丢弃的问题。
  • 修复了 Wayland 屏幕截图在等待屏幕共享选择器时错误超时的问题。
  • 通过准确报告不确定的调度并防止在回复等待到期后发送操作，提高了 Windows 辅助功能操作的可靠性。
  • 修复了经典 Win32 和 WinForms 按钮和复选框的 Windows 自动化在不执行 click 的情况下错误地激活应用程序或报告成功的问题。
  • 修复了 macOS 计算机控制接管恢复，以便在自动化结束后正确恢复之前的活动窗口，并在无法确认恢复时报告故障。
  • 修复了 macOS 背景键盘和滚动事件，包括通过 iPhone 镜像发送、丢失或意外激活另一个窗口的事件。
  • 修复了活动键盘布局之外的非拉丁字符和其他字符的 X11 键入问题。
  • 现在，当目标文件与创建补丁的版本不匹配时，二进制补丁将拒绝应用，从而防止意外替换已更改的文件。
  • 在 Windows 上，中止或超时阻塞在打开的空标准输入管道上的进程内实用程序现在会终止它，而无需等待管道编写器。

已删除

  • 删除了当源签出从另一个版本加载本机插件时显示的启动警告；当所需的符号不可用时，不兼容的插件仍然会产生可操作的错误。

@oh-my-pi/snapcompact

已修复

  • 修复了 snapcompact 存档摘要，以便它们准确报告密集中间框架的网格布局。

@oh-my-pi/omp-stats

添加

  • 添加了 readDailyActivity()，用于读取存储的日常活动，而不会被写入统计数据库的另一个进程阻止；当不存在统计数据库时，它返回 null。

已修复

  • 修复了 Spotlight 基线和调整后的净计算，以使用一致的结果集，提高标题和步骤行的准确性。

@oh-my-pi/pi-tui

添加

  • 通过 SettingsRuntimeContext.runtimeOptions 添加了主机提供的设置菜单运行时选项，同时保留了思维水平、主题和作曲家形状的内置选项。
  • 添加了中断元数据，以便主机可以区分父代理终止和用户启动的中断。

已修复

  • 修复了仅模型的上游引脚发生变化时跳过的切换。
  • 修复了 /usage 活动日历在刷新失败时保留其历史记录，同时指示数据未同步的问题。
  • 修复了当问题超出面板范围时 SVG 图像在询问表单中闪烁的问题。
  • 修复了主动转弯状态线，使经过的时间能够以十分之一秒的速度平滑更新。
  • 修复了在选定模型上再次按 Enter 时将模型分配给角色的问题，这可能会错误地删除角色。
  • 更新了快速模型选择器 (Alt+P)，以包括会话开始后添加到目录中的模型，即使会话受到 --models 或 enabledModels 限制也是如此。
  • 修复了当 TUI 和 Tern 在不同计算机上或在没有 Tern 共享文件目录的本地会话中运行时，图像和其他基于路径的文件在 Tern 中显示为不可用的问题。

已删除

  • 删除了OmfgPanelComponent.markSaved和saved面板状态；现在，/omfg 面板会在保存规则后关闭。
