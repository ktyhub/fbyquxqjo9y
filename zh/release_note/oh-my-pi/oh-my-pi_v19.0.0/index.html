oh-my-pi v19.0.0

@oh-my-pi/pi-agent-core

添加

  • 添加了对从模型上下文和压缩或分支摘要中排除自定义消息的支持，同时允许排队的转向和后续消息在排除消息后正确继续。

@oh-my-pi/pi-ai

添加

  • 为 Anthropic Messages 请求添加了 prewarm 流选项，以刷新提示缓存而不生成计费输出；它因预算思维、强制工具选择和结构化输出而被拒绝。
  • Claude 使用情况报告现在包括 metadata.subscriptionPlan 中的帐户订阅计划，支持 Max 5x、Max 20x、Pro、Team 和 Enterprise 计划。
  • 在 discoverAuthStorage 中添加了 retryUnreachableBroker 和 onBrokerRetry 选项，允许主机控制暂时不可用的身份验证代理的启动重试并显示重试状态。

已修复

  • 修复了共享每周使用限制恢复后克劳德帐户故障转移的问题，确保当使用情况报告不再显示该窗口时帐户再次可用。
  • 身份验证代理启动现在可以通过重试最多 30 秒来容忍临时代理重新启动和连接中断，同时仍会因令牌被拒绝或快照格式错误而立即失败。
  • 通过容忍未知的凭证、使用情况以及观察到的使用字段和值，改进了 client 和代理版本之间的身份验证代理兼容性。
  • 修复了 Codex Spark 使用计量表，以便仅通过 metered_feature 识别计量表的报告保持正确的 Spark 模型范围。
  • 修复了可用 ID 包含努力后缀的模型的反重力 CLI 请求，例如仅提供 gemini-4-hydrogen-high 时解析 gemini-4-hydrogen。

@oh-my-pi/pi-目录

添加

  • 通过 isPromptCachePrewarmSupported 兼容性功能在第一方 Anthropic 端点上添加了对提示缓存预热的支持。

已修复

  • 修复了评估超过 32 个问题时对 TypeSafe、OpenRouter、Command Code 和 OpenCode Zen 的托管判断请求。
  • 改进了 Devin 图像处理，以支持提供商限制内的更多对话图像，并更新了 Devin Gemini 模型的图像压缩，以反映其计费令牌使用情况。
  • 修复了 Devin Gemini 模型的定价，以便在促销结束时模型从促销价格切换到标价。
  • 修复了 Kiro API 密钥身份验证（KIRO_API_KEY 和 ksk_…），以便模型列表、聊天和 /usage 请求正常工作。

@oh-my-pi/pi-coding-agent

重大变化

  • 更改了 SDK 缓存预热控制：createAgentSession.cacheWarming 现在接受模式上限“off”、“streaming”或“idle”；该值和providers.cacheWarming 中的较低者适用。使用“off”而不是 false。
  • 将artifact://N 链接替换为会话的local:// 根目录下的可读、可列出且可完成的local://N.log 文件。现有会话中的 artifact:// 链接不会迁移。
  • 将 session.handoff(focus) 替换为 session.compact(focus, { mode: “handoff” });使用 abortCompaction() 取消它。
  • 将共享后台进程整合到一个每用户守护程序下，而不是特定于项目的代理程序下。不采用旧版本的守护进程和服务； omp ps 现在一起报告全局、项目和会话单元，删除 —global，将 —json 输出更改为 {daemon, reports}，并且不再将 ?project= 添加到 dsm:// 句柄。
  • 将 SDK deferSkillDescriptionCompression 重命名为 deferHintCompression，将 startSkillDescriptionCompression() 重命名为 startHintCompression()；这些设置和方法现在还涵盖 MCP 命名空间提示。

添加

  • 添加了内置 MCP 转换，包括 Codex Desktop node_repl 替换。可以使用 mcp.builtinTransforms 禁用内置函数； /mcp list 标识已替换的服务器，而 /mcp enable node_repl 可以显式连接其中一台。
  • 通过 mcp.evalNamespaces 添加了可选的 MCP eval 命名空间，将服务器公开为 JavaScript 和 Python 命名空间，文档位于 xd://eval/。结果保留文本和结构化数据，二进制资源保存为 local:// 文件。
  • 为 /tan 代理及其托盘卡添加了模型生成的名称，并在命名失败或超时时提供可读的随机回退。
  • 添加了可配置的缓存预热策略（自动、保活和压缩），包括长工具调用保活和到期前提示压缩。缓存预热事件现在报告所选方法和成本。
  • 添加了可选的跨实例任务发现和使用 task.crossInstance 进行消息传递，通过 agent://peers 公开相同文件夹实例。
  • 添加了顺便说一句模式：以 ? 开头的草稿提交为 /btw 问题并收到不同的 UI 指示。
  • 添加了用于运行子代理和后台作业的 Tern 实时卡，包括进度、工具计数、状态、控制、脚本以及对已完成代理的恢复访问。
  • 通过 OMP_DAEMON_TCP 添加了守护程序更新生存和可选 TCP 托管，在守护程序升级过程中保留正在运行的服务、PTY 和语言服务器。
  • 每台机器加载一次语音到文本和文本到语音模型，并在 15 分钟不活动后卸载它们。
  • 添加了对 /wt、项目恢复选择器和 omp 工作树列表/清除的 ovnfs 工作树支持，同时在签出删除后保留源存储库中的会话恢复。
  • 添加了克劳德订阅计划以进行使用和/使用输出。
  • 添加了后台技能描述和 MCP 命名空间提示生成的进度报告。
  • 在 pi.sendMessage 有效负载中添加了 exceptFromContext，以便扩展可以显示和保存每轮消息，而无需将其发送到模型。
  • 在身份验证代理重新启动或短暂不可用时，为 CLI 和打印模式命令添加了 30 秒的重试窗口。
  • 向 bash 工具添加了一个通知选项，用于报告后台命令和命名服务的匹配输出、唤醒空闲会话或结束阻塞的等待。

已更改

  • 改进了与 Anthropic 兼容的提供程序的缓存预热，在支持的情况下提供无输出预热，并根据实际重播成本进行计费；现在，当启用流加热时，​​任务子代理会在长时间工具调用期间保持提示缓存温暖。
  • 每台机器生成一次技能描述和 MCP 命名空间提示，跨 omp 窗口共享结果和进度。
  • 切换模型时保留思维水平，仅在所选模型无法支持当前水平时进行调整；仅当未设置级别时才应用模型默认值。
  • 延长重复回复和子代理等待以使用会话的提示缓存生存期，并在适当时使子代理等待跟随实时父级的下一条消息。
  • 使 /handoff 作为后台压缩运行，同时保留当前响应和新到达的消息。
  • 将询问提示重新设计为编辑器上方的单个滚动表单，保留部分答案并允许用户通过发送消息跳过待决问题。
  • 默认启用作曲家预测，在完成回合后显示活动模型建议的下一条消息；在“设置”→“交互”中禁用它们。
  • 默认情况下在打印、RPC、ACP 和 SDK 会话中禁用工具调用意图跟踪；使用tools.intentTracing 或PI_INTENT_TRACING 启用它。
  • 更新了 ovnfs 签出指南和 git 防护消息，以解释如何着陆、拉取或放弃更改。
  • 改进了子代理完成探测和侧面请求，以便它们专注于可交付成果，而不包括作为简单历史的静态流推理。
  • 标准化等待行为为 5 秒初始空闲等待，然后是 4 分钟连续等待。
  • 始终为子代理提供共享 LSP 工具； task.enableLsp 现在仅控制 LSP 格式化和编辑诊断。
  • 改进了 bash 服务、PTY 和嵌入式 shell，具有会话环境继承、会话文件 URL 支持、更清晰的就绪验证和更透明的最小化输出。
  • 在窗口中运行时清楚地命名托管 Chromium，并改进跨选项卡和浏览器后端的浏览器、屏幕截图、上传、框架、选择器、网络和 CDP 行为。
  • 通过逐字替换主体改进哈希线编辑，更安全的范围和路径验证，更清晰的解析和语法诊断，支持更大的文件和 SSH 文件，以及更可预测的原始读取和行选择器。
  • 通过十分钟的工具调用截止时间、报告进度时的更长截止时间、更清晰的超时和连接错误以及过期 HTTP 会话后的一次重试，提高了 MCP 可靠性。
  • 通过便携式内置程序和内部 URL 支持扩展了嵌入式 shell，支持常见工作流程，包括文件检查、归档、过程控制、环境加载、文件监视、锁定、语音、打开文件和补丁应用。
  • 改进了 LSP 和调试诊断、语言覆盖范围、工作区检测、引用、重命名、代码操作和服务器生命周期报告。
  • 改进了评估工具，包括 Python 3.9+ 验证、UTF-8 执行、软件包安装刷新、完整工具结果、协议文件访问、线程化 Python 帮助程序以及更清晰的内核丢失和超时消息。
  • 改进了提交草稿和摘要，以更准确地处理挂钩、修改操作、工作树、过滤器、行结尾、大型未跟踪树、审查文件和 JavaScript/Python API 奇偶校验。
  • 改进了 URL、存档、GitHub、Terraform 注册表、包文档、Web 搜索和远程文件处理，包括过滤、分页、二进制转换、存档成员访问和更清晰的提供程序错误。
  • 改进了使用情况和帐户策略报告，以便订阅限制和范围耗尽能够准确识别受影响的计划或计量表。
  • 改进了工作树、进程、等待、代理消息传递、会话恢复、内存保留、Spotlight、Windows shell 和 macOS 性能行为。

已修复

  • 修复了 MCP 资源链接和二进制资源，以便它们仍然可以作为可读文件或内联内容进行访问，而不是被删除或仅显示为占位符。
  • 修复了预提交挂钩和部分先前提交之后的提交草稿，以便索引、差异、选定的块、修改的父项、审查文件和生成的摘要保持准确。
  • 修复了异步工作、子代理或对等消息运行期间的自动后见之明和 Mnemopi 保留，防止重复或重叠保留。
  • 通过报告等待者和依赖链、向排队的代理传递消息以及正确处理终止、驱逐、恢复或空输出作业，修复了阻塞的代理和等待。
  • 修复了跨统一守护进程升级的会话恢复和流程结果处理。
  • 修复了子代理、自动思考会话和手动调整级别的思维级别显示和模型切换器行为。
  • 修复了工作树克隆、ovnfs/Git 转换、服务准备情况检查、shell 环境继承、Windows 连接删除、进程替换、校验和以及后台命令取消。
  • 修复了跨屏幕截图、clicks、填充、选项卡、框架、对话框、上传、CDP 端点、陈旧连接、并发评估、浏览器启动、视口模拟、clipboard 和特定于平台的输入的浏览器自动化可靠性。
  • 修复了哈希线、AST 编辑、生成文件检测、编号内容、远程文件编辑、语法诊断、路径处理和行结束行为。
  • 修复了 eval 内核、Python 和 JavaScript 帮助程序、包导入、嵌套工具调用、内部 URL 和移动的工作目录。
  • 修复了 LSP、语言服务器启动、诊断、引用、重命名、代码操作、项目加载、文件类型和调试器适配器选择。
  • 修复了命令输出摘要，以便保留相关上下文、元数据、Git 输出、测试计时、AWS 输出、lint 诊断和二进制检测，而不是错误分类。
  • 修复了跨选择器、过滤器、分页、存档、二进制内容和提供程序故障的读取、grep、glob、URL、存档、SQLite、视频、RSS、GitHub、包文档、SSH 和 Web 搜索处理。
  • 修复了待办事项操作、询问兼容性和超时行为、图像生成验证、GitHub PR 推送、计划提案以及侧通道模型调用的会话统计。
  • 修复了 MCP OAuth 重新身份验证错误，以公开注册端点、状态详细信息和补救措施，并修复了身份验证代理关闭问题，以便安全保存刷新的令牌。
  • 修复了 Spotlight 重试和帐户处理，包括候补帐户、速率限制、中断和请求识别。
  • 修复了跨平台 shell 和桌面行为，包括 macOS 启动和重绘性能、Windows 文件操作和应用程序查找、语音输出和桌面打开。

@oh-my-pi/collab-web

已修复

  • 修复了没有综合答案的网络搜索卡显示原始编号结果列表的问题；他们现在显示每个来源的简洁摘录。

@oh-my-pi/pi-natives

添加

  • 添加了 VcsGitRepo.worktreeToGit() 以将工作树内容转换为 git add 生成的 blob 表示形式。
  • 添加了对使用 Shell 作为进程 shell 的支持，通过进程的标准流路由命令，同时保留进程会话和外部命令的终端。
  • 添加了 ShellRunOptions.speech 以将主机语音处理程序连接到 shell 的 say 命令。
  • 添加了一个内置的进程内 file shell，具有广泛的文件类型检测、MIME 和编码输出、存档/图像/文档支持以及与常用 file 命令选项的兼容性。

已更改

  • 改进了 iPhone 镜像中的打字和按键响应能力，将每个字符的延迟减少了大约一半。

已修复

  • 修复了 Wayland 和 X11 上部分离屏 Linux 窗口的屏幕截图，以便正确捕获可见区域和基于坐标的缩放目标。
  • 修复了没有可用输入路径的桌面上的 Wayland 输入操作会立即失败并出现明显的 PermissionDenied 错误，而不是首先尝试不必要的屏幕捕获的问题。
  • 修复了 macOS computer 交互，以便后台 click、按键、弹出菜单操作和接管呼叫恢复呼叫中先前活动的窗口。
  • 修复了 macOS 弹出菜单在键入后立即读取的问题，以便它们反映输入字母所选择的选项。

@oh-my-pi/omp-stats

重大变化

  • Spotlight 恢复将从本地溢出文件读取的数据计入恢复计数；从旧会话中的工件引用中读取的内容继续像以前一样计数。

添加

  • 扩展了概述的令牌组合，以包括转录外模型调用（例如标题生成、工作说明、法官查询和缓存预热）以及每个源请求计数、令牌总数和使用份额。
  • 在概述中添加了决策模型卡，显示本机判断模型的判断用例的请求、令牌和使用份额。
  • 标题生成和法官调用的请求详细信息现在显示生成的回复或记录的法官答案。

已更改

  • 主代理、子代理和顾问的代币混合份额现在仅反映对话次数，不包括侧通道模型调用。

已修复

  • 通过拒绝通过未配置的公共主机名发出的请求，强化了仪表板以防止 DNS 重新绑定。 IP 地址、本地主机、LAN 短名称、本地网络域和 Tailscale 名称仍然受支持；使用 OMP_STATS_ALLOWED_HOSTS 配置反向代理或其他自定义域，包括通配符子域，例如 *.example.com。

@oh-my-pi/pi-tui

重大变化

  • 完整输出参考和 [raw output: …] 页脚现在使用 local://N.log 而不是 artifact://N。

添加

  • 添加了 btw 作曲家模式，包括所有捆绑主题中的 btwMode 主题颜色。
  • 为运行时子项添加了功能门控本机对接，允许组件仅出现在宣传所需功能的终端上。
  • 添加了在剥离内联 Markdown 时保留字内下划线以及在选定作业上打开 JobsSheet 的选项。
  • 自定义消息有效负载现在可以从模型上下文中排除，同时在标准化和恢复的已保存条目中保持可用。
  • 添加了通过运行后台作业和服务报告的输出的转录块。

已更改

  • 将询问对话框重新设计为单个堆叠流程：活动问题保持打开状态，而已回答的问题则折叠成紧凑的摘要，并且所选选项可见。这适用于终端和本机界面，并改进了键盘导航、大小调整和主机编辑器集成。
  • 改进了询问对话框挂起时的作曲家行为：作曲家指示在那里键入将跳过问题，在适当时折叠到紧凑状态，并为绕过询问的草稿提供明确的“跳过和发送”操作。
  • 添加了对折叠和微弱的作曲家状态的支持，以及界面等待答案时更清晰的视觉指示。
  • 模型搜索现在支持 provider/model 查询，优先考虑精确的提供商匹配并首先搜索该提供商的模型 ID。

已修复

  • 通过将所有输出分组到一个标题下并显示完整的行，改进了 Tern 中的后台作业通知。
  • 修复了 Tern 作曲家对 -> 和 => 的处理，这样输入它们就不会再意外地插入换行符。
  • 修复了没有综合答案的网络搜索结果，以简洁干净的摘录显示每个来源一次。
  • 修复了长 Tern 工具批准提示，以便其详细信息在可用窗口内滚动，并且选择和批准/拒绝控件保持可见。
  • 修复了表格图表单位显示和缩放单位测量的变化因子计算。
  • 修复了复选框组，因此在未选择任何内容的情况下按 Enter 键首先会检查焦点框。
  • 询问表单现在打开每个问题及其预选答案，允许 Enter 接受建议而不替换它。

@oh-my-pi/pi-utils

添加

  • 添加了使用 local://N.log 格式格式化和解析会话溢出 URL 的实用程序。
  • 添加了 postmortem.exitCleanlyOnStopSignals()，以便长时间运行的服务在 SIGINT 或 SIGTERM 上完成清理后成功退出。

已修复
