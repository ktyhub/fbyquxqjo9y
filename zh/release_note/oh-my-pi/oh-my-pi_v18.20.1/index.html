oh-my-pi v18.20.1

oh-my-pi v18.20.1

@oh-my-pi/pi-agent-core

已修复

  • 更正了省略推理历史的请求的上下文成本估计，因此计费估计现在仅在为工具调用发送或重构时才包括思考文本。

@oh-my-pi/pi-ai

添加

  • 将 setUnpausedProviders() 添加到 @oh-my-pi/pi-ai/oauth，允许应用程序重新启用因身份验证规则而暂停的提供程序；加载的凭证池和扩展登录会在下次读取时识别更改。

已更改

  • 更新了 Vertex AI Gemini 请求以使用 v1beta1 API，恢复对长 Gemini 响应的支持。
  • 改进了 Google 反重力配额恢复，以便在共享 Gemini 容量可用时，在配额或计划更改后可以恢复 Gemini 4 Argon 访问。
  • 改进了 Amazon Bedrock 区域选择，以在回退到 us-east-1 之前遵循配置的区域终端节点。

已修复

  • 修复了跨 Google、Vertex AI、Gemini CLI 和 Antigravity 超出单个输出段的 Gemini 4 响应，确保长响应继续生成并作为一个完整回复传递。
  • 修复了光标对话，以便钩子添加的提示内容保留在当前用户消息中，并且对话上下文在轮流中正确保留。
  • 修复了 Amazon Bedrock 流，因此格式错误的响应会立即失败，并且会重试中断的响应，而不是将其视为完整的响应。
  • 修复了当使用报告仅包含一个共享使用窗口时克劳德帐户恢复的问题。
  • 修复了 OpenRouter 与 Kimi 和 DeepSeek 的对话，以便在切换模型时保留推理上下文。
  • 修复了小米 MiMo 令牌计划身份验证以使用正确的区域端点，包括从捆绑或缓存配置加载的模型。
  • 修复了登录流程和设置向导中登录的困惑，包括电子邮件代码和基于浏览器的 SSO 身份验证。
  • 停止本机判断重试由耗尽的上游凭据引起的网关错误，同时保留对其他暂时性 502 错误的重试。
  • 修复了简单的完成和经过身份验证的网关聊天路由，以便支持的提供商接收停止顺序和频率惩罚设置。
  • 修复了凭证更改、密钥轮换或空闲恢复后的 Muse 会话，以便后续轮次可以正常继续。

@oh-my-pi/pi-目录

添加

  • 在 Google Antigravity 上添加了 Gemini 4 Hydrogen 作为单一模型，具有可选择的低、中、高和 xhigh 思维水平，价格为每百万代币 $1.50/$7.50。
  • 添加了 Chutes 提供程序支持，支持实时模型发现和使用 CHUTES_API_KEY 的 /login chutes 身份验证。

已更改

  • 暂停谷歌反重力：登录不再可用，并且在重新启用提供商之前不会使用存储的凭据。请改用 GEMINI_API_KEY 与 Google AI Studio 或 google-vertex 提供程序 (#18341)。
  • 更新了命令代码模型定价和使用报告，以匹配提供商的当前费率，包括 Claude Haiku 5.5、GPT-6.1 Sol 和 Terra、Grok 4.7 和 Claude Sonnet 5.5 的长上下文定价层。
  • 将 Gemini API 和 Vertex AI 上的 Gemini 4 氩气、碳和氢的最大输出增加到 262,144 个代币，从而实现更长的响应。
  • 更新了 OpenCode Go Claude Haiku 5.5 以支持从低到最高的思维水平，包括显式思维障碍。
  • 更新了 Devin 请求，将其标识为 Devin CLI 3000.12.57，即当前的稳定版本。

已修复

  • 修复了命令代码上的 Gemini 4 Argon，以便保留图像附件，并按每百万输入令牌 2 美元、每百万输出令牌 10 美元和每百万缓存读取令牌 0.10 正确计费（#19125 by @wolfiesch）。
  • 修复了工厂 Droid GPT-6 模型在基岩或雪花会话期间改变思维水平后在下一回合失败的问题（#19188 by @will-bogusz）。
  • 修复了受工作空间限制的 API 键的 OpenRouter 模型列表，以便每个键显示其正确的允许模型名册并维护独立的模型缓存（#19013 by @YibaiMeng）。
  • 修复了 OpenCode Go Muse Spark 工具调用在步骤之间丢失加密推理的问题（#17748 by @nico2525nn）。
  • 修复了 Vertex AI Gemini 3 和更新的模型拒绝缺少思想签名的重播或跨模型工具调用的问题（#17150 by @duck1eee）。
  • 修正了光标模型列表，省略了提供者可用的模型，包括 GLM 5.3 和 Grok 4.7 (#18248 by @joseotaviorf)。

@oh-my-pi/pi-coding-agent

添加

  • 添加了 /commit 以创建仅包含代理或选定子代理所做的更改的提交，同时保留其他代理和用户的工作。该工作流程还可以通过 eval commit 命名空间使用，支持会话目录之外的目标存储库，处理二进制和非 UTF-8 文件、符号链接、文件模式更改和初始提交，并且可以选择使用 no_verify 跳过提交挂钩；使用 commit.enabled 禁用它。
  • 添加了 auth.unpausedProviders（未暂停的提供商设置），以重新启用已暂停的提供商（例如 Google Antigravity），风险由您自行承担，同时保留其存储的登录状态。
  • 通过 todo.midRunNudges 添加了可配置的长轮待办事项提醒，包括禁用提醒、将提醒限制为两次或继续增加间隔的选项。
  • 将样式内容粘贴到编辑器中现在可以保留 Markdown 格式并将嵌入图像放置在其原始位置，而从编辑器复制的代码仍保留纯文本。
  • 添加了 session_clear 挂钩和扩展事件，当 /clear 重置当前会话上下文而不更改其会话 ID 时发出。
  • 通过 bash.allowedEnvVars 和每规则 env 设置添加了路径范围的 Bash 允许规则、项目和配置覆盖优先级以及环境变量控制。
  • 子代理现在在继承模型时保留 @upstream 提供程序固定。
  • 添加了使用删除键从 Ctrl+R 历史记录中删除单个提示的功能。
  • 添加了 --no-judge、--no-spotlight 和 --offline 选项来限制或禁用活动模型提供商之外的辅助服务。
  • 添加了每规则 TTSR repeatMode 设置（once、after-gap 或 always）来控制提醒重复。
  • Bash 批准提示现在单独显示复合命令段，并确定哪些段是允许的或需要批准的。
  • Todo done、drop 和 rm 操作现在在单个请求中接受多个任务，包括换行符、分号、逗号或空格分隔的输入，而无需拆分精确的任务名称匹配。
  • 当涉及多个目标时，待办事项状态行现在会显示任务计数。

已更改

  • /fork 和 fork-from-transcript 现在会中止主动响应并立即分叉。
  • 通过仅显示匹配行并限制每个文件的匹配来减少默认 grep 输出；配置 grep.contextBefore 和 grep.contextAfter 以包含周围的上下文。
  • 将默认的 spotlight.thinking 级别从 low 更改为 med，以便以更高的请求成本进行更深入的结果分析和改进的排名。
  • 启用 Spotlight 后，通常会在大纲之前重新读取源代码并更完整地显示问题或拉取请求内容，包括对其他源文件类型的支持。

已修复

  • /loop 现在在出现提供商错误（例如速率限制）后暂停，而不是重新提交相同的提示并再次附加其 @file 提及（#19272）。
  • 现在，恢复已删除目录的会话将在当前目录中继续，但会出现警告，而不是失败。
  • 模型提及和 /switch 补全现在在提供程序发现在启动时失败后恢复发现的模型，并在需要时重试发现。
  • ACP 提示结束后到达的后台作业结果现在将带入下一个提示，而不是开始一个不可见的回合。
  • OpenAI 服务器压缩失败现在会继续使用下一个可用的压缩方法，而不是在另一个模型上重试服务器压缩。
  • 语言服务器现在可以识别文件创建后不久所做的编辑，包括在 macOS 上。
  • 伪 shell 视图中显示的 Bash 命令现在在流式传输此处文档、替换、循环、延续、算术表达式和后台执行时保持准确。
  • 在使用思维后缀（例如 :xhigh）重试回退后恢复会话或恢复子代理现在会恢复主要模型自己的思维水平，而不是保留回退的（[#19273]（https://github.com/can1357/oh-my-pi/issues/19273））。

@oh-my-pi/collab-web

已修复

  • 修复了重新加入失败后客人保留陈旧代理、工具卡和工作状态的问题；现在，访客在重新连接时可以可靠地恢复当前会话状态。

@oh-my-pi/pi-natives

重大变化

  • 更改了 lsTree() 以返回 { path, mode } 条目而不是裸路径； mode 与 git ls-tree 输出匹配（例如，100755 或 120000）。

添加

  • 在 commitCreate() 选项中添加了 noVerify 以跳过预提交和 commit-msg 挂钩，与 git commit —no-verify 匹配。
  • 为 commitCreate() 添加了乐观并发和备用索引支持，允许提交使用单独的索引，并在 HEAD 更改时拒绝过时的提交。
  • 通过使用可用的服务守护进程，改进了 ovnfs 签出的 grep() 和 glob() 性能，同时保留本机后备行为和现有的流、过滤和链接跟踪选项。

已更改

  • 改进了跨本地和网络文件系统的 shell 搜索：本地搜索避免意外遍历网络挂载，网络支持的搜索同时执行更多目录操作，fd 支持并行遍历以及忽略、修剪、深度、工作和错误报告选项。

已修复

  • 修复了由 diffText({ binary: true }) 和 diffNoIndex(…, true) 为非 UTF-8 文本（例如 Latin-1）生成的二进制补丁，因此补丁保留原始字节并正确应用。
  • 修复了通用字体系列引用不可用字体时的 SVG 渲染，防止 元素消失。
  • 修复了包含只读文件或目录的源签出的工作树添加，包括跟踪目录被符号链接替换的情况。
  • 修复了取消和超时的 Shell.run 调用，以便它们仅终止由该调用启动的作业，同时保留 shell 会话以供以后运行。
  • 可视化长的多行 shell 命令时减少了内存使用量。
  • 修复了 shell cp 内置选项，以便符号链接跟随选项可以在存档和目录复制模式下正常工作，而无需禁用递归或属性保留。
  • 替换了 [ ] 中很长的 -a/-o 链上的内置 shell 崩溃问题，并针对过深的表达式给出了明显的错误测试表达式。

@oh-my-pi/omp-stats

已修复

  • 修复了“跟踪”选项卡计时，以便后台作业显示其实际完成时间，包括准确的空闲时间和轮转持续时间。
  • 修复了 Frustration 页面上每个模型的消息计数，以包含所有已答复的消息。
  • 通过在 Spotlight 重建时保持其他页面和实时状态可用，提高了仪表板响应能力。
  • 修复了每日使用情况图表，以按用户的本地日历日而不是 UTC 对活动进行分组。

@oh-my-pi/pi-tui

添加

  • 当工作分配给多个目标时，将任务计数添加到待办事项状态行。
  • 在 Tern 中复制 Composer 草稿时保留粘贴的图像。
  • 添加了通过按 Ctrl+R 搜索字段末尾的删除键从历史记录中删除所选提示的功能。
  • 使用注册的扩展方案为 Markdown 链接添加了独特的主题，并为未定义新颜色的主题提供了静音后备。
  • 通过区分允许的和需要批准的段并在需要批准的第一个段打开，改进了复合 Bash 命令批准对话框。
  • 添加了一个可选的分支操作来聊天，包括 BTW 历史记录表中的 b 快捷方式。

已修复

  • 修复了从解释 shell 视图切换到原始命令行的异步 Bash 命令。
  • 改进了切换到子代理、恢复会话或重建长记录时的记录呈现，以便立即显示最新消息。
  • 修复了 Markdown 任务列表显示已完成和打开项目的错误复选框状态的问题。
  • 修复了 iTerm2 在报告带内调整大小时将终端调整大小数据插入到 Composer 中的问题。
  • 改进了在终端上等待工具或模型而没有同步输出时的工作行动画，包括 tmux 3.6。
  • 修复了扩展的 IRC 工具卡以显示完整的软包装输出，并向包含隐藏文本的折叠卡添加了扩展提示。
  • 修复了在列表中间附近导航时 /resume 会话选择器中过早滚动的问题。

@oh-my-pi/pi-utils

添加

  • 添加了 mixHex 用于混合两种十六进制颜色。

已修复

  • 改进了 Cloud Code Assist 配额重置信息的提取，包括复合持续时间和重置时间戳，以提供更准确的重试指导。
