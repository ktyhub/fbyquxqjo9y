oh-my-pi v18.21.0

小版本 发布时间2026年11月16日 来源can1357/oh-my-pi 英文原文

oh-my-pi v18.21.0

@oh-my-pi/pi-ai

添加

  • 添加了对以前未知模型的思维能力的自动检测，具有持久的结果并支持替代工作和令牌预算请求格式。

@oh-my-pi/pi-目录

添加

  • 添加了 Modal 作为托管推理提供程序。

已更改

  • 将本地语音模型从 Kokoro 更改为 Phonon 31M。
  • 通过保留未经验证的思维级别支持并使用特定于端点的探测结果（如果可用）来改进推理能力检测。

已修复

  • 修复了 xAI Grok OAuth 模型 grok-composer-2.5-fast 被错误识别为非推理的问题；它现在支持从最低到最高的思维水平。

@oh-my-pi/pi-coding-agent

重大变化

  • 更新了 AgentSession 运行生命周期 API：当运行无法再恢复时，会发出一次 agent_end，并且 agent_pause 报告在等待工作时停止的运行。将 hasPendingAsyncWork()、settleAsyncWork() 和 suppressAutoResumeUntilPrompt() 替换为 isRunActive、wakeSources 和 waitForRunEnd()。现在调用 abort() 也会结束后台工作暂停的运行； RPC、JSON 打印、协作和扩展流保留其现有的每循环 agent_end 行为。

添加

  • 添加了通过 task.agentPrewalkAuto 的可配置自动子代理预走，允许每个代理 on/off 设置或模型模式，同时保留无条件子代理预走。
  • 未知的自定义和发现的模型现在自动检测推理支持并记住支持的推理工作水平以供将来的会话使用。
  • 添加了内联图像和网页回复：支持的终端可以显示本地、数据和 HTTP(S) 图像和嵌入页面，而其他终端则接收链接后备。添加了 tui.renderEmbeds 以禁用此渲染。
  • 在Tern回复中添加了交互式嵌入页面，包括click访问和退出返回导航；接受常见的主机、路径和 file: URL 形式。
  • Bash 重定向现在可以写入所有可写的内部 URL，包括作业取消端点和处理程序支持的 agent://、cfg://、ssh:// 和 xd:// URL。
  • 通过 acceptImages 添加图像粘贴到 ask 表单注释和 ui.formDialog 选项；粘贴的图像使用 [Image #N] 标记返回，并针对纯文本模型进行描述。不支持的提示现在明确拒绝图像粘贴。

已更改

  • 将默认的本地文本转语音模型更改为 Phonon 31M，以实现更快的合成、更小的下载和更多语音。现有的 Kokoro 语音设置会自动迁移；语速范围现在从 0.8× 到 1.3×。
  • Tern /btw 响应现在在请求时显示为折叠的交互式注释，并具有后续、复制、分支、注入和停止操作； /btw在没有提示的情况下仍然打开历史视图。
  • 重叠的 Bash 调用现在共享 shell 状态，包括变量、函数、别名、选项和陷阱，并且由这些调用启动的后台作业继续独立运行。
  • 通过 extensions 或 disabledExtensions 启用或重新配置的扩展现在加载到活动会话中，无需重新启动。
  • 在批准引导期间或在对话框中进行的富文本粘贴现在在插入聊天编辑器时保留 Markdown 格式和图像。
  • 在另一个项目中移动任务或恢复会话现在会切换其代理、扩展、自定义工具和 MCP 服务器以匹配目标项目，而无需重新启动。 ＃＃＃ 固定的
  • 修复了状态指示器错误地将代理显示为空闲而子代理或后台工作仍可以恢复运行的问题。
  • 修复了子代理仍在运行或排队的对等消息保留时完成的子代理和安全扫描。
  • 修复了选定一侧为空或与周围代码共享边缘线时的冲突区域解决方案。
  • MCP stdio 服务器在响应之前出现故障现在报告进程退出代码或终止信号，而不是仅报告关闭的标准输出。
  • 修复了预走切换，以便保留模型和推理工作更改，并且当自动预走更改或禁用时，自动切换将返回到规划模型。

@oh-my-pi/pi-mnemopi

已更改

  • 通过减少检查点期间不必要的磁盘同步、降低跨多个进程共享的存储体的每轮 I/O 开销，提高文件存储体性能。

@oh-my-pi/pi-natives

添加

  • 添加了用于设备上 Phonon 文本转语音的 PhononTts 绑定。
  • 添加了 Shell.adopt(fork) 以将已完成的 fork 中的变量、函数、别名、选项和陷阱应用回其父 shell。当两个 shell 都设置名称时，最后完成的命令的值将被保留。

已修复

  • 修复了并发 commitCreate() 调用错误地覆盖彼此的提交主题和正文。

@oh-my-pi/pi-tui

添加

  • 添加了使用 acceptImages 打开时将图像粘贴到 HtmlFormDialog 选项注释中的支持，包括图像附件、删除以及通过 OptionNote.images 访问保留的图像。
  • 在支持的终端的助手回复中添加了实时网页和图像渲染，包括内嵌图像和嵌入页面预览。添加了 /btw 转录注释，用于在不中断主要对话的情况下共享副主题。

已更改

  • 改进了推理能力发现，因此等待发现的模型遵循会话的思维默认值，并除了禁用和努力级别设置之外还提供自动思维。
  • 将公共 html-form/media API 重命名为 media，包括 loadMedia、Media 和 MAX_MEDIA_BYTES。

已修复

  • 修复了后备模型选择，因此仅向角色提供他们可以使用的模型，排除不兼容的图像和语音模型。
  • 修复了 shell (!) 和 Python ($) 草稿的 macOS 拼写帮助、自动更正、替换和单词完成。

@oh-my-pi/pi-utils

已修复

  • 修复了当韩语、日语或中文文本后面带括号的 URL 后面不带空格时，裸露 URL 会吞没以下单词的问题。
