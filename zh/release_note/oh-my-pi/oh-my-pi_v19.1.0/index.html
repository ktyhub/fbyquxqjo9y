oh-my-pi v19.1.0

oh-my-pi v19.1.0

@oh-my-pi/pi-agent-core

添加

  • 通过 Agent.setStandbyTools() 和 AgentContext.standbyTools 添加了备用工具支持，允许工具保持不活动状态，直到请求明确启用工具使用。

@oh-my-pi/pi-ai

添加

  • 添加了提供商挂钩（@oh-my-pi/pi-ai/provider-hooks 中的 setProviderHooks），它取代了提供商的流适配器或图像生成，同时其模型保留了 api。
  • 添加了选择加入提示扰动：模型可见的提示散文和工具描述使用从覆盖每个静态系统和工具提示行的承诺释义池中选择的每次安装措辞。型号支持 prompt-perturbation KDL 轴； OMP_PROMPT_PERTURBATION=1/0 强制其打开或关闭。

已更改

  • 游标提供程序转发 bash 而不是 write，因此可以最终确定分阶段预览
  • 将提供商流看门狗默认时间从 5 分钟增加到 15 分钟，防止缓慢的一次性完成过早中断。
  • 扩展的 Gemini 推理流保护，允许在中断之前进行更长的计划序列。

已修复

  • 代理支持的凭证存储现在检测代理存储的登录信息，但不提供服务并将其保存在本地 agent.db (HybridAuthCredentialStore) 中，而不是在下一个快照时丢失它；仅代理 RemoteAuthCredentialStore 上传失败并显示 AuthBrokerUnservedProviderError。
  • OpenAI Codex 请求不再发送 session_id 和 conversation_id 标头；会话仅以 session-id 形式发出，就像 Codex CLI 一样，因此拒绝下划线标头名称（Envoy、nginx 默认值）的代理会传递它们（#20018）
  • 对于在工具结果之后折叠用户消息的模型，当用户消息遵循工具结果时，保留了预期的对话结构。
  • 当 422 超出预算响应禁用当前密钥时，LiteLLM 请求现在会轮换到另一个配置的 API 密钥。 (#19860)
  • GPT-6.2 系统提示现在通过第三方响应代理作为领先的开发人员消息发送，从而启用提示缓存并避免后续回合中不必要的全速率输入费用。 (openai/codex#62312)
  • 改进了跨请求格式的思维模式检测，避免不必要的重试并正确记住服务器接受或拒绝的格式。 (#19758 作者：@eggpeat)
  • 可能导致访问令牌在下次重试之前过期的身份验证刷新失败现在会显示警告，而不是仅在调试日志中可见。 (#19590 作者：@will-bogusz)
  • 聊天完成现在保留仅在 reasoning_details 中返回的推理，包括来自 Bifrost Gemini 的推理。 （#19595 作者：@Xytronix）
  • 反重力配额耗尽现在报告为 429 速率限制错误，允许正确应用配置的重试、凭证轮换和模型回退行为，而不是将响应视为辅助文本。 (#19382 作者：@gimso2x)
  • 人为请求现在在对话中稍后激活工具时保留提示缓存，避免不必要的系统提示和记录缓存重写。 (#19826)

@oh-my-pi/浏览器中继

重大变化

  • omp 扩展程序现在使用固定的 Chrome 扩展程序 ID，并通过其本机主机连接到浏览器中继。使用 Chrome 的“加载解压”流程重新安装扩展程序；中继端口和令牌选项已被删除。

添加

  • 添加了 omp Chrome 侧面板，其中包含会话模型选择、角色快捷方式、思维控件、输入快捷方式、消息队列和运行中断控件。
  • 添加了浏览器交互功能，包括页面覆盖、图像和元素选取、教学、预定快捷方式和 GIF 导出。

已更改

  • Chrome 侧面板显示具有结构化意图的工具步骤的简短标签。
  • 该扩展现在可以在 omp 升级和闲置时重新加载时保持已注册安装的最新状态。
  • 浏览器中继端口自动分配并由终端 clients 在本地发现，而侧边栏聊天则继续使用其现有连接。
  • 侧面板会话现在直接控制连接的 Chrome 浏览器，而不是打开单独的无头浏览器。

已修复

  • 改进了中继恢复，因此当本机主机不可用或过时的连接断开时，Chrome 会自动重新连接。

@oh-my-pi/pi-目录

重大变化

  • 删除了内置 Gemini CLI OAuth 提供程序 (google-gemini-cli)。 Google Antigravity 和 Antigravity CLI 仍然可用。

添加

  • 添加了运行时提供程序规则（compat/cascade 中的 setRuntimeProviderRule）。他们将 KDL 指令应用于一个提供商的模型，通过捆绑规则赢得联系，并在规则发生变化时清除规则派生的缓存。
  • 添加了 prompt-perturbation 目录轴，它将提供商或模型选择为每次安装提示释义。
  • 为所有主机上的 GPT-6.2 型号添加了 uncached-instructions 兼容性标志，将系统提示移出未缓存的响应 instructions 字段。

已修复

  • 修复了 Vercel AI Gateway 模型刷新问题，以便在存储的 API 密钥过期时公共模型仍然可被发现。
  • 修复了需要推理但不宣传努力水平的 OpenRouter 模型；禁用思维的请求现在使用最低支持的推理工作而不是失败。
  • 修复了当消息在工具结果后立即到达时，Gemini 4 模型（氩、碳、氢和氖）会失败并出现空的格式错误的响应。
  • 更新了新服务的 Cursor 模型的定价，以使用其记录的每个代币费率，而不是报告为免费。
  • 修复了 Codex client 版本缓存，使其缓存文件存储在配置的 $XDG_CACHE_HOME/omp 目录下。

@oh-my-pi/pi-coding-agent

重大变化

  • 用工具命令替换了 xd:// 工具设备：很少使用的工具现在作为 bash 命令运行（<tool> --help、<tool> <args>），而 bash 处于活动状态并且在其他情况下是普通工具
  • 将 tools.xdev、tools.xdevDocs、tools.xdevInlineDevices 和 tools.xdevNotices 设置重命名为 tools.commands、tools.commandDocs、tools.commandInline 和 tools.commandNotices
  • 分阶段预览、计划提交和自动 QA 报告现在使用 resolve、reject、propose 和 report_issue 命令，工具文档主题从 xd://<tool>/<topic> 移至 help://<tool>/<topic>
  • 删除了tui.completeScrollback设置； HUD、对话框或草稿覆盖的记录行现在总是向后滚动，并且当覆盖关闭时输入返回到底行。
  • 替换了独立的 MCP 传输和工具缓存 SDK 导出，并删除了 DeferredMCPTool 以及 MCP 缓存和重新连接策略管理器选项。现在可以通过 MCP 主机 API 访问 MCP 服务器。
  • 当 Chrome 打开时，浏览器中继托管现在通过 omp 扩展程序的本机主机运行。删除了按需 omp browser-relay 服务器命令及其 --port、--token 和 --no-group 选项； browser.relayUrl 仍然可用于从另一台机器转发的中继。升级后重新加载 omp 扩展一次，或重新启动 Chrome。
  • 更改了 archive.search(query) 以在所有历史记录中搜索会话标题、空闲回顾和用户/助理内容并返回匹配的会话记录；使用 archive.prompts({ query }) 进行仅提示搜索。搜索与单词开头的查询词相匹配。
  • RPC 主机必须将 ask 工具作为一个完整的 HTML 表单 form 请求进行处理，并以提交的数据或取消进行响应；不再发出逐个字段的提示。

添加

  • 扩展可以通过 registerProvider 接管内置提供程序：stream 替换其请求适配器，generateImage 替换其图像生成，webSearch 替换其接地搜索请求，discoverModels 替换其模型发现请求。 rules为其模型设置KDL规则指令（例如prompt-perturbation）。
  • 添加了 magic 编辑模式，该模式接受 # path 标题下分组的 Markdown 项目符号更改描述，并使用可配置的快速模型或角色来生成和应用补丁。它支持简洁的块替换、删除、移动和标识符重命名描述，并显示结果差异。
  • 通过 RPC 添加了远程会话模型控制，包括模型选择器、思维级别和角色选择、auto 思维以及在传递排队消息时恢复、中止或继续主机代理的命令。协作来宾现在可以继续、中断主机的后续提示并对其进行排队。
  • 在斜杠分隔的 secrets.yml 正则表达式中添加了对 Unicode 设置模式 (v) 的支持。
  • 将 MCP 服务器移至 omp 守护程序，并提供可选的跨会话进程共享、延迟启动、空闲关闭、共享发现缓存以及包括进程和会话信息的 /mcp list 状态。配置与mcp.shared的共享和与mcp.idleStopMinutes的空闲关闭。
  • 添加了 MCP 协议修订版 2026-07-28 支持，包括服务器发现、每个请求元数据、根输入轮次、订阅和缓存控制，同时保留与需要初始化握手的服务器的兼容性。
  • 为 Chrome 扩展添加了本机浏览器中继集成，包括侧面板会话、扩展安装和同步、自动配置文件注册和选项卡内操作叠加。除非明确恢复，否则侧面板会话与终端恢复、最近会话、--continue 和 ACP 会话列表保持分离。
  • 为 omp gallery --segment status 添加了彩色扩展状态变体。
  • 添加了当 bash pty 中运行的程序等待键盘输入时的通知和等待状态，例如密码或确认提示；使用 pty.notify 禁用通知。
  • Eval completion() 现在记录用于 /debug 检查的原始提供程序帧，并将失败调用的帧保存为会话工件目录中的日志文件。
  • 将 parentToolCallId 添加到扩展 tool_call 和 tool_result 事件中，以便嵌套工具调用可以与调度它们的 eval 单元或内核定义的工具相关联。
  • 添加了 archive.search 的全文转录搜索索引，涵盖会话历史记录中的用户和助理消息。
  • 会话文件现在记录批准请求及其结果，允许仪表板和侧边栏显示会话何时等待工具批准。
  • 添加了对后台 bash 作业重定向到文件的输出的实时可见性，包括作业流、作业表、作业小部件和命令卡；选择命令会显示其相关管道或重定向流的输出。
  • 添加了 Binary Ninja 作为读取分析视图和 dsm 命名空间的反汇编器后端。使用 disassembler.backend = binja 选择它，并使用 binja.installDir 或 $BN_INSTALL_DIR 配置其安装。
  • Clicking 本机终端主机（例如 Tern）中的使用限制段现在打开 /usage。更改 Tern 的代理托盘设置会立即在托盘卡与正在运行的代理和作业计数器之间切换，而无需重新启动 omp。

已更改

  • 命令打印为 kitty 或 Sixel 图形的图像除了附加之外，还保存到临时文件中并在 bash 输出中链接
  • generate_image 将其图像作为附件返回
  • Spotlight工具调用使用Label: detail；活动仅显示标签，而输出排名则使用完整意图。
  • 改进了 TTSR 和秘密编辑扫描的正则表达式性能，包括 SIMD 加速和更快的候选匹配，而无需更改匹配语义。
  • 提高了列出所有项目中的会话时的性能，尤其是具有数千个项目目录的会话。
  • 交互式 wait 现在在首次调用后台作业时等待最多四分钟，而不是在五秒后返回。
  • 将 MCP OAuth client 名称更新为 Codex。
  • 减少自动重试的干扰：失败的尝试不会出现在记录中，重试状态会解释原因，而成功的恢复只会留下简短的指示。
  • 选择性提交现在可以更准确地归属编辑工具和 shell 内置更改，区分外部程序更改以进行审查，并使用更小的更改日志。长行提交预览现在仅突出显示更改的单词，同时保留原始补丁。
  • 不能中断流的 TTSR 规则在相关响应、推理或工具调用结束时进行评估，减少不必要的工作，同时保留匹配和提醒。
  • Eval completion() 现在接受用户标记的模型代理，例如用 ^model 固定的模型，并使用其标记的工作水平。
  • read 将 SQLite 支持的 .i64 和 .idb 文件识别为 IDA 数据库，并清楚地报告反汇编程序后端不匹配情况。

已修复

  • 从未完成的流留下的未完成的工具卡不再使记录的其余部分无法回滚并压缩为一行；下一个回复开始时关闭
  • 即使代码大纲再次被剪切，Spotlight 也会保留来自多个大型函数体的简短相关段落及其签名。
  • 即使没有 Retry-After 标头，retry.maxDelayMs 内的使用限制重置现在也会等待。
  • 配置身份验证代理时登录不再报告代理存储但不提供服务的提供商的成功（例如旧代理暂停的提供商）；登录信息保存在本机的 agent.db 中，重新启动后仍然存在，并且登录/注销现在名称保存凭据。
  • Spotlight 在长结果和大代码轮廓中保留与其邻居的更多高相关性行，同时在窗口预算内保留可见的意图匹配。
  • 修正了 Tern 托盘卡和子代理实时预览，在代理运行时或模型切换后显示陈旧的调用、模型或思维状态；完成的卡片现在保留所使用的模型和思维水平。
  • 修复了扩展侧面板会话启动 omp 自己的浏览器而不是仅驱动用户的 Chrome 窗口的问题。
  • 恢复、压缩或重建成绩单后，在 Tern 中保留答案页脚和复制控件。
  • 阻止 --continue 和 autoResume 附加到当前由另一个 omp 进程写入的会话。
  • 在 /handoff 编写摘要时添加了可见的进度报告。
  • 修复了对 macOS iCloud Drive、桌面和文档、Google Drive 和 Dropbox 位置上仅云文件的访问。
  • 防止病理 TTSR 条件和秘密编辑正则表达式冻结会话或请求。
  • 修复了 IRC 唤醒子代理和上下文挂钩提供初始消息的会话的提示缓存处理。
  • 改进了 shell rg 和 fd 路径输出和选项处理，以匹配其本机工具，包括以 ZZPH100​​ZZ 开头的路径、空分隔输出和显式当前目录前缀。
  • 修复了不完整操作、数字 || 表达式、嵌套或部分块结尾、JSDoc 注释以及带有尾随空格的哈希线标题的草率编辑验证和块匹配。
  • 修复了 mcp.servers 中的 OpenCode v2 MCP 配置发现，同时保留对传统平面 mcp 条目的支持。
  • 修复了 ovnfs.path 包含 Windows 反斜杠、空格或 $ 字符时的 ovnfs 命令。
  • 停止因记录 URL 凭据、查询字符串、OAuth 设备代码或片段而导致浏览器启动失败。
  • 修复了 web_search 以遵守为当前会话配置的搜索顺序和排除。
  • 修复了 Microsoft Entra 服务器的 MCP OAuth 刷新，其中 client 也是资源；以前保存的凭据可能需要一个 /mcp reauth。
  • 修复了每次呼叫子代理和角色使用的 OpenRouter 路由变体的模型解析。
  • 修复了共享会话中的秘密编辑，因此不会意外保留提供者加密的推理。
  • 修复了具有环境分配和标志的复合命令的 bash 批准处理，包括通配符允许规则。
  • 修复了在提交挂钩期间 HEAD 发生更改以及多个编写者的编辑被重新排序或重叠时的选择性提交；现在，不明确的更改将被发送以进行审查，而不是被重复或默默地误用。
  • 修复了存档记录，以包含所有带有 null 的记录密钥以查找缺失值。
  • 修复了内联 bash/eval 输出和请求超时恢复不必要的空会话日志文件。
  • 改进了针对行、范围和列选择器的 read 建议，并为内存中和转换后的文本读取保留了源行元数据。
  • 修复了涉及重复 ID、待处理消息、关闭和恢复的代理生命周期竞争。
  • 修复了 CDP 引擎上的浏览器选项卡处理，每个页面使用单独的连接，包括超时或工作程序退出后的恢复。
  • 修复了仅覆盖 click、包含内联 SVG 或 MathML 的隐藏框架以及根据关键事件更新的搜索字段的浏览器交互报告。
  • 修复了最小化 macOS 窗口和完全覆盖 Windows Chrome、Edge 和 Electron 窗口的浏览器计算机使用检查。
  • 修复了 Anthropic 上的 /goal 不必要地重写缓存的系统提示和记录。
  • 通过尽早拒绝并识别可用的工作树，而不是在没有可用工作树的情况下启动，修复了裸 Git 存储库中的隔离任务子代理。
  • 修复了 Nix 浏览器中继构建以获取所有依赖项，而无需回退到 npm 注册表。
  • 修复了包含 ? 的路径的扩展、插件、自定义工具、挂钩、命令和共享脚本加载，并提供了识别路径和补救措施的有用错误。

@oh-my-pi/collab-web

添加

  • 增强的访客协作 API：GuestClient.sendPrompt 现在支持发送图像，而 sendResume、sendDeliverQueue 和 followUp 选项可以继续主机的代理、中断它以传送排队的消息或排队后续提示。

已更改

  • 工具命令在 bash 调用内运行，呈现为 bash 卡下的嵌套卡
  • 共享会话和 HTML 导出中的工具卡显示简短的意图标签，而不是详细的排名说明。

@oh-my-pi/pi-mnemopi

已修复

  • 改进了配置的嵌入提供程序失败时的诊断，使提供程序错误在日志中可见，同时保留现有的回退行为。

@oh-my-pi/pi-natives

添加

  • 向 Shell.run (commands) 和 shellReservedCommandNames() 添加了主机提供的会话命令

已修复

  • 修复了当右大括号前面没有分号时，分组的 sed 脚本（例如 1{h;d};2{G}）被拒绝的问题。
  • 修复了当 HOME、PI_NATIVES_DIR 或安装路径包含 ? 时本机插件无法加载的问题。
