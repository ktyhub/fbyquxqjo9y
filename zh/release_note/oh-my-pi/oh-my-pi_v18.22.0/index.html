oh-my-pi v18.22.0

小版本 发布时间2026年11月16日 来源can1357/oh-my-pi 英文原文

oh-my-pi v18.22.0

@oh-my-pi/pi-ai

已修复

  • 修复了带有大参数的 Gemma 工具调用速度缓慢的问题。

@oh-my-pi/pi-coding-agent

重大变化

  • 将二进制分析从独立的 ida 和 ghidra 工具移至后端中性 dsm 命名空间 (xd://eval/dsm)。
  • 将 ida.enabled、ida.maxOpen 和 ida.idleCloseSec 设置替换为 disassembler.backend、disassembler.maxOpen 和 disassembler.idleCloseSec；共享反汇编程序数据库 API 现在可在 @oh-my-pi/pi-coding-agent/disasm 下使用。

添加

  • 新增Tern计划审阅编辑和评论：双click计划对其进行编辑，选择文本添加Google Docs风格的评论，并将评论发送到Refine。
  • 添加了 Ghidra 支持，在明确请求分析时自动设置 Ghidra、JDK 和 PyGhidra；自动模式使用已安装的 IDA Pro（如果可用），否则回退到 Ghidra。
  • 添加了对通过 db.handle() 和 dsm.open(handle) 与子代理共享实时分析数据库的支持。
  • 在 worktree.onExit 中添加了 Force Remove 选项，可在不提示的情况下删除会话创建的工作树，包括具有未提交更改的工作树；新的提交保留在工作树分支上。

已更改

  • 更新了 Tern 计划审查，包括单个批准控件、注释感知优化选项、模型选择和保存操作，该操作可在保持审查打开和计划模式活动的同时写入计划。
  • 普通可执行文件读取现在显示 Mach-O、ELF 和 PE 元数据，无需打开分析数据库或下载后端；请求概述、功能详细信息或 dsm.open() 以开始分析。
  • 改进了模型切换器（Alt+P / /switch），具有提供商过滤和每个交换机思维级别选择。在 Tern 中，它现在在作曲家上方打开，带有集成搜索、提供者和任务/主过滤器以及思维级别滑块。

已修复

  • 删除或移动项目内的大型目录树不再阻碍语言服务器文件监视（#19490 by @H4vC）。
  • 随着会话的增长，减少了长时间运行的子代理的 CPU 和内存使用量（#19486 by @H4vC）。
  • 修复了 commit.draft() 错误地将通过 bash 或 eval 删除或重命名的文件分类为“不是你的”；它们现在出现在“审核”下。

已删除

  • 删除了旧的独立反汇编工具及其相关的提示说明。
  • 从 Tern 计划审查表中删除了“复制”和“在编辑器中编辑”按钮；请改用选择复制和双 click 编辑。

@oh-my-pi/collab-web

已修复

  • 改进了协作查看器中的流性能，防止长回复在收到时逐渐变慢。

@oh-my-pi/pi-natives

重大变化

  • TtyWriter 现在需要消耗阈值和回调，并且仅支持独立可重新打开的 TTY。保守地报告其未决的 UTF-8 字节边界。

已更改

  • 更有效地处理大型终端重绘，减少 JavaScript 线程工作并在输出耗尽后释放过大的缓冲区。

已修复

  • 修复了停滞的终端编写器在关闭后继续发出输出或泄漏文件描述符的问题。
  • 修复了跨块边界保留 Unicode 的终端输出并安全地替换格式错误的代理序列。

@oh-my-pi/pi-tui

重大变化

  • 支持输出背压的终端现在必须实现 onOutputDrain(callback)，它返回取消订阅函数；没有背压的终端可以省略pendingOutputBytes和onOutputDrain。
  • 更新了 PlanReviewOverlay 选项以使用 PlanReviewOverlayChoice 对象并将选项 ID 报告给 onPick 和 selectOption。优化和保存操作现在反映了计划反馈和保存行为；删除了disabledIndices和externalEditorName，并更新了describe以接收DescribeContext。

添加

  • 为 ModelPickerComponent 添加了可配置的模型搜索位置、提供程序范围和可选的思维级别滑块；选定的思维水平通过 onPick 元数据报告。本机选择器表现在支持锚定、范围样式、级别显示和图标操作。
  • 添加了本机计划审查文档，并与可编辑和可评论的计划、报价注释、计划编辑通知、批准、保存和取消操作以及模型选择对接。

已更改

  • 当选择提供商时，提供商范围现在仅显示所选提供商的模型，范围 cycling 能够返回完整模型列表。
  • 更新了思维级别控件以使用左右箭头键，并刷新了滑块和页脚提示演示。
  • 将计划保存叠加层重新命名为“保存计划”并更新了其操作标签。

已修复

  • 修复了缓慢滚动和输入长代理记录的问题。
  • 修复了长度超过 256 行的草稿中打字和光标移动缓慢的问题。

@oh-my-pi/pi-wire

添加

  • 添加了用于工具提示和可访问名称的可选选择器图标，以及控制搜索界面位置的选项。
  • 添加了按钮、菜单和文档组件类型，包括菜单行操作状态更改和文档文本编辑、注释和取消注释事件。

发生了什么变化

  • perf(coding-agent): 停止复制https://github.com/can1357/oh-my-pi/pull/19486中@H4vC的每个发布者刷新的完整消息列表和日志
  • perf(tui)：在 https://github.com/can1357/oh-my-pi/pull/19488 中停止编辑器包装缓存抖动和 @H4vC 的完整视觉线重建
  • perf(ai)：在https://github.com/can1357/oh-my-pi/pull/19487中通过@H4vC增量扫描Gemma带内工具调用
  • perf(coding-agent)：忘记LSP文件观察器中消失的目录，而无需@H4vC在https://github.com/can1357/oh-my-pi/pull/19490中进行全面扫描
  • perf(collab-web)：在 https://github.com/can1357/oh-my-pi/pull/19485 中通过 @H4vC 进行流式传输时保留已完成的 Markdown 块的 DOM
  • perf(tui): 在 https://github.com/can1357/oh-my-pi/pull/19489 中重用 @H4vC 绘制之间的代理记录查看器行 完整 Changelog：https://github.com/can1357/oh-my-pi/compare/v18.21.0…v18.22.0
