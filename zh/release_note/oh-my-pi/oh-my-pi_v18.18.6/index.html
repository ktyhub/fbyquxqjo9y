oh-my-pi v18.18.6

修订 发布时间2026年11月9日 来源can1357/oh-my-pi 英文原文

oh-my-pi v18.18.6

@oh-my-pi/pi-目录

已修复

  • LiteLLM 仅列出配置的密钥可以调用的模型（其经过身份验证的 /v1/models），并为它们保留代理的元数据； /v1/models 失败的代理现在不列出任何模型，而不是列出它所服务的每个模型（#18601）

@oh-my-pi/pi-coding-agent

添加

  • 在 Tern 中，手机上回合的长按菜单可以编辑和重新发送提示、重试回合、打开其上的倒带页面或将会话从其分叉到新会话中
  • 从记录中倒带显示它下降了多少回合，并在 Tern 的吐司上提供“撤消”功能，这会将回合和草稿放回原处

已更改

  • Chrome 选项卡中的浏览器 role/ 选择器现在与 Chrome 的可访问性树报告的角色和名称相匹配，因此它们可以到达开放的影子根并跳过隐藏的元素；在 Tern 中，每个名称 observe() 报告都会再次选择其元素（#18632 by @will-bogusz）

已修复

  • 先前提供商的后期使用限制错误不再阻止或冷却所选提供商；当旧提供者用完重试预算时，重播安全回合仍会尝试所选模型，而不会出现旧配额延迟（#17098、#17571 by @Bensonluo)
  • Tern 中的多问题提问表单在最后一个问题选项卡上显示“提交”，而不仅仅是在“审阅”选项卡上
  • 使用 !command 的 MCP headers 和 stdio env 值现在在 401/403（请求重试一次）、/mcp reconnect 和其他重新连接以及 /mcp reload 上再次运行，因此其命令铸造短期令牌的服务器在过期后继续工作，而不是保持 401 直到重新启动(#18631)
  • 暂停未批准的计划不再告诉代理草稿已批准或继续执行它，并且使用 /plan 暂停会关闭开放计划审查，因此它无法再保存和执行计划（[#18610]（https://github.com/can1357/oh-my-pi/issues/18610））。
  • 关闭 lsp.enabled 现在还会阻止 write 和 edit 启动语言服务器进行诊断或格式化；之前仅禁用了 lsp 工具（@yuzu-octopus 的 #18205、#18490）
  • 修复了背景选项卡 omp 借用（中继 app.target、app.cdp_url）忽略 omp 的 click 和按键或悬停和拖动时超时；该页面在 omp 驱动时读取为可见，并在释放后再次隐藏（#17831 by @will-bogusz）
  • 修复了在流式回复期间向后滚动时文字记录在屏幕顶部边缘跳跃的问题，以及回复完成时屏幕丢弃两行的问题（#12307、#16117 by @galtamam-cmyk）
  • 当快速工具转动在上一个回复的链接完成解析之前完成时，聚焦子代理或返回主会话不再丢失或冻结下一个助手回复，并且在切换期间到达的消息和工具运行按顺序显示一次（#18564 by @eggpeat）
  • omp gc --strip 现在保留最新重播回合的每个响应（包括由工具结果连接的早期工具调用步骤）、仅供参考的图像以及记录的文件权限（#18636 by @eggpeat）
  • 其条目没有 id 写入的会话文件在加载时会重新索引，并且迁移旧会话不再为两个条目提供相同的 id (#18636 by @eggpeat)
  • wait 和 write proc://<id>/kill 现在说明已解决作业的结果如何到达调用者：由调用本身传递（在调用运行时完成），由此快照移交（它取代了作业的排队完成推送，因此不会出现重复），或者真正延迟 - 最后一个保留其“未自动传递；由此快照恢复”警告，并添加调用完成之前的时间(#16052、#18635 作者：@yuzu-octopus)
  • 修复了在选择答案登陆上一问题（而不是显示的问题）后立即添加 n 的 ask 注释； Tern click 然后 Note 仍将答案记录为 clicked，Note 按钮将其命名为 (#18317 by @DonMikone)

@oh-my-pi/pi-natives

已修复

  • 修复了 X11 上的 GTK4 应用程序，例如文件 (Nautilus)：元素 clicks 和 computer.elementAt() 现在可以在屏幕上找到其元素，并且 ax() 不再标记其启用的控件 (disabled) (#18643 by @will-bogusz)
  • grep 不再搜索其自身输出重定向到的文件，也不再搜索从同一文件重定向的标准输入：两者都被 input file is also the output 拒绝，就像 GNU grep 所做的那样（#14808、#16489 by @yuzu-octopus)

@oh-my-pi/pi-tui

添加

  • wait 结果的 JobSnapshot 现在带有 settledAtMs （运行稳定时的纪元毫秒，仍在运行时不存在），因此快照可以告诉调用期间完成的结果与从较早的、从未交付的完成中恢复的结果（#18635 by @yuzu-octopus）
  • 添加了 thinking.set 作曲家操作，以便 Tern 的手机工作菜单可以一键选择思考级别
  • 添加了“全部”、“正在运行”、“完成”和“已停放”状态范围以及对座席中心名册的计数，因此 Tern 的手机可以按状态过滤座席
  • 提示和转弯的答案列出了手机长按（actions.hold）的操作：复制、编辑和重新发送（提示）、重试转弯、倒回到此处……以及从此处分叉；桌面保留其悬停工具栏
  • click 或点击本机倒带页面上的回合即可选择它，并且倒带选择器可以在给定回合上打开（startAt）
  • 状态通知可以在其本机 toast (StatusNoticeAction) 上带有一个按钮，例如倒带后撤消

已修复

  • 修复了在工作行向上时流式传输行在回滚之前被 cli 移到屏幕上方的问题，因此回滚终端会看到行在屏幕的顶部边缘跳转，并且当运行结束时整个屏幕会下降（#12307、#16117 by @galtamam-cmyk）。 Composer.setRuntimeChildren 采用 billedChrome 选项，根部按当前高度计费，而不是穿过地板。
  • 修复了流式回复的行以及比屏幕高的表格的顶行，在启用 tui.completeScrollback 的情况下从屏幕和回滚中丢失的问题；这样的表格现在保留其超出屏幕时的列宽（#16355 by @galtamam-cmyk）

@oh-my-pi/pi-wire

添加

  • actions.hold (TspMenuEntry[])：除了actions.menu之外，长按触摸屏还可以提供什么功能；和 toast 的 action / label 用于吐司上按钮的道具
