oh-my-pi v18.20.3

修订 发布时间2026年11月16日 来源can1357/oh-my-pi 英文原文

oh-my-pi v18.20.3

@oh-my-pi/pi-ai

重大变化

  • 从 providers/cursor-pi-args 中删除了公共 isXdDevicePath 导出。 xd:// 文档的远程读取现在使用标准行选择器行为。

已修复

  • 修复了 Mistral 和其他 OpenAI 兼容提供商的速率限制处理，因此没有可用配额的请求会立即失败，并出现建议模型或计划更改的可操作错误。
  • 修复了对 Claude 池帐户的 Anthropic OAuth 请求，以报告准确的设备和帐户信息，包括在请求期间轮换凭证之后。

@oh-my-pi/pi-目录

添加

  • 添加了公开可用的图像大小调整帮助程序，用于在坐标映射之前确定模型提供的图像尺寸并将图像拟合到指定的长边。

已修复

  • 修复了 DeepSeek V4 Flash 删除的图像输入，恢复一致的多模式图像支持。
  • 将 Mistral GLM 5.3、GLM 5.3 Flash 和 Mistral Large 4 的推理工作选项限制为这些模型支持的级别。

@oh-my-pi/pi-coding-agent

重大变化

  • 将浏览器 tab.clickAt() 选项从 clickCount 重命名为 count，以匹配 tab.click()。
  • 当针对模型缩放屏幕截图时，浏览器视口屏幕截图坐标现在使用显示的图像坐标；传递 css: true（或 { x, y, css: true } 用于拖动点）以显式提供视口 CSS 像素。
  • 添加了选择加入 mnemopi.recallRelevance（off、auto 或 on；默认 off），以使用 judge 角色过滤任务相关性的自动内存调用。
  • 添加了 bash.patterns 和 bashInterceptor.patterns 的路径范围条目，按工作目录解析。项目和 --config 覆盖现在将这些规则添加到全局规则之前，而不是替换它们。
  • 添加了 bash.allowedEnvVars 和每规则 env 列表，以允许在匹配的 allow 规则上显式命名的环境变量前缀。
  • 子代理现在保留 @upstream 提供程序固定在继承的模型上。
  • 添加了 --no-judge、--no-spotlight 和 --offline 选项，以将辅助服务限制为活动模型的提供商或禁用跨提供商服务。
  • 添加了每规则 TTSR repeatMode frontmatter（once、after-gap 或 always）以覆盖全局重复策略。
  • 复合 bash 批准提示现在单独显示每个命令段，区分允许的段和需要批准的段。
  • 删除了 seance 代理、/seance 命令和任务工具的 sourceSession 参数。

添加

  • 为非对称和指令调整的嵌入模型添加了 mnemopi.embeddingQueryPrefix 和 mnemopi.embeddingInputType 配置，包括需要 input_type 的提供程序。

已更改

  • 浏览器屏幕截图以 CSS 像素形式传送到模型，最大可达支持的未缩放尺寸，使视口屏幕截图坐标可直接用于浏览器操作；缩放指导仍然适用于缩放的整页和元素捕获。
  • 浏览器 waitForUrl、waitForResponse 和 requests({ filter }) 现在支持 URL 字符串中的 * 全局模式，而其他字符串保留子字符串匹配。
  • WebKit 浏览器引擎现在自动安装并更新到最新的稳定 ABKit 版本，版本化安装允许更新而无需等待现有浏览器主机退出。
  • 改进的浏览器响应能力和恢复：无响应的 WebKit 页面会因可操作错误而快速失败，导航可以恢复繁忙的页面，浏览器操作可为超时、关闭选项卡、不受支持的事件侦听器、无效路由、cookie 数据和视口更改提供更清晰的诊断。
  • 在 Ctrl+R 搜索字段末尾按“删除”将从历史记录中删除所选提示。
  • /copy 现在可以在查看子代理和该子代理副本的副本时工作。
  • 当所有判断请求失败时，find 现在返回未排名的文字关键字匹配。
  • take() 和 drop() 现在拒绝不存在的大块单位，并出现明显错误。
  • edit 拒绝消息现在建议文件的当前标签，并且在冲突解决之前所做的编辑会延续到已解决的文件。
  • /marketplace 和市场安装/卸载命令现在报告选取器和目录加载错误，而无需退出会话。
  • ACP 会话尊重 client 声明的 MCP 服务器的 mcp.startupTimeoutMs，并且 ACP 表单引出不再不必要地重复字段标签。
  • 现在保留每个 task.steps 子代理步骤的任务进度，而不仅仅是最后步骤的报告。
  • 将 HTML 粘贴到编辑器中现在可以保留 <pre> 块内的纯空白内联元素和缩进中的空格。
  • 使用 Alt+Up 编辑的排队后续消息将恢复为排队消息，而不是发送到活动回合。

已修复

  • 通过抑制助手弃用警告并保留更新的函数元数据 API，修复了 IDA 9.5+ 上的 ida exec 输出。
  • 过期的 Perplexity 登录和 cookie 不再返回错误页面作为搜索答案；该提供商被报告为已过期，并且搜索链仍在继续。
  • 修复了 Chrome 和 Chromium 157 及更高版本上的浏览器 WebMCP 发现和调用。
  • 现在，在文件工具访问它们之前，Ask 和 always-ask-cached 可以正确处理用尾随点编写的私有主机。
  • 修复了从打开的工具批准提示切换会话时 TUI 冻结的问题。
  • 修复了 /commit 和 eval commit 在更改跟踪和选择性提交期间丢弃 UTF-8 BOM 或错误处理引用和 Unicode 文件名的问题。
  • 修复了粘贴图像或 clipboard 为空时误导性的 Wayland ZZPH100​​ZZpboard 警告。
  • 通过将会话工作线程与会话的构建相关联，修复了就地 Linux 升级后的 JavaScript 评估。
  • 删除无法删除的会话不再删除其提示历史记录和统计信息。
  • 修复了 xd:// 设备 URL 上行选择器的 read 和 write 处理。
  • 修复了 eval wait() 拒绝或错误处理数字延迟的问题；浏览器等待现在将用户引导至适当的等待助手。
  • 修复了浏览器 open，具有现有的 Arch Chromium 配置文件、Tern 导航、封闭的外部 Tern 块和停靠的 Tern 视口模拟。
  • 修复了 Tern 和 WebKit 浏览器调用错误地暴露不受支持的页面事件侦听器 APIs 的问题；错误现在识别支持的替代方案。
  • 修复了浏览器超时和繁忙页面错误，以包括当前 URL、受影响的选项卡和可操作的恢复指南。
  • 修复了 Mnemopi 嵌入失败被默默降级为关键字搜索的问题；提供程序错误现在会产生警告，包括在 stderr 上的打印模式下。

@oh-my-pi/pi-mnemopi

添加

  • 为指令调整和非对称嵌入模型添加了可配置嵌入查询前缀和输入类型，包括 Qwen3-Embedding、E5 和 NVIDIA NIM。
  • 添加了 embeddings.onRequestFailed 回调，允许主机处理和显示失败的嵌入 API 请求。

@oh-my-pi/pi-natives

已修复

  • 提交或写入树现在可以正确报告未解决的索引冲突，而不是默默地忽略冲突的文件。
  • 修复了与 GNU grep 的行尾锚定模式（包括 -o 和 -z 模式）的 shell 兼容性，并更正了多字节字符行上的 sed 替换。
  • 修复了包含空格和其他需要引用的字符的文件名的本机差异和补丁处理，包括二进制更改。

@oh-my-pi/pi-utils

已修复

  • 修复了获取和粘贴 HTML 的 HTML 到 Markdown 转换，以保留内联元素中的空格，维护预格式化块中的代码缩进，并避免在块元素之间插入杂散的空白行。
