oh-my-pi v18.19.0

oh-my-pi v18.19.0

@oh-my-pi/pi-ai

添加

  • 为 Liquid AI 决策模型添加了 liquid-systemone 判断 API，包括在提交之前拒绝超过 Liquid 10,000 个 32×32 补丁请求限制的图像集的验证。

已修复

  • 修复了 Gemini CLI 和反重力响应丢失或乱序思想签名和回复文本的问题，包括工具调用后的响应。
  • 修复了 Gemini CLI 和 Antigravity 将回复文本合并到思想签名周围，在回复开始时或工具调用后删除签名，并将思想放在在其之前流式传输的回复文本之前的问题（#18942 by @JustasMasiulis）
  • 修复了 Google Antigravity 通过不消耗配额桶来判断 Gemini 模型的问题：Gemini 3.x 请求忽略 Gemini 4 Argon 每周桶，Argon 请求忽略 gemini-weekly，因此耗尽或低桶不再阻止、保留或限制其他模型的帐户 (#16104)。

@oh-my-pi/pi-目录

添加

  • 添加了 Liquid AI 提供商对 d1.1 和 d1-ultra Judge 模型的支持，以及使用 LIQUID_API_KEY 通过 /login liquid 进行 Liquid 身份验证。

已修复

  • 修复了 Google 反重力 Gemini 4 Argon 模型共享一般 Gemini 配额范围而不是其专用的每周存储桶 (#16104)。

@oh-my-pi/pi-coding-agent

重大变化

  • 更改了浏览器open API：ignore_https_errors现在为insecure，allow_file_access已被删除，file:页面可以访问其他本地文件。
  • 将浏览器 open 和 targets app 选项从对象更改为字符串或 CDP 端点/可执行路径。使用 argv 代替 app.args，使用顶级 target 代替 app.target。
  • 删除了task.file和任务工具的taskFile字段；现在必须内联提供子代理指令。
  • 删除了被阻止的待办事项任务和 blocked 状态/阻止程序元数据。现有被阻止的任务将恢复为待处理。

添加

  • 添加了 systemPromptTemplates，它将模型选择器模式映射到 Handlebars 模板文件以自定义系统提示。切换模型时，模板会重新渲染，并针对丢失或无效模板发出警告并回退到捆绑提示。
  • 通过 task.steps 添加了有序的多步骤任务。子代理依次接收步骤，最后一步决定任务结果；中断的任务将继续执行剩余步骤。
  • 添加了 Liquid AI 判断模型 liquid/d1.1 和 liquid/d1-ultra，包括根据 Liquid 的请求限制调整图像大小。
  • 为 GitHub Actions 手表添加了每步进度、状态和持续时间报告，具有可扩展的详细信息和本机 Tern Surface 协议视图。
  • 添加了 task.autoParallel（off、suggest 或 on）来识别可以并发运行的子任务，并可选择在单个并行任务调用中委托它们。
  • 向 bash 工具添加了便携式 awk、tar、lsof、shasum、md5 和 strings 支持，包括 Windows 支持和内部 URI 路径。

已更改

  • 浏览器会话现在更喜欢捆绑的 ABKit WebKit 引擎（如果可用），并具有自动安装和 SHA-256 验证功能。 WebKit 提供有头的、用户可见的选项卡和更广泛的浏览器兼容性； Chromium 仍然是后备方案，可以使用 app: "chromium" 显式选择，而 app: "webkit" 需要 WebKit。使用 browser.webkit 和 browser.webkitPath 或相应的环境变量配置此行为。
  • 浏览器可见性控件现在立即显示或隐藏 WebKit 选项卡窗口。有头的 WebKit 选项卡可以直接交互，而 Chromium 选项卡保留其现有的模式切换行为。
  • 在具有本机 DOM 访问的 Tern 环境中，浏览器观察和交互使用跨框架和封闭阴影根的 trusted 本机输入，以及插入符感知类型和不区分大小写的文本选择器。
  • edit.modelVariants 现在使用最长的匹配模型模式，因此无论配置顺序如何，特定模式都优先于通用模式。
  • ask 工具现在在超时到期时提交表单的当前值；更新的设置和文档反映了这种行为。
  • read 工具按需加载详细的格式选择器和 URI 子路径语法，减少默认请求描述，同时在禁用 read 时保留内联详细信息。
  • 默认系统提示和工具描述已得到简化，指导更接近工具，并在相关时提供详细的任务/过程参考。
  • bash 伪视图将从文字和扩展构建的单词呈现为 f 字符串 (f"repos/org/{r}/rulesets")，而不是 concat(...) 调用。

已修复

  • 修复了 computer.close()，以便后续计算机控制调用启动新的桌面会话而不是失败。
  • 修复了 oauth.modifyModels 的扩展提供程序，以便它们在登录前不会加载完整的模型目录。
  • 修复了恢复会话，使其不再扫描不相关的后续会话记录。
  • 修复了 Windows 上的会话保存，以避免重复会话文件访问导致 UI 停顿。
  • 修复了自动图表选择，以便生成的图表使用兼容的数据和图表类型。
  • 修复了 env -i 命令的 bash 预览，以便它们显示请求的命令而不是生成的 shell 设置代码。

@oh-my-pi/collab-web

已修复

  • 修复了 task 工具卡，以便生成的任务始终显示其名称、分配的代理和说明，而 steps 生成显示为编号的阶段。

@oh-my-pi/pi-natives

添加

  • 添加了 shellBuiltins(sessionEnv?) 以列出嵌入式 shell 提供的命令，包括进程控制和实用程序。
  • 在 Linux、macOS 和 Windows 上使用 awk、tar、shasum、md5、strings 和 lsof 扩展了嵌入式 shell。可以使用 PI_DISABLE_UUTILS_DESTRUCTIVE 禁用破坏性实用程序；禁用时，tar 将委托给系统。

已修复

  • 修复了 Chrome 和其他基于 Chromium 的应用程序中的 macOS 文本输入，因此键入后按 Return 键会打开输入的文本，而不是重新加载当前页面。

@oh-my-pi/pi-tui

添加

  • GitHub 操作监视卡现在显示当前步骤进度，并且可以使用 Ctrl+O 进行扩展，以在 ANSI 和本机 Tern 视图中显示有序步骤状态和持续时间。

已修复

  • 修复了比较图表将与竞争对手列的差距错误标记为改进或回归的问题。
  • 修复了 Tern 编辑差异，显示不相关的单行块和远处更改周围不正确的行号。
  • 修复了表格图表错误地将列名称中的“with”、“to”和“from”等单词解释为比较条件的问题。
  • 修复了包含尾随数字的图表行名称，例如“EmbeddingGemma 2”和“Jev 15”，被分割或错误嵌套。
  • 修复了 read 拒绝冒号分隔的行范围并将单个请求的范围显示为多行的问题。

已删除

  • 从 TodoStatus 中删除了 blocked 状态，从 TodoItem 中删除了 blocker 字段，以及从 TodoOperation 中删除了 block/unblock 操作。

@oh-my-pi/pi-utils

添加

  • 添加了浏览器实用程序，公开 trusted 浏览器存档提取限制和已安装的 WebKit 主机可执行路径。
