taste-skill v2.0.0

大版本 发布时间2026年10月13日 来源Leonxlnx/taste-skill 英文原文

taste-skill v2.0.0

rateskill v2 是一项新的默认技能，而不是旧技能的编辑。它为编码代理提供了艺术指导、真实图片以及在真实浏览器中检查其工作的方法。

安装或升级

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

安装名称没有改变。需要 Node 22+ 和 Chrome、Edge 或 Chromium。不安装任何内容，不使用 API 密钥。

新内容

  • 用图书馆代替形容词。 通过对 247 个策划站点的研究而构建：20 个方向、48 个英雄构图、172 个部分布局、44 个类型系统、56 个调色板。
  • 脚本处理方向。 scripts/draw.mjs 处理三个方向；代理人会选择一个可以携带只有这台 client 才有的东西的人。
  • 真实图片。 scripts/assets.mjs 在开放收藏中查找主题世界的照片、地图和镜头，下载它们并记录制作人员名单。
  • 真正的浏览器检查器。 scripts/inspect.mjs 以 1440、768 和 390 像素打开页面，但在眉毛标签、发际线、渐变、静止阴影、两行标题、空屏幕和覆盖文本上失败。
  • 查看并修复循环。 代理批评自己的屏幕截图并修复前三个问题，最多三轮。 在使用和不使用该技能构建的四个测试摘要中：37 个小标签和 249 个发际线规则没有它，没有一个；没有它就没有照片，有它的照片有 48 张。

也在这个版本中

  • Codex 可以将集合安装为插件 (codex plugin marketplace add Leonxlnx/taste-skill)。
  • 之前的默认值仍为 design-taste-frontend-v2-experimental，原始版本为 design-taste-frontend-v1。
  • 围绕 v2 重写的自述文件，包含之前/之后的示例。 完整注释：CHANGELOG.md
