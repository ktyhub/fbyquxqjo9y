photocraft v0.13.0

[!注意] FreeBSD aarch64 从此版本中删除。 我们必须削减版本，并且我们无法在任何 Craft 应用程序的 5 小时 CI 限制内构建此目标，因此我们暂时删除它。这是一个已知的拦截器，在 Storytold/craft-common-actions#39 中标记为将来修复。 FreeBSD x86_64 和所有其他平台都包含在内。
