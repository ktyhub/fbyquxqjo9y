photocraft v0.16.0

发生了什么变化

  • 在 https://github.com/storytold/photocraft/pull/8993 中移动@kotulsky 的样式组时重用填充形状效果图
  • 修复（ui-egui）：底层智能过滤器上的 click 会再次选择它们（#8764），作者为 https://github.com/storytold/photocraft/pull/8974 中的 @drunkeninja42

  • perf(mcp): 在 https://github.com/storytold/photocraft/pull/8844 中移动命令列表行而不是通过 @yongjip 进行克隆
  • 编解码器：当 DPX 或 Cineon 在 https://github.com/storytold/photocraft/pull/8793 中通过 @przemyslvw 保存丢弃位时发出警告
  • 修复（类型）：使用新文本的 type.edit 保留 https://github.com/storytold/photocraft/pull/8766 中@FinnNk 未更改文本的样式
