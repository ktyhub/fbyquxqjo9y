photocraft v0.21.0

发生了什么变化

  • 将全尺寸的拼合文档保存到 .pcraft 文件中，作为 @dotCooCoo 在 https://github.com/storytold/photocraft/pull/9913 中的选项
  • 在 https://github.com/storytold/photocraft/pull/5330 中添加受保护的暂存存储和 @vistaero 拥有的内存监督
  • 保存：停止在 https://github.com/storytold/photocraft/pull/8115 中将 @VishnuByrraju 在内存中的编码文件加倍 (#6607)
  • 通过 @vistaero 在 https://github.com/storytold/photocraft/pull/5331 中的有界频带流式传输本机 PSD/PSB 和 EXR 导入
  • 在 https://github.com/storytold/photocraft/pull/10897 中 @wanikhawar 从可用 RAM 中调整 PSD 导入内存限制
  • 便携式模式：专门创建写入探针，而不是通过@dylanmtaylor 在 https://github.com/storytold/photocraft/pull/10963 中的现有条目
  • 编解码器：拒绝 EXR 预览属性大于 @dylanmtaylor 在 https://github.com/storytold/photocraft/pull/10982 中的值
  • 安全性（亲和力）：电荷分配记录、空子路径、油漆列表、图块索引和形状查找，由 @dylanmtaylor 在 https://github.com/storytold/photocraft/pull/10966 中进行
  • 通过 @vistaero 在 https://github.com/storytold/photocraft/pull/5332 中流式传输 GPU 视口页面，并进行有界暂存和取消
  • 修复（ui）：保存为 Web Matte 在 @hnoerenberg 在 https://github.com/storytold/photocraft/pull/8890 中输入时仅采用整个颜色（#8830）
