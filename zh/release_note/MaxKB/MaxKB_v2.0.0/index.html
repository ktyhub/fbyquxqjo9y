MaxKB v2.0.0

大版本 发布时间2025年7月17日 来源1Panel-dev/MaxKB 英文原文

重要升级

■ 多租户权限管理系统（X-Pack）全面升级 MaxKB V2对多租户权限管理系统进行了全面升级。通过用户管理、角色管理、工作空间、资源授权四个模块的协同，构建了一个可扩展的多租户权限管理系统。有效支持多组织、多部门、多用户组的权限和资源管理需求，实现系统对权限和资源的精准控制。 角色管理是RBAC权限系统的核心。 MaxKB V2预设了三种角色：系统管理员、工作区管理员和普通用户。系统管理员拥有系统级管理权限，工作区管理员负责管理成员和资源授权，普通用户可以维护自行创建和授权的资源。 另外，MaxKB V2支持基于系统预设角色的自定义角色功能。在继承系统管理员、工作区管理员或普通用户权限的基础上，可以进行个性化的权限配置。 ■ 新的共享资源管理功能（X-Pack） MaxKB V2增加了共享资源功能，支持跨工作区资源复用和协作。系统管理员可以统一管理知识库、工具、模型等核心资源，并授权到指定的工作空间。在保证资源安全共享的同时，通过权限控制实现共享与控制的平衡。 ■ 新的会话用户管理功能（X-Pack） MaxKB V2还增加了“会话用户管理”功能，支持提问端身份认证。该功能通过会话用户、用户组、应用-会话用户、知识库-会话用户授权等模块的联动，实现对用户提问范围和知识检索权限的管理和控制。从而实现“一人一权”、“一组一权”的精准管理，进一步增强了系统的安全性和可控性。新版本MaxKB还支持LDAP、OIDC、CAS、OAuth2等第三方认证方式，满足企业数据安全需求。 ■ 支持按文件夹目录管理应用程序、知识库和工具 MaxKB V2升级了资源管理能力。用户登录后可以进入工作区管理资源。工作空间资源包括四种核心类型：应用程序、知识库、工具和模型。其中应用程序、知识库、工具可以通过文件夹目录进行管理。这一改进方便用户对资源进行分类整理、分级管理、快速检索，大大提高了资源管理的效率和使用的便利性。

增强功能

  • 资源管理：支持系统管理员查看所有工作区的应用、知识库、工具、模型资源列表；
  • 知识库：离线文档上传到通用知识库后，会存储原始文档，并支持原始文档下载；
  • 知识库：优化段详情页，支持段顺序调整；
  • 应用：高级编排应用的知识库检索节点和多路径召回节点增加了“知识源中显示结果”的开关设置；
  • 应用：“显示设置”功能中，支持设置问答页面的聊天背景； （X - 包）
  • 应用程序：在调试预览中进行对话时，使用保存的应用程序配置；
  • 应用：应用“设置”页面增加“进入对话”入口，方便用户调整配置后进入问答页面进行对话；
  • 问答页面：高级编排应用支持知识源展示；
  • 问答页面：优化了问答页面的交互和风格；
  • 安全性：修复了工具模块中的远程命令执行漏洞（CVE-2025-53927）；
  • 安全性：修复了 MCP 调用期间潜在的远程命令执行漏洞 (CVE-2025-53928)。 附： MaxKB目前不支持从v1.10.x版本直接升级到v2.0.x。 MaxKB团队计划于2025年9月发布相关迁移工具。
