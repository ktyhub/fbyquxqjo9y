airflow 1.21.0

小版本 发布时间2026年4月24日 来源apache/airflow 英文原文

airflow helm-chart/1.21.0

变更流程图

亮点

  • worker 配置迁移 — worker 设置现在归属 workers.celery.* 或 workers.kubernetes.*，从而支持按 executor 定制调度、服务账号、环境变量、卷以及 pod 放置策略。Celery 专属选项（包括 extraPorts、volumeClaimTemplates、hpa 和 logGroomerSidecar）移到 workers.celery.* 下。旧键仍可用，但应在未来移除前完成迁移（#61915、#65059）。
  • 默认使用 Airflow 3.2.0 — chart 现在自带 Airflow 3.2.0，而非 3.1.8（#64841）。请针对 3.2.0 测试 DAG、provider 和插件；如果部署暂时无法采用，请显式固定镜像。
  • 扩展 Helm 模板能力 — ServiceAccount 注解、metadataConnection 和 ConfigMap 名称现在支持 tpl 渲染（#64763），便于从 values 生成环境特定的资源命名和元数据。
  • 清理作业自动回收 — 数据库清理作业支持 ttlSecondsAfterFinished（#64164），完成的 Job 可被自动删除，而不必在命名空间里不断堆积。
  • 凭据与密钥加固 — 生成的 JWT 密钥现在采用推荐长度（#65082），同时修正了 broker URL 的 Secret 引用（#65006）。升级后请验证自定义 broker 配置解析到预期的 Secret。
  • 破坏性变更 — 未声明破坏性变更；弃用的 worker 键仍向后兼容，但计划在未来版本中移除。
