airflow 0.1.5

修订 发布时间2026年6月3日 来源apache/airflow 英文原文

airflow airflow-ctl/0.1.5

这个项目是干啥的：一个用代码编排定时任务的调度平台，把数据处理流程串成流水线，按时运行、失败可重试，适合要管理大量周期性作业的工程师。

变更架构图

亮点

  • 必填参数改为位置参数，不再是 --flag（#66768） — 该版本最大的迁移风险：自动生成的 airflowctl 命令现在把必填的基础类型参数作为位置参数，可选参数仍保持 --flag 形式（依据 dev-list 的 lazy consensus）。任何把 flag 固定用于传必填值的自动化都会在升级时中断——请逐个重新查看命令的 help 输出，而不是假设旧签名。
  • 两个热点端点改为基于游标的翻页（#65604、#64845） — get_dag_runs 和 get_task_instances 新增基于游标的分页，这在遍历大量运行/任务历史时很重要，因为 offset 分页会随行变动而变得不可靠。解析旧响应结构的客户端应验证其逻辑；新集成则获得更稳定的方式遍历大型结果集。
  • 更快的操作工作流：新命令与批量操作（#66172、#66188、#67095、#64141） — dags next execution 展示即将到来的运行，批量删除 Dag Run 加上多实例 clear/mark-success/mark-failure/delete 取代了重复的单条调用。建立在单条请求循环上的工具现在有更快的路径值得切换。
  • clear/rerun 现在遵循配置层级（#63884） — 新增的 rerun_with_latest_version 设置改变了 clear 和 rerun 操作针对的代码版本，优先级现在很重要。依赖针对特定版本重跑任务的团队应在信任默认值前审计配置层如何解析。
  • Core API 与回填可靠性扩展（#67041、#64644、#65158、#64939） — AIP-103 新增用于任务状态和资产状态的 Core API 端点，DAG 响应新增 is_backfillable 标志，回填 create/dry-run 的 payload 以 JSON 发送，回填参数现在能正确覆盖已有 Dag Run 的 conf。如果你手工构造回填请求，请注意 payload/content-type 的变化。
  • 安静的安装与 CLI 解阻（#65489、#65607、#65608、#67063） — 修复了缺失的 pyyaml 运行时依赖，将 httpx 限制在 1.0 以下以避免不兼容版本，dagrun list 省略 --state 时不再崩溃，并修正了 connections 导入的 schema 处理。表面上都是小问题，但它们消除了阻碍全新安装和日常 CLI 调用的失败。

重大变化

  • 添加 dags 下一个执行命令（#66172，#66188）
  • 添加批量删除 Dag Runs (#67095)
  • 添加 rerun_with_latest_version 配置层次结构以清除/重新运行行为 (#63884)
  • 在 API 中实现任务组实例的修补 (#62812)
  • 允许无需身份验证的远程版本检查 (#65099)
  • 为 get_dag_runs 端点添加基于光标的分页 (#65604)
  • 启用新任务排队 (#63484)
  • 为 get_task_instances 端点添加基于光标的分页 (#64845)
  • 将 is_backfillable 属性添加到 DAG API 响应中 (#64644)
  • 将自动生成的命令所需的原始参数公开为位置参数，而不是 --flag 选项。可选参数保持 --flag 形式。遵循 dev-list 关于 airflowctl 参数样式的惰性共识（参见 https://lists.apache.org/thread/m1qvcvow3l17ytv40vhslh40wn3rntrm）(#66768)

错误修复

  • 修复连接导入架构处理 (#67063)
  • 修复文档中损坏的下载 URL 和变量名称 (#67046)
  • 修复缺少的 pyyaml 运行时依赖项 (#65489)
  • 修复 --state 被省略时 dagrun list 崩溃的问题 (#65608)
  • 修复回填参数不覆盖现有 DAG 运行配置的问题 (#64939)
  • 修复 client-py 中的 Ruff 问题 (#64868)

改进

  • AIP-103：添加任务状态和资产状态的核心 API 端点 (#67041)
  • 添加注释以避免在airflowctl PR 中手动编辑 RELEASE_NOTES.rst (#67128)
  • 将 Dag capitalization 从“DAG”对齐到“Dag”以进行airflowctl (#66112)
  • 以 JSON 形式发送回填创建和试运行有效负载 (#65158)
  • 使用airflowctl utils中现有的safe_load函数来加载帮助文本(#65841)
  • 限制 Airflowctl httpx 依赖低于 1.0 (#65607)
  • 删除未使用的 airflow-ctl/newsfragments 目录 (#65507)
  • 修复不正确的后备逻辑 (#64586)
  • 将非提供商 mypy 检查作为常规预提交静态检查运行，而不是单独的 CI 作业 (#64780)
  • 支持清除、标记成功/失败以及删除多个任务实例 (#64141)
