airflow 2.10.3

修订 发布时间2024年11月5日 来源apache/airflow 英文原文

airflow 2.10.3

重大变化

没有重大变化。

错误修复

  • 改进了设置 Airflow 变量时对值屏蔽的处理，以增强安全性。 (#43123) (#43278)
  • 添加对 task_instance_mutation_hook 的支持以处理索引为 0 的映射运算符。 (#42661) (#43089)
  • 修复了执行器清理，以便在任务实例终止时正确处理僵尸任务。 (#43065)
  • 在内部 API 调用中添加 HTTP 502 和 504 错误的重试逻辑，以处理 Web 服务器启动问题。 (#42994) (#43044)
  • 恢复使用单独的会话来写入和删除 RTIF 数据，以防止 StaleDataError。 (#42928) (#43012)
  • 通过将 DAG 名称中的连字符替换为下划线来修复 PythonOperator 错误。 (#42993)
  • 改进任务重试的验证以处理 None 值 (#42532) (#42915)
  • 修复了将数据集别名解析为新数据集时数据集管理器中的错误处理 (#42733)
  • 在 DAG 图形视图中启用 clicking 任务名称以正确选择相应的任务。 (#38782) (#42697)
  • 使用标签/上次运行过滤器防止 /home 上的重定向循环 (#42607) (#42609) (#42628)
  • 支持 OTEL 指标中的 host.name 以及指标中 OTEL_RESOURCE_ATTRIBUTES 的使用 (#42428) (#42604)
  • 通过降低对比度和饱和度来减少黑暗模式下的眼睛疲劳 (#42567) (#42583)
  • 以触发器形式正确处理 ENTER 键并允许手动 JSON (#42525) (#42535)
  • 确保 DAG 触发器表单在键盘提交时提交更新的参数 (#42487) (#42499)
  • 如果 pickling 处于活动状态，请勿尝试通过 xcom 向 UI 提供非“stringified”对象 (#42388) (#42486)
  • 修复任务实例的span链接，使其指向scheduler_job_loop中的正确span (#42430) (#42480)
  • 修复了 Windows 中运行程序的任务执行问题 (#42426) (#42478)
  • 允许使用环境变量覆盖硬编码的 OTEL_SERVICE_NAME (#42242) (#42441)
  • 通过使用 selectinload instead of joinedload 提高触发器性能 (#40487) (#42351)
  • 屏蔽敏感配置时抑制警告 (#43335) (#43337)
  • 屏蔽与 DAG 作者无关的配置值 (#43040) (#43336)
  • 在 BashOperator 中将模板化的 bash 脚本作为文件执行 (#43191)
  • 修复了 Schedule_downstream_tasks 以包含 one_success 触发规则的上游任务 (#42582) (#43299)
  • 在调度程序中添加重试逻辑，以便在发生死锁时更新触发器超时。 (#41429) (#42651)
  • 当手动 dag_run 失败时将所有任务标记为跳过 (#43572)
  • 修复日志和详细信息网格面板中映射任务的“TrySelector”(#43566)
  • 在处理执行器事件时有条件地添加 OTEL 事件 (#43558) (#43567)
  • 修复损坏的统计数据 scheduler_loop_duration (#42886) (#43544)
  • 确保 /api/v1/dags 中的总条目数 (#43377) (#43429)
  • 在列表任务实例（批量）端点的请求正文架构中包含限制和偏移量 (#43479)
  • 当从扩展运算符调用执行时，不要在 ExecutorSafeguard 中发出警告 (#42849) (#43577)

杂项

  • 弃用会话身份验证后端 (#42911)
  • 删除了 Airflow 版本 2.8.0 及更高版本的提供商的 unicodecsv 依赖性 (#42765) (#42970)
  • 删除从 Web 服务器到 Scarf 的引荐来源网址 (#42901) (#42942)
  • 将 /airflow/www 中的 dompurify 从 2.2.9 映射到 2.5.6 (#42263) (#42270)
  • _get_template_context 中正确的文档字符串格式 (#42244) (#42272)
  • 向后移植：将 Flask-AppBuilder 映射到 4.5.2 (#43309) (#43318)
  • 检查用于安装预提交 venvs 的 python 版本 (#43282) (#43310)
  • 解决数据集别名迁移中的警告 (#43425)

仅文档更改

  • 澄清 DAG 作者的 PLUGINS_FOLDER 权限 (#43022) (#43029)
  • 将模板信息添加到 TaskFlow 教程 (#42992)
  • Airflow 本地设置不再可以从 dags 文件夹导入 (#42231) (#42603)
  • 修复 CPU 和内存使用情况的文档 (#42147) (#42256)
  • 修复 docker 撰写指令 (#43119) (#43321)
  • 更新文档以反映返回 dag_warnings 而不是 import_errors。 (#42858) (#42888)
