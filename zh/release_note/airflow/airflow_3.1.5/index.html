airflow 3.1.5

修订 发布时间2025年12月10日 来源apache/airflow 英文原文

airflow 3.1.5

这个项目是干啥的：一个用代码编排定时任务的调度平台，把数据处理流程串成流水线，按时运行、失败可重试，适合要管理大量周期性作业的工程师。

变更架构图

亮点

  • 安全与密钥处理 — 修复 JWTRefreshMiddleware 中无效的 JWT 处理（#56904），并封堵经由弃用导入路径（#58726）、非法参数 kwargs（#58283）和渲染后的 UI 模板（#58772）泄露密钥的路径。如果你对外暴露 Airflow 的 UI/API 或渲染敏感任务数据，请优先升级。
  • 调度器与任务可靠性 — 修复并发 scheduler 下 max_active_runs 回填竞争（#58935）、重复 run_id 的 deadline 清理（#58910）、跨所有退出码的重试（#58478），以及 reset_dag_run=True 时 TriggerDagRunOperator 卡在 deferred 状态的问题（#58333）。还修复了 pre-AIP-39 运行的处理（#58773）以及 dag.test() 和任务子进程的 supervisor 重连（#58266、#58263）。
  • DAG 与资产正确性 — 稳定含无序 dict 模板字段的 DAG 哈希（#59091、#59175），通过原子化的 SerializedDagModel.write_dag 防止孤儿 DAG 版本（#58281），经 AssetAlias 保留 Asset.extra（#58712），并阻止仅有 inlet 的资产被孤立（#58986）。其他修复涵盖假值 default_args（#58396）、缺少 conn_type 的连接（#58664）以及 Pydantic 的字符串转日期时间（#58916）。
  • 资源占用与 UI — gc.freeze 减少 LocalExecutor 的内存尖峰（#58934）。UI 修复新增 grid 查询计数护栏（#57977、#58632），修复任务实例标签页内存泄漏（#58557），并纠正 HITL 渲染、时区处理、回填时序和失败任务的额外链接。这对 LocalExecutor 部署以及大型或高频使用的 grid 最为重要。
  • 升级评估 — 尽管标注「无重大变更」，这其实是一个内容充实的错误修复版本，不是换标签或纯元数据更新。未列出破坏性变更或必需迁移步骤；Airflow 2 数据库访问迁移指南（#57479）仅属文档。受影响的部署应升级，而未受这些修复影响、运行稳定的安装可按常规补丁节奏进行。
