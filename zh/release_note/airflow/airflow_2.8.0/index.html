airflow 2.8.0

小版本 发布时间2023年12月18日 来源apache/airflow 英文原文

airflow 2.8.0

这个项目是干啥的：一个用代码编排定时任务的调度平台，把数据处理流程串成流水线，按时运行、失败可重试，适合要管理大量周期性作业的工程师。

变更架构图

亮点

  • DAG 描述默认更安全 — DAG 文档、参数描述和触发表单中的原始 HTML 现在被禁用。只有在你信任 DAG 作者时才设置 webserver.allow_raw_html_descriptions=True；否则请把 description_html 迁移到 description_md，因为 custom_html_form 已弃用（#35460）。
  • Airflow Object Store 与数据表序列化 — AIP-58 引入 Airflow Object Store（AFS），提供与 provider 无关的对象存储工作流。轻量的 Delta Lake 和 Iceberg 表序列化降低了序列化开销，并改善了与数据密集型流水线的兼容性（#35462、#35456）。
  • 更好的任务日志与 Python 易用性 — 任务上下文日志会把发出的消息转发到任务日志中（#32646、#32693、#35857）。新增 PySpark、外部 Python 和 venv 分支装饰器，拓宽了编写选项；而 literal 包装器可让你显式禁用字段模板化（#35247、#35043、#35017）。
  • 更灵活的调度 — schedule=None 的 DAG 不再要求 start_date，简化了手动触发的工作流（#35356）。新的 prev_end_date_success 访问器改进了调度逻辑（#34528），UTC 偏移修复解决了下次运行时间计算错误的问题（#35887）。
  • 改进的 UI 与运维可见性 — Grid 新增 XCom 标签页（#35719）、从任务实例视图清除下游任务（#34529），以及多选运行状态（#35403）。Dataset listener 钩子支持对数据集更新做出事件驱动响应（#34418、#36247）。
  • 需审查的依赖与 API 变更 — Airflow 升级到 Pydantic v2（#35551），把 Connection.to_json_dict() 更名为 Connection.to_dict()（#35894），默认 MySQL 客户端改为 MariaDB（#36243），并将 Elasticsearch 支持升级到 8.x（#33135）。部署前请审计自定义 Pydantic 模型、连接序列化、数据库客户端和 provider 兼容性。

重大变化

  • 默认情况下禁用 DAG 文档和 DAG 参数描述中的原始 HTML 代码 确保 DAG 作者不会向恶意 javascript 注入 DAG 描述或触发 UI 表单 新参数“webserver.allow_raw_html_descriptions`` was added with default value of ``False”。 如果您 trust 您的 DAG 作者代码并希望允许在 DAG 描述和参数中使用原始 HTML，您可以恢复以前的 通过将配置值设置为“True”来实现行为。 为了确保 Airflow 在默认情况下是安全的，触发器 UI 中的原始 HTML 支持已通过 Markdown 支持进行超级种子化 description_md attribute. If you have been using description_html please migrate to description_md。 custom_html_form 现已弃用。 (#35460)
