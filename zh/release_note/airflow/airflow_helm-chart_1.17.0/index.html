airflow 1.17.0

小版本 发布时间2025年6月23日 来源apache/airflow 英文原文

airflow helm-chart/1.17.0

这个项目是干啥的：一个用代码编排定时任务的调度平台，把数据处理流程串成流水线，按时运行、失败可重试，适合要管理大量周期性作业的工程师。

变更架构图

亮点

  • 默认镜像升级为 Airflow 3.0.2 — 该 chart 把默认镜像从 Airflow 2.10.5 直接跳到 3.0.2（#51594），一次看似常规的 Helm 升级会连带改变应用的主版本。务必先验证 DAG 与插件的兼容性、按 Airflow 3 迁移路径操作；如果暂时无法迁移，请在规划升级期间显式固定旧镜像标签。
  • 最低 Kubernetes 版本提高到 1.30 — 安装 chart 1.17.0 前，低于 1.30 的集群必须先升级（#51515），否则只能停留在旧版 chart。这条兼容性门槛与 Airflow 镜像变更相互独立。
  • 支持 EdgeExecutor 部署 — 新增的 chart 支持（#50897）让 Airflow 3 用户可以选择远程 edge worker，而不必只依赖传统 worker 部署。需要统筹规划 executor 配置、worker 启动引导、网络以及 API server 的可达性；现有的 Celery 或 Kubernetes worker values 不能想当然地适用于 edge worker。
  • 修复 API server 配置与路由 — chart 补齐了缺失的 API server ingress（#49727）、webserver_config.py（#50108）、未声明的属性（#51012）和副本数设置（#50814）。当 base_url 包含子路径时，执行 API URL 也得到修正（#51454），这对反向代理部署尤为关键；升级时请重新核对 ingress 路由、TLS 和路径前缀配置。
  • JWT 密钥自动处理 — Helm 现在会在安装时生成 JWT 密钥（#49923）并始终部署它（#51799），避免 Airflow 3 API 认证路径因密钥缺失而失败。如果你在外部管理密钥，升级前请检查资源归属和覆盖配置，以免与既有密钥工作流冲突。
  • 安全默认值、RBAC 和标签需要复核 — FAB 的 enable_proxy_fix 默认值针对 Airflow 3 做了修正（#50056），pod-launcher 的角色绑定得到修复（#49219），DAG processor 服务账号被加入 SCC 角色绑定（#51080），改善了代理处理以及 Kubernetes/OpenShift 授权。统一标签（#49522）和截断的 executor 标签（#51817）可能影响自定义选择器和仪表盘，发布时请审查依赖标签的工具链。

重大变化

默认 Airflow 图像更新为 3.0.2 (#51594)

与图表一起使用的默认气流图像现在是“3.0.2``, previously it was ``2.10.5”。

新功能

  • 为大多数秘密添加额外的秘密注释 (#48890)
  • 添加对 EdgeExecutor 的支持 (#50897)

改进

  • 统一 k8s 标签并添加一些缺失的 k8s 标签 (#49522)

错误修复

  • 修复缺失的 api 服务器入口 (#49727)
  • 替换 pod-launcher-rolebinding 模板中的中断函数 (#49219)
  • 将 webserver_config.py 文件添加到 api-server (#50108)
  • 声明缺少 API 服务器属性 (#51012)
  • 添加缺少的 api 服务器副本参数 (#50814)
  • 修复 Airflow 3 的 FAB enable_proxy_fix 默认值 (#50056)
  • 将 dag 处理器 ServiceAccount 添加到 SecurityContextConstraints 角色绑定 (#51080)
  • 在 HELM 安装期间生成 JWT 密钥 (#49923)
  • 始终部署 JWT 秘密 (#51799)
  • 在值中添加缺少的 workers.kerberosInitContainer 配置 (#51405)
  • 截断执行器标签长度 (#51817)
  • 当 base_url 有子路径时修复execution_api_server_url (#51454)

文档仅更改

  • 在文档中增加最低 Helm 版本 (#48700)
  • 澄清哪些工作字段适用于 Celery 和 Kubernetes 工作 Pod (#50458)
  • Capitalize 术语气流 (#49450)

  • 为 CeleryKubernetesEExecutor 添加 3.X/2.X 说明 (#49916)
