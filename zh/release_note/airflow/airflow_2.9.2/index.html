airflow 2.9.2

修订 发布时间2024年6月10日 来源apache/airflow 英文原文

airflow 2.9.2

变更流程图

亮点

  • 数据库连接可靠性 — AirflowSecurityManagerV2 不再让会话停留在 idle in transaction 状态，减少连接池耗尽和锁压力（#39935）。迁移修复还纠正了 Alembic 约束命名，并在降级时恢复 existing_nullable 处理，使 schema 回滚更安全（#39032、#39374）。
  • 调度器与重试行为 — mini scheduler 现在使用 SKIP LOCKED 而非 NOWAIT，避免其他 worker 持有行锁时因争用而跳过（#39745）。当某次尝试重试且没有远程日志时，现在也会抓取任务日志，防止故障诊断出现空档（#39496）。
  • 安全与权限 — 自定义 security-manager 的 action 现在能在 has_access 中正确生效（#39421），移除 FAB 的 DAG run 创建选项封堵了一条绕过预期工作流管控的路径（#39881）。无权限用户的实例状态按钮也保持禁用（#38732）。
  • Webserver 与 API 行为 — 错误的 DAG 触发参数现在返回受控的校验响应，而非 HTTP 500（#39409）。静态文件缓存得到恢复，动态生成的响应则显式使用 Cache-Control: no-store；反向代理应遵守后者，避免提供陈旧的安全敏感内容（#39345、#39550）。
  • Airflow 2.9 兼容性 — Dataset URI 校验在 2.9 中改为告警而非报错，降低升级冲击，不过启用严格检查的地方仍会抛出异常（#39670、#39719）。部署方应在转向更严格校验前把这些告警当作待办处理。
  • 破坏性变更 — 未报告。

没有重大变化。
