airflow 3.0.1

修订 发布时间2025年5月12日 来源apache/airflow 英文原文

airflow 3.0.1

这个项目是干啥的：一个用代码编排定时任务的调度平台，把数据处理流程串成流水线，按时运行、失败可重试，适合要管理大量周期性作业的工程师。

变更架构图

亮点

  • 升级与依赖布局 — 3.0 升级现在会清除过期的 dag_code 和 serialized_dag 记录（#49563），导入失败会把 DAG 模型标记为 stale 并关联 bundle（#49769），减少迁移期间不一致的元数据。核心还移除了 gitpython，并把非核心依赖及 SQS 队列支持移到元包/provider 中（#49537、#49846、#50057）；自定义精简安装应显式声明这些依赖。
  • 动态映射可靠性 — 修复强制对映射任务执行 max_active_tis_per_dag（#49708），支持映射 TaskGroup 的映射索引和额外链接（#49996、#50238），并在完成后渲染 map_index_template（#49809）。已有映射 DAG 无需重写，但并发限制和任务详情行为现在更一致。
  • 统一的回填工作流 — 回填与触发 DAG 运行合并为单一表单体验（#49490），包括 dag_run_conf 支持（#49763）。试运行现在使用创建表单的时区（#49911），日期区间校验更严格（#50116）；运维方应验证自动化提交使用的是带时区的时间戳。
  • API 契约更新 — DagRun 响应现在包含 bundle_version（#49726），生成的客户端受益于调整后的 Execution API OpenAPI schema（#49700），默认执行服务器 URL 改为相对 API base URL 解析（#49747、#49782）。请刷新客户端模型，不要假设执行服务器 URL 是绝对的。
  • 登录与安全加固 — 修复防止安全 cookie 重定向循环（#49721）、登出时保留 base_url（#49545）、约束 SimpleAuthManager 中不安全的登录重定向（#49697、#49866），并遮蔽新设置的变量值（#43123）。代理部署应重新测试登录/登出流程，无认证头的 SimpleAllAdminMiddleware（#49599）应继续仅限受信任的内部流量使用。
  • 破坏性变更 — 此补丁版本未明确列出。
