airflow 1.22.0

小版本 发布时间2026年6月13日 来源apache/airflow 英文原文

airflow helm-chart/1.22.0

变更流程图

亮点

  • Helm 基线提高到 3.19.0（#66970） — 这是真正的升级门槛：任何仍在用 Helm 3.18 或更早版本的 CI 作业、GitOps 控制器或本地机器，都会直接无法渲染 chart。请在提升 chart 版本之前固定你的 helm 二进制并对齐工具链——别等到部署中途才发现。
  • 默认 Airflow 镜像移到 3.2.2（#67681） — 未固定版本的安装会从 3.2.1 静默跳到 3.2.2，因此请把它当作一次补丁级 Airflow 发布：即便你没「改」任何配置，也要对 DAG 解析和 provider 兼容性做冒烟测试。需要分阶段升级请显式固定 defaultAirflowTag。
  • enableServiceLinks 变为可配置，2.0 中默认值翻转（#67447） — Kubernetes 会为命名空间内每个 service 注入 <SVC>_SERVICE_HOST/_PORT 环境变量，污染任务 pod 并可能与你自己的变量冲突。现在你可以选择退出，而 2.0 将默认 false。请审查读取这些自动生成环境变量的代码，改用基于 DNS 的查找，或设置 enableServiceLinks: true 争取时间。
  • 可选的 OTel service（#64902） — 现在可以随 Airflow 一起部署一等 OpenTelemetry service，提供受支持的 traces/metrics 路径，而不必自己拼 sidecar。配合 api-server 配置 checksum 修复（#66468）——它终于会在配置变化时滚动 deployment，此前仅改配置可能让旧 pod 继续运行。
  • RBAC 与 ServiceAccount 接线收紧（#66598、#66730、#66208、#66095、#66626） — 一组修复纠正了 Kubernetes-worker 的 ServiceAccount 值、补上缺失的 worker binding/condition、为 executor 类路径扩展 launcher RBAC，并让 ServiceAccount 注解支持 tpl；清理 cron 也新增了 serviceAccountTokenVolume（#67446）以支持 IRSA/workload-identity 令牌投射。在受限集群或使用自定义 executor 类时，这些是最可能为你解除阻塞的改动——也值得与你自己的覆盖项做 diff。
  • 面向日常运维的网络与调度修复（#65754、#67538、#67471、#67762、#65881） — 任务日志访问现在在 Airflow 2 和 3 的 NetworkPolicy 下都能工作，triggerer KEDA 数据库连接渲染得到修正，Celery liveness 探针能正确解析主机名，executor 别名获得正确的 chart 标签，清理/数据库生命周期 hook 也真正生效。如果你一直为其中任何一项带着 workaround，请重新测试并移除；升级顺序参见扩充后的 Airflow 3 迁移指南（#66118）。

重大变化

最低 Helm 版本已更新为 3.19.0 (#66970)

默认 Airflow 图像更新为 3.2.2 (#67681)

与图表一起使用的默认气流图像现在是 3.2.2，以前是 3.2.1。

添加了对配置 enableServiceLinks 的支持 (#67447)

默认情况下将成为图表 2.0 中的 false。如果您依赖这些环境变量， 显式设置 enableServiceLinks: true，或迁移代码以使用基于 DNS 的服务查找。

新功能

  • 将可选的 OTel 服务添加到 Airflow Helm Chart (#64902)
  • 将 serviceAccountTokenVolume 添加到清理 cron (#67446)
  • 将 requirePersistence 选项添加到工人 logGroomerSidecar (#65884)

改进

  • 在 API 服务器部署中添加 api 服务器配置的校验和 (#66468)

错误修复

  • 修复 Helm 图表执行器标签以支持执行器别名 (#67762)
  • 修复触发器 KEDA 数据库连接渲染 (#67538)
  • 修复 Celery 工作进程活跃度探测主机名查找 (#67471)
  • 修复使用 eq 将切片与 nil 进行比较的 Go 模板错误 (#64032)
  • 修复 Kubernetes 工作人员服务帐户值 (#66598)
  • 添加 workers.kubernetes 和条件工作人员 ServiceAccount 的绑定 (#66730)
  • 修复执行程序类路径的启动器 RBAC (#66208)
  • 使用 Airflow 2 和 3 的 NetworkPolicies 修复任务日志访问 (#65754)
  • 为 ServiceAccount 注释添加缺失的 tpl 渲染 (#66095)
  • 修复日志修饰器保留值的 go-template if 语句 (#66012)
  • 修复数据库清理生命周期挂钩 (#65881)
  • 修复未应用清理 Pod 生命周期挂钩的问题 (#65764)
  • 修复弃用警告 (#66238)

文档仅更改

  • 扩展 Airflow 3 迁移指南中的 Helm Chart 升级任务 (#66118)

杂项

  • 更改 job/pod 角色绑定渲染和重构相关测试 (#66626)
  • 对图表措辞中的 Dag capitalization 进行标准化 (#66114)
