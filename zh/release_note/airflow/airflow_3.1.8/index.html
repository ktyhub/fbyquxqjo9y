airflow 3.1.8

修订 发布时间2026年3月11日 来源apache/airflow 英文原文

airflow 3.1.8

变更流程图

亮点

  • 回填授权改为 DAG Run 权限（破坏性） — BaseAuthManager.is_authorized_backfill 被移除（#61456）；Core 不再调用它，provider 侧实现也已弃用。回填现在通过现有的 requires_access_dag 装饰器由 DagAccessEntity.Run 控制，因此能运行 DAG 的人就能回填。升级前请审计安全策略：仅被授予 Backfill 权限的主体会静默失去该能力，自定义 auth manager 应移除这个过时钩子。一项相关修复纠正了回填权限处理本身（#62856、#62873）。

  • 会话 cookie 与 JWT 加固 — 会话 cookie 现在限定在 base_url 范围内（#62771、#62851，UI 后续 #62859），对称密钥 JWT 的头部始终携带 kid（#62883、#62943）。这些是对反向代理/子路径部署和多签发者令牌配置重要的行为变化：如果你的 API server 位于非根 base_url 下，请在升级后验证 cookie 域/路径和令牌校验。该版本还修复了 dependencies 端点缺失 DAG 读权限检查的问题（#62046、#62586）。

  • Elasticsearch 远程日志达到同等支持 — 配合 apache-airflow-providers-elasticsearch>=6.5.0，远程任务日志到 Elasticsearch 现已得到完整支持（#62940、#62121）。如果使用远程日志，请固定该 provider 下限并阅读其 6.5.0 说明——这让 ES 后端成为与旧 S3/WASB 路径并列的一等选项（WASB 的 base-path 处理也已修复，#61013）。

  • 升级时需关注的数据库与迁移变更 — dag_bundle.signed_url_template 从 varchar(200) 扩展为 text（#61041、#62568）；修订 509b94a1042d 修正了 SQLite 迁移对 disable_sqlite_fkeys 的处理（#63256、#63272）；降级时恢复 task_instance_history 序列（#62759）；XCom 迁移不再因 NaN/Infinity 浮点数（#62686）或 pendulum.date.Date 序列化（#61176）而失败。请备份并测试升级与回滚两条路径，尤其是在 SQLite 上。

  • Task SDK 与插件 API 新增 — literal 和 ParamsDict 现已在 SDK 顶层导出（#59782、#62756），新增 on_task_instance_skipped 监听器 hookspec（#59467、#61863），XComResponse 新增 run_after 别名以保持向后兼容（#61443、#61672）。这些风险低但对插件和自定义 DAG 作者有用：它们免除了私有导入的变通做法，并让你无需轮询任务状态即可响应跳过事件。

  • 值得注意的可靠性与可观测性修复 — 修复了触发器在 trigger 调用内置 print 时崩溃（#60258、#61703）、PYTHONASYNCIODEBUG=1 下 API server 崩溃（#61281、#61933），以及任务实例 dag_version_id 为空时调度器崩溃（#61813、#61846）。OTEL 指标在进程关闭时刷新（#61808、#61869），并恢复了缺失的 ti.start/ti.finish 指标（#62019、#62110）——如果你基于 Airflow 3 指标构建 SLO，这点相关。UI 变更还降低了 grid view 的内存和 API 压力（#61273、#61656、#62085）。

重大变化

回填权限现在通过 DagAccessEntity.Run 处理 (#61456)

is_authorized_backfill of the BaseAuthManager 接口已被删除。 Core 将不再调用此方法及其 提供者对应的实现将被标记为已弃用。 现在使用现有的“DagAccessEntity.Run”权限检查回填操作的权限 requires_access_dag 装饰器。换句话说，如果用户有运行DAG的权限，他们就可以对其执行回填操作。 请更新您的安全策略，以确保需要执行回填操作的用户拥有适当的“DagAccessEntity.Run”权限。 （用户 拥有 Backfill 权限但没有 DagRun 权限的用户将无法在没有任何更新的情况下执行回填操作）

Elasticsearch 现在与远程日志记录完全兼容 (#62940)

Elasticsearch 现在与“apache-airflow-providers-elasticsearch>=6.5.0”一起完全兼容远程日志记录。请查看 elasticsearch 提供商 release notes 了解更多信息 https://airflow.apache.org/docs/apache-airflow-providers-elasticsearch/6.5.0/changelog.html (#62121) (#62940)
