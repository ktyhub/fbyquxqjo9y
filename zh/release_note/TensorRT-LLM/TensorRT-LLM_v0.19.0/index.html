TensorRT-LLM v0.19.0

TensorRT-LLM 发布 0.19.0

主要功能和增强功能

  • C++ 运行时现已开源。
  • PyTorch 工作流程
    • 添加了 DeepSeek V3/R1 支持。请参阅 examples/deepseek_v3/README.md，也请参阅博客 docs/source/blogs/Best_perf_practice_on_DeepSeek-R1_in_TensorRT-LLM.md。
    • 添加了 Llava-Next 支持。
    • 添加了 BERT 支持。
    • 添加了基于 C++ 的解码器，增加了对以下内容的支持：
      • TopK / TopP。
      • 脏话。
      • 停止词。
      • 嵌入偏差。
    • 为自定义操作兼容的调整过程添加了自动调谐器。
      • 添加了基于 Python 的 Autotuner 核心框架，用于内核调优。
      • 将自动调谐器应用于融合 MoE 和 NVFP4 线性算子，以进行概念和性能评估。
    • 添加了引导解码支持（XGrammar 集成）。
    • 在 PyExecutor 中添加了对重叠调度程序的管道并行支持。
    • 添加了 Qwen2VL 模型支持。
    • 添加了混合精度量化支持。
    • 添加了管道并行性和注意力 DP 支持。
    • 添加了无缓存注意支持。
    • 添加了 PeftCacheManager 支持。
    • 添加了 Qwen2.5‑VL 支持并重构了 Qwen2‑VL。
    • 添加了 trtllm‑gen FP4 GEMM 支持。
    • 添加了 Qwen2 MoE 支持。
    • 将 AutoTuner 应用于 Fused MoE 和 NVFP4 线性算子。
    • 引入了 UserBuffers 分配器。
    • 添加了 Deepseek eager 模式 AllReduce 融合支持。
    • 添加了多令牌预测 (MTP) 支持。请参阅 examples/deepseek_v3/README.md 的“多令牌预测 (MTP)”部分。
    • 添加了对 SM90 的 FlashMLA 支持。
    • 添加了对使用 CUDA 图形填充启用 MTP 的支持。
    • 添加了初始 EAGLE-3 实施。
    • 添加了对 NVIDIA Hopper 和 Blackwell GPU 上的 FP8 MLA 的支持。
  • PyTorch 工作流程的自动部署。
    • AutoDeploy for PyTorch 工作流程是 tensorrt_llm._torch.auto_deploy 中的一项 实验性 功能。
    • AutoDeploy 提供了从现成模型到 TensorRT-LLM 运行时优化部署的自动化路径。
    • 查看 examples/auto_deploy/README.md 了解更多详情。
  • 法学硕士API
    • [重大变更] 添加了动态 logits 处理器支持，并弃用了静态 logits 处理器。
    • 添加了批量 Logits 处理器支持。
    • 添加了 EAGLE 支持。
    • 添加了中止请求支持。
    • 添加了 get_stats 支持。
    • 添加了对基于 Slurm 的集群的多节点支持，请参阅 examples/llm-api/llm_mgmn_*.sh。
  • 添加了 InternLM-XComposer2 支持。请参阅 examples/multimodal/README.md 中的“InternLM-XComposer2”部分。
  • 添加了对 MoE 模型的 INT4-AWQ 支持。请参阅 examples/mixtral/README.md 中的“AWQ 量化”部分。
  • 添加了 Qwen2 音频支持。请参阅 examples/qwen2audio/README.md。
  • 添加了语言适配器支持。请参阅 examples/language_adapter/README.md。
  • 添加了 OpenSoRA 文本到视频支持的 STDiT。请参阅 examples/stdit/README.md。
  • 添加了具有张量并行性和上下文并行性支持的视觉编码器。请参阅 examples/vit/README.md。
  • 添加了 EXAONE-Deep 支持。请参阅 examples/exaone/README.md。
  • 添加了对 Phi-4-mini 和 Phi-4-MM 的支持。
  • 添加了 Gemma3 纯文本模型支持。请参阅 examples/gemma/README.md 上的“运行 Gemma 3”部分。
  • 添加了对 Qwen2-VL 的 FP8 量化支持。
  • 添加了对 LLM API MMLU 示例 examples/mmlu_llmapi.py 的批量推理支持。
  • 添加了 FP4 量化层范数融合插件支持。 （仅限 Llama 型号）
  • 添加了曼巴混合支持。
  • 添加了 NVILA 视频支持。支持包括1提示-N媒体和N提示-N媒体批处理模式。
  • 添加了 --quantize_lm_head 选项 examples/quantization/quantize.py 以支持 lm_head 量化。
  • 添加了批量张量 FP4 量化支持。
    • 为 trtllm-serve 添加了 /metrics 端点来记录迭代统计信息。
    • 添加了对 Phi-2 模型的 LoRA 支持。
    • 添加了对 trtllm-serve 返回上下文日志的支持。
    • 在 FP16/BF16 上添加了 UserBuffer AllReduce-Normalization 的一次性版本。
    • 添加了 disaggServerBenchmark 的请求 BW 公制测量。
    • 将 logits 位掩码内核更新至 v3。
    • 当使用注意力DP并且不同GPU上的活动请求不均匀时启用CUDA图。
    • 添加了对 trtllm-bench 的迭代日志支持。
    • fp8_blockscale_gemm 现已开源。
    • 添加了对 ModelOpt 检查点的 AWQ 支持。
    • 在 FP4 量化中添加了线性块比例布局支持。
    • 添加了对 Nemotron-mini-4b-instruct 的预量化 FP8 检查点支持。
    • 添加了可变波束宽度搜索 (VBWS) 支持（第 2 部分）。
    • 添加了对 Gemma 的 LoRA 支持。
    • 重构脚手架工人，添加 OpenAI API 工人支持。
    • 可选择将 MoE 输入分割成块，以减少 GPU 内存使用。
    • 添加了 UCX IP 接口支持。
    • [重大变更] 将第一个令牌的输出添加到其他生成输出中。
    • 添加了对 SM120 架构的 FP8 支持。
    • 将 ENABLE_MULTI_DEVICE 和 ENABLE_UCX 注册为 CMake 选项。
    • 使脚手架控制器更加通用。
    • 重大更改：为每个附加输出添加了单独的 GatherContext 支持。
    • 启用 PyExecutor 推理流来估计 kv_cache_manager 的 max_num_tokens。
    • 添加了用于调试的 TLLM_OVERRIDE_LAYER_NUM 和 TLLM_TRACE_MODEL_FORWARD 环境变量。
    • 支持中止断开连接的请求。
    • 添加了一个选项，可以在没有上下文服务器的情况下运行分类服务。
    • 修复并改进了 allreduce 和融合内核。
    • 通过init.py增强脚手架的综合稳健性。

API 变化

  • 将 kc_cache_retention_config 从 C++ executor API 公开到 LLM API。
  • 将 BuildConfig 参数移至 LlmArgs。
  • 从有状态解码器中删除了推测解码参数。
  • 通过绑定暴露 DecoderState 并将其集成到解码器中。
  • 使用 Pydantic 重构了 LlmArgs，并将剩余的 pybinding 配置迁移到 Python。
  • 重构分类服务脚本。
  • 将 numNodes 添加到 ParallelConfig。
  • 为 DeepSeek 重新设计了多流 API。

已修复的问题

  • 修复了 PluginField 的误用长度参数。这也修复了#2685。
  • 修复了 Llama-3.2 SmoothQuant 转换检查点问题。 (#2677)
  • 修复了通过 LLM API 使用 LoRA 加载引擎时的错误。 (#2782)
  • 修复了 addCumLogProbs 内核中不正确的批处理槽使用情况。
  • 修复了 Llama-3.2-11B-Vision-Instruct 的错误输出。 (#2796)
  • 删除了运行 pip install tensorrt-llm 时 --extra-index-url https://pypi.nvidia.com 的必要性。

基础设施变化

  • 依赖的 NVIDIA ModelOpt 版本更新为 0.27。

已知问题

  • SBSA 上的 PyTorch 工作流程与 Ubuntu 24.04 等裸机环境不兼容。请使用 PyTorch NGC 容器 以获得 SBSA 平台上的最佳支持。
