TensorRT-LLM v0.15.0

小版本 发布时间2024年12月4日 来源NVIDIA/TensorRT-LLM 英文原文

TensorRT-LLM v0.15.0

嗨， 我们非常高兴地宣布 TensorRT-LLM 的 0.15.0 版本。本次更新包括：

主要功能和增强功能

  • 添加了对 EAGLE 的支持。请参阅 examples/eagle/README.md。
  • 增加了对 GH200 系统的功能支持。
  • 添加了 AutoQ（混合精度）支持。
  • 添加了 trtllm-serve 命令来启动基于 FastAPI 的服务器。
  • 添加了对 Nemotron NAS 51B 的 FP8 支持。请参阅 examples/nemotron_nas/README.md。
  • 添加了对 GPTQ 量化的 INT8 支持。
  • 添加了对 INT8 平滑量化的 TensorRT 本机支持。
  • 添加了对 Exaone 模型的量化支持。请参阅 examples/exaone/README.md。
  • 为 Qwen2 型号启用美杜莎。请参阅 examples/medusa/README.md 中的“Medusa with Qwen2”部分。
  • 使用ReduceScatter 和AllGather 优化Mixtral 模型的管道并行性。
  • 添加了对 Qwen2ForSequenceClassification 模型架构的支持。
  • 添加了 Python 插件支持以简化插件开发工作。请参阅 examples/python_plugin/README.md。
  • 使用 Hugging Face 格式时，添加了对 LoRA 模块的不同等级维度支持。感谢@AlessioNetti 在#2366 中的贡献。
  • 默认启用嵌入共享。有关嵌入共享所需条件的信息，请参阅 docs/source/performance/perf-best-practices.md 中的“嵌入并行性、嵌入共享和查找插件”部分。
  • 在 Ada 上添加了对每个令牌每个通道 FP8（即按行 FP8）的支持。
  • 将支持的最大 beam_width 扩展到 256。
  • 添加了对 InternVL2-4B 变体的 FP8 和 INT8 SmoothQuant 量化支持（仅限 LLM 模型）。请参阅 examples/multimodal/README.md。
  • 添加了对提示查找推测解码的支持。请参阅 examples/prompt_lookup/README.md。
  • 集成了 QServe w4a8 每组/每通道量化。请参阅 examples/llama/README.md 中的“w4aINT8 量化 (QServe)”部分。
  • 添加了使用 executor API 进行快速 logits 的 C++ 示例。请参阅 examples/cpp/executor/README.md 中的“executorExampleFastLogits”部分。
  • [重大变更] 在此版本和未来版本中删除了 NVIDIA Volta GPU 支持。
  • 在LLM API中添加了以下增强功能：
    • [重大变更] 将运行时初始化从第一次调用 LLM.generate 移至 LLM.__init__，以在无需预热的情况下获得更好的生成性能。
    • 向 SamplingParams 类添加了 n 和 best_of 参数。这些参数允许为单个请求返回多个代。
    • 向 SamplingParams 类添加了 ignore_eos、detokenize、skip_special_tokens、spaces_between_special_tokens 和 truncate_prompt_tokens 参数。这些参数可以更好地控制分词器的行为。
    • 添加了对增量去标记化的支持，以提高流生成的去标记化性能。
    • 将 enable_prompt_adapter 参数添加到 LLM 类，并为 LLM.generate 方法添加 prompt_adapter_request 参数。这些参数启用即时调整。
  • 添加了对 examples/gpt/convert_checkpoint.py 文件的 gpt_variant 参数的支持。此增强功能支持使用更多 GPT 模型变体进行检查点转换。感谢 @tonylek 在 #2352 中的贡献。

API 变化

  • [重大更改] 将 trtllm-build 命令中的标志 builder_force_num_profiles 移至 BUILDER_FORCE_NUM_PROFILES 环境变量。
  • [重大更改] 修改了 BuildConfig 类的默认值，以便它们与 trtllm-build 命令保持一致。
  • [重大变更] 删除了 GptManager 的 Python 绑定。
  • [重大更改] auto 用作量化和检查点转换脚本中 --dtype 选项的默认值。
  • [重大变更] 已弃用 gptManagerBenchmark 中的 gptManager API 路径。
    • [重大变更] 弃用了 LLM API 中 SamplingParams 类的 beam_width 和 num_return_sequences 参数。请改用 n、best_of 和 use_beam_search 参数。
    • 向 OpenAI API 服务器公开 --trust_remote_code 参数。 (#2357)

模型更新

  • 添加了对 Llama 3.2 和 llama 3.2-Vision 型号的支持。有关 llama 3.2-Vision 型号的更多详细信息，请参阅 examples/mllama/README.md。
  • 添加了对 Deepseek-v2 的支持。参考examples/deepseek_v2/README.md。
  • 添加了对 Cohere Command R 型号的支持。请参阅 examples/commandr/README.md。
  • 添加了对 Falcon 2 的支持，请参阅 examples/falcon/README.md，感谢 @puneeshkhanna 在 #1926 中的贡献。
  • 添加了对 InternVL2 的支持。请参阅 examples/multimodal/README.md。
  • 添加了对 Qwen2-0.5B 和 Qwen2.5-1.5B 型号的支持。 (#2388)
  • 添加了对 Minitron 的支持。请参阅 examples/nemotron。
  • 添加了 GPT 变体 - Granite（20B 和 34B）。请参阅 examples/gpt/README.md 中的“GPT 变体 - 花岗岩”部分。
  • 添加了对 LLaVA-OneVision 模型的支持。请参阅 examples/multimodal/README.md 中的“LLaVA、LLaVa-NeXT、LLaVA-OneVision 和 VILA”部分。

已修复的问题

  • 修复了前向功能中的切片错误。 (#1480)
  • 修复了构建 BERT 时出现的问题。 (#2373)
  • 修复了构建 BERT 时模型未加载的问题。 (2379)
  • 修复了损坏的执行器示例。 (#2294)
  • 修复了当专家数量不是 2 的幂时，内核 moeTopK() 无法找到正确专家的问题。感谢@dongjiyingdjy 报告此错误。
  • 修复了 crossKvCacheFraction 上的断言失败。 (#2419)
  • 修复了使用 smoothquant 量化 Qwen2 模型时的问题。 (#2370)
  • 修复了 docs/source/performance/perf-benchmarking.md 中的 PDL 拼写错误，感谢 @MARD1NO 在 #2425 中指出。

基础设施变化

  • TensorRT-LLM 的基础 Docker 映像已更新为 nvcr.io/nvidia/pytorch:24.10-py3。
  • TensorRT-LLM 后端的基本 Docker 映像已更新为 nvcr.io/nvidia/tritonserver:24.10-py3。
  • 依赖的 TensorRT 版本更新为 10.6。
  • 依赖的CUDA版本更新为12.6.2。
  • 依赖的 PyTorch 版本更新为 2.5.1。
  • Linux 平台依赖的 ModelOpt 版本更新为 0.19，Windows 平台仍使用 0.17。

文档

  • 在文档中添加了代码片段的复制按钮。 (#2288) 我们定期更新 main 分支，提供新功能、错误修复和性能优化。 rel 分支的更新频率将会降低，具体频率取决于您的反馈。 谢谢， TensorRT-LLM 工程团队
