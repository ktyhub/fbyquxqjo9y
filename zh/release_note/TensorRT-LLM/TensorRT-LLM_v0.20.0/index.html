TensorRT-LLM v0.20.0

TensorRT-LLM 发布 0.20.0

主要功能和增强功能

  • 模型支持
    • 添加了 Qwen3 支持。请参阅 examples/models/core/qwen/README.md 中的“Qwen3”部分。
    • 在 PyTorch 流程中添加了 HyperCLOVAX-SEED-Vision 支持。参考examples/models/contrib/hyperclovax/README.md
    • 在脚手架示例中添加了 Dynasor-CoT。参考examples/scaffolding/contrib/Dynasor/README.md
    • 在 TRT 工作流程中添加了 Mistral Small 3.1 24B VLM 支持
    • 在 PyTorch 工作流程中添加了 Gemma3-1b-it 支持
    • 添加了 Nemotron-H 模型支持
    • 添加了 Eagle-3 对 LLAMA4 的支持
  • PyTorch 工作流程
    • 添加了劳拉支持
    • 添加了返回日志支持
    • 在 PyTorch 流程中采用新的 logprob 定义
    • 使用 PyTorch 后端启用每个请求的统计信息
    • 在 PyTorch 后端启用 LogitsProcessor
  • 基准：
    • 添加波束宽度以降低延迟。
    • 修复 trtllm-bench iter_stats 和 cuda_graph_batch_sizes 错误。
    • 删除已弃用的 Python 运行时基准测试
    • 添加对脚手架的基准支持
  • 多式联运模型
    • 添加了 trtllm-serve 中的支持
    • 添加了trtllm-bench支持，目前仅支持图像
  • Hopper 支持 DeepSeek-R1 W4A8
  • 添加对单 GPU 的 RTX Pro 6000 支持
  • 集成 Llama4 输入处理器
  • 在 Blackwell 上添加了 CGA 缩减 FHMA 内核
  • 为 FlashInfer 启用分块上下文
  • 支持 MLA 的 KV 缓存重用
  • 添加了分段 CUDA 图形支持
  • 支持多种LoRA适配器和TP
  • 添加了 KV 缓存感知路由器，用于分类服务
  • 对本机支持的全神贯注
  • 添加了 group_rms_norm 内核以标准化单个运算符中的多个输入
  • 为 MoE 模块添加智能路由器
  • 添加了对 QKV 预处理内核的头大小 72 支持
  • 添加了 MNNVL MoE A2A 支持
  • 优化多模态模型中的大型嵌入表
  • 支持LLMAPI中的Top-K logprobs和prompt_logprobs
  • 通过执行器 API 在 TRT 工作流程中启用重叠调度程序

基础设施变化

  • TRT-LLM 团队在 NGC 上正式发布 docker 图像。
  • PyPI 上预构建的 TensorRT-LLM 轮现在与使用 CXX11 ABI 的 PyTorch 2.7.0 链接
  • 依赖的TensorRT版本更新为10.10.0
  • 依赖的CUDA版本更新为12.9.0
  • 依赖的公共PyTorch版本更新为2.7.0
  • 依赖的NVIDIA ModelOpt版本更新为0.29.0
  • 依赖的NCCL版本维持在2.25.1
  • 开源 XQA 内核
  • 相关数据集版本升级至3.1.0
  • 将 Triton 后端迁移到 TensorRT LLM 存储库到 TensorRT LLM 子模块
  • 将 gcc 工具集版本从 13 降级到 11

API 变化

  • [重大变更]：默认启用调度重叠
  • 从 TRT 工作流程中删除已弃用的 GptSession/V1
  • 将 _AutoDeployLlmArgs 设置为主要配置对象
  • 允许使用 trtllm-serve 中的 YAML 文件覆盖 CLI 参数
  • 在 LlmRequest 中引入了多模式嵌入字段

已修复的问题

  • 修复上下文服务器没有足够的 KV 缓存容量时的挂起错误 (#3095)
  • 修复 PyTorch 中的 C++ 解码器同步 (#3106)
  • 修复创建 cuda 流作为默认参数的错误，该参数将在导入过程中初始化 (#3764)
  • 修复与创建 CUDA 流作为默认参数相关的错误，该参数将在导入期间初始化 (#3764)
  • 修复 Qwen3 MoE 模型上的注意力 DP 错误 (#4141)
  • 修复在启用 CUDA Graph 的情况下运行 LLaMA 4 时的非法内存访问 (#4101)
  • 重置计划状态以避免 TrtllmAttentionWrapper 中的内存泄漏 (#4227)

已知问题

  • RTX Pro 6000 上的多 GPU 模型支持
