TensorRT-LLM v0.11.0

嗨， 我们非常高兴地发布 TensorRT-LLM 的 0.11.0 版本。本次更新包括：

主要功能和增强功能

  • 支持 LLaMA 的非常长的上下文（请参阅 examples/llama/README.md 中的“长上下文评估”部分）。
  • 低延迟优化
    • 添加了reduce-norm功能，旨在将AllReduce之后的ResidualAdd和LayerNorm内核融合为单个内核，建议在批量大小较小且生成阶段时间占主导地位时启用该功能。
    • 为 GEMM 插件添加了 FP8 支持，这有利于批量大小小于 4 的情况。
    • 在 SM90 上为 FP8 添加了融合的 GEMM-SwiGLU 插件。
  • LoRA 增强
    • 支持运行带有 FP16 LoRA 检查点的 FP8 LLaMA。
    • 添加了对量化基础模型和 FP16/BF16 LoRA 的支持。
      • SQ OOTB (- INT8 A/W) + FP16/BF16/FP32 LoRA​
      • INT8/ INT4 仅重量 (INT8 /W) + FP16/BF16/FP32 LoRA​
      • 仅重量分组 + FP16/BF16/FP32 LoRA
    • 在 Qwen2 中添加了 LoRA 支持，请参阅 examples/qwen/README.md 中的“使用 LoRA 运行模型”部分。
    • 添加了对 Phi-3-mini/small FP8 底座 + FP16/BF16 LoRA 的支持，请参阅 examples/phi/README.md 中的“使用 LoRA 运行 Phi-3”部分。
    • 添加了对 starcoder-v2 FP8 基础 + FP16/BF16 LoRA 的支持，请参阅 examples/gpt/README.md 中的“使用 LoRA 运行 StarCoder2”部分。
  • 编码器-解码器模型 C++ 运行时增强
    • 支持分页 KV 缓存和飞行批处理。 （#800）
    • 支持张量并行。
  • 支持 INT8 量化，不包括嵌入层。
  • 将 Whisper 的默认模型更新为 distil-whisper/distil-large-v3，感谢 @IbrahimAmin1 在 #1337 中的贡献。
  • 支持Python高级API自动下载HuggingFace模型。
  • 支持用于动态批处理的显式草稿令牌。
  • 支持本地自定义校准数据集，感谢@DreamGenX 在#1762 中的贡献。
  • 添加了批量 logits 后处理器。
  • 将 Hopper qgmma 内核添加到 XQA JIT 代码路径。
  • 支持为 MoE 一起启用的张量并行性和专家并行性。
  • 支持层数不能除以 PP 大小时的管道并行情况。
  • 将 numQueuedRequests 添加到执行器 API 的迭代统计日志中。
  • 将 iterLatencyMilliSec 添加到执行器 API 的迭代统计日志中。
  • 添加来自社区的 HuggingFace 模型动物园，感谢 @matichon-vultureprime 在 #1674 中的贡献。

API 变化

  • [重大变更] trtllm-build 命令
    • 将 Whisper 迁移到统一工作流程（trtllm-build 命令），请参阅文档：examples/whisper/README.md。
    • trtllm-build 命令中的 max_batch_size 默认切换为 256。
    • trtllm-build 命令中的 max_num_tokens 默认切换为 8192。
    • 弃用了 max_output_len 并添加了 max_seq_len。
    • 从 trtllm-build 命令中删除了不必要的 --weight_only_precision 参数。
    • 从 trtllm-build 命令中删除了 attention_qk_half_accumulation 参数。
    • 从 trtllm-build 命令中删除了 use_context_fmha_for_generation 参数。
    • 从 trtllm-build 命令中删除了 strongly_typed 参数。
    • max_seq_len 的默认值现在从 HuggingFace 模式配置中读取。
  • C++运行时
    • [重大变更] 将 ModelRunnerCpp 中的 free_gpu_memory_fraction 重命名为 kv_cache_free_gpu_memory_fraction。
    • [重大变更] 重构 GptManager API
      • 将 maxBeamWidth 移至 TrtGptModelOptionalParams。
      • 将 schedulerConfig 移至 TrtGptModelOptionalParams。
    • 为 ModelRunnerCpp 添加了更多选项，包括 max_tokens_in_paged_kv_cache、kv_cache_enable_block_reuse 和 enable_chunked_context。
  • [重大变更] Python 高级 API
  • 删除了 ModelConfig 类别，所有选项均移至 LLM 类别。
    • 重构了LLM类，请参考examples/high-level-api/README.md
      • 移动了显式参数列表中最常用的选项，并隐藏了 kwargs 中的专家选项。
      • 公开 model 以接受 HuggingFace 模型名称或本地 HuggingFace 模型/TensorRT-LLM 检查点/TensorRT-LLM 引擎。
      • 支持从 HuggingFace 模型中心下载模型，目前仅支持 Llama 变体。
      • 支持构建缓存，通过设置环境变量 TLLM_HLAPI_BUILD_CACHE=1 或将 enable_build_cache=True 传递给 LLM 类来重用构建的 TensorRT-LLM 引擎。
      • kwargs 中公开的低级选项包括 BuildConfig、SchedulerConfig 等，理想情况下您应该能够配置有关构建和运行时阶段的详细信息。
    • 重构了LLM.generate()和LLM.generate_async() API。
      • 删除了 SamplingConfig。
      • 添加了具有更广泛参数的 SamplingParams，请参阅 tensorrt_llm/hlapi/utils.py。
        • 新的 SamplingParams 包含并管理 SamplingConfig、OutputConfig 等的 Python 绑定中的字段。
      • 将 LLM.generate() 输出重构为 RequestOutput，请参阅 tensorrt_llm/hlapi/llm.py。
    • 更新了apps示例，特别是使用LLM API重写了chat.py和fastapi_server.py，详细信息请参阅examples/apps/README.md。
      • 更新了chat.py，支持多轮对话，允许用户在终端中与模型聊天。
      • 修复了 fastapi_server.py 并消除了多 GPU 场景中对 mpirun 的需求。
  • [重大变更] 推测解码配置统一
    • 引入 SpeculativeDecodingMode.h 以在不同的推测解码技术之间进行选择。
    • 引入用于推测解码技术的 SpeculativeDecodingModule.h 基类。
    • 删除了 decodingMode.h。
  • gptManagerBenchmark
    • [重大变更] gptManagerBenchmark 命令中的 api 现在默认为 executor。
    • 添加了运行时 max_batch_size。
    • 添加了运行时 max_num_tokens。
  • [重大变更] 向 LayerNorm 模块添加了 bias 参数，并支持非偏置层归一化。
  • [重大变更] 删除了 GptSession Python 绑定。

模型更新

  • 支持 Jais，请参阅 examples/jais/README.md。
  • 支持 DiT，请参阅 examples/dit/README.md。
  • 支持VILA 1.5。
  • 支持视频 NeVA，请参阅 examples/multimodal/README.md 中的 Video NeVA 部分。
  • 支持 Grok-1，请参阅 examples/grok/README.md。
  • 支持带有 FP8 PTQ 的 Qwen1.5-110B。
  • 支持具有块稀疏注意力的 Phi-3 小模型。
  • 支持 InternLM2 7B/20B，感谢 @RunningLeon 在 #1392 中的贡献。
  • 支持的 Phi-3-medium 型号，请参阅 examples/phi/README.md。
  • 支持Qwen1.5 MoE A2.7B。
  • 支持 phi 3 视觉多模式。

基础设施变化

  • TensorRT-LLM 的基础 Docker 映像已更新为 nvcr.io/nvidia/pytorch:24.05-py3。
  • TensorRT-LLM 后端的基础 Docker 映像已更新为 nvcr.io/nvidia/tritonserver:24.05-py3。
  • 依赖的 TensorRT 版本更新为 10.1.0。
  • 依赖的CUDA版本更新为12.4.1。
  • 依赖的 PyTorch 版本更新为 2.3.1。
  • 依赖的ModelOpt版本更新为v0.13.0。
