TensorRT-LLM v1.1.0

知道问题

  • 如果用户在 pyproject.toml 文件中创建带有 tensorrt-llm==1.1.0 的项目作为依赖项，如下所示： 
    dependencies = [
  "tensorrt-llm==1.1.0",
]
    当用户使用命令 uv sync 安装项目依赖项时，会发生错误并显示消息： 
    No solution found when resolving dependencies for split (markers: python_full_version >= '3.13' and sys_platform == 'darwin'):
╰─▶ Because patchelf==0.18.0.0 was yanked (reason: https://github.com/mayeut/patchelf-pypi/issues/87) and tensorrt-llm==1.1.0 depends on patchelf==0.18.0, we can
    conclude that tensorrt-llm==1.1.0 cannot be used.
    And because your project depends on tensorrt-llm==1.1.0, we can conclude that your project's requirements are unsatisfiable.".
    那是因为 patchelf 0.18.0 被作者拉走了。 解决此问题的有效方法是在 pyproject.toml 中添加块： 
    [tool.uv]
 override-dependencies = [
 "patchelf==0.17.2.4",
]

主要功能和增强功能

  • 模型支持
    • 添加 GPT-OSS、Hunyuan-Dense（@sorenwu 贡献）、Hunyuan-MoE（@qianbiaoxiang 贡献）、Seed-OSS（@Nekofish-Li 贡献）的模型支持。
  • 特点
    • 连接器 API：引入了新的 KV 缓存连接器 API，用于分类服务中的状态传输。
    • 重用和卸载：为 MLA（多头潜在注意力）启用 KV 缓存重用，并添加主机卸载示例。
    • 加盐：实现了 KV 缓存加盐以实现安全的缓存重用。
    • 引导解码集成：启用引导解码以与推测解码（包括 2 模型和草稿模型分块预填充）结合使用。
    • Eagle：添加了多层Eagle支持和优化。
    • CuteDSL：集成 CuteDSL NVFP4 为 Blackwell 分组 GEMM。
    • B300/GB300：添加了对 B300/GB300 的支持。
  • 文档
    • Deployment Guides: Added comprehensive deployment guides for GPT-OSS, DeepSeek-R1, and VDR 1.0.
    • 功能文档：为 KV 缓存连接器、LoRA 功能使用和 AutoDeploy 创建了新文档。
    • 技术博客：发表了有关“结合引导解码和推测解码”和“ADP平衡策略”的博客。
    • 快速入门：完善的快速入门指南，包含指向 ModelOpt 检查点的新链接和更新的安装步骤 (Linux/Windows)。
    • API 参考：通过明确标记稳定与不稳定的 API 来增强 LLM API 文档。
    • 性能：更新了在线基准测试文档和性能概述页面。
    • Examples: Refined Slurm examples and added K2 tool calling examples.
  • 基础设施的变化
    • TensorRT-LLM 的基本 Docker 映像：nvcr.io/nvidia/pytorch:25.10-py3。
    • TensorRT-LLM 后端的基本 Docker 映像：nvcr.io/nvidia/tritonserver:25.10-py3。
    • The dependent public PyTorch version: 2.9.0.
    • 依赖的 NVIDIA ModelOpt 版本：0.37。
    • 依赖的 xgrammar 版本：0.1.25。
    • The dependent transformers version: 4.56.0.
    • 相关 NIXL 版本：0.5.0。
  • API 变化
    • 重大变更：C++ TRTLLM 采样器现在默认启用，取代了旧版实现。
    • KV 缓存连接器 API：推出了新的 KV 缓存连接器 API。
    • Standardized topk logprob returns across TRT and PyTorch backends.
    • Added stable labels to arguments in the LLM class to better indicate API stability.
    • Wait and Cancel API: Added tests and support for handling non-existent and completed request cancellations in the executor.
  • 修复了多个问题
  • illegal memory access, weight loading issues for DeepSeek-R1 W4A8, CUDA graph warmup issues with speculative decoding, memory leaks
  • 已知问题
  • GB300 多节点：多节点配置中对 GB300 的支持目前处于测试阶段，在此版本中尚未经过完全验证。 GB300 多节点配置已在 1.2.0rc4+ 中得到验证。
