TensorRT-LLM v1.2.0

小版本 发布时间2026年3月12日 来源NVIDIA/TensorRT-LLM 英文原文

TensorRT-LLM v1.2.0

变更流程图

亮点

  • 模型支持
    • 添加了对 K-EXAONE、Nemotron Nano V3、Qwen3-Next 和 Qwen3-VL 的测试版支持。
    • 改进了 GPT-OSS、Nemotron、EXAONE、GLM、Starcoder2、Qwen3、KimiK2、DeepSeek v3.2 和 Mistral Large 3 支持和验证。
    • 扩展了 Blackwell/Hopper/Ampere 支持，包括 B300/GB200/GB300 和 SM120/SM121/SM103 路径。
    • 扩展的低精度和 MoE 功能 (FP8/NVFP4/MXFP4/INT4-AWQ)，包括路由和内核。
  • 特点
    • 推测性解码：
      • 为 DeepSeek v3.2 启用 MTP>1 支持
    • 分类服务：
      • 增加了动态扩展的服务发现机制
      • 添加了对取消请求的支持
      • 添加了 NIXL-LibFabric 支持
      • 添加了对 Mooncake 传输引擎作为缓存收发器后端的支持
    • 采样：
      • 使用 FlashInfer 采样实现批量采样
      • 添加了对在 PyTorch 后端中使用流模式增量返回 logprobs 的支持
      • 添加了对 TorchSampler 的光束搜索支持
    • 性能：
      • 改进了 TorchSampler 性能
      • 默认启用 PDL，并添加了对索引器 TopK 和其他内核的 PDL 支持。
      • 改进了 trtllm-gen 内核
      • 通过重叠调度程序启用提前退出
      • 添加了 NUMA 感知的 CPU 亲和性自动配置
    • 专家并行性：
      • 为 trtllm-gen 和 cutlass 后端启用 EPLB
      • 启用具有大 EP 的 CuteDSL MoE
      • 添加了对 DeepEP 的 CUDA 图形支持
      • 多项性能改进
    • 硬件：
      • DGX Spark 支持（测试版）
    • 其他：
      • 螺旋并行支持
      • 新的 Ray 协调器类型
  • 文档
    • 部署指南：
      • 添加了 KimiK2、Qwen3 和 Qwen3-Next 的全面部署指南。
      • 添加了有关 CPU 亲和性配置的新指南。
      • 更新了 GPT-OSS 指南。
    • 开发者指南：
      • 添加了有关 KV 缓存传输的开发人员指南。
      • 性能分析指南中关于 MoE 专家负载平衡分析（完美路由器）的新部分。
      • LLM API 变更指南中关于 API 变更原则的新部分。
    • 功能文档：
      • 为附加输出、螺旋并行、KV 缓存连接器、Ray Orchestrator、稀疏注意力以及 Torch 编译和分段 CUDA 图创建了新指南。
      • 还更新了功能组合矩阵和分页注意力、IFB 和请求调度指南。
    • 技术博客： 发布的博客：
      • “TensorRT LLM 中的扩展专家并行性（第 3 部分：突破性能边界）”
      • “在 NVIDIA Blackwell GPU 上优化 DeepSeek-V3.2”。
    • 示例：
      • 添加了有关分类服务发现方法的新部分。
      • 添加了 K-EXAONE、Nemotron Nano V2 VL 和 Nemotron Nano V3 的示例。
      • 添加了RocketKV使用文档。
  • 基础设施变化
    • TensorRT-LLM 的基础 Docker 映像已更新为 nvcr.io/nvidia/pytorch:25.12-py3。
    • TensorRT-LLM 后端的基本 Docker 映像已更新为 nvcr.io/nvidia/tritonserver:25.12-py3。
    • 依赖的公共 PyTorch 版本更新为 2.9.1。
    • 相关变压器版本更新为4.57.3。
  • 依赖的triton版本更新为3.5.1。
    • 依赖的 NIXL 版本更新为 0.8.0。
  • API 变化
    • 重大变更：
      • FlashInfer 采样现在默认与 PyTorch 后端一起使用。
      • 在一些先前未定义的情况下对采样策略进行了更改。
    • OpenAI API：
      • 使用 PyTorch 后端启用 n > 1
      • 添加了对 GET/DELETE v1/responses 的支持
  • 修复了多个问题
  • 已知问题
    • DGX Spark： DGX Spark 支持处于测试阶段。此版本中仅验证了单节点配置和上面列出的模型。
    • Disaggregated Serving: A hang may occur in disaggregated serving with context pipeline parallelism and generation tensor parallelism configurations.
