ego-lite v2.1.0

ego-lite v2.1.0

变更流程图

亮点

  • 插件分发 — PR #391 为九种 agent 宿主打包了 ego-browser 插件，PR #397 让 Codex 压缩包可以上传到公共插件目录；如果你通过插件目录安装，这个版本才提供可用的产物。
  • 破坏性变更：更严格的校验与 js() 语义 — PR #408 要求截图和 fetch 的 saveAs 使用绝对路径（相对路径会失败）；PR #419 在任何原生调用之前就拒绝非法的 task-space 定位器；PR #421 只在适当情况下才为 js() 源码自动包一层外层 return。迁移方式：把相对保存路径改成绝对路径、修正畸形的 task-space 定位器、给依赖隐式包装的脚本显式加上 return。
  • 自动化稳定性 — PR #415 在 JavaScript 对话框打开时让渲染器命令快速失败，而不是挂住；PR #450 不再把已完成或已移交的任务算到用户头上；PR #452 会把用户持有的 task-space 名称报告为占用。这些合在一起让长时间运行的 ego-browser 会话更可预测。
  • 跨平台与文档 — PR #409 在 Windows 上新增 keyboard.paste 剪贴板支持；PR #413 为 PowerShell 和 cmd 提供了各自的脚本调用形式；PR #406/#407 把 README 本地化为 8 种语言并刷新了英文版。风险低，主要惠及 Windows 用户和非英文读者。
  • 结论 — 不是空操作或重新打标：有实质性修复，外加常规的分支/发布整理（#392、#402、#472）。使用 ego-browser 自动化、Windows 或插件安装的值得升级；如果只看文档，或完全不涉及变化的 API/路径，可以放心跳过。
