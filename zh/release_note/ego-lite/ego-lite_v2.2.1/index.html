ego-lite v2.2.1

变更流程图

亮点

  • 新增 linear-autofix 工作流 — 增加了无人值守的 Linear → PR → 评审循环编排，并修复了在人工评论后重新打开评审、按 PR 自身 diff 评估评论、等待 Claude 用量重置、隔离 dry-run 状态、忽略无关工单等问题。用到这些自动化工具的值得升级；否则主要是增量特性。
  • ego-browser 可靠性与权限修复 — 待处理的导航现在会中断挂起的 evaluate 和 screenshot 操作；v1 点击保持在视口内；finish 能处理包含保留标签页的已认领空间；新的权限提示会在用户控制停止点中被命名。浏览器用户为了这些实打实的正确性修复应升级。
  • CDP 会话处理更严格 — ego-browser 现在拒绝在 cdp 参数里传入 sessionId。受影响的调用方需要迁移： 不要再在那里传会话覆盖，改用受支持的会话选择路径。没有明确列出其他破坏性变更。
  • E2E 反馈前移，但不再阻塞推送 — 真实浏览器门禁移到 pre-push 并缩短了耗时，失败用例改为在 PR 上报告，而不是阻止推送。反馈更快了，但强制策略发生了变化；依赖推送阻塞门禁的团队要考虑到这一点。
  • 维护版本，并非空操作 — 增加了更清晰的浏览器文档，稳定了指针、选择器、命中目标和 OOPIF 测试；原计划的 Pages 行为变更被回退。用 ego-browser 或 linear-autofix 的建议升级；不受影响的团队可以合理跳过。
