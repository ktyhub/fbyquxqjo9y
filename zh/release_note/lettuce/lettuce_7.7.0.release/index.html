lettuce 7.7.0.RELEASE

lettuce 7.7.0.RELEASE

变更流程图

亮点

  • Redis 8.10 命令支持 — Lettuce 7.7.0 为 Redis 8.10 新命令加入类型化 API：HIMPORT（批量哈希插入，按连接惰性 prepare，#3879）、LMOVEM/BLMOVEM（#3858）、SUNIONCARD/SDIFFCARD（#3874）、FT.ALIASLIST（#3844）、XREAD/XREADGROUP 的 MAXCOUNT/MAXSIZE 选项（#3859）、马来语和他加禄语词干分析器（#3792），以及 CLIENT NO-TOUCH（#3776）。跑 Redis 8.10 的话，这些让你不用退化到裸命令派发；否则这些新增是惰性的。
  • 概率数据结构（全新功能域） — 一等支持落地：Bloom filter（BF.*，#3760/#3759）、Cuckoo filter（#3774）、Top-K（#3780）、Count-min sketch（#3821）和 t-digest（#3823）。这是本次最大的新接口面，需要通过 Lettuce 命令接口用这些结构的用户有充分理由升级；不用的用户则一无所得。
  • Vector Sets 与 Search 正确性 — 为 Vector Sets 加 VISMEMBER（#3822），修复单元素向量的 VADD（#3802/#3806），另有搜索修复：FT.AGGREGATE 的 ADDSCORES 参数位置（#3833）、FT.HYBRID COMBINE 中 YIELD_SCORE_AS 的 token 计数（#3832）。注意：损坏的 FT.HYBRID 测试被禁用（#3877），所以部分 FT.HYBRID 行为仍未定案——依赖前先针对自己的负载验证。
  • 集群/响应式与传输可靠性 — 修复 ClusterTopologyChangedEvent 在新拓扑应用前就发布（#2860/#3791）、同步异常时重置拓扑刷新进行中标志（#3817）、去掉集群响应式 MGET 的平方级 key 顺序恢复（#3819）、修正流响应解析（#3801）和原生传输选项顺序（#3818）、jdk.net 模块缺失时回退到普通 SO_KEEPALIVE（#3864），并避免在 RedisURI 脱敏路径调用 Mono.block()（#3762）。对集群和响应式用户，或踩到特定 jdk.net/keepalive 问题的用户价值最大。
  • 兼容性、弃用与升级建议 — 运行时支持大体不变：Java 8+ 至 Java 24、Redis 2.6+ 至 8.x，在 8.10/8.8/8.6/8.4/8.2/8.0/7.4/7.2 上测试。未标注破坏性变更或迁移步骤；最接近的信号是「Deprecate commands」（#3682）和协程 multi DSL 弃用（#2371/#3771），属于前瞻性警告而非移除。「Commands API 接口一致性」被描述为非破坏性（#3865），生成器移除（#3866）是内部工具。需要 Redis 8.10 命令、概率结构、Vector Sets 或集群/流修复的应升级；老 Redis 且不受这些 bug 影响的可放心跳过。这是正常功能版本，不是重发 tag 或只改元数据。

Lettuce 团队很高兴地宣布 Lettuce 7.7.0 次要版本！

✨ 亮点

Lettuce 7.7.0 引入了对 Redis OSS 8.10 版本 中新功能的支持，例如：

  • 新命令：HIMPORT - 高吞吐量紧凑散列批量插入 - 用户指南
  • 新命令：LMOVEM、BLMOVEM - 在列表之间移动多个元素
  • 新命令：SUNIONCARD - 获取多个集合并集的基数
  • 新命令：SDIFFCARD - 获取集合之间差异的基数
  • XREAD、XREADGROUP - 新的 MAXCOUNT 和 MAXSIZE 参数用于限制累积回复条目和大小
  • 新命令：FT.ALIASLIST - 获取索引的所有别名
  • 对马来语和他加禄语的词干分析器支持

Redis 中概率数据结构的功能支持：

  • 布隆过滤器
  • 计数分钟草图
  • 布谷鸟滤镜
  • t-摘要
  • Top-K

生菜 7.7.0 支持 Redis 2.6+ 至 Redis 8.x。在 Java 运行时方面，Lettuce 至少需要 Java 8 和 适用于 Java 24。该驱动程序针对 Redis 8.10、Redis 8.8、Redis 8.6、Redis 8.4、Redis 8.2、Redis 8.0、Redis 7.4 和Redis 7.2。

感谢所有使 Lettuce 7.7.0.RELEASE 成为可能的贡献者。
