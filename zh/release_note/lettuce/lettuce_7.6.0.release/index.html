lettuce 7.6.0.RELEASE

变更流程图

亮点

  • Redis 8.8 命令支持 — 升级的头号理由：Lettuce 7.6.0 新增 Redis 8.8 新特性的 API 支持——新 Array 数据结构（PR #3745）、INCREX 窗口限流器（PR #3746）、显式释放待处理流消息的 XNACK（PR #3728）、ZINTER/ZINTERSTORE/ZUNION/ZUNIONSTORE 的 COUNT 聚合器（PR #3736）、JSON.SET 用于同构 FP 数组的 FPHA 参数（PR #3710），以及补全的 Search 语言（PR #3690）。这些都是增量能力——不瞄准 Redis 8.8 的话行为毫无变化。
  • Azure Managed Redis 修复 — 面向 Azure Managed Redis 的客户端可能报 ERR unknown subcommand 'MYID'（issue #3495，PR #3693 修复），破坏该服务的拓扑/副本发现。如果你跑在这上面，单凭这一条就值得升；否则无关。
  • RedisJSON 正确性 — 根路径的 JSON.ARRAPPEND 此前路径编码错误（PR #3715），现已修复。只影响做根路径数组追加的用户，但有的话值得带上。
  • 传输与依赖更新 — Netty 连升两次到 4.2.13.Final（PR #3723、PR #3751），另有单节点主/副本读取优化（PR #3758）。如果你钉住或共享该依赖，Netty 升级是要重点看的；读密集的单节点部署可能有小幅提升。CI token 加固（PR #3761、PR #3748）和基准/CI 修复对运行时无影响。
  • 升级结论 / 迁移 — 未声明破坏性变更、弃用或迁移步骤——标准 minor 版本（7.5.0.RELEASE → 7.6.0.RELEASE），仍支持 Java 8+ 至 Java 24、Redis 2.6+ 至 8.x。用 Redis 8.8、Azure Managed Redis、根路径 JSON.ARRAPPEND，或想要 Netty 升级的应升；如果还在 Redis ≤ 8.6 且这些都用不上，可以跳过——升级只带来依赖刷新和一点读优化。

Lettuce 团队很高兴地宣布 Lettuce 7.6.0 次要版本！

✨ 亮点

Lettuce 7.6.0 引入了对 Redis OSS 8.8 版本 的新功能的支持，例如：

  • 新的数组数据结构
  • INCREX：结合 INCR、INCRBY、INCRBYFLOAT、边界和过期的窗口计数器速率限制器
  • XNACK：一个新的流命令 - 允许消费者显式释放挂起的消息
  • ZUNION、ZINTER、ZUNIONSTORE、ZINTERSTORE：新的 COUNT 聚合器
  • JSON.SET：新的 FPHA 参数用于指定同构 FP 数组的 FP 类型

生菜 7.6.0 支持 Redis 2.6+ 至 Redis 8.x。在 Java 运行时方面，Lettuce 至少需要 Java 8 和 适用于 Java 24。该驱动程序针对 Redis 8.8、Redis 8.6、Redis 8.4、Redis 8.2、Redis 8.0、Redis 7.4 和 Redis 7.2 进行测试。

感谢所有使 Lettuce 7.6.0.RELEASE 成为可能的贡献者。
