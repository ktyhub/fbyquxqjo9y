archify v3.2.0

归档 v3.2.0

从 Markdown 创建结论优先的单页答案，其中包含引用的来源、交互式图表和浏览器导出。

添加

  • 单页答案（解释器）(#993)。 要求您的代理以页面形式回答，Archify 会根据 Markdown 草稿构建结论优先的解释器。每个小组使用散文、表格、步骤、清单、图表、代码和经过验证的本地图表回答一个问题。
    • 创作和交付： finalize explainer 验证、原子交付并检查页面。图表来自 Mermaid 栅栏或草稿旁边的 CSV/JSON 文件。存储库摘录是从固定提交中读取的。 patch explainer 通过 ID 替换一个面板。
    • 阅读：
      • 步骤位于他们所遍历的图表旁边，您可以逐步执行它们。
      • 文本和图表节点相互突出显示。
      • Clicking 节点会打开聚焦于该节点的完整查看器。
      • 引文和源链接节点开源卡。
      • 每个小组或选定的段落都会产生一个针对该小组的后续问题。
    • 共享： 该页面有四种风格（干净、社论、产品、瑞士），带有浅色和深色主题，并导出 PNG、WebP 或 JPG 长图像或打印为 PDF。
    • 示例： docs/cases/explainer/ 中的四个实时页面。
    • 信用： @goatliamia 的 #942 的一页文档方向塑造了这项工作。
    • 致谢： 感谢@QingYunA 提供的早期一页图表和解释提案和演示原型。

已修复

  • 解释器页面不再包含本地路径。 页面中嵌入的草稿会相对于该页面命名其源文件和数据文件，因此共享页面不会泄露作者的目录。 patch explainer 再次针对页面解析它们。
  • 解释器长图像保持页面的风格和主题。 深色页面或社论、产品或瑞士风格的 PNG、WebP 或 JPG 导出以浅色干净的风格出现，因为页面是在 SVG 内绘制的，其中 <html> 不是 :root。导出现在通过其自身的属性选择页面根目录。
  • 空白图表数据是一个错误，而不是零。 空的 CSV 单元格、JSON null 或图表列中的缺失字段不再成为零条。最终确定为列和行命名。
  • 工作流迁移语义契约 (#497)。 布局规划不再根据已删除路由边缘的临时图检查完整拓扑要求。迁移的文档保留其撰写的合同，并且必须在发布前通过完整的验证。
  • Timeline 时区刻度（#926）。 刻度按显示时区在各真实时刻的 UTC 偏移对齐，修复跨夏令时后日刻度漂移到 01:00／23:00、半小时跳变后小时刻度漂移的问题。回拨的重复时刻保持独立，跳过的小时或日期不生成虚构刻度；事件时间、标签精度、时间轴比例与断轴规则保持不变。

已更改

  • **阅读器控件和节点索引。**紧凑的底部索引行将描述保留在标题下方；菜单和移动键盘导航遵循修饰键。
  • 更新通知。 可用更新包括发布摘要和帮助更新的提议。网络故障仍然是非阻塞的。
  • 网站和可移植性。 双语主页和图库介绍一页答案，同时保留指南和来源支持的案例。浏览器发现、Windows 命令路径、源目录空白和临时工作树清理得到重点修复。

分布

  • 下载下面的 archify.zip。稳定更新通知将在存档验证后单独发布。
  • 单独版本的 DSH 插件不会随此版本重新发布；维护人员必须选择固定源并在单独的后续行动中完成其主机/包的验收。 完整 changelog: https://github.com/tt-a1i/archify/compare/v3.1.0…v3.2.0
