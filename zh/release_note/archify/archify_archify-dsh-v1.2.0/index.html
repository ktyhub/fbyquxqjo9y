亮点

  • 打包 Archify 3.3.0 稳定版 — PR #1464 把 Archify 3.3.0 打包进 DSH 0.2.2-rc.5；PR #1458/#1452 准备稳定版标识和发布产物。这是分发/打包版本，Archify 本身的功能没有变化。
  • 发布文档更新 — PR #1459 在 changelog、README 和官网补充了 Diagnosis、Story 视频和 PR 走查说明。第一次了解这个项目的话值得一看。
  • 查看器布局修复 — PR #1457 把底部节点索引对齐为统一网格；另外两处修复让页脚不再参与可读性和自适应溢出计算。风险很低，属于界面调整。
  • 要不要升级？ 如果你用的是 DSH 打包版，这个版本是 3.3.0 快照，修了查看器布局、补了文档，可以放心更新；如果你只关注 Archify 源码，这个版本对你没有变化。
