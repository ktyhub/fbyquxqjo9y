Archify DSH 1.0.0

@tt-a1i/archify-dsh@1.0.0 将 Archify 3.x 创作和交付流程引入 DeepSeek Harness 社区集成。它捆绑了 Archify 3.0.1，包括来自不可变源 7158026e852f3aa6578c741e673b46d7878c92c1 的 #704 的后标签技能安装修复。 Adapter 和 Archify 版本号是独立的。 支持的主机正是**@deepseek-ai/dsh@0.1.2-rc.1，节点为^22.19.0 || >=24.0.0**。 DSH 仍然是开发者预览版；该适配器的1.0合同不承诺与其他主机版本的兼容性。这是社区集成，而不是 DeepSeek 官方产品。

安装和升级

将 DSH 主机单独更新到支持的版本，然后在使用 Archify 的每个配置文件中运行以下命令：

dsh plugin --profile web add @tt-a1i/archify-dsh@1.0.0

相同的命令升级以前的插件。 Archify 3.x 包括创作的品牌标记、工作流程架构 v2、查看器本地化和可选的更新感知。仍然支持现有的 schema-v1 输入；现有的 HTML 保留其嵌入的查看器。请参阅Archify 3.0 升级说明。 此版本保留了单个 archify-plugin 文件系统技能提供程序。它不添加本机工具、运行时依赖项、生命周期脚本、遥测、凭据处理或自动插件升级。主机在代理沙箱外部评估包的有界 cordis.patch.yml 解析表达式。生成的文件仍然是普通的工作区文件，没有自动 Web 生成的文件芯片。 准备好的适配器0.2.0从未发布。已发布的 0.1.0 保持不变； 1.0.0 取代该候选者。
