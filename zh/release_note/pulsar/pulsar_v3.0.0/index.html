pulsar v3.0.0

重要通知

  • 将 RocksDB 版本升级到 7.9.2，以与 #20072 中 BookKeeper 的 RocksDB 依赖项保持同步
  • 在#19502中引入一致的哈希环来分配多个主题订阅的负载
  • 在 #19486 中对 java 消费者设置 DLQ 策略时删除默认的 30 秒 ackTimeout
  • 需要 authRole 是 proxyRole 才能在 #19455 中设置originalPrincipal
  • 在 #19377 中将 Elasticsearch 接收器空闲 cnx 超时更新为 30 秒
  • 当 newTransaction 时将检查的异常移至构建器中。在 #19356
  • TokenAuthenticationState：仅在 #19314 中验证令牌一次
  • OneStageAuth State：将authn移出#19295中的构造函数
  • 更新 AuthenticationProvider 以简化 #19197 中的 HTTP Authn
  • 删除 #19182 中 2.7 和 2.9 中已弃用的 AuthorizationProvider 方法
  • 弃用 #19180 中的阻塞 AuthorizationService、AuthorizationProvider 方法
  • 拒绝创建不存在的持久分区。在 #19086
  • 当 #18997 中没有代理拦截器时，省略 CommandAck 的副本
  • 在 #18712 中为 tls trust 证书使用正确的文件路径
  • 在 #18097 中为 Quorum 和 Netty 服务器启用证书刷新
  • 从 #17419 中的 Prometheus 指标中删除时间戳
  • 恢复 5895：修复 #17060 中的 redeliveryCount
  • 修复生产者/消费者权限无法在 #16018 中获取 v1/schema
  • 自动恢复默认 reppDnsResolverClass 到 #15640 中的 ZkBookieRackAffinityMapping
  • 允许在 #19432 中构建和推送多架构 Docker 图像
