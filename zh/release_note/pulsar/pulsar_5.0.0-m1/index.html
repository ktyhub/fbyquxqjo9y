pulsar v5.0.0-M1

pulsar v5.0.0-M1

这个项目是干啥的：一个分布式消息与流处理平台，负责在服务之间可靠地传递海量实时数据，给要搭建高并发数据管道的后端和数据工程师用。

2026-06-23

Apache Pulsar 5.0.0-M1 是 Apache Pulsar 5.0.0 道路上的第一个里程碑版本，预计将于 2026 年晚些时候全面上市。这是一个预览：一个早期版本，将 5.0 的主要新功能放在您的手中，以便您可以在实际工作负载中尝试它们，并在 GA 发布之前发送反馈。它不用于生产。有两个变化很突出 - 可扩展主题，一种可以自行增长和缩小的新主题类型，以及将 Oxia 提升到 Pulsar 推荐的元数据存储 - 同时将构建系统迁移到 Gradle、将 IO 连接器拆分为单独的存储库以及结构化日志记录。

有关完整演练，请参阅公告：Apache Pulsar 5.0.0-M1：下一个主要版本的预览。

亮点

可扩展主题（主题 v5）。 一种新的主题类型，用基于范围的段替换固定分区，因此主题可以通过透明地拆分和合并段来扩展和缩小，同时保留每个键的排序。这可以避免因更改常规分区主题的分区计数而导致的顺序破坏和操作漂移。这项工作涵盖代理端控制器 (PIP-468)、元数据驱动事务 (PIP-473)、常规到可扩展主题迁移 (PIP-475) 和自动拆分/合并 (PIP-483)。请参阅 PIP-460。

新的 V5 Java client API。 用于可扩展主题的全新、专用的 client API，作为新的附加 pulsar-client-v5 模块提供 - 现有的 pulsar-client 和 pulsar-client-api 模块保持不变，因此当前的应用程序可以继续运行。它用三种专用消费者取代了经典的 Consumer/Reader 和四种订阅类型：QueueConsumer（并行、单独确认的工作队列消耗，支持死信）、StreamConsumer（有序、累积确认）和 CheckpointConsumer（用于跟踪自己位置的 Flink 和 Spark 等流处理器）。 V5 client 还适用于现有的分区和非分区主题，消费者可以订阅整个命名空间。在 M1 中，它支持 Java；其他语言 SDK 将在 GA 之前推出。请参阅 PIP-466。

Oxia 现在是推荐的元数据存储。 Oxia 成为 5.0 中新 Pulsar 集群的推荐元数据存储，并且是可扩展主题的首选后端，其查找建立在其流式观看会话之上。 ZooKeeper 仍然得到完全支持，并且 PIP-454 添加了一个实时、零停机迁移框架，可将现有集群从 ZooKeeper 移动到 Oxia，同时数据平面保持发布和使用。

构建系统从 Maven 迁移到 Gradle。 构建现在使用 ./gradlew 而不是 mvn，具有任务级缓存和并行性，可大大减少本地和 CI 构建时间，以及用于依赖项管理的中央版本目录 (gradle/libs.versions.toml)。对于使用已发布的 Maven 工件、Docker 映像和着色的 client JAR 的用户来说，迁移是透明的。请参阅 PIP-463。

IO 连接器拆分为单独的存储库。 内置的 Pulsar IO 连接器已从核心存储库中移出，以便它们可以遵循自己的发布节奏。请参阅 PIP-465。 结构化日志记录。 Pulsar 现在通过 slog 跨代理、client、托管账本、函数和元数据模块发出结构化日志，并具有平面 JSON / OpenTelemetry 日志输出和 PULSAR_LOG_FORMAT 环境变量以轻松切换格式。请参阅 PIP-467。

API 和平台现代化。 Pulsar 从 javax.* 迁移到 jakarta.* APIs (PIP-472)，将 Protobuf v4 设为默认值，将 REST API 注释从 Swagger 迁移到 OpenAPI 3，现在支持在 Java 25 上构建和运行。策略获得了遗留感知、元数据存储支持的路由后端 (PIP-469)。

安全和依赖项更新。 此版本捆绑了大量依赖项升级，可解决 Netty、Jetty、log4j、BouncyCastle、Thrift、vert.x 和 async-http-client 中的众多 CVE，并将 BookKeeper 升级到 4.18.0。请参阅下面的库更新。

重要通知

5.0.0-M1 是一个主要版本，删除了已弃用的功能并更改了一些 API。升级前请检查以下内容：

  • javax.* → jakarta.* 迁移（PIP-472）。 自定义代理插件、拦截器、身份验证/授权提供程序或引用 javax.* 包（例如 javax.ws.rs 或 javax.servlet）的其他扩展必须更新为相应的 jakarta.* 包并重新编译。
  • 删除了 Etcd 元数据存储后端 (PIP-462)。 使用 Etcd 作为元数据存储的部署必须在升级之前迁移到 ZooKeeper 或 Oxia。
  • IO 连接器移至单独的存储库 (PIP-465)。 连接器不再从核心 Pulsar 存储库中发布；从专用连接器项目中获取它们。
