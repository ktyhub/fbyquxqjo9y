pulsar v3.2.1

修订 发布时间2024年3月8日 来源apache/pulsar 英文原文

pulsar v3.2.1

经纪人

  • 始终向 REST API 添加细粒度授权 #22202
  • 向保留管理员 API 添加细粒度授权 #22163
  • 删除分区主题失败时打印非日志 #22153
  • 修复代理在启用事务和可扩展负载管理器时无法启动的问题 #22139
  • 在分配和释放时返回 getOwnerAsync，无需等待源代理，并在角色初始化期间处理角色更改 #22112
  • 当发送到系统主题时缓存内部编写器。 #22099
  • 由于确认和传递并发性，启用批处理会导致负的 unackedMessages #22090
  • 支持运行 gid != 0 的 docker 容器 #22081
  • 添加错误日志以解决启动代理注册表失败的问题 #22065
  • 显式设置 ServiceUnitStateChannel 主题压缩阈值，改进 getOwnerAsync，并修复其他错误 #22064
  • 修复使用以数字结尾的消费者名称时的哈希冲突 #22053
  • 在登录 apply-config-from-env.py 脚本之前清理值 #22044
  • 修复无法使用后缀匹配的正则表达式订阅分区主题的问题 #22025
  • 不保留系统主题中的数据 #22022
  • 由于调用 Admin APIanalyzeSubscriptionBacklog，订阅被卡住 #22019
  • 当主题元不存在并且不期望创建新主题元时，不要尝试打开 ML #22004
  • 调用管理员 API 且主题不存在时响应 HTTP-404 时不打印错误日志 #21995
  • 如果由于 LockBusyException 导致查找失败，请勿关闭套接字 #21993
  • 支持在 PersistentMessageExpiryMonitor 中动态设置 autoSkipNonRecoverableData #21991
  • 添加健康检查超时读取#21990
  • 修复删除具有多个分区和架构的分区主题时的架构删除错误 #21977
  • 如果所有者处于非活动状态，则推迟所有权检查 (ExtensibleLoadManager) #21811
  • 修复消息过期时压缩/复制数据丢失的问题 #21865
  • 如果未配置，则跳过加载 NAR 包 #21867
  • 改进 NamespaceUnloadStrategy 错误消息 #21880
  • 不要根据不活动滚动空账本 #21893
  • 根据账本关闭时间使消息过期，以避免 client 时钟偏差 #21940
  • 修复阅读器在禁用读取压缩模式的情况下读取压缩主题时卡住的问题 #21969

Client

  • 修复多主题消费者在搜索后可能收到旧消息的问题 #21945
  • 修复 ConsumerBuilderImpl#subscribe 在 2.12.0 之前使用 pulsar-client:3.0.x 和 jackson-annotations 时卡住的静默问题 #21985

Pulsar IO 和 Pulsar 函数

  • [FN] 添加连接器和功能包 url 源的配置 #22184
  • [FN] 将缺少的“异常”参数添加到某些 log.error #22140
  • [FN] 防止 putstate 使用空值 #22127
  • [FN] 通过延迟加载和直接 zip/字节码访问优化 Function Worker 启动 #22122
  • [FN] 防止通过 API 调用不存在的实例创建状态表 #22107
  • [FN] 使用统一的 PackageManagement 服务下载软件包 #21955

CLI

  • [管理员] 向管理员公开卸载阈值（以秒为单位）#22101
  • [CLI] 修复使用 -T 设置保留指定大小时的错误 #22150
  • [CLI] 当 —bundle 为空时设置 —destinationBroker 时出错 #21879

其他

  • [MISC] 添加对输入时间值的检查 #22023
  • [代理]添加对尚不支持多uri的brokerServiceURL的检查#21972
  • [TX] 通过托管账本获取先前位置 #22024
  • [ML]修复删除账本失效的重试机制#21869
  • [ML] 在从账本读取条目之前过滤掉已删除的条目 #21739

库更新

  • 将 Jetty 升级到 9.4.54.v20240208 以解决 CVE-2024-22201 #22144
  • 将 commons-compress 升级为 1.26.0 #22086
  • 将 BookKeeper 依赖项升级到 4.16.4 #21983
