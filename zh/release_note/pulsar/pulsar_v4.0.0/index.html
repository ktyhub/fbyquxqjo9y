pulsar v4.0.0

2024年10月21日

自 3.3.0 发布准备工作开始以来，4.0.0 版本发生了变化。 如需完整列表，请查看完整 changelog 和 完整 PR 列表。 Apache Pulsar 4.0 的新增功能？ 涵盖以下主题：

  • 增强Key_Shared订阅实现
  • 基于 Alpine Linux 和 Java 21 的安全 Docker 运行时
  • 增强多租户部署的服务质量控制
  • 速率限制作为多租户资源管理的基础
  • 之前版本的升级路径
  • Client 兼容性以及升级 Java client 以解决 CVE-2024-47561 的重要性
