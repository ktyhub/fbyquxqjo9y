pulsar v3.0.15

修订 发布时间2025年11月17日 来源apache/pulsar 英文原文

2025-11-17

库更新

  • [改进][杂项]将 Netty 升级到 4.1.128.Final (#24911)
  • [修复][秒] 将 io.vertx:vertx-web 从 4.5.10 更改为 4.5.22 (#24889)
  • [修复][秒]将 BouncyCastle FIPS 升级到 2.0.10 以修复 CVE-2025-8916 (#24923)
  • [修复][秒]将 Jetty 升级到 9.4.58.v20250814 以解决 CVE-2025-5115 (#24897)
  • [修复][秒] 将 Spring 升级到 6.2.12 以修复 CVE-2025-22233 和 CVE-2025-41249 (#24903)
  • [改进][ci] 升级 GitHub Actions 工作流程以使用 ubuntu-24.04 (#24841)

经纪人

  • [修复][broker]在策略缓存清理期间避免 ConcurrentHashMap 中的递归更新（#24939）
  • [修复][broker]当光标 mdPosition 位于打开的分类帐上时，BacklogMessageAge 不会重置（#24915）
  • [修复][经纪人]修复TransactionBufferDisable中的getMaxReadPosition应该返回最新的（[#24898]（https://github.com/apache/pulsar/pull/24898））
  • [修复][broker]修复关闭连接时由于竞争条件导致的堆栈溢出（#24934）
  • [修复][broker]修复从非持久调度程序中删除消费者时totalAvailablePermits不会减少（#24885）
  • [修复][代理] Flaky-test：ExtensibleLoadManagerImplTest.testDisableBroker (#24770)
  • [修复][broker] 仅在注册租户/命名空间时运行 ResourceGroup 任务 (#24859)
  • [修复][broker]如果复制器已终止，则停止重试读取条目（#24880）
  • [修复][broker] 对于不存在的主题仅触发一次主题创建事件 (#24802)
  • [修复][管理员]设置本地策略会覆盖命名空间创建期间传递的“捆绑包数量”(#24762)
  • [修复][ml] 修复 getNumberOfEntries 可能指向已删除的分类帐 (#24852)
  • [fix][txn] 修复并发错误导致 txn 卡在 TransactionBufferHandlerImpl#endTxn (#23551)
  • [cleanup][broker][branch-3.0] 删除因择优挑选而导致的无操作配置（#24960）

Client

  • [修复][client] 修复 getPartitionedTopicMetadata 的重复数据删除以包含方法参数 (#24965)
  • [修复][client] 修复 PartitionedTopicProducerStatsRecorderImpl 的 getPendingQueueSize：避免 NPE 并实现聚合 (#24830)
  • [修复][client] 修复 ServiceUrlProvider 使用的 reloadLookUp 方法中的线程泄漏（#24794）
  • [修复][client] 使自动分区更新适用于没有 PIP-344 的旧代理（#24822）
  • [改进][client]为 Pulsar client 时钟配置添加空检查 (#24848)
  • [修复] 修复混合查找/分区元数据请求导致可靠性问题和错误响应 (#24832)

测试和 CI

  • [修复][build]删除 settings.xml 中导致 gpg 签名失败的无效配置文件 (#24812)
  • [修复][测试] 修复不稳定的 KeySharedSubscriptionBrokerCacheTest.testReplayQueueReadsGettingCached (#24955)
  • [修复][测试] 修复不稳定的 NonPersistentTopicTest.testProducerRateLimit (#24951)
  • [修复][测试] 修复不稳定的 ReplicatorTest.testReductionAfterBacklogRelaxed (#24904)
  • [修复][测试] 通过仅在查找后计算订阅来修复不稳定的 SubscriptionSeekTest.testSeekWillNotEncounteredFencedError (#24865)
  • [修复][测试]修复无效测试 NonPersistentTopicTest.testProducerRateLimit (#24957)
  • [修复][测试]首次发布后通过隔离来稳定 SequenceIdWithErrorTest 以避免空账本删除和发送超时 (#24861)
  • [修复][测试]通过可靠地触发非持久性发布者删除来稳定 testMsgDropStat (#24929)
  • [改进][ci] 将复制测试移至 Pulsar CI 中的新组 Broker Group 5 (#24917)
  • [fix][ci][branch-3.0] 删除 Docker 文件中的 UBUNTU_MIRROR/UBUNTU_SECURITY_MIRROR 支持，因为它已损坏
  • [修复][测试][branch-3.0] 向后移植测试用例，以便在分支-3.0 中编译 如需完整列表，请查看完整 changelog。
