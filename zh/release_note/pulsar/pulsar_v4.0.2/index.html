pulsar v4.0.2

此版本中的已知主要问题

此版本包含一个通过时间戳影响 seek 方法的已知问题。该问题是在版本发布后报告的。

  • [Bug] 按时间戳查找会导致订阅重置到最早的位置 (#23910) 该问题的解决方法： 该问题是由 #22792 中引入的更改引起的。要解决此问题，请通过设置以下配置来禁用该功能：
managedLedgerCursorResetLedgerCloseTimestampMaxClockSkewMillis=-1

解决方法配置说明：

  • 此配置密钥需要手动添加到您的 broker.conf 文件中，因为默认情况下它不存在
  • 对于 Apache Pulsar Helm Chart Kubernetes 部署，请将以下内容添加到 broker/configData 部分下的 value.yaml 文件中：
broker:
  configData:
    PULSAR_PREFIX_managedLedgerCursorResetLedgerCloseTimestampMaxClockSkewMillis: "-1"
