pulsar v4.0.3

2025-02-27

已知问题

由于 https://github.com/apache/pulsar/pull/23931 更改，消费消息可能会失败，因此存在潜在的回归问题。 https://github.com/apache/pulsar/pull/24055 和 https://github.com/apache/pulsar/pull/24089. 正在解决此问题，目前不存在解决方法。
