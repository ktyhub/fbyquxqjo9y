DocsGPT 0.14.0

小版本 发布时间2025年6月19日 来源arc53/DocsGPT 英文原文

DocsGPT 0.14.0

变更流程图

亮点

  • 代理式检索与回答 — 代理-检索器工作流与日志栈（#1648）、ReActAgent 重构（#1721）以及代理辅助回答/搜索（#1693），支持多步、工具驱动的检索，而不再只依赖一次性生成。API 客户端应在 #1734 修复后验证 /api/answer 的 thought 参数处理。
  • 可扩展工具与提供方 — 工具调用现被追踪（#1630），无效工具名得到处理（#1625），工具结果被缩短以获得更干净输出（#1774）。新增 Brave（#1684）、ntfy（#1692）和 ReadWebpage（#1792）工具扩展代理能力；Novita 支持（#1689）和 Azure OpenAI 签名修复（#1702）拓宽提供方选择。LLM handler 重构（#1824）后请重新测试自定义集成。
  • 可复用代理与访问控制 — Webhook（#1755）、分享与置顶（#1775、#1801）、文档代理（#1806）和图片上传/检索（#1849）让代理更适合团队及外部工作流。JWT 认证与 token 管理（#1701）以及分析与反馈（#1647）增加了身份与用量可见性；在广泛启用前请审查权限及 webhook payload 暴露。
  • 知识库维护与渲染 — 分块现在可查看、添加和删除（#1624），让开发者直接控制检索上下文——但变更会影响回答质量与引用。上传重构（#1621）、文件系统抽象（#1742）、附件存储变更（#1768）和非 ASCII 文件名处理（#1838）提升了摄取健壮性，而 Mermaid 集成（#1732）支持富图表文档。
  • 部署与组件兼容性 — React widget 升级到 0.5.1 并支持来源展示（#1637、#1809）；请更新任何固定版本的 widget 资源。Docker 修复涉及 .env 加载、卷/用户、OPENAI_BASE_URL 及 Ollama 连通性（#1700、#1790、#1791），Arm 构建和 Windows 安装拓宽部署选项（#1615、#1729）。在重大依赖升级后请重新测试自定义前端和提供方代码，包括 react-redux 9（#1524）和 google-genai 1.x（#1652）。
  • 破坏性变更 — 本更新日志未宣布。
