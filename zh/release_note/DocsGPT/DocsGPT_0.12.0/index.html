DocsGPT 0.12.0

变更流程图

亮点

  • 扩展文档摄取 — 新增 .xlsx（#1184、#1349）、.pptx（#1405）和 JSON（#1377）解析器，让 Office 和结构化数据仓库更容易索引。GitHub loader 也安全地处理二进制文件（#1337）；在批量摄取前请用代表性文件验证上传白名单和抽取质量。
  • 更多向量库选项与检索修复 — LanceDB 支持（#1122）、Milvus 修复（#1407），以及改进的 FAISS 错误处理、类型标注和文档（#1183）增强了后端灵活性。请在索引副本上测试更新后的迁移脚本（#1198），并对流式检索器选择（#1314）和空文档行为（#1384）做回归检查。
  • 新模型与集成路径 — Groq LLM 支持（#1246）新增一个提供方选项，文本转语音（#1397、#1381）和 Slack 集成（#1346）启用新的投递渠道。Discord 修复（#1401–#1403）改进格式和消息分块；上线前请验证提供方凭据、机器人权限和速率限制。
  • 技术内容渲染更佳 — Markdown 公式支持（#1190）、空表格处理（#1178）和表格重设计（#1300）提升了文档密集型回答的可读性。现有文档应检查表格布局与公式渲染是否回退。
  • React widget 升级到 v0.4.7 — 快速迭代（#1415、#1418、#1424、#1426）新增自定义尺寸和默认展开行为（#1389）、更平滑的过渡（#1423、#1425），并修复杂散的 undefined 输出（#1355）。升级前请固定 widget 版本并对嵌入做视觉回归测试。
  • 破坏性变更 — 未宣布。
