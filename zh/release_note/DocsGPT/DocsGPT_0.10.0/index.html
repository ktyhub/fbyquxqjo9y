DocsGPT 0.10.0

小版本 发布时间2024年7月18日 来源arc53/DocsGPT 英文原文

DocsGPT 0.10.0

变更流程图

亮点

  • 国际化正式上线 — 通过 i18next 接入了完整的国际化能力（#969），新增日语（#987）和普通话（#991）翻译，并支持自动识别用户浏览器语言环境（#1032），对话历史下拉框也完成了翻译（#972）。这是 0.10.0 的头号特性：只要你的用户中有非英文用户，升级后无需逐用户配置即可拿到本地化界面；纯英文部署除了底层重构之外收益不大。

  • 新增部署与分享能力 — 加入了 Kubernetes 部署清单（#963）、分享端点（#1034），以及针对向量的 token 计量（#964）和面向用户展示的费用单位（#990）。已在 k8s 上推进标准化的自托管用户有了官方支持路径，需要统计 embedding/LLM 成本的团队也获得了可见性；仍在使用普通 Docker、或没有成本统计需求的运维可以把这些当作可选项。

  • 对话体验与可靠性修复 — 新增清空聊天记录按钮（#929）、调整对话历史上限的下拉框（#965）、代码片段复制按钮（#955），以及从远程来源一点回到原始 URL 的可点击链接（#970）。同时修复了对话空回复（#967）、改进了 /stream 错误处理（#1002）、远程上传错误（#933）、API 密钥解析（#952）以及移动端溢出/断词问题（#942）。如果你的用户天天都会撞上这些前端和流式问题，值得升级。

  • 安全与依赖维护 — 多项升级带有实际安全意义：braces 3.0.2→3.0.3（#1006、#1011、#1029、#1033）修复了一个已知的 ReDoS 公告，此外还有 werkzeug 3.0.1→3.0.3（#939）、requests 2.31.0→2.32.0（#961）、next 14.0.4→14.1.1（#943）和 qdrant-client 1.8.2→1.9.0（#979）。即使上面的特性一个都不想要，仅凭这些也足以让对外提供服务的实例升级。

  • 升级注意事项与可跳过人群 — 没有正式的破坏性变更说明，但有三处需要核对：celery.py 被重命名（#994），任何引用该路径的自定义脚本、服务定义或 CI 都会中断；embeddings 的实例化被重构为单例（#996），llama_cpp 中也做了对应的单例修复（#1013），如果你在代码层面做集成需要留意；基础镜像切换到 Ubuntu 24.04（#1000），并更新了多平台构建目标（#958），所以要验证你的构建/拉取流水线。如果你还跑在稳定的 0.9.x 上，且不需要 i18n、k8s 或这些安全补丁，可以暂缓。
