appsmith v2.5.1

修订 发布时间2026年10月21日 来源appsmithorg/appsmith 英文原文

appsmith v2.5.1

这个项目是干啥的：一个低代码内部工具平台，拖拖拽拽就能做出管理后台和仪表盘，还能接数据库和接口，适合想快速做工具的开发者。

变更架构图

亮点

  • 破坏性部署变更 — docker.env 现在按字面数据校验和加载，不再当作 shell 代码。未解析的 shell 表达式会阻止启动；升级前请把 JVM 选项移到 Docker Compose 或 Helm 环境配置中，并把表达式替换为已解析的值。生成的默认值和 Admin Settings 里的值无需改动。(#42225)
  • 安全加固改变行为 — 内置依赖做了漏洞更新，MongoDB 替换现在能以线性时间处理超大或畸形输入，主题列表需要编辑权限。更重要的是，SMTP 数据源在测试和发送时都会强制受限主机策略，升级后通往被屏蔽目标的连接会失败。通过 MCP 认证的 Git 请求不再能检出远程分支或标签。自托管管理员应在升级前审计 SMTP 目标和 MCP Git 工作流。(#42343, #42398, #42380, #42392, #42399, #42414)
  • 注册滥用防护 — 表单式自助注册现在限制为每个客户端 IP 每 24 小时 20 次请求。自定义代理必须设置 X-Forwarded-For，否则用户会共用代理的限流桶；邀请和超级用户设置不受影响。(#42351)
  • Appsmith AI 已经停止服务 — 本版本并非新禁用 Appsmith AI：无论是否升级，现有查询早已停止工作。请把残留查询迁移到直连 OpenAI、Anthropic 或 Google AI 数据源；单靠升级无法恢复它们。
  • 针对性的可靠性与编辑器改进 — Ask AI 现在正确授权 widget 属性绑定，并发创建 JS action collection 不再丢失 action，MCP 治理和分支创建流程更健壮。MCP SQL 新增空过滤器跳过和 PostgreSQL 列表值过滤器，编辑器能识别 Blob、File、FormData、URL 及文本编码器等 API。使用这些工作流的团队应升级；其他用户主要获得安全修复，以及较小的电话字段、必填标记和配置改进。(#42383, #42408, #42412, #42413, #42373, #42376, #42381)

🗑️ 功能删除提醒

Appsmith AI 已于 2026 年 9 月 30 日终止生命周期。

您无法再添加新的 Appsmith AI 数据源连接或查询。无论您是否升级，现有查询都已停止工作。

将剩余的 Appsmith AI 查询迁移到直接提供商数据源，例如 OpenAI、Anthropic 或 Google AI。

⚠️ 重要升级说明

  • 定制的 docker.env 文件现在必须包含已解析的文字值。 Shell 表达式通过经过编辑的诊断来停止启动。升级之前，将 JVM 选项从 docker.env 移动到 Docker Compose 或 Helm 环境配置。生成的默认值和管理设置值无需更改。 (#42225)
  • 基于表单的自助注册现在限制为每个 client IP 每 24 小时最多 20 个请求。自定义代理后面的实例应确保它设置 X-Forwarded-For；否则注册者可以共享代理的速率限制存储桶。邀请和超级用户设置不受影响。 (#42351)

🔐 安全

  • 更新了捆绑依赖项以解决报告的漏洞。 （[#42343]（https://github.com/appsmithorg/appsmith/pull/42343），[#42398]（https://github.com/appsmithorg/appsmith/pull/42398））
  • MongoDB 智能替换现在可以在线性时间内处理大型且格式错误的输入，同时保留有效的特殊类型值。 (#42380)
  • 应用程序主题列表现在需要编辑权限。已发布的应用程序继续以其当前主题呈现。 (#42392)
  • SMTP 数据源连接现在在测试和发送电子邮件时强制执行受限主机策略。升级后，指向被阻止目标的现有数据源将停止连接。 (#42399)
  • Docker 环境配置现已验证并作为数据而不是 shell 代码加载。 (#42225)
  • 经过 MCP 验证的 Git 请求无法再签出远程分支或标签。本地分支机构工作流程继续运行。 (#42414)
  • 自助注册现在有每个 client-IP 的速率限制。 (#42351)

🛠️ 可靠性

  • Ask AI 现在授权针对应用程序的小部件属性绑定，而不是将小部件 ID 视为操作 ID。 (#42383)
  • 同时创建 JS 操作集合不再因为共享列表竞争而丢弃操作或失败。 (#42408)
  • MCP 治理审计工具现在可以从用户配置文件中获取调用者的组织范围。 (#42412)
  • MCP 分支创建现在最多等待 120 秒，并在重试找到该分支时返回现有分支的应用程序 ID 和编辑器 URL。 (#42413)

✨ 新功能和增强功能

  • MCP 结构化 SQL 查询可以跳过空过滤器值并使用列表值 PostgreSQL 过滤器。新的过滤栏配方解释了如何安全地组合控件、查询和事件。 （[#42373]（https://github.com/appsmithorg/appsmith/pull/42373），[#42376]（https://github.com/appsmithorg/appsmith/pull/42376））
  • 编辑器现在可以识别受支持的工作线程 API，例如 Blob、File、FormData、URL 和文本编码器，而不会出现错误的未定义变量错误。 (#42381)

🎨 UI 和小部件改进

  • 当国家/地区共享拨号代码时，电话输入和 JSON 表单电话字段现在可以保留正确的国家/地区和标志。圭亚那、开曼群岛和梵蒂冈城的拨号代码数据也已更正。 (#42372)
  • 具有必需切换功能的旧版小部件现在一致地显示所需标记。 (#42379)

🔧 Git、部署和配置

  • 设置 APPSMITH_DISABLE_HELP_ICON=true 以隐藏编辑器和应用程序页面中的帮助入口点。该设置默认为关闭。 (#42378)
  • 自定义域设置现在解释了接受的格式并在保存之前拒绝协议、路径和空格。 (#42405)
