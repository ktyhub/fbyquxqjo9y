appsmith v2.4

小版本 发布时间2026年9月9日 来源appsmithorg/appsmith 英文原文

appsmith v2.4

这个项目是干啥的：一个低代码内部工具平台，拖拖拽拽就能做出管理后台和仪表盘，还能接数据库和接口，适合想快速做工具的开发者。

变更架构图

亮点

  • Appsmith AI 停止服务（破坏性，硬性截止） — Appsmith AI 将在 2026-09-30 到达 EOL，比 v2.4 晚三周。新的 AI 数据源连接/查询自 v2.3 起已被阻断，但现有的只工作到该日期，之后无论是否升级都会停止。请在此之前把所有残留的 Appsmith AI 查询迁移到直连 OpenAI、Anthropic 或 Google AI 数据源；v2.4 专门刷新了这三家的模型列表，以便当前模型可用于迁移。(#42114)
  • Admin env API 密钥脱敏（对自动化是破坏性变更） — GET /api/v1/admin/env 现在会脱敏敏感值，可编辑的 MongoDB 和 Redis URL 字段被替换为只读的连接状态指示器。任何抓取这些值的脚本或自动化都必须更新。提交脱敏后的值会被视为”未改动”，因此现有配置会保留而非被覆盖。(#42169)
  • 嵌入式 MCP Server（BETA，需主动开启） — 新的 Model Context Protocol server 让兼容的 AI 客户端通过结构化工具 API 构建/编辑应用；agent 不会编写原始 widget DSL、SQL、JS 或 {{ }} 绑定，工具在调用者自己的权限下编译（不提权）。它在全新安装和升级上都默认关闭，所以升级到 v2.4 不会暴露 agent 端点——通过 Admin Settings → Instances → MCP Server (BETA) → Save & Restart 启用（Cloud 自定义组织账户用 Organizations）。访问使用 Profile → MCP keys 下的每用户密钥，有效期 30/60/90/180/365 天（默认 30），未撤销的密钥最多 10 个，密钥只显示一次；关闭 server 会拒绝密钥但不会撤销它们。破坏性操作需要绑定到目标及其当前内容版本的 prepare_* → confirm_* 审批握手；Git 连通的应用必须指定当前分支，Git 状态不可读时失败关闭，并把 agent 提交限制在保留的 mcp/ 分支命名空间，且带不可剥离的 [mcp] 前缀。运维警告： 创建 mcp/ 分支或确认提交会用实例 deploy key 推送到 git 远端，因此远程 CI 和 webhook 会在 mcp/* ref 上触发。(#42185, #42187, #42190, #42193, #42208, #42110, #42212)
  • AI 模型发现刷新（可能造成静默破坏） — OpenAI、Anthropic 和 Google AI 数据源现在列出当前的 GPT、Claude 和 Gemini 模型。保存的 Anthropic 查询如果使用了手工输入的现代模型 ID 并读取 completion，可能需要更新绑定，所以升级后请核验这些查询——尽管它们与 Appsmith AI 的关停无关。(#42114)
  • 值得升级——安全/可靠性加固；不是空操作 — 这是一次实质性发布，不是仅改元数据的重新打标签。如果实例是共享的或暴露在公网，请升级：在 Custom JavaScript Library manifest 和 Git 路由解析应用或使用已存凭据之前，现在会先强制应用读权限；应用更新不能再启用包含凭据的导出/分叉；当 origin 与请求主机不匹配时，OAuth 数据源重定向会被拒绝；受限主机检查覆盖 IPv4/IPv6/IPv4-in-IPv6 的替代形式；客户端/服务端/可观测性/基础镜像依赖都做了更新。可靠性收益包括：阻塞式数据源操作移出共享服务线程并为 SMTP/SSH 设置有界超时，改进 Redis 支撑的 Git 分支同步以支持没有本地分支的仓库，副本集检查接受更新的 MongoDB URI 选项如 serverMonitoringMode=poll；此外还有通过 ApplicationIntent=ReadOnly 配合 Always On 可读副本路由的 MSSQL 只读连接。谁可以跳过： 孤立的单用户/本地实例，不使用 Appsmith AI、没有针对 GET /api/v1/admin/env 的自动化、也不需要 MCP server 或安全加固，可以延后——但任何还有 Appsmith AI 查询的人，无论何时升级，都必须在 2026-09-30 前行动。(#42159, #42138, #42108, #42131, #42113, #42121, #42146, #42132, #41668)

🗑️ 功能删除提醒 - 2026 年 9 月 30 日 - EOL

Appsmith AI 将于 2026 年 9 月 30 日（此版本发布三周后）终止生命周期。

正如 v2.3 中所宣布的，您无法再添加新的 Appsmith AI 数据源连接或查询。您当前拥有的任何数据源都将继续工作到 2026 年 9 月 30 日。在此日期之后，所有 Appsmith AI 数据源都将停止工作 — 无论您是否升级。

在此日期之前将任何剩余的 Appsmith AI 查询迁移到直接提供商数据源（OpenAI、Anthropic 或 Google AI）。此版本刷新了所有三个提供商的可用模型列表，因此当前模型可以迁移到。 (#42114)

⚠️ 重要升级说明

  • 管理设置机密 — GET /api/v1/admin/env 返回的敏感值现在被屏蔽，可编辑的 MongoDB 和 Redis URL 字段被只读连接状态替换。更新从管理员 API 读取这些值的任何脚本或自动化。提交回屏蔽值将被视为“未更改”，因此现有配置将被保留。 (#42169)
  • AI 数据源响应 — OpenAI、Anthropic 和 Google AI 数据源现在列出了当前模型。使用手动输入的现代模型 ID 保存的人择查询如果读取为 completion，则可能需要绑定更新。 (#42114)

✨ 新功能和增强功能

  • Appsmith MCP 服务器（BETA） — 一个选择加入的嵌入式 模型上下文协议 服务器，允许兼容的 AI clients 通过结构化工具 API 构建和编辑 Appsmith 应用程序。代理从不编写原始小部件 DSL、SQL、JS 或 {{ }} 绑定 - 它们调用服务器在调用者自己的权限下编译的工具。 设置 MCP 服务器 → (#42185、#42187、#42190、#42193、#42208、 #42210、#42212)
    • 默认情况下关闭，在新安装和升级时类似 - 升级到 v2.4 不会公开代理端点。自托管：管理设置 → 实例 → MCP 服务器（测试版） → 启用 → 保存并重新启动。具有自定义组织名称的 Appsmith Cloud 帐户可在 组织 下启用它。
    • **管理设置下的 每用户密钥 → 配置文件 → MCP 密钥。密钥将 client 作为该用户进行身份验证，并且不授予任何其他权限。密钥的有效期为 30/60/90/180/365 天（默认 30 天），每个用户最多有 10 个未撤销的密钥；该秘密仅在创建或旋转时显示一次。禁用服务器会拒绝现有密钥，但不会撤销它们。
    • 破坏性操作需要人工批准，通过 prepare_* → confirm_* 握手，并一次性确认绑定到目标及其当前内容修订。
    • Git 连接的应用程序是门控的。 突变必须命名应用程序的当前分支，如果无法读取 git 状态，则失败关闭。代理仅在保留的 mcp/ 分支命名空间内提交，并且每个代理提交都带有不可删除的 [mcp] 前缀。
    • **操作员注意：**创建 mcp/ 分支或确认提交 使用实例部署密钥推送到 git 远程，因此监视分支推送的远程 CI 和 webhooks 将在 mcp/* 引用上触发。
  • MSSQL 只读连接 — 添加了 ApplicationIntent=ReadOnly 的只读模式，包括 SQL Server Always On 部署的可读辅助路由。 (#41668)
  • 评估值助手 - 改进了弹出窗口的位置并添加了持久紧凑的折叠视图。 (#42128)

🤖 人工智能改进

  • 更新了当前 GPT、Claude 和 Gemini 模型的 OpenAI、Anthropic 和 Google AI 数据源模型发现。 (#42114)

🎨 UI 和小部件改进

  • 清除小部件事件后删除了过时的 JavaScript lint 错误。 (#42130)
  • 防止自定义 ECharts 配置中的 null 值破坏页面评估。 (#42145)
  • 防止大型自定义小部件 JavaScript 语法错误导致构建器崩溃。 (#42198)
  • 恢复了旧版“选择”、“多重选择”和“树选择”小部件上的必填字段标记。 (#41927)
  • 切换时保持“允许所有用户注册”表单登录标签一致。 (#42167)

🛠️ 可靠性

  • 将阻塞数据源操作从共享服务器线程中移出，并添加了有限的 SMTP 和 SSH 超时。 (#42159)
  • 删除了操作验证期间重复的数据源查找和策略更新。 (#42138)

🔐 安全

  • 派生共享自定义 JavaScript 库标识符服务器端并在返回库清单之前强制执行应用程序读取权限。 （[#42108]（https://github.com/appsmithorg/appsmith/pull/42108），[#42131]（https://github.com/appsmithorg/appsmith/pull/42131））
  • 阻止应用程序更新请求启用包含凭据的导出或分叉行为。 (#42113)
  • 在 Git 路由解析应用程序或使用存储的 Git 凭据之前强制执行应用程序读取权限。 (#42121)
  • 阻止 OAuth 数据源流重定向到与请求主机不匹配的源。 (#42146)
  • 加强了对备用 IPv4、IPv6 和 IPv4-in-IPv6 表示形式的受限主机检查。 (#42132)
  • 更新了 client、服务器、可观察性、捆绑工具和基础映像依赖项，以解决报告的漏洞。 (#42103、#42110、#42075、#42154、#42183、#42200)

🔧 Git、部署和配置

  • 改进了 Redis 支持的 Git 分支同步，适用于没有本地分支的存储库。 (#42176)
  • 允许副本集启动检查以接受较新的 MongoDB URI 选项，例如 serverMonitoringMode=poll。 (#42188)
