appsmith v1.93

这个项目是干啥的：一个低代码内部工具平台，拖拖拽拽就能做出管理后台和仪表盘，还能接数据库和接口，适合想快速做工具的开发者。

变更架构图

亮点

  • GraphQL 成为一等公民 — 自定义 GraphQL Action（#41404）、查询编辑器中 GraphQL body 的语法格式化（#41425），以及修正的编辑器占位文案（#41423）一起让你原生构建 GraphQL 后端应用，而不用通过 REST action 伪装。如果你一直在等 GraphQL 支持，这个版本值得升级。
  • Helm 灵活性，但有个认证坑 — 现在可以在 Helm chart 中固定部署，而不必被强制启用自动扩缩（#41397），简化了单副本和小型安装。另外，#41426 会拿 APPSMITH_BASE_URL 校验 Origin 头；base URL 配错或有多个服务主机名的任何人，升级前都应核对该设置，否则合法请求可能被拒。没有正式的破坏性变更或迁移章节，但这是唯一有真实配置敏感性的改动。
  • 静态 URL 与新 widget API — 应用和页面可以通过稳定的静态 URL 提供访问（#41312），便于分享/公开链接和缓存。Radio Group widget 新增 setValue 方法（#41402），与其他 widget 的编程式控制能力对齐。
  • 无需操心的修复 — 自定义库的局部导出不再静默导出零个库（#41416），Gemini 模型选项现在与 generate 命令一致（#41415），isChecked 更新逻辑做了内部简化（#41430），表格横向滚动条加粗（#41370）。这些都不需要用户操作。
  • 值得升级吗？ — 这是一次真正的特性与修复发布，不是重新打标签或仅改元数据。想要 GraphQL 集成、静态 URL、Radio Group API 或 Origin 头加固就升级；如果都不适用且你在旧版本上稳定，可以跳过。复杂的 Helm 或多主机名部署应先检查 APPSMITH_BASE_URL。

特点

  • 应用程序和页面的静态 URL 支持。 (#41312)
  • 添加了对自定义 GraphQL 操作的支持，以便使用 GraphQL 进行集成。 (#41404)
  • 在查询编辑器中添加了 GraphQL 正文的格式。 (#41425)
  • 为无线电组小部件添加了 setValue 方法。 (#41402)
  • 允许在 Helm 图表中指定部署，而无需自动缩放。 (#41397)

修复

  • 通过删除不必要的参数简化了 isChecked 更新逻辑。 (#41430)
  • 通过根据 APPSMITH_BASE_URL 验证 Origin 标头改进了身份验证。 (#41426)
  • 更正了 GraphQL 操作编辑器中的占位符文本。 (#41423)
  • 解决了部分导出自定义库导致导出零库的问题。 (#41416)
  • 更新了 Google AI 数据源中的 Gemini 模型选项，以确保与 generate 命令的兼容性。 (#41415)
  • 使水平滚动条更粗，以便在表格中获得更好的可见性。 (#41370)
