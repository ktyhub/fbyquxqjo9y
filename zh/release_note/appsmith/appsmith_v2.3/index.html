appsmith v2.3

这个项目是干啥的：一个低代码内部工具平台，拖拖拽拽就能做出管理后台和仪表盘，还能接数据库和接口，适合想快速做工具的开发者。

变更架构图

亮点

  • 破坏性变更——Appsmith AI 数据源 EOL — v2.3 阻止新建 Appsmith AI 数据源连接/查询，并加上废弃横幅（#42015）。现有连接只工作到 2026-09-30，之后无论升级与否都会停止。该截止日期已经过去，现在就必须迁移走；跳过 v2.3 并不会延长支持。
  • 安全——强烈的升级理由 — 修复包括导入/分叉及 Action 创建/更新时隐藏/私有数据源的授权绕过（#42066、#42018）、跨工作区权限组分配（#42023）、符号链接 Git 导入的路径穿越（#41993），以及伪造 Origin 的登录重定向（#41995）。npm 11.18.0 和 tar ^7.5.19 还解决了严重的 node-tar DoS 漏洞 CVE-2026-59873（#42064、#42034）。使用导入、分叉或暴露数据源的自托管实例应优先升级。
  • 部署检查——嵌入与代理行为 — 通配 frame-ancestors 默认值被移除（#42012），现有 iframe 嵌入可能需要显式 CSP 允许列表。Caddy 限流现在使用受信任的客户端 IP，并采用受限的受信代理集合（#42071）；发布时请核验代理配置，避免客户端 IP 与限流判断出错。
  • 特性与可靠性——匹配你的工作流时才有用 — Custom Widgets 获得原生 AI Copilot（#42063），Ask AI 进入 Community Edition（#42065），新的 Card Widget 和共享 tabOrder 改善可组合布局与键盘导航（#42026、#41895）。Hikari keepalive 和有界 socket 超时加固了 JDBC 连接（#41851），Git 导入和发布也得到针对性的稳定性修复。
  • 升级建议 — 除非你已经应用了等效的安全修复，否则应尽快升级。不需要新 AI/widget 能力的部署可以放到常规维护窗口。Appsmith AI EOL 与本次升级决策无关，仍需迁移。

🗑️ 功能删除 - 2026 年 9 月 30 日 - EOL

升级到版本 2.3 后，您将无法再添加新的 Appsmith AI 数据源连接或查询。您当前拥有的任何数据源仍将继续工作，直到 2026 年 9 月 30 日。在此之后，任何 Appsmith AI 数据源都将停止工作 - 无论您是否升级。

  • Ask AI 社区版 — 将 Ask AI 助手引入社区版。 （＃42065）。 https://docs.appsmith.com/build-apps/how-to-guides/use-ask-ai
  • 卡片小部件 — 添加了一个新的卡片小部件，用于显示具有可组合主体画布的实体。 （＃42026）。更多信息可参见https://docs.appsmith.com/reference/widgets/card
  • 按钮小部件标签样式 - 向按钮小部件添加了标签样式选项。 (#41998)
  • 键盘导航 - 在标准小部件中添加了共享 tabOrder 属性，以改进键盘选项卡导航。 (#41895)
  • HTML 语言属性 — 添加了对自定义 HTML lang 属性的支持。 (#41593)
  • Git 存储库检查 - 添加了对 Redis 中存储的 Git 存储库的健全性检查。 (#41970)

🤖 AI 和助理改进

  • AI 助手超时 — 增加了 AI 助手提供程序超时以提高可靠性。 (#42096)
  • 自定义小部件 AI 反馈 - 改进了自定义小部件 AI 助手的反馈和错误处理。 (#42095)
  • Ask AI CE 强化 - 在 CodeRabbit 审核后强化了 Ask AI 社区版实施。 (#42092)
  • Appsmith AI 弃用 - 阻止创建新的 Appsmith AI 数据源并添加弃用横幅。 (#42015)

🔐 安全

  • 数据源授权绕过 - 修复了一个漏洞，该漏洞可能允许在应用程序导入和分叉操作期间重用隐藏的数据源。 (#42066)
  • Git 导入路径遍历 - 防止 Git 导入期间基于符号链接的路径遍历，这可能导致任意文件读/写。 (#41993)
  • 权限组安全性 - 分配权限组时强制执行工作区边界。 (#42023)
  • 数据源授权 - 修复了操作创建/更新授权，以防止用户暴露另一个工作区的私有数据源以进行未经身份验证的执行。 (#42018)
  • 数据源网络访问 - 限制数据源对实例自己的网络地址的访问。 (#41985)
  • Frame Ancestors 安全性 — 删除了默认通配符 frame-ancestors，以防止过于宽松的嵌入策略。 (#42012)
  • 预身份验证电子邮件安全 — 来自预身份验证电子邮件端点的标准化响应并删除了未使用的路由。 (#41996)
  • 租户端点安全性 — 从匿名用户的租户响应中删除了内部配置详细信息。 (#42001)
  • 登录开放重定向 — 防止登录期间伪造 Origin 标头导致的开放重定向。 (#41995)
  • 执行器安全性 — 在未配置内部密码时阻止执行器基本身份验证。 (#41964)
  • SMTP TLS 验证 — 通过验证主机名，同时维护与 SSRF 验证地址的连接，改进了 SMTP TLS 验证。 (#42060)
  • Caddy 速率限制 — 通过使用 trusted client IP 和限制 trusted 代理改进了速率限制。 (#42071)
  • 服务器和插件 CVE - 修复了 Docker Scout 扫描识别的服务器和插件 JAR 漏洞。 (#42074)
  • npm 安全更新 — 将 npm 升级到 11.18.0 以解决严重的 node-tar DoS 漏洞 (CVE-2026-59873)。 (#42064)
  • tar 安全更新 — 将 tar 分辨率更新为 ^7.5.19 以解决 CVE-2026-59873。 (#42034)
  • 依赖项安全更新 - 应用依赖项更新解决多个报告的漏洞。 （#42091、#42051、#42049、#41969、#41965）

🔧 Git 和版本控制

  • 改进的 Git 错误消息 — 更新了 Git 错误处理以显示失败的实际原因，而不是显示一般消息。 (#42053)
  • Git 导入优化 - 将同级分支实体导入仅限于导入期间所需的字段。 (#41972)
  • Git 发布稳定性 — 删除了导致发布问题的孤立遗留 Git 控制器。 (#41974)

🎨 UI 和小部件改进

  • 应用程序主题权限 - 在编辑模式下阅读应用程序主题时所需的编辑权限。 (#42090)
  • 横幅定位 - 修复了横幅偏移。 (#42073)
  • 复制到应用程序 - 修复了下拉列表滚动并改进了复制模式中的数据源注释可见性。 (#42007)
  • 表格小部件 — 修复了菜单按钮列宽度。 (#41948)
  • 文本小部件链接 — 修复了 mailto:、tel: 和 ftp: 链接被错误修改的问题。 (#41997)

🛠️ 可靠性、测试和开发人员经验

  • Cypress API 拦截 - 修复了由于 cy.log 导致的合并 API 拦截钩子失败的问题。 (#42069)
  • Filepicker 评估 - 当 Filepicker 二进制数据传递到操作运行时保留同级参数。 (#42021)
  • MSSQL 验证 — 拒绝包含连接字符串分隔符的 MSSQL 数据库名称。 (#42077)
  • Intl Linting — 修复了错误的 Intl is not defined lint 错误。 (#42080)
  • JDBC 可靠性 — 为 JDBC 连接添加了 Hikari keepalive 和有界套接字超时。 (#41851)
  • 电子邮件设置测试 — 通过在继续之前等待电子邮件 HTML 正文来提高测试可靠性。 (#41893)
  • Client Build CI — 在确定更改的文件时防止出现“参数列表太长”错误。 (#42050)
  • MongoDB 错误处理 — 通过等待现有 toast 清除后再再次检查，改进了对重复 MongoDB 副本集错误的处理。 (#41963)

🏢 权限和配置
