appsmith v2.5.0

appsmith v2.5.0

这个项目是干啥的：一个低代码内部工具平台，拖拖拽拽就能做出管理后台和仪表盘，还能接数据库和接口，适合想快速做工具的开发者。

变更架构图

亮点

  • Appsmith AI 已停止服务——先迁移走 — 自 2026-09-30 起，你无法再创建新的 Appsmith AI 数据源或查询，现有查询无论是否升级都已停止工作。没有兼容路径：在依赖任何 AI 驱动的应用之前，把残留查询改写为直连提供商数据源（OpenAI、Anthropic 或 Google AI）。这是本版最紧急的一项，且不以是否采用 v2.5.0 为前提。

  • Server schema 13 改变 Git 与导出的可移植性 — Git 连通的应用下次打开时会被静默升级到 server schema 13，并可能产生一条你会在历史记录里看到的一次性系统提交（#42322）。更重要的是，从这个版本导出的应用无法导入 schema-12 的服务器——所以要协调控制面升级，避免把导出文件往返到旧实例。请把它当作一次性、版本锁定的迁移。

  • 数据源凭据现在绑定到确切的连接配置 — 更改任何生效的认证、TLS 或 SSH 设置都意味着要重新输入凭据；未改动的连接继续使用已保存的密钥（#42339）。这次加固还收紧了数据源测试/结构/触发请求的权限，在更新时保留请求所选的数据源身份（#42356），并保证即使替换全局请求构造器，求值环境请求中的凭据省略保护依然生效（#42355）。此前原地修改连接设置的脚本，要预期出现交互式重新认证。

  • Elasticsearch 绑定现在严格类型化 — 替换使用带类型的 JSON，并在执行前校验替换值和动态路径，因此插入序列化 JSON、拼接部分 JSON 字符串或构造动态路径的查询，现在可能在查询时失败，而不是悄悄产生奇怪结果（#42342）。发布前请审计 ES 查询——这是只在这些查询真正运行时才会暴露的行为破坏。

  • MCP 对智能体式应用构建变得实用得多 — MCP 现在可以创建和更新结构化 JS 对象、处理更多 MongoDB 过滤类型、修补更广泛的 widget 设置、接线 JS 函数调用，并标记常见布局问题（#42311）；创建数据源时让服务端选择正确环境（#42341）；日志现在记录每次工具调用的真实结果，并在相关后端调用上带上正确的请求 ID（#42350）。尤其是日志改动，让 MCP 驱动的运行调试起来容易得多。

  • 现有应用值得注意的可靠性与 UI 修复 — MySQL 存储过程调用现在可以接受尾随查询，同时仍把绑定值当数据处理（#42329）；失败的 OAuth2/SSO 登录会把用户送回实例登录页，而不是走进死胡同（#42330）；卡片、标签页、工作表及列表项中的区域终于使用全部可用宽度，而不是塌缩成窄列（#42364）。widget 方面，表格新增表头换行（#42354）以及表头字重/斜体/下划线控制（#42323），List widget 新增 Disable selection 选项（#42261），应用可以携带显示在应用卡片上的描述（#42312）。

🗑️ 功能删除提醒 - 2026 年 9 月 30 日 - EOL

Appsmith AI 已于 2026 年 9 月 30 日终止生命周期。

您无法再添加新的 Appsmith AI 数据源连接或查询。无论您是否升级，现有查询都已停止工作。

将剩余的 Appsmith AI 查询迁移到直接提供商数据源，例如 OpenAI、Anthropic 或 Google AI。

⚠️ 重要升级说明

  • Git 连接的应用程序在下次打开时更新到服务器架构 13。这可以创建一次性系统提交。从此版本导出的应用程序无法导入到仅支持架构 12 的旧服务器中。(#42322)
  • 更改数据源连接设置时，必须再次输入主动身份验证、TLS 和 SSH 设置的凭据。未更改的连接可以继续使用保存的凭据。 (#42339)
  • Elasticsearch 主体绑定现在使用类型化的 JSON 替换。查看插入序列化 JSON、构建 JSON 字符串的一部分或构建动态路径的查询。无效的绑定现在会返回查询错误。 (#42342)

🔐 安全

  • 更新了捆绑依赖项以解决报告的漏洞。 (#42314、#42324、#42331)
  • 数据源凭据重用现在与保存的连接配置相关联，并且数据源测试、结构和触发请求使用更严格的权限检查。 (#42339)
  • 来自评估环境的请求现在保留凭据遗漏保护，即使全局请求构造函数发生更改也是如此。 (#42355)
  • 登录速率限制现在使用与身份验证相同的标准化帐户身份。 (#42337)
  • 数据源更新现在保留请求选择的数据源的标识。 (#42356)
  • Elasticsearch 查询现在在执行前验证替换的 JSON 和动态路径值。 (#42342)

🛠️ 可靠性

  • 准备好的 MySQL 存储过程调用现在可以与尾随查询一起运行，并将绑定值保留为数据。 (#42329)
  • 失败的 OAuth2 和 SSO 登录现在会将用户返回到实例登录页面。 (#42330)
  • 卡片、选项卡、工作表和列表项中的区域现在使用完整的可用宽度，而不是折叠成窄列。 (#42364)
  • MCP 数据源创建现在允许服务器选择正确的环境。 (#42341)

✨ 新功能和增强功能

  • 应用程序现在可以有一个可选的描述，显示在应用程序卡上。 (#42312)
  • 列表小部件现在为不需要行选择或项目 click 行为的应用程序提供了“禁用选择”选项。 (#42261)
  • MCP 现在可以创建和更新结构化 JS 对象、使用更多 MongoDB 过滤器类型、修补更多小部件设置、连接 JS 函数调用以及检测常见布局问题。 (#42311)

🎨 UI 和小部件改进

  • 表列现在有一个可选的 标题换行 设置，用于长列标题。 (#42354)
  • 表格标题现在支持可配置的字体粗细、斜体文本和下划线。 (#42323)
  • 应用程序页面现在位于缺少的基本 URL 横幅下方，因此工作区控件仍然可见。 (#42319)

🔧 Git、部署和配置

  • MCP 日志现在记录每个工具调用的实际结果，并在相关后端调用上保留正确的请求 ID。 (#42350)
