appsmith v2.7.1

修订 发布时间2026年11月18日 来源appsmithorg/appsmith 英文原文

变更流程图

亮点

  • 破坏性：嵌入允许列表与 Git 页面名门槛 — 两条新的校验规则会在你碰任何应用代码之前就改变行为。APPSMITH_ALLOWED_FRAME_ANCESTORS 现在严格按 CSP frame-ancestors 源表达式解析；此前以其他形式保存的值，在下次重启后会被静默当作 'self'，导致合法的第三方嵌入在保存时没有任何报错却失效（[#42622]）。另外，只要有任何页面名不是单个路径段，Git 就会拒绝提交应用，创建或重命名成这种名字会被直接拒绝（[#42633]）。升级之前请审计页面名和已保存的嵌入值——这两种失败都是硬阻断，不是警告。

  • 破坏性：navigateTo 解析与 Helm 探针默认值 — 从 2.7.0 之前升级会改变两处运行时行为。对不存在的页面名调用 navigateTo 不再回退成把它当 URL 打开：即使是像 navigateTo("OldPage?file=report.pdf") 这样带点的参数，或 intranet 这样的单词主机名，现在都会报 “Enter a valid URL or page name”，所以依赖隐式 URL 强制转换的调用方必须传完整 URL（[#42513]）。Helm chart 现在会给未设置的 probes 键填入 10 秒周期和 5 秒超时，任何非正整数值都会让 helm install/helm upgrade 失败；如果你此前按旧的 60 秒节奏调过 failureThreshold，也要设置 periodSeconds: 60（像 "5" 这样的带引号数字仍可解析）（[#42571]）。

  • 安全态势：公式注入与权限边界收紧 — CSV 导出现在把单元格值写成文本，堵上了电子表格公式注入路径（Excel 导出不变）（[#42569]）。授权模型新增三项检查：校验 action 时更改数据源用途，现在需要该数据源的 create-action 权限（[#42601]）；编辑页面的依赖图需要该页面的编辑权限（[#42642]）；Git 读写删被限制在应用自己的仓库内（[#42633]）。此前依赖隐式访问的自动化要预期更严格的失败；这些是在关闭有意提权，不是回归。

  • MCP 成为真正的分析能力面，而不只是查询执行器 — 结构化 SQL 在 PostgreSQL 和 Redshift 上新增按日/周/月/季/年的日期分桶、最多六个聚合、DISTINCT，以及带 CASE/WITH 的 join（[#42608]、[#42619]）。MCP 还能把已保存的 SQL 或 REST 查询复制到其他页面或应用而不暴露查询文本、在现有 SMTP 数据源上创建邮件查询，并生成格式化日期或写日志的 JavaScript（[#42624]、[#42638]）。净效果是：更多数据塑形工作可以留在 MCP 里，而不必在 JS 中重建。

  • 可靠性：认证、导入与 MCP 正确性 — OAuth2 授权码 token 交换现在会遵循数据源的自签证书，修复了此前失败的私有 CA token URL 登录（[#42605]）。导入应用不再丢弃并发创建的数据源或 JS 库（[#42612]）。MCP 会把更新后的查询留在自己的集成上，而不是搬到另一种数据源类型（[#42620]），并停止为 Redshift 和 Snowflake 注入参数值，因为这两者不绑定参数（[#42617]）——如果你以为 MCP 绑定的值在这两个地方是安全的，这行为很重要。

  • UI 打磨带一个迁移动作 — Bug 修复级改动消除视觉/输入回归，而非新增能力：BYN、VES、ZMW 加入货币输入列表，旧代码仍保留（[#42445]）；单按钮 Button Groups 保留圆角（[#42250]）；表格单元格中的 Icon Button/Video 控件恢复为 30 px，使配置的行数能放下（[#42615]）；只有一个字段、没有 Submit 按钮的 JSON Form 中按 Enter 不再刷新页面（[#42607]）；保存的 Border radius/Box shadow 选项现在正确高亮（[#42292]）。唯一需要操作的：Admin Settings → Branding 不再提供 SVG logo，只接受 PNG/JPG（[#42637]）——升级前请转换 SVG 素材。

⚠️ 重要升级说明

  • 嵌入允许列表： APPSMITH_ALLOWED_FRAME_ANCESTORS 必须是 CSP frame-ancestors 源表达式的列表。下次重新启动后，不采用该形式的保存值将用作 'self'。保存设置会拒绝无效值。 (#42622)
  • Git 页面名称： 当任何页面名称不是单个路径段时，Git 不会提交应用程序。首先重命名该页面。创建页面或将其重命名为此类名称将被拒绝。 (#42633) 如果您是从 v2.7.0 之前的版本升级
  • Helm 图表：如果您设置了一些 probes 键，则您未设置的键现在将采用新的默认值（10 秒周期，5 秒超时）。如果您将 failureThreshold 调至旧 60 年代时期，则还要设置 periodSeconds: 60。非正整数的探测值现在会失败 helm install 和 helm upgrade。引用的数字（例如 "5"）仍然有效。 (#42571)
  • navigateTo 到不再存在的页面名称现在会失败，并显示“输入有效的 URL 或页面名称”，即使参数值包含点也是如此。之前，它以网址的形式打开名称，例如https://OldPage?file=report.pdf。带有点参数的单字主机（例如 intranet）现在也会失败。请改用完整的 URL。 (#42513)

🔐 安全

  • 表 CSV 下载不再让单元格作为电子表格公式运行。单元格保存为文本。 Excel 下载量没有变化。 (#42569)
  • 在验证操作时更改谁可以使用数据源现在需要在该数据源上创建操作的权限。创建或更新单个操作已经需要这样做。 (#42601)
  • 框架祖先设置仅接受 CSP 源表达式。无效的保存值将作为 'self'。 (#42622)
  • Git 写入和删除保留在该应用程序的存储库中。页面名称必须是单个路径段。 (#42633)
  • 更新页面的依赖关系图现在需要编辑该页面的权限。 (#42642)

🛠️ 可靠性

  • OAuth2 授权代码登录现在使用数据源的自签名证书进行令牌交换。之前，该步骤忽略了该设置，并且当令牌 URL 使用私有证书时登录失败。 (#42605)
  • 当同时创建多个应用程序时，导入应用程序不再删除新的数据源或 JS 库。 (#42612)
  • MCP 在其自身的集成中保留更新的查询。它不再将查询移动到不同类型的数据源上。 (#42620)
  • MCP 不会向 Redshift 或 Snowflake 上的查询添加值，因为这些数据源不绑定参数。 (#42617)

✨ 新功能和增强功能

  • 文件选择器上传对话框遵循应用程序的 HTML 语言。不受支持或空的语言保留为英语。 (#42572)
  • MCP 结构化 SQL 可以在 PostgreSQL 和 Redshift 上按日、周、月、季度或年对日期进行存储，最多返回六个聚合，并选择不同的行。 (#42608)
  • MCP结构化SQL可以连接表并使用CASE和WITH。 (#42619)
  • MCP 可以将存储的 SQL 或 REST 查询复制到另一个页面或另一个应用程序。查询文本保留在服务器上。 (#42624)
  • MCP 可以在现有 SMTP 数据源上创建电子邮件查询。 MCP 内置的 JavaScript 可以格式化日期并写入日志条目。 (#42638)

🎨 UI 和小部件改进

  • 货币输入添加了白俄罗斯卢布 (BYN)、委内瑞拉玻利瓦尔 (VES) 和赞比亚克瓦查 (ZMW)。较旧的代码 BYR、VEF 和 ZMK 仍保留在列表中。 (#42445)
  • 包含一个按钮的按钮组在每个角上都保持其角半径。 (#42250)
  • 表格单元格中的图标按钮和视频控件的高度再次为 30 像素，没有额外的垂直填充，因此所选的行数仍然适合。 (#42615)
  • 在具有一个文本字段且没有提交按钮的 JSON 表单中按 Enter 键不再重新加载页面。提交按钮的工作方式与以前一样。 (#42607)
  • 在 JSON 表单中，按钮边框半径和框阴影控件突出显示已保存的选项。 (#42292)
  • 管理设置 → 品牌不再为实例徽标提供 SVG。接受 PNG 和 JPG，这是服务器允许的。 (#42637)
