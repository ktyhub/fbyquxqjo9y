appsmith v2.4.3

修订 发布时间2026年9月30日 来源appsmithorg/appsmith 英文原文

appsmith v2.4.3

变更流程图

亮点

  • Appsmith AI 停止服务——务必在 2026-09-30 前行动 — 这是本版唯一真正的破坏性变更：现有 Appsmith AI 查询和数据源会在该日期停止工作，无论是否升级，而新连接/查询已被阻断。请把残留查询迁移到直连提供商数据源（OpenAI、Anthropic 或 Google AI），不要等补丁——截止之后没有任何回退。
  • MCP 会话现在放在 Redis 里（PR #42279） — 会话在副本间共享，并能在 MCP 进程重启后存活，因此被路由到其他副本的请求不再 404。标准 Docker 和 Helm 配置无需改动，但如果你外部 Redis 强制受限 ACL，必须授予 appsmith:mcp:* 的读写权限，以及 appsmith:mcp:relay:* 上的 PUBLISH/SUBSCRIBE——否则 MCP 进程根本起不来，发布前请检查 ACL。
  • Action 失败现在可调试（PR #42277、#42280） — 执行现在暴露真实的超时、网络、网关和服务端错误消息，而不是统统替换成泛泛的客户端错误。运维上这是很大的进步：定位失败的 action 不再需要猜测上游服务实际返回了什么。
  • 编辑器冷加载不再撞 HTTP 429（PR #42286） — 带哈希的静态资源被移到独立、容量更高的限流区，而动态请求保留原有上限。此前在全新缓存或部署后遇到编辑器加载失败——尤其是在共享出口 IP 之后——的团队，应该能看到问题消失，同时不必放宽 API 限流。
  • 依赖安全刷新（PR #42307、#42309） — 内置依赖已更新以处理报告的漏洞。风险低，但如果你运行公开可访问的实例，值得尽快应用；预计没有应用层行为变化。
  • UI 与 widget 行为修复（PR #42215、#42301、#42271） — Rich Text Editor 新增字体族控件（含 Default 和 web-safe 字体）；浏览器前进/后退现在会在查询参数变化时刷新 appsmith.URL 和由 URL 驱动的 widget 值，修复深链应用中的陈旧状态；Table 的 HTML 列重新支持对纯文本值的搜索、过滤和排序——如果你曾回退到纯文本列作为变通方案却一直没等到这些功能回来，这点很有用。

🗑️ 功能删除提醒 - 2026 年 9 月 30 日 - EOL

Appsmith AI 将于 2026 年 9 月 30 日终止生命周期。

正如 v2.3 和 v2.4 中所宣布的，您无法再添加新的 Appsmith AI 数据源连接或查询。现有的服务将在该日期停止工作——无论您是否升级。

在 9 月 30 日之前将剩余的 Appsmith AI 查询迁移到直接提供商数据源（OpenAI、Anthropic 或 Google AI）。

⚠️ 重要升级说明

  • MCP 会话现在使用由 APPSMITH_REDIS_URL 配置的 Redis。标准 Docker 和 Helm 部署不需要更改配置。如果您的外部 Redis 使用受限 ACL，请允许对 appsmith:mcp:relay:* 上的 appsmith:mcp:* 和 PUBLISH/SUBSCRIBE 进行读/写访问；否则MCP进程将不会启动。 (#42279)

🔐 安全

  • 更新了捆绑依赖项以解决报告的漏洞。 （[#42307]（https://github.com/appsmithorg/appsmith/pull/42307），[#42309]（https://github.com/appsmithorg/appsmith/pull/42309））

🛠️ 可靠性

  • 操作执行现在保留有用的超时、网络、网关和服务器提供的错误消息，而不是用 client 端错误替换它们。 （[#42277]（https://github.com/appsmithorg/appsmith/pull/42277），[#42280]（https://github.com/appsmithorg/appsmith/pull/42280））
  • 散列静态资产现在使用单独的、更高容量的速率限制区域，防止冷编辑器加载因 HTTP 429 失败，同时保留动态请求的现有限制。 (#42286)

🎨 UI 和小部件改进

  • 在富文本编辑器工具栏中添加了字体系列控件，包括默认选项和网络安全字体选择。 (#42215)
  • 当查询参数更改时，浏览器后退和前进导航现在会刷新 appsmith.URL 和 URL 驱动的小部件值。 (#42301)
  • 恢复了表格小部件 HTML 列中纯文本值的搜索、过滤和排序。 (#42271)

🔧 配置

  • MCP 会话现在通过 Redis 在副本之间共享，并在 MCP 进程重新启动后继续存在，从而防止路由到另一个副本的请求返回 404。（#42279）
