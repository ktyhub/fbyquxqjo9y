Understand-Anything v1.3.0

小版本 发布时间2026年3月28日 来源Egonex-AI/Understand-Anything 英文原文

Understand-Anything v1.3.0

变更流程图

亮点

  • 层级图导航（#44） — 大图现在支持层级簇概览与文件级下钻、跨层传送门链接、面包屑、历史记录，以及用 Esc 返回。节点记忆化和仅在结构变化时才用 dagre 重新布局，降低了浏览时的渲染开销。
  • 更低成本的分析，可选启用 LLM 审阅（#47） — 预解析的 importMap 数据、batchImportData、精简的架构/导览载荷以及更大的批次，据称把 token 成本降低约 85%。LLM 图审阅器现在需要 --review 才会运行；默认运行使用确定性校验，因此现有自动化必须显式选择启用，并注意更高并发带来的速率限制。
  • 自动图刷新（#31） — understand skill 的 --auto-update 模式会在提交时触发更新，并用结构指纹跳过无实质变化。这对 hook 和 CI 很有用，但指纹模型之外的编辑可能不会强制重新生成。
  • 仪表盘健壮性与主题（#42、#45） — 分层校验会修复常见图问题并显示横幅，而不是不透明地失败，不过格式错误的集合仍会被拒绝。主题预设、强调色定制和浅色模式改善易用性；CSS 变量简化定制，而 localStorage 持久化是按浏览器隔离的。
  • 仪表盘端点安全加固（#33） — 基于 token 的访问控制现在保护仪表盘和开发服务器端点。请更新脚本、健康检查和浏览器流程以提供凭据；配套修复还加固了注入处理、排序变更、目录基线和错误路径。
  • 兼容性 — 发布说明未报告破坏性变更。

v1.3.0 的新功能

基于分层透镜的图形导航（#44 — @fishinakleinbottle）

  • 两级概览/细节模型：顶层集群→深入到文件级细节
  • 门户节点：使用 click 导航的跨层依赖关系的可视化指示器
  • 面包屑导航：始终知道您在哪里； click 向后跳
  • 侧边栏导航历史记录：最近访问过的节点的踪迹
  • 转至概览：从任何图层详细视图中按 Esc
  • 自定义节点上的 memo() 包装器以提高渲染性能
  • 拓扑/视觉分离——仅在结构变化时进行粗大的布局

主题预设系统 (#45 — @Lum1104)

  • 精心策划的主题预设与强调色定制
  • 仪表板标题中的 ThemePicker 弹出窗口
  • 浅色主题支持 CSS 变量注入
  • 主题保存到本地存储
  • 硬编码颜色合并到 CSS 变量中

仪表板稳健性 (#42 — @Lum1104)

  • 具有分层自动修复管道的宽松图形验证
  • 格式错误的图形数据上的用户友好的错误横幅
  • 用于开发的杂乱图形测试夹具

~85% 代币成本降低 (#47 — @Lum1104)

  • 扫描仪预解析扫描结果中的导入 → importMap。json
  • 在文件分析器中将 allProjectFiles 替换为 batchImportData
  • 精简第 4 阶段（架构）和第 5 阶段（游览）有效负载
  • 从第 2 阶段批次中删除了语言/框架附录
  • --review 标志后面的门控法学硕士图审稿人；默认情况下内联确定性验证
  • 增加批量大小 (5-10 → 20-30) 和并发性 (3 → 5)

提交时自动更新 (#31 — @1AdityaX)

  • 由提交触发的自动知识图更新
  • 结构指纹识别以检测有意义的变化
  • --auto-update 标志用于理解技能

扩大测试覆盖范围（#41 — @berkcangumusisik）

  • 新的插件发现和插件注册测试套件
  • 额外的持久性和树保姆插件测试
  • 添加了 vitest 覆盖依赖项

访问令牌安全性 (#33 — @saismrutiranjan18)

  • 基于令牌的仪表板端点访问控制
  • 增强了开发服务器的端点安全性

错误修复

  • 修复审查结果：排序突变、注入保护、目录基线、错误处理（#33）
  • 修复边缘类型、验证器防护、理解技能的提示准确性（#47）
  • 恢复验证错误兼容性并拒绝格式错误的集合 (#42)

  • @1AdityaX — 自动更新功能

  • @saismrutiranjan18 — 令牌身份验证和端点安全
