Understand-Anything v1.2.0

Understand Anything 是一个开源工具，它将 LLM 智能与静态分析相结合，生成用于理解代码库的交互式仪表板。

亮点

  • 多代理分析管道 - 项目扫描器、文件分析器、架构分析器、游览构建器和图审阅器协同工作以生成丰富的知识图
  • 交互式仪表板 - 黑暗奢华主题的 React Flow 可视化，具有图形优先布局、模糊/语义搜索、导游和角色模式
  • 与语言无关的分析 — 配置驱动的插件注册表，支持 12 种以上语言，具有框架检测功能（TypeScript、Python、Django 等）
  • 多平台支持 — 可与 Claude Code、Cursor、OpenCode、Gemini CLI（反重力）和 Pi Agent 配合使用
  • 差异模式 — 可视化覆盖在知识图上的 PR/差异变化
  • 大图性能 — 基于 Web Worker 的 Dagre 布局、缩放限制、自动居中以及优化的平移/缩放交互
  • 键盘快捷键 — 使用键盘控制有效地导航仪表板

技能

  • /understand — 完整的多代理代码库分析
  • /understand-dashboard — 启动交互式可视化
  • /understand-chat — 与您的代码库上下文聊天
  • /understand-diff — 分析 PR 和差异
  • /understand-explain — 深入文件分析
  • /understand-onboard — 生成团队入职指南
