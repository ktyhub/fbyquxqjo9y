Understand-Anything v2.9.0

小版本 发布时间2026年7月10日 来源Egonex-AI/Understand-Anything 英文原文

Understand-Anything v2.9.0

亮点

新分析模式：/understand-figma (#559) — by @gruming

将工具指向 Figma 文件，并获得与代码相同的可导航知识图：页面→屏幕→组件/变体/实例，以及轻型设计系统模型（设计令牌和 uses_token 边缘）。通过Figma REST API进行确定性解析，通过新的design-analyzer代理进行LLM丰富，仪表板侧边栏中的屏幕缩略图，增量UP_TO_DATE重新运行，以及严格保留在请求标头中的FIGMA_TOKEN。架构添加向后兼容（6 种节点类型、3 种边缘类型、kind:"design"）。后续修复针对真实的 API 样式键桥接、已发布的组件键、种类范围的别名规范化和仪表板边缘类别过滤器。

数据目录重命名为 .ua/ — 完全向后兼容

分析工件现在位于 .ua/ 而不是 .understand-anything/ 中。由旧版本分析的项目不需要迁移：当旧版 .understand-anything/ 目录存在时，它会继续用于读取和写入。解析规则在核心 (resolveUaDir) 中实施一次，并受到每个捆绑脚本、技能、代理定义、挂钩和仪表板开发服务器的遵守。

新语言支持

  • Dart (#435) 和 C++ 测试/基准忽略模式 (#480, #466) — by @thejesh23
  • Scala (#553，来自 #493) 和 Swift (#537) — by @KumamuKuma
  • Kotlin (#347) — 作者：@tirth8205
  • 现代 TS 类型声明提取修复 (#532) — by @jian4wqy

新平台支持

  • Kiro (#364) — by @smjeong84
  • 纳米机器人 (#419) — by @ Chengyongru
  • Trae (#235) — 作者：@ZebangCheng
  • Windows install.ps1 vibe 支持 (#550) 和 Windows 测试可移植性 (#531, #538, #551) — by @KumamuKuma

合并管道可靠性

  • 结构子域边缘 (contains_flow/flow_step/cross_domain) 不再默默地丢弃：响亮的警告、持续的 merge-report.json 以及下次运行时自动重试 (#529)。
  • 加载但贡献零节点/边的批处理文件在阶段报告中标记，而不是消失在部分合并中（#484）。
  • Karpathy wiki 解析器处理标题大小写 Index.md/Log.md 和文章根前缀 [[wiki/...]] 链接 (#342)。
  • 跨层容器布局缓存修复 (#541) — by @computersniper； Windows 上的 UTF-8 域上下文 (#524) — 作者：@multimail-dev；第 7 阶段清理和扫描结果保存修复（#387、#332） — 作者：@tirth8205 和 @ZebangCheng。

安全强化

  • 技能注入 ReDoS 强化 (#557) — by @jian4wqy
  • 递归子代理调度预防 (#560) — by @crow-1412

管道性能和 DX

  • 语义批处理和输出分块 (#204)、/understand 管道性能 (#346) — by @tirth8205
  • 首次运行时对话语言自动检测 (#378) — by @BozhengLong
  • 配置模式验证测试 (#471) — by @yiziff; Node 24 运行时上的 CI。 完整 Changelog：https://github.com/Egonex-AI/Understand-Anything/compare/v2.7.3…v2.9.0
