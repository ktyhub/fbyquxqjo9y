Understand-Anything v2.7.3

修订 发布时间2026年5月19日 来源Egonex-AI/Understand-Anything 英文原文

Understand-Anything v2.7.3

变更流程图

亮点

本地化分析输出 — --language (#142, #145) — by @zhushen12580

/understand（和朋友）现在接受 --language 标志。架构摘要、节点描述、游览和入门内容均以您要求的语言通过代理管道端到端生成。每个自述文件中都有记录。

仪表板 i18n (#142 堆栈 + 9d1318a)

仪表板 UI 随分析管道一起发送翻译文件：

  • 所有 UI 字符串（侧边栏、代码查看器、搜索、游览、移动布局）都通过 I18nProvider 路由。
  • 新：俄语 (ru) 加入现有语言环境。 MobileLayout 现在包含在提供程序中，因此移动屏幕也可以本地化。
  • 输出语言从相同的 outputLanguage 配置键读取，以确保生成的内容和 chrome 之间的一致性。

统一安装脚本 (#123)

将每个平台的安装程序堆替换为单个 install.sh / install.ps1，检测目标 CLI（Claude Code、Codex、Cursor、Copilot CLI、opencode、Gemini CLI、KIMI、Cline、Hermes、Mistral vivi）并连接正确的符号链接和配置。卸载对部分状态具有鲁棒性；重新分析删除受到保护。

新平台支持

  • KIMI CLI (#134) — 安装+技能管道。
  • Cline (#116) — 安装+技能管道。
  • Hermes (#91) — 开源代理兼容性，自述文件刷新。
  • Mistral vivi (#127, by @3ng7n33r) — 安装脚本条目。

测试覆盖率可视化 — tested_by 边缘 + 仪表板徽章（#122/问题#113）

确定性 tested_by 链接器在合并期间运行，采用交换然后补充策略来恢复每个文件批次丢弃的边缘和最大权重 Pass-1 重复数据删除。现在，经过测试的文件会在其节点卡上呈现一个小徽章，以便您一眼就能发现未覆盖的代码。

仪表板文件/类双视图切换 (#132) — by @Xingkai98

在文件级和类级结构视图之间切换，以消除大型面向对象代码库的混乱。视图状态重置是有范围的，因此切换图层时切换保持正常，并且详细信息工具栏隐藏在不适用的域视图中。

可定制的标题字体 (#121) — by @Buzzwoo-Ecom-Team

主题设置公开了标题字体覆盖，因此团队可以匹配其内部设计系统而无需分叉。

移动布局 + 响应式仪表板 (880e223)

仪表板现在具有真正的移动布局，而不是水平滚动的桌面。侧边栏折叠，代码查看器适应纵向，并且触摸导航可以工作。

关闭了图形提取中无声数据丢失的 12 个来源 (c49c46d)

管道范围内的审计发现了在批量文件分析和合并期间节点或边缘被悄悄删除的 12 个位置。所有十二个现已关闭并覆盖：

  • 当文件分析器批次删除 imports 边缘时，它们会恢复 (05fd423)。
  • 在添加之前强制转换 tested_by 格式错误的标签（fdfa331，问题 #113）。
  • 文件分析器保留语言，并在导入未解决时回退（7834f9b）。
  • 合并期间保留规范边缘方向，因此重复数据删除不会丢失一半边缘（f71bad5，在 2.7.1 中）。
  • 指纹合并在第 3d 阶段变得明确，因此重新运行收敛（dd8b724，在 2.7.2 中）。
  • .understandignore 排除实际上应用于 auto-update (5304ff0) 的第 0 阶段。
  • build-fingerprints.mjs 捆绑且第 7 阶段重新排序，因此增量更新适用于全新安装（e7af9ae，在 2.7.3 中）。

自动更新/增量管道（2.7.x 线）

结构指纹识别 (--auto-update / --no-auto-update) 在 2.7 系列中成为现实：仅通过分析重新运行更改的文件，指纹确定性合并，第 0 阶段尊重 .understandignore。针对大型回购的重复运行大幅加速。

仪表板 ACCESS_TOKEN 覆盖 (1779cbd)

对于嵌入式/CI 用例，可以通过 env var 覆盖开发服务器的访问令牌，而无需编辑配置。
