Understand-Anything v2.1.0

小版本 发布时间2026年4月3日 来源Egonex-AI/Understand-Anything 英文原文

Understand-Anything v2.1.0

这个项目是干啥的：一个帮你看懂海量资料的工具，能分析知识库、画出业务领域关系图，给想快速理清陌生领域的人用。

变更架构图

亮点

  • 业务领域图 — /understand-domain 新增专用分析器、domain/flow/step 节点、下钻视图，以及 saveDomainGraph/loadDomainGraph 持久化。这让开发者可以结合架构检查业务行为，而不必只从代码结构推断意图。

  • 可靠的生成图 — 确定性的 ID 规范化让并行分析器的输出不受执行顺序影响即可复现，跨变体的边解析现在覆盖全部 13 种节点类型并追踪被丢弃的边（#65）。函数/类节点现在也正确出现在层级详情中（#65、#66），减少误导或不完整的依赖分析。

  • VS Code + GitHub Copilot 支持 — Agent skills 现在能与 Copilot 协同工作（#52），把项目的分析工作流带到更广的编辑器集成中，无需单独迁移。

  • 更好用的仪表盘 — 节点类型过滤、工具提示和路径查找改善了图浏览体验（#50）。PNG 导出现在使用 SVG 图元而非 foreignObject，避免不支持的 SVG/HTML 特性导致渲染失败；溢出的图例可横向滚动（#50）。

  • 可移植性与提示维护 — POSIX 兼容的 hook 取代仅 Bash 的 herestrings（#64），改善 shell 兼容性。提示模板现在放在 agent 定义内部，因此定制应针对这些定义；CI 也会在 PR 上检查构建、测试和类型。

  • 破坏性变更 — v2.1.0 未列出。

v2.1.0 的新功能

业务领域知识图谱

全新的域图视图映射您的代码库的业务逻辑（域、流程和流程步骤），以便您可以了解软件的功能以及它是如何构建的。

  • 新的 /understand-domain 技能使用专用的域分析器代理提取业务领域知识
  • 仪表板中的域图视图，带有视图模式切换药丸，可在体系结构和域图之间切换
  • 自定义节点组件：DomainClusterNode、FlowNode、StepNode 以及域感知 NodeInfo 侧边栏
  • 域概述和详细深入视图，具有自动加宽长边标签间距的功能
  • 新的核心类型：domain、flow、step 节点类型和特定于域的边缘类型
  • 核心中的saveDomainGraph / loadDomainGraph持久化功能

错误修复

  • 层详细信息视图中缺少节点类型 - 函数/类节点现在正确显示在层详细信息中（#65、#66）
  • 确定性节点 ID 标准化 - 并行批量分析器输出现在生成一致的 ID，无论执行顺序如何 (#65)
  • 处理所有 13 种节点类型 — 生成图的边跨变体分辨率和下降边可追溯性 (#65)
  • 步骤 ID 标准化 通过额外的测试覆盖率得到改进
  • **冗余底栏（CodeViewer）**不再出现在节点 click 上（#55）
  • POSIX 兼容的钩子 — 用 POSIX 管道替换 bash herestring 以获取更广泛的 shell 支持 (#64)
  • 修复了所有 7 个代理的 24 个提示工程审计问题
  • 8 个仪表板审计问题 跨组件解决

新平台支持

  • VS Code + GitHub Copilot 代理技能支持 (#52)

仪表板增强功能

  • PNG 导出修复：用干净的 SVG 基元替换 foreignObject (#50)
  • 节点类型过滤器、路径查找器和工具提示 (#50)
  • 标题图例现在可以在溢出时水平滚动

其他

  • CI：添加了用于构建、测试和类型检查的 PR 工作流程
  • 提示模板移至代理定义中以确保提示完整性
  • 所有自述文件翻译的文档均已更新
