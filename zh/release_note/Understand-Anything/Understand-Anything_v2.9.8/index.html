Understand-Anything v2.9.8

修订 发布时间2026年11月15日 来源Egonex-AI/Understand-Anything 英文原文

Understand-Anything v2.9.8

变更流程图

亮点

代码课程与源代码 (#753) — by @06FallingLight90

代码查看器现在包含与导览一致的每个文件的解释。巡回演出的文件有详细的部分； clicking 一个部分会突出显示其源代码行。其他文件收到概述。课程在构建或重建游览时生成，在保存图表后发布，并在文件离开图表时修剪。部分更新保留了现有的经验教训；巡演重建刷新了他们的线路范围。

Devin 支持和 stdio MCP 服务器 (#726) — by @isaiahfrantz

Devin 可以加载插件的分析管道和提交后挂钩。新的 MCP 服务器为现有图表提供了六种工具：状态、搜索、解释、变更影响分析、入门和仪表板启动。每个工具都包含图形新鲜度信息，并且仪表板进程在服务器退出时停止。设置说明位于 MCP 自述文件 中。

增量分析和符号保存

  • 确定性增量准备可协调文件更改、忽略规则、结构指纹和导入。当这些阶段不需要运行时，更新会保留幸存的架构和游览内容（#682）。
  • 源证据检查在增量更新期间保护现有符号，失败的最终确定会恢复保存的图形和指纹（#683、#753）。
  • 指纹通过其封闭的所有者和名称来匹配方法，使不同类中的同名方法保持不同（#766）——作者：@thejesh23。
  • Swift、Rust、Ruby 和 PHP 的基线批量合并、Python 相对导入、Makefile 目标检测和 Z​​ZPH1ZZ 关系收到正确性修复（#564、#728、#725、#689）。

图表新鲜度和自动更新

  • 当保存的分析过时时，仪表板和图形消耗技能会报告（#558）——作者：@jian4wqy。
  • PostToolUse 挂钩从 stdin 读取工具输入，并以支持的响应格式提供附加上下文（#598、#609）——作者：@amitvijapur 和 @KumamuKuma。
  • 仅包含生成的图形工件的提交不再触发自动更新循环 (#634) — 作者：@SulimanAbdulrazzaq。
  • 不可读的文件与没有解析器支持的文件分开报告（#686）——作者：@dajiao Huang。

仪表板和大型存储库支持

  • 强制布局计算在 Web Worker 中运行 (#576) — 作者：@KumamuKuma。
  • 图形处理改进涵盖游览生成、解析、社区检测、过滤和嵌入搜索 (#490) — 作者：@DashBot-0001。
  • 可重复的基准测试记录大型存储库的确定性分析时间、内存、覆盖范围和完整性结果 (#587) — 作者：@KumamuKuma。
  • Markdown 文件在代码查看器中呈现，图形加载失败会显示其 HTTP 错误 (#577)。
  • /understand --exclude 接受用户提供的忽略模式 (#373) — by @yiziff。 Starter 忽略规则现在涵盖额外的 Python、Rust、Ruby 和 Swift 测试和装置（#579、#582、#597、#600） — 作者：@thejesh23。

语言、安装和文档

  • 越南语仪表板、技能和自述文件支持 (#709) — 作者：@rgb-vgx。
  • Kimi 安装在 Unix 和 Windows 上使用 .kimi-code/skills (#685, #687) — 作者：@FumasterLin 和 @dajiao Huang。
  • Windows 安装支持 PowerShell 5.1 (#185) — 作者：@Bortlesboat。
  • 更新了 Codex 和 VS Code Copilot 安装指南、贡献者测试命令、翻译的自述文件以及保存为 UA_ONBOARDING.md 的入门输出（#566、#756、#718、#567、#606、#637）。

独立查看器

随附的 understand-anything-viewer.tgz 包括此版本的仪表板。使用以下命令打开已分析的项目：

npx https://github.com/Egonex-AI/Understand-Anything/releases/download/v2.9.8/understand-anything-viewer.tgz /path/to/analyzed/project

查看器需要 Node.js 18 或更高版本。工作区构建和 MCP 服务器需要 Node.js 22 或更高版本以及 pnpm 10 或更高版本。现有的 .ua/ 和旧版 .understand-anything/ 数据目录仍然受支持。 完整 Changelog：https://github.com/Egonex-AI/Understand-Anything/compare/v2.9.0…v2.9.8
