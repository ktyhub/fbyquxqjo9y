KTransformers v0.6.4：高性能端到端全参数和 LoRA 微调

KTransformers v0.6.4 是针对大型稀疏 MoE 模型的 KT 微调路径的重大升级。此版本将 KT SFT 从端到端 全参数微调 扩展到 LoRA，同时提高了 BF16 CPU-GPU 异构训练吞吐量以及跨主机 RAM 和 GPU VRAM 的内存效率。

🚀 核心亮点

  • 端到端全参数和 LoRA SFT：通过熟悉的 LLaMA-Factory 工作流程，使用完全微调、LoRA 或混合配置训练大型稀疏 MoE 模型。
  • 高训练吞吐量：在真正的端到端训练运行中（不是孤立的内核基准测试），KTransformers 在使用 2 个 AMD EPYC 9355 CPU 和 2 个 RTX 5090 GPU 的 Qwen3-30B-A3B 上达到了大约 400 个令牌/秒（使用 Full-FT）和 600 个令牌/秒（使用 LoRA）。使用一个 RTX 4090 和一个支持 AMX 的 CPU 的单独 LoRA 设置可维持超过 700 个令牌/秒。由此产生的检查点还显示出端到端微调验证的明显收益。
  • Ampere GPU 上的 DeepSeek V4：BF16 注意力回退和 FP8 MoE Marlin 路径将 DeepSeek V4 Flash 支持扩展到没有本机 FP8 Tensor Core 的 GPU。
  • RAWINT4 兼容性和加速：更广泛的打包重量兼容性、AVX-VNNI-256 专家加载以及更快的 Kimi K2 预填充路径。
  • 实验性英特尔 iGPU 后端：针对英特尔集成 GPU 的新的基于 SYCL 的 GPTQ INT4 MoE 推理支持。

📌 全参数、LoRA 和混合 SFT

此版本完成了大型稀疏 MoE 模型的 KT CPU-GPU 异构训练工作流程：

  • 全面微调 更新 KT 管理的 CPU 专家权重以及模型的常规可训练参数。
  • LoRA 涵盖常规线性层、路由器和门以及融合的 MoE 专家。
  • 混合训练允许同时训练 Full-FT 和 LoRA 参数。
  • 可靠的多步训练 支持梯度累积、激活检查点、分布式执行、优化器更新和分析。 新的培训路径主要针对BF16 KT CPU专家培训。 👉主要实现：ktransformers PR #2094

📌 DeepSeek V4 和 Ampere GPU

捆绑的 sglang-kt 集成在 Ampere GPU 上增加了更广泛的 DeepSeek V4 Flash 和 FP8 MoE 支持：

  • 没有原生 FP8 张量核心的 GPU 的 BF16 KV 缓存和注意力回退。
  • FP8 MoE Marlin 支持 GPU 专家、GPU 预填充和动态专家更新。
  • 修复了长输入调度、AMXINT4/8 启动和 FP16 FE8M0 规模反量化的稳定性。 相关变更：
  • Ampere GPU 上的 DeepSeek V4 Flash 推理
  • 修复 V4 SWA 代币池大小
  • 修复 AMXINT4/8 SwiGLU 参数处理
  • FP8 MoE Marlin 用于 GPU Expert 和 GPU 预填充
  • FP16 FE8M0 马林鱼鳞片去量化

📌 RAWINT4 兼容性和预填充加速

KTransformers v0.6.4 通过以下方式改进了 RAWINT4 CPU Expert 路径：

  • 支持压缩张量检查点，将打包的 INT4 权重存储在 int32 中。
  • AVX-VNNI-256 系统上的每专家 RAWINT4 加载。
  • 阻塞矩阵乘法路径可实现更快的 Kimi K2 RAWINT4 预填充，同时保留短序列的现有解码路径。 相关变更：
  • 标准化压缩的 RAWINT4 权重
  • AVX-VNNI-256 每个专家 RAWINT4 加载
  • K2 RAWINT4 预填充垫-垫发货

📌 实验性 Intel iGPU SYCL 后端

此版本引入了一个实验性 SYCL 后端，用于 Intel 集成 GPU 上的 GPTQ INT4 MoE 推理。兼容性和性能取决于 Intel GPU、驱动程序、SYCL 工具链和模型配置。 👉 Intel iGPU SYCL GPTQ INT4 MoE 后端

🔐 安全

balance_serve 调度程序现在将其 ZMQ ROUTER 端点绑定到 127.0.0.1 而不是所有网络接口，从而减少未经身份验证的远程 pickle 反序列化的风险。

  • 安全修复 PR #2091
  • GHSA-83vp-v6wg-x93x

📦 安装

KT SFT

pip install "ktransformers[sft]"

KT SFT 继续使用 LLaMA-Factory 培训入口和 YAML 工作流程。

KT 推理

pip install kt-kernel sglang-kt

从源安装

git clone https://github.com/kvcache-ai/ktransformers.git
cd ktransformers
git submodule update --init --recursive
cd kt-kernel && ./install.sh
cd .. && ./install.sh

需要 CUDA 12.0 或更高版本。各个后端可能有额外的 CPU ISA、GPU 架构、驱动程序或编译器要求。
