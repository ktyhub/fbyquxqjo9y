ktransformers v0.6.1

KTransformers v0.6.1 是对大型 MoE LoRA SFT 现有 KT 微调路径的全面重构和重大升级。此版本围绕 kt-kernel 重建了 KT SFT 后端，将 SFT 堆栈打包在 ktransformers[sft] 条目后面，并保持 LLaMA-Factory 培训条目和 YAML 工作流程为用户所熟悉。 在测量的基准设置中，与 ZeRO-Offload 基准相比，KT SFT 达到了 6-12x 训练性能。另外，与之前的 KT SFT 路径相比，CPU 内存使用量减少到大约 1/2，在相同基准测试环境下 GPU 内存压力更低。这些结果与基准设置相关，应与模型、硬件、上下文长度、LoRA 配置和基线详细信息一起阅读。

🚀 核心亮点

  • 重构大型 MoE SFT 后端：围绕具有 LoRA 支持的 AMX MoE 内核重建 KT SFT 路径，包括 SFT 特定的 AMX 内核、LoRA 融合添加测试、重新打包测试、Python SFT 包装器、autograd 集成、层定义和权重助手 (#1936)。
  • 可通过 Pip 安装的 SFT 堆栈：ktransformers[sft] 现在通过常规 Python 软件包安装 KT SFT 堆栈：ktransformers、kt-kernel、transformers-kt 和 accelerate-kt。
  • LLaMA-Factory 工作流程集成：KT SFT 设计为在安装 LLaMA-Factory 后使用，同时保留标准 accelerate launch / src/train.py / YAML 工作流程。同伴 LLaMA-Factory PR：hiyouga/LLaMA-Factory#10430。
  • 更清晰的包边界：旧的 kt-sft 包已被存档； SFT 现在使用 ktransformers[sft]，而 KT 推理使用 kt-kernel + sglang-kt（#1954、#1955）。
  • 当前的 torch 基线：包元数据和经过验证的公共安装路径在 torch==2.9.1 上对齐，其中 torchaudio==2.9.1 和 torchvision==0.24.1 用于当前的全堆栈设置。

📌 模型、硬件和工具

SFT 和包装

  • 在 main 上准备 v0.6.1 SFT 轮包装，包括 ktransformers[sft]、kt-kernel 包装更新、发布工作流程更新和轻量级顶级包垫片 (#1945)。
  • 将 kt-kernel 和相关包元数据与当前版本依赖关系基线对齐 (#1948)。
  • 压平 ktransformers 包装垫片以清洁车轮包装 (#1955)。
  • 将旧版 kt-sft 封装归档到 archive/kt-sft/ 下，以便更容易推断活动封装布局 (#1954)。

内核和硬件改进

  • 在 AMX 后端添加对 FP8 和 BF16 的 AVX512F+BW 回退支持，改善 AMX 特定路径不可用的 CPU 回退覆盖范围 (#1908)。
  • 添加对 GPTQ INT4 MoE 的 VNNI-256 支持，包括新的 gptq_int4_avxvnni 路径和每次提交准确性测试覆盖范围 (#1926)。
  • 添加 SFT 特定的 AMX MoE 内核、张量并行 MoE SFT 助手、LoRA 内核测试、重新打包测试和 Python SFT 模块包装器 (#1936)。

推理和运行时集成

  • 同步捆绑的 sglang 子模块以进行 KT 分层预填充更新和后续的打包修复 (#1920)。
  • 更新 SGLang-KT 发布工作流程以使用托管运行器，避免在不可用的自托管运行器上发布阻塞。

模型启用

  • 添加 GLM-5.1 教程和 kt-kernel 路径的先决条件说明（#1916、#1932）。
  • 刷新 Kimi-K2.5、MiniMax-M2.5、Qwen3.5、DeepSeek-V3.2 和 SFT 文档的自述文件和模型文档链接。

📦 安装

KT SFT 与 LLaMA-Factory

使用包含 KT 示例和 requirements/ktransformers.txt 的 LLaMA-Factory 结账。

cd /path/to/LLaMA-Factory
pip install -e .
pip install -r requirements/ktransformers.txt

对于在需求文件之外直接安装包：

pip install "ktransformers[sft]"

KT 推理

KT 推理使用 SGLang-KT 路径：

pip install kt-kernel sglang-kt

将 kt-kernel 保留在推理安装路径中。 LLaMA-Factory SFT 继续使用 ktransformers[sft]。
