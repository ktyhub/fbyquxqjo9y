bootstrap v5.3.4

修订 发布时间2025年4月3日 来源twbs/bootstrap 英文原文

变更流程图

亮点

  • 色彩模式视觉修复 — 如果你发布浅/深主题，这个补丁清掉若干回归：modal 和 offcanvas 头部不再塌缩（#41336）、关闭按钮在上下文浅/深背景上正确渲染（#41126）、light 轮播变体在深色页面上正常显示（#40695）。如果你为这些 bug 加过本地 CSS 补丁，现在可能冗余了。
  • 浮动标签调优 — 一系列修复让浮动标签更可预测：与 form-select 尺寸对齐（#41013）、遵守正确的 max-width 和 background-color（#39720）、使用更新后的占位符色（#39494）。如果手动打过标签尺寸或颜色的补丁，升级前对照新默认值 diff 一下。
  • Popover 切换行为改变 — #40803 修复 popover：第二次点击切换按钮现在真的会关闭它。这是真实的行为变化：检查任何依赖（或绕过）旧双击切换行为的 UI 逻辑或测试。#38725 还修正 JS 内部函数的 this 绑定——如果间接调用插件方法，值得冒烟测一下。
  • Sass 与构建工具兼容性 — 从源码编译更干净：#40623 把出现在嵌套规则之后的声明移走（Dart Sass 1.77.7 起弃用）以消除警告，#41004 绕过 postcss-values-parser 在负 calc() 值上失败的问题，#39804 优化 Sass SVG 资源。过时的 flexbug 兼容代码也被移除（#40876），自定义构建应更安静、更精简。
  • 组件打磨与迁移提醒 — btn-group-vertical 现复用 btn-group 规则以统一样式（#40488），手风琴 border-radius 选择器被合并（#39697）。对从 v4 升级的用户，迁移指南现在明确记录 util.js 被移除（#41187）——提醒 v5 没有可沿用的独立工具 JS 层。
  • 破坏性变更 — 无；这是补丁版本，没有 API 破坏性变更。
