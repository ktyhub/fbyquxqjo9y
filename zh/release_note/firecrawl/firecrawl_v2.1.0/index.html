firecrawl v2.1.0

firecrawl v2.1.0

这个项目是干啥的：一个把整个网站爬下来并整理成 AI 可用数据的工具，支持搜索和并发抓取，给需要喂数据给大模型的开发者用。

变更架构图

亮点

  • 更广的提取与搜索控制 — 新增 v2 图像提取、data-* 属性提取、元数据中的 PDF 标题，以及通过 categories（github 和 research）进行搜索过滤。这些减少了下游解析工作，也让发现过程更有针对性。
  • 改进的爬取覆盖 — 爬取端点现在能处理基于 hash 的路由，Google Drive 抓取也支持 TXT、PDF 和 Sheets 文件。如果基于 hash 路由的应用或 Drive 托管的文档在你的数据流水线中，就升级。
  • 可靠性与计费修复 — 修正了 Google 搜索的 UTF-8 处理、v2 /search 配合 scrapeOptions.formats 时的 JSON 和文档字段处理、预览爬取状态、Python SDK 缺失的方法，以及 v0 credits_billed 的填充；api_key_id 现在也会传到计费环节。对多语言搜索、Python 客户端、预览测试和使用量报告尤其相关。
  • 规模、部署与安全 — map 端点现在支持最多 10 万条结果，自托管有了初版 Helm chart，XFF 欺骗防护也得到改进。对大规模 map 任务或 Kubernetes 部署值得采用，不过该 chart 官方称为初版。
  • 升级评估 — 文档未记录破坏性变更或必需的迁移步骤。如果你需要新能力，或依赖被修复的行为，就升级；否则，稳定的 v2.0.1 工作流可以合理跳过此版本。

#Firecrawl v2.1.0 来了！

✨ 新功能

  • 搜索类别：使用 categories 参数按特定类别过滤搜索结果：
    • github：在 GitHub 存储库、代码、问题和文档中搜索
    • research：搜索学术和研究网站（arXiv、Nature、IEEE、PubMed 等）
    • 更多即将推出
  • 图像提取： 添加了对 v2 抓取端点的图像提取支持。
  • 数据属性 Scraping： 现在支持提取 data-* 属性。
  • 基于哈希的路由： 爬网端点现在处理基于哈希的路由。
  • 改进了 Google Drive Scraping： 添加了从 Google Drive 抓取 TXT、PDF 和表格的功能。
  • PDF 增强功能： 提取 PDF 标题并在元数据中显示它们。
  • API 增强功能：
    • 地图端点支持最多 100k 结果。
  • Helm Chart： 为 Firecrawl 部署添加了初始 Helm 图表。
  • 安全性： 改进了针对 XFF 欺骗的保护。

🛠 修复

  • 修复了 Google 搜索抓取工具中的 UTF-8 编码。
  • 恢复了预览模式下的抓取状态。
  • 修复了 Python SDK 中缺失的方法。
  • 更正了使用 scrapeOptions.formats 进行 v2 搜索的 JSON 响应处理。
  • 修复了 v0 刮擦中 credits_billed 的现场人口。
  • 改进了 v2 搜索中的文档字段覆盖。
