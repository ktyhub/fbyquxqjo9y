goose v1.30.0

小版本 发布时间2026年4月8日 来源aaif-goose/goose 英文原文

🪿 鹅 v1.30.0 Release Notes

发布日期： 2026 年 4 月 8 日

✨ 新功能

🖥️ 终端 UI (TUI) 检修

  • 选项卡可扩展工具调用 - 工具调用输出现在可以通过选项卡展开来完全折叠 (#8136)
  • 改进消息渲染 - 更好的排序、流式传输/滚动以及消息、工具调用和文本输入的整体视觉效果（#8144、#8156、#8214）
  • 独立的 --text 模式 — 文本模式现已与普通 TUI 分离，以获得更干净的无头体验 (#8210)
  • goose serve — 将 Goose 作为后台服务运行的新子命令 (#8209)

🔌 提供商和模型

  • Gemini OAuth 提供程序 — Google Gemini 的一流基于 OAuth 的身份验证 (#8129)
  • Copilot ACP 提供商 — 通过 ACP 为 GitHub Copilot 提供新提供商 (#8154)
  • Zhipu 声明性提供程序 — 添加了具有可配置 ZHIPU_BASE_URL 覆盖的 Shipu AI (#8204)
  • 用于声明性提供程序的可配置 fast_model — 允许您为快速任务指定轻量级模型 (#8194)
  • Gemma 4 本地模型支持 — 启用 Gemma 4 作为本地模型选项 (#8366)
  • VMware Tanzu 平台提供商改进 — 错误修复、流支持和 UI 增强 (#8126)

🛡️ 安全性和可观察性

  • 出口日志检查器 — 用于记录和检查出站网络调用的新安全功能 (#8149)
  • 受限机密文件权限 - 现在使用更严格的操作系统级别权限创建机密文件（#8118）

🧩 扩展和技能

  • 在 UI 中显示已安装的技能 - 现在可以从桌面应用程序查看和浏览技能 (#7910)
  • 技能平台扩展 - 技能现在作为专用平台扩展进行管理（#8377）
  • 递归发现嵌套技能 - 现在可以在任何深度找到配置根下的技能（#8082）
  • 可配置的分机超时 — 通过 ACP _meta 或全局默认值设置每个分机的超时 (#8295)
  • 可重复使用的 ACP 提供程序控件 — 用于 ACP 提供程序配置的共享 UI 组件 (#8314)
  • Rust ACP client 用于扩展方法 (#8227)
  • 开发人员 MCP 服务器增强 (#7770)

🌐 国际化

  • i18n 基础设施 — 在桌面应用程序中添加了基于 react-intl 的国际化框架 (#8105)

🩺 诊断

  • goose doctor — 用于诊断常见配置和环境问题的新命令 (#8342)

⚙️ 配置

  • GOOSE_SHOW_FULL_OUTPUT — 用于禁用工具输出截断的新配置选项（#7919）
  • GOOSE_CLI_SHOW_THINKING — 现在可以在 config.yaml 中设置（不仅仅是环境变量）（#8097）
  • GOOSE_CONTEXT_LIMIT — 现在可以从 config.yaml 读取 (#7900)
  • GOOSE_DISABLE_KEYRING — 现在在启动时获得 config.yaml 的荣誉 (#8219)
  • 每个代表 max_turns 覆盖 (#8066)
  • skip_canonical_filtering 用于声明性提供者 (#8052)

🏗️ 构建和打包

  • 可选的 native-tls 支持 — 对于需要系统 TLS 的环境，替代 rustls (#8037)
  • 功能门控的 AWS 提供商依赖项 — 在 aws-providers 功能标志后面，用于更精简的构建 (#8080)
  • 功能门控遥测 - 遥测现在位于 Cargo 功能标志后面 (#8119)
  • 推理网格设置选项卡 (#8094)

🐛 错误修复

提供商

  • 修复当消息同时包含文本和图像时，用户消息文本会自动删除 (#8071)
  • 为基岩工具输入发送空对象而不是 null (#8121)
  • 当模型端点获取失败时回退到配置的模型（#7530）
  • 防止 Ollama 提供程序挂起工具调用请求（#7723）
  • 增加 Ollama 重试配置 + 添加仅瞬态重试模式 (#7677)
  • 使用 safely_parse_json 作为 OpenAI 流工具参数 (#8208)
  • 对 GCP Vertex AI 上的 Google/MaaS 模型使用 v1beta1 API 版本 (#8278)
  • 使用 build_host_url 进行 GCP Vertex AI 位置回退（#8185）
  • 解析 LiteLLM 中的嵌套使用负载（#8081）
  • 优先考虑预定义模型 context_limit 而非规范注册表 (#7888)
  • 始终将 --model 传递给游标代理 CLI (#8106)
  • 修复 OAuth 配置完成后“选择模型”模式中未显示的模型 (#7891)
  • 允许使用受保护资源回退而不是 WWW-Authenticate 标头连接到 OAuth 服务器 (#8148)

桌面应用程序

  • 修复“View as Markdown”功能不起作用 (#8160)
  • 修复桌面斜线命令（#8341）
  • 修复 GitHub Copilot 身份验证无法在桌面应用程序中打开浏览器的问题 (#8019)
  • 在用户界面中隐藏隐藏的扩展（#8346）
  • 当聊天解析错误发生时返回原始文本（#8402）
  • 修复 Gemini ACP，不会出现意外的终端窗口 (#8101)
  • 用图标组件中正确的 SVG 类型替换 any (#7873)
  • 修复 CLI 中带引号的扩展命令 (#8150)
  • 修复 overflow: clip 以免破坏粘性 ToC (#8158)
  • 修复 Windows 上的 i18n 编译 (#8202)
  • 修复 MultilineInput 组件 (#8382)

CLI & 核心

  • 使用 ETXTBSY 修复 Goose 更新在 Linux 上失败的问题 (#8107)
  • 解决 MCP 扩展子进程的用户登录 PATH (#7896)
  • 在 CLI 会话生成器中用用户友好的错误替换恐慌（#7901）
  • 在 CLI 会话标题生成中剥离消息包装器（#7996）
  • 在密钥环配置对话框中显示平台正确的秘密路径（#8328）
  • 将截断通知作为单独的内容块提供（#7899）
  • 在开发人员扩展指令中使用适合平台的命令（#7898）
  • 重新整合拆分工具调用消息以遵循 OpenAI 格式（#7921）
  • 父进程突然退出后清理 MCP 子进程 (#8242)
  • 修复 Flatpak 沙箱阻止访问主机系统命令 (#8109)
  • Gate keyring 平台功能背后的目标特定部门 (#8039)
  • 将默认堆栈保留提高到 8 MB (#8234)

ACP

  • 将 ACP 会话与用户会话分开 (#7857)
  • 避免工具调用周围出现重复的思维块 (#8215)

⚡ 性能

  • 在 ACP 服务器中并行化扩展加载以加快启动速度 (#8098)
  • 网格二进制文件管理 — 每次启动时下载新的二进制文件；当 Goose 退出时杀死网格 (#8228)

📚 文档
