ECC v1.9.0

这个项目是干啥的：是一个给Claude Code用的配置与玩法合集，把常用的规则、技能和子代理打包好，让想让AI编程更顺手的人直接拿来用。

变更架构图

亮点

ECC Tools Pro 已上线。 GitHub 应用程序现在具有 Pro 级别的 Stripe 计费功能（19 美元/席位/月），用于私人回购分析、每月 50 次分析以及 AgentShield 支持的扫描。公共回购的免费套餐仍为每月 10 次分析。在 github.com/apps/ecc-tools 安装，在 ecc.tools/pricing 升级。 此处为选择性安装。 使用 --with 和 --without 标志仅安装您需要的内容。 ecc install --profile developer --with lang:typescript --with agent:security-reviewer --without skill:continuous-learning。代理和技能组件系列现在位于安装清单中。 12 种语言生态系统。 C#、Rust、Java、Kotlin、C++、Go、Python、TypeScript、Perl、PyTorch、Nuxt 4 和 Flutter 现在拥有专用的规则、代理或技能。 AgentShield v1.4.0 随附。 修复了误报扫描。 CVE 数据库包含 25 个以上已知的 MCP 漏洞。供应链验证。运行时监控。观看模式。公关安全门。组织范围内的政策执行。 https://github.com/user-attachments/assets/eece2c76-7eb9-4865-a58b-f11247fd774e
