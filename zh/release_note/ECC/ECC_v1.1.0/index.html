介绍 ecc.tools

问题： 你的代码库中有一些你甚至没有意识到是模式的模式。 每个团队都有跨越多个提交的流程 - 例如：

  • 添加新的数据库表（修改架构、生成迁移、更新索引、修复合并冲突）
  • 设置新的 API 端点（创建路由、添加验证、编写测试、更新文档）
  • 加入新服务（配置文件、环境变量、CI/CD 更新） 您手动执行这些操作，分散在数十次提交中，而没有意识到它们可能是单个 /new-table 或 /new-endpoint 技能。 ecc.tools 的作用： 它会分析您的 git 提交历史记录，以找到这些隐藏的模式，并自动将它们包装到 Claude Code 技能中。 它发现：
  • 无需思考即可重复的多步骤流程
  • 你从未注意到的队友使用的模式
  • 您在脑海中无意识地自动化但从未记录下来的工作流程 然后它会生成 SKILL.md 文件和挂钩，以便 Claude Code 可以为您完成这些工作。

GitHub 应用程序（等待市场批准）

ecc.tools GitHub 应用程序目前正在审核中。一旦获得批准： 1、用一台click安装 2.它分析你的存储库的提交历史记录 3. 识别重复的多文件更改模式 4. 生成即用型技能和本能集合

即将推出：插件发布

ecc.tools 还将作为 Claude Code 插件提供，用于本地分析，无需 GitHub 应用程序。 安装GitHub应用程序： https://github.com/apps/skill-creator 访问： https://ecc.tools

亮点

会话 ID 跟踪（问题 #62）

会话文件现在包含唯一标识符，以便更好地进行多会话跟踪：

~/.claude/sessions/2026-01-25-abc12345-session.tmp

跨平台支持

所有挂钩和脚本均以 Node.js 重写，以实现 Windows、macOS 和 Linux 兼容性。

新技能

  • 迭代检索 - 子代理的渐进上下文细化
  • 持续学习-v2 - 基于本能的学习和置信度评分

异步钩子文档

新的 async: true 选项用于在后台运行而不会阻塞的挂钩：

{
  "type": "command",
  "command": "node analysis.js",
  "async": true,
  "timeout": 30
}
