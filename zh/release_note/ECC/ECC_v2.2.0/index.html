ECC v2.2.0

小版本 发布时间2026年8月28日 来源affaan-m/ECC 英文原文

ECC v2.2.0

ECC 2.2 现已推出，由 Claude Code、Codex 和 Kimi 的一位指导安装人员领导。 它还添加了原生 Antigravity 2.0 支持和实验性的、可选的 Nasiko CLI 生命周期桥梁。 发布管道也更严格：确切的 npm 存档必须通过生命周期 在 latest 移动之前在 Linux、macOS 和 Windows 上进行了测试。

进入 ECC 的一种引导路径

使用以下命令启动引导安装程序：

npx --yes ecc-universal@2.2.0 install --guided

安装程序在写入文件之前检查每个选定的线束，然后应用 将设置作为一项操作。提供商拥有的模型和身份验证设置 处于提供商的控制之下。终端欢迎仅在 交互式安装成功。

Nasiko：实验性的、选择加入的、明确的

ECC 2.2 可以检查、安装和拆卸一个固定的 Nasiko v0.1.0 CLI 版本：

npm install -g ecc-universal@2.2.0
ecc nasiko status --json
ecc nasiko install --version v0.1.0 --dry-run --json
ecc nasiko install --version v0.1.0 --yes --json

下载内容已定址并经过 SHA-256 验证，状态为只读，并且 卸载可保护修改过的或不合格的二进制文件。上面的仪表板是 纳西科自己的产品。 ECC 不连接代理、启动服务器、启用 遥测、共享数据或操作该控制平面。这座桥依然存在 实验性和选择性加入。 在 Nasiko 存储库 中了解更多信息。

每条线束都更可靠

  • 本机反重力 2.0： ECC 安装到 .agents/{rules,workflows,skills,agents} 并安全迁移遗留所有权。
  • **可靠卸载：**重复选择性安装保持完整所有权 分类帐，因此可以干净地删除未更改的 ECC 管理文件。
  • 更安全的迁移： OpenCode 使用 ~/.config/opencode，而 OpenCode 和 Codex 在清理期间保留已编辑或未跟踪的文件。
  • 更多工作流程： Pi、Itô、代理评估、多模型委员会、开发团队、 Living docs、安全终端、TasteForge 和 skill-comply 都扩展了 发货分配。 ECC 2.2 配备 68 个代理、286 个技能和 94 个命令垫片，加上规则， 钩子、记忆、持续学习以及围绕它们的安装表面。

发布保证

标记的提交必须匹配 origin/main。一个 npm 存档已打包、散列， 并在所有三个操作系统上进行测试，然后在暂存标签下发布。 在 latest 移动之前，注册表完整性必须匹配。之前的2.1.0封装 仍然是立即回滚目标。

安装或升级

对于原生 Claude Code 插件：

/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc

现有的 Claude 安装可以运行 /plugin update ecc。
