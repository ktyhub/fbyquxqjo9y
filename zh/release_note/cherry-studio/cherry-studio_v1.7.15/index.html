cherry-studio v1.7.15

修订 发布时间2026年1月25日 来源CherryHQ/cherry-studio 英文原文

变更架构图

亮点

  • 安全 / 凭据变更 — 修复 DXT 插件系统的路径穿越漏洞（#12377），并移除内置的 mineru API key（#12455）。使用 DXT 插件的人都应升级；**潜在破坏性变更：**如果你此前依赖内置的 MinerU 访问能力，可能需要自行提供 API 凭据。
  • provider 与 MCP 兼容性 — sendReasoning 现在只作用于 openai-compatible SDK provider，OpenRouter 禁用严格 JSON schema 以便 MCP 工具可用，qwen-code 的 base URL 补上 /v1，并修复了图像增强历史记录和图片生成 URL 尾部斜杠的问题。使用这些 provider 或工作流的人应升级。
  • 新能力 — Code Tools 新增 Kimi CLI，并修复自定义 provider 和 Windows Terminal 相关问题；新增 Qwen 文本嵌入、baichuan-m3 / baichuan-m3-plus，以及笔记的 Word 导出。如果这些对你有用就值得升级，否则可选。
  • 桌面与可靠性 — 改进 Linux 支持：musl 依赖、托盘聚焦、图标和 .deb 安装修复，新增 Linux 标题栏设置，并修复 provider 选择器无限重渲染循环。Linux 用户和遇到 UI 卡死的人应更新；不受影响的人可跳过这些修复。
  • 迁移与结论 — 开发钩子从 Husky 迁移到 prek，贡献者必须改用新工具；Translate 动作的双语选择器被移除。未记录公共 API 或数据迁移。总体来看，为了安全和 provider 修复应升级；不受影响领域的人可以延后。
