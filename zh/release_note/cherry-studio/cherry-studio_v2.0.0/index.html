cherry-studio v2.0.0

大版本 发布时间2026年8月5日 来源CherryHQ/cherry-studio 英文原文

变更架构图

亮点

  • 2.0 界面大改版 — v2.0.0 是从零开始的 UI 重设计（多窗口与分屏布局，重新组织聊天/角色/项目/任务），所以你的工作区看起来和用起来都会与 1.x 明显不同。如果你同时应付多条会话线和多个交付物，值得升级；如果你习惯旧的单视图布局，那就先跳过，或做好重新学习的心理准备。
  • 内置 Agent 运行时与订阅复用 — agent 运行时现在直接打包进应用，省去了此前让 agent 功能难以启用的依赖安装和环境配置。它同时面向 OpenAI 和 Anthropic 端点，并能复用现有的 Claude/Codex 订阅——如果你想做研究、文档、演示、数据分析或编码 agent 而不另装工具，这是最强的升级理由。
  • 知识库与”Code Mate”替代方案 — agent 现在可以读取和维护知识库（像 Wiki 一样持续生长），编码工具被”Code Mate”取代，为 Claude Code 和 Codex 提供一键模型服务配置，图片生成也会动态展示每个模型可用的参数。注意工具被替换/改名为”Code Mate”——已有的 code-tool 工作流可能需要重新配置。
  • 性能工作，但未说明迁移路径 — “全面升级的数据基础”、超长对话中更顺滑的滚动、大文件夹导入不再阻塞界面，这些特别惠及历史记录庞大的用户。然而，尽管这是主版本且重写了存储层，changelog 并未指出破坏性变更或迁移步骤——升级前请备份数据。配置规模小、不需要 agent 或大历史性能的用户可以合理留在 1.x。

Cherry Studio 2.0.0 - 全新的 AI 工作空间，从聊天到完成工作 ✨ 新界面，新体验

  • 升级的交互和视觉设计使聊天、角色、项目和任务更清晰、更容易组织
  • 专为多任务处理而设计，具有多窗口和分割视图布局，可在工作之间切换以及查看进度和可交付成果 🤖 更强大的代理
  • 支持 OpenAI 和 Anthropic 端点，重用 Claude 和 Codex 订阅，并可与更多模型配合使用
  • 内置核心Agent运行时，大大减少依赖安装和环境设置
  • 更快地完成研究、文档、演示、数据分析和编码，并可一click 预览结果 🛠️更多工具升级
  • 代理可以读取和维护知识库，帮助您的知识像维基一样不断增长
  • 编码工具升级为Code Mate，为Claude Code、Codex等提供one-click模型服务配置
  • 图像生成动态显示每个模型可用的参数，使结果更容易控制 ⚡ 性能
  • 全面升级的数据基础即使具有丰富的历史记录也能保持响应能力
  • 在很长的对话中滚动更顺畅，而大文件夹导入不再阻塞界面
