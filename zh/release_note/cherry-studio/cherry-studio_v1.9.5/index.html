cherry-studio v1.9.5

修订 发布时间2026年5月12日 来源CherryHQ/cherry-studio 英文原文

变更架构图

亮点

  • macOS 备份恢复数据丢失 — PR #14781 把恢复的数据先暂存到 .restore 目录，修复 macOS 上的静默数据丢失；#14961 在恢复重启前清理选择钩子。这是本版本影响最大的改动：任何在 macOS 上恢复过备份的人都应升级。没有正式的迁移步骤，但请重新核验在受影响版本上做过的恢复操作。
  • 模型覆盖与推理控制 — 默认 DeepSeek 模型切换到 V4（#14877），带路由的 V4 slug 会被识别推理努力程度（#14887），官方 host 上的 DeepSeek V4+ pro 报告 1M 上下文（#14965）；新增 Claude Opus 4.7（#14349）、托管 Gemma 4 思考模式（#14793）和 AiHubMix gpt-image-2（#14903）。对 SiliconFlow 上设置了 reasoning_effort 为 none 的 DeepSeek/Zhipu 模型，应用现在改为发送 enable_thinking（#14782）。使用这些 provider 的人值得升级；否则只是增量添加。
  • API 与 agent 基础设施 — Anthropic SDK 的 baseURL 现在会去掉尾部的 /v1（#14818），Vercel 模型列举绕过 @ai-sdk/gateway 的 schema 校验（#14772），Vertex 模型列表拉取和服务账号设置得到修复（#14611），CherryIN 的 OpenAI 协议模型出现在 Agent 模型选择器中（#14811）。cron 工具新增 timeout_minutes 参数（#14707），agent 提示中过时的 mcp__browser__* 引用被移除（#14815），opencode 内置的自动更新检查被禁用（#14925）。
  • 安全与体验打磨 — run_eval.py 对其子进程调用做了净化（#14842），非 ASCII 的 provider 名称在用作环境变量时会被清理（#14915）。UI 修复覆盖仅网页搜索的工具列表（#14752）、横向多模型布局的外层滚动（#14768）、生成图片再编辑（#14500）、通过 emoji 反应在飞书输入（#14799）、切换语言时 i18n 助手/主题名（#14607），以及侧边栏会话/agent 可见性（#14954）。
  • 升级结论 — 无破坏性变更或迁移步骤；这是实质性补丁版本，不是重新打标签或仅改元数据。为了 macOS 备份修复、新模型支持和 run_eval.py 安全修复应升级；其他平台且不依赖上述 provider 的用户可以合理跳过。
