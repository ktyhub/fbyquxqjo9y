cherry-studio v2.1.2

修订 发布时间2026年9月21日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • 智能体分叉与心跳现可靠 — 原生检查点分叉（PR #20340）可回链到源会话（PR #20714）；长时 DSH 分叉不再超时（PR #20840），心跳调度器在 JobManager 栈上恢复（PR #20055），现使用系统工作区并清理旧条目（PR #20875）。若依赖分叉/恢复或定时智能体运行，这是此处最实质的变化。
  • Gemini：两类 HTTP 400 失败已修复 — 此前当工具参数声明数字或布尔枚举值（PR #20802、PR #20782）以及启用内置浏览器工具时（PR #20782）请求会失败。另外，长智能体流不再每次 tick 都触发完整 Markdown 重新解析（PR #20750），流式期间 UI 保持响应。
  • 隐私：退出选项现真正停止分析 — 此前关闭数据采集仍会发送事件；现在撤回同意时会丢弃队列并取消重试（PR #20701、PR #20818），且不再上报嵌入 token 用量（PR #20820）。若你依赖退出选项来满足合规要求，这点很重要。
  • 新提供商及需提前规划的行为变化 — 新增 oMLX 作为内置本地 OpenAI 兼容提供商，带预设 base URL 且无需 API Key（PR #20683），以及 Moonshot AI 全球端点（PR #18835）；刷新 DeepSeek 列表/目录（PR #20869），格式错误的 LM Studio 条目不再丢弃有效模型（PR #20450）。值得注意的行为变化：回收站更名为 Archive 并提升为独立设置页（PR #20873）；CherryIN 登录从系统自定义协议处理器切换为本地 HTTP 回环回调（PR #20280——可能需要重新认证）；mcp-auto-install 写入被限制在 Cherry 配置目录内（PR #20847——指向旧路径的外部工具需更新）；注册表模型补充现为选择加入（PR #20876）。
  • 升级结论 — 无破坏性 API 变更，无需迁移脚本；这是稳定性/打磨更新，不是重新打标签或仅改元数据的空操作（v2.1.0/v2.1.1 元数据同步 PR #20724 与 PR #20866 只是日常维护）。Gemini 用户、重度智能体/分叉或 MCP 用户、遇到追踪历史丢失的 Windows 用户，以及需要隐私修复的用户值得升级；在 2.1.1 上用得不错且无这些需求的用户可跳过。

尊重模型声明的用于generate_image引用的maxInputImages。 🐛 错误修复 - [侧边栏] Cli在侧边栏中点击应用程序图标会再次替换活动选项卡，而不是跳转到另一个选项卡。 - [侧边栏] 现在可以通过上下文菜单删除所有资源快捷方式。 - [设置] 修复了设置、授权、计费和反馈链接在内部浏览器而不是系统浏览器中打开的问题。 - [设置] 英文搜索词现在可以找到 V2 通过避免在每个刻度上重新解析完整的 Markdown，在长代理流期间保持 UI 响应。 - [Markdown] 修复了保存带有相邻标点符号的笔记后强调格式丢失的问题。 - [Windows] 修复了永远不会保存的代理会话跟踪历史记录。 - [聊天]修复了涉及工具或 MCP 调用的 AI 回复没有编辑选项的问题；他们的文本现在是可编辑的。 - [隐私] 修复了禁用数据收集后仍发送分析事件的问题。
