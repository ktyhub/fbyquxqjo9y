cherry-studio v2.0.2

修订 发布时间2026年8月7日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • v1→v2 迁移 — 这是重试卡住升级的版本：PR #18093 允许直接升级到 v2.0.x（无需中间跳板），PR #18002 允许迁移失败后重跑 v1 迁移，PR #18101 在智能体迁移时跳过符号链接，不再因链接数据卡住。仍停留在 v1 或卡在半途迁移的用户应升级；未提及其他破坏性变更或手动迁移步骤。
  • 提供商与模型处理 — 内置网页搜索现支持 DeepSeek、OpenRouter 和 Dashscope，并显示可区分的解析后模型名，便于看清请求实际用了哪个具体模型（PR #17983）。PR #18014 在 CLI 配置中通过统一网关添加详细模型，PR #18033 让新 API 从单一主机提供所有端点并按路由区分版本（若你针对这些端点写脚本，这是值得注意的行为变化）。
  • 智能体与工具循环可靠性 — 默认工具调用轮次上限提高（PR #18072），长时智能体运行不再那么容易被截断；Claude Code 现在关闭时回收其 SDK CLI 子进程（PR #17969）；目录树补齐了快照到流的交付缺口（PR #18009）；本地模型在镜像失败时仍可存活并保持嵌入推理离线（PR #18016）；ProxyService 现接管 worker 路由策略（PR #18095）。依赖智能体循环、Claude Code 或离线/本地模型的用户应升级。
  • 数据导入与清理 — 可直接导入 Claude（Anthropic）对话（PR #16164），新增选择性缓存/旧数据清理（PR #17377），无需清空一切即可回收空间。空分支节点现会持久化（PR #17667），MCP 设置保留表单编辑并改进工具详情（PR #17647），智能体渠道的微信扫码登录恢复可用（PR #18071），选择助手遵循繁体中文（PR #18098）。
  • 升级建议 — 内容实在的补丁，不是空操作或仅改元数据的重新打标签。对 v1 升级者以及遇到工具循环、本地模型或迁移问题的用户强烈推荐；聊天标签页重新显示的工作也做了性能精简（PR #18038）。若已在 v2.0.1 且上述均与你无关，可放心等待。
