cherry-studio v2.0.12

修订 发布时间2026年9月4日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • 设置与翻译 — 设置页新增侧边栏搜索，覆盖所有静态分区（含 MCP 标签页），支持中文拼音、键盘导航与高亮跳转目标。翻译模型也新增独立的 temperature、top-p 与推理强度控制。
  • 智能体 Markdown 工作流 — 聊天外的 Markdown 预览现使用更丰富的聊天渲染器。在智能体会话与产物预览中，工作区文件在产物面板打开、目录在系统文件管理器打开，相对链接从智能体工作区根目录解析。
  • 提供商与聊天可靠性 — Cherry Cloud 现遵循服务端声明的模型能力，支持配置的 OpenAI Chat Completions 路由，并兼容较旧的模型列表响应。不完整流保留部分响应并显示可重试错误；讯飞 MaaS 自定义模型也新增推理控制。
  • 安全与集成修复 — 无论「允许抓取本地网络地址」设置如何，Jina Reader 回退都不再接收 localhost、局域网或本地无法解析的 URL。还修复了使用 socks5 代理时 OpenClaw 网关启动失败的问题。
  • 升级指引 — 未记录破坏性变更或必需的迁移步骤。Cherry Cloud、智能体、网络搜索与 OpenClaw 用户值得升级；其他用户可推迟，不过聊天自动滚动、持久图片缩略图、数字输入处理与绘画历史性能也有修复。

模型现在支持服务器声明的功能，支持配置的 OpenAI 聊天完成路由，并与旧模型列表响应保持兼容。消息令牌详细信息现在还显示第一个令牌的时间，而无需扩展运行时细分。 - [聊天] 保留部分聊天响应，并在提供程序流在没有结束原因的情况下结束时显示清晰的可重试错误。 - [聊天] 修复聊天消息列表中的中click（自动滚动）滚动，使其不再振动或跳跃。 - [聊天]
