cherry-studio v1.9.12

修订 发布时间2026年7月5日 来源CherryHQ/cherry-studio 英文原文

变更架构图

亮点

  • 模型与 provider 兼容性 — 新增 Kimi K2.7 Code 支持、Claude Fable 系列与 Opus 5 能力检测、面向 V1 目标分支的 Anthropic 原生 /v1/models 拉取器、为 OpenAI 兼容 provider 转发 DeepSeek V4+ reasoning_effort，并修正 MiniMax-M3 思考控制。如果你使用这些模型或依赖准确的能力检测，建议升级。
  • 自定义端点行为 — NewAPI 的 Anthropic 端点现在使用 anthropicApiHost，aihubmix 则根据配置的 base URL 推导 Gemini base URL，并把 provider 链接重定向到 inferera。使用自定义网关或 provider 链接的用户应核验自己的配置；文档未说明迁移步骤。
  • 流式与 agent 可靠性 — 异常的流结束原因现在会作为错误块浮现，而不是可能被当成成功；claude-code 安装在原生二进制缺失时可以恢复；claude code agent 使用配置中的第一个 key。对 agent、多 key 配置，以及排查响应不完整问题的人，这点值得升级。
  • UI、文件与搜索修复 — 审批按钮不再切换折叠的 AccordionTrigger 分组；被 CSP 拦截的 SVG data URL 图片现在可以下载；saveBase64Image 和 savePastedImage 会恢复扩展名开头的点；ExaMCP 结果保留完整 URL 并解析 Highlights；CherryIN 的手动添加模型按钮被隐藏。这些是针对痛点的体验修复，而非让不受影响用户着急升级的理由。
  • Windows 维护与升级建议 — 磁盘信息现在改用 fs.statfs，消除了 PowerShell 进程泄漏。此补丁版本未列出破坏性变更或必须执行的迁移；上述任何一条影响到你就升级，否则可以放心跳过，等需要其中某项修复时再升。
