cherry-studio v1.6.3

修订 发布时间2025年10月8日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • 原生工具调用与提示词工具分离 — provider 定义的工具现在走一条独立于提示词内嵌工具的路径（#10428），更清楚地区分哪些能力通过 API 发送、哪些被注入上下文。有自定义工具插件的团队应在升级后核验注册情况和工具选择。
  • provider 与模型支持扩展 — 新增 LongCat（#10365）、自托管 Intel OpenVINO Model Server（#9853）和 gpt-5-codex（#10448），并修复 Gemini 匹配与视觉能力（#10463、#10530）。一次迁移会修复缺失的 provider 记录（#10438），但自定义端点仍应在升级后复查。
  • Copilot CLI 加入编码工具 — Copilot CLI 现在可作为编码工具集成（#10403），让已经使用它的团队在 Cherry Studio 里多一条工作流。它依赖本机可用的 Copilot CLI 安装与鉴权，与 Cherry Studio 的 provider 凭据相互独立。
  • 推理与延迟埋点 — 推理耗时处理经过重构（#10393），首 token 延迟上报得以恢复（#10538）。这有助于吞吐对比和慢响应诊断；由于早期的延迟数据可能不完整，仪表盘可能需要新的基线。
  • 笔记更强大，预览更安全 — 笔记新增导出（#10488）、LLM 辅助重命名（#10487）、拼写检查控制（#10507）和表格自动换行（#10503）。文本预览明确设为只读，同时通过可复用的编辑器选项保持可复制（#10499、#10516），减少误编辑。
  • 破坏性变更 — 上游未声明。
