cherry-studio v2.0.11

修订 发布时间2026年9月3日 来源CherryHQ/cherry-studio 英文原文

变更架构图

亮点

  • Cherry Cloud 与感知权益的 Agent — 头号新特性：登录 Cherry Cloud 后会带来感知权益的 Agent 模型、本地 Gateway 自动启动、感知配额的模型选择，以及持久化的 Product Session 处理。如果你使用 Agent，或一直被配额/权益问题困扰，这就是升级的主要理由；它是一项新的可选能力，并不改变已有的本地工作流。

  • WebDAV TLS 校验——需要行动 — 这是真正带迁移影响的行为变化：WebDAV 备份现在默认校验服务端 TLS 证书。如果你的 WebDAV 端点使用自签名证书，备份/恢复将开始失败，直到你开启”允许自签名证书”。依赖 WebDAV 的用户请在升级前验证这一设置。

  • 值得了解的默认值变化 — 多处默认值调整：网页搜索现在优先使用模型原生搜索，并自动回退到配置的服务；单向翻译只需目标语言（不再做源语言检测）；长文本粘贴重新默认以内联纯文本呈现，“将长文本粘贴为文件”开关回到输入设置中；新安装会首先打开 Agent 并把它排在 Chat 之前，已有用户保留已保存的侧边栏顺序。

  • 上下文控制、新模型与性能 — 现在可以按助手或全局在设置中设定上下文压缩触发阈值；新增 Hy4 Preview、Ling 3.0 Flash 和 Qwen3.8 Flash；Anthropic 兼容 provider 可保留 prompt 缓存 1 小时；土耳其语本地化初步落地。性能方面，导出/分析含大量网页/知识库搜索的长话题不再出现二次方级劣化，文件预览启动更快。本次还包含大量 v1→v2 迁移、provider（Kimi K2.5 采样、OpenRouter 推理选项）、引用和聊天状态修复。

  • 升级建议 — 这不是空操作或仅改元数据的版本，而是一次实质性的特性/修复发布。使用 Agents/Cherry Cloud、正在从 v1 迁移到 v2，或处理大历史与重度导出/搜索负载的人应升级。不碰这些领域且没遇到具体 bug 的人可以合理跳过——没有破坏性 API 变化，与迁移相关的意外只有 WebDAV TLS 默认值和上述 UI 默认值。
