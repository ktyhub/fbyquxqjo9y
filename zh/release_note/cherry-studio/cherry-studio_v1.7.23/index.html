cherry-studio v1.7.23

修订 发布时间2026年3月4日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • 构建工具链（源码构建） — claude-agent-sdk 补丁不再是静态 pnpm patch，现通过 postinstall 脚本应用（#13139）。若从源码构建或携带下游补丁，请重新运行 install 并移除旧补丁文件——这是本版本最接近迁移步骤的一项。
  • 智能体/工具行为 — 审批卡片现对内置与提供商工具显示（#13154），并新增仅开发版可用的消息数据检查按钮（#13142）。使用工具审批流程的用户会看到新提示；检查按钮仅对开发构建开放，不影响普通用户。
  • 稳定性修复 — 防止关闭透明动作窗口时 Windows 崩溃（#13177），在出错时把翻译块清理持久化到数据库（#13134），并在遵循地区过滤的同时同步迷你应用设置状态（#13166）。Windows 用户及遇到翻译/迷你应用问题的用户有明确升级理由。
  • UI / UX 打磨 — Esc 现可关闭模态框（#13159），外部编辑器在新窗口而非复用窗口打开（#13160），另有插件浏览器修复（#13153）、通过 optionRender 渲染目录 Select 选项（#13152），以及用于溢出文本的新 MarqueeText 回弹滚动组件（#13168）。这些改动明显但风险低。
  • 依赖与结论 — @uiw/codemirror 系列包升到 4.25.7（#13149）。无终端用户破坏性变更；这是真正的补丁版，不是重新打标签/仅改元数据的空操作。Windows 用户及依赖 Claude 智能体/工具流程的用户应升级；其他用户可安全跳过或择机升级。

发生了什么变化

  • 修复：渲染目录在 https://github.com/CherryHQ/cherry-studio/pull/13152 中使用 @Pleasurecruise 的 optionRender 选择选项
  • 修复：在新窗口中打开外部编辑器，而不是在 https://github.com/CherryHQ/cherry-studio/pull/13160 中重用 @kovsu 现有的编辑器
  • 修复：https://github.com/CherryHQ/cherry-studio/pull/13159 中@kovsu 支持 esc 关闭模态框
  • 修复：在 https://github.com/CherryHQ/cherry-studio/pull/13154 中显示 @al-prk 的内置工具和提供程序工具的批准卡
  • 杂务（deps）：通过https://github.com/CherryHQ/cherry-studio/pull/13149中的@EurFelux将@uiw/codemirror包升级到4.25.7
  • 修复：通过 @Pleasurecruise 在 https://github.com/CherryHQ/cherry-studio/pull/13153 中的三个小修复来改进插件浏览器用户体验
  • 修复（ci）：在 PR 正文/标题编辑上跳过 CI，仅在 https://github.com/CherryHQ/cherry-studio/pull/13150 中 @EurFelux 的基础分支更改上重新运行
  • 修复（渲染器）：同步小应用程序设置状态并遵守 https://github.com/CherryHQ/cherry-studio/pull/13166 中 @nanimore 的区域过滤器

  • 杂务：通过 @EurFelux 在 https://github.com/CherryHQ/cherry-studio/pull/13175 中改进 Claude 翻译工作流程逻辑和清晰度
  • 修复：https://github.com/CherryHQ/cherry-studio/pull/13134 中 @kovsu 出错时将翻译块清理持久保存到数据库
