cherry-studio v2.0.1

变更流程图

亮点

  • 安全与迁移安全 — 更新依赖以处理高危和严重漏洞公告（#17875），同时修复 V2 迁移崩溃、导出/向量迁移 OOM、不可用的旧版 API key、重叠工作区和云元数据反复变动的问题。从旧版本升级的人——尤其是知识库很大时——应优先选择此版本；文档未说明需要手动迁移步骤。
  • Agent 与 provider 兼容性 — 规范化无 prefill 的 Agent 请求和内部续接，在 Responses API 中支持 Claude 工具，并按实际服务协议路由 OpenCode Go 模型。DeepSeek V4 现在可通过 Anthropic 端点使用，DeepSeek 新增内置网页搜索，不兼容的工具 schema 元数据会被剥离。Agent、网关和多 provider 用户应升级。
  • 新配置与工具 — 为 NEWAPI 新增 embedding 端点类型、内置 agent 文档转换、通过 anydoc 以二进制方式摄入 Office 文档知识，以及本地诊断包导出。使用这些工作流的人会觉得实用；均无需声明迁移。
  • 聊天正确性与易用性 — 修复折叠预览中的引用上下文泄漏、删除消息时保留分支、单条回复与迁移后回复恢复模型/助手身份，以及待审批工具期间保护上下文。还新增助手分组拖拽排序，以及多项导航、滚动、模型选择和渲染修复。
  • 升级建议 — 这是实质性补丁，不是重新打标签或仅改元数据的版本。未明确列出破坏性变更。大多数用户应为了安全和数据安全修复而升级；不受所修复工作流影响的人可以合理等待，但跳过意味着继续承受已知的兼容性和迁移风险。
