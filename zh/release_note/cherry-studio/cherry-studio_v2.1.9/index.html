cherry-studio v2.1.9

变更流程图

亮点

  • 知识库是最大亮点 — 重建不再重置分块规则，导入不再卡在「准备中」，中断的转换在重启后继续，批量导入现可超过 20 个文件（#22089）并支持文件夹拖拽（#22656）；大型知识库的删除/重建索引快了很多。任何被不稳的摄取折磨过的用户，仅此就值得升级。
  • 提供商变更附带迁移注意点 — DashScope 更名为 Qwen AI Platform，端点与图标更新，新增 QwenCloud 提供商支持聊天/图片/推理及原生网络搜索；因端点变更，请核对已保存的提供商配置。相关：#22719 修复 DashScope 模型报「This model does not support enable_search」的问题，只对支持该参数的模型发送 enable_search；Anthropic 提示词缓存登陆 Vercel AI Gateway，并新增 Kimi K3.1 Pro 与 DeepSeek V4 Flash 关闭开关。
  • 图表与文件/智能体工作区得到实质改进 — Mermaid 现用更快、感知主题的引擎渲染，并可从 .mmd/.mermaid 文件打开预览；输入图表代码块时的卡死已修复，新代码块以编辑模式打开。Agent Files 新增带面包屑的标签页打开、可调整大小的树，以及自动保存/缩进/自动换行设置；新的默认「Cherry」代码主题与大代码预览虚拟化完善了编辑器工作。
  • 升级前需了解的行为变化 — api-gateway（#22342）不再用 HTTP 2xx 回应失败的生成，因此任何依赖它并把 2xx 视为成功的脚本都必须适配。聊天文件链接的揭示从悬停移到右键菜单（#22646），开启 Full Access 现在需要作用域确认（#20807），新标签页在活动标签旁打开而加号按钮在末尾追加——都小但日常可见。
  • 可靠性修复与结论 — 长时间静默推理阶段现用 120 分钟空闲上限而非 30，推理文本可编辑，超长会话中的分支切换/消息删除更快，Kokoro 中文 TTS 现能在 Windows 上用所需普通话 eSpeak 数据初始化，网络搜索新增 Desearch/SearchApi 并带 Bocha/Querit 域名黑名单。依赖知识库、Mermaid、Qwen/DashScope，或遇到长推理/导入问题的用户应升级；依赖网关失败时返回 HTTP 2xx 的调用方应先验证。这是内容充实的功能/修复版本，不是空操作或仅改元数据的重新打标签，尽管有「sync v2.1.8 metadata」和版本更新等日常提交。

Cherry Studio 2.1.9 - 图表、文件窗格和提供商更新
✨ 新功能
  • [图表] 美人鱼图表现在在后台使用更快的引擎进行渲染，匹配应用程序的浅色/深色主题，并从 .mmd/.mermaid 文件中打开预览。
  • [代理文件] 使用面包屑在选项卡中打开文件，调整树大小，并在窗格设置中配置自动保存、缩进和自动换行。右键 click 将文件或文件夹附加为上下文。
  • [代理] 通过一次操作存档代理的所有对话，并显示计数确认。从“分支管理”面板中删除对话分支。
  • [网页搜索] 添加 Desearch 和 SearchApi 作为网页搜索提供商。
  • [提供商]添加QwenCloud，包括聊天、图像、推理控件和本机网络搜索。使用更新的端点和图标将 DashScope 重新命名为 Qwen AI Platform。添加对 Vercel AI Gateway 的 Anthropic 提示缓存支持。
  • [代码主题] 新的默认“Cherry”代码主题在浅色和深色模式下融入应用程序背景。
  • 【思考】在助手消息编辑器中直接编辑消息的推理内容。
  • [权限] 启用完全访问现在会在生效前显示范围确认。
  • [选项卡] 活动对话选项卡具有更清晰的选定轮廓和稍微粗体的标题。
  • [注释] 直接从导出成功 toast 中打开新保存的注释。 🐛 错误修复
  • [工具提示] 修复了工具提示在对话框边缘被切断的问题，例如选择助手自定义操作对话框中的帮助工具提示。
  • [聊天]长时间静默推理阶段不再在30分钟后中止；空闲时间现在为 120 分钟。修复了更新后助手模型不再存在时的误导性错误。
  • [选项卡] 再次在选项卡上显示对话名称和助手图标。新选项卡在活动选项卡旁边打开；加号按钮附加在末尾。
  • [导航]统一的侧边栏和选项卡选择样式，明暗主题对比更清晰。
  • [注释] 修复了输入图表代码块时的冻结问题。新图表块在编辑模式下打开。
  • [知识] 修复了重建重置分块规则、导入等待时超时、重启后恢复中断的转换以及卡在“准备”状态的问题。
  • [浏览器] 在本地 HTML 文件中跟踪片段链接时保留未保存的输入和页面状态。
  • [文件链接]删除了聊天文件链接的悬停显示图标；使用上下文菜单显示文件。
  • [Web 搜索] 修复了 DashScope 模型失败并显示“此模型不支持 enable_search”的问题。黑名单规则现在排除 Bocha 和 Querit 上的域。
  • [TTS] Kokoro 中文文本转语音现在可以在 Windows 上使用所需的普通话 eSpeak 数据正确初始化。
  • [MCP] 修复了打开已删除页面的内置 MCP 服务器文档链接。
  • [AiHubMix] 修复当内置工具包含输入示例时 Claude 聊天因 HTTP 400 失败的问题。 ⚡ 性能
  • [知识] 在大型知识库中删除或重新索引项目要快得多。
  • [对话] 修复了很长的对话中缓慢的分支切换和消息删除。加载较早的消息速度更快。 </详情>
