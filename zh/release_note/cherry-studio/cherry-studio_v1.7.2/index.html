cherry-studio v1.7.2

修订 发布时间2025年12月8日 来源CherryHQ/cherry-studio 英文原文

变更架构图

亮点

  • Provider/API 兼容性 — 修复 formatApiHost 中 # 的处理、为空或过期的 anthropic-beta 头、Vercel AI Gateway 自定义参数的位置，以及 Ollama/OVMS URL 构造。本地 API 连接现在使用 127.0.0.1 而非 localhost，兼容性更好。
  • 模型与生成行为 — 更新 DeepSeek v3.2 的处理，为 gemini-3-pro-image 加入显式的 thinking-token 支持，引入用户可配置的 OpenAI 流式选项，并改进 temperature/top_p 处理。使用这些模型或控制项的用户有明确的升级理由。
  • 数据与配置完整性 — 修复过期的主题名、残留的 message_blocks、OpenAI 设置类型错误、provider/模型规范化、API key 轮换，以及能力编辑后的助手默认值。AI gateway 的 provider 类型规范化包含一次迁移，但未说明需要手动迁移。
  • 生产力与无障碍 — 新增文档文件翻译、斯洛伐克语拼写检查、动态输入高度、生成期间抑制 Enter 发送、避免多文件 UI 卡死的批处理、可用的快速助手快捷键、Windows 便携版 Git Bash 检测，以及改进的 NVDA 支持。这些改动主要惠及碰到对应工作流或 bug 的用户。
  • 升级判断 — 这是实质性的 bug 修复版本，不是重新打标签；CI 依赖升级只是附带。未列出明确的破坏性变更或必需的用户迁移步骤。如果上述任何 provider、模型或 UX 问题影响到你，就升级；否则稳定的安装可以合理跳过此补丁。
