cherry-studio v1.7.7

修订 发布时间2025年12月25日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • Provider 与模型支持 — 新增 OpenRouter、GLM-4.7 和 MiniMax-M2.1，并修复 OpenRouter 上 GPT-5.1/5.2 推理努力程度 none 以及交错思考的问题。OpenAI provider 选项还新增了持久化的服务端配置。使用这些 provider 或模型的人应升级。
  • 本地模型与 MCP — OVMS 升级到 2025.4，新增 Qwen3-4B-int4-ov 预设，并会在应用退出时一并终止。MCP 现在先检查系统的 npx/uvx，再检查内置二进制，因此本地安装的工具版本可能影响运行时行为。
  • 可靠性与数据安全 — 修复记忆检索并启用数据库备份。Azure OpenAI 端点规范化和 AIHubMix Anthropic API 路径得到修正，urlContext 校验也变严。依赖记忆功能或这些 provider 集成的人应升级。
  • 体验与默认行为 — 历史搜索现在显示关键词附近的片段并对齐匹配项；笔记/网页搜索设置和长字体名处理得到改进；二维码传输从 landrop 切换到 lantransfer。默认助手设置现在禁用 temperature，除非重新开启，否则可能改变输出。
  • 升级结论 — 未列出明确的破坏性变更或手动迁移步骤；内部迁移版本推进到 188。这是实质性维护版本，OpenRouter、本地模型或 MCP 用户以及遇到上述修复问题的人值得升级；工作流未受影响的人可以跳过。
