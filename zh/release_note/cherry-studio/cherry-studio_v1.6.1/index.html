cherry-studio v1.6.1

变更流程图

亮点

  • AI SDK 运行时与原生提供商工具 — AI SDK 现封装在基于插件的请求与 MCP 层之后（#7404），带来提供商选项、内置工具、Google URL context 与修订后的引用处理（#10068）。自定义集成应迁离旧的中间件钩子；配置外部搜索提供商时内置网页搜索也会被抑制，避免重复搜索与计费（#9995）。
  • 本地 API 服务器 — 可选的 Express 服务器暴露 OpenAI 兼容的 /v1/chat/completions 与 /v1/models 端点、MCP 路由和 OpenAPI 文档。默认监听 localhost:23333，带 API Key/Bearer 认证（#9855），让脚本和其他客户端复用已配置的提供商；应保持关闭或严格鉴权，因为它直面本地模型凭据。
  • Anthropic OAuth 与推理预算 — Anthropic 设置现支持 PKCE OAuth、授权码输入以及登录/登出，作为 API Key 之外的替代（#8905）。思考请求在调用 AI SDK 前会从 maxTokens 中扣除推理预算，防止两者叠加超出模型上限（#9991）。
  • 统一知识库与原生文档上传 — 大文件处理改用 OpenAI Files API，Qwen 的 qwen-long 与 qwen-doc 模型支持原生上传（#9997）。FAISS/LangChain 后端被移除，改用 EmbedJS/libSQL（#10178）；持久化状态迁移丢弃旧的 framework 选择器（#10148, #10178），因此自定义状态读取代码需要更新，受影响的 FAISS/LangChain 索引应重建。
  • 更可靠的 MCP 工具执行 — 日志、错误传播与请求头处理得到加固（#9878, #10100），进度事件现包含 callId，工具调用状态管理也经过重构（#9946, #10028）。这改善了长时间运行或并发工具的关联追踪；解析进度负载的集成应以 callId 作为键。
  • Zod 4 与贡献者工具链迁移 — 校验 schema 迁至 Zod 4（#10002），样式转向 HeroUI/Tailwind（#9973），格式化、lint 与类型检查改用 Biome、Oxlint 和 tsgo（#10170, #10168, #10188）。Fork 与插件作者应预期 schema API 和 UI 组件的变化，并相应更新本地脚本。
