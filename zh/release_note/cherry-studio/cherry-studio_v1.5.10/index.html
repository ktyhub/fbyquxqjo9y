cherry-studio v1.5.10

修订 发布时间2025年9月11日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • 工具链与构建变更 — Vite 被下调并锁定到 7.1.5（#9794），TypeScript 配置/脚本经过重做（#9792），electron.vite.config.ts 的外部依赖被精简（#9835），同时还改进了 Linux 系统 OCR 构建（#9775）。这些改动一起落地，因此维护 fork 或源码构建的人应重新校准基线，并在外部依赖变化后留意依赖解析差异——这组改动最可能带来意料之外的构建破坏。
  • 升级时的设置迁移 — 迁移逻辑推进到版本 145，并强制采用 showMessageOutline 默认值（#9805），同时 showWorkspace 从全局设置迁移到笔记模块（#9814）。升级后首次启动时，这些值会被重置或迁移；任何按旧设置结构写脚本的东西都需要更新。
  • 聊天失败可恢复 — 加载状态不再阻塞输入框，并新增”重试失败消息”按钮（#9513）。这是聊天流程的真实行为变化：发送失败现在可以原地重试，而不打断对话。
  • 更丰富的链接预览 — URL 的 OG 元数据现在会被解析并合并进预览内容（#9752），iframe 截图也包含动画和字体（#9800）。消息/链接渲染的消费者会得到更完整的预览，但应注意额外元数据和字体加载完成时的布局跳动。
  • MCP 集成修复 — 通过 JSON 添加的服务器现在能正确转换其参数（#9850），streamable-HTTP 检测改为 includes http 判断（#9865）。后者值得验证：如果你使用 URL 中并不字面包含 “http” 的自定义端点，检测行为已经变了。
  • 新能力 — KnowledgeFiles 组件新增文件选择与上传（#9815），Gemini 2.5 Flash Image 现在会自动启用图片生成按钮（#9787），并附带标签拖拽排序的 NavigationService 初始化时机修复（#9700）。

本版本无破坏性 API 变更。
