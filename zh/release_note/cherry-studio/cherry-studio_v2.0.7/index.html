cherry-studio v2.0.7

修订 发布时间2026年8月17日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • 智能体运行时与一项行为破坏性变更 — 新增 deepseek harness (dsh) 作为第三种智能体会话运行时并集成到 Code Mate，修复自定义提供商端点、依赖打包、子智能体路由、用量请求头与陈旧的 npm 路径。pi 智能体新增自动权限模式与更扁平的运行时选择器。**破坏性：**每智能体 max_turns 上限被取消（PR #18579）；依赖它的配置不再强制该限制，且未记录替代方案，升级前请检查长时运行的智能体。
  • 聊天与模型路由正确性 — 修复跨尺寸提供商误匹配，限制 MiniMax-M3 输出 token，并停止在本地阻止发给「非视觉」模型的图片。还保留软换行、内联显示生成的图片，并从叶子消息创建真实分支。若模型选择、多模态聊天或会话分支此前不可靠，应升级。
  • 知识库与数据保全 — 保存会话现保留代码围栏；批量重建索引跳过进行中的条目；恢复 0.01 的 RAG 相似度阈值；本地嵌入就绪检查磁盘缓存；无法读取的知识库结果不再破坏会话。该版本还新增 .xlsx 产物预览、加速多消息 Notion 导出，并避免把英文名写进未命名的 v1 迁移主题。
  • 输入框与键盘控制 — 发送、换行与转向快捷键可配置，F13–F24 与 CapsLock 现也可作为快捷键。围绕延迟输入、草稿恢复、粘贴重放、历史调出与焦点的修复减少漏按或重复按键——键盘重度用户值得升级。
  • 安全与桌面稳定性 — 合并 15 处脱敏实现，并从 MCP serverKey、内置服务器与日志通知输出中移除环境机密，使诊断分享更安全。会话删除白屏、分离标签页恢复、始终置顶行为，以及打包构建中 createOpenAI 失败也已修复。运行 MCP 服务器或受影响的智能体/窗口工作流的用户应升级；否则这是有价值的可靠性补丁，稳定安装环境可酌情推迟。
