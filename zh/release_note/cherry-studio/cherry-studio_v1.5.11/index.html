cherry-studio v1.5.11

修订 发布时间2025年9月12日 来源CherryHQ/cherry-studio 英文原文

cherry-studio v1.5.11

变更流程图

亮点

  • 顶栏模式下的小程序标签式导航 — 顶部导航栏现在以标签而非嵌套条目的形式呈现小程序，这实际上改变了应用的信息架构。对开发小程序或通过深链进入小程序的人来说，入口和视觉提示都变了；请检查那些仍假设旧布局的内部文档、截图和上手流程。
  • Google 小程序登录修复 — Google 小程序的 OAuth 登录此前是坏的，现已修复。它解除了所有依赖 Google 认证小程序的流程的阻塞，但因为这是修复而非新能力，请在这个版本上端到端验证完整登录流程，不要假定已有会话或 token 能干净地沿用。
  • 笔记拖拽排序 — 笔记现在支持拖拽手动排序，取代固定或默认顺序。对大量笔记集合来说这是直接的易用性提升，但如果下游有东西依赖确定性顺序（导出、脚本或肌肉记忆式工作流），在依赖新顺序之前请先确认它是如何持久化的。
  • 没有出现的同样重要 — 这是一个以 UI 和修复为主的小补丁，没有新的 provider 集成、API 表面变化或数据模型迁移。如果你在评估是否采用 v1.5.11，把它当作低风险的增量更新而非特性版本；除非上面三条中某条正好解决你的痛点，否则没有什么令人信服的理由单纯为了新功能而升级。

无破坏性变更。
