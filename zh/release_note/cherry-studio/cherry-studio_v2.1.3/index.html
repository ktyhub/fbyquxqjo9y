cherry-studio v2.1.3

修订 发布时间2026年9月24日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • 远程设备连接 — 可通过加密局域网连接配对兼容的移动端，导入提供商并控制桌面智能体，带重连恢复与审批流程。**需要迁移：**旧设备必须重新配对以适配新的基于身份的协议。
  • 智能体、技能与文档工作流 — 新增按智能体覆盖回复语言、更丰富的技能详情/管理页面、远程更新、更安全的安装，并支持最多 20,000 个文件的技能包。自托管 MinerU 4 解析与 macOS/Windows 系统 OCR 减少了对本地模型与服务的依赖。
  • 扩展的模型目录 — 新增 Claude Opus 5.5、GPT-6 Sol 与 Luna、Grok 4.7，以及 Xiaomi MiMo V2.6 Flash/Pro/Pro-UltraSpeed，并更新推理、定价、限制与提供商可用性。对使用新支持提供商或推理模式的用户价值最大；否则基本只是增量添加。
  • 破坏性变更：macOS 快捷键 — Command+W 现关闭当前标签页而非窗口；关闭窗口改为 Command+Shift+W。请更新肌肉记忆、宏以及依赖旧行为的文档化工作流。
  • 为可靠性修复值得升级 — 修复代理与 IPv6 绕过失败、被拦截 TLS 的模型同步、仅代理的 Agent 会话、Windows 启动崩溃、Linux AppImage 的 libfuse2 依赖、Gemini 工具 schema 报错、Responses 续写失败，以及若干聊天/UI 回归。受这些问题影响的用户应升级；未受影响且不需要新功能或模型的用户可合理跳过。

Cherry Studio 2.1.3 - 新功能、性能和可靠性
✨ 新功能
  • [远程] 设备连接：将兼容的移动 client 与导入提供商配对，并通过加密 LAN 连接使用桌面代理，包括重新连接恢复、执行失败、批准和问题。所需操作：旧设备必须针对新的基于身份的协议重新配对。
  • [文档] 支持自托管 MinerU 4 文档解析，同时保留与旧版 Open MinerU 服务器的兼容性。
  • [屏幕截图] 在 macOS 和 Windows 上使用系统 OCR 选择并复制屏幕截图文本，无需下载本地模型。
  • [模型] 将 Claude Opus 5.5 添加到 API 聊天，并更新模型限制、定价、推理控制和网络工具资格。
  • [模型] 添加 GPT-6 Sol 和 Luna 目录元数据、OpenAI 网络搜索资格和 OpenAI Codex 模型条目。
  • [模型] 将 Grok 4.7 添加到模型目录（xAI、OpenRouter、Vercel AI Gateway、OpenCode、Copilot）中，并进行 xhigh 推理； Grok CLI 现已上市 Grok 4.6、Grok 4.7 和 Grok 4.7 Fast； Grok 4.6 获得了 xhigh 推理能力。
  • [型号] 将小米 MiMo V2.6 Flash、Pro 和 Pro-UltraSpeed 添加到 MiMo、OpenRouter、Vercel AI Gateway 和 OpenCode 提供商的型号目录中，并带有思维开关。
  • [技能] 为从确切支持的路径安装的技能添加受保护的自动文件保存和手动远程更新。
  • [技能] 添加专用技能详细信息页面、源标签、更安全的删除以及将单 click 启动到代理会话中。
  • [设置] 添加具有预设值和自定义值的“客服回复语言”设置（默认：遵循对话语言），以及具有有效语言预览的每个客服覆盖，以便用户可以固定客服回复的语言。
  • [快捷方式] 在 macOS 上，Command+W 现在关闭活动选项卡而不是窗口；关闭窗口移至 Command+Shift+W。 🐛 错误修复
  • [设置] 恢复从列表外部滚动提供者模型列表，并让组标题随页面滚动。
  • [设置] 英文搜索词现在找到V2对话风格设置。
  • [设置]添加模型后自动验证并启用提供程序，并防止加载大列表时模型选择对话框跳转。
  • [代理] 修复了当 IPv4 或 IPv6 环回请求通过代理路由时 DeepSeek Harness 等本地服务无法连接的问题。
  • [代理] 修复了模型列表同步在公司代理后面或使用截获的 TLS 证书时失败的问题，此前即使提供程序本身用于聊天也会失败。
  • [代理] 修复以裸 IPv6 文字（::1、fe80::1、2001:db8::1）编写的代理绕过规则从不匹配，并按值匹配 IPv6 地址，以便识别等效符号。
  • [代理] 现在可以通过 cron 工具就地编辑计划任务，并具有会话重用控制和更清晰的名称冲突指导。
  • [代理] 捆绑的 Cherry 工具指南现在描述了通知工具何时可用以及计划任务如何获取其通知收件人。
  • [代理] 通过将配置的代理继承到代理运行时进程中，修复了 dsh 类型代理会话在仅代理网络上失败的问题。
  • [代理] 通过紧凑的子任务列表和可靠的嵌套任务导航，将多代理请求保留在一个回复中，直到所有工作完成。
  • [代理] 修复了发送消息链接芯片和网站悬停预览打开单独的选项卡，而不是使用代理对话的浏览器窗格。
  • [聊天] 提高长推理内容的思维面板高度、滚动和文本可读性。
  • [聊天] 切换对话时保留未提交的 AskUserQuestion 答案，以便返回待处理的问题可以从用户上次中断的位置继续。
  • [聊天]修复了消息刷新后某些型号无法计算或显示令牌使用情况的问题。
  • [聊天]修复了鼠标滚轮向下滚动或拖动滚动条后聊天消息无法停留在底部的问题。
  • [聊天] 修复了发送 UUID 作为输入项 ID 并被拒绝的响应延续，因为该 id 必须以 rs 或 msg 开头。
  • [聊天] 修复仍指向旧数据目录的已迁移托管映像。
  • [技能]修复技能 ZIP 导入拒绝限制内技能的问题，因为其周围的存储库存档超出了旧的共享上限；技能包现在最多可容纳 20,000 个文件。
  • [技能] 修复了由于未定义下载大小限制而导致 ClawHub 技能安装失败的问题。
  • [技能] 从 Claude 插件和 Skills.sh 安装的技能现在仅下载技能的目录而不是整个存储库，并且从 GitHub 链接安装更大的技能不再超时。
  • [技能] 提高两列设置布局中名称的可读性，同时保留卡片大小，并在工具提示中显示全名和描述。
  • [技能] 修复编辑消息时和取消编辑后的斜杠命令和技能菜单。
  • [技能]修复了当没有安装实际运行时CLI卡卡在“正在安装…”的问题；现在，状态会根据实时操作而不是 trusting 剩余标记进行协调。
  • [屏幕截图] 修复了当选择内容靠近显示屏左边缘时，屏幕截图工具栏被部分推离屏幕的问题。
  • [文件] 修复了临时 Windows 文件锁定观察程序错误后停止的工作区文件树。
  • [文件] 在短暂的页面切换中保留目录状态，而不保持页面处于活动状态。
  • [AI] 修复了当工具架构包含 propertyNames 或additionalProperties 关键字时，Gemini 请求因未知字段 400 错误而失败的问题。
  • [AI] 显示清晰的 HTTP 400 请求失败消息并保留 Claude Agent SDK HTTP 状态代码以进行准确的错误分类。
  • [AI] 解释 HTTP 413 代理请求失败并建议在重试之前减少有效负载大小。
  • [Windows] 修复了应用程序控制阻止本机关闭处理程序时 Windows 启动崩溃的问题。
  • [Linux] Linux AppImages 不再需要系统 libfuse2 库。
  • [迷你应用程序] 修复了添加迷你应用程序对话框的宽度，以便安装内容保留在对话框内。
  • [历史记录] 聊天和代理历史记录现在使用存档图标和标签来准确描述其可恢复的存档操作。
  • [UI] 修复了在代理会话中 clicking 文件路径后工具提示内容有时会残留在左上角的问题。
  • [UI] 修复了切换右窗格面板后工具提示在窗口左上角徘徊的问题。
  • [UI] 在不支持悬停支持的设备（包括带有独立键盘的 Windows 平板电脑）上保持消息、对话和清晰的操作可访问。
  • [错误] 将错误原因渲染为文本而不是 HTML，以便更安全地显示。
  • [引文] 引文面板源现在在左侧 click 的侧边栏浏览器和中间 click 的单独应用程序选项卡中打开。 </详情>
