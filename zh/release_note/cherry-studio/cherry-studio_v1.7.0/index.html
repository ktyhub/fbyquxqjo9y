cherry-studio v1.7.0

小版本 发布时间2025年11月28日 来源CherryHQ/cherry-studio 英文原文

变更流程图

亮点

  • 智能体与本地 API 服务 — 智能体实现（#10096）现已内置自动数据库迁移（#10215）、独立设置与会话控制（#10668, #10773），并在存在智能体时自动启动 API 服务（#10772）。这免去了手动搭建服务的步骤；但已有安装环境的用户升级前应先备份智能体数据，升级后核对迁移过来的智能体与默认模型。
  • 提供商与模型覆盖 — 新增 Mistral（#10795）、Hugging Face（#10966）、NewAPI（#10696）、Ling（#10863）以及带 NPU OCR 的 Intel OVMS（#10570, #10737）等接入。Claude Haiku 4.5、GPT-5-Codex、Gemini 2.5 Image Flash 与 MiniMax-M2 也获得专门支持或修复（#10800, #10587, #10781, #10683, #10962），减少针对特定提供商的配置与流式传输失败。
  • 采样与 API Key 行为 — 助手设置中 Top-P 现默认禁用（#10754），此前依赖它的提示词可能需要显式重新开启。API Key 现保留空格，多个密钥用逗号或换行分隔（#10751），且按请求轮换（#10776）；请据此重整带填充或空格分隔的密钥列表。
  • 知识与 RAG 可靠性 — 修复知识库删除与网络搜索失败（#10595），支持知识工具选择（#10763），并为引用增加缺失数组的防护（#10778）。移除网络搜索 RAG 的 LRU 路径（#10631）应能改善有问题的检索流程，但可能改变缓存与复用行为；若延迟敏感，请对重复搜索做基准测试。
  • 笔记与迷你应用 — 笔记新增图片导出（#10559）、全文搜索（#10640）与右键创建（#10523）。迷你应用新增搜索（#10609）、可靠的 Cmd/Ctrl+F 处理（#10641, #10783），以及标签导航下的外部浏览器链接（#10669），对大型归档和键盘驱动的工作流更实用。
  • 运行时与集成层面 — React 升至 19.2.0（#10710），Electron 升至 38（#10884），AI SDK 依赖刷新（#10643）。OpenAI 导入迁移到 @cherrystudio/openai（#10802），MCPToolResponse 被替换为 NormalToolResponse（#10303）；耦合这些内部实现的自定义代码需要更新或重新验证。
  • 破坏性变更 — 未列出。
