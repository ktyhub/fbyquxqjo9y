cherry-studio v2.1.7

修订 发布时间2026年10月19日 来源CherryHQ/cherry-studio 英文原文

变更架构图

亮点

  • 破坏性变更：智能体运行时被替换 — refactor(agent-runtime): replace DSH with Pi and migrate history（#21400）将 DSH 运行时换成 Pi 并迁移已有历史。这是升级时唯一真正需要注意的变更：请核对依赖 DSH 特定行为的智能体或已保存历史。相关的 Claude Code 工作转向按需下载的原生运行时（#21548）与原生 AGENTS.md 加载（#21580），因此基于 Claude 的自动化行为也可能不同。
  • 移除：局域网传输 — refactor(lan-transfer): remove unused transfer feature（#21570）直接删除了局域网传输功能。若你曾用它在设备间传文件，升级后该路径将不复存在，需要另找替代方案。
  • 模型、提供商与搜索覆盖扩展 — 新增 Gemini 4 Argon（思考等级加自动长输出续写）、Muse Spark Open（多模态与推理控制）、LiteLLM 提供商（#21511）、无需 API Key 的 DuckDuckGo 关键词网络搜索，以及 GPT-Image-2 宽高比预设（16:9、9:16、16:10、4K）。还新增提供商计费倍率/每日费率计划（#21498），并修复 Gemini 模型列表分页 token 为 null 的问题。想要更新模型或更便宜路由的用户，这是主要升级理由。
  • 语音围绕本地语音全面改造 — 新增本地 TTS/ASR：Windows x64/Linux/macOS 上的 Kokoro 中英双语 TTS（103 种音色）、Apple Silicon 上的 Qwen3-TTS，以及三大桌面平台均支持的本地 FunASR 转写。模型需先在「设置 > 本地模型」下载，首次使用前请预留这一步；并注意平台差异：Apple Silicon 拿到的是 Qwen3-TTS 而非 Kokoro。另新增实时音频频谱、空听写后恢复麦克风，并修复朗读跳过代码块/行内代码的问题。
  • 云端、可靠性与升级人群 — Cherry Cloud 在国际版新增订阅/额度可见性（托管模型带限时免费与额度耗尽标签）、紧凑的锚定账户菜单，并在连接/刷新瞬时故障时保留登录；错误通知现给出可读的诊断与恢复操作，覆盖会话、提供商检查与 MCP。值得注意的修复：MCP 可重连以 5xx 响应版本探测的服务器、托盘图标缺失时 Windows/Linux 窗口恢复、便携安装的稳定 Windows 托盘 GUID、SVG 缩放清晰度、输入法安全的行内重命名、取消输入框字数上限并自适应高度，以及设置面板懒加载与 Markdown 预览延迟加载以提升性能。为新模型、本地语音和稳定性修复而升级；仅当你依赖局域网传输或 DSH 特定智能体行为，或在 Apple Silicon 上就是想要 Kokoro 时才跳过。

<摘要>Release Notes</摘要>
Cherry Studio 2.1.7 - 语音、云和模型更新
✨ 新功能
  • [语音] 添加适用于 Windows x64、Linux 和 macOS 的 Kokoro 中英文 TTS（103 种语音）以及适用于 Apple Silicon 的 Qwen3-TTS。首次使用前，请从“设置”>“本地模型”下载模型。
  • [语音] 在语音播放和听写控件中显示实时音频频谱。空听写后恢复麦克风。
  • [语音] 在 Windows、Linux 和 macOS 上添加本地 FunASR 语音转录。
  • [Cherry Cloud] 在全球版中添加订阅计划和配额使用可见性，以及托管模型的限时免费和耗尽配额说明。
  • [Cherry Cloud] 添加紧凑的锚定侧边栏帐户菜单。头像和昵称打开个人信息设置；外观和登录保留在菜单中。
  • [Cherry Cloud] 在临时连接或刷新失败期间保留登录。
  • [自动化] 通过持久的 JavaScript 协调浏览器和计算机的使用，并提供更清晰的执行反馈。
  • [知识库] 在组之间拖动知识库并重新排序组；通过升序、降序和默认排序循环项目列。
  • [图像] 为 16:9、9:16、16:10 和 4K 输出添加 GPT-Image-2 宽高比预设。
  • [模型]添加Gemini 4 Argon支持，具有思维水平和自动长输出延续。
  • [模型] 添加具有多模态功能和推理控制的 Muse Spark Open 模型识别。
  • [搜索] 添加 DuckDuckGo 作为免费关键字网络搜索提供商。无需 API 密钥。
  • [工具] 工具结果现在预览图像链接并显示 clickable 网页链接。
  • [错误] 显示可操作的错误通知，其中包括可读的诊断、可扩展的详细信息以及对话、提供商检查和 MCP 故障的恢复操作。
  • [聊天]排队的后续消息开始折叠。 Click 标题以展开或折叠。
  • [聊天] 将鼠标悬停在对话上可查看全名、活动时间和工作区详细信息。
  • [注释] 按名称搜索代码块语言。 🐛 错误修复
  • [附件] 修复无法识别的扩展名文本文件（例如 .lrmx）不被读取为文本的问题。
  • [OCR] 确定将图像发送到非视觉模型时哪个 OCR 路径发生故障，并提供每种故障类型的指导。
  • [窗口] 修复了 Windows/Linux 上主窗口关闭时托盘图标不可用时隐藏窗口的问题，无法恢复或退出。
  • [消息] 保留披露状态并在消息显示中遵循流式推理。
  • [作曲]自动跟随提示文字方向；保留前导点文件名；接受代理表面上的任何文件类型。
  • [文件] 添加文件上下文菜单操作；将文件链接和图标与内嵌文本对齐。
  • [MCP] 连接到远程 MCP 服务器，该服务器拒绝版本探测并出现 5xx 错误；重新连接前确认健康状况。
  • [模型] 接受 null Gemini 模型列表分页标记；改进 Gemini 模型发现和元数据刷新。
  • [托盘] 使用稳定的 Windows 托盘 GUID 进行便携式安装。
  • [语音] 修复了朗读时跳过代码块和内联代码中的文本的问题。
  • [代理] 允许用户通过 declining 设置关闭登录。
  • [翻译] 在输入文本旁边保留空闲听写和复制按钮，而不添加额外的工具栏行。
  • [计算机使用]修复了克劳德代理缺失的自动化工具输出，并添加了结构化可访问性树分页，以防止遗漏过大的观察结果。
  • [设置] 恢复设置滚动条和一致的布局，阐明计算机使用权限操作，并修复 clipped 内容、MCP 选项卡顺序和不必要的使用热图溢出。 </详情>
