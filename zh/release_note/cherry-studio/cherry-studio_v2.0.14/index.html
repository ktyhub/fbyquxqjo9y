cherry-studio v2.0.14

cherry-studio v2.0.14

变更流程图

亮点

  • 破坏性变更：Cherry Cloud 登录 — 云会话现在与当前计算机绑定，在同一台机器上重置凭据仍可保留免费额度历史。普通桌面用户无需迁移步骤，但自定义构建必须配置客户端签名密钥，否则 Cloud 登录会失败。

  • agent 与聊天可靠性 — OpenCode Go/Zen 请求现在在聊天、模型健康检查、主题命名和上下文压缩全过程中保留必需的 session header，修复 MissingSessionID 失败。纯文本续聊会忽略过期的图片附件，删除上下文选中的回复会保留分组回复，运行时启动的 agent 轮次会标注来源。

  • 知识库数据完整性 — 通过 Mistral OCR 导入的 PDF 表格现在能在转换后保留下来，并以 Markdown 表格建立索引。已有条目必须重新建立索引才能找回表格内容；否则本版本不会追溯性地应用这个修复。

  • 导出与交互修复 — Notion 导出会等待完成并上报写入失败，而不是误报成功；Obsidian 导出现在生成合法的 YAML front matter 和标签列表。Prompt Polish 增加取消和 60 秒超时，Call Chain 调试面板不再因长输出而截断或卡死。

  • 升级建议 — 使用 Cherry Cloud、OpenCode Go/Zen、Mistral OCR 导入、导出功能，或遇到过升级后启动失败的人值得升级。知识管理对话框现在改为懒加载，打开页面更快；模型目录新增 DeepSeek V4.1 Flash Expires-On-0910 视觉模型。不受这些领域影响的用户可以放心跳过这个实质性补丁版本；metadata-sync 那次提交并非本版本的主要内容。
