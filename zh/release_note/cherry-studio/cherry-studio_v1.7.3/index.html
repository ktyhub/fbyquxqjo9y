  • 壮举：在 https://github.com/CherryHQ/cherry-studio/pull/11797 中添加 @kangfenmao 的 CherryIN API 主机选择设置

  • 杂务：通过 @defi-failure 在 https://github.com/CherryHQ/cherry-studio/pull/11807 中添加 gitcode 发布同步工作流程
  • feat(SelectionAssistant)：通过 @0xfullex 在 https://github.com/CherryHQ/cherry-studio/pull/11770 中打开 URL 进行搜索操作
  • 壮举：增强网络搜索工具切换逻辑，以支持 @DeJeune 在 https://github.com/CherryHQ/cherry-studio/pull/11769 中提供的特定上下文
  • 🐛修复：稳定@vaayne在https://github.com/CherryHQ/cherry-studio/pull/11830中的MCP日志IPC注册
  • 壮举：支持 @beyondkmp 在 https://github.com/CherryHQ/cherry-studio/pull/11813 中自定义 git bash 路径
  • 重构（ui）：通过@kangfenmao在https://github.com/CherryHQ/cherry-studio/pull/11819中改进设置选项卡和辅助项UI
  • 修复：在 https://github.com/CherryHQ/cherry-studio/pull/11794 中 @CalWade 中止回复时停止思考计时器
  • 功能：https://github.com/CherryHQ/cherry-studio/pull/11104 中@Copilot 为小程序网页视图添加打印到 PDF 并另存为 HTML 的功能
