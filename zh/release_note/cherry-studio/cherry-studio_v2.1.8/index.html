cherry-studio v2.1.8

修订 发布时间2026年10月26日 来源CherryHQ/cherry-studio 英文原文

变更架构图

亮点

  • 文件编辑与文档安全 — 草稿现按笔记、技能与产物相互隔离，失败的编辑会保留以便重试，文本编辑/预览支持最大 8 MiB。修复缓存笔记被覆盖、笔记冲突对话框阻塞后续重命名/删除/移动的问题，若你的笔记或技能承载重要工作，这点尤其有价值；RTF 预览、旧版 .doc 提取、相对 Markdown 图片与 CJK 文件检测也有改进。
  • 语音与转写大改造 — 按住说话听写、流式语音合成、助手文本增量朗读、流式 Qwen3 听写/播放、本地 Qwen3 1.7B 转写，以及 Apple 系统语音 PCM 播放，大幅减少等待。新增失败/超时诊断便于排查，Windows ASR 现接受标准 16 kHz WAV 输入。
  • 搜索、智能体与集成 — 内置腾讯元宝搜索与 DeepSeek 搜索&抓取扩展搜索选项；智能体聊天定时任务新增交互式任务卡片。远程访问配对接受自定义主机名、IP 或端口，飞书群可要求 @提及，Pi 成为新建智能体的默认智能体。MCP 还会在保存的请求头与环境变量值中保留字面 # 字符。
  • 兼容性与可靠性修复 — Claude Code 经内部网关保留 1M 上下文预算，含 [1M] 的 Coding Partner ID 可正确解析，Claude 采样参数与 Anthropic 工具输入示例处理更安全，并接受无 offset 的 url_citation。Computer Use 输出/观察、远程访问分页、文件预览、虚拟列表与代理绕过行为也获得针对性修复。
  • 升级建议 — 这是内容充实的版本，不是重新打标签或仅改元数据。未记录破坏性变更或必需的迁移步骤。使用语音、笔记/技能/产物编辑、网络搜索、MCP 或受影响模型网关的用户应升级；纯文本稳定用户可推迟，但会错过重要的数据丢失修复与 Electron 44.9.3 证书安全更新。

<摘要>Release Notes</摘要>
Cherry Studio 2.1.8 - 编辑、语音和集成更新
✨ 新功能
  • [文件编辑]跨笔记、技能和工件隔离草稿，保留失败的编辑以供重试，并支持高达 8 MiB 的文本编辑和预览。
  • [语言] 添加意大利语 (it-IT) UI 支持，包括完整翻译和表情符号选择器。
  • [语音] 在文本输入中按住鼠标按钮即可开始听写，松开即可转录。
  • [语音] 流式语音合成，实时音频播放。
  • [网页搜索]添加腾讯元宝搜索作为内置提供商。
  • [计划任务] 通过客服人员与交互式任务卡的聊天来创建和管理计划任务。
  • [屏幕截图] 将捕获内容复制到 clipboard，同时保持覆盖层打开。
  • [选择] 选择任意位置的文本以自动复制并显示快速引用工具栏。
  • [Composer] 文件和链接标记与文本行对齐，显示每种类型的文件图标，并在编辑时加载图标。
  • [RTF] 将富文本格式文件预览为格式化文档。
  • [飞书]配置机器人是否只回复群聊中的@提及。
  • [远程访问] 设置自定义主机名、IP 或端口以进行配对邀请。
  • [助手]记住“同时存档相关主题”选项以供将来存档。 🐛 错误修复
  • [笔记]修复在缓存笔记之间切换时笔记内容被覆盖的问题。
  • [技能] 当 ZIP 或文件夹丢失 SKILL.md 时显示本地化错误消息，而不会泄漏临时路径。
  • [聊天]默认展开长用户消息；保持后续队列独立于已读回执。
  • [代理] 匹配短通配符 IP 绕过规则，例如 Windows 上的 192.168.*。
  • [Claude Code] 通过内部网关路由时保留 1M 上下文预算。
  • [选项卡栏] 关闭最后一个选项卡将打开启动板，而不是退出应用程序。
  • [文件预览]刷新文件时保留阅读状态；修复 Word 文档的行间距。
  • [侧边栏] 所选条目在浅色和深色主题中均使用中性填充图标。
  • [聊天布局] 隔离每个窗口的列表组扩展状态。
  • [绘画] 限制加载网格密度以防止性能问题。
  • [MCP] 在保存的标头和环境值中保留文字 # 字符。
  • [知识] 为 Linux x64 提供基线 sqlite-vec 构建。
  • [语音] 添加操作失败和流超时的诊断。
  • [代理会话]跨代理创建时继续目标工作区；表面压实失败。
  • [消息] 删除具有不兼容重播输入的历史工具部件。
  • [虚拟列表] 将粘性标题移至固定的堆栈底部。
  • [注释] 修复了关闭“磁盘上的注释已更改”冲突对话框导致编辑器会话卡住，导致所有后续注释重命名、删除和移动失败并出现误导性错误的问题。 🔒 安全
  • [Electron] 升级到 44.9.3 以修复证书安全问题。 </详情>
