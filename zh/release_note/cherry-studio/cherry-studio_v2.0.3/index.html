cherry-studio v2.0.3

修订 发布时间2026年8月10日 来源CherryHQ/cherry-studio 英文原文

cherry-studio v2.0.3

变更流程图

亮点

  • 智能体会话可预测性大幅提升 — 一组运行时修复让配置的系统提示词成为权威（#18100），新增作用域 AGENTS.md 指令（#18126），从重复工具使用 ID 失败中恢复（#18119），优先使用模型的 Anthropic Messages 端点（#18221），修正 Claude Code 自动压缩预算（#18137），并暴露而非吞掉 Claude Code API 失败（#18280）。MCP 也更稳：Windows stdio 服务器解析为完整路径（#16472），关闭陈旧客户端使 ping 失败不再留下孤儿子进程（#18146）。对运行智能体或 MCP 服务器的用户，这是主要升级理由。
  • 新增模型重试与回退，以及代码工具扩展 — ai-retry 集成（#16057）加入用户可配置的重试与回退行为，瞬时提供商故障可优雅降级而非中止运行。同时：Pi 编码智能体加入 Code Tools（#16928），支持 Windows Terminal（wt.exe）（#17942），修复 OpenCode/Codex 配置与认证错误（#18015, #18188），并保留 OpenCode 会话亲和性（#18184）。
  • 输入框与聊天 UX 优化 — 现显示助手上下文用量（#18006），推理强度支持顺滑滚轮控制（#17829），编辑过的用户消息可保存而不重发（#18057），未发送草稿在导航后保留（#18019）。需注意的行为变化：新用户的权限模式默认固定（#18222），影响新接入的配置。
  • 知识库、网络搜索与稳定性修复 — Firecrawl 作为 URL 抓取提供商加入（#18089），笔记可直接写入知识库（#18022），知识库通过关闭严格模式在 Anthropic 上可用（#18179）。迁移错误已修复（v1 文件夹文件与重复上传不再迁移为 UUID，#18167；容忍格式错误的智能体 MCP 数据，#18176），备份跳过 EBUSY 的 LevelDB LOCK 文件（#18117, #18173），Linux 自带 GLIBC 兼容的 better-sqlite3（#17778），并通过懒加载五个重型主进程依赖让启动更轻（#18189）。
  • 升级指引 — 这是内容实在的补丁版（v2.0.2 → v2.0.3），不是重新打标签或仅改元数据；唯一非功能性条目是 CI 运行时缩短（#18165）和两次每日 i18n 同步。未指出破坏性变更或迁移步骤。智能体/MCP 用户、Linux 用户、依赖自动备份的用户，以及想要重试/回退或新 UX 控件的用户值得升级；仅当你满意当前智能体行为且不需要新提供商或选项时可安全跳过。
