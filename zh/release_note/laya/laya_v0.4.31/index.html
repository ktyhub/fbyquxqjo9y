laya v0.4.31

修订 发布时间2026年11月10日 来源NandhaKishorM/laya 英文原文

laya v0.4.31

这个项目是干啥的：一个毫秒级的「快思考」小模型，不写长篇大论，直接给分类、打分、是或否的判断，给需要给 AI 工作流做快速路由和把关的开发者用。

变更架构图

亮点

  • Vega 校准目录不再误伤无关校准 — PR #1479 修复了加载仅含部分头的校准目录时，会重置该目录实际并未包含的校准的问题。如果你按头管理校准、且会加载部分目录，应升级：以前一次加载可能静默清掉该目录里没有的头对应的校准。
  • Vega 预测钩子的缓存结果得以保留 — PR #1488 不再丢弃被缓存的预测钩子结果。在期望钩子被记忆化的场景下，这关系到正确性和重复调用的性能；受影响的 vega 用户应升级。
  • 路由可见性与策略遵从性提升 — PR #1447 在 ts 里暴露本地路由诊断信息；PR #1489 让 langchain 遵循模型原生的 auto/review 路由策略。如果你依赖路由决策可观测，或希望 langchain 尊重模型自身的路由策略，就升级；这些是增量式的行为变化，不是对别处错误结果的修复。
  • 无破坏性变更，无需迁移 — 本版包含两项增量特性和两个 bug 修复，没有删 API、改 flag 名或改配置的说明。是常规补丁版本，不是重新打标或仅改元数据。
  • 谁该升级 — 使用校准目录或预测钩子缓存的 vega 用户，以及用到 ts 路由诊断或 langchain auto/review 路由的人，都该升到 v0.4.31。走不到这些代码路径的用户可以放心跳过。

发生了什么变化

  • feat(ts)：通过 @xinpingzh 在 https://github.com/NandhaKishorM/laya/pull/1447 中公开本地路由诊断 *修复（vega）：加载仅头校准目录会重置https://github.com/NandhaKishorM/laya/pull/1479中@aashish254不保留的校准
  • 修复（vega）：在 https://github.com/NandhaKishorM/laya/pull/1488 中保留 @GoldArowana 缓存的预测钩子结果
  • feat(langchain)：尊重https://github.com/NandhaKishorM/laya/pull/1489中@xinpingzh的本机自动/审查路由策略 完整 Changelog：https://github.com/NandhaKishorM/laya/compare/v0.4.30…v0.4.31
