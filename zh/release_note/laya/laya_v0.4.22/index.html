laya v0.4.22

修订 发布时间2026年11月3日 来源NandhaKishorM/laya 英文原文

laya v0.4.22

变更流程图

亮点

  • TypeScript 正确性 — Router 批次现在会保留 token 预算；latinProfile 和 stateText 改为按 Unicode 码点而非 UTF-16 单元来计数或截断，与 Python 行为对齐。处理多语言文本或依赖批次上限的 TypeScript 用户应升级。
  • 置信度溢出处理 — 当有限权重的总和溢出时现在会做归一化，解决了可能扰乱置信度计算的边界情况。工作负载使用超大置信度权重的应升级。
  • 性能 — 语言状态文本处理增加了惰性遍历和字符串快速路径，减少不必要的计算。对处理大块或嵌套状态文本的 TypeScript 用户有意义，不过没有给出基准数据。
  • 依赖与升级指引 — CI action 有更新，包括 actions/checkout 升到 7.0.1、actions/setup-python 升到 7.1.0、actions/upload-artifact 升到 7.0.2；agno 的开发依赖范围放宽到 >=1.1.14,<4。没有列出破坏性变更或迁移步骤。纯 Python 用户可以跳过，除非要维护 CI 或开发依赖；这次主要面向 TypeScript 用户。

发生了什么变化

  • 构建（deps）：通过 https://github.com/NandhaKishorM/laya/pull/1357 中的 @dependabot[bot] 从 4.4.0 碰撞操作/结账到 7.0.1 *构建（deps）：通过@dependabot [bot]在https://github.com/NandhaKishorM/laya/pull/1360中将python从5.6.0碰撞到7.1.0
  • build(deps-dev): 将 agno 要求从 <2,>=1.1.14 更新为 >=1.1.14,<4 by @dependabot[bot] in https://github.com/NandhaKishorM/laya/pull/1350
  • 构建（deps-dev）：通过 @dependabot[bot] 在 https://github.com/NandhaKishorM/laya/pull/1351 中将 /laya-ts 中的 vitest 从 5.0.4 提升到 5.0.5
  • 构建（deps）：通过 https://github.com/NandhaKishorM/laya/pull/1354 中的 @dependabot[bot] 将操作/上传工件从 4.6.2 碰撞到 7.0.2
  • 构建（deps）：通过 https://github.com/NandhaKishorM/laya/pull/1355 中的 @dependabot[bot] 将 pypa/gh-action-pypi-publish 从 1.14.2 提升到 1.14.3
  • 修复（ts）：在https://github.com/NandhaKishorM/laya/pull/1441中@xinpingzh在路由器批次中保留代币预算
  • 修复（置信度）：当 https://github.com/NandhaKishorM/laya/pull/1442 中的 @GoldArowana 总溢出时，对有限权重进行归一化
  • 修复（ts）：计算 latinProfile 中的代码点，如 https://github.com/NandhaKishorM/laya/pull/1445 中 @rahul05ranjan 的 Python
  • 修复（ts）：在 https://github.com/NandhaKishorM/laya/pull/1446 中 @rahul05ranjan 的 Python 等代码点削减 stateText 预算
  • perf(lang): https://github.com/NandhaKishorM/laya/pull/1448 中 @HamidRezaLS 的惰性状态文本遍历和字符串快速路径 完整 Changelog：https://github.com/NandhaKishorM/laya/compare/v0.4.21…v0.4.22
