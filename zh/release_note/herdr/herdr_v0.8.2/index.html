herdr v0.8.2

这个项目是干啥的：一个专为 AI 编程助手设计的终端多路复用器，能把 Claude Code、Codex 等多个助手同屏管理并标出谁在干活、谁卡住了，给同时跑多个助手的开发者用。

变更架构图

亮点

  • Windows 支持进入稳定版 — Windows 现已正式可用，默认使用稳定更新渠道，并支持 herdr --remote 连接到 Linux/macOS 服务端。Cursor Agent CLI、MastraCode、Hermes Agent 和 Grok CLI 集成也能原生运行。Windows 用户应升级；现有预览安装会停留在预览渠道，直到显式切换。
  • 繁忙与自动化会话的强力升级理由 — 多项修复降低了高输出、多窗格和隐藏标签页场景下的 CPU 占用与输入延迟。agent prompt 现在会拒绝已阻塞的代理并返回 agent_blocked，而不是发送输入；agent start 会等待 shell 和首次运行提示符就绪。这些改动对可靠的自动化和响应迅速的长会话很重要。
  • 更广、更准的代理状态检测 — 新增 Qwen Code 检测及可选原生恢复，并修复 Claude Code、Copilot、Cursor、Kiro CLI 等集成中的误判空闲/阻塞状态。OpenCode 恢复现在遵循每个窗格自身 TUI 中选中的根对话。依赖代理监控或恢复的用户应升级。
  • 新的终端与标签页定制 — 新增可配置的状态栏条目、直接的窗格大小调整/标签页重排绑定，通过 ui.window_title 同步外层窗口标题，并加入独立的外层窗格边框、侧边栏背景以及跟随主题的状态/选中颜色。如果这些工作流或外观改进正中你的需求，升级价值最大。
  • 加固与兼容性修复，无需迁移 — Unix CLI 命令现在在管道关闭时安静退出而非 panic，下载和更新会校验 SHA-256 摘要，Windows 安装程序使用原子激活。大量键盘、IME、鼠标报告、远程客户端和跨平台修复改善了兼容性。未列出明确的破坏性变更或迁移步骤；稳定版用户可以放心跳过，除非受到某个具体修复影响。

添加

  • CLI 帮助现在将编码代理指向 Herdr 的纯文本指南、文档索引和内置控制技能。
  • 添加了针对空闲、工作和用户确认状态的 Qwen 代码检测，以及可选的本机会话恢复。 （＃2730，＃2743）
  • Herdr 现在通过 ui.window_title 使外部终端窗口标题与会话保持同步，因此窗口管理器和终端选项卡栏显示活动工作区和窗格实际运行的主机。 （＃2627，谢谢@dhh）
  • 桌面选项卡栏现在具有可配置的右对齐状态条目，用于缩放状态、主机名、日期/时间、文字文本和异步刷新的命令输出。
  • 可选的 keys.move_tab_previous 和 keys.move_tab_next 绑定现在将活动选项卡重新排序到位，在任一端换行。 （＃2561，谢谢@dhh）
  • 可选的 keys.resize_pane_left、keys.resize_pane_down、keys.resize_pane_up 和 keys.resize_pane_right 绑定现在只需一击键即可调整聚焦窗格的大小，而无需进入调整大小模式。 （＃2558，谢谢@dhh）
  • Windows clients 现在可以使用 herdr --remote 连接到 Linux 和 macOS 上的 Herdr 服务器。 (#2329)
  • Cursor Agent CLI、MastraCode、Hermes Agent 和 Grok CLI 集成现在可以在 Windows 上本地安装和运行。
  • 窗格现在可以通过窗格菜单、herdr pane input、pane.input.set 或 pane split --right-click pane 启动选项将正常的右 click 手势路由到鼠标报告应用程序。
  • ui.pane_outer_borders 现在可以独立于内部分隔线保留或隐藏分割窗格边框的外边缘。 （＃2535，谢谢@dhh）
  • theme.custom.sidebar_bg 现在可以为桌面侧边栏提供自己的背景，而无需更改内置主题默认值。
  • 设置和 ui.status_indicators = "symbols" 现在可以使用不同的静态形状来表示阻塞、工作、完成、空闲和未知代理状态。 （＃2260）
  • 导航模式选择行现在使用专用的每个主题光标颜色，可通过 theme.custom.selection_bg 进行自定义，因此光标与活动空间和代理突出显示保持可区分。
  • 复制模式现在支持以空格分隔的大字上的 B、E 和 W 动作。 （＃2270，谢谢@jplew）
  • 插件市场现在可以在存储库根目录和子目录中发现有效清单，将每个存储库下的多个插件分组，并发布它们的版本和确切的默认分支提交。

已更改

  • Windows 支持现在通常通过稳定版本提供，并且默认使用稳定更新通道。现有预览安装将保留预览状态，直到明确切换为止。
  • 当未连接 client 时，无头服务器现在使用可配置的 120×40 虚拟终端，而不是 80×24，为新创建的窗格提供实用的默认大小。 (#2828)
  • 桌面选项卡标签现在位于其选项卡中央，因此活动选项卡突出显示具有对称填充。 （＃2570，谢谢@dhh）
  • 实验窗格图形现在支持有界命名层、经过审核的本地终端上公认的全 RGBA 主层直接文件帧、拥有的 BGRA 后备、精确像素鼠标输入以及仅放置调整大小重播。

已修复

  • Unix CLI 命令现在在下游管道关闭时安静退出，而不是因退出 101 而恐慌。 (#2994)
  • 现在，当导航光标落在展开和折叠的侧边栏中时，终端主题使活动空间行填充保持可见。 (#2987)
  • 繁忙的多窗格会话现在可以避免冗余的隐藏窗格唤醒和窗格缩放路径中的完整终端状态格式化，从而防止高速后台输出、滚动条和增强的键盘模式导致 CPU 回归。 （＃2550，＃2901，＃2962）
  • 当焦点应用程序请求可打印的按键释放事件时，中文 IME 现在会提交到 macOS 上的窗格。 (#2924)
  • Windows 现在通过 Ctrl+9 键绑定识别 Ctrl+1，而不是将这些键记录解码为控制字符。 (#2910)
  • PowerShell 窗格现在使其进程报告的工作目录与 shell 的逻辑位置保持同步。 （＃2879，感谢@Pimpmuckl）
  • 前台输入不再等待隐藏选项卡中窗格的输出所消耗的渲染节奏。 (#2890)
  • Windows ARM64 安装程序现在等待 x64 仿真来发布经过验证的可执行文件，然后再激活下载的版本。 (#2916)
  • 在 Unix 上，Ctrl-click URL 打开程序现在会在退出后被回收，从而防止失效的子进程在长时间运行的服务器上累积。 （＃2903）
  • Windows 更新现在仅重用经过验证的本地软件包，避免安全工具下载块，同时保留校验和验证。 （＃2751，＃2816，谢谢@Pimpmuckl）
  • Herdr 不再在 WSL 下发送完整的 OSC 4 调色板查询突发，从而防止回复片段通过 ConPTY 泄漏到 shell 中。 (#2440)
  • Qwen 代码窗格现在使用与区域设置无关的终端标题状态和本地化确认回退，防止活动或阻止的轮流显示为空闲。 (#2756)
  • 克劳德代码窗格现在可以识别并剥离每个半圆标题旋转框，防止活动回合出现空闲状态并保持标题干净。 （＃2707，＃2709，＃2760，＃2762）
  • 副驾驶提示现在会在发送输入之前将焦点集中在目标窗格中，因此背景窗格不会默默地删除提示。 （＃1698，＃2734，谢谢@xkrogen）
  • 代理挂钩现在调用正在运行的 Herdr 二进制文件，而不是 PATH 上首先出现的二进制文件。 （＃2722，感谢@Pimpmuckl）
  • 当远程会话保持活动状态时，关闭运行 herdr --remote 的终端不再产生本地 client 核心转储。 (#2424)
  • 活动空间和代理行现在使用专用主题颜色，当主机终端背景与选定的 Herdr 主题匹配时，这些颜色仍然可见。 (#2792)
  • agent prompt 现在拒绝已经在等待批准或与 agent_blocked 进行问题对话的客服人员，无需发送文本或 Enter。 (#2788)
  • agent start 现在等待新的窗格 shell 和首次运行代理提示准备好，而不是与它们竞赛或报告过早的准备情况。 （＃2410，＃2537，＃2773，＃2774，谢谢@Pimpmuckl）
  • prefix+e 现在在编辑器中打开软包装回滚时保留逻辑行。 (#2733)
  • 备用屏幕窗格读取避免了不必要的 ANSI 格式化工作，从而减少了 TUI 代理的读取延迟。 （＃2387，＃2426）
  • 在本机全屏中使用 Ghostty 时，标签栏 clicks 现在可以正确注册。 （＃796，＃2736，感谢@HackAttack）
  • 前缀键绑定现在可以消除布局感知的移位标点符号的歧义，因此移位的 \ 不再在同一键产生两个字符的键盘布局上触发 prefix+|。 (#2674)
  • 远程 clients 现在继续以非常大的终端尺寸重绘，而不是在完整 ANSI 帧超出传输限制时冻结。 (#2670)
  • Windows Git 状态刷新现在重用存储库配置，而不是重复触发 WSL 存储库的安全扫描。 （＃2643，＃2688，谢谢@Pimpmuckl）
  • Windows 空闲代理检测现在跨窗格共享进程快照，从而减少与许多 Git Bash 窗格的会话中的 CPU 使用率。 （＃2459，＃2494，＃2642，＃2651，谢谢@Pimpmuckl）
  • 嵌入式裸存储库现在可以派生出正确的存储库名称和工作树位置。 （＃2657，＃2660）
  • 根存储库工作区现在在更新重新启动时保留其保存的标签。 （＃2594，＃2727）
  • Elevated Windows panes no longer expose PowerShell’s administrator decoration as the terminal title. （＃2632，感谢@Pimpmuckl）
  • 模态名称输入现在将主机 IME 光标锚定到文本字段，而不是对话框后面的窗格。 （＃1755，＃2569，谢谢@kataokatsuki）
  • 会话导航器移动忽略修改的 j、k 和箭头键，而不是消耗不相关的窗格输入。 （＃1981，＃2377，感谢@atomsbaza）
  • OpenCode 窗格现在跟踪在自己的 TUI 中选择的根对话以进行本机恢复，而无需采用附加 clients 的活动。 (#2450)
  • 服务器停止请求现在绕过窗格和 API 流量，防止繁忙的会话阻止关闭或在关闭挂起时允许 client。 (#2612)
  • Fish Ctrl+Alt 键绑定现在可以在使用两个修饰符解码传统 Alt 前缀控制字节后在窗格中工作。 (#2514)
  • Windows recent-history reads no longer perform redundant snapshots, restoring recent output while reducing read cost. （＃962，＃2474，谢谢@Pimpmuckl）
  • Windows 安装程序现在使用原子目录交换激活版本，防止更新中断留下空的版本目录。 （＃2356，＃2530，谢谢@Pimpmuckl）
  • herdr config check 现在报告未知的内置主题名称，而不是默默地接受它们。 (#2452)
  • macOS herdr --remote clients 现在保持接受的桥接套接字阻塞，防止协议握手后立即断开连接。 （＃2478，感谢@mathijshenquet）
  • 前缀键绑定现在在 WezTerm Kitty 键盘模式下保留 Shift，因此配置重新加载等命令不再触发其未移动的操作。 (#2435)
  • 窗格应用程序现在接收修改其他键版本并移动备用报告，而不会丢失版本或泄漏 Ctrl+Tab 序列。 (#2296, #2302, #2303)
  • 现在，分离可以恢复主机键盘报告，防止增强的键盘序列在 Herdr 退出后泄漏到 shell 中。 （＃2393，＃2395）
  • 默认鼠标报告被解码，而不是将转义字节泄漏到聚焦窗格中。 （＃2309，＃2312）
  • 窗格程序发出的 BEL 字符现在到达外部终端，因此其声音和视觉铃声设置可以做出反应。 (#2453)
  • 稳定的直接安装、自我更新和远程帮助程序下载现在需要并验证为每个 GitHub 发行资产发布的 SHA-256 摘要。
  • pane read 和 pane wait-output 现在接受 --flag=value 以及窗格 ID 之前或之后的选项。 （＃2183，感谢@KyleCo76）
  • pane current、pane get 和 pane layout --current 现在解析调用窗格，而不是另一个 client 的焦点窗格。 （＃2297，＃2298）
  • 包含已停用的 Herdr 写入的 ui.agent_panel_scope 设置的配置在升级后不再将其报告为未知密钥。 (#2292)
  • 使用 Enter to confirm · Esc to cancel 的克劳德代码确认提示现在报告 blocked 而不是 idle。 (#2268)
  • Kiro CLI 提示现在具有积极的空闲检测，而不是保持在未知状态。 （＃2301，感谢@smileynet）
  • 光标的“运行所有内容”页脚不再产生错误的阻止状态。 （＃1763，＃2220，感谢@Nagi-ovo）
  • 现在可以检测版本化的 Python 代理包装程序，例如 python3.13。 （＃2188，感谢@plarson）
  • Pi 状态报告现在忽略 RPC、JSON 和非交互式 TUI 会话的打印模式帮助进程。 （＃2159，谢谢@rhjoh）
  • 折叠的工作区和代理行保持其状态和活动指示器可见，包括十个或更多工作区。 （＃2216，＃2239，＃2382，谢谢@ianks）
  • 当不同大小的 clients 连接到同一会话时，侧边栏代理列表会保持滚动。 （＃2255，感谢@aiworkflowpro）
  • 会话导航器现在搜索重命名的单选项卡标签。 （＃2320）
  • 新的拆分将焦点返回到打开它们的窗格。 （＃2266，感谢@jondkinney）
  • 半角片假名浊音和半浊音标记现在呈现在正确的单元格中。 （＃2257，感谢@kazunari-kamata）
  • Ctrl-clicking URL 在浏览器获得主机焦点后不再转发其版本，从而防止重复的选项卡。 （＃2290，＃2291，谢谢@kataokatsuki）
  • OSC 4 调色板覆盖现在使用请求的颜色进行渲染，而不是转发调色板索引。 （＃2162，感谢@hamidi-dev）
  • 当焦点返回时，会重新查询主机终端外观，保持自动亮色和暗色主题为当前状态。 （＃2416，＃2417）
  • 捆绑且可安装的 Herdr 代理技能现在与此稳定版本的 CLI 和生命周期行为相匹配。 (#2847)
  • pane send-keys 和 agent send-keys 现在在发送 shift+tab 时保留 Shift，允许以编程方式循环代理权限模式。 （＃1561，感谢@keinstn和@tomohisa）
