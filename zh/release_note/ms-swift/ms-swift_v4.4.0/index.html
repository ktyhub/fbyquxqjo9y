ms-swift v4.4.0

小版本 发布时间2026年7月6日 来源modelscope/ms-swift 英文原文

ms-swift v4.4.0

这个项目是干啥的：魔搭社区的大模型微调和训练框架，覆盖海量模型并支持GRPO等强化学习训练，给想微调模型的AI开发者用。

变更架构图

亮点

  • RL：GRPO/GKD trainer 重构，外加 OPD 与多 teacher — GRPO/GKD Trainer 已重构（#9580，与 SP 重构 #9509 并行的 “[1/N]” 系列），同时新增 OPD RL 训练（#9641）、多 teacher 训练（#9678）、多轮 openenv 支持（#9628）和用于 rollout 的样本级 chat template kwargs（#9623），并修复缺失的 offload_teacher_model 参数（#9674）以及 HF OPSD/GKD 中的 use_vllm=False（#9677）。如果你运行 GRPO/GKD，这是升级的主要理由——但请把 trainer 重构视为迁移风险，重新验证配置。
  • 新模型与模态 — 新增 GLM-5.2（glm_moe_dsa 配合 indexer_type='shared'，#9581）、Kimi-K2.7-Code / kimi_k27（#9552）、MiniMax-M3（#9553/#9568）、带 R-SWA 的 Unlimited-OCR（#9645/#9665）、通过 DLLM 训练的扩散 Gemma（#9548）和 Qwen3-TTS（#9638）；Qwen3.5 与 minicpmv4.6 新增 padding_free/packing（#9571/#9654）。只有需要这些模型族时才值得升级。
  • 训练旋钮：MRL 与可组合损失缩放 — Embedding 模型通过新增 mrl_dims 参数获得 MRL（#9528），ConcatLossScale（#9537）让你可以叠加 last_round+ignore_empty_think+hermes 等策略。模板行为也有变化：混合思考模型现在设置 enable_thinking=False（#9557），新增”禁用 ignore empty think”选项（#9558），并修复思考列表（#9679）。如果依赖之前的默认值，请检查这些变化。
  • Megatron-SWIFT / NPU：版本升级与明确的破坏性变更 — NPU Megatron-Core 升到 0.16，并修复 MindSpeed 兼容性（#9624）；moe_router_load_balancing_type 现在可以指定多个类型（需要 mcore>=0.16，#9603）。破坏性变更：cross_entropy_fusion_impl 默认值由 'te' -> 'native'（#9578），Megatron 的 num_samples 被移除（#9522），而此前因参数/配置名不匹配被静默丢弃的 muon_use_nesterov 现在会生效（#9599），并新增 muon_coefficient_type（#9591）和 optimizer_cuda_graph（#9680）旋钮。NPU/Megatron 用户必须对齐环境，并重新检查融合/优化器默认值。
  • 跨领域修复与谁可以跳过 — 修复覆盖 AMD/ROCm（异步 IPC #9627、Megatron Ray #9653）、DDP（#9590/#9592）、transformers>=4.57.6 弹性代码（#9614）、MeanMetric 跨 rank dtype（#9551）、空 rejected_messages 数据集崩溃（#9642），以及 Gemma4 系统/权重同步问题（#9604/#9572）。RL、Megatron/NPU 和新模型用户应升级；稳定在 4.3.x 且只做已支持纯文本训练的用户可以跳过。这是实质性的功能发布，不是重新打标签或仅元数据变更。

中文版

新特性

  1. RL a. GRPO 支持 OPD RL 训练。参考文档：https://swift.readthedocs.io/zh-cn/latest/Instruction/Distillation.html b. GRPO/GKD支持多师训练。参考文档：https://swift.readthedocs.io/zh-cn/latest/Instruction/Distillation.html c. 新增多模态 vLLM 单色测试。参考问题：https://github.com/modelscope/ms-swift/issues/9668 d. GRPO/GKD Trainer 完成重构。
  2. 威震天-SWIFT a. 新增 model_type 支持：GLM-5.2（glm_moe_dsa 新增 indexer_type = ‘shared’ 支持）、minicpmv4_6。 b. NPU Megatron-Core版本升级至0.16。（感谢@addsubmuldiv的贡献） c. moe_router_load_balancing_type支持同时指定多个类型。 d. 修复DeepSeek-V4 FP8相关问题。
  3. 训练 a. 新增 DLLM 训练支持（DiffusionGemma）。训练脚本参考：https://github.com/modelscope/ms-swift/blob/main/examples/models/gemma4/diffusion_gemma.sh b. 新增 Qwen3-TTS 训练支持。训练脚本参考：https://github.com/modelscope/ms-swift/tree/main/examples/models/qwen3_tts c.嵌入模型新增MRL支持，引入mrl_dims参数。 d.损失规模支持ConcatLossScale，可将多种损失规模策略加载，例如：last_round+ignore_empty_think+hermes。 e. Qwen3.5、minicpmv4.6支持padding_free/packing。

新模型

  1. 纯文本模型 a.智普AI/GLM-5.2
  2. 多模态模型 a. Moonshotai/Kimi-K2.7-代码 b. MiniMaxAI/MiniMax-M3 c. PaddlePaddle/Unlimited-OCR d.谷歌/diffusiongemma-26B-A4B-it
