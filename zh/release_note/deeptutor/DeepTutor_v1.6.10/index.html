DeepTutor v1.6.10

修订 发布时间2026年9月22日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.09.22 v1.6.10 以 v1.6.9 为基础，为原生 LightRAG 引擎提供了自己的角色模型，并发布了一个已发布的索引来说明其构建内容。围绕它：PDF附件现在尊重你的解析引擎，代币预算被切断的一代如此表示，而不是因为解析错误而失败，并且模型提供者不再被过滤掉 DeepTutor 无法预先验证的服务。直接插入——无需迁移。

新消息

Native LightRAG 榜样

原生 LightRAG 引擎采用自己的基本模型，独立于聊天模型，并具有用于提取、关键字、查询和视觉的可选每个角色覆盖。在新配置中，视觉默认处于关闭状态。知识库创建和完全重建使用共享引擎默认值而不是每个索引覆盖，并且在提交之前会显示更改的配置以供审核。

记录其构建方式的索引

出版物固定了构建索引所用的提取和视觉标识，因此以后对引擎默认值的更改不会影响现有索引。索引版本显示其嵌入、提取和视觉来源；历史身份未知的索引保持可查询，但拒绝增量写入，直到完全重建。启用、禁用或替换视觉或提取需要完全重建，而失败的重建将撤回其发布，而不是留下半发布的索引。凭证被排除在持久策略和来源之外。

嵌入兼容性是强制执行的，不建议

本机 LightRAG 查询和增量索引需要已发布索引记录的嵌入配置 - 模型、维度和端点标识。如果发生更改，请恢复原始配置或使用当前嵌入进行重建。知识库详细信息和索引版本视图包含恢复指南，文件始终可供查看和下载。

PDF 附件遵循您的解析引擎

附加到回合的 PDF 将通过设置 → 知识库中配置的解析器，其处理阶段在运行时可见。当全局默认引擎无法接受文件时，DeepTutor 会回退到支持文本的引擎而不是失败，并且解析器失败仍然会回退到本机 PDF 提取。非 PDF 轮次完全跳过解析器设置，并且重新生成带有附件的轮次不再破坏请求验证。

被截断的答案表示它已被截断

响应现在可以区分完整的一代和在 max_tokens 处截止的一代，因此推理模型耗尽的预算不再表现为无法诊断的解析错误。数学动画师在重试中提高自己的预算（上限为基数的两倍），并告诉重试是预算耗尽，而不是格式耗尽。 Visualize 解释了屏幕上被截断的渲染，而不是无声结束，并且其温度和令牌预算现在可以在设置 → 功能中进行配置。

您可以配置和测试的模型提供程序

提供商选项不再对 DeepTutor 无法预先验证的服务隐藏：选择任何提供商进行嵌入、搜索、语音或多模式，并让连接测试判断该模型是否真正发挥该作用。未经认可的供应商通过通用 OpenAI 兼容绑定进行解析，但搜索除外，搜索没有通用适配器并且按名称拒绝。暂存提供程序连接也可以通过纯 HTTP 进行，其中 crypto.randomUUID 不存在，并且 Continue 按钮之前没有执行任何操作。

学习和掌握证据

掌握证据与目标和问题身份相关，因此修复适用于它所来自的问题，并且重播的定性评估不会重复计算。从未发布过的掌握卡不能再声称已交付，并且选定的测验必须在交付前完成。笔记本证据与聊天会话分离，个性化学习仪表板不再在其第一张卡上崩溃。

可靠性修复

沙盒执行可以容忍现代 Linux 上的 bwrap 环回拒绝，并在回退期间保持网络隔离。启动器不再打开一个显示为“后端已退出”的杂散控制台窗口，并且设置派生的环境密钥停止跨进程隐藏实时设置 API。研究报告在完成的回复中恢复其标签，GitHub 源同步正确记录已确认的当前源，Mastery Composer 资源与聊天页面匹配，角色预设经过管理控制，重试状态在请求验证中幸存，并且可以通过 UI 访问工具提示。

升级注意事项

运行pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。

  • 现有的 LightRAG 索引继续工作。 它们像以前一样查询；仅增量写入被门控。没有记录嵌入标识的索引，或者嵌入配置已更改的索引，在接受新文档之前会要求恢复或完全重建。
  • 视觉索引是新角色配置的选择加入。 打开（或关闭，或交换模型）适用于下一次完整重建，而不是已发布的索引。
  • 提供者列表故意更宽。 无法提供所选角色的提供者现在无法通过其连接测试，而不是从列表中消失。申请前进行测试。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.6.9…v1.6.10
