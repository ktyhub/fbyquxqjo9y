DeepTutor v1.7.3

修订 发布时间2026年11月15日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.11.16 v1.7.3 基于 v1.7.2 构建，使阅读和书籍编辑更加灵活，扩展搜索和代理连接，并改进学习记录、模型流和桌面升级。

新消息

阅读、缩放并重新访问问题帮助

PDF 阅读器添加了连续缩放、文本适合控件和图像查看器。注释更新和多材质选择更可靠。阅读测验将答案密钥保留在服务器上，并将与问题相关的帮助与尝试分开保存；授权监护人可以查看阅读进度、测验记录和帮助活动。

在应用书籍更改之前查看它们

编辑生成的章节和章节，无需重建整本书。结构更改和页面聊天提案在应用之前显示可审查的差异，并且可以撤消最近未更改的编辑。打开时会生成新的空部分；数学渲染和页面聊天延续也得到修复。

更多搜索提供商和连接代理

搜索添加了 DeepSeek、SpecStream 和 SearchApi，包括 SearchApi 网页、新闻和学者模式。 Web Fetch 获得可选择的 DeepSeek 后端，标准计算加入模型设置。已配置的代理 Client 协议 (ACP) 进程可作为本地子代理进行咨询。同意并重启后，MCP OAuth 刷新和重新连接更加可靠。

对话和练习保留其背景

选择每个对话支持的推理努力。未触及的聊天会话继承了现成的工作区知识库，为同一帐户重新打开保存的侧聊天选项卡，并且问题库源支持搜索和分页。精通修复保留了失败尝试的解释，在重新索引后保持发布的问题可分级，并改进参考答案和窄屏导航。

更好的文档解析和语言支持

Docling 保留结构化页面内容并公开可选的公式和图片丰富内容。上传验证遵循可用的解析器格式，GitHub 知识源接受 MDX，检索遵循确切的源路径。意大利语和匈牙利语加入了界面和回复语言选项，而印地语则成为回复语言。

更可靠的模型流和桌面升级

提供者调用更仔细地处理停滞的流、不完整的终端事件、工具标识符和重放推理。历史在凝结停止后仍然超出了其计划，并出现了明显的错误。安装较新的桌面应用程序采用其较新的捆绑核心，具有备份和回滚功能； macOS Finder 启动还会在常见安装位置发现主机 CLI。启动器和更新器准备就绪等待尊重配置的限制。

升级注意事项

  • 完整应用程序： 停止 DeepTutor 并备份运行时主页，然后运行 python -m pip install --upgrade "deeptutor[full]==1.7.3"。保持相同的DEEPTUTOR_HOME；重新启动前请与 python -m pip check 和 deeptutor module list 进行验证。附加功能轮也必须与 1.7.3 匹配。
  • 旧版安装： 1.6.15 及更早版本需要在安装模块化系列之前卸载旧的 deeptutor-cli 软件包。使用v1.7.0中的手动迁移；旧的更新工作线程无法追溯获取新的迁移逻辑。在同一环境中使用 "deeptutor[full,parse]==1.7.3" 通过可选解析恢复完整的应用程序。
  • 源和 Docker： 源用户安装 requirements/full.txt，然后安装 python -m pip install -e . --no-deps，并在 Node.js 22 上使用 npm ci --legacy-peer-deps 刷新 web/。Docker 用户拉取 ghcr.io/hkuds/deeptutor:1.7.3 或 :latest 并使用其现有数据卷重新创建容器。
  • 桌面： 使用匹配的 Apple Silicon 或 Intel DMG、Windows 安装程序或便携式 ZIP。 Windows 版本保持未签名状态。自动更新发现未连接；现在替换应用程序会尝试更新的捆绑核心并保留工作区备份。
  • 嵌入： 索引的 OpenAI 兼容嵌入响应现在恢复为输入顺序。如果网关之前返回了重新排序的向量，请重建受影响的索引以更正其文本/向量关联；现有索引文件将被保留。
  • 书籍编辑和 ACP： 在结构编辑之前暂停书籍生成。 ACP 需要配置的代理命令及其自身的身份验证；此初始 client 不支持交互式启发和权限请求。
  • 提供程序恢复： 默认值仍然是 store=false。当请求已选择 store=true 时，已知响应的恢复仅限于官方 OpenAI 响应端点；未解决的操作会暂停，而不是自动提交替换工作。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.7.2…v1.7.3
