DeepTutor v1.5.6

修订 发布时间2026年7月28日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.07.29 v1.5.5 的后续版本完成了它所开始的工作：它提供的 Codex 登录现在实际上在远程或容器化部署上完成，并且也适用于合作伙伴和非管理员。除此之外，知识库可以指向您已保存在腾讯 IMA 中的库，对话生成的文件不再隐藏在文字记录中，日语书籍不再带有中文测验。直接插入——无需迁移。

新消息

连接腾讯IMA库

知识库现在可以是指向您在 Tencent IMA 中策划的库的指针，而不是 DeepTutor 构建的索引。它完全遵循 lightrag-server 形状：没有复制任何内容，也没有在本地存储任何内容 - 将文档添加到 IMA 中，检索调用 IMA 的 OpenAPI，并且聊天循环仍然写入答案。凭据 (client_id + api_key) 和库 ID 按 KB 实时显示，因此在共享部署中，每个用户都通过自己的 IMA 帐户而不是全局密钥进行检索，并且连接是独立的，无需首先填写设置界面。连接会探测库一次，因此输入错误的 id 会在连接时失败，而不是在以后的每个查询中默默失败。

生成的文件，您可以在其中再次找到它们

导师制作的文件只能通过制作它们的一个助手气泡访问，因此再次找到一副纸或电子表格意味着滚动成绩单。活动面板现在将对话“生成”的内容与您“上传”的内容分开：生成的文件在附件上方拥有自己的卡片，其大小和悬停标题显示文件位于数据根下的位置。行重用现有的在查看器中打开的路径。

远程 Codex 登录完成

v1.5.5 附带 OpenAI Codex OAuth 的警告 - 在远程盒子上，请改为从服务器登录。那个警告消失了。浏览器的localhost和服务器的localhost是不同的机器，因此单独的反向代理永远无法承载回调； DeepTutor 现在仅通过 Web 源将确切的回调路径转发到状态验证代理，并且设置卡和 CLI 打印真实的回调地址、SSH 隧道命令、显式授权操作以及页面重新加载后的倒计时（#716）。 两个后续措施使其适用于部署中的其他人。回调由 OAuth state 传递——该过程为一次登录创建的秘密，在恒定时间内进行比较——而不是由请求的用户传递，因为浏览器通过您自己的隧道到达并且不携带会话 cookie；如果没有此选项，远程登录将为每个非管理员返回 login_not_active。现在，合作伙伴会将 Codex 凭据解析为所有者的根目录，而不是合作伙伴的综合工作区，因此与合作伙伴聊天不再因“使用此模型之前登录 Codex”而失败 (#713)。 侦听器保持绑定到环回，端口 1455 和 1457 永远不会发布，回调响应永远不会回显代码或状态，并且 PKCE 和令牌交换不变。

每种语言都有自己的语言

parse_language() 以裸露的 return "zh" 结束，因此 ja/ko/fr/de/ru/ar 全部解析为中文 - 这就是为什么一本日本书带着中文测验回来的原因 (#712)。现在，它委托给现有的规范化器并传递未知代码，假设答案是 zh 或 en 的两个后备链也会效仿：提示尝试 [code, base locale, "en"]，因此 zh-tw 重用中文文件，而 ja 则显示英文而不是中文。

各种修复

  • 书籍创建和块重新生成通过 WebSocket 运行，而不是代理可能超时的请求，书脊综合和 Visualize 的分析阶段使用非流调用，因此单章回退或截断的代码块不会发生（#707）。所有三个现在都通过代理接缝进行路由，这会恢复图像附件、跟踪元数据以及每个代理路由直接工厂调用被丢弃的情况。
  • deeptutor start 在新源签出时会为您安装 web/node_modules，而不是因缺少模块错误而崩溃 (#710)。
  • 管理员用户管理、注销、确认对话框和 toast 均已本地化，因此将 UI 切换为中文后不再保留英语帐户管理 (#718)。
  • 服务lazy-loader使用文字导入路径（#717）——行为中立，但它使模块图可以静态分析。

升级注意事项

从 v1.5.5 插入：pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。无需迁移，无需架构或配置更改。

  • 远程 Codex 登录现在使用 SSH 隧道，并且在服务器上运行 deeptutor provider login openai-codex 的 v1.5.5 建议不再是唯一路径。 DeepTutor 打印准确的 ssh -N -L … 命令；仅运行与其报告的回调端口相匹配的端口，并注意该命令中的 3782 是一个示例 - 将其替换为实际侦听 SSH 主机环回的 Web 端口。
  • 腾讯 IMA 知识库需要来自 ima.qq.com/agent-interface 的 client_id 和 API 密钥以及库 ID。文档是在 IMA 中添加的，而不是通过 DeepTutor 添加的。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.5.5…v1.5.6
