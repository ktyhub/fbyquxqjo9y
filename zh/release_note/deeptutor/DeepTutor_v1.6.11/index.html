DeepTutor v1.6.11

修订 发布时间2026年9月24日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.09.24 v1.6.11 建立在 v1.6.10 的基础上，是一个广泛的版本：法语和乌克兰语加入界面，沉浸式阅读获取文件夹、数字和聊天内选择操作，Office 文件预览为真实页面，知识库学会保持同步。迁移是附加的并且在首次启动时运行。 Docker 映像更大 (LibreOffice)，如果 /app/data 不可写，容器现在将拒绝启动。

新消息

四种界面语言，十四种回复语言

该界面现在提供英语、中文、法语和乌克兰语版本，可从设置 → 常规中进行选择。乌克兰语已完成；尚未翻译的法语字符串会回退为英语。模型回复可以设置为 14 种语言，并且 Composer 中的新 /language 命令会为一个对话固定回复语言，而无需触及您的帐户默认设置。

沉浸式阅读，重新组织

阅读收藏变成彩色文件夹，有自己的文件和对话页面，全屏学习模式隐藏了应用程序的其余部分。选择一个段落并选择“解释”、“翻译”或“指导我”现在会在阅读聊天中发布一条普通消息并附加引用，因此交流会保留在对话历史记录中。 在此页面上测验我 在打开的页面上运行三个问题的测验，无需切换对话模式。 EPUB 获得显示控制（字体、线宽、主题、两页跨页）、适合学习者年龄的内置操作，并且在修订材料时重新定位注释。

图片和人物到达模型

提取 DOCX、PPTX 和 PDF 中嵌入的图像，在其原始位置显示，并从聊天附件（每个文档最多 12 个）转发到视觉模型。作为矢量绘制的页面被光栅化，以便模型可以看到图形，并且图形标题可作为选择加入的解析设置。现有材料不会自动重新提取 - 请参阅升级说明。

Office 文件预览为页面

聊天查看器和知识库文件预览通过 LibreOffice 将 Word、PowerPoint 和 Excel 文件（包括旧格式）渲染为分页 PDF。如果没有 LibreOffice，DOCX 和 XLSX 会退回到浏览器内渲染器和其他格式来提取文本。观看者还可以获得新选项卡启动器和更流畅的打开/关闭动画。

保持最新的知识库

文档站点源按照持久的计划重新同步（默认情况下每 24 小时一次，每个源 1-168 小时），并包含作业历史记录、取消和重试。链接的本地文件夹显示跟踪的文件和“立即同步”操作，以拾取新文件和更改的文件。 .bib 文件可以建立索引，新的 zotero_search 工具查询您的 Zotero 库，仅图像扫描的 PDF 会回退到本地 OCR，并且 LightRAG 会公开其 LLM 超时。现在，每个本地引擎都会在首次​​上传时引导一个空的知识库。 ###学习进度 新的设置 → 学习进度页面显示您在每种材料中阅读的程度以及您最近的学习操作（仅限于您的帐户）。掌握度审查计划采用每条路径的召回目标。

供应商、代理商和进口

统一加入提供商列表，Grok CLI 加入我的代理中的实时子代理，导入向导接受来自官方 ChatGPT 数据导出的 conversations.json。速率限制请求现在尝试每个配置的 API 密钥，拒绝 temperature 的 Claude 模型不再在任何路由上接收它，并且 Codex 模型目录跟踪当前的 Codex client 版本。

帐户和部署

管理员可以从CSV导入用户并批量删除。私有/公共分离部署可以限制私有主机的密码登录，并通过短期切换链接配对公共设备。设置提供四个可审查、无需凭据的预设。 Docker 尊重 PUID / PGID 的绑定安装（Unraid），独立构建打包其静态资产，并且合作伙伴 QR 入门可在简单安装中工作。

聊天、语音和合作伙伴

失败的回合可以从其保存的请求中重新发送，并且被拒绝的重新生成将保留之前的答案。语音将 LaTeX 作为单词大声朗读（数学说话，默认情况下处于启用状态）。可选的 Google 网络风险过滤会删除标记的搜索引用。飞书合作伙伴在话题中回复，并在直接消息中使用 /model 切换模型，Telegram 回复落在原始主题中，固定的小组讨论导出为 Markdown，同步浏览器 在您的浏览器中进行合作伙伴对话。

修复

可能覆盖任意 JSON 文件的笔记本路径遍历错误已被关闭。授权文件以原子方式写入，并且在损坏时会失败关闭，学习者仅限于一组明确的知识库读取，重新索引进度不再在工作人员之间泄漏，IMA 不再报告空搜索的引用，并且使用定价更喜欢精确的模型匹配。

升级注意事项

运行pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。

  • Docker： 图像现在包含 LibreOffice 和 CJK 字体，因此它明显更大。入口点将容器用户重新映射到 PUID / PGID（默认 1000），如果 /app/data 不可写，则在启动时停止，而不是稍后失败 - 修复绑定挂载所有权或设置 PUID / PGID。
  • 源安装： 将 soffice 放在 PATH 上以获得分页 Office 预览；如果没有它，预览会如上所述回退。
  • Web 源开始自动同步。 现有文档站点源在升级后默认为 24​​ 小时计划。将其关闭或更改知识库页面上每个源的间隔。
  • 旧阅读材料保留其摘录。 要将图形（和可选标题）添加到已摄取的材料中，请运行 python scripts/reading_refresh_figures.py --all --yes（为标题添加 --caption）；注释被保留。
  • **删除：**阅读“开启者”端点 (/reading/workspaces/{id}/openers) 及其 阅读开启者 任务模型。为其保存的 PIN 码会自动删除。
  • 新可选钥匙： UNIFICALLY_API_KEY； auth.private_login_hosts / AUTH_PRIVATE_LOGIN_HOSTS 和 AUTH_TRUSTED_FRONTEND_PROXY_IPS 用于分体部署； tools.web_search.source_filtering.use_web_risk 与 GOOGLE_WEB_RISK_API_KEY。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.6.10…v1.6.11
