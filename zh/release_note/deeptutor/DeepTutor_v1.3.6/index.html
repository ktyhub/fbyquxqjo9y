DeepTutor v1.3.6

修订 发布时间2026年5月3日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.05.03 v1.3.6 专注于使模型路由在 DeepTutor 中明确。用户可以 从聊天和 TutorBot 流程、运行时服务中选择配置的 LLM 配置文件 在不泄露提供商秘密和 RAG/知识库的情况下解决这些选择 当持久嵌入无效时，索引处理更具防御性。

变更架构图

亮点

基于目录的模型选择

  • 聊天可以针对配置的模型 - 统一的聊天回合现在带有 通过 WebSocket 负载、会话选择 profile_id 和 model_id 首选项、转动快照并重新生成流程。
  • 设置公开安全的 LLM 选项 - 新的设置选项端点 返回可显示的提供者/模型选择，同时省略凭据和 来自响应的连接秘密。
  • 运行时模型覆盖的范围是每回合 - 选定的配置文件是 通过活动请求的提供者目录进行解析，无需写入 临时选择返回磁盘或更改全局默认值。
  • 模型选择器 UI 是共享的 - 聊天和 TutorBot 屏幕使用相同的 配置模型选择器，具有本地化标签和系统默认处理。

TutorBot 模型控制

  • 机器人可以保留模型选择 - TutorBot 创建/更新流程现在接受 llm_selection，根据配置的目录验证它，并将其存储为 每个机器人。
  • 运行机器人可以重新加载其 LLM - 更改机器人的模型会更新 主动代理循环，而不需要完全重新启动机器人。
  • 最近的机器人历史记录更加稳定 - TutorBot 历史记录组件现在按以下顺序排序 在获取最新上下文之前具有稳定平局的消息时间戳。
  • 机器人聊天路线更改更清晰 - 网络聊天页面在飞行中取消 机器人在切换机器人时请求并重置瞬时推理状态。

RAG 和知识可靠性

  • 无效向量触发重建 - 重新索引不再处理匹配 当现有向量存储嵌入失败时，文档签名可重复使用 验证。
  • 完全重建使用新版本目录 - 完整的知识库 重建写入新的平面索引版本，同时保留失败的旧存储 可供检查。
  • RAG 工具日志可以流式传输到 clients - 检索运行可以转发捕获的数据 当事件接收器可用时，信息级进程将日志记录为原始工具事件。
  • 知识健康检查识别不良嵌入 - 无效持续 向量会更早地出现，而不是产生不透明的搜索失败。

提供商和启动修复

  • OpenAI 响应令牌限制已标准化 - 响应 API 调用现在映射 聊天风格 max_completion_tokens 和 max_tokens 到 max_output_tokens， 修复了 #437 中为较新的 OpenAI 模型报告的 SDK 错误。
  • Azure 和 OpenAI 兼容路径共享映射 - 流式传输和 非流响应 API 路由使用相同的转换助手。
  • 启动端口来自 .env 和环境变量 - 设置和启动 助手现在使后端/前端端口行为与项目保持一致 .env 文件而不是旧的运行时设置 JSON。

Web UX 波兰语

  • 技能名称在保存前验证 - 技能编辑器会显示名称， 标记无效的内联输入，并防止大写 API 静默失败 字母、空格、下划线或其他不受支持的字符。
  • 技能编辑器模态在主题之间是不透明的 - 编辑器现在使用 页面背景标记，避免半透明主题中的文本渗透。
  • 太空导航更容易扫描 - 太空迷你导航、笔记本、 题库、技能和会话列表间距都得到了更清晰的收紧 卡和分隔符处理。

测试

  • 添加了安全选项列表、活动标记的模型选择服务测试， 无效的配置文件/模型拒绝，以及非变异目录覆盖。
  • 为持久的 LLM 选择添加了统一的 WebSocket 运行时测试， 无效选择、模型切换、快照和重新生成行为。
  • 添加了 TutorBot API 和 llm_selection 持久性管理器测试， 验证、运行时重新加载和默认模型行为。
  • 添加了范围目录的设置、提供程序运行时和 LLM 配置测试 选择和每回合配置优先级。
  • 添加了针对无效向量存储的 RAG 和知识路由器测试、重新索引 重建决策和存储版本解析。
  • 添加了针对令牌限制别名、优先级的 OpenAI Responses 转换器测试 None 过滤和输入不变性。
  • 添加了用于技能名称规范化和验证的前端 slug 测试。

升级注意事项

  • 想要显式模型路由的聊天和 TutorBot clients 应发送 llm_selection 为 { "profile_id": "...", "model_id": "..." }。省略它 继续使用配置的系统默认值。
  • TutorBot 配置文件现在可能包含 llm_selection。现有机器人 没有该字段的配置将继续加载，并且旧的 model 值仍然存在 可用作模型名称覆盖。
  • 启动端口应在 .env 或进程环境变量中配置 （BACKEND_PORT / FRONTEND_PORT）。老款data/user/settings/env.json 端口块不再用作启动端口源。
  • 具有陈旧或无效持久向量的知识库可能会在 即使文档签名没有更改，下一次也会重新索引。
  • 技能名称现在已标准化并验证为最多 64 的小写字母 使用字母、数字和连字符的字符。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.3.5…v1.3.6
