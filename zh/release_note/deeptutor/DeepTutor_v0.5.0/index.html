DeepTutor v0.5.0

DeepTutor v0.5.0 Release Notes

发布日期： 2026.01.15 我们很高兴推出 DeepTutor v0.5.0！此版本提供了统一的服务配置、灵活的 RAG 管道选择以及跨多个模块的主要 UI/UX 改进。

稳定性更新： 此版本修复了多个环境配置和稳定性问题。我们建议所有用户下载最新版本！请记住更新您的 .env 文件！ [!提示] 问题征询： 我们欢迎您的反馈！如果您遇到任何错误或有功能请求，请打开问题！如果您想提交 PR，请查看我们的贡献指南。

快速总结

  • 配置 — 重构配置逻辑，以实现更流畅的 LLM/嵌入设置。后端秘密对前端隐藏。添加了更多搜索提供商。
  • RAG 管道 — 按 KB 选择不同的管道：LlamaIndex（直接）、LightRAG（图形）、RAG-Anything（多模式图形）。
  • Question Gen — 统一的 BaseAgent 架构，具有更直观的 UI。
  • 主页 — 将聊天记录保存到笔记本中。
  • 侧边栏 — 拖放重新排序+可自定义的左上角标签。
  • 杂项 — 各种错误修复和稳定性改进。

✨ 亮点

统一配置系统

完全重新设计了 LLM、嵌入、TTS 和搜索服务的配置管理： 主要特点：

  • 基于环境的机密：在 UI 中管理配置时将敏感的 API 密钥存储在 .env 中
  • {"use_env": "VAR_NAME"} 语法：引用环境变量而不在前端公开它们
  • 每服务活动配置：每个服务（LLM、嵌入、TTS、搜索）维护自己的活动配置
  • 无缝提供商切换：在前端添加新提供商而无需触及后端机密 新搜索提供商： |供应商|描述 | |:---|:---| |塔维利 | AI原生搜索API | |埃克 |神经搜索引擎 | |吉娜 |基于读者的网络搜索| |蛇 |谷歌搜索结果 API |

RAG 管道选择

根据您的速度/质量要求，为每个知识库选择最佳的 RAG 管道：

管道 指数类型 最适合 速度
骆驼索引 矢量（直接） 快速设置，简单文档 最快
LightRAG 知识图谱 一般文件，文字较多 快
RAG-任何东西 多模态图 学术论文、带有图表/方程的教科书 彻底

问题生成大修

使用统一的代理架构重构了问题生成模块： 后端更改：

  • 迁移到与其他模块一致的BaseAgent模式
  • 新的专业代理：RetrieveAgent、GenerateAgent、RelevanceAnalyzer
  • 具有相关性分类的单遍生成（无迭代验证循环）
  • 通过 Markdown 代码块提取改进了 JSON 解析 前端改进：
  • 带有阶段指示器的实时进度仪表板
  • 用于调试生成过程的日志抽屉
  • 更干净的问题卡布局和答案提交
  • “添加到笔记本”集成

主页增强功能

将聊天记录保存到笔记本：

  • 聊天界面新增“保存到笔记本”按钮
  • 自动将对话格式设置为 Markdown
  • 使用角色标签保留用户查询和助理响应

侧边栏定制

拖放导航：

  • 通过拖动对组内的侧边栏项目重新排序
  • 拖动操作期间的视觉反馈
  • 持久订单保存到用户设置 可定制描述：
  • Click 编辑侧边栏描述标签
  • 个性化您的工作空间身份

📦 发生了什么变化

核心基础设施

  • 添加了 src/services/config/unified_config.py — 集中配置管理器
  • 添加了 src/api/routers/config.py — 所有服务配置的统一 REST API
  • 重构网络搜索以支持多个提供商（src/services/search/）
  • 使用 LLM 错误框架增强错误处理

RAG系统

  • 使用定制嵌入适配器实施 LlamaIndexPipeline
  • 实现了纯 LightRAGPipeline 并完成了初始化
  • 在知识库创建/上传期间添加了管道选择（PR #129）
  • src/services/rag/factory.py中的工厂模式用于管道管理

问题生成

  • 与专门代理重构AgentCoordinator
  • src/agents/question/agents/中的新RetrieveAgent、GenerateAgent、RelevanceAnalyzer
  • 删除了迭代验证循环以加快生成速度
  • 添加了用于前端状态管理的 useQuestionReducer 钩子

前端更新

  • web/app/settings/page.tsx — 使用统一的配置 UI 完成重建
  • web/app/question/page.tsx — 带进度跟踪的新仪表板
  • web/app/page.tsx — 添加了“保存到笔记本”功能
  • web/components/Sidebar.tsx — 拖放+可编辑描述
  • web/components/AddToNotebookModal.tsx — 可重复使用的笔记本集成
