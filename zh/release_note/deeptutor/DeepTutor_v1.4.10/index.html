DeepTutor v1.4.10

修订 发布时间2026年6月21日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.06.21 v1.4.9 的部署和帐户后续操作：自助服务 带有头像的个人资料页面，一个可以无根运行的硬化容器故事 在单个端口后面，以及多用户部署中更严格的 MCP 工具访问。 适合所有人——一项行为更改仅限于非管理员用户 多用户模式。

多用户部署注意事项。 MCP 工具现在 默认拒绝 对于非管理员用户：普通用户无法再发现或加载 部署范围内的 MCP 主机工具，直到管理员授予特定工具名称 在他们的资助下。管理员不受限制，单用户/无身份验证安装 不受影响（他们的会话以管理员身份运行）。没有任何东西迁移，也没有任何东西 升级中断 — 如果您的非管理员需要 MCP 工具，请在 用户的授予。

新消息

带头像的个人资料页面

每个登录用户都会获得一个自助个人资料页面：选择一个内置图标 （带有颜色）或上传您自己的图片作为头像，查看您的帐户和角色， 并退出。然后您的头像会显示在侧边栏中，并且会出现一个管理环标记 管理员帐户一目了然。

在容器中运行 DeepTutor，无根就绪

一个新的 CONTAINERIZATION.md 导轨涵盖三种形状 - 普通 docker run、docker compose 以及 PocketBase sidecar，以及硬化的无根 Podman 路径（compose.yaml， 只读根文件系统，tmpfs 系统目录） — 加上 .env.example 来启动 从。前端现在根据请求将 /api/* 和 /ws/* 代理到后端 ** time**，因此浏览器只与一个端口 (:3782) 通信：没有烘焙 API URL 进入JS包后，没有启动sed。映射一个端口就完成了。

多用户模式下更严格的 MCP 工具访问

如上所述，非管理员用户现在无法关闭 MCP 工具，直到管理员 授予名称。拨款编辑器将 MCP 工具拨款与 内置工具白名单，因此您可以查看并准确设置每个用户可以访问的内容。

更安静的日志

例程 200s — /settings、/tools 的喋喋不休的前端轮询， /knowledge/list 和朋友们 - 不再淹没控制台。独角兽的 现在在 每个 启动路径上禁用每个请求访问日志（deeptutor start、启动器和 Docker 入口点）和单个中间件 仅表面非 200，那些实际上值得一看的。

修复

  • Client 身份验证状态在请求时通过新代理解析，这也 调整上传请求正文的大小（头像图像、附件）。
  • 对于未知颜色，头像渲染安全地回退而不是转动 看不见的； auth-status 获取已进行重复数据删除。
  • docker-compose.yml PocketBase 安装路径已更正。

升级注意事项

从 v1.4.9 插入：pip install -U deeptutor； Docker用户拉 ghcr.io/hkuds/deeptutor:latest。无需迁移，无需更改配置。 **仅限多用户部署：**如果您的非管理员用户依赖 MCP 工具， 为每个用户授予特定的工具名称——除非您这样做，否则它们将无法关闭。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.4.9…v1.4.10
