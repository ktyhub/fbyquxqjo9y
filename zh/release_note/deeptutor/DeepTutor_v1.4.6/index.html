DeepTutor v1.4.6

修订 发布时间2026年6月17日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.06.17 注意：文档仍在赶上这个版本，所以一些 页面可能尚未反映以下所有内容。 在 v1.4.5 之上进行了广泛的整合发布，组织了 围绕它所接触的四个表面：学习空间成为一个真实的 仪表板，知识中心获得新的检索引擎和外部 安装，设置打开文档解析、语音和媒体生成， 并且该平台收紧了每个用户的访问权限。直接升级 — 无需数据迁移。

新消息

学习空间

Space 现在是一个学习仪表板，可将您的工作整合在一起，并且 它周围的表面长大了：

  • 我的特工 — 将您本地的 Claude Code / Codex 聊天历史记录导入到 您可以继续与可恢复的代理交谈 (/space/agents)。一个参考的 成绩单得到客观的简报和第三方框架，因此导师 叙述它而不是像你一样进行角色扮演。
  • 内存被提升到它自己的顶级目的地（/memory） 被埋在工作空间中，L1/L2/L3 视图完好无损。
  • 合作伙伴对话现在与聊天在同一管道上流入内存。
  • 在 /space/skills 内联安装 EduHub 的社区技能。

知识中心

/knowledge 被重建为 知识中心 控制台 - 引擎卡 纯入口点和配置移至每个引擎的详细信息页面：

  • 新的检索引擎加入 LlamaIndex：GraphRAG (microsoft/graphrag)， PageIndex（云推理检索），以及内置的LightRAG 后端——根据知识库选择。
  • 链接知识库 — 将知识库指向已构建的索引文件夹作为 只读挂载，完全跳过摄取。
  • Obsidian — 连接实时保管库作为代理知识功能， 直接读写笔记。

设置

新的可配置服务，每个服务都有自己的设置页面，并且全部关闭，直到 你设置它们：

  • 文档解析 — 可插入解析层（MinerU、Docling、MarkItDown） 具有内容寻址缓存（/settings/document-parsing）。 MinerU 添加了一个 云/本地双后端（/settings/mineru），现在提取问题类型， 难度及答案。
  • 语音 — 扬声器按钮，具有三态自动播放回复 (TTS) 和 用于听写 (STT) 的作曲家麦克风，位于 /settings/tts 和 /settings/stt。
  • 图像和视频生成 — 可配置的模型目录连接到聊天中 工具（/settings/image、/settings/video）。
  • 围绕扩展的表面重建设置导航。

其他

  • 每用户访问门控 — LLM 功能对没有权限的用户锁定 分配的模型，侧边栏锁和服务器端门始终处于状态 协议。
  • 解决被重建为聊天循环上的一项功能，并带有每步门 以及中途失败的后备措施，强制优雅地完成而不是 整个转弯失败。
  • 登录接受用户名（不仅仅是电子邮件），显示错误登录错误 内联而不是静默重新加载，并修复了 NEXT_PUBLIC_AUTH_ENABLED 标志。
  • CLI 获得 deeptutor skill 命令 - 浏览器登录以及发布/更新 为了你自己的技能。
  • 上下文选择器被打磨到具有实时预览的共享外壳上，并且 引用前数学渲染修复可防止 $…$ 被引用破坏 链接化。

升级注意事项

  • 从 v1.4.5 直达：pip install -U deeptutor； Docker用户拉 ghcr.io/hkuds/deeptutor:latest。无需迁移——现有数据按原样加载。
  • 为每个用户分配一个模型，以便解锁他们的能力；管理员管理这个 从模型目录。
  • 新引擎和服务可供选择：GraphRAG 需要额外的 (pip install 'deeptutor[graphrag]')、文档解析需求 deeptutor[parse]，语音/图像/视频需要其型号目录 配置。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.4.5…v1.4.6
