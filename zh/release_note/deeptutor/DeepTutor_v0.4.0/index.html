DeepTutor v0.4.0

🚀 DeepTutor v0.4.0 Release Notes

发布日期： 2026.01.09 我们很高兴推出 DeepTutor v0.4.0！此版本带来了新主页、对 LLM 和嵌入提供商的扩展提供商支持、RAG 模块解耦、Web 改进以及一系列小的改进。

🚧 可能的问题： Docker 部署和本地 LLM/嵌入设置（Ollama、LM Studio）可能仍然存在兼容性问题。我们正在积极致力于改进。 欢迎提出问题和 PR！ → 打开问题 | 投稿指南

⚠️ 重大变更：环境配置

环境变量名称已更新。 请根据 .env.example 更新您的 .env 文件。

旧变量 新变量 笔记
OPENAI_API_KEY LLM_API_KEY 现在与提供商无关
OPENAI_API_BASE LLM_HOST 为清楚起见已重命名
OPENAI_MODEL LLM_MODEL 为清楚起见已重命名
EMBEDDING_DIM EMBEDDING_DIMENSION 全字命名
（硬编码） BACKEND_PORT 现在可在 .env 中配置（默认值：8001）
（硬编码） FRONTEND_PORT 现在可在 .env 中配置（默认值：3782）
新的必需变量：
  • LLM_BINDING — 提供商类型：openai、ollama、azure_openai、anthropic 等。
  • EMBEDDING_BINDING — 提供商类型：openai、ollama、jina、cohere 等。 新的可选变量：
  • SEARCH_PROVIDER — Web 搜索提供程序：perplexity（默认）或 baidu
  • BAIDU_API_KEY — 用于百度人工智能搜索 (百度AI搜索)
  • NEXT_PUBLIC_API_BASE — 用于远程/LAN 访问的前端 API URL（例如，http://192.168.1.100:8001）

💡 远程访问： 如果从网络上的其他设备访问 DeepTutor，请将 NEXT_PUBLIC_API_BASE 设置为您服务器的 IP。如果未设置，则默认为 http://localhost:8001（仅限本地计算机）。 📌 所需操作： 将 .env.example 复制到 .env 并在升级之前更新您的配置。

✨ 亮点

🔌 多提供商法学硕士和嵌入支持

从仅限本地扩展到完整的提供商生态系统：

法学硕士提供者 嵌入提供商
OpenAI、Anthropic、Azure OpenAI OpenAI、Azure OpenAI、Jina AI
Ollama、Ollama Cloud、LM Studio Cohere，Ollama，LM Studio
Groq、OpenRouter、DeepSeek、Gemini HuggingFace（兼容 OpenAI）
src/services/embedding/adapters/ 中基于适配器的新架构可以轻松添加新的提供程序。

🧩 RAG 模块解耦

新的 RAGService 类提供了一个统一的、与提供商无关的接口：

from src.services.rag import RAGService

service = RAGService()  # Uses RAG_PROVIDER env var (default: raganything)
await service.initialize("my_kb", ["doc.pdf"])
result = await service.search("query", "my_kb")

📌 目前支持 RAG-Anything (MinerU + LightRAG)。更多后端即将推出！

🌙 深色模式和 UI 检修

  • 主题切换，具有系统偏好检测和本地存储持久性
  • 可折叠侧边栏，具有仅图标紧凑模式
  • 设置页面重建：基于类别的组织环境变量管理
  • 所有页面一致的深色模式样式

⚙️ 集中配置

新款settings.py采用pydantic-settings进行统一配置：

类别 环境变量
法学硕士 LLM_BINDING、LLM_MODEL、LLM_HOST、LLM_API_KEY
嵌入 EMBEDDING_BINDING、EMBEDDING_MODEL、EMBEDDING_HOST、EMBEDDING_API_KEY、EMBEDDING_DIMENSION
抹布 RAG_PROVIDER
语音合成 TTS_MODEL、TTS_URL、TTS_API_KEY、TTS_VOICE
搜索 PERPLEXITY_API_KEY
通过 /api/settings/env 进行运行时更新，并具有自动 .env 持久性。

📦 发生了什么变化

核心基础设施

  • 添加了 settings.py 和 pydantic-settings 以进行集中配置管理
  • 增加了src/core/llm_factory.py与统一的llm_complete()功能
  • 添加了 /api/embedding-providers 路由器用于嵌入配置 CRUD
  • 添加了用于运行时环境管理的 /api/settings/env 端点

服务模块重组（src/services/）

services/
├── embedding/          # 🆕 Adapter-based embedding providers
│   ├── adapters/       # Provider implementations
│   │   ├── base.py, openai_compatible.py, jina.py, cohere.py, ollama.py
│   ├── client.py       # Unified embedding client
│   ├── provider.py     # Provider manager (singleton)
│   └── provider_config.py  # Multi-provider config persistence
├── llm/                # LLM configuration & client
├── rag/                # 🆕 Decoupled RAG system
│   ├── service.py      # Unified RAGService entry point
│   ├── factory.py      # Pipeline factory
│   ├── pipelines/      # Backend implementations
│   │   └── raganything.py, lightrag.py, llamaindex.py, academic.py
│   └── components/     # Modular RAG components
│       ├── chunkers/   # Text chunking strategies
│       ├── parsers/    # Document parsers (PDF, Markdown, Text)
│       ├── embedders/  # Embedding wrappers
│       ├── indexers/   # Vector & Graph indexers
│       └── retrievers/ # Dense & Hybrid retrieval
├── prompt/             # PromptManager singleton
├── tts/                # TTS configuration
└── setup/              # Initialization utilities

  • 🆕添加了带有功能概述的主页（web/app/page.tsx）
  • 🆕 重建历史页面 (web/app/history/page.tsx)，并改进活动视图
  • 添加了带有主题实用程序的 web/lib/theme.ts（initializeTheme()、setTheme()）

  • 为SSR主题水合添加了web/components/ThemeScript.tsx
  • 为历史页面添加了 web/components/ChatSessionDetail.tsx
  • 重构Sidebar.tsx，具有可折叠模式
  • 使用环境变量管理重建 settings/page.tsx

IdeaGen 改进

增强的 4 阶段工作流程：宽松过滤 → 探索想法 → 严格过滤 → 生成语句

🐳 Docker

简化的单容器部署：

docker compose up -d
# Exposes: backend (8001), frontend (3782)
# Volumes: ./config (ro), ./data/user, ./data/knowledge_bases

通过 NEXT_PUBLIC_API_BASE_EXTERNAL 支持云部署。
