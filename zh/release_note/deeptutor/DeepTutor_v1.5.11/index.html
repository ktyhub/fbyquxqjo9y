DeepTutor v1.5.11

修订 发布时间2026年8月9日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.08.10 v1.5.10 是关于请求阻塞下的路径；这是关于仍在写答案时发生的事情。与用于消失在跟踪中的工具调用共享一轮的散文，被截断的一代被读取为模型决定它已经完成，并且本地索引位于事件循环上的所有其他需要。设置条也停止重述模型页面已经告诉你的内容，并开始显示其他没有做的一个数字：DeepTutor 实际在内存中的成本是多少。直接插入——无需迁移，无需重新索引。

新消息

工具调用周围的文本不再丢失

DeepSeek 的 Anthropic 兼容端点将面向用户的散文和 DSML 工具调用标记交错在单个内容流中。旧的处理是全有或全无：一旦一轮的内容通道显示 DSML 标记，该轮的其余部分就会转移到思维通道，因此模型围绕其调用编写的任何解释都会从答案中消失。流过滤器现在仅逐步删除 DSML 信封和 invoke 块 — 呼叫流之前、之间和之后的文本并作为回复的一部分保留。不完整的调用会在刷新时逐字释放而不是被吞噬，并且 512 个字符的上限意味着普通散文中的杂散 < 无法使实时流永远等待结束括号。

DSML 数组和对象参数正确解码

DeepSeek 基本上标记了包含的每个 DSML 参数 string="true"、JSON 数组和对象，因此容器参数以 JSON 字符串的形式到达工具。参数解码现在参考声明的工具模式：当有效负载实际匹配时，解析模式类型为 array 或 object 的参数，并且提供者的字符串合同仍然在其他地方获胜。即使提供程序拒绝本机 tools 并且循环回退到 DSML（这正是解析器需要它的时候），架构目录也会保留。

被截断的一代要求延续

length 完成是一个不完整的生成，而不是模型选择停止 - 但它被视为完成，因此回复在句子中结束。现在，循环保留可见前缀并请求继续，而组装的答案将前缀传递到持久性和 SDK。重新调整回合预算以确保这一安全：探索回合，然后是一个小的有界结算窗口，然后是单个无工具硬精加工，因此重复截断和畸形工具循环共享 exploration + 4 的一个绝对上限。

设置中的实时内存使用情况

设置状态栏包含后端、LLM、嵌入和搜索——其中三个重申了模型和聊天页面已经拥有的内容。现在，它包含没有设置页面显示的两个运行时事实：后端是否已启动，以及整个 DeepTutor 进程树中的常驻内存（后端、Next.js 服务器以及任何处于活动状态的沙箱和子代理 CLI），以及每个进程的内联分割和一个压力点，该压力点在超过限制的三分之二时会变成琥珀色。由新的 GET /api/v1/system/memory 提供服务； psutil 读取树并通过 /proc 后备延迟导入，因此缺少轮子会花费条带而不是应用程序。非管理员和无法读取树的平台获得 {available: false} 并且没有条带。

本地 LightRAG 索引不再拖延其他一切

RAG-Anything 的本地存储后端从异步方法内部进行同步图形合并和 JSON 序列化，因此在服务事件循环上索引文档会在其持续时间内冻结不相关的 API 和 LLM 工作。索引现在在工作线程自己的事件循环上运行，通过一个窄桥将 LLM、视觉和嵌入调用转发回请求循环，并携带调用者上下文的副本，以便请求本地模型和用户配置保持可见。远程 LightRAG 服务器不受影响。

掌握来自于持续存在的问题，而不是模型的复述

提出的问题现在投射到一个小型公共合同中——提示、类型和选项标签/正文图——通过注册、演示和评分共享，预期答案保留在服务器端。 ask_user 呈现持久状态，而不是显示模型重新创作的数据，因此学习者看到的选择就是将被评分的选择。注册验证测验形状，而不是默默地接受矛盾的形状：从有效负载推断出缺失的类型，short/open 问题拒绝选项，选择问题必须带有真实选项主体，而不是裸露的 A/B/C 标签。

什锦

  • 连接的知识库诚实地回答本地文件。 链接的外部资源没有 DeepTutor 管理的 raw/ 目录；列出其文件会返回一个空集合，而不是创建一个集合，并且需要本地文件的端点会返回一个显式的 409。
  • 生成的输出工件在请求范围内提供服务。 新的 /api/outputs 端点在一个操作中解析并授权路径，并且在没有请求用户时以 404 失败关闭，因此身份验证上下文回归无法将管理员的工件交给普通请求。
  • 可视化 iframe 收缩和增长 - 高度桥测量主体内容而不是主机已经拉伸的根高度，并将报告合并到一个动画帧中。
  • 聊天页面的模型列表只获取一次。 选项加载移动到带有单次重复数据删除的钩子中，因此并发安装和选项卡焦点刷新不再堆叠相同的请求。

升级注意事项

pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。没有架构更改，没有重新索引，没有迁移。

  • psutil 是一个新的依赖项，随升级一起安装。它是在 /proc 后备之后延迟导入的 - 如果您的环境无法提供它，则内存条将保持隐藏状态，并且不会发生任何其他变化。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.5.10…v1.5.11
