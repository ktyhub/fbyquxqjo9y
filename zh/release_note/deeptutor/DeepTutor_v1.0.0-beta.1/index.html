DeepTutor v1.0.0-beta.1

🚀 DeepTutor v1.0.0-beta1 Release Notes

发布日期： 2026.04.04 我们很高兴地宣布DeepTutor v1.0.0-beta1——全新 DeepTutor 架构的第一个测试版。这是一次彻底的重写，将 DeepTutor 从单一的 RAG 导师转变为一个代理原生学习平台，具有两层插件模型（工具 + 功能）、三个统一入口点（CLI / WebSocket / Python SDK）和完全重建的 Web 应用程序 shell。更多惊喜等你来发现！

⚠️ 测试版通知： 这是 v1.0.0 的 测试版 1。核心架构是稳定的，但一些 UI 交互和边缘情况工作流程可能仍然包含错误。感谢您的耐心等待，并欢迎通过问题 报告错误。 📌 知识库注释： 在此版本中，RAG 管道已 简化为仅 LlamaIndex。 LightRAG 和 RAG-Anything 管道及其相关知识库内容已被 暂时删除 以专注于稳定性。它们将在即将发布的版本中重新引入。 [!提示] 征求反馈： 据了解，一些旧功能未包含在最新版本中。如果您有任何有用的意见、遇到任何错误或有任何功能请求，请打开问题！也欢迎 PR——请参阅我们的贡献指南。 差异范围： main...dev（更改了 903 个文件，插入了 92,701 个，删除了 73,749 个）

快速总结

  • 架构 — 使用代理本机运行时（工具 + 功能）从 src/ 完全重写为 deeptutor/ + deeptutor_cli/。
  • 入口点 — 三个统一入口点：独立 CLI (deeptutor)、WebSocket API (/api/v1/ws) 和 Python SDK 外观。
  • 功能 — 五种内置功能：chat、deep_solve、deep_question、deep_research、math_animator。
  • 工具 — 七个 LLM 可调用工具：rag、web_search、code_execution、reason、brainstorm、paper_search、geogebra_analysis。
  • Web 应用程序 — 使用工作区/实用程序路由组、新的 Playground、Co-Writer、Agents 和 Guide 页面重建 Next.js 应用程序。
  • TutorBot — 支持 12 个消息平台的多渠道机器人代理。
  • 基础设施 — SQLite 支持的会话持久性、转向运行时、提供商级 LLM 流量控制和遥测。

✨ 亮点

🏗️ 代理本机运行时（工具 + 功能）

引入了一个两层插件模型，将工具执行与高级代理工作流程分离：

  • 核心合约： ToolProtocol、CapabilityProtocol、UnifiedContext、StreamEvent 和 StreamBus — 所有运行时执行的基础。
  • ChatOrchestrator： 具有两个注册表的中央协调器：
    • ToolRegistry — 工具发现、OpenAI 风格的模式导出和执行。
    • CapabilityRegistry — 功能路由、清单管理和阶段感知流。

🖥️统一入口点：CLI / WebSocket / Python SDK

三个入口点共享一个 ChatOrchestrator 运行时：

切入点 描述
CLI (deeptutor) 基于打字机的 CLI，带有子命令：run、chat、bot、kb、memory、session、notebook、plugin、config、provider、serve
WebSocket (/api/v1/ws) 具有回合生命周期的统一端点：start_turn、subscribe_turn、subscribe_session、resume_from、cancel_turn
Python SDK (deeptutor.app.facade) SDK 式集成的程序化外观

🧠 能力层

五种内置功能，每种功能都有一个多步骤代理管道：

能力 阶段 描述
chat 回应 默认工具增强对话
deep_solve 计划→推理→写作 多阶段问题解决
deep_question 构思→评估→生成→验证 具有跟进模式的智能问题生成
deep_research 搜索→分析→综合→报告 具有报告生成功能的多主体研究
math_animator 分析 → 设计 → 代码生成 → 审查 → 渲染 基于Manim的数学概念视频生成

paper_search arXiv 学术论文搜索

🤖 TutorBot — 多渠道机器人代理

新的自主机器人系统 (deeptutor/tutorbot/) 将 DeepTutor 引入消息传递平台：

  • 12 个渠道： Telegram、Discord、Slack、企业微信 (WeCom)、飞书、钉钉、WhatsApp、Matrix、QQ、电子邮件、MoChat
  • 代理循环： 工具增强的 LLM 循环，具有内存、子代理生成和团队协作功能
  • 内置工具： Shell、文件系统、Web、MCP、cron 和消息工具
  • 后台服务： 心跳健康检查和基于 cron 的计划任务

🔒 安全与稳定

  • 代码执行安全： 基于 AST 的导入/调用防护，具有可配置的允许列表。
  • LLM 流量控制： 提供商级断路器、错误率跟踪和重试机制。
  • 启动验证： 启动时检查功能与工具的一致性。

🧪 测试覆盖率

跨所有主要层的 53 个以上新测试文件：运行时（工具/功能注册表、协调器）、服务（LLM 提供程序/工厂/路由/遥测、RAG 管道、嵌入、搜索、会话、内存、笔记本、配置）、代理（聊天、解决、问题、math_animator）、API（知识、内存、解决、WebSocket 运行时）、CLI 和工具（代码执行器）安全）。

⚠️ 重大变更

  • 封装布局： src/ → deeptutor/ + deeptutor_cli/。旧的 src/ 目录完全删除（140 个文件）。
  • 软件包重命名： ai-tutor → deeptutor，版本 1.0.0。
  • 运行时模型： 能力原生编排。默认为chat；通过 run 命令或 WebSocket 显式选择深度模式。
  • 网页路线： 所有页面均在 (workspace)/ 和 (utility)/ 下重新组织。旧页面（/solver、/question、/research、/ideagen、/notebook、/history）已删除。
  • RAG 管道： 仅 LlamaIndex 可用。 LightRAG 和 RAG - 暂时删除的任何内容。
  • 数据布局： 运行时数据集中在 data/user/workspace/... 下。
  • 依赖关系： 分为分层需求：cli.txt、server.txt、dev.txt、math-animator.txt、tutorbot.txt。
