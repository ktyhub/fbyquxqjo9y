DeepTutor v1.3.10

修订 发布时间2026年5月10日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.05.10 v1.3.10 是针对 v1.3.9 之后报告的问题的重点可靠性版本。 它恢复更顺畅的远程 Docker 访问，使自签名 LLM 端点正常工作 在 SDK 支持的提供商中保持一致，保护代码片段免遭引用 重写 Matrix E2EE 并将其拆分为显式选择加入依赖项。

变更架构图

亮点

远程 Docker 和 CORS 恢复

  • 远程单用户 Docker 再次开箱即用 - 当 AUTH_ENABLED=false，DeepTutor 现在通过 HTTP/HTTPS 接受浏览器来源，因此 LAN 或远程服务器前端不再影响 v1.3.8/v1.3.9 CORS #463 中报告了回归。
  • 经过身份验证的部署保持明确 - 当 AUTH_ENABLED=true、CORS 时 仍然需要通过 CORS_ORIGIN 或 CORS_ORIGINS 建立具体的许可名单， 保留凭证授权安全边界。
  • 支持多个部署源 - CORS_ORIGINS 接受逗号 或换行符分隔值，并且两个 Docker Compose 文件都通过该设置 到后端容器。
  • 设置不再删除网络标志 - CORS_ORIGIN、CORS_ORIGINS 和 DISABLE_SSL_VERIFY 是规范 .env 写入顺序的一部分。

提供商 TLS 和渲染修复

  • DISABLE_SSL_VERIFY 现在到达 OpenAI SDK 路径 - OpenAI 兼容， Azure OpenAI、执行器、TutorBot 和旧版嵌入 SDK clients 均接收 当该标志启用时共享 httpx.AsyncClient(verify=False)，修复 #464 中报告的自签名 HTTPS LLM 端点。
  • 生产仍然阻止不安全的 TLS 绕过 - ENVIRONMENT=prod 或 ENVIRONMENT=production 拒绝 DISABLE_SSL_VERIFY，并发出一个警告 已登录非生产用途。
  • 代码块保持数组索引完整 - 现在 Markdown 引用链接 在重写引用之前屏蔽围栏和内联代码，因此 values[0] 保留 代码而不是成为 #references 引用链接 (#468)。

矩阵安装兼容性

  • Matrix 默认不再安装 E2EE - 标准 matrix 额外和 requirements/matrix.txt 现在使用普通 matrix-nio，避免了 macOS Python 3.14 和 Apple 上出现的 python-olm / libolm 构建失败 铿锵 21 (#462)。
  • 加密房间是一个明确的附加组件 - 安装 deeptutor[matrix-e2e] 或 requirements/matrix-e2e.txt 当需要 E2EE 支持且 libolm 时 可用。
  • 运行时故障更清晰 - Matrix 默认为非 E2EE 模式，并且 现在无需加密依赖即可启用 E2EE，从而引发可操作的安装 消息而不是在导入时失败。

多用户运行时兼容性

  • 默认工作空间路径在用户范围之外保持稳定 - 当没有电流时 多用户上下文处于活动状态，路径解析回退到默认数据 工作区而不是强制管理范围。
  • 旧版测试和 Monkeypatch 挂钩仍然可用 - 会话和设置 路由器保留测试和旧集成所使用的兼容性垫片。
  • 本地代理工件被忽略 - .claude/ 现在已从 Git 中排除，因此 本地工作树和代理元数据不会意外进入版本。

测试

  • 添加了针对未经身份验证的远程来源和经过身份验证的 CORS 设置测试 明确的允许名单。
  • 添加了跨提供商核心、Azure 的共享 OpenAI SDK HTTP-client 测试 执行器、TutorBot 和嵌入适配器。
  • 添加了针对散文引用、围栏代码、内联代码的 Markdown 显示测试， 和明确的反引号引用。
  • 添加了 Matrix 依赖性拆分测试，以保持默认安装免费 matrix-nio[e2e]。
  • 重新运行目标 Python 测试、Web 节点测试、Ruff 检查和 diff 空白 验证发布补丁。

升级注意事项

  • 如果您使用 AUTH_ENABLED=false 运行远程 Docker，则不需要额外的 CORS 设置 普通 HTTP/HTTPS 浏览器源所需的。
  • 如果您使用 AUTH_ENABLED=true 运行共享或经过身份验证的部署，请设置 例如，CORS_ORIGIN 或 CORS_ORIGINS 到确切的前端原点 https://learn.example.com。
  • 仅将 DISABLE_SSL_VERIFY=true 用于本地、自签名或气隙测试 LLM 终点。它在 ENVIRONMENT=prod 中仍然被阻止，并且 ENVIRONMENT=production。
  • Matrix 安装现在默认为非 E2EE。对于加密的矩阵房间， 安装 .[matrix-e2e] 或 requirements/matrix-e2e.txt，确保 libolm 是 存在，并在矩阵通道配置中设置 e2ee_enabled=true。
  • 如果您之前安装.[matrix]只是为了获得非加密的Matrix 消息传递，此版本后重新安装不应再需要本机 libolm 构建工具。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.3.9…v1.3.10
