DeepTutor v1.6.0

小版本 发布时间2026年8月27日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.08.27 v1.5.17 将合作伙伴个性化，让知识库跟踪 GitHub。 v1.6.0 连接学习工作区的其余部分：忠实源阅读、课程和小导师线程、提问模式、有界网络源同步以及不共享读者学习状态的共享书籍。现有数据保持不变；多用户管理员只需在需要的地方授予图书访问权限。

新消息

沉浸式阅读成为一名完整的读者

EPUB 在忠实于源的视图中加入了 PDF，具有格式感知的轮廓和保存的阅读位置。 W3C 文本选择器通过重排保留突出显示，Recogito 呈现注释，提取的文本视图获得持久的版式和颜色控制，安装的阅读扩展仅通过有界协议接收经过验证的可见文本或选择。

课程、小导师、提问

学习空间现在将对话组织到课程中，并具有固定、存档、移动、过滤和嵌套导师线程控件。选择对话中的文本以打开一个独立的、基于源代码的 Little Tutor 线程，该线程位于其父线程下方并继承课程。 提出问题从情境感知澄清卡开始，然后根据答案完成原始请求。

知识库跟踪文档站点

除了 GitHub 存储库之外，知识库还可以注册具有显式爬网深度和页数限制的文档 URL。在重新索引之前按需同步哈希差异添加、更改和删除页面。 Serply 添加了网络、新闻和学者搜索模式，而兼容的 OpenAI Responses 模型可以使用其本机服务器端网络搜索。

共享书籍让学习保持私密

管理员可以将每个用户的规范图书共享为 none、read 或协作 edit，单独控制个人图书创建，并将删除保留为仅限管理员。进度、书签、测验尝试、页面聊天链接和可审阅的学习捕获收件箱对每个读者都是保密的。共享编辑使用修订检查，因此过时的编辑器会刷新而不是覆盖协作者。

阅读、辅导和长期可靠性

阅读器大纲和顺序导航保持其位置，格式错误或超时的阅读扩展保持隔离，注释锚点在标题和重排中仍然存在。选择导师的基础和测验后续行动仍然持久； Mastery 拒绝纯文本测验回退，并将澄清与答案区分开来；对话压缩保持在有限的预算内，并且解码的不可见 Unicode 控件不再泄漏到显示中。

提供商和平台强化

llama.cpp 报告其真实上下文窗口，Kimi 编码模型接收兼容参数，LightRAG 保留非对称嵌入上下文，Codex TLS 故障保持故障关闭。 Windows 运行器、工具、路径和测试兼容性得到了广泛的清理。发布工作流程现在会在误导性或非版本标签取代最新稳定版本之前拒绝它们。

升级注意事项

pip install -U deeptutor; Docker用户拉动ghcr.io/hkuds/deeptutor:latest。无需手动迁移或重新索引。

  • 共享管理书籍默认无访问权限。现有个人书籍保持私密且不变。在多用户部署中，打开 /admin/users，展开用户，并仅为他们应该阅读或编辑的管理员图书配置图书访问权限。
  • 共享编辑是乐观的。 如果其他编辑首先推进书籍修订，请刷新书籍并再次应用更改； DeepTutor 不会默默地覆盖较新的版本。
  • Web 和 GitHub 源仍然是选择加入的。 在您注册源并运行同步之前，现有知识库不会改变。
  • 搜索仍然是可选的。 在 deeptutor init 期间选择 Serply 或稍后在 设置 → 模型 → 搜索 下配置它；现有的搜索设置继续有效。
  • 英文和中文指南已在deeptutor.info上一起更新。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.5.17…v1.6.0
