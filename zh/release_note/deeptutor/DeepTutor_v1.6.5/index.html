DeepTutor v1.6.5

修订 发布时间2026年9月6日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.09.06 v1.6.5 为 DeepTutor 提供了一个您自己的文件夹供您使用。您将其指向一个目录，助手可以浏览、阅读和搜索已有的内容，而它生成的所有内容都会落在一个可预测的位置 - 任何离开该位置的内容都需要您的批准。围绕这一点，代码执行折叠成一个工具，掌握路径学习何时允许教导和重新设计，设置最终区分“未配置”和“损坏”。直接用于本地安装； Docker 用户应阅读下面的工作区安装说明。

新消息

您选择的内容工作区

将 DeepTutor 指向任何文件夹，它就会成为整个会话的工作目录。助手可以列出、阅读和搜索其中的内容，因此您无需上传任何内容即可使用自己的材料。生成的文件落在 outputs/ 中，将文件从 outputs/ 移动到文件夹的其余部分是一个明确的、用户批准的步骤，而不是悄悄发生的事情。从“设置”或使用 deeptutor workspace show、set 和 reset 进行管理。

一个工具运行代码

code_execution 和 exec 是两种工具，完成一项工作。它们现在是一个采用 Python、C、C++ 或 shell 的单个 exec。每个调用轮流共享一个工作目录和一个依赖环境，因此后面的调用可以重新打开并修改先前调用写入的文件，而不用重新开始。

掌握路径知道它处于哪种模式

现在，研究目标在三种模式之间切换——设计大纲、推进研究和审查——可用的工具也随之而来。只有outline可以改变地图，所以导师不能在课中悄悄地重写你的计划；只有study和review可以对你进行检查，并且在大纲真正达成一致之前都不会开始。提出的问题作为一张结束回合的卡片到达，因此回答是一种有意的行为。

设置区分“未设置”和“已损坏”

概述将每个功能分级为阻止程序、警告或建议，并且每一行记录安装是否真正依赖于它。您从未配置过的可选视频模型不再报告为故障；您“确实”选择了一个解析器，但它不起作用。该矩阵仅包含身份、布尔值和原因代码 - 提供程序 URL、模型名称、凭据和异常文本保留在服务器上，并且永远不会调用模型提供程序来构建它。

问题在写的时候就出现了

过去，一张 ask_user 卡会在介绍它的散文几秒钟后立即到达。现在，该卡片会显示其简介，并在模型写入选项时增加其选项，因此在它询问您某些内容时，转弯不再保持沉默。

您可以保留的视频学习

连接的 Invidious 帐户拥有自己的适配器，转录提示在播放移动时保持可见，带时间戳的笔记导出到 Markdown。视觉学习板收集课程产生的内容。

知识库固定其索引模型

LightRAG 知识库记录哪些模型对它们建立了索引，并让您固定每个库的这些模型，因此重新索引不会默默地改变现有索引背后的嵌入。

网络上的子代理

强化的远程 Hermes 后端连接本地子代理线束，因此所咨询的代理可以在本机以外的其他地方运行。

修复

中文 Markdown 在流式传输时保留其原始内容；不安全的网络搜索标题和片段被过滤； DeepSeek 推理重播 Responses 回合中的 400 会回退而不是回合失败；设置在其自己的窗格内滚动；旧版 Mastery /study URL 重定向至 /sessions；测验卡文本解码 unicode 转义；恢复阅读材料的延迟加载；更新时可以正确检测源签出。

升级注意事项

运行pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。设置、书籍、课程和学习数据不需要手动迁移。

  • code_execution 工具消失了 — 它的工作转移到了 exec 中。名为 code_execution 的自定义提示、技能或插件应使用 language 来调用 exec。
  • Docker 工作空间挂载。 容器现在需要稳定路径 /workspace 处的内容工作空间。在python scripts/docker_compose.py up -d之前设置DEEPTUTOR_WORKSPACE_HOST=/absolute/host/folder以选择主机文件夹；省略它保留 ./data/user/workspace。帮助程序会为您创建文件夹及其 outputs/，因此绑定挂载不是 root 拥有的。
  • **沙盒跑步者看到的更少。**它不再安装data/users；它接收只读的 /workspace 和可写的 /workspace/outputs，以 DEEPTUTOR_RUNNER_ALLOWED_WORKDIRS 为界。执行的代码无法再访问另一个帐户的设置、聊天历史记录或知识库。
  • 多用户部署共享已安装的工作区。 当设置 DEEPTUTOR_WORKSPACE_ROOT 时（每个提供的 Compose 文件都会设置它），一个文件夹是每个帐户的内容工作区，并且路径在“设置”中显示为锁定。保留其未设置以保留每个用户的工作空间。
  • 导入 deeptutor.config.schema、.defaults、.accessors 或 .constants 的扩展必须移至公共设置界面；这些模块已被删除。
  • 英文和中文指南已在deeptutor.info上一起更新。 全Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.6.4…v1.6.5
