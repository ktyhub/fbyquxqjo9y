DeepTutor v1.3.8

修订 发布时间2026年5月7日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.05.08 v1.3.8 将 DeepTutor 的可选多用户模式带入主发布系列。 它保持本地单用户安装不变，同时添加经过身份验证的共享 具有隔离的用户工作区、管理员管理的访问权限和更清晰的部署 部署指导。

变更流程图

亮点

多用户工作区

  • 身份验证可以控制共享部署 - 启用 AUTH_ENABLED 添加登录、注册、JWT 会话和第一用户管理流程。
  • 每个用户都获得独立的数据 - 普通用户在 multi-user/<uid>/ 具有独立的聊天记录、内存、笔记本和 知识库，而管理员则保留主要工作区。
  • 管理员授予控制访问权限 - /admin/users 允许管理员创建用户并 分配允许的模型配置文件、知识库、技能和复制空间 而不暴露 API 密钥。

更安全的运行时边界

  • 知识和 RAG 保持范围 - 分配的知识库可见 徽章和非管理 RAG 调用不再默默地回退到管理数据。
  • 模型路由荣誉授予 - 非管理员聊天轮流使用指定的模型 如果没有可用的法学硕士，则会提前失败。
  • 为用户编辑设置 - 非管理设置显示主题、语言、 和模型摘要，而提供者机密和端点仍仅供管理使用。

部署和用户界面

  • 包括前端身份验证路由 - /login、/register、身份验证感知 中间件、注销控件和管理导航都连接到 Web 应用程序中。
  • 多用户文档现在是一流的 - 自述文件和翻译自述文件 文档设置、工作区布局、审核日志、环境变量和生产 注意事项。
  • 可选的 PocketBase 仍然记录在案 - PocketBase 仍然可以用作 sidecar 路径，但真正的多用户部署应该离开 POCKETBASE_URL 取消设置并使用内置的 JSON/SQLite 后端。

测试

  • 添加了身份迁移、首次管理员注册的多用户测试， 补助金、设置限制、范围界面首选项、技能访问以及 RAG 后备预防。
  • 添加了状态编辑覆盖范围，因此非管理员用户不会收到提供程序 模型或搜索端点详细信息。

升级注意事项

  • 现有本地安装保持单用户模式，除非 AUTH_ENABLED=true。
  • 对于真正的多用户部署，设置 AUTH_ENABLED=true，保留 POCKETBASE_URL留空，通过/register创建第一个admin，并分配 普通用户开始轮流聊天之前的模型。
  • 新的部署状态存储在multi-user/下；备份 data/ 和 升级共享实例之前的 multi-user/。
  • 多工作人员部署应谨慎引导第一个管理员，因为 第一个用户升级受到进程内锁的保护。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.3.7…v1.3.8
