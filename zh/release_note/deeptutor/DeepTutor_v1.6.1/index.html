DeepTutor v1.6.1

修订 发布时间2026年8月30日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.08.30 v1.6.0 连接学习工作区。 v1.6.1 是关于您每天接触的部分：模型配置分为您输入一次的凭据和按用途分配，设置成为导航器而不是卡片墙，侧边栏文件研究其主题下的对话并让您自己安排它，LightRAG 作为第一方引擎而不是通过包装器运行。直接插入——无需迁移，无需重新索引。

新消息

一键输入一次

模型配置是一层复制七次：每个服务都使用自己的凭据保存自己的配置文件，因此必须将单个 OpenRouter 密钥粘贴到五个单独的页面中。 连接现在持有一个供应商凭证 - API 密钥、版本、额外标头、可选端点覆盖 - 并将其链接到供应商可以提供的每一项服务。在一个地方旋转密钥即可到达每个链接的配置文件；删除连接是取消链接而不是擦除。想要每个服务有不同的密钥？根本不建立联系。

任务模型

没有人要求的这两个调用 - 在第一次交换后命名对话，并在作曲家下写下起点 - 不再需要在您为实际推理而选择的模型上运行。该目录包含一个 task 服务，其形状与 llm 完全相同，因此配置它是相同的行为，并且可以从 LLM 服务中引入提供者，而无需再次键入。留空（这是默认值），两个调用都将像以前一样解析。

设置是导航器，而不是中心

卡格不见了。持久的、可搜索的导航器可以到达 click 中的任何页面，模特/聊天/代理类别滚动为一页，草稿在导航中保存 - 现在保存草稿实际上可以保存。打开连接会显示它根据自己的配置文件提供的服务。

Mastery Path 归档自己的对话

学习对话已经是携带 mastery_path_id 的普通会话；侧边栏有它需要的一切，但没有使用它。现在，它们位于主题下方并在教程中打开 - 包含大纲、航路点标题和作曲家 - 而不是登陆 /home 并放弃所有三个。作曲家占位符由任务模型根据视图中的航路点编写，Tab 接受它。

你安排的侧边栏

功能页面折叠成更多组，导航和聊天历史记录都通过拖动重新排序 - 按下仅在移动几个像素后才变成拖动，因此行保持 clickable。该排列是一种视图首选项，并且存在于您排列它的计算机上。 ###阅读伴侣是聊天界面 打开文档旁边的面板现在由 /home 自己的组件（相同的消息列表、编辑器、活动抽屉和大纲）组装而成，而不是对它们进行 380 像素重新实现。阅读时保留的内容是实际内容：开放的材料、选定的段落、链接的对话以及针对视图页面编写的占位符。阅读会话也不再被排除在侧边栏之外，并分组在其收藏下。

LightRAG，第一方

LightRAG 引擎直接与 SDK 通信，而不是通过 RAG-Anything。 pip install 'deeptutor[rag-lightrag]' 现在仅拉动受支持的 LightRAG 版本，并且不再过渡性地拖拽 MinerU — MinerU 仍然是独立选择的解析器，并且强制冲突的 pdfplumber 引脚被解除。部分接受的入口和不确定的初始候选将被保留，而不是在追加时被丢弃。

修复

在 OpenAI 绑定上启用 DeepSeek Pro 原生 Web 搜索并关闭 Flash Thinking；人类SDK 1.x再次将temperature带到extra_body； Jina 嵌入检索角色受到表彰。扫描的 PDF 解释了为什么它们无法解析，而不是报告没有找到任何内容。身份验证秘密和令牌文件仅由所有者创建。当多个共享 slug、选择新发送的聊天分支并且 ask_user 有效负载不再泄漏 Unicode 转义时，ClawHub 安装的范围由发布者确定。

升级注意事项

pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。无需手动迁移或重新索引 - 现有模型配置文件保持不变，并且连接和任务模型都是选择加入的。

  • 如果您使用该引擎，请重新安装 LightRAG extra。 pip install -U 'deeptutor[rag-lightrag]' 将 raganything 替换为 lightrag-hku。现有索引按原样读取。如果您依赖 MinerU 附带此附加功能，请立即安装它 — 在 设置 → 文档解析 下选择它，然后配置其云模式或安装其本地 CLI。
  • 连接是可选的。 现有的每服务凭据保持不变，并继续按照以往的方式进行解析。仅当您需要一键服务多项服务时才建立连接；链接会在保存时镜像凭证，因此每个用户都会继续阅读独立的配置文件。
  • 英文和中文指南已在deeptutor.info上一起更新。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.6.0…v1.6.1
