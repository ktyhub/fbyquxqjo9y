DeepTutor v1.5.2

修订 发布时间2026年7月19日 来源HKUDS/DeepTutor 英文原文

发布日期： 2026.07.19 v1.5.1 之上的维护版本：聊天附件限制现在由您调整，PageIndex 通过推理整个文档进行检索，并且广泛的提供程序、书籍和知识库可靠性修复位于下方。直接插入——无需迁移。

新消息

可配置的聊天附件限制

附件大小上限和提取文本预算现在可在 设置 → 聊天 → 附件（仅限管理员）中编辑：每个文件和每轮上传上限，以及每个文档和每轮字符预算，存储在 system.json 中，并可由 CHAT_ATTACHMENT_* 环境变量覆盖。这也修复了大上传时无提示地断开连接的问题——WebSocket 帧上限现在是从总上限中得出的，而不是固定的默认值。降低限制对下一条消息生效；将大小上限提高到当前帧上限需要重新启动。

PageIndex 通过推理文档来检索

PageIndex 知识库现在通过内部 MCP 服务器进行查询，因此聊天通过对文档树进行代理工具调用来检索，而不是单个固定查找 - 对多步骤问题进行更清晰的页面级引用。 Ingestion 现在还接受更多格式：PDF、Office（Word / PowerPoint / Excel）、Markdown、纯文本和 CSV。

更广泛、更稳定的模型支持

  • 较新的 Anthropic 和 OpenAI 模型通过其官方 SDK 工作，包括 OpenAI Codex 本机工具调用。
  • 基于努力的克劳德模型自适应地驱动扩展思维，而不是固定的令牌预算，并且温度抑制模型集得到纠正，因此不受支持的模型不再出错。
  • 流式令牌使用量每次完成时都会计算一次，从而修复了夸大的使用量和成本核算。

更稳定的书籍和知识库

  • 陷入 GENERATING 或 PLANNING 的书籍页面会在失败时被拯救并重置，因此后台编译错误不再困扰页面。
  • 上传和文件夹同步的知识库状态更新，链接文件夹同步状态持续存在，并且所有管理器写入都是原子的 - 崩溃后不再有半写入的 JSON。

聊天和频道优化

带有单个可预测滚动条的全角聊天；对齐的作曲家和消息栏； Enter 发送已编辑的消息（Shift+Enter 表示换行符）；格式错误的 Markdown 链接不再使渲染器崩溃。 WeCom 合作伙伴与 SDK 1.0.8 保持一致，并且掌握路径新近度权重已恢复 (#618)。

升级注意事项

从 v1.5.1 插入：pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。无需迁移——现有的知识库、合作伙伴和掌握路径继续有效。新的附件默认值非常大（每个文件 20 MB，每回合 25 MB；200k / 150k 角色预算），因此除非您在 设置 → 聊天 → 附件 下调整它们，否则不会有任何变化；仅将大小上限提高到超过当前 WebSocket 帧上限需要重新启动。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.5.1…v1.5.2
