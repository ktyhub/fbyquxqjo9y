OpenHands cloud-1.41.0

这个项目是干啥的：一个让AI替你写和改代码的开发助手，能看懂整个代码仓库、也能在命令行里跑，给想提高效率的程序员用。

变更架构图

亮点

  • 感知 AST 的文件分块 — 文件上下文现在用 tree-sitter 语法树分块，而不是随意按文本边界切分，有助于在大文件进入 agent 上下文时保留函数、类和其他结构单元（#14699）。
  • 并行工具执行 — agent 新增 tool_concurrency_limit 设置用于并行工具调用，让多步骤工作流更快。会修改外部系统的集成应验证顺序假设，并设置合适的限制（#14929）。
  • 组织授权与 key 控制 — 组织获得管理员会话仪表盘、带权限回退的 user.role_id 超级角色，以及暴露调用方权限的 /organizations/{id}/me 端点。API key 现在支持 not_before/expires_at 有效期窗口和显式的 unbound 组织作用域，使短期凭据和跨组织访问更容易表达（#14846、#14937、#15048、#15085、#15096）。
  • 工作区快照与 trace 归因 — 生产环境 app-server 工作区现在会捕获初始状态，并在删除前归档；Laminar trace 包含仓库和分支元数据。这改进了删除后的恢复/可审计性，并把 agent 运行与被操作的代码版本关联起来（#14953、#15059）。
  • 流式、运行时与依赖修复 — 云端会话和 profile 切换现在会流式输出 LLM token，V1 聊天不再重复流式 delta，沙箱供给在 runtime-api 报告没有预热运行时时会回退到默认值。authlib 更新修复了 CVE-2026-44681；SDK/agent-server 包升级到 1.31.1 并做了精确固定，因此升级应包含相应的数据库迁移和刷新的 lockfile（#15021、#15108、#15141、#14983、#15127、#14384）。
  • 兼容性 — 本版未列出破坏性变更。
