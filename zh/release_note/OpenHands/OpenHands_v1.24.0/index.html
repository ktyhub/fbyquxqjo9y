OpenHands v1.24.0

小版本 发布时间2026年9月25日 来源OpenHands/OpenHands 英文原文

变更架构图

亮点

  • 后端隔离的配置缓存 — OpenAI 订阅缓存现在按后端隔离，设置条目也以供给它的后端为键（#16699、#17430）。这防止切换 provider 或环境时跨后端复用缓存，减少过时或不匹配的配置。
  • 只读的云端自动化共享 — 共享的自动化会话现在可以在云端以只读方式打开（#17683），让检查自动化运行更容易，而不必授予编辑权限。
  • 更广的 cron 支持 — 自动化调度校验器现在接受带单一起始步长的 cron 字段（#17274），使受支持的步长表达式得以保存，而不是在校验时被拒绝。
  • 更持久的 MCP 授权 — OAuth 凭据现在能在云端保存后保留，有效 token 会跳过冗余的同意提示（#17677），减少重复认证摩擦，同时在 token 失效时仍保留同意检查。
  • 更少的运行时与状态失败 — Canvas 验证和上下文压缩动作现在直接调用 agent-server 运行时，而不是 /api/cloud-proxy，修复了 HTTP 405 错误（#17511）。历史记录重新加载会保留较新的失败消息，过时的组织选择得以恢复，已保存的 LLM profile 会对不可用模型发出警告（#17647、#17671、#17675），减少静默的状态丢失和配置意外。
  • 破坏性变更 — 无。
