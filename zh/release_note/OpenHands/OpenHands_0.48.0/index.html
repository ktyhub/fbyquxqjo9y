OpenHands 0.48.0

小版本 发布时间2025年7月2日 来源OpenHands/OpenHands 英文原文

OpenHands 0.48.0

这个项目是干啥的：一个让AI替你写和改代码的开发助手，能看懂整个代码仓库、也能在命令行里跑，给想提高效率的程序员用。

变更架构图

亮点

  • 项目与用户定制 — OpenHands 现在会从 ~/.openhands/microagents/ 读取 microagent，并支持根目录 .cursorrules，让团队复用既有项目指令，用户也能在已有来源之外维护自己的个人 agent。
  • 会话控制与设置 — 新增停止会话的能力。LLM 设置改动现在会在停止并重启现有会话后对其生效；必须重启，而不是立即应用。
  • CLI 行为变更 / 迁移 — Jupyter 插件现在在 CLI 运行时中默认禁用。依赖 notebook 的工作流应在采用本版前验证并显式重新启用它。未列出 API 或数据格式的破坏性变更。
  • 设置诊断与 CLI 打磨 — setup.sh 的执行现在出现在事件流中，便于检查 setup 行为。--file 选项更具交互性，pending action 的超时提示不再那么吓人，CLI 退出信息更清晰，suggested tasks 增加了 tooltip。
  • 升级建议 — 需要设置可见性或会话控制的 CLI 用户，以及采用 .cursorrules 或用户级 microagent 的团队，值得升级。如果这些工作流与你无关，可以跳过；Jupyter 用户应在重新启用插件后做测试。

发生了什么变化

添加

  • 除了 https://github.com/All-Hands-AI/OpenHands/pull/9333 中 @enyst 的现有源之外，还添加了对从用户目录 (~/.openhands/microagents/) 读取微代理的支持
  • 添加了对 .cursorrules 的支持。可以通过https://github.com/All-Hands-AI/OpenHands/pull/9327中的@AutoLTX放到根目录
  • 添加了在 https://github.com/All-Hands-AI/OpenHands/pull/9458 中通过 @hieptl 停止对话的功能
  • 在事件流中添加了 setup.sh 脚本执行，允许用户查看 @neubig 在 https://github.com/All-Hands-AI/OpenHands/pull/9427 中何时以及如何运行安装脚本

已更改

  • 通过 @xingyaoww 在 https://github.com/All-Hands-AI/OpenHands/pull/9398 中使 —file 选项更具交互性和用户友好性
  • 在 CLI 运行时默认禁用 Jupyter 插件，@li-boxuan 在 https://github.com/All-Hands-AI/OpenHands/pull/9452 中

已修复

  • 降低了 https://github.com/All-Hands-AI/OpenHands/pull/9415 中 @xingyaoww 的待处理操作超时消息的严重性
  • @Adityauyadav 在 https://github.com/All-Hands-AI/OpenHands/pull/9432 中改进了 CLI 退出消息
  • @hieptl 在 https://github.com/All-Hands-AI/OpenHands/pull/9447 中添加了 suggested tasks 的工具提示
  • 在 https://github.com/All-Hands-AI/OpenHands/pull/9460 中 @hieptl 停止并重新启动现有对话后，更新 LLM 设置现在将应用于现有对话

新贡献者

  • @Adityauyadav 在 https://github.com/All-Hands-AI/OpenHands/pull/9432 中做出了第一个贡献
  • @hieptl 在 https://github.com/All-Hands-AI/OpenHands/pull/9442 中做出了第一个贡献 完整 Changelog：https://github.com/All-Hands-AI/OpenHands/compare/0.47.0…0.48.0
