OpenHands cloud-1.40.0

发布 发布时间2026年6月26日 来源OpenHands/OpenHands 英文原文

变更流程图

亮点

  • 仓库与沙箱控制 — 按用户的完整 Git 历史让 agent 获得更广的仓库上下文，而 default_sandbox_spec_id 让沙箱选择可配置。git_full_clone 修复在读取设置时能容忍遗留的 NULL 数据库值，减少升级时的失败（#14950、#14985、#14988）。
  • 暂停行为改用中断 — 暂停 UI 现在调用中断端点，使 UI 动作与执行控制路径对齐。自定义客户端应验证其暂停处理与此行为一致，而不要把暂停当作纯 UI 状态变化（#14972）。
  • 企业供给的编程化 — 新的管理员用户供给端点为组织入驻和用户生命周期工作流提供了自动化钩子，减少对手动管理步骤的依赖（#14864）。
  • 更丰富的 Azure DevOps 与 Jira 集成 — Azure DevOps 增加了 resolver 提及和组织级一键 webhook 设置。Jira Data Center 增加了邮件模式自动链接、定向仓库查找和选择器提及，有助于减少歧义的仓库选择和手工 issue 关联（#14991、#15001）。
  • 安全依赖升级 — 本版把 @opentelemetry/core 更新到 2.8.0、pydantic-settings 到 2.14.2、protobufjs 到 7.6.4、ws 到 8.21.0，以解决 CVE-2026-54285、GHSA-4xgf-cpjx-pc3j、CVE-2026-48712 和 CVE-2026-48779。自托管部署应重建镜像并刷新 lockfile 以继承修复；新的 Python 依赖新鲜度护栏提供持续保护（#14979、#14980、#14981、#15007、#13754）。
  • 破坏性变更 — 本版无。
