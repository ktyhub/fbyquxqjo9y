OpenHands 1.0.0

大版本 发布时间2025年12月16日 来源OpenHands/OpenHands 英文原文

OpenHands 1.0.0

变更流程图

亮点

  • 全面迁移到 software-agent-sdk — 这是一个真正的大版本，而非只改元数据的重新打标：1.0.0 基于全新的 software-agent-sdk 重建了 OpenHands V1（参见 V1 架构文档），并带来“全应用的广泛优化”。请预期它与 0.62.0 在行为和集成上存在差异，要安排真正的验证流程，而不是当作一次可直接替换的补丁升级。
  • 破坏性变更：CLI 移出主仓库 — OpenHands CLI 已拆分到独立仓库 https://github.com/OpenHands/OpenHands-CLI。任何围绕“CLI 位于 OpenHands monorepo 中”编写过脚本或工具的人，都必须在升级前迁移源码/检出，并更新所有路径或固定引用。
  • 新集成与 agent 能力 — Azure DevOps 支持通过 PR #11243 落地，新的任务跟踪器接口来自 PR #11692，PR #11687 让运行时连接建立期间发送的聊天消息进入队列（启动时发出的消息不再丢失）。PR #11774 为 gemini-3-pro-preview 启用了原生工具调用，另有一批常规 UI 修复。使用 Azure DevOps 或依赖 Gemini 3 Pro 工具调用的团队收益最明显。
  • 升级建议 — 想要基于 SDK 的架构、Azure DevOps 集成、新任务跟踪器、Gemini 3 Pro 原生工具调用或聊天排队可靠性修复的团队值得升级；CLI 工作流必须跟随拆分后仓库的人更是硬性要求。若你稳定运行在 0.62.0、不需要这些特性、也不用 Azure DevOps/Gemini 3、且不依赖 CLI，完全可以等 SDK 迁移在你的环境中稳定后再说。

发生了什么变化

新的 OpenHands 1.0.0 使用新软件代理-sdk，并在整个应用程序中进行了许多优化。查看有关OpenHands V1 如何使用软件代理-sdk 的文档。
