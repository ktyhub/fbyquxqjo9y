OpenHands 0.45.0

小版本 发布时间2025年6月20日 来源OpenHands/OpenHands 英文原文

OpenHands 0.45.0

变更流程图

亮点

  • Kubernetes 运行时支持（#8814） — OpenHands 现在可以直接把 agent 沙箱调度到 Kubernetes 集群上，团队因此有了横向扩展隔离执行器、复用现有集群鉴权/策略的路径，而不必为每个用户跑 Docker/Podman 主机。如果你在评估运行时后端，这是首个适合 K8s 原生部署的选项——但这是全新的集成，RBAC、命名空间隔离和镜像拉取配置都需要你自己验证。
  • 配置目录迁移——需要手动操作（#9135） — 状态从 ~/.openhands-state 迁移到统一的 ~/.openhands。已有安装不会找到旧的设置、会话或凭据，除非你搬迁目录（或建软链接），所以要把它当作一个手动迁移步骤，并在升级前更新所有引用旧路径的脚本、CI 缓存或 Docker 卷挂载。
  • 更长的 agent 运行，附带每会话预算（#9203、#8812） — 迭代上限从 250 跃升到 500，让 agent 可以尝试复杂得多、多步骤的任务而不撞到天花板。这也会让潜在 token 消耗大约翻倍，所以新的每会话预算控制是配套护栏，要在生产环境启用长运行之前配置好——两者一起设，别只顾着调高上限。
  • 更丰富的输入：上传、Bitbucket 和日语（#8945、#9021、#9244） — 会话现在接受文件和图片上传（#8945），配合修复空图片 URL 引发 litellm 错误的问题（#9214）——对截图驱动的调试和设计工作很有用。本地使用的 Bitbucket 支持（#9021）补上了非 GitHub 团队的真实缺口，日语 UI 支持（#9244）扩大了受众；要注意，让 Bitbucket/GitLab 工作流真正可靠的是针对非 GitHub 集成的 microagent 加载修复（#9189）。
  • 生产级可靠性修复（#9187、#9189、#9190、#9111、#9136、#9238） — 一批运维向的清理：远程运行时状态现在能正确渲染（#9190），重启的云端会话保留其 token（#9111），Daytona 沙箱处理得到纠正（#9187），容器内 git 所有权错误被解决（#9136），会话轨迹页面不再 500（#9238）。这些共同消除了日常使用云端会话和非默认运行时时的几个痛点——如果你碰到过其中任何一项，就值得升级。
  • 本地/自托管的顺畅接入（文档） — 新增 Python CLI 版本要求（#9164）、uvx 安装（#9186）和 Ollama 本地服务（#8807）指南，另有一篇“用 OpenHands 开发 OpenHands”的递归开发文档（#9146）。如果你在评估离线隔离或完全本地的部署，这些能切实降低配置摩擦；CLI/LLM 弃用警告的清理（#9188、#9261）也让日志更安静。
