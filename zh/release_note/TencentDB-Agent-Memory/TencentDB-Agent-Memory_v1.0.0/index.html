TencentDB-Agent-Memory v1.0.0

大版本 发布时间2026年6月11日 来源TencentCloud/TencentDB-Agent-Memory 英文原文

TencentDB-Agent-Memory v1.0.0

这个项目是干啥的：一个给AI智能体当长期记忆的组件，能存住聊天和历史信息、本地优先还能上云，给做AI助手的开发者用。

变更架构图

亮点

  • Gateway + v2 API 移除 OpenClaw 依赖 — Memory 现在作为独立服务运行，暴露 14 条路由，覆盖 CRUD、原子更新、场景索引、流水线状态和实例生命周期。任何支持 HTTP 的 agent 都可以集成；Bearer 鉴权、CORS 白名单和 1 MiB 请求限制为对外部署提供了更安全的保障。
  • 部署与配置有破坏性变化，需要明确的迁移路径 — 嵌入式插件变成客户端/服务端架构：要把扁平的 gateway 配置改名为嵌套的 server，然后选择 local 模式（默认，进程内）或 client 模式（外部 Gateway）。现有的 0.x 安装可以留在 main；面向服务的 1.x 线在 feat/server 上，内存引擎和数据格式保持兼容。
  • 官方 SDK 覆盖完整 API — TypeScript SDK（@tencentdb-agent-memory/memory-sdk-ts）提供类型化访问，Python 包（tencentdb-agent-memory-sdk-python）同时支持同步和异步工作流。在集成 LangChain、AutoGPT、Hermes 或自定义框架时，不必再手工维护 HTTP 客户端。
  • Offload 处理重新设计，面向并发与上下文控制 — 异步的 L1/L1.5/L2 执行器处理大规模会话量，L3 则把 Mermaid 符号化与上下文预算强制结合用于压缩。多模态数据可以通过 /v2/offload/* 进入流水线，让记忆基础设施不再局限于纯文本对话。
  • 生产可观测性内置 — OpenTelemetry trace 通过 OTLP 导出到 Jaeger 或 Grafana Tempo 等后端；Langfuse 只接收与 LLM 相关的 span，用于提取质量评估。流水线指标 —— 包括 L1 提取率、去重决策、token 用量和召回延迟 —— 帮助诊断记忆行为，而不是把它当黑盒。

[1.0.0] - 2026-06-11

正式版本发布：从OpenClaw专用插件演进为面向所有代理的通用记忆服务。完整的网关独立服务+ v2 HTTP API +官方TypeScript / Python SDK，任何代理框架都需要接入完整的楼梯记忆与高层记忆。

⚠️ 重大变更

  • 客户端/服务端架构拆分：记忆引擎从 OpenClaw 嵌入式插件拆分为独立网关服务进度，部署方式与接入方式发生变化。
  • 配置结构变更：插件配置结构重构，原gateway字段迁移为server。
  • 插件入口模式变更：支持local（进程内本地运行，默认）和client（连接外部内存网关）两种接入模式。

🚀 独立网关服务（v2 API）

记忆能力不再绑定OpenClaw，以独立服务形式运行，通过v2 HTTP API为任何Agent提供记忆读写与表格管理：

  • 完整v2 API：14条标准路由覆盖记忆CRUD、原子更新、场景索引、表格状态查询等全部操作。
  • 楼梯状态查询（/v2/pipeline/status）：实时获取L1/L2/L3各阶段运行状态与进展。
  • 实例生命周期管理（/v2/instance/destroy）：支持外部系统主动创建/回顾记忆实例。
  • 任选承载鉴权+CORS白名单：保护对外暴露的API安全。
  • 请求体校验：强制1 MiB上限，防止异常请求。

🚀 官方 SDK

  • TypeScript SDK 1.0.0（@tencentdb-agent-memory/memory-sdk-ts）：类型安全，覆盖全部v2 API，npm安装即用。
  • Python SDK（tencentdb-agent-memory-sdk-python）：点轮安装，同步/异步双模式，覆盖全部v2 API。

🚀 通用代理框架装备

  • OpenClaw 插件装备：支持 local（进程内部本地运行，默认）和 client（连接外部内存网关）两种接入模式。local 模式保持原有体验。
  • Hermes Agent 车辆：memory_tencentdb_v2 适配器，支持 Hermes 框架多车站场景。
  • 通用接入：任何能发HTTP请求的Agent（LangChain、AutoGPT、自研框架等）通过SDK或裸API接入。

🚀 可启动性

  • OpenTelemetry全仓库Trace：支持OTLP协议上报，可对接Jaeger / Grafana Tempo等耳机。
  • Langfuse集成：仅转发LLM相关跨度，适合评估记忆质量。
  • 抑制排气指标：L1提取率、去重决策分布、各阶段令牌消耗、召回延迟等。

🚀 卸载服务器 V2

  • L1 / L1.5 / L2 异步执行器：独立的Offload处理平台，支持大规模会话并发。
  • L3压缩处理器：Mermaid符号化 + 上下文预算控制，智能上下文压缩。
  • MMD注入：支持多模态数据注入Offload流程。
  • 网关集成/v2/offload/*路由：统一卸载API入口。

📦部署方式

方式 说明
Docker 容器 docker pull agentmemory/hermes-memory:1.0.0
直接运行源码node --import tsx/esm src/gateway/server.ts
OpenClaw 插件 通过 install-openclaw-plugin-v2.sh 安装
爱马仕 (Hermes) 插件 内置 memory_tencentdb_v2 Python 插件

⬆️ 从 0.x 升级说明

v1.0.0 与 0.x 是家具维护的消耗版本线：

  • 0.x（main分支）：OpenClaw 嵌入式插件，适合轻量单机场景
  • 1.x（feat/server分支）：独立内存服务，适合多Agent / 多框架 / 服务化部署

二者核心记忆引擎相同（L0→L3分层+BM25/提供混合搜索+Mermaid符号化短期记忆），数据格式兼容。

🐛 修复（v1.0.0-beta.2 → v1.0.0）

  • Hermes 插件 install_hermes_tdai_gateway.sh 完善：支持root自动切换用户、旧路径自动迁移、幂等检测以跳过重复安装
  • 网关配置优化：默认端口8420，同步写入/etc/profile.d/ 和 ~/.hermes/.env 两份环境变量
  • SDK 文档补全：TypeScript / Python SDK README 和接入示例
  • OpenClaw 插件.json 配置调整：删除已弃用的字段，车辆 OpenClaw 最新版本
