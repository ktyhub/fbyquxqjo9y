TencentDB-Agent-Memory v2.0.0

大版本 发布时间2026年8月3日 来源TencentCloud/TencentDB-Agent-Memory 英文原文

TencentDB-Agent-Memory v2.0.0

变更流程图

亮点

  • 完整的四资产记忆栈 — v2.0.0 开源了 Chat Memory 的 L0–L3 提取流水线、带版本的 Skills、结构化 Wiki 页面，以及面向符号、文件、调用和影响分析的 CodeGraph 索引。强制的技能归档降低了已验证工作流丢失的风险，定时 CodeGraph 同步让仓库上下文保持最新而无需手工重建；请按仓库的变更频率核对同步周期。
  • 团队级访问控制与资产装配 — Memory Hub 通过 private、team 以及基于 ACL 的 restricted 访问，为 Users、Roles 和 Agents 管理所有权、版本、状态和可见性。Agent Loadout 控制每个 agent 拿到哪些资产、优先级以及使用方式；管理员现在可以直接管理资产，面板也支持中英文切换。
  • Anthropic 与 OpenAI 兼容 agent 的即插即用记忆 — Memory Proxy 暴露 /claude-code/<spaceId>/v1/messages 和 /v1/chat/completions。它在 sessionInit 时持久化团队/agent/任务选择，然后每轮注入 L2/L3 记忆、匹配的 Skills、Wiki 和 CodeGraph 上下文。由于 x-tdai-user-key 会被校验成 user_id，资产 ACL 直接影响哪些知识进入系统提示词 —— 而不只是面板上显示什么。
  • TypeScript SDK 现在默认使用 v3 隔离 — 尽管包名是 memory-sdk-ts-v2，其根导出已是带严格隔离的 v3 API；旧版兼容层仍在 .../v2/v3 下。升级前请审查 import 和隔离假设。Python 的 v3 模块则通过同步和异步客户端提供完整 API。
  • 容器部署更易启动 —— 也更易重置 — 三个镜像 memory-core、memory-hub 和 memory-proxy 支持 linux/amd64 和 linux/arm64。start-all.sh 会初始化管理员、生成 .admin-key、运行自检，并打印一条可直接复制的 claude 命令。请保护这个 key，并把 stop-all.sh --purge 当作破坏性操作：它会删除卷和管理员 key。
  • 破坏性变更 — 没有明确声明。

[2.0.0] - 2026-08-03

v2.0.0正式版发布，较beta.1新增技能强制归档、CodeGraph定时同步、 面板中英文切换/管理员资产管理等功能，并完善了部署流程和接入文档。

产品定位：让Agent的经验、文档、代码沉淀成可复用的资产，让下一位Agent 直接读档。参见README_CN.md。

🧠四种记忆资产 · 第一个完整开源

四类资产从“对话/工作痕迹”里自动沉淀出来：

  • 聊天记忆 — 从对话中逐层提取L0原始记录→L1事实→L2场景→L3 长期认知；跨会话保留偏好、决策、交往历史。
  • 技能 — 从跑通的任务里提炼可复用SOP，附版本/资源文件/触发边界/ 执行步骤/验证规则。新增强制归档功能，确保关键技能不遗漏。
  • Wiki — 把文档变成构造页面 + 链接图谱（灵感来自 Karpathy 的 LLM 知识库） 实践）。
  • CodeGraph — 索引仓库的符号 / 文件 / 调用关系 / 影响路径，Agent 改代码 之前先做一下影响分析。新增定时自动同步代码库功能，仓库变更后手动删除 触发。

🎛️ Memory Hub · 面向团队的操作台

管控面板（agentmemory/memory-hub镜像，含面板+知识服务）：

  • 建队/代理，将资产按Owner/版本/状态/可见性统一管理
  • 三级可见性：private / team / restricted（用户/角色/代理ACL）， 外加 agent 定向装配
  • 代理配出：给不同的代理绑定不同的资产、调整优先级和使用方式
  • Wiki + CodeGraph工坊内置于Hub，导入代码库/文档即可自动构建
  • 新增管理员（System Admin）也可使用资产管理功能
  • 新增面板全面支持中英文切换；统一页面设计风格，优化列表交互和分页体验

🔀 Memory Proxy · Agent 挂上记忆的通道

agentmemory/memory-proxy 让 Claude Code 等编码代理直接用上团队记忆：

  • Anthropic / OpenAI 双协议：/claude-code/<spaceId>/v1/messages 和 /v1/chat/completions 都接
  • 首轮引导：sessionInit通过AskUserQuestion让用户选择团队/经纪人/ 任务，代理 记住绑定
  • 每轮注入：把该代理的L2/L3记忆、匹配技能、wiki/code-graph 拼进系统提示，转发上游LLM
  • 鉴权：x-tdai-user-key → 内核 /v3/meta/auth/verify 换 user_id， 更多维度用户控制资产可见性

🚀部署方式

方式 说明
Docker 三件套 agentmemory/memory-core / agentmemory/memory-hub / agentmemory/memory-proxy，多架构（linux/amd64 + linux/arm64），一键start-all.sh拉起。首次启动自动init-admin并生成.admin-key，start-all.sh自检通过后打印可复制的claude启动命令
源码运行 参考 INSTALL_CN.md / INSTALL.md

stop-all.sh --purge可彻底清理音量+管理键，方便重置环境。
