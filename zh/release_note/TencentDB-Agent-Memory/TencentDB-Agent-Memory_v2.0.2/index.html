TencentDB-Agent-Memory v2.0.2

TencentDB-Agent-Memory v2.0.2

这个项目是干啥的：一个给AI智能体当长期记忆的组件，能存住聊天和历史信息、本地优先还能上云，给做AI助手的开发者用。

变更架构图

亮点

  • MongoDB 成为黏性的一等后端 — 两个新存储（memory-prompt、generation-ref）补全了 Mongo schema，但与采用最相关的变化是行为上的：./start-all-mongo.sh 现在把 STORE_MODE 持久化到 .env，因此你的后端选择在重启后依然保留，不必每次启动时重新声明。索引冲突的自愈意味着重复的默认/提取记录不再导致启动中止 —— 共享集合上的冷启动失败会更少。
  • 客户端集成改为纯配置且覆盖面更广 — OpenCode 提供官方 Memory 适配器（opencode.json + 文档，无需插件代码），并支持 2.0 的 v2 provider schema（opencode.v2.json）；DeepSeek Harness 桌面版（./agents/dsh/README.md §1.6）和 Pi —— 一个基于 OpenAI Chat 协议的 Codex 类 agent —— 也已接入。注意 v1 与 v2 provider 的区分：要加载与你客户端版本匹配的配置文件，否则适配器不会挂上。
  • 外部资产导入闭环，带凭据隔离 — 任务可以从外部任务系统导入，带来源徽标、ID 复制和分页；私有仓库可以注册为代码源，并按团队配置互不可见的凭据；Wiki 成为第三种来源。隔离是安全上的关键收益 —— 多个团队可以共用一套部署，而不会互相读取对方的私有仓库。
  • 技能提取加入护栏与排序 — 冷启动批量提取新增用于质量控制的严格模式，生成内容会自动跟随用户语言，列表可以按使用活跃度排序，让高频技能浮上来。对采用者来说，当自动提取的技能噪声太大时，严格模式就是该用的旋钮。
  • 召回与会话可靠性加固 — 无 embedding 的 BM25 召回、L0 工具结果污染、空召回、重复历史消息、多团队列表截断，以及 Claude Code 中丢失 AGENTS.md 指令的问题都已修复。注意 hub 中有一处行为变化：手动刷新现在会重置时间过滤器，使新生成的记忆立即出现 —— 如果你依赖过滤视图，这点很重要。
  • 破坏性变更 — v2.0.2 未报告。

[2.0.2] - 2026-10-09

产品定位：让Agent的经验、文档、代码沉淀成可复用的资产，让下一位Agent 直接读档。参见README_CN.md。

🗄️ 存储可扩展 · 支持 MongoDB

团队记忆不再绑定单一的数据补充，MongoDB 的能力进一步补充：

  • 新增 memory-prompt 和 Generation-ref 两类存储，覆盖更多记忆数据结构
  • 一键输入 ./start-all-mongo.sh 将 STORE_MODE 持久化写入 .env，后续启动 保持同一配置，不再重复配置
  • 修复索引冲突场景的自愈能力，重复的默认/抽取记录不再导致启动报错

🔀更多客户端接入

  • OpenCode 新增官方内存适配器配置包（含 opencode.json 和接入文档），按说明配置即可接入，需要编写插件代码
  • OpenCode 支持 2.0 的 v2 提供者配置结构，新版客户端可直接复用官方 opencode.v2.json
  • DeepSeek Harness 新增 dsh 桌面端装备，配置方式可参考 ./agents/dsh/README.md 中 1.6 的部分
  • 新增 Pi 客户端接入（类似Codex的AI Agent客户端，走OpenAI Chat协议）

🧠外部源导入（Wiki / 代码 / 任务）

  • 新增从外部任务管理系统导入任务的能力，任务对应直接展示来源、支持ID复制与分页
  • 新增外部股票源（外汇仓）注册与外汇储备，各团队持有外汇股票、互不可见
  • 新增Wiki外部来源导入，与代码源、任务源一起补齐外部资产导入仓库

🧰 技能（Skill）体验优化

  • 冷启动批量技能抽取新增严格模式，抽取质量更加可控
  • 技能抽取自动跟随用户语言，生成内容更贴合习惯
  • 技能列表支持使用主动度排序，高频技能更容易被找到

🎛️ 内存中心面板

  • 任务反馈支持源展示、ID复制与分页优化，批量导入交互更多
  • 手动刷新时间自动重置时间筛选，新产生的记忆能力即时

🔄 会话与接入体验

  • 会话引导在更多客户端下更稳定：自动选中唯一代理、资产确认更精准、预设失败时 自动绕行绕行卡住
  • 修复 WorkBuddy 玩具子代理反复弹窗的问题，会话归一更坚固
  • 修复多个客户端下记忆命令、工具结果污染、历史消息重复等影响体验的问题

🐛 修复

  • 修复无嵌入场景下BM25召回异常、L0工具结果污染与原文展示问题
  • 修复记忆记忆为空、历史消息重复、多团队切换列表断断等问题
  • 修复 Claude Code 的 AGENTS.md 指令丢失等问题
  • 修复配置脚本在部分环境下的兼容性问题
