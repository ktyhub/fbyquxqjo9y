Codewhale v0.9.5

修订 发布时间2026年8月8日 来源codewhale-hq/Codewhale 英文原文

Codewhale 是 Shannon Labs 的公共产品。 codewhale 命令、npm 包和发布资产名称保留小写技术名称 标识符。旧版 npm 包 deepseek-tui 已弃用，并且 不再收到进一步的发布。来自 v0.8.x 旧版 deepseek 的用户 / deepseek-tui 名称应随 docs/REBRAND.md 一起迁移。

安装

推荐 — npm（一个命令，两个入口点）

npm install -g codewhale

包装器下载匹配的 codewhale 和 codew 命令资源 从本版本开始。两者都包含相同的编译运行时。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.5

该图像公开与 codewhale 和 codew 相同的运行时。的 latest 标签也在发布时进行了更新。

货物（Linux / macOS）

cargo install codewhale-cli --locked

Cargo 包安装 codewhale。 Cargo 无法创建第二个命令 来自一个二进制目标的别名；想要更短拼写的用户可以添加 codew 到已安装的可执行文件的符号链接。 npm、Homebrew、存档、 shell-installer 和容器通道直接安装这两个命令名称。

v0.9.5 里有什么

Codewhale v0.9.5 将终端应用程序整合为一个已编译的应用程序 运行时，同时保留熟悉的 codewhale 和 codew 命令。它 还扩展了托管运行时 API，使会话和队列工作更容易 检查并恢复，并删除隐藏的本地延续逆止器 可能会在没有助理最终回应的情况下结束富有成效的工作。

添加

  • model = "auto" 用于基于提示的层选择：设置后， 调度程序在委托给 TUI 之前分析用户的提示并 选择 deepseek-v4-pro 执行复杂任务或选择 deepseek-v4-flash 执行简单任务 任务（PR #5257）。
  • 运行时 API 控制持久目标、有限内存检查、MCP 服务器和技能生命周期管理，以及持久的舰队接收证据。
  • 仅附加会话树历史记录，包括 /tree、/branch、/fork 和 /resume，加上 /rc 远程控制和托管登录。
  • 统一的舰队名册，用于内置调度姿势和固定指示器 使活动的后台工作在作曲家上方可见。
  • 增量 MCP 注册表刷新，立即返回本地快照 并在后台更新它。
  • 侦察员和审查员代理可以使用有界直接命令证据外壳 只读工作区、Git 和 GitHub 检查，并可以保持私密工作 他们在自己的待办事项中做了笔记，而持久的笔录则保留了他们的证据。

已更改

  • codewhale-cli 现在直接包含终端运行时。发布安装程序 无需单独的 TUI 即可公开字节相同的 codewhale 和 codew 命令 可执行的。 v0.9.5 资产集单独保留已弃用的 codewhale-tui-* 文件名作为字节相同的兼容性副本，因此 安装的v0.9.4 clients可以发现并完成此升级。
  • 启动版本检查将成功查找缓存一小时。更新程序 下载并验证一次主运行时，然后刷新任何现有的 来自相同字节的 codew 或传统 codewhale-tui 命令路径。
  • 无头 codewhale exec 运行和验证器基准测试不再推出 施加 100 步默认值。 --max-turns 仍可作为显式 选择加入上限；车队工作人员保留其单独配置的预算。
  • 目标代币和时间预算是遥测而非默认停止 条件，并且自动目标延续是无限的，除非用户 明确配置连续上限。
  • 命令面板和斜杠补全阴影现在共享一个别名感知功能 发现合同。
  • 网站安装指导、本地化产品文案、导航控件、 社交元数据和 Cloudflare 构建管道现在描述和部署 相同的一次性发布合同。

已修复

  • 隐藏的 20 步无用户输入逆止器不再结束高效转弯。 工具结果、排队引导、子完成、REPL 反馈和目标 延续都可以到达下一个提供商步骤和最后一个助手 回应；明确的用户配置限制和真正的卡环防护仍然存在。
  • 失败后可以直接检查完整的错误详细信息，而不是 终端上留下 clipped、不可恢复的错误片段。
  • 在同一提供商选择中采用新创建的 OAuth 凭证 流，而不需要第二次拣选行程。
  • 新的会话标题可以替换陈旧的缓存 New Session 占位符， 未知模型上下文限制严重失败，并且发布/源安装后备 不再请求通过单运行时转换删除的二进制文件。
