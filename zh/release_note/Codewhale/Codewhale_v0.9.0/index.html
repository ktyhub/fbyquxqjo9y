Codewhale v0.9.0

小版本 发布时间2026年7月16日 来源codewhale-hq/Codewhale 英文原文

Codewhale 是 Shannon Labs 的公共产品。 codewhale 命令、npm 包和发布资产名称保留小写技术名称 标识符。旧版 npm 包 deepseek-tui 已弃用，并且 不再收到进一步的发布。来自 v0.8.x 旧版 deepseek 的用户 / deepseek-tui 名称应随 docs/REBRAND.md 一起迁移。

安装

推荐 — npm（一个命令，两个二进制文件）

npm install -g codewhale

包装器从此版本下载匹配的运行时二进制文件并将它们放在同一目录中。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.0

该映像附带了 codewhale 调度程序、codew shim 和 codewhale-tui 运行时。 latest 标签也在发布时进行了更新。

货物（Linux / macOS）

cargo install codewhale-cli codewhale-tui --locked

这两个包都是必需的 - codewhale-cli 生成 codewhale 调度程序和 codew shim，而 codewhale-tui 生成调度程序委托给的交互式运行时。仅安装一个 crate 将在运行时失败并出现 MISSING_COMPANION_BINARY 错误。

手动下载——平台档案（推荐）

下面的每个存档都包含 codewhale 调度程序、codew 填充程序和 codewhale-tui 运行时以及安装脚本：

平台 档案 安装脚本
Linux x64 codewhale-linux-x64.tar.gz install.sh
Linux ARM64 codewhale-linux-arm64.tar.gz install.sh
Android ARM64 (Termux) codewhale-android-arm64.tar.gz install.sh
macOS x64 codewhale-macos-x64.tar.gz install.sh
macOS ARM codewhale-macos-arm64.tar.gz install.sh
Windows x64（安装程序） CodeWhaleSetup.exe NSIS 设置
Windows x64 codewhale-windows-x64.zip install.bat
Windows x64（便携式） codewhale-windows-x64-portable.zip —
Unix（Linux / macOS）： 
tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows：

  • 对于安装程序路径，运行 CodeWhaleSetup.exe；它会在 %LOCALAPPDATA%\Programs\CodeWhale\bin 下安装 codewhale.exe、codew.exe 和 codewhale-tui.exe 并将该目录添加到当前用户的 PATH 中。
  • 提取codewhale-windows-x64.zip
  • 运行install.bat（复制到%USERPROFILE%\bin）
  • 将 %USERPROFILE%\bin 添加到您的路径 便携式 Windows 存档会跳过安装脚本 - 从任何目录提取并运行。 NSIS 安装程序当前未签名，可能会触发 Windows SmartScreen，直到签名证书连接到发布管道。 每个平台还附有裸露的、未存档的二进制文件（codewhale-<platform>、codew-<platform> 和 codewhale-tui-<platform>） - npm 包装器和应用内 codewhale update 下载匹配的运行时二进制文件，而上面的 .tar.gz / .zip 存档是建议的手动下载，并另外捆绑安装脚本。旧版 npm 包 deepseek-tui 已弃用并且不会重新发布。有关从 v0.8.x 旧二进制名称的迁移，请参阅 docs/REBRAND.md。

v0.9.0 中有什么

Codewhale v0.9.0 用水下替换默认终端外壳 交互系统，使操作消息优先，并强化舰队， 支持日常工作的工作流程、路由、会计和发布界面 代理工作。该版本还扩大了本地化范围，并为公共网站提供了 更安静、文档优先的社区基金会。它的提供者工作取代了旧的 手动维护的选择器边界与实时 ProviderLake 发现并添加 迄今为止该项目中规模最大的策划模型和定价扩展。

固定 — 最终集成

  • 编辑配置的、环境的、文件支持的和裸露的活动凭据 来自每个工具结果，然后再通过任何模型提供商有线协议； 检索到的溢出内容在该边界处再次进行清理。这 read_file工具也拒绝CodeWhale配置、备份和 凭证存储路径，防止常规工具使用暴露这些路径 本地文件。
  • 在 shell 内保留即时 TUI 提交失败：自定义提供者路由 预检和关闭邮箱错误现在可以恢复准确的作曲家草稿和 选择重试技能，并显示粘性可见错误而不是退出。
  • 将自动压缩阈值锚定到路线的可花费输入 预算在输出预留和安全余量之后，因此大输出和 在提供商上下文拒绝之前，紧密的自托管路由会变得紧凑。途易 预发送门和警告副本现在使用与 发动机。保留 262K Kimi 路线的可用输入预算并使用 记录 32K 默认生成预算，而不是镜像上下文 窗口作为输出（#4293 by @SamhandsomeLee、#4368 by @bruce6135 和 #4378 作者：@mvanhorn）。
  • 失败关闭，而不是报告直接 OpenAI 的基本利率美元估算 GPT-5.4/5.4 Pro、GPT-5.5（包括带日期的快照）和 GPT-5.6 Sol/Terra/Luna 请求超过 272K 个输入令牌。精确的分层会计 仍然遵循通用定价模式；较小的 5.4 变体， GPT-5.5 Pro、Codex 订阅和国外提供商路由不变 （＃4317）。
  • 在 deepseek-chat 和 deepseek-reasoner 到达 DeepSeek 之前退役 第一方 OpenAI 或 Anthropic 线 API，将两者迁移到记录的 deepseek-v4-flash 的替换同时保留传统的非思考 / 未设置明确推理层时的思维意图。聚合器，万杰 Ark、自托管和自定义端点模型 ID 仍由提供商拥有 (#4320)。
  • 使操作成为消息优先的多任务界面：普通提示无需操作即可工作 一个工作流程，直接父工具遵循相同的批准，沙箱，shell， 询问规则和存储库保护作为行动，后续行动可以排队 工作很活跃。有限制的背景工作者仍然是独立、 并行、隔离或长时间运行的工作；子交接不能继承 享有完全访问权限，每次发送都会产生一个持久的完成 收据。
  • 让CODEWHALE_HOME/agents中的个人车队档案穿越 存储库，而 .codewhale/agents 中的项目配置文件会覆盖它们。 保存会刷新实时名单，并且用户界面现在明确显示该个人资料 可用性不会扩展工作空间、trust 或文件系统权限。
  • 将文件提及发现移动到一个有界的、生成安全的背景上 因此，缓慢的文件系统读取无法冻结作曲家输入。精确路径 发送时解决；模糊匹配保留在完成弹出窗口中，而不是 静默附加任意同名文件（@WavesMan 的#4365，其中 来自@LeoLin990405 的 #4367 的初始有界行走方法）。
  • 将选择加入的 remember 工具保留在模型可见的首轮目录中，以便 持久的偏好捕获工作不需要模型来发现 它还不知道工具是否存在（#4373 by @Angel-Hair 和 #4377 by @Angel-Hair） @mvanhorn）。
  • 通过比较，使 review 处理相对于基本引用的暂存快照 带有索引的分支合并基树。这保留了承诺和 分阶段的分支工作，排除未分阶段的编辑，并避免无效 git diff --cached <base>...HEAD形式。
  • 在调用之前尊重每个 MCP 服务器宣传的发现功能 可选工具、资源、模板或提示；保留可选探头 独立有界和软故障（#4308 by @nsfoxer）。
  • 使离线 scorecard 定价提供商知晓：turn_end 记录带有 有效的路由和非秘密计费表面、运行时导出和 支持的别名干净地摄取，遗留/未知路由显式保留 未定价、路由范围的缓存和记录时间定价取代了仅模型 猜测。历史运行时间聚合使用每个回合的记录时间； 无成本的目录路线失败，而准确的供应商拥有的手动价格 行仍然可用。 StepFun PAYG 和 Step Plan 的使用现在保持不同 无需保留原始端点 URL，因此永远不会报告订阅配额 作为代币支出（#4335）。仅完成外壳、手动压实和清除 事件对于 turn_end 观察者来说仍然可见，作为明确的非模型 生命周期记录。这建立在 @findshan 引入的记分卡的基础上 第3388章
  • 在 TUI 会话中保留指定的定制提供商身份，exec --resume， 运行时线程、导出、缓存和工作流收据。恢复解决 在创建 client 之前根据实时配置保存提供程序，从不 从模型 ID 推断提供者，并在指定路由被关闭时失败 已删除、无效或不明确 (#4334)。
  • 将凭证绑定到拥有它们的端点。环境选择定制 主机不能再继承保存的提供程序密钥、密钥环条目、OAuth 或 环境提供者变量；只有明确源标记的 CLI 密钥才可以 遵循显式的 CLI 端点覆盖。 auth_mode = "none"还条 TUI 和应用程序服务器中一致的凭证形状自定义标头， 而无密钥环回路由仍然可用作本地运行时。
  • 使托管运行时线程具有确定性和提供者精确性：序列化 线程、回合和事件突变；向房东保留取消所有权； 在每一次持久的转变中保护选定的提供商；终端化 异常流一次；并防止运行时管理器默默地 调度无人认领的目标延续或子轮流。
  • 将所需的用户确认视为真正的目标障碍而不是失败 目标，并解释如何在先前缓存的批准被拒绝时恢复。 缓存拒绝恢复也作为已结算的抄本收据提交，因此 工具完成或以后的状态更新无法将其从回滚中删除或 可访问性输出。该通知现在描述了匹配的、流程范围的 在所有发货地点如实否认；审批审核荣誉 CODEWHALE_HOME，并且过期的状态 toast 不能仍然被困在 持久条目。这两种状态都保持可见且可操作，而不是 看起来像是无法解释的模型或工具故障（#4374 和 #4375 by @Angel-Hair，@nightt5879 在 #4385 中进行了最终硬化）。
  • 使舰队发射和拆卸具有确定性：路线标志放置在之前 exec，工作人员包含在拥有的 Unix 会话或 Windows 作业对象中， 并且取消会在之前以有限的升级收获幸存的后代 经理状态稳定。围栏进度、终端状态、验证 持久尝试生成的收据和证据，以便陈旧的流程可以 切勿完成或覆盖重新启动的尝试；最终状态和收据 现在原子地提交，陈旧的心跳决策使用完整的租约 CAS， 耗尽重试警报恰好是一次，并且崩溃截断的账本尾部是 在下一次追加之前被隔离。独立 CLI 和运行时 API 重启 控件现在通过真正的执行器驱动替换尝试 终端接收，而每次运行管理器所有权会阻止并发 控制器不会两次发起相同的尝试。
  • 保持停船工作流程夹具限制为测量的每转 24k 角色 预算和 360k 总计。现已编写儿童步数和墙壁时间限制 到达实时运行时，包括启动队列等待；提升的证据保留 角色之间保持完整，无工具切换消费者省略了工具字段 提供商线路，并且终端 BLOCK 使工作流程失败而不是产生 成功的巷收据。自由形式的描述不再捏造， 外壳或网络风险；未知的结构性风险仍然无法关闭。
  • 保持存储库 trust 肯定且明确：仅公布 1/Y 作为接受键，而 Enter 仍然是非肯定键并解释 所需的选择。
  • 替换简体中文设置中的字面法律和教义隐喻 /constitution 副本，包含由专家审核的直接协作术语 母语人士（#4369 by @hmr-BH）。
  • 当内联审批卡处于活动状态时，保持成绩单可审阅： 向上/向下翻页、修改箭头、Home/End 和鼠标滚轮现在可以移动 不改变或驳回待决决定的可见证据 （#4371 作者：@amuthantamil）。
  • 将生成的工作人员名称与活动 UI 语言相匹配，同时保留 明确的用户名，并收紧跨舰队行的 89x50 shell 节奏， 选择对话框、转录边界和空闲作曲家。
  • 在小屏幕上将文档内容和搜索放在完整索引之前，减少 移动死区，并使公共社区文案重点关注问题， 拉取请求和国际贡献者。

改变了——水下贝壳

  • 用水下交互系统替换默认的TUI外壳：一个 渲染器拥有标题、顶部工作条、转录分类帐、作曲家和 页脚，具有明确的紧凑/正常/宽层，并且没有旧的侧边栏或 默认路径中的仪表板。遗留的作品仅在后面幸存 内部classic处理。
  • 添加独特的会话前启动屏幕 - 新会话、新工作树（带有 内联命名和实际通道配置），范围恢复计数，changelog， 退出 — 具有可靠的非冲突按键和行/键盘奇偶校验。
  • 渲染变成账本：用户消息、简短叙述、固定工具 收据，而且正好是一排。快速工具爆裂直接着陆 批量收据（无旋转搅拌机），完整的收据可供检查， 故障会导致珊瑚收据与标准错误一 v 相距，并且一共享 工具栏取代了嵌套的卡片边框。
  • 一口气完成：working -> finishing -> done 仅页脚，没有文字记录重绘，没有挥之不去的循环，也没有陈旧的内容 取消已完成状态下的操作。
  • 按照一种细小的语法重建次要房间——配置、设置、 会话、帮助、上下文、主题、模型/路线、车队、文件附加 — 每个 带有标题细线，带有焦点/选择/鼠标奇偶校验的行对象， 一个面板拥有的滚动导轨，以及包裹的动作页脚。
  • 使 /model 成为跨配置的模型优先原子路由选择器 提供者：提供者和模型在应用时一起切换，并且每一行 打印解析后的模型。 /theme获得真实的实时预览 Esc 可恢复所有 12 个已发布的主题。
  • 添加由当前路由支持的实时上下文检查器 (Alt+C)：精确 系统/消息/免费令牌桶，比例图，向下钻取 详细信息寻呼机，并且在打开时没有冻结会话。
  • 项目工作流程作为流内运行图运行：折叠的单行卡 展开为每通道行，包含角色、已解析模型、工作树、 经过的跟踪，以及每个成员的运行/等待/失败/取消/完成 状态，加上门和仅根据实际运行数据构建的汇报。儿童 转录本永远不会淹没父外壳。
  • 将舰队统一到名册/设置/工人房间：首先固定操作员 通过实时会话路由，成员显示已解析的路由真相（继承/ 快车道/固定），工人选项卡是一个控制界面 行本地打开/停止和实际生命周期计数。
  • 区分存储库法批准与普通批准： 宪法提示命名其权限、来源、匹配规则和目标， 完全访问永远不会绕过它。普通批准呈现为静态 可见转录物上方的珊瑚带。
  • 保持诚实和廉价的流媒体：提供者单位增量取代每个字素 排队，转录本是顶部锚定的，所以附加的行停止移动 固定行，环境动画在实际工作期间停止，而普通 完成不再触发全屏清除（通过 render-diff 验证 日志：流式传输时数十个单元的后缀更新，零周期 全面重绘）。
  • 赋予每一次水下治疗环境生命：Ombre 呼吸着水 柱而平，码头自有，保留闲鱼和气泡 （仅适用于终端的前台），键入的处理设置替换字符串 比较，减少运动清晰地冻结了生命，fancy_animations = false 会使铬静止，打字会立即分散鱼。鱼 与占用的文本保持一个单元格的间隙；鲸鱼仍然是单一品牌 标记并在碱扫之间恢复静止。
  • 使用柔和的对角碱扫使鲸鱼标记栩栩如生，然后让它变得栩栩如生 真正的休息。活动标记现在共享更平滑的 8 Hz 时钟 现有的赢得运动延迟，同时减少运动，隐藏/屏幕外视图， 模式所有权和紧凑型终端重划预算仍然具有权威性。 该动作改编自 Apache-2.0 Grok Build 交互语言， 不复制为全局脉冲或高频接收级联。
  • 保持紧凑型终端可操作：/config 和 /resume 折叠 在牺牲 40x12 的可选行之前进行辅助镀铬 60x16，页脚实际包裹高度的主体预算，以及 通过调整大小，选择保持可见。
  • 通过分类吐司系统路由页脚通知，以便提供信息 确认（例如“自动压缩已启用”）过期而不是 成为永久闲置的镀铬物，而警告和错误仍然存在 注意到直到他们的窗口过去。
  • 完成CODEWHALE_ASCII_SAFE=1装饰层：鲸鱼标记， 上下文计，盲文状态标记（按点密度映射，因此工作 气泡仍然读作上升填充）、气泡、轨道和角色/车道字形 当用户、模型和 CJK 文本传递时，所有内容都缩小为语义 ASCII 通过原封不动。通过全表面渲染缓冲区扫描进行验证。
  • 修复帮助目录以匹配处理程序真相（Alt+G、Alt+Shift+G、 Alt+[、Alt+]、Alt+L、Alt+?），并给出主题、帮助、模型和 配置行直接鼠标路径，激活方式与 Enter 相同。

  • 工具挂起看门狗时间从 15 分钟缩短至 10 分钟 (#1862)；审批模式 页脚提示使用更高对比度的层（#3380）；状态/模式副本是 在页眉、页脚、卡片和侧边栏上披露一次，而不是 每层重复一次。
  • 删除了未使用的 tui::whale_routes 分类模块及其测试。 由 Darrell Thomas (@DarrellThomas) (#4041, #3852) 贡献。

已弃用

  • YOLO模式：--yolo、default_mode = "yolo"和热键YOLO操作 现在通过兼容性填充程序映射到 Act + Full Access 权限 显示一次性弃用通知。 v0.9.0 后的移除被推迟，因此 如果没有专门的切换，此版本不会破坏现有脚本。

已删除

  • 删除此中已弃用的 deepseek 和 deepseek-tui 二进制垫片 打破释放。 codewhale、codew 和 codewhale-tui 是受支持的 入口点；现有 DeepSeek 提供商支持和旧配置/会话 迁移保持完整。

已知问题

  • Android/Termux arm64 仍然是 v0.9.0 中的预览版。目标、资产布线、 更新程序选择、依赖关系图和源构建路径已自动或 静态覆盖，但 shell/PTY/config/TUI 启动和运行时行为仍然存在 未经在真实设备上验证（#4236，#4242）。不要使用 GNU/Linux arm64 在 Termux 中存档。
