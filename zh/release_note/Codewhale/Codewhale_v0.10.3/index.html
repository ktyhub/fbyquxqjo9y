Codewhale v0.10.3

v0.10.3 里有什么

Codewhale v0.10.3 带来了具有创建者模式 ([features] plugin_creator) 的统一插件界面和未修改的 DeepSeek Harness (@deepseek-ai/dsh-*) 插件兼容性、具有工作区边界、软规则、子代理返回审核和一次性重试批准的升级版自动审核守护程序，以及默认为接受编辑 (Ask → Accept Edits → Plan → Auto-Review → Full Access) 的单个 Shift+Tab 权限拨号。它将 ACP 服务器和外部代理会话（包括 Qwen Code 和 GitHub Copilot CLI）移动到官方代理 Client 协议 SDK 上，发布本机签名的 HarmonyOS ARM64 版本资产，添加经过验证的签名模型和提供者注册表通道以及统一模型 ID 解析和托管 /v1/models 定价，将设计令牌更新为 5.4.0停靠的单行批准条、折叠转弯活动、实时工作行光扫和 13 个六角点阵鲸鱼形式，添加了 claude-org 计费验证、show_data 成绩单图表、codewhale sessions migrate、DeepSeek Chatbot 网络搜索和语音工具、收到的自我更新和 codewhale uninstall，以及土地可靠性、CJK/Unicode、Windows 和沙箱安全修复。

安装

###推荐——GitHub官方发布 新的 macOS/Linux 安装（此版本中的校验和二进制文件）：

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.10.3" sh
"$HOME/.local/bin/codewhale" --version

对于 Windows，请使用下面匹配的安装程序或存档。对于现有的 直接安装，运行codewhale update；它打印可执行路径并 保留较新的版本。如果安装目录被不同的版本占用， 使用安装指南中的全新目录迁移。

二次包装——npm 和 Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

包装器下载匹配的 codewhale 和 codew 命令资源 从本版本开始。两者都包含相同的编译运行时。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/codewhale-hq/codewhale:v0.10.3

该图像公开与 codewhale 和 codew 相同的运行时。的 latest 标签也在发布时进行了更新。

货物（Linux / macOS）

cargo install codewhale-cli --locked

Cargo 包安装 codewhale。 Cargo 无法创建第二个命令 来自一个二进制目标的别名；想要更短拼写的用户可以添加 codew 到已安装的可执行文件的符号链接。 npm、Homebrew、存档、 shell-installer 和容器通道直接安装这两个命令名称。

手动下载——平台档案（推荐）

下面的每个存档都包含 codewhale 下的相同运行时和 codew 命令名称，加上安装脚本：

Unix（Linux / macOS）： 
tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows：

  • 对于安装程序路径，运行 CodeWhaleSetup.exe；它安装 codewhale.exe、codew.exe 和 codewhale.bat 下 %LOCALAPPDATA%\Programs\CodeWhale\bin，将该目录添加到 当前用户路径，并创建一个首选的开始菜单快捷方式 安装后的 Windows 终端 (wt.exe)。
  • 提取您机器的存档：codewhale-windows-x64.zip 或 codewhale-windows-arm64.zip
  • 双click codewhale.bat（不是原始的.exe）推出
  • 运行 install.bat 将二进制文件和启动器复制到 %USERPROFILE%\bin
  • 将 %USERPROFILE%\bin 添加到您的路径 便携式 Windows 存档会跳过安装脚本 - 从任何目录提取并运行 codewhale.bat。 NSIS 安装程序当前未签名，可能会触发 Windows SmartScreen，直到签名证书连接到发布管道。 每个平台还有 裸露、未存档 codewhale-<platform> 和 codew-<platform> 资产。七个 codewhale-tui-<platform> 文件名 附加到 v0.9.5 的是字节相同的兼容性副本，仅用于让 已安装的 v0.9.4 clients 发现并跨越这个单一二进制文件 过渡；当前的安装程序不会公开第三个运行时。遗留的 npm 软件包 deepseek-tui 已弃用并且不会重新发布。用于迁移 来自 v0.8.x 旧二进制名称，请参阅 docs/REBRAND.md。

验证（推荐）

从该版本下载校验和清单并验证：

sha256sum -c codewhale-bundles-sha256.txt --ignore-missing

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt --ignore-missing

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt --ignore-missing
shasum -a 256 -c codewhale-artifacts-sha256.txt --ignore-missing
