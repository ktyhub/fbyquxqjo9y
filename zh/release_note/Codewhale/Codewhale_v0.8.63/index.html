Codewhale v0.8.63

CodeWhale 是规范的项目、命令、npm 包和 发布资产名称。旧版 npm 包 deepseek-tui 是 已弃用并且不再收到进一步的版本。用户来自 v0.8.x 旧版 deepseek / deepseek-tui 名称应迁移 与 docs/REBRAND.md。

安装

推荐 — npm（一个命令，两个二进制文件）

npm install -g codewhale

包装器从此版本下载两个二进制文件并将它们放在同一目录中。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.63

该映像附带了 codewhale 调度程序和 codewhale-tui 运行时。 latest 标签也在发布时进行了更新。

货物（Linux / macOS）

cargo install codewhale-cli codewhale-tui --locked

这两个包都是必需的 - codewhale-cli 生成 codewhale 调度程序，而 codewhale-tui 生成调度程序委托给的交互式运行时。仅安装一个二进制文件将在运行时失败并出现 MISSING_COMPANION_BINARY 错误。

Unix（Linux / macOS）： 
tar xzf codewhale-<platform>.tar.gz

Windows：

  • 对于安装程序路径，运行 CodeWhaleSetup.exe；它会在 %LOCALAPPDATA%\Programs\CodeWhale\bin 下安装两个二进制文件，并将该目录添加到当前用户的 PATH 中。
  • 提取codewhale-windows-x64.zip
  • 运行install.bat（复制到%USERPROFILE%\bin）
  • 将 %USERPROFILE%\bin 添加到您的路径 便携式 Windows 存档会跳过安装脚本 - 从任何目录提取并运行。 NSIS 安装程序当前未签名，可能会触发 Windows SmartScreen，直到签名证书连接到发布管道。 每个平台还附有裸露的、未存档的二进制文件（codewhale-<platform> 和 codewhale-tui-<platform>） - 这些是 npm 包装器和应用内 codewhale update 下载的内容，而上面的 .tar.gz / .zip 存档是建议的手动下载，并另外捆绑安装脚本。旧版 npm 包 deepseek-tui 已弃用并且不会重新发布。有关从 v0.8.x 旧二进制名称的迁移，请参阅 docs/REBRAND.md。

v0.8.63 里有什么

添加

  • 子代理扇出保护措施（#3318、#3319）。 高扇出工作流运行可以 现在排队并耗尽比瞬时并发上限更多的代理 默认值，可使用 [subagents] max_admitted 来调整该界限 招生人口。不同的 agent 调用不再受 运行时启动并发和提供程序之前的每回合循环保护 可以应用速率限制退避。 [subagents] token_budget适用于共享 根 agent 运行及其后代的聚合令牌上限。
  • 每个工作人员子代理令牌强制执行 (#3321)。 A token_budget / 在单个 agent 调用上设置的 max_tokens 现在限制该单个工作人员 中期：一旦其累积的模型代币超过上限，它就会干净地停止 具有 budget_exhausted 状态，而不是运行到 max_steps。这个 补充范围级准入门（#3319）——每个工人的上限停止 一名失控的工人，范围上限限制了总扇出——没有 重复计算。由@donglovejava 从#3321 中收获。
  • 特定于提供商的子代理扇出配置。 [subagents.providers.<provider>] 配置文件现在覆盖 enabled、max_concurrent、max_admitted、 launch_concurrency、max_depth、代币预算、API 超时和心跳 活动提供者超时。使用广泛的直接 API 配置文件，例如 [subagents.providers.deepseek] 和更严格的订阅配置文件，例如 [subagents.providers.glm]; /config subagents status 显示全局 和活跃提供商解析值。
  • **子代理控制和隔离。**单个 agent 工具现在公开 正在运行的子进程的状态、查看和取消操作，并接受 worktree: true 创建一个独立的 git 工作树/分支以进行并行编辑 车道，而不是要求呼叫者手动滚动 cwd。

已修复

  • **模式和工具目录的正确性。**核心操作工具仍然可发现 在面向模型的目录/工具搜索中，以及一致性自检标志 已注册的处理程序偏离了广告目录。回顾性的 显式 Agent/YOLO 模式下的提示现在保留请求的模式和工具， 仅提供咨询性审查提示。
  • **子代理编排恢复。**子代理现在重试瞬态 失败前提供程序标头/SSE 超时，并且父运行合成丢失 来自终端子状态的子完成，因此编排不能挂在 丢失完成事件。
  • DeepSeek 思维工具调用。 DeepSeek 聊天完成请求现在省略 每当启用推理/思考时，显式 tool_choice ，避免 提供商拒绝，同时保持不加思考的路线不变。
  • 任务侧边栏快捷键和归属。 Ctrl-K 保持调色板/emacs-kill， 而 Ctrl-X 的作用范围是任务侧边栏后台 shell 取消。壳牌 由子代理启动的作业现在由其子代理所有者在 任务侧边栏和文字记录。
  • **基准转向复苏和背景经济。**重复只读搜索 循环块现在返回指导而不是致命的工具故障，Python 构建 缺少 setuptools 的故障包括安装/重试提示，长 前台 shell 超时会将模型引导至后台执行，并且存在噪音 shell/test/web 输出会更早地针对大上下文路由进行压缩。
  • 配置显示密文。 codew config get/list 现在递归屏蔽 内部有类似令牌、秘密、密码、凭证和授权的密钥 未知的 extras 表并在之前编辑了敏感的 HTTP 标头值 打印配置输出。
  • 排队后续提示和强制转向键。 现在等待输入预览 每当存在排队的后续任务时就通告 Ctrl+S send now，并且 Ctrl/Cmd+Enter 强制转向也接受常见的 Ctrl+J 终端 轮流运行时进行编码。
  • **恢复侧边栏默认可见性（#3328）。**新的和升级的会话 现在，当终端很宽时，默认使用固定组合侧边栏 足够了，因此实时代理和任务会浮出水面，而无需选择返回空闲状态 自动崩溃。捕获 v0.8.62 自动折叠的旧设置文件 默认现在迁移到 pinned 除非 /sidebar auto --save 记录 明确选择加入。 /sidebar 现在报告宽度或自动折叠 抑制渲染而不是说侧边栏可见。报道者 @dxfq。
  • JavaScript 执行代理环境处理（#3273、#3331）。 js_execution 现在当存在代理变量时启用 Node 的环境代理模式， 镜像子进程的小写代理变量，并回填 HTTP_PROXY / HTTPS_PROXY 来自 ALL_PROXY。由@lordwedggie 报道和 由@cyq1017 从 #3331 中收获。
  • 旧版应用程序服务器非环回身份验证强化 (#3258)。 裸露 codewhale app-server --host 0.0.0.0 现在会快速失败，除非明确 提供 --auth-token 或 CODEWHALE_APP_SERVER_TOKEN，保持生成状态 一次性 cwapp_* 令牌仅环回。
  • 旧版 .deepseek 状态写入路径迁移 (#3240)。 状态子目录 （sessions、slop_ledger、trophies、catalog）现在始终写在下面 ~/.codewhale/，子目录的第一次写入会重新定位任何预先存在的 ~/.deepseek/<sub> 内容写入主要位置，以便遗留树停止 在保留旧数据的同时不断增长。读取解析器仍然找到遗留数据 用于回填，直到每个子目录迁移。 @Final527 报道；入职 @nightt5879 的 #3302 标记切片。
  • Windows 上的状态子目录验证 (#3240)。 现在状态路径强化 在解析之前拒绝根/前缀子目录字符串，例如 /etc 或 迁移状态目录，将 .codewhale 写入解析器保留在内部 其跨平台的状态根。 此版本的贡献者积分位于上面的 changelog 条目中 — 感谢所有参与其报告、公关、评论和复制品的人。 有关完整说明，请参阅 CHANGELOG.md；有关旧版本，请参阅 docs/CHANGELOG_ARCHIVE.md。
