orca v1.4.233

orca v1.4.233

非常感谢您使用 Orca 并一直以来的支持！ ❤️ 我们今天发布了两个版本！如果您错过了，也请查看 v1.4.232 release notes。亮点包括手动/自动/Yolo 代理权限、本机聊天中的 OpenCode 2、具有文件附件和内联技能的更好的手机编辑器、更流畅的 SSH 恢复以及具有更快 Mac 更新的更小应用程序。 手机更新： 更新桌面上的 Orca 还会更新所连接手机上的应用程序 - 手机直接从桌面加载该应用程序。

简短版本

  • SSH 和远程工作空间： 当两台机器都无法下载 Node.js 时，连接到 SSH 主机可以正常工作，Orca 会记住并重试一个 click 镜像。较旧的 Windows 主机（Windows 10 1809 和 Server 2019）可以运行 Orca 的服务器，并且当旧的 SSH 连接占用端口时，隧道会恢复。
  • 设置中的远程服务器： 远程 Orca 服务器是一个列表，而不是六个部分，并且 SSH 主机可以批量删除并保持删除状态。当同一个服务器被保存两次时，Orca 会告诉您，并添加您已保存的服务器来更新它。
  • 电话： 从手机创建工作区要快得多，工作区列表与桌面保持一致，会话选项卡图标在长标题旁边保持其大小。
  • 编辑器： Orca 拒绝保存对磁盘上您未见过的文件所做的更改，并且之后的重新加载和撤消行为将按预期进行。
  • 日常润色： 不同机器上具有相同名称的项目保留短名称并显示它们所在的机器。当 Orca 扫描会话历史记录时，长期保存的对话使用的内存要少得多。

产品体验

SSH、托管服务器和远程

SSH 主机在更多情况下连接，远程 Orca 服务器是一个清晰的列表，并且编辑始终会转到拥有工作区的计算机。

  • 当两台机器都无法在 https://github.com/stablyai/orca/pull/31069 中下载 @nwparker 的 Node 时，One-click Node.js 镜像
  • 一旦正在运行的连接失败，请使用保存的 Node.js 镜像重试，@nwparker 在 https://github.com/stablyai/orca/pull/31089 中以同样的方式重试
  • 运送node-pty的winpty后端，以便Windows 1809 / Server 2019主机可以通过@nwparker在https://github.com/stablyai/orca/pull/31056中部署
  • 转发无法启动的托管隧道占用 stdio 桥，并回收 https://github.com/stablyai/orca/pull/31062 中 @nwparker 持有的旧 ControlMaster 端口
  • 在同一套接字上重新启动的传统继电器永远不会接管 https://github.com/stablyai/orca/pull/31068 中@nwparker 打开的选项卡
  • 通过 https://github.com/stablyai/orca/pull/31077 中的 @nwparker 跨 SSH 和 WSL 可靠地检测 Linux 库
  • 远程 Orca 服务器：一个列表而不是六个部分； SSH 主机：批量删除，在 https://github.com/stablyai/orca/pull/31082 中被 @nwparker 保留删除状态
  • 添加您已保存的服务器会更新它，而不是通过 @nwparker 在 https://github.com/stablyai/orca/pull/31080 中保存两次
  • 说明哪些保存的服务器是同一台机器配对两次，以及如何通过 https://github.com/stablyai/orca/pull/31100 中的 @nwparker 修复它
  • 在 https://github.com/stablyai/orca/pull/31099 中 @nwparker 在 UI 中说“Orca on ”而不是“托管服务器”
  • 移动的 SSH 主机在 https://github.com/stablyai/orca/pull/31064 中 @nwparker 的项目可用主机中列出一次
  • 新的本地项目永远不会通过 @nwparker 在 https://github.com/stablyai/orca/pull/31055 的同一路径上对 SSH 项目进行重复数据删除
  • PR/MR工作树库拒绝https://github.com/stablyai/orca/pull/31054中@nwparker仅以executionHostId命名的SSH项目
  • Worktree create 发送 @nwparker 在 https://github.com/stablyai/orca/pull/31066 中选择的主机 —project/—host
  • 编辑器按行写入和不合格的删除路由，而不是 @nwparker 在 https://github.com/stablyai/orca/pull/31036 中的活动服务器焦点
  • 没有所有者路由读取活动服务器焦点，因此本地行永远不会通过 https://github.com/stablyai/orca/pull/31058 中的 @nwparker 路由到焦点服务器
  • 损坏的浏览器文件列表仅禁用浏览器 client，而不禁用 https://github.com/stablyai/orca/pull/31025 中@nwparker 的远程服务器
  • 实时 orcad 的浏览器助手在 https://github.com/stablyai/orca/pull/31059 中由 @nwparker 暂停 macOS 桌面安装

  • 在 https://github.com/stablyai/orca/pull/31169 中 @AmoabaKelvin 的长标题旁边保持会话选项卡图标为全尺寸
