orca v1.4.237

100,000 颗星。谢谢你！ ⭐🐳

Orca 刚刚在 GitHub 上突破 100,000 颗星！每个错误报告、拉取请求、共享工作流程和建议都帮助我们实现了这一目标。感谢您与 Orca 一起构建并帮助塑造接下来的发展。 ❤️ 为了庆祝，此版本带来了更强大的电话体验、更可靠的代理对话以及使您的工作能够在桌面和远程计算机之间移动的修复。

简短版本

  • 通过手机完成更多工作： 创建和编辑笔记、在无头主机上保存 Markdown、跟踪相关文件链接以及查看嵌入的图像。缓冲的终端草稿现在也可以在工作区导航中幸存下来。
  • 您可以返回的聊天： Codex 聊天在撤消后可以正确重新打开，Claude 在 Orca 回滚过程中保留其回绕上下文，并且屏幕截图保留在对话中。 Codex 的技能选择器现在反映了 Codex 实际加载的技能。
  • 您的工作保持受保护： 放弃会暂停跨工作区自动保存同一文件。只读 Markdown 和 CSV 视图可以保护您未保存的编辑，并且新的、未暂存的 Markdown 文档可以直接在丰富的编辑器中打开。
  • 桌面之外的语音： 电话听写再次通过无头 orca serve 主机工作，并使用 CLI 命令配置主机的 OpenAI 密钥。
  • 更顺畅的远程工作： 重新启动后重新连接隐藏的终端选项卡，在主机再次配对时保持浏览器登录状态，并在不冻结界面的情况下搜索数千台主机的 SSH 配置。
  • 小细节，更好的流程： 电话选项卡遵循桌面顺序，横向布局显示会话标题，键盘控件保持其高度，工作树安全扫描跳过未更改的工作区。 手机更新： 在为您的手机提供服务的计算机上更新 Orca 也会更新手机的服务界面。持久的终端草稿还需要更新的移动外壳。

兼容性和升级说明

  • 本机聊天（实验性）： 与 Orca 一起更新配对主机和 SSH 主机以获得最新的聊天修复。可以在具有支持主机的桌面上进行精确的 Codex 技能文件选择；电话选择和较旧的主机保留纯文本技能名称。将技能作为新消息发送给 Codex，以便在回合开始时应用它。
  • 无头听写： 将 OpenAI 密钥保存在使用 orca speech openai-key set 进行转录的主机上（从标准​​输入读取密钥）。 Linux 和 macOS 上的已安装应用程序 orca serve 主机也可以使用捆绑的设备上识别器； Windows、托管 SSH 和 WSL 服务器使用云模型。
  • CLI 启动选择： 显式 --surface 选择需要更新的执行主机。省略该选项将保留现有的默认值。
