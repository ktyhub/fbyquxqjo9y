orca v1.4.268

今天我们发布了多个版本。也请查看 1.4.267 和 1.4.266。

更多代理、更丰富的 Slack 和更快的 Orca 上的机器人 ✨

机器人现在可以在 Cursor、GitHub Copilot 和 Hermes 上运行，Slack 获得调度和画布，Orca 在后台执行的工作更少，因此感觉更快。

  • 🤖 在更多代理上运行机器人： 机器人可以在 Cursor、GitHub Copilot 和 Hermes 上运行，并且 OpenCode 2.x 机器人获得其常设指令。新的机器人获得了身份证，灵魂与记忆重新设计了编辑器。
  • 🖼️ 发送图像和文件： 在机器人聊天、群聊和项目评论中附加图像和文件，包括附加到配对计算机上的机器人。 Slack 请求上的图像作为图像到达代理。
  • 💬 来自 Slack 的更多信息： orca slack post --at 安排稍后发布帖子，新的 pin、canvas、list 和 scheduled 命令涵盖图钉、画布和列表。连接 Slack 会获取复制的令牌，而无需额外的 click，并提及读取为名称。
  • ⚡ 更轻、更流畅的 Orca： 动画再次平稳运行，而不是每秒运行一次，旋转器和脉冲绘制更少的帧，凭证读取移出主线程，并且自动堆配置文件消失了。 Orca 还建议在磁盘快满时清理工作区。
  • 🧭 更可靠的工作人员和聊天： 因崩溃或重启而中断的聊天可以继续，工作人员的最终报告会唤醒启动它的代理，并且聊天中的工作人员名称会打开工作人员。 Chat 还修复了 Antigravity、Claude、Codex 和 Droid。
  • 🌐 在远程主机上注释页面： 浏览器注释现在也可以在远程主机上使用。

关于 Orca 机器人（测试版）

Orca 机器人像一流的队友一样工作：每个托管代理会话都会获得其工具和身份，机器人可以代表所有者进行共享，它们更可靠地遵循 Slack 线程和 Gmail 触发器，并且连接它们更清晰、更安全。

  • 每个机器人会话都会获得其工具和身份： 托管代理会话不再仅限于 Claude 和 Codex；每个人都从其所需的工具和身份开始。
  • 🔗 机器人可以共享，就像所有者一样： 代理 CLI 呼叫者可以像所有者一样使用共享。
  • 💬 松弛线程显示机器人正在做什么： 线程现在反映了轮到它正在做什么，长答案会完整到达而不是被分割。
  • 📬 Gmail 触发器与真实发件人匹配： 触发器与发件人的实际地址匹配，而不是可能不同的显示名称。
  • 🛡️ 更清晰的访问警告： 访问确认对话框现在会在连接机器人之前阐明您允许的内容。
