orca v1.4.239

今天发布两个版本！ 也请查看 v1.4.238 release notes。该版本带来了跨工作区共享未保存的编辑、更丰富的代理聊天和远程帐户设置、功能更强大的浏览器以及更流畅的电话控制。

你的工作空间，一起工作🐳

在一台 click 中设置代理技能，将浏览器会话在项目之间分开，并在聊天和终端之间更轻松地移动。此版本还增强了基本功能：共享文件保持同步、SSH 会话恢复更可靠、电话交互感觉更可预测。

简短版本

  • 技能，随时随地准备就绪： 从设置屏幕将 Orca 的技能安装到一台 click 中，并使用 Orca 自己的安装程序在配对服务器和 SSH 主机上安装或更新它们。
  • 适合您项目的浏览器： 为新选项卡选择共享、每个存储库或每个工作空间配置文件。将本地应用程序登录分开，使用熟悉的页面上下文菜单，并在页面无法加载时获得更清晰的解释。
  • 更流畅的座席对话： 在当前聊天旁边拆分成新的聊天，从窗格标题继续使用终端座席，并保持排队的消息和多个图像附件完好无损。
  • 更安全的编辑，更安静的后台工作： 共享文件视图在撤消和丢弃后保持最新状态。非 UTF-8 文件在转换前询问，文件监视在速度变慢后恢复，Orca 监视的不相关文件更少。
  • 远程工作返回： 从“设置”中的陈旧锁定中恢复受支持的托管 SSH 服务器，在密码登录后恢复终端，并通过重新启动保留配对服务器的 SSH 访问链接。
  • 通过手机更好： 点击通知会打开发送通知的代理，代理聊天选项卡可以开始听写，终端复制命令到达手机 clipboard，Android 滚动可让键盘不受影响。
  • **跨语言的日常润色：**更好的韩语输入、孟加拉语和其他印度语终端渲染、更完整的翻译、Jira 用户选择器以及直接跳转到编辑器的 PR 评论链接。 手机更新： 在为您的手机提供服务的计算机上更新 Orca 会更新所提供的界面。本机下载、进度和导航改进需要更新本机手机应用程序。

兼容性和升级说明

  • 浏览器配置文件： 选择 设置 → 浏览器 → 新选项卡配置文件。 共享保持默认；每个存储库和每个工作空间的配置文件适用于新选项卡。配对服务器页面使用服务器自己的配置文件。
  • 本机聊天（实验性）： 与 Orca 一起更新配对主机和 SSH 主机，以获取最新的聊天和启动修复。聊天可用性现在与终端 CLI 分开检查聊天运行时，包括支持的反重力设置。
  • SSH 恢复： 恢复服务器… 适用于报告过时锁定拒绝的受支持托管 Linux SSH 主机。它会检查锁并要求您确认共享该主目录的其他计算机没有运行 Orca，然后再清除它。电话会将您引导至桌面设置。
  • 实验基础工作： 布局所有者基础工作仍然处于禁用状态。空组启动操作和子工作区状态切换在发布前已恢复。
