orca v1.4.227

orca v1.4.227

非常感谢您使用 Orca 并一直以来的支持！ ❤️

简短版本

  • 原生聊天有自己的权限模式。 从“设置”→“聊天”→“行为”为每个新的 Claude 或 Codex 聊天选择权限；现有的聊天保留他们已经使用的模式，并且更改模型不再重置它。
  • 本机聊天会话更容易继续。 您可以在新的本机聊天中恢复大型终端对话，恢复重启后在后台运行的唯一工作的聊天，并在会话历史记录中准确查看每个受支持的聊天提供程序。
  • Claude 帐户和 Codex 聊天设置更加流畅。 Claude 帐户再次使用单独的文件夹，可以复制登录链接，Codex 聊天需要 0.136.0 或更高版本，并且 Codex Ultrafast 可作为速度选择。
  • 浏览器自动化让您的键盘可靠地恢复。 代理浏览器命令针对预期页面，浏览器弹出窗口的行为更像 Chrome。
  • **此外：**工作树清理更安全，读取 macOS 通知会从通知中心消失，长时间聊天在手机上加载效果更好，冷会话历史记录读取可避免不必要的重新索引。
