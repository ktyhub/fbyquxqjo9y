orca v1.4.243

Orca 浏览器中的 Chrome 扩展、iPhone Duo 支持以及将终端代理会话实时转换为聊天 ui 🧩

此版本为 Orca 浏览器带来了实验性的 Chrome 扩展，一旦您在终端中退出其代理，对话就可以继续在 Chat 中进行，并在重新启动后尽快显示您的本地工作树。它还增加了对折叠 iPhone Duo 的支持、紧凑的原生风格菜单、手机上的浅色和深色主题，以及针对 Windows 终端、SSH 主机和更新的修复。

简短版本

  • Chrome 扩展程序（实验性）： 使用 Add to Orca 从 Chrome Web Store 添加扩展程序，因此 Bitwarden 和 1Password 等密码管理器可以在 Orca 浏览器中填充登录信息。默认关闭。
  • 将终端代理会话实时转换为聊天 ui： 一旦您在终端中退出 Claude 或 Codex，相同的对话可以在终端选项卡保持打开状态时在 Chat 中继续。 Claude 聊天还可以在模型更改期间保留保存的批准选择，并首先询问关闭仍在运行的聊天。
  • 重新启动后更快的工作树： 本地工作树在终端恢复之前加载，侧边栏显示发现仍在运行，而不是显示空列表。
  • 更稳定的终端： Windows 终端通过宽度变化保留其历史记录，睡眠终端在您离开的文件夹中唤醒，macOS 的内置 bash 在 DEBUG 陷阱更改后按顺序保持命令跟踪，并且从远程主机上的 pi 进行复制到达您的 clipboard。
  • 编排： 选择工作人员心跳间隔或关闭心跳，并通过停止固定工作人员轮询命令来减少 CPU 使用率。
  • 完善重要的地方： 紧凑的本机样式菜单、带有粘性标题的 VS Code 样式 Markdown 突出显示，以及通过设置代理进行更新检查。
  • 来自社区的修复： 退出并停止所有会话、聊天中的数学、复制带有行范围的远程 URL、终端中的 IME 突出显示、Windows 上的 fnm 以及日语和中文翻译都工作得更好。 电话和网络更新： 手机获得浅色和深色主题，支持折叠式 iPhone Duo、快速查看中的 PDF 以及聊天中的复制按钮。现在，许多手机屏幕都遵循桌面的聊天、源代码控制和终端规则，并且在长时间聊天中打字和滚动可以保持快速。

兼容性和升级说明

  • 新终端主机： 新终端在新终端主机上启动，因此此版本的终端修复适用，包括在其终端代理退出后继续聊天。更新之前已打开的终端将在前一个主机上继续运行并保持连接，直到您将其关闭。
  • 浏览器扩展（实验性）： 打开 设置 → 实验 → 浏览器扩展，重新启动，然后在 Orca 浏览器选项卡中打开 Chrome 网上应用店。扩展程序仅在本地浏览器配置文件中运行。广告拦截器已安装，但尚未拦截，并且某些扩展程序（例如 Tampermonkey）不起作用。
  • 工作人员心跳： 默认情况下，心跳每 5 分钟保持一次。 设置→代理编排中的更改适用于新派遣的工人；已经运行的工作人员保留简短的发言，老主人保留 5 分钟。
  • 克劳德子代理导航： 标记您正在查看的子代理的眼睛消失了。查看的子代理行使用正常的当前行突出显示。
