orca v1.4.269

继1.4.268之后，这是虎鲸的下一轮。机器人又学习了八个代理，手机应用程序赶上了桌面应用程序。

新增 8 个代理、功能更齐全的手机和更安静的 Mac 上的机器人 ✨

机器人现在可以在 Kiro、Kimi Code、Auggie、Gemini CLI、Kilo Code、MiMo Code、Droid 和 Goose 上运行，聊天可以直接打开更多代理，手机应用程序可以应答、批准和设置桌面可以进行的几乎所有操作。

  • 🤖 在更多代理上运行机器人： 机器人可以在 Kiro、Kimi Code、Auggie、Gemini CLI、Kilo Code、MiMo Code、Droid 和 Goose 上运行。聊天也可以打开 Kiro、Auggie 和 Goose，并且 Kiro 聊天运行您自己的钩子。
  • 📱 通过手机执行更多操作： 从聊天中回答客服人员的问题和 Google 或 Composio 设置卡、在“需要您”中查看工具批准和访问请求、管理客服人员的工具和 Webhooks、从 + 开始新的聊天以及浏览群组的线程和项目。这些需要匹配的移动版本。
  • 🔐 反重力，你的方式： Google 帐户用户可以选择 Orca 的内置 Google 登录或 agy 代理，并且 agy 有自己的登录设置。
  • 💤 空闲时更安静的 Mac： 空闲的 Mac 终端使用较少的 CPU，Git 工作在 macOS 和 Linux 上的后台进程工作器上启动。
  • 🧭 更清晰的聊天： 较旧的消息显示日历日期，恢复在暂停的队列中脱颖而出，而设置阻止完全访问的克劳德聊天如此说并选择最接近的允许模式。

关于 Orca 机器人（测试版）

Orca 机器人的工作方式就像一流的队友：它们现在运行在更多的代理上，在小组房间中相互协作，并发送您可以实际打开的结果。

  • 机器人背后还有八个代理： Kiro、Kimi Code、Auggie、Gemini CLI、Kilo Code、MiMo Code、Droid 和 Goose 加入了机器人可以运行的代理。
  • 链接在机器人发布时显示进度，您可以直接从其“授予访问权限”对话框中拒绝访问请求。
  • 🤝 小组房间中的交接： 当机器人在其回复中将另一个成员命名为 @Name 时，该成员将接管轮流。
  • 📎 您可以打开的结果： 机器人共享链接、附加文件或提供内容而不是自己计算机上的路径，并且 Slack 消息中的本地路径成为可读标签。
  • 🧩 每个机器人一个技能文件夹： 机器人自己的技能位于一个与代理无关的文件夹中，它运行的每个代理都可以使用该文件夹。
