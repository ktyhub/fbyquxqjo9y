orca v1.4.230

非常感谢您使用 Orca 并一直以来的支持！ ❤️

简短版本

  • 本机聊天（实验性）： 在聊天中使用反重力，选择哪些代理作为聊天打开，并从聊天本身安装缺少的代理。将复制的文件粘贴为附件、对图像进行排队，并在附件和队列操作待处理时查看更清晰的反馈。
  • 帐户和代理： 切换 Claude 帐户后，在新帐户上重新启动正在运行的会话。从“设置”中删除下载的代理运行时，并通过 Orca CLI 编辑或删除线性注释。
  • 电话： 就地编辑排队消息，使用桌面式卡片跟踪工具运行，并在从历史记录恢复时立即查看您的对话。横向手机将会话选项卡放在顶部栏中，任务可以清楚地表明您正在使用哪个桌面。
  • SSH 和远程工作区： 断开连接保持断开状态，睡眠工作区保持睡眠状态，关闭的选项卡在重新连接后保持关闭状态。更清晰的服务器更新和重新配对消息可帮助您恢复连接。
  • 日常润色： 快速命令快捷方式遵循聚焦分割，选项卡预览等待完整的悬停延迟，文件头提供在 Finder 中显示。工作区清理可以更好地保护其他计算机上的相同路径项目。

兼容性和升级说明

本机聊天（实验性）： 某些聊天功能需要远程主机的支持。保持主机与 Orca 一起更新，以使用最新功能。 SSH 主机上的 orca 命令： 现有主机保留显式保存的 CLI 控制首选项；未设置的首选项将迁移至关闭。要允许连接的 SSH 主机上的命令打开并控制该主机工作区的该桌面的 Orca 浏览器选项卡，请在设置 → SSH 主机 → 编辑主机 → 高级连接下启用 允许该主机的 orca CLI 控制 Orca。
