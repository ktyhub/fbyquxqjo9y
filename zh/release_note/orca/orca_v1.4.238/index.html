orca v1.4.238

更多互联工作，更安全的编辑 🐳

此版本使代理、文件、浏览器和远程计算机之间的移动变得更加容易。同一文件的选项卡现在共享未保存的编辑，本机聊天可拾取其他地方的轮流，并且手机获得更可靠的终端手势和更丰富的选项卡控件。

简短版本

  • **您的编辑保持在一起：**同一文件的选项卡在工作区之间共享未保存的文本。冲突审查可以看到实时文本、工作区删除列出未保存的文件以及过时的 Markdown 或笔记本编辑不再覆盖较新的工作。
  • 持续的聊天： Codex 和 Pi 显示聊天之外的轮流。长粘贴可以成为文本附件，Codex 问题可以获得答案卡，OMP 可以获得图像发送和可操作的计划审查卡。
  • 对代理进行更多控制： 创建工作区时选择聊天或终端，为默认代理设置该选择，在支持的远程服务器上添加 Claude 和 Codex 帐户，并为另外 11 个代理安装共享技能。
  • 功能更强大的浏览器： 工作区感知的新选项卡、地址栏建议、记住的站点权限、每个站点的外观和缩放以及桌面和手机上的页面加载进度。
  • 更流畅的电话体验： 在选项卡中查看座席活动，双击重命名，向后滚动之前的聊天消息，更自然地选择终端文本，并在恢复后返回到终端阅读位置。
  • 更好的可见性和恢复： 检查资源管理器中的本地终端，当主机移动到 Orca 服务器被阻止时使用普通 SSH，并通过托管服务器更新和恢复保持配对。
  • 日常润色： 巴西葡萄牙语、入职期间的语言选择、​​可搜索的发布版本、更清晰的历史扫描进度，以及 使用 AI 解决 暂停的合并、变基和挑选 — 即使在文件冲突得到修复之后也是如此。 手机更新： 在为您的手机提供服务的计算机上更新 Orca 会更新所提供的界面。新的 Home → New Workspace 条目和本机 iOS 听写修复需要更新的本机手机应用程序；主屏幕条目随下一个应用程序版本一起提供。

兼容性和升级说明

  • 远程帐户： 更新新的 Claude 和 Codex 添加帐户流程的配对服务器。 Windows 服务器和较旧的主机保留 orca account add 指南。凭证保留在服务器上；现有帐户的远程重新身份验证不属于此更改范围。
  • 本机聊天（实验性）： 与 Orca 一起更新配对主机和 SSH 主机以获得最新的聊天修复。代理版本检查现在接受满足最低要求的较新版本和预发行版；已知的旧版本显示更新指南。
  • 资源管理器： 新的 PTY 视图涵盖本地终端。结束终端需要主机支持验证所选会话；老主机拒绝未经检查的终止。
  • HTML 文件： 此版本恢复了默认在预览中打开 HTML 的功能。
  • 实验基础工作： 下面列出的布局所有者和侧边栏更改仍然处于禁用状态。新的可选代理写入控件没有启用现有的呼叫者。
