orca v1.4.240

更可靠的工作空间 🐳

此版本提供了内置浏览器可搜索历史记录，使代理活动更易于跟踪，并改进了聊天和远程终端之间的恢复。您还将发现 Lean 和 Zig 语法突出显示、对更大的快速命令集合的支持，以及用于查找开发服务器的新 orca ports 命令。

简短版本

  • 与您保持联系的对话： Claude 聊天现在显示在 Orca 之外进行的回合。保留的消息在重新连接后返回，无需重新打开聊天，并且崩溃恢复不再猜测已发送的消息未送达。
  • 具有更好内存的浏览器： 搜索您的浏览历史记录、重新打开页面、删除不需要的建议以及使用撤消清除历史记录。页面还可以使用您通过文件系统访问选取、保存或删除的文件。
  • 远程工作中断较少： 缓慢的连接不会丢失唤醒探测，重新连接通知会解释发生的情况，SSH 终端等待登录，新的分片会保留在配对的服务器上。
  • 您可以 trust 的代理状态： 已完成的 Codex 子代理停止显示为“正在工作”，正在运行的主要任务通过 /side 对话保持可见，并且需要批准的 Codex MCP 工具会获得批准卡。
  • 为您的工作流程提供更多空间： 保存 40 多个快速命令，使用 orca ports 查找工作树检测到的开发服务器端口，并回收旧的依赖项安装并从开发工作树构建输出。
  • 完善重要的地方： Lean 和 Zig 突出显示、更清晰的会话搜索摘录、终端应用程序中 Mac 触控板滚动更流畅，以及更好地保护 Windows 和 WSL 之间共享的未合并分支和工作树。 电话和网络更新： 在为您的手机或浏览器提供服务的计算机上更新 Orca 会更新所提供的界面。此版本还使正在运行的 Codex 任务在 /side 对话期间在配对和移动视图上保持可见，并修复了浏览器选择或删除的聊天附件上传到配对服务器的问题。

兼容性和升级说明

  • 本机聊天（实验性）： 与 Orca 一起更新配对主机和 SSH 主机，以获取最新的聊天、代理状态和启动修复。 Codex 的新批准卡涵盖不需要表单字段的 MCP 工具批准；此更改不支持一般 MCP 表单和基于 URL 的验证。
  • 浏览器历史记录： 从页面菜单中打开 历史记录，或在 macOS 上使用 Cmd+Y，在 Linux 和 Windows 上使用 Ctrl+H。搜索、删除单个条目，或清除过去一小时、今天或所有时间，并使用“撤消”清除功能。
  • 检测到的端口： orca ports 通过主机范围的端口扫描支持运行时的工作区选择和 JSON 输出。 Direct SSH 主机尚不支持检测；本机文件夹工作区需要 --all 来列出主机的侦听器。
  • 开发清理： 开发启动时的手动 pnpm reclaim-space 和自动清理可以使用默认的 30 天截止时间回收被忽略、未跟踪的依赖项安装和旧同级工作树中生成的输出。选定的、调用的和排除的工作树仍然受到保护。在应用手动清理之前停止同级应用程序、代理、安装、构建和测试；回收的安装和输出在再次使用时需要重新安装或重建。
  • 终端文件链接： 在此版本中恢复了在 clicked 工作区中打开文件链接的早期更改。
