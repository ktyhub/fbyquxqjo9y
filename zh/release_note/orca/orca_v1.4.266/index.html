orca v1.4.266

这个项目是干啥的：桌面版AI编程调度台，让Claude Code、Codex等命令行助手在独立代码目录里并行干活并对比结果，给同时带几个AI程序员的开发者用。

上一版本：1.4.265：Orca Bots 是一流的队友，桌面更轻，适合繁忙的聊天。

Orca 机器人简介（测试版）

Orca 机器人像一流的队友一样工作：每个托管代理会话都会获得其工具和身份，机器人可以代表所有者进行共享，它们更可靠地遵循 Slack 线程和 Gmail 触发器，并且连接它们更清晰、更安全。

  • 每个机器人会话都会获得其工具和身份： 托管代理会话不再仅限于 Claude 和 Codex；每个人都从其所需的工具和身份开始。
  • 🔗 机器人可以共享，就像所有者一样： 代理 CLI 呼叫者可以像所有者一样使用共享。
  • 💬 松弛线程显示机器人正在做什么： 线程现在反映了轮到它正在做什么，长答案会完整到达而不是被分割。
  • 📬 Gmail 触发器与真实发件人匹配： 触发器与发件人的实际地址匹配，而不是可能不同的显示名称。
  • 🛡️ 更清晰的访问警告： 访问确认对话框现在会在连接机器人之前阐明您允许的内容。 我们今天发布了两个版本。也请查看以前的版本，1.4.265。

以您的方式登录反重力

反重力聊天现在可以使用 Gemini API 密钥或 Google Agent Platform (ADC) 登录，并且新聊天在登录的 agy 上运行，因此聊天、配额和所选帐户都一致。更多代理也可以开箱即用：当主机没有代理时，Orca 会安装自己的副本。

  • 🔑 Gemini API 密钥或 Google Agent Platform： 选择反重力聊天登录方式，并在聊天和配额中查看相同的帐户。
  • 📦 更多代理，随时可用： Orca 在主机没有时安装自己的 OpenCode、Cursor、Copilot、Grok、Kimi Code 和 OMP，并为每个本机聊天代理提供 CLI 更新。
  • 🛡️ 每个平台上都有更稳定的反重力： 自动更新在主机启动时保持关闭，Windows 发现和钩子时间固定，并且审核者决定工具的使用。
  • 🖼️ 图像预览： 最近粘贴和删除的图像显示预览，并且 Codex CLI 图像预览有效。
  • 📱 更友好的手机： 代理行和会话选项卡上有未读的铃声，主机的 Orca 版本包含更新步骤，并且桌面上不再有它无法到达的无尽旋转器。

变更架构图

亮点

机器人、评论和侧边栏。 在侧边栏中重新排序机器人和项目，在堆叠的编辑器中编写较长的项目评论，逐步浏览项目而不离开它，并直接从活动中的卡片回复未解决的问题。折叠的 Bots 侧边栏更加清晰，Slack 在代理聊天节目中提到了名字。 更安静、更平静的聊天。 完成的安静回合会以轻微的淡入淡出隐藏其“工作”栏，并且重新启动时恢复是一个小吐司而不是对话框。终端选项卡在关闭后和恢复时保留其名称。 专为配对服务器而构建。 在该主机的 Orca 浏览器中打开来自 SSH 和配对主机的本地主机链接，在远程 HTML 预览中播放视频和音频，并从配对的 client 读取和更改服务器的通知开关。无头服务器停止通告它们无法执行的更新。 在您的计算机上更轻。 会话保存保持未更改的条目相同，主机状态工作仅针对发生更改的主机进行，并且 Windows 工具从绝对 System32 路径启动。 Linux 在回退之前打开一个无密码密钥环，并且重新打包的 .deb 安装不再交给 dpkg。 电话兼容性。 下面列出的电话更改是此版本边界中包含的源更改。安装此桌面更新不会安装移动应用程序更新；这些功能需要相应的移动版本。

Orca 机器人简介（测试版） 以您的方式登录反重力变更架构图亮点机器人、评论和侧边栏。 在侧边栏中重新排序机器人和项目，在堆叠的编辑器中编写较长的项目评论，逐步浏览项目而不离开它，并直接从活动中的卡片回复未解决的问题。折叠的 Bots 侧边栏更加清晰，Slack 在代理聊天节目中提到了名字。 更安静、更平静的聊天。 完成的安静回合会以轻微的淡入淡出隐藏其“工作”栏，并且重新启动时恢复是一个小吐司而不是对话框。终端选项卡在关闭后和恢复时保留其名称。 专为配对服务器而构建。 在该主机的 Orca 浏览器中打开来自 SSH 和配对主机的本地主机链接，在远程 HTML 预览中播放视频和音频，并从配对的 client 读取和更改服务器的通知开关。无头服务器停止通告它们无法执行的更新。 在您的计算机上更轻。 会话保存保持未更改的条目相同，主机状态工作仅针对发生更改的主机进行，并且 Windows 工具从绝对 System32 路径启动。 Linux 在回退之前打开一个无密码密钥环，并且重新打包的 .deb 安装不再交给 dpkg。 电话兼容性。 下面列出的电话更改是此版本边界中包含的源更改。安装此桌面更新不会安装移动应用程序更新；这些功能需要相应的移动版本。发生了什么变化 机器人、连接器和访问📱 电话和手机💬 聊天和协调 代理、模特和帐户🖥️ SSH、WSL 和远程主机🌐 浏览器🗂️ 工作区、侧边栏和选项卡⌨️ 终端🔀 源代码控制和集成📝 编辑器和文件🎨 设置和用户界面⚡ 性能和可靠性🛠️ 测试、CI 和维护新贡献者
