orca v1.4.271

继1.4.269之后，这是虎鲸的下一轮。机器人到达 Qwen 代码并跨越您配对的计算机，手机应用程序端到端管理代理，聊天变得更轻松、更快。

跨计算机的机器人、运行代理的手机以及更快捷的聊天 ✨

现在，一个机器人组可以容纳配对计算机上的机器人，机器人可以在 Qwen Code 上运行，聊天可以删除并在使用限制后自行继续，并且手机应用程序可以在没有桌面的情况下共享、导入和连接代理。

  • 🤖 跨计算机和代理的机器人： 一个机器人组可以容纳来自配对计算机的机器人，机器人可以在 Qwen 代码上运行，并且小组房间将后续轮流交给每个成员和代理 @mentions。
  • 📱 从手机运行代理： 编辑代理的自动化，连接 Slack、Linear、GitHub、Google 和 Composio，通过链接共享代理，从 OpenClaw 或 Hermes 导入代理，读取其灵魂并管理其内存和技能，并将历史会话移交给另一代理。这些需要匹配的移动版本。
  • 💬 更平静的聊天： 删除聊天，默认情况下在使用限制后继续，在 @ 菜单中列出文件夹，并查看更安静的行和保持欢迎文本清晰的作曲家。
  • 🐧 更稳定的 Windows 和 WSL： WSL 主机计数工作代理以保持唤醒，Codex 帐户和设置在 WSL 上运行，并且首先询问将文件夹移动到 WSL 主机。
  • ⚡ 全面减轻： 终端标题更改、代理状态更新、机器人列表和手机刷新停止重新扫描或重建所有内容，隐藏动画暂停。
  • 🐙 多个 GitHub 帐户： 链接多个 GitHub 帐户，并提供更精简的链接预览和评论投票。

关于 Orca 机器人（测试版）

Orca 机器人像一流的队友一样工作：它们现在跨越您的计算机，记住它们完成的内容，并在使用限制或重新启动中断的地方继续工作。

  • 机器人背后的 Qwen 代码： Qwen 代码加入机器人可以运行的代理。
  • 🖥️ 一组，多台计算机： 机器人组可以容纳来自配对计算机的机器人，并且代理对同伴请求的答复显示在房间中。
  • 📓 保持记忆： 机器人会记录每个已关闭的项目及其 PR，知道工作状态存在于项目和日记中，并且试点 Tidy-up 会移动并合并内存行，而不是重写它们。
  • 🔁 从上次中断的地方继续： 重新启动或使用限制暂停后，机器人会保留其打开的请求并继续一次。
  • 💬 更简单的回复： 项目评论框获得作曲家的提及和斜杠选择器，“回复”会跳转到它回答的问题。

已知问题

  • ⚠️ 机器人可以暂停其工作： 应用程序重新启动后，或出现使用限制等错误后，机器人可以中途停止其工作。这将在下一版本中修复。

即将推出

  • 反重力错误修复
  • 更多连接器
  • 机器人在不同机器之间移动更容易
  • 更多性能改进
  • 修复机器人在繁重的任务负载下停滞问题
  • 改进公关审核工作流程
  • 更多插件API
  • 侧边栏用户体验改进
