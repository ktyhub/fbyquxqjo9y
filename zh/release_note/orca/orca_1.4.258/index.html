orca v1.4.258

这个项目是干啥的：桌面版AI编程调度台，让Claude Code、Codex等命令行助手在独立代码目录里并行干活并对比结果，给同时带几个AI程序员的开发者用。

先前版本：1.4.257 — 更流畅的长聊天、保存的浏览器反馈和更好的听写。

更流畅的工作空间、恢复手机滚动和副驾驶聊天 ✨

Orca 1.4.258 在打开大型工作区集合、移动窗口和更改布局时减少了停顿。本地使用情况更新减少了处理击键过程中的工作量，帮助聊天 UI 和终端用户在使用情况刷新时继续工作。

  • 📱 再次滚动电话聊天： 在桌面提供的聊天页面上，滑动消息并横向滑动宽代码块。用两根手指捏合即可调整聊天文本的大小，而无需缩放整个页面。
  • 💬 在聊天中使用 GitHub Copilot： 选择 启动聊天 以流式传输回复、检查工具输出并在对话中查看文件差异，您可以在重新启动 Orca 后重新打开。
  • ⌨️ 使用您选择的模型和思维水平启动 Pi： 终端启动器会应用您的模型选择并在您发送第一个提示之前提供推理工作。
  • 🗂️ 以更少的步骤添加项目： 浏览文件夹、克隆 URL 或直接从 添加项目 创建项目。菜单里面切换机器；从新工作树，它从您选择的在主机上运行开始。

变更架构图

亮点

  • 保持对话继续进行： 使用限制 移交给另一个代理 包括完整保存的对话。生成的图像保留在最终答案旁边，并且通过回复聊天关闭窗口使用正在运行的工作确认。回答协调员发出的工作许可提示，并在作曲家上方列出待处理的请求，并按对话顺序收据。
  • 浏览、查看和打开文件： 默认情况下，在 设置 → 浏览器 中启用扩展。 Git Graph 减少了滚动和分页时的重复工作；空闲的编辑器停止轮询复制提示。不受支持的文档选项卡提供 使用默认应用程序打开，首先下载 SSH 或配对主机文件的副本。
  • 远程切换 Claude 帐户： 在 询问 下，电话或 CLI 交换机可恢复所选帐户上的终端会话，而无需桌面对话框。繁忙的会话首先结束； 永不重新启动仍保持原样。
  • 阅读更清晰的电话代码和历史记录： 电话页面获得语法颜色、固定差异间距和 PR 状态图标。会话历史记录可找到压缩的 Codex 档案、OMP 配置文件和更大的 OpenCode 2 会话。

兼容性和升级说明

  • 副驾驶聊天： 需要副驾驶 CLI 1.0.88+ 并登录。启动后出现模型；没有模型选择的计划使用自动。尚不支持将会话历史记录导入聊天。避免在外部终端中将聊天会话切换为允许所有：重新打开时该权限设置仍然存在，即使 Orca 显示询问。
  • 电话更新： 桌面提供更新的电话网页；它不会替换已安装的本机应用程序。从此源构建的新本机 iOS 需要 iOS 16.4+。如果选项卡显示“更新手机”，请更新手机应用程序并重新连接。
