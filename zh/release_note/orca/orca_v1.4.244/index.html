orca v1.4.244

更快的 diff 查看和编辑器、更多语言和更好的远程文件 🌍

此版本添加了四种界面语言，通过准备要打开的工作区来加快切换工作区的速度，并允许 SSH 主机和配对服务器上的文件像本地文件一样播放、保存和打开。它还带来了更流畅的聊天流、新 Windows 终端中更快的提示、更稳定的 WSL 终端以及针对手机听写的许多修复。

简短版本

  • 四种新语言： 德语、俄语、土耳其语和繁体中文加入语言选择器，并且翻译了更多对话框、菜单和快捷方式。德语是机器翻译的，欢迎母语人士发表评论。
  • 更快的工作区切换： 将工作区悬停在侧边栏中即可使其准备就绪，当前工作区旁边的工作区保持温暖，并且切换本身的工作量更少。拖动行永远不会切换。
  • 像本地文件一样工作的远程文件： 从 SSH 主机和配对服务器播放音频和视频，保存最多 50 MB 的远程文本文件，滚动时打开太大而无法回复的文件夹，并且永远不要以文本形式打开远程二进制文件。
  • 更流畅的聊天： 长回复流减少了口吃，@file 建议保留在大型存储库中，多代理 Codex 聊天不再将本地聊天历史记录增长到千兆字节。克劳德的聊天可以倒回到您的第一条消息之前。
  • 更稳定的终端： 新的 Windows 终端立即显示提示，而不是大约 3 秒后，关闭或调整终端大小不再冻结 macOS 和 Linux 上的其他终端，并且 WSL 终端在发行版停止时保留其会话和文件夹。
  • 浏览器： 当 Google 登录卡在旧帐户上时，从配置文件中清除 Google cookie，从 Vivaldi 导入 cookie，并且当扩展程序的帮助程序窗口关闭时，Orca 在 Windows 和 Linux 上启动时不再退出。
  • 来自社区的修复： Kimi K3 用于提交消息、Open In 中的 Devin Desktop、突出显示 Glimmer、CUDA、Groovy 和 shebang 脚本、工作树位置中的 orca worktree create --branch、~、macOS 上的 MacPorts 工具以及更快的 Windows 提示符。 电话和网络更新： 手机上的听写功能通过重新连接持续录音，通过通话和繁忙的点击保留您的话语，在停止时返回音频，并在请求麦克风之前解释设置。移动设置页面现在将 iPhone 安装发送到 App Store。韩语 10 键输入、手持终端键、配对和文件保存在手机上效果更好，并且手机在后台执行的工作更少。

兼容性和升级说明

  • 与 v1.4.243 相同的终端主机： 此版本保留 v1.4.243 的终端主机，而不是启动一个新的终端主机，因此当您更新时终端会打开并保持运行并保持连接。一些终端修复在终端主机内运行，例如新 Windows 终端中的更快提示、关闭终端或调整终端大小而不冻结其他终端，以及 Codex 中的 Ctrl+C。它们在终端主机重新启动后生效，例如在您重新启动计算机后。
  • SSH 主机和配对服务器： 在此版本上，一些远程修复也需要主机的 Orca 服务器：保存大文件、打开非常大的文件夹、配对终端中 Codex 的主题答案以及手动启动 Codex 复制（主机更新后打开新的远程 shell）。较旧的服务器保持其当前的行为。
  • SSH 工作区： 删除 SSH 项目上的工作区现在提供 从 Orca 中删除，这会使其在主机上的文件保持不变。
  • 工作区切换： 工作区仍然在 click 上切换。现在，按住下一个或上一个工作区快捷键 (Cmd+Shift+Up/Down) 可移动侧边栏突出显示，并在松开后进行切换。
  • 工作树位置： 以 ~ 开头的位置现在表示您的主文件夹。早期版本保存的 ~ 值将在下次启动时扩展。
  • 单词分隔符： Double-click 始终在空格和制表符处断开单词，即使您的自定义单词分隔符设置将它们排除在外。保存的设置不会改变。
  • 移动设置： 移动设置页面上的 iOS 按钮、二维码和复制的链接指向 App Store。 TestFlight 预览选项消失了； Android 仍然使用 APK 链接。
