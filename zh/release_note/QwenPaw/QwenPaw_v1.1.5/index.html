QwenPaw v1.1.5

修订 发布时间2026年4月29日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v1.1.5

✨ 已添加

  • CJK 感知内存搜索：内存搜索现在在字符级别标记 CJK 查询，同时保留拉丁语/数字运行 (#3811)
  • 上下文压缩回退：当基于 LLM 的上下文压缩失败或被禁用时，上下文管理器现在会重试上下文拆分，并增加保留以保留最近的对话轮次（#3882）
  • 自适应模型重试：运行时现在可以从 API 故障中学习每个模型的怪癖，并主动调整后续请求（#3874）
  • ACP 代理重命名和删除：现在可以从 WebUI 重命名和删除 ACP 代理（#3859）
  • QQ 语音和 ASR 支持：QQ 频道现在通过文件扩展名检测语音消息，并在可用时使用平台 ASR 转录（#3845）

🔄 已更改

  • 代理统计导航：将代理统计页面移至侧栏上的工作区组中 (#3754)
  • Docker 文件清理：现在在 Docker 文件中的 pip install 之后删除构建目录，以获得更精简的图像 (#3638)
  • 聊天组件升级：升级了 @agentscope-ai/chat 并修复了 stopChat (#3917)

⚡ 性能

  • 配置加载缓存：根和每个代理配置文件现在使用基于 mtime 的失效进行缓存（#3865）
  • 技能清单缓存：技能清单读取按文件路径和 mtime 进行缓存，减少热路径上的重复磁盘读取 (#3910)
  • 型号 API 重复数据删除：聊天页面上并发的 listProviders 和 getActiveModels 调用现在可以删除它们自己的正在进行的请求的重复数据（#3897）
  • 控制台聊天性能：聊天会话列表使用 react-window 进行虚拟化，搜索通过进度指示器逐步加载会话（#3908、#3912）

🐛 已修复

频道

  • 通道中的批准：修复了 /approve 和 /deny 命令在通道中不起作用的问题（#3832、#3896）
  • WeCom @提及命令：修复了当机器人被@提及时在 WeCom 群聊中失败的斜杠命令（#3903）
  • 飞书反应事件：为飞书消息反应事件注册无操作处理程序（#3890）
  • QQ WebSocket 重新连接：QQ 频道现在会在出现可恢复的 WebSocket 错误时重新连接 (#3872) 控制台和用户界面
  • 每选项卡代理选择：修复了浏览器选项卡之间泄漏的代理选择（#3857、#3867）
  • 备份导入图标：更新了备份导入按钮以使用导入图标而不是上传（#3909） 代理系统
  • 时区标准化：非标准时区名称现在映射到规范的 IANA 标识符（#3858）
  • ACP 后备继承：后备代理配置文件现在从主配置继承 ACP 配置（#3834）
  • MCP 执行超时：MCP client 超时现在传递到工具执行（#3904）
