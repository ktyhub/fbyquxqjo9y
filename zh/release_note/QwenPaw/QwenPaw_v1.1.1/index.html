QwenPaw v1.1.1

修订 发布时间2026年4月14日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v1.1.1

✨ 已添加

提供商和模型

  • OpenRouter Provider：内置 OpenRouter 提供程序，具有模型发现、系列浏览以及按模式和定价进行过滤的功能 (#1192)
  • OpenCode 提供程序：内置 OpenAI 兼容的 OpenCode (Zen) 提供程序，具有免费模型 (#2463)
  • 模型 ID 自动完成：添加模型时用于模型 ID 选择的自动完成下拉列表，默认情况下为所有提供程序启用模型发现（#3175、#3341） 多代理系统
  • 内置代理协作工具：新的 list_agents 和 chat_with_agent 内置工具具有专用技能和简化的 CLI 代理命令，用于代理间通信（#3292） 频道
  • 矩阵通道重写：端到端加密 (E2EE)、提及处理、消息历史记录支持和 Markdown 渲染 (#2509)
  • 飞书引用消息：带有文本、帖子、图像和文件内容提取的回复链消息处理（#3207）
  • 钉钉二维码认证：控制台中钉钉通道设置的二维码设备流认证（#3315） 安全
  • 扩展 Shell 命令防护：新的防护规则涵盖 $IFS 注入、控制字符、Unicode 空白、/proc/*/environ 访问、危险的 jq 标志和 Zsh 特定的危险内置函数 (#3303) 工具和技能
  • ClawHub 技能要求：支持具有多个元数据命名空间解析的 ClawHub 格式的技能要求（#3310）
  • 媒体 URL 查看：view_image 和 view_video 工具现在接受 HTTP/HTTPS URL，无需下载即可直接查看媒体（#3358）

🔄 已更改

提供商和模型

  • 多模态探针统一：Anthropic、Gemini 和 OpenAI 提供商之间的图像支持探测现在共享单一评估路径，并改进了误报检测 (#3367)
  • 模型切换的消息规范化：消息在请求时进行规范化，因此在模型提供程序之间切换时媒体附件会保留在内存中（#3359）
  • Anthropic 媒体重复数据删除：工具结果中的重复 Base64 媒体被替换为文本占位符，以防止超过 Anthropic 的消息大小限制 (#3372) 频道
  • 钉钉SDK迁移：频道迁移至阿里云官方SDK，AI卡模式下处理和媒体投放时有表情反应反馈（#3236、#3337、#3374）
  • 飞书 WebSocket 稳定性：重构事件循环处理，以提高重新连接期间的跨线程可靠性（#3360）
  • 微信回复限制警告：频道设置现在显示有关微信 iLink 的 context_token 回复限制的警告 (#3376) 工具和技能
  • 浏览器托管 CDP：默认浏览器启动策略更改为托管 CDP，具有自动 Chromium 检测、端口分配和进程生命周期管理 (#3164) 控制台和用户界面
  • 模型管理重新设计：提供者模型管理模式重新设计，具有功能标签、模型搜索和简化的卡片布局（#3273、#3294）
  • 代理配置选项卡：代理配置页面从堆叠卡重构为选项卡式界面（#3354）
  • 技能选择用户界面：改进了技能选择，包括标签建议、长名称工具提示、改进的加载行为和批量选择操作（#3320、#3362、#3373）
  • 下载页面：网站下载页面经过稳定版和预览版分组的重新设计（#3353）

🐛 已修复

频道

  • QQ WebSocket 关闭：stop() 不再通过在关闭时强制关闭 WebSocket 来阻塞 8 秒（#3188） 控制台和用户界面
  • 修复了深色模式下聊天会话图钉按钮的对比度（#3267）
  • 标题中的 Markdown 链接现在在应用程序内导航，而不是打开新选项卡 (#3186)
  • 网站贡献者针对中文语言环境的布局对齐（#3332） 提供商
  • 修复了 Windows 上的本地模型下载失败 ([Errno 22] Invalid argument) (#3321)
  • 省略 tool_choice=auto 以实现 vLLM 兼容性，以避免在没有 --enable-auto-tool-choice 的部署中出现 400 错误 (#3295)

📚 文档

  • RESTful API 教程：全面的 REST API 教程，涵盖聊天端点、身份验证、多轮会话、流式传输和代理切换 (#3335)
  • 技能聊天命令：在命令文档中添加了技能聊天命令参考（#3330）
