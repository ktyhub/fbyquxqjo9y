QwenPaw v1.1.6

修订 发布时间2026年5月9日 来源agentscope-ai/QwenPaw 英文原文

✨ 已添加

代理系统

  • Windows 诊断：qwenpaw doctor 现在检查特定于 Windows 的环境问题，包括长路径支持、PowerShell 语言模式和工作目录路径长度 (#4032)
  • 代理状态 API：新的 GET /agents/{agentId}/agent-status 端点报告代理运行时状态、运行任务计数和任务时间戳 (#4107)
  • Cron 会话隔离：Cron 作业现在支持 share_session 选项 - 禁用时，每个计划运行都会创建一个带有 cron 作业 ID 的隔离会话上下文 (#4117)
  • GPT Image 2 Plugin：用于通过 OpenAI 的 GPT Image 2 API 生成图像的新工具插件（#3911）
  • 配置驱动的代理名称：使用配置的代理配置文件名称而不是硬编码的默认名称（#4140） 聊天和控制台
  • Whisper 语音输入：将浏览器本机 Web 语音 API 替换为服务器端 Whisper 转录，以实现更可靠的跨浏览器语音输入（#3574）
  • LLM 生成的会话标题：聊天会话现在由 LLM 在第一条消息后在后台自动命名。可通过代理配置中的“自动生成会话标题”切换进行配置 (#3829)
  • 令牌使用趋势：在令牌使用设置页面中添加了每个模型和每个令牌类型的趋势线图，以可视化随时间推移的使用情况（#4080、#4094）
  • 批量技能操作：向技能批量操作工具栏添加启用和禁用按钮，并提供每个技能的错误报告（#4091）
  • 美人鱼图渲染：带有 mermaid 语言标签的 Markdown 代码块现在在聊天和文件预览中呈现为交互式图表 (#4146)
  • 巴西葡萄牙语 (pt-BR)：为控制台 UI 和后端语言设置添加了完整的 pt-BR 区域设置支持（#4009、#4143） 提供商
  • 火山引擎提供程序：添加火山引擎作为内置 OpenAI 兼容提供程序，具有标准和编码计划端点 (#3994)
  • DashScope 区域选择：现在可以从预设区域端点修改 DashScope 基本 URL (#4074)
  • 阿里云令牌计划提供商：添加阿里云令牌计划作为内置提供商（#4122）
  • Anthropic 默认最大令牌：将 Anthropic 兼容模型的默认 max_tokens 提高到 16,384 (#4054) 频道
  • 飞书交互式审批卡：飞书中的工具卫士审批请求现在呈现为交互式按钮卡，在批准/拒绝时就地更新，当未订阅卡操作回调时会显示文档链接提示（#3941、#3982）
  • WeCom 群组会话共享：添加了 share_session_in_group 开关来控制群聊成员是否共享单个会话或获得每个成员的隔离（#3948）
  • 飞书发件人上下文：飞书发件人昵称现在传递到代理环境上下文（#4098）
  • WeCom 交互式批准卡：WeCom 中的工具防护批准请求现在呈现为交互式模板卡 (#4112) 安全
  • 静态文件路径遍历保护：控制台静态文件服务现在拒绝绝对路径以防止路径遍历绕过（#3973）
  • 规则级自动拒绝：现在可以将单独的安全规则配置为自动拒绝工具调用（#4046） 技能和CLI
  • 技能测试 CLI：新的 qwenpaw skills test 命令用于验证技能内容并运行安全扫描（#3999）
  • 技能安装/卸载 CLI：新的 qwenpaw skills install 和 qwenpaw skills uninstall 命令用于从命令行管理技能，支持池级别和每个代理工作区安装 (#4053)

⚡ 性能

  • 控制台渲染：通过稳定批准轮询状态比较和记住聊天运行时选项来消除重复的重新渲染（#4052、#4110、#4153）
  • 聊天历史记录导航：跳过非箭头键的聊天历史记录查找并缓存用户消息列表，以避免每次击键时重复扫描（#4130）
  • QR 轮询清理：立即停止 QR 码轮询并清除身份验证完成或代码到期时的状态指示器 (#4148)

🐛 已修复

频道

  • WeCom Stream Keepalive：通过定期刷新保持“Thinking…”占位符流处于活动状态，以防止 WeCom 中的状态指示器卡住（#3950）
  • WeCom 重新连接竞赛：修复了 WeCom WebSocket 处理中的双重重新连接调度和跨事件循环断开连接（#3963）
  • Telegram 网络重试：为暂时的 Telegram 网络错误添加了指数退避和受控重新连接，而不是默默地死亡（#4039）
  • 微信 Cron 缓冲区刷新：立即刷新微信合并缓冲区，以绕过正常完成路径的 cron/主动发送 (#4106)
  • Markdown 表拆分：通过在每个片段中重复标题行和分隔符行来保留跨消息块的 Markdown 表结构 (#4119) 代理系统
  • 外部代理超时：为 delegate_external_agent 添加了安全默认超时（60 秒）以防止无限期挂起（#3928）
  • 代理配置重新加载：代理配置文件更改现在会触发优雅的重新加载，并通过任务耗尽而不是轻量级重新实例化（#4064）
  • 代理配置持久性：修复了控制台代理配置编辑器通过保留完整的配置结构在保存时删除嵌套设置的问题 (#4157) MCP
  • MCP 执行超时：使用 sse_read_timeout 作为 MCP 工具执行超时，而不是较短的 HTTP 连接超时（#4058、#4061）
  • MCP Client 生命周期泄漏：修复了生命周期任务泄漏，其中 close() 可以跳过停止后台重新连接任务（#4152） 控制台和用户界面
  • SSE 代理安全：通过在序列化之前清理不可编码内容，避免 SSE 流因格式错误的代理文本而崩溃 (#3553)
  • CodeMirror 换行：工具调用输入/输出块中的固定换行（#3960）
  • 默认代理显示名称：在所有 UI 界面中遵循默认代理的自定义名称 (#4073)
  • 文件预览路径：修复了文件预览路径中多余的 URL 前缀剥离可能导致 URL 损坏的问题 (#4089) 基础设施
  • Docker 备份还原：通过交换目录内容而不是重命名，正确还原 Docker 卷安装点上的机密 (#3916)
  • 音频块路径：返回 file:// URL 音频块的解析文件系统路径并删除冗余文件处理代码（#4021、#4048）
  • 日志轮换：在所有平台上使用 RotatingFileHandler 进行日志轮换 (#4076)
  • 环回代理绕过：绕过环回 API 运行状况检查的代理环境变量，以防止公司代理后面的连接失败 (#4092)
  • Conda Packaging：在运行 conda-pack 之前恢复 conda 打包工具，以防止打包管道损坏（#4093）

📝 文档

  • WSL2 超时常见问题解答：添加了在 WSL2 NAT 模式下运行时处理 APITimeoutError 的常见问题解答条目 (#4005)
  • 文档更新：更新了网站文档以反映新功能（#4013）

🧪 测试和 CI

  • 控制台单元测试：添加了 Vitest 设置，其中包含单元和组件测试，涵盖聊天、API 层和共享组件（#3559、#4121）
  • 集成冒烟测试：添加了应用程序启动和设置/环境变量冒烟测试（#4081）
