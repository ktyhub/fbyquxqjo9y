QwenPaw v1.0.2

修订 发布时间2026年4月9日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v1.0.2

✨ 已添加

核心

  • 插件：从工作区 plugins/ 文件夹（#3101、#3131、#3132）安装扩展。
  • copaw task：在没有 Web 服务器的情况下从终端运行一次性作业 (#3031)。
  • 聊天中的 /model：切换模型、列出可用的模型、重置为默认值以及检查模型 - 无需打开“设置”(#3133)。 模型和提供商
  • SiliconFlow：SiliconFlow 兼容 OpenAI 的 API (#2886) 的即用型中国和国际端点。
  • CoPaw Local：支持图像和视频的模型、控制台中更丰富的设置以及 Windows 上更可靠的下载和功能检测（#3021、#3087、#3140）。 安全
  • 更安全地保存秘密：API 密钥和类似值在磁盘上加密；如果可能，加密密钥保留在操作系统钥匙串中（#3025）。 控制台和用户界面
  • 聊天输入历史记录：使用箭头键浏览以前的用户行（#2466）。
  • 聊天搜索：跨会话搜索消息文本 (#2842)。
  • 固定会话：固定线程，使它们保持在列表顶部（#3137）。
  • 每个代理聊天：切换代理时恢复上次打开的聊天 (#3155)。
  • 视觉美化：模型旁边的内置工具和提供商徽标的图标（#3061、#3130）。 技能和工具
  • 技能命令：/skills 显示通道启用的内容；输入 /<skill name> 打开技能或使用您的消息运行它（#3150）。
  • 池技能标签：使用标签组织共享池（#2837、#3069）。
  • MCP 工具发现：通过 HTTP API (#3149) 查询每个连接的 MCP 服务器的工具名称、描述和参数。 频道
  • QQ：跨消息类型一致地发送文件和富媒体 (#3012)。
  • WeCom：传入消息保留引用/回复上下文，以便代理看到引用的内容（#3024）。

🔄 已更改

  • 时区选择器：区域名称遵循您选择的 UI 语言 (#2497)。
  • 文件大小：控制台中随处可见的人类可读大小（#2808）。
  • 控制台启动：按需加载较重的设置页面，因此第一个屏幕打开速度更快（#3122）。
  • 大型技能列表：当您拥有许多池技能时，滚动和交互会更流畅（#3141、#3158）。
  • 提供商连接测试：状态消息以您的语言显示（#2913）。
  • 错误代码：跨通道、API 和 CLI (#3110) 更一致的错误代码。

🐛 已修复

频道

  • iMessage：私人聊天现在尊重您的 DM 政策，并以与其他频道相同的方式列入许可名单 (#2491)。
  • Discord：长助手回复不再破坏中间围栏的 Markdown 代码块（#2976）。
  • 飞书：重新连接并运行多个代理不再因共享锁或混合事件循环而出错（#3095、#3145）。 工具和技能
  • MCP：重新加载后关闭或重新连接 clients 不再导致 CPU 使用率失控（#3106）。
  • 浏览器自动化：当存在重复项时，Clicking 元素会指向正确的元素；文档更清楚地解释了选择器（#3023）。
  • Shell 工具：带引号文本的命令保持换行符不变（#3070）。
  • 技能：损坏或非对象技能元数据不再导致需求解析崩溃（#3072）。
