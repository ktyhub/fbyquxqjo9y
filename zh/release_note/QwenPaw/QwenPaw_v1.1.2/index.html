QwenPaw v1.1.2

修订 发布时间2026年4月17日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v1.1.2

✨ 已添加

代理系统

  • 任务模式：用于自主、多阶段任务执行的 /mission 命令 - 代理迭代地计划、执行和自我纠正。支持/mission status和/mission list监控正在运行的任务(#3364、#3480)
  • 仅文本自动继续：启用后，如果模型响应文本但没有工具调用，代理会自动重试最多两次额外的推理过程 (#3107)
  • 自定义代理 ID：从控制台或 API 创建代理时指定自定义 ID (#3333)
  • ACP 外部代理委派：通过具有权限保护和实时流输出的新 delegate_external_agent 工具将任务委派给外部编码代理（OpenCode、Qwen、Claude Code、Codex）（#3340）
  • 代理 CLI：使用 qwenpaw agents create 从命令行创建代理，并选择模板（default、local、qa）和工作区初始化（#3385） CLI
  • qwenpaw doctor：检查环境、配置、提供商、通道、技能、MCP、内存、安全性等的诊断命令 - 使用 doctor fix 进行自动修复（#3371）
  • qwenpaw skills info：从命令行检查技能详细信息（启用状态、通道、路径、描述）；还在聊天中添加了 /skills 斜线命令（#3459） 内存
  • 记忆梦想：预定的长期记忆巩固 - “梦想”代理定期删除重复并重组 MEMORY.md (#2177)
  • 递归文件观察器：新的 recursive_file_watcher 选项可在内存索引中包含子目录文件（#3347） 控制台和用户界面
  • 技能导入中心：重新设计了导入模式，包括 URL 验证、市场集成以及导入与现有技能冲突的技能时的覆盖确认（#2412、#3415、#3482）
  • 调试页面：设置中的新调试页面可实时查看后端日志文件（#3478） 频道
  • 微信引用消息：现在解析引用/回复消息，支持文本、图像、语音、文件和视频（#3483）

🔄 已更改

  • 提供商排序顺序：设置中的提供商列表现在按可用性排序（#3458）
  • 代理通信工具：代理间通信工具分为 chat_with_agent（同步）和新的 submit_to_agent / check_agent_task（异步后台任务）（#3485）

🐛 已修复

控制台和用户界面

  • 清除聊天历史记录：/clear 现在可以正确清除控制台 UI 中的聊天历史记录（#3348）
  • 令牌使用排序：令牌使用“按日期”表现在首先以最新日期排序（#3387）
  • Cron 作业 ID 工具提示：Cron 作业 ID 工具提示已更正，将其描述为系统生成的 UUID (#3404)
  • 消息历史记录导航：当斜杠命令建议可见时，ArrowUp 消息历史记录不再触发 (#3444) 提供商
  • 图像 MIME 标准化：将数据 URL 中的 image/jpg 标准化为 image/jpeg，以防止严格的 API 拒绝（#3313）
  • 多模式工具调用排序：升级的图像消息不再破坏 OpenAI 和 Anthropic 所需的连续工具结果块（#3299）
  • 提供程序类标识：修复了从多个导入路径加载同一提供程序时 Pydantic 类标识崩溃的问题 (#3431) 代理系统
  • 后台任务跟踪：通过 AgentApp API 调度的后台任务现在由 TaskTracker 跟踪，防止在重新加载或关闭期间取消任务（#3305）
  • 内存压缩防护：内存压缩钩子不再在每个推理步骤运行两次（#3461） 频道
  • Discord 线程路由：Discord 线程消息现在路由到正确的线程会话而不是父通道 (#3144)
  • 微信打字指示器：微信打字指示器不再泄漏后台任务；键入在消息接收时开始，并在完成或错误时可靠地停止 (#3488) 桌面
  • Python 环境隔离：打包的桌面版本现在设置 PYTHONNOUSERSITE=1 以防止用户安装的软件包与捆绑的依赖项发生冲突（#3476）

🔧 CI 和基础设施

  • 渠道测试基础设施：用于渠道质量保证的合同测试、单元测试、CI 工作流程和 Makefile 目标 (#2506)
