duckdb v1.4.2

这是针对我们发布 1.4.1 后发现的各种问题的错误修复版本。 PR #19716 解决了 CVE-2025-64429 中提出的问题。鼓励 DuckDB 加密功能的用户进行更新。

发生了什么变化

  • 1.4.1 的凹凸 duckdb-azure 参考，作者：https://github.com/duckdb/duckdb/pull/19275 中的@benfleis
  • 修复正则表达式优化，以在 https://github.com/duckdb/duckdb/pull/19290 中通过 @mlafeldt 转换为 contains 时删除标志

  • 通过 @c-herrewijn 在 https://github.com/duckdb/duckdb/pull/19306 将 Julia 提升至 v1.4.1
  • 在 https://github.com/duckdb/duckdb/pull/19304 中 @hannes 在 OSX 上使用静态库的交叉编译
  • 允许https://github.com/duckdb/duckdb/pull/19319中的@Mytherin跨数据库实例对同一数据库进行多个只读附加 *巨大的int_t修复由@carlopi在https://github.com/duckdb/duckdb/pull/19318
