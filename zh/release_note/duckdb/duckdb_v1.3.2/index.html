duckdb v1.3.2

这是针对我们发布 1.3.1 后发现的各种问题的错误修复版本。没有新的主要功能，只是修复了错误。此版本可以读取从 DuckDB 版本一直追溯到 v0.9 创建的数据库文件。

发生了什么变化

  • 通过 @c-herrewijn 在 https://github.com/duckdb/duckdb/pull/17966 将 Julia 提升至 v1.3.1
  • [CI] 将 DONT_LINK 参数添加到 https://github.com/duckdb/duckdb/pull/17967 中 @hmeriann 的 inet 扩展的测试扩展配置中
  • 逐出队列：对已清除的节点进行排序并通过@lnkuiper在https://github.com/duckdb/duckdb/pull/17913中批量重新添加
  • 在 https://github.com/duckdb/duckdb/pull/17964 中 @lnkuiper 完成动态过滤器之前获取锁定
  • 问题 #5144：@hawkfish 在 https://github.com/duckdb/duckdb/pull/17978 中的 AsOf 加入阈值
  • 修复 https://github.com/duckdb/duckdb/pull/17988 中 @pdet 在 filter_combiner 中的 IsDenseRange 检查
  • 在 https://github.com/duckdb/duckdb/pull/17983 中的 @Mytherin 在 DataTable::Fetch 中使用 SharedLockTable
  • 在 Windows CI 上，使用来自 msys2 的 zip，而不是 https://github.com/duckdb/duckdb/pull/17993 中 @staticlibs 的 choco
  • [修复] Arrow ArrowBool8 扩展类型在 https://github.com/duckdb/duckdb/pull/18005 中添加 @rustyconover 的有效性类型检查
  • @lnkuiper 在 https://github.com/duckdb/duckdb/pull/18022 中使测试更加宽松
  • 在https://github.com/duckdb/duckdb/pull/18023 中@taniabogatsch 打印事务回滚失败时的内部异常堆栈跟踪
  • 关于 https://github.com/duckdb/duckdb/pull/18024 中的 @taniabogatsch 的 GetDatabases 的更多修复
  • [修复] @taniabogatsch 在 https://github.com/duckdb/duckdb/pull/18014 中解析具有结构别名的 lambda 时的绑定错误
  • 在 Windows 上通过 https://github.com/duckdb/duckdb/pull/17991 中的 @staticlibs 禁用 constexpr std::mutex
  • https://github.com/duckdb/duckdb/pull/17860 中 @Tmonster 下推过滤器后使用正确的表达式函数
  • https://github.com/duckdb/duckdb/pull/18032中通过@lnkuiper实现非并发队列的批量入队
  • 在 https://github.com/duckdb/duckdb/pull/18019 中将 libduckdb-src.zip 作为 @mlafeldt 的发布工件带回来
  • 问题 #18035：https://github.com/duckdb/duckdb/pull/18045 中 @hawkfish 的零填充 TIMESTAMP_NS
  • 修复 https://github.com/duckdb/duckdb/pull/18033 中@Damon07 在RemoveUnusedColumns 中处理动态表过滤器的问题
  • 修复 @taniabogatsch 在 https://github.com/duckdb/duckdb/pull/18058 中索引扫描的不正确结果
  • 凹凸空间 (v1.3) by @Maxxen in https://github.com/duckdb/duckdb/pull/18059
  • 当参数是https://github.com/duckdb/duckdb/pull/18018中@Tmonster的绑定列reg时，可以替换常量或null
  • 问题 #18047：@hawkfish 在 https://github.com/duckdb/duckdb/pull/18064 中的 TIMESTAMP_TZ 向上转换成本

  • 针对 PR 上的 Python 3.9 和 3.13 运行 Python 工作流程，以确保……由 https://github.com/duckdb/duckdb/pull/18080 中的 @evertlammerts 提供
