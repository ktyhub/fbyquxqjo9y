duckdb v1.5.0

此版本的 DuckDB 被命名为“Variegata”，以天堂 shelduck Tadorna Variegata 命名，Tadorna Variegata 也称为天堂鸭，是 Shelduck（一群类似鹅的鸭子）的一种，是新西兰特有的。 另请参阅公告博文：https://duckdb.org/2026/03/09/announcing-duckdb-150.html
