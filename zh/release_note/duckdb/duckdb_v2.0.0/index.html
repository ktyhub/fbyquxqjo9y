duckdb v2.0.0

此版本的 DuckDB 被命名为“Cyanoptera”，以 Spatula Cyanoptera（一种在北美和南美西部发现的鸭子）命名。 另请参阅公告博文：https://duckdb.org/2026/10/21/announcing-duckdb-200.html
