MetaGPT v0.7.0

小版本 发布时间2024年2月9日 来源FoundationAgents/MetaGPT 英文原文

MetaGPT v0.7.0

发布亮点

  • 更简单、更灵活的配置：简化的配置设置，从全局 CONFIG 转向使用 Config 实例进行更精细的控制。典型用例涉及将不同的法学硕士分配给不同的角色。详细使用方法请查看这里。
  • 引入Context：Context由config、repo、workspace等组成。每个Role都可以拥有自己的Context，允许更灵活的Context管理。
  • 添加了metagpt —init-config 命令：对于 pypi 包用户来说更友好的设置过程。
  • Repo 重组：合并 FileRepo 和 GitRepo 职责以简化代码和逻辑。
  • 订阅标签：更改了订阅标签的概念，以提高可读性和可用性。
  • 删除显式序列化/反序列化函数：从 Role 中删除了这些函数，使用 mixin 代替以获得更好的清晰度。
  • 支持从 pydantic.BaseModel 初始化 ActionNode：定义 ActionNode 的简单且结构化的方法。
  • WritePRD Action 重构：简化代码，增强效率，修复 bug 逻辑。
  • Env重构（实验性）：重新抽象Env以更有效地适应各种环境；使用mark_as_read mark_as_writable来装饰APIs，通过observe和step来统一观察并作用于环境。
  • 拥抱多模态：添加了基于 GPT-4V 的视觉代理，查看示例此处！
  • 改进增量开发：与之前的版本相比，增量开发的成功率更高。
  • 引入CodeInterpreter：通过编码解决问题的总代理。该代理利用计划和工具，能够解决广泛的问题，包括数据可视化、机器学习建模、数学推理、Web scraping、网页模仿等。我们正在此处添加示例！

改变了什么

向后不兼容的更改

  • 重要提示：我们删除了 config.yam、key.yaml 并切换到最小的 config2.yaml。请在[此处]查看最新设置方法(https://docs.deepwisdom.ai/main/en/guide/get_started/setup.html)
  • 我们删除了 Role._init_actions 并添加了 Role.set_actions，它允许在初始化之外随时设置操作。对于 Role 初始化，用户现在还应该使用 self.set_actions(...)
