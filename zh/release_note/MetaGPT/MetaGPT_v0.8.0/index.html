MetaGPT v0.8.0

发布亮点

数据解释器：开源和更好的“Devin”

Data Interpreter 是一个自主代理，它使用笔记本、浏览器、shell、稳定扩散和任何自定义工具来完成任务。 Data Interpreter 在机器学习、数学推理和开放式任务方面取得了最先进的成绩，并且可以分析股票、模仿网站和训练模型。 它可以自行调试代码、自行修复故障、自行解决大量现实问题。 我们开源代码并提供大量工作示例，让每个人都能获得最先进的人工智能功能。 📝 纸 🔗 示例 📖 使用方法

抹布

集成 RAG 模块！支持索引、检索和排名等常见功能。探索此示例 以快速入门。

新法学硕士

支持的法学硕士家族新成员：Claude、QianFan、DashScope 和 Yi。查看此处 进行配置。
