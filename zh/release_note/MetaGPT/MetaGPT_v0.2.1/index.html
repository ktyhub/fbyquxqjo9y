MetaGPT v0.2.1

修订 发布时间2023年8月28日 来源FoundationAgents/MetaGPT 英文原文

MetaGPT v0.2.1

发生了什么变化

  • 支持https://github.com/geekan/MetaGPT/pull/207.中@hezhaozhao-git与qdrant矢量数据库集成
  • 支持https://github.com/geekan/MetaGPT/pull/186.中@LeonZh0u在github代码空间上的集成和执行
  • 在 https://github.com/geekan/MetaGPT/pull/161. 中添加与多个网络搜索引擎 (duckduckgo_search/googleapi) 的集成
  • 增强网页搜索结果解析能力，支持https://github.com/geekan/MetaGPT/pull/69.中的@shenchu Cheng进行有针对性的网页内容检索和结果解析
  • https://github.com/geekan/MetaGPT/pull/112.中@wangjie5540为OpenAI接口添加超时设置和网络异常警报
  • 在update_cost 和update_usage 计算中加入容错功能，并减少https://github.com/geekan/MetaGPT/pull/138.中@alitrack因网络异常而导致的代码执行错误的情况
  • 介绍并细化qa engineer的角色，通过@garylin2099在https://github.com/geekan/MetaGPT/pull/77.中实现编写测试用例、运行代码、调试错误等能力
  • 修复https://github.com/geekan/MetaGPT/pull/121中无法使用代理的bug并通过@flyi更新默认设置检查机制
  • 介绍并细化researcher的角色，实现在线搜索、分析和总结网络搜索结果以及在https://github.com/geekan/MetaGPT/pull/161.中由@shenchu Cheng撰写报告等能力
  • 通过 @bocandrei 在 https://github.com/geekan/MetaGPT/pull/257 中添加适用于 Windows 的自定义循环策略
  • 修复了 @denniseilander 在 https://github.com/geekan/MetaGPT/pull/221 中导入 ProductManager 的错误
  • 在 https://github.com/geekan/MetaGPT/pull/194 中使用 @flyi 的 Anthropic_API_KEY 而不是 OPENAI_API_KEY 时处理异常
  • 在 https://github.com/geekan/MetaGPT/pull/139 中添加 @voidking 的 MetaGPT 快速入门文档链接
  • 修复 https://github.com/geekan/MetaGPT/pull/144 中 @jansalvador 的 run_code.py 中的拼写错误问题
  • https://github.com/geekan/MetaGPT/pull/238 中 @talkingtoaj 的正确要求和安装说明
  • 在https://github.com/geekan/MetaGPT/pull/124中添加动作`write docstring`，支持@shenchu Cheng的sphinx/google/numpy样式
  • 更新Docker文件，翻译代码中的中文注释，并执行其他拼写错误更正，谢谢@voidking @LeonZh0u @flyi。
  • 修复https://github.com/geekan/MetaGPT/pull/84中@seehi调用`faiss_store write`时的错误
  • 修复 https://github.com/geekan/MetaGPT/pull/116 中 @femto 错误的 parse_tasks 和 parse_workspace 的错误
  • 支持在https://github.com/geekan/MetaGPT/pull/83中本地安装mmdc并跳过@alitrack下载Chromium
  • https://github.com/geekan/MetaGPT/pull/73中@qa6300525实施代码审查，增强生成代码的可执行性，优化代码编写提示，提高生成代码的可执行性
  • https://github.com/geekan/MetaGPT/pull/73中@qa6300525添加重试机制，降低代码生成失败的概率
  • 使用 ann 添加 memory_storage 以避免 @better629 在 https://github.com/geekan/MetaGPT/pull/70 中重复执行类似的想法
  • 添加一个新的 api 键字段，并通过 @LeonZh0u 在 https://github.com/geekan/MetaGPT/pull/50 中为 serper API 创建包装类
  • 格式化import ，根据现有未使用的代码进行排序和清理，添加.pre-commit-config.yaml，以在@seehi在https://github.com/geekan/MetaGPT/pull/67中提交代码时自动检测代码问题
  • 在https://github.com/geekan/MetaGPT/pull/57中添加@Hallimede的requirements.txt保存和`api_spec_and_tasks.md`
  • 错误修复：https://github.com/geekan/MetaGPT/pull/137 中 @voidking 创建目录时删除特殊字符
  • 在https://github.com/geekan/MetaGPT/pull/65中添加@LeoXV1对人类克劳德api的支持

其他更新：

  1. 感谢 https://github.com/geekan/MetaGPT/pull/136, 中的@geniuslzh 提供常见问题解答-EN
  2. 感谢https://github.com/geekan/MetaGPT/pull/143,中的@eltociear创建了`REAME_JA.md` 3.感谢https://github.com/geekan/MetaGPT/pull/208,中的@hezhaoozhao-git为代码linter添加ruff
  3. 感谢@voidking和@alitrack在更新docker镜像以及优化https://github.com/geekan/MetaGPT/pull/106和https://github.com/geekan/MetaGPT/pull/109.中的Docker文件方面所做的工作
  4. 感谢 https://github.com/geekan/MetaGPT/pull/63, 中的 @stellaHSR 提供了 ui 角色并启用了稳定的扩散 text2image api。
  5. 感谢https://github.com/geekan/MetaGPT/pull/179,中的@wangjie5540对Dockfile的优化。
  6. 感谢https://github.com/geekan/MetaGPT/pull/156,的@martcpp提供英文评论。
