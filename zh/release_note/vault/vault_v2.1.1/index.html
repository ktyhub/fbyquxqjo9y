vault v2.1.1

2.1.1

2026 年 9 月 16 日

安全：

  • 核心：将github.com/apache/thrift更新为v0.24.0，修复安全漏洞ghsa-8wv5-x4w7-5gww。
  • 核心：更新 golang.org/x/crypto 为 v0.56.0，修复安全漏洞 GO-2026-6354 和 GO-2026-6355。
  • 核心：更新 google.golang.org/grpc 为 v1.83.2，修复安全漏洞 GHSA-2v4p-qf9q-27wj。 变化：
  • auth/jwt：添加了 Okta 提供程序，当 fetch_groups=true 且检测到截断时，可以从管理 API 获取组。
  • auth/jwt: 将插件更新为 v0.26.4
  • core/raft：将并发重试加入工作线程限制为 20 个。在 20 个进程正在进行时，任何进一步的重试加入尝试都将导致错误 (too many concurrent raft retry joins in progress)。
  • 核心：Bump Go版本为1.26.8 改进：
  • 秘密导入：将 allowed_ipv4_cidrs 添加到 source_aws 和 source_azure 秘密导入块，以允许 SSRF 安全连接的私有 CIDR 豁免。
  • Secrets/pki：添加一个附加字段以包含 (/pki/revoke) 和 (/pki/revoke-with-key) 的 RFC 5280 撤销原因。
  • ui：将 dompurify 更改为 3.4.15 以解决 SECVULN 建议 错误修复：
  • Secrets Recovery（企业）：修复在没有路径的情况下运行 vault recover 时 cli 中的 Vault 恐慌。
  • auth/jwt：修复了代理上限策略评估期间返回的不正确的 HTTP 状态代码。
  • auth/token：修复了 auth/token/lookup 和 auth/token/lookup-self 在非根命名空间中为 JWT 令牌返回 403 的错误。
  • 消费计费：修复了 OIDC 身份令牌计费单位在定期刷新周期中计算不正确的问题。计费标量现在应用每个令牌持续时间调整，因此报告的标量和每个安装的归因细分始终一致。
  • core/activitylog（企业）：通过在策略更改时安全处理暂时缺失的策略和零策略路径/权限数据，修复 CensusReport ACL 策略指标收集中的恐慌。
  • core/mounts：修复了当目标路径具有前导斜杠时，vault secrets move（和 vault auth move）错误地将安装放置在根命名空间中的问题。
  • oauth-resource-server（企业）：修复了当令牌的 iss 声明与资源服务器配置文件中存储的发行者相比存在外观差异（例如不同的大小写或尾部斜杠）时，RAR 强制执行被跳过的问题。
  • 插件：修复在根命名空间中运行时 vault plugin reload -mounts 命令的问题
  • 秘密同步（企业）：通过将请求转发到活动节点而不是允许性能备用节点或性能辅助节点在本地提供服务，修复 LIST /v1/sys/sync/associations 间歇性返回零关联/秘密的问题。
  • Secrets/pki（企业）：修复当证书请求消息为空时 CMPv2 哨兵字段解析中的恐慌。
  • Secrets/pki（企业）：修复后台传输将本地吊销的证书复制到统一存储后，统一 CRL 未重建的问题。
  • ui：修复代理注册表上限策略由于属性名称不正确而未显示的问题
  • ui：修复机密同步概述页面上的总机密计数绑定，以匹配 API 响应密钥。
  • ui: 解决字段中命名空间添加尾部斜杠时登录页面闪烁的问题。
