vault v2.0.1

修订 发布时间2026年5月19日 来源hashicorp/vault 英文原文

vault v2.0.1

重大变更：

  • 容器：在构建时在Vault上设置cap_ipc_lock功能。运行Vault容器时，容器运行时需要添加IPC_LOCK功能。 安全：
  • api：更新 golang.org/x/net 以解决 GO-2026-4918”
  • 核心/身份：拒绝呈现的身份模板中的通配符
  • 核心：通过删除对 github.com/jackc/pgx/v3 和 github.com/jackc/pgx/v4 的依赖来解决 GHSA-j88v-2chj-qfwx
  • 核心：更新github.com/Azure/go-ntlmssp以修复安全漏洞v0.1.1。
  • 核心：更新github.com/apache/thrift修复安全漏洞GHSA-wf45-q9ch-q8gh
  • 核心：更新github.com/jackc/pgx/v5修复安全漏洞GHSA-j88v-2chj-qfwx。
  • 核心：更新 golang.org/x/net 以解决 GO-2026-4918”
  • 核心：验证对 sys/audit/{path} 的请求的路径和 file_path 不能为空
  • sdk：通过删除对 github.com/jackc/pgx/v3 和 github.com/jackc/pgx/v4 的依赖来解决 GHSA-j88v-2chj-qfwx
  • sdk：更新 github.com/Azure/go-ntlmssp 以修复安全漏洞 v0.1.1。
  • sdk：更新github.com/jackc/pgx/v5以修复安全漏洞GHSA-j88v-2chj-qfwx。
  • sdk：更新 golang.org/x/net 以解决 GO-2026-4918” 变化：
  • auth/jwt：将插件更新为 v0.26.3
  • 核心：将 Go 版本升级为 1.26.3
  • 身份：需要 sudo 功能才能调用身份实体合并 API 端点（身份/实体/合并）。
  • Secrets/azure：将插件更新为 v0.26.2+ent
  • Secrets/openldap：将插件更新为 v0.18.1+ent 特点：
  • 计费指标仪表板：使用响应式布局创建新的计费仪表板以显示指标数据。
  • Secrets Sync UI：在 AWS、Azure 和 GCP 同步目标的 UI 中添加了工作负载联合身份验证 (WIF) 支持 改进：
  • api：将 start_month 和 end_month 参数添加到 /sys/billing/overview 端点，以允许查询特定时间范围的账单数据。
  • api：将 migration_done_at_epoch 添加到 sys/seal-status 响应。
  • 消费计费：为操作系统本地帐户静态角色添加计费跟踪，以支持基于消费的计费指标和高水位线 (HWM) 跟踪。
  • 消费计费：添加了 OIDC 代币的消费计费指标。
  • 消费计费：添加了 PKI 外部 CA 证书的消费计费指标。
  • 消费计费：添加了 SPIFFE JWT 令牌的消费计费指标。
  • 消费计费：在管理命名空间中启用 sys/billing/overview 端点。
  • 消费计费：sys/billing/overview 返回的 Float64 值现在四舍五入到小数点后 4 位。
  • 消费账单：账单数据保留时间从 2 个月增加到 37 个月。 /sys/internal/billing/overview API 端点现在默认返回 37 个月的历史消费账单数据。
  • 消费计费：/sys/internal/billing/overview API 端点现在始终返回响应中的所有指标类型，即使它们的值为零。这确保了一致的响应结构，以便更轻松地进行 client 端解析。
  • 核心（企业）：清理后的配置现在显示 kms_library 配置。
  • core/seal（企业）：使新节点可以加入配置了 Seal 高可用性的集群。
  • scim：SCIM Group PATCH 处理程序现在支持删除操作中的members[value eq “id”] 形式的路径字段。
  • sdk：扩展对 docker 测试集群选项（如密封、kms 库和熵增强）的支持。 DockerClusterNode.UpdateConfig 现在采用全套集群选项，而不仅仅是节点配置。
  • sdk：添加 WIF 和旋转助手来检查参数是否已更新，以允许消费者知道何时需要将更改保存到存储中
  • Secrets/pki（企业）：允许 SCEP 使用由基于 RSA 的 PKCS#11 托管密钥支持的颁发者
  • Secrets/transit：更改为使用 Trail of Bits 库在 Transit 中实现 PQC 签名
  • ui/dashboard：重新组织仪表板小部件以改进布局和可用性。更新了小部件以使用 HDS 表组件以获得更好的一致性。通过常用链接和现有操作增强了快速操作卡。
  • ui：将自定义消息列表视图的分页大小设置为 10，并根据筛选器选择切换“应用筛选器”按钮的可见性。
  • ui：更新合并实体页面上的副本，以指定实体 ID 是合并实体时所需的数据输入。
  • ui：向 ACL 可视化策略编辑器添加验证，以防止其保存具有空路径或功能的策略。 错误修复：
  • auth/aws：修复旋转和 Wif 配置更新未持久保存到存储的错误
  • client/ocsp：添加宽限期以更新 OCSP 响应的缓存条目。
  • 核心：修复了在存储写入 totp 密钥期间无法检测错误的问题。
  • 数据库/mssql：通过用粒度元数据查询替换未记录的 sp_msloginmappings 过程，修复租约撤销期间的“sysadmin”要求。这允许插件使用“查看任何定义”而不是完整的系统管理员权限来运行。
  • 数据库/mssql：通过将自定义语句作为单个批次执行而不是按分号分割来修复动态秘密撤销
  • 数据库/雪花：修复密钥对根凭证轮换的 WAL 回滚问题。
  • 数据库：通过在 UpdateUser 和 Initialize 周围添加超时，防止静态角色轮换和连接 init 在数据库调用阻塞时无限期挂起
  • 事件（企业）：修复复制租赁事件时的恐慌。
  • go-plugin：升级 go-plugin 以修复生成外部插件时文件描述符可能泄漏的错误
  • 身份：修复了罕见但可能的身份数据竞争问题。
  • sdk：与 docker 测试容器清理和映像构建相关的小错误修复。
  • Secrets-sync（企业）：修复 WIF Identity_token_ttl 规范化和 GCP service_account_email 解码的目标 PATCH 处理。
  • Secrets/kmip（企业）：在托管对象的失效处理程序中寻址 nil 指针。
  • Secrets/ldap：对“openldap”插件别名启用正确的许可证检查。这会在使用“openldap”别名配置安装时启用企业功能。
  • Secrets/pki（企业）：修复审核数据中的 SCEP 随机数记录。
  • Secrets/pki（企业）：当根是直接颁发者时，将根 CA 包含在 CIEPS 端点的链中，除非remove_roots_from_chain 为 true。
  • Secrets/pki：从支持的 ACME 算法列表中删除无效值。
  • ui：将名称字段验证添加到 LDAP 创建和编辑角色表单。
  • ui：修复 UI 中的 LDAP 分层角色导航
  • ui：修复实体页面以在成功编辑实体后显示成功消息。
  • ui：将秘密修复为书签 URL 的秘密引擎重定向。
  • ui：修复了自定义消息列表，以显示非活动消息徽章上的过期时间。
  • ui：修复了侧边栏导航动画问题
  • ui：恢复秘密和命名空间表的可调整大小的列。
  • ui：更新 DR 操作令牌生成以接受主根令牌进行身份验证。
  • ui：更新 KV max_version 验证以禁止负值。
