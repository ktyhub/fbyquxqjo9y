vault v2.2.2

2026 年 11 月 12 日

安全：

  • core/acl：通过不区分大小写地匹配请求的路径来强化显式拒绝规则评估。 变化：
  • auth/alicloud: 更新插件为v0.24.1
  • auth/cf: 将插件更新为 v0.24.1
  • auth/jwt: 将插件更新为 v0.27.2
  • auth/kerberos: 将插件更新为 v0.18.1
  • auth/oci: 将插件更新为 v0.22.1
  • 核心：Bump Go版本为1.27.4
  • core/acl：修复了未针对被拒绝路径的大小写变体强制执行显式拒绝策略规则的问题。显式拒绝规则现在还可以不区分大小写地匹配请求的路径，并遵循通常的规则特异性。例如，对 secret/data/example 的拒绝现在也会拒绝对 secret/data/EXAMPLE 的请求。
  • 数据库/couchbase：将插件更新为v0.17.1
  • 数据库/elasticsearch：将插件更新为v0.21.1
  • 数据库/mongodbatlas：将插件更新为 v0.18.1
  • 数据库/redis：将插件更新为v0.9.1
  • 数据库/雪花：将插件更新为 v0.17.1
  • 代理/代理：通过代理或代理返回交互式 HTML 的自定义插件或集成将不再在浏览器中以交互方式呈现。
  • Secrets/alicloud: 更新插件至 v0.23.1
  • Secrets/azure: 将插件更新为 v0.28.5+ent
  • Secrets/keymgmt：将插件更新为 v0.20.2+ent
  • Secrets/mongodbatlas：将插件更新为 v0.18.1
  • Secrets/terraform：将插件更新为 v0.15.1 改进：
  • 核心：在挂载设置失败日志中包含命名空间 ID
  • 核心：将 github.com/go-jose/go-jose/v4 更新为 v4.1.6，将 golang.org/x/net 更新为 v0.62.0
  • ui：当静态角色尚未轮换时，在 LDAP 角色凭证页面上显示“从不”作为最后一次 Vault 轮换，而不是 0001 年的日期。 错误修复：
  • Transit（企业）：修复导致使用托管密钥将非零 auto_rotate_period 值写入缓存的缓存错误
  • agent/pki-external-ca（企业）：修复自动身份验证重新身份验证时过早重新颁发证书的问题，以便证书续订遵循 percent_renew_before_expiry，而不是由令牌更新触发。
  • 审核：修复了由于操作系统 Unix 数据报套接字大小限制（EMSGSIZE / ENOBUFS）而无法将大型响应（例如 PKI ?help=1 请求）写入系统日志审核设备时 Vault 返回 HTTP 500 的错误。系统日志接收器现在将超大的审计有效负载分割成安全大小的块，并重试瞬时满的套接字缓冲区。
  • 审计：修复了在拆卸期间审计代理未初始化时可能发生的恐慌。
  • auth/approle：登录期间拒绝过期的 SecretID，而不是依赖定期清理。
  • auth/spiffe（企业）：修复可再生代币未更新的问题
  • 核心（企业）：修复根代理注册表安装不可用时出现的恐慌和部分名称空间创建问题
  • 核心/人口普查（企业）：修复了在计费开始日期自动滚动后的第一个月中 previous_month_complete 人口普查仪表报告 0 的问题，以便报告上一个计费周期的最终 client 计数。
  • 核心/插件：修复了外部秘密引擎和身份验证插件在启动或解封期间加载失败后仍保持只读状态的问题。操作员现在可以恢复丢失的二进制文件或注册并重新加载插件以恢复写入，而无需重新启动 Vault。
  • 核心：修复了仅尾部斜杠不同的请求的策略路径匹配可能不一致的问题。
  • 身份：仅在区分大小写模式下重新加载时使用报告冲突解决程序，以避免在解封后收集重复项。
  • pki-external-ca：修复在 tidy 期间过早删除已撤销证书记录的问题；现在，已撤销的订单将保留到证书的 NotAfter 日期，而不是 ACME 订单到期日
  • Secrets/azure：当活动应用程序已经不存在时，继续永久应用程序清理，允许稍后的清理尝试重试清除。
  • Secrets/azure：将新创建的服务主体添加到 Azure 组时重试暂时性 Microsoft Graph 403/404 错误。
  • Secrets/kv：修复了 KV v1 中的一个问题，即编写包含连续斜杠的秘密路径会导致列表操作返回“/”作为目录条目，从而在 Vault UI 面包屑中产生无限循环。
  • tpm：tpm auth 现在遵循 InsecureSkipVerify 选项
  • ui：修复数据库概述页面以列出动态和静态角色并允许生成凭据，并为仅具有静态角色权限的用户恢复“角色”选项卡
  • ui：修复实体列表上的分页 *Vault代理：支持auto_auth块中的tpm方法以与代理匹配奇偶校验。
