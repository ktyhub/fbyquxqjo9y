codebase-memory-mcp v0.5.5

这个项目是干啥的：给 AI 编程助手装的代码库记忆，一次调用就摸清整个项目的架构和调用关系并用图谱记牢。给想让 AI 快速看懂大项目的人用。

变更架构图

亮点

  • 安全加固（头号变化） — 这压倒性地是个安全版本：system() 调用被替换为 cbm_exec_no_shell()（fork+execvp），任何受污染数据都到不了 shell；修复了 11 个 snprintf 溢出 bug，并通过原子权限和 open-then-fstat 关闭 TOCTOU 竞态，由 CodeQL SAST 零告警门槛以及每次构建的 JSON-RPC/Cypher 模糊测试兜底。如果你的服务索引不可信仓库或接受外部 Cypher 输入，升级会实质缩小攻击面；这里几乎没什么新功能，所以安全态势才是主要升级理由。

  • 杀毒软件误报消除（#89） — 触发 Windows Defender 启发式的 DLL 解析跟踪字符串被移除，并在任何二进制发布前运行多层 AV 关卡（Windows Defender、Linux/macOS 上的 ClamAV，加上覆盖 70+ 引擎的 VirusTotal 零容忍检查）。如果你或你的用户曾在前几个版本上遇到下载/执行拦截，单为这点就值得升级；v0.5.5 的每个产物都附带公开扫描报告。

  • 新增供应链验证 — 发布产物现在包含 SLSA 来源证明、Sigstore cosign 无密钥签名、SPDX 2.3 SBOM（sbom.json）、SHA-256 校验和，以及固定到 SHA 并启用 Dependabot 的 GitHub Actions。可用 gh attestation verify <downloaded-file> --repo DeusData/codebase-memory-mcp 和 cosign verify-blob --bundle <file>.bundle <file> 验证。对受监管或安全敏感部署有意义；否则只是零成本的透明度提升。

  • 客户端兼容性特性 — 为 OpenCode 新增 Content-Length 分帧传输，agent 检测扩展到 10 个（新增 OpenClaw + VS Code），并支持双 MCP 配置位置（~/.claude/.mcp.json + ~/.claude.json）。如果你用 OpenCode、VS Code 或 OpenClaw，就升级——这些是客户端启用项，而非对现有用户核心行为的改变。

  • Bug 修复与迁移 — 修复 Swift 调用提取（此前 0 条 CALLS 边，#43）、Laravel 路由误报（PR #65）、FastAPI Depends() 边追踪（PR #66）、批量写入时保留 WAL journal 模式（PR #72），以及 VS Code 兼容性（PR #79）。未指出破坏性变更或迁移步骤。如果你的技术栈里没有这些语言/客户端，AV 也没有标记你的二进制，那么这个版本对你实际上等于安全/基础设施空操作，可以跳过。

安全

  • CodeQL SAST — 使用构建模式手册进行静态分析（100% 源代码覆盖率），零打开警报门
  • 消除 Shell 注入 — 用 cbm_exec_no_shell() (fork+execvp) 替换 system() 调用，没有受污染的数据到达 shell
  • snprintf 溢出修复 — 修复了 11 个缓冲区溢出漏洞（每次追加后钳位偏移）
  • TOCTOU 竞赛修复 — 原子文件权限、open-then-fstat 模式
  • 31 项安全防御测试 — shell 注入、SQLite 授权者、通过 Cypher 的 SQL 注入、路径遏制、无 shell 执行
  • 模糊测试 - 每个构建上的随机/变异 JSON-RPC + Cypher 输入
  • 本机防病毒扫描 - 每个版本均支持 Windows Defender、ClamAV (Linux + macOS)
  • VirusTotal 零容忍门 — 所有发布的二进制文件在发布前均经过 70 多个引擎扫描
  • SLSA 出处 + Sigstore 联合签名 + SBOM (SPDX 2.3) + SHA-256 校验和
  • GitHub 操作通过 Dependabot 固定到 SHA

防病毒误报预防

在构建管道中添加了多层反病毒扫描，以在误报到达用户之前捕获并防止误报。删除了触发启发式检测的 DLL 解析跟踪字符串。此版本中的每个二进制文件均已通过 VirusTotal 经 70 多个防病毒引擎验证干净。 （修复#89）

新功能

  • 内容长度帧传输 — OpenCode 兼容性
  • 10 代理检测 — OpenClaw + VS Code 支持
  • 双 MCP 配置位置 — ~/.claude/.mcp.json + ~/.claude.json

错误修复

  • 修复 Swift 调用提取：0 调用边缘 (#43)
  • 修复 Laravel 路由误报：扩展范围+路径过滤器（PR #65）
  • 端口 FastAPI Depends() 边缘跟踪（PR #66）
  • 在批量写入期间保持 WAL 日志模式（PR #72）
  • 修复 VS Code 兼容性（PR #79）
  • 删除 DLL 解析跟踪（Windows Defender 误报）
