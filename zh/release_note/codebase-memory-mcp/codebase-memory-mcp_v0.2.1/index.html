codebase-memory-mcp v0.2.1

修订 发布时间2026年2月28日 来源DeusData/codebase-memory-mcp 英文原文

变更架构图

亮点

  • 语言覆盖 — Kotlin（.kt、.kts）经由 PR #3（@GauravRatnawat）成为第 13 种支持语言，具备完整的 tree-sitter 解析、AST 节点提取、调用解析、使用跟踪和字符串常量传播；PR #2（@bhicks329）接入 tree-sitter-c-sharp 语法，修复了此前损坏的 C# 支持。如果你的代码库中有这两种语言中的任一种，这就是升级的首要理由。
  • 安全性 — 缓存目录权限从 0755 收紧到 0750（gosec G301），堵上了共享或多用户主机上全局可读的缓存；风险低但实实在在的加固，值得拥有。
  • 更新通知 — 服务现在在启动时检查 GitHub releases，发现新版本会显示一次直接指向发布页的通知。方便，但注意它引入了一次启动时的网络调用，对隔离网络或离线环境有影响。
  • 破坏性变更/迁移 — 未记录：这是一个增量式的 v0.2.1 点版本，未指出 API、flag、配置或 schema 变更，因此无需迁移步骤。
  • 谁该升级 — 索引 Kotlin 或 C# 的团队有实际功能收益，在共享主机上运行服务的用户也受益于权限修复；CI/CD 重构（lint 关卡 → 分平台测试 + 构建 → 发布）纯属内部改动。两种语言都不用、也不关心共享主机的用户可以放心跳过。这不是空操作或仅改元数据的重新打标签。

新消息

Kotlin 语言支持（社区 PR #3 by @GauravRatnawat）

  • 添加了 Kotlin（.kt、.kts）作为第 13 个支持的语言
  • 完整的树守护者解析、AST 节点提取、调用解析、使用跟踪和字符串常量传播

C# 语法修复（社区 PR #2 by @bhicks329）

  • 将 tree-sitter-c-sharp 语法连接到解析器中，修复 C# 支持

安全

  • 加强缓存目录权限从 0755 到 0750 (gosec G301)

更新通知

  • 启动时检查 GitHub 版本，并在有新版本可用时显示一次性通知
  • 直接链接到发布页面进行下载

基础设施

  • 重组 CI/CD 管道：lint gateway → 每个平台测试 + 构建 → 发布
