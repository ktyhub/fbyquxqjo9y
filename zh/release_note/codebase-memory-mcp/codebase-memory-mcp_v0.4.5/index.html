codebase-memory-mcp v0.4.5

修订 发布时间2026年3月7日 来源DeusData/codebase-memory-mcp 英文原文

codebase-memory-mcp v0.4.5

变更流程图

亮点

  • 语言覆盖从 59 扩到 63 — 新增 MATLAB（包括借助 Linguist 启发式消除 .m 歧义）、Lean 4、FORM 和 Magma，支持定义、导入、使用以及/或调用图。使用这些语言的开发者现在能获得有用的代码上下文和导航；现有语言的用户不会从这次扩展直接受益。
  • 文件路径导入与 Magma 调用图更可靠 — 原始路径解析失败时，passImports() 现在回退到 fqn.ModuleQN()，改善 load "utils.mag" 和 #include "helpers.h" 这类导入的跨文件关联。Magma 语法现在通过 field('path', ...) 捕获每个 load_statement，而不再是每个文件只取第一个；跨函数 CALLS 边、递归调用和 trace_call_path 都做了端到端验证。
  • Windows 安装与 watcher 修复 — 修正 watcher 中 Windows 文件 URI 解析，提供静态链接二进制以避免缺 DLL 错误，并修复安装脚本的二进制移动命令（#16）。Windows 用户——尤其是全新安装的用户——有明确的升级理由。
  • 推荐受影响用户升级；未声明破坏性变更 — 如果你使用这四种新支持的语言、依赖基于路径的导入/调用图，或在 Windows 上运行，就升级。未指出破坏性变更或迁移步骤；不属于这些情况的用户可以放心跳过这个维护版本。

新消息

4 种新语言 (59 → 63)

  • MATLAB — 函数定义、用法、通过语言启发式消除 .m 文件歧义
  • 精益 4 — 定理/定义提取、导入
  • FORM — 用于符号计算脚本的 #procedure/#call 提取
  • Magma — 函数/过程/内在定义、load 导入、调用图提取

Magma 图表质量修复

  • 修复了 load_statement 导入提取 - 将 field('path', ...) 添加到语法中，以便捕获所有 load 语句（以前仅捕获每个文件的第一个）
  • 验证调用提取的端到端工作：跨函数调用边缘、递归调用、trace_call_path

导入链接器改进

  • 当原始路径不匹配时，passImports() 现在通过尝试 fqn.ModuleQN() 来解析文件路径导入（例如 load "utils.mag"、#include "helpers.h"）——一般修复使任何具有基于文件路径导入的语言受益

其他变化

  • 通过构建注入的 ldflags 进行统一版本管理
  • 修复了观察器中的 Windows 文件 URI 路径解析
  • 静态链接 Windows 二进制文件以修复丢失 DLL 错误
  • 修复了安装脚本中的二进制移动命令（#16）
