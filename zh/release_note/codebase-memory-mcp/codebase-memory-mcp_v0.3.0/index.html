codebase-memory-mcp v0.3.0

小版本 发布时间2026年3月1日 来源DeusData/codebase-memory-mcp 英文原文

变更流程图

亮点

  • 大幅扩展的语言支持 — tree-sitter AST 解析从 13 种语言扩展到 35 种，新增 Ruby、C、Bash、Zig、Elixir、Haskell、OCaml、Objective-C、Swift、Dart、Perl、Groovy、Erlang、R、HTML、CSS、SCSS、YAML、TOML、HCL、SQL 和 Dockerfile。这实质提升了多语言仓库的实用性。解析器修复还恢复了 C# 提取，并新增 Erlang -define/-record 以及 SQL CREATE TABLE/VIEW/FUNCTION 支持。

  • 更好地集成 Claude Code 与 Codex — 四个任务专用的 Claude Code skill 现已内嵌进二进制，由 codebase-memory-mcp install 安装；安装不再依赖 claude CLI 存在。同时包含 Codex CLI 指令支持和通过 config.toml 进行 MCP 注册。如果你用这两种 agent CLI，值得升级。

  • 安装、更新与可靠性修复 — 新增 codebase-memory-mcp update 命令，检查 GitHub releases 上的新版本。其他修复包括通过 -s user scope flag 解决 mcp remove 挂起、发布包内二进制名称规范化、Windows .exe/USERPROFILE 的 CI 处理，以及通过上下文取消实现优雅关闭。主要改善安装和运行稳定性。

  • 可观的基准测试覆盖 — 上游报告称 35 种语言各用 12 个标准化问题测试，加权得分 91.8%，在含 20K 节点、67K 边的 Linux 内核图上无超时。完整结果见 BENCHMARK.md。27 个 PASS、7 个 PARTIAL 和 1 个 FAIL 提供了有用证据，但不保证适用于每个仓库。

  • 升级建议 — 新支持语言的用户、受影响的 C# 项目，或使用 Claude Code/Codex 集成的用户有明确升级理由。已在现有支持语言上稳定安装的用户大概率可以跳过。未宣布明确的破坏性变更或强制迁移步骤。

v0.3.0 的新功能

35 种语言支持

通过完整的树托管 AST 解析，编程和配置语言从 13 种扩展到 35 种。 新语言：Ruby、C、Bash、Zig、Elixir、Haskell、OCaml、Objective-C、Swift、Dart、Perl、Groovy、Erlang、R、HTML、CSS、SCSS、YAML、TOML、HCL、SQL、Dockerfile

综合基准

  • 35 种语言经过 12 个标准化问题的测试
  • 91.8% 总体加权分数（27 个通过级、7 个部分级、1 个不及格级）
  • Linux 内核压力测试：20K 节点、67K 边、零超时
  • BENCHMARK.md 中的完整结果

嵌入式技能

  • 4 个嵌入二进制任务的特定 Claude Code 技能
  • 通过 codebase-memory-mcp install 自动安装
  • Codex CLI 指令支持

自我更新

  • codebase-memory-mcp 更新检查 GitHub 版本是否有较新版本

错误修复

  • 修复安装：现在无条件写入技能（克劳德 CLI 存在时不会被限制）
  • 修复 Windows CI：.exe 后缀、USERPROFILE env、跳过 Unix 特定测试
  • 修复 mcp 删除挂起：添加 -s 用户范围标志
  • 修复版本二进制命名（档案内的规范名称）
  • 通过 config.toml 修复 Codex CLI MCP 注册
  • 添加替换选项以发布工作流程
  • 优雅关闭并取消上下文
  • Erlang 变量提取 -define/-record
  • SQL CREATE TABLE/VIEW/FUNCTION 提取
  • C# 解析器零提取修复
