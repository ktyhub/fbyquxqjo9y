codebase-memory-mcp v0.4.0

小版本 发布时间2026年3月6日 来源DeusData/codebase-memory-mcp 英文原文

codebase-memory-mcp v0.4.0

变更流程图

亮点

  • 提取引擎与语言覆盖 — 用内置 C 语法取代 Go tree-sitter 绑定，将支持扩展到 59 种语言，新增 39 种，包括 Clojure、F#、Julia、Nix、Common Lisp、COBOL、Verilog、Vue、Svelte 和 GraphQL。内置语法消除了外部语法依赖并简化安装。未列出破坏性变更或必须迁移的步骤，但引擎重写值得对关键仓库验证索引。

  • 导入与调用图准确性 — 新增 17 个语言专属导入解析器、用于 implements 解析的语言感知类声明检测、Haskell/OCaml/Elixir 的 apply/中缀被调方提取，以及把 TSX JSX 组件引用作为 CALLS 边。测试夹具现在被排除在 HTTP 链接之外。这些改动让受影响语言的依赖分析和代码导航更可靠。

  • 提取正确性 — 修复 C/C++/CUDA/GLSL 函数名解析、Groovy 方法返回类型而非方法名的问题，以及 Common Lisp、Makefile、Vim Script、Julia 和 Elm 中缺失或不正确的函数提取。如果这些语言此前产生不完整或误导性的符号，就该升级。

  • 运行时与安装改进 — 新增上下文感知的优雅关闭、Linux/macOS/Windows 跨平台构建、自更新检查和 install/uninstall CLI 命令。Louvain 社区检测的瓶颈从 O(N²) 降下来，改善大型仓库处理。

  • 升级建议 — 多语言仓库、新支持或已修正语言的用户，以及遇到社区检测缓慢或跨平台安装问题的人值得升级。仅用 JavaScript、现有结果准确的项目可以缓一缓，不过仍能受益于图质量和关闭修复。

v0.4.0 的新功能

59 种语言支持（Tree-Sitter 引擎）

  • 完全重写提取引擎，从 Go 树保姆绑定到供应的 C 语法
  • 39 种新语言：Clojure、F#、Julia、Vim Script、Nix、Common Lisp、Elm、Fortran、CUDA、COBOL、Verilog、Emacs Lisp、JSON、XML、Markdown、Makefile、CMake、Protobuf、GraphQL、Vue、Svelte、Meson、GLSL、INI 等
  • 所有语法均作为 C 源代码提供 — 零外部依赖

管道质量改进

  • 17 个特定语言的导入解析器（ES 模块、Java、Kotlin、Scala、C#、C、C++、PHP、Ruby、Rust、Lua、Elixir、Bash、Zig、Erlang、Haskell、OCaml）
  • 用于实现解析的语言感知类声明检测
  • Haskell/OCaml/Elixir 被调用者提取（应用/中缀表达式）
  • JSX 组件引用作为 TSX 的 CALLS 边缘
  • 路由测试过滤以从 HTTP 链接中排除测试装置

提取修复

  • 修复了 C/C++/CUDA/GLSL 函数名称解析（声明符遍历中的一对一）
  • 修复了 Groovy 方法名称（返回返回类型而不是方法名称）
  • 修复了 CommonLisp、Makefile、VimScript、Julia 函数提取
  • 修复了 Elm value_declaration 名称解析

基础设施

  • 优雅地关闭并取消整个管道的上下文
  • 自我更新检查器和安装/卸载 CLI 命令
  • 跨平台构建（Linux、macOS、Windows）
  • Louvain社区检测O(N^2)瓶颈修复
