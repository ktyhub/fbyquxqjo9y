ppt-master v6.3.1

修订 发布时间2026年9月9日 来源hugohe3/ppt-master 英文原文

补丁发布。建议对包含第三方来源的 SVG 的项目打开实时预览 (svg_editor/server.py) 的任何人进行升级。

安全

Zick Sun 私下报告了两个问题并在 514596e5 中修复。感谢您提供清晰、经过验证的报告。两者都需要恶意 SVG 已位于项目目录中（例如来自第三方模板包，或由管道转换的有毒源文档）。两者都不允许读取项目之外的文件；两台服务器仅保持绑定到 127.0.0.1。

  • 实时预览清理程序绕过 (mXSS)。 预览页面中的 sanitizeSvg() 在 XML 解析上区分大小写地比较元素和属性名称，然后通过 innerHTML 插入结果，这会小写名称。因此，大写 ONERROR=、<SCRIPT> 和 XLINK:HREF="javascript:" 在过滤器中幸存下来。比较现在不区分大小写，SVG/XLink 命名空间之外的元素被删除，vbscript: 与 javascript: 和 data: 一起被拒绝，并且格式错误的 SVG 现在显示错误而不是注入解析器错误文档。预览页面还获得了内容安全策略，将脚本限制为同源文件。
  • 图标占位符属性注入。 embed_icons.py 将 <use data-icon> 占位符中的 fill、stroke、stroke-width 和 transform 插入到生成的标记中，而无需 escaping。包含裸 " 的单引号值可以注入 CLI 然后写入磁盘的同级属性。现在，这四个属性已根据严格的语法进行验证，并且每个内插值均已转义。合法值（包括实时编辑器写回的 matrix() 变换）保持不变；对现有 50 页项目的回归运行产生了字节相同的输出。

自 v6.3.0 以来的其他变化

  • 模板：Z-CARE Rescue 品牌和值班手册样式。
  • 视频：在合并的字幕子句之间保留空格（#283，感谢@MaxFreedomPollard）。
  • 脚本：slice_images.py 在纯键去溢出期间保持不透明键色调前景完好无损。
  • 自述文件：恢复明星历史图表，添加趋势徽章。

安装

对于直接加载技能目录的代理，ppt-master-skill-v6.3.1.zip 资产仅包含 skills/ppt-master/。
