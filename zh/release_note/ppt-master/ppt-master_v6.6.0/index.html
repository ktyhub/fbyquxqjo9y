ppt-master v6.6.0

小版本 发布时间2026年9月19日 来源hugohe3/ppt-master 英文原文

自 v6.5.0 以来三天的端到端运行的小版本：每条路线都通过真实的甲板驱动 - 同甲板超链接导航，快速美化，编辑本机，删除页面并使用外国 PPTX 作为模板，创建品牌/布局/样式，然后生成，四个捆绑的布局模板，视觉审查阶段，EPUB 和 RST 源，双语甲板，以及中文、英语、德语、西班牙语、葡萄牙语和英语的甲板越南语。以下每项更改均由重现的缺陷或记录的合同差距支持；没有添加或删除任何路线。

捆绑的布局模板

  • editorial_bleed 淡入淡出现在可以保护自己的文本槽。 六个文本图像渐变仅在它们要保护的标题、说明文字和正文槽下达到 0.12–0.35 alpha（第一次视觉审查运行在没有移动槽的平台上测量了 1.2–2.5:1 对比度）。每个都获得一个中间止损，该止损通过其插槽至少保持 0.60，并且仅在超过它之后下降（012a54f5）。
  • presentation_core、presentation_core_43 和 report_core 表格和图表原型通过本机奇偶校验。 每个库都发布了八个“阻止 --native-charts-and-tables 导出”警告，表示复制继承的原型元数据的套牌；有效负载现在携带行高、标题对齐、带行填充和粗体单元格颜色（其后备绘制）（7599c78e）。
  • 插槽的边界是容量，而不是空白配额：结构界面现在说明当内容未满插槽时要做什么，并且结构化页面上的 Morph 对是在第一页之前决定的幻灯片本地组 - 为模板作者、规划者和执行者声明（b526e82e、b431e1b9、e1ab6661、9ce704c6）。

编辑原生 PPTX

  • 导入的文本与 PowerPoint 渲染的内容相匹配。 a:normAutofit fontScale / lnSpcReduction 现在达到了发出的字体大小和行高 - 60 pt 的框缩小到 25%，用于以 80 px 导入，并且在任何编辑时都会使帧门失败 - 并且在其链中任何地方都没有字体的运行采用主题的小拉丁/东亚对，而不是裸露的 sans-serif，它将每个编辑的运行导出为Segoe UI (f4ab81fb)。
  • 往返检查器承认编辑不超过其自己槽位的源文本，并拒绝语义形状内的绝对 y 行，该语义形状先前已通过门，然后崩溃了导出 (f4ab81fb)。
  • 从具有相同甲板链接的甲板上删除页面：导出列出每张幻灯片，其跳转一次离开页面计划而不是每次运行一次，仅在写入包后打印其收据，并且工作流程记录如何重新定位跳转（92901494、658ebf2d）。
  • 新元素可能是本地标记的图表和表格；边界部分现在是这样说的（29770a2b）。

导出和检查

  • --kiosk 编写循环、自运行的信息亭显示并相应地命名导出（067cb13c、92901494）。
  • 超链接：检查器将每个页面的锚点与其 design_spec §IX 超链接行进行比较；一个顶级组周围的裸 <a> 对于动画和分组是透明的（b7d0114e、48238f99、d4c59f1c）。
  • 图标引用在紧凑创作下将其 fill 保留在本地 - embed_icons 不读取继承的绘制，因此规范创作建议与执行者的硬性规则相矛盾 (aa5cf55f)。
  • 表格外边界上的描边矩形在边界拓扑检查中算作其框架；输入的图表/表格槽提示现在显示标准导出失败，并命名幻灯片本地替代方案 (7599c78e)。
  • 模板页面上的结构合同错误现在表示可以重新绘制填充、描边和渐变 - 只有 id、顺序、几何和 data-pptx-* 元数据是合同 - 并且布局槽内的文本溢出不再建议扩展槽的边界（4a28573c、ca15a6ad）。
  • --template-mode 在共享工作区 (aa5cf55f) 中的品牌或风格规范旁边报告名册合同； beautify_inventory --verify 根据导出的牌组 (7e0ea2bf) 检查每个冻结的源字符串； pptx_intake 报告幻灯片空间中的分组形状 (9e0c2468)。

文本测量

  • 捆绑预售表从五个系列增加到十个：Cambria、Trebuchet MS、Garamond 和 Tahoma 加入 Arial、Times New Roman、Georgia、Verdana 和 Calibri； Segoe UI 通过 Selawik 进行测量，Selawik 是 Microsoft 的 OFL 度量兼容替代品（d874fb12、3214e29a）。
  • 表外的重音字母与其基本字母一样前进。越南语、土耳其语、波兰语和捷克语预写字母过去常属于 0.55 em 默认层 — Ổ 27 % 窄，Ị 83 % 宽 (c050b1fa)。
  • Unicode 固定宽度空格的大小由定义确定 (70705ebf)。

来源、图像和工具

  • web_to_md 验证 client 实际连接的主机，并将连接引脚连接到已验证的地址 (3b45af2c)。
  • 当每个发现都是关键噪声时，slice_images --strict-alpha 使用测量的容差重试一次 (d475c0a7)；多单元布局的几张不透明照片可以共享一张由网格切片生成的工作表。
  • import-sources 删除已移动的重复项，而不是宣布从未发生过的移动 (7599c78e)； animation_config 拒绝项目目录所在的文件路径 (df118dad)； visual_review.py --pages 采用逗号列表 (012a54f5)； image_search 保留呼叫者的提供商密码 (1b57b01e)。

工作流程和提示

  • 视觉审查可能会加深文本下方已经存在的淡入淡出，将在甲板范围内重复出现的软打击推迟到聚合代理的一个决定，并命名并行子代理主机形式（b431e1b9）。
  • 创建模板：standard 读取足够的幻灯片来确定方向，而 fidelity 读取全部；布局带有一个中性的拉丁面孔；品牌手册的使用规则位于其管辖的部分下；长 PDF 参考按页面情况进行采样（9ce704c6、5dd4c34a）。
  • 快速：从名册中读取模板原型和首页套牌语言；按标题索引阅读一本书长度的来源；安装的规范是无锁运行的可重新读取的事实（05ad6264、adb9faf0、e1ab6661、5dd4c34a）。
  • 数字、引文和单位约定遵循每种内容语言；旁白朗读双语笔记两遍；委托会跳过确认页面，而不是三个解决方案意图（7c4543b2、e2aff570、b431e1b9）。
