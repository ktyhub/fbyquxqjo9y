AutoGPT autogpt-platform-beta-v0.11.0

🔥 有什么新内容？

⚠️ 重大变更

  • #16459 - 付款强制现在是后端设置 ENABLE_PLATFORM_PAYMENT（默认关闭）而不是 enable-platform-payment 功能标志。收费的自托管安装必须设置它； FORCE_FLAG_ENABLE_PLATFORM_PAYMENT 和 NEXT_PUBLIC_FORCE_FLAG_ENABLE_PLATFORM_PAYMENT 不再执行任何操作（by @Pwuts）
  • #16474 - 平台 API 在非上传路由或 Webhook 入口的任何路由上通过 MAX_REQUEST_BODY_MB（默认 10 MiB）向请求正文应答 413。如果您内联传递较大的文件，则提高它或配置媒体存储（由@Pwuts）
  • #16522 - 在 X-Forwarded-For 携带多个地址的代理链后面，在新的 TRUSTED_PROXIES 设置（IP 地址或 CIDR 范围）中列出您的代理。如果未设置，每个访问者限制将不会获得 client IP，而是不会获得标头最左侧的条目。不是 IP 地址或 CIDR 范围的条目会阻止前端启动（作者：@Pwuts）
  • #15853 - LaunchDarkly 支持已删除，每个功能标志均从 PostHog 读取。 LAUNCH_DARKLY_SDK_KEY、FEATURE_FLAG_BACKEND、NEXT_PUBLIC_LAUNCHDARKLY_ENABLED、NEXT_PUBLIC_LAUNCHDARKLY_CLIENT_ID 和 NEXT_PUBLIC_FEATURE_FLAG_BACKEND 被忽略；没有 PostHog，每个标志都是默认值（由 @kcze 提供）
  • #16026 - AutoPilot 对话不再追踪到 Langfuse，它现在仅用于提示管理。 AutoPilot 跟踪记录转到 PostHog（作者：@kcze）
