caddy v2.11.2

修订 发布时间2026年3月6日 来源caddyserver/caddy 英文原文

caddy v2.11.2

这个项目是干啥的：一个主打自动申请 HTTPS 证书的 Web 服务器，配置简单，用来托管网站和转发流量，适合个人站长和想快速上线的开发者。

Caddy 2.11.2 包含许多错误修复和增强功能！我知道这是一个蹩脚的总结，但它确实无处不在。

变更架构图

亮点

  • 反向代理在与 PROXY 协议、运行状况检查端口和重试时关闭主体相关的某些边缘情况下广受喜爱。现在可以跟踪动态上游，从而实现被动健康检查。
  • 指标性能改进。
  • 新的 tls_resolvers 全局选项可在使用 ACME DNS 质询时控制所有站点的 DNS 解析器。
  • 日志滚动现在支持zstd压缩；已弃用 roll_gzip，将来将被删除。请改用 roll_compression。
  • 完善的日志记录和一些错误消息。
  • 修复了重写处理程序中的一个错误，当 URI 路径是目标路径的转义形式时，该错误可能导致某些 URI 无法重写。感谢@MaherAzzouzi 的报告。

安全修复

此版本修复了两个 CVE。

  • @NucleiAv 报告了 forward_auth 指令中的一个错误，该错误可能允许身份注入和潜在的权限升级。
  • @sammiee5311 报告 vars_regexp 双展开占位符，允许一些不寻常的配置泄露秘密。

另外：

  • 基于 Go 1.26.1（今天也发布）构建，修补了多个 CVE。
  • 我们的文档已更新，注意到文件系统区分大小写可能会影响 file_server 处理程序的 hide 选项的行为。

感谢所有做出贡献的人，感谢我们持续的赞助，使这一发展成为可能！
