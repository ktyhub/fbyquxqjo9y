openclaude v0.31.0

0.31.0 (2026-09-22)

特点

  • 启动器： 支持 —max-old-space-size-percentage (#2219) (055e5d5)
  • 提供商： 添加命令代码混合网关 (#2196) (5b9daef)
  • 查询： 配置空闲超时 (#2233) (876fb79)
  • 技能： 添加撤销验证和眉毛漂移检查 (#2215) (eb3c590)
  • 技能： 在安装时强制执行注册表撤销。json (#2187) (0ea8eef)
  • 网络搜索： 添加 Ollama 后端 (#2234) (70d97fd)
  • zai: 添加 GLM-5.3-Flash 编码计划支持 (#2185) (aceacf0)

错误修复

  • 代理： 将子代理权限提示转发到父会话 (#2235) (a07b06c)
  • api: 在本机 Anthropic clients (#2169) (35d7edc) 中验证 API_TIMEOUT_MS
  • bg: 清理旧的已完成会话工件 (#2167) (70fe2de)
  • chrome: 在 npm installs 中启动打包的 CLI 入口点 (#2146) (bfb44ff)
  • ci: 恢复主要验证 (#2236) (5fb5abb)
  • ctx: 让显式覆盖击败发现的上下文窗口 (#2082) (3451187)，关闭 #2081
  • frontmatter: 锚定结尾 --- 到行的开头 (#2027) (cbbe10f)
  • 挂钩： 在 Windows 上保留复合 Bash 命令 (#2217) (0c2043f)
  • 识别 OpenCode Go 请求 (#2203) (3609d75)
  • 图像： 允许在调整大小失败时进行大/无元数据的屏幕截图 (#1964) (#1970) (2e687df)
  • mcp: 通过自身属性解析服务器名称，而不是原型链 (#1983) (c3930ca)
  • openai-shim: 从兼容的本地提供商请求流媒体使用 (#2144) (decad0e)
  • 插件： 在副本 ENOENT 上保留 Windows 市场缓存 (#2220) (e2b021d)
  • 配置文件： 将上下文限制应用于所有配置文件模型 (#2201) (0b68e57)
  • sdk: 保留异步生成器会话上下文 (#2204) (0abfca3)
  • xai: 在解决回调之前验证 OAuth 状态 (#2228) (d16318a)

性能改进

  • bg: 避免完全扫描确切的会话 ID (#2166) (55e9b24)
