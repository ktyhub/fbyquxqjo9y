generative-models 0.0.1

变更流程图

亮点

  • 全新的 sgm 代码库与 SD-XL 模型 — 这是首发版本（0.0.1，2023-06-22），而非补丁更新：它同时交付 Stability AI 的 sgm 库以及 SD-XL 0.9-base 和 SD-XL 0.9-refiner 权重。如果你想运行或微调 SDXL，这就是需要参照的权威实现；由于没有更早版本，也就不存在迁移路径的问题。

  • 用 GeneralConditioner 统一条件输入 — 过去大量子类化的做法被移除；向量、序列、空间条件以及它们的各种组合，现在统一由单个 GeneralConditioner 类处理。如果你写过自定义条件子类，要注意这个扩展点已经消失——得把条件表达为传给通用类的输入，而不是靠覆写子类来实现。

  • 引导器、采样器与去噪框架解耦 — 引导器（guider）和采样器现在与模型相互独立，训练和推理都采用”去噪框架”。实际好处是：你可以自由组合采样/引导策略，无需编写模型专属代码；离散时间模型也被视为连续时间模型的一个特例。不过，围绕旧的紧耦合循环写的训练/推理脚本，预计都需要改造。

  • 独立的噪声/损失控制与清理后的自编码器 — 扩散损失函数的加权、网络预处理、训练时的噪声水平采样，现在都是独立可调的旋钮；自编码模型也做了清理。对希望单独调节这些因子的研究者来说值得升级；但自编码器相关的 API 已经变化，触碰这部分的下游代码应当复查。

  • 结论 — 如果你在做 SDXL 相关工作，或者要在 sgm 技术栈上开新项目，就采用这个版本；它是唯一版本，也奠定了整体架构。只有在你用的是完全无关且稳定的流水线、根本不需要 SDXL 时才可以跳过——这里没有任何增量可”升级”。官方没有给出明确的破坏性变更或迁移说明，但移除子类化和模型解耦重构，强烈意味着任何基于预发布版 sgm 编写的代码都会遇到破坏性变更。

  • 发布 SD-XL 0.9-base 和 SD-XL 0.9-refiner 模型
