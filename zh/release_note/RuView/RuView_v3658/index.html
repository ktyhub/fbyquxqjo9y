RuView v3658

这个项目是干啥的：一个面向机器人和边缘设备的感知开发工具，能跑模型测试、做证明和固件修复，给搞机器人开发的工程师用。

变更架构图

亮点

  • Linux wheel 用 Rust 1.89 重构建（PR #2521） — 合并 fix/pip-release-rust-1.89 重新固定了 pip-release CI，使 Linux wheel 用 Rust 1.89 编译。对在 Linux 上通过 pip 安装 RuView 的人来说，这就是本版本的全部意义：它针对与 Rust 工具链相关的 wheel 构建失败，让预构建 wheel 可靠产出，而不是退回到源码构建。如果你在之前 wheel 出问题后加过带固定版本的变通方案，这个 tag 就是重新测试的合适目标。
  • 仅打包改动，不是运行时发布 — 该快照（源码提交 9f91022）除了 CI 修复外没有任何功能工作，也没有源码变更。从上一 tag 升级对应用代码在运维层面没有影响——没有新 API、没有行为变化、没有 schema 迁移。把它当作分发产物的修复，而不是功能升级。
  • 本 tag 不含固件 — 该条目明确不随附固件包。ESP32 二进制只附在专门的 vX.Y.Z-esp32 发布上，因此烧录硬件必须从那些 tag 获取；只依赖此快照会让设备更新没有镜像可用。
  • 容器镜像独立发布 — sensing-server 的 Docker 镜像来自单独的 sensing-server-docker.yml 工作流，而非本发布 tag。如果你的部署流水线依据 GitHub release tag 来选取镜像，请注意 v3658 并不意味着有对应的新容器镜像。

无破坏性变更。
