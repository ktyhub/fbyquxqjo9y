RuView v3750

大版本 发布时间2026年11月17日 来源ruvnet/RuView 英文原文

RuView v3750

变更流程图

亮点

  • 供应链审计清理随私有 API 边界一并落地 — PR #2574 通过把 libz-sys 固定到 1.1.33、registry ZIP 固定到 9.0.5（两者都藏在一个私有的 Candle 文件名 API 适配器之后）来解决发布审计发现的问题。公告忽略列表有意保持不变，因此没有引入新的已知漏洞豁免——这是良好的合规信号。注意：适配器是私有的，意味着任何穿透到旧 Candle 文件名 API 的下游代码都必须改造；归档防护和真正的 Candle 张量 I/O 回归测试现在会守护这条依赖边界，升级时请测试你的张量 I/O 路径。

  • 可复现检出终于正常工作 — #2559 修复了检出本地的记忆引导，并隔离了旧缓存，使陈旧的缓存状态不再渗入全新的检出。对 CI runner 和干净构建工作流来说，这是最具实际意义的改动：根源于缓存记忆的”在我机器上能跑”差异应当消失。迁移提示：升级后请清理一次旧缓存，因为新的隔离不会追溯性地净化已有的磁盘状态。

  • 实时标签与字幕变得权威可靠 — #2558 从真实来源重新推导实时标签和 observatory 字幕，而不再使用此前缓存/派生的值。如果测试、仪表盘或抓取脚本固定依赖旧的字幕字符串，要预期出现偏移；应把显示的遥测视为新近可信而非表面修饰，并重新校准任何字符串断言。

  • RSSI 运动检测重新调参——需在硬件上验证 — #2557 为单链路 RSSI 运动检测换入一个较短的 dB 域窗口，改变了单链路运动推断的灵敏度和延迟。关键提醒：回归证据明确是合成的，真实 macOS/设备上的准确性尚未验证。投入生产前请在实际硬件上验证。

  • 范围：仅源码 tag，产物在别处 — v3750（提交 13b47883）是 CI 验证的源码快照，不含固件包。容器镜像通过单独的 sensing-server-docker 工作流发布，固件挂在专门的 vX.Y.Z-esp32 发布上，因此不要指望本 tag 下有固件产物。

未报告破坏性变更。

由 CI 管道验证的源快照。此条目不包含固件包。 变化： 合并来自 ruvnet/fix/issues-2557-2559 的拉取请求 #2574 修复签出本地内存引导程序和旧版缓存隔离 (#2559)，从实际源导出实时标签和天文台标题 (#2558)，并使用短 dB 域窗口进行单链路 RSSI 运动 (#2557)。 使用私有 Candle 文件名 API 适配器后面的 libz-sys 1.1.33 和注册表 ZIP 9.0.5 解决发布审核结果。现有的建议忽略列表保持不变。存档防护和真实的 Candle 张量 IO 回归覆盖了依赖边界。 验证和 CI 收据：https://github.com/ruvnet/RuView/pull/2574 RSSI 回归证据是综合的；真正的 macOS/设备准确性尚未得到验证。 修复#2559 修复#2558 修复#2557 源代码提交： 13b47883a73d5070f35a3f04aec2ffa778b47e29 容器镜像通过传感服务器发布工作流程单独发布。 固件下载附在专用 vX.Y.Z-esp32 版本中。
