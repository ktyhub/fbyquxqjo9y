pi v1.0.1

新功能

  • Nix flake — nix run github:earendil-works/pi/stable 运行最新版本，nix profile add github:earendil-works/pi/stable 安装它。请参阅安装 pi。
  • MCP 服务器的项目覆盖 — .pi/mcp.json 和 /mcp 可以启用、禁用或更改一个项目的用户级服务器的公开。请参见配置服务器。
  • MCP Client ID 元数据文档 — oauth.clientRegistration: "cimd" 允许授权服务器通过其文档 URL 来允许 pi，而不是动态注册。请参阅使用 OAuth 进行身份验证。
  • 任何工具的工具渲染器 — pi.registerToolRenderer() 绘制对尚未注册的工具的调用，例如恢复会话中的 MCP 工具。请参见工具渲染。
  • Cloudflare Clef 分类器 — @cf/cloudflare/clef 和 @cf/cloudflare/clef-flash 可从代码模式脚本和扩展中使用。请参阅使用分类器模型。

添加

  • 在 /login、/mcp 和 /mcp login 中的 OAuth 登录屏幕中添加了复制密钥（app.message.copy，默认为 ctrl+x），该密钥可在无法打开浏览器或无法选择包装链接时复制登录 URL。
  • 为 MCP 服务器添加了 oauth.clientRegistration: "cimd"，它使用 pi.dev 上的 Client ID 元数据文档来标识 pi，而不是动态 client 注册，因此授权服务器可以通过 URL 允许 pi (#10302)
  • 添加了用户级 MCP 服务器的项目覆盖：没有 command 或 url 的 .pi/mcp.json 条目仅设置用户级服务器的 enabled、exposure 和 toolExposure，而 /mcp 可以启用或禁用当前项目的服务器（#10277）
  • 将 Cloudflare 的 Clef 和 Clef Flash 分类器模型添加到 cloudflare-workers-ai，可通过代码模式脚本和扩展使用（#10316 by @ndisidore、#10322 by @RealAlexandreAI）
  • 添加了 pi.registerToolRenderer()，它选择如何调用工具，包括未注册的工具（#10285）
  • 添加了适用于 macOS 和 Linux 的 Nix flake：nix run github:earendil-works/pi/stable 运行最新版本，nix profile add github:earendil-works/pi/stable 安装它。请参阅安装 pi (#9137)

已更改

  • 全局 npm 安装上的 pi update 现在建议从 pi.dev 安装程序迁移到托管安装，该安装程序会固定所有依赖项。
  • 在对话中添加或重新定义的人为工具现在在对话中内联定义，因此以相同名称重新定义工具会保留提示缓存，而不是重新发送完整的工具列表。

已修复

  • 修复了通过将 brace-expansion 5.0.12 固定为直接依赖项来解决易受攻击的 brace-expansion 5.0.9 的安装（GHSA-q2hr-2g5m-vwhr、GHSA-qhr7-859c-m2p7、GHSA-6j4f-fj2g-mc7p）（#10288）
  • 修复了 --models 中的尾随逗号，向模型循环添加额外模型（#10334）
  • 修复了一个 codemode 脚本，该脚本在循环中打印，由于内存不足而导致 pi 崩溃：一旦其输出传递 16 个 Mi 字符或 100000 个项目，脚本就会失败（#10283）
  • 修复了通过 Image 扩展渲染的 JPEG、GIF 和 WebP 图像不会出现在 Kitty、Ghostty、WezTerm 和 Warp 中的问题 (#10292)
  • 修复了恢复会话中的 MCP 工具调用和 HTML 导出渲染完全扩展，直到服务器连接为止，或者如果从未连接过则永久扩展（#10285）
  • 修复了在 WezTerm 中滚动后全屏 Kitty 图像折叠成单行条的问题（#10319）
  • 修复了“所选模型已满”提供商错误结束回合而不是重试（[#10278]（https://github.com/earendil-works/pi/issues/10278））
  • 修复了使用虚线模型 ID（claude-opus-5-5 而不是 claude-opus-5.5）时 Cloudflare AI Gateway Claude 模型失败并出现 404 错误的问题
  • 修复了当 ChatGPT 的回调端口被另一个登录占用时继续使用 ChatGPT 登录，这导致浏览器显示“OAuth 状态不匹配”的问题；现在失败并出现端口使用错误 (#10265)
  • 修复了 Amazon Bedrock OpenAI 模型在短上下文速率下花费超过 272k 输入令牌的请求；基岩模型现在包括 models.dev 上列出的定价等级（#10326）
  • 修复了系统提示或工具更改后，Amazon Bedrock Claude 请求失败并显示“thinking 块中的 signature 无效”的问题 (#10324)
  • 修复了 Together DeepSeek V4 Pro 在 Together 重命名为 deepseek-ai/DeepSeek-V4-Pro-0813 后失去思考水平控制的问题 (#10336 by @cv)
  • 修复了默认 NVIDIA 型号指向 nvidia/nemotron-3-super-120b-a12b 的问题，该型号 NVIDIA 不再提供服务；现在默认为 nvidia/nemotron-3-ultra-550b-a55b

已删除

  • 从已发布的包中删除了 npm-shrinkwrap.json。 npm 安装不再固定传递依赖项，库使用者现在可以覆盖它们。使用 pi.dev 安装程序进行固定安装 (#5653)
