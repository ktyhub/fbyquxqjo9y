pi v0.86.0

pi v0.86.0

新功能

  • 提示缓存预热 — 在长时间工具运行期间以及可选地在空闲时使用成本感知刷新来保持有价值的提示缓存处于活动状态。请参阅缓存预热。
  • 错误报告 — 使用经过编辑的诊断、可选记录或导出的 ZIP 存档来报告 /bug 的问题。请参阅报告错误。
  • 转录感知提示和工具更新 — 在恢复和分支导航中保留指令和工具更改，同时保留缓存的前缀。请参见 before_agent_start。
  • 离线 Radius 模型目录 — 立即选择 Radius 模型，并在可用时覆盖缓存和实时目录。请参见半径。
  • 每个模型压缩预算 - 按模型配置保留和最近令牌预算。请参阅按型号覆盖。

重大变化

  • 将继承的 pi-ai 提供程序流输入从 Context 更改为标准化 TranscriptContext 值。自定义提供程序必须阅读 context.messages、getCurrentSystemPrompt() 和 getCurrentTools() 的系统提示和工具声明。请参阅自定义流媒体 API。
  • 将继承的 ToolCall.arguments 和 ToolResultMessage.details 限制为 JSON 兼容值，将 ToolResultMessage 更改为条件类型，并使 JsonValue 数组只读。
  • user_bash 现在无法关闭：错误或无效的定义结果会中止命令，而不调用后续处理程序或在本地执行。返回undefined继续传播；否则返回 { operations } 或 { result } (#9068)。

添加

  • 添加了转录支持的中间对话系统提示和工具更改，因此指令和工具更新可以在恢复和分支导航中保留下来，同时保留支持模型上的缓存前缀。请参阅 before_agent_start 和 条目类型 (#9548)。
  • 为 Fireworks 消息模型添加了继承的本机延迟工具加载。使用 ToolSearch 或 tool_search 作为提示前缀延迟的加载程序名称（#9323）。
  • 添加了分支摘要、压缩摘要和技能调用条目的 click 切换。
  • 添加了公共 Radius 模型目录，用于即时和离线模型选择，并在可用时覆盖缓存和实时网关目录。
  • 添加了 ctx.modelRegistry.stream() 和 streamSimple()，用于通过已配置的提供程序进行扩展模型调用，并解析身份验证（#8964）。
  • 通过 compaction.modelOverrides 添加了每个模型的 reserveTokens 和 keepRecentTokens 设置，并使用普通压缩设置作为后备（#8133）。
  • 添加了 compat.allowedFallbackModels 配置，用于覆盖或禁用 Anthropic 服务器端回退模型（#9294）。
  • 添加了 pi.on() 的取消订阅功能，以便扩展可以删除事件处理程序。在调度期间添加或删除的处理程序适用于以后的调度，而不是当前的调度（#8967）。
  • 导出以前从包入口点省略的扩展挂钩事件和结果类型（#9642）。
  • 添加了 /bug [description] 以向 Pi 开发人员报告错误。该报告捆绑了环境、模型、提供程序、扩展和设置元数据（已编辑的机密）、会话中的辅助消息诊断、可选的会话记录或模型编写的错误摘要。它被上传到 Radius（无需登录；登录时归属）或导出为 zip 存档，并且报告 ID 作为 pi.bug-report 条目记录在会话中。崩溃记录在~/.pi/agent/crashes.json中，在下次启动时公布一次，并附在下次报告中；无法解释的错误和耗尽的重试指向 /bug，每个会话一次。
  • 在长时间工具运行期间以及可选地在空闲时添加了成本感知提示缓存预热，具有可配置模式、模型缓存生命周期元数据、/session 诊断、转录通知和 cache_warming_decision 扩展事件。请参阅缓存预热 (#9668)。

已更改

  • 使 --resume 会话结果逐步显示，使用文件修改时间来优先考虑所有文件夹加载并在选择后取消未完成的转录读取。
  • 通过按修改时间顺序检查候选会话标头并在最新匹配会话后停止，减少了 --continue 启动时间。
  • 用捆绑的异步 macOS、Windows 和 X11 帮助程序替换了外部本机 clipboard 依赖项，同时保留平台命令和 OSC 52 回退 (#9163)。
  • 通过使用本机子字符串搜索而不是扫描 JavaScript 中的每个字符，减少了长文本的继承模糊搜索延迟（#9267）。
  • 将压缩、分支汇总和重试旋转器移至工作指示器旁边的编辑器边框中。自定义编辑器对所有状态旋转器使用相同的嵌入选择。
  • 默认情况下，对内置 read、bash、powershell、edit 和 write 工具启用严格首选 JSON 模式采样，而不需要 PI_EXPERIMENTAL。扩展可以使用 constrainedSampling: false 重新注册工具定义。
  • 格式化的 Bash 和 PowerShell 工具持续时间至少为一分钟，如分钟和秒，需要时可以为小时 (#9628)。
  • 推迟了扩展编译器和捆绑的虚拟模块，直到加载文件系统扩展为止，从而降低了基线 SDK 导入成本（#9540）。

已修复

  • 修复了 GitHub Copilot GPT 模型，包括 GPT-6 Astra，使用聊天完成适配器而不是所需的响应适配器（#9253 by @petrroll）。
  • 修复了 OpenRouter 和 OpenCode Go 上继承的 DeepSeek V4.1 思维水平，保留提供者工作元数据 (#9485)。
  • 修复了来自非 Cerebras 提供商的继承的无正文 HTTP 400/413 错误，该错误被错误分类为上下文溢出 (#9482)。
  • 修复了继承的 Vercel AI Gateway 将未签名的思维重播为辅助文本的问题 (#9676)。
  • 修复了当省略推理或 Gemini 系列中模型功能不同时使用不受支持的思维水平继承的 Google Generative AI 和 Vertex AI (#9455)。
  • 修复了继承的人类兼容中继在报告不同的响应模型时破坏签名思维重放，同时保留后备定价（[#9188]（https://github.com/earendil-works/pi/issues/9188））。
  • 修复了继承的 Amazon Bedrock 一小时缓存写入按五分钟费率定价的问题 (#9457)。
  • 修复了耗尽缓冲的 EventStream 事件时继承的二次 CPU 使用率（#9055）。
  • 修复了继承的 Mistral Medium 推理请求，以将 reasoning_effort 用于所有具有推理功能的 mistral-medium-* 模型 ID，而不是不受支持的 prompt_mode (#8700)。
  • 修复了继承的 OpenCode 和 OpenCode Go 请求，以跨所有支持的 API 适配器从 sessionId 发送 x-opencode-session (#9326)。
  • 修复了继承的 OpenAI Codex 请求，以发送模型的关闭推理工作而不是忽略它，同时尊重不受支持的关闭映射 (#9191)。
  • 修复了使用目录元数据继承的 Fireworks 未签名思维重放和推理工作选择，并验证了 DeepSeek V4 和 Qwen3.8 回退，并删除了冗余的 GLM 5.2 和 Kimi K3 工作别名（#9323）。
  • 修复了启用提示缓存时，从 sessionId 发送 x-session-id 的继承 OpenRouter 请求，用于聊天完成和人类消息模型 (#9102)。
  • 修复了继承的 DeepSeek 目录，以宣传 DeepSeek V4.1 Flash 的 deepseek-flash，而不是已停用的 Flash 别名，并刷新了 DeepSeek 定价元数据 (#9423)。
  • 修复了继承的 Mistral 托管的 GLM-5.2 推理请求，以使用 reasoning_effort 而不是被忽略的 prompt_mode (#9375)。
  • 修复了继承的 OpenAI 兼容响应错误，以识别实际的提供者，而不是始终将其标记为 OpenAI 错误 (#9298)。
  • 修复了从 sessionId 发送会话关联标头的继承 Baseten 请求，以实现自动提示缓存路由（#9629）。
  • 修复了 Cloudflare 520 响应的继承重试分类 (#9627)。
  • 修复了暂时性 Azure 峰值负载容量错误的继承重试分类 (#9669)。
  • 修复了主动压缩的会话树导航竞速问题，并用 @acmerfight 替换其进度 UI (#9179)。
  • 修正了精确的会话 ID 查找扫描完整的记录正文，而不是读取会话标题（@metaist 的#9601）。
  • 修复了针对相同掉落块显示的重复人择思维掉落通知，并缩短了通知，同时保留会话中的详细信息（#9391）。
  • 修复了运行中阈值压缩静默跳过过大的尾随工具结果的问题（#9740）。
  • 修复了信号终止的本地 shell 命令被报告为部分输出成功的问题（@BrendanJMurphy 的#9577）。
  • 修复了当终端忽略后备 OSC 52 写入时报告成功的本地 clipboard 故障，并在 clipboard 后端不工作时添加特定于平台的设置指南 (#9618)。
  • 代理级重试回退上限为 retry.maxAgentDelayMs（默认为 60 秒），以便长时间重试运行在长时间短暂中断期间保持响应（#8826）。
  • 修复了绕过扩展 input 处理程序的直接 RPC steer 和 follow_up 命令（#8718）。
  • 通过等待目录发现修复了登录后过早丢失模型的错误。半径现在默认为 balanced，在需要时回退到第一个可用的半径模型。
  • 修复了全屏模式为呈现零行的自定义页脚保留空白行的问题 (#8919)。
  • 修复了没有参数架构的扩展工具在注册期间被拒绝而不是破坏提供程序请求的问题（#9300）。
  • 修复了 before_agent_start 处理程序在具有对话中系统消息的模型上返回 systemPrompt（和 forceSystemPrompt）的问题：强制提示现在作为提供程序的主要系统提示发送，而不是作为部分补丁附加在原始提示之后。
  • 修复了加载带有 enable_thinking 聊天模板的 llama.cpp 模型，忽略 Pi 的思维水平（#9528）。
  • 修复了取消竞赛，可能会启动自动压缩、留下过时的重试状态或在等待摘要身份验证时错过取消（#9340、#9777）。
  • 修复了异步 Kitty 图像转换，替换了较新的部分工具输出图像（#8743 by @wutongyuonce）。
  • 修复了继承技能斜线命令自动完成排名 skill: 前缀而不是裸技能名称（#9120 by @yearth）。
  • 修复了继承的文件自动完成边界和围绕 CJK 标点符号的路径引用（#9746 by @haoqixu）。
  • 修复了继承的 LaTeX 旧版字体切换回原始源、围绕周围方程居中的 cases 布局以及垂直布局不受支持和嵌套的显示脚本（#8827、#9564、#7929）。
  • 修复了继承的全屏 Kitty 图像被 WezTerm 中后续行清除所删除的问题 (#9169)。

已删除

  • 从 OpenAI Codex 选择中删除了不可用的继承 GPT-5.4 和 GPT-5.4 迷你模型 (#9394)。
