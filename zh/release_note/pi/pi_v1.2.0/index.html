pi v1.2.0

pi v1.2.0

新功能

  • 每键 OpenRouter 模型列表：使用 OpenRouter 密钥，Pi 仅列出该密钥可能使用的模型，以及该密钥的上下文大小、最大输出和价格，包括在 models.json 中设置的区域端点。请参阅OpenRouter。
  • 已发布的配置模式：将 $schema 添加到 settings.json、models.json、键绑定和主题以进行编辑器验证和完成。请参阅设置、型号、按键绑定和主题。
  • Clipboard 通过远程会话进行复制：当 Pi 无法检测到远程会话（例如从另一台计算机连接的多路复用器）时，PI_CLIPBOARD_OSC52=1 将复制的文本发送到远程 client 的 clipboard。请参阅Pi 进程配置。
  • 代码模式改进：工具声明显示输入约束，例如整数、最小值/最大值和默认值，代码模式行显示已用时间和总时间。请参阅代码模式。
  • before_agent_start 用于扩展触发的运行：由 pi.sendMessage(..., { triggerTurn: true }) 启动的运行将经历与提示相同的设置。请参阅事件和并发。

重大变化

  • 在 https://pi.dev/schemas/*.schema.json 上发布了模型、设置、键绑定和主题的生成配置架构。主题架构移至https://pi.dev/schemas/theme.schema.json；现在，启动期间加载的主题会收到与稍后重新加载相同的架构验证。更新主题 $schema 引用，定义 vars 下可重用的颜色，并删除不受支持的元数据（#9880、#10751 by @christianklotz）
  • 将 before_agent_start 更改为在空闲时由 pi.sendMessage(..., { triggerTurn: true }) 启动的运行也会触发。 BeforeAgentStartEvent 现在是 messageType 上的联合体："user" 赛事携带 prompt 和 images，而 "custom" 赛事则携带起始 message 而没有 prompt。处理程序返回的消息将添加到两种类型的运行中，并且挂起的 deliverAs: "nextTurn" 消息将随自定义消息运行一起传递。仅应根据用户提示执行操作的处理程序必须检查 event.messageType === "user"（#10267、#5581、#10739 by @davidbrai）
  • 将会话更改为在运行开始时计数为繁忙，包括在 before_agent_start 处理程序期间：ctx.isIdle() 为 false，pi.sendMessage() 排队进入开始运行，而不是启动因“代理已在处理”而失败的第二次运行，pi.sendUserMessage() 需要 deliverAs，同时请求中止，一旦启动就会中止运行（#10739作者：@davidbrai)
  • 将 pi mcp list --json 更改为为提供资源的服务器报告 resources: true，而不是 resources 和 resourceTemplates 计数； Pi 在连接时不再列出资源 (#10526)

添加

  • 在工具定义中添加了 reachesTools，以便到达其他工具（例如 codemode 和 tool_search）的工具声明调用可以到达哪些工具； MCP 扩展使用它来等待呼叫所需的服务器，并决定替换的 codemode 或 tool_search 工具是否可以到达 MCP 工具
  • 将 aliases 添加到工具命名空间； codemode 的 describeNamespace() 和 searchTools() 的 namespace 选项与它们匹配，MCP 命名空间使用服务器名称
  • 添加了每个密钥的 OpenRouter 模型列表：使用 OpenRouter 密钥，Pi 仅列出该密钥可能使用的聊天模型，以及该密钥的上下文大小、最大输出和价格，包括在 models.json 中设置为基本 URL 的护栏和区域端点。该列表已保存并离线使用（#10353、#10672 by @davidbrai）
  • 添加了 PI_CLIPBOARD_OSC52=1，以在本地 clipboard 写入后使用 OSC 52 将复制的文本发送到终端，因此当 Pi 无法检测到远程会话时，副本会到达远程 client 的 clipboard，例如从另一台计算机或远程 IDE 守护程序连接的多路复用器（#10826， #10835、#10114)
  • 添加了代码模式脚本运行时的经过时间及其完成后的总时间到代码模式工具行，如 bash 行（#10708）

已更改

  • 更改了 showHardwareCursor 设置以仅使用终端光标，而不是同时绘制 Pi 的反显光标
  • 更改了代码模式工具声明，以在属性注释上将输入约束（例如整数、最小值/最大值、长度、模式和默认值）显示为 @ 标记，因此脚本无需工具在描述中重复它们即可看到它们（#10707）
  • 更改了 MCP 工具的代码模式声明，以阐明结果类型（content、structuredContent、isError），而不是引用 CallToolResult<T>，describeTool()、searchTools() 和 ALL_TOOLS 在未定义它的情况下显示了它；代码模式描述不再包含共享 MCP 类型
  • 更改了 serializeConversation()（压缩、分支摘要、错误报告）以省略思维块；重播的思维通常不在实时上下文中，因此包含它可能会使总结请求大于它总结的上下文并失败

已修复

  • 修复了代码模式忽略不是脚本第一行的 // @options: 行的问题，该行在没有请求的 timeout_ms 的情况下运行脚本；现在，在脚本运行之前调用失败并出现错误 (#10631)
  • 修复了请求超时后米斯特拉尔流在生成中期（例如在长时间思考期间）中止的问题；超时现在仅适用于等待响应标头（#10609）
  • 修复了嵌套在其主存储库中的 git 工作树中的符号链接 AGENTS.md 导致无法加载项目上下文文件（#10681）
  • 修复了代码模式工具描述，声称每个失败的工具调用都会被拒绝；声明输出模式的工具也会在失败时解析其值（例如具有非零退出的 bash）
  • 修复了由 pi.sendMessage(..., { triggerTurn: true }) 启动的运行，删除了第一次工具调用后在 before_agent_start 中添加的系统提示部分，这在运行中更改了提示，并在每次运行时两次破坏了提供程序提示缓存（#10267、#10739，作者：@davidbrai)
  • 修复了在执行多次 text() 调用的脚本后代码模式阻塞进程几秒到几分钟的问题；连接输出项是二次的（#10678）
  • 修复了当最终响应在模型的输出令牌限制处被切断时打印模式（-p）退出 0 且没有警告的问题；它现在打印部分文本，向 stderr 写入警告，然后退出 1 (#10799)
  • 修复了 pi mcp login --help 和 CLI 文档，将 --timeout 描述为仅等待浏览器；它限制了整个登录（#10636）
  • 修复了 ~ 未在 extensions、skills、prompts 和 themes 设置的 !pattern、+path 和 -path 条目中展开的问题，因此 !~/skills/pdf 等条目不匹配任何内容（#10765）
  • 修复了 MCP 服务器的资源在列出所有资源之前不会注册任何工具； Pi 在连接时不再列出资源，因此 /mcp 和 pi mcp list 显示服务器提供资源而不是对资源进行计数 (#10526)
  • 修复了当服务器返回非对象（数组、null 或原语，如 MCP 2026-07-28 允许的情况）的结构化内容时 MCP 工具调用失败的问题；不带输出模式的 MCP 工具的代码模式声明现在将 structuredContent 键入为 unknown 而不是对象 (#10416)
  • 修复了在 Windows 上读取或写入 auth.json 时，当仍删除先前的锁定文件夹时，失败并显示 EPERM 的问题； Pi 现在在报告错误之前短暂重试 (#10801)
  • 修复了 OpenRouter 路由器模型，例如 openrouter/auto，显示每 100 万代币的成本为 - 1,000,000 美元； OpenRouter 的负占位符价格现在为 0（#10672 by @davidbrai）
  • 修复了当提供者拒绝语法大小、工具计数或联合限制的严格工具集时，人择请求失败的问题； Pi 现在使用非严格的首选工具重试一次（#10409）
  • 修复了“上游提供程序返回错误”未作为暂时提供程序错误重试的问题 (#10842)
  • 修复了焦点全屏覆盖阻止鼠标滚轮滚动转录的问题（#10769）
  • 修复了碎片化的终端颜色回复将十六进制值泄漏到提示中并打开外部编辑器的问题（相关报告：#10256、#10657）
  • 修复了自 1.1.0 以来内联图像未在 Herdr 中渲染的问题（#10774 by @ogulcancelik）
  • 修复了命名移位符号（例如 + 或 ctrl++）的键绑定，在 Kitty 键盘协议下不匹配或修改其他键（#9880 by @christianklotz）
  • 修复了自定义编辑器中嵌入的压缩状态指示器，使用默认的静音颜色而不是编辑器边框或思维级别颜色，就像工作指示器一样（#10809、#10810 by @Jay-Madden)
  • 修复了在等待 OAuth 刷新时取消或超时的 MCP 工具调用，刷新完成后仍会发送到服务器 (#10598)
  • 修复了 MCP OAuth 登录接受带有 iss 参数的授权响应的问题，由于未发现授权服务器元数据，因此无法检查该参数；由于颁发者不匹配，登录现在失败。报道者：@AizenvoltPrime
  • 修复了当 Pi 在节点 24 或 26 上的 node --watch 下运行时代码模式因断桥错误而失败的问题 (#10725)

已删除

  • 删除了未发布的实验服务器 client 和插件堆栈（src/experimental、src/cli/experimental）及其仅源的 ./client 和 ./experimental/plugin 导出；这些都不是已发布的包的一部分。它使用的@earendil-works/pi-client、@earendil-works/pi-protocol和@earendil-works/pi-server封装已被删除，不再发布
  • 删除了对 @earendil-works/chord 的依赖
