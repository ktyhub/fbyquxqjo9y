pi v0.87.0

pi v0.87.0

新功能

  • 规范会话上下文和扩展边界 - 编辑模型上下文而不重写历史记录并添加可操作的生命周期挂钩。请参阅 ContextEditEntry 和 扩展事件。
  • 完整转录上下文扩展 — 使用 context_with_system 进行每个请求的系统消息转换。请参阅 context_with_system。
  • 每模型图像输入限制 — 为附件、read 和工具结果图像配置每个模型的缓存安全图像调整大小。请参见图像输入限制。

重大变化

  • 删除了继承的shouldStopAfterTurn代理选项。使用 finishTurn 并返回 { action: "end" }。 finishTurn 在 turn_end 之前运行，但随后应用决策，并且它还会收到错误和中止响应；通过为这些硬退出返回 undefined 来迁移正常响应谓词。有关完整的前后示例，请参阅 @earendil-works/pi-agent-core changelog。
  • 将 ContextEditEntry 添加到导出的 SessionEntry 联合中。具有详尽入口开关的 TypeScript 消费者必须处理 context_edit；使用 replacement: null 进行省略和内容替换。
  • 使 SessionManager 成为 AgentSession 提供者上下文的规范。分配 session.agent.state.messages 不再取代未来的请求历史记录；使用 SessionManager.inMemory(cwd, { id }, entries) 恢复，使用 session.navigateTree() 导航，或通过 session.sessionManager 追加并调用 session.refreshContext()。
  • 使用所需的边界字段扩展了 TurnEndEvent，并将 AgentBeforeSettleEvent 添加到导出的 ExtensionEvent 联合中。构建事件或彻底切换 ExtensionEvent 的消费者必须处理新形状。 ExtensionRunner.emit()不再接受turn_end；主机集成通过 emitBoundary(baseEvent, buildContext) 调度可操作的边界。
  • 推迟 agent_settled 处理程序请求的运行，直到所有已解决的处理程序完成。处理程序仍然观察 ctx.isIdle() === true，但在同一通知调度期间不再看到可重入的 agent_start。

添加

  • 添加了仅附加模型上下文编辑。例如，sessionManager.appendContextEdit(entryId, null) 从未来的提供程序上下文中省略一条消息，而不更改原始历史记录、使用情况或 UI 历史记录。
  • 添加了可操作的 turn_end 和 agent_before_settle 扩展边界。返回 { entries: [...event.entries, draft], continue: true } 以按顺序保留结构条目，并确保下一个提供者请求，而无需更改转向或后续调度。
  • 添加了保留无压缩输入：sessionManager.appendCompaction(summary, null, tokensBefore) 将压缩自己的 ID 存储为其保留边界。
  • 添加了 context_with_system 扩展事件，该事件在完整记录（包括系统消息）上的 context 处理程序之后运行，并逐字发送其结果。参见context_with_system。
  • 通过 models.json 中的 inputLimits.images.resize 添加了每个模型图像调整大小配置文件，应用于文件附件、图像读取和工具结果图像 (#9631)。

已修复

  • 修复了字符串上下文编辑替换生成无效助手和工具结果消息内容而不是文本块的问题。
  • 修复了上下文不可见的边界元数据和替换编辑，导致新附加或替换的输入在第一个提供程序请求之前进行汇总。
  • 修复了编辑上下文会计，丢弃最新上下文编辑后捕获的有效助手使用情况，并在稍后的压缩使其过时后重用该用法。
  • 修复了选定的错误重试和最终长度/溢出恢复，在未来的提供者上下文中保留放弃的模型尝试；现在，运行后恢复遗漏会持续存在，而无需隐藏原始转录历史记录或更改队列调度。
  • 修复了 context 处理程序，该处理程序会过滤或切片消息，从而删除提示和工具声明，这些处理程序在扩展驱动的压缩后留下没有内置工具的请求，或者使 Codex 发出原始工具调用文本。处理程序不再看到系统消息； Pi 在运行后恢复提示和工具状态。请参见 context（#9789、#9822）。
  • 修复了 /bug，允许在离线模式下上传，同时保留本地 zip 导出（#9841 by @christianklotz）。
  • 修复了当定时器或扩展决策延迟时空闲提示缓存预热重建过期缓存的问题。
  • 改进了崩溃诊断，并提供了识别堆栈跟踪中出现的已加载扩展的提示。
  • 修复了以 GIF 开头的文本文件被错误分类为图像并从 read 和 CLI @file 输入中省略的问题（#9755）。
  • 修复了格式错误的提示模板 frontmatter 被默默忽略而不是报告为资源警告的问题（#9830 by @christianklotz）。
  • 修复了继承的未知 OpenAI 兼容聊天完成端点接收严格的工具模式，除非它们明确宣传支持（#9816）。
