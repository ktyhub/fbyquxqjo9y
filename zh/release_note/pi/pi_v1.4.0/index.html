pi v1.4.0

pi v1.4.0

新功能

  • 分类器的图像输入：对于 typesafe、cloudflare-workers-ai 和 OpenRouter 上的 TypeSafe 的 Jev 和 Cloudflare 的 Clef 模型，代码模式 models.classify() 接受 images。请参阅使用分类器模型 和代码模式。
  • 模型配置参考：从其架构生成的 models.json 的每个提供程序、模型、模型覆盖和兼容性字段。请参见型号配置。
  • 没有固定输出上限的摘要：压缩和分支摘要使用模型的输出限制，因此长推理不再使它们失败。请参见压实。
  • Codemode 等待空闲工作人员：并行脚本和进程内子代理排队而不是失败，并且 PI_CODEMODE_MAX_WORKERS 提高了限制。请参阅代码模式限制。
  • Rex 终端支持：OSC 8 超链接、真彩色和内联图像。

添加

  • 添加了从 models.json 架构生成的模型配置参考，列出了所有提供程序、模型、模型覆盖和兼容性字段 (#10790)
  • Codemode models.classify() 现在在 typesafe、cloudflare-workers-ai 和 OpenRouter 上接受 TypeSafe 的 Jev 和 Cloudflare 的 Clef 模型的 images，并在 Workers AI 上列出 Clef Omni 和 Jev 1.14。
  • models.json 中的提供商级 compat 现在也适用于分类器模型，其中 System One 字段 imageInput 和 sendImageOptInHeader 用于为另一服务的分类器提供服务的代理。扩展分类器模型也接受 compat。
  • 将 MiniMax-M3.1-Flash 添加到 minimax 和 minimax-cn 提供程序中，思维水平从低到最高（#11121）
  • 添加了对 Rex 终端的支持：OSC 8 超链接、真彩色和内联图像（#11131、#11150 by @petrroll、#11183 by @nihaals）

已更改

  • 提供商归属标头现在来自 pi-ai 的 client 身份。扩展的 before_provider_headers 处理程序不再看到 OpenRouter、NVIDIA NIM 和 OpenCode 属性标头；返回 null 仍会将其删除。 Cloudflare 请求发送 pi 的详细 User-Agent 而不是 pi-coding-agent，GitHub 版本检查工具下载也是如此，OpenCode 请求在启用归因时发送 x-opencode-client，而不仅仅是会话。
  • generateSummary() 和 generateSummaryWithUsage() 现在忽略其 reserveTokens 参数。摘要请求改为使用模型的输出限制。
  • 将默认的 GitHub Copilot 型号从 Copilot 退役的 gpt-5.4 更改为 gpt-6.1-sol。
  • 将默认 NVIDIA 型号更改为 nvidia/nemotron-3.5-super-vl-120b-a12b（@cv 的#10910）
  • 由于 mimo-v2.5-pro 已退出目录，因此将 xiaomi 和小米代币计划提供商的默认小米型号更改为 mimo-v2.6-pro。
  • xai 提供商上的 Grok 4.3 和 Grok 4.5 现在提供 xhigh 思维级别。
  • 使用 ChatGPT 登录：不会重试 ChatGPT Business 工作区使用限制错误，并告诉用户要求其工作区管理员增加限制。

已修复

  • 修复了当推理使用大部分固定摘要输出限制时，压缩和分支摘要因“生成达到令牌上限”而失败的问题。摘要现在使用模型的输出限制，并且 compaction.reserveTokens 仅控制压缩何时开始（#9512、#9075）。
  • 修复了 models.schema.json 缺少提供者和模型字段的描述，因此编辑器没有显示它们的提示（#10790）
  • 修复了当 managed-install.json 以 UTF-8 BOM 开头时 pi update 失败并显示“托管安装标记丢失或无效”的问题，Windows PowerShell 5.1 在重写文件时会添加该 BOM。
  • 修复了 HTML 导出在 CJK 标点符号旁边显示 Markdown 粗体和斜体字面星号的问题（#3353、#10154）
  • 修复了当 pi 在没有正常终端拆卸的情况下退出时，终端停留在鼠标跟踪、焦点报告、Kitty 键盘和备用屏幕模式，这会用转义序列淹没 shell 提示符 (#11170)
  • 修复了交互模式下的并发扩展 select/confirm/input/editor 对话框和内联 custom() 组件：第二个对话框取代了第一个对话框，第一个承诺从未解决；关闭可见对话框现在会再次显示上一个对话框（#11166、#9909）
  • 修复了在 Linux 上复制 pi 中的文本并使用 Ctrl+Z 暂停后在 shell 中粘贴的问题：持续为 clipboard 提供服务的后台 wl-copy/xclip/xsel 进程与 pi 一起被暂停（#11179）
  • 修复了当两个代码模式工作人员都忙时（例如并行代码模式调用或进程内子代理）时代码模式脚本立即失败的问题。脚本现在最多等待 60 秒等待一个空闲的工作线程，并且 PI_CODEMODE_MAX_WORKERS 提高了两个工作线程的限制 (#11184)
  • 通过扩展加载器别名和虚拟模块公开子路径，修复了导入 @earendil-works/pi-ai/models（例如 clampThinkingLevel）时无法加载扩展的问题（#11156）
  • 修复了以 UTF-8 BOM 开头的 mcp.json 文件无法解析的问题，该文件跳过了所有 MCP 服务器并导致 pi mcp add/pi mcp remove 失败（#11191）
  • 修复了 /compact <instructions> 在总结压实分裂的回合开始时忽略说明的问题。当分割回合是自上次压缩以来唯一的新内容时，指令将被完全忽略（#11058）
  • 修复了恢复会话和 /tree 导航，当分支在注册之前记录其工具时，使扩展工具处于非活动状态，例如会话开始后安装的扩展中的工具。从未添加或删除的分支的扩展工具现在处于活动状态，除非它们已向 defaultActive: false 注册（#11062、#11075）
  • 修复了从输出限制处切断的响应恢复后会话中断的问题：省略了截断的工具调用，但保留了其工具结果，因此提供程序拒绝了以后的每个请求（#11227、#11233 by @petrroll）
  • 修复了 RIPGREP_CONFIG_PATH 之后的 grep 工具，其中 --fixed-strings 等选项默默地将正则表达式搜索更改为文字搜索。该工具现在运行 rg --no-config (#11203、#11230 by @petrroll)
  • 修复了拒绝可运行的 Microsoft Store shell 别名的 Windows shell 检测（#9504 by @petrroll）
  • 修复了当 C:\Windows 中未安装 Windows 时，Windows shell 检测在 PATH 和旧版 WSL bash.exe 启动器之外缺少 PowerShell 的情况。 pi 现在检查 %ProgramFiles%\PowerShell\7、%SystemRoot%\System32\WindowsPowerShell\v1.0 和 %SystemRoot% (#9501 by @petrroll)
  • 修复了具有大型请求正文（例如许多图像）的 GitHub Copilot 会话，失败并显示 HTTP 413 failed to parse request，而不是压缩和重试（#11016 by @petrroll）
  • 修复了提供 gpt-5.5 和 gpt-5.3-codex-spark 的 openai-codex 提供商对于 ChatGPT 帐户总是失败的问题 (#11173 by @lucasmeijer)
  • 修复了纯空白工具输出（例如 bash 中的裸 \r\n），导致 OpenAI 完成、OpenAI 响应和 Google 请求失败并显示 400 (#8720)
  • 修复了更多网关上游故障、Codex CLI 代理中继的 stream disconnected before completion 错误、暂时性 Google Vertex OAuth 令牌刷新失败以及由于请求 id 或字节计数中的数字而导致的重试错误（#10920、#11057）时不会触发自动重试的问题。 #10996)
  • 修复了删除工具后 OpenAI Responses 模型在每个延迟工具加载时丢失提示缓存的问题 (#10940)
  • 修复了 Cloudflare Workers AI 分类器的定价：Clef Flash 的成本为每百万输入代币 $0.038，Jev 的成本为 $0.042，而不是 Jev 被列为免费。
  • 修复了未封闭的 $$ 显示数学块吞没或损坏其后的每个 Markdown 表的问题 (#11159)
  • 修复了 Markdown 粗体和斜体不在 CJK 标点符号旁边渲染的问题 (#10730 by @theBucky)
  • 修复了 @ 文件自动完成功能，对于包含正则表达式元字符（例如 [ 或 (）的查询不返回结果（#10972）
