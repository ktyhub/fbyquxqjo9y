arthas arthas-all-4.3.5

发布 发布时间2026年8月31日 来源alibaba/arthas 英文原文

arthas arthas-all-4.3.5

变更流程图

亮点

  • fastjson2 安全升级（PR #3261） — 内置的 fastjson2 从 2.0.58 升到 2.0.64，带来 AutoType 反序列化加固和解析器层的 OOM/DoS 修复。这是本版本唯一的运行时代码改动，也是采用它的主要理由：如果你运行 Arthas Server/tunnel，或在共享、不可信环境中依赖 OGNL/JSON 反序列化，这次升级堵上了已知的滥用途径。它只是依赖版本提升——命令语法和 API 表面均无变化——因此是低风险、高价值的更新。
  • Kubernetes 临时容器与 sidecar attach 指南 — 新文档覆盖 kubectl debug 临时容器路径和跨容器 sidecar attach。这在运维上很关键：对于 distroless/极小镜像或只读根文件系统、无法 kubectl exec 进 shell 的场景，这是受支持的调试路径。请留意验证容器间的共享 PID namespace 和进程可见性，因为 attach 目标必须在 pod 内可见。
  • 复杂 OGNL 实战手册（PR #3262） — 新增中英文进阶 OGNL 表达式指南，统一了相关命令（watch、trace、stack、tt 等）与 API 文档中的链接。实际价值在于：watch 和 tt 中的复杂条件/过滤是大多数人卡壳的地方；这份指南减少试错，并引导你写出避免重度反射或副作用的追踪表达式。
  • 清理失效的教程链接（PR #3263） — 从 CLI、README、Web Console 和站点文档中移除过期的在线教程入口。这属于外观调整但直接面向用户：“打开教程”的入口不再指向死链，上手摩擦随之降低。值得快速检查是否有内部文档或 runbook 复制了这些现已移除的链接。

本版本无破坏性变更。

变更概览

  • 修复：将 fastjson2 从 2.0.58 升级到 2.0.64，引入 AutoType 及解析器 OOM/DoS 修复，见 #3261
  • 文档：新增 Kubernetes 临时调试容器与 sidecar 跨容器附加指南
  • 文档：新增中文复杂 OGNL 表达式指南，并来自相关命令与 API 文档统一链接，见 #3262
  • 杂务：清理CLI、README、Web Console与站点文档中已失效的在线教程入口，见#3263
