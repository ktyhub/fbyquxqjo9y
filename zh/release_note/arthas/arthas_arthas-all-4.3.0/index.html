arthas arthas-all-4.3.0

发布 发布时间2026年6月15日 来源alibaba/arthas 英文原文

arthas arthas-all-4.3.0

变更流程图

亮点

  • 行级探针（line，#3210） — 新增断点式命令，可在指定源码行检查参数、局部变量、任意表达式和当前调用栈，且无需重启。它补上了方法级 watch/trace 与完整调试器之间的空白，很可能成为定位方法内中途状态的首选——但它依赖编译产物中保留调试符号/局部变量表，剥离符号的构建拿不到完整信息。
  • 静默终端模式（#3213） — 面向 agent/AI、批处理、WebSocket 和 MCP 调用方的低噪声输出模式，去掉交互式提示和装饰。如果你以编程方式驱动 Arthas，把自动化切到这个模式是值得的：更干净的输出意味着解析更不容易脆弱，也比抓取 TTY 格式文本少浪费 token。
  • MCP 版本工具（#3211） — 把正在运行的 Arthas 版本暴露为 MCP 工具，让客户端在发命令前先发现能力。适合在 agent 工作流中按版本开关命令；它纯粹是增量添加，现有工具契约不受影响。
  • Advice 监听器快照修复（#3209） — 修正快照注册，使增强监听器的状态保持一致。这是字节码插桩可靠性修复：如果你维护自定义 advice 插件，或曾在不同 re-transform 之间看到不一致行为，这项改动值得关注。
  • ClassLoader 表格转义（#3208） — 多行 ClassLoader 名称现在会正确转义，终端表格不再串列。表面上是外观问题，但如果你解析 classloader 输出就很关键——请按新格式重新检查日志抓取逻辑。
  • Spring Boot Starter 兼容性文档 — 刷新了 starter 的支持版本矩阵。如果你锁定某条 Spring Boot 版本线，升级前值得一看，因为文档现在反映的是实际受支持的版本。

本版本无破坏性变更。

变更概览

  • feat: 新增 line 命令，支持在指定源码行插入引用，观察方法参数、局部变量、表达式结果和当前调用栈，见 #3210
  • feat: 为agent/AI场景增加安静终端模式，减少批处理、WebSocket和MCP执行时的交互噪音，见#3213
  • feat: 新增Arthas MCP版本工具，支持通过MCP工具查询当前Arthas版本，见#3211
  • 修复：修复建议监听器快照注册逻辑，避免增强监听放大器故障，见#3209
  • 修复：修复 classloader 展示中多行类加载器名称的转义问题，避免终端表格输出错位，见 #3208
  • 文档：更新 Spring Boot Starter 支持版本说明
