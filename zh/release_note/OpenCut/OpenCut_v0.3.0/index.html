OpenCut v0.3.0

这个项目是干啥的：一个在浏览器里就能用的视频剪辑工具，渲染快、能加动画特效，给不想装复杂软件、想快速剪视频的人用。

变更架构图

亮点

  • Rust/wgpu 渲染器取代 WebGL — 整个渲染后端被换掉：GLSL 着色器和旧 WebGL 工具链移除，改为编译到 WASM 的 Rust/wgpu 合成器（rust/crates/compositor、.../effects、.../masks 用 JFA 做羽化、.../gpu），绑定位于 rust/wasm/，由 TypeScript 通过 src/lib/wasm/ 调用。这是本版本影响最大的变更：播放性能据称大幅提升，交互中音频不再卡顿，但任何基于旧 WebGL 层的自定义着色器或扩展都无法移植。编辑器内新增提示，用于说明 GPU 加速渲染何时不可用。
  • 时间改为整数 tick，不再是浮点秒 — MediaTime 以每秒 120,000 tick 的计数取代浮点秒（rust/crates/time），FrameRate 改为有理数 {numerator, denominator}。120,000 基数可被标准帧率分母整除（含丢帧率：23.976 → 5,005 tick/帧、29.97 → 4,004、30 → 4,000），消除了累积舍入误差，帧对齐和时间码更精准。所有时间运算、帧吸附与时间码格式化都移入 Rust 并由 WASM 暴露——任何用浮点秒做数学的代码都要重新设计。
  • 存储迁移 v9–v25 — 十六个新迁移步骤覆盖了这一周期累积的 schema 变更，旧项目加载时必须逐段走完；自托管或分发保存的项目文件时，要为迁移测试留出时间。同时 OpenCut 现在会向浏览器申请持久化存储，避免磁盘空间不足时项目静默消失——这是实打实的数据丢失修复，不只是 UX 调整。
  • 轨道模型改为类型安全，ripple 编辑重写 — SceneTracks 用显式的 overlay、单例 main VideoTrack 和 audio 字段取代扁平轨道数组，从结构上杜绝轨道类型混用或放错。Ripple 编辑改为 src/lib/ripple/ 下的 diff 引擎：把前后轨道快照当区间集比较，计算空出的区间（含被移到其他轨道的元素），再单独应用显式 RippleAdjustment。更可组合、更易测试，但对任何直接读写扁平轨道数组的代码都是破坏性变更。
  • 导入路径重排；新增部署目标 — src/types/ 和 src/constants/ 被拆散，类型与常量移到所属代码旁的 src/lib/；内部包 packages/env、packages/ui 并入 web 应用（图标 → src/components/icons/，env → src/lib/env/）。这属于机械改动但影响面很广，升级后预期会有大量 import 报错要修。好的一面是 web 应用现在可通过 OpenNext 部署到 Cloudflare Workers（wrangler.jsonc、apps/web/open-next.config.ts），新的 apps/desktop/ GPUI + Rust 应用已能构建，但还没有功能。
  • 面向创作者的功能与行为变化 — 蒙版（分割/矩形/椭圆/星形/心形/菱形/电影宽银幕条，支持羽化和描边）、用于关键帧缓动的贝塞尔曲线编辑器、逐轴缩放、音量与速度（含保持音高选项）、自定义画布尺寸、预览缩放/平移、字幕文件导入、独立 X/Y 动画、关键帧复制粘贴，以及可展开的逐属性关键帧轨道。还要留意更隐蔽的行为变化：Shift/Ctrl 拖选现在会追加到选区，时间线默认滚动到底部，RMS 波形只渲染可见区域，带音频的 MP4 导出终于在 Firefox 上成功。

此版本添加了蒙版、关键帧曲线的图形编辑器、音量和速度控制、预览缩放、画布背景、贴纸等等。

特点

  • 添加了包含可下载品牌资产的品牌页面。还可以直接从标题徽标上下文菜单访问资源。
  • 比例现在具有单独的宽度和高度控件。您可以在每个轴上独立拉伸或挤压元素。
  • 音频和视频元素的音量控制，无论是在属性面板中还是在时间轴 clips 上内嵌。
  • 视频和音频 clips 的速度控制。包括保持音调选项，因此当您更改速率时，音频不会变得花哨或加深。
  • 面具。隐藏或显示任何视频或图像层的部分内容。从分割条形、矩形条形、椭圆形条形、星形条形、心形条形、菱形条形和电影条形中进行选择。在属性面板中调整位置、大小、旋转、羽化和描边，或在预览中拖动手柄。
  • 画布背景又回来了。从设置面板中的新背景选项卡将模糊、纯色或渐变设置为画布背景。
  • 自定义画布尺寸。您现在可以输入所需的任何宽度和高度，而不必局限于少数预设。
  • 预览缩放和平移。放大画布以处理精细细节，并在放大时平移以进行导航。
  • 贴纸面板现在有内容。浏览并添加徽标、国旗和形状。
  • 您现在可以导入转录文件来生成字幕，而不是运行自动转录。
  • 关键帧曲线的图形编辑器。通过拖动贝塞尔手柄来调整关键帧之间的缓动。
  • 多个选定的时间线 clips 一起移动并调整大小。
  • 位置 X 和 Y 现在可以独立设置动画。
  • 可以在元素之间复制和粘贴关键帧。
  • 时间轴 clips 可以展开以显示每个动画属性的通道。右键 click a clip ->“展开关键帧”以查看其自己行中的所有属性。

改进

  • 在页脚添加了 changelog 链接。
  • 播放性能显着提高。编辑器过去在播放过程中速度缓慢，并且在播放过程中与元素交互时音频会断断续续。两者都是固定的。
  • 时间轴轨道之间有更多的垂直空间。相邻轨道上的选择轮廓不再相互重叠。
  • 在时间轴中拖动选择时按住 Shift 或 Ctrl 现在会添加到现有选择，而不是替换它。与 Shift/Ctrl+click 已经工作的方式匹配。
  • 时间轴轨道行现在在包含选定元素时突出显示，从而更容易一目了然地查看哪些轨道处于活动状态。
  • 系统字体（Arial、Helvetica、Times New Roman 等）现在与 Google 字体一起出现在字体选择器中。
  • 如果您的磁盘空间不足，您的项目可能会消失。 OpenCut 现在要求浏览器保护它们。
  • 属性面板经过重新设计，采用选项卡式布局。
  • 音频波形得到了升级。旧的不准确，容易崩溃，而且不太有用。新的基于 RMS，适当缩放，并且只渲染可见的内容，因此不会减慢速度。
  • 时间线现在打开时滚动到底部，因此您的主视频轨道立即可见，而不是隐藏在折叠上方。
  • 设置面板经过重新设计，布局更清晰，组织更好。
  • 您现在可以在资产面板中选择多个资产。对于一次删除多个很有用。
  • 如果您的浏览器不支持 GPU 加速渲染，编辑器现在会显示一条通知，解释原因并建议切换到其他浏览器。

修复

  • 赞助商徽标现在可以在深色模式下正确反转。
  • 网格视图中的媒体资产卡比缩略图大，在每个项目周围留下空白空间。卡片的大小现在适合其内容。
  • 即使时间线为空，项目缩略图现在也可以正确生成。如果您设置没有 clips 的背景颜色或渐变，缩略图会反映该背景颜色或渐变，而不是保持空白。
  • Clicking 选定的元素不再保留其余的选择。
  • 时间线左侧的曲目标签与右侧的曲目未对齐。
  • Cli现在在时间轴轨道下方的空白区域中寻找播放头。
  • 时间轴垂直滚动现在可以在面板中的任何位置工作，而不仅仅是在轨道标签上。标题不再随轨道滚动。
  • 在 Firefox 上导出带音频的 MP4 失败。现在，无论浏览器如何，导出都会成功完成。
  • 将全画布元素移动到框架中心时，预览面板中的捕捉参考线不会显示。
  • 当元素位于画布顶部附近时，旋转手柄可能会漂浮在编辑器 UI 上方。它现在 clips 到预览区域。
  • 当模糊背景也处于活动状态时，具有 0% 强度模糊效果的图像将完全消失。现在，0% 模糊可以正确渲染图像不变。
  • 当该部分不可折叠时，属性面板中的部分标题显示错误的文本颜色。不可折叠的标题现在使用正确的静音样式。
  • 模糊在较高强度下看起来像素化，而不是产生真正的模糊。画布背景模糊和模糊效果现已修复。
  • 自动生成的字幕有时不准确。根本问题已得到解决。
  • 文本元素句柄不再在您键入时移动位置。
  • 随着画布尺寸变小，旋转手柄距离元素越来越远。在 100x100 的项目中，它几乎超出了屏幕范围。现在，无论画布尺寸或缩放如何，间隙都是固定大小。 <详情>
技术细节 - 波纹编辑现在有了适当的算法基础。旧的内联方法被 `src/lib/ripple/` 中基于 diff 的系统取代：将操作之前和之后的轨道快照作为间隔集进行比较，计算空出的间隔（考虑移动到其他轨道的元素），结果是在单独的传递中应用的显式 `RippleAdjustment` 值的列表。可组合、可测试且独立于触发它的命令。 - 时间现在表示为 `MediaTime`，即每秒 120,000 个刻度的整数刻度计数，在 `rust/crates/time` 中定义。以前，始终使用浮点秒，这会累积舍入误差并使帧对齐不精确。选择 120,000 是因为它可以除以每个标准帧速率分母，包括丢帧速率：23.976 映射到 5,005 个刻度/帧，29.97 映射到 4,004、30 到 4,000。 `FrameRate` 是有理 `{numerator, denominator}` 类型而不是浮点数。所有时间算术、帧捕捉和时间码格式化均在 Rust 中实现，并通过 WASM 公开。 - 现在在类型级别强制执行轨道排序。 `SceneTracks` 用三个显式字段替换平面磁道阵列：`overlay`、`main`（单例 `VideoTrack`）和 `audio`。该类型在结构上使得混合轨道类型或放错轨道是不可能的。 - WebGL 渲染器已替换为编译为 WASM 的 Rust/wgpu 合成器。 `rust/` 箱树涵盖合成 (`rust/crates/compositor`)、效果 (`rust/crates/effects`)、基于 JFA 羽化的蒙版 (`rust/crates/masks`)、GPU 上下文 (`rust/crates/gpu`) 和时间 (`rust/crates/time`)。 WASM 绑定存在于 `rust/wasm/` 中，并从 TypeScript 到 `src/lib/wasm/` 被消耗。旧的 GLSL 着色器和 WebGL 实用程序已经消失。 - `src/types/` 和 `src/constants/` 已解散。现在，所有类型和常量都与 `src/lib/` 中拥有它们的代码一起存在。 `packages/env` 和 `packages/ui` 内部包也折叠到 Web 应用程序中，图标位于 `src/components/icons/`，环境位于 `src/lib/env/`。 - Web 应用程序现在可以通过 OpenNext 部署到 Cloudflare Workers。 `wrangler.jsonc` 和 `apps/web/open-next.config.ts` 可供任何人自行托管。 - `apps/desktop/` 是一个新的 GPUI + Rust 应用程序。现在还很早：有一个 `main.rs` 和一个工作构建设置，但还没有任何功能。 - 添加了 16 个新的存储迁移步骤（v9 到 v25），涵盖了在此发布周期中积累的架构更改。
