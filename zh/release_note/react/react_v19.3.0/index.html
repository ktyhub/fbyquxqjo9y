react v19.3.0

以下是所有新功能、API 和错误修复的列表。 阅读 React 19.3 发布帖子 了解更多信息。

新的 React 功能

  • <ViewTransition />：添加 <ViewTransition /> 和 addTransitionType API 来增强 React 中的视图转换动画（@sebmarkbage、@jackpope、@gaearon：#31975、#31987、#31996、 #31999、#32001、#32002、#32028、#32029、#32031、 #32034、#32038、#32041、#32050、#32090、#32105、 #32254、#32379、#32422、#32462、#32540、#32545、 #32585、#32599、#32611、#32612、#32617、#32651、 #32653、#32656、#32664、#32699、#32723、#32734、 #32751、#32752、#32760、#32761、#32764、#32772、 #32790、#32819、#32820、#32822、#32833、#32849、 #33094、#33191、#33200、#33206、#33293、#33330、 #33331、#33332、#33357、#33362、#33433、#33576、 #34374、#34450、#34481、#34500、#34502、#34510、 #34511、#34539、#35567、#35564、#35485、#35380、 #35063、#35060、#34676、#36917、#35337、#35520)
  • 片段引用：将引用添加到 <Fragment /> 以支持可组合平台行为（@jackpope、@sebmarkbage、@eps1lon、@Dhakshin2007、@chirokas、@teamleaderleo、@fallintoplace：#32465、#32613、 #32619、#32654、#32660、#32682、#32722、#32813、 #32814、#33056、#33058、#33093、#34069、#34103、 #34544、#34545、#37062、#37061、#37060、#36047、 #36010、#35642、#35641、#35637、#35630、#34935、 #37457、#37408、#37326、#37251、#37171、#37169、 #37168、#37167、#37166、#37165、#37164、#37163、 #37162、#37161、#37160、#37125、#37063)

新的 React DOM 功能

  • browser()：一个新的 react-dom API，它返回一个可用的错误，在服务器渲染期间出现错误并在浏览器中解决。 <Suspense> 边界内的 use(browser()) 将子树标记为仅限浏览器，而不报告可恢复错误（@gnoff：[#37143]（https://github.com/facebook/react/pull/37143），[#37241]（https://github.com/facebook/react/pull/37241））
    • 在 react-dom/server API 中添加了 onBrowserBailout 选项，以观察子树何时遵循浏览器 (@gnoff #37193)

显着变化

  • 启用 Trusted 类型 API 集成 (@rickhanlonii #35816)
  • 过渡现在独立渲染，而不是纠缠在单个渲染中，因此缓慢的过渡不再阻碍不相关的过渡（@acdlite #37290）
  • 当组件似乎已通过有条件调用 use() 解锁时添加了仅 DEV 警告（@hoxyq、@eps1lon：#37104、#37203、#37491）
