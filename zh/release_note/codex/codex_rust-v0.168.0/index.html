codex rust-v0.168.0

发布 发布时间2026年11月13日 来源openai/codex 英文原文

新功能

  • 在“会话”→“模型提供者”下浏览模型提供者，并为新聊天选择默认值。 （＃59541，＃59722）
  • 启用 features.tui_workspace 可以查看主聊天旁边的副对话。拖动分隔线以调整窗格大小，或按 leader z 缩放聚焦窗格。 （#58992、#59527、#59595）
  • 使用支持音频的型号时附加录音。 Codex 在稍后的回合中跳过已确认的拒绝录音，并使用 clip 持续时间在上下文中保留更短的录音。 （＃59234，＃59268）
  • 使 features.image_generation_animation 能够生成或编辑带有可选帧计数和定时控制的动画 GIF。 (#59073)
  • 全屏 Codex 在使用 allow-passthrough all 的 Ghostty 和 Kitty 上的 tmux 中显示图像预览和宠物。 （＃59579，＃59580）
  • 为终端通知设置 tui.notification_method = "osc777"。批准通知显示更长的命令预览，并将终端输入与网络访问请求区分开来。 (#59256)

错误修复

  • 本地 TUI 历史记录和简历选择器通过登录的 ChatGPT 帐户过滤新创建的线程。 (#58918)
  • 在更改新聊天的默认设置后，打开和恢复的聊天将使用其保存的模型提供程序。 (#59503)
  • TUI 将工具调用中断的回复呈现为单个 Markdown 消息，并在重播对话时恢复推理摘要。 （＃59698，＃59700）
  • 在最终记录保存期间或切换回长时间运行的聊天后发送时，转向消息会达到运行轮次。 （＃58877，＃58998）
  • 模糊文件搜索赋予文件名匹配更大的权重，因此匹配的父目录不太可能将它们排除在外。 (#59709)
  • Windows 上空闲的本地 MCP 服务器将文件系统 I/O 留给 Codex 的其余部分。 (#59726)

文档

  • 应用程序服务器参考涵盖列出模型提供程序、创建自定义网关以及更新网关、Bedrock 和 GCP 设置。 （＃58845，＃58876）

家务事

  • 当显式配置 features.multi_agent 时，Codex 会发出警告，并指向 agents.enabled 以禁用子代理工具。 (#59479)
  • 贡献者可以在本地运行 Bazel CI 作业，无需 BuildBuddy 凭据。 (#59055)
