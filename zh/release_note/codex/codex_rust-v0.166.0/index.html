codex rust-v0.166.0

发布 发布时间2026年10月29日 来源openai/codex 英文原文

变更流程图

亮点

  • TUI 效率 — 键盘驱动的记录选择现在支持词、行、页移动，带可配置快捷键和集成搜索。异步提示词/回复中的 Markdown 渲染、更清晰的安全拦截补救途径、codex queue --resume 和 codex doctor --network-only 让排队工作恢复和网络排障不再那么痛苦（#57221、#57222、#57223、#57224、#57259、#57292、#57363、#57365、#57232、#57606）。

  • 恢复/fork 正确性 — 已确认的审批和权限现在能在恢复/fork 后保留，同时保留 reasoning-token 核算以防止过早压缩。解除归档父线程时会恢复子线程，本地图片附件在 composer 被杀后恢复时保留——对长生命周期会话是重要修复（#57227、#57839、#57635、#57502）。

  • App-server 与独立版可靠性 — 线程启动/关闭竞态得到修复，完成的 runtime 被及时释放；TUI 重连和离线 /quit//exit 处理也改进（#57787、#57788、#57820）。独立执行器现在随标准 CLI 和 app-server 包一起发布，macOS 清理处理使用中的安装和非 ASCII 路径（#57837、#57503）。

  • 构建/工具链迁移 — 开发和发布构建统一到 Node.js 24.22.1 和 Rust 1.95.0。Bazel 改为源码构建的 V8，带目标匹配的 Rust 绑定和原生 Windows MSVC 归档支持（#57168、#57373、#57164、#57269、#57644、#57832）。没有指定最终用户迁移，但贡献者和自定义构建流水线应采用这些工具链和构建预期。

  • 升级建议 — 对重度 TUI 用户、长时间运行的恢复/fork 或 app-server 工作流，以及需要在捆绑目录、Vertex AI 或 Amazon Bedrock 目录中使用 GPT-6.1 Terra 的人值得升级（#57293）。不受这些工作流影响的用户可以跳过；这是一次有实质内容的发布，不是重打标签或纯元数据更新，也没有列出明确的最终用户破坏性变更。

新功能

  • 添加了键盘驱动的转录选择，包括单词、行和页面动作、集成搜索和可配置的快捷方式。 （#57221、#57222、#57223、#57224）
  • 在异步问题、选择、答案和文字回复中一致地呈现 Markdown。 （＃57259，＃57292）
  • 将 GPT-6.1 Terra 添加到捆绑、Vertex AI 和 Amazon Bedrock 模型目录中。 (#57293)
  • 添加了 codex queue --resume 以在对消息进行排队后恢复卸载的线程。 (#57232)
  • 在 TUI 中添加了更清晰的安全块说明和可选的更安全的后续提示。 （＃57363，＃57365）
  • 添加了 codex doctor --network-only，用于集中配置、连接和 WebSocket 诊断。 (#57606)

错误修复

  • 恢复或分叉线程时保留确认的批准和权限设置。 (#57227)
  • 恢复被杀死的作曲家文本时保留本地图像附件。 (#57502)
  • 修复了当安装正在使用或路径包含非 ASCII 字符时 macOS 上的独立版本清理。 (#57503)
  • 在取消归档其父线程时恢复了生成的后代线程。 (#57635)
  • 修复了应用程序服务器线程启动和关闭竞争并立即发布已完成的运行时。 （＃57787，＃57788）
  • 改进了 TUI 重新连接恢复，包括离线 /quit 和 /exit 处理。 (#57820)
  • 跨简历和分叉保留推理令牌会计以避免过早压缩。 (#57839)

家务事

  • 将 Bazel 切换为源构建的 V8，具有目标匹配的 Rust 绑定和本机 Windows MSVC 存档支持。 （#57164、#57269、#57644、#57832）
  • 在规范的 CLI 和应用程序服务器发行包中提供独立执行器。 (#57837)
  • 基于Node.js 24.22.1和Rust 1.95.0的标准化开发和发布。 （＃57168，＃57373）
