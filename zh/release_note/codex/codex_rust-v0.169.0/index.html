codex rust-v0.169.0

发布 发布时间2026年11月13日 来源openai/codex 英文原文

变更架构图

亮点

  • 非交互运行现在要求显式项目信任（破坏性） — codex exec 不再在不受信任目录中加载项目配置或 MCP server，即使带 --sandbox workspace-write（#60041）。如果你的 CI 或脚本化 codex exec/codex review 依赖项目配置或 MCP 工具，请添加 --trust（并保存信任），否则这些工具会静默停止工作；这是唯一需要走迁移流程的一项。

  • 自定义 provider 与 gateway 在终端中成为一等公民 — 你可以在 TUI 中添加/编辑自定义模型 provider，并在启用自定义 gateway 引导时于登录过程中创建（#59779、#60009、#60186、#60486、#60662），对支持的 gateway 通过 SSH 或没有本地浏览器时使用 device-code 授权（#59822）。App-server 客户端也可以为已配置的 provider 列出模型或授权 gateway，而无需更改默认 provider（#59776、#59819）。如果你自托管或通过 gateway 路由，这省去了手动改配置，并解锁了无头环境。

  • 可选的 Cloud 连接与更丰富的终端工作区 — 在 macOS/Linux 上，一个有开关的 Cloud 后端让你可以从终端发送图片、选择模型和推理强度，以及归档/恢复 Cloud 聊天（#59828、#60061、#60635、#60651）。可选的工作区新增多个侧边聊天标签，支持键鼠切换并在重启后保留（#59784、#60152、#60181），按名称/提示词/工作目录搜索任务历史（#60286），全屏记录可用的”折叠回合详情”（#60554、#60555、#60556、#60557），以及 Ctrl+S 在本地保存诊断 ZIP（即使上传被禁用）（#60542）。这些都是可选的生活质量改进，不是默认行为变化。

  • 值得拥有的可靠性与平台修复 — 终端不再因为共享 app server 从未上报的 MCP server 而一直忙等（#60280、#60622）；被中断的回合会干净关闭，延迟的中止或文件审批取消不再渗漏到后续回合（#59910、#60700）；Windows 沙箱处理带引号的 cmd.exe 路径以及父目录不可读时的 PowerShell cwd（#60624、#60647）；macOS 粘贴的图片保持方向并使用原生 PNG/JPEG 剪贴板数据（#60455）。内置 SQLite 升级到 3.54 以修复 WAL 问题（#60432），插件市场升级复用磁盘上的 Git 对象（#60528）。

  • 谁该升级 — 使用自定义 gateway/provider、可选的 Cloud 或工作区功能，或撞上 MCP 挂起/中断回合 bug 的用户应升级；CI/脚本用户应升级，但必须先在 codex exec/codex review 调用中加入 --trust（#60041）。如果你用默认设置、不用这些可选功能且不受修复影响，可以跳过——除信任变更外，这里没有强制的格式或平台迁移。

新功能

  • 选择加入的终端工作区支持多个侧边聊天选项卡。使用键盘或鼠标在它们之间切换，并在重新启动 Codex 后重新打开保存的本地聊天。 （#59784、#60152、#60181）
  • 按名称、提示预览或工作目录从代理命令中心搜索旧任务。 (#60286)
  • 在全屏记录中打开折叠回合详细信息，将已完成的活动折叠在每个提示下方，同时保持答案可见且工具输出可搜索。 （#60554、#60555、#60556、#60557）
  • 从终端添加或编辑自定义模型提供程序。启用自定义网关加入后，您可以在登录期间创建提供程序，并通过 SSH 或无需本地浏览器使用支持网关的设备代码。 （#59779、#60009、#60186、#60486、#60662）
  • 在终端报告编辑器中按 Ctrl+S 可在本地保存诊断 ZIP，即使上传被禁用也是如此。 (#60542)
  • 通过 macOS 和 Linux 上的选择加入云连接，发送图像、选择模型和推理工作，以及从终端存档或恢复云对话。 （#59828、#60061、#60635、#60651）

错误修复

  • codex exec 在 untrusted 目录中保持项目配置和 MCP 服务器禁用，即使使用 --sandbox workspace-write 也是如此。使用 --trust 与 codex exec 或 codex review 显式保存项目 trust。 (#60041)
  • 是的，明确背景并实施现在将完整批准的计划移交给新会议，并在移交失败时保持当前会议开放。 (#60763)
  • 修复了对引用的 cmd.exe 路径和工作目录具有不可读父目录的 PowerShell 会话的 Windows 沙箱处理。 （#60624，#60647）
  • macOS 上粘贴的图像保留其预期方向，并使用本机 PNG 或 JPEG clipboard 数据（如果可用）。 (#60455)
  • 终端不再忙于等待共享应用程序服务器未报告的 MCP 服务器。 （#60280，#60622）
  • 中断的回合现在可以干净地关闭，并且延迟中止或文件批准取消不再中断稍后的回合。 （＃59910，＃60700）

文档

  • 更新了 openai-docs 技能，重点关注 Codex 和 ChatGPT Work 问题以及首次 API 设置，并提供跨团队配置 Codex 的专门指导。 （＃59944，＃59949）
  • 记录了应用程序服务器 clients 如何在不更改默认提供程序的情况下列出模型或为已配置的提供程序授权网关。 （＃59776，＃59819）

家务事

  • 插件市场升级可以重用磁盘上已有的 Git 对象，从而减少重复下载。 (#60528)
