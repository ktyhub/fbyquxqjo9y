codex rust-v0.170.0

这个项目是干啥的：OpenAI 官方的命令行 AI 编程助手，在终端里让 AI 帮你写代码、改代码、跑测试。给喜欢在命令行里干活的开发者用。

变更架构图

亮点

  • TUI 中的实时语音 — 实时语音通话现在支持 WebRTC 协商（#61172），为终端用户增加一种交互模式。实验性 MCP 配置现在可以在不同环境中使用同名 server 而不混淆它们（#60905）。
  • 可靠性与认证修复 — 过大的 WebSocket 请求现在立即回退到 HTTP，同时遵守通告的消息大小限制（#60840、#60841）。MCP OAuth 凭据持久化和刷新取消是竞态安全的（#60849、#60981），OpenTelemetry HTTP exporter 可以自动刷新认证头（#61028），有利于凭据轮换的用户。
  • 沙箱与 Windows 加固 — 权限更新和子线程现在保留现有的沙箱限制（#60936、#61134），降低无意扩大访问的风险。Windows 修复覆盖文件替换、权限保留和 runtime 注册恢复（#60872、#60943、#60944）。迁移提示： 旧的沙箱策略 setter 从 Config 中移除（#61144）；使用它的自定义集成必须迁移到 permission profile。
  • 会话恢复与搜索正确性 — Cloud 对话重连更可靠，并在重连间保留活跃的恢复回合（#60969、#61014）。文件搜索不再从重叠的根目录返回重复项，包含空白的线程搜索产生正确的片段（#60845、#60846）。
  • 升级建议 — 这是一次有实质内容的发布，不是重打标签。Windows 用户、MCP OAuth 用户以及任何依赖沙箱限制的人应升级；使用凭据会过期的 OTLP HTTP exporter 的用户有额外理由。不受这些领域影响的用户可以跳过，除非想要实验性的跨环境 MCP 支持或 TUI 语音通话。

新功能

  • 在 TUI 中添加了用于实时语音通话的 WebRTC 协商。 (#61172)
  • 为 OpenTelemetry HTTP 导出器添加了自动刷新的身份验证标头。 (#61028)
  • 添加了对跨环境使用相同名称的 MCP 服务器的实验性支持。 (#60905)

错误修复

  • 超大的 WebSocket 请求现在回退到 HTTP，无需进行不必要的重试。 （#60840，#60841）
  • 修复了取消、登录和注销期间的 MCP OAuth 凭证竞争问题。 （＃60849，＃60981）
  • 改进了云对话的自动重新连接，并在 clients 重新连接时保留主动恢复轮次。 （#60969，#61014）
  • 修复了 Windows 文件替换、沙箱权限保存和运行时注册恢复。 （#60872、#60943、#60944）
  • 修复了权限更新和子线程丢失现有沙箱限制的问题。 （#60936，#61134）
  • 删除了重复的文件搜索结果并修复了包含空格的查询的线程搜索片段。 （#60845，#60846）

文档

  • 更新了沙箱文档以解释权限配置文件和文件系统规则。 (#61133)
