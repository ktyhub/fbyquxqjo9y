codex rust-v0.165.0

发布 发布时间2026年10月27日 来源openai/codex 英文原文

变更架构图

亮点

  • Vertex AI 与模型支持 — 新增内置的 Google Cloud Vertex AI provider，通过 model_provider = "gcp" 配置，并在模型目录中加入 GPT-6.1 Terra。想要托管的 Vertex AI 支持或使用新模型的用户应升级。
  • 新的对话默认值 — 对支持的模型，reasoning-effort 的更改现在默认可在对话中途进行。Memory v2 现在仅对全新 profile 成为默认，并支持导入外部 agent 的 memory；文档没有说明现有 profile 需要迁移。
  • TUI 与 API 易用性 — 新增仓库过滤、跨关联 worktree 的目录分组，以及 app-server API 中实验性的附加线程 fork（#56351）。对多 worktree 用户和 app-server 集成者尤其有用，不过 fork 应视为实验性功能。
  • 可靠性修复 — 全新的 TUI 会话现在遵循服务端的默认审批 reviewer，偏好设置在执行设置无效时仍可用，丢失的 MCP 请求会被取消，排队的 agent 消息不会在中断或 Plan 模式切换后重新开始工作。模型未找到错误现在直接终止而不是重试。重度使用 agent 和 TUI 的用户应升级。
  • 安全与升级结论 — 修复了 marketplace URL 校验漏洞，该漏洞可能把 Git 重定向到与允许模式检查不同的主机（#56263）；从 marketplace 安装内容的用户应优先升级。没有列出明确的破坏性变更或强制迁移步骤。不受新 provider、默认值和 API 影响的用户可以推迟，但安全修复使升级普遍值得。

新功能

  • 添加了内置 Google Cloud Vertex AI 提供程序，配置为 model_provider = "gcp"。 (#56265)
  • 将 GPT-6.1 Terra 添加到模型目录中。 (#57337)
  • 向会话选择器添加了存储库过滤器，并向代理命令中心添加了目录分组，从而可以更轻松地跨链接工作树导航会话。 (#56308)
  • 向应用程序服务器 API 添加了实验性附加线程分叉。 (#56351)
  • 默认情况下，支持模型在对话期间启用推理工作变化。 (#56163)
  • 默认情况下为新配置文件启用内存 v2，并添加了对将外部代理内存导入其中的支持。 （＃56211，＃56414）

错误修复

  • 修复了新的 TUI 会话，以在未提供显式覆盖时尊重服务器的默认审批审阅者。 (#56090)
  • 保持 TUI 首选项可编辑，并在执行设置无效时立即应用。 (#56091)
  • 当本地响应未来被丢弃时，取消了远程 MCP 工具请求。 (#56132)
  • 防止排队的代理消息在中断或切换到计划模式后重新启动工作。 (#56330)
  • 当提供程序报告未找到模型时停止重试，保留其错误消息。 (#56445)
  • 弥补了市场 URL 验证漏洞，该漏洞可能允许 Git 连接到与根据允许模式检查的主机不同的主机。 (#56263)
