codex rust-v0.162.0

发布 发布时间2026年10月8日 来源openai/codex 英文原文

变更流程图

亮点

  • TUI 工作流生活质量 — 面向用户改动最多的一批：当 worktrees 功能启用时，可从受信任的本地项目创建/列出受管 Git worktree 的工具（#50148），Command Center 用 p 固定任务以及共享的 Pinned 分组（#51500），通过 /copy、Ctrl+Insert 进行记录块复制/导航，以及新的 tui.mouse_scroll_speed 设置（#50434、#50215、#50209），还有审批头、问题、MCP 提示词、警告、横幅和验证提示中的可点击 URL——包括跨行换行的链接（#51439–#51458）。如果你常待在 TUI 里，仅此一项就值得升级。

  • 沙箱与跨平台加固 — Linux 沙箱启动现在容忍多个被拒绝的文件，拒绝来自 PATH 的可写沙箱构建可执行文件，并阻止 ripgrep 配置削弱 deny-glob 掩码（#50059、#51211、#51407、#51527）；恢复 Windows 10 盘符访问，并让沙箱临时权限与子进程环境一致（#51511、#51512）；apply_patch 无条件保留 CRLF 行尾，无需 opt-in（#51203）；可重试的 Responses/WebSocket 失败遵循服务端的 Retry-After（#50418、#51440）。拒绝可写可执行文件是有意的安全收紧——如果你依赖 PATH 上的自定义 bubblewrap 二进制，请注意。

  • 面向高级用户的可选扩展 — 自定义 Responses 兼容 provider 现在可以通过 capability overrides 声明实时 web 访问和远程压缩（#50459），Code Mode 新增 JavaScript promise-settlement 流式辅助函数（#51126）以及可选的排序式工具发现（#51209）。如果你运行自定义 provider 或依赖 Code Mode 自动化，这些解锁实际能力，但属于小众且非破坏性；其他人可以忽略。

  • Windows 分发修复 — Windows 发布现在附带签名的 PowerShell 安装程序（#51158），当存在 PowerShell 7 模块路径时归档校验和验证得到修复（#51257），并且较旧的稳定版/预发布版不再把较新的稳定下载目标或安装程序别名往回拉（#51186、#51425）。主要与 Windows 用户和部署安装程序的 IT 相关；发布指针的保护是这里低调但重要的修复。

  • 升级结论 — 没有指出破坏性变更或必需的迁移步骤，而且这显然不是空操作/重打标签——有大量的面向用户的改动。如果你是重度 TUI 用户、使用自定义 provider 或 Code Mode，或曾被 Linux/Windows 沙箱或安装程序问题坑过，应升级。如果你只在稳定平台上跑基本的 agent 回合且以上都不适用，这是一次安全但可选的增量更新，可以跳过。

新功能

  • 添加工具，用于在启用工作树功能时从 trusted 本地项目创建和列出托管 Git 工作树。 (#50148)
  • 使用 p 将任务固定在代理命令中心中，并在服务器支持时将它们保留在共享固定组中。 (#51500)
  • 使用 /copy 导航和复制转录块，使用 Ctrl+Insert 复制选择，并使用 tui.mouse_scroll_speed 调整鼠标滚轮滚动。 （#50434、#50215、#50209）
  • 使 URL clickable 在批准标题、问题、MCP 提示、警告、横幅和验证提示中，包括当链接换行时。 （#51439、#51449、#51450、#51451、#51452、#51458）
  • 为自定义响应兼容模型提供程序配置实时 Web 访问和远程压缩功能。 (#50459)
  • 添加 JavaScript 帮助程序，以便在结算时流式传输承诺结果，以及在代码模式下选择加入排名工具搜索。 （＃51126，＃51209）

错误修复

  • 尊重新 TUI 线程的服务器模型和推理摘要默认值，同时保留显式启动覆盖。 （#50013、#50811、#50913）
  • 在 apply_patch 更新中保留现有的 CRLF 行结尾，无需选择加入。 (#51203)
  • 修复具有多个拒绝文件的 Linux 沙箱启动，拒绝可写的沙箱构建可执行文件，并防止 ripgrep 配置削弱拒绝全局掩码。 （#50059、#51211、#51407、#51527）
  • 恢复 Windows 10 上的普通驱动器号文件访问，并将 Windows 沙箱临时权限与子进程环境相匹配。 （＃51511，＃51512）
  • 尊重服务器 Retry-After 对可重试响应和 WebSocket 失败的建议。 （＃50418，＃51440）
  • 修复了在存在 PowerShell 7 模块路径的情况下通过 Windows PowerShell 安装时的存档校验和验证。 (#51257)

家务事

  • 随 Windows 版本发布签名的 PowerShell 安装程序。 (#51158)
  • 防止较旧的稳定版本和预发行版本替换较新的稳定下载目标或安装程序别名。 （＃51186，＃51425）
