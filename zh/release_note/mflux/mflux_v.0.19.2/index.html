mflux v.0.19.2

发布 发布时间2026年9月17日 来源mflux-community/mflux 英文原文

mflux v.0.19.2

这个项目是干啥的：一个在Mac本地跑的AI绘画和修图工具，支持Qwen-Image和FIBO图像编辑，给想在电脑上手动画图的创作者用。

变更架构图

亮点

  • 检查点解析 — 自定义检查点重新能推断出正确的模型家族，--steps 现在跟随解析出的模型，而不是一律默认 25。对 Z-Image 和已缓存的预量化 FLUX.2 检查点，--base-model 也始终生效。如果你使用本地或第三方检查点，建议升级；这些修复可避免选错模型和参数。（#688、#697、#699、#702）
  • 运行复现与模型保存 — --config-from-metadata 重新支持复现那些未带 --base-model 创建的旧运行，并且会复用 sidecar 中记录的检查点路径，而不是悄悄替换成内置权重。所有 FLUX.1 生成变体都开放了 save_model，mflux-save 的 dev-redux 检查点现在也能正确加载回来。如果你需要复现运行或保存模型，这些修复尤其值得。（#680、#696、#708）
  • 更低显存的训练 — 选择性启用的 "gradient_checkpointing": true 开关现已支持 FLUX.2、Z-Image 和 Ernie 的 LoRA 训练。开启后反向传播会从最后一个 block 开始（Krea 2 也一样），从而真正省下内存；据反馈 FLUX.2 klein-base-4B 的编辑训练可在 32–36 GB 的 Mac 上跑通。训练默认行为保持不变。（#711）
  • 运行时与工具链修复 — SeedVR2 在 mlx 0.32.2 上不再于第一次放大前崩溃。CUDA 环境把 mlx 固定到 0.32.2，以规避 0.32.1 的 matmul 回归，macOS 仍保持 0.32.0。Shell 补全现在会提示规范的 --base-model 取值，just install 也会在改动前拒绝非 git 目录。（#690、#692、#706、#683）
  • 升级建议 — 对使用自定义检查点、做训练，或碰到保存/SeedVR2 bug 的用户来说，这个补丁版本值得升级。官方未声明破坏性变更或必需的迁移步骤；不受这些问题影响的用户可以合理跳过。

0.19.2

已修复

  • 使用 —config-from-metadata 重放运行对于没有 —base-model 的运行再次有效；早期版本编写的 sidecar 也会重播。 （#696）
  • mflux-generate-flux2 和 mflux-generate-z-image 再次从自定义检查点的名称中选择家庭兄弟（mlx-community/flux2-klein-9b-8bit 作为 klein-9b 运行，不带 —base-model）；不匹配任何内容的名称将保留命令的默认模型。 （#697）
  • 第三方或本地检查点的 —steps 默认值现在遵循其解析到的模型（通过 —base-model 或其名称中的别名），而不是始终为 25。 (#699)
  • mflux-generate-z-image 现在支持自定义检查点的 —base-model ； family inference 仅读取检查点自己的名称，因此父目录无法再重塑它； Flux2 指导错误名称 —base-model 作为修复。 （#702）
  • SeedVR2 升级在 mlx 0.32.2 上执行第一步之前不再崩溃：注意力的 mx.repeat 调用再次采用纯整数计数。 （#690）
  • 对于 Hugging Face 缓存中已有的检查点，mflux-generate-flux2 --model <pre-quantized repo> 再次尊重 --base-model。 （#688）
  • 每个 FLUX.1 生成变体（Depth、Fill、Kontext、In-Context Fill 和 Dev、Redux）都有 save_model，dev-redux 的 mflux-save 写入加载回来的检查点。 （#680）

内部

  • CHANGELOG.md 已退役；每个版本的 release note 都包含在 GitHub 版本中。 (#700)
  • CI：release 和 ci-extract 工作流程不再将动态值扩展到 shell 源代码中；分支守卫和调度确认从环境中读取它们。 （#679）
  • just install 在执行任何操作之前检查当前目录是否为 git 存储库。 （#683）
  • 在 CUDA 上，mlx 固定为 0.32.2（0.32.1 具有 matmul 回归；macOS 保留在 0.32.0）。 （#692）

添加

  • 训练：FLUX.2、Z-Image 和 Ernie LoRA 训练的新选择加入 "gradient_checkpointing": true 配置标志，并且现在只要检查点处于活动状态（包括 Krea 2），就会对后向传递进行最后块优先评估，因此实际上节省了内存。 FLUX.2 klein-base-4B 编辑训练适用于 32-36 GB Mac。 (#711)

已更改

  • Release note 现在从每个 PR 的发行说明块中收集到 GitHub 版本草稿中，维护者在发布前进行审查。 CHANGELOG.md 不再手工编辑。 （#685）
  • Shell 完成现在建议 —base-model 值（规范模型名称）。 （#706）
  • 元数据 sidecar 现在记录运行所使用的检查点路径，并且 —config-from-metadata 从中重放，而不是默默地替换内置模型的权重。 （#708）
  • 自述文件：贡献者部分，包含贡献者图像和 Filip Strand 的版权。 (#720)
