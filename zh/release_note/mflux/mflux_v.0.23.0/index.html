mflux v.0.23.0

mflux v.0.23.0

0.23.0

新

  • mflux-generate-flux3 和 mflux-generate-flux3-edit 现在运行 FLUX 3 Image Klein（蒸馏和基础），具有文本到图像、最多十个参考图像的编辑以及 4、6 和 8 位量化。 （#878）
  • mflux-generate-flux3 和 mflux-generate-flux3-edit 现在以 ComfyUI/ai-toolkit (BFL)、扩散器/PEFT 和 kohya 键格式加载带有 --lora 的 FLUX 3 Image Klein LoRA。 （#881）
  • mflux-generate-qwen-2.1、-edit 和 -controlnet 现在分 8 个步骤运行 Qwen-Image-2.1-Turbo (--model qwen-image-2.1-turbo)。 mflux-save 现在写入一个 Qwen-Image-2.1 检查点，文本到图像和编辑命令都会加载该检查点。 （#859）
  • 新命令 mflux-generate-krea2-controlnet：带有深度 ControlNet 的 Krea 2 Turbo。给它一张照片（Depth Pro 估计深度）或现成的深度图。 LoRA 和 -q 的工作方式与 mflux-generate-krea2 相同。 （#864）

改进

  • 内置模型现在从固定的 HuggingFace 提交加载，因此每次安装都运行相同的权重。从另一个提交缓存的模型需要一次在线运行才能切换；磁盘上已有的权重将被重复使用。 （#872）
  • Qwen Image 2.1 的融合注意力序言现在可以处理跨步投影并保留 MLX RMSNorm 精度和舍入，同时直接生成注意力布局。生成的像素可能与之前的融合实现不同；不受支持的配置保留组合路径。 （#846）
  • Qwen Image 2.1 在生成过程中包含兼容的密集注意力和前馈投影，减少投影开销，同时保持检查点兼容性。量化和适配器轴承投影保留其原始路径。 （#847）

已更改

  • 现在，当无法写入输出文件（权限错误、磁盘已满、卷丢失）时，图像保存会导致运行失败，而不是记录错误并退出 0。 (#861)

文档

  • Qwen-Image-2.1 自述文件现在记录了 mflux-generate-qwen-2.1-controlnet：控制类型、Turbo、使用蒙版修复以及如何调整控制图像的大小。 （#880）
  • mlx-teacache 的自述文件条目现在命名了跳过步骤的模型：FLUX.1 dev 和 Krea、FLUX.2 Klein 基础、Z-Image 基础和 Qwen-Image（原始检查点）。 （#855）
  • docs/plugins.md 讲述如何查找、安装和编写在 mflux.extras 下添加命令的插件。自述文件链接到它。 （#856）

内部

  • 新的/mflux-pr-docs代理技能编写PR正文和release note供开发者批准。更新 .claude/skills/ 中克劳德代码、光标和 GitHub 副驾驶的技能。 （#837）
  • /mflux-pr-docs 现在将开发人员批准的标题传递给 gh pr create，因此它可以从 Claude Code 运行。开放 PR 会保留其标题，除非开发人员更改它。 （#854）
  • 为 Krea 2、Qwen-Image、Qwen-Image-2.1、FIBO lite 和 ERNIE-Image 重新生成了黄金测试参考，并为 FIBO Edit 和 HuggingFace LoRA id 修复了黄金测试助手。生成的图像不会改变。 （#871）
