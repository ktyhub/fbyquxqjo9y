lighthouse v8.4.0

小版本 发布时间2021年9月8日 来源GoogleChrome/lighthouse 英文原文

全Changelog 我们预计此版本将在 Chrome 95 的 DevTools 中发布，并在 2 周内发布到 PageSpeed Insights。

新贡献者

感谢我们的新贡献者👽🐷🐰🐯🐻！ 埃马努伊尔·祖姆波拉基斯@emzoumpo 米卢汀·克里斯托菲奇@milutin 比约恩·埃里克·佩德森@bep 杰罗姆库基尔@jckr 索拉夫·库马尔@svkrclg

新审核

  • 检测 LCP 元素何时延迟加载。延迟加载的首屏图像会在页面生命周期的后期呈现，这可能会延迟最大的内容绘制。 了解更多 (#12838)

核心

  • 网络请求：将文件系统资源识别为非网络资源（#12970）
  • 视口：添加视口审核作为性能诊断（#12972）
  • csp-evaluator: 凹凸包版本 (#12990)
  • 配置：在skipAudits 情况下保留全页屏幕截图（#12645） *大型javascript库：删除（[#12941]（https://github.com/GoogleChrome/lighthouse/pull/12941））
