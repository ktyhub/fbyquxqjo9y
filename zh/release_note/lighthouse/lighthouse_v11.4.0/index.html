lighthouse v11.4.0

全Changelog 我们预计此版本将在 Chrome 122 的 DevTools 中发布，并在 2 周内发布到 PageSpeed Insights。

新贡献者

新审核

Chrome 计划取消对第三方 cookie 的支持，这些第三方 cookie 可以使用新的 Lighthouse 审核进行检测。 了解有关逐步淘汰第三方 cookie 的更多信息。 (#15632)
