lighthouse v4.2.0

小版本 发布时间2019年3月14日 来源GoogleChrome/lighthouse 英文原文

全Changelog 我们预计此版本将在 Chrome 74 的 DevTools 中发布。

新贡献者！

@pra85、@tgfjt、@gidztech 和 @jburger424。谢谢你！

新审核

  • 点击目标：验证点击目标大小合适且清晰（#5846）

报告

  • 重组 a11y 审核组 (#7129)
  • clip 标头中的 URL 异常长 (#6858)
  • 详细信息渲染器：使用新的审计详细信息类型（#7192）

核心

  • fid：将最大潜力 FID 添加到 JSON (#5842)
  • 工件：将 AnchorElements 统一为单个收集器（#7101）
  • 工件：在脚本工件中包含内联脚本 (#7065)
  • 工件：创建 ViewportMeta 计算工件 (#7264)
  • 工件：添加 TestedAsMobileDevice 基础工件 (#7280)
  • 启动时间：更好的归因 (#7059)
  • 字节效率：使用更乐观的 GZIP 比率 (#7210)
  • 缓存头：修复必须重新验证中的拼写错误（#7189）
  • 细节渲染器：添加片段细节渲染器 (#6999)
  • 诊断：添加诊断审核 (#7052)
  • 驱动程序: 添加 waitForFCP 超时 (#7356)
  • 驱动程序：从进程外 iframe 收集网络请求（#6922）
  • 驱动程序：将“Chrome-Lighthouse”添加到用户代理（#7297）
  • 模拟：将 chrome useragent 升级为 m74 (#7211)
  • fcp-3g：删除未使用的 i18n 以实现 LR 兼容性（#7103）
  • 字体显示：更准确地遵循 CSS 规范 (#7191)
  • 图像元素：限制自然大小的获取时间（#7274）
  • Lantern：添加预计算网络分析的配置（#7239）
  • lhr：在网络请求审核中包含资源大小（[#7056]（https://github.com/googlechrome/lighthouse/pull/7056））
  • 清单：删除清单工件以支持新的 WebAppManifest (#7078)
  • 指标：如果 TTI 失败也不会失败 (#7132)
  • 网络分析：将附加 RTT 设置为 0 而不是 NaN (#7156)
  • 网络记录器：由脚本启动的重定向被设置为启动器（#7352）
  • 插件：添加对组的支持 (#7304)
  • seo：删除手动移动友好审核（#7223）
  • seo：添加 rel=canonical 测试来审核域根（#7228）
  • 点击目标：禁用桌面上的字体大小和点击目标审核（#7393） *点击目标：使点击目标失败更加明显（[#7373]（https://github.com/googlechrome/lighthouse/pull/7373））
  • tsc：修复审核详细信息类型层次结构（[#7177]（https://github.com/googlechrome/lighthouse/pull/7177）），[#7154]（https://github.com/googlechrome/lighthouse/pull/7154），[#7285]（https://github.com/googlechrome/lighthouse/pull/7285）） *未使用的CSS：更改标题推迟->删除（[#7235]（https://github.com/googlechrome/lighthouse/pull/7235））
  • 为节点 11 中损坏的测试详细信息提供排序回退（#7216）
  • 抑制 LR 中应用程序清单错误的协议超时（#7184）
  • 优化点击目标审核 (#7130)
  • 没有错误时删除 NO_ERROR 运行时错误 (#7358)

CLI

  • 在退出 Chrome 之前在 runLighthouse 中写入报告 (#7339)

部门

  • snyk：更新 snyk 快照 (#7277、(#7233、#7167)、#7116)
  • 更新以消除传递性漏洞 (#7319)
  • 更新 cssstyle 以解析更多命名颜色、CSS4 颜色 (#7283)

文档

*贡献.md：修复拼写错误（[#7170]（https://github.com/googlechrome/lighthouse/pull/7170））

  • 修复节流速率评论并调整康卡斯特带宽 (#7374)
  • 改进扩展和使用配置文件的解释 (#7354)
  • 将节流文档更新为公共版本 (#7332)
  • 自述文件：将灯塔守护者添加到集成中（#7399）
  • 文档（相关项目）添加react-lighthouse-viewer（[#7262]（https://github.com/googlechrome/lighthouse/pull/7262））
  • 自述文件：将 Fluxguard 添加到集成列表中 (#7249)
  • 变异性：添加专用方差文档（#7175）

国际化

  • 修复最大潜在 FID 描述 (#7353)
  • ICU 语法修正 (#7320)
  • 为 i18n 准备的 seo 字符串 (#6860)
  • 翻译点击目标审核中的字符串（#7111）
  • a11y 类别标题和描述 (#7113)
  • 导入翻译后的可访问性和 lh 错误消息 (#7008)

测试

  • 重构驱动程序，更多 gotoURL 测试（#7270、#7242、#7212）
  • 在 CI 中运行节点 11 (#7230)
  • 用内联文字替换非易失性快照 (#7217)
  • Smokehouse：重构以启用 Smokerider (#7284)
  • 熏制室：+/- 运算符 (#7343)
  • Smokehouse：gzip 测试来断言传输和资源大小（#7286）
  • Smokehouse：finalUrl/errorCode 不匹配时失败（#7227）

其他

  • tap-targets：删除带有尾随空格的行（[#7105]（https://github.com/googlechrome/lighthouse/pull/7105））
  • 在 travis 构建缓存之前清理 node_modules/.cache (#7388)
  • 将 Flags 注释转换为 jsdoc 以获得更好的智能感知 (#7359)
  • 从 emulation.js 导出 UA 字符串 (#7318)
  • 修复评论中的拼写错误 (#7296)
