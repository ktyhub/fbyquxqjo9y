lighthouse v8.0.0

大版本 发布时间2021年6月2日 来源GoogleChrome/lighthouse 英文原文

全Changelog 我们预计此版本将在 Chrome 93 的 DevTools 中发布，并且已经在 PageSpeed Insights 中！

显着变化

  • 性能类别 进行了许多评分更改，以与其他性能工具保持一致并更好地反映网络状态。
    • 性能分数已重新加权（#12577）
    • TBT 和 FCP 分数曲线已更新（#12576、#12556）
    • CLS 已更新为新的窗口化版本 定义（#12554） 有关更多详细信息，请参阅 v8.0 性能常见问题解答。
  • 该报告包含一个新的指标过滤器。选择一个指标来关注与改进该指标最相关的机会和诊断：
  • 灯塔树形图 现已在所有主要灯塔 clients 上提供。如果您的站点向 Lighthouse 公开源地图，请查找“查看树形图”按钮以查看已发货的 JavaScript 的详细信息，可按大小和负载覆盖范围进行过滤。

🆕 新审核

  • 新的审核 csp-xss 已添加到最佳实践中，以评估内容安全策略并提出提高其安全性的方法。根据托管环境和页面内容，这可能是一项具有挑战性的审核，因此目前它是不评分的（#12514、#12551）

🤖💥 针对程序化用户的重大变化

  • 自 Lighthouse 6 以来，旧指标 estimated-input-latency 和 first-cpu-idle 已被弃用、未加权和隐藏。它们现已被删除 (#12553)
  • 从 Node 13 开始，Node 默认使用 full-icu 构建，因此非常大的 intl polyfill 已从 Lighthouse 的依赖项中删除。如果您无法使用 small-icu 但需要本地化支持，请参阅 自述常见问题解答 (#12426)
  • 长时间审核的uses-webp-images有一个新的ID，modern-image-formats。 WebP 现在相当主流，这使得审核可以开始包括未来其他尖端图像格式的详细信息 (#12535)
  • 为了清晰起见，对 image-elements 工件进行了重组（#12568）

🧱 核心

  • 导航：仅观察 PerfObserver 中的长任务（#12545）
  • script-treemap-data：不要创建名称为空的节点 (#12569)

⛏️👷 碎石

支持审核用户流（#11313）

  • 添加 settings 来收集上下文 (#12574)
  • 修复分布式条件类型的使用（#12565）
  • 支持inspector-issues收集器(#12530)
  • 支持tags-blocking-first-paint收集器(#12527)
  • 支持response-compression收集器(#12508)
  • 将 navigation-runner 与旧版 gather-runner 对齐（#12478）

📔 报告

  • 提高公制过滤器的可访问性（#12552）
  • 树形图：添加占位符、要点和文件上传功能 (#12511)
  • 树形图：支持在 url 中传递 gzip 压缩数据（#12509、#12519）
  • 查看器：修复要点图标 (#12505)

👥 Clients

  • 修复开发工具的主会话 OOPIF 检查（#12533）
  • 在所有 clients 中渲染树状图按钮（#12516、#12570、#12590）
  • 向后移植原始格式修复 (#12566)

🌍 国际化

  • 导入新字符串 (#12515, #12591)

📋 测试

  • 在 CI 中的所有活动节点版本上运行单元测试 (#12513)
  • 同步开发工具网络测试 (#12578)
  • 树形图：减少 debug.json (#12555)

🕸️ 部门

  • 将 lighthouse-plugin-publisher-ads 更新为 1.4.1 (#12592)
  • 将 axe-core 更新为 4.2.1 (#12575)
  • 将 puppeteer 更新为 9.1.1 (#12284)
  • 将 chrome-launcher 更新为 0.14.0 (#12507)
