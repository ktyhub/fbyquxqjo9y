lighthouse v5.2.0

小版本 发布时间2019年7月24日 来源GoogleChrome/lighthouse 英文原文

预计在 Chrome 77 中发布 DevTools（2019 年 9 月）

新审核

  • 第三方使用，一种新的性能诊断，显示页面中第三方资源的细分以及加载它们所需的时间/字节（#9067）
  • 总阻塞时间，一个实验性的新指标，作为 TTI 的配套，帮助确定主线程解锁的优先级。由于目前处于实验阶段，审核未评分，并且仅出现在原始 LHR JSON 中，而不出现在 HTML 报告中。 （[#8975]（https://github.com/googlechrome/lighthouse/pull/8975），[#9409]（https://github.com/googlechrome/lighthouse/pull/9409））

显着变化

  • tracehouse：性能跟踪处理已移至 lib/tracehouse/ 中自己的目录，以充当更独立的库（9f80524、1af2edd、7ba6776、ddff3d6）
  • 证书安全错误不再是致命的 Lighthouse 错误，尽管 Chrome 错误页面默认情况下仍会在报告中返回少量结果。请参阅文档 以测试这种情况下的页面。 (#8865)
