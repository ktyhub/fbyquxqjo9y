FlagEmbedding v1.3.2-BGE-Update

修订 发布时间2024年10月31日 来源FlagOpen/FlagEmbedding 英文原文

FlagEmbedding v1.3.2-BGE-Update

变更流程图

亮点

  • 更简化的推理入口 — FlagAutoModel 和 FlagAutoReranker 为 embedding 和 reranking 模型提供自动加载接口，减少手工设置模型和 tokenizer 的工作。

  • 可扩展、感知 OOM 的推理 — 多 GPU 支持和动态批大小让推理更容易跨硬件扩展，并减少 OOM 失败；优化后的 padding 提升吞吐，对变长输入尤其明显。

  • 更广泛、更简单的评估 — 内置对常见评估数据集的支持，外加自定义评估接口，减少准备工作；采用时要求你的数据遵循既定的组织规范。

  • 工作流重组 — 仓库现在把推理、微调和评估路径分开，所以升级时应预期 import 和脚本会发生变化。

  • 发布说明中没有明确点出破坏性变更，但仓库重组意味着值得检查集成路径。

我们完全更新了 BGE 代码存储库，包括以下关键改进：

推理代码

  • 添加了FlagAutoModel和FlagAutoReranker，使模型的使用更加容易。

推理优化

  • 实现了多 GPU 支持。
  • 引入了动态批量调整大小以防止内存不足 (OOM) 问题。
  • 优化填充以提高效率。

评估代码

  • 对常见评估数据集的集成支持，以提高用户便利性。
  • 提供自定义评估接口，遵循指定的数据组织标准，简化评估流程。

项目结构组织

  • 重组项目以简化与推理、微调和评估相关的流程。
