angular v21.2.17

变更流程图

亮点

  • SSR 与传输缓存加固 — TransferState 恢复现在能抵御 DOM clobbering，SSR location-origin 校验更严格，传输缓存键改用加密安全的 SHA-256。不可缓存的 HTTP 流量和带凭证的 fetch 请求被排除在传输缓存之外，降低了不当复用响应的风险。SSR 密集的应用应优先升级。

  • 有兼容性影响的网络安全修复 — JSONP 现在拒绝非 HTTP(S) URL，service worker 在跨域重定向时剥离敏感 header。可能有破坏性： 使用自定义 URL scheme 或依赖授权 header 跨源转发的应用，可能需要调整请求流程。

  • ServerXhr 弃用 — @angular/platform-server 中的 XHR 支持，包括 ServerXhr（#69255），已弃用，但文档未标注为移除。请在未来移除之前，把服务端 XHR 集成迁移到标准的 fetch API。

  • 校验与边界情况修复 — 双向属性会被净化，SVG 动画属性名按小写校验（#69269），超长日期格式字符串被限制，HttpRequest 会保留显式为空的 referrer。这些是正确性修复而非新功能；受影响就升级，否则未走这些路径的应用可以按常规补丁升级节奏合理推迟。
