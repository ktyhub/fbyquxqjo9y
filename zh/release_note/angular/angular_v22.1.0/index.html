angular v22.1.0

小版本 发布时间2026年7月29日 来源angular/angular 英文原文

angular v22.1.0

变更流程图

亮点

  • 应用级 CSS 变量 — 编译器现在把 CSS 变量限定到应用作用域，包括组件 properties 中使用的变量。这减少了独立构建的库与全局样式之间的冲突，但要审查依赖精确 CSS 变量名的集成（#68846）。

  • 外来组件互操作 — foreignImports 现在支持 import 别名，Angular 组件也接受未调用的 signal 直接作为外来组件的 prop。另有修复覆盖外来作用域和控制流块，以及处置外来 @content 内的 Angular 视图，让混合框架渲染更可靠（#68674、#69558、#69674）。

  • 可写 linkedSignal 行为 — 新增自定义 set 选项，让开发者定义显式写入行为，同时保留 linkedSignal 由源驱动的重置语义，从而在不替换 signal 抽象的前提下实现更丰富的可编辑状态模式。

  • 显式 HTTP 缓存控制 — 新选项允许缓存带凭证的请求和通常不可缓存的请求。与此同时，传输缓存现在默认跳过带凭证和不可缓存的流量（#69017）。请把缓存带凭证的请求当作一项明确的安全与失效决策；本版本还为根级提供的 HttpClient 实例启用了 XSRF 保护。

  • 更强的编辑器诊断 — 语言服务现在会检查未导出的 standalone 类和需要内联 typecheck 块的模板，并考虑 strictTemplates 默认启用（#68454）。预期编辑器发现的问题会更贴近编译结果。

  • 弃用与迁移支持 — HttpClient.jsonp、HttpClientJsonpModule 及相关 JSONP API 已弃用；请把使用方迁移到标准的 HTTP 请求。Angular 还新增了 injectable 到 service 的迁移，并修复控制流迁移在 then/else 附近的处理，请在提交前审查迁移输出。

无破坏性变更。
