angular v22.2.5

修订 发布时间2026年11月6日 来源angular/angular 英文原文

angular v22.2.5

变更流程图

亮点

  • rxResource 诊断 — rxResource() 现在接受 debugName，与 resource() 和 httpResource() 一致。可用它在 Angular DevTools 中识别由 Observable 支撑的 resource 信号；这改善了内省能力而不改变加载行为。
  • 更安全的 nullable 媒体绑定 — 对 <img> 和 <video>，绑定到 null 或 undefined 的 [attr.src] 现在会移除该属性，而非写入 src=""，修复了 #71095 引入的回归。这避免了媒体 URL 异步到达时产生的虚假错误事件；属性绑定（[src]）保留原有强制转换。
  • 自定义控件遵循 updateOn — 与 [formControl] 或 formControlName 配合使用的 FormValueControl 实现，现在会为 updateOn: 'blur' 和 'submit' 缓冲值和脏状态变更，分别在 touch 和提交时落地。自定义控件现在能匹配内置校验时机；请确认你的控件会发出 touch，并测试会清除待定变更的重置。
  • Signal forms 对齐与更低分配 — CompatFieldNode.required() 现在响应式反映 Validators.required，包括校验器更新和控件替换。Signal forms 也不再为普通元数据和内置规则创建字段注入器，降低每个字段的建立/拆除开销，同时保留异步校验器清理。
  • 按导航控制焦点 — 借助 Navigation API 集成，router 现在从导航 extras 读取 focusReset，帮助聚焦字段在 URL 同步的导航中保留。这支持 #71595 在 main 上公开引入的行为；在 v22 补丁分支上，focusReset 被内部读取，但尚未加入 NavigationBehaviorOptions。
  • google3 中更快的懒加载 — #70860 让 g3 构建在根环境注入器中运行 loadComponent 和 loadChildren，从而并行加载，而不是等待 loadConfig 的懒加载 provider。这仅适用于 g3；第三方构建在 v23 前保留 route-injector 行为。
