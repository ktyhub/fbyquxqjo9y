angular vsix-22.0.0

发布 发布时间2026年6月3日 来源angular/angular 英文原文

angular vsix-22.0.0

变更流程图

亮点

  • 内置 TypeScript 6.0——第一天就要迁移配置 — 这是本版本真正的破坏性变更：扩展现在自带 TS 6.0，其新默认值（尤其是 strict: true）会进入 Angular 模板类型检查。从未选择严格模式的项目一打开就会开始抛错，请在 tsconfig.json 中加入 "strict": false 以保留旧行为。如果你更愿意停留在自己固定的编译器上，可以把 tsdk 指向工作区的 TypeScript 安装（与内置 TS/JS 扩展同样的机制），而不是放宽 tsconfig。请把这当作必需的升级步骤，而非可选调整。

  • @Input transforms 现在能正确类型检查（dc9c72da9b） — 一项语言服务修复，专门影响使用 transform 函数的 signal input。此前模板检查器可能错误推断 input 类型并发出误报；现在转换后的类型会被采纳，因此 <my-comp [value]="..."> 会按 transform 实际接受的类型校验。如果你采用了带 transform 的 signal input，且曾压制或忽略虚假错误，升级后值得重跑模板诊断。

  • 模板的 Document Symbols（cfd0f9950c） — Angular 模板现在参与 IDE 全局符号导航：大纲视图、面包屑以及”跳转到文件/工作区符号”都会显示模板声明，而不再把模板当作不透明字符串。实际收益是在大型组件中更快定位；注意元素和绑定多的组件里符号大纲会变得更密集。

  • 模板内的嵌入提示（5a6d88626b） — 推断出的绑定类型和参数名现在会在模板标记中内联显示，无需逐个悬停就能看到表达式解析成什么。这是一项可读性功能，对复杂表达式和 let/@let 别名有实际的调试价值，但确实增加视觉噪音——不喜欢的团队可以在编辑器层面禁用嵌入提示。

  • 可配置的延迟块 idle 超时（c6f98c723c） — 语言服务现在理解 @defer 块的 idle timeout 选项，因此 on idle 触发器能得到准确分析和补全，而不再被标记或保持不透明。如果你依赖 @defer 优化首屏加载，这让你能表达并校验一个有界等待，再渲染 idle 加载的内容——请检查超时值是否匹配服务能识别的新语法。

  • 除上述 TypeScript 6.0 默认值转变外，无其他破坏性变更。

重大变化

该扩展现在捆绑了 TypeScript 版本 6.0，它本身包括破坏 更改，包括新默认值，例如 strict 变为 true。您需要明确设置 "strict": false 在你的 tsconfig.json 中。或者，该扩展支持以与内置 TS/JS 扩展相同的方式配置 tsdk。

修复和功能

  • 修复（语言服务）：添加对带有转换的 @Input 的支持 (dc9c72da9b)
  • feat(语言服务)：添加对 Angular 模板的文档符号支持 (cfd0f9950c)
  • 壮举（语言服务）：添加角度模板嵌入提示支持（[5a6d88626b]（https://github.com/angular/angular/commit/5a6d88626b604db937287a501cb723c088412a7e）） -壮举（语言服务）：添加对延迟块中空闲超时的支持（[c6f98c723c]（https://github.com/angular/angular/commit/c6f98c723cdd2c209092927855f8cbaf63ecce30））
