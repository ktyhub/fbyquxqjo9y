小版本 发布时间2026年11月18日 来源angular/angular 英文原文

angular v22.3.0

这个项目是干啥的：谷歌出的前端框架，帮程序员用组件化方式搭网页和应用，这次主要修了编译器与模板里的毛病，适合做大型网站的团队。

变更架构图

亮点

  • 更强的模板校验 — 现在会报告显式 ng-template 元素上的未知属性绑定，并拒绝以冒号开头的属性/property 名。在把 CI 升级前请先修复这些诊断，以免暴露此前被隐藏的模板错误。
  • 更严格的控制流类型 — 无效的 @let 用法和跟踪函数不再级联成一连串误导性的编译器错误，同时不可迭代的 @for 表达式不再被抑制。无效的循环输入应加以修正，而不是依赖其静默失败。
  • CSS 单位检查 — 编译器 CLI 现在会检测需要单位的 CSS 属性的数值，捕获浏览器原本会拒绝的样式。
  • 预处理器工作流支持 — 预处理器新增 serve 工具和同步 WASM 执行（#71313），使本地编译工作流更完整，也更易与开发工具集成。
  • 更好的编译器与预处理器一致性 — @defer 校验、宿主指令、诊断、查询产出顺序、装饰器处理和声明产出正日益与 ngtsc 对齐；工具链用户应期待更一致的错误和生成代码。
  • 兼容性 — 未宣布破坏性变更。
