angular v22.2.6

变更流程图

亮点

  • 运行时稳定性与内存 — 修复了渲染器和引用保留相关的泄漏，在事件重放后移除过期的事件监听器，并确保水合失败时释放 pending tasks。Resource URL 属性现在接受 null 和 undefined；长期运行和水合的应用应升级。

  • HTTP 行为与包体积 — HttpParams 现在会省略空数组，因此有自定义查询字符串处理的应用应验证该行为；同步拦截器错误也会正确清理 pending tasks。httpResource 的初始化代码和未使用的传输缓存获得 tree-shaking 改进。

  • Signal 表单正确性 — 触碰字段会刷新防抖的后代值，SignalFormControl 保留传入的 options，parseErrors 更新不再发出重复的 valueChanges 事件。校验器也不再跟踪 parseErrors，减少不必要的响应式和控件保留。

  • 模板、翻译与导航 — &ngsp; 在 ngNonBindable 内变成空格，编译器诊断和无效的 ICU 翻译消息得到改进，router 修复避免在取消导航时调用不必要的 history.go()，以及用 Navigation API 恢复 URL 时的重新加载。

  • 升级建议 — 这是一个内容充实的补丁版本，不是重新打标签或仅元数据更新。changelog 未发现破坏性变更或必需的迁移步骤；如果你用到受影响的 API 或观察到这些症状，就升级，否则这是一次可推迟的常规维护升级。
