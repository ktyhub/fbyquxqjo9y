angular v22.0.1

修订 发布时间2026年6月10日 来源angular/angular 英文原文

angular v22.0.1

这个项目是干啥的：谷歌出的前端框架，帮程序员用组件化方式搭网页和应用，这次主要修了编译器与模板里的毛病，适合做大型网站的团队。

变更架构图

亮点

  • URL 处理与 HTTP 进度上报 — 查询参数现在插入到 URL fragment 之前，router 导航边界使用原生 URL 对象，POST/PATCH 请求能正确转发 reportUploadProgress 和 reportDownloadProgress。JSONP 请求拒绝非 HTTP(S) URL，并保留显式为空的 referrer。

  • 模板与绑定安全 — 链接净化现在覆盖 MathML 的 href/xlink:href 属性以及双向属性；i18n 事件属性被禁止。compiler-cli 还会绑定 switch 穷尽性检查表达式，改善类型收窄和编译期校验。

  • SSR 与 TransferState 加固 — SSR 加固覆盖 platform-location origin 校验、抵御 DOM clobbering 的 TransferState 恢复，以及服务端禁用 WebMCP。WebMCP 工具现在必须有描述，生成的表单 schema 设置 additionalProperties: false。

  • 原型污染防御 — 表单组控件查找拒绝原型遮蔽的键，formatDateTime 防止原型污染，样式工具正确处理 null 原型对象。如果你的应用根据用户输入构造动态控件名和日期/时间输入，这些值得做回归测试。

  • 稳定性与生命周期修复 — 处理了 PendingTasks.run 中的同步错误，已销毁视图不再保留悬空的 prevConsumer 引用（#68681），表单动画监听器在销毁时被清理。传输缓存键现在改用加密的 SHA-256，而非非加密哈希。

  • 服务端 XHR 弃用 — @angular/platform-server 中的 XHR 支持已弃用；请把 SSR 请求代码迁移到标准的 fetch API。

本补丁版本无破坏性变更。
