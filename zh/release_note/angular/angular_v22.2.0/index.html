angular v22.2.0

angular v22.2.0

变更流程图

亮点

  • 模板访问与 CSS 封装 — 模板现在可以访问组件的私有属性，不必再为了绑定而写 public getter；注意 private 不再是模板绑定的边界。嵌套 CSS 现在能正确限定作用域，::ng-deep 的后代元素也不再被额外封装——如果你依赖深度样式，请校验生成的选择器。

  • 更早发现模板错误，@defer 加载更精简 — 新的 strictUnclaimedEventNames 编译器选项能揪出拼错的输出绑定，避免事件处理器悄悄失效。带 key 的 @defer 块现在会做作用域类型检查，跨块共享的延迟导入也会去重，减少重复加载。

  • 错误边界走出模板 — 编程式 ErrorBoundary API 加上语言服务对 @boundary 块的支持（#70463），让开发者可以在代码里组合错误处理逻辑，而不再只能依赖模板声明，同时改善了声明式边界的编辑器工具。

  • Signal 表单与 WebMCP 元数据 — 永久隐藏的 signal-form 字段让向导步骤或条件区块可以保留值而不必一直显示。隐式 WebMCP signal 表单现在硬编码 readOnlyHint 和 untrustedContentHint，工具声明也接受注解，给客户端提供显式元数据，而不再要求其靠行为去推断。

  • 路由资源与导航语义 — 路由资源和 containsTree 现在公开，activated-route 资源暴露 reload()，抛出 RedirectCommand 也能发起重定向。阻塞现在只取决于资源加载状态，回滚则在加载完成前保持状态冻结；自动 injector 清理的稳定化也让原有的手动销毁逻辑值得复核。

  • 兼容性 — 未列出破坏性变更。
