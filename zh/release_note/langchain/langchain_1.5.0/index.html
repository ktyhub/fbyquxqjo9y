langchain 1.5.0

小版本 发布时间2026年11月11日 来源langchain-ai/langchain 英文原文

langchain 1.5.0

这个项目是干啥的：一个搭建 AI 应用的万能积木框架，把大模型、工具、数据串成能自动干活的工作流，给想把大模型做成真正产品的开发者用。

变更架构图

亮点

  • 放弃 Python 3.10 支持（破坏性） — 最低版本现在是 Python 3.11（3.10 已 EOL）。仍在 3.10 上的用户会继续解析到 langchain 1.4.x，必须在升级到 1.5.0 之前把运行时升到 3.11+；这是主要的迁移门槛。
  • langchain-core 下限提高到 1.8.0 — langchain==1.5.0 现在要求 langchain-core>=1.8.0，因此 lockfile 和 pin 住的环境需要同步升级 core，否则解析会失败。
  • 新的模型路由 + 自动模式中间件 — 新增 ModelRouterMiddleware 和自动模式中间件（#41766），用于动态模型选择/路由。注意它明确标记为 beta（#41797），因此要视其 API 为不稳定，暂时不要在生产中形成硬依赖。
  • 其余仅文档变更 — 剩余的变更是澄清 Baseten 最低版本（#41777）；对运行时行为没有影响。
  • 升级建议 — 如果你想要新的路由中间件且已经在 Python 3.11+，值得升级；如果你 pin 在 3.10 或不需要新中间件，可以跳过，因为 1.4.x 仍会继续支持你。

langchain 1.5.0 放弃对 Python 3.10 的支持，该版本已达到生命周期终点。最低支持版本现在是 Python 3.11，langchain-core 的最低版本现在是 1.8.0。Python 3.10 的用户将继续解析到 langchain 1.4.x。
