langchain langchain-xai 1.4.0

发布 发布时间2026年11月15日 来源langchain-ai/langchain 英文原文

langchain langchain-xai==1.4.0

变更流程图

亮点

  • ChatXAI 改走 LangSmith 网关——本次重头戏（#41838） — 模型调用现在经由 LangSmith 转发，而非直连 xAI。这是真实的行为变更；如果你的部署依赖直连 xAI 端点，或尚未配置好 LangSmith 的配置与认证，升级前务必确认这一侧已就绪。
  • 移除 Python 3.10——破坏性变更，需要迁移（#41268） — 合作伙伴包不再支持已 EOL 的 Python 3.10。如果你仍在使用 3.10，请先迁移到受支持的解释器，否则安装会失败；已在 3.11+ 的用户不受影响。
  • 推理 token 计数修正（#39667） — 在把推理 token 计入输出后，total_tokens 现在会重新计算，修复了启用推理的 xAI 模型用量/计费数字不准的问题。如果你跟踪 token 消耗或成本，值得升级；否则影响较小。
  • 依赖整理，基本无功能影响（#41407、#41884） — 放宽了第三方依赖上限并升级了传递依赖（aiohttp 3.14.4→3.14.5、certifi、urllib3 2.7.0→2.8.0、anyio 4.11.0→4.14.2），缓解了依赖冲突。大量 model-profiles 刷新提交只是数据更新；#40026 仅把结构化输出指南的链接指向 xAI 官方文档。
  • 结论——不是空操作，选择性升级 — 这里确实存在行为变更（网关路由、Python 最低版本、token 计算），因此如果你想要 LangSmith 网关集成或准确的推理 token 计数，且已在受支持的 Python 上，建议升级。如果这些对你都无关紧要、且仍固定在旧解释器上，可以放心跳过。
