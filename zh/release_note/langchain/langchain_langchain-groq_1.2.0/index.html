langchain langchain-groq 1.2.0

发布 发布时间2026年11月15日 来源langchain-ai/langchain 英文原文

langchain langchain-groq==1.2.0

这个项目是干啥的：一个搭建 AI 应用的万能积木框架，把大模型、工具、数据串成能自动干活的工作流，给想把大模型做成真正产品的开发者用。

变更架构图

亮点

  • LangSmith 网关路由 — ChatGroq 现在经由 LangSmith 网关转发（#41837），这是一项行为变更，升级前值得审查。更新日志未说明配置、认证或兼容性细节，因此上线前请查阅对应 PR 文档。
  • Groq 新能力 — 新增 performance 服务层级（#38339），并把上下文长度错误映射为 ContextOverflowError（#37676），为调用方提供了新的层级选项和统一的溢出错误处理类型。
  • 模型兼容性清理 — 替换了已弃用的 Groq llama 模型（#38363），更新了推理集成覆盖范围（#38976）；升级前请核对任何固定（pin）的模型名。破坏性变更： 本次发布从合作伙伴包中移除了已 EOL 的 Python 3.10 支持（#41268），因此 Python 3.10 用户必须迁移到受支持的版本。
  • 升级建议 — 如果你需要 performance 层级、标准化的溢出错误或更新的模型配置，值得升级。否则，现有 ChatGroq 用户可以跳过本次发布，除非网关路由变更与你的部署相关；其余条目主要是依赖、追踪元数据、文档和测试维护。
