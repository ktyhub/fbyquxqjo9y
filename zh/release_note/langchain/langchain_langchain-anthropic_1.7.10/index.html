langchain langchain-anthropic 1.7.10

发布 发布时间2026年11月4日 来源langchain-ai/langchain 英文原文

langchain langchain-anthropic==1.7.10

这个项目是干啥的：一个搭建 AI 应用的万能积木框架，把大模型、工具、数据串成能自动干活的工作流，给想把大模型做成真正产品的开发者用。

变更架构图

亮点

  • 标准化的拒绝内容块 — #41582 中的 feat(core) 在各模型间引入统一的”refusal”内容块，让安全拒绝以结构化内容呈现，你可以检测并据此分支，而不用处理零散文本或错误。如果你解析模型输出或构建护栏 UX，这点很重要 —— 响应处理代码需要认识新的块类型。
  • Gemini 安全块规范化 — #41658 把 Gemini 的安全块转成同样的拒绝内容块，提升跨 provider 的一致性。如果你切换模型（例如 Gemini ↔ Anthropic），拒绝处理现在可以只写一次，而不必按 provider 分别实现。
  • 依赖下限提高（迁移提示） — #41682 把要求提高到 langchain-core>=1.7.5。如果你 pin 了较旧的 langchain-core，必须连同 langchain-anthropic==1.7.10 一起升级，否则依赖解析会失败。这是本次唯一影响升级的点；没有 API 移除。
  • 值得升级吗？ — 这是一个有实质内容的特性版本，不是空操作或重新打标签（release(anthropic): 1.7.10 #41685 只是版本标签）。如果你消费拒绝/安全内容，或面向多个 provider 想要统一处理，就升级；如果你不检查拒绝内容且已经在 langchain-core>=1.7.5 上，可以安全跳过。
