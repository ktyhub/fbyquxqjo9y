langchain langchain-typesafe 0.0.1

发布 发布时间2026年11月4日 来源langchain-ai/langchain 英文原文

langchain langchain-typesafe==0.0.1

变更流程图

亮点

  • 首个包版本发布 — langchain-typesafe==0.0.1 引入了 TypeSafeClassifier 以及实验性的 AutoModeMiddleware 和 ModelRouterMiddleware。这是一个新包的首发版本，不是常规升级。
  • 分类器与追踪修复 — 分类器的提问（questions）现在限定在单次调用作用域内，其状态与单次调用绑定，而不再在多次调用间共享。同时修复了用量元数据的追踪，改善了这些 API 的可观测性。
  • 依赖兼容性 — 放宽了第三方依赖上限，补齐了缺失的合作伙伴包依赖，并将 certifi 从 2026.7.22 提升到 2026.10.19，减少了依赖解析和安装问题。
  • 升级指引 — 未列出破坏性变更或迁移步骤；也没有此前的稳定基线可供迁移。如果你想评估新的类型安全 API，值得试用；但现有应用可以跳过，除非需要它们，尤其是在中间件 API 仍处于实验阶段的情况下。
