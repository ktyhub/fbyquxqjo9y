langchain langchain-fireworks 1.7.2

发布 发布时间2026年11月4日 来源langchain-ai/langchain 英文原文

langchain langchain-fireworks==1.7.2

这个项目是干啥的：一个搭建 AI 应用的万能积木框架，把大模型、工具、数据串成能自动干活的工作流，给想把大模型做成真正产品的开发者用。

变更架构图

亮点

  • 流式 token 用量 — fix(fireworks): report streamed token usage once (#41693) 修复了流式 token 用量被重复计数的问题；如果你根据响应元数据计量成本或配额，这能消除流式调用的重复计费，准确的 token 计量对你很重要就升级。
  • 响应元数据 — fix(fireworks): report the served model in response metadata (#41686) 在响应中加入实际服务的模型，当请求解析到不同的底层模型时提升可观测性；无需操作，但对日志和调试有用。
  • Reranking 退出 beta — fix(fireworks): promote reranking out of beta (#41551) 将 reranking 标记为稳定；如果你因为 beta 状态一直不敢用，现在采用它更安全，且没有标记破坏性变更，不过仍应确认 API 契约适合你的用法。
  • 依赖与模型 profile — chore(deps) 升级 certifi 2025.8.3→2026.10.19、aiohttp 3.14.4→3.14.5（以及 3.14.3→3.14.4）和 orjson 3.12.0→3.13.0；chore(infra): relax third-party dependency upper bounds (#41407) 与 fix: fix dependencies in some partner packages (#41266) 减少了依赖解析冲突，而反复的 chore(model-profiles) 刷新更新了 profile 数据 —— 大体属于卫生和安全更新，对大多数调用方没有行为变化。
  • 升级结论 — 没有破坏性变更、迁移步骤或重新打标签/仅元数据的标记；依赖流式 token 计数、实际服务模型元数据、reranking 或补丁依赖的 Fireworks 用户值得升级，而非 Fireworks 用户或不受影响者可以安全跳过。
