nacos 3.0.3

修订 发布时间2025年8月21日 来源alibaba/nacos 英文原文

nacos 3.0.3

这个项目是干啥的：阿里开源的服务发现和配置管理中心，帮微服务互相找到彼此并统一管配置，支持gRPC和IPv6，给微服务团队用。

变更架构图

亮点

  • MCP 注册表成为一等公民 — 3.0.3 的招牌：MCP 工具可在服务端创建/更新时自动拉取（#13441、#13442），可从 Swagger API 文件导入 HTTP 传输工具（#13542），可通过 Security Schema 描述（#13455），并新增客户端 AI API（#13524、#13683）。如果 Nacos 是你的 MCP 注册表，这省掉手工接入工具，是离开 3.0.2 的主要理由；不用 MCP 的话，整个主题与你无关。
  • MCP 查询性能 — 在 mcpId/mcpName 上加内存索引（#13526），并收紧 get-mcpserver 逻辑，避免创建后立即冗余查询（#13602），降低查找开销。主要在注册表规模大或 MCP 流量高时有意义，小部署无所谓。
  • 即使不用 MCP 也有实打实的 bug 修复 — 3.0.3 修复配置客户端模糊监听和管理端按 groupName 搜索（#13468、#13648）、beta 配置删除和 config_info_beta 存在性检查（#13585）、破坏 HTTP 配置查询 API 的命名空间转换（#13614）、CloneConfig 在无源命名空间写权限时返回 403（#13600）、functionMode 为 config 或 naming 时启动失败（#13458）、Spring 中 LDAP bean 加载失败（#13522），以及 logback 1.5+ / Spring Cloud Alibaba 提示与报错问题（#13454）。如果 3.0.2 上碰到其中任何一条，不管用不用 MCP 都该升级。
  • 需要核实的行为与部署变化 — 未明确声明 API 破坏，但 v3 admin readiness API 响应码变了（#13437），maintainer SDK 创建 MCP 服务器时现在返回 mcpId（#13553），所以解析这些响应的客户端要检查。frontEndpointConfig 加到 McpInfo（#13527），gRPC 监听 IP 可配置而不再硬编码 0.0.0.0（#13549），控制台 MCP UI 做了重构（#13668、#13702），并为旧控制台访问路径加了 web 提示（#13324）。部署基线：Server/Console 要求 Java 17；Nacos-Client 和 Nacos-Maintainer-Client 仍是 Java 8。
  • 升级结论 — 用 Nacos 做 MCP 注册表或受上述修复影响的人值得升级。3.0.2 用户如果不用 MCP、没碰到那些 bug、且无法满足 Java 17 服务端要求，可以安全跳过。这是实质性特性+修复补丁——不是空操作、重新打标或纯元数据版本。

此版本主要聚焦 MCP 生态扩展和性能优化，同时兼顾开发体验与系统健壮性，并修复旧版本的许多 bug。

关于新的 MCP 注册表特性，Nacos 增加了 MCP 工具动态管理（创建/更新时自动拉取），支持通过 Swagger API 文件导入 HTTP 传输工具，增强安全 schema 定义和客户端 AI 交互 API。还引入内存索引优化 MCP ID/名称查询性能，支持自定义 gRPC 监听 IP 配置，并添加 frontEndpointConfig 以简化前端集成。

在系统与体验改进方面，Nacos 重构了 MCP 管理 UI，优化 Docker 端口配置提示，改进服务创建流程，并加强校验（如用户名/密码检查、删除前表存在性校验）。还增强 MCP 服务器查询逻辑和错误日志，标准化 readiness API 响应，并确保 SDK 返回 MCP ID 的一致性。

特点

[#13441] 支持在创建 mcp 服务器时添加 mcp 工具。 [#13442] 支持创建 mcp 服务器或更新 mcp 服务器时自动获取 mcp 工具。 [#13455] 支持 mcp 服务器的安全架构定义。 [#13524][#13683] 为 AI mcp 添加 client api。 [#13526] 支持 mcpId 和 mcpName 的内存索引以提高性能。 [#13527] 将 frontEndpointConfig 添加到 McpInfo 中。 [#13542] 支持通过 swagger API 文件导入 mcp 工具，以进行 http 传输到 mcp 服务器。 [#13549] 支持指定 grpc 监听 ip 替换 0.0.0.0。

增强/重构

[#13324] 当用户使用旧方式访问 nacos 控制台 ui 时添加 Web 提示。 [#13437] 增强 v3 管理员 API 的准备 API 响应代码。 [#13553] Ai 维护者 sdk 在创建新的 MCP 服务器时将返回 mcpId。 [#13559] 增强 docker-桌面页面导出 nacos 端口配置。 [#13565] 优化 MCP 服务器未找到场景的错误日志。 [#13585] 在删除 BETA 配置之前检查表 config_info_beta 是否存在。 [#13602] 增强获取 mcpserver 逻辑，减少创建后可能查询 mcp 服务器。 [#13625] 创建用户检查用户名和密码不为空。 [#13668][#13702] 增强和重构 MCP 管理的控制台 UI。 [#13678] 创建新版本 mcp 服务器时创建新服务。

错误修复

[#13367] 修复 nacos-custom-environment-plugin 的 NPE 问题。 [#13454] 修复 logback 1.5+ 在使用 spring cloud alibaba 时打印提示和错误的问题。 [#13458] 修复 set functionMode 为 config 或naming 时 nacos 启动失败的问题。 [#13468] 修复 nacos 配置 client 无法通过 groupName 模糊 watch 配置的问题。 [#13497] 修复 getSpec() 时的服务 NullPointerException。 [#13522] Ldap 相关 bean 已正确加载到 Spring 中。 [#13523] 修复 DefaultPushFuture 在抛出 ConnectionBusyException 时不取消的问题。 [#13566] 修复 mcp 列表分页查询异常。 [#13585] 修复无法删除 beta 配置的问题。 [#13600] 修复当用户没有源命名空间写入身份验证时 CloneConfig 收到 403 代码。 [#13614] 修复命名空间未正确转换，无法通过 HTTP 配置查询 API 查询配置的问题。 [#13628] 修复使用 null 值更新实例元数据时的 NPE 问题。 [#13648] 修复配置管理模糊搜索不适用于 groupName 的问题。
