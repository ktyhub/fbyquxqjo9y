nacos 3.1.0-bugfix

小版本 发布时间2025年9月22日 来源alibaba/nacos 英文原文

变更架构图

亮点

  • MCP 注册中心与管理 — 适配 2025-09-16 版 MCP 官方 registry 协议，Nacos 可作为私有 MCP 注册中心；支持从 spec JSON 或 MCP URL 导入服务器、自动拉取工具、在控制台启用/禁用服务器，并可用配置加密插件加密工具提示词。部署或管理 MCP 服务器的团队值得升级。

  • A2A 注册中心 — 新增 AgentCard 元数据与 agent 端点的注册与发现，对 Spring AI Alibaba 等 agent 框架很有用。目前仅支持按 agent 名称发现，技能、标签、描述还不支持；受下述数据兼容问题影响，已有 AgentCard 需要重新发布。

  • 从 3.1.0-BETA 升级的破坏性变更 — 升级前先删除所有 AgentCard；若直接从 3.1.0-BETA 升级而未处理，升级后需删除所有含 agent 和 agent-version 的配置分组，再重新发布 AgentCard。从其他版本升级不受影响。

  • 可靠性与安全修复 — 修复配置数据源映射遗漏、Derby/MySQL 配置发布性能不一致、删除角色时误删 ROLE_ADMIN 的防护、Kubernetes getSpec() 空值处理、MCP 控制台 OpenAPI 解析与 URL 乱码，以及客户端 MCP/A2A gRPC 解析和鉴权登录信息泄露。依赖配置发布、角色管理、Kubernetes 或 MCP 客户端的场景值得为此升级。

  • 升级建议 — 这是有实质内容的版本，不是换标签或仅改元数据。需要 MCP/A2A 能力或受上述修复影响就该升级，否则可以跳过。服务端与控制台要求 Java 17，Nacos-Client 和 Nacos-Maintainer-Client 仍为 Java 8。

Nacos 3.1.0 发布期间，MCP 官方团队发布了新版本的注册中心协议（2025-09-16）。 Nacos 3.1.0 已迅速完成对该协议的适配。要使用此功能，请下载最新的Nacos 3.1.0发布包和Docker镜像。 该版本是一个新的磨石版本，修复了3.1.0-BETA的一些错误。 在3.1.0中，Nacos遵循新的MCP官方注册协议。所有用户都可以使用Nacos作为MCP官方注册中心私有部署，为MCP服务器构建自己的私有市场或注册中心。 Nacos 还支持通过 MCP 服务器规范 json 导入 MCP 服务器，并支持通过 mcp url 自动获取工具，这两个新功能将提高用户在 Nacos 中创建 MCP 服务器的使用率。 此外，该版本支持用户在控制台中启用/禁用 MCP 服务器，并支持使用配置加密插件进行存储的加密 mcp 工具方案。 更重要的是，在这个版本中Nacos支持A2A注册表，它可以允许用户或像Spring AI Alibaba这样的代理框架发布和发现AgentCard和代理端点。目前仅支持通过代理名称发现。 Nacos 未来将支持通过技能、标签或描述进行发现。 其他变化是修复了之前版本中发现的许多错误并进行了一些依赖项升级。 3.1.0-BETA 有一处变化。如果您从3.1.0-BETA升级版本，请在升级前删除所有AgentCard，或升级后删除所有包含agent和agent-version的配置组。并重新发布 AgentCard。如果从其他版本升级可以忽略。 3.1.0的详细变化参见：

特点

[#12191] 添加命名空间存在检查。 [#13322] 支持 A2A 注册表。 [#13423] 支持在控制台中启用或禁用 MCP 服务器。 [#13543] 添加具有注册表支持的 MCP 服务器导入功能。 [#13783] 添加配置元数据更新管理 api。 [#13808] 添加支持官方 mcp 注册表协议。 [#13814] 支持 mcp 工具的提示加密。

增强/重构

[#13777] 增强命名空间存在检查逻辑以提高代码质量。 [#13829] 增强发布重名代理时的提示。

错误修复

[#13744] 修复配置数据源插件省略 CONFIG_INFO_GRAY_WRAPPER_ROW_MAPPER 的问题。 [#13752] 修复 NPE 并忽略 InterruptedException 堆栈日志。 [#13761] 修复删除角色时的添加验证，以防止错误删除 ROLE_ADMIN 等问题。 [#13767] 修复 K8S getSpec() 时服务 NullPointerException。 [#13773] 修复了构建 MCP OpenAPI 派生 URL 时保留协议斜线的问题。 [#13779] 修复 Mcp 工具描述编辑限制。 [#13787] 修复 Nacos Mcp 控制台无法正确解析 OpenApi 文件的 bug。 [#13801] 修复 MCP 控制台解析 OpenAPI 文件 URL 时有时出现乱码的问题。 [#13810] 修复了发布配置时导致 Derby 和 MySQL 数据库之间性能不一致的错误。 [#13824][#13826] 修复 nacos-client 中 MCP/A2A 请求的 AI gRPC 资源解析器和泄漏身份验证登录。 [#13830] 修复agentCard订阅判断问题。 [#13832] 修复模糊搜索可能包含意外结果的问题。

依赖关系
