nacos 1.4.2

修订 发布时间2021年4月29日 来源alibaba/nacos 英文原文

该版本主要优化了JRaft的leader选择的稳定性，配合最新的nacos-k8s项目，可以有很大程度的稳定性优化。 此外，该版本还增强了一些关于Server is Down问题的提示，并修复了1.4.1的许多错误。 详情见下：

特点

-[#4452] 添加配置比较功能。 -[#4602] 添加导出配置的新方式。 -[#4996] 使 nacos-core 模块的日志级别可更改。 -[#5367] 在 client 中添加预插件用于加密配置。

增强

-[#3922] ServiceManager 中的 createServiceIfAbsent 方法需要同步。 -[#4274] 当 db.num 为 1 时跳过主选择任务。 -[#4753] 使用 SafeConstructor 解析 yaml 配置。 -[#4762]命名健康检查线程数支持用户自定义。 -[#4770] Beta发布：更改选择betaIps的方式，从输入改为选择。 -[#4778] 使 SecurityProxy.accessToken 在单写入器多读取器中线程安全。 -[#4903] 为登录页面添加安全提示。 -[#4917] Raft ops 接口添加身份验证。 -[#4980] Log4J2NacosLogging.loadConfiguration() 当位置为空时直接返回。 -[#5010]修复TemplateUtils的使用。 -[#5190]添加登录失败时的一些提示日志。 -[#5234]解决当发布配置请求正在处理时页面可以编辑的问题。 -[#5331]修复鼠标在指针状态下悬停在页边距上且无法clicked的问题。 -[#5350]添加一致性状态Down的提示和详细原因。 -[#5439]支持client指定命名UDP推送端口。 -[#5434]优化ConfigType.isValidType方法。

重构和代码质量

-[#3779] 检查 groupName 不能为空。 -[#4661] ConfigServletInner#doGetConfig 代码优化。

错误修复

-[#3610] 修复新配置页面中按 F1 全屏问题。 -[#3876]修复推送空服务名称。 -[#4306]修复按组搜索服务错误问题。 -[#4573,#4629] Jraft 领导者状态检查错误。 -[#4672]修复克隆配置丢失描述的问题。 -[#4699]修复元数据批量操作可能删除实例的问题。 -[#4756] 修复配置列表排序和搜索问题。 -[#4787] 如果解析主机抛出 UnknownHostException，则丢失成员。 -[#4806]修复addListener方法注释。 -[#4829] 当发行版和 raft 删除实例数据时删除实例。 -[#4852]修复main.js太大的问题。 -[#4854]修改标头以支持按键忽略大小写。 -[#4898]修复实例列表页面错误。 -[#4925]修复成员列表更改将覆盖成员状态和元数据的问题。 -[#5078]修复多次查询订阅者列表数据结果不一致的问题。 -[#5026] 修复 MetricsHttpAgent 指标两次。 -[#5018]检查groupKey中的组和dataId。 -[#5114] ConcurrentHashSet.java 与 jdk1.6 或 1.7 不兼容。 -[#5253] 修复缺少身份验证身份标头错误。 -[#5291] 修复 Beat 任务在抛出意外异常时停止的问题。 -[#5301]响应istio的各种集合请求。 -[#5351] 修复 Jraft 选举后一致性状态无法切换为 UP 的问题。 -[#5390] 修复 ip 验证错误。 -[#5427] 如果 CurcuitFilter 中 Jraft 领导者为空，则修复 NPE。 -[#5437]修复配置测试功能会丢失转储事件的问题。 -[#5451]修复标签无法删除的问题。

其他

-[#4822][#4823][#4824][#4825][#4979][#5506]修复依赖安全问题。 -[#5277] 订阅者列表服务器名称添加为必填项。 -[#5380][#5418]添加和增强单元测试。
