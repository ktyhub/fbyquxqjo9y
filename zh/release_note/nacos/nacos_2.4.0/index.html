nacos 2.4.0

小版本 发布时间2024年7月19日 来源alibaba/nacos 英文原文

nacos 2.4.0

变更流程图

亮点

  • 别用这个 tag——请上 2.4.0.1 — 发布说明开头就写着”Please use 2.4.0.1 first”；2.4.0 明确不是推荐目标，补丁版本就是为了修它的问题，因此升级应直接到 2.4.0.1。已在更高 2.4.x 补丁版本上的用户，本版本等同于空操作。

  • 破坏性变更：移除默认 nacos 密码、derby ops API 默认关闭 — #11957 移除用户 nacos 的默认密码，维护者必须在首次启动时初始化管理员密码，而不能依赖已知默认值。#12372 默认禁用 derby ops API（可通过 nacos.config.derby.ops.enabled=true 重新开启）。依赖默认凭据或该 API 的部署脚本和单机环境需要更新。

  • 安全加固——暴露在公网/多节点部署值得升级 — 新增集群节点间可选的 TLS gRPC（#11456），把 TLS 从客户端—服务端扩展到节点间；accessToken 从 URL 中移除（#12221）；安全相关依赖升级到 Spring Security 5.7.12（#11904）、Spring Framework 5.3.34（#11980）和 grpc 1.64.2（#12369）。Nacos 面向公网或集群部署推荐升级；可信内网单机且不需要新特性的用户可以缓一缓。

  • 新的扩展与可观测性能力 — 命名模块支持在 Subscriber 回调前自定义 Selector，并新增服务差异事件以减少缓存和比对开销（#10374）；Prometheus SD 支持把元数据作为标签（#12130）、修复非法标签名（#12196）并新增 ConfigDump 开销指标（#12355）；新增阿里云 RAM v4 签名（#12162）和 RAM 信息开关（#12382）。控制台新增 CAS 配置发布（#11847）、导入/克隆的用户与操作人记录（#11943、#12180）以及分页总数统计（#12178、#12246）。依赖这些集成的场景应升级。

  • 需规划的 schema 与客户端变更 — #10639 将 encrypted_data_key 改为 text 类型，说明中警告旧版本无法直接升级，需要规划迁移路径；#12197 为 roles 和 permissions 表新增 id 主键列。客户端侧日志重构为通过 SPI 加载 logger 适配器（#11956），自定义适配器可能需要调整。值得注意的修复还有磁盘满自我保护（#11926）和磁盘故障转移数据源状态保留（#12207）。

请先使用2.4.0.1 该版本是一个重要的版本，支持许多新功能。 最重要的功能是Nacos支持维护者初始化admin用户nacos密码而不是使用默认密码，以提高部署nacos集群的默认安全性。 另一件事是默认禁用德比操作 API，以防止在独立模式下部署时未启用身份验证的用户出现有关相应风险的误报。如果维护人员想使用这个API在derby中维护和查询数据，维护人员可以使用nacos.config.derby.ops.enabled=true打开这个API。 其他主要功能是支持 Nacos 集群节点之间的 TLS Grpc 通信作为可选功能，以提高 Nacos 的安全性，这意味着 nacos 不仅支持 client 与服务器之间的 TLS 通信；更重要的是，Nacos开始支持用户在命名模块回调Subscriber之前扩展Selector，不仅可以通过健康和集群来选择服务实例。 Nacos client 支持通过新事件区分回调服务，以减少 Subscriber 缓存和比较逻辑。 第三个主要功能是支持Nacos控制台中的一些配置用法，并支持插件的更多增强用法，例如支持将所有元数据添加到prometheus sd协议以及支持aliyun ram v4签名。 除了实质性的功能更新外，该版本还修复了之前版本的一些错误，并升级了某些存在安全漏洞的依赖项。 详细见：

特点

[#10374] 支持命名自定义选择器并支持服务差异事件。 [#11456] 支持 Nacos 集群节点之间的 TLS Grpc 通信。 [#11847] Nacos 控制台支持使用 cas 发布配置。 [#11943] 记录导入配置的用户。 [#11957] 删除用户 nacos 的默认密码。 [#12130] 将元数据添加为 prometheus http sd 中的标签。 [#12162] 支持aliyun ram v4签名方式。

增强&重构

[#11956] 重构 nacos client 日志记录模块，使用 SPI 加载电流记录器适配器。 [#12013] 通过环境 CUSTOM_NACOS_MEMORY 增强在startup.sh中快速配置Nacos内存设置。 [#12072] 当 TotalCountLimit 小于 0 时，支持不会施加任何限制。 [#12166] 增强 nacos client 初始化属性记录器。 [#12177] 将控制台标题链接更新为新的 nacos.io。 [#12178] 添加分页显示总记录数。 [#12185] 在 CacheDirUtil 中使用 nacos 属性。 [#12221] 从 URL 中删除 accessToken。 [#12235] 增强 ResponseExceptionHandler 中的日志记录格式。 [#12246] 国际化配置列表和服务列表中总计数的显示。 [#12321] 增强 NetworkInterface.ifUp 中意外异常的日志。 [#12355] 在 Prometheus 中记录 ConfigDump 的成本。 [#12372] 默认禁用德比行动 api。 [#12382] 支持内存信息切换。

错误修复

[#10639] 修复 encrypted_data_key 为文本类型，旧版本无法直接升级。 [#11902] 修复 nacos-client 的 java 本机运行时的请求和响应泄漏。 [#11926] 修复 Nacos 在某些操作系统中磁盘已满时无法触发自我保护的问题。 [#11951] 修复删除空服务实例时 serviceName 和 groupName 解析不正确的问题。 [#11967] 修复 Window 操作系统下 dataId 包含特殊单词时 Config 无法发布和监听的问题。 [#11968] 修复多个配置更改插件实现配置冲突问题。 [#12022] 修复 nacos 数据源插件 ClassCastException 问题。 [#12046] 修复 cipher-aes 配置加密插件再次发布配置时不生效的问题。 [#12060] 修复禁用身份验证时 ttl 过大的问题。 [#12146] 修复删除操作类型回滚配置时不显示操作类型的问题。 [#12168] 修复权限控制-角色管理页面查询条件标签在系统语言切换为英文后仍显示中文的问题。 [#12180] 修复克隆和导入操作期间不记录操作员的问题。 [#12196] 修复 prometheus http sd 无效标签名称。 [#12207] 修复磁盘故障转移数据源不保持状态的问题。 [#12197] 将 id 主键列添加到角色和权限表中。 [#12219] 修复 nacos-client 中的 ServerListManager 无法解析配置中的端点的问题。 [#12253] 为配置和命名服务器列表管理器添加端点集群名称。 [#12265] 修复了没有 grpc 包的 nacos client 依赖关系树。 [#12323] 修复 nacos client logback 配置会覆盖打包数据的问题。 [#12333] 修复 auth Plugin 资源解析器无法解析 v2 配置 openAPI namespaceId。

依赖关系

[#11904] 将 Spring Security 升级为 5.7.12。 [#11975] 删除未使用的依赖 javatuple。 [#11980] 将 spring framework 转换为 5.3.34。 [#12135] 将模块 naocs-console 从 junit4 升级到 junit5。 [#12369] 将 grpc 升级到 1.64.2。
