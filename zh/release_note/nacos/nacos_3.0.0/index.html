nacos 3.0.0

大版本 发布时间2025年4月27日 来源alibaba/nacos 英文原文

3.0.0（2025 年 4 月 25 日） 该版本是3.0.0的GA版本。该版本中，Nacos基于Nacos3.0.0-BETA支持MCP(Model Content Protocol)管理。 在本次3.0.0 GA版本中，Nacos将进行以下重要的功能和更改：

  1. API分为不同类型，不同类型的API采用不同的默认认证策略。 2.启用nacos控制台认证，首次部署时需要更多配置。
  2. Nacos 控制台 UI 使用新的 v3 控制台 API 替换旧的 v1 API，并默认禁用旧的 v1 API 旧控制台 UI。
  3. 默认命名空间 public 将其 id 从“(empty string) to public”更改为“(empty string) to public”。 5.直接支持xDS协议。目前支持EDS、LDS、RDS、CDS。 6.将spring boot升级为3.4.1，并将jdk版本升级到17。 7.为Nacos 3.0添加ADMIN API系列，使维护人员和自定义控制台可以维护和获取Nacos的数据。
  4. 支持Nacos控制台独立部署，nacos服务器和nacos控制台部分配置发生变化，请检查applciation.properties以强制升级。 9.支持MCP（模型内容协议）管理。 10.支持实验性功能分布式锁。 11.支持实验性功能模糊监听服务和配置。 3.0.0的详细变化参见：
