nacos 2.2.1

修订 发布时间2023年3月17日 来源alibaba/nacos 英文原文

nacos 2.2.1

这个项目是干啥的：阿里开源的服务发现和配置管理中心，帮微服务互相找到彼此并统一管配置，支持gRPC和IPv6，给微服务团队用。

变更架构图

亮点

  • 移除安全默认值（破坏性——升级前先迁移） — token.secret.key 和 server.identity 不再带默认值（#10108，公告）。任何依赖内置密钥的集群升级后都会鉴权失败或拒绝启动；必须先在配置中显式设置 token.secret.key（以及用到时的 server.identity）。这是升级的首要理由——堵住已知的默认凭据暴露——但也意味着这是一次需要改配置、有计划的上线，而非直接替换的补丁。

  • 节点间流量改走 gRPC，TLS 处于 beta — #9949 把所有服务端之间的 HTTP 请求替换为 gRPC，#9888 新增 beta 版 gRPC TLS 支持；#9859 把默认鉴权插件改写为自定义 JWT 而非 jjwt，#9837 调整 gRPC 连接时序以加快快照加载。运维上这改变了节点间的端口/协议预期——整个集群要一起升级，并检查防火墙/代理和混合版本兼容性，尤其你基于 HTTP 的 nginx 方案已是已知痛点（#9819 修复 nginx 后的密码修改）。

  • 依赖刷新带来兼容性影响 — Spring Boot → 2.6.14（#9504/#9767）、gRPC → 1.50.2（#9772）、JRaft → 1.3.12（#9789）、SnakeYAML → 2.0（#10091）。这些带来安全/稳定性修复（单凭这点也值得升级），但尤其 SnakeYAML 2.0 是大版本跨越，可能让依赖旧构造 API 的代码出错——请验证自定义 YAML 处理。flatten-maven-plugin 也换成了 easyj-maven-plugin（#9985），仅对从源码构建 Nacos 的用户相关。

  • 新 API 与鉴权选项 — 按内容搜索配置（#9276）、目录 v2 API 列出未启用实例（#9703）、Prometheus SD 基础鉴权（#9710），以及命名的阿里云 STS 鉴权（#10062）。结合一批扎实的鉴权/正确性修复——distro 过滤前先做鉴权检查（#9861）、LDAP 登录（#9862）、Derby 上的 CAS 更新（#9943），以及开启鉴权后非管理员用户的配置权限（#9795）——开启鉴权或使用 Prometheus 发现的用户都值得升级。鉴权关闭、不需要这些特性的稳定集群可合理跳过；依赖默认密钥或跨节点 HTTP 的用户都应升级，但前提是先把配置准备好并做全集群滚动上线。

该版本主要是**特别删除了token.secret.key和server.identity的默认值。**详细信息参见：公告。 并且该版本升级了spring-boot、Grpc、jraft等许多依赖项。 此外，该版本添加了测试版功能，使grpc请求支持TLS，并修复了一些错误并增强了一些使用问题。 详细见：

功能

[#9276] 按内容添加搜索配置。 [#9703] 添加目录 v2 API 以支持未启用的列表实例。 [#9710] 支持 prometheus-sd 基本身份验证。 [#9888] Beta 支持 Grpc TLS 功能。 [#10062]命名支持阿里云STS认证。

增强&重构

[#9510] 添加sql日志打印功能。 [#9646] 用占位符替换连接的字符串。 [#9708] 清理 HTTP client 的过期和无效连接。 [#9783] 将公共命名空间 ID 处理为 V2 http api 的发布和查询配置的默认命名空间 ID。 [#9837] 增强集群开始快速加载快照时的 Grpc 连接时间。 [#9859] 重构默认身份验证插件，使用自定义 JWT 而不是 jjwt。 [#9860] 通过 SPI 调整 logback 1.4.5。 [#9885] 添加 prometheus api 异常处理。 [#9949] 使用 Grpc 替换服务器之间的所有 Http 请求。 [#9951]判断消息是否为null元数据处理器。 [#10084] Client 使用异步附加程序打印日志。 [#10108] 删除身份默认值。

错误修复

[#9621] 修复 Config Client 服务器检查始终启动的问题。 [#9728] 修复 prometheus http sd 仅返回公共命名空间问题。 [#9732] 修复命名空间 v2 api 身份验证不起作用的问题。 [#9734] 修复 http 登录 url 无默认端口问题。 [#9795] 修复非管理员用户打开 auth 后导出配置失败的问题。 [#9816] 修复并发注册和注销服务时重做数据与服务器不同的问题。 [#9819] 修复使用 nginx 后更新密码失败的问题。 [#9825] 修复配置历史页面分页问题。 [#9861] 修复发行版过滤器之前的身份验证检查。 [#9862] 修复 LDAP 登录失败的问题。 [#9943] 修复使用 derby 数据库时 Config cas 更新无法工作的问题。 [#10014] 清除有关命名空间属性的混乱逻辑。 [#10038] 修复加载故障转移文件失败的问题。

依赖关系

[#9504][#9767] 将 spring-boot 版本升级到 2.6.14。 [#9789] 将 jraft 版本升级到 1.3.12。 [#9772] 将 Grpc 版本升级到 1.50.2。 [#9985] 将 flatten-maven-plugin 替换为 easyj-maven-plugin。 [#10091] 将snakeYaml升级到2.0。
