nacos 2.0.0-bugfix

大版本 发布时间2021年3月30日 来源alibaba/nacos 英文原文

nacos 2.0.0-bugfix

变更流程图

亮点

  • ThreadPool 修复（#5233、#5237）——发版的主因 — 修复错误的 ThreadPool 用法，该问题会导致 Nacos 服务发现失效、在低性能机器上拒绝请求。如果你在 2.0.0 上发现负载高时或小实例上发现请求被丢弃，这正是针对性修复；本版本就是为这个 bug 发的。

  • Distro 同步数据完整性（#5169） — 防止 distro 同步任务失败时实例被非负责节点误删。运行 AP/distro 复制的集群用户应升级，因为此前一次瞬时同步失败就可能导致服务实例被无端移除。

  • 分页查询修复（#5204） — 修正 pageNo 超过服务总数时的查询错误。严重程度低，但如果你的工具或 UI 会翻服务列表并可能请求越界页，就有关系。

  • 升级建议 / 破坏性变更 — 未提及破坏性变更、API 变更或迁移步骤，是对 2.0.0 的直接替换补丁。所有 2.0.0 用户都值得升级——尤其是在受限硬件或集群部署上；只有不在 2.0.0 或不依赖服务发现/distro 同步的用户可安全跳过。这是真正的 bug 修复版本，不是空操作或纯元数据换标签。

该版本主要修复了Threadpool使用问题，在低性能机器环境下，该问题会导致nacos服务发现无法按预期工作并拒绝请求。 此外，此版本还修复了一些简单的错误。 详细见： [#5233][#5237] 修复 ThreadPool 使用问题。 [#5169] 当发行版同步任务失败时，实例可能会被不负责任的服务器删除。 [#5204] 修复 pageNo 大于服务号时查询错误的问题。
