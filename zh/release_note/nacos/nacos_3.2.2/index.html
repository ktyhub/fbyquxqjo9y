nacos 3.2.2

修订 发布时间2026年5月29日 来源alibaba/nacos 英文原文

变更流程图

亮点

  • AI 注册表与 Skill 生命周期 — 3.2.2 的重头戏：现在可以从运维配置的外部注册表导入 AI 资源（MCP、Skill well-known、SPI 模型、内置预设、基于来源的导入 UI）[#15183]，注册表适配器支持最新 Skill well-known 协议 [#15247]，并改进可配置性与 Skill 上传（拖拽 ZIP + 批量上传 [#15142]、目标版本 [#14907]、提交信息 [#15234]、审核后可选自动发布 [#15022]）。注意 AgentSpec 订阅被重构为 HTTP 轮询并处理 304 [#15263]——对依赖旧订阅传输的东西来说是行为变化。
  • 迁移/破坏性变更 — LDAP 鉴权现在拆成可选插件并自带打包 JAR [#14911]，所以现有 LDAP 用户升级后必须部署/配置该插件；nacos.functionMode 扩展了 microservice 和 ai 模式 [#15031]，AI 发布流水线现在默认启用 reviewed 状态 [#15258]/[#15059]。更严格的校验可能拒绝以前接受的内容：AgentSpec ZIP 的 Zip Slip/Zip Bomb/条目数防御 [#15066]，条目/大小限制可配 [#15164]，Markdown 正文必须是非 frontmatter [#14983]，forcePublish 限制为合法 Skill 状态 [#15145]，非 draft 版本的提交请求被拒 [#15192]。
  • 正确性与稳定性修复 — 值得有的集群/客户端修复：v3 Naming API 加入 DistroFilter，让客户端实例注册/注销在集群中可用 [#14992]；MemoryMcpCacheIndex#removeIndex 缺写锁 [#15067]；模糊监听防止丢失/虚假唤醒 [#15228]；DiskUtils 分块边界保留多字节 UTF-8 [#15073]，未列出的 AI 资源加 base64 回退 [#15162]；修复 PostgreSQL 租户为 null 时配置同步行爆炸 [#15150]、group_id LIKE 占位符缺失 [#15000]、OIDC 插件 NoClassDefFoundError（通过 shade Caffeine）[#14774]，以及用 sh 调用时启动脚本在 bash 下重执行 [#15171]。
  • 控制台体验 — 新 Console 加入配置发布 diff 确认 [#15138] 和 Prompt Markdown 下载 [#14848]、持久化实例注销 [#14985]，并修复命名空间上下文 [#15152]/[#15252]、主题色 RGB 回退 [#14882]、历史/回滚/比较的拒绝访问错误 [#15037]、MCP 编辑器对 object 类型工具输入的回归 [#15207]，以及 Skill 卡片溢出 [#15240]。这些只影响 UX，不影响服务端行为。
  • 升级结论 — 这是 bugfix/体验改进版本，不是重新打标或纯元数据变更；Java 要求不变（服务端/控制台 Java 17，客户端 8）。在 3.2.x 上的应升级——尤其是 AI 注册表/MCP/Skill 用户（新导入、订阅和审核流程）、集群 Naming 部署，以及碰到上述具体 bug 的人；LDAP 用户必须把插件迁移算进去。依赖升级（PostgreSQL JDBC 42.7.2→42.7.11 [#15039]、Micrometer 1.15.10 [#15060]，以及供应链加固 [#15087]/[#15148]）也让它成为合理的安全补丁。不在 3.2.x、不用受影响特性且没碰到那些痛点的可以放心跳过。

Nacos 3.2.2 主要是 3.2 系列的 bugfix 和体验改进版本。

本版本聚焦：

  • 改进 Config、Naming、MCP、Skill、AI 资源和命名空间工作流的控制台体验。
  • 修复 Config、Naming、插件、启动脚本和 AI 资源处理的稳定性与兼容性问题。
  • 改进 AI 注册表导入、发现、发布、订阅和安全。

对 AI 注册表和控制台用户，本版本新增或改进：

  • 从运维配置的外部注册表导入 AI 资源。
  • Skill well-known 发现、Skill 订阅和最新协议适配器支持。
  • 配置 diff 确认、Prompt Markdown 下载，以及 Skill 上传生命周期改进。

还修复 Config、Naming、Console、MCP、Skill、插件和客户端 watch 处理中的 bug。

本版本的详细变更：

Nacos 3.2.2 主要是针对 3.2 系列的 bug 修复和体验提升版本。 此版本重点关注：

  • 配置、命名、MCP、技能、AI 资源和命名空间工作流程的控制台体验改进。
  • 修复了配置、命名、插件、启动脚本和 AI 资源处理的稳定性和兼容性。
  • AI 注册表导入、发现、发布、订阅和安全性改进。 对于 AI Registry 和控制台用户，此版本添加或改进了：
  • 从运营商配置的外部注册表导入人工智能资源。
  • 技能知名发现、技能订阅、最新协议适配器支持。
  • 配置差异确认、提示 Markdown 下载和技能上传生命周期改进。 它还修复了配置、命名、控制台、MCP、技能、插件和 client 端手表处理中的错误。

此版本的详细变化：

特点

[#14695] 支持配置灰色规则的基于标签的匹配。 [#14848] 添加提示版本下载为 Markdown。 [#14907] 支持上传技能时指定目标版本。 [#14985] 在 Console v3 中添加持久实例取消注册支持。 [#15022] 支持可选技能审核后自动发布。 [#15031] 使用微服务和 AI 模式扩展 nacos.functionMode。 [#15142] 支持拖放 ZIP 上传和批量技能上传。 [#15183] 支持从运营商配置的外部注册表导入 AI 资源，包括 MCP 资源、技能知名资源、导入器 API、SPI 模型、内置预设和基于源的导入 UI。 [#15234] 支持上传 AI 技能时提交消息。 [#15247] 支持注册表适配器中最新的 Skill 知名协议。 [#15263] 添加 Skill 订阅支持，并通过 304 处理将 AgentSpec 订阅重构为 HTTP 轮询。

增强/重构

[#14833][#15221] 通过跟踪事件和默认插件路由 AI 资源版本跟踪日志记录。 [#14911] 将 LDAP 身份验证拆分为可选插件并将 LDAP 插件 JAR 打包。 [#14983] 在技能验证期间强制执行非 frontmatter Markdown 正文内容。 [#15059] 在技能版本的管道批准后添加已审核的版本状态。 [#15066] 使用 Zip Slip、Zip Bomb 和条目计数防御强化 AgentSpec ZIP 解析。 [#15138] 在新控制台中添加配置发布差异确认。 [#15145] 将强制发布限制为有效的技能状态并添加管道陈旧标志以进行重新编辑。 [#15164] 使技能 ZIP 条目和大小限制可配置。 [#15165] 并行化 AgentSpec 存储写入以与 Skill 行为保持一致。 [#15258] 默认情况下为 AI 发布管道启用已审核状态。

错误修复

[#11122] 接受 healthCheckEnabled 作为命名开关条目别名。 [#14774] 将 Caffeine 隐藏到 OIDC 插件 JAR 中以避免 NoClassDefFoundError。 [#14882] 通过添加 RGB 后备修复控制台主题颜色丢失。 [#14952] 修复了 restToMcp 开关关闭时不正确的 MCP 协议值。 [#14992] 将 v3 命名 API 添加到 DistroFilter 以修复集群中 client API 实例注册和注销问题。 [#14997] 在上传和下载过程中保留 SKILL.md 缩进并验证技能版本。 [#15000] 在 BaseConfigInfoMapper 中添加缺少的 group_id LIKE 占位符。 [#15004] 将已弃用的 AccessControlException 用法替换为 SecurityException。 [#15037] 修复控制台历史记录详细信息、回滚和比较页面上的访问被拒绝错误。 [#15067] 修复 MemoryMcpCacheIndex#removeIndex 中丢失的写入锁。 [#15073] 跨 DiskUtils 块边界保留多字节 UTF-8 字符。 [#15136] 修复密码修改对话框显示。 [#15141] 修复命名空间 ID 缺失时的命名空间描述编辑问题。 [#15150] 防止 PostgreSQL 租户 null 导致配置同步行爆炸。 [#15152] 修复命名空间切换后配置页面显示不匹配的问题。 [#15160] 修复了 srcType 缺失时 ConfigChangeAspect 将控制台配置更改错误分类为 RPC 的问题。 [#15162] 默认未列出的 AI 资源为 base64，以避免 UTF-8 损坏。 [#15167] 修复控制台控制器与请求上下文路径的映射。 [#15171] 当通过 sh 调用时，在 bash 下重新执行启动脚本。 [#15192] 拒绝提交非草稿 AI 资源版本的请求以保护正式版本状态。 [#15201] 修复上传新版本后技能描述列表与详情不一致的问题。 [#15207] 修复对象类型工具输入字段的 MCP Console 编辑器回归。 [#15228] 保护模糊监视 future 免受丢失和虚假唤醒的影响。 [#15240] 接下来修复控制台中长技能名称的技能安装卡溢出问题。 [#15252] 保留控制台 AI 资源页面上的命名空间上下文。

依赖关系

[#15039] 将 PostgreSQL JDBC 驱动程序从 42.7.2 升级到 42.7.11。 [#15060] 将 Micrometer 升级到 1.15.10 以修复 Prometheus 端点。 [#15087] 升级 Nacos 服务器映像报告的易受攻击的依赖项并启用默认 AI 导入器。 [#15148] 添加 console-ui-next npm min-release-age 策略以确保供应链安全。
