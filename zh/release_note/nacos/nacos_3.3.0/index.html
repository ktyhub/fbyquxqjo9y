nacos 3.3.0

这个项目是干啥的：阿里开源的服务发现和配置管理中心，帮微服务互相找到彼此并统一管配置，支持gRPC和IPv6，给微服务团队用。

变更架构图

亮点

  • AI 注册表与生命周期管理 — Nacos 新增协议无关的 Agent 管理，以及覆盖草稿、审核、发布、上下线和可见性的共享 MCP 生命周期，并提供 Java SDK 和控制台支持。ARD Search 加入关键词/向量混合检索、制品访问、持久化索引和可选的 Jev 相关性过滤。技能上传现在自动发布首个版本，并在服务端管理保留的 latest 标签；历史 MCP 对账保留已有 Config/Naming 服务数据。对正在整合 Agent、MCP 和 Skill 工具的团队意义重大。
  • DNS 发现与分布式锁 — 可选 DNS 发现通过 UDP 和 TCP 提供 A、AAAA、SRV 记录，带指标和可配置的外部 DNS 转发，让标准 DNS 客户端能发现 Nacos 服务。分布式可重入/非可重入锁加入看门狗续期、FIFO 等待、gRPC 通知、Raft 一致性和 Java Lock SDK，为集群应用提供另一种协调选项。
  • 默认值变化与迁移检查 — 客户端 API 鉴权默认开启，现有客户端上线前必须配置鉴权。部分弃用的 Pipeline 和 MCP 导入 API 默认禁用；请迁移调用方或显式开启共享的临时兼容开关。必需的 Prometheus 客户端依赖被可插拔的客户端指标 SPI 取代，默认 no-op，所以要确认你的指标实现已注册。自定义内嵌数据库查询被限制为支持的标量类型和已注册的行映射器。
  • 运行时、SDK 与可靠性改进 — 统一动态插件管理支持运行时更新和可扩展的可见范围。兼容性扩展到 Spring Boot 4、Jackson 2 和 Jackson 3、可选的 Spring AOT/GraalVM 初始化，以及 Linux RISC-V64 上的 RocksDB JNI 加载。Config SDK 请求/结果方法、加密 Config CAS 发布和复用缓存的条件查询改善配置工作流；Config 缓存/并发、Naming 重连/重启、Prompt 可见性和无效 Bearer token 处理等修复减少陈旧数据和访问控制失败。
  • 升级建议 — 这是实质性稳定特性版本，不是重新打标。如果你需要 Agent/ARD/MCP/Skill 管理、DNS 发现、分布式锁、运行时插件管理、更新的运行时兼容性，或上面列出的 Config/Naming/安全修复，就升级。只用 Config/Naming 的部署，如果那些改进不解决当前需求，可以推迟；但任何升级都应围绕上面的鉴权、弃用 API、指标默认值和内嵌数据库兼容性检查分阶段进行。

Nacos 3.3.0

Nacos 3.3.0 是 Nacos 3.x 系列的特性迭代版本。它把协议无关的 Agent 管理与发现、共享 AI 资源搜索和统一的 MCP 生命周期管理带入稳定版。

本版本聚焦：

  • 覆盖 Agent、AgentSpec、Skill、Prompt 和 MCP 资源的 AI 注册表能力。
  • DNS 服务发现与分布式锁。
  • 动态插件管理和默认开启的鉴权。
  • Spring Boot 4 与 Jackson 3 兼容性，并改进客户端和服务端可靠性。

主要特性更新包括：

  • 通过 Java SDK 和控制台工作流实现 Agent 注册、版本管理、运行时端点、RAD 发现、传输协商以及 Watch/Push。
  • 共享 AI 资源搜索，支持关键词与向量混合检索、制品访问和可选相关性过滤。
  • MCP 草稿、审核、发布、上下线和可见性管理，并支持历史资源迁移。
  • 可选 DNS 发现，通过 UDP 和 TCP 提供 A、AAAA、SRV 记录。
  • 分布式可重入与非可重入锁，带看门狗续期和 Raft 一致性。

稳定版还改进了 Skill 元数据在版本切换间的一致性，扩展可见性插件能力，并增强 Config SDK 易用性、控制台兼容性，以及 Naming 重连和集群重启后的恢复能力。

这些发布说明是累积的，包含 3.3.0-BETA 和 3.3.0-RC 中交付的改动。

#Nacos 3.3.0

Nacos 3.3.0 是 Nacos 3.x 系列的功能迭代版本。它为稳定版本带来了协议中立的 Agent 管理和发现、共享 AI 资源搜索以及统一的 MCP 生命周期管理。

此版本重点关注：

  • 跨 Agent、AgentSpec、Skill、Prompt 和 MCP 资源的 AI 注册表功能。
  • DNS服务发现和分布式锁。
  • 默认情况下启用动态插件管理和身份验证。
  • Spring Boot 4 和 Jackson 3 兼容性，改进了 client 和服务器可靠性。

主要功能更新包括：

  • 代理注册、版本管理、运行时端点、RAD 发现、传输协商以及通过 Java SDK 和控制台工作流程进行监视/推送。
  • 共享人工智能资源搜索，具有混合关键字和向量检索、工件访问和可选的相关性过滤。
  • MCP起草、审核、发布、在线/离线和可见性管理，并支持历史资源迁移。
  • 可选的 DNS 发现，通过 UDP 和 TCP 进行 A、AAAA 和 SRV 记录。
  • 具有看门狗更新和 Raft 一致性的分布式可重入和不可重入锁。

该稳定版本还提高了跨版本转换的技能元数据一致性，扩展了可见性插件功能，并增强了 Config SDK 的可用性、控制台兼容性以及命名重新连接和集群重新启动后的恢复。

这些注释是累积性的，包括 3.3.0-BETA 和 3.3.0-RC 中提供的更改。
