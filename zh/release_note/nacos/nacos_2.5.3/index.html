nacos 2.5.3

nacos 2.5.3

这个项目是干啥的：阿里开源的服务发现和配置管理中心，帮微服务互相找到彼此并统一管配置，支持gRPC和IPv6，给微服务团队用。

变更架构图

亮点

  • 安全依赖更新（Java 8 基线不变） — 内嵌 Tomcat 升到 9.0.118（#13998、#14859）以关闭已知 Tomcat CVE，同时 Jackson 升到 2.18.9、gRPC Java 升到 1.75.0、Spring Security 升到 5.8.16（#15025、#15451）。v2.x 线刻意不引入 Spring Boot 3、Spring Framework 6 及其他仅支持 JDK 17+ 的升级；服务端/控制台和客户端仍要求 Java 8，所以不强制升级运行时。
  • 配置命名空间隔离修复（#15497） — 按 ID 导出、批量删除和克隆现在遵守命名空间边界，克隆请求还会校验对源命名空间的读权限。这是真正的跨命名空间数据暴露修复：依赖命名空间隔离的多租户部署应升级，否则调用方可以导出、删除或克隆本命名空间之外的配置。
  • 客户端稳定性（#15437、#13940） — #15437 修复 ConfigRpcTransportClient 及相关客户端组件的关闭线程泄漏和执行器创建竞态；#13940 采用安全的 Log4j2 初始化，避免 Log4j2 配置重载时持续类卸载。对做动态配置/log4j 重载的长驻客户端最重要——泄漏和 classloader 抖动都会减少。
  • 服务端校验与日志行为 — #14423 让服务端在表单参数超过配置的 Tomcat 请求大小限制时抛异常，而不是静默错误处理。#12323 让 Logback 的 packagingData 可通过 nacos.logback.packagingData 配置（默认 false），并把外部 Logback 适配器升到 1.1.5——注意 false 相对之前开启的状态是行为变化，如果日志里依赖 packaging data，请显式设为 true。
  • 升级建议 / 破坏性变更 — 无破坏性 API 变更、无 JDK 提升，也不是空操作/重新打标——这是实打实的 bugfix 和安全版本。推荐所有 2.5.2 用户升级，尤其是重视安全或多租户的；上线前唯一要核实的是 nacos.logback.packagingData 默认翻转为 false。没有多租户隔离需求、也不涉及受影响路径的团队可以合理跳过或推迟。

Nacos 2.5.3 主要是 2.x 系列的 bugfix、安全和体验改进版本。

本版本聚焦：

  • 与 v2.x JDK 8 基线兼容的安全依赖升级。
  • 客户端稳定性与日志改进。
  • 配置命名空间隔离修复。
  • 服务端请求校验改进。

同时保持不兼容的主版本依赖线不进入 v2.x，例如 Spring Boot 3、Spring Framework 6 以及其他仅支持 JDK 17+ 的升级。

本版本的详细变更：

Nacos 2.5.3 主要是针对 2.x 系列的 bug 修复、安全和体验提升版本。 此版本重点关注：

  • v2.x JDK 8 基线的兼容安全依赖项升级。
  • Client 稳定性和日志记录改进。
  • 配置命名空间隔离修复。
  • 服务器端请求验证改进。 它还将不兼容的主要依赖项保留在 v2.x 之外，例如 Spring Boot 3、Spring Framework 6 和其他仅适用于 JDK 17+ 的升级。

此版本的详细变化：

特点

没有重大功能变化。

增强/重构

[#12323] 通过使用默认的 false 通过 nacos.logback.packagingData 进行配置，改进了 Logback packagingData 行为，并将外部 Logback 适配器升级到 1.1.5。

错误修复

[#13940] 使用安全 Log4j2 初始化修复 Nacos Client Log4j2 配置重新加载期间的连续类卸载。 [#14423] 修复表单参数超出配置的 Tomcat 请求大小限制时丢失的异常。 [#15437] 修复 ConfigRpcTransportClient 和相关 client 组件中的 client 关闭线程泄漏和执行程序创建竞争条件。 [#15497] 修复基于 ID 的导出、批量删除和克隆操作的 Config 命名空间隔离，并强制克隆请求的源命名空间读取权限。

依赖关系

[#13998][#14859] 将嵌入式 Tomcat 升级到 9.0.118 以解决已知的 Tomcat CVE。 [#15025][#15451] 升级兼容的 v2.x 依赖项，包括 Jackson 到 2.18.9、gRPC Java 到 1.75.0、Spring Security 到 5.8.16，同时保留 JDK 8 基线。
