该版本主要修复了一些Jraft请求处理过程中可能出现的任意文件读写的问题。 该漏洞仅影响端口7848（默认），该端口通常用作Nacos集群间协议的通信端口，不处理client请求。因此，可以通过在旧版本中禁用来自 Nacos 集群外部的请求（例如通过限制或不公开端口）来控制风险。 此外，该版本还对Derby Ops API进行了进一步优化，默认限制了Derby数据库可执行的SQL命令范围，从而降低了用户访问Derby Ops API时的风险。 请参阅以下更改的详细信息：

亮点

  • 关键安全修复 — 修复处理部分 Jraft 请求时的任意文件读写问题。默认暴露在 7848 端口，该端口通常用于集群间 Raft 通信而非客户端请求。若该端口对可信集群之外可达，请尽快升级；旧版本可通过禁止外部访问止血，但不能替代升级修复。

  • Derby Ops 加固——行为变更 — Derby Ops API 现在默认限制可执行的 SQL 类型，降低开启该管理接口后的风险。依赖此前允许的 SQL 的自动化脚本可能失败，升级前请检查这些查询。changelog 未说明具体允许的类型，也没有覆盖开关。

  • 潜在破坏性变更 — KvStorage 和 ConsistencyService 被移除（#12489）。引用这些组件的扩展或插件必须更新，但本版本未给出替代方案或迁移路径。

  • 运维改进 — 新增服务/实例元数据长度上限的可配置能力、控制台命名空间选择器、LDAP 插件的自定义默认管理员密码、默认鉴权插件退出登录时的 auth_basic 支持，以及 token.secret.key 非 base64 时更清晰的警告。主要对用到相应特性的部署有意义。

  • 升级评估 — 还修复了跨命名空间持久实例健康检查、指标内存计算、空连接控制规则解析、beta/正式配置不匹配提示以及 Hessian 依赖冲突。多数用户应因安全修复而升级；只有 7848 严格隔离、Derby Ops 关闭、且不依赖被移除组件或受影响行为的部署，才适合在常规维护窗口里延后。

特点

增强&重构

[#11887] 添加 token.secret.key 不是 base64 时的一些提示。 [#12311] 增强控制台以支持带有选择器的命名空间列表。 [#12405] LDAP 插件默认支持自定义管理员用户密码。 [#12446] 增强在默认身份验证插件中获取 Mac 实例时出现错误时的提示。 [#12466] 增强了可配置的服务元数据和实例元数据长度。 [#12477] 增强默认身份验证插件以在注销时支持 auth_basic。 [#12489] 删除 KvStorage 和 ConsistencyService。 [#12490] 增强 derby 模式以支持限制 SQL 类型。

错误修复

[#12301] 修复不同命名空间的持久实例的 headlth 检查，但 groupName 和 serviceName 相同。 [#12374] 修复指标 api 的内存计算错误。 [#12397] 修复解析空连接控制规则问题的 bug。 [#12410] 修复 beta 配置内容与正式内容不相等时没有提示的问题。

依赖关系

[#12342] 解决 Hessian 包冲突。
