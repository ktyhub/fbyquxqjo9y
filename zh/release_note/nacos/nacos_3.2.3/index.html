nacos 3.2.3

修订 发布时间2026年7月14日 来源alibaba/nacos 英文原文

nacos 3.2.3

变更流程图

亮点

  • 配置隔离与 PostgreSQL 升级修复 — #15498 将基于 ID 的配置导出、批量删除和克隆操作限定在命名空间内：这是实打实的行为变更，此前用 ID 跨命名空间操作的自动化现在会被限制在单个命名空间。另外 #15275 把 pg-upgrade-null-tenant-id.sql 复制到 distribution/conf，避免 PostgreSQL Docker 升级在启动时失败——如果你在 Docker 里跑 3.2.x + PostgreSQL 并计划升级，这条很关键。

  • AI Registry / MCP / Skill / A2A 数据完整性 — #15359 修复删除版本会破坏版本聚合、导致 A2A/MCP 查询失败的问题——属于数据完整性修复：如果在 3.2.2 上删过 AI Registry 版本，升级后请校验聚合数据。现已支持上传嵌套 Skill 包并保留嵌套 SKILL.md 作为资源（#15143、#15463）；#15428 保留发布后 MCP 端点 URL 中的查询参数，#15430 在自动生成的端点 spec 中保留 transportProtocol，#15265 修复 skillName 以连字符开头或结尾时的 Skill 列表模糊查询，#15229 对 A2A agent 的空名称做归一化。

  • 命名校验与客户端稳定性 — #15305 拒绝 Naming 注册中的空白实例 IP（行为变更：注册空 IP 的客户端现在会被拒绝）。#15032 修复 TCP 健康检查 SocketChannel 泄漏并强制成员 IP 精确匹配，#15321 在订阅者通知后异步刷新客户端磁盘缓存，#12585 修复 ? 占位符分页参数绑定。遇到 fd 泄漏或客户端缓存问题的部署值得升级。

  • 可观测性与新版控制台 — 新增按 Raft 分组的 leader 状态和 term 指标（#12737、#12867），集群诊断更细粒度。新版控制台修复：Config 克隆目标 Data ID/group 可编辑（#15355）、Config 历史对比内容为空（#15350）、AI 资源版本差异展示（#15435）、MCP 服务选择器分页（#14693）和侧边栏布局（#15354）；#15442 汇总 console-ui-next 依赖修复并重建静态资源。

  • 升级结论 — 不是空操作或换标签：这是一次有实质内容的 bug 修复与体验汇总，没有强制迁移步骤，Java 要求不变（Server/Console 为 Java 17；Client 和 Maintainer-Client 为 Java 8）。使用 PostgreSQL-in-Docker 升级、AI Registry/MCP/Skill/A2A 工作流，或需要 Naming/客户端及 Raft 指标修复的用户应升级；仍在 3.2.2、没有这些负载且不急于要控制台改进的用户可安全跳过。

Nacos 3.2.3 主要是针对 3.2 系列的 bug 修复和体验提升版本。 此版本重点关注：

  • 改进 AI 注册表、技能、MCP 和下一个控制台工作流程。
  • 修复配置命名空间隔离、命名验证和 client 稳定性问题。
  • 提高可观察性并释放依赖卫生。 它还修复了配置、命名、AI 注册表、A2A、MCP、Client、Core 和 Console 中的错误。

此版本的详细变化：

特点

  • #15143 #15463 支持嵌套技能包上传并将嵌套 SKILL.md 文件保留为资源。

增强/重构

  • #12737 #12867 添加每个 Raft 组领导者状态和术语指标。
  • #15321 在订阅者通知后异步刷新 client 磁盘缓存。
  • #15322 对齐 Logback 适配器 packagingData 配置。
  • #15354 调整下一个控制台侧边栏菜单元素。
  • #15435 改进下一个控制台中的 AI 资源版本差异显示。

错误修复

  • #12585 修复分页参数绑定，以便 ? 占位符正常工作。
  • #14036 在 HTTP 登录处理中支持 HTTPS/TLS 前缀。
  • #14693 修复控制台中的 MCP 服务选择器分页。
  • #15032 修复 TCP 运行状况检查 SocketChannel 泄漏和精确的成员 IP 匹配。
  • #15229 规范列表查询中的空 A2A 代理名称。
  • #15265 当 skillName 以连字符开头或结尾时允许技能列表模糊查询。
  • #15275 将 pg-upgrade-null-tenant-id.sql 复制到 distribution/conf 以防止 PostgreSQL Docker 升级启动失败。
  • #15296 实例在线/离线切换后更新服务详细状态。
  • #15305 拒绝命名注册中的空白实例 IP。
  • #15350 修复下一个控制台中空的配置历史比较内容。
  • #15355 恢复可编辑的配置克隆目标数据 ID 和组字段。
  • #15359 修复 AI 注册表版本删除破坏版本聚合并破坏 A2A/MCP 查询的问题。
  • #15428 发布后保留 MCP 端点 URL 中的查询参数。
  • #15430 在自动构建的 MCP 端点规范中保留 transportProtocol。
  • #15498 按命名空间进行基于范围 ID 的配置导出、批量删除和克隆操作。

依赖关系

  • #15442 汇总 console-ui-next 依赖项修复并重建下一个控制台静态资源。

Java 版本要求

模块 需要 Java
Nacos-服务器/Nacos-控制台 Java 17
Nacos-Client Java 8
Nacos-维护者-Client Java 8
