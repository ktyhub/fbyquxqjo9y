nacos 3.1.2

变更流程图

亮点

  • 安全依赖 — Spring Boot 升到 3.4.10 以修复 CVE-2025-55752，org.apache.logging.log4j:log4j-core 从 2.24.3 升到 2.25.3，gRPC 升到 1.78.0。对安全策略敏感的部署应优先打这个补丁。
  • AI/MCP 可靠性 — 同名重建 MCP 服务器不再留下缓存索引不一致；修复缺失 context path 影响 importToolsFromMcp 和控制台 AI API 的问题；Maintainer SDK 的 Get Agent Card 方法新增版本参数支持；agent/MCP 端点操作现在会发布事件供集成使用。
  • 控制台与分布式部署 — 自动同步服务端成员，修复集群环境下控制台成员信息过期；导入/导出现在选择健康的远端节点而非可能不健康的。另有 context-path、分页和通知刷新修复，减少非根路径和分布式部署的运维失败。
  • 客户端与配置正确性 — Configuration.initialize() 消除配置重载时的类卸载内存泄漏，修正 UUID 处理避免模糊监听初始化事件被过滤。Config 元数据发布现在支持审计日志和通知，LIKE 查询转义和持久化实例健康状态修复提升正确性。
  • 升级建议 — 这是实质性稳定性/安全补丁，不是重新打标。未明确列出破坏性 API 变更或迁移步骤；Nacos-Server/Nacos-Console 要求 Java 17，Nacos-Client/Nacos-Maintainer-Client 要求 Java 8。生产、配置重载、模糊监听、AI/MCP 和分布式控制台用户应升级；未涉及这些领域的用户可按常规补丁节奏推迟。

Nacos 3.1.2 是聚焦稳定性改进、安全修复和 AI 模块增强的补丁版本。主要亮点包括：

  • 安全：将 Spring Boot 升级到 3.4.10 以解决 CVE-2025-55752，另升级 log4j 和 gRPC 依赖
  • AI/MCP：修复 MCP 缓存不一致问题，为 Agent Card 查询增加版本参数支持
  • 控制台：通过自动服务端成员同步改善分布式部署体验，修复多个 context path 问题
  • 客户端：消除配置重载时的类卸载内存泄漏，修复模糊监听中的 UUID 传递问题
  • 配置：增强配置元数据发布，支持审计日志和通知
