nacos 1.4.3

修订 发布时间2022年1月27日 来源alibaba/nacos 英文原文

nacos 1.4.3

这个项目是干啥的：阿里开源的服务发现和配置管理中心，帮微服务互相找到彼此并统一管配置，支持gRPC和IPv6，给微服务团队用。

变更架构图

亮点

  • 安全——Log4j 升级到 2.17.0 — 升级的首要理由：#7420 把 log4j 从 2.15.0 升到 2.16.0，#7480 让 v1.x 分支升到 2.17.0，堵住 1.4.2 的 2.15.0 未完全覆盖的后续 Log4Shell CVE。仍在 1.4.x 且 log4j 未打补丁的用户都应升级；仅此一点就值得。

  • 配置稳定性——加密配置修复 — #7188 把 encryptedDataKey 通过 LocalEncryptedDataKeyProcessor.getEncryptDataKeySnapshot 加入 LocalConfigInfoProcessor.getSnapshot，#7191 修复客户端 LongPollingRunnable 中 EncryptedData 长轮询监听的 bug。使用配置加密加动态刷新的团队得到实打实的正确性修复；其他用户无感。

  • 行为变更——导入现在会覆盖 — #1773（“Let the imported config over the original config”）改变导入语义：导入的配置会取代现有配置。按行为/破坏性变更对待，检查所有假设”导入保留原配置”的自动化。

  • 命名 / Dubbo 修复 — #5747 修复在 Dubbo 多注册中心且 namingLoadCacheAtStart=true 时 NacosNamingService 缓存互相覆盖，#1733 修复注册两次再注销后仍能拿到实例。Dubbo 多注册中心用户受益；单注册中心用户可据此跳过。

  • 控制台及其他 — #5672 重排配置页面，另有特殊字符分组搜索（#3969）、回车搜索丢失查询参数（#5814）以及关闭鉴权时 srcUser 被填成用户名（#3548）的修复。属于次要改动，没有明确的破坏性 API 变更，也没有迁移步骤——只有已自行打过 log4j 补丁的用户才需要跳过。

该版本主要优化了config模块的稳定性，提出了控制台的交互体验。 更重要的是，这个版本还在UT覆盖率方面做出了较大的改进，并修复了1.4.x的许多Bug。 详情见下：

特点

[#6016] 支持从带有命名空间的端点获取服务器列表。 [#5672] 重新布局配置页面。

增强

[7188] 将加密数据密钥与 LocalEncryptedDataKeyProcessor.getEncryptDataKeySnapshot 添加到 LocalConfigInfoProcessor.getSnapshot 中。 [#6663] 优化 GetServerListTask 加载优先级。 [#1773] 让导入的配置覆盖原始配置。 [#5635] 修复 CreateUser 按钮和刷新没有间隙的问题。

重构和代码质量

[#7480] 将 v1.x-develop 的 log4j 升级到 2.17.0。 [#7420] 将 log4j 从 2.15.0 升级到 2.16.0。 [#5547] 优化 ConfigRequest 和 ConfigResponse 代码，提取公共常量。 [#5621] 删除重复的依赖项。 [#5528] 优化 ParamUtil 代码并提取常量。 [#5587] 更改 NotifySingleService 中的无效比较。

错误修复

[#1733] 修复注册两次并注销后仍然获取实例的问题。 [#7191] 修复 client(LongPollingRunnable) 中的 EncryptedData 长轮询侦听错误。 [#3969] 修复按组名搜索特殊字符匹配错误的问题。 [#5814] 修复 Nacos 1.x 中按回车键搜索时查询参数丢失的问题。 [#5747] 使用Dubbo的多注册中心功能时，设置namingLoadCacheAtStart=true时，NacosNamingService的缓存会互相覆盖。 [#5683] 修复逻辑判断表达式。 [#5664] 修复配置历史详细信息页面中 Action Type 字段的区域设置不生效的问题。 [#3548] 修复禁用 auth 时 srcUser 填写用户名的问题。

其他

[#7342] 优化 client 节拍日志输出，删除不必要的错误日志。

测试

[#5538] 修复一些失败的测试用例。 [#5577] [#5600] [#5601] [#5484] [#5599] [#5595] [#5596] [#5579] [#5583] [#5539] [#5545] 为 nacos-core 和 nacos-naming 中的某些类添加单元测试。
