nacos 2.1.2

修订 发布时间2022年10月17日 来源alibaba/nacos 英文原文

nacos 2.1.2

变更流程图

亮点

  • 客户端打包与兼容性 — 新增更小巧的纯 nacos-client 构建（minijar）（#7929、#9091），改善产物体积和依赖管理。迁移提醒： 依赖 shaded 或重定位类的构建应核查产物与依赖配置，别假定新打包方式可直接替换。

  • 命名与客户端可靠性 — 修复 endpoint 配置启动（#8882）、IPv6 解析（#9269）、重试 header 丢失（#8934）、ServerListMgr 清理（#9047）、取消订阅失败（#9062）、批量实例计数/序列化（#8910、#8931）以及监听器/索引缓存陈旧（#9277、#9311）。还新增 Naming Distro 版本同步（#9210）和命名异步查询开关（#9325），但此处未记录其名称和默认值。遇到这些正确性或生命周期问题应升级。

  • 服务端、配置与插件修复 — 修正鉴权/加密插件加载（#8947）、cipher- dataId 创建（#9023）、畸形 dataId 的构建资源（#9305）、数据源连接/超时处理（#8611、#9101）、JraftServer 关闭后 NPE（#9271、#6876），以及 1.x HTTP openAPI 服务检查（#9323）。org.yaml.snakeyaml 也从 1.30 升到 1.32（#9177），自定义 YAML/解析器与数据源集成应做回归测试。

  • 控制台与权限控制 API — 改进控制台国际化和命名空间重名处理（#8956、#8976），并在权限控制中加入模糊查询（#8941）。changelog 提示有相关 API 变更但未给出契约细节；权限控制 API 的调用方应在升级前查看上游改动。

  • 升级结论 — 这是有实质内容的维护版本，不是换标签或纯元数据更新。2.1.0/2.1.1 用户——尤其使用 endpoint、命名订阅/批量注册、加密配置或自定义插件的——有明确升级理由。不受这些路径影响的稳定部署可跳过；控制台改进是增量，且未提供正式迁移指南。

该版本主要增强控制台UI，发布无阴影的纯nacos client并修复大量错误。 下一个版本计划发布2.2.0，其中包含许多新插件。 详细见：

增强

[#6112] 统一德比数据变量。 [#7929] 通过 minijar 减少 nacos-client jar 大小。 [#8941] 支持权限控制模糊查询—api 变更。 [#8956] 在 nacos 控制台中国际化产品描述内容。 [#8976] 使用重复的命名空间显示名称创建新的命名空间。 [#9091] 发布时构建纯 nacos-client。 [#9210] 命名发行版同步支持修订版。

重构&依赖

[#8611] 关闭旧数据源连接。 [#8650] 使集群/报告接收和发送元数据。 [#9013] 重构 rpcClient 和 grpcClient 以支持集合配置。 [#9014] 重构 TpsMonitorPoint。 [#9177] 将 org.yaml.snakeyaml 版本从 1.30 升级到 1.32 [#9325] 添加异步查询命名开关。

错误修复

[#8882] 修复使用端点配置时 nacos-client 2.1.0 启动错误。 [#8910] 修复使用批量寄存器时计算实例计数错误。 [#8925] 修复 hasQueryString 的值始终为 false 的问题。 [#8928] 修复replaceAll操作对服务器列表无效的问题。 [#8931] 修复 BatchInstanceData 无法序列化的问题。 [#8934] 修复请求重试时标头丢失的问题。 [#8947] 修复 nacos 服务器上未加载认证/加密插件的问题。 [#9023] 修复无法创建极端情况配置 dataId ‘cipher-’ 的问题。 [#9047] 修复 nacos-client 中 ServerListMgr 未关闭的问题。 [#9060] 修复 NamingTraceEvent 连续打印日志的问题。 [#9062] 修复取消订阅服务失败的问题。 [#9101] 修复数据源连接中的 ConnectionTimeout 属性被覆盖的问题。 [#9227] 修复 2.1.1 中没有设置范围时实例更改事件订阅失败的问题。 [#9230] 修复快照加载的错误事件顺序。 [#9269] 修复 RpcClient 解析 ipv6 地址错误问题。 [#9271][#6876] 修复服务器异常关闭后的“JraftServer”NPE。 [#9277] 修复删除服务时 ClientServiceIndex 不干净的问题。 [#9305] 修复带有错误 dataId 的构建资源。 [#9311] 修复监听器添加延迟时缓存未删除的问题。 [#9323] 修复 1.x http openAPI 中的服务检查问题。
