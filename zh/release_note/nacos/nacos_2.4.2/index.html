nacos 2.4.2

修订 发布时间2024年9月5日 来源alibaba/nacos 英文原文

该版本主要修复了 2.4.1 版本中与 Raft 协议初始化相关的启动过程中潜在的死锁问题（#12526）。它还回滚了版本 2.4.1 中所做的降低 hessian 版本的更改，这些更改由于与 hessian 依赖项冲突而导致 JDK 17+ 版本上的启动问题。此外，还优化了检查ServerStatus的逻辑，防止由于Raft选举失败而影响非Raft相关功能的可用性。 此外，该版本还包括多项可用性增强功能并解决了一些其他错误。 请参阅以下更改的详细信息：

更改详细信息

这个项目是干啥的：阿里开源的服务发现和配置管理中心，帮微服务互相找到彼此并统一管配置，支持gRPC和IPv6，给微服务团队用。

变更架构图

亮点

  • 关键的 2.4.1 回归修复 — 解决启动时 Raft 初始化可能死锁的问题（#12526），并回退导致 JDK 17+ 启动失败的 Hessian 版本降级（#12498、#12503）。所有跑 2.4.1 的都应升级，尤其是 JDK 17+。
  • Raft 故障期间可用性提升 — 重构了 ServerStatus 检查和协议管理器加锁（#12573、#12583），让 Raft 选举失败不再无谓地影响非 Raft 依赖功能。这对出现部分故障的集群很重要。
  • 客户端与 API 正确性 — 修复 nacos-client 的 accessToken 更新（#12509）、来自环境变量的配置标签（#12604）、HTTP Open API 错误码错误（#12610），以及密码重置、校验和命名空间配额问题。如果你依赖 token 鉴权、环境变量驱动配置或 API 错误处理，请升级。
  • 易用性与依赖更新 — 新增配置格式显示、日志脱敏（#12547）、配置 diff 行折叠（#12608）和更广的数据库支持。依赖更新到 mysql-connector-j 8.2.0、Spring 5.3.39、Tomcat 9.0.93 和 logback 适配器 1.1.3。文档未声明破坏性变更或必做迁移步骤；未受影响的早期版本用户可跳过，但自定义数据库或容器集成应在依赖升级后重新测试。

此版本主要修复 2.4.1 启动过程中与 Raft 协议初始化相关的潜在死锁问题（#12526）。同时回退 2.4.1 中降低 hessian 版本的改动——该改动因 hessian 依赖冲突导致 JDK 17+ 启动问题。此外优化了 ServerStatus 检查逻辑，避免 Raft 选举失败影响非 Raft 依赖功能的可用性。本版本还包含若干易用性增强和其他 bug 修复。详细变更如下：

变更详情

增强&重构

[#12483]配置列表添加配置格式。 [#12547] Nacos client 支持日志记录脱敏。 [#12555] SwitchManager 支持http、tcp、mysql HealthParams 和pushCSharpVersion 更新。 [#12569] 增强现有表逻辑以支持更多数据库。 [#12573] 增强服务器状态检查以避免影响核心功能。 [#12583] 增强协议管理器锁定逻辑。 [#12608] 增强配置差异，支持折叠相同行。

错误修复

[#12093] 修复重置密码成功但没有消息的问题。 [#12498][#12503] 恢复“解决 Hessian 包冲突问题。(#12449)”。 [#12509] 修复 nacos-client 更新 accessToken 的错误。 [#12526] 修复启动期间可能出现的死锁问题。 [#12563] 修复参数检查器无效的错误。 [#12581] 修复命名空间配额和参数优化。 [#12604] 修复从环境参数获取配置标签的问题。 [#12610] 修复 http 打开 api 请求的错误错误代码。

依赖关系

[#12568] 将 mysql-connector-j 从 8.0.33 升级到 8.2.0。 [#12387] 将 logback 适配器升级到 1.1.3 [#12586][#12596] 将春季版本升级到 5.3.39。 [#12596] 将 tomcat 升级到 9.0.93。
