nacos 3.0.1

修订 发布时间2025年5月22日 来源alibaba/nacos 英文原文

变更流程图

亮点

  • MCP 新增多命名空间、版本管理和标准 Registry API——默认关闭 — 3.0.1 为 MCP 增加多命名空间支持（[#13356]）、MCP 服务器版本控制器（[#13401]），并实现定稿的 MCP Registry API（[#13377]），Nacos 是首个实现该标准的方案。Registry API 默认禁用，因为需要额外端口/资源；用 nacos.ai.mcp.registry.enabled=true 开启，并通过 nacos.ai.mcp.registry.port 设置端口（默认 9080）。跑 MCP 负载、想要符合标准的发现的团队应升级并开启；非 MCP 用户从这里得不到收益。

  • 破坏性变更：MCP Server 数据结构变了——从 3.0.0 升级必须迁移 — 官方 Registry API 标准变更导致 MCP Server 元数据定义不兼容。3.0.0 → 3.0.1 后控制台可能无法读取此前存储的 MCP Server。请运行随附的 mcp-migration-tool.jar（见升级文档），它会把存量 MCP Server 迁到默认的 public 命名空间。好处是标准已定稿，MCP Server 结构稳定且今后向后兼容。已有 MCP Server 数据的用户必须规划迁移；没有 MCP Server 的可跳过。

  • 值得为 3.0.0 打这个补丁的修复 — 包括配置变更插件返回值不兼容（[#13249]）、含非法字符的服务删除失败（[#13267]）和控制台删除命名空间失败（[#13368]）、集群客户端忽略 nacos.remote.client.grpc 配置（[#13273]）、Prometheus 指标 API 失效（[#13321]）、apiClient readTimeout 处理（[#13345]）、默认命名空间配置监听（[#13405]）以及 MCP stdio 提示（[#13413]）。还改进了 Windows startup.cmd 重复 secret.token.key 提示（[#13335]）和初始密码提示（[#13348]）。3.0.0 上被这些问题困扰的用户应升级。

  • 升级结论与版本说明 — MCP 用户（新能力）和受上述 bug 影响的用户值得升级；不使用 MCP、也未踩到这些问题的稳定 3.0.0 部署可安全跳过。部署要求不变：服务端/控制台需 Java 17，客户端需 Java 8。注意发布资产已重新打标为 3.0.1.1——从本版本下载的内容与 3.0.1.1 相同，因此这实际上是在真实 3.0.1 改动之上做了一次元数据/资产更新。

发布资源已更新为3.0.1.1，此发布资源下载与3.0.1.1发布相同。 该版本基于3.0.0版本，引入了对MCP的多命名空间管理能力和多版本管理能力的支持。 Nacos社区为MCP注册中心API标准做出了贡献，并且是第一个实施该标准MCP注册中心API的社区。 部署Nacos 3.0.1时，可以通过设置参数nacos.ai.mcp.registry.enabled=true来启用标准MCP注册表API，参数nacos.ai.mcp.registry.port（默认9080）指定MCP注册表API的端口。由于 MCP 注册表 API 需要额外的端口和资源，因此它在标准配置中默认保持禁用状态。 由于官方 MCP 注册表 API 标准的更改，MCP 服务器的元数据定义已更新，导致潜在的不兼容数据结构更改。从版本 3.0.0 升级到 3.0.1 可能会导致控制台无法从以前的 MCP 服务器读取数据。 Nacos社区提供了一个迁移工具，可以在执行后将现有的MCP Server重新定位到默认命名空间public。有关使用迁移工具 mcp-migration-tool.jar 的详细说明，请参阅 文档。 随着MCP注册表API现已最终确定，MCP服务器的数据结构已经稳定，确保了未来版本的向后兼容性。 除了新功能外，该版本还优化了Windows系统的初始密码提示和启动脚本，同时还修复了3.0.0版本中存在的多个错误。 3.0.1的详细变化参见：

功能/重构

[#13356] 支持 MCP 功能的多个命名空间。 [#13377] nacos mcp 模块支持 mcp 注册表 api。 [#13401] 支持 mcp 服务器的版本控制器。

增强/重构

[#13335] 增强 Windowsstartup.cmd 以减少 Secret.token.key 的重复提示。 [#13348] 增强初始化密码的提示。

错误修复

[#13249] 修复配置更改插件返回不兼容的问题。 [#13267] 修复无法删除包含非法字符的服务的问题。 [#13273] 修复创建集群 client 不使用 nacos.remote.client.grpc 配置的问题。 [#13321] 修复 prometheus 指标 api 无法接受的问题。 [#13345] 修复 apiClient readTimeout 必须为零。 [#13368] 修复控制台 ui 中无法删除命名空间的问题。 [#13405] 修复默认命名空间的监听配置问题。 [#13413] 修复 mcp stdio 服务器的提示问题。
