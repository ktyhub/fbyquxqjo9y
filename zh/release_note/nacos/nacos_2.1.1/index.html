nacos 2.1.1

修订 发布时间2022年8月8日 来源alibaba/nacos 英文原文

变更架构图

亮点

  • 两个新 BETA 特性，尚不适合生产 — batchRegister 服务支持（#5863）面向 nacos-sync 之类的代理注册场景，服务端 TRACE 事件（#8481）把配置/服务变更信息暴露出来，作为未来插件的基础。两者都明确标为 beta：可以用来试点，但暂时别把生产依赖建在它们上面。

  • 破坏性变更：服务节点离群 API 被移除 — #8305 临时移除了”让 Nacos 服务节点离群”的 API。任何通过该端点脚本化调整集群成员或下线节点的人都要改；更新日志没给替代品或回归时间表，升级前请核对你的工具链。

  • 安全/兼容性依赖升级与移除 — jackson 升到 2.12.6.1（#8383）、spring-boot 升到 2.6.8（#8540）、mysql-connector-java 升到 8.0.28（#8623），同时移除 mina（#8369）和 commonOkHttp（#8421）依赖。如果你依赖被移除的库，可能出现 classpath/插件冲突；但也能拿到这些升级本要修的问题。

  • 运维上重要的 bug 修复 — 尤其是 HTTPS 客户端连接（#8372）、集群模式下内置存储的鉴权登录（#8295）、开启鉴权时配置导入失败（#8833）、无读权限时重复加载配置（#8880）、Prometheus 客户端 API 错误（#8514/#8539）、持久化实例错误地变成临时实例（#8516）。性能方面还有默认鉴权插件（#8561）、GrpcUtil 内存/CPU（#8592）、distro 同步快速失败（#8099）及可配置加载超时（#8594）。

  • 升级结论 — 对跑 2.1.0 的人来说是扎实的 bugfix/加固版本，尤其是启用鉴权、集群、HTTPS 或 Prometheus 监控的部署；为了稳定性和依赖安全修复值得升级。如果你在稳定的 2.1.0 之前版本且没有这些痛点，或者只想要那两个新特性但无法接受 beta API，可以跳过。

此版本主要修复 2.1.0 中的大量 bug，并升级许多依赖以修复一些大问题。同时社区做了一些性能增强，例如默认鉴权插件、Grpc 请求和 distro 协议。最后，新增两个 beta 特性——batchRegister 和 trace event。前者用于 nacos-sync 之类的代理注册场景，后者用于获取配置或服务变更信息，将成为社区的一个新插件。详情见：

特点

[#5863] (BETA) 支持批量注册服务。 [#7424]历史列表中添加版本数据比较。 [#8305] (REMOVE) 暂时删除离开的 nacos 服务器节点 API。 [#8481]（测试版）将 TRACE 事件添加到服务器。 [#8755] 添加默认模糊搜索功能。

增强

[#8099] 如果集群断开连接，发行版同步任务和验证任务会快速失败。 [#8150] 在命名空间列表页面添加命名空间描述项。 [#8345] 添加对服务集群名称的验证。 [#8515] 优化 InetUtils 中的部分代码。 [#8561] 增强默认身份验证插件性能。 [#8574] 增强推送回调的过滤服务信息。 [#8592] Ehhance GrpcUtil 内存和 CPU 成本。 [#8622] 添加 NacosEnvironment 并添加一些单元测试。

重构&依赖

[#8369] 删除 mina 依赖项。 [#8383] 将 jackson 版本升级到 2.12.6.1。 [#8421] 删除 commonOkHttp 依赖项。 [#8472] 删除无用的依赖项。 [#8479] 将单例构造重构为私有。 [#8540] 将 spring-boot 版本升级到 2.6.8。 [#8594] 使发行版数据加载超时可以配置。 [#8596] 显式指定 spring-boot-maven-plugin 版本与 spring-boot 相同。 [#8623] 将 mysql-connector-java 升级到 8.0.28。

错误修复

[#7039] 修复配置加密数据 md5 计算问题。 [#8153] 修复 AutoExpireCache 的 NPE。 [#8243][#8653] 修复运行状况检查插件问题。 [#8275] 修复使用 skywalking 时无法注册服务的问题。 [#8295] 修复集群模型中使用嵌入式存储时无法登录的问题。 [#8318] 修复 findAllConfigInfoForDumpAll sql args 错误。 [#8372] 修复 client 无法使用 https 连接的问题。 [#8424] 修复循环依赖问题。 [#8428] 修复多个 NamingService 时的命名订阅错误。 [#8505] 修复 spring-boot 项目中的日志配置冲突。 [#8514][#8539] 修复 client 中的 prometheus api 错误。 [#8516] 修复持久实例变成临时实例的问题。 [#8602] 修复删除当前命名空间后的显示错误。 [#8632] 修复首次订阅禁用实例的问题。 [#8635] 修复调用 shutdown 方法时的 NPE。 [#8720] 修复配置方面无效的问题。 [#8742] 修复更改实例元数据，修改服务不改变的问题。 [#8784] 修复控制台 UI 的一些错误。 [#8833] 修复打开 auth 时导入配置失败的问题。 [#8880] 修复在没有读取权限时不断加载配置的问题。

测试
