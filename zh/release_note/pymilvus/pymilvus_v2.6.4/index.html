pymilvus v2.6.4

pymilvus v2.6.4

亮点

1. 支持 TimestampTZ 数据类型（Milvus v2.6.6 中引入）

PyMilvus 现在支持 TIMESTAMPTZ 数据类型，允许您存储和查询带有时区信息的时间戳。

from pymilvus import MilvusClient, DataType

client = MilvusClient(uri="http://localhost:19530")

# 1. Define Schema with TimestampTZ
schema = MilvusClient.create_schema()
schema.add_field("id", DataType.INT64, is_primary=True)
schema.add_field("timestamp", DataType.TIMESTAMPTZ)
schema.add_field("vector", DataType.FLOAT_VECTOR, dim=128)

client.create_collection(collection_name="ts_collection", schema=schema)

# 2. Insert Data (using ISO 8601 format strings with timezone)
data = [
    {"id": 1, "timestamp": "2025-01-01T12:00:00+00:00", "vector": [0.1] * 128},
    {"id": 2, "timestamp": "2025-01-02T08:30:00-05:00", "vector": [0.2] * 128}
]
client.insert(collection_name="ts_collection", data=data)

# 3. Query Data
# Query records by ID to retrieve timestamps
res = client.query(
    collection_name="ts_collection",
    filter="id in [1, 2]",
    output_fields=["id", "timestamp"]
)
print(res)

更改日志

功能和增强功能

  • [TimestampTZ] 添加了对 TIMESTAMPTZ 数据类型的支持。 (#3092)
  • [BulkWriter] BulkWriter 支持 STRUCT 字段数据类型。 (#3068)
  • [BulkWriter] BulkWriter 支持几何数据类型。 (#3052)
  • [BulkWriter] 添加了对在 RemoteBulkWriter 中指定本地临时路径的支持。 (#3077)
  • [STRUCT] 支持 STRUCT 字段中的 TypeParams 定义。 (#3055)
  • [MilvusClient] 将 6 个 API 迁移到 MilvusClient：flush_all、get_flush_all_state、list_loaded_segments、list_persistent_segments、get_server_type 和 get_compaction_plans。 (#3096)
  • [Array] MilvusClient 中的 ARRAY 字段支持 numpy ndarray 输入。 (#3096)

错误修复

  • [导入] 在 list_import_jobs() 中添加了 db_name 参数，以正确列出特定数据库下的作业。 (#3088)
  • [连接]修复了与连接重置处理相关的错误。 (#3085)
  • [连接] 修复了检索集合架构时连接缓存的问题。 (#3072)
  • [STRUCT] 修复了查询 STRUCT 字段可能错误返回空数组的错误。 (#3074)
  • [MilvusClient] 修复了 insert() 未将 **kwargs（例如超时）传递给底层实现的问题。 (#3096)
  • [异步] 通过在连接别名中包含事件循环 ID 修复了连接重用问题。 (#3096)
  • [异步]修复了异步刷新()不等待段被刷新的问题。 (#3090)
  • [MilvusClient] 修复了段信息检索中的键名称。 (#3096)
  • [错误处理] 为错误处理程序添加了详细的回溯，以便更好地调试。 (#3096) 完整 Changelog：https://github.com/milvus-io/pymilvus/compare/v2.6.3…v2.6.4
