gradio gradio@6.32.0

这个项目是干啥的：一个几行代码就能给机器学习模型搭出网页界面的工具，方便试用和分享，给做 AI 演示的研究者和开发者用。

变更架构图

亮点

  • 鉴权/MCP 行为变更 — 使用鉴权的应用现在要求 MCP 服务端登录，并且排队的 MCP 调用在鉴权下可用（#14053）。**对未鉴权的 MCP 客户端是破坏性的：**集成方必须做认证；已鉴权应用的用户应升级以修复排队调用。
  • Hugging Face 运行历史 — 运行历史桶访问现在使用访客自己的 HF token（#14050），改变了共享历史所使用的身份和权限。如果你依赖 HF 支持的运行历史，请核实 token 供应、作用域和访问权限。
  • 依赖与扩展支持 — 6.x 线现在接受 Pillow 13，同时保持 32 位整数 PNG 输出正常（#14034），CLI 支持 GitHub 安装的扩展（#14042）。如果其中任一项解开被卡住的依赖或扩展工作流，建议升级。
  • 工作流与嵌入式调试 — 工作流新增深度估计处理、掩码文本框和 3D 模型节点（#14017、#13972、#14057）。嵌入式应用还会转发控制台消息（#14059），改善宿主页面中的调试。
  • 针对性的可靠性修复 — 延迟的 always_last 事件获得各自的事件数据（#13991），摄像头权限拒绝会显示错误（#14027），Windows 修复解决了缓存文件过早删除和误导性的保留端口错误（#14064）。受影响则升级；否则本版本可选。

特点

  • #14050 fda8037 - 将访问者自己的 HF 令牌用于运行历史存储桶。 谢谢@dawoodkhan82！
  • #14034 1028366 - 允许 6.x 上的 Pillow 13 并保持 32 位整数 PNG 输出正常工作。 谢谢@abidlabs！
  • #14042 2f8693a - 添加 GitHub 安装的 CLI 扩展。 谢谢@abidlabs！
  • #14059 5819440 - 为嵌入式应用程序添加控制台转发。 谢谢@pngwn！
  • #14017 ebccfcf - 工作流程：处理深度估计。 谢谢@hannahblair！
  • #13972 d702b19 - 工作流程：在文本框上添加屏蔽设置。 谢谢@hannahblair！
  • #14057 ab27f92 - 工作流程：添加 3d 模型节点支持。 谢谢@hannahblair！
  • #14053 29ba706 - 当应用程序使用身份验证时需要登录 MCP 服务器，并使排队的 MCP 调用与身份验证一起使用。 谢谢@abidlabs！

修复

  • #13991 fa3f296 - 使用其自己的事件数据运行延迟的always_last 事件。 谢谢@hysts！
  • #14064 62e7c9e - 修复两个 Windows 错误：重用的缓存文件提前删除、误导性保留端口错误。 谢谢@dawoodkhan82！
  • #14027 f3bab14 - 当网络摄像头的摄像头权限被拒绝时显示错误。 谢谢@hysts！
