小版本 发布时间2026年9月30日 来源anthropics/anthropic-sdk-python 英文原文

1.10.0 (2026-09-30)

完整 Changelog: v1.9.0…v1.10.0

特点

  • api： 将拒绝停止原因和 stop_details 添加到托管代理会话空闲事件 (cba653f)
  • api： 将 Claude Enterprise 分析、支出限制以及 RBAC 组和角色添加到管理员 API (6bb2c0c)
  • api： 将每个用户的使用情况和成本报告添加到管理 API 分析中 (7443920)
  • api: 将插件和插件市场添加到管理 API (1baad3b)
  • api: 将存储库错误类型添加到托管代理会话错误 (c682f7e)
  • api： 允许删除插件的组织范围安装设置 (17f52fc)
  • api: MCP 隧道测试版：将只读 transport 对象添加到隧道并在创建响应中返回一次性中继 token (88718ff)
  • api: 组织 API 端点现已正式发布 (f1d195a)

错误修复

  • api: 使内存存储描述、元数据、archived_at 为必需 (6cc39d3)
  • api: 将管理插件首选项和市场字段键入为枚举 (b4dfd99)
  • **凭据：**拒绝组或其他人可以写入的配置文件（[cd5fc6a]（https://github.com/anthropics/anthropic-sdk-python/commit/cd5fc6a1e5a65cbd08f5c77465617526c313f0b8））
  • 分页： 当设置 next_page 时，自动分页会继续经过空白页 (c027a26)
  • 工具： 在结束转弯的任何空闲后停止会话工具运行器 (#969) (9c60a53)

家务事

  • api: 更新 MCP 隧道类型和描述 (aa49ba7)
  • ci: 在最旧和最新的 Python 上并行运行测试 (53bb298)
  • 文档： 删除占位符枚举描述 (f535d67)
  • 内部： 每行一个参数的格式请求选项 (4e2463e)
  • 测试： 当请求添加查询参数时匹配模拟的二进制路由 (0781470)
