bookkeeper release-4.18.0

这个项目是干啥的：Apache 的分布式日志存储系统，专门可靠地存一串串追加写入的记录，常被消息队列和实时计算当底层存储，适合大数据团队。

4.18.0 版本是一个主要功能版本。它在整个系统中引入了结构化日志记录 代码库 (BP-69)，将有线协议序列化迁移到 LightProto 和本机 I/O 库到Rust，并将所需的最低Java版本提高到17。它还包括许多 改进、错误修复和依赖项/CVE 更新。

鼓励 Apache BookKeeper 用户升级到 4.18.0。请查看 升级前的重大更改和已知问题如下。

变更架构图

亮点

  • 结构化日志记录 (BP-69) — 所有 BookKeeper 日志记录均已从 SLF4J 转换 将字符串格式化为 slog，结构化日志记录 API，其中每个事件都携带键入的键/值 属性（例如 ledgerId、entryId）。记录器上下文通过 client 传播 操作，因此与同一分类账相关的所有事件都会自动标记。 属性由 log4j2 以纯文本和 JSON 输出呈现，并提供示例 OpenTelemetry 兼容的 JSON 日志的配置。 PR #4751, #4754, #4755, #4756, #4757, #4758, #4765, #4766, #4767, #4770
  • LightProto 序列化 — BookKeeper 有线协议、元数据格式和流 存储原型已从 protobuf-java 迁移到 LightProto，后者可以解析和 直接在 Netty 缓冲区上序列化，无需中间分配，减少 GC 压力 走在热路上。 PR #4779, #4780, #4781, #4783
  • 在 Rust 中重写的本机 I/O 库 — native-io 库用于直接 I/O 博彩公司已从 C 迁移到 Rust。 PR #4738
  • Java 17 基线 — 现在需要 Java 17 或更高版本来构建和运行 BookKeeper。 PR #4446
  • Bookie 退役清理 cookie (BP-68) — 退役管理员 API 现在 从元数据存储中删除 bookie cookie，因此可以使用停用的 bookie id 无需手动清理即可重复使用。 PR #4500, #4592
  • ZooKeeper 重新复制期间的读取限制 (BP-66) — 重新复制现在可以 限制其 ZooKeeper 读取，保护元数据存储免受读取风暴的影响 账本正在被恢复。 PR #4258
  • 批量读取未确认的条目 (BP-62) — batchReadUnconfirmedAsync 现在是 暴露在ReadHandle上。 PR #4739

重大变更

  • 构建和运行 BookKeeper 需要 Java 17+（以前是 Java 11） PR #4446
  • readOnlyModeOnAnyDiskFullEnabled 的默认值更改为 true：现在是博彩玩家 一旦任何账本磁盘已满，而不是仅当所有磁盘都已满时，就会转换为只读 已满。将其设置回 false 以恢复之前的行为。 PR #4520
  • bookkeeper-slogger 模块已被删除，由 slog 结构取代 记录 API (BP-69) PR #4764
  • 删除了已弃用的、拼写错误的方法 setAllocatorPoolingConcurrenncy — 使用 setAllocatorPoolingConcurrency 改为 PR #4431
  • 删除了已弃用的类 MathUtils PR #4274

已知问题

  • PR #4730（读取线程阻塞修复 此版本中包含的 sendResponseAndWait）被发现可能会导致死锁 在书迷阅读路径上。它已被恢复到 PR #4830，它将成为 4.18.1 的一部分。

特点

  • 支持 bookie 服务器的 TCP 保持活动配置 PR #4762
  • 新的 client API 用于检查 BookKeeper client 是否连接到元数据服务 PR #4342
  • 从 Yahoo DataSketches 迁移到 Apache DataSketches 7.0.1 (KLL) PR #4774
  • 允许配置 log4j2 AsyncLogger PR #4269

改进

赌徒

  • 添加 total_entry_log_space_bytes 公制 PR #4507
  • 丰富 GC 指标，以更好地分析 GC 行为和每个阶段所花费的时间 PR #4384
  • 添加 RocksDB getLastEntryInLedger 指标以帮助识别瓶颈 PR #4529
  • 在 EntryLoggerAllocator 中为执行器设置 ThreadFactory PR #4562
  • 为本机库添加临时目录属性 PR #4533
  • 将 WRITE_BUFFER_WATER_MARK 设置应用于 bookie Netty 服务器中的子频道 PR #4337
  • 当持有写锁时，跳过 SingleDirectoryDbLedgerStorage 中浪费的乐观缓存插入 PR #4306
  • 仅覆盖日志
