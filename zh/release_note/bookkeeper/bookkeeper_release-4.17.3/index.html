bookkeeper release-4.17.3

这个项目是干啥的：Apache 的分布式日志存储系统，专门可靠地存一串串追加写入的记录，常被消息队列和实时计算当底层存储，适合大数据团队。

变更架构图

亮点

  • 垃圾回收的健壮性 — 遇到损坏的 entry log 文件时，GC 可能无限挂起（#4544）；4.17.3 把触发 GC 停止的条件收敛到 DbLedgerStorage 上真正的磁盘满场景（#4661），记录每一个 GC 线程错误（#4649），并在 GC 期间对 ZooKeeper 读取限流（#4645）。从运维角度看，这意味着悄悄吃掉磁盘的无声停顿更少了，但 GC 日志会明显吵闹很多，大规模 compaction 也可能因 ZK 限流而变慢。
  • 下线（decommission）与 ledger 读取 — 反复对 bookie 做 decommission 后，entry 读取可能失败（#4613）；打开一个已删除的 ledger 会返回误导性的错误码 -102（#4657）。凡是把滚动下线和 ledger 生命周期处理自动化的，都应重新检查错误码分支——原来按旧值判断的调用方现在可能走到另一条路径。
  • 只读恢复与 API 兼容性 — bookie 在磁盘已回收后仍可能卡在只读状态（#4640）；该修复一度移除了一个 public 方法，#4682 又把旧的 public 方法名恢复了回来。如果你测过中间快照，请重新验证调用方——正式发布的 4.17.3 公共 API 是完整的。
  • 构建与平台支持 — native I/O 的 JNI 源码在 Windows 的 JDK 11 下编译失败（#4665）。这主要影响在 Windows/JDK 11 工具链上从源码构建的团队，对直接使用发布二进制的用户影响不大。
  • 客户端网络与 bookie 视图 — bookie 客户端现在可以配置 TCP keepalive 参数（#4683），适合穿过 NAT/负载均衡器的长连接；BookieServerInfo 新增了 equals/hashCode（#4686），修掉了基于 set/map 的 bookie 视图里的去重问题。
  • 依赖更新，且带有迁移代价 — Netty 升到 4.1.130（#4699），OpenTelemetry 升到 1.56.0 / instrumentation 2.21.0 / semconv 1.37.0（#4690）；一个安全修复把 net.jpountz.lz4:lz4 换成了 at.yawk.lz4:lz4-java（#4696），同时移除了 commons-collections（#4689）以及顶层的 commons-configuration2/commons-beanutils（#4648）。靠传递依赖使用这些库的消费者必须改为显式声明；LZ4 包名变更也值得在升级前做一次 classpath/shading 检查。

本版本没有有意引入破坏性变更。

4.17.3

4.17.3 版本包含多个错误修复和少量依赖项更新。

如果您使用的是 4.17.x，我们鼓励 Apache BookKeeper 用户升级到 4.17.3。 此版本的技术细节总结如下。

错误

  • 修复：垃圾收集卡在损坏的条目日志文件上 PR #4544
  • [修复] 多次停用后读取条目失败 PR #4613
  • [修复]即使磁盘为空，BK 仍保持只读状态 PR #4640
  • 恢复从 #4640 PR #4682 中删除的旧公共方法名称
  • [修复]环境 jdk11 和 windows 下文件 native_io_jni.c 的编译错误 PR #4665
  • 仅为 DbLedgerStorage 的填充磁盘停止 Gc PR #4661
  • [修复]打开已删除的分类帐时出现错误的错误代码(-102) PR #4657
  • 记录 GarbageCollectorThread 中的所有错误 PR #4649

改进

  • BookieServerInfo 支持 equalsAndHashcode PR #4686
  • 支持在Bookie Client中配置TCP Keepalive相关参数。 PR #4683
  • 在 gc 中添加 zk 读取速率的速率限制。 PR #4645

依赖项更新

  • 将 netty 升级到 4.1.130 Final PR #4699
  • [安全] 将 net.jpountz.lz4:lz4 替换为 at.yawk.lz4:lz4-java PR #4696
  • 将 OpenTelemetry 升级到 1.56.0，将 Otel 仪器升级到 2.21.0，将 Otel semconv 升级到 1.37.0 PR #4690
  • 从依赖项中排除公共集合 PR #4689
  • 从顶级依赖项中删除 commons-configuration2 和 commons-beanutils PR #4648
