bookkeeper release-4.18.1

发布 发布时间2026年9月16日 来源apache/bookkeeper 英文原文

bookkeeper release-4.18.1

变更流程图

亮点

  • 新的客户端控制能力 — withOrderingKey 现在可以把 ledger 回调固定到调用方指定的工作线程；OpenBuilder.withKeepUpdateMetadata 和 DeleteBuilder.withLoggerContext 新增了可选的 builder 控制项。现有调用方无需改动；在回调落点、元数据处理或日志上下文有要求的场景里采用它们即可。
  • 降低调度和 I/O 开销 — SingleThreadExecutor.executeOrRun、从 ledger 线程内联读取，以及批量排空队列，减少了 executor 的线程切换。把 journal 的长度前缀和负载合并进一次 BufferedChannel 写入也降低了 journal 开销，对延迟和吞吐敏感的部署都有好处。
  • 减少分配和 CPU 开销 — Java9IntHash 通过 MethodHandle.invokeExact 避免每次校验和都装箱；关闭 debug 日志时会跳过 journal flush 的 trace 循环；OrderedExecutor 改用 ThreadLocalRandom；BlockingMpscQueue 的忙循环加了自旋等待提示。其中校验和的改动对校验和密集的工作负载尤其相关。
  • 线程泄漏修复与延迟修复回退 — BookKeeper 客户端构造失败时不再泄漏线程，这对重试频繁的启动路径很重要。但 PR #4830 回退了 #4730 针对 READ_ENTRY_REQUEST p99 延迟的修复，恢复到更早的行为；受影响的部署应重新压测，而不是想当然地认为读延迟改善了。
  • 依赖更新与升级建议 — Jetty 升到 12.1.10，org.apache.thrift:libthrift 升到 0.24.0，at.yawk.lz4:lz4-java 升到 1.11.1，native-io Rust 模块的 bytes 升到 1.11.1。未列出破坏性 API 变更或强制迁移项。BookKeeper 建议 4.18.x 用户采用此版本；线程泄漏修复和性能优化足以构成升级理由，而稳定的部署如果不急着要这些、也不想重新验证依赖集成，可以推迟。

4.18.1

4.18.1 版本包括一些新的 client API、多项性能改进、错误修复和依赖项更新。

如果您使用的是 4.18.x，我们鼓励 Apache BookKeeper 用户升级到 4.18.1。 此版本的技术细节总结如下。

特点

  • 通过 withOrderingKey 将账本的回调固定到调用者选择的工作线程 PR #4881
  • 将 OpenBuilder.withKeepUpdateMetadata 和 DeleteBuilder.withLoggerContext 添加到构建器 API PR #4834

改进

  • 添加 SingleThreadExecutor.executeOrRun 并从账本自己的线程中发出内联读取 PR #4883
  • 使用 MethodHandle.invokeExact 避免 Java9IntHash 中的每个校验和装箱 PR #4876
  • 在 SingleThreadExecutor 中使用批量排空队列 PR #4836
  • 禁用调试日志记录时跳过日志刷新跟踪循环 PR #4835
  • 在单个 BufferedChannel 写入中写入日志条目长度前缀和有效负载 PR #4833
  • 在 OrderedExecutor 中使用 ThreadLocalRandom 进行线程选择 PR #4832
  • 将旋转等待提示添加到 BlockingMpscQueue 生产者端繁忙循环 PR #4831

错误

  • 恢复“修复 sendResponseAndWait 中的读取线程阻塞导致 READ_ENTRY_REQUEST p99 延迟峰值 (#4730)”PR #4830
  • 当 BookKeeper client 构造函数失败时防止线程泄漏 PR #4798

依赖更新

  • 将 Jetty 升级到 12.1.10 并修复二进制许可证元数据 PR #4871
  • 将 org.apache.thrift:libthrift 从 0.23.0 提升到 0.24.0 PR #4874
  • 将 at.yawk.lz4:lz4-java 从 1.10.2 切换到 1.11.1 PR #4869
  • 在本机 io Rust 模块中将字节从 1.5.0 映射到 1.11.1 PR #4747
