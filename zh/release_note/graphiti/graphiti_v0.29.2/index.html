graphiti v0.29.2

修订 发布时间2026年6月8日 来源getzep/graphiti 英文原文

graphiti v0.29.2

这个项目是干啥的：一个给 AI 智能体用的时序知识图谱库，能记住并检索随时间变化的事实关系，给需要长期记忆的 Agent 开发者用。

变更架构图

亮点

  • MCP server 接近功能对齐 — PR #1553 让 MCP server 具备与核心库对齐的双时态查询、saga、社区、过滤器、三元组以及自定义实体/边类型；PR #1558 让读工具接受标量 group_id 而不只是列表；PR #1552 现代化 MCP SDK 和依赖集。如果你运行 MCP server，这是升级的头条理由；如果不运行，这些改动与你无关。

  • LLM 默认切换到 gpt-5.5 与更严格的结构化输出 — PR #1551 将默认模型改为 gpt-5.5，并将推理强度与模型绑定；PR #1537 让 OpenAIGenericClient 默认使用 json_schema，并以 json_object 兜底。PR #1146 和 #1535 改进 Ollama/OpenAI 兼容服务商支持，并将模型环境变量覆盖扩展到所有 MCP 配置，同时加入服务商路由测试。需要注意的行为变化：如果你依赖旧的默认模型或宽松的 JSON 输出，升级后请验证结构化输出仍能正确解析。

  • FalkorDB 修复批次与嵌入式后端 — PR #1125 新增 FalkorDBLite（嵌入式 FalkorDB），PR #1536 通过固定 redis<8 让嵌入式安装真正可用；PR #1549 修复默认 group_id 并为 RediSearch 转义，PR #1531 从参数中剥离 NUL 字节，PR #1126 / #1532 修复 docker-compose profile 和端口不匹配。FalkorDB 用户——尤其是嵌入式模式的采用者——应升级；请把 redis<8 约束作为迁移考量。

  • Kuzu 已弃用 — PR #1548 将 Kuzu 后端标记为弃用，并从默认测试矩阵中移除。它仍然存在，但默认不再测试，应视为即将退出。这是本版本唯一的弃用/破坏信号；没有硬性 API 移除或明确的迁移步骤，但 Kuzu 用户应规划迁移到其他后端。

  • CLI flag 修复，其余多为非运行时改动 — PR #1376 修复 --host 和 --port 在 apply_cli_overrides 中被忽略的问题，对用这些 flag 驱动 CLI 的用户有用。其余都是依赖/Dependabot 升级（#1528 清理 uv.lock 告警，以及 faker、ruff、pyyaml、anthropic）和仅 CI 的工作（Claude review 工作流、CLA Assistant 切换为 GitHub App token），对库行为没有影响——因此除 CLI 修复和上述项目外，基本属于维护版本。
