rust 1.89.0

小版本 发布时间2025年8月7日 来源rust-lang/rust 英文原文

rust 1.89.0

语言

  • 稳定显式推断的 const 参数 (feature(generic_arg_infer))
  • 添加默认警告 mismatched_lifetime_syntaxes lint。 此 lint 检测函数参数和返回值之间的不同语法类别何时引用相同的生命周期，这可能会导致阅读混乱，尤其是在不安全的代码中。此 lint 取代默认警告的 elided_named_lifetimes lint。
  • 扩展 unpredictable_function_pointer_comparisons 也可以检查外部宏中的函数指针比较
  • 默认拒绝 dangerous_implicit_autorefs lint
  • 稳定avx512目标特征
  • 稳定 x86 的 kl 和 widekl 目标功能
  • 稳定 x86 的 sha512、sm3 和 sm4 目标功能
  • 稳定LoongArch目标特征f、d、frecipe、lasx、lbt、lsx和lvz
  • 从improper_ctypes_definitions中删除i128和u128
  • 稳定repr128 (#[repr(u128)], #[repr(i128)])
  • 在任何地方都允许 #![doc(test(attr(..)))]
  • 扩展临时生命周期以也通过元组结构和元组变体构造函数
  • wasm32-unknown-unknown 目标上的 extern "C" 功能现在具有符合标准的 ABI

编译器

  • aarch64-linux 上默认为非叶框架指针
  • 为 Arm64EC Windows 启用非叶框架指针
  • 按架构设置 Apple 框架指针

平台支持

  • 添加新的Tier-3目标loongarch32-unknown-none和loongarch32-unknown-none-softfloat
  • x86_64-apple-darwin 正在通过主机工具降级到第 2 层 有关 Rust 分层平台支持的更多信息，请参阅 Rust 的平台支持页面。

图书馆

  • 指定file!的基本路径
  • 允许在变量中存储 format_args!()
  • 将#[must_use]添加到[T; N]::map
  • 为Lazy{Cell,Lock}实施DerefMut
  • array::IntoIter 实施 Default
  • slice::ChunkBy 实施 Clone
  • io::Take 实施 io::Seek

稳定的 API

  • NonZero<char>
  • x86 的许多内在函数，此处不一一列举
    • AVX512 内在函数
    • SHA512、SM3 和 SM4 内在函数
  • File::lock
  • File::lock_shared
  • File::try_lock
  • File::try_lock_shared
  • File::unlock
  • NonNull::from_ref
  • NonNull::from_mut
  • NonNull::without_provenance
  • NonNull::with_exposed_provenance
  • NonNull::expose_provenance
  • OsString::leak
  • PathBuf::leak
  • Result::flatten
  • std::os::linux::net::TcpStreamExt::quickack
  • std::os::linux::net::TcpStreamExt::set_quickack 这些以前稳定的 API 现在在 const 上下文中稳定：
  • <[T; N]>::as_mut_slice
  • <[u8]>::eq_ignore_ascii_case
  • str::eq_ignore_ascii_case

货物

  • cargo fix 和 cargo clippy --fix 现在默认与其他构建命令相同的 Cargo 目标选择。 以前它将应用于所有目标（如二进制文件、示例、测试等）。 --edition 标志仍然适用于所有目标。
  • 稳定 doctest-xcompile。 现在在交叉编译时测试 Doctest。就像其他测试一样，它将使用 runner 设置 来运行测试。如果需要禁用某个目标的测试，可以使用 ignore doctest attribute 指定要忽略的目标。

Rustdoc

  • 在移动设备上，使侧边栏全宽并换行。这使得长的部分和项目名称在移动设备上更容易处理。

兼容性说明

  • 使 missing_fragment_specifier 成为无条件错误
  • 在 aarch64-unknown-none-softfloat 上启用 neon 目标功能会导致警告，因为 LLVM 不正确支持具有和不具有该目标功能的混合代码
  • 大小层次结构：第一部分
    • 引入了一个小的重大更改，影响包含关联类型投影的递归类型上的 impls 的 ?Sized 边界。预计不会影响任何现有的已发布 crate。可以通过重构涉及的类型或选择 sized_hierarchy 不稳定功能来修复。有关代码示例，请参阅 FCP 报告。
  • 默认警告 elided_named_lifetimes lint 被默认警告 mismatched_lifetime_syntaxes lint 取代。
  • 类型检查器中较早的递归不透明类型出现错误
  • 要求数组重复表达式的元素类型导致的类型推断副作用是 Copy 现在仅在类型检查结束时可用
  • 已弃用的意外稳定的 std::intrinsics::{copy,copy_nonoverlapping,write_bytes} 现在是正确的内在函数。没有针对 UB 的调试断言，并且它们不能被强制为函数指针。
  • 删除长期弃用的 std::intrinsics::drop_in_place
  • 使格式良好的谓词不再共归纳
  • 检查 impl 方法兼容性时删除 hack
  • 删除由于内置特征对象实现而导致的不必要的类型推断
  • 针对非 x86-32 目标上的“stdcall”、“fastcall”和“cdecl”进行 Lint 处理
  • 与 never 类型 (!) 相关的未来不兼容警告现在在依赖项中报告
  • 确保 std::ptr::copy_* 内在函数也执行静态自初始化检查
  • wasm32-unknown-unknown 目标上的 extern "C" 功能现在具有符合标准的 ABI

内部变化

这些更改不会影响 Rust 的任何公共接口，但它们代表了 rustc 及相关工具的性能或内部结构的重大改进。

  • 使用 rustc-dev 组件正确取消重新映射编译器源路径
