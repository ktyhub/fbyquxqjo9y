rust 1.96.0

小版本 发布时间2026年5月28日 来源rust-lang/rust 英文原文

rust 1.96.0

语言

  • 允许将 expr 元变量传递给 cfg
  • 始终强制从不输入元组表达式
  • 在极少数情况下避免函数参数的错误推理指导
  • 支持内联汇编中的 s390x 矢量寄存器
  • 允许使用 ManuallyDrop 类型的常量作为模式（修复 1.94.0 中引入的回归）

编译器

  • 为LoongArch Linux目标启用链接松弛功能
  • 将 riscv64gc-unknown-fuchsia 基线更新为 RVA22 + 矢量

图书馆

  • 支持在 NonZero 整数范围内迭代
  • 重构“读/写有效”定义：排除 null；将其添加为单个方法的例外
  • 通过 ToSocketAddr 修复 SGX 延迟主机查找

稳定的 API

  • assert_matches!
  • debug_assert_matches!
  • From<T> for AssertUnwindSafe<T>
  • From<T> for LazyCell<T, F>
  • From<T> for LazyLock<T, F>
  • core::range::RangeToInclusive
  • core::range::RangeToInclusiveIter
  • core::range::RangeFrom
  • core::range::RangeFromIter
  • core::range::Range
  • core::range::RangeIter

货物

  • 允许依赖项指定 git 存储库和备用注册表。 就像 crates.io 一样，git 存储库将在本地使用，但发布时将使用注册表版本。
  • 在配置中添加了 target.'cfg(..)'.rustdocflags 支持。
  • 修复了 CVE-2026-5222 和 CVE-2026-5223。

Rustdoc

  • 弃用注释现在像任何其他文档一样呈现。以前他们使用 css white-space: pre-wrap; 属性并从渲染的 html 中删除任何 <p> 元素，但这会导致问题和不直观的行为。新的行为应该更可预测，但是一些多行弃用注释现在将呈现为单行。如果不希望出现这种情况，您可以使用标准 Markdown 方法强制换行，即两个空格后跟一个换行符 ("\n")。
  • 不要在 impl 项目上发出 rustdoc missing_doc_code_examples lint
  • 侧边栏中的单独方法和关联功能

兼容性说明

  • 修复涉及无人居住的零大小类型字段的某些边缘情况下 #[repr(Int)] 枚举的布局
  • 防止取消大小强制转换为 Pin<Foo>，其中 Foo 未实现 Deref。以前允许一些此类强制转换，但会产生没有有用的公共 API 的类型。
  • rustc：停止在 wasm 目标上传递 --allow-undefined
  • 意外稳定的#![reexport_test_harness_main]属性门
  • 类型过于私有的 return-position-impl-trait-in-traits 错误
  • 报告依赖项中的 uninhabited_static lint 并使其默认拒绝
  • 分布式版本现在包含 windows-gnu 的非分割调试信息 这似乎提高了回溯的质量。此更改对这些目标上 rustc/cargo 的默认输出没有影响。
  • 检查 const 泛型参数是否在更多位置正确键入
  • 删除-Csoft-float
  • 现在不再允许使用 ::{self [as name]} 导入结构，例如 struct S {}; use S::{self as Other};，因为 {self} 导入需要模块父级。
  • 对于 export_name、link_name 和 link_section 属性，如果存在多个相同属性，则第一个属性优先。
  • 将最小外部 LLVM 更新为 21
  • 在 avr 目标上，C 的 double 类型默认为 32 位，因此在 avr 目标上将 c_double 更改为 f32 以匹配。这是一个重大改变，但对于使 c_double 匹配 C 的双倍来说是必要的。
  • BTreeMap::append() 已优化，现在可能会导致具有不正确 Ord 实现的类型出现恐慌

内部变化

这些更改不会影响 Rust 的任何公共接口，但它们代表了 rustc 及相关工具的性能或内部结构的重大改进。

  • JSON 目标：aarch64 softfloat 目标现在必须将 rustc_abi 设置为 "softfloat"
  • 目标规范：更严格地检查 LLVM ABI 值，并将其与 cfg(target_abi) 相关联
