composio @composio/cli@0.6.0

这个项目是干啥的：给智能体连接各种外部应用的工具箱，让 AI 能直接操作 Gmail、Slack 等上百款软件。给做自动化 AI 助手的开发者用。

组合 CLI 0.6.0

这个次要版本带来了一致的开发人员项目和代理用户解决方案、明确的中断结果、侦听器故障控制以及从解析的命令输入派生的更安全的遥测。

变更架构图

亮点

  • 开发人员命令一致地解析执行用户和所选项目。 dev connected-accounts link 现在使用开发者项目，而根 link 保留其消费者项目行为。命令拒绝它们无法遵守的共享标志。
  • 由 SIGINT、SIGTERM 或 SIGHUP 中断的普通命令现在退出 130、143 或 129。订阅的侦听器可以通过 Ctrl+C 或 SIGTERM 干净地停止。 run 将信号转发到其子进程组并保留子进程的结果。
  • listen 和 dev triggers listen 支持 --fail-fast 接收器故障。 Toolkit 过滤器正确匹配包含下划线的段。
  • 连接列表包括帐户 ID、别名、单词 ID 和提供商显示名称（如果有）。本地文件上传保留其 MIME 类型，代理调用强制执行消费者权限。
  • 预期的命令失败会产生可操作的消息和失败的退出代码。升级输出不再重复过时的更新通知。
  • 遥测使用规范的注册身份和类型解析输入。拒绝的标志、脚本尾部选项、凭据、请求正文和标头值均从生命周期属性中排除。帮助和解析失败会忽略未解析的输入属性。
  • 贡献者演练、生成的命令目录和 CLI/Effect 技能配方描述了当前的架构。源链接示例和选定的调用合约在 CI 中运行。

迁移注意事项

  • 脚本必须处理新的中断退出代码，而不是将取消视为成功。
  • 开发者帐户链接需要可解析的开发者项目和代理用户。初始化工作目录或在需要时显式选择项目。
  • 如果工具包有多个没有 default 别名的帐户，请传递 --account <id|alias> 或分配默认别名，而不是依赖隐式最新帐户选择。

安装

curl -fsSL https://composio.dev/install | sh
composio --version

现有安装可以运行 composio upgrade。 CLI 0.5.0 的完整源码比较
