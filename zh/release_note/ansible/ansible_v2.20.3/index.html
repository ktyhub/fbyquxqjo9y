ansible v2.20.3

修订 发布时间2026年2月23日 来源ansible/ansible 英文原文

ansible v2.20.3

变更流程图

亮点

  • 委托异步轮询修复 — 当原任务使用 delegate_to 时，修正了 async_status 轮询的解释器发现逻辑（#86493）。此前 Ansible 可能在被委托主机上使用控制节点的 Python 路径，导致轮询失败；升级后无需再对 playbook 做变通处理。

  • 本地 become 可靠性提升 — 修正了密码检查时传给 become 插件的类型（#86473），恢复了本地 su 工作流——此前在检测到密码提示后可能卡住，尤其是在乌克兰语等本地化提示下。

  • action 插件报错更清晰 — _make_tmp_path 错误现在报告失败的原始命令，而不是内部 mkdtemp 数据类的表示形式（#86505）。临时目录失败更容易诊断，解析这些消息的自动化脚本也会少看到内部噪声。

  • collection 测试基础设施调整 — ansible-test 迁移到新的 Ansible Core CI 端点，并更新了 FreeBSD wheel 地址（#86499、#86496）。测试运行器应升级以避免 CI 服务或托管 FreeBSD provisioning 失败；这些变更不影响 playbook 执行。

无破坏性变更。

#Changelog 有关此版本中包含的更改，请参阅完整的 changelog。
