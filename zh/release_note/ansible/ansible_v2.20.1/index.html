ansible v2.20.1

ansible v2.20.1

这个项目是干啥的：一个不用装客户端就能批量管服务器的自动化运维工具，用简单脚本做配置和补丁更新，适合运维人员，这版主要是安全修复。

变更架构图

亮点

  • AnsibleModule.human_to_bytes() 修复 — 修正参数转发，使 isbits 不再绑定到独立 helper 的 default_unit 参数，恢复自定义模块预期的位/字节转换（#85259）。
  • get_url 校验和兼容性 — 带可变空白以及 ./ 或 * 文件名前缀的 GNU digest 清单现在能正确解析，避免有效下载因校验失败（#86134，修复 #86132）。
  • Python 3.13+ 容器支持 — 显示初始化和本地连接现在处理用户名查找抛出的 OSError，避免运行时 UID 在 /etc/passwd 中没有条目时崩溃（#86144）。
  • 更安全的变量文件诊断 — 无效的 vars_files、include_vars 以及主机/组变量现在指出有问题的文件，而不再转储变量内容，既便于定位失败，也减少意外秘密暴露（#86277）。
  • collection sanity 测试准确性 — runtime-metadata 比较版本时忽略预发布和构建后缀，避免诸如 3.0.0-prerelease collection 配 3.0.0 tombstone 的误报失败（#86159）。
  • 破坏性变更 — 无。

#Changelog 有关此版本中包含的更改，请参阅完整的 changelog。
