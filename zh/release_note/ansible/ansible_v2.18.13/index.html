ansible v2.18.13

修订 发布时间2026年1月29日 来源ansible/ansible 英文原文

ansible v2.18.13

变更流程图

亮点

  • 2.19 条件表达式迁移现在开始 — 回溯的检查（#86446）让 when 和 assert 对非布尔结果发出弃用警告；这些表达式将在 2.19 中默认失败，因为真值字符串、列表或数字会掩盖恒真逻辑。请用 ANSIBLE_ALLOW_BROKEN_CONDITIONALS=false 跑 CI，然后用显式布尔表达式或 | bool 替换隐式真值判断。
  • 修复 Windows LIB 被破坏 — Add-CSharpType 现在保留真实的环境值，而不再替换为 System.Collections.DictionaryEntry（#86438）。这防止在定义了 LIB 时 Windows 模块和自定义 PowerShell 自动化中的 Add-Type 编译失败；在适当之处可以移除受影响的 LIB: '' 变通做法。
  • RHEL 测试远程端升级 — ansible-test 用 9.7 替换 RHEL 9.4，用 10.1 替换 RHEL 10.0（#86378、#86391）。固定了旧远程标识符的 collection CI 作业需要更新；这在不改变被管节点运行时要求的前提下提升了覆盖。
  • 集成测试保障措施 — 新增一项 sanity 测试，捕获集成测试中的直接 S3 链接（#86467），有助于防止脆弱的 fixture 下载导致未来 CI 失败。这只影响测试基础设施，不影响 playbook 或模块行为。
  • 破坏性变更 — 2.18.13 中无。

#Changelog 有关此版本中包含的更改，请参阅完整的 changelog。
