新消息

  • DeepSeek-V4.1 在 H200 上每个 GPU 的吞吐量提高了 2.3 倍，现在在 AMD MI350X / MI355X 上运行，DSpark 的吞吐量提高了 1.9 倍（#41251、#41308）。
  • Qwen3.8-Flash-Next 在 B200 上的解码速度提高了 12%，在 B300 上使用 DFlash 的 GLM-5.3-Flash 解码速度提高了 10%（#42175、#42489）。
  • MiMo-V2.6-Pro 在 B300 上通过 DFlash 获得 1.85 倍的解码吞吐量 (#41886)。
  • 使用新的 InstantTensor 加载器 (#40453)，模型加载速度提高 10 倍。
  • 在长提示工作负载上，PD 分解可提高高达 27% 的吞吐量和一半的 p95 TTFT (#40703)。
  • HiSparse 现在支持 EAGLE 和 MTP，通过 CPU 内存中的 KV 缓存进行长上下文服务 (#37771)。
  • GLM-5.2 和 GLM-5.3 现在可以将解码上下文并行性与 MTP 结合起来，GLM-5.3 上的解码速度提高达 2.1 倍（#43735）。
  • SGLang 现在可以在具有标准 PyTorch 后端的 Apple Silicon Mac 上运行，以及 MLX (#36780)。
  • MiniMax-H3 和 Qwen-Image 2.1 现在使用 SGLang Diffusion 在 ComfyUI 中运行，它还加载社区 GGUF 检查点和 LoRA（#43504、#43581、#42556、 #39523、#42174)。
  • 重要修复：当推测解码和结构化输出一起使用时，混合线性模型可以从错误的曼巴状态恢复。感谢 @Wirick 和 Baseten 找到它 (#43029)。

重大变更和升级说明

  • SGLang 需要 Python 3.11 或更新版本。 在 Python 3.10 上，pip install sglang 不会失败；它解析为支持 3.10 的最后一个版本。移至 Python 3.11+（例如 Ubuntu 22.04 系统 Python）以获取此版本和更高版本：#43021
  • --enable-dp-attention 已弃用；使用 --attn-dp-size N。 --dp-size 现在仅计算模型副本。旧的 --dp-size N --enable-dp-attention 仍然解析为 --attn-dp-size N 并带有警告；将副本与注意力 DP 相结合，或传递两种拼写，在启动时会被拒绝：#41818。在 DeepSeek 上下文并行性下，--dp-size N 仍然表示注意力 DP，但现在发出警告，并将在 2026 年 12 月 31 日后被拒绝：#42348
  • --disaggregation-decode-host-receive-threshold 翻转其编码。 1（新的默认值）禁用主机接收，而 0 现在意味着始终在主机上接收。通过 0 禁用它的配置必须通过 1：#43407
  • ChunkCache 已删除。 对于 --disable-radix-cache，全注意力、混合 SWA 和 Mamba 模型在禁用模式下运行 UnifiedRadixCache，纯 SWA 模型运行 PureSWARadixCache (#43198、#43199、 #43200、#42354、#43201)。流媒体会话现在仅在 UnifiedRadixCache 上启动； pure-SWA、FlexKV 和插件树缓存在启动时失败，并出现“未验证”错误 (#42295)，并且波束搜索也拒绝使用 --disable-radix-cache 的 Mamba 模型 (#42354)
  • tc_piecewise 预填充 CUDA 图形后端已删除。 传递 --cuda-graph-backend-prefill tc_piecewise 或 tc_compiler 设置现在会引发错误； CUDA 保留 breakable 作为默认预填充图后端，其他平台默认没有预填充图：#42287
  • 重命名并停用环境变量。 SGLANG_AITER_MLA_DCP_DECODE_BACKEND 变为 SGLANG_AITER_MLA_DECODE_BACKEND，其默认值从 gluon 更改为 asm (#34537)； SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW 变为 SGLANG_OPT_RELEASE_PREFILL_SWA (#42657)；旧名称继续使用，并带有弃用警告。 SGLANG_DSPARK_FAST_SAMPLING、SGLANG_DSPARK_FOLDED_SAMPLING 和 SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV 已弃用，不再执行任何操作（#43622、#43668），并且 SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE 已弃用：#43444
  • OpenAI 聊天响应在三个小方面发生了变化。 tool_choice: "none" 不再显示 DeepSeek 模型的工具架构 (#43006)，省略缺失的 tool_calls 字段，而不是返回为 null (#43027)，并且流在其整个生命周期中保留一个 created 时间戳： #43026
  • --enable-layernorm-sp 因管道并行性而被拒绝。 之前第一次预填充失败：#43458
  • 对于模型和插件作者： ModelRunner.tp_group 已删除；在代码运行的范围内读取 get_parallel().tp_group (#41817)。 model.tp_size等未读的放置属性消失了；读取 get_parallel() (#41812)。声明阶段边界并在管道并行下运行的模型必须将其共享阶段声明 (stage_facts) 传递给 make_layers / make_pp_layers: #43460
