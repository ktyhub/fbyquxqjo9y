sglang gateway-v0.3.1

🚀 SMG v0.3.1 发布！

我们很高兴地宣布推出 SMG v0.3.1——这是一个改变游戏规则的版本，性能提高了 10-12 倍，缓存感知路由内存减少了 99%，并且具有企业级安全性！

🌲 基数树/缓存感知路由：速度提高 10-12 倍 + 内存减少 99% ⚡

对我们的缓存感知路由引擎进行全面优化，具有惊人的性能和内存增益：

性能改进

  • 我们的缓存感知路由现在可以每秒处理超过 216,000 次缓存插入（之前为 18,900 次），每次操作的延迟从 52.9 微秒降至仅为 4.6 微秒。
  • 对于跨 10,000 个树条目的前缀匹配，吞吐量从每秒 41,000 次操作跃升至 124,000 次操作。
  • 在 64 个线程的并发负载下，系统每秒处理 474,000 次操作，比之前的 59,000 次操作/秒提高了 7.9 倍。

数据处理

  • INSERT 操作现在的处理速度为 440 MB/s（之前为 38 MB/s），
  • MATCH 操作处理速度为 253 MB/s（高于 83 MB/s）。

内存改进：

  • 每个树节点内存减少约 99%：
  • 之前：每个节点约 180 KB（170 核机器上的 DashMap 默认配置）
  • 之后：每个节点~1.4 KB 结果：在相同的内存占用中部署多 100 倍的缓存条目！ 对于具有 10,000 个缓存前缀的典型部署，内存使用量从 ~1.8 GB 降至仅 ~14 MB，从而为实际推理工作负载释放资源。 影响：缓存感知路由现在速度提高了 10-12 倍，并且使用的内存减少了 99%。这对于大规模多租户部署至关重要。

🔐 JWT/OIDC 身份验证

控制平面 API 的生产级安全性，具有对行业标准 OIDC 提供商的本机支持：Google、Azure、Oracle、GitHub 等。使用您已使用的企业身份验证基础架构来保护令牌生成器管理、工作人员注册和管理端点。对于企业部署至关重要 - 将 SMG 无缝集成到您现有的身份和访问管理系统中。

📊 分类 API 支持

对分类工作负载的本机支持！通过专用管道阶段和协议类型，与现有推理队列一起部署和服务分类模型。

✨ 附加功能

  • PrefixHash 负载平衡：新的 KV 缓存感知负载平衡策略使用前缀哈希来提高多租户环境中的缓存命中率。
  • Nemotron Nano V3 解析器
  • 动态请求期限指标：跟踪动态请求期限，以实现更好的可观察性和 SLA 监控。

🛠️ 增强功能

开发者经验：

  • 将 CLI 参数组织成逻辑组
  • 缩短日志记录目标（sgl_model_gateway→smg）
  • 针对 HuggingFace 的全面嵌入正确性测试
  • 在wheel构建过程中自动生成protobuf文件

可靠性：

  • 修复外部 OpenAI 工作人员的 IGW 路由
  • 解决孤儿进程问题
  • 防止子流程处理中潜在的挂起
  • 使用 504 Gateway Timeout 表示上游超时（正确的 HTTP 语义）

🐛 错误修复

  • 修复了嵌入工人健康检查崩溃的问题
  • 修复了标记生成器以匹配变压器特殊标记处理
  • 修复了年龄桶渲染问题
  • 修复了非 PD 路由器 HTTP 标头白名单
  • 修复了响应 ID 中重复的分类前缀
  • 修复了多核机器上的 WASM 测试错误

⚡ 专为速度而生。专为规模而设计。经过生产验证。
