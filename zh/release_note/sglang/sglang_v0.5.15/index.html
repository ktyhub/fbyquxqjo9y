sglang v0.5.15

亮点

GLM-5.2 NVFP4，针对生产进行了调整：我们在本周期中花了一些时间在 Blackwell 上调整 GLM-5.2 NVFP4，以优化生产服务。现在，它在 8x B300 上的运行速度为 500+ tok/s/user，在 4x GB300 上的运行速度为 450 (bs=1)。使用我们的说明书 运行 GLM-5.2。

  • 默认情况下规范 V2：通过 CUDA 可绘制 DSA 草稿扩展进行零开销调度、删除 D2H/H2D 同步、融合元数据操作。 +11% 端到端 TPS（#29413、#29343、#29166、#29077）。
  • IndexShare MTP：在草稿步骤中重复使用索引器 top-k，在长上下文中草稿步骤成本最多降低 1.9 倍（#29959、#29787、#29654）。
  • TopK V2：将 top-k 选择与页表转换融合，运行时间 k 高达 2048（#30274、#26788）。
  • 索引器序言融合：12 个内核变为 4 个内核，在 bs=1 时解码速度加快约 8% (#27705)。
  • GEMM：用于 Blackwell 的形状专用 JIT 路由器 GEMM + CuteDSL BF16 GEMM（#21531、#30117）。
  • FlashInfer 自动调谐：现在涵盖草图模型图 (#29595)。 新模型支持：混元3(Hy3)、层次推理模型(HRM-Text)、NVIDIA LocateAnything-3B、百度无限-OCR、JoyEcho多镜头A/V，加上Qwen3.6 NVFP4支持。 本机网络搜索 (Exa)：Exa 支持的内置 web_search 支持 (#29342)。 默认情况下打开 Breakable CUDA Graph：Breakable CUDA Graph 现在是默认捕获路径，减少了每步内核启动开销（#29458）；对预填充阶段的完整 CUDA Graph 支持处于实验阶段（#27988）。 线性注意力内核 (KDA / GDN)：用于安全门 KDA 线性注意力的新 FlashKDA 预填充后端 (#29472)，加上用于线性注意力的 ReplaySSM 缓冲仅输出解码 (#28451)。 用于路由 MoE 的 FlashInfer A2A：使用 flashinfer_trtllm_routed MoE 运行程序 (#22394) 添加 FlashInfer all-to-all。 DeepSeek-V4 优化：
  • 使用请求状态池优化 C128 状态池分配（#28612）。
  • 现在 DeepSeek-V4 默认启用 FlashMLA 稀疏预填充，在长上下文中达到 >10% 的吞吐量增益。 （[#29775]（https://github.com/sgl-project/sglang/pull/29775））。
  • 非分页索引器支持长上下文预填充，具有 >5% 的 e2e 吞吐量增益。(#29619)。 解码上下文并行性：解码 MLA 模型的上下文并行性，包括 DeepSeek V3 和 Kimi K2 系列 (#14194)。 依赖项升级：transformers 升至 5.12.1 (#29393)； tvm-ffi / sgl-deep-gemm / tilelang 升级（[#29554]（https://github.com/sgl-project/sglang/pull/29554））。 和 。请参阅DeepSeek-V4 食谱。 按类别列出的完整 release note。
