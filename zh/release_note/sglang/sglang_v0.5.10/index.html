sglang v0.5.10

修订 发布时间2026年4月6日 来源sgl-project/sglang 英文原文

sglang v0.5.10

亮点

  • 默认启用分段 CUDA 图形：分段 CUDA 图形捕获现在是默认执行模式，可减少内存开销并提高具有复杂控制流模式的模型的吞吐量：#16331
  • 用于部分容错的 Elastic EP：将 Elastic NIXL-EP 集成到 SGLang 中，为 DeepSeek MoE 部署启用部分容错 - 当 GPU 发生故障时，系统 redistributes 专家权重并继续服务，无需完全重启：#19248、#17374、#12068 博客
  • 用于 PD 分解的 GPU 暂存缓冲区：将分散的头切片收集到连续内存中以进行批量 RDMA 传输，将 GQA 模型上的 RDMA 请求计数减少约 1000 倍。在 Qwen3.5 上使用 Prefill TP4+Decode DEP4，大并发上的 TPS/GPU 提高了约 5 倍：#19890
  • HiSparse 用于稀疏注意力：集成 HiSparse 稀疏注意力后端，通过稀疏感知注意力减少计算量，实现高效的长上下文推理：#20343
  • SGLang-扩散更新：
    • 模型支持：LTX-2、Hunyuan3D-2、Helios
    • Qwen-image、Z-image 的性能改进提高了 1.5 倍
    • 新平台：macOS
    • 新功能：通过集成 Cache-DiT 的所有优化来增强扩散器后端的性能
    • 技能：随意探索用于开发和优化俚语扩散的策划技能！
  • FlashInfer MXFP8 内核支持：集成用于 GEMM 和 MoE 操作的 FlashInfer mxfp8 内核，通过 RL 和一般工作负载的微缩放实现更高精度的混合精度 FP8 推理：#19537
  • 变形金刚 5.3.0 升级：从变形金刚 4.57.1 到 5.3.0 的重大升级，解锁对 HuggingFace 最新模型架构和功能的支持。此映像现在支持 GLM-5 模型，而不是自定义构建的映像：#17784
  • DeepSeek V3.2 / GLM-5 优化：GLM-5 可在主分支上运行（带有升级的变压器）。 用于预填充 KV 缓存获取的 Fused Triton 内核，用于 K 缓存的 NSA 熔丝存储索引器，SM100/SM103 上默认的 TRT-LLM 预填充/解码 DSA 内核，以及 IndexCache，可在高工作负载下将吞吐量提高 10% 以上：#19319， #19148、#20062、#21914、#21405
  • Qwen3.5 GDN/KDA 优化：将线性注意力状态布局从 [N, HV, K, V] 转置为 [N, HV, V, K]，并使用 Triton 内核在 GDN 投影中融合 split/reshape/cat 操作，加上 CuTeDSL KDA 解码内核支持以提高 Qwen3.5 性能：#20283、#21019、#21203
  • LoRA 对 MoE 层的支持：添加对具有 JIT 对齐内核、融合 Triton 内核、TP 支持、CUDA 图形支持和 LoRA 目标模块自动检测的专家混合层的 LoRA 微调支持 — 实现对 DeepSeek 等 MoE 模型的高效基于适配器的调整：#19710、#19711、#14105、#21439、#21647
  • MHA (Qwen3) 的预填充上下文并行：在 Qwen3 MoE 等多头注意力模型的预填充期间启用上下文并行，在 GPU 之间分配长序列以减少每个 GPU 内存并加速预填充：#18233
  • Flash Attention 4 官方库支持：升级到官方 FlashAttention 4 包，带来最新的注意力优化和 Blackwell GPU 支持：#20303
  • FlashInfer TRT-LLM Kernels 的 Skip-Softmax Attention：通过跳过冗余的 softmax 归一化来减少注意层中的计算开销：#19089
  • 使用 FA4 后端进行推测解码：为 FA4 注意力后端启用推测解码，将推测推理与下一代闪存注意力相结合以实现更快的生成：#21080
  • SM100 上的 MM Attention FA4 默认设置：多模态注意力现在在 Blackwell 硬件上默认使用 FA4，以提高 VLM 性能：#21595
  • 更强大的 Transformers 建模后端：增强的 Transformers 后端，具有完整的 TP、PP、MoE、VLM 支持和 torch.compile 兼容性：#19163
  • sglang-kernel 0.4.1：主要内核包版本，包含重命名包（sql-kernel → sglang-kernel）、合并内核以及清理已弃用的操作：#20440、#22009
  • Apple Silicon 的本机 MLX 后端：添加本机 MLX 执行后端，使 SGLang 能够直接在没有 CUDA 的 Apple Silicon Mac 上运行推理：#20342
