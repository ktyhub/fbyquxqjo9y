主要特点

  • PD 实例可以在预填充和解码之间动态切换，无需重新启动 (#28403)。
  • 前缀缓存现在默认在 Rust 核心上运行 (#39627)。
  • DeepSeek-V4.1 在长提示下第一个令牌的速度提高了 22% (#40352)。
  • Kimi K3 在 PD 服务中预填充吞吐量提高了 20.6% (#40045)。
  • GLM-5.3-Flash 现在在 AMD MI355X 上运行，具有 FP8 / MXFP4 MoE 和 MTP 推测解码（#38546、#39341、#39778）。
  • 在 PP、DP 注意和 CP 下获得更准确的结果，层通信现在由 SGLang 处理（指南、#41557）。
  • 新决策 API (/v1/decisions) 将 LLM / VLM 转变为低延迟分类器和评分器（文档、#41208）。
  • 分数 API (/v1/score) 在一个请求中对所有候选者进行评分（#38965、#41188）。
  • 在 ComfyUI 中运行带有 SGLang Diffusion 的 MiniMax-H3 (#35990)。

重大变更和升级说明

  • 统一基数树默认使用Rust核心。 Rust核心不支持自动回退到Python的配置；设置 SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python 以在各处强制使用 Python 核心：#39627
  • 为了数值准确性，FlashInfer MoE 融合最终确定默认关闭。这会造成一些 W4A4 MoE 延迟；设置 SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 恢复融合原子终结：#40105
  • PD 解码现在在 Mooncake 和 NIXL 后端上默认推迟中止时的 KV 释放，保留页面直到每个预填充等级确认（30 秒超时，SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT）。设置SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False恢复立即释放：#41023
  • 请求提供的聊天模板被拒绝。 /v1/chat/completions 或 /v1/tokenize 上的 chat_template_kwargs 内的 chat_template 密钥现在返回错误，除非服务器以 --trust-request-chat-template 启动；其他chat_template_kwargs不变：#28135
  • 已删除已弃用的端点、环境变量和别名。 使用 /model_info 代替 /get_weight_version 和 /weight_version，使用 /v1/loads 代替 /get_load，使用 POST /hicache/storage-backend/clear 代替 /clear_hicache_storage_backend。 SGLANG_NSA_* 别名让位于 SGLANG_DSA_*，SGLANG_ENABLE_SPEC_V2 消失了，--elastic-ep-rejoin 变为 --elastic-ep-join-mode recover，--kv-cache-dtype fp4_e2m1 变为 fp4_mx_block16，python -m sglang.bench_offline_throughput / sglang.bench_one_batch 移动到 sglang.benchmark.offline_throughput / sglang.benchmark.one_batch：#40795
  • 旧基数缓存实现已删除。 实验性 C++ 基数树 (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) 已消失 (#40775)，并且 SGLANG_ENABLE_UNIFIED_RADIX_TREE 不再执行任何操作，尽管它仍然打印弃用警告 (#40780)。导入 SWARadixCache、MambaRadixCache 或 HiRadixCache 的代码必须移至 UnifiedRadixCache：#40313、#40787
  • 自定义 logit 处理器必须返回全形状 logits。 返回简化形状（例如 (1, vocab)）并依赖于广播的 CustomLogitProcessor 现在会在解码时引发。内置处理器不受影响：#39234
  • RL 权重更新在会话内运行。 update_weights_from_tensor 和 update_weights_from_distributed 必须在 begin_weight_update() 和 end_weight_update() 之间调用。 UpdateWeightsFromTensorReqInput.disable_draft_model 被 selector="target" 取代，ChecksumInfo.parallelism_info 现在是一个列表，每个角色一个条目：#40777
  • 并行状态 getter 已弃用。 它们不再从 sglang.srt.distributed 重新导出；通过get_parallel()（例如get_parallel().tp_group）读取组或直接从parallel_state导入：[#40342]（https://github.com/sgl-project/sglang/pull/40342），[#40344]（https://github.com/sgl-project/sglang/pull/40344），[#40707]（https://github.com/sgl-project/sglang/pull/40707）
