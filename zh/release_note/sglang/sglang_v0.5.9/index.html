sglang v0.5.9

亮点

  • LoRA 权重加载与计算重叠：在推理期间将 LoRA 权重加载与计算重叠，在大型适配器上将 TTFT 减少约 78%，将 TPOT 减少约 34.88%：#15512
  • DeepSeek V3.2 的 TRT-LLM NSA 内核集成：集成 TRT-LLM DSA 内核以实现本机稀疏注意力，将 Blackwell 平台上的 DeepSeek V3.2 性能提高 3 倍至 5 倍，同时使用 trtllm 实现 —nsa-prefill-backend 和 —nsa-decode-backend （精度略有下降）：#16758、#17662、#18389
  • Flashinfer 多对多 MoE 调度程序：添加 Flashinfer 多对多 MoE 调度程序以实现高效的专家并行通信，从而在 MoE 模型中实现优化路由：#14668
  • FA4 (FP4 Attention) 支持多模态编码器：为多模态编码器引入 FP4 注意力后端和可变长度注意力功能，从而实现视觉语言模型的低精度推理：#13539
  • Anthropic 兼容 API 端点：将本机 Anthropic API 兼容性添加到 SGLang，允许直接与为 Anthropic API 格式构建的工具和 clients 集成：#18630
  • SGLang-Diffusion 高级优化：生产就绪的改进，包括令牌级序列分片、并行 VAE 解码、融合内核、Nunchaku 和 FP8 支持以及 ComfyUI 插件中的多个新模型：博客
  • Spec V2 严重错误修复：修复推测解码 v2 中由 torch 垃圾收集引起的索引外错误，提高推测验证的可靠性：#18958
  • 在 GB300 NVL72 上部署 DeepSeek：在 NVIDIA 最新的 GB300 平台上使用预填充解码分解和其他 SGLang 功能进行长上下文推理的优化工作：博客
  • 将 AITER 版本升级为 0.1.10.post3：支持 FP8 预填充/解码/KV 缓存
  • 在 docs.sglang.io 中进行提交版本查找：轻松查找包含给定 PR 或提交的最早正式版本，简化用户和开发人员的发布跟踪：#18450，链接
