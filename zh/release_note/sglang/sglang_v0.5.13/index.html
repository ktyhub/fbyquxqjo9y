sglang v0.5.13

这个项目是干啥的：一个高性能大模型推理框架，把模型部署成响应快、成本低的在线服务，给需要大规模跑模型的应用开发者和企业用。

变更架构图

亮点

新模型支持：

  • 自回归：Nemotron 3 Ultra（第 0 天，博客），Step-3.7-Flash，命令 A+
  • 扩散：Cosmos3、LingBot-World、SANA-WM、Ernie-Image、FLUX.2-Klein 4B/9B、表意文字4 Spec V2 现在是默认的推测解码路径：topk > 1 的树起草可在 triton / FA3 / MLA / aiter 后端进行生产准备，包括 page_size > 1 和 Mamba/混合线性模型 (#26997、#26972、 #27463)。 Spec V1 已弃用，EAGLE/MTP 现在在统一的 V2 Worker 上运行 (#25464)，并且 topk = 1 起草速度更快 (#26397、#26424）。 降低每步调度程序开销：统一的异步值通过 FutureMap 传递，加上将预填充输入传输移动到前向流，减少了每步启动开销并提高了高并发下的稳定性（#25945、#25879、#26380）。 分段和可破坏 CUDA 图表覆盖：分段 (PCG) 和可破坏 (BCG) CUDA 图表捕获更多模型以减少每步内核启动开销，现已扩展到 DSA 模型、Kimi-K2.5 和 DeepSeek V4：#23351、#26382、 [#25195]（https://github.com/sgl-project/sglang/pull/25195）。 Blackwell 上更快的 Qwen 3.5：新的 FlashInfer Gated DeltaNet (GDN) 内核和 CuTeDSL GDN 预填充内核可加快 Blackwell GPU 上的 Qwen 3.5 速度：#22921、#23273、#26200。 默认情况下用于混合模型的 HiCache：HybridModel (SWA/Mamba) 默认情况下通过 UnifiedTree 启动 HiCache，将分层 KV 缓存卸载带到开箱即用的滑动窗口和 Mamba 混合模型中：#27759。 异构 CPU + GPU EPD 分解（使用 Intel）：将 VLM 视觉编码与 GPU 一起卸载到 Intel Xeon CPU 上，负载下的 P99 TTFT 和请求吞吐量增益高达约 1.3 倍。 （博客） AMD Instinct MI355X 上的 MoRI（与 AMD）：通过 AMD 的 MoRI 通信库进行具有成本竞争力的 DeepSeek-R1 分类推理，每百万代币 0.169 美元，速度为 129 tok/s/用户。 （博客） DeepSeek V4 — 上下文并行性和稀疏注意力内核：v0.5.13 在 v0.5.12 Day-0 路径上构建，将 DeepSeek-V4 扩展到上下文并行服务并添加其稀疏注意力内核：
  • 上下文并行 + MTP：#24934
  • 上下文并行 + 融合 MoE 内核（非 DeepEP）：#24947
  • 通过 flash_mla_sparse_fwd 的稀疏 FlashMLA：#25418
  • FP4 索引器支持：#26209
  • SM120 支持：#24692
  • DeepEP 充水负载平衡：#25391
  • MHC 内核预热：#25810
  • DeepSeek V4 的可破坏 CUDA 图表：#25195
  • 由 sql-kernel 0.4.3 支持，公开 sgl_kernel.flashmla：#26421、#26132 有关调整后的部署命令，请参阅 DeepSeek-V4 说明书。 SGLang-Diffusion — 实时和渐进分辨率：OpenAI 风格的实时视频生成，具有 msgpack 帧流和独立浏览器 WebUI（#26954、#26959）、连续摄像机控制 + 超分辨率控制（#27026、 #27297)，以及跨 FLUX / FLUX.2 / Qwen-Image / Wan / Z-Image (#27524) 的渐进分辨率增长。
