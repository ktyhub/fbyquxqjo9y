用于 RL 部署的采样掩码。 使用 return_sampling_mask，每个解码步骤都会返回采样器从中提取的准确标记支持以及其下采样标记的对数概率，因此训练人员可以重播部署，而无需重建 top-k 或 top-p (#36630)。掩码现在在重叠调度下运行：在 Qwen3-8B 上，与之前的实现相比，第 1 批的解码吞吐量提高了 17%，第 64 批的解码吞吐量提高了 52%。容量由 --sampling-mask-max-tokens 设置（默认 4096）（#36631）。 DisallowedTokensLogitsProcessor 与掩码一起受支持 (#38279)。
统一基数树。 SWA 组件的分支点缓存将滑动窗口状态保留在请求从共享前缀分叉的点，因此分支会重用它而不是重新计算。在具有共享系统提示的 DeepSeek-V4-Flash 上，令牌命中率从 43.8% 上升到 60.8%，平均 TTFT 从 1.57 下降到 1.07 (#34565)。选择加入的外部链接器允许树通过 Mooncake 或 UMBP 寻址共享全局内存池（#37381）。
PD 下的 DSpark 具有解码上下文并行性。 DCP1 预填充现在可以将其 DSpark 草稿 KV 传输到 DCP-N 解码，因此 Kimi-Linear 等混合模型以分解的上下文并行服务运行 DSpark。在 8x B300 上通过 NIXL 和 Mooncake 高达 256K 输入进行验证 (#37709)。
响应 API 存储是选择加入的。 /v1/responses 不再将结果保留在内存中，除非服务器以 --enable-response-store 启动。如果没有它，检索、previous_response_id 链接和后台请求将返回 400； PD 部署无法启用它 (#39122)。
SGLang 模拟器。 仅 CPU 模拟器运行真正的调度程序、基数缓存和分层缓存，并用延迟预测器代替模型转发。根据测量的服务轨迹，它预测大多数轨迹上的 TTFT 在 6% 左右（最长的 32K 到 128K 轨迹上可达 10%），并且前缀重用在 0.05 个百分点内，用于没有 GPU 的缓存和调度研究 (#33824)。
预填充上下文并行性 v1 已删除。 基于策略的实现现在是唯一的预填充 CP 路径； v1 运行时及其 CLI 选项已消失。 HIP、NPU 和 MUSA 上的预填充 CP 将被拒绝，直到这些平台被移植为止 (#36228)。
在 ROCm 上加载模型速度更快。 大型可分页主机到设备副本是暂存的，而不是固定到位的，这会阻止驱动程序在每次驱逐时挂起 GPU 队列。 GLM-5.2 在 TP4 上的 4x MI355X 上加载 40.4 而不是 505.7 (#37720)。
Intel XPU 加入发布映像。 每个标记版本现在都会从 XPU Docker 文件构建和发布 lmsysorg/sglang:vX.Y.Z-xpu，因此 Intel GPU 用户可以获得版本化映像，而不是依赖夜间构建 (#37340)。
Blackwell 上的 DeepSeek-V4。 TRT-LLM 注意力内核现在覆盖 SM100 和 SM103 上的 DeepSeek-V4 的 CSA 和 HCA 层：在 B200 上的内核级别，预填充速度比 FlashMLA 快大约 1.2 倍，解码速度快 1.45 倍（#30805）。 FlashInfer MegaMoE 的型号为 --moe-runner-backend flashinfer_megamoe；在 TP4/DP4 的 DeepSeek-V4-Flash NVFP4 上，每级 8192 个令牌的预填充吞吐量总计达到 11.9%，解码时的 trtllm 运行器饱和度在 2% 以内（#31470）。
RTX PRO 6000 上的 DeepSeek-V4。 在 SM120 上，稀疏 MLA 索引器现在在 DeepGEMM 的分页 MQA 内核上运行，并且 DeepGEMM FP4 MoE 后端已启用，取代了唯一工作路径的火炬回退。在 4x RTX PRO 6000 上，DeepSeek-V4-Flash 解码 TPOT 在批次 1 中从 36.1 下降到 10.5 毫秒，TTFT 从 8K 输入下降到 128K 输入下降 20%。通过 PR 中的环境标志选择加入 (#29927)。
依赖关系和图像。 CUDA 12 通道已退役； v0.5.19 是带有 -cu12x 车轮和图像的最后一个版本 (#38404)。 sglang-kernel 移动到 0.4.7 (#39346)，sql-deep-gemm 移动到 0.2.0 (#39371)。新图像：适用于 MI30x 和 MI35x 的 ROCm 10，具有匹配的内核轮 (#38763)、适用于 Strix Halo / Ryzen AI MAX+ 的 gfx1151 (#33939) 和 Moore Threads MUSA (#36709)。 ROCm 7.0 CI、图像和内核轮已停用（#38632、#38767）。
