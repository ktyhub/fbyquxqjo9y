sglang v0.5.8

亮点

  • 所有主要扩散型号 https://lmsys.org/blog/2026-01-16-sglang-diffusion/ 全面提速高达 1.5 倍
  • 接近线性缩放，具有超长百万令牌上下文 https://lmsys.org/blog/2026-01-15-chunked-pipeline/ 的分块管道并行性
  • 优化 GLM4-MoE 进行生产：TTFT https://lmsys.org/blog/2026-01-21-novita-glm4/ 速度提高 65%
  • EPD 分解：视觉语言模型 https://lmsys.org/blog/2026-01-12-epd/ 的弹性编码器缩放

新模型支持

  • 第 0 天对 GLM 4.7 闪存的支持：#17247
  • LFM2 模型支持：#16890
  • Qwen3-VL-Embedding 和 Qwen3-VL-Reranker 模型支持：#16635、#16403
  • DeepSeek V3.2 NVFP4：https://huggingface.co/nvidia/DeepSeek-V3.2-NVFP4
  • 扩散 black-forest-labs/FLUX.2-klein-9B

DeepSeek V3.2 优化

  • 上下文并行优化，支持融合 MoE、多批次和 FP8 KV 缓存：#13959

闪光注意 4

  • 支持 Flash Attention 4 解码内核：#16034

SGLang-扩散

  • 使用扩散器后端运行 sglang-diffusion
  • 功能：多 LoRA 推理、SLA 注意后端、CLI 中的预热开关、ComfyUI 插件
  • 所有型号的性能改进

依赖关系

  • sql 内核更新为 0.3.21：#17075
  • Cutedsl 更新为 4.3.4：#17075
  • 添加了 tvm-ffi 和 quack-kernels 的依赖项：#17075
  • Flashinfer 更新为 0.6.1：#15551
  • 月饼传输引擎更新为 0.3.8.post1：#16792

安全

  • 修复了 urllib 和 gpgv 漏洞：#17439
