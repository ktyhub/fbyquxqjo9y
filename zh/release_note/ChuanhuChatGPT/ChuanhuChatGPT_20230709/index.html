ChuanhuChatGPT 20230709

这个项目是干啥的：是一个给ChatGPT套的网页界面，把GPT-4、视觉模型和本地运行的开源模型都装进去，让不懂命令行的人也能在浏览器里聊天传文件。

变更架构图

亮点

  • 必须升级 Gradio — 本版本目标为 Gradio 3.36.1。拉取 20230709 后请运行 pip install -r requirements.txt；沿用旧环境会有启动和 UI 不兼容的风险。
  • Gradio 样式迁移 — 布局/样式选项现在通过组件构造函数传入，而非已弃用的 .style() 调用，遵循 gradio-app/gradio#4374。自定义 UI 包装层也应同样迁移，以消除弃用警告并为 Gradio 未来移除做准备。
  • 可配置 LaTeX 渲染 — 新增 latex_option，可取 default、strict、all 或 disabled。用 strict 避免把单美元符号当作数学公式，all 启用 equation、align、CD 等环境，disabled 则关闭渲染。
  • 空白消息拦截 — 纯空白输入现在会让发送按钮保持禁用，并在提交前被裁剪，防止误触发空模型调用和历史条目。该校验在客户端，因此 API/服务端集成仍需自己的检查。
  • 部署可靠性修复 — 更新检查现在比较 GitHub release 的 created_at 时间戳并把提交时间归一到 UTC，消除误报”有可用更新”。PR #827 在 Clipboard API 不可用时增加 textarea/document.execCommand('copy') 回退，恢复内网部署的复制行为。
  • 兼容性 — 文档未记录破坏性变更。

注意，本次更新需要您更新 gradio，请在更新后执行pip install -r requirements.txt
