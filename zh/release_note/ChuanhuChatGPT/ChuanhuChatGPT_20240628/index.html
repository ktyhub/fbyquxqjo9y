ChuanhuChatGPT 20240628

这个项目是干啥的：是一个给ChatGPT套的网页界面，把GPT-4、视觉模型和本地运行的开源模型都装进去，让不懂命令行的人也能在浏览器里聊天传文件。

变更架构图

亮点

  • 自定义模型登场 — 本版本的头条能力：用户自定义模型配置成为一等公民，为内置供应商之外的自托管和第三方端点打开大门。这实际上是一个破坏性新增——升级前应对照新的 自定义模型 wiki 检查现有配置，因为模型定义和选择行为现在可被扩展，可能改变此前的假设。
  • GPT-4V 并入 GPT-4-Turbo — 对锁定 GPT4-V 模型标识符的人是真正的破坏性变更：具备视觉能力的 GPT-4 现在归到 GPT-4-Turbo 条目下，保存的预设、脚本或配置中引用旧模型名的都必须迁移，否则解析结果会不同。升级后视觉请求将走 Turbo 路径。
  • 暂时禁用 LaTeX 渲染 — Gradio 上游回归迫使维护者暂时关闭 LaTeX 数学渲染。若你的工作流或分享的聊天输出依赖公式渲染，这是值得注意的可见行为回退——在 Gradio 问题修复、后续版本恢复渲染前，请围绕它做好规划。
  • 新增供应商：Groq、GPT-4o、Claude 3.5 Sonnet — 三个模型后端一次性落地，显著扩展延迟/价格/质量的选择空间：Groq 主打快速推理，GPT-4o 是 OpenAI 最新模型，Claude 3.5 Sonnet 面向 Anthropic 用户。采用者应核对 API key/凭据和模型选择默认值，因为新条目的加入改变了 UI 中”默认”或推荐模型的含义。
  • 在线 RAG 切换到 text-embedding-3-large — 一个安静但影响重大的改动：在线 RAG 管线现在使用 OpenAI 维度更高的 text-embedding-3-large 嵌入模型。这会影响嵌入质量和 API 成本，也可能改变检索排序——如果你有用旧嵌入模型建立的持久化索引，请寻找重建索引或兼容步骤，别假定其向量仍然有效。
  • 手动更新者的迁移提示 — 如果你手动更新而非通过内置更新器，更新后必须运行 pip install -r requirements.txt --upgrade；新增了依赖，跳过会导致运行时失败。另有两个 UI 层面的变化需留意：前端高度改用 dvh 单位（标记为可能有浏览器兼容问题），config_example.json 把 PaLM 更名为 Gemini——若你维护自定义配置或面向旧浏览器，都应检查。
