ChuanhuChatGPT 20230916

变更流程图

亮点

  • 基于 Gradio 的 UI/UX 全面重建 — 界面端到端重做：自适应的历史面板 + 菜单栏 + 聊天区 + 工具栏、玻璃拟态风格、重做的输入框、带安全区边距的移动端布局，以及抽屉式工具栏/设置。这是视觉和交互的大改，不是开关式功能，所以自定义 CSS、主题和 UI 驱动的测试很可能要坏；这个版本把 Gradio 钉在 3.34.2。
  • 对话历史变成可管理的列表 — 历史现在以列表展示，支持重命名和删除，名字从第一个问题和内容摘要自动生成，支持含正则的名字搜索，下载/导出和上传历史也改进了。对用户来说聊天记录变成了可移植、可搜索的数据；对集成方来说历史的导出/导入路径变了，要重新测试。
  • 可安装的 PWA 目标 — Chuanhu Chat 现在可作为 PWA 安装：桌面浏览器会弹安装提示，手机浏览器提供”添加到主屏幕”，图标也重新设计过，裁剪和独立显示都好看。自托管者得到一个类应用的 Web 部署，但需要有效的 manifest 和通过 HTTPS 提供的 service worker，安装入口才会出现。
  • 模型层扩展与保留上下文的切换 — 新增讯飞星火支持和应用内 GPT-3.5 微调，并允许在同一对话里切换模型同时保留之前的上下文。对接 provider 的人来说这是影响最大的变化：加后端或让用户换模型不再强制清空上下文，这改变了多 provider 回退的设计方式。
  • 更丰富的输入区与可操作的消息气泡 — 网页搜索、基于文件的问答和单轮模式可以直接从输入区启用，气泡在最新一条消息上暴露删除、重试和点赞。以前在独立面板里的能力挪进了输入框，减少了 UI 面积，但改变了自动化和测试要走的交互路径。
  • 手动升级路径与运行时变化 — 从 20230911 beta 过来的用户可能发现应用内更新按钮没反应，必须手动更新，然后跑 pip install -r requirements.txt 刷新依赖。另注意 Gradio 升到 3.34.2、日志级别设为 info、语言环境别名同时接受 en_US 和 en-US 两种写法、只读历史现在只在未登录且设了 hide_history_when_not_logged_in 时生效，以及 Azure OpenAI、文件解析失败隔离、Windows 路径和气泡溢出的修复。

    现在有了更完善优雅的历史记录下载导出与上传功能，数据随时下载到本地。
