optimum v1.24.0

Release Notes：最佳 v1.24.0

我们很高兴地宣布发布 Optimum v1.24.0。此更新扩展了基于 ONNX 的模型功能，并包括多项改进、错误修复和社区的新贡献。

:rocket：新功能和增强功能

  • ORTQuantizer 现在支持具有 ONNX 子文件夹的模型。
  • ONNX 运行时 IO 绑定支持，适用于所有受支持的 Transformer 模型（不遗漏任何模型）。
  • SD​​3 和 Flux 模型支持 添加到 ORTDiffusionPipeline，支持最新的基于扩散的模型。
  • Transformers v4.47 和 v4.48 兼容性，确保与 Hugging Face 生态系统的最新进展无缝集成。
  • ONNX 导出支持扩展到各种模型，包括 Decision Transformer、ModernBERT、Megatron-BERT、Dinov2、OLMo 等（查看详细信息）。

:wrench：关键修复和优化

  • 不再支持 Python 3.8
  • ModelPatcher、SDXL 精炼机导出和设备检查中的 错误修复，以提高可靠性。
