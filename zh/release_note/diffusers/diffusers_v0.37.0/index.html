diffusers v0.37.0

小版本 发布时间2026年3月5日 来源huggingface/diffusers 英文原文

模块化扩散器

模块化扩散器引入了一种通过组合可重复使用的块来构建扩散管道的新方法。您现在可以混合和匹配构建块来创建适合您的特定需求的自定义工作流程，而不是从头开始编写整个管道！这补充了现有的 DiffusionPipeline 类，提供了更灵活的方式来创建自定义扩散管道。 此处 了解有关如何开始使用模块化扩散器的更多详细信息，并查看公告帖子。

新管道和模型

图片🌆

  • Z Image Omni Base：Z-Image 是 Z-Image 系列的基础模型，专为高质量、强大的生成多样性、广泛的风格覆盖和精确的及时遵守而设计。虽然 Z-Image-Turbo 是为了速度而构建的，但 Z-Image 是一款全功能、未经蒸馏的转换器，旨在成为需要最高水平创作自由度的创作者、研究人员和开发人员的支柱。感谢@RuoyiDufor 在#12857 中做出的贡献。
  • Flux2 Klein：FLUX.2 [Klein] 将生成和编辑统一在一个紧凑的架构中，以低至一秒的速度提供最先进的质量和端到端推理。专为需要实时图像生成而不牺牲质量的应用程序而构建，并在消费类硬件上运行，VRAM 低至 13GB。
  • Qwen Image Layered：Qwen-Image-Layered 是一个能够将图像分解为多个 RGBA 层的模型。这种分层表示解锁了固有的可编辑性：每个层都可以独立操作，而不影响其他内容。感谢 @naykun 在 #12853 中做出的贡献。
  • FIBO Edit：Fibo Edit 是一种 8B 参数图像到图像模型，引入了结构化控制的新范例，在与源图像配对的 JSON 输入上进行操作，以实现确定性和可重复的编辑工作流程。它具有可实现精细精度的原生掩码，超越了简单的基于提示的扩散，提供针对生产环境优化的明确、可解释的控制。其轻量级架构专为深度定制而设计，使研究人员能够为特定领域的任务构建专门的“编辑”模型，同时提供顶级的美学质量。感谢 galbria 在 https://github.com/huggingface/diffusers/pull/12930 中做出的贡献。
  • Cosmos Predict2.5：Cosmos-Predict2.5，Cosmos World Foundation Models (WFM) 系列的最新版本，专门用于模拟和预测世界的未来状态。感谢@miguelmartin75 在#12852 中做出的贡献。
  • Cosmos Transfer2.5：Cosmos-Transfer2.5 是一种具有自适应多模态控制的条件世界生成模型，可根据多个控制输入生成高质量的世界模拟。这些输入可以采用不同的模式，包括边缘、模糊视频、分割图和深度图。感谢@miguelmartin75 在#13066 中做出的贡献。
  • GLM-Image：GLM-Image是一种图像生成模型，采用混合自回归+扩散解码器架构，有效推动视觉保真度和细粒度细节的上限。在一般图像生成质量方面，它与基于 LDM 的行业标准方法保持一致，同时在知识密集型图像生成场景中展现出显着优势。感谢 @zRzRzRzRzRzRzRzR 在 https://github.com/huggingface/diffusers/pull/12973 中的贡献。
  • RAE：表示自动编码器（又名 RAE）是传统 VAE 的令人兴奋的替代品，通常用于图像生成的潜在空间扩散模型领域。 RAE 利用预先训练的视觉编码器并训练轻量级解码器来完成重建任务。

视频 + 音频 🎥 🎼

  • LTX-2：LTX-2 是一种音频调节的文本到视频生成模型，可以生成带有同步音频的视频。支持完整模型推理和蒸馏模型推理，以及空间采样的两阶段推理。我们还支持条件管道，允许传递不同的条件（例如图像、图像系列等）。查看文档以了解更多信息！
  • Helios：Helios 是一种 14B 视频生成模型，在单个 NVIDIA H100 GPU 上以 17 FPS 运行，支持分钟级生成，同时满足强大的质量基准。感谢@SHYuanBest 在 https://github.com/huggingface/diffusers/pull/13208 中贡献此内容。
