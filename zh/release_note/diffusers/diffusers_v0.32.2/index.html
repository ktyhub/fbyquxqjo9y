diffusers v0.32.2

修订 发布时间2025年1月15日 来源huggingface/diffusers 英文原文

diffusers v0.32.2

这个项目是干啥的：Hugging Face 出品的扩散模型工具库，用它调用 Flux 等模型生成图片和音频，上手也快。给做 AI 绘画和多媒体生成的开发者用。

变更架构图

亮点

  • Flux 单文件加载 — 修复了导致 Flux Dev 微调的 Comfy UI 格式单文件 checkpoint 无法加载的回归问题（#10545）。依赖该 checkpoint 格式的用户应升级；文档未说明迁移步骤。
  • Flux LoRA 兼容性 — 恢复扩展 Flux LoRA 的多 LoRA 加载与卸载可靠性，并新增对 bitsandbytes 4bit 量化 Flux 模型 LoRA 的支持（#10578）。如果你会组合或动态切换 LoRA，这项修复尤其有价值。
  • Flux Control 生命周期 — 为 Flux Control 新增 unload_lora_weights()（#10206），让 Control 流程有受支持的方式移除已应用的 LoRA 权重。
  • Hunyuan Video 修复 — 解决 batch size > 1 时的失败、注意力掩码维度 bug，以及 PyTorch < 2.5 下的 NaN 问题；同时支持加载用原始仓库代码创建的 LoRA。如果你批量提交提示词、使用较旧 PyTorch 或原始格式 LoRA，值得升级。
  • 升级建议 — 这是一个功能性补丁版本，不是重新打标或仅改元数据的更新。未发现破坏性变更或必需的迁移步骤；受影响的 Flux 和 Hunyuan Video 用户应升级，不走这些路径的负载可以合理跳过。

修复 Flux 单文件加载、4bit BnB Flux 的 LoRA 加载、Hunyuan Video

该补丁版本

  • 修复了 Flux 的 Comfy UI 格式单文件 checkpoint 加载回归问题
  • 修复了 bitsandbytes 4bit 量化 Flux 模型加载 LoRA 的回归问题
  • 为 Flux Control 新增 unload_lora_weights
  • 修复了 Hunyuan Video 在 batch size > 1 时无法运行的问题
  • 允许 Hunyuan Video 加载用原始仓库代码创建的 LoRA
