Scrapling v0.3

小版本 发布时间2025年9月1日 来源D4Vinci/Scrapling 英文原文

🎉 主要版本 - 完整的架构检修 Scrapling v0.3 代表了该项目历史上最重要的更新，具有完整的架构重写、相当大的性能改进和强大的新功能，包括 AI 集成和交互式 Web Scraping shell 功能。 此版本包含多项重大更改；请仔细查看 release note。

🚀 主要新功能

基于会话的架构

  • 新会话类：完全重写，引入持久会话支持
    • FetcherSession - 具有持久状态管理的 HTTP 请求，适用于同步和异步代码
    • DynamicSession/AsyncDynamicSession - 浏览器自动化，同时保持浏览器打开直到完成
    • StealthySession/AsyncStealthySession - 隐秘浏览，同时保持浏览器打开直到完成
  • 异步浏览器选项卡管理：新的选项卡池功能通过 max_pages 参数旋转浏览器选项卡以实现并发浏览器获取
  • 并发会话：同时运行多个隔离会话 有关更多详细信息，请参阅网站上的 Fetching 部分。

许多新的隐形/反机器人功能

  • 🤖 Cloudflare Solver：StealthyFetcher 及其会话类中的自动 Cloudflare Turnstile 挑战解决
  • 浏览器指纹模拟：使用全新的 Fetcher 类模仿真实浏览器的 TLS 指纹、版本匹配的浏览器标头、HTTP/3 支持等
  • 改进的隐身模式：DynamicFetcher 及其会话类的隐身模式现在更加强大和可靠（又名 PlayWrightFetcher）

AI 集成和 MCP 服务器

  • 内置 MCP 服务器：用于 AI 辅助 Web scraping 的模型上下文协议服务器
  • 6 个强大的工具：get、bulk_get、fetch、bulk_fetch、stealthy_fetch、bulk_stealthy_fetch
  • 智能内容提取：将网页/元素转换为 Markdown、HTML，或提取文本内容的干净版本
  • CSS 选择器支持：在将内容交给 AI 之前，使用 Scrapling 引擎精确定位特定元素
  • 反机器人绕过：处理 Cloudflare Turnstile 和其他保护
  • 代理支持：使用代理进行匿名和地理定位
  • 浏览器模拟：使用 TLS 指纹识别真实浏览器、与该版本匹配的真实浏览器标头等来模仿真实浏览器
  • 并行处理：同时抓取多个 URL 以提高效率
  • 以及更多…

新的交互式 Web Scraping Shell

  • 新外壳：自定义 IPython 外壳，具有许多智能内置快捷方式，如 get、post、put、delete、fetch 和 stealthy_fetch
  • 智能页面管理：新命令 page 和 pages 自动存储通过 shell 完成的所有请求的当前页面和历史记录
  • Curl 集成：将带有 uncurl 和 curl2fetcher 函数的浏览器 DevTools curl 命令转换为 Fetcher 请求
  • 以及更多…

从终端抓取，无需编程

  • 新提取命令：基于终端的 scraping 无需编程
    • scrapling extract get/post/put/delete - 简单的 HTTP 请求
    • scrapling extract fetch - 动态内容 scraping
    • scrapling extract stealthy-fetch - 反机器人绕过
  • 下载网页并将其内容保存到文件中。
  • 将 HTML 转换为可读格式（如 Markdown），将其保留为 HTML，或者仅提取页面的文本内容。
  • 支持自定义 CSS 选择器来提取页面的特定部分。
  • 处理 HTTP 请求并通过浏览器获取。
  • 高度可定制，具有自定义标头、cookie、代理和其余选项。几乎所有通过代码可用的选项也可以通过终端访问。
  • 以及更多…

🔧 技术改进

性能增强

  • Fetcher 现在速度提高了 4 倍 - 是的，您没看错！
  • DynamicFetcher 现在速度加快约 60% - 速度更快的版本，具体取决于您的配置（尤其是隐身模式）
  • StealthyFetcher 现在速度提高了 20–30% - 使用新结构，并开始使用我们的实现而不是 Camoufox Python 接口
  • 跨核心选择方法（find_by_text、find_similar、find_by_regex、relocate 等）的综合速度增益超过 50% 🚀
  • ~10% CSS/XPath 优先方法速度提升 - css_first 和 xpath_first 现在比 css 和 xpath 更快
  • 内容提取 get_all_text() 方法快 40%
  • 自适应元素重定位速度提高 20%
  • 导航属性优化 — next、previous、below_elements 等属性现在明显更快
  • 文本清理速度提高 5 倍操作
  • 通过优化导入和减少开销提高内存效率
  • ⚡ 闪电般的导入：通过优化模块加载缩短启动时间
  • 更好的基准：与其他库相比，Scrapling 的所有速度改进都比以前快得多（比 BeautifulSoup 快 1775 倍，比 AutoScraper 快 5.1 倍，请检查 基准）

架构/代码质量和生活质量

  • 持久上下文：所有基于浏览器的获取器现在默认使用持久上下文。 （也解决了#64）
  • 在运行请求之前使用 msgspec 非常快速地验证所有基于浏览器的获取器，因此现在更容易调试错误。
  • 从 fetchers 返回的所有 cookie 现在都与同一 fetchers 接受的格式匹配。因此，您可以检索 cookie 并将它们再次传递给所有获取器及其会话类。
  • 由于迁移到 ruff，更快的 linting 和格式化
  • 现代构建系统：从 setup.py 迁移到 pyproject.toml 📦
  • 更好的 GitHub 操作和工作流程，使开发和测试更加顺利
  • 🎨 增强类型提示：采用现代 Python 标准的完整类型覆盖，以获得更好的 IDE 支持和可靠性
  • 更干净的代码库：删除死代码并优化核心功能🧹
  • 🚀 向后兼容性：添加了快捷方式以保持与旧代码的兼容性

重大变更

最低 Python 版本

  • Python 3.10+ 必需：放弃对 Python 3.9 及更低版本的支持

类和方法命名

这些重命名旨在提高清晰度和一致性，特别是对于新用户而言。

  • Adaptor → Selector：核心解析类重命名（但仍然可以导入为 Adaptor 以实现向后兼容）
  • Adaptors → Selectors：集合类重命名（但仍然可以导入为 Adaptors 以实现向后兼容）
  • auto_match → adaptive：在所有方法中重命名参数
  • adaptor_arguments → selector_config：配置参数重命名
  • automatch_domain → adaptive_domain：域参数重命名
  • additional_arguments → additional_args：缩短的参数名称
  • ⚠️ text/body → content：选择器构造函数参数现在接受 str 和 bytes 格式
  • PlayWrightFetcher → DynamicFetcher：浏览器自动化类重命名（但仍然可以导入为 PlayWrightFetcher 以实现向后兼容性）
  • DynamicFetcher 不再具有 NSTBrowser 逻辑/参数，因为现在离开这个逻辑是没有意义的。
  • StealthyFetcher 的无头参数不能再接受“虚拟”作为参数，因为除了获取浏览器安装路径和其余启动选项之外，我们现在没有使用 Camoufox 的库

🐛 错误修复

  • 修复了 get_all_text 的忽略标签中的嵌套子项计数 (#61)
  • 修复了由于 Python 可执行路径中存在空格而导致的安装问题 (#57)
  • 启用自适应功能时通过递归处理解决了存储中的线程问题
  • 修复了 FetcherSession 中使用 Sentinel 模式的参数优先级问题
  • 解决了 StealthyFetcher 中的代理类型处理
  • 修复了 referer 和 google_search 参数冲突
  • 修复了异步隐形脚本注入问题 🙏 特别感谢我们的 Discord 社区 在过去四个月里的所有持续测试、反馈和贡献
