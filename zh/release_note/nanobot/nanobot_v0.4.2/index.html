nanobot v0.4.2

nanobot v0.4.2

这个项目是干啥的：一个轻量AI助手，支持网页上的持久会话和飞书、Discord、Slack里聊天，给想在多平台用AI机器人的用户用。

变更架构图

亮点

  • 独立 API 服务被移除（破坏性） — nanobot serve、其 /v1 端点和 nanobot-api Compose 服务均已退役，没有即插即用的 HTTP 替代；升级前请停掉旧进程/容器，但保留数据卷。所有 HTTP 客户端必须迁移到 Python SDK（旧 API 的会话可通过它读取）；gateway、WebUI、SDK 和出站模型连接不受影响。#6614

  • 需要配置迁移（破坏性） — 如果你通过旧的 apiType/api_type 设置显式选过 API，升级前请先用 v0.4.1 保存配置，或迁移到当前的 api 字段，并单独更新旧的启动器环境变量（旧的 auto 默认值无需操作）#6615。unifiedSession/unified_session 现在被忽略：已有会话数据保留原处，但新消息改用按聊天或显式选择的话题路由 #6621。

  • 会话可靠性与 SSH/Windows 可达性 — 重连现在更可靠地保留进行中的轮次状态；折叠的轮次会显示最新动态以及哪些后续消息仍在等待（#6664、#6719、#6726、#6715）。SSH 现在可以访问同时公布了公网 WebSocket URL 的 gateway；Use existing SSH settings 支持以 python 提供 Python 3 的 Windows 主机；快速配对仍仅限 Linux，gateway 原生 TLS 和 trustedProxyAuth 在 SSH 下仍不受支持 #6682。

  • 输入框与 UI 工作流 — 工具、Skills 和聊天平台整合进统一的 Apps 目录（#6700、#6441）；可在输入框按消息选择推理强度，而不必改共享预设。长消息可用 Show more 折叠，或在不展开的情况下复制全文（#6739）；设置侧栏底部控件对齐，切换预设后快速重开时模型选择器会保持展开（#6743，提交 bc690f0394a00703d6f25a48c63ecb0170b2e091）。

  • Dream 知识与结论 — Dream 可以把详细知识组织成 Markdown wiki，同时在上下文中保留简短的记忆摘要；现有记忆文件和自定义 Dream 指南仍受支持 #4477。这不是空版本或重新打标签：为 UI/会话/SSH 改进值得升级，如果你依赖已退役的 HTTP API 则必须升级（迁移是强制的）；如果这些方面都与您无关，可以跳过。仅支持手动安装——应用内自动更新未启用，所以请备份配置和工作区，按原安装方式更新 gateway，并让任何独立的 WebUI 客户端保持同一版本。

变化

  • 通过 SSH 连接到也公布公共 WebSocket URL 的网关。 使用现有 SSH 设置 现在支持 Windows 主机，其中 Python 3 可用作 python。快速配对命令仍然仅限 Linux； SSH 仍然不支持网关本机 TLS 和 trustedProxyAuth。 #6682
  • 当回合折叠时查看最新活动，并查看哪些后续消息仍在等待代理。重新连接还可以更可靠地保留运行转弯的状态。 #6664、#6719、#6726、#6715
  • 在一个应用程序目录中查找工具、技能和聊天平台。选择作曲家为您的下一条消息进行的推理工作，而无需更改共享预设。 #6700, #6441
  • 您发送的长消息可以折叠起来，以使对话更容易浏览。使用 显示更多 展开它们，或复制全文而不展开。 #6739
  • 对齐设置侧栏中的页脚控件，并在切换预设后快速重新打开模型选择器时保持模型选择器打开。 设置侧边栏修复、#6743
  • Dream 可以在 Markdown wiki 中组织详细的知识，并在上下文中保留简短的记忆摘要。现有内存文件和自定义梦想指南仍然受支持。 #4477

升级注意事项

  • 对于手动更新，请停止 Nanobot，备份您的配置和工作区，并使用原始安装方法更新网关。如果您将单独的 WebUI client 与远程网关一起使用，请将两者更新到相同版本。 更新指南
  • 独立 API 服务器： nanobot serve、其 /v1 端点和 nanobot-api Compose 服务已停用。在升级之前停止旧的进程或容器并保留数据卷。没有直接的 HTTP 替代品。网关、WebUI、Python SDK 和出站模型连接仍然有效；旧的API对话可以通过Python SDK读取。 #6614
  • OpenAI 提供程序设置： 如果您使用旧的 apiType 或 api_type 设置明确选择了 API，请在升级之前使用 v0.4.1 保存您的配置，或迁移到当前的 api 字段。单独更新任何旧的启动器环境变量。旧的默认 auto 无需任何操作。 #6615
  • 全局共享会话： unifiedSession 和 unified_session 现在被忽略。现有会话数据保持不变；新消息使用每个聊天或明确选择的主题路由。 #6621
  • 此版本支持手动安装。未启用应用内自动更新。
