nanobot v0.3.0

小版本 发布时间2026年7月25日 来源HKUDS/nanobot 英文原文

🐈 nanobot v0.3.0 在这里：合并了 260 个 PR，并增加了 38 个新贡献者。代理人获得代理权。 体验该版本的最快方法是一个命令：

nanobot webui

它准备本地 WebUI、启动网关并打开浏览器工作台。在全新安装中，引导式设置可帮助您选择提供商并配置访问权限，而无需从 JSON 文件开始。发布的包已经包含 WebUI，因此没有单独的前端构建。 产品故事是一个 ​​WebUI，现在感觉就像是纳米机器人的前门。聊天被解读为主题；文档、引用的后续内容、多模式工具结果、文件差异、代码预览和模型回退在对话中可见。模型预设可以从编辑器切换，本机桌面主机可以打开系统文件夹选择器，设置在窄屏幕和深色模式下工作得更好，界面现在包括巴西葡萄牙语和大幅改进的繁体中文。 在这种体验的背后是有界限的代理。纳米机器人可以咨询内联子代理，通过验证进行明确授权的工作，通过更清晰的运行时上下文路由转向状态，以及每个会话切换模型预设。长时间运行的行为是经过深思熟虑的：/goal 选择持续执行任务，而普通对话仍然是普通对话。 基础是为实际部署而构建的运行时。配置可以在不拆除进程的情况下重新加载，通道具有更清晰的包边界，网关重启和关闭路径更坚固，并且Docker和渲染部署更容易重现。提供商范围内的代理、OpenCode、Kimi Coding、带有托管 X Search、并行搜索、Serper、Mattermost 的 Grok OAuth 以及本机 Neonize WhatsApp 通道拓宽了 Nanobot 可以运行的范围和范围。

变更架构图

亮点

  • 向工作台发出一个命令 - nanobot webui 准备本地通道，启动网关，打开浏览器，并引导首次使用的用户进行引导设置。
  • 更强大的浏览器工作台 - 主题式聊天、作曲家模型切换、引用的后续内容、文档附件、本机文件夹选择、响应式设置和更清晰的后备状态。
  • 代理协调，无需核心蔓延 - 内联子代理可以在活动任务内部进行咨询，授权工作可以通过验证继续，并且类型化的运行时上下文使提供者拥有的状态保持在临时循环逻辑之外。
  • 明确的长期运行目标 - 持续执行在 /goal 后面进行门控，具有更清晰的许可、取消、超时、心跳和本地触发行为。
  • 您可以检查的文件和工具活动 - 语法突出显示的预览、实时文件编辑差异、更好的代码复制行为、结构化工具错误、更丰富的 MCP 工件以及保留的多模式工具输出。
  • 更具操作性的运行时 - 实时配置重新加载、有界会话和执行状态、更安全的重启/关闭、更干净的取消所有权、更可靠的计划工作和更快的 CI。
  • 更广泛的提供商和搜索 - OpenCode Zen/Go、Kimi Coding、Grok OAuth、提供商范围的代理、Copilot Enterprise 覆盖、并行搜索、Serper 和更稳定的身份验证回退。
  • 频道作为可维护的扩展 - 原生 Neonize WhatsApp、Mattermost、改进的飞书/Telegram/Discord/Matrix/QQ 行为、可选的频道依赖关系和更清晰的设置流程。
  • 边缘安全性加强 - 链式命令白名单绕过被阻止，SSRF 检查 pin 验证的 DNS，凭据从 MCP URL 进行编辑，远程 API 绑定需要身份验证，并且附件入口受到限制。
  • 文档和交付赶上了 - 面向工作流的文档、自动化指南、one-click 渲染部署、更强大的 Docker 控件、社区维护的项目语言以及更新的 SVG 标识。

升级注意事项

  • WhatsApp 现在使用 Neonize，而不是旧的 Node.js/Baileys 桥。 删除 bridgeUrl 和 bridgeToken，运行 nanobot plugins enable whatsapp，然后再次使用 nanobot channels login whatsapp 链接帐户。旧的网桥验证数据不会被重用。 allowFrom 条目应使用不带前导 + 的发件人 ID。
  • 持续目标现在很明确。 当任务应在连续轮次中继续工作时，请使用 /goal。普通聊天不再隐式继承长期运行的目标行为。
  • 远程暴露需要身份验证。 在环回之外绑定 API 或 WebUI 网关的配置必须提供相应的 API 或 Web 令牌。本地主机设置继续使用引导的短期令牌流。

社区

感谢塑造 v0.3.0 的每个人：260 个合并 PR、38 个首次贡献者，以及一个月对代理核心、WebUI、提供商、渠道、安全性、文档和部署的仔细审查。该机构的发布并不是要让纳米机器人无限制地行动。它是为一个小的、可检查的特工提供协调、证据和操作纪律，以完成更多你有意交给它的工作。
