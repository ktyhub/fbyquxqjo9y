nanobot v0.1.4.post3

修订 发布时间2026年2月28日 来源HKUDS/nanobot 英文原文

🐈 纳米机器人 v0.1.4.post3 刚刚发布 - 合并了 33 个 PR，16 个新贡献者！你们势不可挡🔥 此版本的目的是通过减少垃圾来使代理变得更加智能：更清晰的上下文、强化的会话历史记录和更少的幽灵消息。更少的噪音输入 → 更少的幻觉输出。加上闪亮的新矩阵通道和实验思维模式。

亮点

  • 代理循环强化 - 现在过滤空助手消息（无内容，无工具调用），而不是中毒上下文； LLM 错误响应不再保存到历史记录中，防止永久的 400 错误循环；消息工具抑制仅限于同一频道（#1314、#1198、#1206）
  • 上下文降噪 - 运行时元数据（时间、频道、聊天 ID）分离到 untrusted 层中并从会话历史记录中排除，因此代理只看到重要的内容 - 更少的令牌、更少的混乱、更少的幻觉（#1126、#1222）
  • 会话安全 — Base64 图像从历史记录中删除，以防止上下文溢出；空响应不再破坏未来的回合（#1191，#1314）
  • 矩阵通道 - 完整的矩阵（元素）聊天通道支持 E2EE、媒体上传和输入指示器（#420、#1239）
  • 提供商兼容性 — Mistral 的短字母数字 tool_call_id；优雅地处理列表类型工具参数；配置中显式提供程序选择（#1293、#1294、#1214、#1316）
  • 思考模式（实验） — 新的 reasoning_effort 配置支持对支持的模型进行 LLM 推理；会话历史记录跨回合保留 reasoning_content 和 thinking_blocks (#1351、#1330、#1074)
  • 子代理改进 - /stop 取消生成的子代理；简化的提示消除了死代码并重用了 ContextBuilder（#1180、#1347）
  • 飞书 - 交互式卡片文本提取修复，可配置反应表情符号，更正机器人权限（#1323、#1257、#1317、#1348）
  • 钉钉 — 以正确的消息类型而不是纯文本链接发送的图像和媒体 (#1337)
  • Telegram — 媒体组聚合到单个入站消息中 (#1258)
  • QQ — 修复了 C2C 回复权限，禁用只读文件系统上的文件日志（#1307、#1346）
  • WhatsApp — 消息重复数据删除可防止冗余代理处理 (#1325)
  • Shell & Security — 工作区防护中的完整 Windows 路径解析；子进程路径的可配置 path_append (#1286, #1083)
  • 内存和并发 - 用于合并锁的 WeakValueDictionary 消除了竞争条件和手动清理 (#1326)
  • 工作区 - 自动模板同步在启动时恢复关键文件 (#1253)
