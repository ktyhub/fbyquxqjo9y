nanobot v0.1.4.post1

这个项目是干啥的：一个轻量AI助手，支持网页上的持久会话和飞书、Discord、Slack里聊天，给想在多平台用AI机器人的用户用。

🎉 🐈 纳米机器人社区的另一个重大发布 - 感谢所有贡献者，特别是我们的 19 个新贡献者！ 此版本带来了飞书、Slack 和 Discord 的重大渠道改进、新的提供商、提示缓存和重要的代理循环重构。更可靠、更强大、更精简的代码😄。

变更架构图

亮点

  • 飞书媒体 - 机器人现在可以发送和接收图像、音频和文件（#844、#922）
  • Slack Media Upload — 直接从代理发送文件 (#904)
  • Discord 长消息 — 自动分割超过 2000 个字符的消息 (#900)
  • VolcEngine 提供商 — 新的 LLM 提供商支持 (#812)
  • 提示缓存 — Anthropic 和 OpenRouter cache_control 支持以降低成本（#854、#905）
  • MCP Auth headers - 经过身份验证的 MCP 服务器的自定义 HTTP 标头 (#807)
  • Telegram 改进 — 可配置的回复行为，/help 绕过 ACL（#879、#824）
  • CLI 子代理支持 — CLI 现在通过消息总线进行路由，从而实现完整的子代理支持 (#908)
  • 可靠内存 - 内存整合使用结构化工具调用而不是脆弱的 JSON 解析 (#866)
  • Leaner Agent Loop - 提取内存逻辑，合并冗余方法，-31% 行 (#930)
  • 更智能的文件编辑 — edit_file 现在在 old_text 不匹配时显示差异 (#921)
  • 错误修复 — MCP 重新连接、会话密钥持久性、重复回复、cron 执行等（#892、#902、#832、#821、#823，…）
