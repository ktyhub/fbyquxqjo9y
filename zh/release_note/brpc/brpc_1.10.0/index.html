brpc 1.10.0

小版本 发布时间2024年7月17日 来源apache/brpc 英文原文

brpc 1.10.0

变更流程图

亮点

  • 熔断器半开状态 — （#2634）新增半开探测阶段，跳闸的 channel 在完全闭合前先用有限请求试探恢复。实际效果是瞬时下游抖动后卡在开路的熔断器更少；需要注意的是，既然恢复改为探测而非纯计时，你现有的失败阈值与重试预算是否仍匹配。
  • 在创建 socket 时连接 — （#2574）在 Socket 构造时建立连接，而非推迟到首次 RPC。这把错误暴露提前：依赖惰性连接且从不检查早期失败的代码，现在必须在创建时处理它们。配合双重关闭（#2663）与未初始化 local-side（#2672）修复，本版本 Socket 生命周期处理明显更安全。
  • 更严格的 HTTP 处理 — （#2600）拒绝无 Host 头的请求，（#2577）修正存在多个 Cookie/Set-Cookie 值时的畸形请求头。合规调用方无碍，但此前发送无 Host 请求的代理、健康检查器或裸 socket 客户端现在会被拒绝——升级前请审计。h2 rpc_dump 内存泄漏修复（#2661）对长驻服务器也值得注意。
  • 细粒度线程控制 — bthread 并发数现可按 tag 设置（#2628），EventDispatcher 接受多种 IO 类型（#2560），FastPthreadMutex 向用户开放并带争用分析器（#2589）。对混合负载服务器可实现针对性调优；新分析器是定位锁争用的正确方式，而非靠猜。
  • 编译期与 API 规范 — BRPC_VALIDATE_GFLAG 现仅限全局与命名空间作用域（#2625）；类或函数内的宏使用将无法编译，这是下游代码最可能的迁移障碍。MongoServiceAdaptor 与 SpanFilter 新增虚析构（#2651），使跨共享库边界的多态删除安全，新的 SCOPE_EXIT 宏（#2643）简化清理路径。
  • 值得优先处理的正确性修复 — FlatMap 的 assign 运算符（#2622）与多 FlatMap 扩容/尺寸错误（#2669）、stream_rpc↔baidu_std 切换（#2678），以及 thrift 与 nshead 的最大并发强制（#2613）。若服务使用 FlatMap 支撑的结构，或在同一端点混用流式与标准 RPC，本版本解决的是真实行为缺陷，而非打磨。

  • 支持在套接字上创建连接（#2574），作者：@chenBright
  • 支持 ServerNode 的更多元数据 (#2603) by @chenBright
  • 支持百度协议的代理和泛型调用 (#2629) by @chenBright
  • 支持线程局部对象迭代 (#2632) by @chenBright
  • 支持断路器半开状态 (#2634) @jianyt-git

错误修复：

  • 修复 IOBuf 分析器速率 (#2601) by @chenBright
  • 修复 @chenBright 在 run_tests.sh 中发现的不正确的核心文件 (#2614)
  • 修复 FlatMap 分配运算符错误 (#2622) by @chenBright
  • 修复 GetProgramName 不包含 cmdline 的绝对路径 (#2644) by @ehds
  • 修复多个 cookie 和 set-cookie 的无效标头 (#2577) by @chenBright
  • 修复了 thrift 协议和 nshead 协议的最大并发数 (#2613) by @chenBright
  • 修复bug：当标签为空时，‘quantile=’ 之前有一个 ’,’ (#2659) @renzhong
  • 修复 h2 rpc_dump mem 泄漏错误 (#2661) by @GreateCode
  • 套接字：修复潜在的双重关闭（#2663），作者：@BusyJay
  • 修复 Socket 未初始化的本地端 (#2672) by @chenBright
  • 修复错误：在stream_rpc和baidu_std之间切换（#2678）由@howarle
  • 修复多 FlatMap 比例和大小 (#2669) by @chenBright

增强：

  • 添加对标签范围的检查（#2607），作者：@yanglimingcn
  • bthread 通过标签设置并发 (#2628) by @yanglimingcn
  • 支持 SCOPE_EXIT 宏 (#2643) by @chenBright
  • 选择异步日志的性能 (#2602) by @chenBright
  • 仅将 BRPC_VALIDATE_GFLAG 限制为全局范围和命名空间范围 (#2625) 作者：@chenBright
  • 修复 http2_rpc_protocol.cpp 中的比较警告（#2626），作者：@imdouyu
  • 将虚拟析构函数添加到 MongoServiceAdaptor 和 SpanFilter (#2651) by @yozhao
  • EventDispatcher 支持各种 IO 类型 (#2560) by @chenBright
  • 支持 FastPthreadMutex 争用分析器 && 将 FastPthreadMutex 暴露给用户 (#2589) by @chenBright
  • 拒绝没有主机的 http 请求 (#2600) by @chenBright
  • 支持在打开之前删除旧的 rpcz 目录 (#2610) by @yanglimingcn
  • 添加延迟比例因子 (#2655) by @superhail
  • 添加用于 Socket 健康检查的调试日志 (#2673) by @chenBright
  • 使用 butil::ThreadLocal 存储密钥表 (#2645) by @MJY-HUST

其他：

  • 修复 ci (#2611) by @chenBright
  • 通过 @chenBright 更新文档中的 protobuf 版本 (#2618)
