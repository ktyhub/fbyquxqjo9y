brpc 1.14.0

小版本 发布时间2025年7月28日 来源apache/brpc 英文原文

brpc 1.14.0

这个项目是干啥的：百度开源的 RPC 网络框架，让不同服务之间高效互相调用，支持多种协议和高并发，适合写高性能后端服务的工程师。

变更架构图

亮点

  • 新特性面 — 为 MultiDimension API 新增泛型（#3026）、rpc checksum（#2967）、RDMA 轮询模式（#2920），以及 epoll bthread 优先处理（#2819）。这些提供额外的正确性、性能与部署选项，但变更日志未说明其默认值或启用细节。
  • 内存安全与并发 — 修复 Butex 归还 ObjectPool 时的 use-after-poison（#3012）、StringSplitter 无效内存访问（#2996）、SignalTrace 内存/死锁问题（#3019）、bthread task tracer 死锁（#2988），以及 TimerThread 关停挂起（#2986）。长驻、高并发或开启调试追踪的服务有充分升级理由。
  • 协议正确性 — 修复 gRPC 认证不兼容（issue #3001、#3002）、Thrift 序列号错误与无效 Thrift URL（#2984、#2975），以及无健康检查时 socket 异常回收（#3010）。使用 gRPC 认证、Thrift 或关闭健康检查的部署应优先升级。
  • 资源限制与构建规范 — 修正 bthread_worker_usage 超过 bthread_worker_count 的情况（#3009），修复 save_series 为 false 时 LatencyRecorder::expose 的 CHECK 失败（#3022），并新增 Redis 分配大小限制（#3035）。大 Redis value 负载应核对该新限制，其阈值此处未说明；GCC 13、Bazel libunwind 与 macOS 测试修复主要惠及打包者和 CI。
  • 升级建议 — 未列出显式破坏性变更或迁移步骤；这主要是增量特性与错误修复版本。使用受影响协议、RDMA、Redis 或可靠性敏感执行路径的用户应升级；否则避开这些领域的稳定部署可合理跳过。

特点：

  • 支持 MultiDimension APIs 的泛型 (#3026)，作者：@chenBright
  • 支持 rpc 校验和 (#2967), by @yanglimingcn
  • 支持 RDMA 轮询模式 (#2920), by @yanglimingcn
  • 支持 epoll bthread 首先处理 (#2819), by @zhengJade

错误修复：

  • 错误修复：运行时扩展块池（#2965），作者：@yanglimingcn
  • 错误修复：bthread_worker_usage 可能超过 bthread_worker_count (#3009)，作者：@chenBright
  • 错误修复：SignalTrace 模式存在内存和死锁问题 (#3019)，作者：@chenBright
  • 错误修复：Butex 返回到 ObjectPool 会触发 use-after-poison (#3012)，作者：@chenBright
  • 错误修复：当 save_series 标志为 false 时 LatencyRecorder::expose CHECK 失败 (#3022)，作者：@chenBright
  • 修复 grpc 协议与身份验证不兼容的 bug(issue:#3001) (#3002), by @Paragrf
  • 错误修复：没有健康检查的套接字将被异常回收（#3010），作者：@chenBright
  • 修复：为绑定和连接指定全局命名空间（#3007），作者：@zhoukangsheng
  • 修复导致 TimerThread 在关闭期间挂起的竞争条件 (#2986)，作者：@gitccl
  • 修复 StringSplitter 中潜在的无效内存访问 (#2996)，作者：@gitccl
  • 修复 bthread 任务跟踪器死锁错误 (#2988)，作者：@CodeZHXS
  • 修复了 thrift 消息开始中不正确的 seq id 设置（#2984），作者：@chenBright
  • 修复了 GCC 13 中由于缺少 包含而导致的 UT 编译错误 (#2979)，作者：@XueSongTap
  • 修复 thrift 的无效 url (#2975)，作者：@chenBright
  • 修复通过 bazel 构建时默认在 x86_64 cpu 上链接的 libunwind (#2973)，作者：@tongke6

增强功能：

  • 优化加载 libibverbs 的后备代码 (#3008)，作者：@zhangqiongyu
  • 添加 redis 分配大小限制 (#3035)，作者：@wwbmmm
  • 选择日志函数名称 (#3017)，作者：@chenBright
  • 使单元测试可在 macOS 上运行（#3018），作者：@gitccl
  • 在 rwlock.h 中添加包含防护（#3005），作者：@xiongjiwei
  • 一致的哈希支持服务器标签 (#2994)，作者：@egolearner
  • 支持宏来禁用移动（#2989），作者：@chenBright
  • 优化 DoublyBufferedData 中的 share_ptr 分配 (#2981)，作者：@gitccl
