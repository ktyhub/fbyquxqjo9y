brpc 1.9.0

小版本 发布时间2024年4月26日 来源apache/brpc 英文原文

brpc 1.9.0

这个项目是干啥的：百度开源的 RPC 网络框架，让不同服务之间高效互相调用，支持多种协议和高并发，适合写高性能后端服务的工程师。

变更架构图

亮点

  • Protobuf 22–25 支持 — #2546 新增 Protobuf 22 支持，#2576 修复 22–25 的编译，因此可在不本地打 brpc 补丁的情况下升级 protobuf 工具链；注意配套变更 #2592 停止链接 abseil interface 目标，此前隐式依赖那些传递链接 flag 的项目可能需要显式加入 abseil。
  • bthread 原语与跨池调度 — bthread_once 加 bthread 单例（#2520）、可跨不同 worker 池使用的原语（#2551），以及 bthread 与 pthread 的定时连接（#2524），带来更安全的单次初始化与真实连接超时；跨池行为是新的，在负载下依赖它之前请重新验证任何假定 tag/池局部性的代码。
  • 可观测性与异步调用链 — 新 bthread 的 span 传播（#2519）与日志中的 bthread id（#2570）让异步请求路径可端到端追踪，IOBuf Profiler（#2497）与致命崩溃的同步日志则补齐内存压力与硬崩溃调试的空白。
  • 流式 RPC 失败处理 — 流式 RPC 的 on_failed 回调（#2565）与忽略流控制帧上的 eovercrowded，让你能对流失败作出反应而非静默停滞；预期要在任何自定义流式实现中接入新钩子。
  • 足以支撑升级的正确性修复 — 可能触发两次的取消回调（#2557）、DefaultAllocator 下未释放的 MPSCQueue 内存（#2553）、错误的 ELEMENTS_PER_BLOCK（#2562）、返回 keytable 中使用 butex（#2558），以及 rpc_channel_connection_count；这些是静默的泄漏与并发缺陷，主要在持续负载下显现。
  • 构建与工具链灵活性 — 兼容 cmake < 3.7，以及通过脚本检测 GCC 版本以支持交叉编译（#2567），降低旧环境或交叉构建环境的门槛；关闭写与成功写通知（#2547）改变 socket 关闭语义，连接生命周期代码值得检查。

特点：

  • 支持 ListOfABAFreeId 的 gc (#2479) by @stdpain
  • 支持 bthread 和 pthread 的定时连接 (#2524) by @chenBright
  • 支持 bthread_once 和 bthread singleton (#2520) by @chenBright
  • 支持新 bthread 的跨度 (#2519) by @yanglimingcn
  • 支持 Protobuf 22 (#2546) by @wasphin
  • 支持与 @wasphin 的 cmake < 3.7 兼容
  • 支持 bthread 原语跨不同工作池 (#2551) by @yanglimingcn
  • 支持流式 rpc 的 on_failed 回调（#2565），作者：@chenBright

错误修复：

  • 修复 gflags bthread_concurrency_by_tag 验证失败 (#2543) by @yanbinyang
  • 修复了 @BusyJay 的测试/iobuf 不匹配释放问题
  • 修复 MPSCQueue 内存未通过 DefaultAllocator 释放的问题 (#2553)，作者：@legionxiong
  • 修复了 @MJY-HUST 在返回密钥表中使用 Butex 的问题 (#2558)
  • 修复取消回调可能会被 @chenBright 调用两次 (#2557)
  • 第一次修复 CachedReader 的随机值 (#2556) by @chenBright
  • 修复 ELEMENTS_PER_BLOCK 可能不正确的问题 (#2562) by @shanhe72101
  • 修复了使用 protobuf 22-25 进行编译的问题。 （＃2576）由@ketor
  • 通过@yyweii修复rpc_channel_connection_count

增强功能：

  • 支持忽略流控制帧的过度拥挤 @chenBright
  • 支持日志的 bthread id (#2570) by @chenBright
  • 支持 IOBuf Profiler (#2497) by @chenBright
  • 支持关闭写入并通知写入成功 (#2547) by @chenBright
  • 添加 ScopeGuard 的 UT (#2569) by @chenBright
  • 通过脚本获取 gcc 版本以支持交叉编译 (#2567) by @wasphin
  • 使用同步日志来记录崩溃致命日志，作者：@chenBright
  • 为 Linux ci 安装 gdb (#2587) by @chenBright
  • 不要链接 @wasphin 的下降接口目标 (#2592)

其他：

  • 更新@omahs、@Divyansh200102、@YinZheng-Sun 的文档和评论
