brpc 1.13.0

小版本 发布时间2025年5月18日 来源apache/brpc 英文原文

brpc 1.13.0

变更流程图

亮点

  • HTTP 与 Baidu-std 负载灵活性 — HTTP body 现支持 ProtoJson（#2921），Baidu-std 接受 JSON、Proto JSON 与 Proto text（#2946）。这改善 protobuf 互操作性，但客户端必须显式对齐序列化选择并测试 content-type 处理。
  • 运行时可调的方法并发 — 每方法并发数可动态更新（#2923），运维无需重新部署即可调整限流。变更限制时请重新检查排队与尾延迟。
  • 大流自动分段 — 大型 bRPC 流消息自动分段（#2889），减少手动分块与超大负载失败。请针对旧版或非 bRPC 对端验证行为，并监控背压。
  • 并发正确性加固 — 修复覆盖 AgentCombiner（#2949）、Wrapper（#2952）、批量流创建与 SetHostSocket（#2938），以及编译器敏感的 thread-local 访问（#2918, #2934）。高并发服务升级后应重跑 Release 构建的压力测试。
  • 诊断与依赖兼容性 — AddressSanitizer 支持（#2890）、修正的 Prometheus 格式（#2899）与 EventDispatcher 延迟指标（#2897）改善排障。在依赖升级构建检查中纳入 protobuf v27+（#2941）与 glog 链接（#2914）。
  • 破坏性变更 — 本版本未列出。
