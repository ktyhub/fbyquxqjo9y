hyperframes v0.9.27

修订 发布时间2026年11月9日 来源heygen-com/hyperframes 英文原文

hyperframes v0.9.27

变更流程图

亮点

  • 渲染共享锁 — Studio 渲染现在和 CLI 渲染使用同一个”一次一个”的锁，避免并发任务争抢机器资源。如果你同时跑 Studio 和 CLI 渲染，这个版本值得升级。
  • 渲染可靠性与性能 — 分布式和范围渲染现在会正确处理页面运动模糊；停留在末帧的视频只 seek 一次而非反复读取。大批量渲染更稳。
  • 升级建议 — 并行渲染用户建议升级；其他场景可跳过。

超帧 v0.9.27

发布于 2026 年 11 月 9 日。 Studio 渲染现在等待与 CLI 相同的一次一个渲染槽，因此两个渲染不再在它们之间分割一台机器。 Windows 上的长项目路径和 macOS 开发人员工具提示也得到了修复。

特点

  • 技能： 在模板外部路由样式而不是列出它们（37f1819f3、#7450）。
  • CLI： 反向和模板报告自己的运行；命令说明安装了哪些技能（448f88ff3、#7444）。
  • 技能： 使用核心集反向安装任何视频和风格采样（ad6f7858f、#7445）。
  • 制作人： 分布式和范围渲染荣誉页面运动模糊（[c38ac5438]（https://github.com/heygen-com/hyperframes/commit/c38ac5438c751094a720c55c68bd15fc6450ec37），[#7311]（https://github.com/heygen-com/hyperframes/pull/7311））。
  • CLI： 添加其他探测器使用的代理标记，已在上游验证（7bf65995b、#7425）。
  • CLI： 在遥测中检测更多代理运行时间（[c14f25890]（https://github.com/heygen-com/hyperframes/commit/c14f258907252cc4b44e79b7f92e2cc870bb6259），[#7423]（https://github.com/heygen-com/hyperframes/pull/7423））。

修复

  • CLI： Studio 渲染采用与 CLI 相同的单渲染槽锁定（4b3f70fb1、#7459）。
  • CLI： 模板将解包拉到 .hyperframes 下，而不是在 templates/ 旁边（a4e16d87c、#7269）。
  • 技能： 等待玩家在接缝门中寻找（[fc13420de]（https://github.com/heygen-com/hyperframes/commit/fc13420de8f0627a7db1f9f375163c1bbd6ad0c4），[#7454]（https://github.com/heygen-com/hyperframes/pull/7454））。
  • CLI： 在 Windows 上按文件名标记 SVG 联系表缩略图（0ca2b1ae9、#6732）。
  • CLI： Windows 上项目路径旁边的暂存文件夹不再超过 260 个字符（b59fa2083、#7338）。
  • CLI： 在没有工具的 Mac 上，git、xcrun 或 cc 检查没有 macOS 开发人员工具提示（c14973081、#7257）。
  • CLI： 转录读取带有 nan 或 inf 值的耳语输出（[7b30a50b5]（https://github.com/heygen-com/hyperframes/commit/7b30a50b518436d14fa19cb7ab3e323f26d9be70），[#7110]（https://github.com/heygen-com/hyperframes/pull/7110））。
  • CLI: 间隔路径提示采用最长的路径并读取 —flag=value;遥测文档将反向会话 ID 命名为（3a24da8a8、#7452）。
  • 核心： 从结构上检测模板条目（caa62fe68、#7249）。
  • CLI： 测量代理最常犯的四个错误的答案（[eb0a52c29]（https://github.com/heygen-com/hyperframes/commit/eb0a52c2980318aa07df4290c247cd41b08ed268），[#7443]（https://github.com/heygen-com/hyperframes/pull/7443））。
  • 核心： 尾部的视频被查找一次，而不是每一帧（a73572c3b、#7442）。
  • CLI： 让特工自己的名字击败编辑器和主机标记（[c1e96a45b]（https://github.com/heygen-com/hyperframes/commit/c1e96a45b24c66c96ed9151075f5262d4a3614dc），[#7424]（https://github.com/heygen-com/hyperframes/pull/7424））。

文档和示例

  • Mcp： 当前的 ChatGPT 和 Claude 设置步骤、托管渲染的真实输出以及有效的第一个提示（48a2b4e01、#7439）。
  • Changelog： 每周摘要 2026-11-02-2026-11-09（[3ff0b3d81]（https://github.com/heygen-com/hyperframes/commit/3ff0b3d81c011c63917c66df0d2cf45a32148882），[#7453]（https://github.com/heygen-com/hyperframes/pull/7453））。
  • CLI： 代理检测中正确的克劳德代码标记注释（[e35125372]（https://github.com/heygen-com/hyperframes/commit/e351253724c7142cc4697de652f353a0fd74b66e），[#7426]（https://github.com/heygen-com/hyperframes/pull/7426））。
  • 在 v0.9.26 注释中列出 1440p 预设（d09584382、#7422）。

内部

  • 引擎： 夜间运动模糊运行在生成的合成上（7bf19ab5f、#7437）。
  • 引擎： Real-Chrome 测试在慢跑者上每次测试需要 30 秒，而不是 5 秒（4d29a64b0、#7456）。
  • Codegen： 重新同步生成的云 client (b95ab794e、#7455)。
  • 引擎： 使用假定时器驱动空屏幕截图探针测试（c9fe04150、#7000）。
