hyperframes v0.9.65

hyperframes v0.9.65

变更流程图

亮点

  • 密封预览的动画编辑终于能用了 — Studio 的密封预览现在可以绘制和创建运动路径、读取 GSAP 关键帧与取值，并且在添加关键帧或动画移动图层时把移动后的图层保持在原位（#8108、#8105、#8117、#8003、#8113、#8103）。如果你在密封预览里编辑动画，这是升级的首要理由；不用密封预览的话，这些改动与你无关。
  • 遥测数据结构变更——对事件消费方实为破坏性变更 — 错误事件现在发送错误类别、形状以及 Studio 自己的帧信息，而不再携带错误文本；分析事件发送的是路径/选择器的事实标记，而不是实际的路径和选择器（#8114、#8109）。目的是保护隐私——错误文本、文件路径和选择器都不再离开客户端——但任何解析这些事件的系统（仪表盘、告警、日志抓取）都必须同步更新；文档没有明确的迁移说明，请把它当作一次 schema 变更，上线前务必验证。
  • Studio Server 新增 403 拒绝指标 — 主机现在可以统计自己拒绝（403）的 API 请求数（#8049）。只有自建 Studio 托管服务的运维才需要关注，其他用户无感。
  • CLI 与发布链路加固 — CLI 的人脸检查现在只读取页面被允许加载的媒体（#8116）；Windows 上的 Chrome 清理和进程读取不再传入 PowerShell 命令文本（#8085）；接收文件的追踪逻辑得到修正（#8100、#8098）；MCP Server 现在以 com.heygen/hyperframes 的名义列出，并由 heygen.com 的密钥签名（#8106）。这些都是低风险的正确性/安全改进，让增量升级更稳妥。
  • 要不要升级？ 文档没有明确列出破坏性 API 变更或迁移步骤，但上面的遥测结构变更是唯一可能搞坏下游工具的地方。如果你用密封预览编辑动画，或需要 CLI/registry 的修复，建议升级；消费 Studio 错误/分析事件的团队应先审计自己的 schema；CLI/Studio 流程稳定且不依赖遥测的团队可以放心跳过。

超帧 v0.9.65

发布于 2026 年 11 月 17 日。 Studio 的密封预览现在可以绘制运动路径、读取关键帧并在添加关键帧时将移动的图层保留在适当的位置。 Studio 的错误和分析事件不再包含错误文本、文件路径或选择器。

特点

  • Studio Server： 让主机对 API 拒绝的请求进行计数 403 (078e54d00、#8049)。

修复

  • Studio： 错误事件发送类、形状和 Studio 自己的框架，而不是错误的文字（195aa2f0c、#8114）。
  • Studio： 在密封预览上添加关键帧，将移动的图层保持在适当的位置（ce3decb6b、#8117）。
  • CLI： 检查的面部通行证仅读取页面可能加载的媒体（[c4a4167aa]（https://github.com/heygen-com/hyperframes/commit/c4a4167aace1c3aba115ba8505207dfdbc6413f0），[#8116]（https://github.com/heygen-com/hyperframes/pull/8116））。
  • Studio： 密封预览移动并保存其动画移动的图层（7a9d78e69、#8105）。
  • Studio： Analytics 发送路径和选择器事实，而不是路径和选择器（d87285387、#8109）。
  • Studio： 运动路径可以在密封预览中绘制和创建（373d987e3、#8108）。
  • 技能： 通过启动器选择独立的 CLI 版本（414adffb8、#8102）。
  • Figma： 编写 .media 和组件输出，无需以下链接（[a765c9379]（https://github.com/heygen-com/hyperframes/commit/a765c937918d67d9b9f5a3564fc59a845f252ab3），[#8111]（https://github.com/heygen-com/hyperframes/pull/8111））。
  • Studio： 一旦普通元素获得关键帧（ba62d7748、#8113），编辑台就会等待预览交换。
  • CLI： Windows Chrome 清理和进程读取不再传递 PowerShell 命令文本（b930c4d2d、#8085）。
  • 发布： 无帐户推送器检查直接读取其文件，没有管道（[740796888]（https://github.com/heygen-com/hyperframes/commit/7407968882c86080bb528af6caef6ac646030ce9），[#8095]（https://github.com/heygen-com/hyperframes/pull/8095））。
  • **生产者：**将静态媒体选择器检查与其所经过的页面绑定（[435dd0e68]（https://github.com/heygen-com/hyperframes/commit/435dd0e68507f53bcf6940d2033a53b6f08913eb），[#8091]（https://github.com/heygen-com/hyperframes/pull/8091））。
  • Studio： 密封预览重新加载后，所选元素保持绘制和可拖动状态（1bf629c1d、#8081）。
  • Studio： 两次快速搜索后，click 在密封预览中添加关键帧（93622154e、#8103）。
  • 发布： 将 MCP 服务器列为 com.heygen/hyperframes，由 heygen.com 的密钥签名（88ba1b4d7、#8106）。
  • 媒体使用： 音频脚本根据 CLI 的规则（bc5259d2d、#8086）判断收到的 .env。
  • 媒体使用： 将本地生成器输出写入私有每次运行文件夹（ac33c1f2b、#8030）。
  • Studio： GSAP 关键帧和值读取在密封预览中工作（133965e4f、#8003）。
  • CLI： 保留主机保留记录中仍列出的已接收文件（183bf2a41、#8100）。
  • CLI： 假设列出的接收文件已消失，并在重命名时删除媒体文件的行（[4a59fef2d]（https://github.com/heygen-com/hyperframes/commit/4a59fef2d0b91de31f97e4a8d9b9071a3e8330c9），[#8098]（https://github.com/heygen-com/hyperframes/pull/8098））。

目录
