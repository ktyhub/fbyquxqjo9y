hyperframes v0.9.35

这个项目是干啥的：HeyGen 开源的 AI 视频剪辑框架，把 HTML 当视频来写并渲染成 MP4，还能让 Claude Code 等助手直接改片，给会写网页的开发者和做批量视频的人用。

变更架构图

亮点

  • 预览安全加固（行为变更） — 预览包现在不再包含 .env 文件和 Git 数据，通过分享链接也不行。显式引用这些文件的渲染会直接报错退出；请修改受影响的渲染配置，而不要指望它们还能被打进包里。
  • 本地共享收紧（行为变更） — 共享现在只响应本机请求。在容器中运行的 Studio 会对非本地共享请求返回 403，容器化用户升级前必须重新评估该工作流。
  • 可执行文件查找加固 — 辅助程序只从受信任的 PATH 目录中解析，Windows 不再搜索当前工作目录。如果自定义辅助程序依赖从当前目录启动，请把其所在目录加入 PATH。
  • 共享与 CLI 修复 — 变更检测现在能正确处理 .hyperframesignore 中的 gitignore 模式（如 /exports/、**/*.mov），不再因此失败。四舍五入后的时长和大小也能正确进位（显示 1m 0.0s、1.0 MB），解析 CLI 输出的脚本和日志会更可靠。
  • 要不要升级？ 只要你会发布预览或依赖本地共享，就建议升级——这些安全修复堵上了实实在在的泄露路径。不涉及私有文件渲染、容器化共享或辅助程序解析的用户可以放心跳过这次维护发布；类型化的预览消息端口目前还只是内部铺垫，没有用户可见的行为变化。

超帧 v0.9.35

发布于 2026 年 11 月 11 日。

.env 和 git 数据等私有文件不包含在预览包中，本地共享仅适用于您自己的计算机。当 .hyperframesignore 使用 gitignore 模式时，共享也会持续跟踪更改。

修复

  • 安全性： 预览包永远不会包含 .env 文件或 git 数据，即使是通过链接也是如此。命名这些文件之一的渲染现在会停止并出现错误。本地共享仅响应此计算机，因此从容器中的 Studio 共享现在会收到 403（a243169f8、#7563）。
  • 安全性： 通过直接遍历 trusted PATH 文件夹来找到帮助程序。在 Windows 上，永远不会搜索工作文件夹（9a048ac01、#7562）。
  • 分享： 当 .hyperframesignore 使用 gitignore 模式（例如 /exports/ 或 **/*.mov）时，更改检测继续工作。之前，这些模式因错误而停止（[c07468d6a]（https://github.com/heygen-com/hyperframes/commit/c07468d6a7155d28828eef1058896b7aa74114a1），[#7568]（https://github.com/heygen-com/hyperframes/pull/7568））。
  • CLI： 四舍五入时，持续时间和大小会滚动到下一个单位，因此您会看到 1m 0.0s 和 1.0 MB，而不是 60.0s 和 1024.0 KB (182608311、#7565)。

文档和示例

  • Studio 应用程序： 品牌套件页面显示套件仅与您的工作区共享（c218b37a3、#7570）。

内部

  • 核心： 预览运行时为其父级提供类型化消息端口。这为 Studio 准备了密封预览帧，并且尚未更改任何内容（ef5cdeb0a、#7556）。
  • CLI： Local Studio 的共享窗口计数按钮 click 和选项。仅记录固定类别，从不记录链接、路径或电子邮件地址（2a70733c1、#7566）。
