hyperframes v0.9.66

修订 发布时间2026年11月18日 来源heygen-com/hyperframes 英文原文

发布于 2026 年 11 月 18 日。 Studio 的密封预览现在可以进行属性编辑、裁剪、调整大小和播放幻灯片场景。当 clip 停止下载时，预览不再位于缓冲中，并且播放器可以带有您自己的品牌。

特点

变更架构图

亮点

  • 封存预览变为完全可交互 — 这是 v0.9.66 的主要变化：封存预览现在接受属性面板的样式/属性编辑（#8149）、裁剪与缩放调整（#8005）、带块堆叠/下钻/快捷键的幻灯片场景（#8118）。此前封存后基本只能看，现在可以像正常编辑一样改。

  • 升级建议 — 经常使用封存预览的用户升级收益最大。

  • 播放器： 将可自定义的品牌添加到预览播放器（a9b4745f1、#7718）。

修复

  • AWS Lambda： 将 shell 与其自己的 pin 匹配，仅发送散列文件，拒绝 CDK 和 SAM 中的 shell ZIP（61d65e717、#8173）。
  • AWS Lambda： 固定 shell ZIP 路径、gate ZIP 净空、将 arm64 字体与 x86 匹配（ed3f05a05、#8170）。
  • Studio： 属性面板样式和属性编辑显示在密封预览中（b525686e7、#8149）。
  • 编译器： 从文件中读取组合资产路径并对其添加的内容进行重新设置（bb55c1ea7、#8166）。
  • CLI： Figma 命令打印带有可见转义符的清单和文件夹文本（420f14d15、#8126）。
  • CLI： 将打印名称中的控制字符显示为可见转义符（[3e788fb15]（https://github.com/heygen-com/hyperframes/commit/3e788fb15addd7573c398c5c67a1bd330b842143），[#8008]（https://github.com/heygen-com/hyperframes/pull/8008））。
  • 技能： 发射器的楼层是0.9.65，最古老的桌面版本船舶（[140b70140]（https://github.com/heygen-com/hyperframes/commit/140b7014034fc4cc977eeb897660b8d4be16fe9c），[#8159]（https://github.com/heygen-com/hyperframes/pull/8159））。
  • AWS Lambda： arm64 视频图像中的 Chrome-headless-shell 158，x86 ZIP 中的 sparticuz 153 (81d73d227、#8155)。
  • 生产者： 仅当页面保持在其大小限制内时内联本地字体（[3b79b1858]（https://github.com/heygen-com/hyperframes/commit/3b79b1858e2feb1ebc6b549d7e418f697ba1eabc），[#8152]（https://github.com/heygen-com/hyperframes/pull/8152））。
  • Studio： 密封预览的元素读取是有界的，并且没有代理的框架会立即回答（[e623031f3]（https://github.com/heygen-com/hyperframes/commit/e623031f3a56053b913616969500f13aa9714198），[#8055]（https://github.com/heygen-com/hyperframes/pull/8055））。
  • 核心： 每个编辑 client 都有自己的端口，因此密封预览再次回答 Studio（[e95cdf7d7]（https://github.com/heygen-com/hyperframes/commit/e95cdf7d76064eb8166a36823a202cf5e0f03859），[#8154]（https://github.com/heygen-com/hyperframes/pull/8154））。
  • 核心： 保持 SVG id 重命名在页面大小和渲染大小限制内呈线性（5bd3e3242、#8147）。
  • Studio： 检查文件夹移动或删除所带来的每个文件（7ea012953、#8143）。
  • 工作室： 密封预览从播放器获取影片的尺寸（d574ded1e、#7967）。
  • 核心： 保留 id 包含 $ 模式的合成的样式（[12a2f83c4]（https://github.com/heygen-com/hyperframes/commit/12a2f83c49db1730519cf0df8f58e548cda7e8c4），[#8141]（https://github.com/heygen-com/hyperframes/pull/8141））。
  • 编译器： 绑定组合可变样式和可变媒体源（c6e3f30be、#8144）。

  • 播放器： 当您跳到另一个时刻时保持视频播放（3ee095bde、#7719）。
  • CLI： 从主目录运行全局更新（[e99cd75b4]（https://github.com/heygen-com/hyperframes/commit/e99cd75b4228cccee644a4e650db961b5b02f9bf），[#8131]（https://github.com/heygen-com/hyperframes/pull/8131））。
  • 媒体使用： 在剩余的解析和多维数据集验证行中转义控制字符（9a096d72f、#8059）。

  • CLI： 测试从 CI 缓存读取 opencv.js，而不是 CDN 中期测试（e6cee094b、#7968）。

  • 技能： 启动器永远不会启动早于其安全层的 CLI（[63c8f8ef6]（https://github.com/heygen-com/hyperframes/commit/63c8f8ef66e3c5e2dbcfee77923def09cf360112），[#8125]（https://github.com/heygen-com/hyperframes/pull/8125））。
  • CLI： 当检查的面部通行证在其时间限制内停止源时（[59fbb22eb]（https://github.com/heygen-com/hyperframes/commit/59fbb22ebac388d74c93c038a0b47975be8f7f1f），[#8122]（https://github.com/heygen-com/hyperframes/pull/8122））。
