hyperframes v0.9.32

hyperframes v0.9.32

变更流程图

亮点

  • 长片渲染 — 首帧等待时间现在随浏览器启动时间伸缩，最长可达 15 分钟，因此加载缓慢的长片不会再在渲染开始前就失败。如果你渲染大型项目或遇到过启动超时失败，建议升级。
  • 更高保真的 SDR 母版 — --chroma-subsampling 444 可以在 SDR MP4 输出中保留完整的色彩细节，适合渲染结果还要再次编码的场景。该选项是 opt-in，默认输出不变。
  • 安全加固 / 可能需要迁移 — 项目文件夹不能再决定 CLI 和渲染器执行或提供哪些程序、配置、Studio 内容或本地服务，合成的悬停预览也与 Studio 隔离。虽然没有正式声明破坏性变更，但依赖项目内可执行文件/配置发现，或依赖脚本访问 Studio 页面的工作流可能需要调整。
  • 可靠性与诊断 — 中断的分享/导出不会再在没有硬链接的文件系统上留下卡死的锁；输入法（IME）组词不再导致文本被误提交；lint 现在能检测 GSAP 加载前对 gsap 的调用。渲染流的 complete 事件也会标明渲染它的 producer 版本，便于追溯。
  • 升级建议 — 这是一个有实质内容的补丁，而非仅元数据更新。多数用户都应升级以获得安全与渲染修复；不受这些问题影响的用户可以放心跳过，因为其余值得注意的改动只是文档性能、sitemap 条目和 README 徽章。

超帧 v0.9.32

发布于 2026 年 11 月 11 日。 打开速度慢的长影片现在会渲染，而不是在第一帧之前失败。 CLI、Studio 和渲染器还会阻止项目文件夹选择它们运行或服务的内容。

特点

  • SDR MP4 渲染可以使用 --chroma-subsampling 444 保留全彩细节，以便重新编码的母版；默认值保持不变（1a9fb8acb、#5820）。
  • 生产者： 渲染流的完整事件命名渲染它的生产者版本（[7afa05a78]（https://github.com/heygen-com/hyperframes/commit/7afa05a782c452ca76af22bdde12d4cddaf64c60），[#7515]（https://github.com/heygen-com/hyperframes/pull/7515））。

修复

  • 分享： 导出重播被拒绝时的指导恢复（941049a84、#7531）。
  • Studio： 合成悬停预览与 Studio 自己的页面隔离运行，因此合成的脚本无法进入 Studio（0c229a26c、#7522）。
  • Studio： 当输入法仍在撰写文本时按 Enter 或 Escape 不再提交文本，并且 Escape 然后离开文本字段不再保存取消的编辑（ff285d3f2、#6011）。
  • 共享： 在没有硬链接的文件系统上，在获取锁定时终止的共享或导出不再留下以后尝试无法清除的锁定（b37e4b026、#7516）。
  • 制作人： 打开缓慢的长片在第一帧之前不再失败：现在，第一帧的等待时间取决于浏览器启动所需的时间，最多 15 分钟（7ff8ece46、#7517）。
  • Lint： 标记在 GSAP 加载之前调用 gsap 的脚本，并在渲染失败时说明该脚本（124591a9d、#7514）。
  • 生产者、引擎： 强化渲染路径、渲染槽和本地侦听器（60fb9d2c5、#7508）。
  • Studio Server： 强化预览路径、缓存文件夹和本地服务器（b8bb49190、#7510）。
  • CLI： 阻止项目文件夹选择程序并配置 CLI 运行（[84c7d02a1]（https://github.com/heygen-com/hyperframes/commit/84c7d02a190f79420cd8c5d112033706fb0a8efc），[#7511]（https://github.com/heygen-com/hyperframes/pull/7511））。
  • CLI： 强化 lambda 销毁、快照媒体、升级和项目文件服务（c96ff540c、#7509）。

性能

  • 文档： 仅当展示胶片图块靠近屏幕时才加载它们（fd0c2337c、#7507）。

文档和示例

  • 在 robots.txt 中列出中心的 /blog、/vs 和 /tools 站点地图（499a17e67、#7527）。
  • 自述文件： 显示 GitHub 排名和技能下载徽章（[717d3d02c]（https://github.com/heygen-com/hyperframes/commit/717d3d02cd819a5b2064d54c623ab7e3856af1c4），[#7519]（https://github.com/heygen-com/hyperframes/pull/7519））。

目录

  • 强化文档片段、SVG 清理程序、lint 正则表达式、GSAP 编写器和注册表引脚（24508ce2d、#7512）。

内部

  • 检查器： 解码 HTTP 合约装置中的文件 URL（e7a323ade、#6010）。
