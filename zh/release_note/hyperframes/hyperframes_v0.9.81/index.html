hyperframes v0.9.81

超帧 v0.9.81

发布于 2026 年 11 月 22 日。 现在，可以渲染较重的页面，而不会耗尽内存：渲染仅启动尽可能多的浏览器。密封预览需要进行更多编辑，从移动和裁剪到撤消和热键。

修复

  • Studio： Studio 仅在实际按下或 click（3ac5265aac、#8503）后才对密封预览的关键报告进行操作。
  • 核心： 数百个无设定长度的 clips 预览不再全部加载（d4e8d6f983、#8303）。
  • Studio： 擦过切口会显示最新的框架，而不是黑色（[0e6879b8ef]（https://github.com/heygen-com/hyperframes/commit/0e6879b8efea57f588ed835fab56f9211e0cfcde），[#8501]（https://github.com/heygen-com/hyperframes/pull/8501））。
  • Studio： 复制并重复拒绝不属于项目作品之一的文件（45674e840f、#8490）。
  • 工作室： 密封预览版的 clips 保留其 GSAP 过渡标签（97b90d8fa2、#8499）。
  • 工作室： 跨框架交换的密封压力机从所示框架开始（[a770f4b85d]（https://github.com/heygen-com/hyperframes/commit/a770f4b85dd73e60d7880c630fc3514877d0c611），[#8492]（https://github.com/heygen-com/hyperframes/pull/8492））。
  • Studio： 粘贴和重复写入仅允许标记，除非它来自同一文件（[0b73069201]（https://github.com/heygen-com/hyperframes/commit/0b73069201b7771078c63c92db0e5b73d99e4dd7），[#8483]（https://github.com/heygen-com/hyperframes/pull/8483））。
  • Studio： 在密封预览中旋转图层会将其从样式表显示的角度旋转（039eca4f0f、#8469）。
  • Studio： 不适合下面的菜单会在上面打开，永远不会超过打开它的菜单（[679a5a7e0b]（https://github.com/heygen-com/hyperframes/commit/679a5a7e0b8d6ecc75ac79c3780d814b0d2bb40d），[#8406]（https://github.com/heygen-com/hyperframes/pull/8406））。
  • Studio Server： 剪辑根据文件自己的 ID 命名其新的一半（fccd00e719、#8481）。
  • Ci: 从未上传结果的分片会重新运行，并且不会被读取为编辑准确性下降（71588b0a73、#8477）。
  • Studio： 粘贴的元素位于其原始元素之后，而不是位于脚本内（bfd6cb755f、#8489）。
  • 核心： 预览搜索等待每个分级视频绘制其新帧（104eab37ad、#8488）。
  • 核心： 运行时放开的远 clip 会继续计算电影的长度（[5ae70826ed]（https://github.com/heygen-com/hyperframes/commit/5ae70826edba1babb96e57d99be9699c45f0c1d9），[#8480]（https://github.com/heygen-com/hyperframes/pull/8480））。
  • 播放器： 密封影片在运行时开始时不再显示加载失败（835e660e0e、#8472）。
  • Studio： 密封预览显示来自 Studio 解码器的暂停视频帧（61008a40dd、#8466）。
  • Studio： 仅当落在 clip 上（c99cbbe44d、#8456）时，被拒绝编辑后面的拖动才会被拒绝。
  • Studio： 裁剪图层的密封图层选择将其调整大小角放在整个图层上（[f57552da49]（https://github.com/heygen-com/hyperframes/commit/f57552da49c3426e3af641c086fa5cdd25fd595a），[#8468]（https://github.com/heygen-com/hyperframes/pull/8468））。
  • Ci: 重新运行捕获检查会读取 PR 的当前正文 (8f7e59742f、#8479）。
  • Studio： 密封移动或调整大小会在保存自己的帧消息中结束其草稿（[7e26a6d3c0]（https://github.com/heygen-com/hyperframes/commit/7e26a6d3c0ac6df0e9cc881b8e3009046ff47015），[#8473]（https://github.com/heygen-com/hyperframes/pull/8473））。
  • 核心： 仅为沿路径补间的页面加载运动路径插件（4157992664、#8449）。
  • Studio： name getter 抛出的抛出值仍会回退到重新加载（f51e57b26e、#8474）。
  • 引擎： 繁重的页面仅启动与机器内存相同数量的捕获浏览器（969eeba6ee、#8452）。
  • Studio： 在项目切换之前排队的时间线编辑保留在其自己的项目中（3e101f9654、#8458）。
  • Studio： 密封作物以其自己的比例绘制图层的插图并遵循搜索（[05d1bc8b1c]（https://github.com/heygen-com/hyperframes/commit/05d1bc8b1c1cbff2fcb447a36da5b5db4e7bad79），[#8451]（https://github.com/heygen-com/hyperframes/pull/8451））。
  • Studio： 抛出的就地补间补丁说明了为什么它会回退到重新加载（[e98ca56c4a]（https://github.com/heygen-com/hyperframes/commit/e98ca56c4abe575b88ca76566e85773cf378438b），[#8454]（https://github.com/heygen-com/hyperframes/pull/8454））。
  • Studio： 密封调整大小可将自居中图层保留在其所在位置（926e1b5601、#8467）。
  • Studio： 添加密封页面第一次编辑的撤消或重做保持在原位（2d72e523ff、#8462）。
  • Studio： 隐藏元素会将其隐藏在预览中，无论是否密封（d37563e35b、#8461）。
  • Studio： 在被拒绝的编辑后面排队的波纹移位在写入之前被拒绝（[56e0d6fbd7]（https://github.com/heygen-com/hyperframes/commit/56e0d6fbd7fbaa4f668ac940b95089347d1f274e），[#8443]（https://github.com/heygen-com/hyperframes/pull/8443））。
  • Studio： 重新加载的预览显示已保存的成绩，而不是撤消撤回的成绩（5e6068e94a、#8455）。

  • CLI： 医生输出测试不再运行每次机器检查（[aa262c244d]（https://github.com/heygen-com/hyperframes/commit/aa262c244dbe1250356f36fc08d25cfa6c2d15ad），[#8497]（https://github.com/heygen-com/hyperframes/pull/8497））。

  • Studio： 预览回归对解码的封面进行计数，而不是 macOS gamma 滤镜（154842851a、#8484）。
