hyperframes v0.9.63

这个项目是干啥的：HeyGen 开源的 AI 视频剪辑框架，把 HTML 当视频来写并渲染成 MP4，还能让 Claude Code 等助手直接改片，给会写网页的开发者和做批量视频的人用。

变更架构图

亮点

  • 发布范围 / 升级建议 — 这是一个有实质内容的版本，不是重新打标签：它还携带了从未发布到 npm 的 v0.9.62。使用 Studio、本地渲染/检查服务器或 Producer 的用户建议升级；其余用户除非需要新的几何流或渲染修复，否则可以跳过。
  • 核心与编辑器 — 预览现在可以逐帧把元素的几何信息流式传给编辑器，从而支持跟踪元素实时位置的编辑器功能。VideoFrame 生命周期修复也让持有的视频画面在整个绘制过程中保持有效。
  • Studio 响应速度与启动 — 密封预览现在支持音频电平表和音频组，图层重排重新变成一次撤销步骤，添加轨道不再重新挂载所有 clip。并行的静帧检查让文字影片启动更快，Producer 也不再等音频混音完成才开始绘制。
  • 服务器端加固 — CLI、Producer 和 Inspector 服务器不再提供 service-worker 脚本；Studio Server 也不再把项目文件当作脚本提供，Studio 在加载预览帧前会清除陈旧的项目 service worker。运行本地预览/渲染服务器的用户应升级；文档未说明迁移步骤。
  • 潜在破坏性 SDK 行为 — Producer 的站点列表现在默认排除外部链接并向 SDK 调用方发出警告。如果你的集成依赖这些链接，升级前应检查并更新列表处理逻辑；changelog 没有给出可选的 opt-in flag。

超帧 v0.9.63

发布于 2026 年 11 月 17 日。

Studio 的密封预览显示了音频表和音频组，图层重新排序又是一个撤消步骤，并且文本影片开始得更快。没有 HyperFrames 服务器将项目文件作为服务工作线程的脚本提供服务。此版本还包含针对 0.9.62 列出的所有更改。该版本从未到达 npm：合并队列将其与另一个 PR 一起推送到一个推送中，并且发布仅读取推送的最后一次提交。从 #8077 开始，版本从推送中自己的提交发布。

特点

  • 核心： 预览可以每帧将元素的几何图形流式传输到编辑器（f9c5ed07b、#8052）。

性能

  • 引擎： 一次检查多个页面上的静止帧，以便文本电影更快开始（[8ec97da01]（https://github.com/heygen-com/hyperframes/commit/8ec97da011f8746b6a82a03356ed3808aa7dfc6b），[#7997]（https://github.com/heygen-com/hyperframes/pull/7997））。
  • 制作人： 在音频混合完成时开始绘制帧（0be1a0719、#7985）。

修复

  • CLI，制作者、检查器： 渲染、捕获和检查器服务器从不提供 Service Worker 的脚本（72925380c、#8073）。
  • Studio： 图层重新排序又是一个撤消步骤（df31ce2b1、#8072）。
  • 工作室： 音频表和音频组在密封预览中工作（93a4d29c0、#8011）。
  • Studio： 添加轨道不再重新安装时间线上的每个 clip（b064e40e1、#8068）。
  • Studio Server： 项目文件永远不会用作 Service Worker 的脚本（b4acc1a1d、#8064）。
  • Studio： 一个服务工作者留下的项目在预览帧加载之前就消失了（[7a0bec682]（https://github.com/heygen-com/hyperframes/commit/7a0bec682809f18ee37d5d4e085f73afaca6a9b1），[#8067]（https://github.com/heygen-com/hyperframes/pull/8067））。
  • 核心： 通过绘制后关闭的 VideoFrame 绘制保存的视频图片（43e5b7cec、#7971）。
  • 生产者： 默认情况下将外部链接保留在站点列表之外，并警告 SDK 调用者（fbb483852、#8065）。

内部

  • 发布： 与其他 PR 合并在一次推送中的版本在其自己的提交中发布（9b565c8e0、#8077）。
  • 发布： 使用作业的 OIDC 令牌（而不是存储的令牌）发布到 npm（c106793f7、#8070）。
  • 核心： 重新加载的视频播放头测试构建了一个较小的影片，因此繁忙的 CI 永远不会超时（34f98e6a0、#8069）。
  • Studio： 编辑台通过其编辑端口读取密封预览（5f8b7a6ee、#8010）。
