hyperframes v0.9.28

修订 发布时间2026年11月10日 来源heygen-com/hyperframes 英文原文

hyperframes v0.9.28

变更流程图

亮点

  • 管道渲染可观测性 — @hf-result 行现在会报告动态模糊的结果细节：tier、movers 和失败帧。宿主应用无需解析日志即可展示渲染质量和失败情况；文档未描述消费者需要迁移。
  • Apple 编码视频修复 — 短 clip 现在会保留最后一帧，而不再丢失。任何渲染 Apple 编码短片的用户都应升级。
  • 分享可靠性 — 重新邀请会被保留，工作区响应也会经过校验，减少反复分享访问权时的协作失败。
  • 播放器资源清理 — 清空视频的 src 现在会卸载该视频，帮助应用释放媒体资源，避免源变化时播放到过期内容。
  • 升级指引 — Studio App 文档现在明确：云导出随方案提供，而不仅是 API key。没有宣布破坏性变更或必需迁移；受上述修复影响或在意导出访问说明的用户应升级，否则本版可以安全跳过。

超帧 v0.9.28

发布于 2026 年 11 月 10 日。 管道渲染现在报告其运动模糊的情况。 Apple 编码视频中的 clips 短视频保留其最后一帧。

特点

  • CLI： 管道渲染的 @hf-result 线现在带有运动模糊结果（层、移动器、失败的帧），因此主机应用程序可以报告它（651de1d94、#7468）。

修复

  • 引擎： Apple 编码视频中的短 clips 保留其最后一帧（4d0fa2baa、#7469）。
  • 分享： 保留重新邀请并验证工作区响应（58e9cae75、#7470）。
  • 播放器： 清除 src 后卸载视频（e5e79e59e、#7466）。

文档和示例

  • Studio 应用程序： 计划附带云导出，而不仅仅是 API 密钥（756bd6b17、#7441）。
