hyperframes v0.9.74

这个项目是干啥的：HeyGen 开源的 AI 视频剪辑框架，把 HTML 当视频来写并渲染成 MP4，还能让 Claude Code 等助手直接改片，给会写网页的开发者和做批量视频的人用。

变更架构图

亮点

  • 渲染修复 — 后续场景在通过 id 选中的元素上设置 !important 背景时，不再影响该场景开始之前的影片，空白渲染问题已解决。如果你用了按场景设置的 id 背景，建议升级；无需迁移。
  • Studio 密封预览 — 密封预览中的帧现在支持就地编辑文本，拖到密封预览上的 clip 也会出现在时间线上。常用密封预览的 Studio 用户建议升级，其他用户可以跳过这项。
  • Producer 计费与取消 — 嵌套宿主的合成 ID 现在只计一次，而入口页面元素照常计费——这是对用量统计的校正，并非统一降价。编译结束时（包括失败路径）下载会停止，渲染取消现在也能传递到 URL 源探测环节。
  • CLI 与输出兼容性 — Agent 技能改为通过启动器调用 CLI，不再直接调用项目脚本；CLI 的模型检测现在把”每个对象都携带的模型名”视为未知模型。行为变更： 写入媒体时会替换输出位置的符号链接，而不是跟随它；依赖”覆盖符号链接指向的目标”的工作流必须改为直接写入该目标，或相应调整。
  • 发布自动化与结论 — 发布失败的包会自动重试，出口代理测试改为在进程内生成证书；这些都是面向维护者的改进。收到文件夹中未经提示的分享内容现在也会关联到其来源审核。文档没有记录任何公开 API 的移除或正式迁移步骤，因此建议为上述面向用户的修复而升级；否则本版本可以安全跳过。

超帧 v0.9.74

发布于 2026 年 11 月 21 日。 稍后场景在 id 上设置 !重要背景的电影不再呈现空白。 Clips 落在时间线上的密封预览节目中，并再次尝试发布失败的包。

特点

  • 核心： 密封预览的框架运行 Studio 的就地文本编辑会话（9848647b9、#8181）。

修复

  • 生产者： 对嵌套主机计算一次合成 id，并对入口页面的元素进行计费（acdf9e59b、#8335）。
  • Ci: 发布失败的包会在发布失败之前再次尝试（55cfbe008、#8333）。
  • 核心： 在开始之前隐藏后面场景的 id 选择的！重要图层（[861046f50]（https://github.com/heygen-com/hyperframes/commit/861046f5083ed74d82e7b1dc674dde9e5d67c2ef），[#8331]（https://github.com/heygen-com/hyperframes/pull/8331））。
  • 生产者： 当编译返回时，编译的下载停止，但它结束了（[1ce69fd81]（https://github.com/heygen-com/hyperframes/commit/1ce69fd8181b2911ec4a22a73e150197ead00ff1），[#8321]（https://github.com/heygen-com/hyperframes/pull/8321））。
  • 工作室： 放置在密封预览中的 clip 在时间轴上显示（ca91e800e、#8330）。
  • 技能： 代理通过启动器运行 CLI，而不是项目的脚本（b2c18a45c、#8326）。
  • 媒体使用： 媒体写入替换输出名称处的链接，而不是跟随它（9e3fb696c、#8324）。
  • CLI： 每个对象携带的模型名称都是未知模型（[2ed4a141e]（https://github.com/heygen-com/hyperframes/commit/2ed4a141eb84b511eb52add7a82b6ea621401715），[#8319]（https://github.com/heygen-com/hyperframes/pull/8319））。
  • 共享： 在收到的文件夹中保留自动共享以查看其读取的评论（0012c1cb8、#8322）。
  • **生产者：**将渲染的取消传递给在其 URL 处读取的源探测器（f8c90591b、#8312）。

内部

  • 引擎： 出口代理测试使其证书处于进程中，而不是使用 openssl (cc453b767、#8296)。
