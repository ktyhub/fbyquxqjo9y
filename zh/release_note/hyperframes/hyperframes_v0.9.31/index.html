hyperframes v0.9.31

hyperframes v0.9.31

变更流程图

亮点

  • Safari 视频性能与正确性 — Safari 中长视频不再一次性把整个文件载入内存（#7436），小视频会保留其 preload，正在播放的 clip 也会保留其播放源（#7498）。如果你在 Safari 里剪辑或预览长素材，这次会明显降低内存与带宽占用，并减少项目中途播放被重置的情况——这是最值得升级的理由。
  • 开发服务器强制校验 Host 头（需要迁移） — Studio 开发服务器现在会在 API 路由上检查 Host 头，与 0.9.30 中预览服务器的行为保持一致（#7493）。此前可用的隧道、Codespaces 或远程开发环境现在可能返回 403。迁移方式：把域名加入 HYPERFRAMES_PREVIEW_ALLOWED_HOSTS（逗号分隔），该变量现在同时供开发服务器自身的允许列表使用。如果你做远程开发，升级前务必先处理这一项——这是唯一可能破坏现有工作流的改动。
  • 缩略图与预览处理加固 — 缩略图链接的来源现在由服务器决定，来自其他站点的预览会以沙盒方式打开（#7492）。这是偏安全的修复：如果你会打开不可信来源的项目或预览，这项很重要；否则无感。
  • 离线渲染 — Producer 加载默认 GSAP 文件的渲染现在使用 CLI 内置的副本，不再走 CDN，因此无网络也能工作（#7388）。对于隔离网络、CI 或网络不稳定的渲染环境，值得为此升级。
  • 结论与次要项 — 这不是空版本或重打标签，改动都很实在。用 Safari 处理长视频、通过隧道/Codespaces 远程开发（按上面的方式配置域名），或需要离线渲染的用户建议升级。其余用户可以合理跳过：剩下的都是低影响改动——安装冲突警告只会提示包管理器能挪动的包（#7499）、clip/关键帧数量的单复数显示修正（#7496）、文件声明等待首次复制以让编辑可撤销（#7497），外加文档新增一个采用者（DoneCut，#5638）和内部发布构建加固。

超帧 v0.9.31

发布于 2026 年 11 月 10 日。 在 Safari 中，长视频不再一次加载整个文件，并且播放 clips 会保留其源。 Studio 开发服务器现在检查其 API 路由上的主机，因此隧道或远程设置可能需要一项设置。

修复

  • 核心： 在 Safari 中，小视频文件保持其预加载，正在播放的 clip 保持其源（cda84222a、#7498）。
  • Studio： Studio 开发服务器现在也会检查其 API 路由上的主机标头，就像预览服务器自 0.9.30 以来所做的那样。以前工作的隧道、Codespaces 或远程开发主机现在可以获得 403：以 HYPERFRAMES_PREVIEW_ALLOWED_HOSTS（逗号分隔）命名主机，现在也可以到达开发服务器自己允许的主机（b0835262a、#7493）。
  • Studio Server： 缩略图链接源自服务器，并从其他站点打开沙盒预览（983e865ad、#7492）。
  • 制作人： 从 CDN 加载默认 GSAP 文件的渲染使用 CLI 已发布的副本，因此它可以在没有网络的情况下工作（5c5799975、#7388）。
  • CLI： 关于另一个安装隐藏此安装的消息仅指定其包管理器可以移动的安装（[b28bd2b34]（https://github.com/heygen-com/hyperframes/commit/b28bd2b3482a6bcb04d0d0ba0eaee74fbb965455），[#7499]（https://github.com/heygen-com/hyperframes/pull/7499））。
  • Studio： 计数 clips 或关键帧的消息显示 1 clip，而不是 1 clips (ec30de062、#7496)。
  • Studio Server： 当文件仍在更改时，声明会等待其第一个副本，因此仍可以撤消编辑（248f56fba、#7497）。

性能

  • 核心： 在 Safari 中，长视频的 clips 不再一次加载整个文件（fecde9992、#7436）。

文档和示例

  • 文档： 采用者列表添加 DoneCut (0b531bc7a、#5638)。

内部

  • 发布： 强化的发布版本。
