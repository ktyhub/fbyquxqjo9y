hyperframes v0.9.55

这个项目是干啥的：HeyGen 开源的 AI 视频剪辑框架，把 HTML 当视频来写并渲染成 MP4，还能让 Claude Code 等助手直接改片，给会写网页的开发者和做批量视频的人用。

变更架构图

亮点

  • 密封 Studio 预览的可靠性 — 两处修复让密封预览正确处理视频：等待视频代理副本时现在能通过预检（#7856），重载也统一以当前帧令牌为键（#7862）。如果你用密封预览播放视频，这消除了帧残留/竞态问题，是升级的直接理由。
  • 云渲染上传效率 — 云渲染在负载合适时只发一个 zip，并且只上传最大的那个媒体文件（#7859）。这能缩短云渲染的上传时间和带宽消耗，频繁使用云渲染的用户收益最大。
  • 文件服务器与上传的安全加固 — 静态、producer 和 engine 文件服务器现在会校验 Host 头并标记运行时页面（#7852），上传归档也会排除凭据和 agent 状态文件（#7830）。这堵住了 Host 头滥用，防止密钥泄露进上传包——只要有任何文件服务器暴露在网络上就很重要。
  • 性能与 CLI 健壮性 — 子合成头部和根标签扫描改为线性时间（#7866）；CLI 还有几处修复：子目录渲染无论祖先记录如何存储或拼写都能解析到（#7847），publish/cloud-render 暂存会跳过其他电脑的网络共享（#7858），engine 和 CLI 共用一套可信 PATH 规则（#7801）。风险低，主要是透明度和正确性方面的改进；文档还澄清了下载限制是按每次尝试、每个进程计算的（#7867）。
  • 升级结论 / 迁移 — 未记录破坏性变更、API 或 flag 变更，也没有迁移步骤；这是修复与加固版本，不是空操作或重新打标。仍停留在 v0.9.54 的用户应为安全和可靠性修复而升级；不碰 Studio 预览、云渲染或暴露文件服务器的用户可以推迟，但风险很低，升级是合理选择。

超帧 v0.9.55

发布于 2026 年 11 月 15 日。

密封的 Studio 预览现在可以播放视频的代理副本，并在一个当前帧令牌下重新加载。云渲染会在适合时发送一个 zip，并仅上传最大的媒体。文件服务器检查它们所询问的主机，并发布和云渲染暂存跳过其他计算机的网络共享。

修复

  • Studio Server： 子组合头和根标签扫描需要线性时间（ceb969dba、#7866）。
  • CLI： 引擎和 CLI 共享一个 trusted PATH 规则，跳过的项目副本说明了原因（e2430edec、#7801）。
  • CLI： 云渲染在适合时发送一个 zip，并仅上传最大的媒体（9bc2b231d、#7859）。
  • 文档： 引擎文档说下载限制适用于每次尝试和每个进程（[4c09c8b79]（https://github.com/heygen-com/hyperframes/commit/4c09c8b7937eb8972b947df06dd187608ff02345），[#7867]（https://github.com/heygen-com/hyperframes/pull/7867））。
  • CLI： 上传档案绝不包含凭证或代理状态文件（52d43f33a、#7830）。
  • 静态、生产者和引擎文件服务器检查主机并标记运行时页面（490199cef、#7852）。
  • Studio： 密封预览的重新加载要求在一个当前帧标记下（1f17b3dfe、#7862）。
  • CLI： 发布和云渲染暂存跳过其他计算机的网络共享（[c030e3193]（https://github.com/heygen-com/hyperframes/commit/c030e3193d0d5e910d0d03d0a881848b35cdc44d），[#7858]（https://github.com/heygen-com/hyperframes/pull/7858））。
  • Studio Server： 密封预览等待视频的代理副本通过其预检（ae5​​829db7、#7856）。
  • CLI： 子文件夹呈现读取祖先的记录，无论其存储或拼写如何（[fe21bee3c]（https://github.com/heygen-com/hyperframes/commit/fe21bee3cf40007c23e7a3ad7dc7a2cf08f5df20），[#7847]（https://github.com/heygen-com/hyperframes/pull/7847））。
