hyperframes v0.9.50

修订 发布时间2026年11月15日 来源heygen-com/hyperframes 英文原文

hyperframes v0.9.50

变更流程图

亮点

  • 渲染资源访问收窄到自身范围 — 渲染现在只读取属于自己的媒体和文件，会递归校验它引用的每一个播放列表，并拒绝指向目录之外的播放列表。迁移提示： 升级前请把目录外的资源移入播放列表所在目录，或调整这些播放列表的结构。
  • AWS Lambda 默认仅访问公网地址 — 除非函数显式选择退出，否则 Lambda 渲染无法访问私网/内网地址。潜在破坏性变更： 使用私网媒体 URL 的部署必须开启该退出选项；更新日志没有说明对应的 API 或 flag 名称，升级前请自行确认。
  • 文件服务与 Producer 加固 — 渲染文件服务器会拒绝 env 文件和 Git 文件，shown-box 采样限定在本次渲染内，Producer 的媒体探测也只走公共 HTTPS。请检查是否有工作流故意提供这些文件或探测私网/非 HTTPS URL；文档没有提供例外配置或迁移 API。
  • lint 速度提升 — lint 规则现在以线性时间扫描脚本、样式和注释块，大型模板受益明显，且无需改动代码。这主要是性能优化，并不是要你调整渲染逻辑。
  • 要不要升级？ 如果你使用 Lambda、渲染输入来自不可信来源，或项目依赖严格的资源隔离，在通过上述兼容性检查后建议升级。项目小而自包含、且不涉及上述网络与文件服务行为的用户可以合理跳过这个补丁。

超帧 v0.9.50

发布于 2026 年 11 月 15 日。

渲染器现在仅读取属于它们的媒体和文件，包括每个播放列表的播放列表名称。与其他云渲染路径一样，Lambda 渲染默认仅到达公共地址，并且 lint 规则可以更快地检查大文件。

修复

  • AWS Lambda： Lambda 仅渲染公共地址，除非该函数选择退出（e8a59bf17、#7780）。
  • 引擎： 媒体播放列表通过其命名的每个列表进行检查（f4b6aad33、#7778）。
  • 引擎： 拒绝在其文件夹之外命名文件的媒体播放列表（06cf96464、#7768）。
  • 渲染文件服务器拒绝 env 和 Git 文件；显示框采样保留在渲染内（603395c89、#7765）。
  • 生产者： 渲染服务媒体探针保留在公共 HTTPS 上（0e767d620、#7764）。

性能

  • Lint： 规则在线性时间内扫描脚本、样式和注释块（12832e3a9、#7770）。
