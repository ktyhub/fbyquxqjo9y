TypeScript v6.0.3

这个项目是干啥的：一个给JavaScript加类型检查的编程语言，能提前发现代码错误、编译还快了很多，给写大型网页应用的程序员用。

变更架构图

亮点

  • 6.0 线上的维护发布 — v6.0.3 交付的是针对编译器和编辑器服务的修复，不是 TypeScript 6.0 的新能力。已在 6.0 的用户可直接就地升级；从 5.x 升上来的团队应把它当作一次 6.0 迁移，而非普通补丁更新。
  • 类属性推断回归已修复 — #63310 恢复了已初始化属性的独立控制流作用域，修复了 #62243 引入的回归：模块级收窄可能让类字段或静态字段收得过窄，例如推断成 "A" 而不是 AB。在移除此前作为规避手段加上的显式注解前，请重新验证一遍。
  • ATA 更早拒绝非法包名 — #63368 在构造启用 shell 的 npm install 命令之前，用严格的 ^[\w.-]+$ 白名单取代了基于 URI 的过滤。非法包名现在会在校验阶段就被拦下，不会进入安装流程；这属于加固，并不是新增的安全边界。
  • 安装代码操作同样走校验 — #63401 把包名检查扩展到了 InstallPackageRequest.packageName，包括通过 applyCodeActionCommand 发起的请求，堵住了绕过 ATA 侧过滤的路径。自定义编辑器客户端应当处理非法包名时的失败响应。
  • 从 5.x 直接升级仍需检查配置 — 升到 6.0.3 会继承 6.0 的默认配置，例如 strict: true、types: []、rootDir: "."、module: "esnext"、target: "es2025"，以及一批已废弃的编译器选项。请显式固定原有取值或完成迁移；"ignoreDeprecations": "6.0" 只是临时过渡，到 TypeScript 7 就不再有效。
  • 破坏性变更 — 本补丁没有引入破坏性变更。
