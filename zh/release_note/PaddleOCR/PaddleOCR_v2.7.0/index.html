PaddleOCR v2.7.0

小版本 发布时间2023年9月22日 来源PaddlePaddle/PaddleOCR 英文原文

PaddleOCR v2.7.0

这个项目是干啥的：一个能把图片里的文字识别出来的工具，支持多国语言和最新模型，给想从图片或扫描件里提取文字的人用。

变更架构图

亮点

  • PP-OCRv4 mobile 模型 — 在速度与 PP-OCRv3 相当的前提下，中文精度提升 4.5%、英文提升 10%，80 语种平均提升超过 8%——对延迟敏感的移动端应用来说是很有吸引力的升级目标。

  • PP-OCRv4 server 模型 — 追求最高精度：检测模型在中英文场景提升 4.9%，识别模型提升 2%。适合服务端负载，因为那里吞吐和识别质量比移动端限制更重要。

  • 更简单的训练与部署路径 — 更新后的快速上手支持一行命令完成 OCR 推理，PaddleX 通用 OCR 行业方案提供低代码的训练、推理和高性能部署。这降低了采用新模型的运维成本，而不只是跑通单次推理。

  • 用于结构化抽取的 PP-ChatOCR — 把 PP-OCR 与文心大模型结合，从通用场景中抽取关键信息，使本版本超出纯文字识别的范畴。构建文档理解流程的团队需要把文心的服务要求、延迟和成本与 OCR 一起纳入考量。

  • 破坏性变更 — 上游发布说明中未提及。

Release Note

  • 发布 PP-OCRv4，支持 mobile 版和 server 版
    • PP-OCRv4-mobile：速度相当时，中文场景效果相比 PP-OCRv3 提升 4.5%，英文场景提升 10%，80 语种多语言模型平均识别精度提升超过 8%。
    • PP-OCRv4-server：发布目前精度最高的 OCR 模型，检测模型在中英文场景精度提升 4.9%，识别模型精度提升 2% 参考 quickstart 用一行命令快速上手，同时也可在 PaddleX 的通用 OCR 行业方案中用少量代码完成模型训练、推理和高性能部署的全流程。
  • 发布 PP-ChatOCR，这是一种使用 PP-OCR 模型和文心大模型抽取通用场景关键信息的新方案。

Release Note

  • 发布PP-OCRv4，支持移动版和服务器版
    • PP-OCRv4-mobile：速度相当时，中文场景效果较PP-OCRv3提升4.5%，英文场景提升10%，80种语言多语言模型平均识别准确率提升8%以上。
    • PP-OCRv4-server：发布目前准确率最高的OCR模型，中英文场景检测模型准确率提升4.9%，识别模型准确率提升2% 参考【quickstart】(./doc/doc_en/quickstart_en.md)一行命令快速使用，同时PaddleX中的【通用OCR行业解决方案】(https://aistudio.baidu.com/aistudio/modelsdetail?modelId=286)中也可以用很少的代码完成模型训练、推理、高性能部署的全过程。
  • 发布PP-ChatOCR，一种利用PP-OCR模型和ERNIE LLM提取通用场景关键信息的新方案。
