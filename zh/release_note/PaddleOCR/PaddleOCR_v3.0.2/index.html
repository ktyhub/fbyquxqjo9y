PaddleOCR v3.0.2

修订 发布时间2025年6月18日 来源PaddlePaddle/PaddleOCR 英文原文

PaddleOCR v3.0.2

变更流程图

亮点

  • 默认模型来源改为 HuggingFace — 模型权重现在默认从 HuggingFace 下载，而不再从 BOS 下载；可通过 PADDLE_PDX_MODEL_SOURCE=BOS 切回百度对象存储。这会影响首次运行行为和 CI：只能访问 BOS 的环境（例如中国区 runner 或预置缓存）若不覆盖该变量或预填模型缓存，会静默失败。请把它当作运维层面的变更，而不只是文档细节。

  • 服务化调用走向多语言 — PP-OCRv5、PP-StructureV3 和 PP-ChatOCRv4 新增 C++、Java、Go、C#、Node.js 和 PHP 的服务调用示例，另有新的 PP-OCRv5 Android 示例。这才是真正的落地收益：无需逆向服务协议就能把这些流程集成进非 Python 后端。就 PP-StructureV3 而言，版面区域排序算法也针对复杂竖版版面做了重构，因此请重新检查竖排/扫描文档上的排序质量。

  • 更智能的模型与设备选择——但要验证可复现性 — 当设置了 lang 但未指定 ocr_version 时，流程现在会自动选择支持该语言的最新模型；默认设备检测也会考虑所安装 Paddle 构建的实际支持能力。两者都是行为变化：未锁定的 ocr_version 可能静默解析到更新、不同的模型，所选设备也可能与以往不同。如果需要跨升级结果一致，请锁定 ocr_version 并显式指定设备。

  • MKL-DNN 缓存、默认值与并发修复 — MKL-DNN 缓存现在有默认上限且容量可配置，不会再无限增长；高性能推理默认启用 Paddle MKL-DNN 加速并采用更智能的自动配置；基础服务化部署在 MKL-DNN 下的多线程错误也已修复。内存和吞吐特征会有所变化——请重新压测热点路径，并重读已按实际行为更新的 enable_mkldnn 文档。

  • 可能改变输出的正确性修复 — 修复了 Latex-OCR 预处理、文字识别可视化和 PP-StructureV3 表格可视化中的通道顺序（RGB/BGR）问题；PP-StructureV3 的 CLI 参数现在真正生效；export_paddlex_config_to_yaml 和 save_path 的行为与文档一致；极端输入下 overlap_ratio 的溢出也已消除。如果你曾对比可视化图片或绕过「失效」的 CLI flag，请重跑样本——输出和版面现在理应有所不同，那些 workaround 也该移除了。

  • 兼容性与破坏性变更 — 本版本无破坏性变更；放宽了 numpy/pandas 的版本上限，恢复对 Python 3.12 的支持，消除了一个常见的安装阻碍。上游说明中没有 PR 号，因此没有逐条变更的引用。

  • 功能新增：

    • 模型默认下载源从BOS改为HuggingFace，同时也支持用户通过更改环境变量PADDLE_PDX_MODEL_SOURCE为BOS，将模型下载源设置为百度云对象存储BOS。
    • PP-OCRv5、PP-StructureV3、PP-ChatOCRv4等pipeline新增C++、Java、Go、C#、Node.js、PHP 6种语言的服务调用示例。
    • 优化PP-StructureV3产线中版面分区排序算法，对复杂竖版版面排序逻辑进行完善，进一步提升了复杂版面排序效果。
    • 优化模型选择逻辑，当指定语言、未指定模型版本时，自动选择支持该语言的最新版本的模型。
    • 为MKL-DNN缓存大小设置默认上界，防止缓存无限增长。同时，支持用户配置缓存容量。
    • 更新高性能推理默认配置，支持Paddle MKL-DNN加速。优化高性能推理自动配置逻辑，支持更智能的配置选择。
    • 调整默认设备获取逻辑，考虑环境中安装的Paddle框架对计算设备的实际支持情况，使程序行为更符合直觉。
    • 新增PP-OCRv5的Android端示例，详情。

  • Bug修复：

    • 修复PP-StructureV3部分CLI参数不生效的问题。
    • 修复部分情况下export_paddlex_config_to_yaml无法正常工作的问题。
    • 修复save_path实际行为与文档描述不符的问题。
    • 修复基础服务化部署在使用MKL-DNN时可能出现的多线程错误。
    • 修复Latex-OCR模型的图像预处理的通道顺序错误。
    • 修复文本识别模块保存可视化图像的通道顺序错误。
    • 修复PP-StructureV3中表格可视化结果通道顺序错误。
    • 修复PP-StructureV3产线中极特殊的情况下，计算overlap_ratio时，变量溢出问题。

  • 文档优化：

    • 更新文档中对enable_mkldnn参数的说明，使其更准确地描述程序的实际行为。
    • 修复文档中对lang和ocr_version参数描述的错误。
    • 补充通过CLI导出产线配置文件的说明。
    • 修复PP-OCRv5性能数据表格中的列缺失问题。
    • 润色PP-StructureV3在不同配置下的benchmark指标。

  • 其他：

    • 放松numpy、pandas等依赖的版本限制，恢复对Python 3.12的支持。
