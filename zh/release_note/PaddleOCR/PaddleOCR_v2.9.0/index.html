PaddleOCR v2.9.0

这个项目是干啥的：一个能把图片里的文字识别出来的工具，支持多国语言和最新模型，给想从图片或扫描件里提取文字的人用。

变更架构图

亮点

  • 为 PaddlePaddle 3.0 做好准备 — 非文档类改动中很大一部分是 3.0 兼容层：基准测试支持（#13574）、运行时修复（#13568），以及 PIR（新的程序中间表示）下 dy2st 训练和 while 算子的修复（#13853、#14016）。如果你用静态图训练或导出推理模型，这些是图重写过程中静默的正确性修复——即便暂不升级，也应在 3.0 上验证导出的模型。
  • PaddleX 成为推荐路径 — 主分支支持 PaddleX（#13523），把「一站式」工具重新定位为低代码开发（#13979、#13932–#13934），并提供基于 PaddleX 的快速上手（#13936），显示项目正转向流程化 API、远离手工编辑 YAML。文档整合到新的 MkDocs 站点并支持版本化（#13375、#13957），同时删除了旧的应用/数据集文档（#13551、#13662、#13700），因此请更新深链接——旧文档 URL 会 404。
  • LaTeX 公式识别进入主流程 — 新增 LaTeXOCR 支持（#13401），并与 PDF 转 Markdown 导出（#13868、#13942）打通，这是本版本中第一条端到端的「文档 → 带数学公式的 Markdown」路径。后续一串补丁（#13750、#13920，以及 #14047 中最后一刻的重置）暗示该功能在打 tag 时仍在稳定过程中；需要可复现输出时请锁定精确版本。
  • 更多语种脚本——但要核实模型是否可用 — 新增了希伯来语（#13797）、叙利亚语（#13800）、越南语（#13698）和孟加拉语（#13373）的字典/语料。加字典不等于提供训练好的识别权重，所以在把这些语种当作生产可用（而不仅仅是分词器覆盖）之前，请确认存在匹配的 rec 模型。
  • 更轻量的安装与新的版本方案 — 依赖精简（#13461）、禁用 albumentations 自动版本检查（#13583）、针对 setuptools 72.2.0 的 MANIFEST.in 修复（#13670），以及改用 setuptools-scm 提取版本（#13716）。请留意依赖间接导入的代码——tools.infer 的导入失败就需要专门修复（#13348），下游脚本中可能出现类似问题。
  • 需要注意的推理与部署行为 — C++ 推理现在会遵守 --enable_mkldnn=false（#13539），且该 flag 更名为 onednn（#13757），请更新部署脚本。--image_dir 现在是 CLI 必填参数（#13896）。此外还修复了 hubserving（#13918）、多 GPU 模型下载（#13610）、SRN/SLANet 推理（#13851、#13861）以及 GPU 显存增长（#14044）——请移除为此锁定的 workaround。

本版本未正式声明破坏性变更。
