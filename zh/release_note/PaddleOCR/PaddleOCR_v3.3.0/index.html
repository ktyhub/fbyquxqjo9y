PaddleOCR v3.3.0

小版本 发布时间2025年10月16日 来源PaddlePaddle/PaddleOCR 英文原文

PaddleOCR v3.3.0

这个项目是干啥的：一个能把图片里的文字识别出来的工具，支持多国语言和最新模型，给想从图片或扫描件里提取文字的人用。

变更架构图

亮点

  • 端到端文档解析 — PaddleOCR-VL 提供了一种基于 VLM 的方案，可替代串联式 OCR 流程，在页面和元素两个层级识别文字、表格、公式和图表，还支持手写和历史文档。团队若要用它替换现有流程，应验证结构化输出的一致性，而不只是识别精度。
  • 紧凑的动态分辨率架构 — PaddleOCR-VL-0.9B 把 NaViT 风格的高分辨率视觉编码器与 ERNIE-4.5-0.3B 结合起来。目标是以更低成本推理复杂版式，但真正上生产仍需在代表性文档上压测显存占用和延迟。
  • 更广的多语言覆盖 — PaddleOCR-VL 支持 109 种语言，包括俄语、阿拉伯语、印地语和泰语，更适合全球文档负载。精度应按目标文字分别评估，而不能从汇总基准结果推断。
  • PP-OCRv5 轻量识别模型升级 — 这个 200 万参数的多语言模型改进了拉丁文字覆盖，并新增西里尔字母、阿拉伯语、天城文、泰卢固文和泰米尔文。上游报告部分语言精度提升超过 40%，是资源受限 OCR 部署的有力候选。
  • 模型获取 — PaddleOCR-VL 权重已发布在 PaddlePaddle/PaddleOCR-VL。
  • 破坏性变更 — 未提及。

2025.10.16 v3.3.0 发布

  • 发布 PaddleOCR-VL：

    • 型号介绍：

      • PaddleOCR-VL 是专为文档解析量身定制的 SOTA 和资源高效型模型。其核心组件是PaddleOCR-VL-0.9B，这是一种紧凑而强大的视觉语言模型（VLM），它将NaViT式动态分辨率视觉编码器与ERNIE-4.5-0.3B语言模型集成在一起，以实现精确的元素识别。这种创新模型有效支持 109 种语言，擅长识别复杂元素（例如文本、表格、公式和图表），同时保持最低的资源消耗。通过对广泛使用的公共基准和内部基准的综合评估，PaddleOCR-VL在页面级文档解析和元素级识别方面均实现了SOTA性能。它的性能显着优于现有解决方案，与顶级 VLM 相比具有强大的竞争力，并提供快速的推理速度。这些优势使其非常适合实际场景中的实际部署。该模型已在HuggingFace上发布。欢迎大家下载使用！

    • 核心特征：

      • 紧凑而强大的 VLM 架构：我们提出了一种新颖的视觉语言模型，专为资源高效推理而设计，在元素识别方面实现了出色的性能。通过将 NaViT 式动态高分辨率视觉编码器与轻量级 ERNIE-4.5-0.3B 语言模型集成，我们显着增强了模型的识别能力和解码效率。这种集成保持了高精度，同时减少了计算需求，使其非常适合高效实用的文档处理应用。
      • 文档解析的 SOTA 性能：PaddleOCR-VL 在页面级文档解析和元素级识别方面均实现了最先进的性能。它的性能显着优于现有的基于管道的解决方案，并且在文档解析方面与领先的视觉语言模型（VLM）相比表现出强大的竞争力。此外，它还擅长识别复杂的文档元素，例如文本、表格、公式和图表，使其适用于各种具有挑战性的内容类型，包括手写文本和历史文档。这使得它具有高度的通用性，适用于各种文档类型和场景。
      • 多语言支持：PaddleOCR-VL支持109种语言，涵盖全球主要语言，包括但不限于中文、英语、日语、拉丁语、韩语，以及俄语（西里尔字母）、阿拉伯语、印地语（梵文）、泰语等不同文字和结构的语言。这种广泛的语言覆盖范围大大增强了我们的系统对多语言和全球化文档处理场景的适用性。

  • 发布PP-OCRv5多语言识别模型：

    • 提高了拉丁文字识别的准确性和覆盖范围；新增对西里尔文、阿拉伯文、梵文、泰卢固文、泰米尔文等语言系统的支持，覆盖109种语言的识别。该模型仅有2M参数，部分模型精度较上一代提升40%以上。

2025.10.16 v3.3.0 发布

  • 发布PaddleOCR-VL：

    • 模型介绍：

  • PaddleOCR-VL 是一款先进、高效的文档解析模型，专为文档中的元素识别设计。其核心组件为 PaddleOCR-VL-0.9B，这是一个紧凑而强大的语言模型（VLM），它由 NaViT 风格的动态解析编码器与 ERNIE-4.5-0.3B 语言模型组成，能够实现精准的元素识别。该模型支持 109种语言，并在识别复杂元素（如文本、表格、公式和图表）方面表现出色，同时保持极低的资源消耗。通过在广泛使用的公开基准与内部基准上的全面评测，PaddleOCR-VL在页级文档解析与元素级识别均达到SOTA它大家都明显着眼于现有的基于Pipeline方案和文档解析多态模方案先进的通用以及多模态模型，并具有更快的推理速度。这些优势产品非常适合在真实场景中落地部署。模型已发布至HuggingFace，欢迎下载！

    • ** 特性：**
      • 高效而强大的语言模型架构：我们提出了一种新型的高效语言模型，专为资源的推理而设计，在元素识别方面表现出色。通过将NaViT风格的动态高度视觉编码器与轻量级的ERNIE-4.5-0.3B语言模型结合，我们显着增强了模型的识别能力和解码效率。这种集成在保持高准确率的同时降低了计算需求，非常适合实用的文档处理应用。
      • 文档解析的SOTA性能：PaddleOCR-VL在页面级文档解析和元素级识别中达到了最先进的性能。它显着着现有的基于模拟的解决方案，并在文档解析中进行了与领先的视觉语言模型（VLM）的对比此外，它在识别复杂的元素（如文本、表格、公式和图表）方面表现出色，适用于包括手写文本和历史文献内容的具有各种常见的内容类型。这使得它具有高度的多功能性，适用于广泛的文档类型和场景。
      • 多语言支持：PaddleOCR-VL支持109种语言，覆盖了主要的全球语言，包括但不限于中文、英文、日文、拉丁文和韩文，以及使用不同文字和结构的语言，如阿拉伯语、印地语（天城文）和泰语。这种广泛的语言覆盖很大程度上增强了我们系统在多语言和全球化文档处理场景中的适用性。

  • 发布PP-OCRv5小语种识别模型：

    • 优化拉丁文识别的准度和广度，新增西里尔文、阿拉伯文、天城文、泰卢固语、泰米尔语等语系，覆盖109种语言文字的识别。模型参数量2M，部分模型精度较上一代提升40%以上。
