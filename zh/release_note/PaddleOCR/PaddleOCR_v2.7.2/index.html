PaddleOCR v2.7.2

修订 发布时间2024年3月25日 来源PaddlePaddle/PaddleOCR 英文原文

#PaddleOCR v2.7.2

变更架构图

亮点

  • 正式发布到 PyPI — #11800 新增了将包发布到 PyPI 的 CI 工作流，并提升版本号。对采用者来说这是最实际的变化：项目转向受支持的 pip install paddleocr 安装方式，不再依赖源码/手动安装，因此部署更简单、更可复现，也有新的版本可供锁定。

  • 移除 Paddle Fluid API（破坏性） — #11098 更新了 TIPC 测试脚本，并移除已废弃的 Fluid API。如果你的集成代码或自定义脚本仍在调用 Fluid 时代的入口，这就是唯一可能让你踩坑的改动；升级前请审计并迁移到较新的 Paddle API。

  • PyMuPDF 惰性导入 — #11685 把 PyMuPDF 的导入推迟到真正需要时。此前它是硬性的导入期依赖，现在这一依赖被软化，不做 PDF 输入的环境启动更快、更轻，安装失败也更少——但 PDF 功能只有在被调用时才会报错，所以如果依赖这些功能，请务必保留 PyMuPDF。

  • PP-OCRv4 框架更新 — #11047 刷新了 v4 框架定义。如果你在训练或转换 PP-OCRv4 模型，保持同步很重要，因为过时的框架文件会导致模型/配置不匹配。

  • 一批正确性修复 — #11408 修复 rec_postprocess.py 的 bug，#11405 处理版面恢复时 list index out of range 的崩溃，#10973 解决 cls_x/bbox_x 可能未绑定的问题，#11556 修复一处 AttributeError。这些改动共同增强了识别输出和版面处理对畸形或边界输入的健壮性——如果你遇到过间歇性崩溃，值得升级。

  • 芬兰语语言文件 — #10850 新增芬兰语 OCR 支持，扩展了开箱即用的语言集合，便于识别北欧文本。
