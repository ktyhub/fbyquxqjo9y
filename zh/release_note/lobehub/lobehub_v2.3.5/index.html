lobehub v2.3.5

lobehub v2.3.5

这个项目是干啥的：一个开源AI助手平台，带聊天界面和频道协作空间，让团队能和多个AI机器人一起干活，给想自建AI助手的团队用。

变更架构图

亮点

  • Agent 封面色兼容性修复 — 将青色、绿色和红色封面色回移植到社区分支。在 @lobehub/ui@6.19.0 下，旧的七项调色板无法通过类型检查（TS2739），并让部分生成的头像返回 undefined，从而呈现中性背景。此修复使用主题 token，并保持紫色不变。
  • 继续支持较旧的 UI 版本 — 封面色查找会推断其键，保持与本版现有 @lobehub/ui 依赖范围的兼容性。无需依赖更新或迁移步骤。
  • 分享上传锁测试回移植 — canary 回归测试现在只统计被测分享的建议锁，允许不相关会话并发持有自己的锁。这改善了测试隔离性；不改变运行时锁行为。
  • 升级建议 — 如果你在社区分支上使用 @lobehub/ui@6.19.0、遇到 TS2739，或看到生成的头像颜色不正确，就值得升级。否则，这是一个小型、非破坏性的热修复，没有这些问题的用户可以安全跳过。

发布 v2.3.5

来自 PR #23632：https://github.com/lobehub/lobehub/pull/23632

总结

贡献来源：AI辅助 将青色、绿色和红色代理封面颜色从 #23624 向后移植到社区发布分支。全新安装 main 可以在声明的依赖项范围内解析 @lobehub/ui@6.19.0。旧的七项调色板无法对该版本进行类型检查，并为某些生成的头像返回未定义的封面颜色。 封面为每种新颜色使用相应的主题标记。推断查找的键还支持该版本现有依赖范围中的旧 UI 版本。 还向后移植事务范围共享上传锁的金丝雀测试。现在，它的查询会计算所测试共享的咨询锁数量，从而允许不相关的会话同时持有自己的锁。

测试

  • 添加了使用 UI 库的实际头像生成器的回归测试。在最初的版本中，绿色头像收到了 undefined，其中主题指定为 var(--lobe-green)。
  • Ran lint 和 10 个相关的封面颜色测试。
  • 针对原始版本和使用 UI 6.19.0 的此提交进行相同的独立工作区兼容性检查。原来的TS2739型式检验不合格；该修复通过了类型检查和所有 505 个工作区测试。
  • 运行存储库类型检查。
  • 在专用 PostgreSQL 实例中的单独连接上持有两个不相关的咨询锁。旧的测试看到了三个锁并且失败了。通过向后移植，所有 60 个代理共享测试都通过了，而两个不相关的锁仍然保留。存储库 lint 和相关测试也通过了。

接受

根据发布基础验证了真实的 /agents 页面以及使用 UI 6.19.0 的此提交。底座上，生成的青色、绿色和红色头像均具有相同的中性卡牌背景。修复后，每张卡片都有其相应的主题颜色。紫色控件在两个版本中保持相同的背景。 浏览器捕获和计算样式（可能需要测试帐户访问权限）。
