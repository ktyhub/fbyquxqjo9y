lobehub v2.3.4

修订 发布时间2026年11月18日 来源lobehub/lobehub 英文原文

发布 v2.3.4

来自 PR #23286：https://github.com/lobehub/lobehub/pull/23286

🚀 LobeHub 发布 (20261118)

变更流程图

亮点

  • 频道成为协作工作空间 — 这是头条改动：Agent 现在可以给人员/其他 Agent 发消息、就地或在 Thread 中回复、被静音直到被 @提及、为离线设备排队回复，并在同一个 Thread 中汇集以拆分工作（#23139、#23244、#22911）。结合在 lh connect 设备上运行的 MCP 连接器（stdio 和本地连接器）、经由设备的 HTTP MCP 路由、webhook 事件订阅，以及每个 OAuth 连接器支持多个账号（#23047、#23056、#23067），这是一次真正的能力扩展——使用频道或 MCP 的用户都应升级。
  • 编码会话获得大幅易用性改进 — 后续消息现在可以引导或排队到正在运行的 Agent/子 Agent，而不必停止再重启（#23171、#22377）；你可以在发送中途选择/切换/分叉 worktree 和分支，把多个 PR 连同原因关联到某个主题，应用创建的 worktree 在主题归档或移入回收站时自动清理。持久化沙箱加上对话文件夹/仓库的延续（#23126、#23122）让长时间运行的编码工作流轻松许多——对重度 Codex/编码用户是强有力的升级理由。
  • 破坏性变更与必需迁移 — 移除项：im_layout 栏式布局，以及旧版插件 CLI 的 create/install 子命令已消失（#23084、#22372），因此任何依赖它们的脚本或自定义 UI 配置都必须更新。本版还包含针对联系人、入站 webhook、连接器可见性、频道 Thread 锁、验收审查轮次和画板表的数据库迁移（#23045、#22990、#22996、#23143、#22833、#22772）；自托管实例在启动时会应用这些迁移，因此升级前请备份数据库。Composer 行为也变了：只有一个固定的发送/停止按钮，发送键选择移入设置（#23261）。
  • 安全与可靠性加固 — 服务端 HTTP MCP 请求现在走 SSRF 安全的 fetch（#23050），上传需要由预留支持的上传会话（#20524），异构 Agent 不再把 GitHub 凭据发送到设备（#23225）。预期错误条件现在返回 4xx 或回退，而不再暴露为 500（#23058）。这些改动低调但对自托管者和任何暴露 MCP/上传的用户意义重大——仅从安全姿态就值得升级。
  • 升级结论 — 不是空操作：291 个合并 PR，来自 13 位贡献者，是一次实质的每周发布。如果你使用频道、MCP 连接器、编码/worktree 工作流、钉钉/企业微信机器人，或需要安全修复，就升级；要考虑到被移除的 CLI/布局命令，并在自托管时做数据库备份。如果你只使用狭窄的个人聊天设置，且依赖被移除的 im_layout 或旧版插件 CLI 命令，可以合理跳过，因为迁移这些的成本超过功能对你的价值。

发布日期： 2026 年 11 月 18 日
自 v2.3.3 起： 291 项提交 · 291 项合并 PR · 13 名贡献者

此每周版本将频道变成人们和代理并肩工作的地方，让 MCP 连接器在您自己的设备上运行，并使编码会话在运行时更容易引导。

✨ 亮点

  • 通道中的代理 — 代理可以相互发送消息或为其请求者向某人发送消息，就地或在线程中应答，在@提及之前保持静音，并等待离线设备而不是失败回复。 @提到的代理现在聚集在一个线程中并划分工作。 （#23139、#23244、#22911、#23164、#23060、#23103、#23222）
  • 设备上的 MCP 连接器 — 在 lh connect 设备上运行 stdio 和本地 MCP 连接器、通过设备路由 HTTP MCP 服务器、订阅 Webhook 事件以及每个 OAuth 连接器连接多个帐户。 （#23047、#23056、#23067、#22991、#22988）
  • Webhooks 和自动化 — 从 CLI 和代理工具管理 Webhooks 和自动化，并将其事件传递到通道。 (#23266)
  • 更好的编码体验实验室 - 在代理运行时排队或引导后续操作，为新主题选择一个分支，在发送时切换或分叉工作树，并将多个拉取请求链接到一个主题，并附上每个链接的原因。当应用程序创建的工作树的主题被存档或删除时，工作树就会被清理。 （＃23171，＃23186，＃23175，＃23173，＃23185，＃23248，＃23241）
  • 持久沙箱 — 从执行环境中选择一个持久沙箱；新对话保留每个云沙箱的最后一个文件夹和存储库。 （＃23126，＃23122，＃23212）
  • 钉钉和WeCom机器人 — 将钉钉连接为IM机器人通道，并通过指导设置通过其长连接运行WeCom AI机器人。 （＃22336，＃22326，＃23089）
  • 语音和音乐生成 — 添加了 ElevenLabs、Fish Audio、Doubao Speech 和 Gemini 文本转语音，以及与提供商无关的音乐生成和音频文件预览。 （＃22168，＃22951，＃22977，＃23000，＃22918）
  • 更简单的作曲家 - 一个固定的发送/停止按钮，并将发送键选项移至设置。文件上传时发送会将消息排队。粘贴和上传的图像显示为动画卡，重复的粘贴将被跳过，引用的选择将保留在消息中。 （#23261、#23095、#23098、#23080、#23096、#23111）

🏗️ 核心代理和架构

代理运行时

  • 代理现在停在长时间运行的 shell 命令上，而不是轮询它，并在重复未知的工具名称后优雅地停止。 （＃22979，＃23024）
  • 正在运行的子代理可以通过后续操作进行引导或取消。 （＃22377，＃22496）
  • 可以从通用 webhook 中唤醒代理。 (#23128)
  • 运行时状态读取不再加载完整状态 blob，工具集副本不处于每个步骤状态，并且内联步骤读取主题一次。 （＃23210，＃23170，＃23144）
  • 手动压实使用主题固定模型，并且过时的工具结果修剪在热转弯中仍然存在。 （＃22697，＃22981）
  • 已删除的代理文档不再从主题历史记录中发送。 (#23235)
  • 按“停止”不再丢失其中断的步骤的消息。 (#23269)

目标和任务

  • 目标支持运行和评估者评分目标之间的标记，并且可以共享已完成目标的报告。 （＃23108，＃22752）
  • 搜索“目标”页面并从命令菜单中查找目标。 (#23206)
  • 使用 Mod+F 在任务页面视图中查找；将未归档的任务树移动到项目中也会移动其子任务。 （＃22960，＃23214）

记忆和知识

  • 内存提取重试短暂的模型中断，停留在上下文窗口内，并从退役模型中回退。 （＃22894，＃23088）
  • 知识项目支持每个项目的访问列表，在内容读取时强制执行。 (#22905)
  • 上传文件解析和分块现在与主服务器隔离运行。 （＃23117，＃23260）

📱 渠道与集成

  • 管理员可以公开群组频道，供工作区加入；项目渠道首先向项目代理商开放。 （＃23110，＃23107）
  • 人们可以固定对话、编辑自己的消息以及将长直接回复移至主题中。在一个组中，代理会在请求下打开一个长回复线程并在其中进行确认。 （＃23161，＃23155，＃23074，＃23268）
  • 话题预览出现在根消息下方和频道列表中。 （＃22914，＃23204）
  • 您发送的消息不再算作未读。 (#23263)
  • QQ 群@mentions 现在可以到达 LobeHub 并在窗口中获得回复。 (#22921)
  • 延迟的机器人消息不再循环重播，WeCom 会保留在网关重新启动期间到达的回复。 （＃23147，＃23092）

🖥️ 桌面和用户体验

  • 桌面： 导出诊断包，使用查询 CLI 写入结构化日志，并将计算机注册为私有工作区设备。 （＃22966，＃22873，＃22826）
  • 桌面： 使用 Cmd/Ctrl+Shift+T 重新打开关闭的选项卡，并使用 Cmd+1–9 切换选项卡；最近的页面显示每个页面自己的标题。 （＃23224，＃23223）
  • 桌面： 现在显示分阶段核心 OTA 更新，而不是报告“最新”。 (#23018)
  • 侧边栏： 拖动以重新排序团队和个人图钉、隐藏代理组，并在紧凑的收藏夹行中查看任务状态。 Clipped 主题标题在悬停时滚动，双击主题不再打开新选项卡。 （#23048、#23072、#23203、#23062、#23076）
  • 工作侧边栏： 概述显示 Claude Code 后台任务。 (#23198)
  • 项目： 文件夹卡视图，通过“设置”→“环境”统一项目环境，以及每个新项目的专用主代理。 （＃22860，＃23150，＃23129）
  • **技能：**库技能是每个代理选择加入的，并且连接器和技能目录具有新的布局。 （＃23188，＃23187）
  • 代理配置文件： 更简单的导航和指令编辑。 (#23275)
  • **Agent共享：**访问者可以使用共享的Agent的执行环境。 (#23240)
  • 订阅： 使用量和余额合并到一个设置页面，并且提供基本计划。个人设置现在列出订阅帐户，分为“工作空间”和“私人”选项卡。 （#22985、#23090、#23270、#23250、#23242、#23245）
  • 设置： 数据导出在后台运行，并在文件准备就绪时通知您。 (#23125)
  • 会员和代理悬停卡现在出现在整个应用程序中。 （＃22970，＃23054）
  • 长工作流程在打开和流式传输时保持响应。 (#23176)
  • 正确回答的问题卡清晰可见，头像会裁剪非方形图像而不是拉伸它们。 （＃23063，＃23064）

🔧 工具和 CLI

  • lh agent list --tag、lh agent create --tag、代理转移和移动组命令。 （＃23016，＃23012，＃22923）
  • lh acceptance delete 删除了接受外壳。 (#23081)
  • 使用相同帐户凭据恢复从 CLI 上传的库。 (#23259)
  • 支持反重力作为本地代理，并通过 ACP 发现 DeepSeek Harness 模型。 （＃22008，＃22542）
  • 后续行动现在引导本机 Codex 在连接的设备上运行，并且 Codex 警告不再保存为工具调用。仅当选择该模型时才会显示该模型的每周配额。 （＃23264，＃23252，＃23071）
  • 固定的私人工作空间代理的所有者可以将其切换到他们的私人设备。 (#23230)
  • 为 Gemini 4 Hydrogen 添加了 GPT-6.1 Terra 模型卡和 xhigh 思考。 （＃22805，＃22933）

🔒 安全性和可靠性

  • 安全性： 服务器端 HTTP MCP 请求通过 SSRF 安全获取。 (#23050)
  • 安全性： 上传现在需要预留支持的上传会话。 (#20524)
  • 安全性： GitHub 凭证不再发送到异构代理的设备。 (#23225)
  • 可靠性： 预期错误条件返回 4xx 或回退，而不是显示为 500。(#23058)
  • 可靠性： 被拒绝的异步任务完全失败，带有 JWT 过期和图像类型保护。 (#23135)

⚙️ 升级说明

  • 此版本包括联系人的数据库迁移、入站 Webhook、连接器可见性、通道线程锁、验收审核轮次和画板表。 （#23045、#22990、#22996、#23143、#22833、#22772）自托管部署在启动时应用它们；升级前备份数据库。
  • im_layout 导轨布局和旧插件 CLI 创建/安装子命令被删除。 （＃23084，＃22372）
