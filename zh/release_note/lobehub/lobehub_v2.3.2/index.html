🚀 LobeHub 发布 (20261106)

发布日期： 2026 年 11 月 6 日
自 v2.3.1 起： 127 个合并 PR · 11 个贡献者

日常工作变得更容易组织，更容易撤消：任务获得标签和回收站，频道的行为就像真实的对话，交互式 MCP 视图在聊天中打开。

✨ 亮点

  • 任务标签 — 从 Web UI、代理工具或 CLI 中标记任务、按标签过滤并按标签对视图进行分组。 （＃22176，＃22175）
  • 撤消批量任务操作 — 批量操作通过撤消立即应用，删除的任务将进入回收站。 (#22167)
  • 对话中的 MCP 应用程序 — 来自 MCP 应用程序的交互式视图在对话内呈现。 (#21231)
  • 消息列表中的频道 — 对话作为频道打开，消息在您发送后立即显示，提到的成员会收到通知，@提及频道外的某人会邀请他们。 （＃22205，＃22325，＃22222，＃22294）
  • GitHub Copilot CLI 作为异构代理 — 与现有本地代理一起运行 Copilot CLI。 Codex 还根据机器支持的内容获得本机问题和速度选择。 （＃22195，＃22287，＃22264）
  • 托管云设备 — 将一台设备与 lh connect --managed 连接，遵循其在设备列表中的阶段，并在分派工作之前让它唤醒。 （＃22269，＃22275，＃22274，＃22276）
  • 更丰富的聊天输入 — 将代理文档拖到输入中，@提及市场中的代理和技能，然后选择粘贴文本的转换方式。 （#22104、#22194、#22183）
  • 项目设置清单 — 新项目列出了其基本步骤，并在您需要时提供连接。 (#22279)

🏗️ 核心产品和架构

任务和目标

  • 使用 Mod+F 在任务详细信息页面中查找文本，并从全局搜索中搜索任务描述和说明。 （＃22267，＃22256）
  • 存档目标并按存档过滤目标列表；已完成的目标无需签字即可存档，并标记为“已完成”。 （＃22172，＃22259）
  • 成员受让人可以在任务运行时更改，并且一旦任务停止运行，“存档”按钮仍然可用。 （＃22181，＃22321）
  • 批量分配给代理会在分配私人代理之前进行分组并确认。 (#22300)

聊天和代理

  • 粘贴的文本逐字发送，而不是重新格式化为降价。 (#22189)
  • 作曲家上传的内容保留在他们的对话中，并且拒绝的主页消息保留在作曲家中。 （＃22329，＃22280）
  • 转发的主题在源工作目录中继续。 (#22238)
  • 小组运行显示每个成员并行任务的进度。 (#22282)
  • 当您停止运行时仍在运行的工具被标记为已中止。 (#22330)
  • Pi RPC 传输现在支持 Pi 1.x 事件，并且可以预览远程设备运行的工具结果图像。 （＃22324，＃22211）

模型和生成

  • GPT 图像模型可以输出动画 GIF。 (#22306)
  • 对于 Anthropic 结构化输出禁用 DeepSeek V4 思维。 (#22369)

📱 平台/集成

  • **线性：**导入不属于任何项目的问题，在导入选择器中查看问题总数，可以选择包括存档的问题，并在一个请求中运行规则同步轮次。 （＃22301，＃22258，＃22340，＃22263）
  • 机器人： 默认情况下，处理占位符处于关闭状态，并在每个平台上进行切换，并且新机器人以关闭状态反应启动。 （＃21981，＃22182）
  • 机器人： 机器人在禁用组策略时告诉发件人他们缺乏权限，并且 Discord 测试连接会标记已卸载的机器人、已禁用的意图或应用程序 ID 不匹配。 （＃22187，＃22178）
  • 桌面： 使用 Ctrl+数字切换选项卡，修复了 rapid 切换。 (#22225)
  • 页面编辑器： 标题显示实时页面上还有谁，每页字符限制也适用于协作页面。 （＃22174，＃22277）

🖥️ CLI 和用户体验

  • MCP 连接器的新 lh connector 命令组。 (#22193)
  • lh whoami 显示服务器报告的范围，lh doc list 浏览旧文档的页面。 （＃22254，＃21720）
  • lh gen image 让服务器选择默认模型。 (#22197)
  • 本地代理的 lh 使用桌面登录，并在缺少时命名为 lh login。 (#22114)
  • 浏览器选项卡在打开的页面或项目之后标题。 (#22228)

🔧 工具

  • 在 ~/.lobehub/worktrees 下创建新工作树。 (#22203)
  • 现在可以恢复失败的桌面金丝雀上传。 (#22312)

🔒 可靠性和升级

  • 可靠性： 大量映像重新托管不再导致数据库池死锁，并且文件存储探测在数据库事务之外运行。 （＃22290，＃22385）
  • 可靠性： 在第一个字节返回结构化错误之前失败的聊天。 (#22314)
  • 可靠性： 目标管理器声称不再永远重新排队，并且长期死亡的并发运行停止重新警告。 （＃22209，＃22208）
  • 自托管： 此版本附带迁移 0200–0205，它在启动时自动运行。他们添加了 channels.config、goals.archived_at、project_sites.last_seen_at、任务标签表、可重复使用的工作区邀请链接和 LobeBench 评估表。 0204 还使 workspace_invitations.expires_at 可为空，并添加一项检查以确保不可重复使用的邀请保持过期状态。在升级之前进行常用的数据库备份。 （＃22173，＃22171，＃22175，＃22278，＃22245，＃22157）
