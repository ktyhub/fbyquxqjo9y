lobehub v2.2.20

这个项目是干啥的：一个开源AI助手平台，带聊天界面和频道协作空间，让团队能和多个AI机器人一起干活，给想自建AI助手的团队用。

变更架构图

亮点

  • 本地优先加载与设备模型中继（架构转变） — 主题、Agent 文档、设备、git 状态和首页最近项现在先从本地副本读取，让页面在网络响应之前就能绘制（#20449、#20869、#20838、#20841、#20851）。另外，服务端运行、预设任务、模型列表和 Ollama 下载现在可以使用只存在于浏览器标签页或桌面应用中的模型（#20453–#20457）。如果你原本期望模型驻留在服务端，这点很重要——在依赖之前，请对照新的中继机制验证服务端运行的模型路径。
  • 目标获得带决策闸门的批量推行 — 目标现在会保持草稿状态，直到你启动它；一个目标可以批量推行重复任务，每一批都在所有者审查闸门处停下（#20840、#20704、#20917、#20833）。自动化用户获得了人在回路的控制；任何以为目标创建后会自动运行的人会看到不同行为。
  • 小组件/仪表盘与扩展的 CLI 能力 — 新增首页/项目仪表盘、Agent 小组件工具、聊天预览，以及 lh widget / lh dashboard 命令（#20421、#20771），外加任务归档/看板创建、lh connect --auv 用于 Computer Use，以及 lh connect service install --workspace（#20983、#20818）。重度使用 CLI 和仪表盘的用户获益最多。
  • 需要验证的行为变化（没有明确的破坏性变更/迁移声明） — 没有记录正式的 BREAKING CHANGE 或迁移步骤，但几处变化可能咬人：OAuth 不再经过邮箱验证路由（#20545）；子 Agent 现在通过父级执行器执行，afterToolCall 可以拦截工具结果（#20446、#20297）；副本会忽略迟到的 hydrate/错误（#20754）；桌面端可以要求安全更新，Canary 构建会检查首次启动（#20168）。任何 OAuth/邮箱流程或自定义子 Agent/执行器逻辑依赖旧行为的用户，都应显式测试。
  • 新模型/集成与升级结论 — 新增 Claude Haiku 5.5、fal H3 Max 和 Seedance 2.5 视频、DeepSeek Harness 适配器、设备上的 Codex app-server（在 Labs 之后），以及 Droid/OpenCode 的服务端默认模型（#20517、#20210、#18333、#20820、#20965、#20963），并将 nodemailer 升级到 ^9.1.1（#20338）。对设备密集、CLI 和 Agent 自动化用户，以及想要新模型或 nodemailer 修复的用户，值得升级；纯聊天用户若稳定在 v2.2.19 且没有这些需求，可以合理跳过——这是一个包含 419 个 PR 的大型版本，不是空操作或纯元数据重新打标签。

提交消息

🚀 LobeHub 发布 (20261018)

发布日期： 2026 年 10 月 18 日
自 v2.2.19 以来： 419 个合并 PR · 14 个贡献者

现在，代理可以跨设备到达更远的地方，并且应用程序打开速度更快。主题、文档和设备数据首先从本地副本加载，服务器运行可以使用仅存在于您的设备上的模型。

✨ 亮点

  • 批量推出的目标 — 目标在您启动之前一直处于草稿状态，并且目标可以批量推出一项重复任务。每个批次都会停在一个决策门处，供所有者审查。 （#20840、#20704、#20917、#20833）
  • 小部件和仪表板 — 主页和项目仪表板、代理小部件工具、聊天预览和新的 lh widget / lh dashboard 命令。 （＃20421，＃20771）
  • LLM 中继到您的设备 — 服务器端运行、预设任务、模型列表和 Ollama 下载现在可以使用仅在浏览器选项卡或桌面应用程序中可用的模型。 （#20453、#20454、#20455、#20456、#20457）
  • 远程终端和设备维护 — 从网络上打开连接设备上的交互式 shell，并从设备设置更新或重新启动 CLI 守护程序。 （＃20600，＃20527，＃20528）
  • 本地优先加载 — 主题、代理文档、设备、git 状态和家庭最近加载首先从本地副本加载，因此页面在网络响应之前显示内容。 （#20449、#20869、#20838、#20841、#20851）
  • 代理文档文件夹 — 文件夹、批量移动、作为父级的文档，并按名称、创建或修改时间排序。 （＃20761，＃20926）
  • 来自材料的记忆 — 记忆可以从粘贴的文本、文件、文档和对话中提取规则。 (#20266)
  • 从回复中分叉 — 从任何助理消息中开始一个新主题。 (#20610)

🏗️ 核心代理和架构

  • 子代理通过父执行器运行，afterToolCall 控件可以控制工具结果。 （＃20446，＃20297）
  • 在作曲家或 CLI 中选择的技能将在服务器运行时注入。添加代理会安装它引用的市场技能。 （＃20961，＃21059）
  • 代理到代理的消息现在显示是哪个代理发送的。 (#20548)
  • 每次发送时重复的设备和市场查找次数减少，项目发送立即出现。 （#20465、#20897、#20628）

📱 平台/集成

  • 异构代理： DeepSeek Harness 适配器。 Codex 应用程序服务器可以在连接的设备上运行（位于实验室后面）。 Codex 用户消息可以编辑和重新发送。 Codex 和 Pi 可以使用任何支持工具的 LobeHub 模型。 Droid 和 OpenCode 支持服务器默认模型。 （#18333、#20820、#20467、#20612、#20965、#20963）
  • 桌面： macOS 上捆绑的“计算机使用”应用程序、引导式 macOS 隐私权限、带有正在运行的主题的 Dock 菜单、带有固定/取消固定的选项卡拖动以及即时主题切换。 （#20780、#20932、#20635、#20650、#21001）
  • 型号： Claude Haiku 5.5、fal H3 Max 和 Seedance 2.5 视频。 （＃20517，＃20210）
  • OpenAPI： 异步 IM 通道和推送令牌 REST 资源。 (#20440)

🖥️ CLI 与用户体验

  • 任务：归档、从看板列创建任务以及从命令菜单创建或搜索任务。 （#20990、#21020、#21000、#21002）
  • 侧边栏主题可以按项目内的设备、时间、状态或代理进行分组。 （#20811、#20592、#20715）
  • 项目可以有标志，垃圾可以按项目过滤。 （＃20641，＃20739）
  • lh connect --auv 提供计算机使用，lh connect service install 接受 --workspace。 （＃20983，＃20818）
  • 设置搜索可以更好地对结果进行排名并处理 IME 输入。 (#20620)

🔒 安全性和可靠性

  • 安全性： 桌面可能需要安全更新并检查 Canary 版本的首次启动。凭证是通过安全表格收集的。 nodemailer 已更新为 ^9.1.1。 (#20168、#20469、#20338)
  • 可靠性： OAuth 不再经过电子邮件验证，并且副本会忽略迟到的水合物和错误。 （＃20545，＃20754）
