lobehub v2.2.21

这个项目是干啥的：一个开源AI助手平台，带聊天界面和频道协作空间，让团队能和多个AI机器人一起干活，给想自建AI助手的团队用。

变更架构图

亮点

  • 项目与多智能体工作流 — 项目现在成为对话、任务、频道和验收的工作空间；多智能体频道支持按频道的 Agent/设备/目录继承、回复风格和 emoji。Bot 还新增了在 Discord、Slack 和飞书/Lark 上对回复、确认、Thread、编辑和多方 Thread 的唤醒控制。使用项目或基于频道的 Agent 的团队应升级。
  • 资源 → 文档、目标与编辑器 — 资源被重构为”文档”，带有收藏和产物渲染；目标新增选项树、交付审查/签收、跨 Agent 视图和指标图表；编辑器 7.0 新增告警、图表、脚注和页内目录。这些是实质的工作流变化，使用这些领域的人值得升级，但不使用的人不受阻碍。
  • API/CLI 与集成扩展 — 新增群聊、任务运行和通知的 OpenAPI 端点；CLI 命令包括 lh gen json、lh gen decide、lh read <url> 和 lh notification；可重连的 WebSocket；Linear OAuth 的 issue-to-task 同步；以及新的提供商/模型。API 和 CLI 消费者应为新能力而升级，纯浏览器用户若以上都不适用可以跳过。
  • 安全与可靠性 — 新增 JWKS 轮换、带鉴权的记忆 webhook、隔离的提供商端点凭据、@modelcontextprotocol/sdk 安全公告更新、经授权的 marketplace OAuth MCP 安装，以及日志脱敏。它还保留了上下文压缩失败后的历史记录，并改进了 MCP/会话处理。自托管者应为安全修复而升级。
  • 需要自托管迁移 — 本版包含针对收藏、Linear 同步、频道生命周期、项目站点和成员角色的自动启动数据库迁移。**破坏性/运维提示：**升级前请备份数据库，并为迁移时间做好计划；变更日志中没有记录手动迁移或回滚路径。

项目成为工作发生的地方——对话、渠道、任务和接受都存在于其中——而机器人学习何时发言，目标获得完整的审查循环，资源成为文档。

✨ 亮点

  • 项目作为工作区 — 在项目内运行对话和任务，包括项目主编辑器、成员和库设置、可交换的主代理、按代理分组并按状态和设备过滤的主题、拖放重新排序项目以及在项目内分组的频道。 （#21370、#21345、#21344、#21483、#21382、#21398、#21490、#21752）
  • 多代理通道 — 代理在通道中协作，每个通道继承其代理的设备和目录，并且重新设计的通道设置保留每个通道的回复样式和表情符号。 （＃21545，＃21782，＃21658，＃21757）
  • 机器人唤醒 - 机器人根据自己的职责决定何时回复，可以首先确认并在线程中回答，在@提及它们的编辑时唤醒，不参与多方线程，并且选择不回复呈现为自己的状态。可在 Discord、Slack 和飞书/Lark 上使用。 （＃21585，＃21726，＃21719，＃21756，＃21728，＃21727，＃21825）
  • 目标工作区 — 跨代理目标页面、决策选项树、在签署前查看的交付报告、在个人和工作区范围之间复制目标以及北极星指标图表。 （#21221、#21560、#21773、#21665、#21126）
  • 文档和收藏夹 — 资源被重组为带有侧边栏视图选项和工件渲染的文档；将任何页面固定到侧边栏“收藏夹”部分。 （＃21373，＃21548，＃21572）
  • Canvas — 使用 lobe-* 元素呈现的多文件 HTML 工件、代码突出显示、显式共享按钮以及统一的 Canvas/HTML CLI 发布。 （#21326、#21506、#21589、#21671）
  • 编辑器 7.0 — 文档中的警报、图表和脚注以及斜杠菜单，以及 Notion 样式的页面目录。 （#21799、#21826、#21321）
  • Linear 集成 — 通过 OAuth 连接 Linear，并将 Linear 问题同步到项目任务中。 （＃21036，＃21723）

🏗️ 核心代理和架构

  • 子代理在后台运行并将其结果作为消息传递。 (#20862)
  • 通过 OpenRouter 和 OpenAI 的本机决策 API 的决策模型，可按通道配置并在重新设计的服务模型设置中，以及验证器模型。 （#20836、#21359、#21788、#21480、#21774）
  • 新的提供商和型号：Magpie、TypeSafe、MiniMax M3.1 Flash 以及任何带有图像/视频型号列表的 fal 端点。 （＃21644，＃21444，＃21216，＃21238）
  • 为超大请求提供上下文压缩，并在压缩摘要失败时保留历史记录。 （＃21504，＃21590）
  • Stdio MCP 会话在工具调用中保持活动状态并显示可操作的启动错误； MCP 协商现代 HTTP 协议版本。 （＃21031，＃21110，＃21743）
  • 过滤消息搜索、目标搜索和 lh recall。 (#21188)
  • 大型服务器路由器、服务和数据库模型分成了专门的模块，许多 client 商店转移到 @lobechat/replica 上，以实现更快的陈旧优先油漆。 （#21085、#21132、#21145、#21200、#21118）

📱 平台/集成

  • OpenAPI： /api/v1/chat-groups 上的聊天组，立即运行任务并在 /api/v1/tasks/{id}/runs 上读取其运行情况，以及通知设置端点。 （＃21280，＃21470，＃21538）
  • IM: 上传的消息附件、消息读取中模型可见的聊天图像以及实际上@提及人员的 Discord 回复。 （＃21581，＃21758，＃21736）
  • 外部代理： + 菜单中的文件/图像上传，Claude Code 看到 claude.ai 连接器，设备绑定运行在重试时恢复，而不是擦除回合。 （＃21794，＃21294，＃21494）
  • 桌面： 当工作区成员提及您并将链接 URL 悬停在状态栏中时，操作系统会发出通知。 （＃21436，＃21291）
  • **移动：**桌面表面进入移动网络。 (#21503)
  • CLI： lh gen json、lh gen decide、lh read <url>、lh notification、--workspace 的工作区 slugs、替代 SSE 的可重新连接的 WebSocket 以及 lh connect 设备上的浏览器工具。 （#21413、#21835、#21514、#21539、#21540、#20501、#21422）
  • SDK： 用于本机应用程序和 accessToken 提供程序的 OAuth 帮助程序。 (#21435)

🖥️ 用户体验

  • 验收获得工作空间范围、项目绑定、终端证据和反馈移交给原始代理。 （#21432、#21392、#21734、#21619）
  • 内存将上下文页面替换为基于实际内存数据构建的实体页面。 (#21347)
  • 使用 Mod+F 在主题中查找、悬停预取主题页面和工作区回收站。 （＃21530，＃21724，＃21537）
  • 为代理、人员和没有头像的工作空间生成头像，以及代理列表徽章墙。 （#21778、#21632、#21786、#21815）
  • 连接器作为列表 → 详细信息页面打开，并具有管理它们的工作区设置。 （＃21684，＃21653）
  • 更清晰的中文用户界面副本，并纠正了错误翻译。 (#21505)

🔒 安全性和可靠性

  • 安全性： JWKS 密钥轮换用于身份验证。 (#21431)
  • **安全性：**内存 Webhook 需要身份验证配置，并且提供者端点凭据是隔离的。 （＃21254，＃21255）
  • 安全性： @modelcontextprotocol/sdk 已针对安全公告进行更新，市场 OAuth MCP 安装已获得授权，并且 MCP 日志会编辑敏感元数据。 （＃21351，＃21367，＃21423）
  • 安全性： 无法再从通知界面批准安全凭证表单。 (#20580)
  • 可靠性： Web 会话通过延迟会话刷新保持活动状态。 (#21707)
  • 可靠性： SSRF 安全的获取流响应主体而不是缓冲它们。 (#21701)
  • **自托管：**此版本提供了多个数据库迁移（收藏夹、线性同步、频道生命周期、项目站点和成员角色）；它们在启动时自动运行。 （＃21792，＃21722，＃21691，＃21290）
