argo-cd v3.6.1

argo-cd v3.6.1

这个项目是干啥的：一个给 Kubernetes 用的持续交付工具，把应用配置放在 Git 里，一改动就自动同步到集群，适合做 GitOps 的运维团队。

变更架构图

亮点

  • 侧边栏布局修复 — 切换后 UI 侧边栏现在保持对齐（#30771，cherry-pick #30762）。用户遇到侧边栏布局错位时应升级；无需改配置。
  • 自定义 UI 路径修复 — index.html 不再被 webpack 压缩，恢复与 --rootpath 和 --basehref 的兼容性（#30768，cherry-pick #30767）。在反向代理或非根 base path 下提供 Argo CD 时很重要。
  • 升级建议 — 这是以 UI 为主的维护补丁；另一处改动只是版本号升到 3.6.1（#30769）。未列出破坏性变更或迁移步骤。v3.6.0 上不受影响的用户可跳过；从其他 minor 版本升级应遵循官方升级文档。

快速入门

非 HA：

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.6.1/manifests/install.yaml

哈：

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.6.1/manifests/ha/install.yaml
