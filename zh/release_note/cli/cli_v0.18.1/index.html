cli v0.18.1

修订 发布时间2026年3月18日 来源googleworkspace/cli 英文原文

cli v0.18.1

这个项目是干啥的：谷歌办公套件的命令行工具，让你在终端里直接收发 Gmail、管理草稿和操作谷歌服务。给不爱开网页、爱用命令行的办公用户用。

变更架构图

亮点

  • 容器优雅关停 — gws gmail +watch 和 gws events +subscribe 现在除 Ctrl+C 外还处理 SIGTERM，使 Kubernetes、Docker 和 systemd 能够干净地停止长时间运行的拉取循环，而不必依赖强制终止。
  • 兼容性 — 这是补丁级的生命周期修复。没有破坏性 API 变更、新 flag、配置变更或迁移步骤。
  • 升级建议 — 若上述任一命令作为常驻服务运行，尤其是在容器中或由进程管理器托管，应升级到 v0.18.1。不运行这些命令的用户可安全跳过本版本。

Release Note

补丁变更

  • a87037b：在 gws gmail +watch 和 gws events +subscribe 中处理 SIGTERM 以实现干净的容器关闭。 长时间运行的拉循环现在可以在 SIGTERM 上正常退出（除了 Ctrl+C）， 在 Kubernetes、Docker 和 systemd 下启用干净关闭。

安装 gws 0.18.1

通过 shell 脚本安装预构建的二进制文件

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/googleworkspace/cli/releases/download/v0.18.1/gws-installer.sh | sh

通过 powershell 脚本安装预构建的二进制文件

powershell -ExecutionPolicy Bypass -c "irm https://github.com/googleworkspace/cli/releases/download/v0.18.1/gws-installer.ps1 | iex"

将预构建的二进制文件安装到您的 npm 项目中

npm install @googleworkspace/cli@0.18.1
