cli v0.19.0

这个项目是干啥的：谷歌办公套件的命令行工具，让你在终端里直接收发 Gmail、管理草稿和操作谷歌服务。给不爱开网页、爱用命令行的办公用户用。

变更架构图

亮点

  • 认证 CLI 全面重构到 clap（次要变更；请回归测试脚本） — a078945 将 handle_auth_command、handle_login、resolve_scopes 和 handle_export 中的手写参数解析替换为结构化的 clap::Command 定义，新增 ScopeMode 枚举以实现类型安全的范围选择，并让每个 gws auth 子命令都拥有真正的 --help。设计上保持行为兼容，但依赖旧解析器“怪癖”的自动化脚本应做一次冒烟测试——官方并未提供显式迁移命令。
  • events 助手支持安全模拟 — 8a749c2 为 gws events +renew 和 gws events +subscribe 增加 --dry-run：命令只打印将要执行的操作，不发起任何 API 调用，因此智能体无需触达服务器即可模拟请求。该选项默认关闭、风险低，对于编写 events 工作流的脚本用户是明确的升级理由。
  • 生成的 skills 终于能通过校验（#521） — f157208 将生成的 SKILL.md frontmatter 从流式序列（bins: ["gws"]）改为块式序列（bins:\n - gws），因为参考校验工具 agentskills validate 使用的 strictyaml 不接受流式写法，导致全部 93 个生成的 skill 校验失败。若你用此工具生成或校验 Agent Skills，请重新生成——这是本版本功能上最重要的修复。
  • 认证加固与崩溃修复 — d341de2 让 gws auth setup 在启动向导前先响应 --help/-h（只查看用法时不再误建项目），b4d5e26 正确向上抛出令牌目录创建/权限错误而非静默忽略，d679401 通过按字符索引修复多字节 UTF-8 机密上的 mask_secret 崩溃。对非 ASCII 机密和权限收紧的家目录而言，可靠性提升明显。
  • 升级建议 — 这不是空操作或重新打标签，包含实质性代码变更。使用 gws auth 子命令（新 --help、ScopeMode）、events 助手（--dry-run）或生成/校验 skills（#521）的用户应升级。若只用未触及这些路径的只读命令、且没有依赖认证解析器重写的脚本，可放心跳过。

Release Note

小改动

  • a078945：重构所有 gws auth 子命令以使用 clap 进行参数解析 将 handle_auth_command、handle_login、resolve_scopes 和 handle_export 中的手动参数解析替换为结构化 clap::Command 定义。引入 ScopeMode 枚举以进行类型安全范围选择，并为所有 auth 子命令添加适当的 --help 支持。

补丁变更

  • 8a749c2：壮举（助手）：添加 —dry-run 支持事件助手命令 将空运行模式添加到 gws events +renew 和 gws events +subscribe 命令。 当指定 —dry-run 时，命令将打印将执行的操作 无需进行任何 API 调用即可获取。这允许代理模拟请求 无需到达服务器即可学习。
  • d679401：通过使用基于字符的索引而不是字节偏移切片来修复多字节 UTF-8 机密上的 mask_secret 恐慌
  • d341de2：启动设置向导之前在 gws auth setup 中处理 —help/-h，防止用户只需要使用信息时意外创建项目
  • f157208：修复：在生成的 SKILL.md frontmatter 中使用块样式 YAML 序列 将流程顺序（bins: ["gws"]、skills: [...]）替换为块式 所有生成的 SKILL.md frontmatter 模板中的序列 (bins:\n - gws)。 流序列是有效的 YAML，但被 strictyaml 拒绝，这 代理技能参考实现（agentskills validate）用于解析 前题。这导致所有 93 个生成的技能都无法通过验证。 修复#521
  • b4d5e26：修复身份验证错误传播：当令牌目录创建或权限设置失败时正确传播错误，而不是默默地忽略它们

安装 gws 0.19.0

通过 shell 脚本安装预构建的二进制文件

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/googleworkspace/cli/releases/download/v0.19.0/gws-installer.sh | sh

通过 powershell 脚本安装预构建的二进制文件

powershell -ExecutionPolicy Bypass -c "irm https://github.com/googleworkspace/cli/releases/download/v0.19.0/gws-installer.ps1 | iex"

将预构建的二进制文件安装到您的 npm 项目中

npm install @googleworkspace/cli@0.19.0
