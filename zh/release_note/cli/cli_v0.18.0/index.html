小版本 发布时间2026年3月18日 来源googleworkspace/cli 英文原文

cli v0.18.0

这个项目是干啥的：谷歌办公套件的命令行工具，让你在终端里直接收发 Gmail、管理草稿和操作谷歌服务。给不爱开网页、爱用命令行的办公用户用。

变更架构图

亮点

  • Gmail 发送改进 — +send、+reply、+reply-all 和 +forward 现在使用 mail-builder 构建符合 RFC 的 MIME 并处理显示名引号。Gmail 的”以…身份发送”身份会自动填充 From，裸 --from 地址会获得其配置的显示名，+send 支持用 --from 选择别名。
  • 附件 — 所有邮件助手新增 -a/--attach，自动检测 MIME 并做 25MB 校验。较大的邮件走上传端点，把实际限制从 5MB 的纯元数据路径提高到 Gmail 的 35MB API 上限。
  • 读取与回复修复 — 新增 +read，可将邮件头和正文提取为文本、HTML 或 JSON。对自己发送的邮件”回复全部”不再因”No To recipient remains”而失败；现在会指向原始的 To 收件人，与 Gmail 网页版行为一致。
  • 破坏性变更 / 迁移 — 已失效的 +send --attachment 参数被移除；脚本应改用 -a/--attach。由于 --attachment 此前被静默忽略，没有可用行为消失。构造 OriginalMessage 的 Rust 消费者必须处理 thread_id 变为 Option<String>。
  • 终端加固与升级建议 — 输出处理现在一致地尊重 NO_COLOR 和 TTY 检测，剥离危险的 Unicode 控制字符，并清理原始 API 错误和用户查询。Gmail CLI 用户应为附件、+read 和发送修复而升级；只使用非 Gmail 命令的用户一般可以跳过，除非他们依赖 watch/输出行为或需要这些清理加固。

Release Note

小改动

  • 908cf73：feat(gmail)：使用发送设置中的显示名称自动填充 From 标头 获取用户的发送身份，以在所有邮件助手（+send、+reply、+reply-all、+forward）中设置带有显示名称的 From 标头，与 Gmail 网络 client 行为相匹配。还通过配置的显示名称丰富了裸 --from 电子邮件。
  • 6e4daaf：Gmail 帮助程序汇总：邮件生成器迁移、—attach 标志（上传端点）、+读取帮助程序
    • 将 +send、+reply、+reply-all 和 +forward 迁移到 mail-builder 箱，以实现符合 RFC 的 MIME 结构
    • 将 --from 标志添加到 +send 以支持发送别名
    • 将 -a/--attach 标志添加到所有邮件助手（+send、+reply、+reply-all、+forward），并具有 mime_guess2 自动检测、25MB 大小验证和上传端点支持（35MB API 限制与仅 5MB 元数据）
    • 添加 +read 帮助程序以提取消息正文和标头（文本、HTML 或 JSON 输出）
    • 使 OriginalMessage.thread_id 可选 (Option<String>) 以实现草案兼容性
    • RFC 2822 显示名称引用由 mail-builder 本地处理
    • 在执行器中引入 UploadSource 枚举以实现类型安全的上传策略

补丁变更

  • 1e90380：修复（gmail）：从 +send 中删除死 --attachment arg +send 子命令定义了一个重复的 "attachment" arg "attach" arg 已由 common_mail_args 提供。自 parse_attachments 读取 "attach"，--attachment 标志被默默地忽略。删除了 死重复。
  • 908cf73：修复（gmail）：正确处理对自己消息的全部回复 全部回复您发送的邮件不再出现“没有收件人”的错误。原来的“收件人”收件人现在用作回复目标，与 Gmail 网络 client 行为相匹配。
  • 2e909ae：将终端清理、着色和输出助手合并到新的 output.rs 模块中。修复了 watch.rs 中绕过 NO_COLOR 和 TTY 检测的原始 ANSI 转义码，升级 sanitize_for_terminal 以去除危险的 Unicode 字符（双向覆盖、零宽度空格、方向隔离），并清理以前的原始 API 错误主体和用户查询输出。

安装 gws 0.18.0

通过 shell 脚本安装预构建的二进制文件

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/googleworkspace/cli/releases/download/v0.18.0/gws-installer.sh | sh

通过 powershell 脚本安装预构建的二进制文件

powershell -ExecutionPolicy Bypass -c "irm https://github.com/googleworkspace/cli/releases/download/v0.18.0/gws-installer.ps1 | iex"

将预构建的二进制文件安装到您的 npm 项目中

npm install @googleworkspace/cli@0.18.0
