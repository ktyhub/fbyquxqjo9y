caveman v3.1.0

三种技能取代了六个强度级别、经过审查的修复堆栈土地以及自 3.0.0 附带以来堆积的回购维护。 main 上有 106 次提交。

技能，针对当前模型的重新思考

/caveman 是声音。 /ultracave 剥离语法。 /megacave 说文言文。每个都是一个独立的 skills/<id>/SKILL.md，形状相同：论文、持久性、原因、带有坏/好对的编号规则、何时违反规则、预发送检查。简化技术英语 (ASD-STE100) 是这三种语言的基础，而不是竞争的语域。工具调用静音禁令成为每个阶段的一条状态线（#1127、#1154），并且主机线束的优先级高于何时说话的技能（#1125）。 /caveman lite|full|ultra|wenyan* 继续作为别名使用；存储的会话在读取时迁移。 挂钩：模式 ID 现在为 caveman、ultracave、megacave（+ 一次性、off）；遗留值映射到每个读取路径上； SessionStart 钩子注入主动技能整体；每回合强化源自技能的主题；状态行呈现 [CAVEMAN]、[ULTRACAVE]、[MEGACAVE]；固定到插件缓存路径的过时状态行副本现在会触发修复微移。始终在线的规则副本（IDE 规则、opencode AGENTS.md、OpenClaw、扩展、cavecrew 代理、Codex/Gemini 存根、Codex 插件镜像）会重新生成或与漂移测试手动同步。设计记录：docs/technical/three-skills-refactor.md。 在隔离主机设置的 claude-opus-5-5 上重新运行评估：与普通 Answer concisely. 对照相比，中位输出减少为穴居人 3%、超洞穴 35%、巨型洞穴 9%（n=10，单次运行，仅长度）。 README 和 HONEST-NUMBERS 正是引用了这一点。 所有者决定： 默认语音在此模型上仅增加了“简洁”； ultracave 可以节省开支。

修复堆栈（PR #1163 #1157 #1158 #1159 #1160 #1161 #1162，合并为一个）

代理会话标记关联和静默 CCR 失败 (#1105 #1110 #1149 #1113)；引擎 JSON 省略、非有限单元、收缩哨兵 (#1151 #1095)； CLI 悬空钩子、收缩钩子权限、Codex TOML、远程控制、opencode OAuth、水印锁（#1137 #1138 #1133 #1134 #1101 #1119 #1116 #1132）；状态栏微移路径（#1147）； Codex SessionStart 遵循 defaultMode (#185 #1139)； Caveman-压缩流/天花板/配对（＃1131＃1107）。 #1164（Pi 恢复证明，Pi 1.0.0）不在这里：它必须等待 caveman-mcp 二进制版本。
