caveman v3.2.0

Caveman 3.2.0 带来了版本清理和随后对安装程序、插件、技能和本地运行时的本机安装修复。

缓存安全压缩和运行时

  • 在对话中保持先前的压缩决策稳定，包括发送原始字节的决策。缓存前缀检查记录本地请求遥测和 caveman status 中由穴居人引起的更改。
  • 使用 Retry-After 传递速率限制响应； Pin 接受了对其对话沿袭的原始重试。
  • 构建代理和引擎，支持六平台二进制矩阵中的 TypeScript、JavaScript、Python、Rust、Java、C 和 C++。该容器仍然是纯 Go 构建。
  • 通过请求协议路由裸 /v1/models，在没有硬链接的文件系统上支持 CCR，并压缩支持的 JUnit、pytest 和 Jest 报告。
  • 通过订阅代理路由 Pi 的 ChatGPT OAuth 流量，包括 zstd 请求解码。工具结果压缩需要可恢复的句柄。

本机安装、挂钩和技能

  • Native Claude 和 Codex 安装包括三种语音技能。禁用本机路由可保持这些技能可用并禁用每个配置的 Claude 配置文件。
  • 子代理继承其会话的模式。无头 claude -p 和代理 SDK 会话在语音关闭的情况下开始。
  • 在 SessionEnd 记录会话统计信息，并进行项目范围的会话查找。
  • 添加或扩展 Codex、Cursor、Copilot CLI、Antigravity CLI 和 Grok Build 的始终在线集成；添加CodeBuddy代码安装。
  • 将 OpenCode Cavecrew 代理安装为子代理，并在活动提供商绕过代理时发出警告。
  • 将独立安装程序从 bin/ 移至 installer/，以实现企业市场兼容性；改进 Windows 命令填充程序处理和代理检测。
  • 细化差异优先答案、问题、评论和无钩状态报告的语音规则。

压缩、评估和扩展

  • 将独立的 OpenCode 和 OpenAI 兼容提供程序添加到 caveman-compress、提供程序特定的模型选择以及受保护的 nocompress 区域。
  • 记录评估使用情况，添加确定性保真度套件，支持特定于语言的提示集，并在运行中断后保留部分结果。现有已发布的风格测量仍保留其原始规则和方法的标签。
  • 浏览器扩展 1.3.0 改进了丰富的编辑器快照和发送控制发现。浏览器商店发布与此 GitHub 版本是分开的。

配套版本

  • 已签名的二进制文件和容器：bin-v2.1.0。
  • npm CLI: @caveman-ai/cli@2.1.0。
  • npm Pi 扩展名：@caveman-ai/pi@0.3.0，包括 Apache-2.0 许可证转换和未发布的 0.2.0 版本中的许可证/通知文件。
  • npm TypeScript 中间件：@caveman-ai/middleware@1.0.1，通过 0.131.0 支持经过测试的 Anthropic SDK 版本。 所有四个配套版本都是通过存储库的签名标签工作流程发布的。所有 36 个运行时二进制文件都是匿名下载的；他们的校验和清单和发布身份已签名。容器签名根据确切的发布工作流身份进行验证。 npm 包带有 GitHub Actions 出处。平台集成测试、本地缓存检查和发布工件不会建立客户节省或生产成果。 已发布的 CLI 烟雾在 macOS ARM、Linux x64 和 Windows x64 上传递：干净的 npm 安装、签名的配套设置、记录模式下的包装器端点注入、使用字节精确检索进行压缩以及隔离的 npm 卸载保留不相关的配置。 完整改动：https://github.com/JuliusBrussee/caveman/compare/v3.1.0…v3.2.0
