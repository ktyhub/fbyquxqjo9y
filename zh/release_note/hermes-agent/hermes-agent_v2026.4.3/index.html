hermes-agent v2026.4.3

修订 发布时间2026年4月3日 来源NousResearch/hermes-agent 英文原文

#爱马仕代理v0.7.0(v2026.4.3) 发布日期： 2026 年 4 月 3 日

弹性版本 — 可插拔内存提供程序、凭证池轮换、Camofox 反检测浏览器、内联差异预览、跨竞争条件和批准路由的网关强化，以及针对 168 个 PR 和 46 个已解决问题的深度安全修复。

✨ 亮点

  • 可插入内存提供程序接口 - 内存现在是一个可扩展的插件系统。第三方内存后端（Honcho、向量存储、自定义 DB）实现一个简单的提供者 ABC 并通过插件系统注册。内置内存是默认提供程序。 Honcho 集成恢复到与具有配置文件范围的主机/对等解析的参考插件完全同等。 (#4623、#4616、#4355)
  • 同一提供商凭证池 — 为同一提供商配置多个 API 密钥并自动轮换。线程安全的 least_used 策略在密钥之间分配负载，401 故障会触发自动轮换到下一个凭证。通过设置向导或 credential_pool 配置进行设置。 (#4188、#4300、#4361)
  • Camofox 反检测浏览器后端 — 使用 Camoufox 进行隐形浏览的新本地浏览器后端。具有用于可视化调试的 VNC URL 发现的持久会话、用于本地后端的可配置 SSRF 旁路、通过 hermes tools 自动安装。 (#4008、#4419、#4292)
  • 内联差异预览 - 文件写入和修补操作现在会在工具活动源中显示内联差异，让您在代理继续操作之前直观地确认发生了什么变化。 （[#4411]（https://github.com/NousResearch/hermes-agent/pull/4411），[#4423]（https://github.com/NousResearch/hermes-agent/pull/4423））
  • API 服务器会话连续性和工具流 — API 服务器（开放式 WebUI 集成）现在实时流式传输工具进度事件，并支持跨请求持久会话的 X-Hermes-Session-Id 标头。会话保留到共享 SessionDB。 (#4092、#4478、#4802)
  • ACP：Client 提供的 MCP 服务器 - 编辑器集成（VS Code、Zed、JetBrains）现在可以注册自己的 MCP 服务器，Hermes 将其作为附加代理工具。您编辑器的 MCP 生态系统直接流入代理。 (#4705)
  • 网关强化 - 主要稳定性通过竞争条件、照片媒体交付、洪水控制、卡住会话、批准路由和压缩死亡螺旋。该网关在生产中更加可靠。 (#4727、#4750、#4798、#4557)
  • 安全：秘密渗透阻止 - 现在扫描浏览器 URL 和 LLM 响应以查找秘密模式，通过 URL 编码、base64 或提示注入阻止渗透尝试。凭据目录保护扩展到 .docker、.azure、.config/gh。 execute_code 沙箱输出已被编辑。 (#4483、#4360、#4305、#4327)
