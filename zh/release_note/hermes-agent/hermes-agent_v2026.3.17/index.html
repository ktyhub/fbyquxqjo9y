hermes-agent v2026.3.17

修订 发布时间2026年3月17日 来源NousResearch/hermes-agent 英文原文

#爱马仕代理v0.3.0(v2026.3.17) 发布日期： 2026 年 3 月 17 日

流媒体、插件和提供商发布 — 统一的实时令牌交付、一流的插件架构、使用 Vercel AI Gateway 重建的提供商系统、原生 Anthropic 提供商、智能审批、实时 Chrome CDP 浏览器连接、ACP IDE 集成、Honcho 内存、语音模式、持久 shell 以及跨每个平台的 50 多个错误修复。

✨ 亮点

  • 统一流基础设施 — CLI 和所有网关平台中的实时逐个令牌传送。响应在生成时流动，而不是作为块到达。 (#1538)
  • 一流的插件架构 — 将 Python 文件拖放到 ~/.hermes/plugins/ 中，以使用自定义工具、命令和挂钩扩展 Hermes。无需分叉。 （[#1544]（https://github.com/NousResearch/hermes-agent/pull/1544），[#1555]（https://github.com/NousResearch/hermes-agent/pull/1555））
  • Native Anthropic Provider — 使用 Claude Code 凭证自动发现、OAuth PKCE 流和本机提示缓存进行直接 Anthropic API 调用。不需要 OpenRouter 中间人。 (#1097)
  • 智能审批 + /stop 命令 — 受 Codex 启发的审批系统，可了解哪些命令是安全的并记住您的偏好。 /stop 立即终止当前运行的代理。 (#1543)
  • Honcho 内存集成 — 异步内存写入、可配置的调用模式、会话标题集成以及网关模式下的多用户隔离。作者：@erosika。 (#736)
  • 语音模式 — CLI 中的一键通、Telegram/Discord 中的语音注释、Discord 语音通道支持以及通过更快的耳语进行本地耳语转录。 (#1299、#1185、#1429)
  • 并发工具执行 — 多个独立工具调用现在通过 ThreadPoolExecutor 并行运行，显着减少多工具轮流的延迟。 (#1152)
  • PII 编辑 — 启用 privacy.redact_pii 后，在向 LLM 提供商发送上下文之前会自动清除个人身份信息。 (#1542)
  • /browser connect via CDP — 通过 Chrome DevTools 协议将浏览器工具附加到实时 Chrome 实例。调试、检查已打开的页面并与之交互。 (#1549)
  • Vercel AI 网关提供商 — 通过 Vercel 的 AI 网关路由 Hermes，以访问其模型目录和基础设施。 (#1628)
  • 集中式提供商路由器 — 使用 call_llm API 重建提供商系统、统一的 /model 命令、模型交换机上的自动检测提供商以及辅助/委托 client 的直接端点覆盖。 (#1003、#1506、#1375)
  • ACP 服务器（IDE 集成） — VS Code、Zed 和 JetBrains 现在可以作为代理后端连接到 Hermes，并提供完整的斜线命令支持。 （[#1254]（https://github.com/NousResearch/hermes-agent/pull/1254），[#1532]（https://github.com/NousResearch/hermes-agent/pull/1532））
  • 持久 Shell 模式 - 本地和 SSH 终端后端可以跨工具调用维护 shell 状态 - cd、环境变量和别名持续存在。作者：@alt-glitch。 （[#1067]（https://github.com/NousResearch/hermes-agent/pull/1067），[#1483]（https://github.com/NousResearch/hermes-agent/pull/1483））
  • 代理按策略蒸馏 (OPD) — 用于蒸馏代理策略的新 RL 训练环境，扩展了 Atropos 训练生态系统。 (#1149)
