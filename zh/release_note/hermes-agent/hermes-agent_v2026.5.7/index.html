hermes-agent v2026.5.7

修订 发布时间2026年5月7日 来源NousResearch/hermes-agent 英文原文

#爱马仕代理v0.13.0(v2026.5.7) 发布日期： 2026 年 5 月 7 日 自 v0.12.0 起： 864 个提交 · 588 个合并 PR · 更改了 829 个文件 · 128,366 个插入 · 282 个问题已关闭（13 个 P0，36 个 P1） · 295 个社区贡献者（包括共同作者）

坚韧发布 — Hermes 特工现在完成了它开始的事情。看板作为耐用的多代理板提供（心跳、回收、僵尸检测、不完全退出时自动阻止、每个任务重试、幻觉恢复）。 /goal 使代理在回合中锁定目标（拉尔夫循环）。 Checkpoints v2 通过真正的修剪重写了状态持久性。网关在重新启动后自动恢复中断的会话。 Cron 发展了 no_agent 看门狗模式。安全浪潮关闭了 8 个 P0 — 默认情况下，编辑功能处于开启状态，Discord 角色允许列表属于行会范围，WhatsApp 默认情况下拒绝陌生人，TOCTOU 窗口在 auth.json 和 MCP OAuth 上关闭。 Google Chat 成为第 20 个平台。提供者成为可插拔的表面。七个 i18n 语言环境船舶。

✨ 亮点

  • 多代理看板 - 委托给实际完成的人工智能团队 - 启动一个耐用的看板，将任务放在上面，让多个 Hermes 工作人员拿起它们，移交并关闭它们。心跳、回收、僵尸检测、重试预算和幻觉门让团队保持诚实。一次安装，多个看板。 (#17805、#19653、#20232、#20332、#21330、#21183、 #21214)
  • /goal — 代理不会忘记您要求它做什么 — 将代理锁定到目标上，并且它会在轮流中保持执行任务。 Ralph 循环作为一流的原语。 (#18262、#18275、#21287)
  • 显示视频 — 新的 video_analyze 工具，用于在 Gemini 和兼容的多模式模型上理解本机视频。 (@alt-glitch) (#19301)
  • 克隆语音 — xAI Custom Voices 成为提供语音克隆支持的 TTS 提供商。 (@alt-glitch) (#18776)
  • Hermes 讲您的语言 — 静态网关 + CLI 消息可翻译为 7 种语言环境：中文、日语、德语、西班牙语、法语、乌克兰语和土耳其语。文档站点获得中文 (zh-Hans) 语言环境。 (#20231、#20329、#20467、#20474、#20430、#20431)
  • Google Chat — 第 20 个消息传递平台 — 加上通用平台插件挂钩表面，因此第三方适配器无需触及核心即可插入（IRC 和 Teams 已迁移）。 (#21306、#21331)
  • 会话在重新启动后仍然存在 - 网关在代理中间反弹，/update 重新启动，源文件重新加载 - 网关恢复时对话自动恢复。 (#21192)
  • 安全波 - 8 P0 关闭 - 默认情况下进行编辑，Discord 角色允许列表行会范围（CVSS 8.1 跨行会 DM 旁路关闭），WhatsApp 默认情况下拒绝陌生人，TOCTOU 窗口在 auth.json 和 MCP OAuth 上关闭，浏览器强制执行云元数据 SSRF 底线，cron 提示注入扫描组装的技能内容，hermes debug share 在上传。 (#21193、#21241、#21291、#21176、#21194、#21228、 #21350、#19318)
  • 检查点 v2 — 状态持久性重写。真正的修剪，磁盘护栏，不再有孤儿影子回购。 (#20709)
  • 代理 lint 自己的写入 — write_file + patch 上的写入后增量 lint。 Python、JSON、YAML、TOML。语法错误立即浮出水面，而不是传递到下游。 (#20191)
  • no_agent cron 模式 - 仅脚本看门狗 - cron 作业现在可以完全跳过代理并仅运行脚本。空的标准输出是静默的，非空的标准输出会逐字传递。 (#19709)
  • 到处都有平台白名单 — allowed_channels / allowed_chats / allowed_rooms 跨 Slack、Telegram、Mattermost、Matrix 和 DingTalk 的配置。 (#21251)
  • 提供商现在是插件 — ProviderProfile ABC + plugins/model-providers/。在不触及核心的情况下引入第三方提供商。 (#20324)
  • API 服务器 - 每个会话的长期内存 - X-Hermes-Session-Key 标头为内存提供者提供了稳定的会话标识符。 (#20199)
  • MCP 升级 — SSE 传输具有 OAuth 转发、陈旧管道重试、图像结果作为媒体标签显示而不是被丢弃、在长期生命周期等待中保持活动状态。 (#21227、#21323、#21289、#21328、#20209)
  • Curator 增加子命令 — hermes curator archive、prune、list-archived。手册 hermes curator run 现在是同步的 - 您无需轮询即可看到结果。 (#20200、#21236、#21216)
  • ACP — /steer 和 /queue — 指导飞行中的客服人员或从 Zed、VS Code 或 JetBrains 排队跟进。加上原子会话持久性和重启后的推理元数据保存。 (@HenkDz) (#18114、#20279、#20296、#20433)
  • TUI 发光 — /model 选择器将 hermes model 与内联身份验证 (@austinpickett)、可折叠启动横幅部分 (@kshitijk4poor)、状态栏中的上下文压缩计数器相匹配。 (#18117、#20625、#21218)
  • 仪表板成长 - 插件页面（管理、启用/禁用、身份验证状态）（@austinpickett）、配置文件管理页面（@vincez-hms-coder）、可排序分析表、通过 X-Forwarded-Prefix 的反向代理支持、新的 default-large 18px 主题。 (#18095、#16419、#18192、#21296、#20820)
  • SearXNG + 拆分网络工具 — SearXNG 作为本机仅搜索后端提供； Web 工具现在允许您根据功能选择不同的后端（搜索、提取、浏览）。 (@kshitijk4poor) (#20823、#20061、#20841)
  • OpenRouter 响应缓存 — 对公开它的模型的显式缓存控制。 (@kshitijk4poor) (#19132)
  • [[as_document]] — 技能媒体路由指令 — 技能可以强制网关在支持它的平台上以文档形式提供输出。 (#21210)
  • transform_llm_output 插件挂钩 — 新的生命周期挂钩，允许插件在 LLM 输出进入对话之前重塑或过滤它。对于上下文窗口缩减器和内容过滤器很有用。 (#21235)
  • Nous OAuth 跨配置文件持续存在 — 共享令牌存储：登录一次，每个配置文件都会继承会话。 (#19712)
  • QQBot — 原生批准键盘 — 与 Telegram / Discord 批准 UX 功能相同。分块上传，引用附件。 (#21342、#21353)
  • 6 个新的可选技能 — Shopify（管理员 + Storefront GraphQL）、here.now、shop-app 个人购物助理、Anthropic 金融服务捆绑包、看板视频编排器 (@SHL0MS)、searxng-search (@kshitijk4poor)。 (#18116、#18170、#20702、#21180、#19281、#20841)
  • 新型号 — deepseek/deepseek-v4-pro、x-ai/grok-4.3、openrouter/owl-alpha（免费）、tencent/hy3-preview (@Contentment003111)、Arcee Trinity Large Thinking 温度 + 压缩覆盖。 (#20495、#20497、#18071、#21077、#20473)
  • 100 个新鲜的 CLI 启动技巧 - 随机提示横幅获得 100 个新条目，涵盖 cron、看板、策展人、插件和鲜为人知的标志。 (#20168)
