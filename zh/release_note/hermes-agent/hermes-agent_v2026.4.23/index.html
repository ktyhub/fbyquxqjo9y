hermes-agent v2026.4.23

修订 发布时间2026年4月23日 来源NousResearch/hermes-agent 英文原文

#爱马仕代理v0.11.0(v2026.4.23) 发布日期： 2026 年 4 月 23 日 自 v0.9.0 起： 1,556 次提交 · 761 个合并 PR · 更改了 1,314 个文件 · 224,174 次插入 · 29 名社区贡献者（290 名包括合著者）

接口版本 — 交互式 CLI 的完整 React/Ink 重写、每个提供商之下的可插拔传输架构、原生 AWS Bedrock 支持、五个新推理路径、第 17 个消息传递平台 (QQBot)、显着扩展的插件界面以及通过 Codex OAuth 的 GPT-5.5。 此版本还包含 v0.10.0（仅提供 Nous Tool Gateway）推迟的所有亮点 - 因此它涵盖了整个堆栈大约两周的工作。

✨ 亮点

  • 新的基于 Ink 的 TUI — hermes --tui 现在是交互式 CLI 的完整 React/Ink 重写，带有 Python JSON-RPC 后端 (tui_gateway)。粘性作曲家、支持 OSC-52 clipboard 的实时流媒体、稳定的选择器键、带有每回合秒表和 git 分支的状态栏、/clear 确认、浅色主题预设和子代理生成可观察性覆盖。 ~310 承诺 ui-tui/ + tui_gateway/。 （@OutThisLife + Teknium）
  • 传输 ABC + 本机 AWS Bedrock — 格式转换和 HTTP 传输从 run_agent.py 提取到可插入的 agent/transports/ 层中。 AnthropicTransport、ChatCompletionsTransport、ResponsesApiTransport 和 BedrockTransport 各自拥有自己的格式转换和 API 形状。通过 Converse API 提供的原生 AWS Bedrock 支持基于新抽象。 (#10549、#13347、#13366、#13430、#13805、#13814 — @kshitijk4poor + Teknium）
  • 五个新推理路径 - 原生 NVIDIA NIM (#11774)、Arcee AI (#9276)、Step Plan (#13893)、Google Gemini CLI OAuth (#11270)、以及具有定价 + 动态发现功能的 Vercel ai-gateway（#13223 — @jerilynzheng）。另外，Gemini 通过本机 AI Studio API 进行路由以获得更好的性能（#12674）。
  • GPT-5.5 over Codex OAuth — OpenAI 的新 GPT-5.5 推理模型现在可通过 ChatGPT Codex OAuth 使用，实时模型发现已连接到模型选择器中，因此新的 OpenAI 版本无需目录更新即可显示。 (#14720)
  • QQBot — 第 17 个支持的平台 — 通过 QQ 官方 API v2 的本机 QQBot 适配器，具有 QR 扫描配置设置向导、流式光标、表情符号反应以及与 WeCom/Weixin 奇偶校验相匹配的 DM/组策略门控。 （[#9364]（https://github.com/NousResearch/hermes-agent/pull/9364），[#11831]（https://github.com/NousResearch/hermes-agent/pull/11831））
  • 插件表面扩展 - 插件现在可以注册斜线命令 (register_command)、直接调度工具 (dispatch_tool)、从挂钩阻止工具执行（pre_tool_call 可以否决）、重写工具结果 (transform_tool_result)、转换终端输出 (transform_terminal_output)、发送 image_gen 后端以及添加自定义仪表板选项卡。默认情况下，捆绑的磁盘清理插件是选择加入的参考实现。 (#9377、#10626、#10763、#10951、#12929、#12944、 #12972、#13799、#14175)
  • /steer - 中运行代理轻推 - /steer <prompt> 注入运行代理在下一次工具调用后看到的注释，而不会中断转弯或破坏提示缓存。当您想要在飞行中纠正座席航向时。 (#12116)
  • Shell 挂钩 — 将任何 shell 脚本连接为 Hermes 生命周期挂钩（pre_tool_call、post_tool_call、on_session_start 等），而无需编写 Python 插件。 (#13296)
  • Webhook 直接传递模式 — Webhook 订阅现在可以将有效负载直接转发到平台聊天，而无需通过代理 — 用于警报、正常运行时间检查和事件流的零 LLM 推送通知。 (#12473)
  • 更智能的委派 - 子代理现在具有明确的 orchestrator 角色，可以生成自己的工作人员，并具有可配置的 max_spawn_depth （默认平坦）。并发同级子代理通过文件协调层共享文件系统状态，因此它们不会破坏彼此的编辑。 （[#13691]（https://github.com/NousResearch/hermes-agent/pull/13691），[#13718]（https://github.com/NousResearch/hermes-agent/pull/13718））
  • 辅助模型 - 可配置 UI + 主模型优先 - hermes model 有一个专用的“配置辅助模型”屏幕，用于按任务覆盖（压缩、视觉、会话搜索、标题生成）。 auto 路由现在默认为所有用户的副任务的主要模型（以前聚合器用户被默默地路由到廉价的提供商端默认值）。 （[#11891]（https://github.com/NousResearch/hermes-agent/pull/11891），[#11900]（https://github.com/NousResearch/hermes-agent/pull/11900））
  • 仪表板插件系统 + 实时主题切换 — Web 仪表板现在可扩展。第三方插件可以添加自定义选项卡、小部件和视图，而无需分叉。与实时切换主题系统配对 - 主题现在控制颜色、字体、布局和密度 - 因此用户可以热交换仪表板外观而无需重新加载。 CLI 具有相同的主题规则，现已在网络上发布。 (#10951、#10687、#14725)
  • 仪表板完善 — i18n（英文 + 中文）、react-router 侧边栏布局、移动响应、Vercel 部署、真实每会话 API 呼叫跟踪以及一键 click 更新 + 网关重启按钮。 (#9228、#9370、#9453、#10686、#13526、#14004 — @austinpickett + @DeployFaith + Teknium）
