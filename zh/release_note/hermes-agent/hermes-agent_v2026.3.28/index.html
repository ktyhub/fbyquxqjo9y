#爱马仕代理v0.5.0(v2026.3.28) 发布日期： 2026 年 3 月 28 日

强化版本 — Hugging Face 提供程序、/model 命令大修、Telegram 私人聊天主题、本机 Modal SDK、插件生命周期挂钩、GPT 模型的工具使用强制执行、Nix flake、50 多个安全性和可靠性修复以及全面的供应链审计。

✨ 亮点

  • Nous Portal 现在支持 400 多个模型 — Nous Research 推理门户已大幅扩展，Hermes Agent 用户可以通过单个提供商端点访问 400 多个模型
  • Hugging Face 作为一流的推理提供商 — 与 HF Inference API 完全集成，包括映射到 OpenRouter 类似物的精选代理模型选择器、实时 /models 端点探测和设置向导流程（#3419、#3440）
  • Telegram 私人聊天主题 — 基于项目的对话，每个主题绑定功能技能，从而在单个 Telegram 聊天中实现独立的工作流程 (#3163)
  • 本机 Modal SDK 后端 — 用本机 Modal SDK (Sandbox.create.aio + exec.aio) 替换了 swe-rex 依赖项，消除了隧道并简化了 Modal 终端后端 (#3538)
  • 插件生命周期挂钩已激活 - pre_llm_call、post_llm_call、on_session_start 和 on_session_end 挂钩现在在代理循环和 CLI/网关中触发，从而完成插件挂钩系统（#3542）
  • 改进了 OpenAI 模型可靠性 - 添加了 GPT_TOOL_USE_GUIDANCE 以防止 GPT 模型描述预期操作而不是进行工具调用，并自动从对话历史记录中删除过时的预算警告，这些警告导致模型避免使用工具（#3528）
  • Nix flake — 完整的 uv2nix 构建，具有持久容器模式的 NixOS 模块，从 Python 源自动生成的配置密钥，以及代理友好性的后缀路径（#20、#3274、#3061），作者：@alt-glitch
  • 供应链强化 - 删除了受损的 litellm 依赖项，固定了所有依赖项版本范围，使用哈希值重新生成了 uv.lock，添加了 CI 工作流程扫描 PR 以查找供应链攻击模式，并增加了 deps 来修复 CVE（#2796、#2810、 #2812、#2816、#3073)
  • Anthropic输出限制修复 - 将硬编码的16K max_tokens替换为每个模型的本机输出限制（Opus 4.6为128K，Sonnet 4.6为64K），修复了直接Anthropic API上的“响应被截断”和思考预算耗尽（[#3426]（https://github.com/NousResearch/hermes-agent/pull/3426）， #3444)
