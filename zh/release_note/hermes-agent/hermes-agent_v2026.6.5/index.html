hermes-agent v2026.6.5

修订 发布时间2026年6月6日 来源NousResearch/hermes-agent 英文原文

#爱马仕代理v0.16.0(v2026.6.5) 发布日期： 2026 年 6 月 5 日 自 v0.15.2 起： 874 次提交 · 542 个合并 PR · 1,962 个文件已更改 · 205,216 个插入 · 46,217 个删除 · 399 个问题已关闭（2 个 P0、62 个 P1、16 个安全标记） · 170 个社区贡献者（包括共同作者）

Surface 版本。 无论您在哪里工作，Hermes 都会与您见面。一个全新的本机桌面应用程序（在一周内构建了 100 个 PR 和 159 个提交）为您提供了 Hermes 作为真正的 macOS/Linux/Windows 应用程序：one-click 安装、应用内自我更新、将文件拖放到聊天中、状态栏中的内联模型选择器、并发多配置文件会话、完整的简体中文翻译以及通过 OAuth 或用户名/密码连接到远程 Hermes 网关的能力。除此之外，Web 仪表板还开发了一个完整的基于浏览器的管理面板（MCP 目录、消息通道、凭据、Webhooks、内存、可插入 OIDC/用户名密码登录），并且首次设置有一个“通过 Nous Portal 快速设置”路径，可让您在几秒钟内从安装到第一条消息。默认技能集已根据您的实际需要进行了调整，NVIDIA/技能加入了 trusted 技能中心水龙头，模型选择器现在可以在任何地方（桌面、网络、TUI、CLI）进行模糊搜索，而 /undo 终于可以让您收回最后 N 回合。 2 个 P0 和 62 个 P1 关闭，加上一轮安全轮（CVE-2026-48710 Starlette 引脚、SSRF 离环强化、子进程凭证剥离）。

✨ 亮点

  • Hermes Desktop — 一个真正的本机应用程序，而不是终端包装器 — 这是标题。现在有一个 apps/desktop/ Electron 应用程序，它可以像 macOS、Linux 和 Windows 上的任何其他桌面应用程序一样安装，从应用程序内部进行自我更新，并为您提供一个完美的 GUI，用于 Hermes 所做的一切。您将获得一个带有流媒体的正确聊天窗口、一个可以存档和搜索的会话列表、在聊天区域中的任何位置拖放文件、clipboard 图像粘贴、Cmd+K 命令调色板以及状态栏中的模型选择器。如果您一直告诉朋友“这是 CLI 代理”并看着他们目光呆滞 — 现在您只需向他们发送安装程序即可。一周前这些都不存在。 (#20059、#35607、#37099、#37379、#38631 — @OutThisLife、@jquesnelle、@ethernet8023、 @austinpickett，@benbarclay）
  • 针对远程 Hermes 运行桌面应用程序 — 使用 OAuth 或用户名/密码登录 — 桌面应用程序不必在本地运行 Hermes。将其指向远程 Hermes 网关（您的家庭实验室、托管盒子、队友的服务器），它会通过安全的 WebSocket 进行连接，使用 OAuth 或用户名/密码登录进行身份验证 - 无需摆弄 --insecure 标志或手动复制的会话令牌。每个配置文件都可以定位其自己的远程主机，并且您可以使用跨配置文件 @session 链接在一个窗口中跨多个配置文件运行并发会话。实用版本：您的笔记本电脑运行瘦 GUI，重型代理在您的 API 密钥和计算实时运行的地方运行。 (#37888、#38851、#39330、#39778 — @benbarclay、@OutThisLife、@teknium1)
  • 网络仪表板现在是一个完整的管理面板 - 通过浏览器配置所有内容 - 仪表板从“查看您的会话”发展为完整的管理界面。有一个通道页面，可通过浏览器设置每个网关消息传递平台（Telegram、Discord、Slack 等）、MCP 目录的管理面板，具有启用/禁用切换、凭证管理、Webhook 和挂钩创建、内存配置、网关控制，以及具有更新前检查和 one-click 调试共享的系统页面。您不再需要通过 SSH 登录并编辑 config.yaml 来连接新的消息传递通道或 MCP 服务器 - 现在都是点对点 click。 (#36704、#36736、#37211、#38205、#38600 — @teknium1)
  • Hermes Desktop 讲简体中文 - 聊天 GUI 中的完整简体中文 - 桌面应用程序现在在每个 UI 界面上提供完整的简体中文 (简体中文) 翻译 - 聊天窗口本身、侧边栏、设置、命令中心、cron、消息、配置文件、技能、代理等等。英语保持默认；在外观设置中切换语言，该选择将保留到您的配置中 (display.language)。它构建在正确类型的 i18n 层上，因此从这里添加更多语言非常简单。 (#38241 — @JimLiu)
  • 更精简的默认技能集 - Hermes 仅提供您实际需要的内容 - 捆绑的技能集经过了刻意的修剪。多余或死亡的技能已经消失（spotify - 被原生 Spotify 插件的 7 个工具取代；linear - 被 hermes mcp install linear 取代；kanban-codex-lane、debugging-hermes-tui-commands、陈旧的 domain 孤儿和几个空类别标记）。较重或小众的技能从捆绑变为可选（宝玉创意集，dspy，subagent-driven-development，minecraft-modpack-server，pokemon-player，hermes-s6-container-supervision） - 仍然有一个hermes skills install，只是默认情况下未加载。新的 environments: 相关性门将特定于上下文的技能（看板、docker/s6）保留在永远不会使用它们的用户的技能索引之外，同时仍然根据明确的请求加载它们。结果是：默认技能列表更小、更清晰，选择器中的噪音更少，提示更轻。管理者现在也可以修剪未使用的内置技能（不仅仅是代理创建的技能），并跟踪每项技能的使用情况。 (#39028、#36701、#36228 — @teknium1)
  • NVIDIA/skills 现在是内置的 trusted 技能水龙头 — NVIDIA/skills 加入 OpenAI、Anthropic 和 HuggingFace 作为技能中心中的默认 trusted 水龙头 — 通过同一管道可发现、可浏览、可搜索和自动更新。只需安装一次即可获得 NVIDIA 针对 CUDA-X、AIQ、cuOpt 及其产品堆栈其余部分的经过验证的技能，并具有来自存储库的 skills.sh.json sidecar 的真实类别标签。 (#34333 — @teknium1)
  • 通过 Nous Portal 进行快速设置 - 从安装到第一条消息只需几秒钟 - 首次设置被简化为两条清晰的路径：快速设置（使用 Nous Portal 登录，获取模型选择器，立即开始聊天）或完整设置（针对高级用户的详细向导）。 hermes portal 现在是人类可读的别名，可运行完整的快速设置 Nous 流程。首次运行菜单内联解释了其中的差异，因此新手不会猜测。目标：全新用户不需要阅读文档来发送第一条消息。 (#35723、#36227、#38449、#38465 — @teknium1、@kshitijk4poor)
  • 模糊模型选择器，无处不在 - 输入几个字母，找到您的模型 - 模型选择器现在可以在桌面应用程序、Web 仪表板、TUI 和 CLI 中进行模糊搜索。类型“v4fl”和 deepseek-v4-flash 表面；多端点提供程序分组在一行下，而不是用重复项使列表混乱，并且每一行都带有说明，以便您知道您正在选择什么。该目录每小时更新一次，而不是每天更新一次，因此新型号会在发布的同一天出现。新建此窗口：deepseek-v4-flash、具有 1M 上下文的 MiniMax-M3、qwen3.7-plus。 (#36928、#35227、#35756、#35659、#36214 — @kshitijk4poor、@teknium1)
  • /undo [N] — 收回最后 N 个回合 — 说错了话，或者让特工走上了一条错误的道路？ /undo 备份 N 个用户回合，预填充您的最后一条消息，以便您可以编辑和重新发送，并软删除之间的回合。它可以在 CLI、TUI 和跨消息平台（Telegram、Discord 等）中工作，并且具有完全对等性。关闭长期存在的请求 (#21910)。 (#36229、#36699 — @teknium1)
  • 选择您的默认界面 — cli 或 tui — 您现在可以设置 hermes chat 默认情况下是进入经典 CLI 还是 Ink TUI，并使用 --cli 标志覆盖每次调用。 TUI 还获得了一个统一的 /model 命令和一个用于在实时会话之间切换的会话覆盖。使用您真正喜欢的界面。 (#37782、#37112 — @OutThisLife)
