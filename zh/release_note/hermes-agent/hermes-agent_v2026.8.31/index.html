hermes-agent v2026.8.31

修订 发布时间2026年8月31日 来源NousResearch/hermes-agent 英文原文

#爱马仕代理v0.21.0(v2026.8.31) 发布日期： 2026 年 8 月 31 日 自 v0.20.0 以来： ~5,800 次提交 · ~2,475 个合并 PR · ~5,680 个文件已更改 · ~869,000 个插入 · ~135,000 个删除 · ~2,100 个问题已关闭 · 760 多个贡献者

万神殿发布。 v0.20.0 让赫耳墨斯成为先驱——他说话，并将消息传达给其他特工。在《v0.21.0》中，诸神齐聚。机器人模式内置于桌面应用程序中：一个由指定代理组成的社会，他们有自己的面孔和群聊，您的机器人可以像团队而不是工具箱一样相互交谈，也可以与您交谈。围绕这个脊柱：cron 作业获得了内存和连续性，因此计划的代理实际上在运行之间进行学习，子代理可以在飞行中进行实时引导，MCP 表面成为真正的命令中心，并且代理现在可以驱动桌面自己的浏览器。此版本汇总了 v0.20.1–v0.20.6 基础设施补丁标签中的所有内容 - 这些窗口已在此处完整记录。

✨ 亮点

  • 机器人模式 - 您的代理成为一个内置的社会 - 机器人模式现在是桌面应用程序的捆绑、默认部分：每个代理配置文件都有一个名称、一个确定性的头像面孔（带有随机/锁定控件）以及共享名册中的一个位置。创建 Discord 风格的群聊，多个机器人和您在一个房间中交谈，@提及作曲家的任何机器人，并给出房间名称和图片。以前，“多代理”意味着管道；现在，“多代理”意味着管道。现在它看起来像一个充满同事的聊天应用程序。 (#87886、#88243、#89386、#96726 — @teknium1、@OutThisLife、@dokterdok)
  • hermes peer — 代理之间的机器人对机器人 DM — 任何 Hermes 代理现在都可以通过手柄、跨配置文件和网关、从 CLI 或从对话内部向任何其他代理发送消息。要求您的研究机器人将研究结果交给您的编码机器人，并在您可以阅读的地方获取回复。回复会出现在每个代理的规范机器人聊天中，因此代理之间的对话是持久且可检查的，而不是一劳永逸。 (#88725、#88178、#91487 — @teknium1)
  • 记住的 Cron 作业 — 预定作业不再是金鱼。 Cron 代理现在像所有其他代理一样加载和更新持久内存，continuity=true 将每次运行的输出传送到下一次运行（因此监视器可以根据已报告的内容进行重复数据删除），每个作业都会获得一个耐用的记事本便笺本，监视器模式作业在没有任何更改时完全跳过 LLM，并且 cron 输出可以落在机器人的规范机器人聊天中 - 机器人实际响应的地方。您的上午 9 点简报工作现在知道了昨天告诉您的内容。 (#91447、#80774、#81139、#81138、#91487 — @teknium1、@smwbev)
  • 在子代理运行时引导它们 — delegate_task 获得了实时编排：列出正在运行的子代理，通过修正航向来引导其中一个子代理，或者提前停止并保留部分结果。在子输出上添加可选的 JSON 模式验证，结果中显示每次委托成本，并提高了默认值（250 次迭代，10 个并发子项）——委托从“发射和祈祷”转变为实际管理的并行工作。 (#85232、#81144、#81142、#86506、#86745 — @teknium1)
  • MCP 命令中心 — MCP 服务器和目录合并到一个连贯的桌面页面中，并具有拖入式“粘贴任何内容”导入功能、后台运行状况检查（可在工具调用失败之前促使您重新进行身份验证）、显示架构令牌估计值和每台服务器 30 天使用情况的队列成本/使用情况叠加层，以及安装 MCP 服务器并进行明确确认的 hermes:// 深层链接。管理 20 台 MCP 服务器曾经是配置文件考古学；现在它是一个仪表板。 (#87525、#87572、#87576、#87579、#87581 — @teknium1)
  • CLI 能量波 — Ctrl+P 打开模糊命令面板，/model 选择器在您键入时进行过滤，/status 显示推理模式、待批准和上下文使用情况，状态栏可以显示实时缓存命中百分比、延迟和带有每个字段切换的令牌/秒。另外：全局紧急停止、会话固定/取消固定、旋转的面向任务的作曲家占位符 - 以及幽灵级 终端宠物，因为同伴应该有一个同伴。 (#90730、#90717、#90745、#98250、#98282、#97666 — @teknium1 和挽救社区工作）
  • 代理驱动桌面浏览器 — 应用程序内浏览器不再是代理只能查看的窗口：Hermes 现在可以导航、clicks 并直接读取它，并且可以通过完整链接上下文菜单将页面弹出到您的系统浏览器。要求它遍历文档站点或调试 Web 应用程序，并观察它在您自己的应用程序中发生。 (#90197、#89366 — @OutThisLife、@ethernet8023)
  • 六个新的提供程序和模型目录浪潮 - 元模型 API (Muse Spark) 作为内置提供程序到达，与 CommandCode、Tencent TokenPlan、Nebius Token Factory、Ramp Router 和 Actual Computer 并列。目录中包括 GLM-5.3-Flash、qwen3.8-max/flash、Gemini 3.7 Flash、MiniMax M3 free 和 Nemotron 3.5 Lightning，而 model_overrides 可以让您修补任何型号的上下文窗口或自行定价，而无需等待发布。 （#88565、#88308、#97917、#97916、#97915、#85560 — @teknium1 和社区）
  • 全面加强安全性 - 受保护的代理指令文件（AGENTS.md、技能、内存存储）现在始终需要写入批准，因此提示注入的代理无法悄悄地重写自己的常规命令。深度修订清除了终端错误、.env 文件读取、检查点和 ACP 日志之间的秘密泄漏漏洞；审批系统学习了Windows破坏性命令； macOS 权限最终通过稳定的 TCC 签名身份在更新中保留下来。 （#81152、#80965、#84428、#95091 — @teknium1 和社区）

🏗️ 核心代理和架构

提供商和模型

  • 新提供程序： 实际计算机推理（#79644，#26491 的回收），带有 GOAT/Pro/Max 计划的 CommandCode（#88308，#32909 的回收），元模型 API (Muse Spark) 作为内置提供程序插件(#88565)、Tencent TokenPlan (#97917)、Nebius Token Factory (#97916) 和 Ramp Router (#97915)。
  • 型号目录wave： qwen3.8-max 和 qwen3.8-flash (#78024、#96979)、Gemini 3.7 Flash (#85526)、GLM-5.3-Flash OpenRouter/Nous/z.ai/OpenCode (#95621、#96293)、MiniMax M3 + Inkling 免费 SKU (#96264)、Nemotron 3.5 Lightning (#84645)、Meta Muse Spark 1.2 (#88600)。
  • **通过 model_overrides 配置覆盖每个模型的元数据 - 修补上下文窗口、定价或任何模型的功能，无需等待发布 (#85560)。
  • 数据训练层警告 - 当模型在您的数据上进行训练时，统一的选择保护注册表会在每个选择器表面上向您发出警告（#85917）。
  • 通过入口点发现 Pip 安装的模型提供程序 - 第三方可以将提供程序作为包发送（#85504，salvage #81419）。
  • 在 OpenAI 线路上为 LiteLLM Claude 进行提示缓存（#87517 — @kshitijk4poor），并通过响应 API 路由 api.meta.ai 进行缓存（#88601）。
  • Codex GPT 上下文默认回到已验证的 272K，并为大窗口提供显式 -900k 选择器变体 (#92797)。

代理循环和可靠性

  • 停滞的提供商恢复 — 停滞的流不再使桌面保持沉默或消耗重试预算（#87236 — @fangliquanflq）。
  • MoA 强化集群 — Mixture-of-Agents 外观现在可以承受 client 重建、流重试、提供程序轮换和回退/恢复，而不会将准备好的请求泄露给本机 clients（#90212 和兄弟姐妹）。
  • 结构化输出弹性 - 辅助调用将 response_format 转换为人类线，并在提供者拒绝结构化输出时重试（#89589 - @ethernet8023）。
  • 压缩：精益尾部模式 + 压缩回忆评估工具来测量压缩实际保留的内容（#87326）。
  • 过大的工具结果溢出到缓存，而不是在无沙箱会话中被截断（#89028）。
  • clarify 在一次调用中提出多个独立的问题 - 一种形式而不是一系列往返（#89467 - @ethernet8023）。
  • 验证子系统（来自 superagent-ai/grok-cli 的端口）：运行配方检测 + 环境清单，因此“有效”声明由检测到的构建/测试命令支持（#80686）。

会话和状态

  • 恢复的成绩单永远不会重新附加 - _db_persisted 在行加载时标记（#92539 - @kshitijk4poor）。
  • SessionDB 上下文管理器协议 用于无泄漏的数据库生命周期（#88048 — @jackulau）。
  • 即时会话命名来自开头消息，在简历中带有粘性标题（#81985 — @OutThisLife）。
  • 从 CLI 进行会话固定/取消固定 — 持久保留标志 (#80761)。

📱 消息平台（网关）

  • Slack 本机实时卡 — 通过 chat.startStream 进行实时流式回复，加上用于工具进度的选择加入计划/任务卡 (#85476)；跨本机和中继平面的出站链接预览抑制（#95142 — @benbarclay）。
  • Telegram 内联选择器 — 每个命令和技能都可以通过 @botname 搜索，绕过 Telegram 的命令菜单上限 (#98317)。
  • 中继成熟 - 原生静态/动态插件初始化（#77915 - @bbednarski9），带有草稿流+任务卡的实时卡操作（#85796 - @victor-kyriazakos），会话跨度分段（#85467），通过中继通道恢复语音注释STT （#95274 — @benbarclay），传输重复数据删除/快速失败修复（#89584）。
  • 网关控制套接字 - 队列消费者查询网关本身（识别/状态），更新程序优雅地暂停网关，而不是杀死它们（[#92447]（https://github.com/NousResearch/hermes-agent/pull/92447），[#95695]（https://github.com/NousResearch/hermes-agent/pull/95695））。
  • 选择性 Multiplex 配置文件服务 (#83400)、每个配置文件 MCP 生命周期 RPC (#86473)、显示最新消息的名册预览 (#85905)、默认情况下的简洁后台进程通知 (#85877)。
  • Turn-reaper 堆栈转储 — 当看门狗触发时，会捕获楔入的工作堆栈以进行诊断 (#86248)，并使用端到端连接的循环看门狗调谐旋钮 (#92317)。
  • 分割交付错误类已关闭 - 吞咽决赛和分割交付固定为一个类（[#79669]（https://github.com/NousResearch/hermes-agent/pull/79669） - @kshitijk4poor，salvages #78558）。
