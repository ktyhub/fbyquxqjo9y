hermes-agent v2026.4.13

修订 发布时间2026年4月13日 来源NousResearch/hermes-agent 英文原文

#爱马仕代理v0.9.0(v2026.4.13) 发布日期： 2026 年 4 月 13 日 自 v0.8.0 起： 487 个提交 · 269 个合并 PR · 167 个已解决的问题 · 493 个文件已更改 · 63,281 个插入 · 24 个贡献者

无处不在的版本 - Hermes 通过 Termux/Android 实现移动，添加了 iMessage 和微信，为 OpenAI 和 Anthropic 提供快速模式，引入后台进程监控，启动本地 Web 仪表板来管理代理，并在 16 个支持的平台上提供迄今为止最深入的安全强化。

✨ 亮点

  • 本地网络仪表板 — 一个基于浏览器的新仪表板，用于在本地管理您的 Hermes 代理。配置设置、监控会话、浏览技能和管理网关 - 所有这些都通过干净的 Web 界面进行，无需触摸配置文件或终端。开始使用 Hermes 的最简单方法。
  • 快速模式 (/fast) — OpenAI 和 Anthropic 模型的优先处理。切换 /fast 以通过优先级队列进行路由，以显着降低受支持型号（GPT-5.4、Codex、Claude）上的延迟。扩展到所有 OpenAI 优先处理模型和 Anthropic 的快速层。 (#6875、#6960、#7037)
  • 通过 BlueBubbles 进行 iMessage — 通过 BlueBubbles 进行全面的 iMessage 集成，将 Hermes 引入 Apple 的消息传递生态系统。自动 Webhook 注册、设置向导集成和崩溃恢复能力。 (#6437、#6460、#6494)
  • 微信 (Weixin) 和 WeCom 回调模式 — 通过 iLink Bot API 提供原生微信支持，并为自建企业应用程序提供新的 WeCom 回调模式适配器。流式游标、媒体上传、Markdown 链接处理和原子状态持久性。 Hermes 现在端到端地覆盖了中文消息生态系统。 （[#7166]（https://github.com/NousResearch/hermes-agent/pull/7166），[#7943]（https://github.com/NousResearch/hermes-agent/pull/7943））
  • Termux / Android 支持 — 通过 Termux 在 Android 上本地运行 Hermes。适应的安装路径、针对移动屏幕的 TUI 优化、语音后端支持以及在设备上运行的 /image 命令。 (#6834)
  • 后台进程监控 (watch_patterns) — 设置要在后台进程输出中监视的模式，并在匹配时实时收到通知。监视错误、等待特定事件（“侦听端口”）或观察构建日志 - 所有这些都无需轮询。 (#7635)
  • 原生 xAI 和小米 MiMo 提供商 — 对 xAI (Grok) 和小米 MiMo 的一流提供商支持，可直接访问 API、模型目录和设置向导集成。加上带有门户请求支持的 Qwen OAuth。 （[#7372]（https://github.com/NousResearch/hermes-agent/pull/7372），[#7855]（https://github.com/NousResearch/hermes-agent/pull/7855））
  • 可插拔上下文引擎 — 上下文管理现在是通过 hermes plugins 的可插拔插槽。交换自定义上下文引擎，控制代理每回合看到的内容 - 过滤、摘要或特定于域的上下文注入。 (#7464)
  • 统一代理支持 — 跨所有网关平台的 SOCKS 代理、DISCORD_PROXY 和系统代理自动检测。企业防火墙后面的 Hermes 可以正常工作。 (#6814)
  • 全面的安全强化 - 检查点管理器中的路径遍历保护、沙箱写入中的 shell 注入中和、Slack 图像上传中的 SSRF 重定向防护、Twilio webhook 签名验证（SMS RCE 修复）、API 服务器身份验证强制执行、git 参数注入预防和批准按钮授权。 (#7933、#7944、#7940、#7151、#7156)
  • hermes backup 和 hermes import — 完整备份和恢复您的 Hermes 配置、会话、技能和内存。在机器之间迁移或在重大更改之前创建快照。 (#7997)
  • 16 个支持平台 — 随着 BlueBubbles (iMessage) 和微信加入 Telegram、Discord、Slack、WhatsApp、Signal、Matrix、电子邮件、短信、钉钉、飞书、WeCom、Mattermost、Home Assistant 和 Webhooks，Hermes 现在可以在 16 个消息平台上运行。
  • /debug 和 hermes debug share — 新的调试工具包：跨所有平台的 /debug 斜线命令用于快速诊断，加上 hermes debug share 将完整的调试报告上传到 Pastebin，以便在故障排除时轻松共享。 （[#8681]（https://github.com/NousResearch/hermes-agent/pull/8681））
