aider v0.47.0

小版本 发布时间2024年7月31日 来源Aider-AI/aider 英文原文

变更流程图

亮点

  • 提交信息更可定制 — Conventional Commits 规范已内置到提示词中，--commit-prompt 则让团队强制使用自己的格式；强模型兜底也让提交信息和聊天摘要在主模型吃力时更稳健。

  • Lint 更安全、更快速 — 修复 lint 错误前会先询问，--lint 对全部脏文件的性能得到提升，并在 lint 前自动提交代码改动。结果是更干净、更独立的 lint 修复，但要注意 Git 历史里会多出提交；子进程编码修复也让 /run 更可靠。

  • 更好的 Docker 部署 — 解决了 docker run --user xxx 的权限问题，减少容器里 UID/GID 的摩擦。新的 paulgauthier/aider-full 镜像打包了所有附加组件，开箱即用更完整。

  • 更省钱的切换 — 在代码模式和询问模式之间切换不再生成聊天历史摘要，省掉额外的模型调用和延迟，也减少摘要带来的上下文噪音。

  • 更可预期的交互工具 — 没有命令专属补全时，/commands 现在会给出通用自动补全；/run 的批准流程缺陷也不再打断把命令输出加入对话。

  • 兼容性 — 未列出破坏性变更，不过 lint 自动提交和模式切换的行为变化值得在现有工作流里复查一下。

  • 提交消息 改进：

    • 添加了常规提交指南以提交消息提示。
    • 添加了 --commit-prompt 来自定义提交消息提示。
    • 添加了强大的模型作为提交消息（和聊天摘要）的后备。

  • Linting 改进：

    • 在修复 lint 错误之前询问。
    • 改进了 --lint 对存储库中所有脏文件的性能。
    • 改进了 lint 流程，现在在 lint 之前进行代码编辑自动提交。
    • 修正了正确处理子进程编码的错误（也适用于 /run）。

  • 改进了docker支持：

    • 解决了使用 docker run --user xxx 时的权限问题。
    • 新的 paulgauthier/aider-full docker 图像，其中包括所有附加功能。

  • 切换到代码和询问模式不再总结聊天记录。

  • 添加了助手对每个版本的贡献图表。

  • 为 /commands 提供通用自动完成功能，无需完成覆盖。

  • 修复了损坏的 OCaml 标签文件。

  • /run 中的错误修复添加到聊天批准逻辑。

  • Aider 编写了此版本中 58% 的代码。
