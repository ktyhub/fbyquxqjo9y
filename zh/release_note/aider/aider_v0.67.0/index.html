aider v0.67.0

小版本 发布时间2024年12月6日 来源Aider-AI/aider 英文原文

亮点

  • IDE/编辑器驱动的工作流 — aider --watch-files 把 aider 变成由代码注释驱动的后台助手：以 “AI” 开头或结尾的单行 # ... 或 // ... 注释会被当作指令，写入 “AI!” 则让 aider 一次性读取并执行所有 AI 注释。这是全新的交互模式（在编辑器里改，aider 响应），而非单纯的聊天体验调整；如果你想让 aider 驻留在编辑器而不是独立终端，这是最值得升级的理由。

  • 新模型支持 — 新增 Amazon Bedrock Nova 系列模型，统一使用 Bedrock 的团队无需更换服务商或等待下一个版本就能用上更新的 Nova 家族。仅当你的技术栈里有 Bedrock Nova 时才相关，否则无影响。

  • 更紧凑的修复循环与 diff 行为 — /run 或 /test 退出码非零时，aider 现在会把 “Fix that” 预填到下一条提示中，省去测试—失败—修复循环里的手动步骤。另外 /diff 现在调用 git diff，会遵循你配置的 diff 工具和分页器，而非 aider 内置输出。请注意行为变化：依赖旧版 diff 渲染的用户会发现 /diff 输出不一样了。

  • 终端与健壮性打磨 — 新增 Ctrl-Z 进程挂起、Unicode 符号抛编码错误时 Spinner 回退到 ASCII 图案，以及 --read 支持 ~ 主目录展开。这些都是体验与稳定性小改进，在 Unicode 支持有限的终端或向 --read 传主目录相对路径时最有用。

  • 遥测与升级指引 — 分析中现已启用异常捕获，如果介意错误数据离开本机，这一点值得留意。本版无破坏性变更或迁移步骤；为 watch-files 工作流、Bedrock Nova 或修复循环改进而升级即可，若对当前工作流满意且不需要这些功能，可放心跳过。这是常规功能版本，不是重新打标签或仅改元数据的更新。

  • 在 IDE 或编辑器中使用辅助程序。

    • 运行 aider --watch-files，它将监视您添加到源文件中的指令。
    • 以“AI”开头或结尾的单行 # ... 或 // ... 注释是辅助说明。
    • 当助手看到“AI！”时它会阅读并遵循人工智能注释中的所有说明。

  • 支持新的 Amazon Bedrock Nova 型号。

  • 当 /run 或 /test 具有非零退出代码时，请在下一条消息提示中预先填写“修复该问题”。

  • /diff 现在调用 git diff 来使用您首选的 diff 工具。

  • 添加了对进程暂停的 Ctrl-Z 支持。

  • 如果花哨的符号引发 unicode 错误，Spinner 现在会退回到 ASCII 艺术。

  • --read 现在扩展了 ~ 主目录。

  • 在分析中启用异常捕获。

  • Aider 在此版本中编写了 61% 的代码。 https://github.com/user-attachments/assets/bea76d8b-5c31-4913-9536-97b7e6c632b5
