aider v0.68.0

小版本 发布时间2024年12月10日 来源Aider-AI/aider 英文原文

变更流程图

亮点

  • 面向网页聊天 UI 的复制粘贴模式 — 新的 --copy-paste 模式和 /copy-context 让你可以基于浏览器里的 LLM 聊天（ChatGPT、Claude 等）来驱动 aider，而不是直连 API：aider 组装好上下文和提示词，你粘贴进聊天，再把回复粘回来。当 API 访问被封、被计量或被策略限制时，这是一条真正的逃生通道——如果密钥或代理把你拦在门外，值得看看。注意：它是人工往返，不适合紧凑的”编辑—应用”循环。

  • 从 CLI 或 YAML 提供服务密钥与环境变量 — --api-key provider=key 和 --set-env VAR=value 把密钥与环境配置从 shell 配置文件挪到命令行或 aider.conf.yml，简化了多服务商配置、可复现的配置和 CI 运行。注意：装有真实密钥的 YAML 文件很容易被误提交——别把它纳入版本控制，或者只跟踪一份打码后的模板。

  • --watch-files 支持 bash/zsh，并有 tree-sitter 回退 — 监视模式现在能在 bash 和 zsh 下工作，还修好了没有 tree-sitter 语法的文件，因此多语言仓库不会再悄悄漏掉监视对象。Ctrl-D 现在也能干净退出了——虽是小事，但日常使用中能感觉到。

  • o1 可当弱模型，Gemini 实验性可用 — o1 模型现在可以承担弱模型角色（负责总结和琐碎编辑的廉价/快速档），同时提供实验性的 Gemini 模型。Gemini 和 Bedrock 缺少依赖时的报错改进了，配置失败更容易诊断；实验性的 Gemini 模型在稳定之前请当作”毛边产品”看待。

  • 成本报告可信，自我升级更安全 — 硬性的 API 错误不再计入 token 成本，因此服务商请求中途失败时，用量/成本数据依然准确。自我升级现在使用精确的 sys.python 解释器，修复了升级到错误 venv/conda 的问题；CLI 参数也重新组织，分组和帮助文本更清晰——都是低风险的体验改进，主要减少配置上的摩擦。

  • Aider 适用于 LLM 网络聊天 UI。

    • 新的 --copy-paste 模式。
    • 新的 /copy-context 命令。

  • 从命令行或 yaml conf 文件为所有提供程序设置 API 密钥和其他环境变量。

    • 新的 --api-key provider=key 设置。
    • 新的 --set-env VAR=value 设置。

  • 为 --watch-files 添加了 bash 和 zsh 支持。

  • 当缺少 Gemini 和 Bedrock 模型的依赖项时，会出现更好的错误消息。

  • Control-D 现在可以正确退出程序。

  • 当 API 提供商返回硬错误时，不计算代币成本。

  • 错误修复，以便监视文件可以与不支持树保护的文件一起使用。

  • 修正了 o1 模型可以用作弱模型的问题。

  • 更新了 shell 命令提示符。

  • 为所有编码员添加了文档字符串。

  • 重新组织了命令行参数，改进了帮助消息和分组。

  • 使用精确的 sys.python 进行自我升级。

  • 添加了实验性双子座模型。
