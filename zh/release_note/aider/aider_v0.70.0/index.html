aider v0.70.0

小版本 发布时间2024年12月26日 来源Aider-AI/aider 英文原文

aider v0.70.0

变更流程图

亮点

  • 扩展模型支持 — 完整支持 o1，并新增 openrouter/deepseek/deepseek-chat，让开发者无需离开 aider 现有的编辑流程就能有更多推理模型可选。

  • 子树范围的文件监视 — 监视模式现在支持 --subtree-only，只监视所选子树，不监控之外的文件。改进的监视提示也让文件变更处理在更多模型上更可靠。

  • 降低对 Git 的依赖 — aider 现在可在未安装 Git 的情况下运行，Git 路径中的 Unicode 文件名也能优雅处理。不过依赖 Git 的功能在使用时仍需要 Git。

  • 更清晰的配置与加载失败提示 — 新增基于 uv 的安装方式（含一行命令）简化部署；改进的 Windows 环境变量消息有助于诊断配置问题。通过 /load 或 --load 尝试交互式命令时，现在会明确失败而非抛出费解的错误。

  • 较小的可靠性与体验修复 — 自动建议已修复，元数据中的 Gemini 模型名已更正，只读文件在绝对路径更短时会显示绝对路径，注释里含 AI! 或 AI? 时会显示相关帮助。约 10% 的用户现在会看到分析选择加入提示。

  • 破坏性变更 — 无。

  • 完全支持 o1 型号。

  • 监视文件现在支持 --subtree-only，并且仅监视该子树。

  • 改进了监视文件的提示，以便更可靠地处理更多模型。

  • 通过 uv 的新安装方法，包括单行安装。

  • 支持 openrouter/deepseek/deepseek-chat 模型。

  • 通过 /load 或 --load 尝试交互式命令时更好的错误处理。

  • 如果绝对路径短于相对路径，则显示带有绝对路径的只读文件。

  • 要求 10% 的用户选择加入分析。

  • 自动建议的错误修复。

  • 优雅地处理 git 路径名中的 unicode 错误。

  • 修复模型元数据中的 Gemini 模型名称。

  • 显示有关人工智能的提示！和人工智能？当用户进行人工智能评论时。

  • 支持在没有安装 git 的情况下运行。

  • 改进了 Windows 上的环境变量设置消息。

  • Aider 编写了此版本中 74% 的代码。 https://aider.chat/HISTORY.html
