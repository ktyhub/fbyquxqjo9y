aider v0.86.0

这个项目是干啥的：一个在命令行里陪你写代码的AI助手，能自动改代码、总结聊天记录、规范提交信息，给爱用终端的程序员用。

变更架构图

亮点

  • GPT-5 全面覆盖 — 在 OpenAI、Azure、OpenRouter 的命名体系下都能识别 GPT-5、chat、mini、nano 及带日期的快照。相应的配置会选用 diff 编辑、仓库地图和合适的 gpt-5-nano 弱模型，而不是通用默认值。温度参数默认关闭；要自定义采样需显式覆盖设置。

  • Grok 4 与 Kimi K2 — xai/grok-4 和 openrouter/x-ai/grok-4 分别支持直连 xAI 和走 OpenRouter，两者都带 diff 编辑与 reasoning_effort。Kimi K2 则以 openrouter/moonshotai/kimi-k2 提供，使用 diff 配置和温度 0.6（PR #4342）。务必写对服务商前缀——凭证和请求路由都不一样。

  • Gemini Flash-Lite 预览版 — gemini/gemini-2.5-flash-lite-preview-06-17 新增 diff-fenced 配置、关闭温度以及 thinking_tokens 支持（PR #4324）。它提供了更低成本、更高吞吐的选项，但请锁定带日期的预览版标识，别依赖会变动的别名。

  • 模型覆盖修复 — PR #4300 在应用同名自定义模型定义前，会先移除已有设置。此前，过期的弱模型、编辑格式或额外参数值可能在覆盖后残留。升级后请重新测试自定义模型文件，因为它们的实际生效配置现在可能会正确地发生变化。

  • CLI 与运行时整理 — 单独输入 /model 现在会播报当前选择的模型；/clear 会先确认再删除历史（PR #4321）；/undo 只显示提交标题。LiteLLM 升级到 1.75.0，PostHog 的采集代码也适配了新版 SDK API。解析终端输出的工具要能容忍新增的行；依赖升级后，建议对各服务商集成做一次冒烟测试。

  • 破坏性变更 — 无。

  • 增加了对所有 GPT-5 型号的支持。

  • 通过 xai/grok-4 和 openrouter/x-ai/grok-4 型号名称添加了对 Grok-4 的支持。

  • 添加了对 gemini/gemini-2.5-flash-lite-preview-06-17 模型的支持，作者为 Tamir Zahavi-Brunner。

  • /clear 现在打印“所有聊天记录已清除”。所以你知道它有效，作者：Zoxin Yuan。

  • /undo 输出现在仅显示每个提交消息的第一行，使其更易于阅读。

  • 添加了对 openrouter/moonshotai/kimi-k2 模型的支持，作者：Jack Harrington。

  • 使用无参数 /model 命令显示型号公告。

  • 修复了现有模型的新设置未替换旧设置的问题，作者：Andrew Grigorev。

  • 修复了分析以支持最新的 PostHog SDK 事件捕获 API。

  • 增加依赖项以获取最新的 litellm==1.75.0。

  • Aider 编写了此版本中 88% 的代码。
