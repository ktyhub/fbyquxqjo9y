aider v0.85.0

小版本 发布时间2025年6月27日 来源Aider-AI/aider 英文原文

aider v0.85.0

变更流程图

亮点

  • 新模型与别名调整 — 新增 gemini-2.5-pro、gemini-2.5-flash 和 gemini-2.5-pro-preview-06-05，并为 o1-pro/o3-pro 加入 Responses API 支持。思维代币现在可用 0 关闭，DeepSeek 的最大 token 上限提高到 65536，o3 定价也有更新。行为变更 / 迁移： flash 现在指向 gemini-2.5-flash，gemini 指向 gemini-2.5-pro；若别名变化可能影响你的模型选择或费用，请用 --model 锁定具体模型 ID。
  • 编辑范围与提交默认值 — --add-gitignore-files 让 Aider 可以编辑被忽略的文件，适合处理生成代码，但要小心别把密钥暴露出去。提交信息现在默认带上 Co-authored-by 署名，支持 --commit-language，并使用系统提示前缀。迁移： 如果生成的尾注必须与特定格式一致，请检查提交模板、钩子和署名要求。
  • 性能与运维开关 — 启用 --skip-sanity-check-repo 后会跳过耗时的文件跟踪，聊天历史摘要也更快。新增的 --analytics-posthog-host 和 --analytics-posthog-project-api-key 可自定义 PostHog 上报地址。性能提升的代价是仓库完整性检查减少，只有接受这种取舍时才建议开启。
  • 仓库地图与可靠性 — 仓库地图新增 MATLAB 和 Clojure 支持，对 kebab-case 标识符的识别也更好，这些代码库能获得更准确的上下文。修复涵盖 Copilot token 校验、Vertex AI 模型前缀、/read-only 中的字面路径、git diff/历史编码以及聊天历史目录创建，减少提供商、路径和启动阶段的报错。
  • 升级建议 — 如果你在用新的 Gemini/Responses API 模型、写 MATLAB 或 Clojure、遇到 Copilot/Vertex AI 问题，或需要控制提交语言，值得升级。其他人若已锁定的模型工作稳定，也不需要编辑范围、性能或仓库地图方面的改进，可以跳过——但升级前请留意别名和提交署名的变化。

新型号

  • 增加了对新 Gemini 模型的支持，包括 gemini-2.5-pro、gemini-2.5-flash 和 gemini-2.5-pro-preview-06-05 以及思维代币支持。
  • 更新了模型别名：flash 现在指向 gemini-2.5-flash，gemini 现在指向 gemini-2.5-pro。
  • 支持 Responses API 型号，例如 o1-pro、o3-pro。
  • 添加了对跨多个提供商的 OpenAI o3-pro 模型的支持。
  • 增强的思维标记支持：现在可以通过设置为 0 来禁用，并改进了带有示例的帮助文本。
  • 将 Deepseek 模型的最大令牌增加到 65536，以获得更好的性能。
  • 更新了 o3 的定价。

新功能和增强功能

  • 添加了 --add-gitignore-files 标志，以允许将 .gitignore 中列出的文件添加到 Aider 的编辑范围，由 omarcinkonis 编写。
  • 现在默认为提交消息启用共同创作者归属。
  • 增强提交消息生成以使用系统提示符前缀，作者：Luke Reeves。
  • 添加了 --commit-language 选项来指定提交消息的语言，作者：Kyosuke Takayama。
  • 启用 --skip-sanity-check-repo 时跳过昂贵的文件跟踪操作以获得更好的性能，作者：Makar Ivashko。
  • 优化聊天历史摘要性能，作者：jayeshthk。
  • 添加了带有 --analytics-posthog-host 和 --analytics-posthog-project-api-key 标志的自定义 PostHog 分析配置选项，作者：Vasil Markoukin。

存储库地图

  • 添加了对存储库映射的 MATLAB 语言支持，作者：Matthew Tofano。
  • 添加了对存储库映射的 Clojure 语言支持，作者：Garrett Hopper。
  • 改进了存储库映射中的短横线标识符识别，以实现更好的代码分析。

修复和小改进

  • 通过更好的验证和错误消息改进了 GitHub Copilot 令牌处理，作者：Vincent Taverna 和 Sebastian Estrella。
  • 改进了 Rich markdown 输出中的内联代码渲染，作者：Vamsi Talupula。
  • 修复了设置中的 Vertex AI 模型名称前缀，作者：Wietse Venema。
  • 改进了 /read-only 命令以正确解析文字路径，作者：Matteo Landi。
  • 修复了 git diff 输出和 LLM 历史记录中的编码问题。
  • 修复了搜索块正则表达式，以在处理 HTML 内容时接受可选的结束标记，作者：Mathis Beer。
  • 自动创建聊天历史文件的父目录，以防止启动错误（由贡献者提供）。
  • 在安装软件包之前确保 pip 可用。
  • Aider 在此版本中编写了 21% 的代码。
