aider v0.38.0

小版本 发布时间2024年6月17日 来源Aider-AI/aider 英文原文

亮点

  • 自定义 LLM 元数据 — 现在可通过 .aider.models.json 文件自行定义上下文窗口大小与 token 成本（由 @caseymcc 贡献）。对运行本地、自托管或 aider 尚未识别的全新模型的用户来说，这是重磅改动：准确的上下文上限意味着更少的意外上下文溢出崩溃，以及正确的成本核算。但要小心不要把某模型的元数据锁得过死——夸大窗口仍可能让你撞上真正的 token 上限失败。

  • Token 上限错误 — 溢出错误现在报告的信息详细得多。结合上面的模型元数据改动，“你触及上限了”从死胡同变成可诊断的问题（哪个文件、多少 token、该裁剪什么），让你能真正修复上下文膨胀而不是靠猜。

  • 提交信息行为 — aider 创建的提交现在只有单行，不再追加最近的聊天记录。对频繁提交的人来说历史更干净、diff 更小；但如果你曾依赖这段聊天上下文作为 aider 提交的内置变更日志，就需要另找地方保存。

  • --commit --dry-run 现在是真正的空操作 — 以前 dry-run 路径仍可能产生副作用，现在则什么都不做。可安全用于脚本和 CI 预览行为，但若你的自动化（错误地）依赖那些副作用，请测试一下。

  • Vim 键位 — 传入 --vim 可在聊天输入中启用模式编辑。纯增量改动，对 Vim 用户是体验提升；不使用该 flag 的人不受影响。

  • 重 JS 网站抓取 — Playwright 现在会等待网络空闲再抓取。这让动态渲染页面的获取更可靠，代价是对长轮询或后台流量嘈杂的站点抓取变慢——若你的工作流要抓取大量页面，这点值得注意。

  • 贡献者仓库布局 — 文档移至 website/，测试移至 aider/tests/。终端用户不受影响，但任何本地补丁、脚本或 CI 路径若指向 docs/ 或 tests/，都需要更新。

  • 在聊天中使用 --vim 进行 vim 键绑定。

  • 添加 LLM 元数据 通过 .aider.models.json 文件（由 @caseymcc）。

  • 更详细的有关令牌限制错误的错误消息。

  • 单行提交消息，没有最近的聊天消息。

  • 确保 --commit --dry-run 不执行任何操作。

  • 让剧作家等待网络空闲，以便更好地抓取 js 站点。

  • 文档更新，移至网站/子目录。

  • 将测试/移动到助手/测试/中。
