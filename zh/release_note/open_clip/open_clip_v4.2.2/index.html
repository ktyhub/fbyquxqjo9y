open_clip v4.2.2

PyPI 上的第一个 4.x 版本，它添加了官方预训练的 NaFlex CLAP 音频文本模型。它还将培训转移到 一个新的堆栈并添加了几个模型系列。早期的 4.x 版本号仅是开发版本。 预训练的图像文本推理旨在保持兼容，但训练脚本和下游集成需要审查。请参阅迁移指南。要保留 3.x，请运行 pip install 'open_clip_torch<4'。

变更流程图

亮点

  • NaFlex CLAP： 五个采用可变长度音频的 Apache 2.0 音频文本模型（27M 至 340M 参数），在 LAION-Audio-XL 上进行训练：XXS、XS、S、M、 L
  • NaFlex CLIP： 具有令牌预算批处理的可变分辨率和可变宽高比图像塔
  • NaFlex GenLIP / GenLAP： 具有前缀 LM 注意力的生成图像和音频字幕（训练配置，尚未预训练权重）
  • 现代文本塔： RoPE、SwiGLU/ReLU² 和 RMSNorm 选项、每批次可变长度文本和 Hugging Face ModernBERT 塔
  • MaMMUT 和 CoCa v2： MaMMUT 具有已发布的 LAION 权重，以及更正的 coca2_* 配置
  • 训练堆栈： TrainingTask 包装器、基于字典的批次、FSDP2 (--fsdp)、torch.compile 策略和长度分桶
  • 更安全的检查点加载： 所有检查点加载都使用 weights_only=True，并且 OpenAI 权重现在从 Hugging Face Hub 加载 而不是 JIT 档案

升级注意事项

  • PyPI 现在需要 torch>=2.6（以前是 >=2.0）
  • 默认的 --precision 现在是 amp_bf16（以前是 amp），SigLIP 的 --loss-dist-impl 现在默认为 gather
  • --horovod、--torchscript 和 --trace 已删除
  • 删除了load_openai_model、list_openai_models、build_model_from_openai_state_dict和trace_model；使用 create_model_from_pretrained(..., pretrained='openai') 用于 OpenAI 权重
  • 数据加载器现在发出字典批次，并且训练代码应该传递 TrainingTask 而不是单独的模型和损失
  • python -m open_clip_train.legacy_main 仍然可用作旧图像文本训练脚本的兼容性路径 有关更改的完整列表，请参阅迁移指南。
