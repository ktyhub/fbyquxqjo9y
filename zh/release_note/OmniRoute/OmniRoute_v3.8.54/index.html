OmniRoute v3.8.54

OmniRoute v3.8.54

  • **提供商：**官方“使用 ChatGPT 登录”提供商（chatgpt、PKCE + 实时模型发现）； MiniMax Code（托管网关+仪表板设备代码登录）； RenderHour（图像、视频、语音）； MegaBrain（双重身份验证）； EmpirioLabs、ParalonCloud、deAPI、Replicate chat、Cerebrium、Hetzner Inference 和 Grokified；原生 opencode-server 执行器； Microsoft 365 Copilot 工作/学校登录； GitHub 副驾驶嵌入； Gemini Lyria 3 种音乐型号；自定义 JSON API 提供者节点（请求模板+响应路径）。
  • **路由和组合：**特定于端点的组合路由（聊天、搜索/获取、嵌入、重新排名、图像、视频、音乐、OCR、音频）以及功能感知的搜索/获取组合；新的 jev 和 expiry-first 策略；自动组合的首选账户和储备账户；选择加入首选帐户响应启动故障转移；选择加入截止日期失败的子预算，以干净的 504 结束组合。
  • 搜索： 通过连接的 Codex 帐户可启用 Web 搜索和获取提供商（默认情况下无密钥）和 codex-search。
  • API 按键和使用情况： /v1/me/status 报告今天/本周的使用情况以及每个按键的限制； /v1/me/sessions自助会话列表；每项滚动 5 小时美元预算；可重复使用的关键策略模板； POST /api/keys/import;归因于编码代理会话和项目的使用；通过分析进行提供商报告的缓存读取和 5 分钟/1 小时缓存写入层。
  • **代理管道和流：**跨本机协议的重复工具轮和连续故障检测；选择每个模型预算的上下文压缩； STREAM_READINESS_TIMEOUT 现在表示发生了哪种故障形状； api.anthropic.com 的大型请求正文像 Claude Code 一样进行 gzip 压缩。
  • 隐私和媒体： 选择加入可逆 PII 令牌库（默认关闭，需要 PII_REDACTION_ENABLED）；同意的、租户绑定的视频桥框架带有仪表板控件的向下钻取手柄；在发送前选择图像标准化。
  • 仪表板： 跨连接提供商的“新模型”收件箱；成本 > 提供商之间的定价模型比较和“仅配置”过滤器；跨浏览器同步的配额跟踪器订单； Cmd+K 按比赛质量排名； Codex 个人计划与商务座位；兼容节点的“配额检查”切换。
  • 分发和发布工程： Docker 图像还发布到 Cheaper Inference 组织 (cheaperinference/omniroute) 和 GHCR，由 cheaper-inference/OmniRoute 提供的 Electron 自动更新；派生计数仅在发布时刷新（npm run facts、release:refresh-derived）；带时间戳的迁移名称；全向队列合并队列（影子模式）；完整的欧洲葡萄牙语 (PT-PT) 目录和 66 个语言环境在发布时同步。
