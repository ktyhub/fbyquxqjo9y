亮点

  • 提供商和目录（42 个提供商功能）：新的网关和网络会话提供商（UC / UC Direct、Lyceum、regolo /v1）、Codex 和 OpenAI 目录中的 GPT-6 Astra/Sol/Luna 以及工作别名、帐户实时列表作为 Claude/Codex/Copilot/AGY 的聊天目录源、安全 Codex 模型发现。
  • 路由和弹性：分层并发准入，自适应推理工作（auto），expiry-first帐户回退，每种断路器冷却升级，成功探测后提供者-断路器关闭，本地冷却429不再被视为配额耗尽。
  • 代理：池停止重新为提供商刚刚拒绝的成员提供服务、拒绝出口预留调整、每个池的出口 IP 可见性、选择器远离最近拒绝的成员、保留阻塞判决历史记录。
  • 视频/音频桥：强化的向下钻取缓存基底、有界转录合同、选择加入音频提取 + STT、获得“嵌入式”转录来源。
  • 免费套餐和雷达：资格限制的免费套餐存储桶、customModels[].isFree、插件清单中的免费套餐功能、雷达速率限制和规则呈现。
  • 仪表板和可观察性：连续调用日志导出、编排“重复”、托管租赁会话视图、代理日志上的每次尝试上游计时（选择加入）、日志导出截断通知。
  • 安全强化（周期后期）：隔离领域中的预请求挂钩 (GHSA-9p9m)、在连接上判断 IP 允许/拒绝、尾随点内部主机、OAuth 路由上的管理身份验证、OIDC/Trae/GHE Copilot 防护、恒定时间令牌比较、仅环回版本管理器、Codex /v1/responses 子路径中拒绝的遍历、线性时间工具标记扫描仪。
  • 发布工程：npm TZZPH773Z​​Zed Publishing (OIDC)，锁定文件再次对 npm 10/11/12 有效，AI 归因门以及经过审查的历史白名单。
