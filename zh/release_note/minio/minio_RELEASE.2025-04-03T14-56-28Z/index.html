minio RELEASE.2025-04-03T14-56-28Z

这个项目是干啥的：一个开源对象存储服务，兼容S3协议能存海量文件还支持后量子加密，给需要自建文件存储的团队用。

变更架构图

亮点

  • 安全（立即升级） — 重点是 CVE-2025-31489 / GHSA-wg47-6jq2-q2hh：对 unsigned-trailer 上传的签名校验不完整。已持有某 bucket WRITE 权限访问密钥的行为者，可用任意密钥（用 curl 即可轻松做到）上传任意对象；该公告被评为高优先级，要求“用户必须尽快升级”。由 #21103（“确保校验 unsigned trailer 流的签名”）修复，并配套 #21095（“修复匿名 unsigned trailing headers”），同时升级依赖 github.com/golang-jwt/jwt/v5 5.2.1→5.2.2 和 github.com/golang-jwt/jwt/v4 4.5.1→4.5.2。若无法立即升级，官方给出的缓解办法是在 LB 层拒绝 x-amz-content-sha256: STREAMING-UNSIGNED-PAYLOAD-TRAILER，强制要求 STREAMING-AWS4-HMAC-SHA256-PAYLOAD-TRAILER。仅凭这一点，几乎所有部署都应升级。
  • 监控变更——唯一近似“破坏性”的地方 — TTFB 指标类型改为 histogram（#20999），控制台 PromQL 查询也加上波浪号使 all 变量生效（#21054）。本版本没有显式迁移步骤或服务端 API 破坏性变更，但查询 TTFB 指标的仪表盘、Grafana 面板和告警应重新检查，因为类型变化可能打破原有预期。对监控用户而言这是配置层面的中断，而非客户端 SDK 中断。
  • 新增 STS 令牌吊销 API — #21072 新增一个吊销 STS 令牌的 API 端点。这是全新能力（无需迁移），只有在你签发短期 STS 凭据且需要显式吊销时才有意义；否则对你来说是空操作。
  • 可靠性/正确性修复 — IAM 系统在初次连接失败时现在会重试重连（#20333）；修正了 NewerNoncurrentVersions 的求值（#21096），影响对象生命周期/版本保留；修复了 Windows 上分布式纠删场景的管理员 heal 令牌处理（#21092）；修复了 toAPIErrorCode 中的空错误路径（#21083）。若你依赖 IAM/LDAP 启动、生命周期规则或 Windows distErasure 集群，值得升级——这些都是静默的正确性 bug，否则可能导致错误行为。
  • 内部整理——若非安全因素本可跳过 — 其余均为内部/工具链改动：golanglint-ci 配置迁移到 V2（#21081）、map 删除键循环改为 clear()（#21082）、新增 KVS 配置解析处理（#21079）、模板破折号改下划线（#19566），以及 README 描述修正（#21099）。对运维无运行时或 API 影响。实际上没人应因上述 CVE 而跳过此版本；若你已打补丁或在未受影响的分支上，这些项可忽略，本版本对你基本等于空操作。
