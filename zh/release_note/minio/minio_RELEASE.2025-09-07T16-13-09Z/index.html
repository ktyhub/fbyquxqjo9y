minio RELEASE.2025-09-07T16-13-09Z

这个项目是干啥的：一个开源对象存储服务，兼容S3协议能存海量文件还支持后量子加密，给需要自建文件存储的团队用。

变更架构图

亮点

  • 条件写入与分段上传 — AbortMultipartUpload() 更幂等，忽略由 peer 发起的 errUploadIDNotFound，条件写入现在对不存在的对象返回错误，分段写入也会应用条件检查。若客户端使用条件请求或上传重试，请升级；依赖此前宽松行为的调用方应测试错误处理。
  • 基于 claim 的 OIDC — 修复涵盖使用官方 AWS 库认证、未知 roleArn 处理，以及列出访问密钥时使用的哑 ARN。基于 claim 的 OIDC 部署值得升级；不使用它的环境可跳过这些修复。
  • Helm 版本控制行为 — chart 不再默认暂停 bucket 版本控制，仅在显式配置时才管理版本控制。这避免了意外的版本控制暂停，但改变了既有安装的状态管理。未记录迁移命令；若你依赖隐式暂停，请复查 bucket 设置。
  • 站点复制与集成 — 站点复制在使用合规校验和类型时不再产生无效校验和；AMQP URL 现使用 amqp.ParseURL，缺失的 rebalance 统计配置文件也被安全处理。若你使用带校验和的站点复制或受影响的 AMQP/rebalance 配置，请优先升级。
  • 管理界面与运维修复 — Console 更新到 v2.0.3，object-browser 更新到 v2.0.4，同时修复 listener/DNS、兼容旧版压缩环境变量、统一 imagePullSecrets 类型、LDAP 访问密钥 name/description 和 legalHoldPerm 检查。未列出正式破坏性变更通知或必需的迁移步骤；未受影响的部署可视为常规维护。
