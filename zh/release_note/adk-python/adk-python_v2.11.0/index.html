adk-python v2.11.0

2.11.0 (2026-10-01)

变更流程图

亮点

此版本为工作流程添加了优雅的取消和工具确认、用于在任务中咨询另一个模型的工具以及内置的 SQLite 内存服务。

  • 执行取消：将abort_signal传递给Runner、Workflow和节点以优雅地停止运行；现在，当 client 断开连接时，/run_sse 会取消运行。详情请参阅单位指南。 （[ef5bbcf]（https://github.com/google/adk-python/commit/ef5bbcfe51670bd211645a043914c162e7c1cd60），[3d73603]（https://github.com/google/adk-python/commit/3d73603deb180a6518982b2b60f036c764f0cf7e））
  • 工作流程中的工具确认：工具节点现在暂停以通过 RequestInput 进行用户批准，与 LlmAgent 的方式相同，而不是向下游传递错误。 (ce132b9)
  • ModelConsultTool：让代理在任务中咨询另一个模型，以每轮和每会话预算为上限。详情请参阅装置指南。 (84cc99a)
  • SQLite 内存服务：将代理内存保留在本地 SQLite 数据库中，使用 sqlite:// 内存服务 URI 选择。 (9625b06)
  • MCP SDK 2.x：通过新的选择加入路径通过现代协议连接到 MCP 服务器。 (e738c26)
