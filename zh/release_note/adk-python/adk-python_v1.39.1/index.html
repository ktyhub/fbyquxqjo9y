adk-python v1.39.1

adk-python v1.39.1

变更流程图

亮点

  • 安全加固（主线，全部回填到 v1） — 这实质上是一个安全/健壮性补丁版本：CLI 现在对每个本地 API server 请求检查 Host 头（#6789）；A2A 增加了 RPC 目标源校验（#6800）、事件动作允许列表和 resume 扁平化（#6801），以及 agent 转移目标校验（#6798）；API 注册表凭据只发往 Google 端点（#6889）；凭据和内联数据不再写入日志、repr 和 span（#6797）；DB URL 被脱敏、迁移 unpickling 走允许列表（#6791）；URL 校验、客户端超时和凭据作用域也收紧（#6802）。如果你在 v1 上使用 A2A、本地 CLI server 或任何不可信输入，这些都是真实的暴露面修复，也是升级的主要理由。
  • 制品存储与寻址方式改变 — 应用作用域的文件制品存储（布局派生的 payload 路径，#6795）和制品引用作用域（路径段校验，#6794）被回填到 v1。这改变了制品的存放位置和引用的解析方式；任何手工拼装制品路径、或假设扁平/无作用域布局的代码，都应对照新的校验规则检查。
  • 配置与隔离行为收紧（可能需要迁移） — MCP stdio 配置改为可选启用，并校验保留的工具名（#6796）；agent 配置代码引用和 config_path 会被校验（#6790）；code-executor 的容器/pod 隔离默认设置被应用（#6807）；线程池和 live 模式的工具派发现在走 run_async（#6799）。这些是行为变更，而非纯 bug 修复——尤其是依赖隐式 stdio 的现有 MCP 配置可能需要显式选择启用，因此这是升级前需要验证的一个重点领域。
  • 回归与正确性修复 — v1 现在重新接受完整的 session 资源名（#6888），恢复了此前损坏的行为；还包括分支作用域的 auth 响应和 OAuth2 nonce 转发（#6803）、Gemini 上下文缓存指纹作用域（#6804）、每个注册表的自定义评估指标及从评估配置解析的函数路径（#6792）、session-id/thread-id 作用域和 Vertex RAG 清理（#6809），以及 v1 回填审查发现的残余问题（#6890）。
  • 升级建议 — 不是空操作、重新打标签或纯元数据版本：这是一个包含约 25 项回填修复、无新功能的实质性补丁。没有明确声明的破坏性变更或必需的迁移步骤，但上一条中的校验/选择启用变更值得关注。生产环境的 v1 用户——尤其使用 A2A、制品、MCP、代码执行或本地 CLI server 的人——应升级；纯开发或隔离实验、且无不可信输入的用户，可以合理推迟到下一个维护窗口。
