可组合性

torch.compile 下 as_strided + 突变的非组合用法将引发错误 (#122502)

torch.compile 流程涉及对正在编译的区域内的任何突变进行功能化。 Torch.as_strided 是 可以非组合使用的现有视图操作：这意味着当您调用 x.as_strided(…) 时，as_strided 只会 考虑 x 的底层存储大小，并在创建新视图时忽略其当前大小/步幅/storage_offset。 这使得在非组合方式创建的 as_strided 视图上安全地功能化突变变得困难， 因此我们禁止它们，而不是在 torch.compile 下冒无声的正确性问题的风险。 下面是一个非组合使用 as_strided 后跟我们将出错的突变的示例。你可以避免 通过重写 as_strided 的用法来解决此问题，使其具有组合性（例如：使用不同的集合 视图操作而不是 as_strided，或者直接在基本张量上调用 as_strided 而不是它的现有视图）。

@torch.compile
def foo(a):
    e = a.diagonal()
    # as_strided is being called on an existing view (e),
    # making it non-compositional. mutations to f under torch.compile
    # are not allowed, as we cannot easily functionalize them safely
    f = e.as_strided((2,), (1,), 0)
    f.add_(1.0)
    return a

我们现在在注册时验证自定义操作的模式 (#124520)

以前，您可以通过操作符注册 APIs 注册自定义操作，但为其提供一个包含以下内容的架构： PyTorch 调度程序未知的类型。这种行为来自 TorchScript，其中“未知”类型是隐式的 TorchScript 解释器将其视为类型变量。但是，通过常规 pytorch 调用这样的自定义操作 稍后会导致错误。从 2.4 开始，当您首次注册时，我们将在注册时引发错误 自定义运算符。您可以通过使用allow_typevars=true 构建架构来获得旧行为。

TORCH_LIBRARY(my_ns, m) {
  // this now raises an error at registration time: bar/baz are unknown types
  m.def("my_ns::foo(bar t) -> baz");
  // you can get back the old behavior with the below flag
  m.def(torch::schema("my_ns::foo(bar t) -> baz", /*allow_typevars*/ true));
}

FullShardedDataParallel v2 (FSDP2)

  • FSDP2 是一种新的完全分片数据并行实现，它使用基于 DTensor 的 dim-0 每个参数 分片以提高灵活性（例如混合数据类型全收集，对requires_grad没有限制） 显着的性能成本。 请参阅文档 了解更多详细信息和 与 FSDP1 的比较（#122888、#122907、#123142、#123362、#123491、#123857、#119302、#122908、#123953、#120952、#123988、#124293、#124318、 ＃124319，＃120256，＃124513，＃124955，＃125191，＃125269，＃125394，＃126070，＃126267，＃126305，＃126166，＃127585，＃127776，＃127832， ＃128138，＃128117，＃128242）

流水线

  • PyTorch 分布式管道并行性 API 是从上游 PiPPy 项目 并可作为原型发布 PyTorch 2.4。 该软件包位于 torch.distributed.pipelined 下 由两部分组成：分割前端和分布式运行时。 分割前端按原样获取模型代码，将其分割为“模型分区”，并捕获数据流关系。 分布式运行时在不同设备上并行执行管道阶段，处理诸如微批量分割之类的事情， 调度、通信和梯度传播。 欲了解更多信息，请查看 文档 和 教程 (#126322, #124776, #125273, #125729, #125975, #126123, #126419, #126539, #126582, #126732, #126653, #127418, ＃127084，＃127673，＃127332，＃127946，＃128157，＃128163，＃127796，＃128201，＃128228，＃128240，＃128236，＃128273，＃128279，＃128276， ＃128278，＃127066）
