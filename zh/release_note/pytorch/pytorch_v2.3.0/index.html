亮点

我们很高兴地宣布 PyTorch® 2.3 发布！ PyTorch 2.3 在 torch.compile 中提供对用户定义的 Triton 内核的支持，允许用户从 eager 迁移自己的 Triton 内核，而不会遇到性能复杂性或图形中断。此外，张量并行性还改善了使用本机 PyTorch 函数训练大型语言模型的体验，该功能已在 100B 参数模型的训练运行中得到验证。 自 PyTorch 2.2 以来，此版本由 3393 次提交和 426 名贡献者组成。我们衷心感谢我们热心社区的贡献。一如既往，我们鼓励您尝试这些并在我们改进 2.3 时报告任何问题。有关如何开始使用 PyTorch 2 系列的更多信息，请访问我们的入门 页面。 <表>
