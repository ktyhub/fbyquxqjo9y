kwarg 的弃用。 (#147301) 自 2.2 以来，这两个 API 均已弃用。请使用 `LRScheduler.get_last_lr()` 来访问学习率。`print_lr` 和 `verbose` 令人困惑，没有正确记录，并且很少使用，如 #99270 中所述，因此我们在 2.2 中弃用了它们。现在，我们通过完全删除它们来完成弃用。要访问并打印 LRScheduler 的学习率：
