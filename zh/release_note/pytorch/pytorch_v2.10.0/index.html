Python 3.14 支持 torch.compile()。 Python 3.14t（自由线程构建）也得到实验性支持。 通过 torchinductor 中的组合内核水平融合减少内核启动开销 一个新的 varlen_attn() 操作，提供对不规则序列和打包序列的支持 使用 DnXgeev 进行高效特征值分解 torch.compile() 现在尊重 use_definistic_mode DebugMode 用于跟踪分派的调用和调试数值偏差 - 这使得追踪细微的数值错误变得更加简单。 Intel GPU 支持： 通过启用 FP8（核心操作和缩放 matmul）和复杂的 MatMul 支持，以及扩展适用于 Windows 自定义操作的 C++ 扩展 API 中的 SYCL 支持，将 PyTorch 支持扩展到 Windows 和 Linux 上的最新 Panther Lake。 有关这些突出功能的更多详细信息，您可以查看[发布博文](https://pytorch.org/blog/pytorch-2-10-release-blog/)。以下是此版本的完整 release note。 # 向后不兼容的更改 ## 数据加载器前端 - 从采样器中删除了未使用的 `data_source` 参数（[#163134](https://github.com/pytorch/pytorch/pull/163134)）。这是一个无操作，除非您有使用此参数的自定义采样器。请相应地更新您的自定义采样器。 - 删除了 torch.utils.data.datapipes.iter.grouping 的已弃用导入（[#163438](https://github.com/pytorch/pytorch/pull/163438)）。不再支持 `from torch.utils.data.datapipes.iter.grouping import SHARDING_PRIORITIES, ShardingFilterIterDataPipe`。请改为从 `torch.utils.data.datapipes.iter.sharding` 导入。 ## 火炬.nn - 从 `nn.attention.flex_attention` 中删除嵌套锯齿状张量支持（[#161734](https://github.com/pytorch/pytorch/pull/161734)） ## ONNX - `fallback=False` 现在是 `torch.onnx.export` 中的默认值（[#162726](https://github.com/pytorch/pytorch/pull/162726)） - 导出器现在使用 `dynamo=True` 选项，无需后备。这是使用 ONNX 导出器的推荐方法。要保留 2.9 行为，请在 `torch.onnx.export` 调用中手动设置 `fallback=True`。 ## 发布工程 - 将 pytorch-triton 包重命名为 triton ([#169888](https://github.com/pytorch/pytorch/pull/169888)) # 弃用 ## 分布式 - 设备网格 - 添加了从根网格切片扁平暗淡的警告以及 _get_slice_mesh_layout 类型（[#164993](https://github.com/pytorch/pytorch/pull/164993)） 我们决定弃用现有的行为，该行为违反 PyTorch 设计原则（显式优于隐式）进行扁平化的设备网格切片。 ### 版本 <2.9 ```python import torch from torch.distributed.device_mesh import

分布式

  • 局部张量：
    • LocalTensor 是 PyTorch 分布式张量生态系统中强大的调试和仿真工具。它允许您在单个进程上跨多个 SPMD（单程序、多数据）等级模拟分布式张量计算。这对于以下方面非常有价值：1）在不启动多个进程的情况下调试分布式代码； 2) 通过检查每阶张量状态来理解 DTensor 行为； 3) 测试跨等级分片不均匀的 DTensor 操作； 4) rapid 分布式算法原型。请注意，LocalTensor 仅为调试目的而设计。它的开销很大，不适合生产分布式训练。
    • LocalTensor 是 torch.Tensor 子类，内部保存从等级 ID 到本地张量分片的映射。当您在 LocalTensor 上执行 PyTorch 操作时，该操作将独立应用于每个本地分片，模仿分布式计算（LocalTensor 在本地模拟集体操作，无需实际网络通信。）。 LocalTensorMode 是启用 LocalTensor 调度的上下文管理器。它拦截 PyTorch 操作并适当地路由它们。在实现分布式代码时，@maybe_run_for_local_tensor 装饰器对于处理特定于等级的逻辑至关重要。
    • 要开始使用 LocalTensor，用户从 torch.distributed._local_tensor 导入，初始化一个假进程组，并将其分布式代码包装在 LocalTensorMode 上下文中。在此上下文中，DTensor 操作会自动生成 LocalTensors。
    • PR：（[#164537]（https://github.com/pytorch/pytorch/pull/164537），[#166595]（https://github.com/pytorch/pytorch/pull/166595）， #168110、#168314、#169088、#169734) -c10d：
