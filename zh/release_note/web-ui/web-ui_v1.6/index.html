web-ui v1.6

感谢@vvincent1234。 现在，您可以在 WebUI 中无缝利用 DeepResearch 的高级功能。 重要提示：

  • DeepResearch 功能目前处于 alpha 版本，正在 rapid 开发中。通过观看此存储库来保持更新。
  • DeepResearch消耗的代币相对较多。请根据您的需要减少最大搜索迭代次数和每次迭代最大查询次数。这两者分别表示最大搜索迭代次数和每次搜索迭代同时查询的数量。 有什么新变化？ 2025/02/09 1.修复一些bug
  1. 分割提取的内容并限制最大内容长度 2025/02/07 1.新增停止按钮，让您随时停止研究。
  2. 使用您自己的浏览器。但是，使用您自己的浏览器当前仅支持每次迭代的单个搜索。 4.目前推荐gemini-2.0-flash-thinking-exp-01-21型号。 这是因为提取的内容过长有时会导致 API 调用错误。 这种集成的主要好处包括：
  • 您浏览器中的 DeepResearch： 直接在您自己的浏览器中访问所有 DeepResearch 功能 – 不再需要外部搜索 API！ 🌐
  • 协作代理： 利用多个人工智能代理协同工作的力量。 🤖🤝
  • 索引信息源： 轻松保存和访问所有参考文章以供将来参考，提高透明度并确保研究的可靠性。 📚 如何开始：
  1. 更新您的代码： 拉取最新版本以体验新功能。 ⬆️
  2. 选择强大的法学硕士： 要充分利用 DeepResearch，请选择具有推理能力的法学硕士，例如 gemini-2.0-flash-thinking-exp-01-21、deepseek-r1 或 o3-mini。 🧠
  3. 输入您的研究主题： 导航至浏览器使用 Web UI 中的 DeepResearch 部分并输入您的研究主题。 📝
  4. 配置参数： 根据您研究的复杂程度调整max_search_iteration_input和max_query_per_iter_input。 ⚙️
  5. 运行深度研究： Cli点击“run_deep_research”按钮，等待您的专业研究报告生成。 ⏳ 演示： https://www.youtube.com/watch?v=sguzGWuiRT8
