浏览器线束现在可以记录浏览器任务，并将代理的工作时间转化为可验证的简短视频。 这些视频使用真实的浏览器框架、clicks、光标移动和打字，然后用简洁的字幕、诚实的错误和更正解释以及经过验证的最终结果来浓缩作品。 视频创建直接内置于浏览器线束中。不需要单独的技能或安装。默认情况下，录音保持关闭状态，可以全局启用，也可以通过“录制此内容”、“告诉我你做了什么”或“制作演示”等提示来请求单个任务。
