LightRAG v1.3.4

修订 发布时间2025年4月26日 来源HKUDS/LightRAG 英文原文

变更架构图

亮点

  • WebUI 现在渲染 Markdown 与 Mermaid — Mermaid 渲染会等流式输出结束后再进行（#1426、#1453），避免反复解析不完整内容；图表只会在响应稳定后出现。
  • 检索测试支持查询模式前缀 — 开发者可以直接在 WebUI 里试用不同的检索策略并对比行为，无需手工改写请求（#1433）。
  • LLM 集成更可配置、更可靠 — 自定义分词器支持有助于让 token 处理与你的模型栈对齐（#1396），system_prompt 修复则恢复了占位符的预期插值（#1402）。抽取与关系权重逻辑对低能力模型也更友好（#1423）；升级后请重新验证提示词与评估。
  • 并发摄入与图遍历更稳 — 并行文档处理（#1447）、FAISS 死锁修复（#1465）、自定义 PostgreSQL AGE BFS（#1446）以及按度数优先的 NetworkX BFS（#1468），都在解决卡顿和图探索缓慢的问题。请在常规摄入并发下做基准测试以确认收益。
  • 摄入与状态 API 更容易自动化 — PGKVStorage.get_all() 增加了存储枚举（#1392），aget_docs_by_ids() 支持文档状态检查（#1419），ainsert_custom_chunks 不再遗漏必填键（#1389），减少了批量摄入与恢复流程中手工检查状态的需要。
  • 兼容性 — 未声明破坏性变更；需要更新那些假定 chunk-context 解析器输出为 CSV 的自定义代码，因为格式已改为 JSON，以提升 LLM 兼容性（#1412）。
