LightRAG v1.4.0

小版本 发布时间2025年7月15日 来源HKUDS/LightRAG 英文原文

变更流程图

亮点

  • 破坏性变更：QueryParam API 变了 — 此前传入 QueryParam 的集成必须更新到最新的签名；权威参考是 WebUI API 页面上的 /query 端点参数。按 v1.3.9 编写的调用点在升级后可能无法编译，或静默丢弃选项，所以上线前请审计每一处查询调用，不要把它当成可直接替换的补丁版本。
  • 文档删除落地——但要求重建索引 — 新的 WebUI 删除流程（#1698、#1697、#1732）只有在同时清空文档和缓存（勾选”同时清除缓存”）并重建索引时才会正确工作；同时为所有存储类型加入了 WORKSPACE 数据隔离（#1743）。从旧版本沿用的索引会保留删除无法清理的陈旧缓存条目；如果你暂时不需要删除功能，可以放心推迟这次代价较高的重建。底层依赖的是扁平化的 LLM 缓存结构（#1729），以及针对 MongoKV 和 PGKV 的删除感知缓存修复（#1718、#1717）。
  • 重排让混合查询成为推荐默认值 — 分块重排（#1753、#1782）显著改善了混合查询的结果，发布说明明确建议在启用重排器时把 mix 设为默认模式。硬编码了查询模式的团队应重新审视，以真正拿到收益；重排器配置和锁状态现在会显示在 WebUI 状态卡片上（#1773）。
  • 并行合并 + 多进程锁修复 — 文档合并阶段现在并行处理以利用 LLM 并发能力（#1549、#1772、#1771、#1770），降低大语料的摄入延迟。配合防止多进程模式下锁被过早清理的热修复（#1774）以及 Redis 连接池修复（#1775）——如果你跑多进程摄入，升级正是为了避免并行 worker 互相踩锁。
  • 新后端与模型兼容性 — Memgraph 加入图数据库后端（#1703、#1766），Cloudflare Workers AI 成为无服务器 LLM/嵌入选项（#1765），部署选择更丰富。现在支持 COT/推理模型：抽取实体/关键词时剥离 <think> 标签（#1752），推理模型的输出不再污染知识图谱。注意行为微调：默认嵌入批大小从 32 降到 10（#1750），以缓解内存压力但牺牲部分吞吐；已弃用的 MAX_TOKEN_SUMMARY 被移除（#1783），以避免输出被截断。

重要提示

  • 升级后，请清除文档和缓存，然后重新索引文档，以便文档删除功能正确运行。请记住在清除文档时选择“同时清除缓存”选项。如果不立即需要文档删除功能，则无需重新索引文档。
  • 此升级包括对 QueryParam 参数的更改。如果您之前使用 QueryParam 集成 LightRAG，请根据最新的 API 更新您的参数传递。请参阅 Web UI 的 API 页面上的 /query 端点参数。
  • 该版本中集成了Reranker，显着增强了混合查询的性能。我们建议启用 Reranker 时默认使用混合查询模式。
