LightRAG v1.4.8rc8

修订 发布时间2025年9月8日 来源HKUDS/LightRAG 英文原文

变更流程图

亮点

  • 小模型实体抽取与提示缓存 — 实体抽取（构建知识图谱的阶段）针对小参数量 LLM 做了调优，并增强了提示缓存（#2076、#2072）。对运行本地或量化模型的用户来说这是头条：它针对调用最密集的阶段，在降低成本和延迟的同时，让低能力模型此前抽取质量偏弱的问题更可靠。如果你用的是小模型，值得重新评测图谱质量。
  • WebUI 中的思维链渲染 — WebUI 现在可以渲染 LLM 的思维链输出（#2077）。这让界面成为真正的调试工具——你能看到模型为什么那样回答，有助于提示词调优和诊断奇怪的检索/回答行为。注意：任何能访问 WebUI 的人都能看到推理文本。
  • 流水线状态历史上限设为 1000 条 — 流水线状态消息现在只保留最近 1000 条（#2064）。这是有意的有界内存改动，避免长时间运行的摄入任务无限累积状态：任何读取完整历史缓冲的代码现在只能看到一个滚动窗口。
  • LLM/嵌入函数工厂重构 — 构造 LLM 与嵌入函数的工厂做了优化（#2068）。如果你注入了自定义的 llm_model_func / embedding_func 实现，升级后请对该集成做回归测试——虽然公开 API 表面看起来稳定，但构造路径变了。
  • 带上下文的 LLM 错误信息 — LLM 异常现在包含带上下文的错误消息（#2069）。实际效果是，抽取和查询阶段大量不透明的失败消失了：你拿到的是出错点周围的上下文而不只是裸的 traceback，有助于快速定位不稳定的模型端点问题。
  • 值得注意的小修复 — 文档状态现在在悬浮时显示元数据（#2070），.env 示例也做了修正（#2075，@k-shlomi 的首次贡献）。都是小改动，但如果你此前复制过旧的 env 模板，请对照修正后的版本重新检查配置。 本版本未报告破坏性变更。

  • 在 https://github.com/HKUDS/LightRAG/pull/2077 中添加 @danielaskdd 对 WebUI 的 LLM COT 渲染支持
  • 通过 @danielaskdd 在 https://github.com/HKUDS/LightRAG/pull/2070 中使用元数据工具提示增强文档状态显示
