LightRAG v1.4.9.11

LightRAG v1.4.9.11

这个项目是干啥的：是一个轻量级的检索增强框架，让开发者用更低成本把文档变成能问答的知识库，并借助图结构提升回答质量。

变更架构图

亮点

  • OpenAI 环境变量配置热修复——通过环境变量配置的用户务必升级 — PR #2585 修复了 OpenAI LLM 绑定选项无法从环境变量加载的问题。如果你通过环境变量设置 OpenAI 绑定，那些选项此前一直被静默忽略，所以这是让这类配置下升级几乎成为必做的一项改动。
  • Gemini：Vertex AI 支持与底层客户端更换 — PR #2529 为 Gemini LLM 绑定新增 Vertex AI 支持（对 GCP 用户是实打实的利好），PR #2531 则将 Gemini 迁移到原生异步 Google GenAI 客户端。后者是重构而非新功能，因此现有 Gemini 用户应做冒烟测试——底层客户端变了。
  • 文档摄入变更值得重新核对 — PR #2550 把 DOCX 抽取改为用 HTML 标签表示空白，这可能改变 DOCX 语料的抽取文本和索引质量；PR #2566 新增 MDX 作为支持的文件类型。所有摄入 DOCX 的用户升级后都应重新验证结果；MDX 用户则获得了直接支持。
  • WebUI 会话与 PostgreSQL 高可用更有韧性 — PR #2543 加入 WebUI 令牌自动续期（滑动窗口过期），活跃会话不再中途掉线；PR #2562 提升了 PostgreSQL 重连容错，面向高可用部署。对 WebUI 用户和在生产环境用 PostgreSQL 跑 LightRAG 的用户来说，这些是最有分量的运维升级理由。
  • 无破坏性变更；主要是增量/本地化/演示——不受影响可安全跳过 — 本版本没有明确的破坏性变更或迁移步骤。其余内容是本地化（韩语 PR #2571；德语、乌克兰语、俄语、日语 PR #2547）、文档修复、新的 Gemini/PostgreSQL/vLLM 演示，以及一次前端 dependabot 更新。不依赖 Gemini、DOCX/MDX 摄入、环境变量配置 OpenAI、WebUI 或 PostgreSQL 高可用的用户可以合理跳过这个补丁。
