LightRAG v1.3.0

小版本 发布时间2025年3月25日 来源HKUDS/LightRAG 英文原文

变更流程图

亮点

  • 认证与版本检查加固（PR #1162、#1171） — 本版本的重心是认证体系大改：对认证与版本检查做了可靠性重构（#1162），并进行了更广泛的认证重写，同时改造了 Swagger Auth 配置（#1171）。如果你接入了自定义认证，或用 Swagger UI 调用受保护端点，请对照新的配置面重新验证——回归问题最可能藏在这里。
  • 启用登录时 API-Key 认证已修复（PR #1171） — 一个具体的行为修复：此前开启登录功能时 API-Key 认证会失败。对于把浏览器登录和程序化 API-Key 访问混用的部署，这解除了相关客户端的阻塞；如果你以前碰到过这个失败，请补一条回归测试。
  • 内存数据库持久化卡死已修复（PR #1171） — 内存存储后端在某些情况下持久化时会挂起。如果你用内存数据库持久化状态，这是本版本运维上最重要的修复——挂起可能拖死长时间运行的摄入任务。
  • MongoDB 文档状态修正（PR #1160） — Mongo 后端的文档状态跟踪被修复，这是 @Gardelll 的首次贡献。此前在 Mongo 上看到状态卡住或不正确的用户，升级后应能拿到准确状态。
  • 访客模式 UI 清理（PR #1161） — 访客模式下不再显示退出登录按钮，让公开或只读部署的体验更合理（退出本来就没有意义）。
  • 服务端文档重构（PR #1166） — LightRAG Server 文档被重写，结构更清晰，降低新用户的上手成本和配置猜测。 本版本未列出破坏性变更。

发生了什么变化

  • 重构（SiteHeader）：在https://github.com/HKUDS/LightRAG/pull/1161中通过@choizhang隐藏访客模式下的注销按钮
  • 通过 @danielaskdd 在 https://github.com/HKUDS/LightRAG/pull/1162 中重构身份验证和版本检查以提高可靠性
  • 重构 LightRAG 服务器文档以提高清晰度和结构。作者：@danielaskdd 在 https://github.com/HKUDS/LightRAG/pull/1166
  • 通过 @Gardellll 在 https://github.com/HKUDS/LightRAG/pull/1160 中修复 mongo 文档状态
  • 由 @danielaskdd 在 https://github.com/HKUDS/LightRAG/pull/1171 中重构身份验证逻辑和 Swagger Auth 配置
  • 修复 https://github.com/HKUDS/LightRAG/pull/1171 中 @danielaskdd 启用登录时 API-Key 身份验证失败的问题
  • 修复内存数据库在某些情况下挂起的持久性，由 @danielaskdd 在 https://github.com/HKUDS/LightRAG/pull/1171 中实现
