LightRAG v1.0.9

LightRAG v1.0.9

这个项目是干啥的：是一个轻量级的检索增强框架，让开发者用更低成本把文档变成能问答的知识库，并借助图结构提升回答质量。

变更架构图

亮点

  • 混合搜索模式 — PR #523 新增了一种检索模式，把知识图谱遍历与 LightRAG 其他搜索技术融合，提示词在 #524 中调优。这是本版本的招牌能力：混合检索在多跳问题上往往胜过纯向量或纯图搜索。接入现有客户端的采用者要注意查询模式参数/枚举的变化。

  • 可断点续跑的入库 — PR #521 引入文档状态跟踪和索引流水线断点续跑，#529 修复了续跑过滤，使只有已完成状态的文档才被跳过。这对跑大型、长周期入库任务的人意义重大——中断后不再从零开始。#529 的细节值得注意：失败和进行中的文档会被重新处理，所以请确保入库路径是幂等的。

  • 时序知识图谱 — PR #525 为知识图谱关系加上时间信息，让图谱能编码某段关系何时成立，而不只是成立过。处理时间敏感语料（新闻、事件日志、版本化实体）的团队，无需另建数据模型就能获得时间感知推理。

  • Windows 异步修复 — PR #516 解决了 Windows 特有的异步运行时问题。如果你在 Windows 上开发或部署，这消除了此前让异步 API 在该平台不可靠的挂起/崩溃——虽是小补丁，却是实打实的可靠性提升。

  • 安装与错误处理清理 — PR #514 精简了 API 安装和文档，降低首次成功运行的门槛。另外 #527 改了某条失败路径的异常类型；如果你的集成捕获特定异常类，请重新检查那些处理器，避免类型被悄悄改掉后错误处理失效。

本次发布未表明有破坏性变更。
