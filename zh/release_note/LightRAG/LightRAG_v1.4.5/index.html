LightRAG v1.4.5

修订 发布时间2025年7月31日 来源HKUDS/LightRAG 英文原文

变更架构图

亮点

  • Rerank 分数过滤 — 可配置阈值（#1871）让检索在弱匹配消耗提示词预算之前把它丢掉。按 reranker 逐个调：切得太狠会降噪，但也可能压掉相关但排名靠后的证据。

  • 文档处理可观测 — 前端 track ID（#1882）、处理耗时元数据（#1883）和基于健康检查的状态卡片（#1873）让异步入库更容易关联和诊断。状态响应现在为了性能不再返回文档内容（#1881），所以轮询客户端不应依赖 content 一定存在。

  • 存储与重建可靠性 — 合并和重建操作现在共享 file_path 处理（#1869），同时修复了路径长度失败（#1862）和 PostgreSQL 路径缺失（#1891）。升级包含历史记录或部分填充记录的存储时，这些改动尤其相关。

  • 更干净、更快的抽取 — 修订后的实体提示词针对幻觉描述和重复的续写输出，同时缩短处理时间（#1845、#1868）。更稳健的关键词抽取 JSON 输出（#1872）也减少了下游解析失败。

  • WebUI 扩容与图谱兼容性 — 文档分页（#1886）避免一次渲染整个集合，查询重置控件（#1889）简化重复搜索。sigma.js v3 边渲染修复（#1863）让图谱边在库升级后仍正确渲染；升级后请重测自定义图谱集成。

  • 配置兼容性 — Ollama 绑定现在可以转发客户端选项（#1874），暴露厂商专有控制项。已弃用的 max_token_size 设置从 embedding 配置中移除（#1875），请审查自定义配置和环境文件里的陈旧引用。

未声明破坏性变更。
