ComfyUI v0.34.0

小版本 发布时间2026年8月26日 来源Comfy-Org/ComfyUI 英文原文

ComfyUI v0.34.0

变更流程图

亮点

  • MiniMax-H3 成长为真正的一等多模态引擎 — PR 15439 加入 MiniMaxH3AddGuide，让你可以在任意帧锚定图像和音频引导，而不再局限于固定位置；15375 新增逐 token 的视频/音频 latent 噪声 mask，实现区域级控制。再加上 taeh3 VAE 支持（15695）、prompt embedding（15697）、补齐缺失的特殊 token（15808）、thinking 处理修复（15611），以及纯单图 Empty Latent Image 节点现在也能配合 H3 使用（15677），这套技术栈终于可以在生产环境中使用 —— 预计要围绕新的 guide 节点重建旧的 H3 图。
  • 动态显存覆盖 AMD，失败诊断更友好 — 15633 在 ROCm 7.14+ 上默认启用动态显存，15722 为动态显存的 safetensors 加载器加入友好的错误提示；15588 修复了非动态显存机器上的 MiniMax Music。AMD 用户升级后会看到真实的内存管理行为变化，因此要重新验证大模型加载，不要以为之前的显存设置会原样保留。
  • 视频输出获得 HDR/AV1/容器支持 —— 以及一个破坏性的组件类型变化 — 15741 新增 HDR 保存、AV1、MKV 和 WebM；15764 为 H.264 加入 HDR 色彩空间选项；15810 增加 colorspace 选项，并把 bit_depth 从自由取值改成下拉组合。注意：15827 提高了最低 pyav 版本，15810 中 bit_depth 的类型变化可能破坏已保存的工作流或传入原始整数的 API payload —— 升级后要逐个复核 Save/Create Video 节点。
  • partner 节点移除迫使工作流迁移 — 15676 移除 Kling v2 图像模型，15851 退役 Tripo Refine 节点及其 v2.0 模型，15751 重命名 Ideogram P-Image 节点，15655 从 x-comfy-credits 中移除自定义价格提取逻辑；引用这些的已保存图在加载时会报错。另一面是新增：Wan 3.0（15843）、支持 1080p 的 Seedance 2.5 视频延长（15579、15684）、Seedream Fast Mode（15750）、Flux Video Upscale（15753）、Pixverse V6（15880）、Meshy-7（15807）、FishAudio（15612）和 Gemini 3.7 Flash（15688）。
  • 3D 生成更广，但内存门槛提高 — 14718 新增 Pixal3d 和 TRELLIS2 支持，14370 新增 Sam3d-body，但 15796 提高了 TRELLIS2 的内存系数 —— 在投入长时间 3D 批处理之前，要按比早期基准更高的标准预留显存。
  • 环境与平台清理，带有实际升级影响 — 15874 提示 Python 3.10 即将 EOL（测试覆盖已接受 Python 3.14 的数学字符串，15645）；15737 限制 Windows 上的多 GPU 可见性，15813 让 Windows 默认使用第一块 CUDA 设备，因此 Windows 多 GPU 用户应重新检查设备选择；14539 修复了使用自定义用户目录时的默认数据库路径。API 消费者还应注意 15369，它不再向 API 节点图像注入不透明的 alpha 通道。
