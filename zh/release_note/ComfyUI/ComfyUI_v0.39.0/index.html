ComfyUI v0.39.0

小版本 发布时间2026年10月5日 来源Comfy-Org/ComfyUI 英文原文

ComfyUI v0.39.0

这个项目是干啥的：是一个用拖拽节点来搭AI绘画流程的工具，让用户像拼积木一样组合模型和控制步骤，把出图过程看得见、改得动。

变更架构图

亮点

  • 离线与节点来源 flag — #16672 新增 --offline 和 --disable-partner-nodes，并弃用 --disable-api-nodes。这是气隙安装以及固定启动时加载哪些节点族的开关；要审查仍在传旧 flag 的启动脚本，因为它虽然还能用，但已进入弃用流程。
  • 输出编码默认值变化 — Save Video 采用更高质量的编码默认值（#16663），Save EXR 新增 16 位浮点支持，exr 选项的默认位深提升到 16 位浮点（#16706、#16715）。从未碰过这些节点的工作流会产出不同、且可能更大的文件，因此要检查存储预算以及任何假设整数位深的下游工具。
  • partner 节点扩展 —— 但有两处回退 — 新模型节点覆盖 Anthropic Sonnet 5.5（#16647）、Ideogram 4.5（#16689）、HeyGen Video 1.0（#16695）、BFL FLUX 3（#16716）、Grok imagine-video-1.5-lite（#16721）和 ElevenLabs Eleven v4 / v4 Turbo（#16737）。与此同时，Luma Ray 2 节点被弃用（#16741），GPT Image 2 失去透明背景输出（#16744）—— 要重新审视依赖这两项行为的工作流。
  • MiniMax H3 运行成本降低 — LynnReal 轻量 Minimax-H3 VAE 支持（#16657）、VAE 卸载修复（#16698），以及在块之前释放 embedding 临时张量（#16677），共同降低了 H3 流水线的峰值显存。如果你之前不得不超量预留内存或强制激进卸载，值得重新调优。
  • 资产扫描不再阻塞保存 — 本版本最大的主题是 SQLite 争用清理：资产数据库切换到 WAL 并使用 synchronous=NORMAL 和短事务（#16748），清理/离线标记和扫描插入做了批处理（#16696、#16748），扫描在文件夹遍历期间暂停、等提示词队列清空后再恢复（#16764、#16765），资产关闭时完全不加数据库锁（#16742）。净效果是：长时间的模型文件夹扫描不再阻塞上传和输出保存。还包括跨卷上传复制（#16722）、宽容的分类扫描（#16658），以及在禁用哈希的磁盘回归时恢复记录（#16646）。
  • 注意力、GPU 与崩溃修复 — comfy_attention / AttentionTensorContainer 的覆盖面扩展到更多模型（#16766）；集成显卡上自动禁用锁页内存（#16746）；Qwen Image 2.1 中的 int8/int4 缓存崩溃被修复（#16667）。iGPU 用户获得更安全的开箱默认设置，混合精度的 Qwen 用户可以重试量化缓存。

本版本没有破坏性变更。
