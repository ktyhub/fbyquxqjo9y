ComfyUI v0.37.0

ComfyUI v0.37.0

这个项目是干啥的：是一个用拖拽节点来搭AI绘画流程的工具，让用户像拼积木一样组合模型和控制步骤，把出图过程看得见、改得动。

变更架构图

亮点

  • 启动与加载更快 — Aimdo 0.5.5 加上在高速磁盘上自动启用 --fast-disk，减少了模型加载开销。如果 fast-disk 模式引发问题，可用新的调试覆盖项关闭它（CORE-440、#16333、#16424）。
  • 新模型支持 — 现已支持 Qwen Image 2.1（#16400）和 MoGe 3（#16381）；SheetSage 2 的位置嵌入精度现在与上游一致，兼容性更好（#16395）。
  • GPU 与内存优化 — 动态显存模式现在始终把文本编码器放在 GPU 上（#16374）。Qwen3/3.5/3.8 获得 CUDA graph 和 W4A8 GEMV 支持（#15623），Comfy Kitchen attention 降低了 Wan 的峰值显存（#16418）。
  • 音乐生成可控性更强 — YuE2 Generate Music 节点新增 CFG 控制（#16373），MiniMax Music 3 在启用 CUDA graph 时不再产生噪声（#16428）。
  • partner 节点更新 — GPT Image 2 新增透明背景生成（#16366），现已支持 Meshy 7.1（#16412），Tripo 现在会直接拒绝那些会产出空 GLB/FBX 链接文件的 P2 运行，而不是事后才失败（#16369）。
  • 工作流兼容性变化 — EmptyLatentImage 的默认值变了（#16384），节点名称/分类也有更新（#16274）；请检查现有工作流和已保存的尺寸设置。
  • 没有明确指出破坏性变更。
