ComfyUI v0.46.0

小版本 发布时间2026年11月18日 来源Comfy-Org/ComfyUI 英文原文

ComfyUI v0.46.0

变更流程图

亮点

  • 破坏性：移除 DirectML 支持 — 不再支持 DirectML（#17711）。工作流依赖该执行路径的 Windows 用户，必须在升级前迁移到受支持的后端或构建版本。
  • partner 节点迁移到 Comfy Router — Wan（#17639）、Krea（#17691）、Luma（#17714）及其他集成（#17794）现在通过 Comfy Router 路由。升级后请重新核对 provider 凭据和已保存工作流的兼容性。已退役的 OpenRouter Qwen3.6 Max Preview 和 Claude Sonnet 4.5 也被移除（#17737、#17819），需要替换模型引用。
  • 新的图像与视频生成选项 — LTX 新增 AlphaGen、SDR-to-HDR、Reframe 和 Upscale（#17664），此外还有 MiniMax H3 Image（#17661）、支持 4:3 和 3:4 比例的 Kling 4.0 Image/Long Image（#17797、#17815），以及支持自动时长的 HeyGen 1080p/30 秒片段（#17721）。这些由 provider 支撑的节点扩展了后处理和托管视频工作流；生产使用前请验证模型可用性和各节点的时长限制。
  • 更强的媒体流水线 — Concatenate Video 现在会把各片段统一到第一个片段的帧率和音频（#17621），因此已有的拼接可能产生不同的时序或音频，应做回归测试。单通道 PNG 保存和通道拆分节点（#17727、#13548）简化了 mask 工作流，Video Deflicker 和更快的 RAFT 光流（#17754）带来了原生的时序清理选项。
  • 扩展的 Qwen 与 SenseNova 文本支持 — Generate Text 支持 Qwen3-1.7B（#17787），经过词表裁剪的 Qwen checkpoint 可以内置 tokenizer（#17633），简化了 checkpoint 打包和部署。SenseNova 新增思考、交错生成和自我纠正（#16032），本版本生成速度也更快（#17811）。
  • 采样与输出可靠性修复 — CFG 为 1.0 时 APG 不再改变输出（#17741），动态显存恢复不再在模型之间泄漏采样 schedule（#16491）；受影响的工作流现在可能产生不同且更正确的结果。新增的 --force-output-rerun 标志（#17809）会刻意绕过缓存执行，重新生成输出节点文件。
