DeepSpeed v0.18.9

修订 发布时间2026年3月30日 来源deepspeedai/DeepSpeed 英文原文

DeepSpeed v0.18.9

这个项目是干啥的：是一个帮大模型训练提速省显存的工具库，让研究和工程团队用普通显卡集群也能训练超大模型，并兼容新版PyTorch。

变更架构图

亮点

  • AutoTP / AutoSP 能力扩展 — 本次的头号特性：AutoTP 新增通用检查点支持（PR #7908）和 HuggingFace tp_plan 支持（PR #7901），AutoSP 也合并进核心仓库（PR #7860）。如果你在用自动张量/序列并行，这就是升级的主要理由——检查点续训和 HF 模型集成由此成为一等公民。
  • Muon 优化器支持 ZeRO Stage 3 — PR #7919 把 Muon 优化器的支持扩展到 ZeRO Stage 3，让团队可以把 Muon 与完整的 ZeRO-3 分片结合，而不再局限于更早的阶段。如果你在用 Muon 训练大规模分片模型，这条与你相关。
  • 可靠性与兼容性修复 — 针对真实边界情况的一批修复：torch.amp.custom_fwd 对 PyTorch < 2.4 的向后兼容（PR #7920）、遵循 $DS_IGNORE_CUDA_DETECTION 跳过本地 GPU 检测（PR #7896）、尊重 $TRITON_HOME（PR #7907）、处理 Triton 自动调优缓存 is_nfs_path 中路径不存在的情况（PR #7921）、在 superoffload 中用共享 CPU 缓冲区保留多组更新（PR #7906），以及移除 ROCm GPU 架构检测中不必要的 shell=True（PR #7915）。
  • 无破坏性变更，无需迁移 — 本版不需要用户侧做任何改动；没有 API 移除，也没有配置格式变更。其余非功能性内容只有文档/元数据：ASPLOS 2026 最佳论文新闻（PR #7923）、README 更新（PR #7931）、AGENTS.md 的预提交说明（PR #7930）、从 AGENTS.md/CLAUDE.md 移除版权（PR #7932），以及 version.txt 版本号提升（PR #7935）。这是一次真正的发布，不是重新打标签或纯元数据变更。
  • 谁该升级 — 如果你依赖 AutoTP/AutoSP、HF tp_plan、Muon + ZeRO-3，或命中上述任一修复场景（旧版 PyTorch、ROCm、Triton 缓存路径、superoffload），建议升级。如果你的配置稳定且以上都没用到，这些改动是增量式的，可以放心观望。

  • 修复了 @tohtana 在 https://github.com/deepspeedai/DeepSpeed/pull/7920 中 PyTorch < 2.4 的 torch.amp.custom_fwd 的向后兼容性
