DeepSpeed v0.18.4

修订 发布时间2026年1月7日 来源deepspeedai/DeepSpeed 英文原文

DeepSpeed v0.18.4

变更流程图

亮点

  • DeepCompile 适配更新的 PyTorch — 针对 PyTorch 2.8/2.9 的兼容性修复，消除了在这些版本上做编译训练的阻碍（#7755）。CI 现已覆盖 Python 3.11/3.12（#7007），不过确定性编译测试被禁用、AMP 测试被移除（#7720、#7745），这些路径的覆盖有所下降。
  • 梯度缩放行为 — 引擎现在只在 scale_wrt_gas=True 时才缩放梯度（#7724）。依赖无条件缩放的自定义循环应核实缩放归属，避免重复缩放或漏掉更新。sqrt 学习率调度器也改用 math.sqrt，规避了张量相关的类型问题（#7735）。
  • 检查点可靠性与 MoE 迁移 — 修复了 Nebula 检查点的 commit() API 不匹配，以及 DecoupledCheckpointEngine 死锁（#7740、#7742），提升了分布式保存的可靠性。MoE 检查点用 seq_dp_world_size 取代 dp_world_size（#7732）；请审查引用旧字段的自定义检查点读写代码。
  • 优化器与反向钩子健壮性 — 修复涵盖 Stage 3 SuperOffload 中缺失的 param_names、反向钩子中的 None 条目、空参数下 OnebitLamb 的 NaN 传播，以及 BF16 DummyOptimizer 的销毁失败（#7715、#7725、#7736、#7763）。这些减少了混合参数配置和优化器清理路径中的崩溃。
  • PEFT 与上下文并行注意力 — UlyssesSPAttentionHF.register_with_transformers() 不再因 PEFT 模型而崩溃（#7737），扫清了将 Ulysses 序列并行与基于 adapter 的微调结合的阻碍。
  • ROCm 与运行时稳定性 — AMD/ROCm 支持改进（#7448）、在 Async I/O 等待期间释放 Python GIL（#7727），以及移除过早的 MPI 环境变量检查（#7751），减少了特定平台的启动失败和罕见的 I/O 挂起。

未声明破坏性变更。
