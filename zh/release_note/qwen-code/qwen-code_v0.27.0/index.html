qwen-code v0.27.0

这个项目是干啥的：一个通义千问出的命令行AI编程助手，在终端里读代码、改代码、跑命令，给想少敲键盘、快速改项目的开发者用。

变更架构图

亮点

  • 托管代理会话可以同时处理多个子问题，以任意顺序回答这些问题，并将每个子问题的草稿和错误分开。 (#16484)
  • Web Shell 添加了任务问答热图和询问详细信息支线任务，该支线任务解释待处理的询问用户问题选项，但无需回答。 （[#16037]（https://github.com/QwenLM/qwen-code/pull/16037），[#16458]（https://github.com/QwenLM/qwen-code/pull/16458））
  • GitHub 频道编辑器添加了存储库过滤器允许列表和阻止列表，同时绑定 PR 传递和普通评论传递变得更加可靠。 (#16493、#16502、#16416)
  • Shell 工具编辑现在可以在 sed 替换中安全地处理 CRLF 和 Unicode，并且取消的命令报告为中断，同时保留部分输出。 （[#15701]（https://github.com/QwenLM/qwen-code/pull/15701），[#15836]（https://github.com/QwenLM/qwen-code/pull/15836））
  • 托管代理运行时速度更快且不易出现死锁，并且具有更安全的会话重命名、快照发布、存储准入和锁定处理。 (#16480、#16478、#16376、#16489、#16447)
  • 升级拒绝和 Advisor 启动错误不再公开嵌入的凭据，并且在启动和验证期间拒绝空的 Harness 用户信息。 （[#16352]（https://github.com/QwenLM/qwen-code/pull/16352），[#16083]（https://github.com/QwenLM/qwen-code/pull/16083））

重大变更

没有已知的重大变化。
