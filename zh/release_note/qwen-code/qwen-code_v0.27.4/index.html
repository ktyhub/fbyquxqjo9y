qwen-code v0.27.4

qwen-code v0.27.4

变更流程图

亮点

  • 托管代理会话可以访问授予的本地目录并打开交互式托管 Web 终端，而无需保留凭据或路径。 （[#16844]（https://github.com/QwenLM/qwen-code/pull/16844），[#16866]（https://github.com/QwenLM/qwen-code/pull/16866））
  • 将输出发送到飞书和WeCom webhooks，长的托管通道回复作为有序片段传送，而不是被截断。 (#17012、#17013、#17223、#17224、#17002)
  • 自动模式现在需要对危险操作进行显式授权，检查分类器超时，避免 HTTP(S) URL 文件系统查找，并明显标记完全访问权限。 (#16858、#17127、#17146、#17100)
  • Web Shell 目标页面可以合并来自 trusted 工作区的目标、显示工作区徽章以及在创建目标时定位选定的工作区。 （[#17230]（https://github.com/QwenLM/qwen-code/pull/17230））
  • 使用恢复的 CLI /内存控件、持久工作区设置以及键入 SDK API 来管理内存以预览、提交、检查、取消和重试 Codex 内存导入。 （[#17162]（https://github.com/QwenLM/qwen-code/pull/17162），[#17213]（https://github.com/QwenLM/qwen-code/pull/17213））
  • 当本机 UUID 支持不可用时，终端选项卡、Web 预览、本地命令和斜线命令仍可通过纯 HTTP 运行。 (#17196)

重大变更

没有已知的重大变化。
