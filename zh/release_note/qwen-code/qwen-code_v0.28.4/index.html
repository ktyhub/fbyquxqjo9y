qwen-code v0.28.4

修订 发布时间2026年11月22日 来源QwenLM/qwen-code 英文原文

qwen-code v0.28.4

亮点

  • Web Shell 本地守护程序模式添加了具有渐进式扫描和流式更新功能的工作区工件库页面。 (#18071)
  • Web Shell 聊天添加了共享的 ChatSurface、继续徽章、建议芯片和会话的移动布局修复。 (#17952、#18044、#17918、#17883、#18011)
  • Core 添加了内置 Gemini 4 推理默认值。 (#18039)
  • 本地运行时现在在进程生成时使用所有者私有权限创建其状态目录。 (#17964)
  • 命令迁移专门创建 Markdown 目标，并在目标冲突时保留原始 TOML。 (#17873)
  • 扩展现在加载使用 UTF-8 BOM 保存的清单。 (#15786)

重大变更

没有已知的重大变化。

网络外壳

通过会话继续、工件浏览、移动布局、建议芯片和更清晰的状态提示改进了 Web Shell 聊天体验。

  • web-shell：保持手机发送到软件键盘上方（#17883）
  • 在 Web Shell 编辑器中添加可点击的建议芯片，以便触摸用户可以在发送之前插入和编辑后续建议。 （[#17918]（https://github.com/QwenLM/qwen-code/pull/17918））
  • Web Shell 现在呈现扩展思维行的 Mod 重写，同时保留原始存储的思维和折叠的完成思维行。 （[#17920]（https://github.com/QwenLM/qwen-code/pull/17920））
  • web-shell：更新深色主题的侧边栏徽标（#17935）
  • Web Shell 添加了一个共享的 ChatSurface 聊天列，可从会话状态呈现文字记录、批准、问题和作曲家。 (#17952)
  • web-shell：紧凑的自动触发消息（#17970）
  • 通过将可选行操作移至“更多”菜单，为会话标题在移动设备和桌面上提供更多空间。 (#18011)
  • Web Shell 侧边栏现在会为上一轮被中断且需要继续的会话显示“继续”徽章。 （[#18044]（https://github.com/QwenLM/qwen-code/pull/18044））
  • web-shell：范围 ChatSurface 准入锁定到所属会话并绑定 loadOlder (#18066)
  • web-shell：将会话悬停状态与行的状态提示对齐（#18070）
  • 在 Web Shell 本地守护进程模式下添加工作区工件库页面，具有渐进式扫描和流式更新。 (#18071)
  • web-shell：使用运行颜色进行主动工作（#18072）

托管代理和托管线束

修复了托管代理环境的托管会话竞赛、预检配置、权限、遥测通道和存储标识符。

  • 托管代理：关闭 config_install 记录名称的资源（#17468）
  • 修复了在构建、关闭和采用延迟构建的 client 时使用一把锁来修复托管安全带竞赛的问题。 （[#17961]（https://github.com/QwenLM/qwen-code/pull/17961））
  • 托管代理预检现在将空白工作区 cwd 视为未配置，而不是使用当前工作目录，并且文档现在匹配已发布的状态目录规则。 (#17965)
  • 当无人无法解决时，耐用的预检装置现在可以干净地跳过，使用显式 0755 权限，并且文档阐明服务用户所有权期望。 (#18020)
  • 添加托管遥测 client 通道值，以便可以将托管代理会话与普通守护程序流量区分开来。 (#18022)
  • 托管代理 OSS 对象现在在密钥中使用可读的租户、工作区和会话标识符，使存储桶内容更易于检查。 (#18048)

核心运行时和模型

更新命令迁移、本地运行时状态权限、工具输出恢复、转录性能和 Gemini 4 推理默认值。

  • 命令迁移现在专门创建 Markdown 目标，并在存在目标冲突时保留原始 TOML。 (#17873)
  • 核心：保护持久工具输出恢复（#17875）
  • 在单独的有界类中缓存超大的转录本索引，因此大索引不再阻止小会话挂钩保留。 (#17910)
  • 在进程生成时使用所有者私有权限而不是在提供程序创建期间创建本地运行时状态目录。 (#17964)
  • 核心：添加内置 Gemini 4 推理默认值（#18039）

扩展和频道

改进了繁忙代理的扩展清单加载和 ACP 通道活动处理。

  • 扩展：加载使用 UTF-8 BOM 保存的扩展清单 (#15786)
  • 让 ACP 通道活跃度将繁忙的代理视为健康状态的时间更长，并在通道关闭时记录证据。 (#18028)

会议和批准

  • 文档现在声明运行交互式会话会自动获取 mcpServers 更改，仅将重新启动作为故障排除后备。 (#17743)
  • 服务：优化 create_sub_session 工作区批准（#17863）

自动修复证据

在显示之前从自动修复失败检查证据中去除终端控制字符和 Unicode Bidi 覆盖。

  • 自动修复失败检查证据现在会在显示之前从日志摘录中删除终端控制字符和 Unicode Bidi 覆盖。 (#16748)

其他变化

  • ci：使用实时审核机器人进行手动重新审核（#17848）
  • 将所需的托管代理检查名称稳定为托管代理门，并防止跳过或无套件审核运行覆盖实际结果。 (#17865)
  • 用显式断言替换收据目录 SpotBugs 排除，同时保持丢失收据字节的 HTTP 400 约定不变。 (#17919)
  • 更新身份去哈希设计文档以更正工作区和存储预算，并在 VARCHAR 转换之前记录重复键约束。 (#17960)

  • 部分发布后，可以通过重用匹配的发布分支并发布剩余的包来恢复发布重试；不同的同版本树仍然被拒绝。 (#17951)
  • 托管代理身份存储删除冗余的同行哈希键列，并在原始身份列上重建受影响的唯一键和索引，而无需更改列顺序。 (#18019)
  • ci：隔离验证流道温度中的划痕（[#17879]（https://github.com/QwenLM/qwen-code/pull/17879））
  • web-shell：向遥测提供每回合辅助反馈（#18021）
  • 重构（托管代理）：删除无效和冗余的模式对象（[#18041]（https://github.com/QwenLM/qwen-code/pull/18041））
  • 测试（渠道）：让四个受管理的钉钉见证人排除他们声称的内容（#17968）
  • 现在，当未准备暂存目录时，CI 验证会明显失败，而不是默默地使用共享操作系统临时空间。 (#18040)
  • 钉钉近期窗口上限测试超时时间提升至 120 秒并固定，以减少不稳定的 CI 故障。 (#17837)
  • CLI 重启恢复崩溃测试现在在终止守护进程之前等待转录和部分响应状态。 (#18049)
  • 文档现在建议为 Web Shell 本地守护程序模式提供一个只读工作区工件库页面。 (#18036)
  • 添加了无状态托管线束第 4 阶段中托管代理操作停车的双语设计文档。（#18047）
  • 将工作区工件库设计标记为已接受但尚未在双语文档中实施。 (#18063)
  • 通过更新 ChatSurface 副本的文档导出渲染器大小预算来恢复绿色 CI 构建。 (#18067)

  • 通过使用真实工作区转录路径修复了 qwen 服务助理反馈遥测的 macOS e2e 测试。 (#18074)
  • 测试（托管代理）：将四个持久的现有目录预检测试门控到 Linux（[#18076]（https://github.com/QwenLM/qwen-code/pull/18076））
  • 重构（托管代理）：将发布 OSS 范围命名移至合约（#18085）

  • 更新设计文档，将自动触发消息标记为已落地，并使渲染器预算历史记录与已实现的行为保持一致。 (#18080)
  • 使自托管 Java CI 作业重建可写作业本地 Maven 存储库，并在缓存重用失败时安全回退。 (#18065)

中文摘要

亮点

  • Web Shell 本地 daemon 模式新增 workspace artifact library 页面，支持渐进式扫描与流式更新。 (#18071)
  • Web Shell 新增共享 ChatSurface、Continue 标记、suggestion chips，并优化移动端布局。 (#17952, #18044, #17918, #17883, #18011)
  • Core 新增内置 Gemini 4 reasoning 默认设置。 (#18039)
  • 本地 Runtime 现在在进程启动时创建状态目录，并仅允许属主访问。 (#17964)
  • 命令迁移现在独占创建 Markdown 目标，冲突时保留原有 TOML。 (#17873)
  • Extensions 现在可加载保存为 UTF-8 BOM 的 manifest。 (#15786)

Web Shell

改进 Web Shell 聊天体验，新增会话继续、工件浏览、移动端布局、suggestion chips 和更清晰的状态提示。

  • web-shell：保持手机发送到软件键盘上方（#17883）
  • Web Shell 输入框新增可点按的 suggestion chip，触控用户可插入并编辑 follow-up suggestion 后再发送。 (#17918)
  • Web Shell 现在可渲染展开的 thinking 行的 Mod 重写，同时保留原始存储内容和折叠的 Done thinking 行。 (#17920)
  • web-shell：更新深色主题的侧边栏徽标（#17935）
  • Web Shell 新增共享 ChatSurface 聊天列，可根据会话状态渲染转录、审批、提问和输入区。 (#17952)
  • web-shell：紧凑的自动触发消息（#17970）
  • 在移动端和桌面端为会话标题留出更多空间，并将可选操作移入 More 菜单。 (#18011)
  • Web Shell 侧边栏会为上次回合被中断、需要继续的会话显示 Continue 标记。 (#18044)
  • web-shell：范围 ChatSurface 准入锁定到所属会话并绑定 loadOlder (#18066)
  • web-shell：将会话悬停状态与行的状态提示对齐（#18070）
  • Web Shell 本地 daemon 模式新增 workspace artifact library 页面，支持渐进式扫描与流式更新。 (#18071)
  • web-shell：使用运行颜色进行主动工作（#18072）

托管代理和托管线束

修复托管会话竞态、预检配置、权限、遥测通道和存储标识，提升 Managed Agent 环境可靠性。

  • 托管代理：关闭 config_install 记录名称的资源（#17468）
  • 修复 Hosted Harness 竞态，在构建、关闭和接管延迟创建的客户端时统一使用同一个锁。 (#17961)
  • managed-agent 将空白的 workspace-cwd 视为未配置，而不是使用当前工作目录，并同步预检文档。 (#17965)
  • 持久预检 fixture 在无法解析 nobody 时跳过，使用显式 0755 权限，并说明 service-user 的所有者期望。 (#18020)
  • 新增 managed 遥测 client-channel 值，以便区分 Managed Agent 会话与普通 daemon 流量。 (#18022)
  • Managed-agent 的 OSS 对象键改用可读的 tenant、workspace 和 session 标识，便于运维查看。 (#18048)

核心运行时与模型

更新命令迁移、本地 Runtime 状态目录权限、工具输出恢复、转录性能以及 Gemini 4 推理默认值。

  • 命令迁移现在独占创建 Markdown 目标文件，遇到目标冲突时保留原有 TOML。 (#17873)
  • 核心：保护持久的工具输出恢复（#17875）
  • 将超大 transcript index 放入独立受限缓存类，避免大索引阻塞小会话的 hook 保留。 (#17910)
  • 在本地 Runtime 进程启动时创建状态目录并使用仅属主可访问权限，而不是在 provider 创建时创建。 (#17964)
  • 核心：添加内置 Gemini 4 推理默认值（#18039）

扩展与通道

改进扩展清单加载，并优化繁忙 agent 的 ACP 通道存活检测。

  • 扩展：加载使用 UTF-8 BOM 保存的扩展清单 (#15786)
  • 让 ACP 通道存活检测将繁忙 agent 视为暂时健康，并在关闭通道时记录证据。 (#18028)

会话与审批

  • 文档现在说明运行中的交互式会话会自动应用 mcpServers 更改，重启仅作为故障排查手段。 (#17743)
  • 服务：优化 create_sub_session 工作区批准（#17863）

Autofix 证据

Autofix 失败检查证据在展示前会移除终端控制字符和 Unicode Bidi 覆盖字符。

  • Autofix 失败检查证据会在展示前移除日志摘录中的终端控制字符和 Unicode Bidi 覆盖字符。 (#16748)

  • managed-agent 移除仅重复本行原始身份列的哈希键列，并在原始身份列上重建唯一键和索引，保持列顺序。 (#18019)

  • CLI 重启恢复崩溃测试现在会先等待会话记录和部分响应状态就绪，再终止 daemon。 (#18049)
  • 新增设计文档，提议在 Web Shell 本地 daemon 模式下提供只读的 workspace 工件库页面。 (#18036)
