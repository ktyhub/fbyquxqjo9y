亮点

捆绑的 CLI 0.23.0 包括 #11022 中请求的两个修复：

  • 托管内存可用性现在遵循 memory.enableManagedAutoMemory 设置 (#6941)。禁用托管自动内存的主机不再在系统提示符中看到已接受的记住/梦想请求或托管内存指令；可以删除本地补丁。
  • 大小触发的微压缩现在会清除旧工具结果以达到低水位线 (#8464)，因此它不再在后续的每个回合中重写对话前缀的另一部分。提供程序提示缓存重用在长时间的工具密集型会话中得以保留，从而降低了缓存输入成本。
