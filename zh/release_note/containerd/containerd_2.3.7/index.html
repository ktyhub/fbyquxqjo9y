containerd v2.3.7

这个项目是干啥的：容器运行时引擎，是 Docker 和 Kubernetes 底下真正负责跑容器的核心。给搭建容器平台、做云原生基础设施的工程师用。

欢迎使用 Containerd 的 v2.3.7 版本！

Containerd 2.3 的第七个补丁版本包含各种修复 以及包括安全补丁在内的更新。

运行时

  • 在解压过程中应用强化来过滤图像注释中的 ID 映射标签 (#14261)
