copilot-cli v1.0.111

修订 发布时间2026年11月13日 来源github/copilot-cli 英文原文

2026-11-13

  • 为企业管理的 Shell、Bash 和 PowerShell 权限规则添加正则表达式支持
  • 添加 —host-allow-session-creation 以允许远程 clients 在 CLI 主机上创建一次启动会话，而无需更改保存的设置
  • 刷新/使用高级请求使用情况，以便百分比保持最新状态。
  • 防止重复的 MCP OAuth 重新连接，并在取消授权后使服务器保持在 need-auth 状态
  • 包含宽符号的 Markdown 表，后跟文本变体选择器，例如 ⌛︎，以正确对齐的行进行渲染
  • footer.showCodeChanges 设置描述现在表示它显示由 Copilot 在此会话中的文件编辑添加和删除的行，而不是挂起的更改
  • /usage 活动图现在通过显示更少的周数来适合狭窄的终端，而不是将每天的行分成两行
  • 当出现终端控制序列时，Shell 输出和自定义状态行可以正确显示，而无需应用意外的文本样式
  • /rewind 与对话 + 文件不再计数、列出或报告为已恢复的文件，该文件后来又已放回或删除
  • 当 CLI 在子目录中启动时，交互式/插件市场命令会查找存储库本地市场
  • 使用 —screen-reader 时，保持选择标签可读并在 /environments 中对齐行
  • /skills get 没有技能名称，而 /mcp 使用文本名称为获取和删除动词，而不是退休的信息和删除
  • /diff 显示二进制文件的清晰通知，而不是乱码文本或空窗格
  • /usage 活动图将其图例隐藏在狭窄的窗格中，以防止其缠绕到额外的行上
  • $ shell 快捷方式会报告一次启动失败，并有明确的原因，包括当 Ctrl+G 同时打开编辑器时。
  • /mcp search 使用您输入的值安装带有 URL 变量的注册表服务器
  • 自定义状态行正确呈现终端颜色和格式，颜色重置后不会出现杂散字符。
  • 挂钩批准对话框将工具名称和参数中的控制字符显示为可见文本，而不是隐藏或重新设计它们
  • /session delete-all、/session prune 和 /session delete 保留在同一窗口中后台运行的会话
  • 调整终端大小后，适合一行的文本保留在一行上
  • 在 /workflows 中，运行的代理列表不再从短终端的底部运行：所选代理保留在屏幕上，长阶段标题保留在一行上
  • copilot 插件启用、禁用、更新和卸载现在会失败，并在无法解析时命名为 config.json，而不是在没有更改的情况下报告成功或未安装插件
  • --no-color 保留文本样式，同时禁用颜色，即使设置了 FORCE_COLOR
  • 在标记粘贴输入的终端中粘贴后立即按 Enter 键时，粘贴的图像路径会正确附加
  • 当导航键无法在短终端中移动选择时，保持所选/共享操作可见
  • MCP 表单立即显示在外部编辑器中使用 Ctrl+G 编辑的答案的验证错误
  • 在没有先前会话的情况下运行 copilot --continue 会显示欢迎标题和入门框。
  • 在导航过程中打开对话框时保持“会话”选项卡响应，并显示可以回答的待处理对话框
  • 保持突出显示的确认选项在短终端上的“会话”选项卡和/环境中可见
  • 将/主题选择器的标题和边框保留在狭窄终端的屏幕上以及停靠的会话侧边栏旁边，而是删除预览
  • /share 屏幕使所选操作在狭窄的终端中可见
  • /ask 和 /btw 在狭窄终端的会话侧边栏旁边正确显示答案
  • 当任务列表长于终端可以显示的长度时，保持 /tasks 标题和边框可见
  • copilot -p "/compact" --silent 不再将压缩结果行打印到标准输出，因此 --silent 输出仍仅限于代理的响应
  • 在短终端上启动动画期间输入多行草稿时，保持提示、选项卡栏和状态行可见
  • /diff 显示新名称下的分阶段重命名，包括重命名时所做的编辑
  • 对于实验性动态工作流程，工作流程自己的代理无法再启动或恢复工作流程运行，因此当允许所有工具时，工作流程无法再无限制地启动自身副本。
  • 在 16 色或 256 色终端上使用高对比度主题时，“会话”选项卡显示所选行的状态图标，而不是将其绘制为蓝底蓝字
  • 客服人员工作时输入的后续信息现在按照输入顺序运行；在两轮之间到达会话的会话不再被其后键入的后续会话所取代。
  • /usage 活动图表仅计算您键入的提示，而不计算子代理或自动驾驶提示，并且其消息总数与图表绘制的天数匹配
  • 粘贴的转义序列不再更改文本颜色或隐藏搜索字段中的文本
  • copilot -p 带有 —trust-folder，从存储库的子目录运行，现在警告存储库根目录处的挂钩未加载，并说明如何加载它们
  • 自定义状态行可以正确显示非 ASCII 字符，即使命令将其分段写入时也是如此
  • 调整终端大小后从换行复制内联代码不再包含额外的不间断空格。
  • 排队的斜杠命令现在在失败时显示错误，而不是默默消失
  • 回合结束时发送的提示现在无需等待后台代理完成即可运行
  • 当不再按住鼠标左键时，拖动会话分隔线或滚动条现在可以干净地结束。
  • 允许在 macOS 上的 /tmp 下使用您自己的暂存文件，而无需路径权限提示，除非设置了 —disallow-temp-dir
  • 切换模型或压缩会话后重新附加图像或文档将其内容发送到模型
  • 当 /update 无法下载版本时显示错误，而不是无限期地留下下载进度消息
  • 当启用远程会话时，可以从 GitHub 控制使用 /new 或从“会话”选项卡启动的会话
  • 在插件挂钩工作目录和环境值中展开 ${COPILOT_PLUGIN_ROOT}
  • 按住空格键时，即按即说会保留听写文本重复暂停和恢复
  • 远程 MCP 服务器的 OAuth 登录通过需要 Kerberos（协商）身份验证的代理进行工作
  • 直接在子代理视图中显示权限提示、问题和确认，以便您无需离开即可回复
  • 保持终端控制序列后的文本在标签和输出中可见，并隐藏嵌入的图像数据
  • 在 /skills、/mcp 和 /plugin 中搜索匹配可见文本，而不是隐藏在终端转义序列中的单词
  • 切换 Copilot Fusion 配置文件时，从页脚和自定义状态行清除先前配置文件的路由模型
  • 防止@文件提及和/sandbox路径完成在快速输入时选择过时的建议
  • /sandbox Credentials 选项卡将屏蔽的环境变量与未屏蔽的建议分开计数
  • /resume 使用 —screen-reader 保持会话行对齐和列可见，并宣布一次未读状态
  • 显示换行的日语、中文和韩语文本的所有行，无需 clipping 最后一行或留下额外的空白行
  • 在文本选择拖动期间调整终端大小可保留 clipboard，而不是复制空行或未突出显示的文本
  • 当忽略工作目录上方的文件更改时，使@文件选择器保持最新
  • 当管理员策略禁用时，自动驾驶仪确认会隐藏辅助权限，并解释它们不可用的原因。
  • 保持 /config 视图选项卡和所选视图在窄终端上的屏幕阅读器模式下可读
  • 在 macOS 和 Linux 上退出 CLI 现在会停止附加的后台 shell，即使它们忽略终止信号也是如此。
  • 即使服务器打印堆栈跟踪，沙盒 MCP 启动错误也会识别拒绝的文件系统操作
  • /mcp 令牌计数排除 client 端工具搜索延迟的工具
  • 在隐藏或打开外部编辑器时保留新粘贴的文本，并防止在粘贴挂起时按 Ctrl+D 退出
  • 防止 # 问题和拉取请求选择器在快速输入时选择过时的结果
  • /plugin Details 显示没有用户范围标签的存储库本地插件，并将版本与描述分开
  • 工作区 MCP 服务器从其配置的目录级别解析相对工作目录，包括在 /cd 之后或从子目录启动时
  • /mcp delete 删除服务器而不重新启动其他连接的 MCP 服务器
  • 通过隐藏不适合的提示，保持会话侧边栏和 shell 快捷方式提示在狭窄终端中可读
  • 排队的 Copilot Fusion 路由配置文件更改会在当前回合结束时、下一个提示之前显示确认。
  • 保持 /diff 对大型未跟踪文件的响应，并通过目标路径而不是内容显示未跟踪的符号链接
  • HTML 导出和富文本副本保留用尖括号编写的通用类型和占位符，例如 Vec 和
  • 当设置时允许生成图像。json 为空或仅包含空格
  • 当区域列表具有焦点时，保持当前位置突出显示并在狭窄的/配置视图中向屏幕阅读器宣布。
  • 从注册表安装 MCP 服务器并将可选字段留空现在会保留服务器默认值，而不是保存占位符文本
  • 当自定义代理共享名称时，在 /subagents 中显示代理 ID，以便您可以了解您配置的代理
  • 粘贴彩色终端输出或控制字符时，将 /ask 和 /btw 问题标题保留为纯文本
  • 当 CLI 的主题更改时，在使用 Ctrl+G 打开的编辑器和使用 $ 打开的 shell 中保留终端自己的颜色
  • 当服务器已包含安装确认标志时，MCP 注册表安装会保留 npm 启动参数
  • 保持粘贴后立即输入的文本分开，以便粘贴的图像路径正确连接，并且长粘贴后的文本仍然可编辑
  • 保持 /config 视图选项卡完好无损，并且所选区域在窄终端上可见
  • 当 CLI 退出时，编辑器快捷方式保持不活动状态，使终端为 shell 做好准备
  • 在 /mcp 身份验证选择器中显示返回空身份验证质询的 MCP 服务器
  • 将文本粘贴到 Ctrl+R 历史搜索中会忽略转义序列，因此匹配、颜色和光标位置保持正确
  • 将彩色文本粘贴到 /plugin、/skills 和 /mcp 搜索中匹配可见文本并保留仪表板颜色
  • 表情符号在 /model 搜索中的光标下保持可读，长 /diff 搜索查询在一行上滚动
  • “会话”选项卡和 /resume 中的长搜索查询正确换行，并使光标与键入的文本对齐。

  • 当帐户查找受到速率限制时，保留 Copilot 模型访问权限
  • 在狭窄的终端中保持折叠失败 shell 行的完整退出状态，并在旁边显示尽可能多的命令描述

  • 从不回答的 GITHUB_ASKPASS 助手不再使启动停止超过五分钟；现在，一名助手超时后登录会失败
  • /code 将会话移交给 VS Code 后，在同一窗口中恢复该会话并切换回来不再会显示该会话在 VS Code 聊天中打开的通知
  • 在批准对话框中包装命令预览时，保留 Windows 驱动器号及其路径
  • 无法读取的config.json，例如带有额外右大括号的config.json或因写入中断而被缩短的config.json，在启动时不再被仅包含firstLaunchAt的文件替换；其 trusted 文件夹、插件、市场和其他保存的状态保留在文件中
  • MCP 启用/禁用和插件命令在设置时起作用。json 为空
  • 在会话启动时拒绝或关闭第一个连接（例如仍在启动时）的远程 MCP 服务器将按计划重试，而不是在会话的其余部分保持失败状态
  • 关闭 sidebar.hoverFocus 并打开 sidebar.showCloseButton 后，将鼠标移到会话侧边栏卡上不再将选择内容移到其上
  • 用鼠标复制答案会将空行保留在块引用内

  • 插件的plugin.json位置包含命名管道或设备链接（例如/dev/zero），当技能、提示或插件列表加载它时，该插件不再挂起或耗尽内存；该文件像不可读的清单一样被跳过
  • 当序列被分割到命令输出的两次读取时，Shell 工具结果不再保留终端转义序列或超链接目标，就像彩色输出大于一次读取时发生的情况一样
  • 在 /compact 之后，运行时不再使 CPU 核心忙碌直到下一个事件，并且会话的实时事件流不再跳过压缩删除早期事件后到达的事件
  • 对于辅助权限未经询问而批准的请求，permission_prompt 通知挂钩不再运行
  • 现在可以立即在 CLI 运行时添加或更改存储库的 GitHub 远程，因此 /pr 不再一直提示存储库未连接到 GitHub，直到 CLI 重新启动。
  • 当扩展加载失败时，其日志现在显示完整的错误报告，包括语法错误的文件和行、堆栈跟踪和任何原因，而不是单行。
  • 您所在会话的会话侧边栏行显示它在整个运行回合中工作，并且屏幕阅读器听到“工作状态”而不是“完成状态”
  • 选择“自动”后，页脚的上下文百分比和状态行的 displayed_context_limit 现在使用自动路由到的模型窗口，匹配 /context，而不是固定的 200,000 个标记
  • 当 cli-native.node 丢失时，独立的 CLI 现在会重新提取其缓存的包，而不是每次启动时都因找不到本机插件“cli-native”而失败
  • 会话文件系统 SQLite 提供程序提交但报告为 postCommitAmbigously 的工作流运行现在启动，而不是失败并留下无法取消或恢复的挂起运行
  • 在短终端上请求许多敏感环境变量的扩展提示现在将第一个列出的名称和其余名称的计数保留在屏幕上，而不是将每个名称滚动到视图之外
  • 当显示背景颜色时，CLI 的选择会复制内联代码和颜色样本，而无需装饰性填充
  • 来自多个 userPromptSubscribed 挂钩的上下文现在到达模型，而不仅仅是最后一个挂钩的上下文
  • 在政策指南和托管设置通知中显示组织支持链接
  • 索引搜索在重新启动后很快就可用，并且仅当索引可以提供搜索时才会出现其启用通知。
