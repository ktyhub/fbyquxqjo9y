copilot-cli v1.0.106

修订 发布时间2026年11月6日 来源github/copilot-cli 英文原文

2026-11-05

  • Rex 终端使用 Kitty 直接放置渲染内联图像。
  • 添加 /code 命令以在 VS Code 中打开当前会话
  • 将 Fusion 层设置添加到 copilot config。
  • 使 /settings 为所有用户打开统一的仪表板，并添加跨设置和本地资源的全局搜索。
  • 交互式 CLI 向支持终端报告程序状态，包括何时需要注意。
  • 为选择加入的本地会话添加选择加入会话管理工具和@提及
  • 添加 COPILOT_SESSION_CWD 用于启动和扩展 LSP 和本地 MCP 服务器配置
  • 当您的帐户可用时，将 GPT-6.1 Terra 添加为新型号下的可选型号
  • 添加沙箱扩展设置以在沙箱内运行扩展进程
  • 通过 OneAuth 添加用于 Entra 身份验证的 MATS 遥测，尊重 client 遥测选择退出。
  • 使用 Ctrl+U、Ctrl+K 或 Ctrl+W 从提示中删除的图像，或由调用的历史记录条目替换的图像，不再与消息一起发送，并且 Ctrl+S 可以在之后隐藏提示。
  • 包含 NEL、Unicode 行或段落分隔符的粘贴文本现在填充单独的提示行，并且粘贴的 DEL 和 C1 控制字符将被删除，而不是保留在提示中并从行末尾剪切字符。
  • 在copilot -p --plan中，代理不再被告知建议Shift+Tab离开计划模式，该模式仅在交互界面中起作用，而是被要求在回复中包含计划的要点。
  • 当Copilot任务服务没有响应时，copilot --resume <id>不再等待无输出且无结束；现在，任务查找会在 10 秒后放弃，并继续解析。
  • 沙盒 grep、rg 和 glob 现在报告 Windows 启动失败，而不是静默的不匹配结果
  • 模型选择器显示扁平、未定价和单层模型的上下文窗口大小
  • 沙盒本地 MCP 服务器尊重会话目录的相对文件系统权限，即使配置了不同的工作目录也是如此。
  • 当 CLI 安装在长目录路径中时，PowerShell 命令可在 Windows 上运行
  • 在其他会话繁忙时切换会话不再导致 CLI 崩溃并留下空白终端
  • 重试包含损坏图像的提示时，保留可读的图像附件
  • 当 Copilot CLI 预授权不可用时，MCP Entra 身份验证现在会回退到 VS Code 注册。
  • 沙盒本地 MCP 服务器现在在配置相对 cwd 时可以正确启动。
  • 在 Windows 上，嵌套 Git 目录中的沙盒会话可以更改为并写入存储库根目录
  • 在仅要求审查或分析的请求后，自动驾驶仪不再开始实施自己的建议
  • 当插件服务器保持不变时，抑制不必要的 MCP 重新加载摘要
  • 现在会重试 Copilot 服务在负载下以空 404 应答的模型请求，而不是以“执行失败：404”结束回合。
  • copilot help config 现在列出了设置目录提供的所有设置，包括手写文本中缺少的设置，例如 askUser、effortLevel、planModel、toolSearch 和 worktreeBaseRef
  • ACP clients 可以将使用 —yolo 启动的会话切换出自动驾驶仪，并且允许全部保持打开状态，而不是因策略阻止而导致切换失败，并再次尝试关闭允许全部。
  • 当键入不带点的查询时，@ 文件选择器现在会在带有 capital 点 I 的名称下划线，例如 stanbul.txt，并且不再缩短该行的匹配文件夹。
  • @ 文件选择器现在会在使用分解重音存储的名称或通过不带重音键入的查询找到的名称中的匹配下划线，并且不再缩短此类行的匹配文件夹。
  • 多行提示中的向上和向下在穿过较短的行时保留您开始的列，而不是将插入符号留在行的开头附近。
  • Ctrl+Y 和 /share Research 跳过不可读文件的研究文件夹条目，例如损坏的链接或命名为报告的文件夹，而不是失败或提供它们。
  • 当多个代理共享显示名称时，在 /agent 中显示每个代理的选择 ID。
  • 编辑工具现在在命名管道、套接字或设备上立即失败，而不是永远等待 FIFO 的另一端，这会导致轮流停止。
  • 空的 plan.md 不再显示 ctrl+y 计划提示或 Plan: yes 在 /session 中，并且 ctrl+y 打开研究报告，匹配 /session 计划。
  • 页脚通过首先缩短目录和分支，而不是将项目从行末尾切掉，从而在狭窄的终端上保持“N 计划”、沙箱、YOLO 和 CI 状态项目完整。
  • 拉取请求、问题和要点详细信息及其加载错误，不再让标题、名称、分支、要点文件或服务器消息中的转义序列重新设置终端的样式。
  • 恢复自动驾驶会话时显示保存的暂停目标和继续指导。
  • 当在前面选择另一个问题时，用 # 选择的问题和拉取请求不再从消息中删除，并且选择两次的问题将发送一次。
  • copilot help billing 现在表示页脚显示此会话中使用的 AI 积分（旧版计费平台上默认没有任何内容），并且 /statusline quota 项目默认关闭，ai-used 开启。
  • copilot help config 现在表示 copyOnSelect 在 macOS 上默认打开，/keep-alive 仅更改当前会话，logLevel 在 /settings 对话框或 settings.json 而不是 copilot config 中设置，trustedFolders 位于 config.json 中并由文件夹-trust 提示符填充。
  • copilot help environment 现在表示“快速”的 COPILOT_AUTO_TIER 值将被忽略并发出通知，而不是被拒绝，并且 USE_TGREP=true 不会覆盖索引搜索是否可用于您的帐户或 USE_BUILTIN_RIPGREP=false。
  • copilot help config、copilot help environment 和 copilot help acp 不再命名隐藏的 --prefer-version、--server 和 --stdio 选项。
  • copilot help limits 显示了实际最低 AI 信用限额的状态示例，并表示当剩余限额的 10% 或更少时会出现最终呼叫警告
  • copilot help monitoring 现在表示，仅当设置了 OTLP CA 证书或 client 证书/密钥变量时，http:// OTLP 端点才会禁用导出，而不是针对每个 http:// 端点。
  • copilot help permissions 现在记录 write(path) 和 read(path) 规则中的 glob 模式，列出 read 和 memory 类型，并解释无作用域的 write 规则批准 shell 输出重定向，但不批准命令本身；它不再说通配符匹配将来会出现。
  • copilot --help 和 copilot help --help 现在列出 acp 帮助主题，而 copilot help --help 不再使用杂散缩进打印其描述和主题列表。
  • 表单和设置文本字段显示存储值（例如 MCP 服务器命令）的控制字符，而不是让它们重新着色或隐藏其文本。
  • 主屏幕上的问题和拉取请求详细信息隐藏了描述中的 HTML 注释，就像 GitHub 所做的那样，而不是将模板说明打印为文本
  • 问题和拉取请求详细信息还隐藏了 <details> 或其他 HTML 块内的空行分割的 HTML 注释，而不是显示其开头及其文本。
  • 助理回复保留非 HTML 的尖括号单词，例如 Vec<String>、Set<T> 和 <file> 占位符，而不是默默地将它们从句子中删除。
  • 现在，在启用其中一个插件时，删除本地市场会被拒绝，—force 还会清除该插件，并且 /pluginmarketplaceremove 在名称之前接受 —force。
  • 当较早的文件待处理时发送的后续文件提及冒号后带有很长数字的文件时，不再因“提交失败”而被拒绝（@file:99999999999999999999）。
  • 当搜索或滚动隐藏第一个模型组时，模型选择器保留其上下文和推理列标签。
  • /model 选择器在窄于 64 列的终端中显示代币价格，并且点引导符在每个价格标签之后开始。
  • --no-ask-user 和 askUser 设置现在表示他们删除了 ask_user 问题表，并且代理仍然可以在回复中提出问题；他们不再说代理人停止提问。
  • /user 开关、环境和 /mcp 身份验证选择器、运行于：状态和传出连接列表不再允许名称、路径或 URL 中的转义序列重新设置终端样式。
  • alwaysApply: false 的插件规则现在不会出现提示，直到您在 /instructions 中启用它们为止；之前，每个会话都会应用它们，直到打开 /instructions 或 /plugins。
  • /pr 显示拉取请求的标题、标签和分支，因此诸如 Fix init.py 导出的标题不再丢失下划线并变为粗体。
  • /pr 将关闭或合并的草稿显示为“已关闭”或“已合并”，保留包含 | 的分支名称和标签完好无损，并将无法启动或正在等待操作的检查运行视为失败而不是挂起。
  • .github/hooks 下无法读取的存储库挂钩文件或其中无效的挂钩条目现在会在启动时和 /cd 进入存储库后与文件和原因一起报告，而不是默默地跳过。
  • /session delete --yes=false 和错误输入的 --yes=<value> 不再删除当前会话，并且 /session delete --local-only <id> 现在可以预览该会话。
  • 当您在同一 CLI 进程中返回会话时，已完成的 /ask 和 /btw 答案现在会重新出现。
  • 副驾驶技能删除和/技能删除现在会忘记已删除技能的禁用状态，因此以后以相同名称添加的技能不再开始禁用。
  • 当 --ui-server 无法启动其服务器（端口已在使用或超出范围）时，会话现在会显示原因，而不是在没有它的情况下静默启动
  • 工具返回图像或资源以外类型的二进制结果的会话可以再次恢复，而不是因“会话文件已损坏”而失败。
  • SDK 的 session.workspaces.updateMetadata 现在会重命名已有名称的会话，并且它和 session.name.set 都会拒绝会话创建所拒绝的名称。
  • 当服务器不发送字符集时，web_fetch 现在会在编码其 XML 声明名称时解码 XML 文档（RSS、Atom 或其他 XML），因此 ISO-8859-1 和其他非 UTF-8 源不再到达模型，其重音字符被替换。
  • 当 Claude 模型在启动工具调用后 declines 请求时，后备重试不再因不匹配的 tool_use 错误而失败，并保留其后备信用。
  • 终端安装程序会配置它找到的每个 Windows 终端设置文件，并正确检测现有的 Shift+Enter 绑定。
  • copilot login --device-code 现在拒绝明文 http:// 主机，就像浏览器登录已经做的那样：设备代码在那里交换为不记名令牌。请改用 https:// 主机。
  • 保持 Unicode 字符（如表情符号和补充符号）的 /diff 输出完整。
  • 当模型不返回答案文本时，快速问题现在会报告明确的错误。
  • 沙盒本地 MCP 服务器现在支持配置的 npm_config_cache，并且可以在启用开发工具访问时写入该缓存。
  • 允许 —continue 和 —resume 在恢复没有记录模型的会话时发送提示
  • 模型选择器通过单独预算每个模型的详细信息，留出更多选择空间
  • 仅当禁用 copyOnSelect 时才显示页脚的复制快捷方式提示
  • 即使同时发生插件刷新，也会在 /cd 之后显示 MCP 重新加载确认
  • 当没有服务器发生变化时，避免在启动期间出现错误的“MCP 服务器已重新加载”通知
  • 调整终端大小后彻底关闭模型选择器，而不留下过时的选择器文本
  • 会话重新同步后保持页脚模型显示为最新
  • 减少多个 MCP 服务器无响应时第一次提示的等待时间
  • 刷新设备列表时，在/语音设备中保持突出显示的麦克风处于选中状态
  • 在 /mcp 身份验证选择器中显示返回裸 HTTP 401 的远程 MCP 服务器，以便您可以登录
  • 现在通过信号停止 npm 安装的副驾驶会取消活动转弯并等待关闭，而不是让它继续运行
  • 即使同时发生插件刷新，也会在 /cd 之后显示 MCP 重新加载确认
  • 现在，当通过文字引用路径调用工具时，沙盒命令会授予预期的开发工具访问权限。
  • /chronicle 成本报告将每个新记录的模型调用计数一次，即使再次收到其使用事件也是如此
  • 恢复的会话保持 shell ID 唯一，以便 bash 工具调用针对正确的 shell
  • 当语言服务器将符号的子项报告为空时，lsp 工具的 documentSymbol 操作不再失败，丢失每个符号；该符号现在列出，没有子项
  • /tasks 详细信息视图显示分离 shell 任务运行时和完成后的最新输出
  • 当模型列表中缺少模型时（例如作为 HydraFusion 组成部分），MAI-Code-1.1-Flash 请求不再因 unsupported_api_for_model 而失败；他们现在使用 Responses API。
  • Windows 上的沙盒 Go 构建和测试跨命令重用构建缓存，以加快重复运行速度。
  • LSP 重命名在更改任何内容之前都会请求每个文件的写入权限，因此 declining 一个文件不会影响所有文件。它还不再损坏语言服务器多次列出的文件，将插入按顺序保留在同一位置，保留无效 UTF-8 的字节，并在跳过文件创建、重命名或删除时进行提示
  • Ctrl+V、Alt+V 和 Super+V 在未检测到附件时将 clipboard 文本粘贴到提示中
  • 无法检索模型目录的 HydraFusion 转向现在是这样说的，而不是归咎于允许的模型策略
  • 没有所需恢复工具的会话将继续自动压缩，而不是失败翻转。
  • 访问 Autopilot 会话后，返回交互式会话会保留待处理的问题，而不是自动回答
  • apply_patch 不再为其添加或删除的每个文件额外计算一行，因此时间线摘要、权限提示、/usage 和退出摘要显示真实的行数
  • 当错误类型的值进行设置时，copilot config 现在会发出警告。json 会被忽略，而不是将每个设置读取为未设置并报告写入该文件，就好像它们已生效一样
  • 删除提示中中文、日文或韩文字符前面的文本不会再使行出现乱码，直到下次编辑为止。
  • Markdown 输出不再将冒号分隔的文本（例如 file.ts:100:5 或 crate::id::Id）转换为表情符号。
  • 技能目录中的顶级 SKILL.md 现在会在 /skills 中生成警告，解释子目录是资源，而不是单独的技能，以及如何加载它们。
  • 当较早的消息仍在等待时，代理工作时发送的提及文件或目录 (@path) 的消息不再被拒绝并显示“提交失败”。
  • 一旦所有跟踪的会话完成工作，包括后台轮流和独立的本地 shell 命令，/keep-alive busy 就会释放睡眠预防功能
  • Git URL 缓存使用短路径并诊断路径长度故障。旧的缓存被复制，而不是移动，并为旧的 CLI 保留；不再需要时手动删除原件。
  • ACP 会话/提示和会话/取消仅停止活动回合，保持后台任务和 shell 命令运行
  • 现在，通过修剪历史推理并重试，可以从过大的请求中恢复长对话。
  • 在通过悬空符号链接进行工作区外访问之前进行提示
  • 倒回并重新提交提示现在会保留图像和文件附件。
  • 会话从不可用的程序端点恢复并继续回答提示
  • 技能调用会解释何时禁用模型调用，而不是将技能报告为未找到
  • /memory 现在报告何时通过实验禁用会话的内存，并澄清 /memory 的行为。
  • 当使用 -p --agent 选择的代理具有 Copilot 忽略的 frontmatter 键时，在 stderr 上发出警告，并记录每个代理文件的警告
  • 当保存的效率首选项不可用时，自动模式会回退到有效的默认值。
  • 当无法读取会话的 session.db 时，/fork 不再因“无法复制 fork 会话数据库”而失败；创建分叉时没有待办事项列表，并且失败的分叉不再留下半创建的会话目录。
  • 使用 UTF-8 字节顺序标记保存的挂钩配置文件（如 Windows PowerShell 5 和旧版记事本版本写入的那样）现在会加载，而不是仅通过日志条目跳过。
  • /share html 导出现在保留编号列表的第一个数字以及任务列表项的复选框和状态，并且这些导出和富文本副本都将文本保留在原始 HTML 块（例如
    ）内，而不是删除它。
  • /ide 将 IDE 和文件夹名称绘制为纯文本，每行一行，并在带有长工作区列表的屏幕或短终端上保留其标题、突出显示的行和关键提示。
  • 有关 LSP 配置文件中无效条目的警告现在会命名它所属的服务器，因此可以修复具有多个服务器的文件，而无需将其一分为二。
  • 对因服务器错误或连接断开而失败的 HTTP MCP 服务器的工具调用不再在原因前面显示内部 Rust 类型名称。
  • 现在会附加粘贴到以绝对路径（例如 /var/log/app.log）开头的消息中的图像或文件路径，而不是以纯文本形式发送。
  • copilot plugin uninstall 现在删除了一个插件，copilot plugin list 在其安装的文件丢失后仍然显示，而不是报告它未安装
  • 问题表单在预填充的默认答案中显示控制字符，而不是将其转义序列发送到终端。
  • 粘贴来自不同文件夹的共享文件名的两个图像或文档现在会附加两个图像或文档，而不是仅静默发送第二个图像或文档。
  • /tasks 对话框将每个任务绘制在一行上，因此任务描述中的换行符不再添加看起来像另一个任务的行，并且转义序列不再重新设计它的样式。
  • 现在，skillDirectories 设置中的 ~/ 条目会从您的主目录加载技能，而不是当前目录中名为 ~ 的文件夹。
  • 模型加载现在在无法访问的网络端点上失败得更快，并显示连接指南。
  • ACP 会话现在显示在会话历史记录、/chronicle 和 session_store_sql 结果中。
  • PowerShell 批准提示现在会解释何时需要对有效命令进行完整脚本审查。
  • 会话持久性失败现在显示一个错误和一个恢复通知，而不是每次重试时都重复。
  • copilot plugin install 现在报告它忽略的插件清单字段，而不是默默地安装没有技能的插件。
  • 当 PAC/WPAD 或系统代理解析失败时，CLI 会退回到直接网络。
