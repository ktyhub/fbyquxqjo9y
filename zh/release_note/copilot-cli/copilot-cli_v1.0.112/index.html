copilot-cli v1.0.112

修订 发布时间2026年11月13日 来源github/copilot-cli 英文原文

2026-11-13

  • 失败的/compact现在显示模型提供者的错误消息，没有内部主机重新抛出前缀
  • CLI 尚未发送的提示（例如仍在加载托管帐户策略时输入的提示）会保留其粘贴的文本，因此再次按 Enter 会发送粘贴内容，而不是文字 [粘贴 #N - M 行] 占位符
  • /plugin 管理器不再显示未加载为启用状态的存储库插件，并且当其源指向市场之外时，插件列表不再显示未找到其目录
  • copilot help sandbox 现在表示，在 macOS 上，沙箱主机规则会阻止与本地端口的直接 TCP 连接，例如构建 client 到达其守护进程； localhost 仅可通过本地代理（如 HTTP 或来自代理感知 client 的 CONNECT 隧道）保持可达
  • copilot workflow run --help 现在在登录中列出了一个 Microsoft 365 帐户，该帐户可以在退出 GitHub 时运行工作流，以及基于使用情况的计费和自定义模型提供商 (BYOK)
  • /subagents 模型选择器为同一代理重新打开，并在从会话切换回来后接受输入
  • 在狭窄终端的 /subagents 设置中保持开/关状态和模型选择器箭头可见
  • 打开子代理的视图不再将转义序列或控制字符从其任务提示写入终端
  • /copy 在粘贴到 Word、Outlook 或 Teams 时保持其格式，并将多消息响应的每条消息保留为其自己的段落、表格、列表或引用
  • 模型切换提示保留在引发它们的会话中，并在您返回该会话时重新出现
  • /settings 列表项在 20 列宽或更窄的终端上键入或查看保存的值时显示每个字符
  • 当终端变短然后再次变高后，屏幕底部的权限提示和其他对话框不再保持向下滚动状态，因此扩展环境变量提示会显示它列出的变量名称
  • /feedback 当附加日志路径未向反馈包贡献任何文件时发出警告
  • 表情符号和其他 Unicode 字符在“问题”和“拉取请求”选项卡中的搜索光标下正确显示
  • 在 /sandbox 中正确截断和对齐包含表情符号或 CJK 字符的路径和变量名称
  • 当 clicked 在消息、shell 命令和 shell 输出中时，带有平衡括号的链接现在会打开完整的 URL
  • 会话限制对话框保留在其会话中，当您切换时，其他会话可以自由打字。
  • copilot mcp get 正确报告未配置的服务器名称，例如在文本和 JSON 输出中找不到的 toString
  • 当 CLI 退出时，会话侧边栏操作不再创建或切换会话，从而保持退出摘要的恢复命令有效
  • /settings 中的文本和数字编辑器使键入的值在狭窄终端的对话框内可见。
  • 工具预览保持表情符号完整，以纯文本形式显示 SQL 和代理消息，并将内存投票预览保持在一行
  • @ 文件选择器保持表情符号和重音字符完整，并在狭窄终端中缩短路径时保留 @ 前缀
  • /lsp 日志错误摘要适合可用宽度而不拆分表情符号，并且服务器消息显示为纯文本
  • 在 /environments 添加连接对话框中使用 j/k 或 Ctrl+N/Ctrl+P 后，箭头键和 Tab 会跟随突出显示的操作
  • 在 Vim 模式下粘贴后立即按 Esc 或 Ctrl+C 时，粘贴的文本会保持在正确的位置
  • 当排队命令打开对话框（例如 /login）时，保持“会话”选项卡响应
  • Ctrl+C 可靠地取消新排队的提示，而不运行它们或显示提交失败。
  • 在启动时取消会话选择器时显示欢迎标题和入门框。
  • 在启动时准备组织所需的插件，避免重复安装和重复的成功或失败通知
  • 工具权限提示使标题和所选答案在短终端中可见，并使用 PgUp/PgDn 滚动命令或文件详细信息
  • MCP 系统提示评论显示纯文本，不允许终端控件重新样式、链接或隐藏内容
  • /plugin 清除市场更新标记，并在重新检查确认没有可用更新时进行计数
  • 提示模式下的 Untrusted 文件夹警告现在可以识别父目录中跳过的工作区 MCP 配置以及 trust 的文件夹以加载它
  • copilot help environment 再次记录 COPILOT_MCP_TOOL_CACHE，该变量关闭每个服务器的 MCP 工具快照缓存
  • 时间线中的代理、代码搜索和 IDE 工具行将模型和 IDE 编写的文本显示为纯文本，而不是将其转义序列和控制字符传递到终端
  • /model plan 现在拒绝额外的参数，而不是在没有它们的情况下保存或清除计划模型，并读取 PLAN 和 —plan plan 作为计划关键字
  • 时间线中的问题行在等待答案时、decline 之后以及 Autopilot 回答时显示问题文本。
  • 恢复会话时，将之前使用的 AI 积分计入会话限制
  • 尊重 /diff 中未跟踪文件的 .gitattributes 二进制设置，并将其内容从添加的行计数中排除
  • 仅显示参数错误使用行中的相关选项，而不是列出每个 CLI 选项
  • 粘贴到 @ 或 # 提及并立即按 Enter、Tab 或 Ctrl+Y 不再从以前的结果中选择文件或问题
  • 当列表比终端高时，保持突出显示的代理在 /agent 中可见
  • 在 /env 中显示包含 Markdown 字符的类似 URL 的名称，不带杂散反斜杠
  • 当 /pr 修复冲突或 /pr 全部修复打开合并策略选择器时，让您的指令在聊天和会话历史记录中可见
  • 当由于文件夹不是 trust 而跳过工作区 MCP 配置时，MCP 检查命令会发出警告，并解释如何对其进行 trust
  • 当设备策略禁用 —yolo 或 —allow-all 标志时，在提示模式警告中显示您组织的支持链接
  • 会话选择器解释何时 —connect 无法找到远程会话或任务，或者何时查找失败
  • 从包含 @ 的存储库路径安装插件，包括范围包目录
  • 保持 /diff 搜索光标在狭窄终端中可见，并在空间允许时显示匹配计数
  • 在 Copilot 问题和 MCP 表格中浏览长列表时，保持突出显示的选项可见。
  • 当 CLI 退出时打开“会话”选项卡或侧边栏可保持屏幕可见，而不是使其空白
  • 即使在狭窄的终端中，也可以在“会话”选项卡中的截断会话名称上保持省略号可见
  • 当文件夹或分支名称包含中文、日语或韩语等宽字符时，保持页脚路径、分支名称和状态文本正确匹配。
  • /tasks 包括恢复会话后子代理后续运行时间
  • 在会话侧边栏打开的情况下快速运行 /exit 或 /quit 两次可退出 CLI，而不是留下空白、无响应的终端
  • 从全屏视图（例如 /help 或 /environments）返回时，保持目标面板待办事项计数准确
  • 在窄终端上将 /settings 记录编辑器和键入的键保留在对话框内
  • 对于无法找到文件夹的已禁用本地市场插件，隐藏 /plugin 中不可用的更新操作
  • 显示 MCP 服务器在活动轮次期间将排队保存为状态消息而不是错误
  • 当突出显示的对话文本的颜色与选择、搜索匹配或悬停的行背景匹配时，保持突出显示的对话文本可读
  • 在启用和禁用对话框中缩短时，包含表情符号的长插件文件夹路径可以正确显示
  • 回复中的 Markdown 表适合狭窄的终端，无需跨行分割边框和行
  • /env 不再列出已加载的 /instructions 中禁用的指令文件
  • 当 Autopilot 目标和子代理描述的文本包含终端转义序列时，保持其可读性
  • 使用 /settings 更改 editorMode 在切换 /vim 后立即生效
  • 当折叠的读取、创建和编辑行换行在狭窄的终端中时，显示完整的文件名
  • 保持 /search 匹配计数在长查询旁边和狭窄终端中可读
  • 在会话侧边栏打开的情况下调整终端大小时 /help 表保持正确对齐
  • 保持突出显示的权限提示答案和键入的回复在狭窄的终端上可读
  • 在重新扫描没有搜索匹配的提供商后，保持 /model 选择器的详细信息和键盘提示正确显示
  • 当切换回在后台重试的会话时，在回复或最终错误上方保留重试通知
  • 当您在代理工作时发送或排队提示时，用 # 选择的问题和拉取请求包括其详细信息
  • 从 INSERT 模式发送或排队提示后，保持 Vim 撤消和重复命令的范围为当前草稿
  • 当按左键两次打开会话侧边栏时，在扩大狭窄的终端后保持提示响应
  • 加载后在 /mcp auth 中显示完整的服务器列表和键盘提示
  • 在具有长单行输出的折叠失败 Shell 行中保持命令描述和退出状态可见
  • 当您的组织的策略禁用 MCP 服务器时，内置 GitHub MCP 服务器不再可用
  • 子代理现在尊重使用 —max-ai-credits 设置的会话范围 AI 信用限额

  • copilot mcp remove 和 /mcp delete 现在表示通过 --additional-mcp-config 传递的服务器来自该选项并且无法删除，而不是调用它未找到或内置服务器。
  • /subagents 在设置菜单中按 Esc 后将光标保留在您刚刚配置的子代理上，因此 Space 不再关闭不同的子代理
  • 屏幕阅读器模式在窄终端上正确命名当前 /config 部分
  • 粘贴到 /plugin、/skills 和 /mcp 搜索中会保留光标后的文本，即使粘贴以不完整的转义序列结束也是如此
  • 在斜杠命令后粘贴、键入、使用 Ctrl+G 编辑或从历史记录中调用时，提示文本会完全显示并正确处理换行符。

  • 键盘导航和提示中的单词删除保持图像附件和粘贴文本标签完好无损
