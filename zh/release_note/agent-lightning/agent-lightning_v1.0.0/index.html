agent-lightning v1.0.0

大版本 发布时间2026年8月17日 来源microsoft/agent-lightning 英文原文

agent-lightning v1.0.0

变更流程图

亮点

  • 无需埋点即可使用真实 agent 框架 — 把模型调用经由 Agent Lightning v1.0 代理路由，无需修改已部署的 agent 即可收集训练数据。这保留了你进行真实 RL 训练所需的工具、上下文、控制流和环境行为，而不是针对一个简化过的框架做优化。
  • 彻底重构、API 面更小 — 代码库缩减到约 3,500 行。这让库更易审计和采用，但要把 v1.0 当作一次重大升级：在从 0.x 迁出之前，重新验证集成以及任何直接导入内部结构的用法是否适配新架构。
  • 原生 Kubernetes 执行 — agent 可以直接作为 Kubernetes Job 运行，不再依赖外部沙箱服务。把这条执行路径纳入训练基础设施时，要规划好 job 级资源限制、可观测性和清理。
  • 可复现的编码 agent RL 流水线 — 发布的端到端示例只用 6K 样本训练 Qwen3.5-9B，就把 SWE-bench Verified 从 41.8% 提升到 56.4%（+14.6 个百分点）。它包含数据清洗、奖励作弊预防和训练脚本，给团队提供了一个可直接改造的具体基线，而不用从零搭流程。

发布说明中未记录破坏性变更。

Agent Lightning v1.0.0 发布！本版本中我们彻底重构了代码库，在保持轻量的同时加入了对最新模型的支持。Agent Lightning v1.0.0 面向 RL 训练，使用与部署时完全一致的 agent 框架，并解决了该范式中的几个关键挑战。

亮点

  • 🪶 约 3,500 行代码： 我们把简洁当作第一原则。
  • 🧩 用真实 agent 框架训练： agent 通过 Agent Lightning v1.0 代理与模型交互，零改动，同时把工具、上下文、控制流和环境都留在回路中。
  • ☸️ 原生 Kubernetes 支持： 直接以 Kubernetes Job 运行 agent，无需依赖外部沙箱服务。
  • 💻 完整的编码 agent 训练示例： 仅用 6K 训练样本，端到端 Qwen3.5-9B 流程就把 SWE-bench Verified 从 41.8% 提升到 56.4%，提升 14.6 个百分点。我们发布了完整流程，包括数据清洗、奖励作弊预防和训练脚本。
