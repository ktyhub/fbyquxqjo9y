feign 13.18

这个项目是干啥的：一个 Java 声明式 HTTP 客户端，写个接口就能调用别的 REST 服务，给做微服务间接口调用的后端开发用。

变更架构图

亮点

  • 新的编解码器与客户端选项 — 新增面向 JDK Simple JSON API（JEP 540）的 feign-jdk-json 编解码器（#3620）；feign-kotlin 新增非阻塞 WebClient AsyncClient，并改进了协程支持（#3645）；还加入了可选启用的目标主机/端口观测标签（#3546）和 feign-mock 中的子集请求头匹配（#3661）。如果你想要 JDK 原生 JSON 编解码器或非阻塞 Kotlin 客户端，值得升级；否则这些只是增量增强，不构成单独的升级理由。

  • URI/查询/请求头构造变更（行为相关） — 一组正确性修复改变了 Feign 实际发出的请求：静态字段不再进入字段查询映射（#3613）；运行时 HeaderMap 值按字面量处理（#3612）；保留字面量查询值并展开数组参数（#3624）；对未转义值遵循保留字符标志（#3627）；修复 URI 片段与转义（#3633）；@Param 展开器现在作用于 QueryMap 的 POJO 字段和 getter（#3658）；HTTP URI scheme 识别改为大小写不敏感（#3665）。字符集处理也收紧了：响应 Content-Type 的字符集在其他参数之后读取（#3628），FormEncoder 支持解析带引号和大小写混合的字符集（#3611、#3674）。这些是 bug 修复，但可能改变生成的请求和解码后的请求体；升级前请对请求/响应格式做回归测试。

  • Java 11 客户端超时与请求头保真 — 响应体超时现在会真正生效（#3462）；为零的连接/读取超时会被遵循而不是被忽略（#3637）；响应头的值顺序和重复项会被保留（#3638）。这可能在慢速流上暴露新的超时异常，并改变 0 超时设置的语义——请核对你 Java11 客户端的超时配置。

  • HTTP 韧性修复 — 恢复 Apache HTTP4 对无请求体的幂等请求的重试（#3634）；当委托方抛出 Error 时，异步客户端的 future 现在会完成（#3630）；HttpCacheInterceptor 跳过 private 和 Vary: * 响应（#3610）；当分块请求体未被完整读取时，DefaultClient 会复用 keep-alive 连接（#3673）。如果你依赖重试行为、异步错误传播或缓存语义，这些修复与你相关。

  • 依赖刷新、无破坏性变更、升级指引 — 大批 Dependabot 升级，包括 Jackson 2.22.3→2.22.4 与 3.2.3→3.2.4、Spring Boot 4.1.1→4.1.2、Spring 7.0.9→7.0.10、okhttp 5.5.0→5.5.1、gson 2.14.0→2.15.0、guava 33.7.2-jre→33.8.0-jre、netty 4.2.18.Final→4.2.20.Final、httpclient5 5.6.4→5.6.5，以及 Kotlin 2.4.20→2.4.21。没有破坏性变更或迁移步骤，也不是空操作/重新打标签；纯文档改动只有拼写修复（#3659）和 Logger 说明澄清（#3544）。为了编解码/超时正确性和新模块建议升级；如果你锁定了特定依赖集，或依赖此前请求构造的行为，则可以跳过。
