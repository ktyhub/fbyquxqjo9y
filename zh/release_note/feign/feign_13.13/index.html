feign 13.13

这个项目是干啥的：一个 Java 声明式 HTTP 客户端，写个接口就能调用别的 REST 服务，给做微服务间接口调用的后端开发用。

变更架构图

亮点

  • 安全加固（升级的主要动因） — PR #3395 修复了三个具体的失效场景：Content-Length 请求走私、日志格式化字符串注入，以及高负载下公共线程池饥饿。任何让 Feign 客户端面对不可信输入或高并发的场景，都应把 13.13 当作安全补丁而非例行升级。
  • 新的扩展面 — 新增 MethodInterceptor 扩展点以及 feign-validation 和 feign-http-cache 模块（PR #3346）；Metrics5Capability 现在接受自定义标签（PR #3320）；RequestTemplate 暴露了 uriTemplate（PR #3393，issue #2998）。feign-bom 升级为真正的模块并自动部署到 Central（PR #3384），因此基于 BOM 的依赖管理现在会一致地发布。
  • 行为类 bug 修复 — 关闭日志时，Slf4jLogger/JavaLogger 不再返回未缓冲的响应（PR #3172）；Apache HttpClient 的受检异常现在会触发 ErrorDecoder（PR #3338，issue #1487）；UNWRAP 只解包已声明的受检原因（PR #3359）；非 FeignException 错误也会开启/停止观测 scope（PR #3407）；数值型 Retry-After 增加了 long 溢出保护（PR #3405）；dismiss404 现在从 CoroutineFeign 构建器传递到 AsyncFeign（PR #3371）；修复了静态默认异步执行器导致的 ClassLoader 泄漏（PR #3394）。Micrometer 指标也补充了文档（PR #3370）。
  • 破坏性变更/迁移——13.x 中没有 — Request.Body 流式 API 的破坏性变更已被回退并推迟到 14.x（PR #3409），损坏的 Request.create 重载移除也已修复（PR #3406）。因此从 13.12 升级无需迁移步骤；一长串 Dependabot 升级只影响构建/测试期，不改变运行时 API。
  • 谁该升级 — 对安全和并发敏感的用户，以及需要新校验/缓存模块或日志、指标、观测、ErrorDecoder 修复的用户，应升级到 13.13。稳定运行在 13.12、没有不可信输入且用不到新模块的团队可以放心跳过。
