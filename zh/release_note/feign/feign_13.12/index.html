feign 13.12

这个项目是干啥的：一个 Java 声明式 HTTP 客户端，写个接口就能调用别的 REST 服务，给做微服务间接口调用的后端开发用。

变更架构图

亮点

  • 表单编码 — UrlencodedFormContentProcessor 现在在键值对中支持 CollectionFormats（#3286）。如果你的客户端会序列化集合值的表单字段，并且需要特定格式的编码行为，建议升级。
  • GraphQL 弃用元数据 — graphql-apt 现在会遵循 @deprecated schema 指令，同时保留类/方法上的覆盖配置（#3315）。对需要反映 schema 弃用状态的生成 GraphQL 类型很重要。
  • 依赖更新 — 本版本还包含运行时和构建依赖的补丁/小版本更新，涉及 Jackson、Netty、Spring Boot、Micrometer、Reactor 和 Guava。这些是配套维护改动，不算独立特性。
  • 升级指引 — 未宣布破坏性变更或迁移步骤。使用 feign-form 或 feign-graphql-apt 的用户应升级并验证受影响的序列化/生成路径；两个模块都不用的用户可以合理跳过。

发生了什么变化

  • feat(form)：增强UrlencodedFormContentProcessor以支持https://github.com/OpenFeign/feign/pull/3286中@yvasylev的键值对中的`CollectionFormats`
  • feat(graphql-apt)：在 https://github.com/OpenFeign/feign/pull/3315 中使用 @velo 覆盖的类/方法来尊重 @deprecated 模式指令
