feign 14.0-alpha1

大版本 发布时间2026年11月10日 来源OpenFeign/feign 英文原文

feign 14.0-alpha1

这个项目是干啥的：一个 Java 声明式 HTTP 客户端，写个接口就能调用别的 REST 服务，给做微服务间接口调用的后端开发用。

变更架构图

亮点

  • 破坏性预发布版本 — 14.0-alpha1 是一个 API 破坏性的预发布版本，不是常规升级。Request、Request.Options 和 MethodMetadata 现在不可变；修改它们的代码必须重构。采用前请先阅读 MIGRATION-v14.md。
  • 模块与 Java 变更 — 破坏性： feign-core 拆分为 feign-api + feign-core，需要更新依赖，可能还要调整 import。最低 Java 版本提升为 11，因此 Java 8 项目无法升级。
  • 流式请求体 — Request.Body 已支持流式处理，DefaultEncoder 支持流式请求体，并新增了流式解码器支持。这对大载荷或不适合缓冲的载荷很重要，但会改变请求体处理语义，建议做集成测试。
  • 其他修复 — multipart 部件的请求头现在会转义 CRLF 和引号，避免生成畸形或可能被注入的请求头。修复了 Windows 下删除日志文件时被锁定的问题。Http2ClientTest 的改动只是移除了测试对真实网络的依赖，并不改善运行时行为。
  • 升级决策 — 如果你需要流式能力，或正在为 v14 迁移做准备，可以评估这个 alpha 版本。它也包含 13.18 的所有修复。运行在 13.x 的生产用户除非需要这些修复，否则可以跳过；低于 Java 11 或追求 API 稳定性的团队应继续留在 13.x。

[!WARNING] 预发布版本。 14.0 是 API 破坏性分支：流式请求与响应体、feign-core 拆分为 feign-api + feign-core、Java 11 基线，以及不可变的 Request/Request.Options/MethodMetadata。升级前请阅读迁移指南。同时包含 13.18 发布的所有修复。

[!警告] 预发布。 14.0 是 API 的突破线：流式传输请求和响应主体，feign-core 分为 feign-api + feign-core、Java 11 基线和不可变的 Request/Request.Options/MethodMetadata。升级前请阅读迁移指南。还包括 13.18 中发布的每个修复。

发生了什么变化

  • 壮举！：@yvasylev 在 https://github.com/OpenFeign/feign/pull/3360 中使 feign.Request.Body 流媒体就绪
  • 重构：将 feign-core 拆分为 feign-api 和 @velo 在 https://github.com/OpenFeign/feign/pull/3383 中的 feign-core
  • 壮举：在 DefaultEncoder 中添加对 DefaultEncoder 中请求主体的流支持，作者为 https://github.com/OpenFeign/feign/pull/3396 中的 @yvasylev
  • 壮举：将最低 Java 版本提高到 11 并应用 @velo 在 https://github.com/OpenFeign/feign/pull/3397 中的 OpenRewrite 最佳实践
  • 在 https://github.com/OpenFeign/feign/pull/3418 中 @alhudz 转义流式多部分部分标头中的 crlf 和引号
  • 如果日志文件仍处于锁定状态，Windows 会阻止删除文件夹。 https://github.com/OpenFeign/feign/pull/3493 有 @trumpetinc 的作品
  • 阻止 Http2ClientTest 通过 @arimu1 在 https://github.com/OpenFeign/feign/pull/3503 中调用实时 nghttp2.org
  • @trumpetinc 在 https://github.com/OpenFeign/feign/pull/3551 中支持流媒体解码器2
  • 通过 @velo 在 https://github.com/OpenFeign/feign/pull/3677 中使 v14 的共享运行时状态不可变

  • @trumpetinc 在 https://github.com/OpenFeign/feign/pull/3493 中做出了第一个贡献
