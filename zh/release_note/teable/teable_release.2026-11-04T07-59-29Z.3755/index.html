teable release.2026-11-04T07-59-29Z.3755

功能更新

  • 例程现在以其所有者身份运行，生成的工件和运行的对话都属于这些所有者。发布、激活或运行非活动例程可能会将所有权转移给执行该操作的用户；沙箱资源、凭证和配额仍受例程约束。
  • 具有读取访问权限的例程成员可以查看正在运行的对话，但只有当前所有者可以继续、停止、重命名或存档它们。当所有权发生变化时，以前的和新的所有者都会收到通知。

错误修复和改进

  • 发送第一条消息后，新对话立即出现在侧边栏中并获得焦点，更新为其分配的名称时不会出现两次，并且在页面导航期间保持可见。
  • 个人访问令牌页面上的标题、操作按钮和表格列现在在滚动时保持正确的位置。选项卡间距和移动滚动体验也得到了改进。
  • 现在，滚动平台列表时，Scraper 子菜单会自动关闭，从而防止浮动菜单脱离其原始位置或定位不正确。
  • 工件卡现在具有更一致的加载占位符、更清晰的元数据放置以及改进的菜单和共享指示器。
  • 修复了阻止具有适当访问权限的用户打开例程创建的工件的问题。
  • 改进了批量记录更新性能，特别是涉及多个字段的大规模更新，同时保留响应完整性、字段和记录顺序、权限、撤消、回滚和 API 兼容性。
  • 修复了通过 GitHub 推送导入包含命名查询的 App Builder 项目时的问题：过时的自动生成的查询文件现在已刷新并同步回 GitHub。手动修改的自动生成的文件仍然会被拒绝。
  • 更改或删除应用程序的自定义域现在会释放以前的域，因此可以将其分配给另一个应用程序而不会出现冲突错误。
