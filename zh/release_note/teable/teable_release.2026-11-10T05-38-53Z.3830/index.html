teable release.2026-11-10T05-38-53Z.3830

功能更新

  • 基于过滤器的更新将相同的值应用于所有匹配的记录，并在更新运行时评估过滤条件。还需要更改关系的更新必须仍然使用基于记录的更新。
  • 现在可以通过应用程序或项目名称或 ID 搜索 JWT 凭据。批量操作仅限于与当前搜索和过滤器匹配的应用程序。
  • 已发布的应用程序现在可以使用新凭据进行刷新，同时保留其上次发布的代码和登录配置。现在，具有过期生产凭据的应用程序将与刷新失败的应用程序区分开来。
  • 默认 Pi 会话现在支持记录列表、聚合和基于时间的分组的结构化查询。后续请求可以调整查询参数，不支持的请求返回更清晰的错误消息。

错误修复和改进

  • 密码更改现在会拒绝与当前密码匹配的新密码，从而防止误导性的成功消息和不必要的注销。
  • 刷新聊天页面不再恢复因角色权限更新而隐藏的表的选项卡，从而防止错误的资源访问限制和“表已删除”消息。
  • 锁定的网格视图现在可以防止列拖动、列大小调整和列冻结。个人观点仍然可编辑。
  • 新安装的模板启用的自动化现在可以正确激活计划的触发器和电子邮件接收触发器。
  • 修复了以小写“rec”开头的粘贴文本（例如“recipe”或“record”）在单行文本字段中错误保存的问题。大批量和流式粘贴操作现在也可以一致地保留文本；以前损坏的值不会自动恢复。
  • 提高了凭证设置、管理、共享和永久删除的安全性和可靠性。
  • 改进了资源标题栏、工具栏标签和视图列表，使操作和当前、加星标、锁定和可拖动状态更容易区分。
  • 共享和 CSV 导出操作现在适用于选定的视图而不是当前打开的视图，包括从经典视图选项卡启动的操作。
  • 整合了应用程序设置操作并改进了登录配置、GitHub 集成和版本历史记录的菜单行为。
  • 修复了创建、转换、更改链接目标或删除双向链接记录字段时丢失的视图信息。相互链接的字段现在保持一致的可见性和排序，并提高了自链接、链接表和撤消/重做的可靠性。
  • 隐藏和可见字段面板现在支持可靠的拖放重新排序，刷新后保留顺序。修复了在视图信息加载完成之前对网格和看板视图中的字段重新排序而导致的崩溃。
