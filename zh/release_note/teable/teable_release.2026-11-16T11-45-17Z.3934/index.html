teable release.2026-11-16T11-45-17Z.3934

发布 发布时间2026年11月17日 来源teableio/teable 英文原文

teable release.2026-11-16T11-45-17Z.3934

功能更新

  • 在顶部应用程序栏中为编辑者添加了“添加登录”操作，以便在设置之前和之后直接访问登录配置。
  • 现在可以在实时模式下直接从预览地址栏打开已发布的应用程序。
  • Teable CLI 现在支持通过团队可访问的链接共享生成的报告。
  • AI 字段和导入 CLI 命令现在分别分组在字段和导入下。 field ai-status —poll 命令在读取生成的值之前等待处理完成。一个版本仍将支持旧命令名称并显示警告。
  • Airtable 和 Google Sheets CLI 导入现在可以在后台运行并使用任务 ID 恢复。重试重用正在进行或最近完成的导入以避免创建重复的数据库；命令在处理继续时提供恢复指令。
  • 添加了 teable 应用程序架构命令，并带有可选的 —check 标志来刷新本地架构和 teable.md。应用程序推送现在会警告远程架构更改，并在发生冲突时拉取报告这些更改，而不会覆盖本地文件。
  • 添加了 teable 应用登录命令，可通过一小时的开发会话以当前 Teable 用户或指定应用用户的身份打开本地开发的应用。
  • 模板提交工作流程现在会检查潜在敏感的示例内容，并允许将有意保留的示例标记为安全。删除模板项目还会取消发布模板并删除待提交的提交及其试用副本。
  • 结构化查询现在支持 DISTINCT 从所选结果中删除重复项，同时提供准确的总计和一致的分页。不允许按所选输出之外的字段进行排序。
  • 结构化查询现在支持根级any 和none 过滤器来检查是否存在可访问的链接记录，并支持API、MCP、生成的clients 和CLI。
  • 当用户添加记录时，模板加入现在可以完成相应的步骤，并将模板安装程序从邀请相关步骤中排除。
  • 报告和图表请求现在默认创建轻量级的单页工件，而不是启动完整的应用程序。

错误修复和改进

  • 移动应用程序现在需要在关闭活动的应用程序生成器沙箱之前进行确认，这会中断所有正在进行的任务。此举会等待沙箱成功关闭，为安全重试提供明确的失败消息，并防止沙箱在原始项目下重复使用。
  • 修复了共享表单中的链接记录过滤，因此当过滤器值不完整、字段已被删除或条件引用其他字段时，有效选项仍然可用。
  • 改进搜索一致性：隐藏全局搜索范围之外的字段不再刷新结果；当找不到匹配项时，角色资源搜索不再显示不相关的文件夹或表。
  • 修复了对话框中下拉菜单和菜单的滚动问题，以便在添加记录时可以访问所有单选选项。
  • 新创建的表记录现在在侧面板中打开，在面板关闭时保留草稿，并在打开多个面板时保持当前记录面板可见。
  • AI 生成的自动化脚本现在在其配置中包含所需的帐户连接。模板可以更准确地识别所需的外部帐户，提示用户连接它们，并在连接可用之前保持相关自动化处于禁用状态。
  • 新生成的附件缩略图使用 WebP 来减少下载大小并提高加载速度。附件视图使用适当大小的缩略图，避免重复请求，并更可靠地处理超宽图像。现有缩略图保留其原始格式。
  • 改进了对缓慢或中断连接的实时更新，包括可靠地交付完成和错误状态更新。
  • 改进了大型操作的分组撤消可靠性，并保留了对早期版本中合格撤消历史记录的访问。
  • 改进了生成的应用程序会话、应用程序生成器、机器人、链接记录字段和出站请求的安全性和访问控制可靠性。
  • 现在协调并发应用程序文件保存，以防止间歇性错误和丢失更改。克隆项目包括成功保存的文件，版本冲突返回可重试的 HTTP 409 响应，回滚使用相同的可靠保存机制。
  • 应用程序生成器现在直接打开所选应用程序的聊天，切换应用程序时对话会自动切换。移动用户现在可以正确关闭聊天。
  • 长时间运行的自动化节点测试现在在请求超时后继续，并在完成后提供结果。重复的请求重用现有的运行以避免重复的副作用。
  • 改进了受限角色的记录计数和现场统计可靠性。隐藏字段不再导致整个统计请求失败。
  • 在共享项目中打开无效表格链接的匿名用户现在会被重定向到可访问的表格，显示一次性通知，并给出刷新后保持干净的更正 URL。
  • 修复了仅通过部门成员身份获得项目访问权限（包括通过子部门成员身份继承的访问权限）的用户的错误和缺少实时更新。
  • 修复了预览确认流程，因此取消登录不再过早关闭对话框，并且登录失败消息仍然可见。
  • 修复了本地签出代码中的 Teable、Google 和 SSO 登录流程，以便用户在登录后返回本地主机应用程序，而不是托管预览。
  • 应用程序入门标记现在在编辑器控件遮盖它们时重新定位，从而在不更改不受影响的布局的情况下保持入门操作可访问。
  • 提高了网格更新期间、临时行以及按 ID 粘贴工作流程中的粘贴可靠性，同时保留权限和字段行为。
  • 记录标题、clipboard 内容以及过滤器和分组值的统一格式，使日期、时区、数字、公式、查找和空值更加一致。当显示值未更改时，人工智能自动填充还可以避免不必要的运行。
  • 改进了使用 onnxruntime-node 的应用程序在中国的 App Builder 预览和发布可靠性。
  • 帐户导出现在包括已准备好的表格，并且可以清楚地识别跳过的表格。不完整的导出会阻止永久帐户删除；失败的导出会干净地停止，不会生成损坏的档案或发送成功通知。
  • 当 ids 参数格式错误时，批处理表快照请求现在会返回清晰的 HTTP 400 响应。 API clients 必须以数组形式提供 ids。
