teable release.2026-11-13T02-21-01Z.3890

功能更新

  • 记录搜索现在支持多个字段、空格分隔的关键字以及短语、所有术语和精确匹配模式。
  • 应用程序构建者可以以选定用户的身份预览应用程序，无需登录代码最多一小时。登录设置现在提供了一个紧凑的用户选择器，可以禁用被域规则阻止的用户，并让构建者直接结束预览。
  • 模板现在支持交互式入门指南，可保存跨会话的进度、自动完成检查、上下文链接、AI 帮助和符合条件的手动步骤。创作者可以使用人工智能起草指南，并在发布之前在副本中进行尝试。
  • 结构化查询现在支持基于公式的指标、每个指标过滤器和聚合级别过滤。查询表达式使用与公式字段相同的公式语法，取代了之前的 v3 仅查询表达式语法； v1 和 v2 格式保持不变。
  • 凭证管理现在支持按应用程序或项目名称或 ID 进行不区分大小写的搜索，批量操作仅限于匹配结果。
  • CLI 命令现在将 AI 现场操作分组到“字段”下，将导入分组到“导入”下。新字段 ai-status —poll 命令等待 AI 填充一个或多个字段完成。旧版独立命令仍与此版本兼容，但已弃用，并将在发布后删除。
  • 资源窗格选项卡现在可以通过拖动重新排序。项目名称还提供对创建、更多、重命名和删除操作的快速访问。
  • 现在可以将文件夹与所有嵌套文件夹和资源一起移至垃圾桶，并在删除开始之前进行确认。
  • 现在可以通过 CLI 和授权的 API 进行工件共享，并提供纯空间或公共链接、可选密码和到期日期。新的 CLI 共享需要明确的范围，禁用共享会使链接失效。
  • 茶包导入现在显示确认预览，其中包含项目名称、内容计数和可折叠文件夹树。
  • 自动化脚本可以通过将 bodyType 设置为 html 来发送原始 HTML 电子邮件。 Markdown 仍然是默认设置。
  • 秘密所有者在确认披露是安全的后，可以通过网络界面消除针对故意公开密钥的暴露警告。
  • Cmd+K 现在搜索可访问的聊天标题和消息内容以及工作区资源。聊天结果包括匹配的片段并在相关消息中打开，并为聊天和资源提供单独的过滤器和分页。

错误修复和改进

  • 视图搜索现在一致地保留视图过滤器并拒绝空搜索。全字段搜索涵盖了超出之前 20 个字段限制的可搜索字段，并提高了宽表的性能。
  • 聚合查询现在返回更一致的总计、分页和空处理，同时尊重访问权限。当没有记录匹配时，筛选的复选框百分比指标返回 0 而不是 null。
  • 当禁用本机数据查询时，CLI 记录计数和字段统计现在尊重权限和当前视图。
  • 用户选择器在滚动时保持添加用户可访问，并在不存在用户时自动打开添加用户表单。模板指南和应用程序预览还具有更清晰的验证、响应式布局和更可靠的注销行为。
  • 无效或撤销的应用程序会话现在会将用户返回到登录页面，而不是显示服务器错误。生成的应用程序预览在启动过程中不太可能卡住。
  • 改进了应用程序保存、回滚、发布、复制和导入重试的可靠性。无效查询现在显示可操作的字段和运算符详细信息，而仅输出架构更改会产生警告而不是阻止保存。
  • 字段删除预览现在可以识别受影响的应用程序和命名查询。
  • 内联应用程序编辑和保存重试现在可以在拒绝请求或中断预览后更可靠地恢复。重叠保存返回可重试冲突而不是服务器错误。
  • 已发布的应用程序在加密密钥轮换后不再错误地报告配置更改，并且重新加密环境变量会保留其原始修改时间戳。
  • 改进了自动化凭证安全性和 Webhook 身份验证可靠性。
  • 每个空间的默认并发例程运行限制现在为 5，而不是 10。现有的管理员覆盖保持不变；大批量可能需要更长的时间才能完成。
  • 表创建现在可以更可靠地从临时冲突中恢复，而无需覆盖较新的字段设置或创建重复的链接字段。
  • 当焦点移动到其他地方时，聊天技能和提及菜单会正确关闭，并且技能管理器滚动条不再与卡片重叠。回复表通过水平滚动保留可读的列宽，操作菜单更好地适应长标签。
  • 清除记录选择现在可以正确删除明确选择的记录。
  • 文件夹删除对话框保持打开状态直至完成。垃圾操作现在提供更清晰的进度和部分恢复反馈，在失败后更可靠地恢复，并提供改进的移动布局和长名称处理。
  • 按 ID 粘贴记录可以更可靠地创建所需列，同时保留列顺序、值映射、撤消和重做、权限和部分完成行为。
  • 无效或损坏的 Tea 包现在显示更清晰的验证错误，而临时预览失败不会不必要地阻止有效导入。
  • 移动应用程序生成器对话现在使用正确的应用程序上下文。新对话在第一次回复后不再冻结，点击状态栏后会保留聊天位置，并且通知会打开正确的应用程序和页面。
  • 在移动设备冷启动或切换工作空间后，应用程序现在会在第一个可访问的项目中打开一个新对话，而不是恢复上一个对话。没有项目的工作区继续显示项目创建。
  • 没有指定视图的表级复制不再继承默认视图过滤器、排序、隐藏字段或字段顺序。复制还保留自定义日期和时间格式并拒绝无效的负行坐标。
  • 设置页面现在使用居中的响应式布局，浪费的空间更少。搜索已从存档聊天中删除，因为它无法返回完整结果。
  • 现在可以无错误地清除评级过滤器值。水平滚动期间看板拖动更加稳定，AI 聊天从临时网络故障中恢复更加可靠。
  • 允许隐藏字段的共享表单现在一致地验证可见的必填字段。缺少这些字段的提交将被拒绝，而隐藏的必填字段仍然是可选的。
  • 删除链接字段不再导致共享其数据的其他活动字段在记录视图、导出或发布的应用程序中失败。此修复不会自动修复以前受影响的表或恢复丢失的数据。
  • 改进了受支持语言的术语、翻译、语法和状态消息，包括设置、导航、通知、电子邮件模板、公式、权限和 AI 功能。
  • 打开已删除或无法访问的表链接现在会重定向到可访问的项目位置，并显示该表不可用的单个通知。
  • 工作区资源和聊天搜索结果独立加载，因此如果另一个失败，其中一个可以保持可用。改进的过滤和分页使旧的聊天匹配和所有启用的资源类型都可以被发现。
