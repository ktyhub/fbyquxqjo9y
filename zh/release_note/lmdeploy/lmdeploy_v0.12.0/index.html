lmdeploy v0.12.0

这个项目是干啥的：一个把大模型跑成在线服务的推理部署工具，支持MoE、FP8和拆分式服务，给需要高效部署模型的开发者用。

变更架构图

亮点

  • 破坏性变更：放弃 Python 3.9 — #4281 移除了对 Python 3.9 的支持（已 EOL）；安装 v0.12.0 必须使用 Python 3.10+。第二处不那么显眼的破坏来自 AsyncEngine 重构：#4252 “Remove deprecates from chat template” 删除了此前已弃用的 API，依赖这些别名的代码需要更新。结合 #4250（MultimodalProcessor）和 #4253（Session/SessionManager）来看，这是一场持续且明确编号的重构，因此升级前请锁定并回归测试任何自定义 AsyncEngine/chat-template 集成。

  • TurboMind 新增模型与量化覆盖 — #4290 新增 llm-compressor AWQ 模型支持，#4305 新增 llm-compressor 对称量化推理，意味着你可以直接服务这些量化格式，而不必自行转换。#4318 新增 Intern-S1-Pro，#4298 为 gpt-oss 加入 router replay。需要这些模型/格式就值得升级；否则属于增量、低风险改动。

  • 分布式/大规模部署工作 — #3362 为 TurboMind 带来 Gloo 通信，#4227 让 CUDA IPC communicator 的 max CTA 和 NVLS 使用可配置，#4296 修复混合 DP+TP 下的 NVLS 初始化，#4246 新增 DeepEP buffer 的 sleep/destroy。多节点或 DP+TP 运维方在这里获得新的调优旋钮和修复；单 GPU 用户可以忽略。注意 #4313 加入了对 NCCL 2.27 内存泄漏的警告——如果遇到无法解释的显存增长，请检查 NCCL 版本。

  • 值得升级的正确性与稳定性修复 — 前缀缓存有多项修复（#4270 性能回退、#4292 整体正确性），FP8 模型现在把 float16 权重转为 bfloat16（#4276），#4308 修复客户端断开（Ctrl+C）时的崩溃。此外修复了 gemma chat 模板（#4280）、ignore-eos（#4282）、None 时的 logit softcapping（#4247）、include_stop_str_in_output 与 output_logits（#4244），以及长上下文（#4309）/get_ppl（#4314）的停止处理。撞上这些 bug 的人应升级；否则收益是渐进的。

  • 构建/可复现性清理 — #4257 固定了 nvshmem，#4258/#4260 固定了 timm（避开有问题的 timm 1.0.23），主要对 CI 和可复现安装有意义；#4251/#4259/#4264 扩充了文档，包括生成的 OpenAPI 规范和 CLI 文档。这不是空操作或纯元数据重打标签——上面的功能改动是实打实的——但不需要新模型、量化路径或修复的用户可以放心留在 v0.11.1。
