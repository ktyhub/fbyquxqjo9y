ml-stable-diffusion 1.1.1

修订 发布时间2024年5月4日 来源apple/ml-stable-diffusion 英文原文

ml-stable-diffusion 1.1.1

变更流程图

亮点

  • 许可证切换为 MIT — 重头戏：项目改用 MIT 许可证，消除此前的授权障碍，在商业产品中采用或发布安全得多。任何需要法务/合规签批的人应重新核对新条款；即便不改代码，仅此就足以让你留意这个版本。
  • 混合位压缩修复并迁移到新 optimize API（PR #279、PR #311） — PR #279 修复缺失参数（mixed_bit_compression_apply）与 mixed_bit_compression_pre_analysis 的损坏导入；PR #311 随后用新的 optimize API 重新实现。这是唯一涉及迁移的领域：若依赖混合位压缩，应预期更新调用点，而非把它当作透明补丁。
  • Python 工具链新增编译模型与 Python 3.8 支持（PR #296、PR #287） — Python 用户获得编译模型支持（PR #296），以及让 pipeline.py 重新兼容 Python 3.8 的修复（PR #287）。走 Python 路径的用户值得升级；纯 Swift 用户在此无收益。
  • 通过 sRGB 实现色彩准确的输出（PR #301） — 生成图片现会在可用时使用 sRGB 配置文件，解决颜色发白/不正确的问题。若你直接对比或消费图片输出，这点相关；视觉上一致的管线可跳过。
  • 小修复与总体结论（PR #276、PR #318） — 最后是 safety_checker dtype 修复与 swift-argument-parser 小版本升级。这是内容实在的补丁版，不是重新打标签或仅改元数据的空操作：为 MIT 许可证、Python 用户和混合位压缩用户（注意上述迁移）而升级；否则是可推迟的常规错误修复版本。
