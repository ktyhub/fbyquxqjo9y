kops v1.36.0

这个项目是干啥的：Kubernetes 官方出的集群管理工具，用一条命令就能在云上建好、升级、扩容 K8s 集群，给需要自己搭和管 Kubernetes 集群的运维和工程师用。

请参阅完整的 kOps 1.36 release notes 了解详细信息，包括重大更改和弃用。

变更架构图

亮点

  • Kubernetes 1.36 支持并完成从树内云提供商的迁移
  • 重新设计的插件管理：kops-channels 现在作为控制平面节点上的静态 Pod 运行；独立的 channels 二进制文件不再分发
  • gossip 集群的混合引导程序：worker 直接针对 API 负载均衡器进行引导，从而简化了 gossip DNS 的迁移（已弃用）
  • Karpenter 刷新：Karpenter v1.13.0，每个实例组具有 kOps 管理的 EC2NodeClass 和 NodePool 对象
  • etcd-manager 改进：使用替换的数据磁盘恢复成员、对无法访问的成员具有弹性的成员资格更改、无发行映像以及更快的单成员集群启动
  • 扩展的 Azure 支持：云控制器管理器、Azure Disk CSI 驱动程序和实验性 Terraform 目标
  • Hetzner Cluster Autoscaler 支持 以及 Linode (Akamai) 作为新云提供商的基础
  • 组件更新：containerd v2.2.4、etcd-manager v3.0.20260707 与 etcd 3.5.31/3.6.12、AWS 负载均衡器控制器 v3.3.0、Cilium 可调参数、CoreDNS v1.14.2、集群自动缩放器 v1.36.0
  • 删除：支持 Kubernetes 1.30、etcd 3.4、Amazon Linux 2、Ubuntu 20.04 和 Debian 10
