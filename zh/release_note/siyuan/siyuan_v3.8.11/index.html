siyuan v3.8.11

修订 发布时间2026年11月19日 来源siyuan-note/siyuan 英文原文

#思源v3.8.11

升级通知

数据库格式

  • 主键富文本（格式 15 和 16）。 早期预览版本以格式 15 保存的内联富文本仍然可读。在主键中保存新的块富文本（包括带图像的文本）会将数据库至少升级到格式 16。 主键兼容性
  • 普通文本字段中的内嵌图像（格式 17）。 将第一个内嵌图像保存在普通文本字段中会将该数据库升级到格式 17。 文本字段兼容性 仅打开数据库不会触发这些升级。 3.8.10 版本最多支持 14 种数据库格式。client 只能打开其支持的格式的数据库。在使用新格式之前更新同步或访问相同数据的每台设备。提前备份您的工作空间。要回滚，请恢复完整的升级前快照。

其他兼容性更改

  • AI 长期内存。 恢复工作区快照现在会回滚内存记录及其撤销状态。如果内存仍然通过了通常的有效性检查，则恢复内存被遗忘之前的快照可以使其再次可用。 长期记忆
  • 内核 API。 API 合约处理的 JSON 请求的主体限制为 32 MiB，loginAuth 的主体限制为 64 KiB。超出这些限制的请求将返回代码 -1。 API合约

概述

此版本在数据库主键中添加了富文本和块编辑、内置日期选择器、统一颜色编辑以及插件快照浏览和恢复。 思维导图支持自定义节点和连接器样式以及节点之间的自由形式连接。独立的 Markdown 编辑器添加了查找和替换功能，而 macOS 则获得了离线 Markdown Quick Look 预览。 观看发布概述：YouTube

Changelog

以下是该版本的详细变化。

增强

  • 支持内置日期选择器并改进日期和时间编辑
  • 支持使用 HEX、RGB 和原生选择器进行统一颜色编辑
  • 支持数据库主键富文本和块编辑
  • 支持 macOS 上离线 Markdown Quick Look 预览
  • 支持选择是否恢复文档读取位置
  • 支持浏览和恢复插件快照
  • 改进Linux上的内核进程图标显示
  • 支持数据库主键和关系/汇总字段单独输入图标控件
  • 支持Linux上KDE系统代理检测
  • 支持思维导图中每个节点的连接器样式和形状
  • 减少文档树缩进以提高可读性
  • 支持具有可配置路径和线条图案的自由形式思维导图关系
  • 支持忽略未使用资产清理规则
  • 在引用可见块时保留文档上下文
  • 改进移动端底部表单拖动
  • 支持在独立 Markdown 编辑器中查找和替换
  • 默认支持展开或折叠分组搜索结果

错误修复

  • 数据库块删除后自动块收集继续
  • 在 iOS 上的外部浏览器中打开嵌入式本地 HTML 附件
