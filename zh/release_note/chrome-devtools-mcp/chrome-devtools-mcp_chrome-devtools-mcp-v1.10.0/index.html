chrome-devtools-mcp v1.10.0

小版本 发布时间2026年9月23日 来源ChromeDevTools/chrome-devtools-mcp 英文原文

变更流程图

亮点

  • MCP SDK v2 迁移 — 服务器迁移到 v2 MCP SDK（#2408），并配套进行了”为 SDK v2 做准备”的重构（#2771）。这是主要的兼容性风险：如果你嵌入该服务器，或针对 SDK v1 的契约/传输行为做测试，请在上线前验证客户端。相关内部实现也发生变动——浏览器状态现在放在 BrowserManager 类中（#2787），工具改为禁用而非注销（#2636），因此客户端现在可能看到此前隐藏的工具以禁用状态暴露出来。
  • 一等公民 CSS 检查 — 新增 get_css_style 工具（#2612），并引入 CSS 格式化类（#2707），现已覆盖 AtRule、PositionTryRule、PropertyRule、FunctionRule、继承规则、匹配规则、伪元素和关键帧（#2717、#2715、#2713、#2716、#2718）。get_css_styles 现在提供默认的 pageSize/pageIdx（#2799），调用方不再需要显式传入分页参数。对通过智能体调试 CSS/布局的人来说，这是最大的收益。
  • 配置接口变化——需要迁移 — 新增配置文件支持（#2661），并修复了保留原始值以便配置强制转换（#2747）以及在 CLI 启动时转发显式 false 选项（#2702）。注意页面路由选项被重命名（#2748），非布尔默认值也得到纠正（#2744）：如果你在现有配置或启动命令中设置了这些选项，请更新名称/取值。此外，除非显式要求，Puppeteer 日志不再写入文件（#2743）。
  • 大追踪与稳定性工作 — 分块的追踪缓冲区解析器（#2721），加上将追踪引擎模型限定为每次解析作用域的内存泄漏修复（#2720），让大型性能录制变得实用。控制台处理做了重新平衡：ConsoleCollector 的保留量按每次导航设限（#2773），而历史记录在同一文档导航之间得以保留（#2676）。还修复了输入工具操作过程中的 JavaScript 对话框（#2794）、WaitForHelper.ts 中的超时（#2772），以及 lighthouse_audit 使用 emulatedUserAgent + finalDisplayedUrl 的问题（#2795）。如果你依赖性能追踪或控制台捕获，尤其值得升级。
  • 遥测增加；升级结论 — 新的遥测会持久化最后一次工具调用的日期（#2705）、记录经过脱敏的客户端名称（#2757），并上报 Hermes 客户端使用情况（#2703）——对注重隐私或离线部署的场景相关。这是一个实质性版本，而非重新打标签或纯元数据变更。如果你需要 CSS 工具、大追踪支持、配置文件或 SDK v2，就升级；如果以上都不适用且你的客户端停留在 v1 SDK 契约上没问题，可以跳过。
