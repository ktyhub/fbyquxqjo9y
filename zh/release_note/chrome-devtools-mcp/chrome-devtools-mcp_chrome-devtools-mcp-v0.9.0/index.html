chrome-devtools-mcp v0.9.0

小版本 发布时间2025年10月22日 来源ChromeDevTools/chrome-devtools-mcp 英文原文

变更架构图

亮点

  • 导航历史现在可调试了 — MCP 会在 PageCollector 中保留最近 3 次导航（#411），并暴露此前的导航（#419），包括先前导航的控制台消息（#452），还修复了导航不足 3 次的情况（#451）。如果你在调试会重载的页面或 SPA 重定向，现在可以检查最后一次导航之前发生了什么，而不会在重载时丢失所有上下文——此前新页面会清空这段历史。
  • 控制台与快照输出更可控 — 控制台消息工具新增了过滤和分页（#387），以及一个专门的详细单消息工具（#435），另外还有详细快照（#388）。这主要对 token/噪声预算有意义：大量控制台输出不再迫使智能体逐页翻看或截断原始内容，你可以只对关心的那一条消息拉取完整细节。
  • 网络请求获得稳定 ID——但 ID 格式变了 — 网络请求的稳定 ID（#375）和请求查询的稳定 ID（#382）让你可以在多次工具调用之间关联同一个请求，而不再依赖瞬时的索引。注意随之而来的”reqid 格式不同”变更（#380）：任何解析、存储或硬编码请求 ID 结构的代码都应重新检查，尽管变更日志中没有列出正式的破坏性变更条目。
  • 新的连接与工具面控制 — 支持自定义请求头的 WebSocket 端点（#404）让你可以通过 WS 连接浏览器并传递鉴权等请求头；工具类别（#454）让你可以限制暴露哪些工具，有助于缩减智能体上下文或限制能力；Claude 市场/插件清单（#396）让安装到 Claude 更方便。这些扩展的是连接与配置方式，而非核心调试行为。
  • 升级结论 — 没有声明破坏性变更；这是一个实质性功能版本。对于跨导航做控制台/网络调试，或想要 WebSocket/自定义请求头连接和工具过滤的用户，值得升级。如果你只对单个稳定页面做基本快照/求值，且对当前控制台输出满意，可以安全跳过。另包含：evaluate_script 现在可在 frame 中工作（#443），pageerror 能处理非错误类型（#442），不可用的请求/响应正文会被明确标示（#446），以及页面销毁时会释放监听器（#318）。
