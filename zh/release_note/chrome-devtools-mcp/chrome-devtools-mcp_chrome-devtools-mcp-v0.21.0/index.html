chrome-devtools-mcp v0.21.0

小版本 发布时间2026年4月1日 来源ChromeDevTools/chrome-devtools-mcp 英文原文

chrome-devtools-mcp chrome-devtools-mcp-v0.21.0

这个项目是干啥的：把 Chrome 开发者工具通过 MCP 接给 AI，让它能自己调试网页、抓网络请求、分析内存堆栈。给做前端开发和用 AI 写代码的人用。

变更架构图

亮点

  • 内存泄漏诊断 — 新增一项技能，用 take_memory_snapshot 检测泄漏，为智能体提供调查内存增长的引导式工作流。如果你经常调试内存保留或性能问题，就升级。
  • 浏览器配置文件行为变化 — 提供 userDataDir 不再隐式启用 isolated，因此 Chrome 会使用所提供配置文件的持久状态，除非显式要求隔离。如果你此前依赖这种隐式隔离默认值，请更新配置以显式请求 isolated。
  • 更健壮的页面处理 — 在选中的页面被关闭后，list_pages 仍能工作，避免标签页管理失败打断浏览器自动化。
  • 权限元数据变化 — Lighthouse 和内存工具现在被归类为非只读。按只读注解来管控工具的客户端可能会要求审批或将其屏蔽，如果这些工作流变得不可用，请更新权限白名单。
  • MCP 配置与升级建议 — .mcp.json 输出现在采用顶层 mcpServers 包装结构；请校验或迁移任何自定义配置到该结构。对使用自定义配置文件、关闭标签页工作流或这些工具的用户来说，这是一次实用的维护版本；其他用户可以安全跳过。
