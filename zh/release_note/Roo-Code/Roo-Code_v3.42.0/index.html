Roo-Code v3.42.0

小版本 发布时间2026年1月23日 来源RooCodeInc/Roo-Code 英文原文

变更架构图

亮点

  • 破坏性变更：移除 Claude Code 提供程序 — 已弃用的提供程序在 #10883 中被删除。选中它的模式、工作流或自动化必须在升级前切换到受支持的提供程序。
  • 旧版 XML 工具调用退役 — #10848 和 #10841 移除了旧的基于 XML 的工具调用路径，#10723 把用户内容统一到 <user_message> 下。排查自定义提示词和集成中对这些已退役格式的依赖。
  • 上下文压缩自定义方式变更 — 压缩提示词现在放在 customSupportPrompts 里（#10881），自定义压缩模型的选项被移除（#10901）。把覆盖配置迁到新的提示词位置，并复查依赖专用压缩模型的工作流。
  • 编辑工具开始强制文件限制 — #10896 在所有编辑工具上一致地施加限制，堵住编辑允许范围之外文件的路径。无需配置迁移，但执行会更严格。
  • Codex 用量可见、信息流更干净 — #10813 在 OpenAI Codex 提供程序中增加了跟踪 ChatGPT 用量上限的 UI。#10888 防止 OpenAI-native 和 Codex 处理器重复输出文本/推理内容，避免输出乱码和流式状态不一致。
  • 模型支持更广、开销更低 — Cerebras 的 zai-glm-4.7 获得提示缓存（#10670），Kimi K2 Thinking 上线 Vertex AI（#9269），各提供程序的模型选择器被统一（#10650、#10294），切换更可预测，缓存还能降低重复前缀的成本和延迟。
