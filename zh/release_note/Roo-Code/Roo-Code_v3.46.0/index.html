Roo-Code v3.46.0

小版本 发布时间2026年1月30日 来源RooCodeInc/Roo-Code 英文原文

Roo-Code v3.46.0

这个项目是干啥的：一个装在VS Code里的AI编程助手，能按你的指令自动写改代码、委派任务给不同AI，给想少敲代码的程序员用。

变更架构图

亮点

  • 并行工具调用现在默认开启 — 相互独立的工具可以并发执行以加快 agent 工作流，同时修复了并行时光倒流的 bug。为性能收益而升级，但要验证依赖严格串行执行的工作流。
  • 更完整的代码与终端上下文 — read_file 新增缩进模式以提取完整语义块，read_command_output 通过分页和正则过滤取回被截断的完整命令输出。对大型仓库和日志密集的调试尤其有价值。
  • fetch_instructions 工作流需要迁移 — 新的 skill 系统用专用的 skill 工具取代 fetch_instructions，内置 create-mcp-server 和 create-mode skills、可配置的位置，以及强制的 skill 检查。使用 fetch_instructions 的自定义指令或自动化应迁移到 skills；工作区和全局 skills 现在可以在设置里管理。
  • 五家提供程序迁移到 AI SDK — Moonshot、DeepSeek、Cerebras、Groq 和 Fireworks 现在使用 AI SDK 支撑的基础设施，流式输出和工具支持更好。这些提供程序的用户应升级并做提供程序特定行为的回归测试。
  • 升级建议 — 这是一个实质性版本：重度使用 agent 的用户，以及处理大代码/命令输出的人应升级。不使用受影响提供程序或 skill 工作流的用户，如果能接受并行执行，可以延后，但会错过检索方面的改进。

3.46.0 发布 - 并行处理能力

  • 默认启用并行工具调用以提高性能（PR #11031 by @daniel-lxs）
  • 受 Codex 启发的 read_file 重构引入了缩进模式，用于提取完整的语义代码块而无需中间功能截断，非常适合从搜索结果或错误中定位特定行（@pwilkin 的 #10239，@hannesrudolph 的 PR #10981）
  • 使用新的 read_command_output 工具的无损终端输出允许通过分页和正则表达式过滤从截断的执行中检索完整的命令输出（#10941 by @hannesrudolph，PR #10944 by @hannesrudolph）
  • 新的技能系统用专用技能工具和用于 create-mcp-server 和 create-mode 的内置技能取代 fetch_instructions，并具有可配置的技能位置和强制技能检查（@hannesrudolph 的 #11062，@hannesrudolph 的 PR #11084）
  • 技能管理 UI 添加到设置面板，用于管理工作区和全局技能（@SannidhyaSah 的 #10513，@SannidhyaSah 的 PR #10844）
  • AI SDK 提供商迁移：Moonshot（PR #11063 by @daniel-lxs）、DeepSeek（PR #11079 by @daniel-lxs）、Cerebras（PR #11086 by @daniel-lxs）、Groq（PR #11088 by @daniel-lxs）和 Fireworks（PR #11118 by @daniel-lxs）使用 AI SDK 获得更好的流媒体和工具支持
  • 为 AI SDK 迁移添加 OpenAI 兼容的基础提供商基础设施（PR #11063 by @daniel-lxs）
  • 添加 AI SDK 依赖项和消息转换实用程序（PR #11047 by @daniel-lxs）
  • Webview-ui 中添加了 React 编译器集成，以实现自动记忆和性能改进（@In-line 的 #9916，@In-line 的 PR #9565）
  • 修复：在任务标头百分比计算中包含保留的输出标记（PR #11034 by @app/roomote）
  • 修复：根据可用输入空间计算标题百分比（PR #11054 by @app/roomote）
  • 修复：防止并行工具调用中的时间旅行错误（PR #11046 by @daniel-lxs）
  • 文档：澄清 read_command_output 搜索参数在不过滤时应被省略（PR #11056 by @hannesrudolph）
  • 添加 pnpmserve 命令用于代码服务器开发（PR #10964 by @mrubens）
  • 将 Next.js 更新到最新版本（PR #11108 by @cte）
  • 将网站上的定制导航菜单替换为 shadcn 导航菜单（PR #11117 by @app/roomote）
  • 将线性整合营销页面添加到网站（PR #11028 by @app/roomote）
