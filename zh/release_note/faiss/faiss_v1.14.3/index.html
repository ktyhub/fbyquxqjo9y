faiss v1.14.3

修订 发布时间2026年6月13日 来源facebookresearch/faiss 英文原文

faiss v1.14.3

亮点

  • 金属 GPU 后端扩展 — 新的 MetalIndexIVFFlat 具有 IVF 扫描/合并内核和扩展的 top-k 支持 (#5202)；现在 Apple Silicon 机器上默认启用 Metal (#5280)
  • ScalarQuantizer 中的 TurboQuant — 具有 SIMD 和优化的完整算法 2（QJL 阶段）(#5170)
  • Sapphire Rapids (SPR) 优化 — ScalarQuantizer L2/IP (#5173)、基于 VPOPCNTDQ 的 HammingComputer (#5183) 和基于 VPOPCNTDQ 的 RaBitQ 内核 (#5149)
  • faiss-gpu pip 轮子 — 新的 GPU 轮子包装 (#5131)；为 faiss-cpu 重新启用 musllinux 轮子 (#5299)
  • SVS 静态 vamana 支持 (#5224)
  • HNSW is_similarity 模式，用于 IP/相似性指标（#5246、#5226）
  • HNSW 搜索性能 — 保留 VisitedTableSet 容量以避免重新哈希 (#5290)，为 VisitedTable 去虚拟化模板化 search_from_candidate_unbounded (#5270)，并在 VisitedTable 中避免运行时检查 (#5234)
  • NEON FINE_SIZE=2 个专业化，适用于 Index2LevelDecoderImpl 和 IndexPQDecoder (#5255)
  • cuVS 升级到 26.06 (#5240)； CI 更新为 ROCm 7 (#5196)
  • 反序列化强化 - IDMap / BinaryFromFloat 中的 bool 字段验证 (#5279) 和 null 内部索引拒绝 (#5239)
  • 构建稳健性 — 通过 .rodata 分区表修复非 AVX2 导入 SIGILL (#5298)、Windows ARM64 (MSVC) NEON 构建修复 (#5274) 以及 AMD 上的 AVX512_SPR 调度修复 (#5281)
