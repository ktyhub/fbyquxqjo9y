faiss v1.14.2

修订 发布时间2026年5月22日 来源facebookresearch/faiss 英文原文

faiss v1.14.2

变更流程图

亮点

  • SuperKMeans — 通过 ADSampling + PDX 渐进式修剪实现更快的 k 均值 (#5168)
  • Apple Silicon 的金属 GPU 后端，从 IndexFlat 开始 (#5144)
  • RVV（RISC-V 矢量）SIMD 后端 + RISC-V 交叉编译 CI（#5156、#5184）
  • pip 安装支持 通过 scikit-build-core + cibuildwheel (#4862)
  • 启用 SVS IVF 索引； SVS 升级至 0.3.0（#4801、#4999）； SVSVamana 可通过 index_factory 用作 IVF 粗量化器 (#5175)
  • TurboQuant (CPU) 量化器 (#5049)
  • HNSW 改进 — 用于增量添加的可选持久锁 (#5031)、prune_headroom 以避免 O(n²) 修剪 (#4847)、更窄的添加时间关键部分 (#4915)
  • 广泛的索引反序列化强化 - 跨约 40 个 PR（二进制、IVF、HNSW、FastScan、ScalarQuantizer、AdditiveQuantizer、ProductQuantizer、SVS、VectorTransform 等）的验证和 OOM/溢出保护
  • 主要动态调度重构跨距离、汉明、分区、RaBitQ、FastScan；动态调度现在构建在 Windows 上 (#5127)
  • cuVS 升级到 26.02（#4945，#4788）； CI 移至 CUDA 13.2 (#5207)； 用于 cuVS 的 C++20 (#4881)； cuVS 索引的过滤搜索 (#4858)
  • IndexHNSW、IndexNNDescent、IndexNSG、IndexFlatCodes、IndexIVF 的 OMP 异常安全（#5106、#5105、#5111、#5133、#5037、#5053）
