添加

  • CPU Faiss 中的 QINCo 实现 (#3608)
  • 向 FlatCodes 添加搜索功能 (#3611)

  • 用于 PQFastScan 的 AVX512 (#3276)

已更改

  • 更快的 hnsw CPU 索引训练 (#3822)
  • 一些小改进。 (#3692)

  • 在训练前设置 verbosoe (#3619)
  • 删除重复的 NegativeDistanceComputer 实例 (#3450)
  • NNDescent 中断 (#3432)

  • PowerPC，改进函数 fvec_L2sqr 的代码生成（#3416）

  • 改进过滤和搜索参数传播（#3304）
  • 更改 index_cpu_to_gpu 以抛出未在 GPU 上实现的索引 (#3336)

  • 使用新的 io 标志跳过 HNSWPQ sdc init (#3250)

  • allocate_index 应默认为 null (#3855)
