accelerate v1.3.0

accelerate v1.3.0

变更流程图

亮点

  • PyTorch 2.0 成为新的最低版本 — 不再支持 PyTorch <2.0（#3331）。升级前请把依赖约束、锁文件、CI 矩阵和 Docker 基础镜像更新为 torch>=2.0。
  • 编译后的分布式模型可安全解包 — unwrap_model 和 extract_model_from_parallel 现在接受 keep_torch_compile（#3282），让调用方保留 torch.compile 包装，而不是只提取底层模块。对需要检查或操作编译后模型的分布式工作流很重要。
  • 大模型加载与 offload 更稳健 — 修复覆盖 tied-parameter 的模块归属（#3327）、TorchAO ≥0.7.0 的 offload（#3332）、通过 torch.xpu.mem_get_info 查询 XPU 显存（#3275），以及 NPU load_state_dict（#3211）。这些改动改善异构硬件上的自动设备映射和 offload，尤其对参数共享模型有利。
  • 支持最新的 bitsandbytes 优化器 — Accelerate 现在能处理不再暴露 optim_args 的优化器实现（#3311），避免在使用当前 bitsandbytes 版本时初始化失败。
  • 数据加载器兼容性护栏防止 in_order 错误 — Accelerate 现在检查 torchdata 版本，只在确实提供了 in_order 时才移除它（#3344、#3346），减少自定义训练数据管线因版本差异而失败。
  • TPU spawn 遵循更新的 XLA 语义 — TPU 启动路径不再把 nprocs 传给 xla.spawn（#3324）。TPU 用户应测试自定义启动包装器里对进程数传递方式的假设。

手电筒 2.0

自 Torch 2.0 首次发布以来已经过去了约 2 年，我们现在要求将其作为 Accelerate 的最低版本，在上一次发布的 transformers 中也是如此。

核心

  • [文档] @faaany 在 https://github.com/huggingface/accelerate/pull/3270 中没有硬编码 cuda
  • 由 @ji-huazhong 在 https://github.com/huggingface/accelerate/pull/3211 中修复 npu 的 load_state_dict
  • 将keep_torch_compile参数添加到unwrap_model和extract_model_from_parallel以用于分布式编译模型。通过 @ggoggam 在 https://github.com/huggingface/accelerate/pull/3282
  • [测试] 通过 @faaany 在 https://github.com/huggingface/accelerate/pull/3340 中使仅 cuda 的测试用例与设备无关
  • 最新的 bnb 在 https://github.com/huggingface/accelerate/pull/3311 中 @winglian 的优化器上不再具有 optim_args 属性
  • 添加 torchdata 版本检查以避免 @faaany 在 https://github.com/huggingface/accelerate/pull/3344 中出现“in_order”错误
  • [文档] 修复拼写错误，将 https://github.com/huggingface/accelerate/pull/3296 中的 @suchot 的“backoff_filter”更改为“backoff_factor”
  • 数据加载器：在尝试通过 https://github.com/huggingface/accelerate/pull/3346 中的 @dvrogozh 删除 in_order 之前，检查 in_order 是否为 kwargs
  • feat(tpu)：从 https://github.com/huggingface/accelerate/pull/3324 中的 @tengomucho 从 xla.spawn 中删除 nproc

大建模

  • 在 https://github.com/huggingface/accelerate/pull/3289 中修复 @SunMarc 的 test_nested_hook
  • 修正https://github.com/huggingface/accelerate/pull/3279中@Nech-C对_init_infer_auto_device_map的返回语句
  • 在 https://github.com/huggingface/accelerate/pull/3275 中使用 @dvrogozh 为 XPU 使用 torch.xpu.mem_get_info
  • 确保绑定参数是 https://github.com/huggingface/accelerate/pull/3327 中@pablomlago 模块的子级
  • 修复了在 https://github.com/huggingface/accelerate/pull/3332 中通过 @a-r-r-o-w 使用 TorchAO >= 0.7.0 时的卸载问题
  • 修复 @SunMarc 在 https://github.com/huggingface/accelerate/pull/3334 中的卸载生成测试
