accelerate v1.8.0

accelerate v1.8.0

这个项目是干啥的：一个帮PyTorch模型轻松在多张显卡或多台机器上训练的工具，配置简单还能组合并行，给搞AI训练的工程师用。

变更架构图

亮点

  • 更简洁、更严格的 FSDPv2 + FP8 配置 — FSDPv2 准备现在使用更严格的配置路径，减少与 FP8、torch.compile 和激活检查点的无效组合，同时追求更好性能。升级前请把现有 FSDPv2 配方对照 examples/fsdp2 检查，尤其是自定义的特性组合逻辑（PR #3585）。

  • IPEX 优化弃用 — Accelerate 不再直接应用 ipex.optimize()，因为多数优化已上游到 PyTorch。在 PyTorch 2.8+ 上请迁移到 PyTorch 原生的等价方案；低于 2.8 的版本仍依赖 IPEX（PR #3608）。

  • Intel CPU 分布式训练调优 — accelerate launch 现在会为 Intel CPU 配置 CCL_WORKER_COUNT 和 KMP 参数，改善 oneCCL 与线程协同。发布说明称第 4 代 Xeon 上 transformer 张量并行训练最高提速 40%；如果你已经覆盖这些环境变量，请检查冲突（PR #3575）。

  • DeepSpeed 编译与梯度累积 — 区域化编译现在能处理 DeepSpeedEngine.compile() 就地修改模型的行为，不同于非原地的 torch.compile()（PR #3609）。梯度累积步数也可以从 DeepSpeed 插件推导并同步，减少重复配置并修复累积相关问题（PR #3630、#3632、#3638）。

  • 更广、测试更充分的 Intel XPU 支持 — 本版本启用 big_model_inference，为 TorchTensorParallelPlugin 增加 XPU 支持，并引入设备无关的 GradScaler（PR #3595、#3627、#3588）。还修复了 XPU 8-bit 数值加载，并扩展了 FSDPv2 基准、区域化编译、TorchAO 和 PiPPy 的测试覆盖，让 XPU 工作流更适合验证。

  • 更灵活的实验追踪与启动 — 现在支持 SwanLab 做离线和在线追踪（PR #3605）。tracker 初始化被延后，避免过早建立分布式环境，因此自定义 tracker 集成不应假设在对象构造期间就已初始化（PR #3581）。

FSDPv2 重构 + FP8 支持

我们简化了如何准备 FSDPv2 模型，因为有太多方法可以将 FSDP2 与其他功能（例如 FP8、torch.compile、激活检查点等）组合在一起。尽管现在的设置更加严格，但它可以减少错误并提供更高性能的用户体验。我们还添加了对 FP8 的支持。您可以在此处 阅读结果。感谢@S1ro1 的贡献！

  • [FSDP2] https://github.com/huggingface/accelerate/pull/3585 中 @S1ro1 重构 + FP8

在 Intel CPU 上更快的分布式训练

我们更新了 CCL_WORKER_COUNT 变量并为 Intel CPU 用户添加了 KMP 参数。这显着提高了分布式训练性能（例如张量并行性），在英特尔第四代至强上训练 Transformer TP 模型时速度提升高达 40%。

  • 在 https://github.com/huggingface/accelerate/pull/3575 中通过@jiqing-feng 在简单启动中设置 ccl 和 KMP 参数

DeepSpeed 的区域编译

我们添加了对 DeepSpeed 引擎的区域编译的支持。 DeepSpeed 的 .compile() 使用 torch.nn.Module.compile(…) 就地修改模型，而不是异地的 torch.compile(…)，因此我们必须考虑到这一点。感谢@IlyasMoutawwakil 提供此功能！

  • 修复 @IlyasMoutawwakil 在 https://github.com/huggingface/accelerate/pull/3609 中的 deepspeed 区域编译

ipex.optimize 弃用

ipex.optimize 已被弃用。大多数优化已上游到 PyTorch，未来的改进将直接落地。对于没有 PyTorch 2.8 的用户，我们现在将继续依赖 IPEX。

  • 删除https://github.com/huggingface/accelerate/pull/3608中@yao-matrix加速中的ipex.optimize
