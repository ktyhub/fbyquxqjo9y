accelerate v1.12.0

变更流程图

亮点

  • 用 DeepSpeed Ulysses/ALST 进行长序列训练 — 通过 ParallelismConfig 增加序列和注意力头并行，使用 sp_backend="deepspeed"、sp_size 和 sp_handler=DeepSpeedSequenceParallelConfig(...)。这是本版本主要的升级理由：长上下文训练者可以把序列切分到多个 rank。要正确训练必须迁移： 调用方必须跨序列并行组收集 loss 和有效 token 数，按文档计算 token 加权的全局 loss，而不能只依赖各 rank 自己的 loss。
  • 张量并行优化器修复 — 在张量并行之后更新 torch.optim.Optimizer 的参数状态。把张量并行与优化器状态结合使用的用户应升级，尤其是在分片后恢复或继续训练的场景；否则优化器状态可能不一致。
  • 低影响的清理与小修复 — 移除 cpu_ram_efficient_loading 警告，更正文档/flag 拼写错误，新增设备类型辅助函数，更新 arXiv 链接标签，并把 CI 切换到自托管 runner。这些改动没有引入已宣布的破坏性 API 变更，也不太可能影响普通用户。
  • 升级建议 — 长序列训练、张量并行优化器用户以及 Trainer 集成采用者值得升级；不在这些范围内的用户可以放心跳过，除非想要这些小修复和文档清理。

Deepspeed Ulysses/ALST 集成

Deepspeed Ulysses/ALST 是一种通过采用序列并行性和注意力头并行性来训练长序列的有效方法。您可以在本文 https://arxiv.org/abs/2506.13996 或 Deepspeed 教程 https://www.deepspeed.ai/tutorials/ulysses-alst-sequence-parallelism/. 中了解有关此技术的更多信息 要启用 Deepspeed Ulysses，您首先需要创建 ParallelismConfig 并设置 sp 相关参数：

parallelism_config = ParallelismConfig(
    sp_backend="deepspeed",
    sp_size=2,
    sp_handler=DeepSpeedSequenceParallelConfig(...),
)

然后，您需要确保按照我们的文档中的描述计算正确的损失

        ...
        losses_per_rank = torch.distributed.nn.functional.all_gather(loss, group=sp_group)
        good_tokens = (shift_labels != -100).view(-1).sum()
        good_tokens_per_rank = torch.distributed.nn.functional.all_gather(good_tokens, group=sp_group)
        total_loss = sum(
            losses_per_rank[rank] * good_tokens_per_rank[rank]
            for rank in range(sp_world_size)
            if good_tokens_per_rank[rank] > 0
        )
        total_good_tokens = sum(good_tokens_per_rank)
        loss = total_loss / max(total_good_tokens, 1)
