agno v3.0.1

修订 发布时间2026年8月26日 来源agno-agi/agno 英文原文

#Changelog

改进

  • 使用许多工具更快地运行代理：工具架构现在一次导出并在运行期间缓存，从而减少了携带大型工具包的代理每次运行的开销。 (#9771)
  • 更快的长对话：会话历史记录每轮都会增量加载，因此响应时间随着对话的增长而保持平稳，而不是随着其长度而缩放。 (#9775)
  • PubMed 请求超时：PubmedTools 现在接受 timeout 并将其传递给两个 NCBI 电子实用程序请求，因此停滞的 PubMed 响应无法无限期地保留工具调用。 (#9463)

错误修复

  • 不带 properties 的严格模式工具架构：Function.process_schema_for_strict 不再在省略 properties 的架构上引发 KeyError（例如逐字注册的 MCP 服务器架构）。 （#9578，修复#9409）
  • Gemini 工具结果媒体：对于 Gemini 3 及更高版本，从工具返回的图像和文档 blob 现在嵌套在 FunctionResponse.parts 内，而不是作为同级 inline_data 部件发出；遗留模型保留以前的表示。仅当支持 MIME 类型时，才会发送 Vertex AI 上支持 URI 的响应媒体。 (#9647)
  • 仅核心安装的位置查找：agno.utils.location 使用未声明的 requests 包，因此 add_location_to_context=True 提升了 ModuleNotFoundError 而不安装额外的包。现在使用httpx。 （#9793，修复#9772）
  • ScheduleManager 清理：close() 可以容忍部分构造的管理器（例如在失败的 deepcopy 后），因此垃圾收集不再在缺失的 _pool 上引发 AttributeError。 (#9792)

食谱

  • 添加了确定性副作用批准流程示例。 (#9790)
  • 添加了 DeepKeep AI 防火墙护栏示例。 (#9784)
  • 记录 AgentOS 团队运行状态。 (#9768)
  • 添加了 Peer Cash MCP 代理示例。 (#9562)
  • 修复了目录重新编号和 MCP 示例中遗留的过时说明书路径。 （＃9789，＃9783）
