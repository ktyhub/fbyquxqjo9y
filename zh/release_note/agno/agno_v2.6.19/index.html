agno v2.6.19

修订 发布时间2026年6月23日 来源agno-agi/agno 英文原文

#Changelog

新功能：

  • 检查点： 添加了工具批次级别检查点和统一的 /continue 用于重新生成和分叉运行。还添加了对分叉会话的支持。请参阅食谱。
  • 添加新的工具包 StudioTool，用于动态代理、团队、工作流程组合。

改进：

  • Gemini：GeminiInteractions 现在是延迟导入的，因此 Gemini 不再需要 google-genai 2.0.
  • PII Guardrail： custom_patterns 现在接受原始正则表达式字符串。
  • 矢量数据库：ClickHouse 和 Pinecone 现在通过 get_supported_search_types() 报告其支持的搜索类型

错误修复：

  • FileTools：从所有平台上的 FileTools 和相关文件工具返回正斜杠路径。
  • 团队取消：异步团队委托现在使用异步取消检查。
  • AccuracyEval：修复了空结果以返回 None 分数。
  • Gemini：在可重试错误后，指导重试现在遵循 retry_with_guidance_limit。
  • 序列化：现在保留非 ASCII 文本而不是转义。
  • 文件：文本文件现在可以从会话历史记录中正确重新加载。
  • 团队：嵌套团队挂钩后事件不再泄漏到响应内容中。
  • 运行事件：流媒体内容事件不再删除 image 字段。
  • OpenAILike：OpenAILike 提供商避免使用 Chat 后缀。
  • SentenceTransformerReranker：允许提供交叉编码器。
  • HackerNews：从正确的 API 字段读取用户 ID。
