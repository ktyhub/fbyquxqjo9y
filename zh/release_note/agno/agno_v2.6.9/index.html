agno v2.6.9

修订 发布时间2026年5月21日 来源agno-agi/agno 英文原文

#Changelog

新功能：

  • 批准 - Post-Hooks 中已解决的批准： Post-hooks 和可观察性集成现在可以通过 run_response.metadata["approval"] 读取完整的已解决批准记录（resolved_by、resolved_at 等）。此前仅曝光了status和resolution_data。住在 metadata，因此它在 RunOutput / TeamRunOutput / 未来的 WorkflowRunOutput 中统一工作。 （＃7366，＃8032）

改进：

  • PgVector - prefix_match=True 实际上有效： PgVector(prefix_match=True) 是一个静默无操作 - 它附加 * 然后通过 websearch_to_tsquery 路由，忽略通配符。现在通过适当的标记化通过 to_tsquery('tok:*') 进行路由，因此像 "ani" FTS 一样的部分查询与记录的 "animal" 匹配。新的食谱 cookbook/07_knowledge/04_advanced/06_prefix_search.py 显示了帮助中心预先输入用例。 （#8048、#8051、#8052）
  • PgVector - 空 tsquery 后备鲁棒性： 用文字 ''::tsquery 转换替换了 to_tsquery(language, '') 后备，因此行为不再依赖于容忍空输入的解析器。 （#8053）
  • Claude 变体 - temp/top_p/top_k = 0 荣幸： Anthropic、AWS 和 VertexAI Claude 变体由于纯粹的真实性检查而默默地下降了 0.0 值。切换到 is not None，以便确定性输出按预期工作。 （#8009，修复#8004）
  • 日历和 Gmail 上下文提供程序 - 干净的指令分层： 通过删除工具包端指令已提供的内容，将 DEFAULT_READ_INSTRUCTIONS / DEFAULT_WRITE_INSTRUCTIONS 从 157 行修剪到 27 行。提供者现在拥有角色+安全；工具包拥有技术参考。 (#7982)
  • decision_log - 删除已弃用的 datetime.utcnow()： 替换为 datetime.now(timezone.utc) 以清除 Python 3.12 弃用警告。 （关闭#8030）
  • Chonkie： 跳转到 >=1.6.7 以获取上游语言自动检测修复；从#7904 中删除了临时测试解决方法。 （#8012）

错误修复：

  • GeminiInteractions - 服务器端工具调用泄漏到代理路径上： 在代理路径（反重力、深度研究）上，FunctionCallStep 描述了自主循环在服务器管理的沙箱内运行的工具。之前我们将它们显示为本地 tool_calls，导致 Function <name> not found 和后续 400 invalid_request 错误。对 self.agent is None 上的 FunctionCallStep 分支进行门控，用于流式传输和非流式传输。用户声明的工具的模型路径未更改。 (#8045)
  • Claude（Anthropic / AWS / VertexAI）- temperature=0 默默地下降： 查看改进。当调用者显式设置 0 时，之前的每个版本都会默默地回退到 API 默认值 (~1.0)。 （#8009，修复#8004）
