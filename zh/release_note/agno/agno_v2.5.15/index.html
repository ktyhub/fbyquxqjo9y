agno v2.5.15

修订 发布时间2026年4月9日 来源agno-agi/agno 英文原文

#Changelog

新功能：

  • 技能： 为团队添加了技能支持。请参阅文档。
  • 工作流程： 添加工作流程作为工作流程步骤（嵌套工作流程）支持。请参阅文档。

改进：

  • 工作流程 HITL：
    • 工作流程步骤现在支持执行后人机循环审核 - 步骤运行后暂停以审核、批准、拒绝反馈并重试，或在继续之前编辑输出（步骤、路由器和循环上的 require_output_review）。请参阅文档。
    • 参数合并到 HumanReview 配置类 - 在步骤、循环和路由器上传递 human_review=HumanReview(…) 而不是平面参数。完全向后兼容。 查看文档
  • 回溯日志记录： 添加了 AGNO_LOG_TRACEBACKS 环境变量（选择加入）以控制 log_error 和 log_warning 中的回溯可见性 — 默认情况下关闭（干净的日志），设置为 true 时进行完整回溯。
  • SessionSummaryManager：添加 last_n_runs 和 conversation_limit 参数 SessionSummaryManager，因此用户可以控制生成会话摘要时包含多少会话历史记录。

错误修复：

  • OpenAI： 停止将共享 HTTP/2 client 注入 OpenAI 和 Azure OpenAI 模型。通过让 OpenAI SDK 管理自己的 HTTP client，修复并发使用下的暂时性 400 错误。
  • 指标：修复了未针对 OpenAI、Perplexity 和 LiteLLM 计算 audio_total_tokens 的问题。
  • 工作流程：
    • 修复了 Condition 步骤类型的 else_steps 未复制的问题。
    • 修复了 StepInput to_dict 以正确序列化 File 对象。
  • **SurrealDb：**更新了正确的 SurrealDB 灵活字段语法。
  • AgentOS： 在 AgentOS 文件上传中添加了 .msg、.xlsx 和 .xls 缺少的 MIME 类型。
  • A2A： 修复为在 str 连接之前序列化 Pydantic output_schema 内容。
  • 团队： 修复了 TeamSession.get_messages(..) 返回重复消息的问题。
  • SlackTools： 修复以向 SlackTools 添加线程感知消息指令。
  • GitHubTool： 修复了当 PR 数量少于请求限制时 get_pull_requests 中的 IndexError
  • 维基百科工具： 已修复以处理维基百科消歧错误并添加可配置的 auto_suggest。
