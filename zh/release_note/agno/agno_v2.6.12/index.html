agno v2.6.12

#Changelog

新功能：

  • HTML 文件生成：通过示例应用程序添加了 HTML 文件生成支持。
  • AG-UI 状态事件：添加了 AG-UI 状态事件支持。
  • 调整引擎提供程序：添加调整引擎作为新模型提供程序。
  • WorkOS RBAC 示例：添加了基于角色的访问控制的 WorkOS 示例。
  • Latitude 可观测性：通过 OpenInference 可观测性示例添加了 Latitude。

改进：

  • MiniMax：将默认模型升级为 M3。
  • WhatsApp 自述文件：更新了新 Meta 开发人员仪表板的设置和 Webhook 指南。
  • 自述文件：通过附加资源链接进行增强。

错误修复：

  • Milvus：更新了混合搜索参数以使用 drop_ratio_search 并删除 drop_ratio_build
  • ArxivReader：更新了 arxiv Client.results() 用法。
  • 运行：更新以防止 from_dict 中的运行列表为空时出现 IndexError。
  • 代码分块：更新为跳过 HuggingFace 下载错误的标记器测试。
  • 代理状态工具：更新的 enable_agentic_state 工具接收字典参数的正确架构。
  • AG-UI 多模式：已修复以保留 AG-UI 多模式输入。
  • AG-UI 协议：更新为引脚 ag-ui-protocol>=0.1.14 以防止推理角色验证错误。
