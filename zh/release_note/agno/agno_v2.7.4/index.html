agno v2.7.4

#Changelog

新功能：

  • Superserve 工具：添加了 SuperserveTools 来运行代理生成的代码并管理 Superserve 中的文件，Superserve 是一个基于 Firecracker 的沙箱平台，适用于长期运行的代理。请参阅文档。
  • Plivo 工具：添加了 PlivoTools 以使用 Plivo 发送短信、拨打语音电话和查找电话号码。请参阅文档。
  • The Context Company：添加了可观察性集成以跟踪代理与 The Context Company 一起运行。请参阅文档

改进：

  • agno create 增强：交互式入门模板和项目名称提示、四个新入门（Azure、Helm、Modal、Render）以及自动 .env 播种。
  • Telegram 工具：添加 pin_message、get_chat、get_file 和 react_with_emoji，以及 save_downloads 和 output_directory 将下载的文件保存到磁盘。
  • Tavily Tools：向搜索添加域、日期范围、主题和国家/地区过滤器。
  • Google 工具：向 Gmail、日历、云端硬盘和幻灯片添加分页。
  • Oxylabs 工具：以 Markdown 形式返回整页内容。
  • 工作流程：在路由器选择器和条件评估器中接受 run_context，弃用 session_state。

错误修复：

  • 团队：
    • 将用户输入传递给在运行中多次暂停的成员。
    • 序列化其媒体或成员响应已经是字典的运行输出。
  • 代理操作系统：
    • 在流式传输团队响应时跳过累积的运行输出。
    • 拒绝使用现有 ID 创建会话，而不是覆盖其历史记录。
  • 工作流程和团队会议：遵守零和负历史记录限制。
  • 工作流程：当工作流程中途失败时，会显示潜在的错误。
  • Slack：每个频道的范围会话，因此频道不再共享历史记录。
  • Tavilly Tools：应用配置的提取深度。
  • OpenRouter：从图像模型返回生成的图像。
  • PostgresDb：当组件覆盖表名称时，遵循 create_schema=False。
  • PubMed、Firecrawl 和 Spider 工具：遵守配置和每次调用结果限制。
  • FixedSizeChunking：当重叠超过内容时保留短文档。
  • CSVReader 和 ExcelReader：为每个读取器提供自己的默认行分块。
