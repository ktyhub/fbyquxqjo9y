agno v2.6.10

修订 发布时间2026年6月2日 来源agno-agi/agno 英文原文

agno v2.6.10

Changelog

新功能

  • 模型提供商：添加了四个新模型提供商：
    • Inception Labs 模型集成
    • Xiaomi MiMo 模型提供商
    • MiniMax 模型提供商 (M2.7)
    • Cloudflare AI Gateway 模型提供商
  • YouTools：为 You.com 搜索 API 集成添加了 YouTools。
  • DOCX 生成：添加了 DOCX 文件生成支持。
  • 上下文提供程序流：从上下文提供程序流式传输子代理事件。
  • 注册表：在注册表中添加了知识和管理器支持。
  • 运行持久性：更新了代理、团队和工作流程以正确保留已取消的运行。
  • RunCompleted 事件：在 RunCompleted 事件上添加了 files 字段。
  • 模型字符串解析器：向模型字符串解析器添加了 google-interactions 提供程序。

改进

  • DeepSeek：更新了 DeepSeek V4 思维模式和默认值。
  • Cookbook：更新了并行 MCP 以使用免费端点；抛光 image_search 自述文件；将 data_labeling 示例切换为模型字符串简写。

错误修复

  • MCP：
    • 防止代理崩溃导致 MCP 连接失败。
    • 当 MCP 工具具有 team/agent/run_context 参数时，避免 kwarg 碰撞。
  • JSON DB：对 JSON DB 文件使用 UTF-8 编码。
  • CSV Toolkit：将 CSV 工具包文件读取为 UTF-8。
  • 异步修复：
    • 在 Discord client 中使用异步 Attachment.read() 而不是阻止 requests.get。
    • 将 _async_create_collection_and_scope 中的阻塞 time.sleep 替换为 await asyncio.sleep。
    • 在嵌入器中将已弃用的 asyncio.get_event_loop() 替换为 get_running_loop()。
    • 在 YouTube 阅读器中使用运行循环。
    • 当没有配置钩子时，工具使用异步执行链中的异步入口点。
    • CSVReader.async_read 使用换行符连接来匹配同步读取行为。
  • OpenAI Tools：关闭 OpenAITools.transcribe_audio 中的音频文件句柄。
  • 团队：
    • 修复了团队继续运行依赖关系；
    • 添加了 _acontinue_run_background_stream 以防止继续运行 SSE 上的 AttributeError。
  • 解析器模型：设置 parser_model 时跳过严格工具模式（代理和团队）；为 continue_run_dispatch 和 acontinue_run_dispatch 添加了 parser_model 防护装置。
  • RemoteTeam：添加了知识过滤器属性。
  • 嵌入：修复了 NULL 嵌入错误。
  • 矢量数据库：Milvus 矢量数据库与 contents_db 兼容；删除了已弃用的 Tantivy FTS，修复了 Redis hset mypy 错误。
  • SeltzTools：针对当前 SDK 进行了更新。
  • Fal：修复了 fal.py 中的数组处理。
  • Zendesk：Zendesk 工具中的 URL 编码搜索查询。
  • 内存：修复了数据库后端的 memory_topics 签名不匹配问题。
  • 会话：使用异步数据库调用时，在 delete_session 中引发 ValueError。
  • 文件上传：修复了文件上传媒体处理。
  • Slack HITL：截断 HITL 卡体以防止静默 Slack 拒绝。
