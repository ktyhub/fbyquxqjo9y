agno v2.7.3

修订 发布时间2026年7月14日 来源agno-agi/agno 英文原文

#Changelog

新功能：

  • 瓦尔基：
    • 添加了 ValkeyDb 作为代理、团队和工作流程的快速内存数据库。请参阅文档
    • 添加了带有矢量和关键字搜索的 ValkeyDB 矢量存储。请参阅文档
  • Redmine 工具：添加了 RedmineTools 来管理开源项目管理工具 Redmine 中的问题、评论和时间日志。
  • TokenLab：添加了 TokenLab 作为新的 OpenAI 兼容模型提供商。

改进：

  • 会话上下文：保存会话上下文时跳过冗余模型调用。
  • AG-UI：扩展了对 AG-UI 的人机交互确认、输入和反馈。
  • 用户内存和配置文件：从对话中提取更可靠的内存和配置文件。
  • MCP 工具：
    • 当 MCP 服务器无法访问时，会出现一个干净的错误。
    • 支持仅以 structuredContent 响应的工具。

错误修复：

  • DoclingReader：接受本地文件路径字符串。
  • JSONReader：阅读JSON文档时尊重chunk=False。
  • PDF阅读器：
    • 修复单页 pdf 的错误页码解释。
    • 自动尝试使用空白密码来加密 PDF。
  • 结构化输出：可靠地解析字段值包含大括号的响应。
  • 文件和编码工具：将搜索和列表包含在配置的根目录中。
  • 反重力：防止来自 escaping 代理目录的符号链接文件。
  • Cassandra：从配置的嵌入器导出向量维度。
  • Mistral：添加 frequency_penalty、presence_penalty 和 stop，并保留零值参数，例如 temperature=0。
  • YouTools：修复失败的搜索并添加区域、语言和新鲜度过滤器。
  • 工作流程指标：包括 WorkflowCompletedEvent 上的指标。
  • 计时器：修复 Timer.elapsed 以实现非常快速的操作。
