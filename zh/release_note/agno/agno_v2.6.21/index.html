agno v2.6.21

修订 发布时间2026年7月2日 来源agno-agi/agno 英文原文

#Changelog

改进：

  • LocalFileSystemTools：
    • 通过 enable_read_file 标志读取文件。
    • 默认保持target_directory内的文件操作；将 restrict_to_base_dir=False 设置为选择退出。
  • 工具：使用向后兼容的别名将 StudioTool 重命名为 StudioTools。

错误修复

  • 注册表/MCP：防止注册表中静默 MCP 工具丢失。
  • 工作流程：
    • 传播用于 WebSocket 工作流工厂运行的 trusted JWT 上下文。
    • 修复了与异步数据库一起使用时同步会话方法无提示地中断的问题。
  • Google Drive：限制 Google Drive 下载文件名。
  • 运行输出：get_last_run_output 不再为代理和团队子类返回 None。
  • 知识：在没有内容数据库的情况下保留知识过滤器。
  • MCP：在 MCP 重新连接期间传播 CancelledError 并丢弃冗余的 build_tools。
  • 知识分块：应用重叠时，保持块哈希 ID 与内容同步。
  • AgentOS：修复了配置无表 500 秒和 A2A 流终端事件。
  • 序列化：修复了在 Web 搜索工具输出中转义为 Unicode 序列的非 ASCII 字符。
  • CustomApiTools：防止身份验证标头泄漏。
  • 性能评估：将 p95 运行时间和内存保持在小样本的观察范围内。
  • CsvTools：查询名称中包含连字符或其他特殊字符的CSV文件。
  • 知识：设置 Reader(chunk=False) 时，URL 摄取不再对文档进行分块。
  • 工具：修复了异步生成器工具无法运行的问题。
