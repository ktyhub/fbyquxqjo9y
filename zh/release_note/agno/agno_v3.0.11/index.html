agno v3.0.11

修订 发布时间2026年9月23日 来源agno-agi/agno 英文原文

#Changelog

新功能：

  • 知识检索管道：Knowledge.search() 现在运行一个知识级别检索管道，可以在重新排序器重新排序之前扩大候选池，因此不再需要为每个向量数据库实现重新排序器。
  • MMR Reranker：添加了 MMRReranker（最大边际相关性）作为平衡相关性与多样性的检索策略，因此接近重复的块不会排挤结果集。
  • 页面源重新定位：添加了 Knowledge.inspect_page_source / ainspect_page_source 和受保护的 migrate_page_source / amigrate_page_source，以将索引文档源移动到新主机名。默认情况下，迁移是一次试运行。
  • 新近度重新排名：添加了 RecencyReranker，它将搜索分数与时间戳上的指数衰减混合在一起，因此较新的修订版比被取代的修订版排名更高。建立在知识水平管道之上，专注于 pgvector。
  • 键入页面工具结果：添加了带有明确错误、完整性和截断元数据的 PageCommandResult 和 PageFileSystem.run_command_result / arun_command_result。 Knowledge.get_tools(page_results=True) 返回排序的 SearchResult 对象，包括 MCP 结构化输出。
  • Y-API：添加了 YAPI 作为 OpenAI 兼容模型提供程序。
  • 取消阶段：向 RunOutput、TeamRunOutput、WorkflowRunOutput 和运行 ZZPH100​​ZZ 架构添加了机器可读的 cancellation_stage（PENDING、EXECUTING、INTERRUPTED 或未知），因此 client 不再与取消消息文本匹配。
  • OpenAIResponses：添加了 use_previous_response_id，因此 store=True 不再强制自动 previous_response_id 链接。

改进：

  • MCP 工具架构：AgentOS MCP 工具上的每个参数现在都在其 inputSchema 中带有描述，而 get_sessions 将 limit 和 page 限制为最小值 1。
  • 推理检测：当通过任何 OpenAILike 提供商（例如 DashScope）提供服务时，DeepSeek 思维模式模型 ID 被识别为推理模型。
  • 工具：从工具文档字符串中删除了幻像 Args 条目，并更正了两个模型类中的流文档字符串参数名称。

错误修复：

  • 工具挂钩：返回 function_call(**arguments) 的同步挂钩现在在异步执行路径中工作。以前，链将未等待的协程视为工具结果，并且工具主体从未运行。
  • MCP 服务器卡：裸机 mcp=True 现在安装与 MCPConfig 相同的路由层，因此主机检查和安装前缀适用于两种拼写。删除了未实现的 ETag / If-None-Match CORS 标头。
  • MCP 工具：原始 ClientSession 上的工具发现现在收集每个 tools/list 页面，而不仅仅是第一个页面。
  • AG-UI：支持ag-ui-protocol 1.0，包括简历上的列表值工具结果内容。
  • 基于 WebSocket 的工作流程：版本固定的提交不再在没有 pin 的情况下排队，在写入路径上检查会话所有权，并且丢失的会话 ID 会像 HTTP 一样创建一个新会话。
  • JSONReader：保留标量 JSON 根。
  • CSVReader：读取文本流，而不仅仅是字节流。
  • CSVReader 和 FieldLabeledCSVReader：在读取之前验证 page_size，因此零或负值会引发 ValueError，而不是默默返回任何文档。
  • 结构化输出解析：从模型输出中提取 JSON 对象时，忽略散文中不匹配的右大括号。
  • GoogleDriveTools：读取分组形状内的文本并在提取 .pptx 文本时遵循换行符。
  • UTF-8 文件：read_yaml_file / write_yaml_file、AntigravityTools 和 AirflowTools 现在以 UTF-8 方式读写文件，无论区域设置如何。
  • DuckDbTools：转义 CSV 分隔符。
  • TavilyTools：转发提取选项。
  • Cookbooks & Docs：替换了知识源中的死链接，并修复了 V3 迁移指南中的重复单词。添加了 Inspeximus 内存和 Confident AI 可观察性示例。

弃用：

  • 矢量数据库重新排序器：矢量数据库上的 reranker 参数已被弃用，取而代之的是 Knowledge 上的重新排序器，它适用于每个矢量数据库并支持异步。
