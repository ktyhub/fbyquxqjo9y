iotdb v2.0.12

iotdb v2.0.12

功能和改进

**SQL注入预防：**重构表模型的PreparedStatement以防止SQL注入 集群管理： 支持IPv6集群部署 REST： REST API 支持设置 client 时区 **数据同步：**优化表模型中非第一个TAG列的过滤性能 数据导入/导出工具： Load 文件的降级策略 数据库管理： SHOW CREATE DATABASE/TOPIC/PIPE **计算-查询执行-SQL子句：**优化select *查询列太多时的错误消息 功能： 新增时频分析功能（FFT） 功能： 新增滤波功能（高通、低通） 最新点缓存： 最新点缓存支持表/库粒度启用/禁用 功能： 表模型的内置rate/increase/irate/delta聚合函数 功能： 新增序列相关函数（XCorr） 功能： 内置M4表值函数 功能： 时间序列趋势匹配表值函数 功能： 新增内置表值函数read_tsfile，支持使用SQL直接从指定tsfile中查询 树模型元数据： 在现有设备下创建新的时间序列时，忽略create语句中指定的对齐/未对齐属性，使用当前设备的对齐/未对齐属性，而不是报错 Measurement： 优化了缓存写入时Measurement的验证结果 **设备粒度删除：**修复删除数据量较大的表并重新建表写入数据后，查询该表延迟较高的问题 **内存优化：**查询期间复制memtable TVList时的内存优化 **管道数据同步：**优化了**的匹配算法 **树模型元数据：**向设备节点添加了一个布尔标志，指示下面是否有其他设备，并调整了查询 select measurement from xxx.** SQL子句： 表模型中全表order by time + limit的性能优化 SQL子句： 表模型中全表查询的内存优化 **Pipe Data Sync：**优化Pipe内存块扩展/收缩算法

错误

**在线文件合并：**修复了 show disk_usage 导致合并挂起的问题 **树模型元数据：**修复了“没有匹配的数据库”问题 数据同步： 支持存储 TsFile 解析检查点进度，以便失败后重试时无需重新解析整个文件 **基本写入：**修复了对于同一对齐设备，先写入少列多行的请求，然后写入多列一行的请求生成WAL，在重启DataNode时，导致严重的memtable空值扩展，最终导致DataNode重启挂起的问题 **TsFile Sync：**加载tsfile时，修改副本集比较逻辑：比较副本集时，不再关心列表顺序，只比较集合内的元素是否完全相同；将列表比较更改为集合比较 **管道数据同步：**修复了将部分插入写入转换为平板电脑时管道为空测量点抛出 NPE 的问题 **管道数据同步：**修复了管道在 tsfile 解析超时后停止的问题 **在线文件合并：**修复了创建硬链接失败时合并没有回退到复制的问题 **管道数据同步：**添加了每管道独立内存配额限制或公平调度 **管道数据同步：**针对磁盘已满或接收器不可用的情况实现了指数退避和断路器保护 管道数据同步： 添加了对正在运行的 TsFiles 的全局和每个管道的限制 **管道数据同步：**修复了 drop pipe 没有等待接收器返回的问题 **数据导入/导出工具：**修复了在以 root. 前缀命名的数据库已存在时执行 tsfile load 时的错误 **表模型元数据：**优化了表视图中用反引号转义的特殊字符的处理 **管道数据同步：**删除管道时有异步进程（例如恢复）；异步执行结果需要传达给用户 管道数据同步： Drop pipe不再等待接收器返回，确保完全移除管道 **管道数据同步：**修复了执行管道创建/启动/停止/删除命令时分配器部分的滞后 **管道数据同步：**通过减少管道接收器端的日志量来修复过多的日志记录问题 **管道数据同步：**修复了在 1.3.x 中拆分 tsfile 以将部分数据同步到 2.x 失败的问题
