iotdb v1.0.1

修订 发布时间2023年2月17日 来源apache/iotdb 英文原文

新功能

  • [IOTDB-5102] 支持使用align by device子句解释sql
  • [IOTDB-5282]添加SQL show Variables，可以显示当前集群变量

改进

  • [IOTDB-4595] 为 tsfile 合并添加实时监控数据
  • [IOTDB-5125]启动 ConfigNode 或 DataNode 时端口已在使用中时停止进程
  • [IOTDB-5185] 修复了 IoTConsensus 中旧快照未删除的问题
  • [IOTDB-5202] 支持显示有关数据库的区域
  • [IOTDB-5205]构建Cluster Node启动协议，使用错误数据时拒绝ConfigNode或DataNode的启动或重启请求
  • [IOTDB-5208] 修复 TsFileResource 降级并使用快速执行器压缩时文件句柄的增加
  • [IOTDB-5223]当数据目录配置多个磁盘且dataRegion共识协议使用Ratis时，导致DataNode启动失败
  • [IOTDB-5232] 添加架构内存使用指标监视器
  • [IOTDB-5249]添加用户自定义mqtt的payload formatter时设置数据类型的接口
  • [IOTDB-5258] 为 ExportCSV/ExportTsFile 工具添加超时参数
  • [IOTDB-5306]更改ConfigNode和DataNode的默认端口
  • [IOTDB-5326] 添加 cluster_name 参数以区分不同的集群
  • [IOTDB-5389] 在 IoTConsensus 中禁用 wal_mode 时导致 DataNode 启动失败

错误修复

  • [IOTDB-4978] 修复使用 select into 时可能出现的死锁
  • [IOTDB-5090]修复执行stop-datanode.sh时的NPE
  • [IOTDB-5116] 修复查询时间序列中没有数据时聚合查询中错误的空结果集
  • [IOTDB-5118] 修复datanode打开过多文件句柄（TYPE DIR）
  • [IOTDB-5174] 修复了 IoTConsensus 主机名包含“-”时重启失败的问题
  • [IOTDB-5126] 修复了显示区域显示 IP 而不是主机名的问题，即使注册时使用了主机名
  • [IOTDB-5135] 修复同步文件为空时同步快照失败（也会阻止 ConfigNode 快照）
  • [IOTDB-5141] 修复快速压缩调度程序错误
  • [IOTDB-5144] 修复 jdbc 的 IoTDBDatabaseMetadata 中的 classCastException
  • [IOTDB-5158] 修复从 tsfile 获取设备失败的问题
  • [IOTDB-5170]修复Windows平台执行stop-confignode.bat时datanode关闭的问题
  • [IOTDB-5210] 修复驱动程序初始化和关闭引起的并发错误
  • [IOTDB-5212]非法CQ验证提示从v0.14.0升级为v1.0
  • [IOTDB-5215] 修复 IoTDBDescriptor 中 chunkPointNumLowerBound 的错误使用
  • [IOTDB-5216] 修复按时间序列排序在对齐的最后一个查询中不起作用
  • [IOTDB-5222] 修复一些指标相关配置的负载
  • [IOTDB-5231] 修复绑定9091错误时Datanode无法启动
  • [IOTDB-5233]更正模式模板不支持thrift接口的消息
  • [IOTDB-5236] 修复DeleteData Python API 无法工作的问题
  • [IOTDB-5240] 修复模式模板时间序列重启后读/写错误
  • [IOTDB-5261] 修复 AsyncIoTConsensusServiceClient 的 client 池中的 client 数量无法通过 dn_max_connection_for_internal_service 更改
  • [IOTDB-5266] 完善交叉选择器代码，修复使用FileTImeIndex时的bug
  • [IOTDB-5269] 修复执行 delete from sql 后应删除设备的错误数据
  • [IOTDB-5277] 修复 SchemaRegion 加载快照时 DataNode 重启失败的问题
  • [IOTDB-5278] 修复 JDBC Driver 无法连接到 dbeaver
  • [IOTDB-5285] 修复使用不同时间分区配置重新启动时的 TimePartition 错误
  • [IOTDB-5286] 修复目标文件被选择参与其他压缩任务的问题
  • [IOTDB-5313] 修复 Python client 无法正确处理 REDIRECTION_RECOMMEND
  • [IOTDB-5452]添加leastDataRegionGroupNumSetByUser检查以确保leastDataRegionGroupNum不会被系统更改
  • [IOTDB-5498] 修复设备和会话数量较多时 SessionPool OOM 问题
  • [IOTDB-5501] 修复 MemoryPool 中的内存泄漏
  • [IOTDB-5525] 修复分区获取器后设备分区错误
