svelte svelte@5.57.0

小改动

  • 壮举：从 svelte/server 导出 RenderOutput、SyncRenderOutput、Csp 和 Sha256Source (#18648)
  • 壮举：将 has 功能添加到 createContext (#18472)
  • 壮举：在 <select> 上支持 defaultValue (#18591)
  • 壮举：将 getOrInsert/getOrInsertCompulated 添加到 SvelteMap (#18728)

补丁更改

  • 修复：在分配商店的承诺上阻止模板商店订阅 (#18582)
  • 修复：通过invoke_error_boundary路由$衍生的拆卸错误（[#18486]（https://github.com/sveltejs/svelte/pull/18486））
  • 修复：跟踪反应中的 SvelteDate 快照 (#18700)
  • 修复：在卸载时移除 <svelte:head> 锚点 (#18697)
  • 修复：对 <svelte:window>、<svelte:document> 和 <svelte:body> 上未声明的速记事件处理程序发出警告（#18480）
  • perf：重用 <option>/<select> 值保护中的缓存值（#18713）
  • 修复：防止具有静态 value 属性的 <select> 格式错误的 AST 输出（#18449）
  • 修复：应用所有权突变会忽略绑定分配（#18718）
  • 修复：当compilerOptions.hmr为true时，防止onoutroend触发两次（#18655）
  • 修复：打印时保留内联元素后面的空格（#18685）
  • perf：将 SSR 块打开标记折叠到分支的第一次推送中（#18712）
  • 修复：当服务器渲染抛出异常时运行 onDestroy 回调（#18585）
  • 修复：在符文模式下报告 export let x = $derived(...) 的 derived_invalid_export (#18692)
  • 修复：永远不要将类哈希应用于 <svelte:head> 内的元素（#18160）
  • 修复：将 defaultChecked 保留在具有扩展属性的水合无线电输入上（#18701）
  • 修复：在 a11y_mouse_events_have_key_events 中接受 onfocusin/onfocusout (#18689)
  • perf：O(n²)→O(n) 旧版 $: 反应式语句排序的映射查找（#18602）
  • 修复：样式/类指令上的不同记忆器（#18466）
  • 修复：在应用起始样式之前测量嵌套过渡（#18647）
  • 修复：不要将 $state 中存储的组件实例转换为状态代理（#18646）
  • perf：为具有单个子元素的元素发出 $.only_child (#18717)
  • 修复：从 SSR 输出中省略 bind:focused （它没有 HTML 属性）（#18724）
  • 修复：Svelte 自定义元素槽的渲染更加稳健（#18710）
  • perf：优化 @const 标签中的简单对象解构（#18390）
  • 修复：在 CSR 期间正确应用静态文本区域值属性 (#18727)
  • 修复：在同步段末尾结束恢复的反应上下文（#18694）
  • 修复：保留抛出的反应的依赖关系，因此它读取的派生既不会泄漏，也不会陷入错误（[#18703]（https://github.com/sveltejs/svelte/pull/18703））
  • 修复：当祖先块暂停和恢复时，不要复活外层元素（#18431）
  • perf：使用 $.comment() 作为单注释模板（#18714）
  • 杂务：将 @types/trusted-types 移至 devDependencies (#18730)
  • perf：将设置器缓存存储为 Set 而不是 Array (#18251)
  • 修复：在服务器端渲染期间正确转换派生分配并选择函数绑定（#18669）
  • 修复：在服务器上渲染属性对象时，将布尔属性保留为空字符串值（#18721）
  • 修复：协议设置器清除端口时同步 SvelteURL 端口信号 (#18705)
  • 修复：在闭包内读取异步值的块声明标签和 {@const} (#18533)
  • 修复：避免导出片段的 CSS 树摇动 (#18540)
  • perf：再次将 <img loading> 视为静态元素（#18711）
  • 修复：防止 selectedcontent 突变更改所选选项（#18495）
  • 修复：对于没有布局框的元素，避免 slide 过渡中的 NaN 关键帧值（#18430）
  • 修复：在属性值中保留换行字符引用 (#18691)
  • 修复：解码大写-X 十六进制数字字符引用 (&#X...;) (#18708)
  • 杂务：澄清 $effect.pre 何时相对于 DOM 更新运行（#18534）
  • 修复：范围 SSR 边界失败的片段到其边界（#18593）
