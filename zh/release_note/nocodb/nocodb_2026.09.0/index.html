## 可用性 |特色 |社区版 |免费云计划 |云/本地付费计划 | | --- | :---: | :---: | :---: | | Claude 连接器中的 NocoDB | ✅ | ✅ | ✅ | | MCP 工具增加 1200% | – | ✅ | ✅ | |工作流程中的富文本电子邮件 | – | – | ✅ | 富文本电子邮件需要 NocoDB Cloud 上的 Plus 计划及以上版本。在社区版中，MCP 服务器保留其记录工具。 ## Claude 连接器中的 NocoDB NocoDB 现在在 Claude 连接器中可用，因此可以从连接器目录将基础连接到 Claude，而不是手动添加 MCP URL。连接后，Claude 可以使用连接用户角色允许的每个 MCP 工具，截至此版本，共有 149 个工具集覆盖整个工作区。 ## MCP 工具增加 1200% MCP 服务器已从 11 个工具增加到 149 个，覆盖整个工作区，而不仅仅是记录。 Claude、ChatGPT、Cursor 或任何 MCP client 现在可以在 NocoDB 中构建：建立一个表、将工作流连接到 Webhook、组装界面页面或锁定权限，所有这些都在一次对话中完成。 工具涵盖表、字段、视图、过滤器、排序、工作流、界面、仪表板、小部件、脚本、文档、Webhooks、注释、权限、记录级安全性、行着色、文件夹、成员以及 CSV 导入和导出。每个都包装与其 REST API 相同的服务，因此验证、权限和审核是相同的，并且每次调用都尊重调用者的角色：查看者读取、编辑者写入、创建者更改架构。 [了解更多MCP →](https://nocodb.com/docs/apis-and-mcp/mcp) 149只是一个开始。我们已经在构建下一组，这将永远改变商业软件。 ## 工作流程中的富文本电子邮件 现在可以格式化工作流程电子邮件。发送电子邮件、SMTP、Gmail 和 Outlook 节点共享一个富文本编辑器，该编辑器支持标题、文本样式、列表、颜色和带有自定义锚文本的链接。工作流程变量可以插入到正文中的任何位置。 [了解有关发送电子邮件节点的更多信息 →](https://nocodb.com/docs/workflows/nodes/action-nodes/send-email) ## 改进 - **跨界面页面的按钮** - 按钮现在可以放置在表格页面标题、记录审阅工具栏、仪表板组标题以及记录表内的字段组上。页面级按钮运行自动化，无需记录，*转到界面页面*可以在库中任意界面打开页面。 [了解更多](https://nocodb.com/docs/interfaces/elements#buttons) - **在列表视图中拖放** - 列表视图中的记录可以在层次结构中拖动：将一个记录拖放到另一个记录上以将其嵌套，或拖放到另一个父记录上以将其移动到那里。子记录与其父记录一起旅行，并且底层链接会为您更新。 [了解更多](https://nocodb.com/docs/product/tables/views/view-types/list) - **创建内联链接记录字段** - 当列表视图级别或嵌套记录需要尚不存在的链接时，click *创建链接记录字段*可在基本视图和界面生成器中当场创建它。 [了解更多](https://nocodb.com/docs/product/tables/views/view-types/list#nested-records) - **工作流表达式中的日期助手** - `$now()` 返回当前时间，`$dateAdd(date, amount, unit)` 对其进行偏移，例如 `$dateAdd($now(), 3, 'days')`。 - **更快的看板** - 优化的看板，以前是功能预览，现在是所有地方的默认设置，包括社区版。当您滚动时，堆栈会逐渐加载。 - **大型表格的 Excel 下载** - Excel 导出是流式传输的，因此非常大的表格可以可靠下载并生成较小的文件。 - **长文档中的任务进度** - 一旦标题滚动到视图之外，清单文档的任务计数就会跟随您进入标题。 ## 修复了什么 - **嵌套查找** - 查找的查找显示网格中的每个值，并在 MySQL、SQL Server 和 Oracle 上通过多对一链接正确解析。 - **使用当前用户的条件汇总** - 条件使用当前用户的汇总、查找和链接字段是为每个用户计算的，而不是从共享缓存提供。 - **同步可靠性** - 表同步现在始终完成，而不是停留在同步状态，并且编辑应用程序同步保存不会出现错误。 - **工作流程记录节点** - 测试创建记录或更新记录节点会报告与目标表不匹配的任何字段键，而不是写入空白记录。 - **界面记录表** - 单步执行记录时所做的编辑会立即显示在网格中，链接和取消链接操作提供*撤消*，并且在组内创建的记录保留在该组中。 - **界面键盘导航** - 打开记录表后，箭头键在网格中移动，表随之移动，Alt+向左和 Alt+向右在记录之间移动。 - **界面生成器** - 添加排序使下拉列表保持打开状态，对嵌入的链接视图进行分组，将其后面的页面保留在适当的位置，启动的界面反映从另一个选项卡发布的更改。 - **文档清单** - 勾选任务会实时反映给每个协作者，并且已完成的任务下呈现的新的未选中子项目不会带有删除线。 - **集成权限** - 尝试编辑其他人创建的集成会显示清晰的消息，而不是将您注销。 - **MCP** - 在社区版中对记录进行排序，没有基本角色的令牌会收到明确的访问拒绝响应，OAuth 授权从 clients（例如 OpenAI 平台）完成。 - **外部来源** - 超大的结果页面解释了如何减少字段或页面大小，而不是将来源报告为无法访问。 - **文件夹** - 外部数据源上的 *+* 按钮现在与 *Table* 一起提供 *Folder*，并且从项目的 *Move to* 菜单创建的文件夹采用项目在侧边栏中的位置，而不是列表末尾的位置。 ## 自托管注意事项 - **社区模式使免费功能保持可见** - 打开*仅显示社区版功能*后，工作流程、界面和文件夹保持可用，并且计划锁定的子功能将被隐藏，而不是显示为死控件。 - **安全强化** - 禁用或过期的 API 令牌在社区版中被拒绝，隐藏字段隐藏在共享视图上的行颜色规则后面，注释的范围仅限于其基础，并且在每个路由上强制执行表可见性。 - **更清晰的 PostgreSQL 权限错误** - 在没有表所有权的情况下尝试架构更改，完整命名受影响的表，包括带空格或混合大小写的引用名称。 - **未许可部署上的付费字段类型** - 社区版中未包含的字段类型（UUID、自动编号、颜色、唯一约束和查找限制）现在被 API 和 UI 拒绝。 ## 计划对 API 日期时间格式进行重大更改 此更改首次在 2026.08.2 中宣布，并且仍计划在即将发布的版本中发布。它不是 2026.09.0 的一部分。我们将通知保留在这里，以便可以准备集成。 在 PostgreSQL 和 SQLite 部署中，NocoDB 返回的日期时间值将从秒精度变为毫秒精度： |今天 |即将发布 | | --- | --- | | `2026-07-25 12:34:56+00:00` | `2026-07-25 12:34:56.000+00:00` | - **范围：** REST API 响应、Webhook 负载和 CSV/文件导出。值在读取时格式化，因此现有记录也以新格式返回。无需数据迁移或回填。 - **要检查的内容：** 使用严格或固定格式解析日期时间的消费者可能需要接受毫秒部分。 Day.js 等宽容解析器和大多数 ISO 8601 解析器不受影响。 - **过滤器：**范围过滤器和排序不受影响。精确日期时间相等过滤器以秒精度进行比较，因此它们可能与携带非零毫秒的值不匹配。毫秒感知过滤计划作为后续措施。 -
