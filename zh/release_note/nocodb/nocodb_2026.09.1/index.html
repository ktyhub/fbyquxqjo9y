nocodb 2026.09.1

这个项目是干啥的：一个开源版Airtable，把数据库变成在线表格看板还能嵌入关联记录，给不想写代码就想管数据的团队用。

变更架构图

亮点

  • 账号级 MCP 连接——能力大幅跃升，但受套餐限制 — 一条 MCP 连接现在可以覆盖你选定的所有 base，工具权限不会超过你自己的角色；服务端工具增至 199 个（比 2026.09.0 多 50 个），新增成员/团队管理、附件上传、upsert、审计日志、回收站恢复和发布。仅 Cloud Free 及付费套餐可用——Community Edition 完全没有——所以如果你用 MCP 自动化 NocoDB，这就是头号变化，agent 的工具列表里会多出约 50 个工具。
  • v3 API 使用者的破坏性变更——升级前先迁移 — 货币选项改用 currency_code 和 currency_locale，表单校验器 minValue、maxValue、custom 会被直接拒绝。仍在发送旧货币选项结构或这些校验器的 v3 集成都会崩；这是发布说明里唯一明确的破坏性变更，需要你改代码。
  • 自托管：加载更快，以及安全/导出变化 — 静态文件做了缓存和压缩，首次加载体积约缩小到 1/3.6；超级管理员在许可证服务器不可达时会看到警告和 Retry now；审计日志访问收紧，同时清理了文件名并修补了依赖。另外注意：CSV 货币导出不再带千位分隔符，Excel 导出现在把 Currency/Decimal 写成真正的数字而不是文本——如果你在下游解析这些导出文件，这点很相关。
  • 表工具与定向字段追踪 — 视图工具栏里的单个 Tools 按钮把字段、关联、权限、webhook 等表工具收拢到一个面板；Last modified time/by 字段现在可以只监听指定的字段。两项在所有版本都可用，所以 CE 用户确实能拿到实实在在的 UI 改进。
  • 值得升级，但有前提 — 分组表格、导入/快照/复制、工作流、看板、邀请（含 CE 和自托管注册）、Airtable 导入都有扎实的修复，被其中任何一条戳中就该升；Timeline View 里的 Summarize（Business+）和 YouTrack Sync（Plus+）是付费专属的额外项。为了 MCP、自托管的性能/安全收益或这些修复都可以升级；不受影响的稳定 CE 环境可以跳过。这不是空发布或仅改元数据的重新打标——是在 2026.09.0 之上的一次实打实的功能+修复版本。

帐户范围的 MCP 连接

现在，一个 MCP 连接可以使用您允许的工具到达您选择的每个基地，但绝不会超出您自己的角色。服务器现在有199个工具，比2026.09.0多了50个，包括成员和团队管理、附件上传、更新插入、审核日志、垃圾恢复和发布。 了解更多MCP →
