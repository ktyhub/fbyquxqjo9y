##网格中的实时存在
实时状态让您可以看到网格内的团队。每个协作者都会获得一种颜色，跟随他们从一个单元到另一个单元，并且他们打开的记录带有一个状态徽章。在通话中一起查看数据？ Click 去那里，您就准确地降落在他们工作的地方。

文件夹

文件夹允许您将表、文档和仪表板分组到可折叠文件夹中。这同样适用于表中的视图。适用于所有计划、NocoDB 云和自托管部署。 了解有关文件夹的更多信息 →

冻结多个字段

当您水平滚动时，网格视图现在最多可以保留三个字段，包括显示值。拖动分隔线以选择保持冻结状态的字段数量。使用网格可视化的界面页面也支持冻结字段。 了解更多

列表视图中的嵌套记录

现在，列表可以使用指向同一个表的链接字段将记录嵌套在其父项下：考虑带有子任务的任务、带有项目的类别或组织结构图。嵌套记录也可在使用列表可视化的界面页面上使用。 了解更多

从现有视图复制设置

创建接口表或记录查看页面时，“连接到表”步骤现在提供“从视图复制设置”选项，该选项可从现有视图生成新页面。 了解更多 - 对界面字段进行更多控制 - 记录页面和表单获得每个字段的 大小 选项来放大重要输入，记录页面上的单选字段可以显示为 步进器，使用点或编号指示器一次遍历一个 click 选项，并且“字段”窗格现在支持在每个可视化中拖放重新排序。

  • 仪表板权限 - 仪表板获得每个仪表板的可见性和编辑权限，使用与表和字段相同的权限系统，因此您可以控制谁可以查看或编辑每个仪表板。 了解更多
  • 按系统用户过滤 - 创建者和上次修改者过滤器现在列出 NocoDB 自己的服务参与者：自动化、同步、工作流和用于公共表单提交的匿名。 - 工作流中来自 URL 的附件 - 创建记录和更新记录工作流节点现在可以填充来自 URL 的附件字段。
  • API 改进 - v3 记录更新插入端点现在接受内联链接字段，通过 ID 或显示值解析链接记录，并且 v3 字段架构现在公开货币字段的已解析货币符号。

修复了什么

  • 在已安装的应用程序中进行双因素登录 - 当 NocoDB 作为应用程序 (PWA) 安装时，双因素身份验证现在可以顺利运行。
  • 计划的快照名称 - 自动快照现在使用计划的时区命名，因此夜间快照带有它在您的时区实际运行的日期。
  • 网格中的富文本预览 - 启用富文本的长文本字段现在可以在网格预览中清晰地呈现，特殊字符可以正确显示并保留链接 URL。
  • AI 助手响应恢复 - 由于连接断开或页面刷新而中断的响应现在可以从中断处恢复。
  • 通过 API 进行的字段更新保留相关字段 - 通过 API 更新字段现在被视为部分更新，保留引用它的 QR 码和条形码字段。
  • 链接字段权限 - 现在通过 API 链接记录（包括嵌套插入和更新）时强制执行字段编辑权限，并且链接选择器尊重只读链接字段。
  • 界面构建器修复 - 可以独立于其页面删除记录详细信息布局，从构建器中显示的视图复制的过滤器，按钮的新记录表单从页面自己的字段开始，以及在关闭内联编辑的页面上双击 cli 记录可以打开内联编辑记录。
  • 界面权限 - 界面页面现在尊重在基础上配置的字段编辑权限，只读预览会在您尝试编辑时显示通知，从工作区中删除成员也会删除其界面访问权限。现在可以正确列出并强制执行通过团队授予的访问权限，并且共享对话框中的角色选项带有帮助文本，解释每个角色可以执行的操作。
  • 界面布局优化 - 界面页面可以通过在侧边栏中拖动来重新排序，记录表单上的组可以通过拖动来重新排序，表单输入位于拆分行中自己的标签下，列表可视化列在调整大小后保持其宽度，列表中的键盘导航使所选记录保持可见。
  • 浅色模式下的网格线 - 在网格视图和列表视图中，在浅色模式下更容易看到行线和列线。
  • 个人和锁定视图中的新字段 - 个人和锁定视图保留其配置的字段列表：添加到表中的字段保持隐藏状态，直到视图所有者显示它们。
  • 按钮可见性条件 - 编辑按钮字段引用的字段时，会保留按钮字段的可见性条件。
  • 工作流程修复 - 条件节点之后的分支现在遵循节点实际发出的端口，包含逗号的附件 URL 将作为单个附件处理，按显示值链接记录可与引号和其他特殊字符配合使用，动态（变量）过滤器现在可以在公式字段上使用，并且过滤器弹出窗口在窗口中保持完全可见。
  • 智能文本可编辑性 - 现有智能文本字段在无法启用新智能文本字段的部署中保持可编辑状态。
  • 转换 UUID 和自动编号字段 - 将字段从 UUID 或自动编号转换出来现在会清除其只读状态，并且基础列的可为空性与字段设置保持同步。
  • SSO 登录错误 - 失败的 SSO 登录现在会显示一个清晰的错误页面，解释出现的问题。
  • 带有附件的基地复制 - 即使基地包含其他成员上传的附件，基地也能可靠地复制。

自托管注意事项

  • 旧版 API 令牌 - 许可的自托管部署不再支持创建新的旧版 API 令牌。现有的旧版 API 代币继续有效；使用细粒度的 API 令牌进行新集成。 了解更多
  • 重命名代码执行和网络搜索变量 - E2B 和 Exa 环境变量已重命名：
  • 环境名称更改 |旧环境变量 |新环境变量 | | --- | --- | | E2B_API_KEY | NC_COMPUTE_E2B_API_KEY | | E2B_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_SCRIPT | | E2B_CHAT_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_CHAT | | EXA_API_KEY | NC_WEB_EXA_API_KEY | 如果您使用这些，则不再读取旧的环境变量：在升级或脚本执行、AI代码分析和AI网络搜索时更新它们。模板变量现在是可选的，并回退到 NocoDB 自己的模板。 了解更多

文档得到修改

  • 随着 NocoDB 的不断发展 - 我们认为现在是修改我们文档的最佳时机。专用选项卡涵盖产品、工作流程、接口、APIs 和 MCP、自托管 和 Changelog，并且产品侧栏现在将页面分组到下面核心、管理和连接，因此相关主题放在一起。文档中之前的每个 URL 都将被正确重定向到正确的页面。
  • 在文档中询问 AI - 每个文档页面现在都包含一个 Ask AI 助手，它使用文档作为源以简单的语言回答问题，因此您可以询问“我该怎么做 X”，而不是在页面中搜索。
