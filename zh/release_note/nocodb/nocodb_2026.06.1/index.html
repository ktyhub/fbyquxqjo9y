nocodb 2026.06.1

## 可用性 |特色 | CE / 免费 |付费/企业| |---|:---:|:---:| |自定义同步 | – | ✅ | |白标| – |企业附加组件 | | SQL Server 支持 | – |企业附加组件 | ## 自定义同步 **自定义同步** 将现有 PostgreSQL 或 MySQL 数据库中的表作为只读同步表镜像到 NocoDB 中，并与其源保持最新状态，为业务团队提供生产数据的友好界面，而无需迁移或导出脚本。选择表，微调每列映射到 NocoDB 字段类型的方式，并手动刷新或按计划进行完整或增量运行。适用于商业计划及以上版本、NocoDB 云和自托管部署。 [了解有关自定义同步的更多信息 →](https://nocodb.com/docs/product-docs/sync/app-sync/custom) ## NocoDB 云上的规模计划 **Scale** 是商业和企业之间的新 NocoDB 云计划，将治理功能引入自助服务计划中。它解锁**无限工作区**、**行级安全性**、**工作区审核日志**和**垃圾保留设置**，以及对记录、存储、API 调用、自动化运行和保留的更高限制。 [了解有关计划和定价的更多信息 →](https://nocodb.com/pricing) ## 白标 **白标** 将您的整个 NocoDB 部署重新命名为您自己的产品。从管理面板中的新白标签选项卡设置您的产品名称、徽标、网站图标和品牌颜色，品牌标识将贯穿登录页面、公共表单、共享视图和交易电子邮件。作为自托管部署的企业客户的附加组件；请联系支持团队 ([support@nocodb.com](mailto:support@nocodb.com)) 来启用它。 [了解更多有关白标的信息 →](https://nocodb.com/docs/self-hosting/white-label) ## SQL Server 支持 **Microsoft SQL Server** 将 PostgreSQL 和 MySQL 作为 NocoDB 中的可连接数据库加入。将其作为外部数据源连接并通过网格、视图和字段使用它，或将其用作[自定义同步](#custom-sync) 源以将表镜像到您的基础中。作为企业客户的附加组件提供；请联系支持团队 ([support@nocodb.com](mailto:support@nocodb.com)) 来启用它。 [详细了解连接数据源→](https://nocodb.com/docs/product-docs/data-sources/connect-to-data-source) ## 改进和修复 - **NocoDocs 中的实时协作。** 多人现在可以同时编辑同一页面：命名光标、状态化身、自动无冲突合并以及在重新连接时协调的离线编辑。 [了解更多→](https://nocodb.com/docs/noco-docs/collaboration) - **将文本转换为链接记录。** 将单行文本字段转换为链接字段；单元格值通过显示值与相关记录进行匹配，转换可以双向进行并且不可撤消，文件导入现在可以将列直接映射到链接字段。 - **日历 3 天视图。** 天和周之间的新布局将接下来的几天保留在一个集中框架中，记录按计划时间排序并通过拖放重新安排。 - **NocoDocs 中的网络书签。** 新的 `/web bookmark` 块可将任何链接变成包含页面标题、描述和预览图像的丰富视觉卡。 [了解更多→](https://nocodb.com/docs/noco-docs/document-content/web-bookmarks) - **在大型表单上构建表单的速度更快。** 编辑具有 100 多个字段的表单变得更加流畅：字段之间的切换从大约 550 毫秒下降到 40 毫秒，打字延迟从大约 380 毫秒下降到 90 毫秒。 - **网格视图会记住您离开的位置。** 返回视图会恢复之前的滚动位置，而不是跳回到顶部。 - **一次最多选择 1,000 行。** 复制、粘贴和填充操作的多单元格选择限制从 100 行提高到 1,000 行。 - **付费计划的无限过滤器。** 每个视图 50 个过滤器的上限（也限制了表单字段条件）在所有付费 NocoDB Cloud 计划中都被删除。 - **文本过滤器现在默认为“is like”。**文本、电子邮件、URL 和电话字段的新过滤器以包含样式匹配而不是精确匹配开头。 - **在此页面上在 NocoDocs 中导航。** 页边距中的微妙标题栏显示您的位置；悬停以打开大纲并跳转到任何标题。也适用于共享文档。 - **NocoDocs 中的封面图像重新定位和全屏图像。** 拖动封面横幅以重新构建它们，并在全屏轮播中打开文档图像。 - **更安全的同步删除。** 删除同步现在会询问是将同步表转换为普通可编辑表还是将其与同步一起删除。 - **隐藏空白字段捕获空链接。** 扩展记录的隐藏空白切换现在还隐藏没有链接记录的链接字段。 - **复制 URL 公式会保留链接。** 复制生成链接的公式单元格现在会粘贴为可用链接，而不是原始公式语法。 - **查找附件下载已修复。** 通过查找字段显示的附件再次可靠地下载，并且嵌套查找呈现为正确的附件条。 - **过滤器值不再被截断。** 编辑具有许多选定选项的过滤器不再默默地删除超过 255 个字符的值。 - **刷新后导入进度仍然存在。** 重新加载页面后，导入等后台作业会继续报告进度。 - **照片以正确的方式向上显示。** 附件缩略图现在遵循 EXIF 方向，因此肖像照片不再横向渲染。 - **更顺畅的 SSO 登录。** 通过 SSO 登录不再偶尔会直接退出。 ## 安全 - **行级安全性现在适用于基础所有者。** 以前，无论 RLS 策略如何，基础所有者都可以看到所有记录。现在，像所有数据查询中的所有其他角色一样对所有者进行过滤，而策略管理仍然仅限于所有者。如果您的工作流程依赖于所有者查看所有内容，请在升级后检查您的策略。 - **强化的公开共享内容。** 共享库不再公开审核信息，共享视图请求不再通过过滤器或聚合引用隐藏字段，并且表单重定向 URL 受到严格验证。 - **CSV 导出可防止电子表格公式注入。** 可以被电子表格应用程序解释为公式的导出值现在已被转义。 - **对外部数据库连接提供更强的保护。** 连接详细信息在连接时进行验证，并且 API 响应不再包含敏感帐户材料。 ## 自托管 - **更精简、更干净的 Docker 映像。** 已重新构建已发布的映像，以修复所有已知的关键和高严重性依赖项漏洞，并且本地映像大约是以前大小的一半。 - **改进了安装程序和撰写示例。** 对安装脚本进行了彻底修改，并重新组织了 Docker Compose 示例，其中包括新的快速入门、Traefik 自定义 SSL、私有 CA PostgreSQL 和托管 PostgreSQL 示例。 - **新配置选项。** `NC_DOCS_REALTIME=false` 禁用新的文档协作层，`NC_GRID_MAX_SELECTION_LIMIT` 调整网格选择上限，`NC_DISABLE_DB_SSL_FILE_PATHS=true` 拒绝外部数据库连接中的文件路径 SSL 证书引用。 - **更好的多节点效率。** Redis 发布/订阅连接现在通过单个侦听器进行多路复用，从而减少繁忙的多实例部署的开销。 ## 弃用通知 这是发布预构建可执行文件的最后一个版本。可执行文件已弃用，从下一个版本开始将不再发布。如果您当前从可执行文件运行 NocoDB，请切换到 [Docker 或其他受支持的安装方法](https://nocodb.com/docs/self-hosting/installation/quickstart) 以继续接收更新。 ## 已关闭的问题 -
