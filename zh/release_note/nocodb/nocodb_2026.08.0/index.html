nocodb 2026.08.0

## 可用性 |特色 | CE / 免费 |付费/企业| |---|:---:|:---:| |接口| – | ✅ | ## 接口 **接口**允许您在基础数据之上构建自定义、易于使用的应用程序。您无需让每个人都可以访问完整的基础及其所有表格、视图和配置选项，而是设计重点页面，准确显示每个受众所需的数据和操作：审批者的审核队列、领导层的仪表板、现场团队的表单或将所有这些内容结合在一起的完整内部工具。你的基础仍然是唯一的真相来源；改变的是每个群体的体验方式。接口（**测试版**）可在**NocoDB Cloud**（Plus 计划及以上）和许可的自托管部署（商业计划及以上）上使用。 [了解更多接口信息 →](https://nocodb.com/docs/interfaces) ## 改进和修复 - **记录级安全性中的动态条件。** 策略现在可以引用正在查看数据的任何人，例如当前用户、他们的电子邮件或其团队，因此像“受让人是当前用户”这样的单个策略涵盖整个工作区。策略还可以根据系统字段进行过滤，例如创建者和上次修改者。可用于 NocoDB Cloud（规模计划及以上）以及自托管规模和企业计划。 [了解更多→](https://nocodb.com/docs/product-docs/roles-and-permissions/record-level-security) - **新的 WEEKNUM 公式函数。** `WEEKNUM(date, [startDayOfWeek])` 返回日期所在一年中的第几周，与电子表格的计算方式相匹配。默认情况下，周从星期日开始，可选的第二个参数选择一周中不同的第一天。 [了解更多→](https://nocodb.com/docs/product-docs/fields/field-types/formula/date-functions#weeknum) - **使用 Shift+click 选择一系列行。** 在 click 网格中的行复选框的同时按住 Shift，可以选择该行与 click 的最后一行之间的每一行，与电子表格的工作方式相同。 - **v3 链接更新的范围仅限于请求的记录。** 通过 v3 记录 API 更新链接字段不再从其他行中删除这些链接记录。 - **在 API v3 中按标题删除选择选项。** 字段选项删除端点现在接受选项标题而不是 id，并忽略不存在的标题。相应地更新现有的 v3 集成。 - **API v1 中的行为更改：用户更新不再更改工作区访问权限。** `PATCH /api/v1/users/{userId}` 不再更改默认工作区访问权限。要授予对特定基地的访问权限，请使用 `POST /api/v3/meta/bases/{baseId}/members` 和 `{ email, base_role }`。要允许基础创建和工作区范围的访问，请将 `POST /api/v3/meta/workspaces/{workspaceId}/members` 与 `{ email, workspace_role }` 结合使用。 - **分组视图在编辑时保持不变。** 按链接、用户、JSON 或附件字段分组的网格不再在每次单元格编辑时清空并重新加载。 - **滚动时不再有重复的行。** 当记录从过滤或排序的网格中删除时，进行中的提取可能会在视图中再次呈现它。 - **复制记录不再移动链接记录。** 逐字复制每个链接可能会默默地从原始记录中分离出多条和一对一的链接记录。现在，副本上会跳过这些链接，并会显示一条通知，列出未保留的字段。 - **使用 QR 代码进行更快的视图。** QR 代码单元格不再为每行生成全尺寸代码，这可能会冻结包含许多记录的视图。 - **快照可靠性。** 快照现在可以在权限受限的基础上以及已达到基础限制的工作区中运行。 - **智能文本修复。** 失败的初始加载不再允许自动保存清除单元格的内容，退格键在扩展编辑器中再次工作，表格显示用于添加行和列的持久栏。 - **汇总字段验证其目标。** 在无法聚合的字段（例如“链接”、“查找”或“按钮”字段）上创建汇总会被拒绝并显示明显的错误，而不是中断对表的每次读取。 - **服务器端脚本使用数据创建记录。** 由工作流和自动化运行的脚本中的 `createRecordsAsync` 不再创建空白记录。 - **图像查看器在表单中工作。**从表单打开图像附件不再引发错误。 - **NocoDB Cloud 上外部数据源上加载的列表视图**。 - **Postgres 导入保持自动增量同步。** 将库导入或迁移到 Postgres 后，创建第一条记录不再因重复键错误而失败。 - **SQLite 架构随索引而变化。** 删除或修改已连接 SQLite 数据库上的索引字段不再失败。 - **沙箱反馈。** 创建沙箱现在会通过消息进行确认，而不是默默地切换您，并且创建沙箱不支持的文档会通过解释禁用，而不是在 click 上失败。 - **更整洁的字段可见性控制。** 表详细信息中的字段面板现在使用眼睛切换来显示或隐藏当前视图中的字段。 - **各种稳定性修复。** Right-clicking 看板上的空白区域不再显示另一张卡片的操作，并且修复了选择单元格和画布网格中的一些崩溃。 ## 安全 - **输入处理。** 跨平台对过滤器表达式、重定向目标、连接配置和 OAuth 参数进行更强的验证。 - **数据访问控制。** 公共共享链接、导出和嵌套数据现在始终遵循视图筛选器和隐藏字段，并且记录级安全条件在数据、实时和缓存路径中统一应用。 - **身份验证和会话。** 强化的会话令牌轮换和 OAuth 授权流程以及通过身份提供商登录现在支持提供商的电子邮件验证状态。 - **嵌入保护。** NocoDB 页面现在发送框架保护标头，因此只有公共共享链接可以嵌入到其他站点中。 - **依赖项更新。** 依赖项已根据最近发布的建议进行更新。 ## 自托管 - **自行更改您的许可证计划。** nocodb.com 上 **帐户 → 自托管许可证** 下的每个许可证都会获得一个详细信息页面，其中包含其计划、计费周期、编辑器计数、续订日期和发票，以及更改计划流程。升级立即生效并按比例计费；降级在当前计费周期结束时生效，并且在此之前可以恢复。 [了解更多→](https://nocodb.com/docs/self-hosting/purchase-license) - **隐藏未许可实例上的付费功能。** **帐户 → 配置文件**下的新 **仅显示社区版功能** 首选项隐藏了付费功能徽章、升级提示和仅导致升级屏幕的控件，因此在没有许可证的情况下运行的实例仅显示其实际功能。该选项仅出现在未经许可的自托管实例上。 - **新的配置选项。** 三个 `NC_AI_*` 变量调整 AI 助手的代币预算：`NC_AI_TURN_TOKEN_BUDGET`、`NC_AI_INRUN_MICROCOMPACT_MIN_TOKENS` 和 `NC_AI_TOOL_OUTPUT_SPILL_MAX_ENTRIES`。 [了解更多→](https://nocodb.com/docs/self-hosting/environment-variables) --------- ### 已关闭的问题 -
