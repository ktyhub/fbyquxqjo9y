nocodb 2026.10.2

## 修复了什么 - **字段和公式** - 更改 PostgreSQL 上的字段类型会保留每个适合的值，重命名字段会更新使用它的公式，数学错误只会将其自己的行清空。 - **过滤器** - *是否*与精确选择选项匹配，删除空过滤器组，并且日期过滤器用于查找日期公式和汇总。 - **更多过滤器** - 保存时会拒绝具有错误值的日期过滤器，跨库链接上的过滤器适用于可以查看链接表的人员。 - **网格和记录** - 转义会取消单元格编辑，粘贴不适合的值会保留旧值，一次编辑会生成一个修订条目。 - **扩展记录** - Ctrl/Cmd+F 在扩展记录时使用浏览器的查找功能，并且在保存时从新记录*创建并链接* 会创建链接记录。 - **打字** - 使用中文或日文输入法输入的第一个键到达单元格，链接选择器中的条形码扫描仪链接扫描的记录。 - **日期和数字** - 100 年之前的日期保留其年份，来自外部数据库的小数字段使用列的比例，日历工作日遵循 UI 语言。 - **富文本** - 富文本和代码块在保存和重新加载后保留其内容和缩进。 [了解更多](/docs/product/tables/fields/field-types/text-based/rich-text) - **注释** - 尖括号中的文本（例如 `Name `）保留在注释中。 - **链接** - 在自链接上*创建并链接* 以正确的方式链接，从废纸篓中删除表会删除其链接字段。 - **查找** - 通过多对多链接的查找保留链接记录的显示值，嵌套查找上的过滤器应用查找自身的条件。 [了解更多](/docs/product/tables/fields/field-types/links-based/lookup#applying-filters) - **外部数据库** - PostgreSQL 生成的列是只读的，MySQL 日期时间汇总显示正确的时间，并且在创建任何内容之前，到具有复合主键的表的链接将被拒绝。 - **垃圾箱** - 删除或恢复记录会保留已在垃圾箱中列出的链接记录。 [了解更多](/docs/product/projects/project-trash#restoring-an-entry) - **复制** - 复制项目或表会跳过它不复制的跨库链接上的过滤器，并使用包含 `?` 的列默认值。 [了解更多](/docs/product/projects/actions-on-project#duplicate-project) - **导入和导出** - Excel 导入保留工作表名称，导出写入链接显示值。 - **CSV 导入** - 在 Id 上合并 CSV 会更新现有记录，导入记录的 Webhook 和工作流程会看到其链接。 - **看板** - 超过 25 个堆栈的板在*全部折叠*后显示每个堆栈。 [了解更多](/docs/product/tables/views/view-types/kanban#collapse-stack) - **日历** - 日期汇总上的日历将记录显示为全天事件。 - **经典应用程序** - 仪表板组过滤器适用于每个小部件，表单页面发送*电子邮件响应*，人员选择器仅列出有权访问的人员，表格页面显示数字分隔符。 - **表单** - 需要登录的表单在登录后打开，没有重定向循环。 - **工作流程** - 发送电子邮件接受逗号分隔的列表，运行历史记录显示运行在第一步之前失败的原因，使用 NocoAI 集成运行的脚本，以及永远无法运行的工作流程不会保持活动状态。 [了解更多](/docs/workflows/nodes/action-nodes/send-email) - **Webhooks** - 示例有效负载显示链接字段，就像真实的有效负载一样。 [了解更多](/docs/product/tables/table-operations/webhook/create-webhook#configuring-webhook) - **表同步** - 来自受密码保护的共享视图的粘贴链接同步接受密码。 [了解更多](/docs/product/sync/nocodb-sync#source) - **安全性** - 共享视图和共享仪表板仅返回它们显示的字段，表单仅写入自己的字段，编辑者不再看到工作流步骤中存储的机密，工作流 Webhook 接受最多 1 MB 的请求正文。 - **脚本** - `table.selectRecordsAsync({ recordIds })` 仅返回请求的记录。 [了解更多](/docs/workflows/scripts/api-reference/table#selectrecordsasync) - **团队** - 添加或删除团队成员会立即更新其项目角色。 [了解更多](/docs/product/collaboration/teams#assign-roles-to-teams) - **文档** - 拖动文档表中的列可调整该表的大小。 - **网格列** - 拖动列标题可以为每列保存唯一的位置。 - **手机和平板电脑** - 点击按钮字段会运行其操作，并且侧边栏开始在平板电脑上折叠。 - **错误消息** - 服务器错误再次显示为 toast，失败的 SQL 操作指出了连接问题。 - **计划标签** - 再次登录后侧边栏会显示正确的计划。 ## 自托管注意事项 - **SCIM 组** - 来自 Entra ID 和 Okta 的组授予其团队的工作区角色。 [了解更多](/docs/product/account-settings/authentication/scim#group-provisioning) - **气隙许可证** - *刷新许可证* 更新气隙许可证。 [了解更多](/docs/self-hosting/license-activation#refresh-license) - **MariaDB** - `REGEX_REPLACE` 和 `REGEX_EXTRACT` 在 MariaDB 上工作，MariaDB 作为元数据数据库。 [了解更多](/docs/product/tables/fields/field-types/formula/string-functions#regex_replace) - **外部数据库** - 超级管理员登录会关闭外部数据库连接，直到使用它们为止。 - **支持聊天** - `NC_DISABLE_SUPPORT_CHAT` 还会阻止浏览器加载聊天脚本。 [了解更多](/docs/self-hosting/environment-variables#support-chat) - **SSO** - 通过 `NC_SSO=oidc` 登录再次有效。对于 `NC_SSO=saml`，IdP 发起的登录会从 NocoDB 重新启动一次，因此 IdP 必须返回未更改的 RelayState。 [了解更多](/docs/self-hosting/environment-variables#authentication) - **Windows** - CSV 和文档导出可在 Windows 上使用本地存储。 - **AI 网关** - AI 功能与 OpenAI 兼容网关配合使用，在代码围栏内返回 JSON。 - **更快的链接写入** - 在社区版上，使用链接进行写入不再再次读取每个链接的记录。删除和添加链接的速度要快几倍，插入和更新链接的速度要快三分之一。 - **时区** - 当 PostgreSQL 报告旧时区名称（例如 `Asia/Calcutta`）时，日期公式起作用。 --- 有关上一版本中的更改，请参阅 [2026.10.1 changelog](/docs/changelog/2026.10.1)。 --- -
