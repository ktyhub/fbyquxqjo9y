**界面现在是经典应用程序。**您可以在*应用程序*下找到它们。您的页面、访问和发布版本保持原样。 [了解更多](https://nocodb.com/docs/classic-apps#classic-apps-were-interfaces) ## 可用性 |特色 |社区版 |免费云计划 |云/本地付费计划 | | --- | :---: | :---: | :---: | |时间线视图中的资源分配 | – | – | ✅ | |回放工作流程运行 | ✅ | ✅ | ✅ | |从按钮运行自动化 | – | ✅ | ✅ | |工作流程电子邮件中的图像和附件 | – | – | ✅ | |通过登录连接您的 AI 工具 | ✅ | ✅ | ✅ | |文本公式的单选格式 | ✅ | ✅ | ✅ | 时间轴视图需要 NocoDB Cloud 上的业务计划及以上版本。发送电子邮件、Gmail 和 Outlook 步骤需要 NocoDB Cloud 上的 Plus 计划及以上版本。 ## 时间轴视图中的资源分配 时间线视图现在可以在屏幕上显示每个人的计划任务使用了每天、每周或每月的工作时间。超额预订的时段会变成红色。该计算考虑了链接表中的工作日、休息时间以及多人共享的任务。 [详细了解时间轴视图中的利用 →](https://nocodb.com/docs/product/tables/views/view-types/timeline#utilization) ## 回放工作流程运行 单步执行过去在画布上运行的工作流程，无需再次运行任何内容。按状态、日期范围和需要注意的运行运行历史过滤器，并且可以停止、暂停、恢复或重试正在运行的工作流程。 ## 从按钮运行自动化 按钮字段现在可以运行自动化。在“运行自动化”下选择一个，或选择“创建新自动化”并在保存字段后构建它。 [了解有关按钮自动化的更多信息 →](https://nocodb.com/docs/product/tables/fields/field-types/custom-types/button#button-automation-) ## 工作流程电子邮件中的图像和附件 发送电子邮件、Gmail 和 Outlook 步骤可以附加来自附件字段、上传或 URL 的文件，最多 10 个文件。它们还可以携带内联图像，无需收件人打开远程图像即可显示。 [了解有关配置发送电子邮件的更多信息 →](https://nocodb.com/docs/workflows/nodes/action-nodes/send-email#configuration) ## 通过登录连接您的 AI 工具 *在帐户菜单中使用 NocoDB From* 通过登录连接 Claude、ChatGPT、Cursor、Claude Code 和其他 MCP clients，无需复制令牌。连接的应用程序永远不会获得比您自己的角色更多的访问权限。 [了解更多MCP →](https://nocodb.com/docs/mcp) ## 文本公式的单选格式 文本公式可以将其结果显示为彩色单选，而过滤器和排序仍将其视为文本。 [了解有关公式格式的更多信息 →](https://nocodb.com/docs/product/tables/fields/field-types/formula/formula-result-formatting#single-select) ## 改进 - **五个级别的分组** - 网格视图现在最多可进行五个级别的分组，将记录拖到另一个组中会更改其分组值。 [了解更多](https://nocodb.com/docs/product/tables/table-operations/group-by#add-or-edit-groups) - **成员和团队位于一处** - 工作区成员和团队共享一个 *成员和团队* 页面，每个团队都会显示其成员继承的工作区角色。 [了解更多](https://nocodb.com/docs/product/workspaces/workspace-collaboration#list-workspace-members-and-teams) - **新项目页面** - 每个*新项目*入口点都会打开一个页面，当NocoAI打开时会出现一个提示框。 [了解更多](https://nocodb.com/docs/product/projects/create-project) - **登录屏幕** - 重新设计登录、注册、双因素、密码重置、SSO 和邀请屏幕，并用徽章标记您上次使用的登录方法。 - **手机** - 网格、输入和日历月份视图在 iPhone 和 Android 上正常工作。 - **共享经典应用程序** - 经典应用程序构建器中的*共享*仅通过电子邮件或私人链接邀请人们访问该应用程序。 [了解更多](https://nocodb.com/docs/classic-apps/share#invite-people-to-a-classic-app) - **报告公共页面上的滥用行为** - 共享视图、表单、经典应用程序和仪表板带有*报告滥用行为*链接，自托管实例的超级管理员可以在管理面板中查看报告。 [了解更多](https://nocodb.com/docs/self-hosting/abuse-reports#what-a-visitor-reports) - **谁可以导出** - 打开*允许导出到 CSV* 后，经典应用程序页面可以按角色、用户或团队限制导出。 [了解更多](https://nocodb.com/docs/classic-apps/builder#page-settings) - **从表单添加链接记录** - 经典应用程序链接字段可以打开表单来创建记录并一步链接它。 [了解更多](https://nocodb.com/docs/classic-apps/layouts/record-detail#linked-records) - **从共享视图导入 Airtable** - 导入不带个人访问令牌的公共共享视图链接。 [了解更多](https://nocodb.com/docs/product/projects/import-project-from-airtable#import-from-a-shared-view) - **冻结更多字段** - 网格视图冻结适合窗口的尽可能多的字段，不再限制为三个。 [了解更多](https://nocodb.com/docs/product/tables/table-operations/freeze-fields) - **Rollups** - *Count All* 对每个链接记录进行计数，并且某个日期的最小值和最大值返回一个日期。 [了解更多](https://nocodb.com/docs/product/tables/fields/field-types/links-based/rollup#aggregation-functions) - **链接过滤器** - 动态条件可以匹配与当前记录共享链接的链接记录。 [了解更多](https://nocodb.com/docs/product/tables/fields/field-types/links-based/links#limit-by-filter-) - **新记录中的默认值** - 展开的表单显示保存前字段的默认值。 - **实时更新** - 当协作者编辑时，网格会就地刷新，并且分组视图保持其打开的组。 - **通过拖动更改显示值** - 将网格视图中的任意列拖动到显示值上，使其成为显示值。 - **用户过滤器上的记录计数** - 经典应用程序用户过滤器选项卡显示每个选项卡后面的记录数。 - **电子邮件显示名称** - `Jane Example ` 等电子邮件作为 mailto 链接打开。 - **更多货币** - 货币字段接受另外 19 个 ISO 4217 代码。 [了解更多](https://nocodb.com/docs/product/tables/fields/field-types/numerical/currency#supported-currencies) - **数据库 SSL 模式** - 外部连接在*否*、*首选*、*必需*和*必需-CA*之间进行选择。 [了解更多](https://nocodb.com/docs/product/integrations/create-connection#database-integrations) - **API 令牌权限** - 细粒度令牌可以读取和管理团队以及读取工作区。 [了解更多](https://nocodb.com/docs/product/account-settings/api-tokens#scopes-permissions) - **MCP 工具** - 文档注释工具、字段类型更改的预演以及带有 `SKILL.md` 入口点的技能指南。 [了解更多](https://nocodb.com/docs/mcp/skills) - **聊天中的 MCP 回退** - 当聊天代理没有满足您要求的专用工具时，它会回退到 MCP 工具。 - **更多云积分** - 每个 NocoDB 云计划都包含更多积分，免费 1,000 个以上。 [了解更多](https://nocodb.com/docs/product/workspaces/credits#monthly-plan-credits) - **环境和每用户凭据** - 现在两者都需要扩展计划。 - **更清晰的更新通知** - 应用内更新通知已重新设计。 ## 修复了什么 - **网格和视图** - 搜索、分组和日历月份视图的行为符合预期，多级列表视图使行保持滚动。 - **数据完整性** - 从错误的父级取消链接会保留真实链接，并且链接写入在 SQLite 和 MySQL 上成功。 - **字段和公式** - 查找链接时的公式有效，`ISBLANK` 在 SQL Server 上有效，持续时间值在复制或导入表、字段或项目时保留秒数。 - **过滤器** - *为空*和`in`过滤器适用于更多字段类型和数据库，API接受数字上的*is Between*，并且DateTime过滤器尊重时区。 - **附件** - 保存通过 v3 API 编写的附件和脚本，并在移动浏览器上预览 PDF。 - **导入和复制** - CSV 导入到单记录链接列中将单元格视为一个值。 - **工作流程** - 迭代过滤器匹配正确的行，服务器端脚本将项目访问保持在 60 秒以上。 - **Webhooks** - 跟踪特定字段的 Webhooks 仅当这些字段发生更改时才会触发。 - **经典应用程序** - 记录页面遵循链接字段的显示值，数字小部件聚合数字公式。 - **MCP** - 表单创作报告它不能应用的内容，而不是删除它。 - **稳定性** - 导航不再泄漏内存，并且多个对话框和弹出窗口关闭时不会出现错误。 - **计费** - 当取消催款周期时，发票会正确作废，并且升级后的工作区将停止收到宽限期电子邮件。 ## 自托管注意事项 - **节点 24.22.1** - Docker 映像移至节点 24.22.1，以实现 2026 年 10 月节点安全版本。 - **席位限制** - 席位上限仅适用于本地许可证设置为 1 的情况。 - **宽限期** - API 和自动化宽限期现在按预期开始，并且自动化宽限上限较低。 - **MCP 响应更改** - 某些 MCP 响应更改了形状，例如作为字符串的共享视图类型。 REST v3 API 保持不变。 -
