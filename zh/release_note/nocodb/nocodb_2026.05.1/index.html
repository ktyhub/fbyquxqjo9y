nocodb 2026.05.1

变更流程图

亮点

  • 破坏性配置变更——升级前先读 — NC_PUBLIC_URL 已改名为 NC_SITE_URL，并且现在是必填；升级时要把它设成实例的公网 URL，否则分享链接、OAuth 重定向和邮件链接都会生成错误。另外，Smart Text 和自助许可证需要 NocoDB 内部托管的 PostgreSQL base——SQLite/MySQL 部署必须先迁移，这些功能才能用。
  • 数字格式行为变化 — 新的 Thousands and decimal separators 下拉框取代了旧的美国专用 “Show thousands separator” 开关，提供五种样式：Locale、1,000,000、1.000.000、1 000 000、1000000。它只影响显示（存储值、排序、筛选、公式和导出都不变），但 Rollup precision 设置被移除——Rollup 现在继承底层数字字段的分隔符，所以依赖旧开关或 rollup 精度的人要重新核对显示的汇总值。
  • 付费新增（Cloud Plus/Business+ 和自托管 Business+） — Bookmarks（私密、可分组、可拖拽排序的工作区/base/表/视图/文档/仪表盘/工作流/脚本快捷方式）、Smart text 字段（把每个 Long text 单元格变成完整的 NocoDocs 编辑器，支持富文本、列表、表格、代码、数学、标注、附件、嵌入和 / 命令，可导出 Markdown/HTML/PDF）、Timeline 升级（从 Day 到 5 Years 共九级缩放，渐进式滚动），以及自助自托管许可证（通过 Cloud Account → Self-Hosted Licenses 购买，Stripe 结账，把 key 粘贴到 Admin Panel → License——不用联系销售）。多数团队在 CE/Free 上看不到这些，不过 Smart Text 在所有 Cloud 套餐（含 Free）上都有。
  • 免费/CE 的改进与修复 — 所有人可用：NocoDocs 中的 Mermaid 图（从代码块实时渲染 SVG，支持代码/分屏/图形三种视图模式、全屏，以及保留 SVG/Markdown 的导出）、按选区的字段汇总（页脚合计会按选中的单元格区域或勾选的行重算，分组也支持）、展开式记录侧栏成为新默认（表格保持可见；带 Fields/Comments/Revision History 标签，老布局可全屏）。还附带一大批 bug 修复，包括 API 方面：PATCH /api/v2/tables/{tid}/records 在外部 PG 表上静默忽略 LinkToAnotherRecord 更新（#13796）、外部 PG 主键 PATCH 报 422（#13789）、SingleSelect 仅改描述的 PATCH 出现 colOptions 回归（#13787），以及 #13845、#13828、#13813、#13812、#13769、#13341。
  • 结论 — 用 PostgreSQL、想要新功能或需要这些修复的人值得升级，但要留出时间处理 NC_SITE_URL 改名并复核数字格式。CE/Free 且用 SQLite/MySQL、又不需要 Mermaid、选区汇总或侧栏的团队可以合理跳过；运维还应注意，最大导入大小现在可以通过环境变量配置，不再是写死的默认值。

书签

> 你的工作很分散。书签将它们组合在一起。 您每天早上检查的黑板都位于一个工作区中。冲刺跟踪器在另一个中。关键文档位于 NocoDocs 中，而您报告的仪表板则埋藏在其他地方几个 click 深处。每次切换都需要时间和注意力。 **书签**是您最常使用的内容的个人快捷方式。固定工作区、基础、表格、视图、文档、仪表板、工作流程或脚本，并从任何地方通过一个 click 访问它。您的书签是私人的；队友有自己的。 从最左侧的扩展坞打开书签弹出窗口。将图钉分组到文件夹中，拖动以重新排序，并在列表增长时进行搜索。重命名和颜色更改自动同步。已删除或撤销项目的书签会自行清除，因此您的列表会自行保持干净。 书签适用于 NocoDB 云上的 **Plus** 计划及以上版本，以及自托管的 **Business** 计划及以上版本。 [了解有关书签的更多信息 →](/docs/product-docs/bookmarks) ## 智能文本字段 > 长文本包含注释。智能文本包含完整文档。 会议回顾需要标题和行动项目。客户电话摘要需要报价、清单和链接。项目简介需要标注、参考文献和临时表格。如今，这些内容从 NocoDB 转移到一个单独的文档中，打破了记录与其背后的故事之间的联系。 **智能文本**是长文本字段的新变体，它将每个单元格变成一个完整的文档编辑器，由与 [NocoDocs](/docs/noco-docs) 相同的引擎提供支持。打开它，每个单元格都会获得丰富的格式、列表、表格、代码块、数学、标注、文件附件和嵌入（YouTube、Loom、Figma、Google Docs、NocoDB 共享视图等）。键入 `/` 以获得完整的斜杠命令菜单。 Click 智能文本单元和侧面板与编辑器一起滑入。调整它的大小，切换到全屏，在不关闭的情况下遍历行，然后将深层链接直接复制到单元格。下载 Markdown、HTML 或 PDF 格式的内容。 网格显示紧凑的降价预览，因此行保持可扫描状态。打开展开的记录以内联阅读完整文档，并通过 click 切换到全屏模式。 智能文本可在 NocoDB Cloud（所有计划）和自托管付费计划（**Business** 及以上）上使用。需要内部 NocoDB 管理的 **PostgreSQL** 基础。 [了解有关智能文本的更多信息 →](/docs/product-docs/fields/field-types/text-based/smart-text) ## NocoDocs 中的美人鱼图 > 将图表写成文本。 NocoDocs 绘制其余部分。 请求流、数据库模式、发布时间线、决策树：一些想法以图表的形式比以段落的形式更快地落地。到目前为止，这意味着在其他地方绘制它，导出图像，然后将其粘贴到文档中，当下次有人需要调整箭头时，它就会变得陈旧。 **美人鱼图** 直接在 NocoDocs 代码块内呈现。插入代码块，将语言切换为 **Mermaid**，您的源代码将实时呈现为 SVG 图表。支持流程图、序列图、ER 图、甘特图和 10 多种其他图表类型。 每个 Mermaid 块都保存在块本身上的三种视图模式（代码、拆分、图表），因此每个读者都使用作者选择的视图打开文档。展开至全屏、下载为 SVG 并导出以保持图表完整：HTML 和 PDF 嵌入渲染的 SVG； Markdown 将源保留为“` ```mermaid `”栅栏，因此 GitHub 和其他与 Mermaid 兼容的查看器会为您渲染它。 美人鱼图适用于所有计划，包括社区版。 [了解有关美人鱼图的更多信息 →](/docs/noco-docs/document-content/mermaid-diagrams) ## 时间线视图增强功能 > 有些计划运行一周。其他人则运行五年。时间线现在可以扩展到两者。 每日和每周计划在时间轴上一直运作良好。任何更长范围的事情都会促使你滚动、跳转日期，或者将工作分成多个视图：多年产品路线图、五年建设计划、跨部门的投资组合审查。它们都不适合在屏幕上显示。 此版本发布了三个时间线升级： - **九个缩放级别**，从一天到五年概览：日、周、2 周、月、季度、6 个月、年、2 年和 5 年。在年份及以上，日期标题会堆叠年份、季度和月份层级，以便您在了解更广泛的跨度的同时保持方向。 - **平滑的水平和垂直滚动。** 在滚动时平移时间并逐渐加载记录，因此您可以浏览几个月或几年，而无需跳转到特定日期。当视图的记录通道数量多于屏幕所能容纳的数量时，垂直滚动就会启动。 时间轴视图适用于 NocoDB 云和自托管的 **Business** 计划及以上版本。 [了解有关时间线视图的更多信息 →](/docs/product-docs/views/view-types/timeline) ## 选择范围字段摘要 > 全桌总数始终为 1 click。现在子集总数也是如此。 当您想要每一行的总计时，字段摘要页脚非常有用。然而，当您想要子集的总计时，您必须添加过滤器，读取数字，然后再次删除过滤器。上周的记录。单个客户。某一地区的记录。每一次都走了一条小弯路。 **选择范围字段摘要** 将页脚的范围重新调整为您选择的任何内容：拖动一系列单元格，或勾选行复选框，页脚将针对该选择重新计算。清除它可返回全表总计。当网格分组时，这同样适用于每个组。 选择范围字段摘要适用于所有计划，包括社区版。 [了解有关字段摘要的更多信息 →](/docs/product-docs/fields/field-summary-footer#selection-scoped-summary) ## 扩展记录侧面板 > 模态覆盖网格。侧面板则没有。 现在，扩展记录默认作为**侧面板**打开，因此在您处理单个记录时网格保持可见。在面板标题中的 **字段**、**注释** 和 **修订历史记录** 之间切换，或使用文件预览和讨论模式进入全屏显示原始布局。 扩展的记录侧面板适用于所有计划，包括社区版。 [了解有关扩展记录的更多信息 →](/docs/product-docs/records/expand-record) ## 自助服务自行托管许可 > 自托管现在无需销售电话即可付费。 在自托管实例上激活付费计划过去意味着每一步都要与销售人员交谈：定价、配置、密钥交付。这对于大规模部署来说是有意义的。对于只想升级的团队来说，这会增加几天的摩擦。 **业务计划** 自托管许可证现在可以端到端购买和激活，无需销售参与。从您的 NocoDB 云帐户（**帐户 → 自托管许可证**）购买，完成 Stripe 结帐，然后将生成的密钥粘贴到 **管理面板 → 许可证** 中的实例中。付费功能立即解锁。 自托管许可证激活需要 NocoDB 在 **PostgreSQL** 上运行。 SQLite 和 MySQL 部署必须在激活许可证之前迁移。 [购买许可证 →](/docs/self-hosting/purchase-license) · [许可证激活 →](/docs/self-hosting/license-activation) ## 改进和修复 -
