nocodb 2026.10.1

> ⚠️ **时间戳包括毫秒。** 在 PostgreSQL 和 SQLite 上，API 响应、Webhook 负载和 CSV 导出中的日期和时间值现在包括毫秒 (`12:34:56.000+00:00`)。检查以固定格式读取日期的集成。 > **MCP 列出了每个工具。** `/mcp` 的 MCP 服务器现在列出了每个工具。如果 Windsurf 或 VS Code Copilot 显示太多工具，请使用 `/mcp-discovery` URL 重新连接。 [了解更多](https://docs.nocodb.com/docs/mcp#clients-that-cap-the-tool-list) > **密码更改注销您的应用程序。** 更改密码会删除您的 API 令牌并断开您通过 OAuth 授权的应用程序。 [了解更多](https://nocodb.com/docs/product/account-settings/api-tokens#password-changes-delete-your-tokens) ## 改进 - **手机上的经典应用程序** - 发布的适合手机屏幕的经典应用程序，包括侧边栏、工具栏、记录表单、仪表板组和枢轴小部件。 - **按更多字段类型分组** - 经典应用程序页面按链接、公式、查找、汇总和链接计数字段分组，列表小部件按设置分组。 [了解更多](https://docs.nocodb.com/docs/classic-apps/layouts/table#grid) - **在经典应用程序中调整列大小** - 拖动列表小部件中的列边缘以调整其大小。建筑商为每个人节省了宽度。 [了解更多](https://docs.nocodb.com/docs/classic-apps/layouts/table#list) - **从视图小部件打开记录** - 当您 click 时，仪表板上的日历、时间轴和甘特图小部件可以打开记录。 [了解更多](https://docs.nocodb.com/docs/classic-apps/layouts/dashboard#configuring-widgets) - **隐藏小部件标题** - 经典应用程序中的数据、图表和数字小部件具有*显示标题*开关。 - **按角色显示按钮可见性** - 经典应用程序中的页面按钮只能向您选择的角色显示。 [了解更多](https://docs.nocodb.com/docs/classic-apps/elements#buttons) - **重新排序用户过滤器选项卡** - 构建者将用户过滤器选项卡拖动到新顺序。 [了解更多](https://docs.nocodb.com/docs/classic-apps/elements#user-filters) - **按选项顺序对单选进行排序** - 单选字段上的排序可以按照其选项的顺序而不是 A 到 Z。 [了解更多](https://docs.nocodb.com/docs/product/tables/table-operations/sort#sort-a-single-select-field-by-option-order) - **退出其他设备** - *帐户* > *安全* 使您在除 NocoDB Cloud 上的当前浏览器之外的所有位置退出。 [了解更多](https://docs.nocodb.com/docs/product/account-settings/authentication/sign-out-other-devices) - **主页上的模板** - 主页和*新项目*页面显示 NocoDB Cloud 上的模板库，使用 AI 构建的项目以一些示例记录开始。 [了解更多](https://docs.nocodb.com/docs/product/projects/create-project#from-template) - **希腊语** - NocoDB 现已提供希腊语版本。 [了解更多](https://docs.nocodb.com/docs/product/account-settings/language) - **MCP 速率限制** - MCP 每个帐户都有自己的限制。检查它的 client 会被告知要等待多长时间。 - **MCP 连接的应用程序** - 连接的应用程序列表显示每个应用程序上次使用的时间。 [了解更多](https://docs.nocodb.com/docs/mcp/connections#managing-and-removing-access) - **OAuth 同意屏幕** - 同意屏幕显示您将被发送到的位置，并在应用程序未经 NocoDB 验证时发出警告。 - **实时更新** - 当协作者编辑时，图库、看板、地图、仪表板和经典应用程序记录审核会刷新。 ## 修复了什么 - **工作流程和 Webhooks** - *记录更新时*工作流程和更新 Webhooks 在通过 API、粘贴或外键更改链接或取消链接记录时运行。 [了解更多](https://docs.nocodb.com/docs/workflows/nodes/trigger-nodes/record-updated#how-it-works) - **公式** - 文本内包含 `?` 的公式进行评估，复选框值在 PostgreSQL 公式中充当 1 和 0，并且可以过滤 XOR 结果。 - **过滤器** - 汇总上的*为空白*过滤器有效，用户字段上的*喜欢*过滤器仅匹配名称。 - **链接** - 自链接一对一字段显示链接的记录，重复的项目保留其链接。 - **复制数据** - 复制和导入项目会使长文本和 JSON 值长度超过 100,000 个字符。 - **经典应用程序** - 在构建器中搜索、表单中的链接选择器、时间轴标签、默认页面名称、未隐藏的表单字段、列表滚动条和条件行颜色的行为符合预期。 - **共享** - 经典应用程序*共享*对话框可以为现有成员提供更高的角色，第二次邀请可以使第一个邀请链接保持有效。 - **附件** - Escape 和箭头键可在任何打开的附件预览中使用。 - **表** - 新表可以采用已废弃表的名称，甚至接近数据库名称长度限制。 - **SQL Server 和 Oracle** - 在 SQL Server 上重复字段工作的排序，在 Oracle 上，数字字段转换为十进制和文本公式排序。 - **人工智能聊天** - 聊天可与 Claude Opus 5.5、Sonnet 5.5 和 Fable 5.1 集成一起使用。 - **登录** - 忘记密码不会再让您退出，并且每种情况登录错误都会显示一条消息。 ## 自托管注意事项 - **首次注册** - 在新的许可安装中，第一位超级管理员无需重新启动即可获得默认工作区和组织。 - **许可证刷新** - “许可证”页面上的“刷新”或重新启动会激活显示为待处理的许可证。 [了解更多](https://docs.nocodb.com/docs/self-hosting/license-activation#refresh-license) - **安全附件** - 现在仅设置 `NC_ATTACHMENT_ACCESS_CONTROL_ENABLED=true` 即可打开安全附件，因此 `/download` 和 `/dl` 停止提供文件。使用附件响应返回的签名 URL。 [了解更多](https://docs.nocodb.com/docs/self-hosting/environment-variables#storage) - **本地数据库** - 专用网络上的 ClickHouse 以及 Unix 套接字上的 MySQL 或 PostgreSQL 需要 `NC_ALLOW_LOCAL_EXTERNAL_DBS=true`。 [了解更多](https://docs.nocodb.com/docs/self-hosting/environment-variables#product-configuration) - **MCP 令牌** - MCP 令牌秘密以散列方式存储并且仅显示一次。 MCP clients 中已有的令牌将继续工作。 - **长表名称** - 新的 SQL Server 和 Oracle 表名称限制为 125 个字符。 - **安全强化** - 强化了注册、邀请、OAuth、共享视图、数据导出、数据库连接和存储的机密，并修补了依赖项。 --- 有关2026.10.0中引入的功能的更多详细信息，请参阅[2026.10.0 changelog](https://docs.nocodb.com/docs/changelog/2026.10.0)。 -
