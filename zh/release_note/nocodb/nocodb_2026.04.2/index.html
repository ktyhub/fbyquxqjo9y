nocodb 2026.04.2

🚀 NocoDB：功能发布

## 诺科文档

**NocoDocs** 是直接内置于 NocoDB 基础中的全功能文档编辑器。无论您是维护内部 wiki、与功能跟踪器一起编写产品需求、记录入职流程，还是构建面向 client 的知识库，NocoDocs 都会将您的文档保存在其引用的数据旁边。 - **丰富的编辑：** 标题、代码块、标注、表格、图像、文件附件、嵌入、数学表达式和用于 rapid 块插入的斜杠命令调色板 - **实时协作：** 线程式讨论可在团队成员中循环播放，而无需离开文档 - **分层组织：** 拖放文档树以使用嵌套页面构建您的知识库 - **自动保存：** 每次更改都会在您键入时自动保存，因此您永远不会丢失工作 - **导出到任何地方：** 使用单个 click 的 Markdown 或 HTML 👉 [了解更多关于NocoDocs →](https://nocodb.com/docs/noco-docs) ## 编辑器现在可以管理视图 我们听到了您大声而清晰的声音。这一变化是对我们社区明确要求我们恢复的内容的直接回应，我们很高兴看到它的回归。 **编辑者**角色现在涵盖了**协作**视图的整个生命周期，因此日常布局工作不再需要通过创建者或所有者进行。无论您的分析师需要调整每周审查的过滤器，您的销售团队想要复制新区域的管道视图，还是任何团队成员想要将排序放入共享视图中，编辑都可以直接处理。 [了解有关协作、个人和锁定视图的更多信息 →](https://nocodb.com/docs/product-docs/views/actions-on-view) **编辑现在可以做什么** - 创建、重命名、复制、删除和配置**协作**视图（过滤、排序、分组依据等）。 **仍然需要创建者或所有者**（不变） - 锁定或解锁视图。 - 修改或删除锁定的视图。 #### 角色变化一览 现在，以下操作的最低作用已降低。 “创作者+”指创作者或所有者； “编辑者+”是指编辑者、创建者或所有者。 |行动|最低角色（之前）|最低角色（现在）| |---|:---:|:---:| |管理协作视图（创建、重命名、复制、删除、转换或编辑过滤器、排序、分组依据等）|创作者+ |编辑+ | ## 改进 - **用户字段默认设置为当前用户** - 用户字段现在可以使用 **当前用户** 作为默认值，因此每个新记录都会自动分配给创建它的人，无需手动选择器。 - **货币字段的汇总精度** - 修复了当汇总针对货币字段时精度（小数位数）选项不可见的问题。可以再次配置十进制格式。 - **分组视图上的评论计数** - 修复了对视图进行分组时评论计数指示器无法正确呈现的问题。现在，计数会按预期显示在每条记录上。 ### 问题已关闭 - [**已关闭**] 🐛 Bug：仅将多行字段从小到大的字母错误重新格式化为 capital 字母错误 [#13563](https://github.com/nocodb/nocodb/issues/13563) - [**已关闭**] 🐛 Bug：“链接到另一条记录”在 v2026.04.1 的 UI 中创建意外的 `_nc_m2m_*` 表 [#13540](https://github.com/nocodb/nocodb/issues/13540) - [**已关闭**] 🐛 Bug：初始化项目错误 [#13534](https://github.com/nocodb/nocodb/issues/13534) - [**已关闭**] 🐛 Bug：使单/多 - 选择颜色更好 [#13532](https://github.com/nocodb/nocodb/issues/13532) - [**已关闭**] 🐛 Bug：选择字段选项颜色在 v2026.04.0 中显示不正确 [#13514](https://github.com/nocodb/nocodb/issues/13514) - [**已关闭**] Bug：评论计数徽章在页面刷新时消失，并在分组视图中丢失 [#13062](https://github.com/nocodb/nocodb/issues/13062) - [**🔦 类型：功能**][**👮 范围：身份验证**] 🔦 功能：两因素身份验证 (2FA) [#2731](https://github.com/nocodb/nocodb/issues/2731)
