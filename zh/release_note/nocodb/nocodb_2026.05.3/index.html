nocodb 2026.05.3

这个项目是干啥的：一个开源版Airtable，把数据库变成在线表格看板还能嵌入关联记录，给不想写代码就想管数据的团队用。

变更架构图

亮点

  • V1→V2 链接迁移加守卫——行为变更 — PR #13923 在源 schema 为只读时拦截 V1→V2 链接升级，修复了 #13911（即便关闭 ‘Allow schema change’，升级仍会静默改动 schema）。这是有意的行为变更：这类升级现在会失败而不是改 schema，因此之前强行通过过的迁移要重跑一遍。周边的 V2/LTAR 修复也值得这么干：”+” 按钮会把新建子记录自动关联到父记录（#13954/#13770）、关联字段的编辑能在界面上正确渲染（#13798）、多个外键指向同一列时显示正确的值（#13759）、PostgreSQL 同表多对多不再产生多余链接（#13349）。
  • 社区版构建修复 — PR #13932 补齐了缺失的 CE 构建文件，找回 CE 2026.05.2 丢掉的网页 favicon 和静态页标题（#13928）。用 CE 镜像自托管、在 2026.05.2 之后看到标签页空白/默认标题的用户建议升级；EE 和 Cloud 用户不受影响。
  • 鉴权与 API 加固 — #13933 让 /auth/user/me 在 JWT 无效时返回 401，不再给出误导性响应；#13734 恢复了 API Key 对 v2 端点的访问，此前这些端点会返回 403 “Forbidden - Unauthorized access”。表单/记录通知邮件现在也能正确渲染关联和用户字段（#13956）。如果你对接 API 或依赖邮件自动化，这条要留意。
  • 这个补丁里还有实打实的功能 — 分组可按组单独启用/禁用（#13921/#13851，另含 #13936 里 ’?’ 子分组绑定修复）、Docs 修订历史（#13919）和公开分享（#13819）、组织管理员角色分配（#13946）、表单通知邮件可自定义主题和纯文本正文（#13891/#13890）、通过 CSV 跨所有表类型批量更新记录（#13841）、AutoNumber 列可作为显示值（#13934）。另修复：CSV 导出保留界面列顺序（#13918/#13768）、MySQL 9.0.1 升级后取数报错（#13404）、webhook 的 Action/Modification 字段（#13110）、“1 hour ago” 时区偏移（#13464）；依赖安全告警通过 pnpm overrides 修补（#13929）。
  • 升级建议 — 正在走 V1→V2 链接迁移、用 CE 自托管，或者用到分组、Docs、表单通知的团队都建议升级。纯 V2 且不涉及这些特性的稳定环境可以跳过——这是功能+修复补丁，不是强制安全版本，API 无破坏性变更。注意 v3 相关项（timeline gantt #13960、v3 API separator 枚举 #13959）也随本版发布，但只有跟进 v3 的人才需要关心；它不是空发布或仅改元数据的重新打标。
