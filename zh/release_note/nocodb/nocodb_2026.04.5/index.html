nocodb 2026.04.5

变更流程图

亮点

  • PostgreSQL ENUM 现在映射为 SingleSelect — 本版头号特性（#4862）补上了把 NocoDB 指向已有 Postgres schema 的团队长期缺失的能力：ENUM 列会显示为 SingleSelect 字段，数据库的标签直接作为选项，读/写/筛选/排序/分组端到端保持类型安全。如果你的 Postgres schema 用 ENUM 作为取值范围的唯一来源，就不用再维护一个平行字段或手动同步取值了——单凭这一条就值得升级。
  • ENUM 编辑直接写库，共享类型会安全分叉 — 在 NocoDB 里新增/改名/删除选项会直接改动底层 Postgres ENUM 类型；当一个 ENUM 类型被多列共用时，NocoDB 会为你编辑的那一列分叉出新类型，避免影响其他列。这是上线前要弄清的关键行为提醒：“只是改个字段”现在也可能改动共享的数据库类型。范围有限——仅 SingleSelect；ENUM 数组和 MultiSelect 支撑的 ENUM 仍不支持，请据此规划。
  • 大 schema 性能与视图正确性 — 几百张表的 base 通过流式加载侧栏元数据，明显变快；两个视图 bug 也修了：CSV 导出现在遵循生效的筛选条件（之前可能漏出被筛选隐藏的行——对导出筛选视图的人来说是真实的数据正确性风险），共享看板视图在分组列被隐藏时不再加载失败（#13732）。schema 大或经常分享/导出视图的团队收益最大。
  • 生产环境要紧的 API 与管理修复 — APIv3 不再把一对多字段截断到 5 条关联记录（#13616）；owner 又能发邀请了（#13611）；JSON 导出现在可以作为数据库模板使用（#13493）；另外还有 NocoDocs 的 RTL 支持（#13617）、表单字段自动补全（#5913），以及日历拖拽/UUID 只读的修复。
  • 升级结论 — 本版没有说明破坏性变更或迁移步骤，是真正的功能版本（不是重新打标或仅改元数据）。外部 Postgres 用了 ENUM、维护大视图或共享视图、依赖 APIv3 关联记录和导出的话建议升级；如果用的是 SQLite/MySQL、base 很小，且上面修的流程都跟你无关，可以合理跳过。

🚀 NocoDB：功能发布

## PostgreSQL 枚举支持 来自外部 Postgres 源的 **PostgreSQL ENUM** 列现在在 NocoDB 中显示为 **SingleSelect** 字段。这是社区中投票最多的请求之一 ([#4862](https://github.com/nocodb/nocodb/issues/4862))，这为将 NocoDB 连接到 Postgres 数据库的团队弥补了长期存在的差距，其中 ENUM 已经定义了允许的值。 无论您是将 NocoDB 连接到现有的 Postgres 架构（其中 ENUM 是事实来源）、构建混合堆栈（其中您的应用程序写入 ENUM 值并让您的团队在 NocoDB 中编辑它们），还是只是想强制执行一组更接近数据的固定值，ENUM 列现在都在 NocoDB 中显示为正确的选择字段。读取、写入和往返保持类型安全，并且完整的允许值集被端到端地保留。 **支持什么** - 从任何连接的 Postgres 源读取 ENUM 列 - 它们显示为 SingleSelect 字段，数据库标签作为选项。 - 从网格、图库、看板和扩展记录视图编辑 ENUM 值；下拉列表仅限于列的定义标签。 - 从 NocoDB 内部添加、重命名和删除选项 - 更改直接应用于底层 Postgres ENUM 类型。 - 当多个列共享相同的 ENUM 类型时，NocoDB 会安全地为正在编辑的列创建一个新类型，因此更改不会泄漏到使用相同 ENUM 的其他列。 - 过滤、排序、分组和搜索 ENUM 字段与任何其他 SingleSelect 完全相同。 > **注意：** PostgreSQL ENUM 在此版本中仅映射到 **SingleSelect**。尚不支持 ENUM 数组列和 MultiSelect 支持的 ENUM。 ## 改进和修复 - **大型模式上的基础加载速度更快** - 具有数百个表的基础现在打开速度明显更快，当您滚动侧边栏时，表元数据会流入。 - **CSV 导出遵循活动过滤器** - 修复了导出过滤视图有时会包含活动过滤器集隐藏的行的问题。导出现在与视图显示的内容完全匹配。 - **共享看板视图** - 修复了当堆叠列隐藏在视图中时共享看板视图无法加载的问题。 ### 问题已关闭 - [**关闭**] 当视图中隐藏分组（堆叠）列时，共享看板视图无法加载 [#13732](https://github.com/nocodb/nocodb/issues/13732) - [**已关闭**] 🔦 功能：支持 NocoDocs 中从右到左 (RTL) 文本方向 [#13617](https://github.com/nocodb/nocodb/issues/13617) - [**已关闭**] 🐛 Bug：APIv3 在一对多字段中仅返回 5 条链接记录 [#13616](https://github.com/nocodb/nocodb/issues/13616) - [**已关闭**] 🐛 Bug：所有者无法向新会员发送邀请 [#13611](https://github.com/nocodb/nocodb/issues/13611) - [**已关闭**] 🐛 Bug：pnpm bootstrap 失败并出现 TypeScript 错误 -filterUtils.ts 中的 dbTableFilter 上不存在属性“delete”[#13602](https://github.com/nocodb/nocodb/issues/13602) - [**已关闭**] 🐛 Bug：在日历月视图中拖动记录会将日期设置为一周的第一天 [#13593](https://github.com/nocodb/nocodb/issues/13593) - [**已关闭**] 🐛 Bug：可以清除 UUID 类型（只读）的 Cell [#13588](https://github.com/nocodb/nocodb/issues/13588) - [**已关闭**] 🐛 Bug/功能：JSON 导出不完整且无法用作数据库模板 [#13493](https://github.com/nocodb/nocodb/issues/13493) - [**已关闭**] 🔦 功能：在表单输入字段中添加自动完成功能 [#5913](https://github.com/nocodb/nocodb/issues/5913)
