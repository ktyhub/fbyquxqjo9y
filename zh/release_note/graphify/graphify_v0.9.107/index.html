graphify v0.9.107

修订 发布时间2026年11月11日 来源Graphify-Labs/graphify 英文原文

graphify v0.9.107

  • 修复：cpp 折叠无参数成员声明 (bar()) 将其在 definition_file 中的实现记录为锚定到与 source_file 相同的根的路径，而不是相对于缓存/输出根的 ../-walk。 0.9.106 中添加的零参数协调存储了内部 _cpp_source_key 证明形式，_norm_source_file 无法重新锚定该形式（它仅相对化绝对路径），因此树外语料库得到了损坏的 definition_file。由于这个原因，兄弟 decl/def 合并已经存储了原始 source_file；现在两条路径都一致了。包含路径证明仍然使用密钥形式。
  • 修复： llm 超时或上下文溢出被识别并放弃的切片（无法进一步分割，或重试深度已耗尽）现在标记其文件部分，因此尾部切片超时的文档不再被缓存并从其其他切片标记为完整；它会在下次运行时重新排队，同时保留同级文件的结果（#5099，感谢@khrisshie）。
  • 修复：php 路由路径扫描在闭包自己的参数处停止，因此 $app->get('/users', function () { ... }) 保留 GET /users 而不是读取闭包之后的尾随字符串参数作为路由；关闭之前的合法路径保持不变（#5135，感谢@mppyxx）。
  • 修复：一个文件中的 ids 两个相同类型的模块级声明，其名称仅通过前导/尾随下划线（function _save(){} 和 function save(){ return _save() }）不同，又是两个节点而不是一个，并且它们之间的调用是真正的 save -> _save 边，而不是捏造的 save -> save 自调用；首先出现的声明保留普通 ID，另一个则加盐。影响 JS、TS、C、C++、PHP、Ruby、Kotlin、Swift 和 Lua（#2810，感谢 @khrisshie）。
  • 修复：一个类、特征、接口或枚举的 php 方法，其名称仅通过前导/尾随 _ (_x() / x()) 不同，是单独的节点，而不是一个吞没另一个：一个公共名称保留其 id，其他名称加盐，如 Python、C#、JS/TS 和 Solidity，因此 $this->x() 和 $b->x() 达到x() 没有迷路，而且 $this->_x() 看起来不再像一个自调用（#5137，感谢 @khrisshie）。
  • 修复：一个类的 java 成员的名称仅因前导/尾随 _ (_name / name) 或仅大小写不同 (run / Run，Java 将其视为不同) 获得单独的节点 id，而不是一个吞下另一个；公共名称保留其 id，并且双胞胎像其他语言一样被加盐，因此正确调用每个解析（#5151，感谢 @rohit-jsfreaky）。
  • 修复：测试复制缓存 terraform id 测试接受在资源压力下无法启动的工作池（它回退到顺序并发出警告），而不是断言池始终启动；真正损坏的池仍然无法通过测试（#5136，感谢@mppyxx）。
  • 修复：php/js 通过 ESM 命名空间成员 (import * as ns; ns.handler()) 或整个模块 require 的调用仅在目标实际可调用时才解析，因此命名不可调用导出（对象文字、常量）的命名空间成员不再获得虚假调用边缘（#5144，感谢 @ayushcodes10）。
  • Perf：查询读取路径（查询/解释/路径/受影响和 MCP 图形加载）不再导入每种语言提取器，从而降低只读命令的导入成本；图形输出未更改（感谢@rohit-jsfreaky）。
  • Perf：提取，当未设置工作线程数量时，AST 工作线程池的大小取决于未缓存的工作量（每约 500 KB 的未缓存源有一个工作线程，上限为 CPU 计数和文件计数），因此小型增量构建会停止旋转整个池；输出对于工人数量是不变的（感谢@rohit-jsfreaky）。
  • 更改：云 OSS 表面（自述文件、CLI 帮助/安装文本、所有 31 个语言环境中的翻译文档以及代理技能）现在指向 app.graphify.com/signup 上的无卡免费计划，而不是 /login 上的“14 天试用版”（试用版仅是付费计划并且需要一张卡，因此旧副本将两者混为一谈）。链接带有每个表面标记的 utm_campaign=oss UTM，因此注册可以归因于它的来源。
  • 更改：云 构建后的 CLI 微调是上下文相关的。它仅适用于 TTY（从不在 CI 或代理管道中），尊重 GRAPHIFY_NO_TIPS/GRAPHIFY_NO_CTA，并在版本 1、5 和 20 上显示，然后永远保持安静。当本地图表达到 25k 个节点（免费计划的每个存储库截止点）时，微移会切换到特定规模的线路（标记为 utm_content=scale），该线路销售 Graphify Pro 并链接到 14 天试用版的定价，而不是免费注册：大小不再适合免费计划的存储库，因此将其指向免费计划将直接达到限制。 AST 缓存模式增加到 44；热缓存重新运行受影响的 C++、PHP、Java 和模块级 ID 提取。
